# Placeholders

Text placeholders allow you to get stuff about your Minecraft instance, like the player's name, the window size or the currently used memory, but they also let you do fancy things like calculating things, getting localized text or even parse JSON files!

# Using Placeholders

Most elements that have text inputs support placeholders. You can see if a text input supports placeholders when editing it. If the full-screen **text editor** opens when editing the text, it supports placeholders. 

To find a **list of all placeholders**, just click on the **Placeholders** button in the **top-right corner** of the **text editor**.

Clicking on a placeholder in the placeholder list will paste it to the text content!

# Placeholder Values

Some placeholders need you to set some values to work properly. Always check if the pasted placeholder has a `values` section you need to configure. 

If you are not sure what to set as value(s), hover the placeholder in the placeholder list for a description tooltip!
