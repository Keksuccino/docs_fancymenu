# Modifizierte FancyMenu-Datei gefunden

Wenn dieser Fehler angezeigt wird, liegt das wahrscheinlich an einer beschädigten Minecraft-Instanz, einem fehlerhaften Mod-Loader oder einem problematischen Mod-Launcher.

Normalerweise wird er angezeigt, wenn FancyMenu verändert wurde. Er kann jedoch auch auftreten, wenn dein Spiel Mods nicht wie vorgesehen korrekt lädt.

Dies kann daran liegen, dass deine **Minecraft-Instanz auf irgendeine Weise beschädigt** ist. In diesem Fall solltest du dein **Spiel neu installieren**.

Eine weitere mögliche Ursache für den Fehler ist, dass dein **Spiel beim Start teilweise abstürzt**, weil einige Mods (einschließlich FancyMenu) **nicht korrekt geladen werden konnten**. Poste in diesem Fall bitte deine Datei `/logs/latest.log` auf dem [Discord-Server](https://discord.gg/rhayah27GC) oder [erstelle ein Issue auf GitHub](https://github.com/Keksuccino/FancyMenu/issues).

Der Fehler kann auch durch die **Verwendung eines problematischen Mod-Launchers** ausgelöst werden (die meisten gecrackten/piratisierten Launcher verursachen diesen Fehler – bitte kaufe das Spiel). Empfohlene Launcher, die stabil sind und hervorragend mit FancyMenu funktionieren, sind der **offizielle CurseForge-Launcher und der offizielle Modrinth-Launcher**.
