# Element-Deckkraft

Die meisten Elemente in FancyMenu (mit einigen Ausnahmen) unterstützen das Festlegen ihrer Deckkraft über ihr Rechtsklick-Menü.

Der Deckkraftwert von Elementen unterstützt Platzhalter, wodurch es möglich ist, ihre Deckkraft dynamisch auf Basis des Platzhalters zu aktualisieren.

Dadurch ist es möglich, benutzerdefinierte Fade-Logik zu erstellen, wenn man sie in Kombination mit Ticker-Elementen verwendet, um Variablenwerte zu aktualisieren und diese dann über Platzhalter als Deckkraft anzuwenden.

Um die Deckkraft von Elementen festzulegen, **klicke mit der rechten Maustaste auf das Element -> Deckkraft -> Setzen**.

# Elemente ein- und ausblenden

Wenn du Elemente einfach nur ein- oder ausblenden möchtest, ist es wahrscheinlich einfacher, die integrierte Fading-Funktion der Elemente zu verwenden. Du kannst das Fading im Rechtsklick-Menü der Elemente aktivieren.

Diese Funktion sorgt dafür, dass Elemente jedes Mal eingeblendet werden, wenn sie geladen werden – sei es beim ersten Laden beim Öffnen eines Menüs oder wenn die Ladeanforderungen des Elements dazu führen, dass es geladen wird. Sie werden immer dann ausgeblendet, wenn ihre Ladeanforderungen dazu führen, dass sie entladen bzw. unsichtbar werden.

Die Fading-Funktion unterstützt das Festlegen einer Fading-Geschwindigkeit, um zu steuern, wie schnell ein Element ein- oder ausgeblendet werden soll.
