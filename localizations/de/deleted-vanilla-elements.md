# Vanilla-Elemente löschen

Sie können alle Standard-/Vanilla-Elemente (einschließlich einiger Mod-Elemente), die im Layout-Editor sichtbar sind, ausblenden. Wenn sie sichtbar sind, klicken Sie einfach mit der **rechten Maustaste** darauf und anschließend auf **Löschen**.


# Gelöschte Vanilla-Elemente wiederherstellen

Um gelöschte/ausgeblendete Vanilla-Elemente wie Schaltflächen, Logos oder andere Elementtypen wieder sichtbar zu machen, öffnen Sie einfach das Layout, in dem Sie sie gelöscht haben, und **gehen Sie dann zur Menüleiste -> Element -> Gelöschte Vanilla-Elemente**. Klicken Sie anschließend mit der **linken Maustaste** auf das bzw. die Elemente, die Sie wieder sichtbar machen möchten.

Wenn die gelöschten Elemente nicht im Menü aufgeführt sind, ist das falsche Layout geöffnet, und Sie müssen das Layout finden, in dem Sie sie gelöscht haben.
