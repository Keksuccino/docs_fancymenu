# Ladebildschirm

FancyMenu passt den Splash-/Ladebildschirm von Minecraft nicht an. Verwende dafür das Add-on [Drippy Loading Screen](https://www.curseforge.com/minecraft/mc-mods/drippy-loading-screen).
