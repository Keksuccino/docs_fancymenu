# Benutzerdefinierter Mauszeiger

Füge einem Layout ein [**Cursor**-Element](/elements#cursor) hinzu, um den Systemzeiger auf diesem Bildschirm zu ersetzen:

1. Wähle **Neues Element -> Cursor**.
2. Lege eine PNG-Textur mit RGBA-Farbe fest.
3. Lege **Hotspot X** und **Hotspot Y** auf den Pixel der Textur fest, an dem Klicks erfolgen sollen.
4. Aktiviere die Editor-Vorschau, wenn du den Mauszeiger während der Bearbeitung überprüfen möchtest.
5. Verwende ein [universelles Layout](/universal-layouts), wenn derselbe Mauszeiger auf mehreren unterstützten Bildschirmen angezeigt werden soll.

Kleine Mauszeigertexturen wie `32×32` oder `64×64` werden empfohlen. Aussehen und Verhalten des Mauszeigers können je nach Betriebssystem variieren.
