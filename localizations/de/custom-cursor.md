# Benutzerdefinierter Mauszeiger

FancyMenu ermöglicht es dir, pro Bildschirm einen benutzerdefinierten Mauszeiger festzulegen.

Dazu fügst du einfach ein neues **Cursor**-Element zu einem Layout hinzu und klickst es mit der rechten Maustaste an, um eine Cursor-Textur festzulegen.

Wenn der benutzerdefinierte Mauszeiger auf allen Bildschirmen angezeigt werden soll, solltest du ein **universelles Layout** verwenden.
