# Welt-Ladebildschirme

Wenn du eine Welt lädst oder einem Server beitrittst, ist dir wahrscheinlich schon aufgefallen, dass dort Bildschirme angezeigt werden, die du nicht wirklich anpassen kannst, weil sie automatisch geschlossen werden.

Um sie zu bearbeiten, musst du eine Instanz von ihnen öffnen, die so lange offen bleibt, wie du möchtest. Das ist möglich, indem du eine „Dummy-Screen-Instanz“ von ihnen öffnest.

Die „Dummy-Screen-Instanzen“ sind eine Funktion von FancyMenu, mit der es möglich ist, EINIGE der Bildschirme zu öffnen, die zu schnell verschwinden, um sie anzupassen.

Um alle Bildschirme zu sehen, die über die Funktion „Dummy Screen Instances“ geöffnet werden können, klicke auf **Menüleiste -> Tools -> Dummy Screen Instances**. Das sich öffnende Menü zeigt alle Bildschirme, die du als Dummy-Screen-Instanz öffnen kannst. Wenn du im Menü **mit der linken Maustaste** auf einen Bildschirm klickst, wird eine Dummy-Instanz davon geöffnet, damit du ihn in Ruhe anpassen kannst.

Wenn du zum Beispiel einer Welt oder einem Server beitrittst, werden während des Ladevorgangs mindestens zwei Bildschirme angezeigt:

- Level-Ladebildschirm (auch: Welt-Ladebildschirm)
- Allgemeiner Dirt-Message-Bildschirm (auch: Dirt-Message-Bildschirm)

> **Wichtig:** Der „Welt-Ladebildschirm“ ist nicht dasselbe wie der „Spiel-Ladebildschirm“ (auch: Splash Screen oder Ressourcen-Neuladebildschirm). Der „Spiel-Ladebildschirm“ kann mit **Drippy Loading Screen** angepasst werden, einem Add-on für FancyMenu.
