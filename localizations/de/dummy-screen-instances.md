# Welt-Ladebildschirme

Wenn du in eine Welt lädst oder einem Server beitrittst, ist dir wahrscheinlich schon aufgefallen, dass dort Bildschirme angezeigt werden, die du eigentlich nicht wirklich anpassen kannst, weil sie automatisch wieder geschlossen werden.

Um sie zu bearbeiten, musst du eine Instanz von ihnen öffnen, die so lange offen bleibt, wie du möchtest. Das ist möglich, indem du eine „Dummy-Bildschirminstanz“ von ihnen öffnest.

Die „Dummy Screen Instances“ sind eine Funktion von FancyMenu, mit der sich EINIGE der Bildschirme öffnen lassen, die sonst zu schnell verschwinden, um sie anzupassen.

Um alle Bildschirme zu sehen, die über die Funktion „Dummy Screen Instance“ geöffnet werden können, klicke auf **Menüleiste -> Tools -> Dummy Screen Instances**. Das sich öffnende Menü zeigt alle Bildschirme, die du als Dummy-Bildschirminstanz öffnen kannst. Ein **Linksklick** auf die Bildschirme im Menü öffnet jeweils eine Dummy-Instanz, damit du sie in Ruhe anpassen kannst.

Wenn du zum Beispiel einer Welt oder einem Server beitrittst, werden während des Ladevorgangs mindestens zwei Bildschirme angezeigt:

- Level-Ladebildschirm (auch: Welt-Ladebildschirm)
- Allgemeiner Schmutz-Nachrichtenbildschirm (auch: Schmutz-Nachrichtenbildschirm)

> [!WARNING]
> **Wichtig:** Der „Welt-Ladebildschirm“ ist nicht dasselbe wie der „Spiel-Ladebildschirm“ (auch: Splash Screen oder Ressourcen-Neuladebildschirm). Der „Spiel-Ladebildschirm“ kann mit **Drippy Loading Screen** angepasst werden, einem Add-on für FancyMenu.
