# Значок і заголовок вікна

FancyMenu дає змогу змінювати значок і заголовок вікна Minecraft.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# Користувацький значок

Щоб встановити власний значок, відкрийте [**Global Customizations**](./global-customizations) через **Customization -> Global Customizations**.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- Значки мають бути файлами **PNG** (а для macOS — **ICNS**)
- Значки повинні мати принаймні **1 прозорий піксель**, щоб не виглядати зламаними (помилка MC/LWJGL)
- Потрібно вказати дійсні файли для всіх 3 версій значка (16x16, 32x32, macOS), щоб увімкнути перемикач користувацького значка

> [!CAUTION]
> **Ще раз**: Значки повинні мати принаймні **1 прозорий піксель**, щоб не виглядати зламаними (помилка MC/LWJGL). Значок виглядатиме пошкодженим, якщо не має хоча б одного повністю прозорого пікселя!


# Користувацький заголовок

Щоб встановити власний заголовок, відкрийте [**Global Customizations**](./global-customizations) через **Customization -> Global Customizations**.
