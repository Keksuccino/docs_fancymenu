# Іконка та назва вікна

FancyMenu дозволяє змінювати іконку та назву вікна Minecraft.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# Власна іконка

Щоб встановити власну іконку для вікна Minecraft у FancyMenu 3.9.0+, перейдіть до **Customization -> Global Customizations** у **рядку меню**.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- Іконки мають бути файлами **PNG** (а для **macOS** — **ICNS**)
- Іконки повинні мати щонайменше **1 прозорий піксель**, щоб не виглядати зламано (помилка MC/LWJGL)
- Потрібно вказати дійсні файли для всіх 3 варіантів іконок (16x16, 32x32, macOS), щоб увімкнути перемикач власної іконки

> **Ще раз**: Іконки повинні мати щонайменше **1 прозорий піксель**, щоб не виглядати зламано (помилка MC/LWJGL). Іконка виглядатиме пошкодженою, якщо в ній немає хоча б одного повністю прозорого пікселя!
{.is-danger}


# Власна назва

Щоб встановити власну назву для вікна Minecraft у FancyMenu 3.9.0+, перейдіть до **Customization -> Global Customizations** у **рядку меню**.
