# Користувацькі GUI

FancyMenu дає змогу налаштовувати існуючі екрани GUI, але також дозволяє додавати абсолютно нові й наповнювати їх елементами.

# Додавання нового екрана

Щоб додати новий екран, перейдіть до **Customization -> Custom GUIs -> Manage Custom GUIs**.

![custom_gui_1](https://github.com/Keksuccino/FancyMenu/assets/35544624/23e704ee-ccb5-434d-b75f-f4418399d9b7)

У наступному меню натисніть **New GUI**.

![custom_gui_2](https://github.com/Keksuccino/FancyMenu/assets/35544624/035454e8-b089-4b9a-9092-89a193c0eacd)

Тут потрібно надати вашому новому GUI унікальний ідентифікатор, а також ви можете налаштувати інші параметри базової поведінки екрана.
Коли закінчите, натисніть **Done**.

![custom_gui_3](https://github.com/Keksuccino/FancyMenu/assets/35544624/1fbed3f9-9c81-4c73-85c7-d152146c55d8)

Тепер у вас є новий порожній GUI. Щоб відкрити його, виберіть GUI в меню **Manage Custom GUIs** і натисніть **Open GUI**.

![custom_gui_4](https://github.com/Keksuccino/FancyMenu/assets/35544624/b2e6a4b7-540d-4bf2-9dce-09bfff11ae7e)

Це відкриє все ще досить порожній екран GUI. Щоб зробити його менш порожнім, просто створіть для нього новий макет так само, як ви робили б для будь-якого іншого екрана.

![custom_gui_5](https://github.com/Keksuccino/FancyMenu/assets/35544624/e7e06a5f-46b3-48f1-9ad9-96a7565c97a9)

# Відкриття GUI через дію

Останній крок — надати звичайним користувачам доступ до вашого GUI. Найпростіший спосіб зробити це — використати дію **Open Screen or Custom GUI** з кнопкою, повзунком або ticker-елементом.

![custom_gui_6](https://github.com/Keksuccino/FancyMenu/assets/35544624/b5cc6518-3fc4-4715-96d4-44b65ab7831d)

# Відкриття GUI через команду

Ви також можете відкривати свій користувацький GUI через [внутрішньоігрову команду](./commands#openguiscreen).
Це навіть дає змогу віддалено відкривати GUI для інших користувачів!

# Режим спливаючого вікна

Починаючи з FancyMenu v3.8.0, Custom GUIs підтримують "Popup Mode", який робить їх схожими на спливаюче вікно, що відкривається поверх іншого екрана (попереднього екрана, з якого було відкрито Custom GUI). Цей параметр можна вмикати окремо для кожного Custom GUI в його налаштуваннях.

FancyMenu 3.9.0 також додає опцію перемикання накладання фону екрана для Custom GUIs під час перебування у світі. Використовуйте її, коли хочете вимкнути або залишити розмиття/темний тон позаду Custom GUI, відкритого поверх гри.
