# Користувацькі GUI

Користувацькі GUI — це нові екрани, які можна заповнювати [елементами](./elements) FancyMenu.

> [!CAUTION]
> Користувацькі GUI можуть виконувати дії. Імпортуйте їх лише з джерел, яким довіряєте.

# Створення користувацького GUI

1. Відкрийте **Налаштування -> Користувацькі GUI -> Керування користувацькими GUI**.
2. Виберіть **New GUI**.
3. Введіть ідентифікатор і налаштуйте параметри екрана.
4. Виберіть **Done**, а потім відкрийте новий GUI в менеджері.
5. Створюйте та редагуйте його макет, як будь-який інший екран.

Ідентифікатори можуть містити малі літери, цифри, `.`, `_` і `-`. Вони не можуть містити пробіли й мають бути унікальними. Порожні, некоректні або дубльовані ідентифікатори не можна зберегти.

Для користувацьких GUI завжди ввімкнено налаштування екрана; перемикач налаштування не можна вимкнути.

# Налаштування екрана

| Параметр | Поведінка |
|---|---|
| Дозволити ESC | Дозволяє клавіші Escape закрити GUI й повернутися до батьківського екрана |
| Призупиняти гру/світ | Призупиняє одиночну гру, поки GUI відкрито |
| Показувати фон світу | Показує завантажений світ позаду GUI |
| Накладка фону світу | Додає стандартне розмиття/темну накладку поверх світу |
| Режим спливаючого вікна | Залишає батьківський екран видимим позаду користувацького GUI |
| Накладка фону спливаючого вікна | Додає розмиття/тонування поверх батьківського екрана в режимі спливаючого вікна |

Режим спливаючого вікна не об’єднує два екрани. Користувацький GUI залишається активним екраном, а батьківський відображається позаду нього. Закриття користувацького GUI повертає до цього батьківського екрана, якщо він існує.

# Відкриття користувацького GUI

Використайте точний ідентифікатор користувацького GUI з одним із таких способів:

- [**Дія Open Screen or Custom GUI**](./action-scripts#open-screen-or-custom-gui-opengui).
- [`/openguiscreen` команда](./commands#openguiscreen).

# Перевизначення існуючого екрана

Користувацький GUI може замінити екран Vanilla або мода щоразу, коли цей екран відкривається.

1. Створіть користувацький GUI для заміни.
2. Відкрийте екран, який хочете замінити.
3. Увімкніть **Налаштування -> Налаштування -> Розширений режим налаштування**.
4. Виберіть **Налаштування -> Користувацькі GUI -> Перевизначити поточний на користувацький GUI**.
5. Виберіть користувацький GUI для заміни.

Керувати збереженими перевизначеннями можна через **Налаштування -> Користувацькі GUI -> Керування перевизначеними екранами**.

Перевизначення пропускає оригінальний екран, тому перевірте його навігацію та будь-які функції, що залежать від поведінки оригінального екрана.
