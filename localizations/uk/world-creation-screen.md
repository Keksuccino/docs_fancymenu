# Екран створення світу

Якщо ви вже намагалися налаштувати екран створення світу (тобто Create World, New World, New Game), ви, ймовірно, помітили, що це _боляче_ налаштовувати. Це тому, що цей екран досить складний і побудований так, що FancyMenu дуже важко правильно його налаштувати через накладання кнопок та інших елементів GUI один на один.

У новіших версіях Minecraft налаштовуваність стала ще гіршою через нову систему вкладок.

Усе це робить **не рекомендованим** налаштування цього екрана, принаймні не складних змін, таких як редагування наявних елементів GUI (наприклад, кнопок Vanilla тощо) або додавання нових власних елементів. Ймовірно, можна без проблем встановити власний фон, але далі все стає заплутаним, тож краще не налаштовувати його надто сильно.
