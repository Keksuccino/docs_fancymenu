# Глобальні налаштування

Глобальні налаштування — це зміни FancyMenu, які застосовуються до всього інтерфейсу гри.
Використовуйте їх, коли хочете мати один послідовний стиль/поведінку всюди, замість окремого редагування кожного макета екрана.

> [!INFO]
> На відміну від більшості функцій налаштування FancyMenu, Глобальні налаштування працюють навіть тоді, коли звичайні налаштування екранів вимкнено.
> Для них **не** потрібно вмикати налаштування для кожного екрана окремо, а це означає, що одна зміна може одразу вплинути на всі екрани.

Типові приклади:

- Використовуйте один спільний стиль кнопок і повзунків для всіх екранів.
- Глобально замініть фон меню, панораму та музику меню.
- Застосуйте глобальну поведінку під час запуску/у віконному режимі (масштаб GUI, повноекранний режим, назва/значок вікна).
- Глобально замініть текстури стандартних кнопок без ресурс-пака.
- Глобально замініть музику стандартного меню без ресурс-пака.

# Де їх знайти

Відкрийте **рядок меню** FancyMenu, коли ви **не** перебуваєте в редакторі макета, потім **Customization -> Global Customizations**.

# Швидкий старт

1. Відкрийте **Customization -> Global Customizations**.
2. Виберіть одну категорію для початку (наприклад, **Custom Button Textures**).
3. Налаштуйте параметри в цій категорії (вибір ресурсів, перемикачі або числові поля).
4. Перевірте результат на кількох екранах.
5. Точно підкоригуйте пов’язані параметри (наприклад, прозорість, стилі підписів, межі nine-slice).

# Що можна налаштувати

## Глобальна поведінка та запуск

- **Game Intro** (вступне відео або анімація, що відтворюється перед появою екрана Title)
- **Singleplayer Screen World Icons**
- **Multiplayer Screen Server Icons**
- **Seamless World Loading** (використовує знімок світу як фон екрана завантаження світу)
- **Custom Window Icon**
- **Custom Window Title**
- **Default GUI Scale**
- **Force Fullscreen on Launch**

## Вигляд кнопок

- **Custom Button Textures** (стани Normal/Hover/Inactive, режим прозорості, nine-slice + розміри меж)
- **Button Labels** (підкреслення при наведенні, базовий/hover колір, масштаб, тінь)

## Вигляд повзунків

- **Custom Slider Textures**
- **Slider Background Texture** (текстура, режим прозорості, nine-slice + розміри меж)
- **Slider Handle Textures** (стани Normal/Hover/Inactive, nine-slice + розміри меж)
- **Slider Labels** (підкреслення при наведенні, базовий/hover колір, масштаб, тінь)

## Вигляд меню та аудіо

- **Custom Menu Background Texture**
- **Custom Menu Background Panorama**
- **Play Vanilla Menu Music** (увімкнути/вимкнути відтворення стандартної музики меню)
- **Custom Menu Music Tracks**
- **Custom Button/Slider Click Sound**

# Custom Menu Music Tracks

Використовуйте **Custom Menu Music Tracks**, щоб створити випадковий список треків для меню.

Налаштовані користувацькі треки замінюють стандартну музику меню.

- Відкрийте **Custom Menu Music Tracks**, щоб відкрити **Manage Menu Music Tracks**.
- Використовуйте **Add Track**, щоб додати джерела аудіо.
- Використовуйте **Remove Track**, щоб видалити один запис.
- Використовуйте **Clear Tracks**, щоб видалити всі записи.
