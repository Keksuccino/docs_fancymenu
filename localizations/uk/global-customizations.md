# Глобальні налаштування

Глобальні налаштування застосовують спільні параметри інтерфейсу та запуску без редагування макета кожного екрана окремо. Вони працюють навіть тоді, коли звичайне налаштування екранів вимкнене.

Типові приклади:

- Використовуйте один спільний стиль кнопок і повзунків для всіх екранів.
- Глобально замініть фон меню, панораму та музику меню.
- Застосовуйте глобальну поведінку запуску/вікна (масштаб GUI, повноекранний режим, заголовок/іконку вікна).
- Глобально замініть стандартні текстури кнопок без ресурс-пака.
- Глобально замініть стандартну музику меню без ресурс-пака.

# Де їх знайти

Відкрийте **рядок меню** FancyMenu, коли ви **не** перебуваєте в редакторі макетів, потім **Customization -> Global Customizations**.

# Що можна налаштувати

## Глобальна поведінка та запуск

- [**Game Intro**](./game-intro) (відео або анімація вступу, що відтворюється перед екраном заголовка)
- **Singleplayer Screen World Icons**
- **Multiplayer Screen Server Icons**
- [**Seamless World Loading**](./seamless-world-loading) (використовує нещодавній знімок світу як фон екрана завантаження)
- [**Custom Window Icon**](./window-customization#custom-icon)
- [**Custom Window Title**](./window-customization#custom-title)
- **Default GUI Scale**
- **Force Fullscreen on Launch**

## Вигляд кнопок

- **Custom Button Textures** (стани Normal/Hover/Inactive, прозорий режим, [nine-slice](./nine-slicing-and-tiling) + розміри рамок)
- **Button Labels** (підкреслення при наведенні, базовий/hover колір, масштаб, тінь)

## Вигляд повзунків

- **Custom Slider Textures**
- **Slider Background Texture** (текстура, прозорий режим, [nine-slice](./nine-slicing-and-tiling) + розміри рамок)
- **Slider Handle Textures** (стани Normal/Hover/Inactive, [nine-slice](./nine-slicing-and-tiling) + розміри рамок)
- **Slider Labels** (підкреслення при наведенні, базовий/hover колір, масштаб, тінь)

## Вигляд меню та аудіо

- [**Custom Menu Background Texture**](./menu-backgrounds)
- [**Custom Menu Background Panorama**](./panoramas)
- **Play Vanilla Menu Music** (увімкнути/вимкнути відтворення стандартної музики меню)
- [**Custom Menu Music Tracks**](./background-music)
- **Custom Button/Slider Click Sound**

# Custom Menu Music Tracks

Використовуйте **Custom Menu Music Tracks**, щоб створити випадковий список треків для меню.

> [!IMPORTANT]
> Глобальні власні треки меню відтворюються лише тоді, коли жоден світ не завантажено, наприклад на екрані заголовка. Використовуйте елемент [**Audio**](./elements#audio) для музики меню всередині світу.

Налаштовані треки використовують звуковий канал Music і замінюють стандартну музику меню у підтримуваних меню без світу.

- Перший трек починається приблизно через п’ять секунд.
- Наступні треки починаються через випадкову затримку приблизно від однієї до тридцяти секунд.
- Треки вибираються випадково.
- Якщо є кілька треків, попередній трек не буде вибрано двічі поспіль.

Керуйте списком треків через **Custom Menu Music Tracks**:

- Відкрийте **Custom Menu Music Tracks**, щоб відкрити **Manage Menu Music Tracks**.
- Використовуйте **Add Track**, щоб додати джерела аудіо.
- Використовуйте **Remove Track**, щоб видалити один запис.
- Використовуйте **Clear Tracks**, щоб видалити всі записи.
