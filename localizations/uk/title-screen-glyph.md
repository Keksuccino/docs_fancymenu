# Значок смарагда/діаманта на екрані заголовка

Якщо вам важко приховати маленький значок, який постійно з’являється на екрані заголовка і виглядає як маленький діамант або смарагд (зелений чи синій маленький значок), то найчастіше це сповіщення про оновлення мода від Mod Menu (мод Fabric) або Forge (вбудована функція завантажувача модів).

У деяких випадках це також може бути частиною кнопки Vanilla Minecraft Realms (для показу сповіщень).

# Приховування значка Mod Menu

Щоб приховати цей значок у Mod Menu, потрібно вимкнути "update indicator" у його налаштуваннях.

Натисніть кнопку **Mods** -> Наведіть курсор на значок мода Mod Menu у списку модів -> Натисніть на нього -> Встановіть для "Update Indicator" значення "Hidden".

# Приховування значка Forge

Forge використовує вбудовану перевірку версій, щоб показувати цей смарагдовий значок, коли моди застарілі. Ви можете вимкнути її:

1. Відкрийте файл `/config/fml.toml`.
2. Знайдіть параметр `versionCheck`.
3. Встановіть для нього `false`: `versionCheck = false`
4. Збережіть файл і перезапустіть Minecraft.

Це повністю вимикає перевірку версій, а разом із нею і приховує смарагдовий значок під час запуску.

Інший спосіб приховати значок — просто сховати всю кнопку Mods через FancyMenu. Приховавши кнопку, ви також приховаєте й значок.

# Приховування значка NeoForge

Для NeoForge це працює точно так само, як і для класичного Forge.

1. Відкрийте файл `/config/fml.toml`.
2. Знайдіть параметр `versionCheck`.
3. Встановіть для нього `false`: `versionCheck = false`
4. Збережіть файл і перезапустіть Minecraft.

# Приховування значків Vanilla Realms

Якщо це не значок Mod Menu і не значок Forge, то, ймовірно, це власні значки сповіщень Minecraft Realms. Ці значки відображаються приблизно в місці кнопки Realms і їх можна приховати за допомогою FancyMenu в редакторі макета. Вам потрібно створити макет "for the current screen" (у цьому випадку — для екрана заголовка), і тоді ви побачите значки Realms як окремий елемент у редакторі. Щоб приховати його, просто **клацніть правою кнопкою миші** по ньому та натисніть **Delete**.

Значки Realms можуть бути у вигляді значка газети, ромбика та інших, наприклад червоного кола з лічильником сповіщень.
