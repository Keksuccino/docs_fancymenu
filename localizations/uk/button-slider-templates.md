# Шаблони кнопок і повзунків

Шаблон — це [елемент «Кнопка»](/elements#button), який передає свій вигляд усім іншим кнопкам або всім повзункам екрана — і стандартним, і створеним вами. Змініть шаблон — і вони зміняться разом із ним.

> [!TIP]
> Щоб усі меню гри мали однаковий вигляд, скористайтеся [Глобальними налаштуваннями](/global-customizations). Шаблони призначені для одного екрана або для всіх екранів, які завантажує [універсальний макет](/universal-layouts).

# Створення шаблону

1. Додайте до макета елемент «Кнопка».
2. Клацніть його правою кнопкою миші, відкрийте **Налаштування шаблону** й увімкніть **Режим шаблону**.
3. У полі **Спільні налаштування для** виберіть **Кнопок** або **Повзунків**.
4. Налаштуйте для шаблону текстури, звуки та написи, як для будь-якої іншої кнопки. Якщо вибрано **Повзунки**, параметри текстур стосуватимуться текстур повзунків.

Поза редактором шаблон не відображається, тож розмістіть його будь-де, де він не заважатиме. У редакторі шаблон для повзунків має вигляд повзунка.

# Що спільного в шаблонів

## Завжди

- Текстури кнопки (або текстури повзунка) та їхні параметри [дев’ятичастинного масштабування](/nine-slicing-and-tiling).
- Звуки наведення, зняття курсора та натискання.

Коли шаблон активний, кнопки використовують його текстури й звуки замість власних. Якщо в шаблону немає текстур, кнопки також не використовують власні текстури.

## Коли ввімкнено

Увімкніть ці параметри в розділі **Налаштування шаблону** шаблону:

| Параметр | Що кнопки отримують від шаблону |
|---|---|
| **Спільний напис у режимі шаблону** | **Напис** і **Напис під час наведення**, а також увесь стиль написів: **Вирівнювання напису**, **Масштаб напису**, **Основний колір напису**, **Колір напису під час наведення**, **Тінь напису** та **Підкреслювати напис під час наведення**. |
| **Спільна позиція X у режимі шаблону** та **Спільна позиція Y у режимі шаблону** | Позицію шаблону. Стандартні кнопки переміщуються, лише якщо для параметра **Точка прив’язки** вибрано значення, відмінне від **Стандартна (початкова)**. |
| **Спільна непрозорість у режимі шаблону** | Непрозорість шаблону. |

## Вирівнювання написів для всіх кнопок

Якщо ввімкнути **Спільний напис у режимі шаблону**, усі кнопки отримають також текст шаблону. Цей параметр призначений для екранів, де всі кнопки мають містити однаковий текст.

Щоб вирівняти лише написи, не змінюючи їхній текст:

- Для одного екрана виділіть кнопки, клацаючи їх із затиснутою клавішею `Ctrl` (див. [Виділення](/layout-editor#selecting)), клацніть одну з них правою кнопкою миші й один раз задайте для всіх параметр **Вирівнювання напису**.
- Для всіх меню скористайтеся параметром **Вирівнювання напису** в розділі [Глобальні налаштування](/global-customizations#labels).

# Корисно знати

- Шаблонами можуть бути лише елементи «Кнопка», але вони працюють зі стандартними й власними кнопками та повзунками.
- На екрані одночасно може бути один шаблон для кнопок і один для повзунків. Якщо шаблонів одного типу більше, працюватиме лише один із них.
- Шаблон працює, лише коли він видимий. За допомогою [умов](/element-visibility) для шаблону його можна вмикати й вимикати.
