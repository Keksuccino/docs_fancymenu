# Анімації

Файли AFMA та FMA — це формати анімованих текстур, створені для FancyMenu.

# Файли AFMA

**AFMA** (Advanced FancyMenu Animation) — це наступник класичних файлів FMA.

AFMA використовує не-ZIP формат із меншими файлами, нижчим використанням пам’яті та кращою продуктивністю, ніж класичний FMA.

Для великих або складних анімованих текстур використовуйте **AFMA** замість класичного FMA.

Створюйте файли AFMA за допомогою вбудованого інструмента:

1. Відкрийте рядок меню FancyMenu.
2. Перейдіть до **Tools -> AFMA Creator**.
3. Імпортуйте/конвертуйте свої кадри за допомогою цього інструмента.

> [!IMPORTANT]
> Файли AFMA не можна пакувати вручну. Використовуйте **Tools -> AFMA Creator**.

Класичні файли FMA й надалі підтримуються, тому наявні макети не потрібно негайно конвертувати.

# Класичні файли FMA

## Створення FMA

Класичний файл FMA — це ZIP-архів із розширенням `.fma`.

### Розширення файлів

Увімкніть показ розширень файлів у файловому менеджері перед створенням або перейменуванням наведених нижче файлів.

У Windows відкрийте Провідник файлів і увімкніть **View -> File name extensions**.

### Підготовка

Створіть папку з назвою `fancymenu_animation` для вмісту архіву.

Створіть усередині неї обов’язкову директорію `frames` і необов’язкову директорію `intro_frames`.

У цій самій папці створіть `metadata.json`. Переконайтеся, що його розширення файлу — `.json`, а не `.txt`.

Тепер папка має містити `frames/`, `intro_frames/` і `metadata.json`.

<br>
<img width="700" alt="Screenshot_3" src="https://gist.github.com/assets/35544624/e29f6666-ee4a-4d79-b7e2-1b640f40ce78">

### JSON метаданих

Відкрийте `metadata.json` у текстовому редакторі та використайте цей шаблон:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
  },
  "custom_frame_times_intro": {
  }
}
```

Відредагуйте значення за потреби.

#### `loop_count`

Керує тим, скільки разів програється анімація. Використовуйте `0` для нескінченного циклу. Додатне значення програє анімацію стільки разів, а потім залишить останній кадр.

#### `frame_time`

Встановлює, як довго кожен звичайний кадр залишається видимим, у мілісекундах.

#### `frame_time_intro`

Встановлює час показу кадрів для необов’язкових **intro**-кадрів.

#### `custom_frame_times`

За бажанням перевизначає тривалість окремих звичайних кадрів. У цьому прикладі кадри `0` і `1` будуть видимі протягом `5000` мілісекунд, а інші кадри використовуватимуть `frame_time`:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
    "0": 5000,
    "1": 5000
  },
  "custom_frame_times_intro": {
  }
}
```

Індекси кадрів починаються з нуля: перший кадр — `0`, другий — `1` і так далі.

Додавайте кому після кожного запису custom frame time, крім останнього.

#### `custom_frame_times_intro`

Використовує той самий формат, що й `custom_frame_times`, але застосовується до необов’язкових intro-кадрів.

Збережіть `metadata.json`.

### Кадри

> [!CAUTION]
> Обмежуйте класичні анімації FMA до 200 кадрів і 1080p. Для довгого контенту або контенту з високою частотою кадрів використовуйте [Video](./video).

Розмістіть звичайні кадри в `frames/`. Вони мають бути PNG-файлами з послідовними назвами, починаючи з `0.png`, наприклад `0.png`, `1.png` і `2.png`. Інші формати та назви не підтримуються.

Щоб витягнути кадри з відео, див. [Extracting Frames with FFmpeg](./ffmpeg-frames).

### Intro

Розмістіть необов’язкові intro-кадри в `intro_frames/`. Вони підпорядковуються тим самим правилам іменування PNG, що й звичайні кадри, програються один раз перед основною послідовністю та не зациклюються.

### Пакування файлу FMA

Створіть ZIP із вмісту папки. `metadata.json`, `frames/` і необов’язкова директорія `intro_frames/` мають знаходитися в корені ZIP, а не всередині іншої директорії.

У Windows виберіть вміст `fancymenu_animation`, клацніть правою кнопкою миші по виділеному та виберіть **Send to -> Compressed (zipped) folder**.

Тепер перейменований архів готовий до використання як файл FMA.

# Використання файлів AFMA та FMA у FancyMenu

> [!IMPORTANT]
> Файли AFMA/FMA — це анімовані текстури, тому додавайте їх через [**Image** inputs](./elements#image). Майже все, що приймає зображення, також приймає файли AFMA та FMA.

Використовуйте файли AFMA/FMA всюди, де приймаються зображення, зокрема в [Image elements](./elements#image) і [Image menu backgrounds](./menu-backgrounds).

Зберігайте файл AFMA/FMA в `<game-directory>/config/fancymenu/assets/`, щоб він відображався в локальному виборі ресурсів FancyMenu.
