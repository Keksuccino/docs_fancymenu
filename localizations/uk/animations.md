# Анімації

FancyMenu відтворює анімовані зображення майже всюди, де можна використовувати зображення: в [елементах зображень](/elements#image), [фонових зображеннях меню](/menu-backgrounds#image), текстурах кнопок і повзунків, [вступі до гри](/game-intro) та в інших місцях.

Для анімацій використовуйте файли **APNG** або **GIF**:

- **APNG** (анімований PNG) забезпечує кращу якість: усі кольори звичайного PNG та належну прозорість із плавними краями. Це найкращий вибір для логотипів, фонів і всього, що має прозорі ділянки.
- **GIF** поширеніший, тому для створення й редагування GIF є більше інструментів. Однак у GIF лише 256 кольорів на кадр, а пікселі можуть бути або повністю прозорими, або зовсім непрозорими.

> [!NOTE]
> Власні формати анімації FancyMenu — FMA та AFMA — застаріли. Ваші наявні файли й надалі працюватимуть, але для нових анімацій використовуйте APNG або GIF. Докладніше див. у розділі [FMA та AFMA](#fma-and-afma).

# Використання анімацій

1. Помістіть файл у `<game-directory>/config/fancymenu/assets/`, щоб він з’явився у вікні вибору файлів FancyMenu. Також можна використовувати вебпосилання та файли наборів ресурсів — див. [Ресурси](/resources).
2. Виберіть його, як будь-яке інше зображення, наприклад у полі **Джерело зображення (Image Source)** елемента зображення.

> [!WARNING]
> Назви файлів APNG мають закінчуватися на `.apng`. Багато інструментів зберігають APNG-файли з розширенням `.png`, тож перейменуйте файл, інакше FancyMenu покаже його як нерухоме зображення. Те саме стосується вебпосилань: вони мають закінчуватися на `.apng`.

## Як відтворюються анімації

- Анімація відтворюється стільки разів, скільки вказано у файлі, а потім зупиняється на останньому кадрі. Кількість повторів задається під час створення файлу.
- Анімації відтворюються лише тоді, коли вони на екрані. Коли вони з’являються знову, відтворення продовжується з того місця, на якому зупинилося.
- Параметр **Перезапускати анімовані текстури під час відкриття екрана (Restart Animated Textures When Opening Screen)** змушує елементи зображень і фонові зображення меню починати анімацію спочатку щоразу, коли відкривається екран.
- Параметр **Перезапускати анімовані текстури під час наведення курсора (Restart Animated Textures On Hover)** змушує текстури кнопок і повзунків починати анімацію спочатку щоразу, коли курсор миші наводиться на них.
- Обробники [**Початок відтворення анімованої текстури**](/listeners#animated-texture-started-playing) і [**Завершення відтворення анімованої текстури**](/listeners#animated-texture-finished-playing) виконують дії, коли анімація починається або завершується.

## Продуктивність

FancyMenu декодує APNG і GIF під час відтворення, обробляючи лише кілька кадрів наперед, тому навіть довгі анімації потребують мало пам’яті.

Великі кадри та висока частота кадрів усе ж впливають на продуктивність. Створюйте кадри приблизно такого самого розміру, як вони відображатимуться на екрані, — див. [Оптимізацію текстур](/optimizing-textures). Для довгих відеороликів зі звуком використовуйте [відео](/video).

# Створення анімацій

За допомогою цих безплатних інструментів можна створювати APNG і GIF з окремих кадрів або відео:

- [ScreenToGif](https://www.screentogif.com/) (Windows): натисніть **Редактор (Editor)**, перетягніть у нього кадри PNG, задайте тривалість кадру та збережіть анімацію у форматі APNG або GIF. Кількість повторів можна задати в меню збереження.
- [ezgif](https://ezgif.com/) (онлайн, завантажувати нічого не потрібно): створюйте [GIF](https://ezgif.com/maker) або [APNG](https://ezgif.com/apng-maker) із зображень, конвертуйте відео у [GIF](https://ezgif.com/video-to-gif) або [APNG](https://ezgif.com/video-to-apng), а також конвертуйте [GIF у APNG](https://ezgif.com/gif-to-apng) і [APNG у GIF](https://ezgif.com/apng-to-gif).
- [FFmpeg](https://ffmpeg.org/download.html) (командний рядок): див. нижче.

## За допомогою FFmpeg

Перетворіть пронумеровані кадри PNG, наприклад `frame_0001.png`, `frame_0002.png` тощо, на APNG, який повторюватиметься без кінця. Параметр `-framerate 20` задає відтворення зі швидкістю 20 кадрів за секунду:

```bash
ffmpeg -framerate 20 -i frame_%04d.png -plays 0 animation.apng
```

Перетворіть відео на APNG. Параметр `fps=20` задає 20 кадрів за секунду, а `scale=960:-1` — ширину 960 пікселів:

```bash
ffmpeg -i trailer.mp4 -vf "fps=20,scale=960:-1" -plays 0 trailer.apng
```

Перетворіть відео на GIF, який повторюватиметься без кінця. Частина `palettegen` підбирає для нього найкращі 256 кольорів:

```bash
ffmpeg -i trailer.mp4 -vf "fps=15,scale=640:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" -loop 0 trailer.gif
```

Перетворіть GIF на APNG:

```bash
ffmpeg -i logo.gif -plays 0 logo.apng
```

# FMA та AFMA

FMA та AFMA — власні формати анімації FancyMenu. Обидва застаріли: вони й надалі відтворюватимуться, але для нових анімацій краще використовувати APNG або GIF.

Щоб створити AFMA:

1. Помістіть кадри у форматі PNG в одну папку. Вони відтворюватимуться в алфавітному порядку назв, наприклад `frame_1.png`, `frame_2.png`, ..., `frame_10.png`.
2. Відкрийте **Рядок меню (menu bar) -> Інструменти (Tools) -> Створювач AFMA (AFMA Creator)**.
3. У полі **Основна папка з кадрами (Main Frames Directory)** виберіть папку. Кадри з поля **Папка зі вступними кадрами (Intro Frames Directory)** відтворюються один раз перед основними кадрами.
4. Задайте **Тривалість основного кадру (мс) (Main Frame Time (ms))** і **Кількість повторів (Loop Count)**. Значення `0` означає безкінечне повторення.
5. Вкажіть **Вихідний файл AFMA (Output AFMA File)** і натисніть **Експортувати (Export)**.
