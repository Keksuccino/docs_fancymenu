# Експорт для ШІ

**Експорт для ШІ** перетворює частину налаштувань FancyMenu на текст, створений для ШІ-помічників, як-от Alice — бота-помічника на [Discord-сервері FancyMenu](https://discord.gg/rhayah27GC). Вставте цей текст у чат — і ШІ побачить, як саме все налаштовано, замість того щоб здогадуватися.

# Навіщо це потрібно

Зі знімка екрана видно, як щось виглядає, але не як це налаштовано. Вручну описувати скрипт дії або умову довго, а важлива деталь часто губиться.

Експорт містить усе, що потрібно ШІ:

- Усі параметри, дії, умови та значення того, що ви експортуєте.
- Версії FancyMenu, Minecraft, завантажувача модів, Java та системи.
- Короткі пояснення роботи FancyMenu, щоб ШІ правильно інтерпретував дані.

Експорт завжди створюється англійською мовою, незалежно від мови гри. Ім’я вашого облікового запису в шляхах до файлів замінюється на `<user>`, тож експортом можна ділитися у відкритих чатах.

# Коли це використовувати

- Щось працює не так, як має: наприклад, кнопка нічого не робить або елемент ніколи не з’являється.
- FancyMenu показує помилку або попередження.
- Вам потрібна допомога зі створенням чогось, наприклад скрипту дії, умови або цілого меню.
- Ви хочете дізнатися, що можливо у вашій грі. **Усе, що вміє FancyMenu** містить список усіх доступних вам елементів, фонів, дій, умов, плейсхолдерів і слухачів, зокрема й тих, що додаються доповненнями.

Експортуйте лише те, чого стосується ваше запитання, наприклад одну непрацюючу кнопку. Менший обсяг експорту допомагає ШІ зосередитися. Потім розкажіть, чого ви очікували і що сталося натомість.

# Як експортувати

Кожен із наведених нижче пунктів відкриває невелике меню:

- **Копіювати в буфер обміну** копіює експорт, щоб ви могли вставити його в чат за допомогою `Ctrl + V` (`Cmd + V` у macOS).
- **Зберегти як файл** зберігає експорт у файл Markdown у папці `<game-directory>/fancymenu_data/ai_exports/` і відкриває цю папку, щоб ви могли перетягнути файл у чат. Використовуйте цей варіант для великих експортів, які не вміщаються в повідомлення чату.

Експорти з редактора макетів, а також із вікон слухачів і планувальників містять зміни, які ви ще не зберегли.

# Звідки можна експортувати

## Рядок меню

| Що експортується | Де знайти |
|---|---|
| Поточний екран, його віджети та дії FancyMenu на ньому | **рядок меню -> Налаштування -> Експортувати поточний екран для ШІ** |
| Макет | **рядок меню -> Налаштування -> Макети**, виберіть макет, а потім **Експортувати макет для ШІ** |
| Відомості про гру, обладнання та моди, а також функції, які може використовувати FancyMenu, як-от підтримка відео й браузера | **рядок меню -> Довідка -> Експорт для ШІ -> Інформація про систему** |
| Усі налаштування FancyMenu, включно з [глобальними налаштуваннями](/global-customizations) | **рядок меню -> Довідка -> Експорт для ШІ -> Налаштування FancyMenu** |
| Усі [змінні](/variables) | **рядок меню -> Довідка -> Експорт для ШІ -> Усі змінні** |
| Усі [слухачі](/listeners) | **рядок меню -> Довідка -> Експорт для ШІ -> Усі слухачі** |
| Усі [планувальники](/schedulers) | **рядок меню -> Довідка -> Експорт для ШІ -> Усі планувальники** |
| Усі [власні графічні інтерфейси](/custom-guis) | **рядок меню -> Довідка -> Експорт для ШІ -> Власні графічні інтерфейси** |
| Усі [профілі](/profiles) | **рядок меню -> Довідка -> Експорт для ШІ -> Профілі** |
| Усі елементи, фони, дії, умови, плейсхолдери й слухачі, доступні у вашій грі | **рядок меню -> Довідка -> Експорт для ШІ -> Усе, що вміє FancyMenu** |

## Редактор макетів

| Що експортується | Де знайти |
|---|---|
| Макет, який ви редагуєте | **Макет -> Експортувати макет для ШІ** у рядку меню редактора |
| Інший макет екрана | **Макет -> Відкрити** у рядку меню редактора, виберіть макет, а потім **Експортувати макет для ШІ** |
| Один елемент | Клацніть елемент правою кнопкою миші, а потім виберіть **Експорт для ШІ** |
| Усі вибрані елементи | **Редагувати -> Експортувати вибрані елементи для ШІ** у рядку меню редактора |
| [Фон меню](/menu-backgrounds) | Клацніть правою кнопкою миші на тлі редактора, виберіть **Фони меню**, виберіть фон, а потім **Експорт для ШІ** |
| [Декоративне накладання](/decoration-overlays) | Клацніть правою кнопкою миші на тлі редактора, виберіть **Декоративні накладання**, виберіть накладання, а потім **Експорт для ШІ** |

## Редактори та вікна

| Що експортується | Де знайти |
|---|---|
| [Скрипт дії](/action-scripts) | Клацніть правою кнопкою миші в редакторі скриптів дій, а потім виберіть **Експортувати скрипт дії для ШІ** |
| [Умови](/conditions) | Клацніть правою кнопкою миші у вікні **Керування умовами**, а потім виберіть **Експортувати умови для ШІ** |
| Текст, наприклад вміст текстового елемента | Клацніть правою кнопкою миші в текстовому редакторі, а потім виберіть **Експортувати текст для ШІ** |
| Одна або всі змінні | Відкрийте **рядок меню -> Налаштування -> Керування змінними**, клацніть правою кнопкою миші, а потім виберіть **Експортувати змінну для ШІ** або **Експортувати всі змінні для ШІ** |
| Один або всі слухачі | Відкрийте **рядок меню -> Налаштування -> Керування слухачами**, натисніть **Експорт для ШІ**, а потім виберіть **Вибраний слухач** або **Усі слухачі** |
| Один або всі планувальники | Відкрийте **рядок меню -> Налаштування -> Керування планувальниками**, натисніть **Експорт для ШІ**, а потім виберіть **Вибраний планувальник** або **Усі планувальники** |

## Помилки та попередження

Коли FancyMenu показує помилку або попередження, натисніть **Експорт для ШІ** поруч із кнопкою **OK**, щоб експортувати повідомлення.

## Сервери

Налаштування [FMData](/fm-data) на сервері, зокрема його серверні слухачі та вітальні дані, можна експортувати за допомогою команди. Для цього потрібен рівень дозволів 2, як і для всіх команд `/fmdata`.

```mcfunction
/fmdata export_for_ai copy
/fmdata export_for_ai file
```

- `copy` надсилає вам повідомлення в чаті. Натисніть його, щоб скопіювати експорт. У консолі сервера натомість відображається весь експорт.
- `file` зберігає експорт на сервері в папці `fancymenu_data/ai_exports/`. Використовуйте цей варіант, якщо експорт завеликий для чату.
