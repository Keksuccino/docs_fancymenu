# Вимоги

Вимоги (у деяких меню вони називаються **Вимогами завантаження**) показують або приховують вміст залежно від таких умов, як стан наведення курсора, розмір вікна або факт завантаження світу.

Їх можна використовувати для [елементів](./elements), цілих макетів і [скриптів дій](./action-scripts).

# Додавання вимог до елементів

Щоб додати вимоги до елемента, клацніть його правою кнопкою миші та виберіть **Вимоги завантаження**.

Вимоги перевіряються, поки меню відкрите, тому елементи оновлюються зі зміною умови.

# Вимоги для всього макета

Ви також можете змінювати видимість цілих макетів: клацніть правою кнопкою миші **фон редактора**, а потім виберіть **Вимоги завантаження [для всього макета]**.

Коли результат вимог для всього макета змінюється, FancyMenu перебудовує поточний екран і застосовує макети, вимоги яких тепер виконуються.

# Скрипти дій

Вимоги також можна використовувати у скриптах дій.
Їх можна додати на екрані редактора скриптів дій і використовувати для виконання певних дій лише за умови виконання вимоги.

# Комбінування вимог

- Вимоги поза групами використовують **AND**, тому всі вони мають виконуватися.
- Усередині групи виберіть **AND** або **OR**.
- Використовуйте **IF NOT**, щоб інвертувати одну вимогу.

Ці правила однакові для елементів, макетів і скриптів дій.

# Значення вимог

Для вимог, яким потрібне значення, використовуйте **Редагувати значення вимоги** та дотримуйтеся опису, показаного в редакторі. Деякі поля підтримують автодоповнення за допомогою **TAB**.

Якщо імпортована вимога перестала працювати після зміни FancyMenu або додатків, відредагуйте її на екрані вимог і перевірте `logs/latest.log` на наявність помилок.

Редактор вимог підтримує контекстне меню правої кнопки миші, навігацію клавіатурою, пошук, скасування/повторення дій (`Ctrl/Command + Z` / `Ctrl/Command + Y`) і збереження за допомогою `Ctrl/Command + S`.

# Детальний опис вимог

У цьому розділі перелічено вбудовані вимоги FancyMenu.

## Чи наведено курсор на елемент (`fancymenu_visibility_requirement_is_element_hovered`)

**Призначення:** перевіряє, чи наведено курсор миші на певний елемент.

**Значення:** обов’язкове — [ідентифікатор елемента](./element-identifiers) цільового елемента (наприклад, `some_element_ID`).

## Чи сфокусовано елемент (`is_element_focused`)

**Призначення:** перевіряє, чи має певний елемент фокус клавіатури (наприклад, текстове поле або сфокусована кнопка).

**Значення:** обов’язкове — ID цільового елемента (той самий ID, що відображається в редакторі)

> [!NOTE]
> Фокус і наведення курсора — це різні стани. Елемент може зберігати вигляд сфокусованого після того, як курсор залишив його; фокус можна отримати клацанням або навігацією клавіатурою.

## Чи наведено курсор на будь-який елемент (`fancymenu_visibility_requirement_is_any_element_hovered`)

**Призначення:** перевіряє видимі/відтворювані елементи в поточному активному шарі налаштування, зокрема елементи зі стекованих макетів.

**Значення:** не потрібне

## Чи наведено курсор на будь-яку кнопку (`fancymenu_visibility_requirement_is_any_button_hovered`)

**Призначення:** перевіряє, чи наведено курсор на будь-яку видиму/відтворювану ванільну або користувацьку кнопку в поточному активному шарі налаштування, зокрема кнопки зі стекованих макетів.

**Значення:** не потрібне

## Чи ввімкнено макет (`fancymenu_visibility_requirement_is_layout_enabled`)

**Призначення:** перевіряє, чи ввімкнено певний макет.

**Значення:** обов’язкове — назва макета (наприклад, `my_cool_main_menu_layout`)

## Чи працює планувальник (`fancymenu_visibility_requirement_is_scheduler_running`)

**Призначення:** перевіряє, чи працює [планувальник](./schedulers).

**Значення:** обов’язкове — ID планувальника (наприклад, `my_scheduler`)

## Чи відповідає масштаб GUI (`fancymenu_loading_requirement_is_gui_scale`)

**Призначення:** перевіряє, чи відповідає поточний масштаб GUI певним умовам.

**Значення:** обов’язкове — використовуйте число для перевірки рівності, `>` для більшого значення або `<` для меншого.

Кілька умов, розділених комами, об’єднуються через AND. Наприклад, `>1,<4` виконується лише тоді, коли масштаб GUI більший за `1` і менший за `4`.

## Чи активна кнопка (`fancymenu_visibility_requirement_is_button_active`)

**Призначення:** перевіряє, чи активна певна кнопка (доступна для натискання).

**Значення:** обов’язкове — ID цільової кнопки (наприклад, "some_element_ID")

## Чи відповідає заголовок екрана (`is_menu_title`)

**Призначення:** перевіряє, чи відповідає ВІДОБРАЖУВАНИЙ заголовок екрана певному тексту або ключу локалізації. Перевіряється лише відображувана назва/заголовок екрана, наприклад "Налаштування" або "Пауза". Ідентифікатор меню/екрана (наприклад, `title_screen`) НЕ перевіряється!

**Значення:** обов’язкове — точний текст заголовка або ключ локалізації екрана

## Чи натиснуто клавішу (`is_key_pressed`)

**Призначення:** перевіряє, чи натиснуто певну клавішу клавіатури.

**Значення:** обов’язкове — код цільової клавіші. Вибирається через інтерфейс під час редагування значення вимоги.

## Чи відкрито будь-який екран (`is_any_screen_open`)

**Призначення:** перевіряє, чи відкрито будь-який екран/меню (повертає false, якщо жоден екран не відображається).

**Значення:** не потрібне

## Чи ввімкнено налагоджувальну панель MC (`is_debug_overlay_enabled`)

**Призначення:** перевіряє, чи видима налагоджувальна панель F3.

**Значення:** не потрібне

## Чи відповідає тип активного курсора (`is_active_cursor_type`)

**Призначення:** перевіряє, чи відповідає поточний активний тип курсора FancyMenu певному стандартному типу.

**Значення:** обов’язкове — тип курсора: `normal`, `writing`, `crosshair`, `pointing_hand`, `resize_horizontal`, `resize_vertical`, `resize_nwse`, `resize_nesw`, `resize_all` або `not_allowed`

## Чи видима панель меню налаштування (`is_customization_menu_bar_visible`)

**Призначення:** перевіряє, чи видима панель меню налаштування FancyMenu.

**Значення:** не потрібне

## Чи ввімкнено режим модпаку (`is_modpack_mode_enabled`)

**Призначення:** перевіряє, чи ввімкнено режим модпаку FancyMenu.

**Значення:** не потрібне

## Чи натиснуто кнопку миші (`mouse_click`)

**Призначення:** повертає true, поки утримується певна кнопка миші. Це не одноразова подія клацання; якщо дію потрібно виконати один раз за клацання, використовуйте [слухач **Після клацання кнопкою миші**](./listeners#on-mouse-button-clicked-mouse_button_clicked).

**Значення:** обов’язкове — `left` або `right`, щоб указати кнопку миші для перевірки

## Чи повноекранний режим (`fancymenu_loading_requirement_is_fullscreen`)

**Призначення:** перевіряє, чи працює гра в повноекранному режимі.

**Значення:** не потрібне

## Ширина вікна (`fancymenu_loading_requirement_is_window_width`)

**Призначення:** перевіряє, чи відповідає ширина вікна гри певним значенням.

**Значення:** обов’язкове — ширина вікна в пікселях (наприклад, "1920"). Кілька значень можна вказати через кому.

## Висота вікна (`fancymenu_loading_requirement_is_window_height`)

**Призначення:** перевіряє, чи відповідає висота вікна гри певним значенням.

**Значення:** обов’язкове — висота вікна в пікселях (наприклад, "1080"). Кілька значень можна вказати через кому.

## Чи ширше вікно за (`fancymenu_loading_requirement_is_window_width_bigger_than`)

**Призначення:** перевіряє, чи ширина вікна гри більша за певне значення.

**Значення:** обов’язкове — ширина вікна в пікселях (наприклад, "1920")

## Чи вище вікно за (`fancymenu_loading_requirement_is_window_height_bigger_than`)

**Призначення:** перевіряє, чи висота вікна гри більша за певне значення.

**Значення:** обов’язкове — висота вікна в пікселях (наприклад, "1080")

## Чи багатокористувацька гра (`fancymenu_loading_requirement_is_multiplayer`)

**Призначення:** перевіряє, чи перебуває гравець у багатокористувацькому світі.

**Значення:** не потрібне

## Чи однокористувацька гра (`fancymenu_loading_requirement_is_singpleplayer`)

**Призначення:** перевіряє, чи перебуває гравець в однокористувацькому світі.

**Значення:** не потрібне

## Чи завантажено світ (`fancymenu_loading_requirement_is_world_loaded`)

**Призначення:** перевіряє, чи завантажено будь-який світ.

**Значення:** не потрібне

## Чи режим «Пригоди» (`fancymenu_visibility_requirement_is_adventure`)

**Призначення:** перевіряє, чи перебуває гравець у режимі гри «Пригоди».

**Значення:** не потрібне

## Чи творчий режим (`fancymenu_visibility_requirement_is_creative`)

**Призначення:** перевіряє, чи перебуває гравець у творчому режимі гри.

**Значення:** не потрібне

## Чи режим спостерігача (`fancymenu_visibility_requirement_is_spectator`)

**Призначення:** перевіряє, чи перебуває гравець у режимі спостерігача.

**Значення:** не потрібне

## Чи режим виживання (`fancymenu_visibility_requirement_is_survival`)

**Призначення:** перевіряє, чи перебуває гравець у режимі виживання.

**Значення:** не потрібне

## Чи відповідає режим гри (`is_gamemode`)

**Призначення:** перевіряє, чи перебуває гравець у певному режимі гри.

**Значення:** обов’язкове — назва режиму гри (наприклад, "creative", "survival", "adventure", "spectator")

## Чи відповідає складність (`is_difficulty`)

**Призначення:** перевіряє, чи відповідає поточна складність гри певному значенню.

**Значення:** обов’язкове — назва складності (наприклад, "peaceful", "easy", "normal", "hard")

## Чи хардкорний режим (`is_hardcore`)

**Призначення:** перевіряє, чи завантажений світ працює в хардкорному режимі.

**Значення:** не потрібне

## Чи відповідає перспектива камери (`is_camera_perspective`)

**Призначення:** перевіряє, чи відповідає поточна перспектива камери певній перспективі.

**Значення:** обов’язкове — `first_person`, `third_person_back` або `third_person_front`

## Чи йде дощ (`is_raining`)

**Призначення:** перевіряє, чи йде дощ у поточному місці перебування гравця.

**Значення:** не потрібне

## Чи гримить (`is_thundering`)

**Призначення:** перевіряє, чи триває гроза у світі гравця.

**Значення:** не потрібне

## Чи ясна погода (`is_clear_weather`)

**Призначення:** перевіряє, чи ясна зараз погода (немає дощу чи грози).

**Значення:** не потрібне

## Чи йде сніг (`is_snowing`)

**Призначення:** перевіряє, чи йде сніг у поточному місці перебування гравця.

**Значення:** не потрібне

## Чи біжить гравець (`is_player_running`)

**Призначення:** перевіряє, чи гравець біжить.

**Значення:** не потрібне

## Чи крадеться гравець (`is_player_sneaking`)

**Призначення:** перевіряє, чи гравець крадеться/присідає.

**Значення:** не потрібне

## Чи використовує гравець предмет (`is_player_using_item`)

**Призначення:** перевіряє, чи гравець використовує предмет.

**Значення:** не потрібне

## Чи пливе гравець (`is_player_swimming`)

**Призначення:** перевіряє, чи гравець пливе.

**Значення:** не потрібне

## Чи стрибає або падає гравець (`is_player_jumping`)

**Призначення:** повертає true, поки гравець перебуває в повітрі у звичайному стані стрибка або падіння. Плавання, рідини, політ на елітрах, сон, візуальне плавання та повзання не враховуються.

**Значення:** не потрібне

## Чи перебуває гравець під водою (`is_player_under_water`)

**Призначення:** перевіряє, чи гравець повністю перебуває під водою.

**Значення:** не потрібне

## Чи перебуває гравець у воді (`is_player_in_water`)

**Призначення:** перевіряє, чи гравець перебуває у воді (занурення може бути частковим).

**Значення:** не потрібне

## Чи перебуває гравець у лаві (`is_player_in_lava`)

**Призначення:** перевіряє, чи гравець перебуває в лаві.

**Значення:** не потрібне

## Чи перебуває гравець у рідині (`is_player_in_fluid`)

**Призначення:** перевіряє, чи гравець перебуває в будь-якій рідині (воді, лаві тощо).

**Значення:** не потрібне

## Чи їде гравець на сутності/транспорті (`is_player_riding_entity`)

**Призначення:** перевіряє, чи гравець їде на будь-якій сутності.

**Значення:** не потрібне

## Чи їде гравець на сутності, здатній стрибати (`is_player_riding_jumpable_entity`)

**Призначення:** перевіряє, чи гравець їде на сутності, яка може стрибати (наприклад, на коні).

**Значення:** не потрібне

## Чи їде гравець на сутності зі здоров’ям (`is_player_riding_entity_with_health`)

**Призначення:** перевіряє, чи гравець їде на живій сутності зі здоров’ям (наприклад, тварині, але не човні).

**Значення:** не потрібне

## Чи перебуває гравець у пухкому снігу (`is_player_in_powder_snow`)

**Призначення:** перевіряє, чи перебуває гравець у пухкому снігу.

**Значення:** не потрібне

## Чи перебував гравець у пухкому снігу (`was_player_in_powder_snow`)

**Призначення:** перевіряє, чи перебував гравець у пухкому снігу (використовується для ефектів, що зберігаються після виходу).

**Значення:** не потрібне

## Чи носить гравець гарбуз (`is_player_wearing_pumpkin`)

**Призначення:** перевіряє, чи носить гравець вирізаний гарбуз на голові.

**Значення:** не потрібне

## Чи летить гравець на елітрах (`is_player_flying_with_elytra`)

**Призначення:** перевіряє, чи гравець летить на елітрах.

**Значення:** не потрібне

## Чи летить гравець у творчому режимі (`is_player_creative_flying`)

**Призначення:** перевіряє, чи гравець літає у творчому режимі.

**Значення:** не потрібне

## Чи має гравець серця поглинання (`has_player_absorption_hearts`)

**Призначення:** перевіряє, чи має гравець серця поглинання (золоті серця).

**Значення:** не потрібне

## Чи уражений гравець висушенням (`is_player_withered`)

**Призначення:** перевіряє, чи на гравця діє ефект висушення.

**Значення:** не потрібне

## Чи повністю замерз гравець (`is_player_fully_frozen`)

**Призначення:** перевіряє, чи гравець повністю замерз (зазвичай через пухкий сніг).

**Значення:** не потрібне

## Чи отруєний гравець (`is_player_poisoned`)

**Призначення:** перевіряє, чи на гравця діє ефект отруєння.

**Значення:** не потрібне

## Чи перебуває гравець у біомі (`is_player_in_biome`)

**Призначення:** перевіряє, чи перебуває гравець у певному біомі.

**Значення:** обов’язкове — ідентифікатор біому (наприклад, `minecraft:birch_forest`)

## Чи перебуває гравець у вимірі (`is_player_in_dimension`)

**Призначення:** перевіряє, чи перебуває гравець у певному вимірі.

**Значення:** обов’язкове — ідентифікатор виміру (наприклад, `minecraft:overworld`, `minecraft:the_nether`, `minecraft:the_end`)

## Чи перебуває гравець у структурі (`is_player_in_structure`)

**Призначення:** перевіряє, чи перебуває гравець усередині певної структури. Для мережевих світів FancyMenu має бути встановлено на сервері.

**Значення:** обов’язкове — ідентифікатор структури (наприклад, `minecraft:village`)

## Чи є поблизу сутність (`is_entity_nearby`)

**Призначення:** перевіряє, чи перебуває сутність певного типу в заданому радіусі від гравця.

**Значення:** обов’язкове — формат: "радіус:ідентифікатор_сутності" (наприклад, `10:minecraft:pig` — перевіряє наявність свиней у межах 10 блоків)

## Чи активний ефект (`is_effect_active`)

**Призначення:** перевіряє, чи діє на гравця певний ефект зілля.

**Значення:** обов’язкове — ідентифікатор ефекту (наприклад, `minecraft:speed`, `minecraft:strength`)

## Чи активний будь-який ефект (`is_any_effect_active`)

## Чи послаблена сила атаки (`is_attack_strength_weakened`)

## Чи відповідає день тижня реального часу (`fancymenu_visibility_requirement_is_realtime_week_day`)

**Значення:** обов’язкове — шлях відносно активного каталогу гри або шлях, що починається з `.minecraft/`, для стандартного каталогу Minecraft. Файли й каталоги вважаються наявними.

## Чи є ОС Linux (`fancymenu_loading_requirement_is_os_linux`)

**Призначення:** перевіряє, чи поточна платформа не є Windows або macOS. Зазвичай це відповідає середовищам Linux.

## Чи завантажено мод (`fancymenu_loading_requirement_is_mod_loaded`)

**Призначення:** перевіряє, чи завантажено певний мод.

**Значення:** обов’язкове — ID моду (наприклад, `fancymenu`, `jei`). OptiFine також можна перевірити за допомогою `optifine`. Підтримуються кілька ID модів, розділених комами; усі перелічені моди мають бути завантажені.

## Чи завантажено Rinku (`is_rinku_loaded`)

**Призначення:** перевіряє, чи встановлено та ініціалізовано [Rinku](https://modrinth.com/mod/rinku). [Rinku](https://modrinth.com/mod/rinku) потрібен для [елемента браузера](./elements#browser) і [застарілих типів відео на основі Rinku](./video#requirements); [вбудовані функції відео](./video) використовують Watermedia.

**Значення:** не потрібне

## Чи є числом (`fancymenu_visibility_requirement_is_number`)

**Призначення:** забезпечує розширене порівняння чисел із різними режимами порівняння.

**Значення:** обов’язкове — складний формат: `["mode":"comparison_mode","number":"value1","compare_with":"value2"]$`, де `comparison_mode` може бути `equals`, `bigger-than`, `smaller-than`, `bigger-than-or-equals` або `smaller-than-or-equals`

## Чи є текстом (`fancymenu_visibility_requirement_is_text`)

**Призначення:** забезпечує розширене порівняння тексту з різними режимами порівняння.

**Значення:** обов’язкове — складний формат: `["mode":"comparison_mode","text":"text1","compare_with":"text2"]$`, де `comparison_mode` може бути `equals`, `contains`, `starts-with` або `ends-with`

## Чи відповідає IP-адреса сервера (`fancymenu_visibility_requirement_is_server_ip`)

**Значення:** обов’язкове — IP-адреса сервера (з портом або без нього)

## Чи доступний сервер (`fancymenu_loading_requirement_is_server_online`)

**Значення:** обов’язкове — IP-адреса сервера (з портом або без нього)

**Значення:** обов’язкове — назва або ID набору ресурсів (наприклад, `Programmer Art` або ID набору)

## Лише один раз за сеанс (`once_per_session`)

**Призначення:** кожен налаштований екземпляр повертає true один раз за сеанс гри. Різні екземпляри відстежуються незалежно.

**Значення:** не потрібне
