# Вимоги
Вимоги (також відомі як «вимоги завантаження») дають змогу робити частини ваших макетів видимими або невидимими залежно від різних умов, наприклад, якщо елемент під курсором, вікно має певний розмір або якщо ви зараз перебуваєте у світі.

Їх також можна використовувати в сценаріях дій для кнопок, повзунків, прокруток і всього іншого, що має поле сценарію дії.

# Додавання вимог до елементів
Щоб додати одну або кілька вимог до елементів, просто клацніть елемент правою кнопкою миші та натисніть **Loading Requirements**.

# Вимоги для всього макета
Ви також можете змінювати видимість цілих макетів, клацнувши правою кнопкою миші **фон редактора**, а потім натиснувши **Loading Requirements [Layout-Wide]**.

# Сценарії дій
Вимоги також можна використовувати у сценаріях дій.
Ви можете додавати їх у вікні редактора сценарію дій і використовувати для виконання певних дій лише тоді, коли умова вимоги виконується.

# Значення вимог
Для деяких вимог потрібно вказати значення, щоб вони працювали належним чином. У такому разі екран вимоги має повідомити вам, що спочатку треба заповнити всі значення, але якщо ні — просто перевірте, чи можна натиснути кнопку **Edit Requirement Value** під час додавання вимоги.
Завжди переглядайте опис вимоги, якщо не впевнені, яке значення потрібно вказати.
Деякі поля значень навіть підтримують **TAB-автодоповнення**.

У FancyMenu 3.9.0 вікно керування вимогами було перероблено: тепер воно використовує контекстне меню правої кнопки миші, навігацію клавіатурою, пошук, скасування/повтор (`CTRL + Z` / `CTRL + Y`) і `CTRL + S` як ярлик **Done**.

# Вимоги докладніше
Наведений нижче список містить більшість, якщо не всі, вимог, доступних у FancyMenu. Можливо, список іноді трохи застарілий через оновлення мода.

## Чи елемент під курсором
Перевіряє, чи на конкретному елементі зараз наведено курсор миші.  
**Потрібне значення**: Так — ID елемента-цілі (наприклад, `some_element_ID`). Ви можете отримати ID, клацнувши елемент правою кнопкою миші в редакторі.

## Чи елемент у фокусі
Перевіряє, чи має певний елемент зараз фокус клавіатури (наприклад, текстове поле або кнопка у фокусі).
**Потрібне значення**: Так — ID елемента-цілі (той самий ID, що показано в редакторі)

> Це не те саме, що просто наведення курсора на елемент, хоча виглядає схоже. Елементи у фокусі продовжують виглядати «під курсором», навіть коли курсор уже не наведений на них. Елементи отримують фокус під час клацання по них або під час використання клавіатури для навігації в меню.
{.is-info}

**Потрібне значення**: Так — ID елемента-цілі кнопки (наприклад, "some_element_ID")

## Чи заголовок екрана
Перевіряє, чи ДИСПЛЕЙНИЙ заголовок екрана відповідає певному тексту або ключу локалізації. Тут перевіряється лише відображувана назва/заголовок екрана, наприклад "Options" або "Pause". Ідентифікатор меню/екрана (наприклад, `title_screen`) ПЕРЕВІРЯТИСЬ НЕ БУДЕ!

**Потрібне значення**: Так — точний текст заголовка або ключ локалізації екрана

## Чи натиснуто клавішу
Перевіряє, чи зараз натиснута певна клавіша клавіатури.  
**Потрібне значення**: Так — код клавіші цілі. Обирається через інтерфейс під час редагування значення вимоги.

## Чи відкрито будь-який екран
Перевіряє, чи зараз відкрито будь-який екран/меню (повертає false, якщо жоден екран не показано).  
**Потрібне значення**: Ні

## Чи активний тип курсора
Перевіряє, чи поточний активний тип курсора FancyMenu відповідає певному стандартному типу курсора.
**Потрібне значення**: Так — тип курсора: `normal`, `writing`, `crosshair`, `pointing_hand`, `resize_horizontal`, `resize_vertical`, `resize_nwse`, `resize_nesw`, `resize_all` або `not_allowed`
