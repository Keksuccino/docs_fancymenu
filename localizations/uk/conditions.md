# Вимоги

Вимоги — це умови на кшталт «курсор миші наведено на цю кнопку», «зараз грудень» або «світ завантажено». Використовуйте їх, щоб:

- показувати [елемент](/elements) лише за певних умов;
- завантажувати цілий макет лише за певних умов;
- вмикати кнопки, повзунки й прапорці лише за певних умов;
- запускати частини [сценарію дій](/action-scripts) лише за певних умов.

FancyMenu постійно перевіряє вимоги, поки меню відкрите, тому елементи одразу з’являються, зникають або змінюються. Це інформаційне вікно показується лише тоді, коли курсор наведено на кнопку «Мережева гра»:

<img width="800" alt="Якщо навести курсор на кнопку «Мережева гра» на титульному екрані, поруч з’явиться інформаційне вікно з адресою сервера" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/requirements_hover.gif?raw=true">

# Де їх знайти

| Де | Що роблять вимоги |
|---|---|
| Клацніть елемент правою кнопкою миші -> **Вимоги до завантаження** | Елемент показується лише тоді, коли вимоги виконано. Також працює для [стандартних елементів](/vanilla-elements). |
| Клацніть правою кнопкою миші тло редактора -> **Вимоги до завантаження [для всього макета]** | Увесь макет завантажується лише тоді, коли вимоги виконано. Див. [Вимоги для всього макета](#вимоги-для-всього-макета). |
| Клацніть кнопку, повзунок або прапорець правою кнопкою миші -> **Стан активності елемента керування** | Елемент можна натиснути лише тоді, коли вимоги виконано. Інакше він буде неактивним. Ця функція є також у стандартних кнопок. |
| IF, ELSE-IF і WHILE у [сценаріях дій](/action-scripts#statements) | Дії всередині виконуються лише тоді, коли вимоги виконано. |

У редакторі макетів елементи завжди показуються, тож ви й надалі можете їх редагувати. Вимоги до елементів діють поза редактором.

> [!TIP]
> У розділі [Видимість елементів](/element-visibility) описано більше способів показувати й приховувати елементи, зокрема за допомогою затримок, поступового зникнення та перемикання кнопкою.

# Додавання вимоги

<img width="800" alt="Копіювання ідентифікатора кнопки «Мережева гра», а потім додавання до інформаційного вікна вимоги «Елемент під курсором» із цим ідентифікатором у розділі «Керування вимогами»" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/requirements_add.gif?raw=true">

1. Клацніть елемент правою кнопкою миші та виберіть **Вимоги до завантаження**. Відкриється вікно **Керування вимогами**.
2. Клацніть порожній список правою кнопкою миші та виберіть **Додати вимогу** або натисніть `A`.
3. Клацніть категорію в розділі **Доступні вимоги** або почніть вводити текст, щоб знайти потрібну вимогу за назвою чи описом. У розділі **Опис вимоги** наведено пояснення вибраної вимоги.
4. Клацніть **Наступний крок**, щоб указати значення. Для вимог без значення замість цього буде кнопка **Готово**. Подвійне клацання на вимозі виконує ту саму дію.
5. Укажіть значення та клацніть **Готово**. Наприклад, для вимоги **Елемент під курсором** потрібен ідентифікатор елемента. Щоб скопіювати його, клацніть елемент правою кнопкою миші та виберіть **Копіювати ідентифікатор елемента**.
6. Клацніть **Готово** у вікні **Керування вимогами**.

## Режим вимоги

Кнопка **Режим вимоги** у вікні вибору вимоги перемикає режими:

- **Звичайний**: вимогу виконано, коли умова істинна.
- **Протилежний**: вимогу виконано, коли умова НЕ істинна. Наприклад, вимогу **Світ завантажено** у протилежному режимі виконано лише в головному меню.

У вікні **Керування вимогами** показано режим і значення кожної вимоги.

## Значення

- У значеннях можна використовувати [заповнювачі](/placeholders) і ваші [змінні](/variables#showing-variables-in-text), наприклад `$$coins`. FancyMenu підставляє їх щоразу, коли перевіряє вимогу.
- У багатьох полях під час введення пропонуються значення, наприклад біоми, ідентифікатори модів, мови або назви ваших змінних. Клацніть потрібну пропозицію або натисніть `Tab`.
- Для вимог із простим значенням відкривається однорядковий текстовий редактор. Його заголовок підказує, що саме потрібно ввести, наприклад **Цільовий ідентифікатор елемента**.

## Керування вимогами

Клацніть список, вимогу або групу у вікні **Керування вимогами** правою кнопкою миші, щоб скористатися такими командами:

| Команда | Сполучення клавіш | Що робить |
|---|---|---|
| **Додати вимогу** | `A` | Додає вимогу. |
| **Додати групу** | `G` | Додає групу (див. нижче). |
| **Редагувати вимогу** | `Enter` або подвійне клацання | Відкриває вікно вибору вимоги з її типом, режимом і значенням. |
| **Видалити вимогу** / **Видалити групу** | `Delete` | Видаляє вимогу або групу. |
| **Скасувати** / **Повторити** | `Ctrl + Z` / `Ctrl + Y` | Скасовує та повторює зміни в цьому вікні. |
| **Експортувати вимоги для ШІ** | | Експортує всі вимоги цього вікна для [чату зі ШІ](/export-for-ai), зокрема незбережені зміни. |

Клавіші `Up` і `Down` вибирають вимогу вище або нижче. Кнопка **Готово** (`Ctrl + S`) зберігає зміни, а **Скасувати** відкидає всі зміни, внесені у вікні. У macOS замість `Ctrl` використовуйте `Cmd`.

Якщо вибрано кілька елементів, команда **Вимоги до завантаження** змінює вимоги для всіх них. Якщо вимоги відрізняються, FancyMenu спершу запитає підтвердження, адже всі поточні вимоги буде замінено.

# Поєднання вимог

Усі вимоги у вікні **Керування вимогами** мають бути виконані. Щоб задати умову «це АБО те», використовуйте групу.

Група діє як одна вимога:

- Режим **І**: мають бути виконані всі вимоги в групі. Нові групи створюються в цьому режимі.
- Режим **АБО**: достатньо виконання однієї вимоги в групі.

1. Клацніть список правою кнопкою миші та виберіть **Додати групу** або натисніть `G`. Група отримає назву на кшталт `group_1`.
2. Клацніть групу правою кнопкою миші та виберіть **Режим групи**, щоб перемкнутися між режимами **І** й **АБО**.
3. Клацніть **Редагувати вимоги групи** або двічі клацніть групу. Відкриється вікно, подібне до **Керування вимогами**, для цієї групи.
4. Додайте вимоги до групи та клацніть **Готово**.

Наприклад, привітання з Різдвом, яке показується в грудні або щоразу, коли гравець вмикає `xmas_lights`: створіть групу в режимі АБО з вимогами **Місяць за реальним часом** зі значенням `12` і **Значення змінної (змінна FM)** для змінної `xmas_lights` зі значенням `on`.

<img width="800" alt="Додавання групи у вікні «Керування вимогами», перемикання її в режим АБО та додавання вимог «Місяць за реальним часом» і «Значення змінної (змінна FM)»" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/requirements_group.gif?raw=true">

- Групи можуть містити інші групи — наприклад, для умови «(А і Б) або (В і Г)». У заголовку вікна показано, де ви перебуваєте, наприклад `Редагувати групу: group_1 › group_2`.
- Команда **Змінити ідентифікатор групи** перейменовує групу. Кожна назва має бути унікальною, зокрема й у групах.
- Порожня група в режимі **АБО** ніколи не вважається виконаною.

# Вимоги для всього макета

Вимоги для всього макета визначають, чи завантажиться цілий макет. Використовуйте їх для нічної версії титульного екрана, окремого макета для кожної мови або макета, який показується лише в одиночній грі.

Клацніть тло редактора правою кнопкою миші та виберіть **Вимоги до завантаження [для всього макета]**. Ця команда також доступна через **Рядок меню -> Макет -> Властивості макета**.

- Якщо результат перевірки зміниться, поки меню відкрите, FancyMenu заново створить екран із макетами, вимоги яких тепер виконано.
- Вони також працюють з [універсальними макетами](/universal-layouts).
- Щоб вмикати й вимикати макет кнопкою, розмістіть кнопку в іншому макеті. Див. [Увімкнення та вимкнення макетів](/element-visibility#turning-layouts-on-and-off).

# Корисно знати

- Вимоги, що стосуються світу й гравця, ніколи не виконуються, якщо світ не завантажено, наприклад у головному меню.
- Вимоги щодо елементів, курсора миші, інвентарів, гравця та світу не працюють у [тікерах](/elements#ticker), якщо ввімкнено **Асинхронно**. У такому разі FancyMenu показує помилку з назвою вимоги.
- Вимоги доповнень, які ви видалили, ігноруються. Щоб остаточно видалити їх, збережіть макет у редакторі.
- Параметр **Рядок меню -> Налаштування -> Параметри -> Тривалість кешування вимог [мс]** дає змогу повторно використовувати результати перевірок протягом певної кількості мілісекунд, що пришвидшує роботу великих макетів. Значення `0` вимикає кешування; це значення встановлено за замовчуванням. Кешування може спричиняти неочікувану поведінку сценаріїв дій і швидких змін.

# Усі вимоги

Вимоги впорядковано так само, як у вікні вибору вимог: спочатку за категоріями, а потім за назвами. Вимоги без категорії розташовані внизу списку вибору; тут їх наведено в розділі [Інше](#інше).

## Інтерфейс

### Активний тип курсора

**Ідентифікатор:** `is_active_cursor_type`

Виконано, коли курсор миші має певну форму — наприклад, **Рука-вказівник** над посиланням або **Текстовий курсор** над текстовим полем.

- Значення: клацніть **Тип курсора**, щоб вибрати **Звичайний**, **Текстовий курсор**, **Перехрестя**, **Рука-вказівник**, **Зміна розміру по горизонталі**, **Зміна розміру по вертикалі**, **Зміна розміру по діагоналі NWSE**, **Зміна розміру по діагоналі NESW**, **Зміна розміру в усіх напрямках** або **Заборонено**.

### Курсор наведено на будь-яку кнопку

**Ідентифікатор:** `fancymenu_visibility_requirement_is_any_button_hovered`

Виконано, коли курсор наведено на будь-яку видиму кнопку — стандартну або користувацьку.

### Курсор наведено на будь-який елемент

**Ідентифікатор:** `fancymenu_visibility_requirement_is_any_element_hovered`

Виконано, коли курсор наведено на будь-який видимий елемент, а не лише кнопку.

### Відкрито будь-який екран

**Ідентифікатор:** `is_any_screen_open`

Виконано, коли відкрито будь-яке меню, наприклад меню паузи чи інвентар. Не виконано, коли ви граєте без відкритого меню.

### Кнопка активна

**Ідентифікатор:** `fancymenu_visibility_requirement_is_button_active`

Виконано, коли кнопку можна натиснути.

- Значення: [ідентифікатор елемента](/element-identifiers), що відповідає кнопці. Клацніть кнопку в редакторі правою кнопкою миші та виберіть **Копіювати ідентифікатор елемента**.

### Панель меню налаштування видима

**Ідентифікатор:** `is_customization_menu_bar_visible`

Виконано, коли відображається панель меню FancyMenu. Не виконано в режимі модпака або коли панель меню вимкнено.

### Елемент у фокусі

**Ідентифікатор:** `is_element_focused`

Виконано, коли елемент у фокусі. Кнопки й повзунки отримують фокус після натискання або коли ви переходите до них клавішами зі стрілками чи клавішею `Tab`. Перехід за допомогою клавіш не вважається наведенням курсора, тому додайте цю вимогу й **Курсор наведено на елемент** до [групи АБО](#поєднання-вимог), щоб врахувати гравців, які користуються клавіатурою.

- Значення: [ідентифікатор елемента](/element-identifiers), наприклад `mc_titlescreen_multiplayer_button`.

### Курсор наведено на елемент

**Ідентифікатор:** `fancymenu_visibility_requirement_is_element_hovered`

Виконано, коли курсор наведено на елемент. Елемент має бути видимим.

- Значення: [ідентифікатор елемента](/element-identifiers), наприклад `mc_titlescreen_multiplayer_button` для кнопки «Мережева гра» на титульному екрані. Щоб скопіювати ідентифікатор, клацніть елемент у редакторі правою кнопкою миші та виберіть **Копіювати ідентифікатор елемента**.

### Прокручено область до кінця

**Ідентифікатор:** `is_scroll_area_scrolled_to_end`

Виконано, коли [область із прокручуванням](/scrollable-areas) або текстовий елемент прокручено до самого низу. Якщо в елементі нічого прокручувати, вважається, що його прокручено до кінця. Ця вимога стане в пригоді для кнопки **Прийняти**, яка має працювати лише після того, як гравець прокрутить правила до кінця.

- Значення: [ідентифікатор елемента](/element-identifiers) області з прокручуванням або текстового елемента.

### Масштаб інтерфейсу

**Ідентифікатор:** `fancymenu_loading_requirement_is_gui_scale`

Виконано, коли масштаб інтерфейсу Minecraft відповідає заданому.

- Значення: число, наприклад `2` — точний масштаб; `>2` — більше за 2; `<4` — менше за 4. Можна використовувати й десяткові дроби, наприклад `<3.5`.
- Розділяйте кілька умов комами. Для звичайних чисел має збігтися одне з них, наприклад `2,3`. Усі умови з `>` і `<` мають виконуватися, наприклад `>1,<4`.

### Натиснуто клавішу

**Ідентифікатор:** `is_key_pressed`

Виконано, поки клавішу утримують. Щоб запускати дії один раз на кожне натискання клавіші, використовуйте слухач [**Клавішу натиснуто**](/listeners#on-keyboard-key-pressed).

- Значення: натисніть **Змінити клавішу** в розділі **Вибір клавіші** та натисніть потрібну клавішу.

### Макет увімкнено

**Ідентифікатор:** `fancymenu_visibility_requirement_is_layout_enabled`

Виконано, коли макет увімкнено.

- Значення: назва макета, наприклад `winter_title_screen`.

### Увімкнено налагоджувальне накладання Minecraft

**Ідентифікатор:** `is_debug_overlay_enabled`

Виконано, коли відображається налагоджувальний екран F3. Не виконано, коли інтерфейс приховано клавішею F1.

### Увімкнено режим модпака

**Ідентифікатор:** `is_modpack_mode_enabled`

Виконано, коли ввімкнено режим модпака FancyMenu.

### Заголовок екрана

**Ідентифікатор:** `is_menu_title`

Виконано, коли заголовок відкритого екрана збігається із заданим, наприклад «Налаштування» або «Меню гри». Це заголовок, який бачать гравці, а не [ідентифікатор екрана](/screen-identifiers).

- Значення: текст заголовка або його ключ локалізації, наприклад `options.title`. У вікні значень показано обидва варіанти для екрана, який ви редагуєте, а також пропонуються ключі локалізації.
- Ключі локалізації працюють усіма мовами. Текст заголовка має збігатися точно.

## Реальний час

Ці вимоги перевіряють годинник на комп’ютері гравця. Розділяйте кілька значень комами: має збігтися одне з них.

### День за реальним часом

**Ідентифікатор:** `fancymenu_visibility_requirement_is_realtime_day`

Виконано в задані дні місяця.

- Значення: від `1` до `31`, наприклад `24,25,26`.

### Година за реальним часом

**Ідентифікатор:** `fancymenu_visibility_requirement_is_realtime_hour`

Виконано в задані години.

### Секунда за реальним часом

### День тижня за реальним часом

## Система

### Файл або папка існує

**Ідентифікатор:** `fancymenu_loading_requirement_file_exists`

Виконано, коли файл або папка існує.

- Значення: шлях у папці гри, наприклад `config/mymodpack/welcome_seen.txt`. Шляхи, що починаються з `.minecraft/`, указують на стандартну папку `.minecraft`.

### Є підключення до інтернету

Виконано, коли комп’ютер підключено до інтернету. FancyMenu час від часу перевіряє це у фоновому режимі.

Виконано в Linux. Технічно — у будь-якій системі, яка не є Windows або macOS.

### Операційна система — macOS

**Ідентифікатор:** `fancymenu_loading_requirement_is_os_macos`

Виконано в macOS.

### Операційна система — Windows

**Ідентифікатор:** `fancymenu_loading_requirement_is_os_windows`

Виконано у Windows.

### Планувальник працює

**Ідентифікатор:** `fancymenu_visibility_requirement_is_scheduler_running`

Виконано, поки працює [планувальник](/schedulers).

- Значення: ідентифікатор планувальника, наприклад `my_scheduler`.

## Вікно

Розміри вікна вказуються в реальних пікселях ігрового вікна, а не в пікселях інтерфейсу. В описі вимоги показано поточний розмір.

### Повноекранний режим

**Ідентифікатор:** `fancymenu_loading_requirement_is_fullscreen`

Виконано, коли гра працює в повноекранному режимі.

### Висота вікна

**Ідентифікатор:** `fancymenu_loading_requirement_is_window_height`

Виконано, коли висота вікна відповідає заданій.

- Значення: висота, наприклад `1080`. Розділяйте кілька значень висоти комами: має збігтися одне з них.

### Висота вікна більша за

**Ідентифікатор:** `fancymenu_loading_requirement_is_window_height_bigger_than`

Виконано, коли висота вікна перевищує задане значення.

- Значення: висота, наприклад `1080`.

### Ширина вікна

**Ідентифікатор:** `fancymenu_loading_requirement_is_window_width`

Виконано, коли ширина вікна відповідає заданій.

- Значення: ширина, наприклад `1920`. Розділяйте кілька значень ширини комами: має збігтися одне з них.

### Ширина вікна більша за

**Ідентифікатор:** `fancymenu_loading_requirement_is_window_width_bigger_than`

Виконано, коли ширина вікна перевищує задане значення.

- Значення: ширина, наприклад `1920`.

## Світ

Ці вимоги ніколи не виконуються, якщо світ не завантажено. Вимоги **Гравець у структурі** та **Гравець у зоні активного рейду** потребують FancyMenu на сервері. В одиночній грі вони працюють завжди.

### У гравця є поглинальні серця

**Ідентифікатор:** `has_player_absorption_hearts`

Виконано, коли в гравця є золоті поглинальні серця.

### Рівень дозволів гравця

**Ідентифікатор:** `fancymenu_loading_requirement_has_player_permission_level`

Виконано, коли рівень дозволів гравця у світі або на сервері не нижчий за заданий, наприклад коли гравець є оператором.

- Значення: від `0` до `4`. Значення `0` виконується завжди; для команд на кшталт `/gamemode` достатньо `2`, а команда `/op` надає рівень `4`.

### Режим пригод

**Ідентифікатор:** `fancymenu_visibility_requirement_is_adventure`

Виконано, коли гравець перебуває в режимі пригод.

### Активний будь-який ефект

**Ідентифікатор:** `is_any_effect_active`

Виконано, коли на гравця діє будь-який ефект, наприклад швидкість або отруєння.

### Сила атаки знижена

**Ідентифікатор:** `is_attack_strength_weakened`

Виконано, коли атака гравця заряджена не повністю. У цей момент відображається індикатор атаки.

### Блок або предмет належить до тегу

**Ідентифікатор:** `is_in_tag`

Виконано, коли блок або предмет належить до певного тегу, наприклад `minecraft:logs` або `c:tools`. Теги доступні лише тоді, коли завантажено світ.

- Значення: клацніть **Тип тегу**, щоб вибрати **Блок** або **Предмет**, а потім введіть **Ключ блока/предмета** й **Тег**. В обох полях пропонуються варіанти. Символ `#` перед тегом необов’язковий.
- Ключ чудово працює зі змінними слухачів, наприклад `$$block_key`. Наприклад, оператор IF у сценарії слухача [**Зламати блок**](/listeners#on-block-broke) може показувати сповіщення лише для колод.

### Перспектива камери

**Ідентифікатор:** `is_camera_perspective`

Виконано, коли камера перебуває в певному ракурсі (F5).

- Значення: клацніть кнопку, щоб вибрати **Від першої особи**, **Від третьої особи** або **Вигляд спереду**.

### Ясна погода

**Ідентифікатор:** `is_clear_weather`

Виконано, коли немає ні дощу, ні грози.

### Творчий режим

**Ідентифікатор:** `fancymenu_visibility_requirement_is_creative`

Виконано, коли гравець перебуває у творчому режимі.

### Курсор утримує предмет з інвентарю

**Ідентифікатор:** `is_cursor_holding_inventory_item`

Виконано, коли курсор миші тримає предмет у вікні інвентарю.

### Складність

**Ідентифікатор:** `is_difficulty`

Виконано, коли у світі встановлено певний рівень складності.

- Значення: `peaceful`, `easy`, `normal` або `hard`.

### Активний ефект

**Ідентифікатор:** `is_effect_active`

Виконано, коли на гравця діє певний ефект.

- Значення: ключ ефекту, наприклад `minecraft:speed`. Коли ви перебуваєте у світі, у полі пропонуються ефекти.

### Поруч є істота

**Ідентифікатор:** `is_entity_nearby`

Виконано, коли поруч із гравцем є істота певного типу.

- Значення: **Ключ істоти в реєстрі**, наприклад `minecraft:creeper`, і **Радіус перевірки в блоках**, наприклад `10`. Коли ви перебуваєте у світі, у полі ключа пропонуються істоти.

### Режим гри

**Ідентифікатор:** `is_gamemode`

Виконано, коли гравець перебуває в певному режимі гри.

- Значення: `survival`, `creative`, `adventure` або `spectator`.

### Хардкорний режим

**Ідентифікатор:** `is_hardcore`

Виконано в хардкорних світах.

### Вибрано комірку панелі швидкого доступу

**Ідентифікатор:** `is_hotbar_slot_active`

Виконано, коли вибрано певну комірку панелі швидкого доступу.

- Значення: від `0` (ліва комірка) до `8`.

### Гравець у зоні активного рейду

**Ідентифікатор:** `is_in_active_raid_area`

Виконано, коли гравець перебуває в зоні рейду, де відображається смужка рейду. Потребує FancyMenu на сервері.

### Комірка інвентарю заповнена

**Ідентифікатор:** `is_inventory_slot_filled`

Виконано, коли в комірці інвентарю гравця є предмет.

- Значення: номер комірки. Від `0` до `8` — комірки панелі швидкого доступу, від `9` до `35` — решта інвентарю.

### Курсор наведено на предмет в інвентарі

**Ідентифікатор:** `is_item_hovered_in_inventory`

Виконано, коли курсор наведено на предмет у вікні інвентарю, наприклад в інвентарі гравця або скрині.

### Мережева гра

**Ідентифікатор:** `fancymenu_loading_requirement_is_multiplayer`

Виконано, коли гравець перебуває на сервері.

### Гравець летить у творчому режимі

**Ідентифікатор:** `is_player_creative_flying`

Виконано, коли гравець летить у творчому режимі.

### Гравець летить на елітрах

**Ідентифікатор:** `is_player_flying_with_elytra`

Виконано, коли гравець ширяє на елітрах.

### Гравець повністю замерз

**Ідентифікатор:** `is_player_fully_frozen`

Виконано, коли гравець повністю замерз у пухкому снігу й на шкалі здоров’я з’явилися замерзлі серця.

### Гравець у біомі

**Ідентифікатор:** `is_player_in_biome`

Виконано, коли гравець перебуває в певному біомі.

- Значення: ключ біому, наприклад `minecraft:birch_forest`. Коли ви перебуваєте у світі, у полі пропонуються біоми.

### Гравець у вимірі

**Ідентифікатор:** `is_player_in_dimension`

Виконано, коли гравець перебуває в певному вимірі.

- Значення: ключ виміру: `minecraft:overworld`, `minecraft:the_nether`, `minecraft:the_end` або виміру з мода. Коли ви перебуваєте у світі, у полі пропонуються виміри.

### Гравець у рідині

**Ідентифікатор:** `is_player_in_fluid`

Виконано, коли гравець перебуває в будь-якій рідині, наприклад у воді чи лаві.

### Гравець у лаві

**Ідентифікатор:** `is_player_in_lava`

Виконано, коли гравець перебуває в лаві.

### Гравець у пухкому снігу

Виконано, коли гравець перебуває в пухкому снігу.

### Гравець у структурі

**Ідентифікатор:** `is_player_in_structure`

Виконано, коли гравець перебуває всередині певної структури. Потребує FancyMenu на сервері.

- Значення: ключ структури, наприклад `minecraft:village_plains`. Коли ви перебуваєте у світі, у полі пропонуються структури.

### Гравець у воді

**Ідентифікатор:** `is_player_in_water`

Виконано, коли гравець перебуває у воді, навіть частково.

### Гравець отруєний

## Інше

### Мова гри

**Ідентифікатор:** `fancymenu_loading_requirement_is_language`

Виконано, коли в Minecraft використовується певна мова.

- Значення: код мови, наприклад `en_us` або `de_de`. У полі пропонуються всі мови.

### Мод завантажено

**Ідентифікатор:** `fancymenu_loading_requirement_is_mod_loaded`

Виконано, коли встановлено певні моди.

- Значення: ідентифікатор мода, наприклад `jei`. У полі пропонуються ідентифікатори ваших модів. Розділяйте кілька ідентифікаторів комами: мають бути встановлені всі ці моди. Значення `optifine` перевіряє наявність OptiFine.

### Число

**Ідентифікатор:** `fancymenu_visibility_requirement_is_number`

Порівнює два числа. У поля можна вставляти заповнювачі або змінні, наприклад `$$coins`.

- **Режим порівняння**: **Дорівнює**, **Більше ніж**, **Менше ніж**, **Більше або дорівнює** чи **Менше або дорівнює**.
- **Число**: число для перевірки, наприклад `$$coins`.
- **Порівняти з числом**: число, з яким його потрібно порівняти, наприклад `100`.

Можна використовувати десяткові дроби, наприклад `2.5`. Якщо поле містить не число, вимога ніколи не виконується.

### Набір ресурсів увімкнено

**Ідентифікатор:** `is_resource_pack_enabled`

Виконано, коли набір ресурсів увімкнено.

- Значення: назва набору, як у вікні наборів ресурсів, наприклад `Programmer Art`, або його ідентифікатор. Регістр літер не має значення.

### Rinku завантажено

**Ідентифікатор:** `is_rinku_loaded`

Виконано, коли встановлено мод [Rinku](https://modrinth.com/mod/rinku). Він потрібен для [елемента браузера](/elements#browser) і застарілих [типів відео на основі Rinku](/video#requirements).

### IP-адреса сервера

**Ідентифікатор:** `fancymenu_visibility_requirement_is_server_ip`

Виконано, коли гравець перебуває на певному сервері.

- Значення: адреса сервера, наприклад `play.example.net`. Якщо вказано порт, наприклад `play.example.net:25566`, він також має збігатися.

### Сервер у мережі

**Ідентифікатор:** `fancymenu_loading_requirement_is_server_online`

Виконано, коли сервер у мережі. FancyMenu перевіряє його у фоновому режимі приблизно кожні 30 секунд, тому після запуску гри може знадобитися трохи часу.

- Значення: адреса сервера, наприклад `play.example.net`.

### Текст

**Ідентифікатор:** `fancymenu_visibility_requirement_is_text`

Порівнює два тексти. У поля можна вставляти заповнювачі або змінні, наприклад `$$key_name`.

- **Режим порівняння**: **Дорівнює**, **Містить**, **Починається з** або **Закінчується на**.
- **Текст**: текст для перевірки.
- **Порівняти з текстом**: текст, з яким його потрібно порівняти.

Регістр літер має значення.

### Значення змінної (змінна FM)

**Ідентифікатор:** `fancymenu_visibility_requirement_is_variable_value`

Виконано, коли одна з ваших [змінних](/variables) має певне значення.

- **Назва змінної**: назва змінної без `$$`. У полі пропонуються ваші змінні.
- **Значення змінної для перевірки**: значення, наприклад `on`. Воно має повністю збігатися; регістр літер має значення.

Вимога не виконується, якщо змінної немає. Для змінної-списку порівнюється JSON-масив усіх елементів, наприклад `["apple","banana"]`. Щоб перевірити наявність одного елемента, використовуйте вимогу **Список містить елемент (змінна FM)**.

### Список містить елемент (змінна FM)

**Ідентифікатор:** `list_contains_entry`

Виконано, коли [змінна-список](/variables#text-and-list-variables) містить певний елемент.

- **Назва змінної-списку**: назва списку без `$$`. У полі пропонуються ваші змінні-списки; якщо ввести назву текстової змінної, з’явиться попередження.
- **Шукати елемент**: елемент для пошуку. Він має повністю збігатися з елементом списку, а не лише з його частиною.
- **Ігнорувати регістр**: якщо ввімкнено, `Apple` збігається також із `apple`.

Вимога не виконується, якщо списку немає.

### Натиснуто кнопку миші

**Ідентифікатор:** `mouse_click`

Виконано, поки кнопку миші утримують. Щоб запускати дії один раз на кожне клацання, використовуйте слухач [**Натиснуто кнопку миші**](/listeners#on-mouse-button-clicked).

- Значення: `left` або `right`.

### Лише один раз за сеанс

**Ідентифікатор:** `once_per_session`

Виконується під час першої перевірки, а потім більше не виконується до перезапуску гри. Кожен окремий екземпляр цієї вимоги рахується окремо.

Якщо потрібно, щоб елементи показувалися лише один раз за сеанс гри, скористайтеся параметром елементів [**Завантажувати лише один раз за сеанс**](/element-visibility#load-once-per-session). Це простіше: такі елементи залишаються на екрані до відкриття нового екрана.
