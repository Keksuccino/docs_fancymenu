# Непрозорість елемента

Більшість елементів у FancyMenu (за деякими винятками) підтримують налаштування своєї непрозорості через контекстне меню, що відкривається правою кнопкою миші.

Значення непрозорості елементів підтримує заповнювачі, що дає змогу динамічно оновлювати її залежно від заповнювача.

Це дає змогу створювати власну логіку плавного зникнення/появи у поєднанні з елементами Ticker для оновлення значень змінних, а потім застосовувати їх як непрозорість через заповнювачі.

Щоб налаштувати непрозорість елементів, **клацніть елемент правою кнопкою миші -> Opacity -> Set**.

# Плавна поява/зникнення елементів

Якщо ви просто хочете, щоб елементи плавно з’являлися або зникали, імовірно, простіше скористатися вбудованою функцією плавного переходу елементів. Її можна увімкнути в контекстному меню елементів.

Ця функція змушує елементи плавно з’являтися щоразу, коли вони завантажуються — чи то під час початкового завантаження при відкритті меню, чи тоді, коли умови завантаження елемента спричиняють його завантаження. Вони плавно зникатимуть, коли умови завантаження зроблять їх незавантаженими/невидимими.

Функція плавного переходу підтримує налаштування швидкості, щоб керувати тим, наскільки швидко елемент має з’являтися або зникати.
