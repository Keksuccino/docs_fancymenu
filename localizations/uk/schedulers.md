# Планувальники

Планувальники запускають скрипт дій за таймером.

Вони глобальні (не прив’язані до конкретного екрана), тому можуть продовжувати працювати навіть тоді, коли жоден GUI не відкрито.

Використовуйте планувальники, коли вам потрібна автоматизація в часі, а не одноразова дія.
Вони корисні для повторюваних завдань, завдань із затримкою та логіки у фоновому режимі.

Поширені приклади:

- Оновлювати змінні або текстові елементи кожні кілька секунд (наприклад, власний годинник/статус-дисплей).
- Запускати періодичні перевірки та тригерити дії, коли виконуються умови.
- Запускати ефекти меню, звуки або іншу скриптовану поведінку в циклі за таймером.
- Відкладати дію та запускати її пізніше без потреби тримати відкритим екран.

# Де їх знайти

Відкрийте **рядок меню** FancyMenu, коли **не** перебуваєте в редакторі макета, потім **Customization -> Manage Schedulers**.

# Швидкий старт

1. Відкрийте **Customization -> Manage Schedulers**.
2. Натисніть **Add Scheduler**.
3. Створіть **Action Script** планувальника (це те, що запускається під час кожного тіку планувальника).
4. Виберіть планувальник і натисніть **Edit Settings**.
5. Налаштуйте:
   - **Scheduler ID** (унікальна назва планувальника; використовується діями Start/Stop та вимогами; дозволено: `a-z`, `0-9`, `.`, `_`, `-`)
   - **Start Delay (ms)** (час очікування до запуску першого тіку)
   - **Tick Delay (ms)** (час очікування між тиками; `0` = кожен ігровий тик)
   - **Ticks to Run** (скільки тиків виконувати перед автоматичним зупиненням; `0` = безстроково)
   - **Start on Launch** (автоматично запускає цей планувальник, коли FancyMenu завантажується)
6. Використовуйте **Start Now**, щоб запустити його негайно.
7. Використовуйте **Stop Now**, щоб зупинити його.

# Керування та перевірка планувальників

Існують дії та вимоги для керування планувальниками й перевірки, чи вони запущені.

## Дії

- **Start Scheduler** приймає ID планувальника та запускає його, якщо він ще не працює.
- **Stop Scheduler** також приймає ID планувальника та зупиняє його.

## Вимога

Щоб перевірити, чи планувальник зараз працює, використовуйте вимогу **Scheduler Is Running**, яка приймає ID планувальника.

# Поради

1. Використовуйте зрозумілі ID, наприклад `hud_update`, `menu_animation`, `music_fade`.
2. Починайте з більшої затримки тіку (наприклад, `200`-`1000` мс), а потім зменшуйте її лише за потреби, щоб заощадити продуктивність.
3. У списку планувальників клацніть правою кнопкою миші на планувальнику, щоб швидко відредагувати його дії.
4. У списку планувальників двічі клацніть ID планувальника, щоб перейменувати його.
