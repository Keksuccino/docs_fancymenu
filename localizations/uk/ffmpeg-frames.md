# Витягування кадрів із відео за допомогою FFmpeg

1. Встановіть [FFmpeg](https://ffmpeg.org/download.html) і переконайтеся, що команда `ffmpeg` доступна.
2. Відкрийте термінал у каталозі, що містить ваше відео.
3. Створіть вихідний каталог:

   ```bash
   mkdir output_frames
   ```

4. Запустіть команду, що відповідає потрібним вам кадрам. Замініть `input.mp4` на ім’я вашого відеофайлу.

## Витягнути кожен кадр

```bash
ffmpeg -i input.mp4 output_frames/frame_%04d.png
```

## Витягнути з фіксованою частотою кадрів

У цьому прикладі створюється 10 кадрів за секунду. За потреби змініть `10`.

```bash
ffmpeg -i input.mp4 -vf "fps=10" output_frames/frame_%04d.png
```

## Змінити розмір витягнутих кадрів

У цьому прикладі кожен кадр масштабується до `1280×720`.

```bash
ffmpeg -i input.mp4 -vf "scale=1280:720" output_frames/frame_%04d.png
```

Пронумеровані PNG-файли в `output_frames` можна використовувати для створення [AFMA або класичної анімації FMA](./fma). Менша кількість кадрів і менші розміри зменшують розмір файлу та використання пам’яті.
