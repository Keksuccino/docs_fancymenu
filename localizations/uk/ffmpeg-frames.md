# Як отримати кадри з відео за допомогою FFmpeg

*Цю сторінку частково згенеровано за допомогою ШІ ChatGPT.*

FFmpeg — це безплатний інструмент, який допомагає працювати з відео та аудіофайлами. Одна з корисних можливостей — витягувати з відео зображення (кадри), наприклад із файлу MP4. Нижче пояснено, як це зробити крок за кроком.

У наведених нижче командах використовується MP4, але FFmpeg також підтримує інші формати відео, зокрема AVI, MOV, MKV і MPEG.

# Що вам потрібно

Перш ніж почати, переконайтеся, що у вас є:

1. **Встановлений FFmpeg**:

   - Завантажте FFmpeg з офіційного [сайту FFmpeg](https://ffmpeg.org/download.html). Обов’язково завантажте повну ("full") збірку.
   - Дотримуйтеся інструкцій зі встановлення для вашої операційної системи.

2. **Доступ до командного рядка**:

   - Використовуйте термінал (Linux/macOS) або командний рядок (Windows), щоб запускати команди FFmpeg.

3. **Відеофайл**:

    - Підготуйте відеофайл MP4, AVI, MOV, MKV або MPEG.

# Перш ніж почати

Перед виконанням будь-яких команд підготуйте таке:

## Увімкніть розширення файлів

  - Важливо бачити розширення файлів, наприклад `.mp4` або `.avi`, коли ви перейменовуєте відеофайл.

    - **У Windows**:

      - Відкрийте Провідник файлів.
      - Натисніть вкладку "Вигляд" угорі.
      - Поставте прапорець біля пункту "Розширення імен файлів".

    - **У macOS**:

      - Відкрийте Finder.
      - Натисніть "Finder" у рядку меню та виберіть "Параметри".
      - Перейдіть на вкладку "Додатково" і встановіть прапорець "Показувати всі розширення імен файлів".

## Створіть папку для вихідних файлів

- Створіть папку з назвою `output_frames` у каталозі, де розташований виконуваний файл FFmpeg. Саме сюди буде збережено витягнуті кадри.

## Підготуйте відеофайл

- Помістіть відеофайл, з якого ви хочете витягнути кадри, у той самий каталог, що й виконуваний файл FFmpeg.
- Перейменуйте відеофайл на `input`, додавши його розширення (наприклад, `input.mp4`, `input.avi` тощо). Це гарантує, що наведені нижче команди працюватимуть без змін.

# Як відкрити FFmpeg

Перш ніж використовувати FFmpeg, його потрібно відкрити через командний рядок. Ось як це зробити крок за кроком у Windows і macOS.

## У Windows:

1. **Відкрийте командний рядок**:
   - Натисніть клавіші `Windows` і `R` одночасно, щоб відкрити вікно "Виконати".
   - Введіть `cmd` і натисніть Enter. Відкриється командний рядок.

2. **Перейдіть до папки FFmpeg**:
   - Потрібно вказати комп’ютеру, де розташований FFmpeg. Використайте команду `cd`, щоб перейти до папки, у якій ви зберегли FFmpeg.
   - Наприклад, якщо FFmpeg знаходиться в папці `ffmpeg-2024\bin` на вашому робочому столі, введіть:
     ```bash
     cd C:\Users\YourUsername\Desktop\ffmpeg-2024\bin
     ```
     (Замініть "YourUsername" на своє фактичне ім’я користувача на комп’ютері.)

3. **Перевірте, що FFmpeg працює**:
   - Щоб переконатися, що FFmpeg працює, введіть таку команду:
     ```bash
     ffmpeg -version
     ```
   - Якщо все працює, на екрані з’явиться інформація про FFmpeg.

## У macOS:

1. **Відкрийте Терминал**:
   - Натисніть `Command` і `Space` одночасно, щоб відкрити пошук Spotlight.
   - Введіть `Terminal` і натисніть Enter, щоб відкрити його.

2. **Перейдіть до папки FFmpeg**:
   - Використайте команду `cd`, щоб перейти до папки, у якій ви зберегли FFmpeg.
   - Наприклад, якщо FFmpeg знаходиться у папці `Downloads`, введіть:
     ```bash
     cd ~/Downloads/ffmpeg-2024/bin
     ```

3. **Перевірте, що FFmpeg працює**:
   - Щоб переконатися, що FFmpeg готовий до роботи, введіть таку команду:
     ```bash
     ./ffmpeg -version
     ```
   - Якщо FFmpeg працює, на екрані з’являться відомості про нього.

# Як зберегти всі кадри

Щоб зберегти всі кадри з відео, використайте цю команду:

```bash
ffmpeg -i input.mp4 output_frames/%d.png
```

## Що це означає:

- `-i input.mp4`: Це ваш вхідний відеофайл. Він має бути в тій самій папці, що й виконуваний файл FFmpeg. Не забудьте змінити `input.mp4` на правильну назву файлу та розширення.
- `output_frames/frame_%04d.png`: Ось як буде збережено кадри:
- `output_frames/`: Зберігає всі кадри в папці `output_frames`.
- `%d.png`: Кадри будуть названі числами, наприклад `1.png`, `2.png` тощо, у правильному порядку.

# Збереження кадрів у певний час

Якщо вам не потрібні всі кадри, ви можете зберігати один кадр щосекунди (або через інші інтервали). Використайте цю команду:

```bash
ffmpeg -i input.mp4 -vf "fps=1" output_frames/%d.png
```

## Що це означає:

- `-i input.mp4`: Це ваш вхідний відеофайл. Він має бути в тій самій папці, що й виконуваний файл FFmpeg. Не забудьте змінити `input.mp4` на правильну назву файлу та розширення.
- `-vf "fps=1"`: Зберігає один кадр за секунду. Змініть `1` на інше число, якщо хочете отримувати кадри частіше або рідше (наприклад, `fps=0.5` зберігає один кадр кожні дві секунди, а `fps=2` — два кадри за секунду).
- `output_frames/%d.png`: Зберігає кадри в папці з назвою `output_frames` під іменами на кшталт `1.png`, `2.png` тощо.

# Зміна розміру та якості кадрів

Ви також можете налаштувати розмір і якість кадрів, які зберігаєте. Ось як це зробити:

```bash
ffmpeg -i input.mp4 -vf "scale=1280:720" -q:v 2 output_frames/%d.png
```

## Що це означає:

- `-i input.mp4`: Це ваш вхідний відеофайл. Він має бути в тій самій папці, що й виконуваний файл FFmpeg. Не забудьте змінити `input.mp4` на правильну назву файлу та розширення.
- `-vf "scale=1280:720"`: Змінює розмір кадру до 1280x720 пікселів.
- `-q:v 2`: Встановлює якість зображення (1 — найкраща, більші числа означають нижчу якість).
- `output_frames/%d.png`: Зберігає кадри в папці з назвою `output_frames` під іменами на кшталт `1.png`, `2.png` тощо.

# Поради щодо збереження кадрів

1. **Економте місце**:

   - Якщо відео довге, ви можете зберігати кадри через інтервали замість того, щоб зберігати кожен кадр. Це особливо корисно, якщо ви використовуєте їх як кадри анімації FMA у FancyMenu.

2. **Дізнайтеся більше**:

   - Запустіть `ffmpeg -h` у терміналі, щоб побачити всі корисні можливості FFmpeg.
