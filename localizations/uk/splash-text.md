# Користувацький елемент Splash Text

Елемент Splash Text у FancyMenu — це повністю налаштовуване покращення для класичних підстрибуючих написів Minecraft. Він зберігає знайоме підстрибування, але дає вам контроль над тим, що саме показується, як це виглядає та коли оновлюється.

> Майте на увазі, що ви не можете по-справжньому налаштувати оригінальний ванільний елемент Splash Text на екрані Title, тому вам слід **видалити** його та натомість використовувати власний елемент Splash Text.
{.is-warning}

## Додавання та вибір елемента
- Відкрийте редактор макета та додайте елемент `Splash Text`.
- Клацніть лівою кнопкою миші один раз, щоб вибрати його та показати рамку, потім клацніть правою кнопкою, щоб відкрити контекстне меню. Усі параметри налаштування знаходяться саме в цьому меню.

## Вибір джерела тексту сплеша
- `Source Mode: Vanilla` залишає класичні випадкові сплеші, які постачаються разом із Minecraft.
- `Source Mode: Direct Input` дозволяє ввести власний текст через `Input Splash Text`. Тут підтримується лише один рядок splash-тексту, але він може містити плейсхолдери.
- `Source Mode: Text File` бере випадковий рядок із `.txt` файла, який ви вибираєте через `Set Source Text File`. Кожен непорожній рядок може стати активним сплешем.
- Перемикання режимів скидає активний текст, тож ви можете безпечно експериментувати. Якщо здається, що текст «застряг», перемкніть інший режим або натисніть `Refresh On Screen Load: Enabled`, щоб примусово обирати новий варіант щоразу, коли відкривається меню.

## Приклад текстового файла
Під час використання режиму джерела "Text File" збережіть список сплешів як звичайний текст (UTF-8 без BOM). Кожен рядок — це можливий сплеш:

```
Welcome to FancyMenu!
{"placeholder":"your_placeholder_id_here"}
{"text":"This is gold and bold text.","color":"gold","bold":true}
&6Use &lMinecraft formatting codes!
```

Замініть `your_placeholder_id_here` на плейсхолдер, який має розв’язуватися під час виконання. FancyMenu обирає випадковий непорожній рядок щоразу, коли сплеш оновлюється.

## Налаштування зовнішнього вигляду
- Використовуйте `Set Scale` і `Set Rotation`, щоб керувати розміром і кутом обертання.
- `Set Text Color` приймає hex-значення (наприклад `#FFFF00`), щоб відповідати вашій темі.
- `Shadow: Enabled` додає стандартну тінь Minecraft; вимкніть її для плаского тексту.
- `Bouncing: Enabled` зберігає знайоме підстрибування; вимкніть для статичного напису.
- FancyMenu рендерить сплеш як повноцінний компонент Minecraft, тому кольорові коди та інші текстові декорації працюють як очікується.

## Динамічні можливості тексту
- Плейсхолдери розв’язуються перед рендерингом, тож ви можете посилатися на імена гравців, дати або інші підтримувані значення прямо в тексті сплешу.
- Оскільки елемент приймає серіалізований JSON-компонент Minecraft, ви можете вставляти складні JSON-фрагменти в Direct Input або у ваш текстовий файл. Елемент автоматично десеріалізує їх і повертається до буквального тексту, якщо щось піде не так.

## Усунення неполадок
- Порожній текст у Direct Input показує `< empty splash element >` під час редагування. Введіть будь-що (навіть пробіл), щоб прибрати попередження.
- Якщо текстовий файл не містить жодного дійсного рядка, елемент показує `ERROR: SPLASH FILE IS EMPTY`. Додайте щонайменше один непорожній рядок і знову відкрийте екран.
- Помилки серіалізованого JSON повертаються до звичайного тексту. Дотримуйтеся стандартної JSON-структури Mojang або перевіряйте фрагменти за допомогою ванільної команди `/tellraw` перед вставленням.
