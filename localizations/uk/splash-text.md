# Власний елемент тексту заставки

Елемент тексту заставки у FancyMenu — це повністю налаштовуване вдосконалення стандартних заставок Minecraft, що підстрибують. Він зберігає знайомий ефект підстрибування, водночас даючи змогу керувати тим, що відображається, як це виглядає та коли оновлюється.

> [!WARNING]
> Зверніть увагу: оригінальний стандартний елемент тексту заставки на екрані заголовка насправді неможливо налаштувати, тому його слід **видалити** й натомість використовувати власний елемент тексту заставки.

## Додавання та вибір елемента
- Відкрийте редактор макета й додайте елемент `Splash Text`.
- Один раз клацніть його лівою кнопкою миші, щоб вибрати його та відобразити обмежувальну рамку, а потім клацніть правою кнопкою миші, щоб відкрити контекстне меню. Усі параметри налаштування містяться в цьому меню.

## Вибір джерела тексту заставки
- `Source Mode: Vanilla` використовує класичні випадкові заставки, які постачаються разом із Minecraft.
- `Source Mode: Direct Input` дає змогу ввести власний текст через `Input Splash Text`. Цей режим підтримує лише один рядок тексту заставки, але рядок може містити заповнювачі.
- `Source Mode: Text File` вибирає випадковий рядок із файлу `.txt`, який ви вкажете за допомогою `Set Source Text File`. Кожен непорожній рядок може стати активною заставкою.
- Перемикання режимів скидає активний текст, щоб ви могли безпечно експериментувати. Якщо текст не змінюється, перемкніть інший режим або натисніть `Refresh On Screen Load: Enabled`, щоб примусово вибирати новий текст щоразу під час відкриття меню.

## Приклад текстового файлу
Якщо ви використовуєте режим джерела "Text File", збережіть список заставок як звичайний текст (UTF-8 без BOM). Кожен рядок є можливою заставкою:

```
Welcome to FancyMenu!
{"placeholder":"your_placeholder_id_here"}
{"text":"This is gold and bold text.","color":"gold","bold":true}
&6Use &lMinecraft formatting codes!
```

Замініть `your_placeholder_id_here` на заповнювач, який потрібно обробити під час виконання. FancyMenu вибирає випадковий непорожній рядок щоразу, коли заставка оновлюється.

## Налаштування вигляду
- Використовуйте `Set Scale` і `Set Rotation`, щоб керувати розміром і кутом повороту.
- `Set Text Color` приймає шістнадцяткове значення (наприклад, `#FFFF00`), щоб узгодити текст із вашою темою.
- `Shadow: Enabled` додає тінь, як у Minecraft; вимкніть цей параметр для плаского тексту.
- `Bouncing: Enabled` зберігає знайомий ефект погойдування; вимкніть його, щоб отримати статичний напис.
- FancyMenu відображає заставку як повноцінний компонент Minecraft, тому коди кольорів та інші оформлення тексту працюють належним чином.

## Функції динамічного тексту
- Заповнювачі обробляються перед відображенням, тому всередині тексту заставки можна використовувати імена гравців, дати або інші підтримувані значення.
- Оскільки елемент підтримує серіалізований JSON компонентів Minecraft, ви можете вставляти розширені фрагменти JSON у Direct Input або текстовий файл. Елемент автоматично десеріалізує їх і в разі помилки використовує звичайний текст.

## Усунення несправностей
- Порожній текст у Direct Input під час редагування відображається як `< empty splash element >`. Введіть будь-що (навіть пробіл), щоб прибрати попередження.
- Якщо текстовий файл не містить дійсних рядків, елемент відображає `ERROR: SPLASH FILE IS EMPTY`. Додайте щонайменше один непорожній рядок і знову відкрийте екран.
- У разі помилок серіалізованого JSON використовується звичайний текст. Дотримуйтеся стандартної структури JSON від Mojang або перевіряйте фрагменти за допомогою стандартної команди `/tellraw` перед вставленням.
