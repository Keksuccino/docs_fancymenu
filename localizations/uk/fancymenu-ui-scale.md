# Масштаб інтерфейсу FancyMenu

Інтерфейс FancyMenu (наприклад, рядок меню та контекстні меню) використовує окремий масштаб, не пов’язаний зі звичайним масштабом GUI в Minecraft.

Якщо інтерфейс FancyMenu здається вам занадто малим або занадто великим, ви можете змінити масштаб інтерфейсу через **рядок меню -> Налаштування оформлення -> Налаштування -> Інтерфейс FancyMenu**.

Коли масштаб інтерфейсу встановлено на **Авто**, найменший автоматичний масштаб — `1.25`. Ви можете вручну вибрати масштаб `1`.

Єдиний виняток — це справжні повноекранні екрани, додані FancyMenu, наприклад екран для керування змінними або редактор макета. У більшості випадків ці екрани використовують звичайний масштаб GUI Minecraft, але можливо, що деякі екрани використовують іншу логіку авто-масштабування, щоб автоматично відображатися з меншим масштабом, коли вікно інакше було б занадто малим, щоб умістити весь вміст екрана.
