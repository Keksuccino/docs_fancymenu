# Масштаб інтерфейсу FancyMenu

Інтерфейс FancyMenu (наприклад, панель меню та контекстні меню) використовує окремий масштаб, який не пов’язаний зі звичайним масштабом GUI в Minecraft.

Якщо інтерфейс FancyMenu здається вам занадто малим або занадто великим, ви можете змінити масштаб інтерфейсу через **панель меню -> Налаштування оформлення -> Налаштування -> Інтерфейс FancyMenu**.

У FancyMenu 3.9.0 додано більше варіантів масштабу інтерфейсу. Коли для масштабу інтерфейсу встановлено значення **Авто**, найменший автоматичний масштаб тепер становить `1.25`; за бажання ви все ще можете вручну вибрати масштаб `1`.

Єдиний виняток — це справжні повноекранні вікна, додані FancyMenu, наприклад екран для керування змінними або редактор макета. Ці екрани, у більшості випадків, використовують звичайний масштаб GUI Minecraft, але деякі екрани можуть використовувати іншу логіку автоматичного масштабування, щоб відображатися меншими, коли вікно інакше було б надто малим для всього вмісту екрана.
