# Локалізація макетів

FancyMenu дає змогу локалізувати текстовий вміст і навіть цілі елементи або макети!

# Текстовий вміст

FancyMenu дозволяє додавати власні локалізації до гри.
Потім їх можна використовувати з підстановкою **Localize Text**, щоб локалізувати текст відповідно до поточної мови гри.

## Використання стандартних ключів локалізації Minecraft

Перш ніж створювати власні локалізації, можливо, варто скористатися наявними ключами локалізації Minecraft. Це економить час і забезпечує узгодженість зі стандартним текстом Minecraft.

### Пошук стандартних ключів локалізації

Найпростіший спосіб знайти ключі локалізації Minecraft — переглянути файли ресурсів гри онлайн:

1. **Відвідайте MCAsset.cloud:**  
   Перейдіть на [https://mcasset.cloud/](https://mcasset.cloud/) — цей вебсайт дає змогу переглядати ресурси Minecraft без вилучення їх із гри.

2. **Перейдіть до мовних файлів:**  
   - Виберіть вашу версію Minecraft у випадаючому списку
   - Перейдіть до: `assets` → `minecraft` → `lang`
   - Відкрийте `en_us.json`, щоб побачити всі англійські локалізації

3. **Знайдіть потрібний ключ:**  
   - Скористайтеся пошуком у браузері (Ctrl+F або Cmd+F), щоб знайти потрібний текст
   - Формат такий: `"key": "text"` — перша частина в лапках перед двокрапкою (`:`) є ключем
   - Наприклад: `"menu.singleplayer": "Singleplayer"` — ключ тут `menu.singleplayer`

### Використання ключів локалізації модів

Якщо у вас встановлені інші моди, ви також можете використовувати їхні ключі локалізації:

1. Перевірте документацію мода на наявні ключі
2. Перегляньте мовні файли мода, якщо він має відкритий вихідний код

## Власні файли локалізації

Файли локалізації — це текстові файли з усім текстовим вмістом, який має бути доступний кількома мовами. Кожен текст, що перекладається, має унікальний ключ, тож Minecraft може знайти правильний текст у файлах локалізації.

- **Файл за замовчуванням (en_us.json):**  
  Англійська (США). Цей файл використовується, якщо не вибрано іншу мовну версію. Він виконує роль резервного мовного файлу.

- **Інші мовні файли:**  
  Наприклад, ви можете створити німецький файл під назвою `de_de.json` для гравців, які користуються німецькою мовою.

### Як створити власний файл локалізації

Вам завжди потрібен файл `en_us.json`! Без нього в гри немає резервного варіанта, якщо щось піде не так або буде встановлено непідтримувану мову.

1. **Відкрийте текстовий редактор:**  
   Використайте Notepad (Windows), TextEdit (Mac) або будь-який простий текстовий редактор.

2. **Напишіть JSON-код:**  
   Створіть файл із власними ключами. Ключ — це унікальна назва, яку Minecraft використовує для пошуку тексту. Наприклад:
   
   ```json
   {
     "modpack_name.custom.localization.key": "Ваш власний текст тут",
     "modpack_name.another.key": "Інше повідомлення"
   }
   ```

3. **Збережіть файл:**  
   Збережіть файл як `en_us.json` для тексту англійською за замовчуванням.

Якщо тепер ви хочете додати перекладені версії, наприклад німецьку, скопіюйте вміст із файлу `en_us.json` у новий файл і перекладайте лише сам текст, А НЕ ключі! Ключі мають залишатися тими самими, щоб гра все ще могла знайти текст.

Для німецької мови файл слід зберегти як `de_de.json`. Для інших мов, будь ласка, перевірте [цю сторінку Minecraft Wiki](https://minecraft.wiki/w/Language), щоб знайти правильний код мови, і назвіть файл відповідно до нього. Знайдіть **"in-game locale code"** для вашої мови.

## Створення пакета ресурсів Minecraft для MC 1.21.4

Тепер, коли ваші файли локалізації готові, нам потрібен спосіб завантажити їх у Minecraft. Для цього ми використаємо пакет ресурсів. Ми зробимо так, щоб він був увімкнений за замовчуванням, а за потреби навіть приховаємо його, щоб користувачі збірки не могли його змінювати.

**Пакет ресурсів** — це ZIP-файл, який містить файли, що змінюють вигляд і стиль гри.

### Кроки створення пакета ресурсів

1. **Створіть нову папку:**  
   Створіть папку з назвою на кшталт `my_custom_pack`, куди ви додасте власні файли локалізації.

2. **Створіть файл пакета (`pack.mcmeta`):**  
   Усередині папки створіть файл `pack.mcmeta` із таким вмістом:
   
   ```json
   {
     "pack": {
       "pack_format": 16,
       "description": "Мій власний пакет із локалізаціями"
     }
   }
   ```
   
   *Примітка: `pack_format` 16 призначено для Minecraft 1.21.4.*

3. **Додайте файли локалізації:**  
   Усередині папки вашого пакета ресурсів створіть таку структуру папок:
   
   ```
   my_custom_pack/
   ├── assets/
   │   └── minecraft/
   │       └── lang/
   │           ├── en_us.json
   │           └── de_de.json
   └── pack.mcmeta
   ```
   
   Помістіть власний `en_us.json` (і будь-які інші мовні файли, наприклад `de_de.json`) у папку `lang`.

4. **Стисніть пакет ресурсів у ZIP:**  
   Після того як папка готова, **стисніть всю папку в ZIP-файл**. Назвіть ZIP-файл **my_custom_pack.zip**. Це приклад назви, який використовується впродовж усього посібника.

## Де розмістити пакет ресурсів

Помістіть файл **my_custom_pack.zip** у папку **Minecraft Resourcepacks**. Зазвичай вона розташована тут:

- **Windows:** `%appdata%\.minecraft\resourcepacks`
- **Mac:** `~/Library/Application Support/minecraft/resourcepacks`
- **Linux:** `~/.minecraft/resourcepacks`

> Для модпаків папка `resourcepacks` знаходиться в каталозі інстанса вашого пакета.

## Автоматичне завантаження пакета за допомогою "Resource Pack Overrides"

Мод **Resource Pack Overrides** дає змогу вмикати пакети ресурсів за замовчуванням.

### Кроки для автоматичного завантаження пакета

1. **Встановіть мод:**  
   Завантажте та встановіть мод із [CurseForge](https://www.curseforge.com/minecraft/mc-mods/resource-pack-overrides) або [Modrinth](https://modrinth.com/mod/resource-pack-overrides).

2. **Знайдіть файл конфігурації:**  
   Знайдіть файл `.minecraft/config/resourcepackoverrides.json`.  
   *Якщо файлу немає, створіть його вручну.*

3. **Відредагуйте файл конфігурації:**  
   Відкрийте файл і додайте свій пакет ресурсів до списку `default_packs`, використавши його назву файлу:
   
   ```json
   {
     "schema_version": 2,
     "default_packs": [
       "file/my_custom_pack.zip"
     ]
   }
   ```
   
   Це повідомляє Minecraft автоматично завантажувати ваш пакет ресурсів під час запуску гри.

   **Важливо додати префікс `file/`!**


*Примітка: Пакети ресурсів у списку застосовуються у зворотному порядку. Це означає, що пакет на початку списку в меню пакетів ресурсів гри відображатиметься нижче за інші.*

## Приховування пакета ресурсів на екрані вибору

Ви можете приховати свій пакет ресурсів, щоб гравці не бачили його на екрані вибору пакетів ресурсів.

### Як його приховати

1. **Знову відредагуйте файл конфігурації:**  
   У тому самому файлі `.minecraft/config/resourcepackoverrides.json` додайте перевизначення для свого пакета:
   
   ```json
   {
     "schema_version": 2,
     "default_packs": [
       "file/my_custom_pack.zip"
     ],
     "pack_overrides": {
       "file/my_custom_pack.zip": {
         "hidden": true
       }
     }
   }
   ```
   
   Ця конфігурація приховає **my_custom_pack.zip** з екрана вибору, але все одно завантажуватиме його автоматично.

## Використання нових ключів локалізації у FancyMenu

Тепер, коли ваші власні файли локалізації завантажені, ви можете використовувати нові ключі в макетах FancyMenu.

1. **Відредагуйте текстовий елемент:**  
   Відкрийте FancyMenu та виберіть елемент, наприклад кнопку або текстовий елемент.

2. **Натисніть кнопку Placeholders:**  
   Знайдіть кнопку Placeholders у верхньому правому куті текстового редактора. (Якщо її не видно, можливо, елемент не підтримує підстановки.)

3. **Вставте підстановку Localize Text:**  
   Підстановка Localize Text відображається як JSON-фрагмент. Вона виглядає так:
   
   ```json
   {"placeholder":"local","values":{"key":"localization.key"}}
   ```
   
   Замініть `localization.key` на власний ключ. Наприклад, якщо ви хочете використати ключ із файлу локалізації, змініть його на:
   
   ```json
   {"placeholder":"local","values":{"key":"modpack_name.custom.localization.key"}}
   ```

Ось, і це, по суті, все! Підстановка має замінюватися на фактичний локалізований вміст, коли ви не редагуєте його в текстовому редакторі.

Пам’ятайте, що підстановка завжди локалізує текстовий вміст відповідно до поточної мови гри.

# Нетекстовий вміст (зображення тощо)

FancyMenu також дає змогу локалізувати зображення і, по суті, будь-який елемент, який вам потрібен.

Для цього потрібно використовувати **loading requirements**.
Якщо точніше — вимогу **Is Game Language**.

Вимога **Is Game Language** дає змогу показувати елементи або макети лише тоді, коли встановлено певну мову гри. Наприклад, ви можете створити два елементи Image, що містять текст, і локалізувати це зображення до версії з японським текстом, якщо вибрано японську мову, або до версії з англійським текстом, якщо вибрано англійську.

Щоб задати loading requirements для **елемента**, клацніть його правою кнопкою миші та натисніть **Loading Requirements**.

Щоб задати loading requirements для **всього макета**, клацніть правою кнопкою миші на тлі редактора макета та натисніть **Loading Requirements [Layout-Wide]**.
