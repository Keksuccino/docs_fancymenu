# Локалізація макетів

Використовуйте заповнювач [**Локалізувати текст**](/placeholders#localize-text) для тексту, який потрібно перекласти:

```text
{"placeholder":"local","values":{"key":"modpack.menu.play"}}
```

FancyMenu спочатку перевіряє активні мовні дані Minecraft. Якщо ключа там немає, він перевіряє власні файли локалізації FancyMenu. Якщо ключа немає в жодному з джерел, буде показано сам ключ.

# Власні файли локалізації FancyMenu

Розмістіть файли в каталозі:

```text
<game-directory>/config/fancymenu/custom_locals/
```

Створіть підкаталог для файлів локалізації:

```text
custom_locals/
└── my_pack/
    └── text.json
```

Розміщуйте файли локалізації щонайменше в одному підкаталозі `custom_locals`; файли, розміщені безпосередньо в кореневому каталозі `custom_locals`, не завантажуються. Вкладені підкаталоги підтримуються.

Підтримувані формати UTF-8:

| Розширення | Формат |
|---|---|
| `.json` | Об’єкт JSON; вкладені об’єкти перетворюються на ключі, розділені крапками |
| `.lang` | Рядки у форматі `key=value` |
| `.properties` | Синтаксис Java Properties |

Приклад JSON:

```json
{
  "modpack": {
    "menu": {
      "play": "Play"
    }
  }
}
```

Це визначає ключ `modpack.menu.play`.

FancyMenu об’єднує підтримувані файли з цих підкаталогів в один власний словник локалізації. Використовуйте кожен ключ лише в одному файлі. Власні файли локалізації не змінюються разом із вибраною в Minecraft мовою; якщо потрібне автоматичне перемикання мов, скористайтеся наведеним нижче способом із пакетом ресурсів.

Після редагування власних файлів локалізації перезапустіть клієнт.

# Текст для різних мов

Щоб автоматично перемикати мову відповідно до вибраної в Minecraft, додайте стандартні мовні файли Minecraft до [пакета ресурсів](/resources#minecraft-resources-resource-packs):

```text
assets/<namespace>/lang/en_us.json
assets/<namespace>/lang/de_de.json
```

Використовуйте однакові ключі у файлах для кожної мови, увімкніть пакет ресурсів, а потім зчитуйте значення за допомогою заповнювача [**Локалізувати текст**](/placeholders#localize-text).

# Локалізація зображень та елементів

Використовуйте умову [**Мова гри**](/conditions#is-game-language), щоб показувати різні елементи або макети для різних кодів мов, наприклад `en_us` і `de_de`.
