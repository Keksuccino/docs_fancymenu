# Локалізація макетів

Використовуйте [**Заповнювач Localize Text**](./placeholders#localize-text-local) для тексту, який потрібно перекладати:

```text
{"placeholder":"local","values":{"key":"modpack.menu.play"}}
```

FancyMenu спочатку перевіряє активні мовні дані Minecraft. Якщо ключа там немає, програма перевіряє власні файли локалізації FancyMenu. Якщо жодне джерело не містить ключа, відображається сам ключ.

# Власні файли локалізації FancyMenu

Розміщуйте файли тут:

```text
<game-directory>/config/fancymenu/custom_locals/
```

Створіть підкаталог для файлів локалізації:

```text
custom_locals/
└── my_pack/
    └── text.json
```

Поміщайте файли локалізації щонайменше в один підкаталог `custom_locals`; файли, розміщені безпосередньо в корені `custom_locals`, не завантажуються. Підтримуються вкладені підкаталоги.

Підтримувані формати UTF-8:

| Розширення | Формат |
|---|---|
| `.json` | JSON-об’єкт; вкладені об’єкти стають ключами через крапку |
| `.lang` | рядки виду `key=value` |
| `.properties` | синтаксис Java properties |

Приклад JSON:

```json
{
  "modpack": {
    "menu": {
      "play": "Play"
    }
  }
}
```

Це визначає `modpack.menu.play`.

FancyMenu об’єднує підтримувані файли з цих підкаталогів в один власний словник локалізації. Використовуйте кожен ключ лише в одному файлі. Власні файли локалізації не перемикаються разом із вибраною мовою Minecraft; використовуйте метод із ресурс-паком нижче, якщо вам потрібне автоматичне перемикання мови.

Перезапустіть клієнт після редагування власних файлів локалізації.

# Текст, залежний від мови

Для автоматичного перемикання разом із вибраною мовою Minecraft надайте звичайні мовні файли Minecraft через [ресурс-пак](./resources#minecraft-resources-resource-packs):

```text
assets/<namespace>/lang/en_us.json
assets/<namespace>/lang/de_de.json
```

Використовуйте однакові ключі в кожному мовному файлі, увімкніть ресурс-пак, а потім читайте їх за допомогою [**Заповнювача Localize Text**](./placeholders#localize-text-local).

# Локалізація зображень та елементів

Використовуйте [**Вимогу Is Game Language**](./conditions#is-game-language-fancymenu_loading_requirement_is_language), щоб показувати різні елементи або макети для різних кодів мов, наприклад `en_us` і `de_de`.
