# Комбінації клавіш і гарячі клавіші

**Модифікатор комбінацій:** Використовуйте `Ctrl` у Windows/Linux і `Command` у macOS, де це підтримується.

# Редактор макета

| Комбінація | Дія |
|---|---|
| `Ctrl/Command + left-click` | Вибрати або перетягнути кілька елементів |
| `Shift + resize` | Зберегти пропорції елемента |
| `Arrow keys` | Точно переміщувати вибрані елементи |
| `Ctrl/Command + A` | Виділити всі елементи |
| `Ctrl/Command + C` | Скопіювати вибрані елементи |
| `Ctrl/Command + V` | Вставити скопійовані елементи, зокрема в інший макет |
| `Ctrl/Command + S` | Зберегти макет |
| `Ctrl/Command + Z` | Скасувати |
| `Ctrl/Command + Y` | Повторити |
| `Ctrl/Command + G` | Перемкнути сітку |
| `O` | Показувати точки прив’язки під час утримання, коли для **Window -> Anchor Overlay Visibility** встановлено **Show On Key Press** |
| `Delete` | Видалити вибрані елементи |

# Текстовий редактор

| Комбінація | Дія |
|---|---|
| `Ctrl/Command + C` | Скопіювати вибраний текст |
| `Ctrl/Command + V` | Вставити текст |
| `Ctrl/Command + Z` | Скасувати |
| `Ctrl/Command + Y` | Повторити |
| `Ctrl/Command + A` | Виділити весь текст |
| `Ctrl/Command + D` | Дублювати поточний рядок |
| `Ctrl/Command + U` | Вирізати вибраний текст |
| `Alt + Arrow Up/Down` | Перемістити поточний рядок |
| `Ctrl/Command + Home/End` | Перейти на початок або кінець тексту |
| `Ctrl/Command + G` | Відкрити **Go To Line** |
| `Ctrl/Command + S` | Підтвердити редактор |
| `Shift + Arrow keys` | Розширити виділення тексту |
| `Arrow keys` | Перемістити курсор |

# Глобальні комбінації меню

Ці комбінації використовують точне поєднання `Ctrl + Alt`:

| Комбінація | Дія |
|---|---|
| `Ctrl + Alt + L` | Відкрити редактор макета з останнім відредагованим макетом |
| `Ctrl + Alt + C` | Перемкнути панель меню FancyMenu |
| `Ctrl + Alt + R` | Перезавантажити FancyMenu та керовані ним ресурси/кеші |
| `Ctrl + Alt + D` | Перемкнути налагоджувальне накладання FancyMenu |

# Вікна редагування

Вікна редагування FancyMenu підтримують навігацію клавіатурою за допомогою стрілок і `Enter`. У багатьох також використовується `Ctrl/Command + S` для **Done** і `Escape` для **Cancel**.

Редактори Action Script, Requirements і Variables також підтримують контекстні меню правою кнопкою миші, пошук, скасування/повторення та навігацію списками за допомогою клавіатури.
