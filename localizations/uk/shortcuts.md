# Комбінації клавіш і гарячі клавіші

У FancyMenu є багато корисних комбінацій клавіш, які роблять роботу з **редактором макетів** та іншими частинами мода зручнішою й ефективнішою.

# Редактор макетів

<br>

## CTRL + Ліва кнопка миші

Ви можете вибирати кілька елементів, утримуючи **CTRL** і **клацаючи лівою кнопкою миші** по елементах.
Також можна **перетягувати/переміщати кілька елементів** мишею, утримуючи **CTRL**.

## SHIFT + Зміна розміру елемента

Під час зміни розміру елементів із затиснутим SHIFT їхні пропорції будуть збережені.

## Клавіші зі стрілками

Клавіші зі стрілками можна використовувати для **переміщення** вибраних елементів із максимальною точністю.

## CTRL + A

Вибрати всі елементи одразу.

## CTRL + C

**Скопіювати** всі вибрані елементи в буфер обміну.

## CTRL + V

**Вставити** всі елементи, які наразі є в буфері обміну.
Це також працює між різними макетами, тож ви можете скопіювати елементи в макеті A і вставити їх у макет B.

## CTRL + S

Швидко **зберегти** макет.

## CTRL + ALT + L

Швидко відкрити редактор макетів із останнім відредагованим макетом.

## CTRL + Z

**Скасувати** останню дію.

## CTRL + Y

**Повторити** раніше скасовану дію.

## CTRL + G

Швидко ввімкнути або вимкнути **сітку**.

## O

Утримування **O** показує накладку точки прив’язки, якщо для її видимості встановлено **Показувати при натисканні клавіші** у **Window -> Anchor Overlay Visibility**.

## DEL

**Видалити** всі вибрані елементи.

# Текстовий редактор

<br>

## CTRL + C

**Скопіювати** вибраний текст у буфер обміну.

## CTRL + V

**Вставити** текст, який наразі є в буфері обміну.

## CTRL + Z

**Скасувати** останню дію.

## CTRL + Y

**Повторити** раніше скасовану дію.

## CTRL + A

**Вибрати** весь текст.

## CTRL + D

**Дублювати** поточний рядок.

## CTRL + U

**Вирізати** вибраний текст.

## ALT + Стрілка вгору / Стрілка вниз

Перемістити поточний рядок вгору або вниз.

## CTRL + Home / CTRL + End

Перемістити курсор на початок або кінець тексту.

## CTRL + G

Відкрити поле **Go To Line**.

## CTRL + S

Підтвердити редактор, так само як натиснути **Done**.

## SHIFT + Клавіші зі стрілками

Виділяти/підсвічувати текст під час переміщення курсора.

## Клавіші зі стрілками

Клавіші зі стрілками можна використовувати для навігації курсора в тексті.

# У меню

<br>

## CTRL + ALT + C

Увімкнути або вимкнути видимість **панелі меню** FancyMenu у верхній частині меню.

## CTRL + ALT + R

**Перезавантажити** FancyMenu.
Це включає повне перезавантаження ресурсів/асетів, а також очищення більшості кешів.

## CTRL + ALT + D

Увімкнути або вимкнути видимість **налагоджувальної накладки** FancyMenu.

# Вікна редагування

Багато вікон редагування FancyMenu у v3.9.0 підтримують навігацію з клавіатури за допомогою **клавіш зі стрілками** та **Enter**. Багато вікон також використовують **CTRL + S** як ярлик для **Done** і **ESC** як **Cancel**.

Оновлені вікна Action Script Editor, Manage Requirements і Manage Variables також підтримують контекстні меню за правою кнопкою миші, пошук, undo/redo та навігацію клавіатурою для своїх списків.
