# Ідентифікатори екранів

FancyMenu використовує ідентифікатори екранів для макетів, віджетів Vanilla, [дій екрана](/action-scripts#open-screen-or-custom-gui) і [перевизначень Custom GUI](/custom-guis#overriding-an-existing-screen). Ідентифікатори чутливі до регістру, тому копіюйте їх точно з налагоджувального накладання.

Для вбудованих екранів зазвичай використовують короткий універсальний ідентифікатор, наприклад `title_screen`. Для екранів інших модів може використовуватися назва їхнього Java-класу. Для Custom GUI використовується ідентифікатор, указаний у менеджері. Це ідентифікатори екранів FancyMenu, а не шляхи до ресурсів Minecraft.

# Як знайти ідентифікатор екрана

Ідентифікатор поточного активного меню можна переглянути в **налагоджувальному накладанні**.
У ньому зазначено ідентифікатор поточного екрана, який можна скопіювати в буфер обміну, клацнувши його лівою кнопкою миші.

>[!TIP]
>Увімкнути **налагоджувальне накладання** можна, натиснувши **CTRL + ALT + D**, коли ви **не** перебуваєте в редакторі макетів.

# Відкриття екранів

Дія [**Відкрити екран або Custom GUI**](/action-scripts#open-screen-or-custom-gui) може відкривати лише ті екрани, які FancyMenu здатен створити в поточному стані гри. Для деяких екранів потрібен завантажений світ, підключення, гравець або початковий батьківський екран.

Якщо FancyMenu не може створити екран за вказаним ідентифікатором, з’явиться повідомлення про помилку. Скористайтеся дією [**Імітувати кнопку Vanilla/моду**](/action-scripts#mimic-vanillamod-button) для віджета, який зазвичай відкриває цей екран.
