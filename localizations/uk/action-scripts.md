# Скрипти дій

Скрипти дій запускають налаштовані завдання, коли натискають [Button](./elements#button), оновлюється [Ticker](./elements#ticker), змінюється [Slider](./elements#slider), відкривається або закривається екран чи відбувається інша підтримувана подія. Такі оператори, як **if**, **else-if**, **else** і **while**, додають умовне керування.

> [!CAUTION]
> Імпортовані скрипти дій можуть змінювати файли, звертатися до серверів, відкривати посилання або запускати команди. Використовуйте лише ті джерела, яким довіряєте.

# Що таке дії?

**Дія** — це завдання або операція, яку FancyMenu виконує після спрацювання тригера. Наприклад, дія може відкрити новий екран, надіслати повідомлення в чат або змінити гучність [Audio element](./elements#audio). У редакторі FancyMenu дії налаштовуються значенням (якщо потрібно), яке містить додаткові деталі — наприклад, URL або адресу сервера.

# Оператори

Щоб створювати складнішу поведінку, FancyMenu підтримує оператори керування в скриптах дій:

| Оператор | Поведінка |
|---|---|
| **If** | Виконує свої дії лише тоді, коли виконуються його [умови](./conditions). |
| **Else-If** | Перевіряє інший набір [умов](./conditions), якщо попередній **If** або **Else-If** не виконався. |
| **Else** | Виконується, коли жодна з попередніх умов **If** або **Else-If** не виконана. |
| **While** | Повторює свої дії, доки його [умови](./conditions) залишаються істинними. Щоб запобігти нескінченним циклам, зупиняється через три секунди; не використовуйте його як таймер. |

# Блоки

До скриптів можна додавати блоки, які дають корисні можливості для більшого контролю над потоком/часом виконання скрипта, а також деякі зручності:

| Блок | Поведінка |
|---|---|
| **Delay** | Запускає зворотний відлік, не зупиняючи решту скрипта. Вкладені дії стають доступними після завершення затримки; повторна ініціалізація екрана скидає відлік. |
| **Execute Later** | Планує нове виконання вкладених дій після затримки щоразу, коли блок досягається. |
| **Comment** | Додає примітку всередині скрипта для впорядкування і не виконує жодної дії. |

# Виконання скрипта

Дії виконуються зверху вниз. Невдалу дію заноситься до журналу, після чого скрипт продовжується.

Завантаження, розпакування ZIP і HTTP-запити завершуються пізніше; наступна дія їх не чекає. Використовуйте [**On File Downloaded via Action**](./listeners#on-file-downloaded-via-action-file_downloaded_via_action), [**On ZIP Extracted via Action**](./listeners#on-zip-extracted-via-action-zip_extracted_via_action) або змінну відповіді HTTP, якщо подальша робота залежить від результату.

# Де можна використовувати скрипти дій?

Скрипти дій універсальні й можуть використовуватися по всьому вашому макету. Їх можна призначати, наприклад, для:

- [**Buttons**](./elements#button): Виконати дію під час натискання кнопки.
- [**Tickers**](./elements#ticker): Безперервно запускати скрипт дій, щоб оновлювати інформацію на екрані в макеті.
- [**Sliders**](./elements#slider): Запускати скрипт дій щоразу, коли змінюється значення повзунка.
- **Screen Events:** Запускати скрипти, коли екран відкривається або закривається (наприклад, відтворювати звук, коли з’являється меню).
- [**Listeners**](./listeners): Коли listener отримує налаштовану подію, він запускає свій скрипт дій.
- [**Schedulers**](./schedulers): Виконувати дії за розкладом, навіть коли жоден екран не відкрито.

# Використання плейсхолдерів у діях

Значення дій підтримують динамічний вміст через **placeholders**. Найчастіше ці плейсхолдери використовують JSON-подібний синтаксис і підставляються актуальними даними під час виконання дії.

## JSON-подібні плейсхолдери

Це звичайні [placeholders](./placeholders), які можна використовувати в багатьох місцях у макетах.

Вони мають такий синтаксис:

```json
{"placeholder": "placeholder_id", "values": {"key1": "value1", "key2": "value2"}}
```

Вони можуть отримувати ігрові дані, як-от ім’я гравця, розміри екрана або обчислені значення за допомогою [**Calculator** placeholder](./placeholders#calculator-calc). Також можна вкладати плейсхолдери для складніших сценаріїв.

## `$$` Placeholders (Variables)

Значення `$$` — це значення лише для читання, які певному скрипту дій передає функція, що його запускає.

Наприклад, [Slider](./elements#slider) передає своє поточне значення як `$$value`.

Кожен [listener](./listeners) документує, які `$$`-значення він передає, наприклад натиснуту кнопку миші або введену структуру.

Назви `$$` чутливі до регістру й працюють лише в тому скрипті, який їх надає. Див. [Listeners](./listeners#listener-variables).

## Роздільники значень дії

Використовуйте точний роздільник, показаний для кожної дії: `:`, `||` або `|||`. Немає синтаксису екранування для роздільників усередині поля.

Плейсхолдери замінюються до того, як значення розділяється. Для `set_variable` лише перша двокрапка відокремлює ім’я від значення, тому наступні двокрапки залишаються частиною значення.

## Текстові значення

Коди форматування [FancyMenu](./text-formatting#minecraft-text-formatting) використовують `&` замість символу Minecraft `§` у всіх діях, які приймають форматований текст.

- [**Send Chat Message/Command**](#send-chat-messagecommand-sendmessage) і [**Paste to Chat**](#paste-to-chat-paste_to_chat) підтримують ці коди форматування.
- [**Display In Chat [Client-Side]**](#display-in-chat-client-side-display_in_chat_client_side) приймає звичайний текст або серіалізований JSON-компонент тексту Minecraft.
- [**Open URL in Browser**](#open-url-in-browser-openlink) застосовує таке саме перетворення кодів форматування перед передачею URL операційній системі.

# Як налаштовувати та редагувати дії

Щоб редагувати дії елемента та блоки операторів, **клацніть елемент правою кнопкою** і виберіть **Manage Action Script**. У редакторі ви можете:

- **Додавати нові дії або оператори:** Вставляти нові записи дій або оператори керування (if, else-if, else, while), щоб будувати свій скрипт.
- **Редагувати наявні дії або оператори:** Змінювати значення дії або логіку керування.
- **Видаляти дії або оператори:** Видаляти непотрібні дії зі скрипта.

Створюйте та редагуйте скрипти listener-ів через [**Customization -> Manage Listeners**](./listeners#using-listeners).

# Гарячі клавіші редактора скриптів дій

## Гарячі клавіші

- `DEL` : Швидко видаляє вибраний запис
- `ENTER` : Починає редагування вибраного запису в рядку (або відкриває екран редагування, якщо для вибраного запису немає редагування в рядку)
- `Ctrl/Command + C` : Копіює вибрану дію (поки що працює лише з діями)
- `Ctrl/Command + V` : Вставляє раніше скопійовану дію
- `Ctrl/Command + Z` : Крок назад (undo)
- `Ctrl/Command + Y` : Крок вперед (redo)
- `ARROW UP` : Перехід на один запис вище від поточно вибраного
- `ARROW DOWN` : Перехід на один запис нижче від поточно вибраного
- `SHIFT + ARROW UP` : Переміщує вибраний запис на один вище
- `SHIFT + ARROW DOWN` : Переміщує вибраний запис на один нижче
- `A` : Швидко відкриває екран Action Chooser, щоб додати нову дію
- `Ctrl/Command + S` : Готово/зберегти з вікна редактора

## Редагування

- Подвійне клацання по значенню дії дає змогу редагувати значення без переходу до повного екрана редагування значення.
- Ланцюжки операторів IF (з доданими операторами ELSE/ELSE-IF), цикли WHILE і папки можна згортати (лише візуально, це не впливає на логіку скрипта).
- Редактор завжди додає нові дії під вибраним записом (або всередині вибраного ланцюжка/циклу/папки).
- Клацання правою кнопкою на темно-сірому тлі області скрипта відкриває контекстне меню з опціями для додавання дій, операторів і всього іншого важливого.

# Дії детально

У цьому розділі перелічено вбудовані дії FancyMenu.

## Next Track (`audio_next_track`)

**Призначення:** Переходить до наступного треку в [Audio element](./elements#audio)

**Значення:** Обов’язково — `audio_element_identifier` (ID елемента аудіо, яким потрібно керувати)

## Previous Track (`audio_previous_track`)

**Призначення:** Переходить до попереднього треку в [Audio element](./elements#audio)

**Значення:** Обов’язково — `audio_element_identifier` (ID елемента аудіо, яким потрібно керувати)

## Set Track Volume (`set_audio_element_volume`)

**Призначення:** Встановлює гучність [Audio element](./elements#audio) (`0.0` до `1.0`)

**Значення:** Обов’язково — `element_identifier:volume`

## Toggle Play/Pause Track (`audio_toggle_play`)

**Призначення:** Перемикає поточний трек [Audio element](./elements#audio) між відтворенням і паузою

**Значення:** Обов’язково — `audio_element_identifier`

## Play Audio (`play_audio`)

**Призначення:** Одноразово відтворює аудіоресурс. Аудіо, запущене цією дією, згодом можна зупинити за допомогою [**Stop All Action Audios**](#stop-all-action-audios-stop_all_action_audios).

**Значення:** Обов’язково — JSON-конфігурація з `audioSource`, `soundChannel` і `baseVolume`

**Приклад:** `{"audioSource":"[source:local]/config/fancymenu/assets/example.ogg","soundChannel":"master","baseVolume":1.0}`

**Поведінка:**

- `baseVolume` обмежується діапазоном `0.0`–`1.0`.
- Невідомий звуковий канал використовує канал Master.
- Дія не може виконуватися з асинхронного [Ticker](./elements#ticker); замість цього FancyMenu показує помилку.
- FancyMenu чекає до десяти секунд, поки аудіоресурс стане готовим.
- Успішно запущені треки можна зупинити за допомогою [**Stop All Action Audios**](#stop-all-action-audios-stop_all_action_audios).

## Stop All Action Audios (`stop_all_action_audios`)

**Призначення:** Зупиняє всі аудіотреки, які було запущено дією [**Play Audio**](#play-audio-play_audio). Це не зупиняє [Audio elements](./elements#audio), звуки відкриття/закриття меню, звуки кнопок або інші аудіосистеми.

**Значення:** Не обов’язково

## Set Video Element Volume (`set_video_element_volume`)

**Призначення:** Встановлює гучність [Video element](./video) (`0.0` до `1.0`)

**Значення:** Обов’язково — `video_element_identifier:volume`

## Set Video Element Play Time (`set_video_element_play_time`)

**Призначення:** Перемотує [Video element](./video) до позначки часу в мілісекундах

**Значення:** Обов’язково — `video_element_identifier:timestamp_ms`

## Toggle Video Element Paused State (`toggle_video_element_pause_state`)

**Призначення:** Перемикає стан паузи [Video element](./video)

**Значення:** Обов’язково — `video_element_identifier`

## Set Video Background Volume (`set_video_menu_background_volume`)

**Призначення:** Встановлює гучність [Video menu background](./video) (`0.0` до `1.0`)

**Значення:** Обов’язково — `background_identifier:volume`

> [!NOTE]
> Щоб отримати ідентифікатор фону, клацніть правою кнопкою на тлі редактора та виберіть 'Copy Background Identifier'.

## Set Video Background Play Time (`set_video_menu_background_play_time`)

**Призначення:** Перемотує [Video menu background](./video) до позначки часу в мілісекундах

**Значення:** Обов’язково — `background_identifier:timestamp_ms`

> [!NOTE]
> Щоб отримати ідентифікатор фону, клацніть правою кнопкою на тлі редактора та виберіть 'Copy Background Identifier'.

## Toggle Video Background Paused State (`toggle_video_menu_background_pause_state`)

**Призначення:** Перемикає стан паузи [Video menu background](./video)

**Значення:** Обов’язково — `background_identifier`

> [!NOTE]
> Щоб отримати ідентифікатор фону, клацніть правою кнопкою на тлі редактора та виберіть 'Copy Background Identifier'.

## Toggle Layout (`toggle_layout`)

**Призначення:** Перемикає макет (увімкнути/вимкнути) за його назвою файлу без `.txt`

**Значення:** Обов’язково — `layout_name`

## Enable Layout (`enable_layout`)

**Призначення:** Увімкнює та зберігає макет за його назвою файлу без `.txt`

**Значення:** Обов’язково — `layout_name`

## Disable Layout (`disable_layout`)

**Призначення:** Вимикає та зберігає макет за його назвою файлу без `.txt`

**Значення:** Обов’язково — `layout_name`

Усі три дії для макетів зберігають стан у файлі макета та негайно оновлюють поточний екран. Використовуйте ім’я файлу з урахуванням регістру, без `.txt`.

## Open Screen or Custom GUI (`opengui`)

**Призначення:** Відкриває екран за його ідентифікатором (ванільний, модовий або власний GUI)

**Значення:** Обов’язково — `screen_identifier`

Скопіюйте точний ідентифікатор із урахуванням регістру з налагоджувального накладання [Screen Identifiers](./screen-identifiers).

Деякі екрани модів не можна створити напряму. Якщо відкриття не вдається, використайте [**Mimic Vanilla/Mod Button**](#mimic-vanillamod-button-mimicbutton) на віджеті, який зазвичай відкриває цей екран.

## Close Screen (`closegui`)

**Призначення:** Закриває активний екран

**Значення:** Не обов’язково

## Update Screen (`update_screen`)

**Призначення:** Повторно ініціалізує поточний екран

**Значення:** Не обов’язково

## Back to Last Screen (`back_to_last_screen`)

**Призначення:** Повертається до батьківського екрана [Custom GUI](./custom-guis) або до останнього закритого екземпляра екрана

**Значення:** Не обов’язково

## Join Server (`joinserver`)

**Призначення:** Підключає гравця до сервера Minecraft

**Значення:** Обов’язково — `server_ip` або `server_ip:port`

Ця дія не може виконуватися, коли світ або сервер уже завантажено. Якщо порт не вказано, використовується `25565`. Якщо адреси немає в списку збережених серверів Minecraft, FancyMenu додає її та зберігає.

## Enter World (`loadworld`)

**Призначення:** Заходить у світ Minecraft

**Значення:** Обов’язково — `world_folder_name`

Значенням є назва папки збереження. Дія нічого не робить, якщо таке збереження не існує або вже завантажено інший світ/сервер.

## Enter/Join Last World/Server (`join_last_world`)

**Призначення:** Заходить/підключається до останнього світу або сервера, на якому був гравець

**Значення:** Не обов’язково

Ця дія не може виконуватися, коли вже завантажено інший світ/сервер. Запам’ятаний сервер, якого немає в списку збережених серверів Minecraft, додається та зберігається перед підключенням.

## Leave World or Server (`disconnect_server_or_world`)

**Призначення:** Виходить зі світу або сервера та відкриває вказаний екран

**Значення:** Обов’язково — `screen_identifier`

Ця дія працює лише тоді, коли завантажено світ і гравця. Ціль може бути ідентифікатором [Custom GUI](./custom-guis) або [screen identifier](./screen-identifiers), який FancyMenu може створити. Якщо ціль не вдається відкрити, FancyMenu повертається на титульний екран.

## Quit Minecraft (`quitgame`)

**Призначення:** Повністю виходить з Minecraft

**Значення:** Не обов’язково

## Send Chat Message/Command (`sendmessage`)

**Призначення:** Надсилає повідомлення в чат або виконує чат-команду. Текст повідомлення підтримує [FancyMenu formatting codes](./text-formatting#minecraft-text-formatting).

**Значення:** Обов’язково — `message_text` або `/command_text`

## Execute Command As Integrated Server (`execute_command_as_integrated_server`)

**Призначення:** Примусово виконує команду в одиночній грі від імені інтегрованого сервера, ігноруючи дозволи та налаштування читів.

**Значення:** Обов’язково — текст команди, наприклад `/give @p minecraft:diamond 1`

> [!WARNING]
> Ця дія працює лише в одиночній грі, коли світ **не відкрито для LAN**. Вона навмисно нічого не робить, якщо інтегрованого сервера немає або якщо інтегрований сервер опубліковано в LAN.

## Paste to Chat (`paste_to_chat`)

**Призначення:** Вставляє форматований текст у поле введення чату, коли завантажено гравця/світ

**Значення:** Обов’язково — `true:Text` або `false:Text`

Коли чат ще не відкрито, FancyMenu відкриває його та встановлює текст введення. Коли чат уже відкрито, `true` додає текст до наявного введення, а `false` замінює його.

## Display In Chat [Client-Side] (`display_in_chat_client_side`)

**Призначення:** Показує клієнтське повідомлення в чаті, коли завантажено світ або сервер. Воно нічого не надсилає на сервер.

**Значення:** Обов’язково — `text_or_json`

## Send HTTP Request (`send_http_request`)

**Призначення:** Запускає HTTP/HTTPS-запит у фоновому режимі; може вести журнал і/або зберігати відповідь у змінну

**Значення:** Обов’язково — конфігурація HTTP-запиту

| Налаштування | Поведінка |
|---|---|
| URL | HTTP або HTTPS endpoint |
| Method | `GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `HEAD` або `OPTIONS` |
| Body | Надсилається для методів, відмінних від `GET` і `HEAD` |
| Content type | Значення `Content-Type` запиту |
| Timeout | Секунди для підключення та читання відповіді |
| Log response | Читає та записує відповідь у журнал |
| Response variable | Читає відповідь і зберігає її після завершення запиту |
| Single-line response | Видаляє перенос рядка з відповіді перед збереженням |
| Authentication | None, Basic, Bearer або API key |
| Headers | Додаткові власні заголовки запиту |

Запити виконуються асинхронно, тому наступна дія їх не чекає. Тіла відповіді читаються лише тоді, коли ввімкнено журналювання або налаштовано змінну відповіді; тіла неуспішних відповідей читаються з відповіді помилки. Не зберігайте паролі або токени доступу в конфігурації дії.

**Значення:** Не обов’язково

Це не перезавантажує ресурс-паки Minecraft. Для цього використовуйте [**Reload Resource Packs**](#reload-resource-packs-reload_resource_packs).

> [!WARNING]

## Mimic Keybind (`mimic_keybind`)

**Призначення:** Виконує клавіатурну або мишачу прив’язку клавіші Minecraft, за потреби утримуючи її натиснутою

## Set Text Input Field Value (`set_text_input_field_value`)

**Призначення:** Встановлює значення власного або ванільного [Text Input Field](./elements#text-input-field) за ідентифікатором елемента.

**Значення:** Обов’язково — `element_identifier|||new_value|||force_set_when_inactive`

Усі три поля мають бути розділені потрійним роздільником `|||`. Встановіть `force_set_when_inactive` у `true`, щоб оновити також неактивне поле вводу; коли значення `false`, неактивні поля не змінюються.

## Create File in Game Directory (`create_file_in_game_dir`)

**Призначення:** Створює порожній файл відносно активного каталогу гри. Приймає префікс `.minecraft/` для вказання звичайного каталогу Minecraft (який може відрізнятися від поточного екземпляра).

**Значення:** Обов’язково — `file_path`

Приклад: `config/some_mod_folder/new_file.txt`. Відсутні батьківські каталоги створюються; наявний файл не змінюється.

## Delete File/Folder in Game Directory (`delete_file_in_game_dir`)

**Призначення:** Видаляє файл або рекурсивно видаляє папку відносно активного каталогу гри. Приймає `.minecraft/` для вказання звичайного каталогу Minecraft. Додайте `*`, щоб видалити **всі файли безпосередньо всередині** папки (ігнорує підпапки та залишає папку).

**Значення:** Обов’язково — `target_path`

Наприклад, `config/downloads/*` видаляє файли безпосередньо в `config/downloads/`, але не проходить у її підпапки й не видаляє їх.

## Copy File/Folder in Game Directory (`copy_file_in_game_dir`)

**Призначення:** Копіює всередині активного каталогу гри; `.minecraft/` вказує на звичайний каталог Minecraft. Названий каталог копіюється рекурсивно. Додайте `*` до **джерела**, щоб скопіювати лише кожен прямий дочірній файл; призначення має бути каталогом і не може використовувати `*`.

**Значення:** Обов’язково — `source||destination`

Наприклад, `config/source/*||config/destination/` копіює лише файли безпосередньо всередині `config/source/`. Для джерела з wildcard FancyMenu створює каталог призначення за потреби, але не копіює жодні підпапки джерела. Копіювання відмовляється перезаписувати будь-яке вже наявне призначення/конфліктний файл.

## Move File/Folder in Game Directory (`move_file_in_game_dir`)

**Призначення:** Переміщує всередині активного каталогу гри; `.minecraft/` вказує на звичайний каталог Minecraft. Додайте `*` до **джерела**, щоб перемістити лише кожен прямий дочірній файл; призначення має бути каталогом і не може використовувати `*`.

**Значення:** Обов’язково — `source||destination`

Наприклад, `config/source/*||config/destination/` переміщує лише файли безпосередньо всередині `config/source/`. Для джерела з wildcard FancyMenu створює каталог призначення за потреби, але залишає підпапки джерела на місці. Переміщення відмовляється працювати з уже наявним призначенням/конфліктним файлом замість перезапису.

## Rename File/Folder in Game Directory (`rename_file_in_game_dir`)

**Призначення:** Перейменовує файл або папку в межах її поточної батьківської папки; `.minecraft/` вказує на звичайний каталог Minecraft. Зберігає вміст і відмовляється використовувати вже наявну назву призначення.

**Значення:** Обов’язково — `path||new_name`

## Download File to Game Directory (`download_file_to_game_dir`)

**Призначення:** Завантажує файл у фоновому режимі до папки відносно активного каталогу гри; `.minecraft/` вказує на звичайний каталог Minecraft.

**Значення:** Обов’язково — `url||target_folder`

Друге поле — це **цільова папка**, а не повний шлях до файлу призначення. FancyMenu створює папку за потреби та визначає ім’я файлу з заголовка `Content-Disposition` відповіді, а потім переходить до шляху URL. Отримана назва URL-декодується і очищується перед використанням; якщо жодне джерело не надає придатної назви, FancyMenu генерує її. Наявний файл із таким самим ім’ям перезаписується.

[**On File Downloaded via Action** listener](./listeners#on-file-downloaded-via-action-file_downloaded_via_action) спрацьовує після як успішних, так і невдалих спроб завантаження та надає URL, визначений цільовий шлях і стан успіху.

У разі успіху `$$target_file_path` — це шлях до збереженого файлу. У разі невдачі він може містити лише цільову папку, оскільки остаточна назва файлу не була визначена.

## Extract ZIP File In Game Directory (`extract_zip_file_in_game_dir`)

**Призначення:** Розпаковує ZIP у цільову папку всередині активного каталогу гри або звичайного каталогу `.minecraft`. Після завершення запускає [**On ZIP Extracted via Action**](./listeners#on-zip-extracted-via-action-zip_extracted_via_action).

**Значення:** Обов’язково — `source_zip_path||target_folder_path`

Наявні файли з однаковими іменами замінюються. Розпаковуйте лише надійні ZIP-файли.

## Open File/Folder In Game Directory (`open_file_folder_in_game_dir`)

**Призначення:** Відкриває файл або папку стандартною програмою операційної системи. З міркувань безпеки ціль має залишатися всередині каталогу гри або стандартного каталогу `.minecraft`.

**Значення:** Обов’язково — `target_path`

## Write File in Game Directory (`write_file_in_game_dir`)

**Призначення:** Записує або додає текст відносно активного каталогу гри; `.minecraft/` вказує на звичайний каталог Minecraft. Створює файл і батьківські папки, якщо вони відсутні. `\n` вставляє розриви рядків; `append_bool=false` замінює наявний файл.

**Значення:** Обов’язково — `path|||content|||append_bool`

## Select File from System (`select_file_to_game_dir`)

**Призначення:** Відкриває системний діалог вибору файлу і копіює вибраний файл всередину активного каталогу гри або звичайного `.minecraft/`, якщо використано префікс. Підтримує фільтри розширень, власну мітку фільтра та перемикач перезапису.

**Значення:** Обов’язково — `target_path|||filter_description|||extensions|||overwrite_bool`

`target_path` — це повний шлях до файлу призначення. Розділяйте кілька розширень за допомогою `;` або `,`, наприклад `png;jpg`; порожній список розширень дозволяє всі файли. Якщо `overwrite_bool` має значення `false`, дія завершується помилкою замість заміни наявного файлу призначення.

[**On File Selected** listener](./listeners#on-file-selected-file_selected_via_action) спрацьовує, коли файл скопійовано, вибір скасовано або вибір не вдався. Він надає вибраний шлях, визначений цільовий шлях, стани успіху/скасування та причину збою.

| `title` | Звичайний текст, серіалізований текстовий компонент Minecraft або порожнє значення |
| `message` | Звичайний текст, серіалізований текстовий компонент або порожнє значення |
| `iconSource` | Необов’язкове [image source](./resources) |
| `backgroundSource` | Необов’язкове [image source](./resources) |
