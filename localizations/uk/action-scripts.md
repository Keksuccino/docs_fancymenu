# Скрипти дій

Скрипт дій — це список команд, які FancyMenu виконує, коли щось відбувається, наприклад коли натискають кнопку або відкривають меню. Кожен елемент — це дія: відкрити меню, приєднатися до сервера, показати повідомлення, відтворити звук тощо. Інструкції на кшталт IF і WHILE визначають, які дії виконувати та як часто.

> [!CAUTION]
> Скрипти дій можуть змінювати файли, з’єднуватися із серверами, відкривати посилання та виконувати команди. Використовуйте лише скрипти з макетів, яким довіряєте.

# Створення скрипту дій

1. У редакторі макета клацніть правою кнопкою миші кнопку й виберіть **Edit Action Script**.
2. Натисніть `A`, щоб відкрити меню вибору дій.
3. Знайдіть потрібну дію, клацніть її, а потім натисніть **Next Step**.
4. Налаштуйте дію у вікні та натисніть **Done**. Для дій без налаштувань достатньо натиснути **Done** у меню вибору.
5. Натисніть **Done** у редакторі скриптів, а потім збережіть макет.

Поза редактором скрипт кнопки запускається після натискання на неї:

<img width="800" alt="Натискання кнопки What's New? на головному екрані показує сповіщення із заголовком і повідомленням про оновлення" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/action_script_use.gif?raw=true">

> [!TIP]
> Клацніть правою кнопкою миші область скрипту й виберіть **Add Action**, щоб переглянути список усіх дій. Клацніть правою кнопкою миші дію в цьому списку, щоб додати її до вибраного й перемістити на початок списку.

# Де можна використовувати скрипти дій

| Де | Коли запускається | Де редагувати |
|---|---|---|
| [Кнопка](/elements#button) | Після натискання кнопки. | Клацніть кнопку правою кнопкою миші -> **Edit Action Script** |
| [Повзунок](/elements#slider) | Коли змінюється значення повзунка. `$$value` — нове значення. | Клацніть повзунок правою кнопкою миші -> **Edit Action Script** |
| [Прапорець](/elements#checkbox) | Коли прапорець встановлюють або знімають. `$$value` — його новий стан: `true` або `false`. | Клацніть прапорець правою кнопкою миші -> **Edit Action Script** |
| [Тикер](/elements#ticker) | Відповідно до **Tick Mode**: повторно, один раз за ігровий сеанс або один раз під час завантаження меню. | Клацніть тикер правою кнопкою миші -> **Edit Action Script** |
| Відкриття меню | Коли відкривається меню макета. | Клацніть тло редактора правою кнопкою миші -> **Edit 'Open Screen' Action Script** |
| Закриття меню | Коли закривається меню макета. | Клацніть тло редактора правою кнопкою миші -> **Edit 'Close Screen' Action Script** |
| [Слухачі](/listeners) | Коли відбувається відповідна подія, наприклад натискання клавіші чи отримання повідомлення в чаті. | **Рядок меню -> Customization -> Manage Listeners** |
| [Планувальники](/schedulers) | За таймером, навіть коли жодне меню не відкрите. | **Рядок меню -> Customization -> Manage Schedulers** |

Скрипти відкриття та закриття також доступні в редакторі через меню **Layout -> Layout Properties**.

# Редактор скриптів

- Дії виконуються згори вниз. Елементи всередині інструкції або папки відображаються під нею з відступом.
- Нові елементи додаються після вибраного. Якщо вибрано інструкцію або папку, елементи додаються на початок.
- Двічі клацніть значення, щоб відредагувати його безпосередньо у списку. Якщо замість значення показано короткий опис, відкриється відповідне вікно.
- Перетягуйте елементи, щоб перемістити їх. Ланцюжки IF, цикли й папки можна згорнути за допомогою маленького перемикача перед ними. Це змінює лише вигляд.
- Смуга праворуч — це мапа всього скрипту. Клацніть її, щоб перейти до потрібної частини.
- Клацніть область скрипту правою кнопкою миші, щоб скористатися іншими функціями, наприклад додати інструкції або вибрати **Export Action Script for AI** (див. [Експорт для ШІ](/export-for-ai)).
- Кнопка **Cancel** або закриття вікна скасовує зміни. Якщо зміни є, редактор спершу перепитає.

## Сполучення клавіш

У macOS замість `Ctrl` використовуйте `Cmd`.

| Сполучення клавіш | Дія |
|---|---|
| `A` | Відкриває меню вибору дій. |
| `Enter` | Редагує вибраний елемент. |
| `Delete` | Видаляє вибраний елемент. |
| `Up` / `Down` | Вибирає елемент вище або нижче. |
| `Shift + Up` / `Shift + Down` | Переміщує вибраний елемент угору або вниз. |
| `Ctrl + C` / `Ctrl + V` | Копіює та вставляє дію. Інструкції й блоки копіювати не можна. |
| `Ctrl + Z` | Скасовує останню дію. |
| `Ctrl + Y` або `Ctrl + Shift + Z` | Повторює скасовану дію. |
| `Ctrl + S` | Зберігає скрипт і закриває редактор, як кнопка **Done**. |

# Інструкції

Інструкції визначають, які дії запускати та як часто. Додавайте їх, клацнувши правою кнопкою миші область скрипту.

## If, Else-If і Else

**Add IF Statement** пропонує задати [умови](/conditions). Дії всередині IF виконуються, лише якщо умови виконано.

Клацніть IF правою кнопкою миші, щоб доповнити ланцюжок:

- **Append ELSE-IF Statement**: перевіряє власні умови, якщо попередній IF не виконався.
- **Append ELSE Statement**: виконується, якщо жодна з попередніх інструкцій у ланцюжку не виконалася.

Наприклад, IF з умовою **Is Layout Enabled** може показувати сповіщення, лише коли ввімкнено зимовий макет, а ELSE — відтворювати звук в іншому разі.

## Цикл While

**Add WHILE Loop** повторює дії, доки виконуються [умови](/conditions).

Кожен запуск завершується через 3 секунди, тож нескінченний цикл не зможе зависнути й заморозити гру. Це не таймер: для дій, які потрібно виконати пізніше або повторювати, використовуйте [Execute Later](#execute-later), [тикер](/elements#ticker) або [планувальник](/schedulers).

## Цикл For Each

**Add FOR EACH Loop** виконує дії один раз для кожного елемента [спискової змінної](/variables#text-and-list-variables), від першого до останнього.

- `$$list_entry` — поточний елемент, а `$$list_index` — його індекс. Індекс першого елемента — 0.
- Обидві змінні можна використовувати в значеннях дій і умовах циклу.
- Введіть назву списку без `$$`, наприклад `quest_log`. У назві також можна використовувати плейсхолдери.
- На початку циклу список зчитується один раз, тож дії всередині циклу можуть безпечно змінювати його.
- Як і цикли WHILE, кожен запуск завершується через 3 секунди.

Приклади див. у розділі [Перебирання списку](/variables#going-through-a-list).

# Блоки

Блоки змінюють порядок виконання дій або допомагають упорядкувати скрипт. Додавайте їх, клацнувши правою кнопкою миші область скрипту.

## Блок затримки

**Add DELAY GATE Block** затримує виконання дій на заданий час у мілісекундах (`1000` — одна секунда).

- Коли скрипт доходить до блоку вперше, запускається таймер, а дії блоку пропускаються. Решта скрипту продовжує виконуватися одразу.
- Якщо скрипт знову доходить до блоку до завершення таймера, дії знову пропускаються.
- Після завершення таймера дії виконуються щоразу, коли скрипт доходить до блоку.
- У скриптах елементів таймер запускається знову, коли меню відкривається повторно або змінюється його розмір.

Цей блок зручний для [тикерів](/elements#ticker), наприклад щоб показати щось лише через кілька секунд після відкриття меню. Сам він нічого не запускає: для цього використовуйте Execute Later.

## Execute Later

**Add EXECUTE LATER Block** виконує свої дії один раз після заданої затримки в мілісекундах. Решта скрипту продовжує виконуватися одразу.

Щоразу, коли скрипт доходить до блоку, запускається новий відлік. Це зручно для скриптів, які запускаються лише один раз, наприклад після натискання кнопки або відкриття меню.

## Папка

**Add Folder** групує дії під назвою. Виконує все всередині й допомагає впорядкувати довгі скрипти. Двічі клацніть назву, щоб перейменувати папку.

## Коментар

**Add Comment** додає примітку для себе. На виконання скрипту вона не впливає. Двічі клацніть примітку, щоб відредагувати її.

# Як виконуються скрипти

- Дії виконуються згори вниз. Якщо дія завершується помилкою, вона записується до журналу гри, а решта скрипту продовжує виконуватися.
- Плейсхолдери у значеннях отримують актуальні дані саме під час виконання дії, тож дія бачить зміни, внесені попередніми діями.
- Завантаження, розпакування ZIP-файлів і вебзапити виконуються у фоновому режимі. Наступна дія не чекає на їх завершення. Щоб запускати дії після завершення, використовуйте слухачі [**On File Downloaded via Action**](/listeners#on-file-downloaded-via-action) і [**On ZIP Extracted via Action**](/listeners#on-zip-extracted-via-action) або змінну відповіді дії [**Send HTTP Request**](#send-http-request).

# Значення дій

Для більшості дій потрібне значення, наприклад адреса сервера. Прості значення — це текст, який ви вводите. Дії з додатковими налаштуваннями мають власні вікна.

## Плейсхолдери

Значення можуть містити [плейсхолдери](/placeholders), наприклад ім’я гравця. Вони підставляються під час виконання дії:

```
/say Welcome back, {"placeholder":"playername"}!
```

## Змінні $$

Введіть `$$` і назву змінної, щоб використовувати її значення в дії або умові. Регістр літер у назвах має значення. Це працює з двома типами змінних:

### Власні змінні

Будь-яку змінну, створену через **Рядок меню -> Customization -> Manage Variables**, можна використовувати з `$$` і її назвою. Змінна `coins` записується як `$$coins` і доступна в будь-якому скрипті. Наприклад, дія **Display In Chat [Client-Side]** з таким значенням повідомить гравцеві, скільки в нього монет:

```
&6You have $$coins coins!
```

Інструкції зі створення та зміни змінних див. у розділі [Змінні](/variables).

### Змінні скрипту

Деякі функції надають власні змінні скрипту:

- [Повзунок](/elements#slider) надає `$$value` — нове значення.
- [Прапорець](/elements#checkbox) надає `$$value` — новий стан: `true` або `false`.
- [Цикл For Each](#цикл-for-each) надає `$$list_entry` і `$$list_index`.
- Кожен [слухач](/listeners#listener-variables) перелічує змінні, які він надає, наприклад клавішу, яку натиснули.

Ці змінні існують лише під час виконання скрипту. Якщо назва однієї з них збігається з назвою вашої змінної, `$$name` означає змінну скрипту.

# Усі дії

Усі дії FancyMenu, згруповані за призначенням.

## Екрани й меню

### Відкрити екран або власний графічний інтерфейс

**Ідентифікатор:** `opengui`

Відкриває меню гри, мода або [власний графічний інтерфейс](/custom-guis).

**Значення:** [ідентифікатор екрана](/screen-identifiers), наприклад `options_screen`

Регістр літер має значення. Деякі меню модів так відкрити не вдається. У такому разі використайте [**Mimic Vanilla/Mod Button**](#імітувати-кнопку-ванільної-гри-або-мода) для кнопки, яка відкриває це меню.

### Закрити екран

**Ідентифікатор:** `closegui`

Закриває відкрите меню. Якщо ви не перебуваєте у світі, відкриється головний екран.

**Значення:** немає

### Оновити екран

**Ідентифікатор:** `update_screen`

Перебудовує відкрите меню, як це відбувається під час зміни розміру вікна. Зручно після зміни масштабу інтерфейсу або інших параметрів.

**Значення:** немає

### Повернутися до попереднього екрана

**Ідентифікатор:** `back_to_last_screen`

Повертає до меню, відкритого раніше. Для [власного графічного інтерфейсу](/custom-guis) це меню, з якого його відкрили.

**Значення:** немає

### Показати сповіщення

**Ідентифікатор:** `show_toast`

Показує сповіщення у верхньому правому куті. Налаштуйте його у відповідному вікні:

- **Toast Width**: ширина від 120 до 320 пікселів.
- **Duration (ms)**: тривалість показу — від 1 секунди (`1000`) до 10 хвилин.
- **Title** і **Message**: текст із [кодами форматування](/text-formatting#minecraft-text-formatting) або JSON-компонент тексту Minecraft.
- **Icon Texture Source** і **Background Texture Source**: необов’язкові [зображення](/resources). Для значків найкраще підходить розмір 20x20 пікселів, а висота тла має бути 32 пікселі, ширина — відповідати ширині сповіщення.

### Імітувати кнопку ванільної гри або мода

**Ідентифікатор:** `mimicbutton`

Натискає кнопку гри або мода так, ніби її натиснув гравець.

**Значення:** [локатор віджета](/widget-locators) кнопки, наприклад `title_screen:mc_titlescreen_options_button`

Щоб отримати його, клацніть кнопку в редакторі правою кнопкою миші й виберіть **Copy Widget Locator**.

## Макети й елементи

### Перемкнути макет

**Ідентифікатор:** `toggle_layout`

Вимикає ввімкнений макет або вмикає вимкнений.

**Значення:** назва макета без `.txt`, наприклад `winter_title_screen`

### Увімкнути макет

**Ідентифікатор:** `enable_layout`

Вмикає макет.

**Значення:** назва макета без `.txt`

### Вимкнути макет

**Ідентифікатор:** `disable_layout`

Вимикає макет.

**Значення:** назва макета без `.txt`

Усі три дії з макетами зберігають зміни й одразу оновлюють відкрите меню. Регістр літер у назві має значення.

### Перемкнути аніматор елемента

**Ідентифікатор:** `toggle_element_animator`

Вмикає [аніматор елемента](/element-animator), якщо він вимкнений, або вимикає його, якщо він увімкнений. Анімація починається спочатку. Стан зберігається.

**Значення:** ідентифікатор аніматора елемента

### Увімкнути аніматор елемента

**Ідентифікатор:** `enable_element_animator`

Вмикає [аніматор елемента](/element-animator). Якщо він був вимкнений, анімація починається спочатку.

**Значення:** ідентифікатор аніматора елемента

### Вимкнути аніматор елемента

**Ідентифікатор:** `disable_element_animator`

Вимикає [аніматор елемента](/element-animator) і скидає його анімацію.

**Значення:** ідентифікатор аніматора елемента

### Скинути аніматор елемента

**Ідентифікатор:** `reset_element_animator`

Запускає анімацію [аніматора елемента](/element-animator) спочатку, не вмикаючи й не вимикаючи його.

**Значення:** ідентифікатор аніматора елемента

### Установити значення поля введення тексту

**Ідентифікатор:** `set_text_input_field_value`

Установлює текст [поля введення тексту](/elements#text-input-field) FancyMenu або гри.

**Значення:** `element_identifier|||text|||force`

Якщо для `force` задати `true`, текст зміниться навіть тоді, коли поле вимкнене (неактивне).

### Прокрутити елемент

**Ідентифікатор:** `scroll_scroll_area`

Прокручує [область прокручування](/scrollable-areas) або елемент [Текст](/elements#text). Налаштуйте дію у відповідному вікні:

- **Identifier of the Element to Scroll**: область або текст для прокручування.
- **Scroll To**:
  - **Start** або **End**.
  - **Position**: **Horizontal Position** і **Vertical Position** у пікселях. Залиште одне поле порожнім, щоб не змінювати його значення.
  - **Element** (лише для областей): прокручує до початку елемента з указаним **Identifier of the Element to Scroll To**.
  - **Line Number** (лише для тексту): перший рядок має номер `1`.
  - **Line with Text** (лише для тексту): переходить до першого рядка, що містить **Text in the Line**. Регістр літер не має значення.
- **Glide There**: прокручує плавно, а не стрибком. Для цього в елементі має бути ввімкнено плавне прокручування.

Нічого не відбувається, якщо такого елемента немає.

## Світи й сервери

### Приєднатися до сервера

**Ідентифікатор:** `joinserver`

Підключається до сервера Minecraft.

**Значення:** `address` або `address:port`, наприклад `play.example.net`

Якщо порт не вказано, використовується `25565`. Якщо світ або сервер уже завантажено, замість цього з’явиться помилка. Сервери, яких немає у списку серверів, додаються до нього.

### Увійти у світ

**Ідентифікатор:** `loadworld`

Завантажує світ для одиночної гри.

**Значення:** назва теки світу в `saves`, наприклад `Survival Island`

Якщо такого світу немає, нічого не відбувається. Якщо світ або сервер уже завантажено, замість цього з’явиться помилка.

### Увійти в останній світ або на останній сервер

**Ідентифікатор:** `join_last_world`

Завантажує світ або підключає до сервера, у якому гравець грав востаннє.

**Значення:** немає

Якщо світ або сервер уже завантажено, замість цього з’явиться помилка. Сервер, якого немає у списку серверів, додається до нього.

### Вийти зі світу або з сервера

**Ідентифікатор:** `disconnect_server_or_world`

Виходить зі світу або з сервера й відкриває меню.

**Значення:** [ідентифікатор екрана](/screen-identifiers) меню, яке потрібно відкрити, наприклад `title_screen`

Працює лише тоді, коли світ завантажено. Підтримуються також [власні графічні інтерфейси](/custom-guis). Якщо меню не вдається відкрити, з’явиться головний екран.

## Чат і команди

### Надіслати повідомлення або команду в чат

**Ідентифікатор:** `sendmessage`

Надсилає повідомлення в чат або виконує команду, наче її ввів гравець.

**Значення:** повідомлення або команда зі слешем `/`, наприклад `/spawn`

### Виконати команду від імені інтегрованого сервера

**Ідентифікатор:** `execute_command_as_integrated_server`

В одиночній грі виконує команду від імені сервера незалежно від дозволів гравця та налаштування читів.

**Значення:** команда, наприклад `/give @p minecraft:diamond 1`

> [!WARNING]
> Працює лише в одиночній грі, коли світ не відкрито для локальної мережі. В інших випадках нічого не відбувається.

### Вставити текст у чат

**Ідентифікатор:** `paste_to_chat`

Вставляє текст у поле введення чату, коли відкрито світ. Якщо чат не відкритий, він відкривається з цим текстом.

**Значення:** `true:text` додає текст до вже введеного, а `false:text` замінює його

### Показати в чаті [лише на клієнті]

**Ідентифікатор:** `display_in_chat_client_side`

Показує повідомлення в чаті лише для цього гравця. На сервер нічого не надсилається.

**Значення:** текст із [кодами форматування](/text-formatting#minecraft-text-formatting) або JSON-компонент тексту Minecraft, наприклад `&aWelcome back!`

Якщо світ не завантажено, нічого не відбувається.

## Змінні й списки

### Установити значення змінної (змінна FM)

**Ідентифікатор:** `set_variable`

Установлює [змінну](/variables).

**Значення:** `variable_name:value`, наприклад `coins:100`

- Лише перший символ `:` розділяє назву й значення.
- [Спискові змінні](/variables#text-and-list-variables) залишаються списками: JSON-масив, як-от `["a","b"]`, перетворюється на їхні елементи; будь-який інший текст стає єдиним елементом; порожній текст очищує список.

### Видалити змінну (змінна FM)

**Ідентифікатор:** `delete_variable`

Повністю видаляє [змінну](/variables). Решта змінних не змінюється. Щоб лише очистити змінну, використайте [**Установити значення змінної (змінна FM)**](#установити-значення-змінної-змінна-fm).

**Значення:** назва змінної

### Очистити всі змінні (змінна FM)

**Ідентифікатор:** `clear_variables`

Видаляє всі [змінні](/variables): текстові та спискові.

**Значення:** немає

### Додати елемент до списку (змінна FM)

**Ідентифікатор:** `add_to_list`

Додає елемент до [спискової змінної](/variables#list-actions).

- **List Variable**: назва списку. Якщо змінної з такою назвою ще немає, дія створить список.
- **New Entry**: текст нового елемента.
- **Index (Optional)**: місце, куди додати елемент. Якщо поле порожнє, елемент додається в кінець. Усі наступні елементи зсуваються на одну позицію.
- **Skip If Already in List**: не додає елемент, якщо в списку вже є такий самий текст. Параметр **Ignore Case** вважає `Apple` і `apple` однаковими.

### Установити елемент списку (змінна FM)

**Ідентифікатор:** `set_list_entry`

Замінює елемент за вказаним **Index** у [списковій змінній](/variables#list-actions) на **New Value**. Нічого не відбувається, якщо такого елемента в списку немає.

### Видалити зі списку (змінна FM)

**Ідентифікатор:** `remove_from_list`

Видаляє елементи зі [спискової змінної](/variables#list-actions). Параметр **Remove** визначає, які саме:

- **Entry at Index**: елемент із указаним індексом.
- **First Match**: перший елемент, що точно збігається з **Value to Remove**.
- **All Matches**: усі елементи, що збігаються з ним.

Параметр **Ignore Case** вважає `Apple` і `apple` однаковими.

### Очистити список (змінна FM)

**Ідентифікатор:** `clear_list`

Видаляє всі елементи зі [спискової змінної](/variables#list-actions). Порожній список залишається.

### Задати список (змінна FM)

**Ідентифікатор:** `set_list`

Замінює всі елементи [спискової змінної](/variables#list-actions). Параметр **Entries From** визначає джерело елементів:

- **Split Text**: розділяє **Text to Split** за вказаним **Separator**, наприклад `,`. Порожній роздільник розбиває текст за переносами рядка. Параметр **Trim Entries** прибирає пробіли на початку й у кінці елементів, а **Skip Empty Entries** пропускає порожні елементи.
- **JSON Array**: використовує елементи масиву, як-от `["Diamonds","Emeralds"]`, або `$$other_list`, щоб скопіювати інший список. Будь-який інший текст стає єдиним елементом, а порожній текст очищує список.

У вікні показано попередній перегляд елементів.

### Упорядкувати список (змінна FM)

**Ідентифікатор:** `arrange_list`

Змінює порядок елементів [спискової змінної](/variables#list-actions). Варіанти **Arrangement**:

- **Sort A–Z** і **Sort Z–A**: сортування за алфавітом.
- **Numbers, Smallest First** і **Numbers, Biggest First**: сортування за числами. Елементи, які не є числами, переміщуються в кінець.
- **Reverse Order**: останній елемент стає першим.
- **Shuffle**: випадковий порядок.
- **Remove Duplicates**: залишає лише перший екземпляр кожного значення.

У всіх діях зі списками індекс першого елемента — `0`, а `-1` позначає останній елемент. Назва списку може містити плейсхолдери. Якщо перед назвою стоїть `$$`, дія використовує значення цієї змінної як назву списку. Текстові змінні зі значенням не змінюються, а дія записує попередження до журналу гри.

## Веб і мережа

### Відкрити URL у браузері

**Ідентифікатор:** `openlink`

Відкриває посилання у браузері за замовчуванням без підтвердження.

**Значення:** посилання, наприклад `https://discord.gg/example`

Використовуйте лише посилання, яким довіряєте.

### Надіслати HTTP-запит

**Ідентифікатор:** `send_http_request`

Надсилає вебзапит у фоновому режимі. Відповідь можна записати до журналу гри або зберегти у змінній.

| Налаштування | Опис |
|---|---|
| URL | HTTP- або HTTPS-адреса. |
| Method | `GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `HEAD` або `OPTIONS`. |
| Body | Дані для надсилання. Не надсилається з методами `GET` і `HEAD`. |
| Content type | Тип вмісту `Content-Type`, наприклад `application/json`. |
| Timeout | Час очікування з’єднання та відповіді в секундах. |
| Log response | Записує відповідь до журналу гри. |
| Response variable | Зберігає відповідь у цій змінній після її отримання. |
| Single-line response | Прибирає переноси рядків із відповіді перед збереженням. |
| Authentication | None, Basic, Bearer або API key. |
| Headers | Додаткові заголовки запиту. |

Наступна дія не чекає на відповідь. Помилки у відповідях також записуються до журналу й зберігаються. Не додавайте до дії паролі чи токени доступу: кожен, хто має макет, зможе їх прочитати.

### Надіслати дані FM на сервер

**Ідентифікатор:** `send_fm_data_to_server`

Надсилає [дані FM](/fm-data) на сервер, на якому також має бути встановлено FancyMenu.

**Значення:** `data_identifier||data`

### Підключитися до віддаленого сервера

Підключається до віддаленого сервера або використовує вже відкрите з’єднання.

**Значення:** адреса сервера, наприклад `wss://example.com/ws`

Підтримувані адреси див. у розділі [Взаємодія з віддаленим сервером](/remote-server-communication#url-modes).

### Надіслати дані на віддалений сервер

Закриває всі з’єднання з віддаленими серверами, відкриті FancyMenu.

**Значення:** немає

## Файли

### Створити файл у теці гри

**Ідентифікатор:** `create_file_in_game_dir`

Створює порожній файл. Якщо потрібних тек немає, їх також буде створено. Наявний файл залишається без змін.

**Значення:** шлях до файлу, наприклад `config/mymodpack/first_start.txt`

Усі дії з файлами працюють лише в теці гри (теці екземпляра). Шляхи, що починаються з `.minecraft/`, використовують стандартну теку `.minecraft`, яка може бути іншою.

### Видалити файл або теку з теки гри

**Ідентифікатор:** `delete_file_in_game_dir`

Видаляє файл або теку разом з усім її вмістом.

**Значення:** шлях, наприклад `config/mymodpack/cache.txt`

Якщо в кінці шляху стоїть `*`, наприклад `config/downloads/*`, дія видаляє всі файли безпосередньо в цій теці, але залишає саму теку та вкладені теки.

### Скопіювати файл або теку в теці гри

**Ідентифікатор:** `copy_file_in_game_dir`

Копіює файл або теку разом з усім її вмістом.

**Значення:** `source||destination`, наприклад `config/presets/default.json||config/mymod/settings.json`

- Якщо в кінці джерела стоїть `*`, наприклад `config/presets/*||config/mymod/`, копіюються всі файли безпосередньо в цій теці, але не теки. У такому разі місце призначення має бути текою, яку буде створено за потреби.
- Наявні файли не перезаписуються: якщо місце призначення вже існує, дія завершується помилкою.

### Перемістити файл або теку в теці гри

**Ідентифікатор:** `move_file_in_game_dir`

Переміщує файл або теку разом з усім її вмістом.

**Значення:** `source||destination`

Символ `*` у кінці шляху до джерела працює так само, як у дії [**Скопіювати файл або теку в теці гри**](#скопіювати-файл-або-теку-в-теці-гри). Наявні файли не перезаписуються.

### Перейменувати файл або теку в теці гри

**Ідентифікатор:** `rename_file_in_game_dir`

Перейменовує файл або теку. Дія завершується помилкою, якщо об’єкт із новою назвою вже існує.

**Значення:** `path||new_name`, наприклад `config/mymod/old_name.txt||new_name.txt`

### Завантажити файл у теку гри

**Ідентифікатор:** `download_file_to_game_dir`

Завантажує файл у теку у фоновому режимі.

**Значення:** `url||target_folder`, наприклад `https://example.com/pack.zip||downloads`

- Друга частина — це тека, а не назва файлу. FancyMenu бере назву з завантаження або посилання.
- Файл із такою самою назвою буде перезаписано.
- Слухач [**On File Downloaded via Action**](/listeners#on-file-downloaded-via-action) запускається після завершення завантаження або в разі помилки. Якщо завантаження успішне, `$$target_file_path` містить шлях до збереженого файлу.

### Розпакувати ZIP-файл у теці гри

**Ідентифікатор:** `extract_zip_file_in_game_dir`

Розпаковує ZIP-файл у теку у фоновому режимі.

**Значення:** `zip_path||target_folder`, наприклад `downloads/pack.zip||resourcepacks/MyPack`

Файли з однаковими назвами замінюються, а додаткова тека з назвою ZIP-файлу не створюється. Після завершення запускається слухач [**On ZIP Extracted via Action**](/listeners#on-zip-extracted-via-action). Розпаковуйте лише ZIP-файли, яким довіряєте.

### Відкрити файл або теку в теці гри

**Ідентифікатор:** `open_file_folder_in_game_dir`

Відкриває файл або теку за допомогою програми, яку для них використовує система.

**Значення:** шлях, наприклад `screenshots`

### Записати дані у файл у теці гри

**Ідентифікатор:** `write_file_in_game_dir`

Записує текст у файл. Файл і потрібні для нього теки створюються за потреби.

**Значення:** `path|||text|||append`, наприклад `config/mymodpack/log.txt|||Joined the server\n|||true`

`\n` починає новий рядок. Якщо для `append` задано `true`, текст додається в кінець файлу; якщо `false` — замінює його вміст.

### Вибрати файл у системі

**Ідентифікатор:** `select_file_to_game_dir`

Відкриває системне вікно вибору файлів і копіює вибраний файл у теку гри.

**Значення:** `target_path|||filter_name|||extensions|||overwrite`, наприклад `config/fancymenu/assets/background.png|||Images|||png;jpg|||true`

- `target_path` — повний шлях до копії разом із назвою файлу.
- Розділяйте розширення символами `;` або `,`. Якщо розширення не вказано, можна вибрати будь-які файли.
- Якщо для `overwrite` задано `false`, дія завершується помилкою, коли файл уже існує.

Слухач [**On File Selected**](/listeners#on-file-selected) запускається після копіювання файлу, скасування вікна вибору або виникнення помилки.

## Гра й FancyMenu

### Вийти з Minecraft

**Ідентифікатор:** `quitgame`

Закриває гру.

**Значення:** немає

### Змінити параметр Minecraft

**Ідентифікатор:** `edit_minecraft_option`

Змінює параметр Minecraft, наприклад дальність промальовування або масштаб інтерфейсу.

**Значення:** `option_name:value`, наприклад `renderDistance:12`

Назви параметрів див. у розділі [Параметри Minecraft](/minecraft-options).

### Імітувати натискання клавіші

**Ідентифікатор:** `mimic_keybind`

Натискає прив’язану клавішу Minecraft, наприклад стрибок або присідання; також може утримувати її.

**Значення:** `keybind|||hold|||duration_ms`, наприклад `key.jump|||false|||1000`

| Частина | Опис |
|---|---|
| `keybind` | Ідентифікатор прив’язки клавіші, наприклад `key.jump` або `key.sneak`. |
| `hold` | `true` утримує клавішу, `false` натискає її один раз. |
| `duration_ms` | Тривалість утримання в мілісекундах. Якщо не вказано, використовується `1000`. |

### Керувати пакетом ресурсів

**Ідентифікатор:** `manage_resource_pack`

Вмикає або вимикає пакет ресурсів. Налаштуйте дію у відповідному вікні:

- **Target Resource Pack**: назва пакета, як її показано на екрані пакетів ресурсів. Регістр літер не має значення.
- **Action Mode**: **Enable**, **Disable** або **Toggle**.
- **Reload Resources**: одразу перезавантажує пакети ресурсів після зміни. Вимкніть цей параметр, щоб перезавантажити їх пізніше, наприклад дією [**Перезавантажити пакети ресурсів**](#перезавантажити-пакети-ресурсів).

Пакети, потрібні грі, вимкнути не можна.

### Перезавантажити пакети ресурсів

**Ідентифікатор:** `reload_resource_packs`

Перезавантажує пакети ресурсів, як `F3 + T`. Протягом п’яти секунд після перезавантаження дія нічого не робить, тож ресурси не можна перезавантажувати безперервно.

**Значення:** немає

### Перезавантажити FancyMenu

**Ідентифікатор:** `reloadmenu`

Перезавантажує макети, [власні графічні інтерфейси](/custom-guis), [панорами](/panoramas), [слайдшоу](/slideshows), налаштування й файли FancyMenu. Пакети ресурсів не перезавантажуються.

**Значення:** немає

> [!WARNING]
> Перезавантаження займає певний час. Використовуйте цю дію для кнопки, а не в [тикері](/elements#ticker) або [слухачі](/listeners), що спрацьовує часто.

### Запустити планувальник

**Ідентифікатор:** `start_scheduler`

Запускає [планувальник](/schedulers).

**Значення:** ідентифікатор планувальника

### Зупинити планувальник

**Ідентифікатор:** `stop_scheduler`

Зупиняє [планувальник](/schedulers).

**Значення:** ідентифікатор планувальника

### Скопіювати текст у буфер обміну

**Ідентифікатор:** `copytoclipboard`

Копіює текст у буфер обміну.

**Значення:** текст, наприклад `play.example.net`

### Вивести текст у журнал гри

**Ідентифікатор:** `print_to_log`

Записує рядок до журналу гри. Зручно, щоб дізнатися, що робить скрипт.

**Значення:** текст
