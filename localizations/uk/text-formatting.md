# Форматування тексту

FancyMenu пропонує три способи форматувати текст:

- **Markdown** для [текстових елементів і елементів підказок](/text-in-menus): заголовки, списки, кольори, зображення, таблиці тощо.
- **Коди форматування Minecraft**, наприклад `&c`, для швидкого додавання кольорів. Вони працюють майже в усіх текстових полях, зокрема й у тексті Markdown.
- **Текстові компоненти Minecraft** для підписів кнопок і повзунків.

> [!TIP]
> На цій сторінці йдеться про те, *як записувати* відформатований текст. Щоб дізнатися, як додавати текст до меню, змінювати його вигляд або робити його прокручуваним, див. [Текст у меню](/text-in-menus).

# Markdown

Markdown форматує текст за допомогою кількох спеціальних символів. Наприклад, `**жирний**` перетворюється на **жирний** текст.

Markdown працює в [текстових елементах](/elements#text) і [елементах підказок](/elements#tooltip). Символи, які ви вводите, визначають, *чим* є текст (заголовком, списком, цитатою). А [вигляд елемента](/text-in-menus#looks-and-styles) визначає, як він відображається: наприклад, його кольори та розміри.

## Короткий огляд

| Ви пишете | Ви отримуєте |
|---|---|
| `**жирний**` або `__жирний__` | Жирний текст |
| `*курсив*` або `_курсив_` | Курсивний текст |
| `++підкреслений++` | Підкреслений текст |
| `~~закреслений~~` | Закреслений текст |
| `` `код` `` | Вбудований код |
| `[Відкрити сайт](https://example.com)` | Клікабельне посилання |
| `%#ff5555%червоний текст%#%` | Кольоровий текст |
| `# Заголовок` | Заголовок |
| `- Елемент` | Маркований список |
| `1. Елемент` | Нумерований список |
| `> Текст` | Цитата |
| `> [!TIP]` | Блок примітки |
| `---` | Роздільна лінія |

## Стилі тексту

| Стиль | Як записати |
|---|---|
| **Жирний** | `**текст**` або `__текст__` |
| **Курсив** | `*текст*` або `_текст_` |
| **Підкреслення** | `++текст++` |
| **Закреслення** | `~~текст~~` (також можна використовувати по одному символу `~` з обох боків) |

Стилі можна поєднувати, наприклад: `***жирний курсив***`.

Окремі символи підкреслення всередині слів залишаються звичайними, тому `my_cool_layout` не стане курсивним. Назви на зразок `C++` також залишаються без змін.

> [!TIP]
> У текстовому редакторі виділіть фрагмент і натисніть `Ctrl + B`, `Ctrl + I` або `Ctrl + U` (`Cmd` у macOS), щоб зробити текст жирним, курсивним або підкресленим. Докладніше див. [Комбінації клавіш для форматування](/text-in-menus#formatting-shortcuts).

## Колір тексту (HEX)

Поставте `%<HEX color>%` перед текстом, а `%#%` — після нього:

```
%#77fc03%Цей текст зелений!%#%
```

HEX-код кольору має починатися із `#`. Також можна використовувати назви кольорів:

```
%#red%Цей текст червоний!%#%
```

Підтримувані назви: `black`, `silver`, `gray`, `grey`, `white`, `maroon`, `red`, `purple`, `fuchsia`, `magenta`, `green`, `lime`, `olive`, `yellow`, `navy`, `blue`, `teal`, `aqua`, `cyan` і `transparent`.

## Шрифти

Щоб відобразити текст іншим шрифтом, поставте `%!!<font name>%` перед ним, а `%!!%` — після. Шрифт можна взяти з Minecraft або набору ресурсів.

```
%!!uniform%Цей текст використовує шрифт uniform%!!%
```

## Вирівнювання тексту

За замовчуванням текст вирівнюється ліворуч. Щоб відцентрувати рядки або вирівняти їх праворуч, розмістіть код вирівнювання в окремому рядку перед ними й після них:

- `^^^` вирівнює рядки по центру.
- `|||` вирівнює їх праворуч.

```
Цей рядок вирівняно ліворуч.

^^^
Цей рядок вирівняно по центру.
І цей також.
^^^

|||
Цей рядок вирівняно праворуч.
|||
```

> [!TIP]
> У текстовому редакторі комбінації `Ctrl + L`, `Ctrl + E` і `Ctrl + R` (`Cmd` у macOS) вирівнюють виділені рядки ліворуч, по центру або праворуч.

## Заголовки

Почніть рядок із `# ` (найбільший), `## ` (великий) або `### ` (малий):

```
# Вітаємо!
## Новини
### Маленький заголовок
```

## Списки

<img width="460" alt="Списки Markdown" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/markdown_lists.png?raw=true">

### Марковані списки

Почніть рядок із `- `. Для кожного рівня вкладеності додавайте перед ним два пробіли:

```
- Перший елемент
- Другий елемент
  - Вкладений елемент
    - Ще глибший рівень
```

### Нумеровані списки

Почніть рядок із числа та крапки або дужки:

```
1. Відкрийте панель меню
2. Натисніть «Налаштування»
3) Так теж працює
```

### Позначки приміток до оновлення

Рядки також можуть починатися із `+`, `-`, `~` або `*`. Для кожного символу передбачена власна позначка — це зручно для приміток до оновлення та журналів змін:

```
+ Додано нове головне меню
- Видалено старий логотип
~ Змінено кольори кнопок
* Виправлено збій під час запуску
```

| Позначка | Значення |
|---|---|
| `+` | Щось додано |
| `-` | Щось видалено |
| `~` | Щось змінено |
| `*` | Щось варте уваги |

Елемент із `-` отримує позначку «видалено» лише тоді, коли в тому самому списку є елемент із `+`. Інакше це звичайний елемент маркованого списку. Цю поведінку можна змінити в меню **Markdown -> Списки -> Додаткові позначки (+ - ~ \*) -> Використовувати позначку -**.

> [!NOTE]
> У нових текстових елементах і елементах підказок за замовчуванням увімкнено нумеровані списки, позначки приміток до оновлення та [блоки приміток](#callouts). У елементах зі старих макетів вони вимкнені, щоб текст раптово не змінився. Увімкніть їх у меню елемента **Markdown**: **Списки -> Нумеровані списки**, **Списки -> Додаткові позначки (+ - ~ \*)** і **Блоки приміток**.

## Цитати

Почніть рядок із `> `, щоб зробити його цитатою. Цитата триває до наступного порожнього рядка:

```
> Це цитата.
І цей рядок також належить до неї.

А цей рядок знову є звичайним текстом.
```

Рядки всередині цитати також можуть починатися із `>`, а рядок, що містить лише `>`, додає до цитати порожній рядок:

```
> Перший абзац цитати.
>
> Другий абзац цитати.
```

## Блоки приміток

Блоки приміток — це кольорові поля зі значком і назвою; вони чудово підходять для порад і попереджень. Створіть цитату, перший рядок якої містить тип примітки:

```
> [!WARNING]
> Не забудьте зберегти макет!
```

<img width="640" alt="Блоки приміток Markdown" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/markdown_callouts.png?raw=true">

Є п’ять типів: `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]` і `[!CAUTION]`.

## Гіперпосилання

Візьміть текст у `[ ]`, а посилання розмістіть після нього в `( )`:

```
[Відвідайте наш сайт](https://example.com)
```

Посилання можуть містити круглі дужки, наприклад `https://en.wikipedia.org/wiki/Minecraft_(video_game)`. Щоб відобразити квадратні дужки в тексті посилання, поставте перед ними `\`: `[Натисніть \[тут\]](https://example.com)`.

## Події натискання та наведення курсора

Текст може запускати [слухачі подій](/listeners), а не відкривати сайт. Використовуйте префікс `click:` або `hover:` та виберіть будь-який ідентифікатор:

```
[текст, на який можна натиснути](click:unique_text_click_event_id)
[текст, на який можна навести курсор](hover:unique_text_hover_event_id)
```

Реагуйте на ці події за допомогою слухачів [**On Markdown Text Clicked**](/listeners#on-markdown-text-clicked) і [**On Markdown Text Hovered**](/listeners#on-markdown-text-hovered). Обидва передають ідентифікатор у змінній `$$text_event_id`.

## Зображення

Розмістіть зображення в окремому рядку за допомогою `![](` + джерело зображення + `)`:

```
![](https://example.com/image.png)
```

Джерелом може бути вебадреса, локальний файл, наприклад `/config/fancymenu/assets/image.png`, або зображення з набору ресурсів. Усі типи джерел описано в розділі [Ресурси](/resources).

Текст у квадратних дужках стає підписом до зображення:

```
![Мій крутий знімок екрана](/config/fancymenu/assets/screenshot.png)
```

Підписи відображаються під зображенням, якщо ввімкнено параметр елемента **Markdown -> Зображення -> Підпис**.

Щоб зробити зображення клікабельним, обгорніть його посиланням:

```
[![](https://example.com/image.png)](https://example.com)
```

## Таблиці

Розділяйте комірки символом `|`. Перший рядок — заголовок, а в другому потрібно вказати `---` для кожного стовпця:

```
| Предмет | Ціна |
|:---|---:|
| Діамантовий меч | 10 |
| Золоте яблуко | 5 |
```

Двокрапки в другому рядку задають вирівнювання стовпців: `:---` — ліворуч, `:---:` — по центру, `---:` — праворуч. Щоб відобразити `|` усередині комірки, напишіть `\|`.

<img width="640" alt="Таблиця та код Markdown" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/markdown_table_code.png?raw=true">

## Роздільники

Рядок, що містить лише `---`, створює роздільну лінію через увесь текст.

## Код

Код відображає текст як є, без форматування.

- **Вбудований код:** обгорніть фрагмент рядка символами `` ` ``, наприклад `` `/spawn` ``.
- **Блоки коду:** поставте рядок із `` ``` `` перед текстом і після нього. Рядки в блоках коду не переносяться.

````
```
/give @p minecraft:diamond 64
```
````

Після перших `` ``` `` можна вказати назву мови, наприклад `` ```json ``. FancyMenu її розпізнає, але вона не змінює вигляд коду.

[Заповнювачі](/placeholders) і далі замінюються всередині коду.

## Звичайний текст

Звичайний текст відображає символи форматування як є, але не має вигляду коду. Обгорніть фрагмент рядка в `;;`:

```
Тут відображаються ;;зірочки;;, а не жирний текст.
```

Щоб застосувати це до цілих рядків, розмістіть `;;;` в окремих рядках перед ними й після них:

```
;;;
**Не жирний**, _не курсив_.
;;;
```

## Екранування символів

Щоб відобразити символ форматування як звичайний текст, поставте перед ним `\`. Наприклад, `\*не курсив\*` відобразить `*не курсив*`.

Це працює для символів `\` `` ` `` `*` `_` `{` `}` `[` `]` `(` `)` `#` `+` `-` `.` `!` `|` `>` `~` і `^`.

# Форматування тексту Minecraft

Коди форматування Minecraft працюють у більшості текстових полів FancyMenu. Використовуйте `&` замість `§` у Minecraft. Наприклад, `&cПопередження` відобразить червоний текст, а `&l` зробить його жирним. `&r` скидає форматування.

Усі коди наведено у [Minecraft Wiki](https://minecraft.wiki/w/Formatting_codes).

Коди форматування також працюють у тексті Markdown, за винятком коду та звичайного тексту. Для стилів на зразок жирного й курсиву зазвичай зручніше використовувати Markdown, а коди корисні для швидкого додавання кольорів.

# Текстові компоненти Minecraft (система необроблених компонентів)

Текстові компоненти Minecraft — це відформатований текст у форматі JSON. Вони підходять для **однорядкового** тексту, наприклад **підписів кнопок і повзунків**, але не працюють у текстових елементах.

Щоб скористатися компонентом, укажіть його як єдиний текст підпису:

```
{"text":"Текст підпису кнопки","font":"uniform"}
```

Текст `Текст підпису кнопки` відобразиться шрифтом `uniform`. У значенні `text` можна використовувати [заповнювачі](/placeholders).

Докладніше див. сторінки Minecraft Wiki про [формат текстових компонентів](https://minecraft.wiki/w/Raw_JSON_text_format) і [шрифти](https://minecraft.wiki/w/Resource_pack#Fonts).
