# Форматування тексту

FancyMenu має багато функцій, щоб зробити текстовий вміст у макетах *крутішим*!

Текстові елементи повністю підтримують **Markdown** з деякими цікавими доповненнями, а більшість іншого текстового вмісту підтримує систему **форматування тексту Minecraft**, а підписи кнопок навіть підтримують **текстові компоненти Minecraft**, які дозволяють використовувати власні шрифти та багато іншого.

# Markdown

**Текстові елементи** FancyMenu повністю підтримують Markdown, що означає, що ви можете форматувати текст, додаючи до нього спеціальні символи.

Наприклад, щоб зробити текст жирним, потрібно додати `**` перед і після жирного тексту, тож `**Деякий жирний текст, який дуже жирний.**` виглядатиме так:
**Деякий жирний текст, який дуже жирний.**

Markdown у FancyMenu має навіть кілька особливих можливостей, що роблять його ще потужнішим!

> Markdown **НЕ ПРАЦЮЄ** для іншого текстового вмісту, наприклад підписів кнопок. Він працює лише для **ТЕКСТОВИХ ЕЛЕМЕНТІВ**. Для всього іншого використовуйте [коди форматування Minecraft](/text-formatting#minecraft-text-formatting).
{.is-danger}

## Шрифти

Ви можете показувати текст у власному шрифті, завантаженому через ресурс-пак, додавши `%!!<font_name>%` перед текстом і `%!!%` після нього.

Допустимий шрифт, що входить до базової гри, — `uniform`, тож щоб показати текст шрифтом `uniform`, зробіть так:
`%!!uniform%це власний шрифт%!!%`

Це покаже `це власний шрифт` шрифтом `uniform`.

## Колір тексту (HEX)

Показати текст у певному HEX-кольорі можна, додавши `%<HEX_color>%` перед текстом і `%#%` після нього.

Допустимий HEX-колір зеленого — `#77fc03`, тож щоб показати текст цим кольором, зробіть так:
`%#77fc03%цей текст зелений!%#%`

Це покаже `цей текст зелений!` як `#77fc03` (зелений).

Переконайтеся, що HEX-колір починається з `#`!

FancyMenu 3.9.0 також підтримує поширені назви кольорів у стилі HTML у цьому ж коді форматування кольору:

```
%#red%Цей текст червоний!%#%
```

Підтримувані назви: `black`, `silver`, `gray`, `grey`, `white`, `maroon`, `red`, `purple`, `fuchsia`, `magenta`, `green`, `lime`, `olive`, `yellow`, `navy`, `blue`, `teal`, `aqua`, `cyan` і `transparent`.

## Вирівнювання тексту

Ви можете вирівнювати рядки тексту, починаючи рядок із певного коду форматування вирівнювання, потім не писати нічого іншого, а далі вказати рядки тексту, які потрібно показати з цим вирівнюванням, і потім знову вказати код вирівнювання на окремому рядку.

Увесь текст за замовчуванням **вирівнюється по лівому краю**, тому є лише коди форматування для **вирівнювання по центру** та **по правому краю**.

### По центру

Щоб вирівняти рядки тексту по центру, використовуйте код форматування `^^^`.

Приклад:
```
Цей текст не по центру.

^^^
Цей текст по центру.
Цей текст також по центру.
^^^

Цей текст більше не по центру.
```

### По правому краю

Щоб показати рядки тексту вирівняними по правому краю, використовуйте код форматування `|||`.

Приклад:
```
Цей текст не по правому краю.

|||
Цей текст вирівняно по правому краю.
Цей текст також вирівняно по правому краю.
|||

Цей текст більше не по правому краю.
```

## Заголовки

Щоб показати **рядок тексту** як заголовок (більший і підкреслений), додайте `# ` (дуже великий), `## ` (великий) або `### ` (малий) перед рядком тексту.

Приклад:
`## Великий заголовок`

## Жирний

Додайте `**` перед текстом і після нього, щоб зробити його **жирним**.

Приклад:
`**жирний текстовий вміст**`

## Курсив

Додайте `_` АБО `*` перед текстом і після нього, щоб зробити його *курсивом*.

Приклад:
`*текстовий вміст курсивом*`

## Закреслення

Додайте `~` перед текстом і після нього, щоб зробити його ~~закресленим~~.

Приклад:
`~текстовий вміст із закресленням~`

## Гіперпосилання

Ви можете додавати до тексту гіперпосилання, які відкриватимуть вебсайт після натискання.

Текст, який має відображатися як [гіперпосилання](https://google.com), потрібно взяти в `[ ]`, а потім вказати сам лінк у `( )`.

Тож якщо ви хочете зробити `example text content` клікабельним і відкривати `https://example-website.net`, зробіть так:
`[example text content](https://example-website.net)`

## Події натискання та наведення

FancyMenu 3.9.0 додає Markdown-події натискання та наведення для Text elements та іншого Markdown-тексту.

Події натискання використовують префікс `click:`:

```
[деякий клікабельний текст](click:unique_text_click_event_id)
```

Події наведення використовують префікс `hover:`:

```
[деякий текст із наведенням](hover:unique_text_hover_event_id)
```

Використовуйте слухачі **On Markdown Text Clicked** і **On Markdown Text Hovered**, щоб реагувати на ці події. Обидва слухачі надають ID події через `$$text_event_id`.

## Зображення

Markdown підтримує показ зображень у текстовому вмісті.

FancyMenu підтримує ресурси Minecraft, локальні ресурси та вебресурси в Markdown.

Щоб додати зображення, почніть рядок тексту з `![](`, потім вкажіть [URL, розташування ресурсу або шлях до ресурсу](/resources), а потім `)`.

Тож щоб показати вебресурс `https://example-website.net/image.png`, зробіть так:
`![](https://example-website.net/image.png)`

Зображення також можуть бути **гіперпосиланнями**, якщо обгорнути весь рядок із зображенням у **гіперпосилання**, ось так:
`[![](https://example-website.net/image.png)](https://example-website.net)`

> Локальні ресурси мають бути в `/config/fancymenu/assets/` !
{.is-warning}

## Цитата

Щоб форматувати текст як цитату, почніть рядок тексту з `> `.
Це форматуватиме всі наступні рядки як цитату, доки не знайде **порожній** рядок.

Приклад:
```
Це не виглядатиме як цитата.

> Це виглядатиме як цитата.
Це також виглядатиме як цитата.

Це вже більше не виглядатиме як цитата.
```

## Маркований список

Щоб показати текст як маркований список ось так:
- Запис 1
- Запис 2
  - Підзапис

Вам просто потрібно почати рядок з `- `.

Приклад:
```
- Запис 1
- Запис 2
  - Підзапис
```

## Розділювальна лінія

Щоб додати до тексту розділювальну лінію, яка має ширину всього текстового рядка, просто почніть рядок із `---` і більше нічого не додавайте.

Тоді це виглядатиме приблизно так:

---

## Блоки коду

Блоки коду можуть допомогти показати текст як `простий текст`, щоб Markdown не намагався його форматувати, або просто відобразити текст у стилі коду без автоматичного перенесення рядків.

Однорядковий блок коду (між іншим текстом) починається і закінчується на \` , що насправді дуже складно показати в Markdown-тексті..

Рядок тексту, що містить однорядковий блок коду, виглядає так:

![single_line_code_block](https://github.com/Keksuccino/FancyMenu/assets/35544624/e78fd38b-7b1a-4f00-9b11-797d964b3b43)

Багаторядкові блоки коду охоплюють кілька рядків в одному великому блоці коду й починаються з рядка, який містить лише \`\`\`, потім іде текстовий вміст і потім знову \`\`\`:

![multi_line_code_block](https://github.com/Keksuccino/FancyMenu/assets/35544624/bf8c77eb-a97e-48cd-9270-8302c2995856) 

## Простий текст

Код форматування простого тексту обходитиме всі інші коди форматування всередині нього.

Він працює подібно до блоків коду, але не форматуватиме його як блок коду. Замість цього він показуватиме текст як звичайний, але без будь-якого форматування.

Щоб обгорнути частину тексту в рядку кодом форматування простого тексту, потрібно додати `;;` перед і після частини тексту, яку ви хочете показати як простий текст, ось так:

```
Це рядок тексту з ;;**цією частиною**;;, що відображається як неформатований текст із видимим кодом форматування ** (жирний) і _цією частиною_ як звичайним відформатованим курсивним текстом.
```

Простий текст також працює як код-обгортка для кількох рядків. Щоб обгорнути цілі рядки, додайте `;;;` перед і після рядка(ів), які ви хочете показати як простий текст, ось так:

```
;;;
Цей рядок буде показаний **неформатованим** із видимими кодами форматування ** (жирний).
Цей рядок також буде показаний _неформатованим_ із видимими кодами форматування _ (курсив).
;;;

Цей рядок знову виглядатиме **звичайно** з "звичайним", відформатованим як жирний текст.
```

# Форматування тексту Minecraft

Сам Minecraft має досить гарну систему форматування, яка працює подібно до Markdown: ви додаєте до тексту спеціальні символи, щоб відформатувати його.

Щоб дізнатися більше про систему форматування Minecraft, будь ласка, перегляньте [цю сторінку Minecraft Wiki](https://minecraft.wiki/w/Formatting_codes).

> У Wiki буде сказано, що префікс коду форматування — це `§`, але у FancyMenu потрібно замінити його на `&`. Усе інше залишається без змін.
{.is-warning}

> **Text elements** є дуже складними, і для підтримки Markdown компромісом було **зламати стандартні ванільні коди форматування Minecraft**, тому ці коди не дуже добре працюватимуть у Text elements (після коду форматування форматуватиметься лише перше слово тощо). Натомість у Text elements слід використовувати коди форматування Markdown.
{.is-danger}

# Текстові компоненти Minecraft (система сирих компонентів)

Система текстових компонентів Minecraft дуже потужна для **однорядкового** текстового вмісту, наприклад **підписів кнопок**.

У Vanilla Minecraft її можна використовувати в командах `/tellraw` і `/title` (і, ймовірно, в інших місцях).
Це відформатований текст, серіалізований у JSON, тож до текстового вмісту можна додавати атрибути форматування.

Щоб дати FancyMenu розпізнати підпис кнопки як **текстовий компонент**, вкажіть у підписі лише серіалізований текст компонента, ось так:
`{"text":"Текст підпису кнопки","font":"uniform"}`

У наведеному вище прикладі підпис кнопки `Текст підпису кнопки` буде показано шрифтом `uniform`.

> Ви можете використовувати заповнювачі FancyMenu у значенні `text` компонентів.
{.is-info}
