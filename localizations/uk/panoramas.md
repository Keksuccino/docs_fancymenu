# Кубічні панорами

Кожна панорама має власний каталог тут:

```text
<game-directory>/config/fancymenu/panoramas/
```

`<game-directory>` — це активний екземпляр лаунчера, який може відрізнятися від звичайного каталогу `.minecraft`.

# Структура каталогу

```text
<game-directory>/config/fancymenu/panoramas/
└── mypanorama/
    ├── properties.txt
    ├── overlay.png          # необов'язково
    └── panorama/
        ├── panorama_0.png
        ├── panorama_1.png
        ├── panorama_2.png
        ├── panorama_3.png
        ├── panorama_4.png
        └── panorama_5.png
```

Шість зображень граней мають бути PNG-файлами з точними назвами, показаними вище, і всі шість повинні мати однакові розміри. Регістр у назвах файлів може мати значення в деяких операційних системах.

Додайте необов'язковий `overlay.png` поруч із `properties.txt` для віньєтки або іншого накладення на всю панораму.

# `properties.txt`

```text
type = panorama

panorama-meta {
  name = name_of_your_panorama
  speed = 1.0
  fov = 85.0
  angle = 25.0
  start_rotation = 0
}
```

| Властивість | Значення |
|---|---|
| `name` | Обов'язковий, чутливий до регістру ідентифікатор під час виконання; зберігайте його унікальним |
| `speed` | Множник швидкості обертання; `1.0` — значення за замовчуванням |
| `fov` | Кут огляду в градусах |
| `angle` | Вертикальний кут огляду в градусах |
| `start_rotation` | Початкове горизонтальне обертання в градусах |

Обов'язковим є лише `name`. Для відсутніх необов'язкових значень використовуються значення за замовчуванням, показані в прикладі. Залишайте `type = panorama` і `panorama-meta` без змін; записуйте по одному `key = value` в кожному рядку та використовуйте крапку для десяткових чисел.

Повторювані назви не відхиляються, і порядок сканування каталогів визначає, яка панорама залишиться доступною. Тримайте назви унікальними в межах каталогу panoramas. Назви панорам і слайд-шоу використовують окремі списки.

# Використання панорами

Перезавантажте FancyMenu через **Customization -> Reload FancyMenu** або перезапустіть клієнт. Потім клацніть правою кнопкою миші на тлі редактора макета та виберіть [**Menu Backgrounds**](./menu-backgrounds) -> **Cubic Panorama**.
