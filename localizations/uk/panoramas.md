# Панорами

Панорама — це фон, який повільно обертається навколо вас, як на титульному екрані Minecraft. Вона складається із шести зображень, що утворюють куб навколо глядача.

Ви можете показувати власні панорами як [фон меню](/menu-backgrounds) макета або замість панорами Minecraft у всіх меню.

<img width="800" alt="Титульний екран на тлі панорами, що повільно обертається: дерев'яна хатина на лісовій галявині під час заходу сонця, поруч сад, дровітня та курник" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/panoramas_title.gif?raw=true">

> [!TIP]
> Панораму на цій сторінці можна безкоштовно використовувати для тестування та у власних модпаках: [forest_homestead.zip](https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/forest_homestead.zip) (4 МБ). Розпакуйте її в `config/fancymenu/panoramas/` і перезавантажте FancyMenu.

# Створення панорами

1. Відкрийте папку `panoramas` у `config/fancymenu/` в каталозі гри. Пункт **панель меню -> Інструменти -> Відкрити каталог FancyMenu** відкриває `config/fancymenu/`.
2. Створіть у ній папку для панорами, наприклад `forest_homestead`. Її назва не має значення.
3. Додайте до неї файл `properties.txt` і папку `panorama` із [шістьма зображеннями](#шість-зображень). Файл `overlay.png` необов'язковий.
4. Перезавантажте FancyMenu через **панель меню -> Налаштування -> Перезавантажити FancyMenu** або натисніть `Ctrl + Alt + R` (`Cmd + Alt + R` у macOS), чи перезапустіть гру.

```text
config/fancymenu/panoramas/
└── forest_homestead/
    ├── properties.txt
    ├── overlay.png
    └── panorama/
        ├── panorama_0.png
        ├── panorama_1.png
        ├── panorama_2.png
        ├── panorama_3.png
        ├── panorama_4.png
        └── panorama_5.png
```

# Шість зображень

Кожне зображення відповідає одній грані куба:

<img width="796" alt="Шість зображень панорами forest_homestead, розкладені у формі розгорнутого куба: верхнє зображення над переднім, ліве, переднє, праве та заднє зображення в ряд, а нижнє — під переднім" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/panoramas_cube.png?raw=true">

| Зображення | Грань |
|---|---|
| `panorama_0.png` | Передня |
| `panorama_1.png` | Права |
| `panorama_2.png` | Задня |
| `panorama_3.png` | Ліва |
| `panorama_4.png` | Верхня |
| `panorama_5.png` | Нижня |

- Чотири бічні грані розташовані навколо вас у такому порядку: правий край кожного зображення переходить у лівий край наступного, а правий край `panorama_3.png` стикується з лівим краєм `panorama_0.png`.
- Нижній край верхнього зображення стикується з верхнім краєм переднього. Верхній край нижнього зображення стикується з нижнім краєм переднього.
- Усі шість зображень мають бути файлами PNG однакового розміру. Рекомендується квадратний формат, наприклад 1024 × 1024.
- FancyMenu не згладжує зображення, тому піксельна графіка залишається чіткою.

Minecraft використовує для власної панорами таке саме розташування, тож підходять і панорами, створені для Minecraft.

# properties.txt

```text
type = panorama

panorama-meta {
  name = forest_homestead
  speed = 2.0
  fov = 85.0
  angle = 25.0
  start_rotation = 0
}
```

| Параметр | Що робить |
|---|---|
| `name` | Назва, за якою можна вибрати панораму. Кожна панорама має мати власну назву. |
| `speed` | Швидкість обертання. Значення `1.0` відповідає одному оберту приблизно за 4 хвилини, а `2.0` — удвічі швидшому обертанню. Значення `0` зупиняє панораму. Значення понад `10.0` не збільшують швидкість. |
| `fov` | Яка частина панорами вміщується на екрані; значення в градусах, від верхнього до нижнього краю екрана. Менші значення наближають зображення. |
| `angle` | Кут нахилу погляду вниз у градусах. Значення `0` спрямовує погляд прямо на горизонт, від’ємні значення — вгору. |
| `start_rotation` | Початкове положення обертання в градусах від `0` до `360`. Значення `0` розміщує переднє зображення по центру. |

Обов’язковий лише параметр `name`. Якщо не вказати інші параметри, використовуватимуться значення `speed = 1.0`, `fov = 85.0`, `angle = 25.0` і `start_rotation = 0`. Не змінюйте рядки `type = panorama` і `panorama-meta {`, записуйте по одному параметру в рядку та використовуйте крапку в десяткових числах, наприклад `1.5`.

# Накладка

Файл `overlay.png`, розміщений поруч із `properties.txt`, накладається на панораму й розтягується на весь екран. Він не обертається разом із панорамою, тому підходить для таких елементів, як віньєтка, рамка чи кольоровий фільтр. Через прозорі ділянки видно панораму.

# Використання панорами

## Як фон меню

<img width="800" alt="Відкрийте розділ «Фони меню», виберіть «Кубічна панорама» в редакторі макетів, увімкніть «Показувати фон» і виберіть forest_homestead у пункті «Вибрати панораму»; вона обертатиметься за кнопками титульного екрана" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/panoramas_background.gif?raw=true">

1. У [редакторі макетів](/layout-editor) клацніть правою кнопкою миші на фоні та відкрийте **Фони меню -> Кубічна панорама**.
2. Натисніть **Показувати фон**, щоб увімкнути його.
3. Натисніть **Назва панорами**, виберіть панораму та натисніть **Готово**. Праворуч у вікні попереднього перегляду ви побачите, як вона обертається.

Щоб прибрати панораму, натисніть **Очистити панораму**. Щоб поєднати її з іншими фонами, дивіться розділ [Фони меню](/menu-backgrounds).

## У всіх меню

Пункт **панель меню -> Налаштування -> Глобальні налаштування -> Панорама власного фону меню -> Вибрати панораму** встановлює вашу панораму замість панорами Minecraft на титульному екрані та в усіх меню до входу у світ. Дивіться розділ [Глобальні налаштування](/global-customizations#menu-backgrounds).

## Попереднє завантаження

Велика панорама може завантажуватися деякий час під час першого показу. Щоб завантажити її під час запуску гри, додайте її за допомогою пункту **Додати кубічну панораму** в розділі **панель меню -> Налаштування -> Попереднє завантаження ресурсів**. Дивіться розділ [Попереднє завантаження ресурсів](/preload-layouts#pre-loading-slideshows--panoramas).

# Корисно знати

- Панорами обертаються вправо: переднє зображення зміщується вліво, а праворуч з’являється праве зображення.
- Усі меню, у яких показується та сама панорама, використовують спільне обертання, тож під час перемикання між ними вона обертається безперервно. Якщо жодне меню її не показує, обертання призупиняється.
- Після перезавантаження FancyMenu кожна панорама починає обертатися з позиції `start_rotation`.
- Панорами належать до завантаженого [профілю](/profiles).
- Якщо панорами немає у списку **Вибрати панораму**, її не вдалося завантажити. У журналі гри `logs/latest.log` зазначено причину, наприклад відсутність параметра `name` або зображення.
- Фіолетово-чорна шахівниця означає, що панораму ще не вибрано, розміри її шести зображень не збігаються або макет використовує назву панорами, якої більше не існує.
- Якщо дві панорами мають однакове значення `name`, відображатиметься лише одна з них.
