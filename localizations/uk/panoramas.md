# Кубічні панорами

FancyMenu підтримує завантаження власних панорам у вигляді куба з 6 зображень як фон для меню.

Ці панорами — це особливий кубічний формат панорами, який Minecraft використовує як фон на екрані заголовка. Він складається з 6 зображень (сторін), які відображаються як куб (або, точніше, як skybox).

> **ВАЖЛИВО**: Якщо ви користуєтеся Windows, не забудьте ввімкнути [розширення файлів](https://cdn.discordapp.com/attachments/795308330746511390/801561308012347482/unknown.png), інакше пізніше ви не зможете побачити важливі частини назв файлів!
{.is-warning}

# Створення панорами

Якщо ви не знаєте, як Minecraft обробляє фонові панорами і як їх створювати, радимо переглянути [це відео](https://www.youtube.com/watch?v=F7jMd3zsjZQ&t).
Воно дасть вам дуже добре розуміння того, як працюють панорами Minecraft і як створити власну!

Після перегляду відео ви помітите, що створення таких панорам може бути трохи трудомістким.
Щоб заощадити час, можливо, варто скористатися модом, який створює їх за вас.
Знайти такі моди можна за запитом `minecraft panorama mod`, але один із них — [Panoramica](https://www.curseforge.com/minecraft/mc-mods/panoramica) (створений мною).

# Підготовка панорами

Після того як у вас будуть 6 зображень панорами, потрібно перемістити їх у правильне місце!

Каталог панорам FancyMenu розташований у `.minecraft/config/fancymenu/panoramas`.
Це каталог для всіх панорам, які ви хочете використовувати в моді.

## Папка панорами

Кожна панорама має власну папку.
Якщо ви хочете додати нову панораму, вам потрібно створити нову папку в `.minecraft/config/fancymenu/panoramas`.
У моєму прикладі я назву папку `mypanorama`.

![1](https://user-images.githubusercontent.com/35544624/100791916-2802d380-341a-11eb-8e32-f9913e93a38c.png)

## Вміст папки

Після створення папки потрібно її заповнити.

### Файл властивостей
Кожна панорама для роботи потребує файл властивостей.
Цей файл завжди має називатися `properties.txt` і містити деякі важливі дані.

Вміст файлу властивостей панорами завжди має виглядати так:
```
type = panorama

panorama-meta {
  name = name_of_your_panorama
  speed = 1.0
  fov = 85.0
  angle = 25.0
  start_rotation = 0
}
```
Змінювати можна лише змінні всередині секції `panorama-meta`!

#### name
Це має бути **унікальна** назва вашої панорами.
Неможливо завантажити дві панорами з однаковою назвою!
Цю назву ви використовуватимете пізніше для ідентифікації панорами.

#### speed
Швидкість, з якою обертається ваша панорама.
Це значення є множником швидкості. Наприклад, `1.0` — стандартна швидкість, `2.0` подвоює її, а `0.5` — зменшує вдвічі.
Від’ємні значення не підтримуються; щоб зменшити швидкість, використовуйте дробові значення.

#### fov
Поле зору.
Стандартне значення FOV — `85.0`.
Занадто великі або занадто малі значення тут зламають панораму. Просто поекспериментуйте, щоб знайти потрібне вам значення FOV.

#### angle
Вертикальний кут, під яким переглядається панорама.
Стандартне значення кута — `25.0`.

#### start_rotation
Кут обертання (по горизонталі), з якого має починатися панорама. Значення від 0 до 360.

<br>

### Папка зображень панорами

Друга обов’язкова річ, яка має бути в папці вашої панорами, — це власне папка із зображеннями панорами.

Назва цієї папки має бути `panorama`.

Помістіть туди всі зображення панорами, але не забудьте правильно їх назвати, як показано у [відео](https://www.youtube.com/watch?v=F7jMd3zsjZQ&t) вище!

![3](https://user-images.githubusercontent.com/35544624/100791922-29340080-341a-11eb-8174-874a180d0485.png)

> Як зображення панорами підтримуються лише PNG-файли!
{.is-warning}

### Накладення панорами

Останній крок є **необов’язковим** і може бути пропущений, якщо ви не хочете накладення поверх панорами.

Якщо ви хочете додати віньєтку або інші типи накладень до своєї панорами, можете додати файл із назвою `overlay.png`.
Пам’ятайте, що для накладення підтримується лише PNG, а ім’я файлу завжди має бути `overlay.png`!

### Ще раз перевіряємо все

Тепер у вас має бути папка в `.minecraft/config/fancymenu/panoramas`, що містить файл `properties.txt`, іншу папку з назвою `panorama` і, можливо, накладення `overlay.png`.

![2](https://user-images.githubusercontent.com/35544624/100791920-29340080-341a-11eb-8e26-98a7fd2ad7eb.png)

# Використання панорами

Після (повторного) запуску гри або перезавантаження FancyMenu через **Customization -> Reload FancyMenu** ви зможете встановити свою панораму як фон меню. Для цього клацніть правою кнопкою миші по фону редактора макетів і натисніть **Menu Background**.
