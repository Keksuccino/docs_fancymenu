# Текст у меню

FancyMenu дає змогу додавати текстовий вміст до меню/екранів за допомогою елемента **Text**.

Цей елемент підтримує прокручування, повну підтримку Markdown і перенесення рядків, що робить його дуже потужним для відображення навіть складного текстового вмісту. Водночас він чудово підходить і для простих однорядкових написів.

# Текстовий вміст

Елемент Text може отримувати вміст у різні способи. Ви можете вказати джерело текстового вмісту: безпосередньо ввести звичайний текст, використати локальний текстовий файл у каталозі ресурсів FancyMenu (`<game-directory>/config/fancymenu/assets/`), вебтекстовий файл (через URL) або локальний текстовий файл, завантажений за допомогою ресурс-пака.

Використання вебджерела як джерела тексту особливо корисне, якщо ви хочете створити, наприклад, завжди актуальний список змін, стрічку новин тощо без необхідності випускати оновлення для вашої збірки модів.

Майте на увазі, що FancyMenu кешує вміст текстових джерел, щоб не отримувати його постійно (що суттєво погіршило б продуктивність). Вміст кешується лише протягом активного сеансу, тому перезапуск гри очистить кеш. Також ви можете очистити кеш, перезавантаживши FancyMenu через **панель меню -> Налаштування -> Перезавантажити FancyMenu**.

# Заповнювачі

Елемент Text також підтримує систему заповнювачів FancyMenu, завдяки чому текстовий вміст може бути динамічним і реагувати на різноманітні зміни в меню, світах, гравцях тощо.

# Налаштування або вимкнення Markdown

Якщо ви хочете налаштувати кольори заголовків або інші параметри, пов’язані з Markdown, просто **клацніть правою кнопкою миші** елемент Text і виберіть **Markdown**. У підменю, що відкриється, ви побачите безліч параметрів для налаштування вигляду та поведінки аналізатора Markdown.

Якщо Markdown вам узагалі не потрібен, його можна повністю вимкнути в меню **Markdown**, яке відкривається після **клацання правою кнопкою миші** елемента Text. Це може підвищити продуктивність під час роботи з великим текстовим вмістом.

# Вимкнення перенесення рядків

Якщо ви не хочете переносити рядки, вимкніть цю функцію, **клацнувши правою кнопкою миші** елемент Text.

# Вимкнення прокручування та приховування повзунків прокручування

Елементи Text за замовчуванням підтримують прокручування. Якщо елемент визначає, що користувачеві потрібно прокрутити вміст, щоб переглянути його повністю, він відображає смуги/повзунки прокручування — невеликі напівпрозорі сірі смуги із заокругленими краями праворуч і внизу елемента Text (вертикальна та горизонтальна смуги прокручування). Іноді повзунки прокручування помилково сприймають як тіні.

Ви можете вимкнути ці повзунки, вимкнувши параметр **Прокручування** в меню, яке відкривається після **клацання правою кнопкою миші** елемента. Це повністю вимкне прокручування, а не лише повзунки. Якщо ви хочете, щоб повзунки були невидимими, але прокручування залишилося доступним, можна встановити власні текстури повзунків прокручування, клацнувши елемент правою кнопкою миші. Просто встановіть повністю прозору текстуру.

# Необроблений формат компонентного тексту Minecraft (серіалізовані компоненти JSON)

Елемент Text НЕ підтримує необроблений компонентний формат Minecraft. Цей формат підтримується лише написами кнопок і повзунків.
