# Текст у меню

FancyMenu дає змогу додавати текстовий вміст до меню/екранів за допомогою елемента **Text**.

Цей елемент можна прокручувати, він повністю підтримує Markdown і автоматично переносить рядки, тож чудово підходить для відображення навіть складного текстового вмісту, але також добре працює й для простих однорядкових повідомлень.

## Текстовий вміст

Елемент Text може отримувати свій вміст багатьма способами. Ви можете вказати джерело його тексту: це може бути безпосередній звичайний текстовий ввід, локальний текстовий файл у папці `assets` FancyMenu (`/config/fancymenu/assets/`), вебтекстовий файл (через URL) або локальний текстовий файл, завантажений через ресурс-пак.

Використання вебджерела як джерела тексту особливо корисне, якщо ви хочете зробити щось на кшталт changelog, який завжди актуальний, або стрічку новин та подібні речі, без потреби випускати оновлення для вашого модпаку.

Майте на увазі, що FancyMenu кешує вміст текстових джерел, щоб йому не доводилося постійно повторно завантажувати вміст (що було б дуже погано для продуктивності). Вміст кешується лише для активної сесії, тому після перезапуску гри кеш буде очищено. Ви також можете очистити кеш, перезавантаживши FancyMenu через **menu bar -> Customization -> Reload FancyMenu**.

## Заповнювачі

Елемент Text також підтримує систему заповнювачів FancyMenu, що дає змогу робити текстовий вміст динамічним і реагувати на різні зміни в меню, світах, гравцях тощо.

## Налаштування або вимкнення Markdown

Якщо ви хочете налаштувати кольори для заголовків або інших елементів, пов’язаних із Markdown, просто **клацніть правою кнопкою миші** по елементу Text і натисніть **Markdown**. У підконтекстному меню, що відкриється, ви побачите багато параметрів для налаштування вигляду та поведінки парсера Markdown.

Якщо вам взагалі не потрібен парсинг Markdown, що може підвищити продуктивність для довгого текстового вмісту, ви можете повністю вимкнути Markdown у меню **Markdown** після **клацання правою кнопкою миші** по елементу Text.

## Вимкнення переносу рядків

Якщо вам не потрібен перенос рядків, його можна вимкнути, **клацнувши правою кнопкою миші** по елементу Text.

## Вимкнення прокрутки

За замовчуванням елементи Text можна прокручувати, і якщо елемент вважає, що користувачеві потрібно прокрутити вміст, щоб побачити все, він покаже смуги прокрутки — невеликі сірі смужки праворуч і внизу елемента Text (вертикальна та горизонтальна смуги прокрутки).

Ви можете вимкнути ці смуги, вимкнувши **Scrolling** у меню, що відкривається після **клацання правою кнопкою миші** по елементу. Це вимкне прокрутку загалом, а не лише смуги. Якщо ж ви хочете, щоб смуги були невидимими, ви можете задати власні текстури смуг прокрутки, клацнувши елемент правою кнопкою миші. Просто встановіть там повністю прозору текстуру.

## Формат сирого тексту компонентів Minecraft (Serialized JSON Components)

Елемент Text НЕ підтримує формат сирих компонентів Minecraft. Цей формат підтримується лише написами кнопок і повзунків.
