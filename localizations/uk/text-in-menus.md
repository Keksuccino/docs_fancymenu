# Текст у меню

FancyMenu дає змогу додавати текстовий вміст до меню/екранів за допомогою елемента **Text**.

Цей елемент підтримує прокручування, повноцінну підтримку Markdown і перенесення рядків, що робить його дуже потужним для відображення навіть складного текстового вмісту, але він також чудово підходить і для простих однорядкових текстів.

# Текстовий вміст

Елемент Text може отримувати свій вміст багатьма способами. Ви можете вказати джерело його тексту: це може бути звичайний текстовий ввід, локальний текстовий файл у папці `assets` FancyMenu (`/config/fancymenu/assets/`), вебтекстовий файл (через URL) або локальний текстовий файл, завантажений через resource pack.

Використання вебджерела як джерела тексту особливо корисне, якщо ви хочете зробити, наприклад, changelog, який завжди оновлений, або стрічку новин та подібні речі без потреби випускати оновлення для вашого модпаку.

Майте на увазі, що FancyMenu кешує вміст текстових джерел, тож йому не потрібно постійно отримувати його заново (що було б дуже погано для продуктивності). Вміст кешується лише для активної сесії, тому перезапуск гри очистить кеш. Ви також можете очистити кеш, перезавантаживши FancyMenu через **menu bar -> Customization -> Reload FancyMenu**.

# Плейсхолдери

Елемент Text також підтримує систему плейсхолдерів FancyMenu, що дає змогу робити текстовий вміст динамічним і реагувати на різні зміни в меню, світах, гравцях тощо.

# Налаштування або вимкнення Markdown

Якщо ви хочете налаштувати кольори заголовків або інші речі, пов’язані з Markdown, просто **клацніть правою кнопкою миші** на елементі Text і натисніть **Markdown**. У підменю, що відкриється, ви побачите багато параметрів для налаштування зовнішнього вигляду та поведінки парсера Markdown.

Якщо вам узагалі не потрібен аналіз Markdown, що може покращити продуктивність для довгого текстового вмісту, ви можете повністю вимкнути Markdown у меню **Markdown**, **клацнувши правою кнопкою миші** на елементі Text.

# Вимкнення перенесення рядків

Якщо ви не хочете перенесення рядків, ви можете вимкнути його, **клацнувши правою кнопкою миші** на елементі Text.

# Вимкнення прокручування та приховування повзунків прокрутки

Елементи Text за замовчуванням можна прокручувати, і якщо елемент вважає, що користувачу потрібно прокрутити, щоб побачити весь його вміст, він покаже смуги/повзунки прокрутки — невеликі сірі напівпрозорі смужки із заокругленими краями праворуч і внизу елемента Text (вертикальна та горизонтальна смуги прокрутки). Повзунки прокрутки іноді також плутають із тінями.

Ви можете вимкнути ці повзунки, вимкнувши **Scrolling** у меню, яке відкривається при **клацанні правою кнопкою миші** по елементу. Це вимкне прокручування загалом, а не лише самі повзунки. Якщо ви хочете, щоб повзунки були невидимими, але прокручування лишалося доступним, ви можете задати власні текстури повзунків прокрутки, клацнувши правою кнопкою миші на елементі. Просто встановіть там повністю прозору текстуру.

# Формат сирого тексту компонентів Minecraft (Serialized JSON Components)

Елемент Text НЕ підтримує сирий формат компонентів Minecraft. Цей формат підтримується лише мітками кнопок і повзунків.
