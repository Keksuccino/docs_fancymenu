# Текст у меню

FancyMenu має два елементи для роботи з текстом:

- **Текст** показує текст безпосередньо в меню — від одного рядка до довгих сторінок із прокручуванням, наприклад списків змін, правил чи новин.
- **Підказка** показує текстове поле у фіксованому місці або біля курсора, наприклад коли курсор наведено на кнопку.

Обидва елементи підтримують [Markdown](/text-formatting) і [заповнювачі](/placeholders), а також мають спільні налаштування вигляду й стилю.

<img width="800" alt="Редагування елемента «Текст»" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/text_editor_showcase.gif?raw=true">

> [!TIP]
> Ця сторінка присвячена елементам та їхнім налаштуванням. Усе, що можна додати до тексту, як-от заголовки, списки, посилання й кольори, описано в розділі [Форматування тексту](/text-formatting).

# Додавання тексту

1. Відкрийте макет у редакторі макетів.
2. Клацніть правою кнопкою миші на тлі редактора та виберіть **Новий елемент -> Текст**.
3. Клацніть правою кнопкою миші на новому елементі та виберіть **Вміст тексту**.
4. Введіть текст і натисніть **Готово**.

# Вміст тексту

## Режим джерела

Клацніть правою кнопкою миші на елементі й виберіть **Режим джерела**:

- **Безпосередньо**: ви вводите текст самостійно в редакторі.
- **Ресурс**: текст завантажується з текстового файлу. Натисніть **Джерело тексту**, щоб вибрати локальний файл із каталогу `<game-directory>/config/fancymenu/assets/`, вебадресу або файл пакета ресурсів. Докладніше див. [Ресурси](/resources).

Вебджерела зручні для списків змін і новин, які завжди мають бути актуальними без оновлення збірки модів.

FancyMenu зберігає текст із файлів і вебджерел до завершення гри. Щоб завантажити його знову, перезавантажте FancyMenu через **панель меню -> Налаштування -> Перезавантажити FancyMenu**.

## Динамічний текст

Текст може показувати змінні значення за допомогою [заповнювачів](/placeholders), наприклад `Вітаємо, {"placeholder":"playername"}!`. Також можна показувати значення [змінних](/variables). Текст оновлюється автоматично, коли ці значення змінюються.

## Редактор тексту

Натисніть **Вміст тексту**, щоб відкрити редактор. Натисніть **Заповнювачі** у верхньому правому куті, щоб переглянути всі заповнювачі й додати їх до тексту.

### Комбінації клавіш для форматування

У редакторі тексту елементів «Текст» і «Підказка» є комбінації клавіш для поширених параметрів форматування. У macOS використовуйте `Cmd` замість `Ctrl`.

| Комбінація клавіш | Дія |
|---|---|
| `Ctrl + B` | Жирний шрифт |
| `Ctrl + I` | Курсив |
| `Ctrl + U` | Підкреслення |
| `Ctrl + L` | Вирівнювання ліворуч |
| `Ctrl + E` | Вирівнювання по центру |
| `Ctrl + R` | Вирівнювання праворуч |

- Спочатку виділіть текст, до якого потрібно застосувати форматування. Натисніть ту саму комбінацію ще раз, щоб скасувати форматування.
- Якщо текст не виділено, комбінація додає символи форматування та розміщує курсор між ними, тож можна відразу продовжити введення.
- Комбінації для вирівнювання застосовуються до виділених рядків або до рядка, у якому стоїть курсор. Якщо натиснути `Ctrl + E` або `Ctrl + R` на рядках із таким самим вирівнюванням, вони вирівняються ліворуч.
- Клацніть правою кнопкою миші в редакторі й відкрийте меню **Форматування**, щоб побачити всі ці команди.

### Інші комбінації клавіш

Цей самий редактор тексту використовується для більшості текстів у FancyMenu, зокрема для значень дій і багатьох налаштувань елементів. Ці комбінації працюють у всіх таких випадках. У macOS використовуйте `Cmd` замість `Ctrl`.

| Комбінація клавіш | Дія |
|---|---|
| `Ctrl + C` | Скопіювати виділений текст |
| `Ctrl + X` | Вирізати виділений текст |
| `Ctrl + V` | Вставити |
| `Ctrl + A` | Виділити весь текст |
| `Ctrl + Z` | Скасувати дію |
| `Ctrl + Y` | Повторити дію |
| `Ctrl + D` | Дублювати рядок, у якому стоїть курсор |
| `Alt + стрілка вгору` / `Alt + стрілка вниз` | Перемістити рядок, у якому стоїть курсор, угору або вниз |
| `Shift + клавіші зі стрілками` | Виділити текст |
| `Ctrl + Home` / `Ctrl + End` | Перейти на початок або в кінець тексту |
| `Ctrl + G` | Перейти до рядка: введіть його номер і натисніть `Enter` |
| `Ctrl + S` | Те саме, що **Готово** |

Комбінації клавіш редактора макетів див. у розділі [Редактор макетів](/layout-editor#shortcuts).

# Вигляд і стилі

Клацніть правою кнопкою миші на елементі та відкрийте меню **Markdown**, щоб змінити вигляд тексту.

## Вигляд

**Вигляд** одразу задає всі параметри стилю тексту:

- **Піксельний**: піксельний стиль для шрифту Minecraft із теплими кольорами, золотими деталями й намальованими від руки маркерами.
- **Класичний**: класичний вигляд FancyMenu з білим текстом, сірими блоками та сірими лініями.
- **Нейтральний**: лаконічний вигляд у кольорах поточної теми інтерфейсу FancyMenu. Кольори зберігаються разом з елементом, тож не зміняться, якщо згодом ви виберете іншу тему.

<img width="800" alt="Три варіанти вигляду Markdown" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/markdown_looks.png?raw=true">

Для нових елементів використовується піксельний вигляд. Елементи зі старих макетів зберігають класичний вигляд, який використовували раніше.

> [!NOTE]
> Вибір вигляду замінює всі задані вами зміни стилю. Передумали? Просто скасуйте дію комбінацією `Ctrl + Z`.

## Параметри стилю

Вибравши вигляд, ви можете окремо налаштувати будь-який його елемент. У меню **Markdown** є параметри для **Тексту**, **Заголовків**, **Списків**, **Посилань**, **Коду**, **Цитат**, **Виносок**, **Таблиць**, **Зображень** і **Роздільників**. Наведіть курсор на параметр, щоб побачити його призначення.

У розділі **Markdown -> Текст** зібрано основні параметри: колір і тінь тексту, міжрядковий інтервал і відступи між текстом та краями елемента.

## Вимкнення Markdown

Якщо Markdown вам не потрібен, вимкніть **Markdown -> Обробник Markdown**. Тоді текст відображатиметься саме так, як ви його ввели, а дуже довгі тексти оброблятимуться трохи швидше.

## Інші налаштування тексту

Щоб знайти ці параметри, клацніть правою кнопкою миші на елементі:

- **Масштаб тексту** збільшує або зменшує текст.
- **Регістр** показує текст у звичайному регістрі, лише великими або лише малими літерами.
- **Автоматичне перенесення рядків** переносить рядки, які задовгі для елемента. Якщо вимкнути цей параметр, довгі рядки не переносяться.
- **Видаляти розриви рядків HTML** прибирає розриви рядків HTML (`<br>`) із тексту. Це зручно для тексту з вебсайтів.

# Тло

Елементи «Текст» можуть показувати під текстом панель. Відкрийте меню **Тло** через клацання правою кнопкою миші на елементі:

- **Показувати тло** вмикає або вимикає панель. Для нових елементів «Текст» цей параметр увімкнено.
- Типово використовується вбудована темна панель. Замість неї можна вибрати власну текстуру, скориставшись [дев’ятичастинним розбиттям](/nine-slicing-and-tiling) і замощенням, щоб краї зберігали форму.
- **Відступи** задають, наскільки тло виходить за межі тексту.
- **Тло позаду смуг прокручування** дає змогу накривати тлом також смуги прокручування. Якщо вимкнути цей параметр, смуги розташовуватимуться безпосередньо поруч із тлом.

Для підказок є окреме меню **Тло**, де можна вибрати текстуру та налаштувати її дев’ятичастинне розбиття.

# Прокручування

Якщо текст не вміщується в елементі, його можна прокручувати. Для цього використовуйте коліщатко миші. Утримуйте `Shift`, щоб прокручувати вбік.

Параметр **Напрямок прокручування** визначає, чи прокручується текст **Вертикально**, **Горизонтально** чи **В обох напрямках**. Якщо в певному напрямку прокручування вимкнено, зайвий текст обрізається.

## Налаштування прокручування

Відкрийте меню **Прокручування** через клацання правою кнопкою миші на елементі:

| Налаштування | Дія |
|---|---|
| **Дозволити гравцям прокручувати** | Визначає, чи можуть гравці прокручувати текст самостійно. Якщо вимкнути цей параметр, текст прокручуватиметься лише автоматично або за допомогою дій. |
| **Швидкість прокручування** | Визначає, на яку відстань текст прокручується за один крок коліщатка миші. |
| **Плавне прокручування** | Забезпечує плавний рух тексту замість різких стрибків. |
| **Перетягування для прокручування** | Дає змогу гравцям захопити текст мишею та перетягувати його, як на сенсорному екрані. |
| **Прокручування клавіатурою** | Коли курсор наведено на текст, клавіші `Page Up` і `Page Down` прокручують на одну сторінку, а `Home` і `End` переміщують на початок і в кінець. |
| **Прив’язка** | Визначає, де зупиняється текст: будь-де (**Вимкнено**), із цілим рядком угорі (**За рядками**), із заголовком угорі (**За заголовками**) або на межі цілої сторінки (**За сторінками**). |
| **Починати з** | Визначає, чи починається текст із **Початку** або **Кінця**. Початок із кінця зручний для журналів, де найновіші записи розташовані внизу. |
| **Скидати під час відкриття екрана** | Повертає текст на початок щоразу, коли відкривається екран. Якщо вимкнути цей параметр, позиція прокручування зберігатиметься до завершення гри. |

## Автоматичне прокручування

Відкрийте меню **Автоматичне прокручування**, щоб текст повільно прокручувався сам, як титри або біжучий рядок новин:

- **Прокручувати автоматично** вмикає цей режим.
- **Швидкість [пікселів за секунду]** визначає швидкість прокручування.
- **Починати спочатку після завершення** повертає текст на початок, коли він дійде до кінця.
- **Призупиняти під час наведення курсора** зупиняє прокручування, коли курсор наведено на текст, щоб гравці могли спокійно читати.

## Смуги прокручування

Відкрийте меню **Смуги прокручування**, щоб змінити їхні параметри:

- **Показувати** визначає, коли відображаються смуги: **Завжди**, лише **Під час прокручування** або **Ніколи**. Якщо вибрати **Ніколи**, текст усе одно можна прокручувати коліщатком миші.
- **Товщина** задає товщину смуг.
- **Вертикальна смуга ліворуч** і **Горизонтальна смуга вгорі** переміщують смуги на протилежний бік.
- **Стиль повзунків прокручування** визначає вигляд повзунків: **Смуга теми** (у кольорах теми інтерфейсу FancyMenu) або **Піксельний повзунок** (піксельна графіка, що пасує до піксельного вигляду).
- **Текстури повзунків прокручування** і **Колір повзунків прокручування [HEX]** дають змогу замінити повзунки власними текстурами або кольорами.
- **Тло смуг прокручування** додає текстури під повзунками вздовж усього шляху їхнього руху.

## Керування прокручуванням за допомогою дій

У FancyMenu можна керувати прокручуванням і стежити за ним також з інших місць:

- [Дія](/action-scripts) **Прокрутити елемент** прокручує елемент «Текст» на початок, у кінець, до певної позиції або номера рядка чи до першого рядка, що містить заданий текст.
- [Заповнювачі](/placeholders) **Позиція прокручування елемента**, **Відсоток прокручування елемента** і **Розмір вмісту елемента** показують, наскільки прокручено текст і який його розмір.
- [Умова](/conditions) **Елемент прокручено до кінця** перевіряє, чи прокручено текст до кінця. Наприклад, так можна активувати кнопку «Прийняти» лише після прочитання правил.
- [Слухачі](/listeners) **Під час прокручування елемента**, **Під час прокручування елемента на початок** і **Під час прокручування елемента до кінця** запускають дії, коли текст прокручується.

Для всіх цих функцій потрібен [ідентифікатор елемента](/element-identifiers) елемента «Текст».

# Клацання крізь текстові елементи

Елементи «Текст» реагують на мишу, щоб працювали посилання та смуги прокручування. Це також означає, що вони перехоплюють клацання, тож кнопки позаду або перед елементом «Текст» можуть їх не отримати.

Якщо це проблема, клацніть правою кнопкою миші на елементі «Текст» і вимкніть параметр **Інтерактивний**. Тоді текст не можна буде прокручувати, а на посилання в ньому — натискати.

# Підказки

Елементи «Підказка» працюють так само, як елементи «Текст», але без прокручування:

- Для них доступні ті самі налаштування тексту, вигляду й стилю, що й для елементів «Текст».
- Параметр **Слідувати за курсором** змушує підказку переміщатися за курсором.
- Використовуйте [умови](/conditions), щоб визначити, коли показувати підказку. Наприклад, умова [**На елемент наведено курсор**](/conditions#is-element-hovered) показує її, коли курсор наведено на кнопку.
