# Ефект паралаксу

Паралакс зміщує фон або елемент залежно від руху миші, створюючи візуальну глибину.

# Фон зображення меню

1. Клацніть правою кнопкою миші по фону редактора макета.
2. Відкрийте [**Фони меню**](./menu-backgrounds) -> **Зображення**.
3. Вкажіть джерело зображення.
4. Увімкніть **Ефект паралаксу**.
5. Встановіть значення інтенсивності X та Y.
6. За потреби увімкніть **Інвертувати рух паралаксу**.

Значення X і Y окремо керують горизонтальним і вертикальним рухом. Використовуйте значення від `0.0` (немає руху) до `1.0` (максимум).

# Елементи

1. Клацніть правою кнопкою миші по [елементу](./elements).
2. Увімкніть **Ефект паралаксу**.
3. Встановіть **Інтенсивність паралаксу X** і **Інтенсивність паралаксу Y**.
4. За потреби інвертуйте рух.

Використовуйте нижчу інтенсивність для далеких шарів і вищу — для передніх шарів. Великі відмінності або інвертовані шари створюють сильніший ефект глибини.

# Усунення несправностей

- Інтенсивність `0` не створює руху на цій осі.
- **Проведення широких зображень зліва направо** конфліктує з фоновим паралаксом і має бути вимкнене.
- Дуже малий рух може виглядати ступінчастим, оскільки позиції GUI використовують цілі пікселі.
