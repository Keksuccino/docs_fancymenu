# Інтро гри

Інтро гри відтворює анімацію або відео під час запуску гри, одразу після екрана завантаження Minecraft. Коли воно закінчується, відбувається плавний перехід до титульного екрана. Ця функція створена для збірок модів: можна показати логотип, заставку студії або короткий трейлер.

<img width="800" alt="Інтро Skyhaven: ніч над плавучим островом змінюється світанком, а логотип з’являється літера за літерою; потім інтро плавно переходить до титульного екрана з тим самим островом на тлі" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/game_intro_showcase.gif?raw=true">

Гравці можуть пропустити інтро будь-якою клавішею або клацанням. Інтро гри — це одне з [глобальних налаштувань](/global-customizations), тому для нього не потрібен макет.

# Налаштування інтро

<img width="800" alt="Відкриття розділу «Глобальні налаштування» та пункту «Інтро гри» на панелі меню, вибір skyhaven_intro.apng за допомогою кнопки «Установити інтро гри», відтворення через кнопку «Повторно запустити інтро гри» та пропуск натисканням пробілу" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/game_intro_setup.gif?raw=true">

1. Помістіть анімацію або відео в `<game-directory>/config/fancymenu/assets/`.
2. Відкрийте **панель меню -> Налаштування -> Глобальні налаштування -> Інтро гри**.
3. Натисніть **Установити інтро гри**. Якщо для параметра **Тип джерела** вибрано **Локальне**, натисніть **Вибрати локальний файл ресурсу**, виберіть файл і натисніть **OK**.
4. Натисніть **Повторно запустити інтро гри**, щоб одразу переглянути його.

Щоб прибрати інтро, наведіть курсор на **Установити інтро гри** та натисніть **Скинути до стандартних**.

## Анімації та відео

- **Анімації:** файли APNG або GIF. Як їх створити: [Анімації](/animations).
- **Відео:** файли MP4. Для них потрібні моди Watermedia V3 і Watermedia Binaries V3. Докладніше: [Відео](/video#requirements). Без них замість відеоінтро на кілька секунд з’явиться лише червоне повідомлення з посиланнями для завантаження.
- Файли з теки вашого екземпляра та з паків ресурсів працюють, а вебпосилання — ні. Докладніше: [Ресурси](/resources).

Інтро займає весь екран і зберігає пропорції, тому на екранах із іншими пропорціями його частини обрізатимуться. Більшість екранів мають формат 16:9, тож створюйте інтро також у форматі 16:9, наприклад 1920x1080. Прозорі ділянки відображаються чорними.

> [!TIP]
> Гравці бачитимуть інтро щоразу під час запуску гри, тож зробіть його коротким — приблизно 5–10 секунд.

## Безкоштовне прикладове інтро

Інтро Skyhaven із GIF-анімацій на цій сторінці можна безкоштовно використовувати для тестування та у своїх збірках модів:

- [skyhaven_intro.apng](https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/skyhaven_intro.apng?raw=true): інтро розміром 1280x720, тривалість — 5,4 секунди. Відтворюється один раз.
- [skyhaven_menu.png](https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/skyhaven_menu.png?raw=true): остання сцена без логотипа, розміром 1280x720. Зробіть її [фоновим зображенням](/menu-backgrounds#image) макета титульного екрана, і інтро плавно перейде в меню, яке йому відповідає, як у першій GIF-анімації.

# Налаштування

Усі параметри розміщено в розділі **панель меню -> Налаштування -> Глобальні налаштування -> Інтро гри**:

| Параметр | Призначення |
|---|---|
| **Установити інтро гри** | Анімація або відео. |
| **Пропуск інтро гри** | Інтро можна пропустити будь-якою клавішею або клацанням; унизу з’являється напис **Натисніть будь-яку клавішу, щоб пропустити**. Якщо вимкнути параметр, інтро відтворюватиметься до кінця. Під час пропуску відтворення одразу завершується, без плавного переходу. |
| **Згасання інтро гри** | Коли інтро закінчується, воно плавно переходить до титульного екрана. Якщо вимкнути параметр, титульний екран з’явиться одразу. |
| **Ігнорувати цикли інтро гри** | Інтро завершується після одноразового відтворення анімації, навіть якщо вона циклічна. Якщо вимкнути параметр, відтворяться всі цикли анімації. Відео завжди відтворюються один раз. |
| **Власний текст для пропуску** | Замінює напис **Натисніть будь-яку клавішу, щоб пропустити**, наприклад, на `Натисніть будь-яку клавішу, щоб почати свою пригоду`. Якщо вказати ключ локалізації з паку ресурсів, наприклад `skyhaven.intro.skip`, текст відображатиметься мовою гравця. |
| **Гучність інтро гри** | Гучність відеоінтро від 0% до 100%. |
| **Канал звуку інтро гри** | Канал звуку для відеоінтро, наприклад «Музика». На нього додатково впливають гучність цього каналу та загальна гучність у налаштуваннях звуку Minecraft. |
| **Повторно запустити інтро гри** | Одразу відтворює інтро поверх поточного екрана. |

Параметри **Пропуск інтро гри**, **Згасання інтро гри** та **Ігнорувати цикли інтро гри** увімкнено за замовчуванням.

> [!WARNING]
> Якщо вимкнути і **Пропуск інтро гри**, і **Ігнорувати цикли інтро гри**, анімація, що зациклюється без кінця, ніколи не завершиться, і гравці не зможуть перейти до титульного екрана.

# Корисно знати

- Інтро відтворюється один раз під час кожного запуску гри, перед першим екраном після екрана завантаження. Зазвичай це титульний екран.
- Щоб змінити екран завантаження Minecraft, який з’являється перед інтро, дивіться розділ [Екран завантаження](/loading-screen).
- Джерело інтро може містити [заповнювачі](/resources#placeholders-in-resource-sources).
- Налаштування інтро гри зберігаються у файлі `options.txt` FancyMenu, тож вони належать до завантаженого [профілю](/profiles). Збірки модів, до яких входить `config/fancymenu/`, постачаються з інтро та його файлом у теці `assets/`. Докладніше: [Збірки модів](/modpacks).
