# Фонова музика меню

FancyMenu може вимкнути стандартну музику меню, відтворювати глобальний список композицій або використовувати [аудіоелементи](/elements#audio) для музики, властивої певним макетам.

# Глобальна музика меню

Відкрийте [**Глобальні налаштування**](/global-customizations) через **Налаштування -> Глобальні налаштування** поза редактором макетів.

Використовуйте ці налаштування:

- **Відтворювати стандартну музику меню** — вмикає або вимикає стандартну музику меню глобально.
- **Власні музичні композиції меню** — керує глобальним списком композицій на заміну.

> [!IMPORTANT]
> Глобальні власні композиції меню відтворюються, лише коли жоден світ не завантажено, наприклад на титульному екрані. Для відтворення звуку меню у світі використовуйте елемент [**Аудіо**](/elements#audio).

Глобальні композиції використовують звуковий канал «Музика». Перша композиція починає відтворюватися приблизно через п’ять секунд; для наступних композицій використовується випадкова затримка від однієї до тридцяти секунд. Композиції вибираються випадково. Якщо налаштовано більше однієї композиції, попередня композиція не повторюється одразу.

# Керування музикою для окремих екранів

Додайте до макета елемент [**Контролер музики**](/elements#music-controller), щоб керувати стандартною музикою на цьому екрані:

1. Клацніть правою кнопкою миші фон редактора.
2. Виберіть **Новий елемент -> Контролер музики**.
3. Налаштуйте окремо музику меню та музику світу.

Елемент підтримує [вимоги завантаження](/conditions).

Якщо вимкнути музику меню за допомогою контролера музики, глобальний список власних композицій меню також не відтворюватиметься на цьому екрані.

# Власна музика за допомогою аудіоелементів

Використовуйте елемент [**Аудіо**](/elements#audio), якщо вам потрібні:

- Різна музика на різних екранах.
- Музика на екранах у світі.
- Вимоги макета, упорядковані списки відтворення, налаштування випадкового відтворення, гучність або керування каналом.

Розмістіть [аудіоелемент](/elements#audio) в [універсальному макеті](/universal-layouts), щоб той самий програвач залишався активним на підтримуваних екранах, для яких завантажується цей макет. Для кожного звичайного екрана, на якому має застосовуватися універсальний макет, потрібно ввімкнути налаштування екрана.
