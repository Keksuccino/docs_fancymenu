# Робота з параметрами Minecraft у FancyMenu

FancyMenu дає змогу отримувати та змінювати налаштування гри Minecraft (параметри) за допомогою різних елементів інтерфейсу. У цьому посібнику показано, як використовувати кнопки, повзунки та таймери для роботи з параметрами Minecraft у ваших власних макетах меню.

# Розуміння параметрів Minecraft

У Minecraft є багато вбудованих параметрів, які керують усім: від графіки до гучності звуку. FancyMenu дає змогу звертатися до цих параметрів за їхніми назвами.

Деякі поширені назви параметрів:
- `soundCategory_master` - Головна гучність
- `soundCategory_music` - Гучність музики
- `soundCategory_ambient` - Гучність фонових звуків
- `soundCategory_players` - Гучність звуків гравців
- `soundCategory_blocks` - Гучність звуків блоків
- `fov` - Кут огляду
- `gamma` - Яскравість
- `renderDistance` - Дистанція промальовування

# Відображення значень параметрів

Ви можете показати поточне значення будь-якого параметра Minecraft за допомогою спеціального плейсхолдера.

Плейсхолдер має такий вигляд:
```
{"placeholder":"minecraft_option_value","values":{"name":"option_name"}}
```

Замініть `option_name` на фактичну назву параметра, який ви хочете відобразити.

# Встановлення параметрів за допомогою кнопок

Кнопки можна використовувати для встановлення конкретних значень параметрів Minecraft.

## Як налаштувати кнопку:

1. Створіть новий елемент Button
2. Встановіть напис на кнопці (що відображатиметься на кнопці)
3. Додайте дію: клацніть правою кнопкою миші по кнопці → Edit Action Script → Add Action → Set Minecraft Option Value
4. У вікні "Set Minecraft Option Value":
   - Name: введіть назву параметра (наприклад, `renderDistance`)
   - Value: введіть значення, яке потрібно встановити (наприклад, `16`)

## Приклад: 

Створення кнопки, яка встановлює дистанцію промальовування на 16 чанків:
- Option Name: `renderDistance`
- Value: `16`
- Label: "Встановити дистанцію промальовування на 16 чанків"

# Встановлення параметрів за допомогою повзунків

Повзунки ідеально підходять для параметрів із діапазоном значень, як-от гучність або яскравість.

## Як налаштувати повзунок:

1. Створіть новий елемент Slider
2. Встановіть тип повзунка:
   - Для цілих чисел (наприклад, дистанції промальовування): оберіть "Integer Range"
   - Для десяткових чисел (наприклад, гучності): оберіть "Decimal Range"
3. Задайте мінімальне та максимальне значення
4. Додайте дію для встановлення параметра Minecraft:
   - Клацніть правою кнопкою миші → Edit Action Script → Add Action → Set Minecraft Option Value
   - Name: назва параметра
   - Value: `$$value` (ця спеціальна змінна містить поточне значення повзунка)
5. Встановіть попередньо вибране значення на поточне значення параметра:
   - У полі "Pre-Selected Value" вкажіть `{"placeholder":"minecraft_option_value","values":{"name":"option_name"}}`

## Приклади форматів напису повзунка:

Щоб показувати поточне значення параметра в написі повзунка, використовуйте:
```
Гучність: {"placeholder":"minecraft_option_value","values":{"name":"soundCategory_master"}}
```

Щоб показати відсоток (зручно для гучності):
```
Гучність: {"placeholder":"calc","values":{"expression":"$$value * 100.0","decimal":"false"}}%
```

# Встановлення параметрів за допомогою таймерів

Таймери — це невидимі елементи, які можуть автоматично змінювати параметри за розкладом.

## Як налаштувати таймер:

1. Створіть новий елемент Ticker
2. Налаштуйте параметри тіку:
   - Tick Mode: виберіть, коли параметр має оновлюватися
   - Tick Delay: встановіть, як часто він оновлюється (у мілісекундах)
3. Додайте дію для встановлення параметра Minecraft:
   - Клацніть правою кнопкою миші → Edit Action Script → Add Action → Set Minecraft Option Value
   - Вкажіть назву параметра та значення

## Приклад:

Встановлення gamma (яскравості) на максимум під час завантаження меню:
- Tick Mode: On Load Screen
- Name: `gamma`
- Value: `1.0`

# Поширені сценарії використання

Ось кілька поширених випадків, що ви можете робити, використовуючи FancyMenu для встановлення та отримання параметрів Minecraft.

## Створення власних повзунків гучності

Повзунки гучності — поширене застосування інтеграції з параметрами Minecraft. Ось як створити власний повзунок гучності музики:

1. Створіть новий елемент Slider
2. Встановіть "Slider Type" на "Decimal Range"
3. Встановіть "Minimum Range Value" на "0.0"
4. Встановіть "Maximum Range Value" на "1.0"
5. Edit Action Script → Add Action → Set Minecraft Option Value
   - Set Name to `soundCategory_music`
   - Set Value to `$$value`
6. Встановіть "Pre-Selected Value" на `{"placeholder":"minecraft_option_value","values":{"name":"soundCategory_music"}}`
7. Щоб показувати гучність у відсотках, встановіть напис так: 
   ```
   Музика: {"placeholder":"calc","values":{"expression":"$$value * 100.0","decimal":"false"}}%
   ```

Ви можете створити подібні повзунки для інших категорій звуку:
- Головна гучність: `soundCategory_master`
- Музика: `soundCategory_music`
- Фон: `soundCategory_ambient`
- Блоки: `soundCategory_blocks`
- Гравці: `soundCategory_players`
- Погода: `soundCategory_weather`

## Створення власного повзунка FOV

Кут огляду (FOV) — важливий графічний параметр, який визначає, наскільки широким є ваш огляд у грі. Параметр FOV внутрішньо використовує значення від -1.0 до 1.0, але в інтерфейсі відображається як від 30 до 110.

### Розуміння зіставлення значень FOV
- Внутрішній діапазон значень: -1.0 до 1.0
- Діапазон значень для відображення: 30 до 110
- Формула зіставлення: `(internal_value + 1) * 40 + 30`

### Крок 1: Створіть елемент Ticker для оновлення тексту FOV

Спочатку нам потрібен таймер, який перевірятиме поточне значення FOV і встановлюватиме змінну з відповідним описом:

1. Створіть новий елемент Ticker
2. Встановіть "Tick Mode" на "Normal" (щоб він оновлювався постійно)
3. Встановіть "Tick Delay" приблизно на "10" (мілісекунд), щоб уникнути надмірної кількості перевірок

Тепер потрібно налаштувати дії для написів FOV. Структура вашого сценарію дій має виглядати так:

```
▶ Action Script
│
├─▶ IF (mapped FOV = 70)
│  └─■ Set Variable Value: fov_text:Normal
│
├─▶ ELSE-IF (mapped FOV = 110)
│  └─■ Set Variable Value: fov_text:Quake Pro
│
└─▶ ELSE
   └─■ Set Variable Value: fov_text:[розраховане числове значення]
```

Налаштуймо кожну частину:

#### Налаштування напису FOV "Normal":
1. Клацніть правою кнопкою миші → Edit Action Script → Add Action
2. Натисніть "IF Statement", щоб додати умовний блок
3. Встановіть умову "Is Number" з такими параметрами:
   - Compare Mode: "equals"
   - Number: `{"placeholder":"calc","values":{"decimal":"false","expression":"({"placeholder":"minecraft_option_value","values":{"name":"fov"}} + 1) * 40 + 30"}}`
   - Compare With: "70"
4. Усередині цього блоку IF додайте дію "Set Variable Value (FM Variable)" з таким значенням:
   - Value: `fov_text:Normal`

#### Налаштування напису FOV "Quake Pro":
1. Усередині Action Script додайте "ELSE-IF Statement"
2. Встановіть умову "Is Number" з такими параметрами:
   - Compare Mode: "equals"
   - Number: `{"placeholder":"calc","values":{"decimal":"false","expression":"({"placeholder":"minecraft_option_value","values":{"name":"fov"}} + 1) * 40 + 30"}}`
   - Compare With: "110"
3. Усередині цього блоку ELSE-IF додайте дію "Set Variable Value (FM Variable)" з таким значенням:
   - Value: `fov_text:Quake Pro`

#### Налаштування числового напису FOV:
1. Додайте блок "ELSE Statement"
2. Усередині цього блоку ELSE додайте дію "Set Variable Value (FM Variable)" з таким значенням:
   - Value: `fov_text:{"placeholder":"calc","values":{"decimal":"false","expression":"({"placeholder":"minecraft_option_value","values":{"name":"fov"}} + 1) * 40 + 30"}}`

### Крок 2: Створіть повзунок FOV

1. Створіть новий елемент Slider
2. Встановіть "Slider Type" на "Decimal Range"
3. Встановіть "Minimum Range Value" на "-1.0"
4. Встановіть "Maximum Range Value" на "1.0"
5. Edit Action Script → Add Action → Set Minecraft Option Value
   - Set Name to `fov`
   - Set Value to `$$value`
6. Встановіть "Pre-Selected Value" на `{"placeholder":"minecraft_option_value","values":{"name":"fov"}}`

### Крок 3: Встановіть напис повзунка

У написі повзунка просто відображайте змінну тексту FOV:

```
FOV: {"placeholder":"getvariable","values":{"name":"fov_text"}}
```

Цей напис показуватиме:
- "FOV: Normal" коли значення дорівнює 70
- "FOV: Quake Pro" коли значення дорівнює 110  
- "FOV: 85" (або будь-яке інше число) для всіх інших значень

### Поради щодо повзунків FOV

- Внутрішній діапазон значень повзунка — від -1.0 до 1.0, який потрібно зіставити з діапазоном 30–110 для відображення
- Формула перетворення: `(internal_value + 1) * 40 + 30`
- Лише два значення мають спеціальні написи: 70 (Normal) і 110 (Quake Pro)
- Значення FOV за замовчуванням у Minecraft — 70 (що відповідає внутрішньому значенню 0.0)
- Змінна `fov_text` автоматично містить або спеціальний напис, або числове значення

## Відображення значень параметрів у текстових елементах

Ви також можете відображати поточні значення параметрів у текстових елементах:

1. Створіть елемент Text
2. Для вмісту тексту використайте плейсхолдер: `{"placeholder":"minecraft_option_value","values":{"name":"option_name"}}`

Наприклад, щоб показати поточну дистанцію промальовування:
```
Поточна дистанція промальовування: {"placeholder":"minecraft_option_value","values":{"name":"renderDistance"}} чанків
```

# Пошук назв параметрів

Ви можете дізнатися назви всіх доступних параметрів так:

  1. Створіть кнопку
  2. Клацніть по ній правою кнопкою миші
  3. Натисніть "Edit Action Script"
  4. Додайте дію "Set Minecraft Option Value"
  5. Під час редагування значення дії зверніть увагу на підказки списку, коли ви почнете вводити текст у полі "Name"
  
# Важливі поради

- **Допустимі значення**: Не всі параметри приймають усі значення. Наприклад:
  - Параметри гучності приймають значення від 0.0 до 1.0
  - Дистанція промальовування зазвичай приймає цілі числа від 2 до 32
  - Булеві параметри (true/false), як-от `pauseOnLostFocus`, приймають "true" або "false"

- **Тестування**: Завжди перевіряйте свої налаштування, щоб переконатися, що вони працюють як очікується!

- **Візуальний зворотний зв’язок**: Надавайте користувачам візуальний зворотний зв’язок щодо поточного значення за допомогою описаних вище плейсхолдерів.
