# Фони меню

FancyMenu дає змогу встановлювати власні фони для меню. Ви можете використовувати зображення, анімовані текстури, слайдшоу, кубічні панорами, кольори, браузери, відео, GLSL-шейдери та багато іншого.

# Налаштування фону

Налаштування фону меню доступне через контекстне меню редактора макета:

1. Відкрийте редактор макета.
2. Клацніть правою кнопкою миші по фону редактора.
3. Відкрийте **Фони меню**.
4. Увімкніть і налаштуйте потрібний тип(и) фону.

Поширені типи фону включають:

- Vanilla
- Зображення
- Слайдшоу
- Кубічна панорама
- Колір (HEX)
- Браузер
- Відео
- GLSL Shader
- Відео [MCEF] (застаріло)
- Додаткові типи фону з аддонів

Старий тип фону **Відео [MCEF]** є застарілим. Для нових макетів використовуйте [вбудований фон **Відео**](./video) на базі Watermedia V3.

# Видалення власного фону

Знову відкрийте **Фони меню** та вимкніть або видаліть тип власного фону, який вам більше не потрібен. Якщо жоден тип власного фону не активний, екран повернеться до звичайної поведінки стандартного фону.

# Накладання фонів

У межах одного макета можна увімкнути кілька типів фону меню. Активні фони рендеряться як стек, тож базове зображення або панораму можна поєднувати з напівпрозорими шарами браузера, шейдера, паралаксу чи іншими.

Якщо у вас також активні кілька макетів, їхні стеки фонів теж можуть поєднуватися. Щоб впорядкувати макети та показувати їх у певному порядку, клацніть правою кнопкою миші по фону редактора та натисніть **Індекс макета**.

# Прозорі фони

FancyMenu рендерить чорний підкладковий шар позаду активних власних фонів. Тому прозорі пікселі у найнижчому фоні показуватимуть чорний колір. Використовуйте непрозорий базовий фон, а потім накладайте зверху напівпрозорі фони.

Щоб зробити фонове зображення напівпрозорим, скористайтеся будь-яким зручним редактором зображень.

# Фони браузера

Тип фону **Браузер** працює так само, як [елемент Browser](./elements#browser), але заповнює весь екран і автоматично отримує фокус. Це корисно для повноекранного вебконтенту, локальних HTML-сторінок або шарів вебвідео.

# Фони GLSL Shader

Тип фону **GLSL Shader** рендерить власні GLSL-шейдери та підтримує стиль створення шейдерів, подібний до Shadertoy. Дивіться сторінку [GLSL Shader API](/glsl-shader-api) для підтримуваних uniform-змінних і структури шейдера.
