# Фони меню

FancyMenu дає змогу встановлювати власні фони для меню. Ви можете використовувати зображення, анімовані текстури, слайд-шоу, кубічні панорами, кольори, браузери, відео, шейдери GLSL та багато іншого.

# Встановлення фону

Налаштування фону меню доступне в контекстному меню редактора макета:

1. Відкрийте редактор макета.
2. Клацніть правою кнопкою миші на фоні редактора.
3. Відкрийте **Фони меню**.
4. Увімкніть і налаштуйте потрібні типи фону.

Поширені типи фону:

- Vanilla
- Зображення
- Слайд-шоу
- Кубічна панорама
- Колір (HEX)
- Браузер
- Відео
- Шейдер GLSL
- Відео [Rinku] (застарілий)
- Додаткові типи фону від аддонів

Старий тип фону **Відео [Rinku]** застарів. Для нових макетів використовуйте [власний фон **Відео**](./video), що працює на Watermedia V3.

# Видалення власного фону

Знову відкрийте **Фони меню** та вимкніть або видаліть непотрібний власний тип фону. Якщо жоден власний тип фону не активний, екран повернеться до звичайної поведінки фону Vanilla.

# Накладання фонів

В одному макеті можна ввімкнути кілька типів фону меню. Активні фони відображаються як стек, тому базове зображення або панораму можна поєднати з напівпрозорими браузером, шейдером, паралаксом чи іншими шарами.

Якщо у вас також активні кілька макетів, їхні стеки фонів теж можуть поєднуватися. Щоб упорядкувати макети та визначити порядок їх відображення, клацніть правою кнопкою миші на фоні редактора й натисніть **Індекс макета**.

# Прозорі фони

FancyMenu відображає чорний фоновий шар позаду активних власних фонів. Тому прозорі пікселі в найнижчому фоні відкривають чорний колір. Використовуйте непрозорий базовий фон, а потім накладайте поверх нього напівпрозорі фони.

Щоб зробити зображення фону напівпрозорим, скористайтеся будь-яким графічним редактором.

# Фони браузера

Тип фону **Браузер** працює як [елемент «Браузер»](./elements#browser), але заповнює весь екран і автоматично отримує фокус. Це зручно для повноекранного вебконтенту, локальних HTML-сторінок або шарів із вебвідео.

# Фони з шейдерами GLSL

Тип фону **Шейдер GLSL** відображає власні шейдери GLSL і підтримує створення шейдерів у стилі Shadertoy. Докладніше про підтримувані uniform-змінні та структуру шейдерів дивіться на сторінці [API шейдерів GLSL](/glsl-shader-api).
