# Фони меню

FancyMenu дає змогу встановлювати власні фони для меню. Ви можете використовувати зображення, анімовані текстури, слайд-шоу, кубічні панорами, кольори, браузери, відео, GLSL-шейдери та інше.

# Налаштування фону

У FancyMenu 3.9.0+ налаштування фону меню відбувається безпосередньо через контекстне меню редактора макета:

1. Відкрийте редактор макета.
2. Клацніть правою кнопкою миші по фону редактора.
3. Відкрийте **Фони меню**.
4. Увімкніть і налаштуйте потрібні типи фону.

Найпоширеніші типи фону:

- Vanilla
- Image
- Slideshow
- Cubic Panorama
- Color (HEX)
- Browser
- Video
- GLSL Shader
- Video [MCEF] (deprecated)
- та інші..

Старий тип фону **Video [MCEF]** є застарілим у FancyMenu 3.9.0. Для нових макетів використовуйте новий вбудований фон **Video**, що працює на Watermedia V3.

# Видалення власного фону

Знову відкрийте **Фони меню** та вимкніть/видаліть тип власного фону, який вам більше не потрібен. Якщо жоден тип власного фону не активний, екран повернеться до стандартної поведінки фонів vanilla.

# Накладання фонів

FancyMenu 3.9.0 дозволяє вмикати кілька типів фону меню в одному макеті. Активні фони рендеряться як стек, тож ви можете поєднувати базове зображення або панораму з напівпрозорими накладками, шарами браузера, шарами шейдерів, паралакс-шарами та іншими ефектами.

Якщо у вас також активовано кілька макетів, їхні стеки фонів теж можуть поєднуватися. Щоб відсортувати макети й змусити їх відображатися в певному порядку, клацніть правою кнопкою миші по фону редактора та натисніть **Порядковий номер макета**.

# Прозорі фони

Оскільки позаду фонів нічого немає, неможливо зробити прозорим самий нижній фон, бо це спричинить графічні збої. Однак використовувати прозорість у стекових налаштуваннях фонів цілком можливо, якщо нижній фон залишається повністю непрозорим. Так ви можете мати напівпрозорі шари фону поверх нижнього.

Щоб зробити фон із зображенням напівпрозорим, скористайтеся будь-яким графічним редактором на ваш вибір.

# Фони браузера

Тип фону **Browser** працює як елемент Browser, але заповнює весь екран і автоматично отримує фокус. Це корисно для вебконтенту на весь екран, локальних HTML-сторінок або шарів вебвідео.

# Фони GLSL-шейдерів

Тип фону **GLSL Shader** відображає власні GLSL-шейдери та підтримує створення шейдерів у стилі Shadertoy. Дивіться сторінку [GLSL Shader API](/glsl-shader-api) для підтримуваних uniform-змінних і структури шейдера.
