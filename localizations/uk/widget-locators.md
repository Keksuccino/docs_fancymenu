# Локатори віджетів

Локатори віджетів використовуються для вказування на конкретний Vanilla-віджет (кнопку, повзунок, поле введення тексту) у меню, що потрібно для деяких функцій FancyMenu, яким необхідно якимось чином взаємодіяти з віджетом.

# Отримання локатора віджета

Існує два способи отримати локатор Vanilla-віджета.

Перший — увімкнути **налагоджувальне накладання** в меню, яке містить віджет, натиснувши **CTRL + ALT + D**, а потім **клацнути віджет правою кнопкою миші**, після чого відкриється контекстне меню з пунктом для копіювання локатора в буфер обміну.

Другий — відкрити **редактор макета** для меню, яке містить віджет, а потім **клацнути елемент віджета правою кнопкою миші**, після чого також відкриється контекстне меню з пунктом для копіювання локатора в буфер обміну.

>[!WARNING]
>Якщо ви **не можете клацнути віджет правою кнопкою миші** через налагоджувальне накладання або він **не відображається** в редакторі макета, ймовірно, він не видимий для FancyMenu, а отже, у такому разі не має локатора. Найчастіше таке трапляється з кнопками модів, які додаються до меню нестандартним способом.
