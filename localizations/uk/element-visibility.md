# Видимість елементів

Елементи не обов’язково мають відображатися постійно. Вони можуть з’являтися лише за певних умов, із невеликою затримкою, плавно з’являтися й зникати або вмикатися та вимикатися кнопкою.

<img width="800" alt="Привітальний текст плавно з’являється через кілька секунд після відкриття екрана, а потім кнопка «Правила сервера» плавно показує та приховує панель із правилами" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/element_visibility_toggle.gif?raw=true">

У редакторі макета елементи завжди відображаються, щоб ви могли їх редагувати. Усе на цій сторінці працює поза редактором.

> [!TIP]
> Усі умови наведено в розділі [Умови](/conditions).

# Показ елементів лише за певних умов

Клацніть елемент правою кнопкою миші й виберіть **Умови завантаження**. Елемент відображається, лише поки виконуються всі його [умови](/conditions), наприклад «курсор наведено на цю кнопку», «зараз грудень» або «змінна має певне значення». FancyMenu постійно перевіряє умови, тож елемент одразу з’являється або зникає.

- **Режим умови** «Протилежне» змінює умову на протилежну, наприклад «НЕ грудень».
- Групи дають змогу створювати умови на кшталт «це АБО те».
- Для стандартних елементів також є параметр **Умови завантаження**. Щоб повністю видалити такий елемент, див. розділ [Видалені стандартні елементи](/deleted-vanilla-elements).

Як додавати умови та поєднувати їх: [Умови](/conditions#adding-a-requirement).

## Завантажувати лише раз за сеанс

Клацніть елемент правою кнопкою миші й увімкніть **Завантажувати лише раз за сеанс**. Елемент з’явиться під час першого відкриття екрана. Коли гравець перейде на інший екран, елемент залишатиметься прихованим до перезапуску гри.

Це зручно для підказок, які мають показуватися лише раз після запуску гри, наприклад «Натисніть F1, щоб переглянути керування». Щоб використати такий самий принцип у сценаріях дій, є умова [**Лише раз за сеанс**](/conditions#only-once-per-session).

# Затримка показу елементів

## Затримка появи

Клацніть елемент правою кнопкою миші й виберіть **Затримка появи**:

- **Затримка**:
  - **Без затримки**: елемент з’являється одразу.
  - **Перший раз**: затримка застосовується лише під час першої появи елемента після запуску гри.
  - **Щоразу**: затримка застосовується під час кожного відкриття екрана та щоразу, коли умови для елемента знову виконуються.
- **Тривалість затримки в секундах**: скільки чекати, наприклад `1.5`.

Зміна розміру вікна не запускає затримку знову.

## Затримка зникнення

Клацніть елемент правою кнопкою миші й виберіть **Затримка зникнення**. Коли умови для елемента перестають виконуватися, він залишається на екрані ще протягом часу, зазначеного в параметрі **Тривалість затримки в секундах**, а потім зникає. Для параметра **Затримка** доступні ті самі варіанти, що й вище.

Наприклад, інформаційна панель з умовою [**Курсор наведено на елемент**](/conditions#is-element-hovered) для кнопки залишається на екрані ще 1 секунду після того, як курсор залишає кнопку.

# Плавна поява та зникнення

Клацніть елемент правою кнопкою миші й виберіть **Плавна поява/зникнення**:

- **Плавна поява** та **Плавне зникнення**:
  - **Без плавного ефекту**: елемент з’являється або зникає одразу.
  - **Лише один раз**: плавний ефект застосовується лише вперше після запуску гри.
  - **Щоразу**: плавний ефект застосовується щоразу.
- **Швидкість появи** та **Швидкість зникнення**: за значення `1` плавний ефект триває 2,5 секунди. Значення `2` удвічі прискорює його.

Елементи плавно з’являються під час відкриття екрана та коли починають виконуватися їхні умови. Якщо задано **Затримку появи**, плавний ефект починається після затримки.

Плавне зникнення відбувається лише тоді, коли умови приховують елемент, а не під час закриття екрана.

# Прозорість

Клацніть елемент правою кнопкою миші й виберіть **Прозорість**: `1.0` — повністю видимий, `0.5` — напівпрозорий, `0.0` — невидимий. Такий параметр є в більшості елементів.

У значенні прозорості можна використовувати [заповнювачі](/placeholders) і [змінні](/variables), наприклад `$$panel_opacity`. Плавна поява завершується на рівні прозорості елемента.

# Перемикання елементів кнопкою

Кнопка може показувати й приховувати елементи, як-от панель із правилами на GIF вище. [Змінна](/variables) запам’ятовує, чи показано панель.

1. Клацніть панель правою кнопкою миші й виберіть **Умови завантаження**. Додайте умову [**Значення змінної (змінна FM)**](/conditions#is-variable-value-fm-variable) зі змінною `show_rules` і значенням `true`.
2. Клацніть кнопку правою кнопкою миші й виберіть **Редагувати сценарій дій**.
3. Клацніть область сценарію правою кнопкою миші й виберіть **Додати оператор IF**. Додайте до нього ту саму умову, що й для панелі.
4. Усередині IF додайте [**Задати значення змінної (змінна FM)**](/action-scripts#set-variable-value-fm-variable) із таким значенням:

   ```
   show_rules:false
   ```

5. Клацніть IF правою кнопкою миші й виберіть **Додати оператор ELSE**. Усередині ELSE додайте **Задати значення змінної (змінна FM)** із таким значенням:

   ```
   show_rules:true
   ```

Отже, кожне натискання перемикає значення змінної: показані панелі приховуються, а приховані — з’являються. Усі елементи з однаковою умовою показуються та приховуються разом. Для плавного ефекту встановіть для параметрів **Плавна поява** та **Плавне зникнення** панелі значення **Щоразу**.

Докладніше про IF та ELSE: [Сценарії дій](/action-scripts#if-else-if-and-else).

> [!NOTE]
> Змінні зберігаються після закриття гри, тож під час наступного запуску панель усе ще буде відкрита. Щоб закривати її під час кожного запуску, клацніть змінну правою кнопкою миші в розділі **Керування змінними** й увімкніть **Очищати змінну під час запуску гри**.

## Перемикання між варіантами

Кнопка також може перемикатися між більш ніж двома варіантами, наприклад трьома фонами:

1. У меню **Панель меню -> Налаштування -> Керування змінними** додайте текстову змінну `background` зі значенням `0`.
2. Для трьох [елементів зображення](/elements#image) задайте умову **Значення змінної (змінна FM)** для змінної `background` зі значеннями `0`, `1` і `2`.
3. Для кнопки додайте дію **Задати значення змінної (змінна FM)** із таким значенням. Вона перебирає значення `0`, `1`, `2`, а потім знову починає з `0`:

   ```
   background:{"placeholder":"calc","values":{"decimal":"false","expression":"({"placeholder":"getvariable","values":{"name":"background"}} + 1) % 3"}}
   ```

Щоб додати більше варіантів, змініть останнє `3`. Докладніше про обчислення: [**Калькулятор**](/placeholders#calculator).

# Увімкнення та вимкнення макетів

Щоб показати або приховати цілий макет:

- Параметр **Умови завантаження [для всього макета]** в контекстному меню тла редактора працює так само, як умови для елементів. Див. розділ [Умови для всього макета](/conditions#layout-wide-requirements).
- Дії [**Перемкнути макет**](/action-scripts#toggle-layout), [**Увімкнути макет**](/action-scripts#enable-layout) та [**Вимкнути макет**](/action-scripts#disable-layout) вмикають і вимикають макет за його назвою.

Розмістіть кнопку в іншому макеті, ніж той, який вона вимикає. Інакше кнопка зникне разом із ним, і ввімкнути макет знову буде нічим.
