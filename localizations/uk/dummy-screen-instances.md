# Екрани завантаження світу

Коли ви завантажуєтеся у світ або приєднуєтеся до сервера, ви, ймовірно, помічали екрани, які з’являються там і які ви не можете по-справжньому налаштувати, тому що вони автоматично закриваються.

Щоб відредагувати їх, вам потрібно відкрити їхній екземпляр, який залишатиметься відкритим стільки, скільки вам потрібно. Це можливо, якщо відкрити для них «dummy screen instance».

«Dummy Screen Instances» — це функція FancyMenu, яка дає змогу відкривати ДЕЯКІ екрани, що зникають занадто швидко, щоб їх можна було налаштувати.

Щоб переглянути всі екрани, які можна відкрити через функцію Dummy Screen Instance, натисніть **menu bar -> Tools -> Dummy Screen Instances**. Меню, що відкриється, покаже всі екрани, які можна відкрити як dummy screen instance. **Клацання лівою кнопкою** на екранах у меню відкриє для вас їхній dummy instance, щоб ви могли налаштовувати їх без поспіху.

Наприклад, під час входу у світ або на сервер під час завантаження з’являються щонайменше два екрани:

- Level Loading Screen (також World Loading Screen)
- Generic Dirt Message Screen (також Dirt Message Screen)

> **Important:** «World Loading Screen» — це не те саме, що «Game Loading Screen» (також Splash Screen або Resource Reloading Screen). «Game Loading Screen» можна налаштувати за допомогою **Drippy Loading Screen**, який є доповненням для FancyMenu.
