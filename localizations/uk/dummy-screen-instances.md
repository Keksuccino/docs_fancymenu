# Екрани завантаження світу

Коли ви завантажуєтеся у світ або приєднуєтеся до сервера, ви, мабуть, помічали екрани, які там з’являються і які не можна особливо налаштувати, бо вони автоматично закриваються.

Щоб їх відредагувати, вам потрібно відкрити їхній екземпляр, який залишатиметься відкритим стільки, скільки потрібно. Це можна зробити, відкривши для них "dummy screen instance".

"Dummy Screen Instances" — це функція FancyMenu, яка дає змогу відкривати ДЕЯКІ екрани, що зникають занадто швидко, щоб їх можна було налаштувати.

Щоб побачити всі екрани, які можна відкрити через функцію Dummy Screen Instance, натисніть **menu bar -> Tools -> Dummy Screen Instances**. У меню, що відкриється, показано всі екрани, які можна відкрити як dummy screen instance. **Лівий клік** по екранах у меню відкриє їхній dummy-екземпляр, у якому ви зможете налаштовувати все без поспіху.

Наприклад, під час приєднання до світу або сервера під час завантаження з’являються щонайменше два екрани:

- Level Loading Screen (також відомий як World Loading Screen)
- Generic Dirt Message Screen (також відомий як Dirt Message Screen)

> [!WARNING]
> **Важливо:** "World Loading Screen" — це не те саме, що "Game Loading Screen" (також відомий як Splash Screen або Resource Reloading Screen). "Game Loading Screen" можна налаштувати за допомогою **Drippy Loading Screen**, який є доповненням для FancyMenu.
