# Відкриття GUI за допомогою команди

FancyMenu постачається з командою, яка дозволяє відкривати стандартні та кастомні GUI через команду.
Ви навіть можете віддалено відкривати GUI для **інших гравців**, якщо встановити FancyMenu і на **сервері, і на клієнтах**.

Щоб відкрити GUI, просто використайте команду `/openguiscreen <screen_identifier> <target_player>`.

Замініть `<screen_identifier>` на фактичний ідентифікатор меню GUI, яке ви хочете відкрити.
Це може бути ідентифікатор вашого Custom GUI (створеного за допомогою FancyMenu) або звичайний ідентифікатор меню стандартного/модового GUI.

Щоб дізнатися **ідентифікатор меню стандартних/модових GUI**, відкрийте меню, ідентифікатор якого хочете дізнатися, та увімкніть **debug overlay** FancyMenu через **Customization -> Debug Overlay**, після чого ви зможете натиснути на ідентифікатор, показаний у першому рядку, щоб скопіювати його до буфера обміну.

![copy_identifier](https://github.com/Keksuccino/FancyMenu/assets/35544624/dd6c53d9-d2bd-4810-be03-3741e326bd5a)

Залиште аргумент `<target_player>` порожнім, щоб відкрити GUI для вашого клієнта, або вкажіть гравця (чи кількох гравців), для яких потрібно відкрити GUI.
Пам’ятайте, що в іншого гравця FancyMenu має бути встановлено на клієнті.

Ця команда працюватиме не для кожного екрана, особливо для екранів модів. Якщо команда не зможе відкрити екран, буде показано помилку. У такому разі ви мало що можете зробити, оскільки, ймовірно, це екран, який занадто складний для автоматичного відкриття FancyMenu.

Я також більше не додаватиму сумісність для екранів модів вручну, оскільки створення сумісності для всіх модів, які існують, забрало б у мене вічність, вибачте.

# Закриття GUI за допомогою команди

У рідкісному випадку, якщо це вам потрібно, також є команда `/closeguiscreen <target_player>`, яка закриває поточний екран.
