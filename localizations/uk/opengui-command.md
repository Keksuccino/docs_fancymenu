# Відкриття інтерфейсів командою

Команда `/openguiscreen` відкриває стандартні, модифіковані та [власні інтерфейси](/custom-guis). Якщо FancyMenu встановлено на сервері та в клієнтах гравців, командою можна відкрити інтерфейс для інших гравців.

Щоб відкрити інтерфейс, використовуйте `/openguiscreen <screen_identifier> [<target_players>]`.

Замініть `<screen_identifier>` на точний ідентифікатор власного, стандартного або модифікованого інтерфейсу. Ідентифікатор чутливий до регістру.

Щоб дізнатися ідентифікатор, відкрийте потрібний інтерфейс і ввімкніть налагоджувальну панель клавішами **CTRL + ALT + D**. Виберіть ідентифікатор у першому рядку, щоб скопіювати його. Докладніше див. у розділі [Ідентифікатори екранів](/screen-identifiers).

![copy_identifier](https://github.com/Keksuccino/FancyMenu/assets/35544624/dd6c53d9-d2bd-4810-be03-3741e326bd5a)

Не вказуйте `[<target_players>]`, щоб відкрити інтерфейс для себе. Щоб відкрити його для одного або кількох гравців, укажіть ім’я гравця або селектор, наприклад `@a`. Для використання аргументу цільових гравців потрібен рівень дозволу 2 (ігровий майстер / OP рівня 2), навіть якщо вказуєте себе. Крім того, у кожного цільового гравця має бути встановлено FancyMenu на клієнті.

Не всі екрани модифікацій можна створити безпосередньо. Якщо цільовий екран не підтримується, FancyMenu покаже помилку. У локальному макеті використовуйте дію [**Імітувати кнопку стандартного інтерфейсу/інтерфейсу модифікації**](/action-scripts#mimic-vanillamod-button) для віджета, який зазвичай відкриває цей екран.

# Закриття інтерфейсів командою

У рідкісних випадках може знадобитися команда `/closeguiscreen [<target_players>]`, яка закриває поточний екран. Якщо цільових гравців не вказано, команда діє на вас. Для використання аргументу цільових гравців потрібен рівень дозволу 2.
