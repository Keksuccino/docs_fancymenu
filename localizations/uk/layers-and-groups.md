# Шари та групи

Відкрийте віджет **Шари** через **Вікно -> Віджети редактора -> Шари**.

# Порядок шарів

Перетягуйте шари в списку, щоб змінити порядок їхнього відображення. Ви також можете клацнути елемент правою кнопкою миші та скористатися командами **Перемістити на один шар вгору** або **Перемістити на один шар вниз**.

Елементи [Player Entity](./elements#player-entity) та [Item](./elements#item) можуть мати обмеження відображення, які не дають застосовувати звичайне впорядкування шарів.

# Групи

Групи впорядковують пов’язані шари та дають змогу переміщувати або приховувати їх разом.

- Створюйте та перейменовуйте групи.
- Перейменовуйте окремі шари.
- Перетягуйте шари в групи та з груп.
- Перетягуйте групу, щоб перемістити всі її шари в порядку.
- Згортайте або розгортайте групу.
- Показуйте або приховуйте кожен шар у групі.
- Видаляйте групу, не видаляючи її шари.

Належність до групи та стан згортання зберігаються разом із макетом.
