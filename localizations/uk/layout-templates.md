# Шаблони макетів

Якщо ви хочете завантажити шаблони дизайну для FancyMenu або одного з його доповнень, як-от SpiffyHUD чи Drippy Loading Screen, найкраще місце для пошуку — канал [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) на [Discord-сервері Kekscord](https://discord.gg/rhayah27GC) (офіційному Discord-сервері Keksuccino для підтримки модів). У цьому каналі спільнота публікує повністю налаштовані збірки FancyMenu з посиланнями для їх завантаження.

Усі публікації із шаблонами мають однакову структуру. Кожна з них повинна містити посилання для завантаження повної збірки FancyMenu — або у вигляді файлу профілю (`.fmp`), або у вигляді папки `fancymenu`.

> [!CAUTION]
> Шаблони від спільноти можуть виконувати дії. Імпортуйте їх лише з джерел, яким довіряєте.

# Встановлення шаблонів

Шаблони — це повністю налаштовані збірки FancyMenu, які зазвичай є дуже складними, тому не рекомендується намагатися об'єднати шаблон з наявною збіркою. Натомість додайте його як окремий [профіль](./profiles):

- **Файл `.fmp`:** відкрийте **панель меню -> Налаштування -> Профілі** та [імпортуйте](./profiles#importing) файл, наприклад перетягнувши його у вікно.
- **Папка `fancymenu`:** [додайте папку як профіль](./profiles#adding-setup-folders).

Після цього виберіть шаблон у вікні «Профілі» та натисніть **Завантажити профіль**. Ваша поточна збірка залишиться доступною як окремий профіль, тож ви завжди зможете повернутися до неї.

# Редагування шаблонів або використання їх у власних проєктах

Більшість шаблонів у цьому каналі можна редагувати й навіть використовувати у власних проєктах, наприклад у модпаках, але дуже важливо **перевірити публікацію із шаблоном, щоб дізнатися, що саме вам дозволено з ним робити**!

Не всі автори дозволяють робити з шаблонами все.
