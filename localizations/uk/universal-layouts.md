# Універсальні макети

Універсальний макет розглядається для кожного підтримуваного екрана, для якого ввімкнено налаштування екрана. Він не застосовується до [заблокованих](/incompatibility-list#screens-where-customization-is-intentionally-disabled) або інших виключених екранів.

Використовуйте універсальні макети для спільних елементів, як-от логотипів, навігації, накладок або [аудіоелементів](/elements#audio), які мають відображатися на кількох екранах.

# Створення макета

1. Відкрийте підтримуваний екран і покажіть панель меню FancyMenu.
2. Виберіть **Макети -> Створити -> Для всіх екранів [Універсальний]**.
3. Додайте елементи та налаштуйте їх.
4. Збережіть макет.

Для звичайних екранів також потрібно ввімкнути **Налаштування поточного екрана**. Глобального перемикача для ввімкнення налаштувань на всіх екранах немає, оскільки модифіковані екрани, які не підтримуються, можуть працювати некоректно після налаштування.

# Обмеження для екранів

Відкрийте налаштування універсального макета через контекстне меню фону редактора.

- **Білий список:** макет застосовується лише до перелічених ідентифікаторів екранів.
- **Чорний список:** макет застосовується до кожного відповідного екрана, крім екранів із переліченими ідентифікаторами.

Скористайтеся пунктом **Налаштування -> Копіювати ідентифікатор поточного екрана**, щоб скопіювати [ідентифікатор екрана](/screen-identifiers).

Також можна додати [вимоги для всього макета](/conditions#layout-wide-requirements), щоб контролювати, коли застосовується макет.

# Порядок макетів

Відповідні універсальні макети та макети для конкретних екранів об’єднуються й накладаються один на одного відповідно до **Індексу макета**. Макети з нижчими індексами застосовуються першими; параметри макетів, доданих пізніше, можуть перевизначати попередні. Якщо індекси однакові, універсальні макети додаються перед макетами для конкретних екранів.
