# Універсальні макети

Універсальний макет застосовується до кожного підтримуваного екрана, для якого ввімкнено налаштування екрана. Він не застосовується до [заблокованих](./incompatibility-list#screens-where-customization-is-intentionally-disabled) або іншим чином виключених екранів.

Використовуйте універсальні макети для спільних елементів, як-от логотипи, навігація, накладки або [аудіоелементи](./elements#audio), які мають залишатися доступними на кількох екранах.

# Створення макета

1. Відкрийте підтримуваний екран і відкрийте панель меню FancyMenu.
2. Виберіть **Layouts -> New -> For All Screens [Universal]**.
3. Додайте та налаштуйте елементи.
4. Збережіть макет.

Для звичайних екранів усе одно потрібно ввімкнути **Current Screen Customization**. Глобального перемикача для ввімкнення всіх екранів немає, оскільки непідтримувані екрани модифікацій можуть працювати некоректно після налаштування.

# Обмеження списку екранів

Відкрийте налаштування універсального макета через контекстне меню фону редактора.

- **Whitelist:** макет застосовується лише до вказаних ідентифікаторів екранів.
- **Blacklist:** макет застосовується до кожного відповідного екрана, крім указаних ідентифікаторів.

Скористайтеся пунктом **Customization -> Copy Identifier of Current Screen**, щоб скопіювати [ідентифікатор екрана](./screen-identifiers).

Також можна додати [загальні для макета вимоги](./conditions#layout-wide-requirements), щоб визначити, коли застосовувати макет.

# Порядок макетів

Доступні універсальні макети та макети для конкретних екранів об’єднуються й накладаються відповідно до **індексу макета**. Макети з меншими індексами застосовуються першими; пізніші параметри, які допускають накладання, можуть перевизначати попередні. Якщо індекси однакові, універсальні макети збираються перед макетами для конкретних екранів.
