# Команди

FancyMenu додає до гри кілька команд, які можуть бути дуже корисними в поєднанні з іншими модами, наприклад FTB Quests.

> [!WARNING]
> FancyMenu має бути встановлено на **СЕРВЕРІ** (і на клієнті), щоб використовувати команди в багатокористувацькій грі!

## Цільові гравці та права доступу

Аргумент цільового гравця для `/openguiscreen`, `/closeguiscreen` і `/fmlayout` є необов’язковим. Якщо гравець його не вказує, команда застосовується до цього гравця. Якщо ціль указано, можна використовувати звичайні імена гравців і селектори, наприклад `@a`.

- Якщо передати цільовий аргумент до `/openguiscreen` або `/closeguiscreen`, потрібен **рівень дозволу 2** (Game Master / рівень OP 2), навіть якщо він указує на джерело команди.
- Якщо передати цільовий аргумент до `/fmlayout`, потрібен **рівень дозволу 3** (Admin / рівень OP 3), навіть якщо він указує на джерело команди.
- Кожен підкоманда `/fmdata` вимагає **рівень дозволу 2** (Game Master / рівень OP 2).

Для трьох команд із необов’язковою ціллю пропуск цільового аргументу працює лише тоді, коли джерелом команди є гравець. Консоль сервера має вказати ціль і відповідати вимогам до прав доступу для цільового аргументу.

## /openguiscreen

Команда `/openguiscreen` відкриває Vanilla-, модове або [Custom GUI](./custom-guis). Вона може націлюватися на інших гравців, якщо FancyMenu встановлено на сервері та в їхніх клієнтах.

Див. [Відкриття GUI через команду](./opengui-command) та [Ідентифікатори екранів](./screen-identifiers).

Не кожен екран мода можна створити безпосередньо. FancyMenu показує помилку, коли цільовий екран не підтримується. У локальному макеті використовуйте [**Mimic Vanilla/Mod Button**](./action-scripts#mimic-vanillamod-button-mimicbutton) на віджеті, який зазвичай його відкриває.

**Використання:** `/openguiscreen <screen_identifier> [<target_players>]`

## /closeguiscreen

Команда `/closeguiscreen` закриває поточний екран для джерела команди або вибраних гравців. Вона корисна з модами квестів, подій або автоматизації, які можуть виконувати команди.

**Використання:** `/closeguiscreen [<target_players>]`

## /fmlayout

Команда `/fmlayout` задає, чи ввімкнено макет на одному або кількох клієнтах. Використовуйте назву макета точно так, як вона відображається у FancyMenu, а назви з пробілами беріть у лапки.

**Використання:** `/fmlayout <layout_name> <true|false> [<target_players>]`

Приклади:

- `/fmlayout quest_complete true` вмикає `quest_complete` для гравця, який виконує команду.
- `/fmlayout quest_complete false @a` вимикає його для кожного онлайн-гравця. Вказання цільового аргументу потребує рівня дозволу 3.

## /fmvariable

Команда `/fmvariable` встановлює та читає [змінні FancyMenu](./variables).

Щоб виконати цю команду від імені іншого гравця, використайте ванільну команду `/execute as`:
`/execute as ExamplePlayer run fmvariable ...`

**Використання:**

- `/fmvariable get <variable_name>`
- `/fmvariable set <variable_name> <send_chat_feedback> <set_to_value>`

### Отримати

Щоб **отримати значення змінної**, використайте підкоманду `get` ось так:
`/fmvariable get some_variable`

Після цього значення цієї змінної буде виведено в чат.

### Встановити

Щоб **встановити змінну**, вкажіть логічний параметр зворотного зв’язку в чаті перед новим значенням:
`/fmvariable set some_variable true new_value`

Аргумент `send_chat_feedback` визначає, чи підтверджує FancyMenu зміну в чаті. Аргумент `set_to_value` споживає решту команди, тому значення може містити пробіли. Наприклад, `/fmvariable set greeting false Hello from FancyMenu` зберігає `Hello from FancyMenu` без надсилання повідомлення про успіх.

## /fmdata

Команда `/fmdata` надсилає користувацькі дані між сервером і клієнтами FancyMenu, керує слухачами на боці сервера та налаштовує дані, які надсилаються під час входу гравців. Кожна підкоманда `/fmdata` вимагає рівень дозволу 2.

Див. [FM Data](./fm-data) для всіх підкоманд, синтаксису та прикладів.
