# Команди

FancyMenu додає до гри кілька команд, які можуть бути дуже корисними у поєднанні з іншими модами, такими як FTB Quests.

> FancyMenu має бути на **СЕРВЕРІ** (і клієнті), щоб використовувати команди в багатокористувацькій грі!
{.is-warning}

## /openguiscreen

Команда `/openguiscreen` дає змогу відкривати GUI (ванільні/модовані та власні GUI).
Вона навіть може віддалено відкривати GUI для інших гравців, якщо FancyMenu встановлено і на сервері, і на клієнтах.

Докладніше про цю команду дивіться на сторінці [Відкриття GUI за допомогою команди](/opengui-command).

Ця команда не працюватиме для кожного екрана, особливо для екранів модів. Якщо команді не вдасться відкрити екран, буде показано помилку. У такому разі ви мало що можете зробити, бо, ймовірно, це екран, який занадто складний для автоматичного відкриття FancyMenu.

Також я більше не додаватиму сумісність для екранів модів вручну, адже додавання підтримки для всіх існуючих модів зайняло б у мене вічність, вибачте.

**Використання:** `/openguiscreen <screen_identifier> <target_player>`

## /closeguiscreen

Команда `/closeguiscreen` дає змогу закрити поточне GUI.

Що? Ви скажете, це абсолютно марно?
Ну так, але насправді ні.

Ця команда корисна, коли ви використовуєте моди, які запускають команди під час певних дій.
Тож так, ця команда абсолютно марна без інших модів, але може бути дуже корисною, якщо у вас встановлено потрібні моди!

**Використання:** `/closeguiscreen <target_player>`

## /fmvariable

Команда `/fmvariable` дає змогу встановлювати та отримувати змінні FancyMenu.

Щоб виконати цю команду від імені іншого гравця на серверах, ви можете скористатися ванільною командою `/execute as`.
Тож припустімо, ви хочете виконати команду `/fmvariable` від імені гравця `ExamplePlayer`. У такому разі введіть:
`/execute as ExamplePlayer run fmvariable...`.

**Використання:** `/fmvariable <get_or_set> <variable_name> [<set_to_value>] [<send_chat_feedback>]`

### Отримати
Щоб **отримати значення змінної**, використайте підкоманду `get` ось так:
`/fmvariable get some_variable`

Після цього значення цієї змінної буде виведено у ваш чат.

### Встановити
Щоб **встановити змінну**, використайте підкоманду `set` ось так:
`/fmvariable set some_variable new_value true`

Останній аргумент тут визначає, чи хочете ви отримувати зворотний зв’язок у чаті, тобто чи має ця команда виводити повідомлення у ваш чат.
