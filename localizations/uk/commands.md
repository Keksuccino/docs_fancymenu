# Команди

FancyMenu додає до гри кілька команд, які можуть бути дуже корисними в поєднанні з іншими модами, наприклад FTB Quests.

> [!WARNING]
> Щоб використовувати команди в багатокористувацькій грі, FancyMenu має бути встановлений на **СЕРВЕРІ** (і на клієнтах)!

## Цільові гравці та дозволи

Аргумент гравця-цілі в командах `/openguiscreen`, `/closeguiscreen` і `/fmlayout` необов’язковий. Якщо гравець його не вказує, команда діє на цього гравця. Якщо ціль указано, можна використовувати звичайні імена гравців і селектори, як-от `@a`.

- Щоб указати аргумент цілі в команді `/openguiscreen` або `/closeguiscreen`, потрібен **рівень дозволів 2** (ігровий майстер / OP рівня 2), навіть якщо в ньому вказано джерело команди.
- Щоб указати аргумент цілі в команді `/fmlayout`, потрібен **рівень дозволів 3** (адміністратор / OP рівня 3), навіть якщо в ньому вказано джерело команди.
- Для кожної підкоманди `/fmdata` потрібен **рівень дозволів 2** (ігровий майстер / OP рівня 2).

У трьох командах із необов’язковою ціллю пропустити її можна лише тоді, коли джерелом команди є гравець. У консолі сервера потрібно вказати ціль і мати необхідний рівень дозволів для її аргументу.

## /openguiscreen

Команда `/openguiscreen` відкриває стандартний, модифікований або [користувацький графічний інтерфейс](/custom-guis). Вона може відкривати інтерфейси для інших гравців, якщо FancyMenu встановлений на сервері та їхніх клієнтах.

Див. [Відкриття інтерфейсів командами](/opengui-command) і [Ідентифікатори екранів](/screen-identifiers).

Не кожен екран мода можна створити безпосередньо. Якщо цільовий екран не підтримується, FancyMenu покаже помилку. У локальному макеті скористайтеся дією [**Імітувати стандартну кнопку / кнопку мода**](/action-scripts#mimic-vanillamod-button) для віджета, який зазвичай його відкриває.

**Використання:** `/openguiscreen <screen_identifier> [<target_players>]`

## /closeguiscreen

Команда `/closeguiscreen` закриває поточний екран для джерела команди або вибраних гравців. Вона стане в пригоді з модами для завдань, подій або автоматизації, які можуть виконувати команди.

**Використання:** `/closeguiscreen [<target_players>]`

## /fmlayout

Команда `/fmlayout` вмикає або вимикає макет на одному чи кількох клієнтах. Указуйте назву макета точно так, як вона відображається у FancyMenu, а назви з пробілами беріть у лапки.

**Використання:** `/fmlayout <layout_name> <true|false> [<target_players>]`

Приклади:

- `/fmlayout quest_complete true` вмикає макет `quest_complete` для гравця, який виконує команду.
- `/fmlayout quest_complete false @a` вимикає його для всіх гравців онлайн. Щоб указати аргумент цілі, потрібен рівень дозволів 3.

## /fmvariable

Команда `/fmvariable` задає та зчитує [змінні FancyMenu](/variables).

Щоб виконати цю команду від імені іншого гравця, скористайтеся стандартною командою `/execute as`:
`/execute as ExamplePlayer run fmvariable ...`

**Використання:**

- `/fmvariable get <variable_name>`
- `/fmvariable set <variable_name> <send_chat_feedback> <set_to_value>`

### Отримання значення

Щоб **отримати значення змінної**, скористайтеся підкомандою `get` ось так:
`/fmvariable get some_variable`

Значення цієї змінної буде виведено в чат.

### Задання значення

Щоб **задати змінну**, укажіть логічне значення для зворотного зв’язку в чаті перед новим значенням:
`/fmvariable set some_variable true new_value`

Аргумент `send_chat_feedback` визначає, чи підтвердить FancyMenu зміну в чаті. Аргумент `set_to_value` охоплює решту команди, тому значення може містити пробіли. Наприклад, команда `/fmvariable set greeting false Hello from FancyMenu` збереже значення `Hello from FancyMenu` і не надішле повідомлення про успішне виконання.

## /fmdata

Команда `/fmdata` надсилає користувацькі дані між сервером і клієнтами FancyMenu, керує прослуховувачами на сервері, налаштовує дані, що надсилаються під час входу гравців, а також експортує ці налаштування для [чатів зі ШІ](/export-for-ai#servers). Для кожної підкоманди `/fmdata` потрібен рівень дозволів 2.

Див. [FM Data](/fm-data), щоб ознайомитися з усіма підкомандами, синтаксисом і прикладами.
