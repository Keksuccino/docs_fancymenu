# Chargement fluide du monde

Le chargement fluide du monde prend une capture d’écran lorsque vous quittez un monde ou un serveur, puis l’utilise comme arrière-plan de chargement la prochaine fois.

Cela rend les transitions de chargement plus fluides, car l’écran de chargement correspond à ce que vous verrez une fois le chargement terminé.

# Où le trouver

Ouvrez la **barre de menu** de FancyMenu pendant que vous **n’êtes pas** dans l’éditeur de disposition, puis allez dans **Personnalisation -> Personnalisations globales**.

# Activer / Désactiver

1. Ouvrez **Personnalisation -> Personnalisations globales**.
2. Recherchez **Chargement fluide du monde**.
3. Réglez-le sur **Activé** ou **Désactivé**.

# Fonctionnement

- Lorsqu’il est activé, FancyMenu enregistre une capture d’écran lorsque vous quittez un monde/serveur.
- Au chargement suivant, cette capture d’écran est utilisée comme arrière-plan de chargement.
- Première utilisation : si aucune capture d’écran n’existe encore, rien ne s’affichera tant que vous n’aurez pas quitté un monde/serveur une première fois.
