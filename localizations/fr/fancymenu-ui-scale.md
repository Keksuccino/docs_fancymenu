# L’échelle de l’interface de FancyMenu

L’interface de FancyMenu (comme la barre de menu et les menus contextuels) utilise une échelle séparée qui n’est pas liée à l’échelle normale de l’interface graphique de Minecraft.

Si l’interface de FancyMenu vous paraît trop petite ou trop grande, vous pouvez modifier l’échelle de l’interface via **barre de menu -> Personnalisation -> Paramètres -> Interface de FancyMenu**.

Lorsque l’échelle de l’interface est réglée sur **Auto**, la plus petite échelle automatique est `1.25`. Vous pouvez sélectionner manuellement l’échelle `1`.

La seule exception à cela concerne les véritables écrans complets ajoutés par FancyMenu, comme l’écran de gestion des variables ou l’éditeur de mise en page. Ces écrans utilisent, dans la plupart des cas, l’échelle normale de l’interface graphique de Minecraft, mais il est possible que certains écrans utilisent une logique de mise à l’échelle automatique différente afin de s’afficher automatiquement à une échelle plus petite lorsque la fenêtre serait autrement trop petite pour contenir tout le contenu de l’écran.
