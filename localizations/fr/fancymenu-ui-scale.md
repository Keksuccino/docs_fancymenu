# Échelle de l’interface de FancyMenu

L’interface de FancyMenu (comme la barre de menu et les menus contextuels) utilise une échelle distincte qui n’est pas liée à l’échelle GUI normale de Minecraft.

Si l’interface de FancyMenu vous paraît trop petite ou trop grande, vous pouvez modifier son échelle via **barre de menu -> Personnalisation -> Paramètres -> Interface de FancyMenu**.

FancyMenu 3.9.0 ajoute davantage de choix d’échelle d’interface. Lorsque l’échelle de l’interface est réglée sur **Auto**, la plus petite échelle automatique est désormais `1.25` ; vous pouvez toujours choisir manuellement l’échelle `1` si vous le préférez.

La seule exception concerne les écrans plein écran ajoutés par FancyMenu, comme l’écran de gestion des variables ou l’éditeur de mise en page. Dans la plupart des cas, ces écrans utilisent l’échelle GUI normale de Minecraft, mais il est possible que certains écrans utilisent une logique de mise à l’échelle automatique différente afin de s’afficher à une échelle plus petite lorsque la fenêtre serait autrement trop petite pour contenir tout le contenu de l’écran.
