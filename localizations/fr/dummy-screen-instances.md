# Écrans de chargement du monde

Lorsque vous chargez un monde ou rejoignez un serveur, vous avez probablement remarqué que des écrans s’y affichent sans que vous puissiez vraiment les personnaliser, car ils se ferment automatiquement.

Pour les modifier, vous devez ouvrir une instance de ces écrans qui restera ouverte aussi longtemps que vous le souhaitez, ce qui est possible en ouvrant une « instance d’écran factice ».

Les « instances d’écran factices » sont une fonctionnalité de FancyMenu qui permet d’ouvrir CERTAINS écrans qui disparaissent trop vite pour qu’on puisse les personnaliser.

Pour voir tous les écrans qui peuvent être ouverts via la fonctionnalité d’instance d’écran factice, cliquez sur **barre de menu -> Outils -> Instances d’écran factices**. Le menu qui s’ouvre affiche tous les écrans que vous pouvez ouvrir en tant qu’instance d’écran factice. Un **clic gauche** sur les écrans dans le menu ouvrira pour vous une instance factice afin que vous puissiez la personnaliser tranquillement.

Par exemple, lors de la connexion à un monde ou à un serveur, au moins deux écrans s’affichent pendant le chargement :

- Écran de chargement du niveau (aussi appelé écran de chargement du monde)
- Écran générique de message sur fond de terre (aussi appelé écran de message sur fond de terre)

> **Important :** L’« écran de chargement du monde » n’est pas le même que l’« écran de chargement du jeu » (aussi appelé écran d’accueil ou écran de rechargement des ressources). L’« écran de chargement du jeu » peut être personnalisé avec **Drippy Loading Screen**, un addon pour FancyMenu.
