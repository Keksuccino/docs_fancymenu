# Écrans de chargement du monde

Lorsque vous chargez un monde ou rejoignez un serveur, vous avez probablement remarqué que des écrans s’y affichent et que vous ne pouvez pas vraiment les personnaliser, car ils se ferment automatiquement.

Pour les modifier, vous devez ouvrir une instance de ces écrans qui restera ouverte aussi longtemps que vous le souhaitez, ce qui est possible en ouvrant une « instance d’écran factice ».

Les « instances d’écran factice » sont une fonctionnalité de FancyMenu qui permet d’ouvrir CERTAINS écrans qui disparaissent trop vite pour pouvoir les personnaliser.

Pour voir tous les écrans qui peuvent être ouverts via la fonctionnalité d’instance d’écran factice, cliquez sur **barre de menu -> Outils -> Instances d’écran factice**. Le menu qui s’ouvre affiche tous les écrans que vous pouvez ouvrir en tant qu’instance d’écran factice. Un **clic gauche** sur les écrans dans le menu ouvrira une instance factice de celui-ci afin que vous puissiez le personnaliser tranquillement.

Par exemple, lors de la connexion à un monde ou à un serveur, au moins deux écrans s’affichent pendant le chargement :

- Écran de chargement du niveau (aussi appelé Écran de chargement du monde)
- Écran de message générique sur fond de terre (aussi appelé Écran de message de terre)

> [!WARNING]
> **Important :** L’« Écran de chargement du monde » n’est pas le même que l’« Écran de chargement du jeu » (aussi appelé Écran de démarrage ou Écran de rechargement des ressources). L’« Écran de chargement du jeu » peut être personnalisé avec **Drippy Loading Screen**, qui est un addon pour FancyMenu.
