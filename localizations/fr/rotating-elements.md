# Éléments rotatifs

La plupart des éléments peuvent être pivotés.

Sélectionnez un élément dans l’éditeur de mise en page. Si la rotation est prise en charge, un guide circulaire et une poignée apparaissent autour de lui. Faites glisser la poignée pour faire pivoter l’élément.

S’il n’y a pas de forme circulaire autour de l’élément, vous ne pouvez pas le faire pivoter.

# Avancé

Vous pouvez également cliquer avec le bouton droit sur l’élément pour définir manuellement les valeurs de rotation via une saisie de texte directe. Cette saisie directe prend en charge les [placeholders](/placeholders), ce qui vous permet de modifier dynamiquement la rotation de l’élément en la combinant avec des placeholders afin d’obtenir les valeurs de variables FancyMenu ou similaires.

# Boutons, curseurs et autres éléments interactifs

La rotation est uniquement visuelle pour les éléments interactifs. Un bouton pivoté continue d’accepter les clics dans sa zone d’origine, non pivotée.
