# Éléments rotatifs

À partir de FancyMenu v3.8.0, il est possible de faire pivoter la **plupart** des éléments !

Pour faire pivoter un élément, sélectionnez-le dans l’éditeur de mise en page et, si vous voyez une forme de cercle autour de l’élément, cela signifie qu’il possède une poignée que vous pouvez saisir pour le faire pivoter autour de son axe.

S’il n’y a pas de forme de cercle autour de l’élément, vous ne pouvez pas le faire pivoter.

# Avancé

Vous pouvez aussi faire un clic droit sur l’élément pour définir manuellement les valeurs de rotation via une saisie textuelle directe. Cette saisie directe prend en charge les [placeholders](/placeholders), ce qui vous permet de modifier dynamiquement la rotation de l’élément en la combinant avec des placeholders afin d’obtenir des valeurs de variables FancyMenu ou similaires.

# Boutons, curseurs et autres éléments interactifs

Dans le cas des éléments interactifs, il est possible de les faire pivoter, mais la rotation est uniquement visuelle. Par exemple, le bouton ne répondra toujours qu’aux clics à l’intérieur de sa zone d’origine, même si la rotation l’a peut-être en partie déplacé hors de cette zone.
