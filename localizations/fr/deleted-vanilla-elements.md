# Supprimer des éléments Vanilla

Vous pouvez masquer tous les éléments par défaut/Vanilla (y compris certains éléments de mod) qui sont visibles dans l’éditeur de mise en page. S’ils sont visibles, faites simplement un **clic droit** dessus, puis cliquez sur **Supprimer**.


# Restaurer des éléments Vanilla supprimés

Pour rendre à nouveau visibles des éléments Vanilla supprimés/masqués, comme des boutons, des logos ou d’autres types d’éléments, ouvrez simplement la mise en page dans laquelle vous les avez supprimés, puis **accédez à la barre de menu -> Élément -> Éléments Vanilla supprimés** et faites un **clic gauche** sur le ou les éléments que vous souhaitez rendre à nouveau visibles.

Si les éléments supprimés n’apparaissent pas dans le menu, c’est que vous avez ouvert la mauvaise mise en page et que vous devez retrouver celle dans laquelle vous les avez supprimés.
