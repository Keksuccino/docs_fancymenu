# Sons et musiques Vanilla

Il est possible d’utiliser les sons et la musique de Minecraft Vanilla dans les éléments Audio et d’autres éléments qui acceptent des fichiers audio OGG.

# Accéder aux ressources sonores Vanilla

Pour accéder aux ressources sonores Vanilla, vous devez connaître leur véritable emplacement de ressource.

Par exemple, la piste musicale `bromeliad.ogg` se trouve dans `assets/minecraft/sounds/music/game/`, donc son emplacement de ressource serait `minecraft:sounds/music/game/bromeliad.ogg`.

Ce site web vous permet de parcourir les assets de Minecraft.
