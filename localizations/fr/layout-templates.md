# Modèles de mise en page

Si vous souhaitez télécharger des modèles de design pour FancyMenu ou l’un de ses modules complémentaires, comme SpiffyHUD ou Drippy Loading Screen, le meilleur endroit où chercher est le salon [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) du [serveur Discord Kekscord](https://discord.gg/rhayah27GC) (le serveur Discord officiel de Keksuccino pour l’assistance concernant les mods). Ce salon contient des configurations FancyMenu complètes créées par la communauté, avec des liens de téléchargement pour chacune d’entre elles.

Toutes les publications de modèles dans ce salon suivent le même format. Elles devraient toutes contenir un lien de téléchargement vers une configuration FancyMenu complète, soit sous forme de fichier de profil (`.fmp`), soit sous forme de dossier `fancymenu`.

> [!CAUTION]
> Les modèles de la communauté peuvent exécuter des actions. Importez-les uniquement depuis des sources auxquelles vous faites confiance.

# Installer des modèles

Les modèles sont des configurations FancyMenu complètes et généralement très complexes. Il est donc déconseillé d’essayer de fusionner un modèle avec votre configuration existante. Ajoutez-le plutôt comme [profil](./profiles) distinct :

- **Fichier `.fmp` :** Ouvrez **barre de menu -> Personnalisation -> Profils** et [importez](./profiles#importing) le fichier, par exemple en le faisant glisser dans la fenêtre.
- **Dossier `fancymenu` :** [Ajoutez le dossier en tant que profil](./profiles#adding-setup-folders).

Sélectionnez ensuite le modèle dans la fenêtre Profils et cliquez sur **Charger le profil**. Votre configuration actuelle reste disponible dans son propre profil, vous pouvez donc toujours y revenir.

# Modifier des modèles ou les utiliser pour des projets

La plupart des modèles publiés dans ce salon vous autorisent à les modifier et même à les utiliser dans vos propres projets, comme des modpacks. Cependant, il est très important de **vérifier dans la publication du modèle ce que vous êtes autorisé à en faire** !

Ils ne vous donnent pas tous l’autorisation de tout faire.
