# Personnalisations globales

Les personnalisations globales sont des ajustements FancyMenu qui s’appliquent à l’interface du jeu dans son ensemble.
Utilisez-les lorsque vous voulez un style/comportement cohérent partout, au lieu de modifier la mise en page de chaque écran séparément.

> [!INFO]
> Contrairement à la plupart des fonctionnalités de personnalisation de FancyMenu, les personnalisations globales fonctionnent même si les personnalisations d’écran normales sont désactivées.
> Elles ne nécessitent **pas** d’activer les personnalisations pour chaque écran, ce qui signifie qu’une seule modification peut affecter tous les écrans immédiatement.

Exemples courants :

- Utiliser un même style de bouton et de curseur pour tous les écrans.
- Remplacer globalement l’arrière-plan du menu, le panorama et la musique du menu.
- Appliquer globalement le comportement de démarrage/fenêtre (échelle de l’interface, plein écran, titre/icône de la fenêtre).
- Remplacer globalement les textures de boutons vanille sans pack de ressources.
- Remplacer globalement la musique de menu vanille sans pack de ressources.

# Où les trouver

Ouvrez la **barre de menu** de FancyMenu pendant que vous n’êtes **pas** dans l’éditeur de mise en page, puis **Personnalisation -> Personnalisations globales**.

# Démarrage rapide

1. Ouvrez **Personnalisation -> Personnalisations globales**.
2. Choisissez une catégorie pour commencer (par exemple **Textures de boutons personnalisées**).
3. Configurez les options de cette catégorie (sélecteurs de ressources, interrupteurs ou champs numériques).
4. Testez le résultat dans plusieurs écrans.
5. Ajustez les paramètres associés (par exemple la transparence, les styles de libellés, les bordures en neuf-patch).

# Ce que vous pouvez personnaliser

## Comportement global et démarrage

- **Intro du jeu** (une vidéo ou une animation d’introduction qui se joue avant l’affichage de l’écran titre)
- **Icônes du monde de l’écran solo**
- **Icônes de serveur de l’écran multijoueur**
- **Chargement fluide du monde** (utilise une capture d’écran du monde comme arrière-plan de l’écran de chargement du monde)
- **Icône de fenêtre personnalisée**
- **Titre de fenêtre personnalisé**
- **Échelle GUI par défaut**
- **Forcer le plein écran au lancement**

## Apparence des boutons

- **Textures de boutons personnalisées** (états Normal/Surligné/Inactif, mode transparent, neuf-patch + tailles de bordure)
- **Libellés des boutons** (soulignement au survol, couleur de base/de survol, échelle, ombre)

## Apparence des curseurs

- **Textures de curseurs personnalisées**
- **Texture d’arrière-plan du curseur** (texture, mode transparent, neuf-patch + tailles de bordure)
- **Textures de poignée du curseur** (états Normal/Surligné/Inactif, neuf-patch + tailles de bordure)
- **Libellés des curseurs** (soulignement au survol, couleur de base/de survol, échelle, ombre)

## Apparence et audio du menu

- **Texture d’arrière-plan du menu personnalisée**
- **Panorama d’arrière-plan du menu personnalisé**
- **Jouer la musique du menu vanille** (activer/désactiver la musique du menu vanille)
- **Pistes musicales de menu personnalisées**
- **Son personnalisé de clic des boutons/curseurs**

# Pistes musicales de menu personnalisées

Utilisez **Pistes musicales de menu personnalisées** pour créer une liste de pistes aléatoire pour les menus.

Les pistes personnalisées configurées remplacent la musique de menu vanille dans les menus.

- Ouvrez **Pistes musicales de menu personnalisées** pour ouvrir **Gérer les pistes musicales du menu**.
- Utilisez **Ajouter une piste** pour ajouter des sources audio.
- Utilisez **Supprimer une piste** pour retirer une entrée.
- Utilisez **Effacer les pistes** pour tout supprimer.
