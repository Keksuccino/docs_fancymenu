# Personnaliser l’écran de chargement

**FancyMenu ne peut pas personnaliser à lui seul l’écran de chargement/intro de Minecraft**. C’est précisément pour cela que nous avons l’extension [Drippy Loading Screen](https://www.curseforge.com/minecraft/mc-mods/drippy-loading-screen) (vous la trouverez aussi [ici](https://modrinth.com/mod/drippy-loading-screen) sur Modrinth).

# Drippy Loading Screen

Si vous venez d’installer l’extension Drippy Loading Screen pour la toute première fois, il vous suffit de cliquer sur le petit onglet mis en évidence ci-dessous afin d’ouvrir l’écran où vous pourrez ensuite [utiliser l’éditeur FancyMenu](https://docs.fancymenu.net) pour personnaliser l’écran de chargement.
