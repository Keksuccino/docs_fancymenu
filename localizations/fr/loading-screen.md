# Écran de chargement

FancyMenu ne personnalise pas l'écran d'accueil/de chargement de Minecraft. Utilisez l'extension [Drippy Loading Screen](https://www.curseforge.com/minecraft/mc-mods/drippy-loading-screen) pour cela.
