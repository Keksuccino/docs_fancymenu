# Personnaliser l’écran de chargement

**FancyMenu ne peut pas personnaliser seul l’écran de chargement/de démarrage de Minecraft**. C’est précisément pour cela que nous avons créé l’extension [Drippy Loading Screen](https://www.curseforge.com/minecraft/mc-mods/drippy-loading-screen) (vous la trouverez également [ici](https://modrinth.com/mod/drippy-loading-screen) sur Modrinth).

> [!IMPORTANT]
>Pour savoir comment utiliser Drippy Loading Screen, veuillez consulter son [wiki](https://github.com/Keksuccino/Drippy-Loading-Screen/wiki).
