# Identifiants des éléments

Chaque élément de FancyMenu possède un identifiant unique qui lui est attribué automatiquement lors de sa création.

Ces identifiants servent à reconnaître les éléments afin que les autres fonctionnalités de FancyMenu, comme les espaces réservés, les actions et les conditions de chargement, puissent communiquer avec eux.

# Obtenir l’identifiant d’un élément

Pour obtenir l’identifiant d’un élément, faites un clic droit sur celui-ci dans l’éditeur, puis cliquez sur **Copier l’ID de l’élément**. L’identifiant est alors copié dans le presse-papiers : vous pouvez le coller là où vous en avez besoin.
