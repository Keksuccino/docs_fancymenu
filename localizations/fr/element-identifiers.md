# Identifiants des éléments

Chaque élément dans FancyMenu possède un identifiant unique qui lui est automatiquement attribué lors de sa création.

Ces identifiants servent, eh bien, à identifier l’élément, afin que les autres parties de FancyMenu, comme les emplacements réservés, les actions et les conditions de chargement, puissent communiquer avec lui.

# Obtenir l’identifiant des éléments

Pour obtenir l’identifiant d’un élément, si vous en avez besoin ailleurs, faites simplement un **clic droit** sur l’élément dans l’éditeur, puis cliquez sur **Copier l’identifiant de l’élément**. Cela copiera l’identifiant de l’élément dans le presse-papiers, afin que vous puissiez facilement le coller là où vous en avez besoin.
