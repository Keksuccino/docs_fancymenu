# Icône et titre de la fenêtre

FancyMenu vous permet de modifier l'icône et le titre de la fenêtre Minecraft.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# Icône personnalisée

Pour définir une icône personnalisée pour la fenêtre Minecraft dans FancyMenu 3.9.0+, allez dans **Personnalisation -> Personnalisations globales** dans la **barre de menu**.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- Les icônes doivent être des fichiers **PNG** (et **ICNS pour macOS**)
- Les icônes doivent contenir au moins **1 pixel transparent** pour ne pas s'afficher de façon glitchée (bug MC/LWJGL)
- Vous devez définir des fichiers valides pour les 3 versions d'icône (16x16, 32x32, macOS) pour activer l'option d'icône personnalisée

> **Encore une fois** : Les icônes doivent contenir au moins **1 pixel transparent** pour ne pas s'afficher de façon glitchée (bug MC/LWJGL). L'icône apparaîtra cassée si elle ne contient pas au moins un pixel complètement transparent !
{.is-danger}


# Titre personnalisé

Pour définir un titre personnalisé pour la fenêtre Minecraft dans FancyMenu 3.9.0+, allez dans **Personnalisation -> Personnalisations globales** dans la **barre de menu**.

![window_title](https://github.com/Keksuccino/FancyMenu/assets/35544624/06ecd207-c2d2-4f7c-83f4-18d94c66c5ff)
