# Icône et titre de la fenêtre

FancyMenu vous permet de modifier l’icône et le titre de la fenêtre de Minecraft.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# Icône personnalisée

Pour définir une icône personnalisée, ouvrez [**Personnalisations globales**](./global-customizations) via **Personnalisation -> Personnalisations globales**.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- Les icônes doivent être des fichiers **PNG** (et **ICNS pour macOS**)
- Les icônes doivent contenir au moins **1 pixel transparent** pour ne pas apparaître bugguées (bug MC/LWJGL)
- Vous devez définir des fichiers valides pour les 3 versions d’icône (16x16, 32x32, macOS) pour activer l’option d’icône personnalisée

> [!CAUTION]
> **Encore une fois** : les icônes doivent contenir au moins **1 pixel transparent** pour ne pas apparaître bugguées (bug MC/LWJGL). L’icône apparaîtra cassée si elle ne contient pas au moins un pixel entièrement transparent !


# Titre personnalisé

Pour définir un titre personnalisé, ouvrez [**Personnalisations globales**](./global-customizations) via **Personnalisation -> Personnalisations globales**.
