# Images

FancyMenu affiche des images à de nombreux endroits, comme dans les éléments Image, les arrière-plans de menus et les textures de boutons. Les formats pris en charge sont les suivants :

- PNG (`.png`) : le meilleur choix pour les images fixes avec transparence.
- JPEG (`.jpg` ou `.jpeg`) : des fichiers plus légers pour les photos, mais sans transparence.
- APNG (`.apng`) et GIF (`.gif`) : des images animées. Voir [Animations](/animations).

FancyMenu distingue les types d’image grâce à leur extension. Le nom du fichier doit donc se terminer par la bonne extension.

> [!TIP]
> FancyMenu utilise vos images telles quelles. Pour qu’elles restent nettes et rapides à charger, consultez [Optimisation des textures](/optimizing-textures).

# Conversion d’images

Les autres formats, comme WebP, ne fonctionnent pas dans FancyMenu. Convertissez-les d’abord, par exemple en ligne :

- [WebP vers PNG](https://convertio.co/webp-png/)
- [JPEG vers PNG](https://jpg2png.com/)
- [PNG vers JPEG](https://www.freeconvert.com/png-to-jpeg) : réduit la taille des images volumineuses, mais supprime leur transparence.

Pour créer ou convertir des animations, consultez [Création d’animations](/animations#making-animations).
