# 全局自定义

全局自定义是会应用到整个游戏 UI 的 FancyMenu 调整。
当你希望所有地方都使用统一的样式/行为，而不是分别编辑每个界面布局时，就可以使用它们。

> [!INFO]
> 与大多数 FancyMenu 自定义功能不同，即使普通的界面自定义已被禁用，全局自定义仍然可用。
> 它们**不需要**为每个界面单独启用自定义，这意味着一次修改就能立刻影响所有界面。

常见示例：

- 为所有界面使用同一套按钮和滑块样式。
- 全局替换菜单背景、全景图和菜单音乐。
- 应用全局启动/窗口行为（GUI 缩放、全屏、窗口标题/图标）。
- 无需资源包即可全局替换原版按钮纹理。
- 无需资源包即可全局替换原版菜单音乐。

# 在哪里找到它们

在**未**进入布局编辑器时，打开 FancyMenu 的**菜单栏**，然后选择 **自定义 -> 全局自定义**。

# 快速开始

1. 打开 **自定义 -> 全局自定义**。
2. 先选择一个类别开始（例如 **自定义按钮纹理**）。
3. 配置该类别中的选项（资源选择器、开关或数值输入）。
4. 在多个界面中测试效果。
5. 进一步微调相关设置（例如透明度、标签样式、九宫格边框）。

# 你可以自定义什么

## 全局行为和启动

- **游戏开场**（在标题界面出现前播放的开场视频或动画）
- **单人界面世界图标**
- **多人界面服务器图标**
- **无缝世界加载**（使用世界截图作为世界加载界面的背景）
- **自定义窗口图标**
- **自定义窗口标题**
- **默认 GUI 缩放**
- **启动时强制全屏**

## 按钮外观

- **自定义按钮纹理**（普通/悬停/禁用状态，透明模式，九宫格 + 边框大小）
- **按钮标签**（悬停时下划线、基础/悬停颜色、缩放、阴影）

## 滑块外观

- **自定义滑块纹理**
- **滑块背景纹理**（纹理、透明模式、九宫格 + 边框大小）
- **滑块手柄纹理**（普通/悬停/禁用状态，九宫格 + 边框大小）
- **滑块标签**（悬停时下划线、基础/悬停颜色、缩放、阴影）

## 菜单外观和音频

- **自定义菜单背景纹理**
- **自定义菜单背景全景图**
- **播放原版菜单音乐**（启用/禁用原版菜单音乐播放）
- **自定义菜单音乐曲目**
- **自定义按钮/滑块点击音效**

# 自定义菜单音乐曲目

使用 **自定义菜单音乐曲目** 为菜单构建一个随机播放的曲目列表。

已配置的自定义曲目会在菜单中替代原版菜单音乐。

- 打开 **自定义菜单音乐曲目** 以进入 **管理菜单音乐曲目**。
- 使用 **添加曲目** 添加音频来源。
- 使用 **移除曲目** 删除一条条目。
- 使用 **清空曲目** 删除所有条目。
