# 全局自定义

全局自定义会应用共享的界面与启动设置，而无需编辑每个界面布局。即使正常的界面自定义被禁用，它们也同样生效。

常见示例：

- 为所有界面使用统一的按钮和滑块样式。
- 全局替换菜单背景、全景图和菜单音乐。
- 应用全局启动/窗口行为（GUI 缩放、全屏、窗口标题/图标）。
- 在不使用资源包的情况下，全局替换原版按钮纹理。
- 在不使用资源包的情况下，全局替换原版菜单音乐。

# 在哪里找到它们

在 **不处于** 布局编辑器时，打开 FancyMenu 的 **菜单栏**，然后选择 **自定义 -> 全局自定义**。

# 你可以自定义什么

## 全局行为与启动

- [**游戏开场**](./game-intro)（在标题界面之前播放的开场视频或动画）
- **单人游戏界面世界图标**
- **多人游戏界面服务器图标**
- [**无缝世界加载**](./seamless-world-loading)（使用最近的世界截图作为加载界面背景）
- [**自定义窗口图标**](./window-customization#custom-icon)
- [**自定义窗口标题**](./window-customization#custom-title)
- **默认 GUI 缩放**
- **启动时强制全屏**

## 按钮外观

- **自定义按钮纹理**（正常/悬停/不可用状态、透明模式、[九宫切片](./nine-slicing-and-tiling) + 边框大小）
- **按钮标签**（悬停时下划线、基础/悬停颜色、缩放、阴影）

## 滑块外观

- **自定义滑块纹理**
- **滑块背景纹理**（纹理、透明模式、[九宫切片](./nine-slicing-and-tiling) + 边框大小）
- **滑块把手纹理**（正常/悬停/不可用状态、[九宫切片](./nine-slicing-and-tiling) + 边框大小）
- **滑块标签**（悬停时下划线、基础/悬停颜色、缩放、阴影）

## 菜单外观与音频

- [**自定义菜单背景纹理**](./menu-backgrounds)
- [**自定义菜单背景全景图**](./panoramas)
- **播放原版菜单音乐**（启用/禁用原版菜单音乐播放）
- [**自定义菜单音乐曲目**](./background-music)
- **自定义按钮/滑块点击音效**

# 自定义菜单音乐曲目

使用 **自定义菜单音乐曲目** 来为菜单构建一个随机播放的曲目列表。

> [!IMPORTANT]
> 全局自定义菜单曲目仅在未加载世界时播放，例如标题界面。若要在世界内播放菜单音频，请使用 [**音频** 元素](./elements#audio)。

已配置的曲目使用音乐声音通道，并在支持的非世界菜单中替代原版菜单音乐。

- 第一首曲目大约在 5 秒后开始播放。
- 后续曲目会在 1 到 30 秒左右的随机延迟后开始播放。
- 曲目会随机选择。
- 当有多首曲目时，上一首曲目不会连续被再次选中。

你可以通过 **自定义菜单音乐曲目** 管理曲目列表：

- 打开 **自定义菜单音乐曲目** 以进入 **管理菜单音乐曲目**。
- 使用 **添加曲目** 来添加音频源。
- 使用 **移除曲目** 来移除一条条目。
- 使用 **清空曲目** 来移除所有条目。
