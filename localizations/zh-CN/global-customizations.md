# 全局自定义

全局自定义可一次性更改所有屏幕上的内容：按钮、滑块、菜单背景、音乐、游戏窗口等。它们无需布局，并且在自定义功能已关闭的屏幕上也能生效。

在布局编辑器之外的任意屏幕上，打开 **菜单栏 -> 自定义 -> 全局自定义**。更改会立即生效并自动保存。

> [!TIP]
> 若只想更改部分屏幕，请使用[布局](/layout-editor)。若想让某些布局中的按钮拥有独特外观，请使用[按钮和滑块模板](/button-slider-templates)。

# 按钮和滑块

这些设置会更改所有屏幕上的所有按钮和滑块，也包括其他模组添加的按钮和滑块。

- 已通过[布局](/layout-editor)或[模板](/button-slider-templates)设置了专属纹理或标签设置的按钮和滑块会保留这些设置。
- 纯图片按钮（例如配方书按钮）会保留原有外观。

## 按钮纹理

**自定义按钮纹理**为按钮的每种状态分别提供一种纹理：

- **正常**
- **悬停**：鼠标位于按钮上，或使用键盘选中按钮时。
- **不可用**：按钮无法点击时。

请为三种状态都设置纹理。未设置纹理的状态会显示 Minecraft 自带的按钮。

同一菜单中还有以下设置：

- **透明背景**会隐藏所有按钮的背景，只显示标签。此设置的优先级高于纹理。
- **按钮背景九宫格切片**可让纹理边缘在任何按钮尺寸下都保持清晰，下方可设置四条边的尺寸。请参阅[九宫格切片与平铺](/nine-slicing-and-tiling)。

> [!TIP]
> 不使用九宫格切片时，纹理会拉伸至每个按钮的尺寸。Minecraft 的按钮高度为 20 像素，宽度大多为 200 或 150 像素。使用九宫格切片后，一张小纹理即可适配所有按钮。

## 滑块纹理

**自定义滑块纹理**分为两部分：

- **滑块背景纹理**：滑块的轨道。使用**设置纹理**进行设置。**透明背景**和**滑块背景九宫格切片**的作用与按钮的对应设置相同。
- **滑块手柄纹理**：可拖动的部分，包含**正常**、**悬停**和**不可用**纹理，以及**滑块手柄九宫格切片**设置。

Minecraft 滑块的手柄宽 8 像素，高度与滑块相同，通常为 20 像素。不使用九宫格切片时，手柄纹理会拉伸至该尺寸。

## 标签

**按钮标签**和**滑块标签**具有相同的设置：

| 设置 | 功能 |
|---|---|
| **悬停时为标签添加下划线** | 鼠标悬停在标签上时，为标签添加下划线。 |
| **标签基础颜色** | 标签的颜色。可使用颜色选择器设置，也可输入 HEX 代码，例如 `#FFF1D6`。 |
| **标签悬停颜色** | 鼠标悬停在标签上时的颜色。 |
| **标签缩放** | 标签的大小。`1` 表示正常大小。 |
| **标签对齐方式** | **左对齐**、**居中**或**右对齐**。 |
| **标签阴影** | 标签后方的深色阴影。关闭后，所有标签都不会显示阴影，包括布局中的标签。 |

通过布局或模板设置了专属标签选项的标签会保留这些设置。对于**标签缩放**和**标签对齐方式**，只有大小为正常且对齐方式为**居中**的标签才会使用全局设置。

## 点击音效

- **自定义按钮点击音效**会替换 Minecraft 按钮和滑块的点击音效。通过布局设置了专属点击音效的按钮会保留该音效。
- **自定义按钮点击音效音量**的范围为 0% 到 100%。Minecraft 声音设置中对应声音通道的音量滑块会在此基础上进一步调节音量。
- **自定义按钮点击音效通道**用于指定播放音效的声音通道，例如音乐。默认使用主音量，即所有声音所用的通道。

# 菜单背景

**自定义菜单背景纹理**是在所有菜单后方显示的图片，但标题屏幕除外：

- 暂停菜单和游戏内的选项界面后方也会显示此背景，因此会遮住游戏世界。物品栏、告示牌和书本仍保持透明。
- **保留背景纹理纵横比**会保留图片的比例。图片仍会铺满整个屏幕，不适配的部分会被裁切。关闭后，图片会拉伸至屏幕大小。

**自定义菜单背景全景图**会替换 Minecraft 的全景图，适用于标题屏幕和加入世界之前显示的所有菜单：

- **选择全景图**可选取一个[全景图](/panoramas)。
- **清除全景图**可恢复 Minecraft 的全景图。
- **当前全景图**会显示已设置的全景图。

如果两项都已设置，纹理会覆盖全景图，因此只有标题屏幕会显示全景图。

布局设置了专属[菜单背景](/menu-backgrounds)的屏幕会改为显示该背景。

# 菜单音乐

- **播放原版菜单音乐**可开启或关闭 Minecraft 的菜单音乐。
- **自定义菜单音乐曲目**会打开**管理菜单音乐曲目**。**添加曲目**可添加声音，**移除曲目**可移除选中的曲目，**清除曲目**可移除所有曲目，**完成**可保存曲目列表。

加入世界之前，这些曲目会在菜单中随机播放，以替代 Minecraft 的菜单音乐。关于这些曲目以及单个屏幕中的音乐，详见：[菜单背景音乐](/background-music)。

# 屏幕和弹窗

| 设置 | 功能 |
|---|---|
| [**游戏开场**](/game-intro) | 在标题屏幕出现之前播放动画或视频。 |
| **单人游戏屏幕世界图标** | 世界列表中世界的图标。关闭后会隐藏这些图标。 |
| **多人游戏屏幕服务器图标** | 服务器列表中服务器的图标。关闭后会隐藏这些图标。 |
| [**无缝世界加载**](/seamless-world-loading) | 离开世界或服务器时截图，并在再次加入时将截图用作加载背景。 |
| **成就提示** | 解锁成就时在右上角显示的弹窗及其音效。关闭后会隐藏这些内容。聊天中的成就消息仍会保留，[成就解锁时](/listeners#on-achievement-unlocked)监听器也仍可正常工作。 |

# 窗口和游戏启动

| 设置 | 功能 |
|---|---|
| [**自定义窗口图标**](/window-customization#custom-icon) | 游戏窗口的图标。需要一个 16x16 PNG 图标、一个 32x32 PNG 图标，以及一个 macOS 图标。 |
| [**自定义窗口标题**](/window-customization#custom-title) | 替换 Minecraft 的窗口标题。支持[占位符](/placeholders)，并会在占位符变化时更新标题。 |
| **默认 GUI 缩放** | 在游戏实例首次启动时设置 Minecraft 的 GUI 缩放比例，例如 `2` 或 `3`。设为 `-1` 可关闭。此功能面向整合包。 |
| **启动时强制全屏** | 每次启动时都将游戏切换为全屏模式。 |

FancyMenu 会在 `fancymenu_data/default_scale_set.fm` 中记录是否已设置**默认 GUI 缩放**。删除该文件后，下次启动时会重新设置缩放比例（请参阅[数据存储位置](/data-storage-locations#instance-data)）。

# 须知

- 全局自定义会保存在 FancyMenu 的 `options.txt` 中，因此属于已加载的[配置档](/profiles)，并会随包含 `config/fancymenu/` 的整合包一同分发。
- 纹理和声音可以是实例中的文件、网页链接或资源包中的文件。请参阅[资源](/resources)。
- **菜单栏 -> 帮助 -> 导出供 AI 使用 -> FancyMenu 设置**会包含这些设置，方便你向 [AI 聊天](/export-for-ai)提问。
