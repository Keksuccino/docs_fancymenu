# 原版元素

FancyMenu 不仅允许你向屏幕中添加新内容，还能自定义原版游戏（Vanilla）和其他模组中的现有元素。

## 原版按钮和滑块（小部件）

要自定义屏幕上的按钮和滑块，请为当前屏幕创建布局（而不是[通用布局](/universal-layouts)），然后在编辑器中右键单击它们。

它们拥有和自定义[按钮](/elements#button)与[滑块](/elements#slider)相同的设置，例如纹理、声音和工具提示。唯一不能更改的是它们的操作脚本：它们会继续执行原本的操作。

原版元素不能放入[可滚动区域](/scrollable-areas)，因为它们属于菜单本身。

### 标签

- **Label** 和 **Hover Label** 会替换按钮文本。对于滑块等其他小部件，这两个选项分别称为 **Widget Text** 和 **Hover Widget Text**。如果不设置这些选项，小部件会保留自己的文本。
- **Label Alignment** 可将标签放置在小部件的**左侧**、**居中**或**右侧**。无论选择哪种对齐方式，宽度超出小部件的标签都会来回滚动。
- **Label Scale**、**Label Base Color**、**Label Hover Color**、**Label Shadow** 和 **Underline Label On Hover** 可更改标签的大小、颜色和阴影。

要一次对齐多个按钮的标签，请按住 `Ctrl` 并逐个单击它们进行选择（参见[选择](/layout-editor#selecting)），然后右键单击其中一个，为所有按钮设置 **Label Alignment**。要设置所有菜单的标签对齐方式，请使用[全局自定义](/global-customizations#labels)中的 **Label Alignment**。也可以使用[模板](/button-slider-templates)为屏幕上的所有按钮设置标签样式。

## 自动点击

原版和模组的小部件都有 **Automated Clicks** 属性。将其设置为大于 `0` 的整数，即可在屏幕加载时按指定次数触发小部件原有的左键点击行为。例如，设置为 `2` 时，每次打开新屏幕后，都会在首次更新期间点击该小部件两次。默认值 `0` 表示禁用自动点击。

这些都是真实的小部件点击：每次点击都可能更改滑块或循环按钮的值、运行小部件的常规回调，甚至打开另一个屏幕。请仔细测试结果，尤其是在设置多次点击时。

要**移动**和**调整大小**原版或模组的小部件，必须先为它们设置锚点。操作方法是：**右键单击**小部件，然后单击 **Anchor Point**。将其设置为除 **Original** 之外的任意值，因为 **Original** 是原版或模组元素的默认锚点。

你也可以通过**右键单击**原版或模组的小部件，然后单击 **Delete** 来将其**隐藏**。它们并不会真正被删除，只是被隐藏了。要恢复它们，请单击 **菜单栏 -> Element -> Deleted Vanilla Elements**，然后**左键单击**想要重新显示的元素。

> [!WARNING]
> 标题屏幕中的 **Copyright** 小部件是唯一**无法**隐藏或删除的元素。这是有意为之。请不要移除版权声明。

## 标题屏幕元素

标题屏幕中有一些并非普通小部件的元素（例如徽标、闪烁文本等），无法移动或自定义。这些元素的设计用途是删除后用自定义元素替换（例如用图像元素替换徽标，或用自定义闪烁文本元素替换原版闪烁文本）。

要删除这些元素，只需右键单击它们。之后若要恢复，请单击 **菜单栏 -> Element -> Deleted Vanilla Elements**，然后**左键单击**想要重新显示的元素。

## 故障排除：编辑器中看不到原版元素

如果在编辑器中看不到原版元素，原因很可能是你使用了**通用布局**，而不是**当前屏幕的布局**。请确保为当前屏幕创建布局。只有在该屏幕启用了自定义功能时，才能为其创建布局。

## 故障排除：自定义设置未生效

如果对原版元素的自定义设置在编辑器之外未生效，通常是因为其他模组覆盖或修改了原版元素所属的父级菜单。

一个模组覆盖屏幕或菜单的典型例子是 **Ice and Fire**，它会覆盖标题屏幕。

菜单未应用自定义设置的问题并不限于原版元素。如果某个模组覆盖或修改了菜单，那么添加到屏幕中的自定义元素也很可能无法应用到该菜单。
