# 常见问题

### 我遇到了问题，需要帮助。我应该提供哪些信息？

为了获得最佳帮助，请尽可能提供更多上下文：
1.  **清晰的问题描述：** 你原本期望发生什么，实际发生了什么？
2.  **你的 `latest.log` 文件：** 这是排查问题最重要的文件。请在实例的 `/logs/` 文件夹中找到它。**不要发送崩溃日志**，除非特别要求；`latest.log` 更有用。你可以使用 https://gist.github.com 之类的网站来分享它。
3.  **你的 Minecraft 版本：**（例如，1.20.1）
4.  **你的模组加载器及其版本：**（例如，Forge 47.2.0、Fabric 0.15.7）
5.  **你的 FancyMenu 版本：**（例如，3.5.2）
6.  **问题的截图或视频** 也会非常有帮助。

### 我该如何更改元素的层级（让某个元素显示在另一个前面或后面）？

*   **自定义 vs. 自定义：** 要更改你自己自定义元素的渲染顺序，请使用 **Layers 小部件**。你可以通过菜单栏打开它：**Window -> Widgets -> Layers**。在这里，你可以在层级结构中上下拖动元素。你也可以右键单击某个元素，并使用“Move One Layer Up/Down”。
*   **自定义 vs. 原版：** 如果你想让所有自定义元素显示在所有原版元素后面（例如把背景图片放到默认按钮后面），请**右键单击编辑器背景**，并切换选项 **“Render Custom Elements Behind Vanilla”**。

### 我可以从通用按钮模板中排除某些按钮吗？

**不可以。如果模板按钮设置了自定义纹理，这些纹理会始终与所有受影响的元素共享。你不能排除单个按钮。**

### 我要怎么让按钮在被点击时执行某些操作？

使用 **Action Script**。
1.  在编辑器中右键单击该按钮。
2.  选择 **Edit Action Script**。
3.  点击 **Add Action**，并从列表中选择操作（例如 `Open Screen or Custom GUI`、`Join Server`、`Set Variable Value`）。
*   更多信息：[Action Scripts](https://docs.fancymenu.net/en/action-scripts)

### 我可以从零创建一个全新的菜单界面吗？

可以，这是通过 **Custom GUIs** 实现的。
1.  在菜单栏中，进入 **Customization -> Custom GUIs -> Manage Custom GUIs**。
2.  点击 **“New GUI”** 并为它提供一个唯一的标识符。
3.  然后你就可以打开这个新的空白界面，为它创建布局，并添加你想要的任何元素。
4.  之后，这个 Custom GUI 可以通过按钮动作打开。
*   更多信息：[Custom GUIs](https://docs.fancymenu.net/en/custom-guis)

### 我启用预加载后，游戏加载时间变得很长。

这是预期行为。在初始启动时预加载大型资源，例如高分辨率动画或声音，自然会增加游戏的加载时间。

### 我的 FMA 动画占用了太多内存！

经典 FMA 文件在包含许多高分辨率帧时可能会消耗大量内存。FancyMenu 3.9.0 新增了 AFMA，它更适合大型或复杂的动画纹理。对于经典 FMA 文件，请保持动画简短，并避免过大的帧数或分辨率。动画适合短小、装饰性的循环效果，而不是播放完整视频。

### FancyMenu 能和 OptiFine 一起使用吗？

不能。OptiFine **不兼容**，并且已知会破坏许多模组，包括 FancyMenu。强烈建议使用现代替代方案，例如 Sodium/Embeddium + Iris/Oculus。
*   更多信息：[OptiFine 替代方案](https://docs.fancymenu.net/en/optifine-alternatives)

### 我的游戏崩溃了。我该如何判断是不是模组冲突？

检查模组冲突的最佳方法是**只运行 FancyMenu 及其依赖项**（Konkrete、Melody）。如果崩溃不再发生，你可以把其他模组分成小组逐步加回去，直到再次出现崩溃，从而找出冲突的模组。

### 我尝试编辑另一个模组的按钮时，它消失了或者不起作用。

这通常意味着那个模组以 FancyMenu 无法交互的非标准方式添加了按钮。这需要那个模组的开发者在他们那边修复。FancyMenu 无法自定义它“看不见”的元素。

### 我可以在服务器上使用 FancyMenu 布局吗？

FancyMenu 是客户端模组。所有布局和自定义都在玩家客户端上进行。你不能把布局放到服务器上强制玩家看到它们。不过，你可以把 `config/fancymenu` 文件夹作为模组包的一部分分发。如果你想在服务器上使用 `/fmvariable` 或 `/openguiscreen` 之类的命令，那么服务器上必须安装 FancyMenu（或其 Spigot 插件）。

### FancyMenu v2（适用于旧版 MC）和 v3 有什么区别？

FancyMenu v3 是一次彻底重写，带来了许多新功能、更稳定的架构和更好的性能。V2 已经过时，不再受支持，而且缺少许多功能，例如高级占位符和脚本。强烈建议在现代 Minecraft 版本（1.18.2+）上使用 v3。加载 V2 布局时可以自动转换为 v3，但可能需要手动修复一些内容。

### 我在哪里可以找到现成的布局和模板？

FancyMenu 社区会在官方 Keksuccino's Mods Discord 服务器（“Kekscord”）的 `#layout-templates` 频道分享布局。

### 我怎样才能让 Player Entity 显示在其他元素后面？

不行。由于 Minecraft 的实体渲染方式，Player Entity 元素几乎总是会渲染在其他 2D 元素前面，而不管层级设置如何。

### 我的 Player Entity 只有一条腿！怎么回事？

这是一个视觉故障，很可能是与另一个会修改玩家动画或模型的模组发生了冲突。检查 Player Entity 的 Pose 设置，看看腿是否被意外旋转或移动了。

### 我该如何在脚本中的操作之间创建延迟？

FancyMenu 3.9.0 为 action scripts 添加了 **Delay** 和 **Execute Later** 块。大多数延迟操作逻辑都可以用它们来实现。对于重复执行的后台逻辑，请使用 [Schedulers](https://docs.fancymenu.net/en/schedulers)。

### 我可以自定义 Create 模组的菜单吗？

不可以。FancyMenu 与 Create 的复杂 GUI 存在已知不兼容问题。为了防止崩溃，Create 界面的自定义功能已被刻意禁用。

### 为什么模组 X 的按钮会在编辑器里消失？

这说明该模组以自定义、非原版的方式添加了按钮。FancyMenu 无法“看见”或与这些元素交互，因此也无法自定义它们。其他模组的开发者需要更改他们添加按钮的方式，才能实现兼容。

### 背景图片和按钮纹理推荐使用什么分辨率？

背景图：标准的 1920x1080（1080p）图片是很好的起点，适合大多数用户并能良好缩放。
按钮：大多数原版按钮大约是 150-200 像素宽、20 像素高。自定义纹理最好也保持类似尺寸，以保持一致性。

### 有没有办法在玩家完成游戏内目标（例如任务）时自动打开菜单或运行命令？
FancyMenu 本身无法检测这类游戏内事件。不过，你可以将它与 FTB Quests 之类的任务模组集成。大多数任务模组都允许你在任务奖励中运行命令。你可以把奖励设置为执行 `/openguiscreen` 或 `/fmvariable` 命令来与你的菜单交互。

### 我要怎样把按钮设为不可用或“变灰”？

你可以使用 Loading Requirements 来控制按钮的激活状态。
在编辑器中右键单击按钮，然后选择“Active State”。
添加一个按钮激活所需满足的条件。例如，要永久禁用一个按钮，你可以添加一个 Is Number 条件，检查 0 是否等于 1（这将始终为假）。
这样按钮就会使用它的“Inactive Background”纹理，并且无法点击。

### 我该如何移除可滚动屏幕上的标题和底部栏（泥土纹理条）？

在 FancyMenu v3 中，你可以自定义这些内容。在布局编辑器中，右键单击编辑器背景，并查找类似“Customize Header/Footer”的选项。你可以把它们的纹理设置为完全透明，从视觉上有效移除它们。请注意，这可能并不适用于所有屏幕，尤其是较旧或高度模组化的界面。

### 我无法创建“当前屏幕”的布局。按钮是灰色的。

你需要先通过 **菜单栏 -> Customization -> Current Screen Customizations -> 切换为 Enabled** 来启用该屏幕的自定义。

### 我在编辑器中打开某个界面时，无法自定义其中的任何元素。它看起来只是一个空白屏幕。

这可能意味着你不小心创建了一个通用布局，而不是一个**用于当前屏幕**的布局。

也可能说明你正在自定义的是一个可滚动屏幕，而这类屏幕默认情况下 FancyMenu 无法自定义。

第三种可能是这是来自某个模组的界面，该模组以非原版方式添加元素，导致 FancyMenu 无法自定义这些元素。

### 我的 Text 元素上有奇怪的灰色框。

这些半透明（低不透明度）的方框/矩形可能出现在 Text 元素的右侧或底部边缘，它们不是 bug。这些是 Text 元素的滚动抓手，因为该元素是可滚动的。

如果你不想让这些方框可见，你可以右键单击该元素并完全禁用滚动；或者，如果你仍然希望该元素可滚动，也可以在同一个右键菜单中把抓手纹理设置为完全透明。

### 我如何在菜单中显示最新的 Minecraft 更新日志？

有一个很棒的 [GitHub 项目](https://github.com/ClaytonTDM/minecraft-changelogs-markdown)，它可以把 Minecraft 的更新日志转换为 FancyMenu 兼容的 Markdown，这样你就可以在菜单中显示最新的 MC 更新日志！它会每日更新以获取新的更新日志。

例如，要在 Text 元素中显示最新的 Minecraft 更新日志，请将其 **Source Mode** 设置为 **Resource**，并将资源来源设置为 **Web**。然后使用以下 URL 作为来源：`https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`

### 将任何元素拉伸到屏幕大小，最简单的方法是什么？

大多数元素的右键菜单中都有一个选项，可以将其水平和垂直拉伸。启用后，它们将始终拉伸到屏幕的完整宽度和/或高度。水平和垂直拉伸可以分别切换。

### 当我用箭头键和 Tab 键在界面中导航时，无法点击按钮或与滑块交互，因为它们在 Text 元素后面或前面。

这是因为 Text 元素默认是可交互的（这样才能抓取滚动条或点击 Markdown 超链接），这意味着它们会消耗鼠标点击和滚轮事件。最好的办法是不要把按钮放到 Text 元素的前后；但如果无法避免，你可以通过**右键单击**该 Text 元素，然后将 **Interactable** 设置为 **Disabled**，让它变得不可交互。请注意，这会使 Text 元素变成静态、不可交互的文本，因此你将不能再滚动它或点击其中的超链接。

### 如何让按钮和滑块在使用键盘的方向键和 Tab 键浏览界面时不再被选中/聚焦？

要让按钮和滑块不能被导航选中，你需要**右键单击**它并将 **Navigable** 设置为 **Disabled**。按钮/滑块仍然可以点击，但你不能再通过方向键/Tab 导航来聚焦它。

如果你想在聊天界面中添加按钮/滑块，这个功能也很有用，这样你仍然可以使用向上箭头键浏览更早的消息，而不会意外选中界面中的按钮/滑块。

### FancyMenu 的某个右键菜单缺少本应存在的选项。

FancyMenu 的右键菜单（即在某处右键单击或与菜单栏交互时打开的菜单）是**可滚动的**。这意味着你可以在鼠标指针悬停在菜单上时使用滚轮上下滚动，从而看到之前不可见的更多选项。

### 我无法自定义标题界面；离开编辑器后它总是显示原版内容。

当你设置自定义菜单背景、移动/编辑按钮或类似内容时，如果在编辑器中一切正常，但一离开编辑器就又恢复成未自定义的版本，这说明有某个模组正在完全或部分覆盖标题界面。FancyMenu 只能自定义原始的 `title_screen`，不能自定义任何被覆盖后的界面，因为 FancyMenu 为该界面添加了特殊兼容。在大多数情况下，如果模组只是向原始界面添加自己的内容（而不是完全覆盖它），那通常没问题；但在某些情况下，这也可能引发问题。

如果某个模组完全覆盖了标题界面，唯一的办法就是找出那个模组，并查看它是否有用于禁用自定义界面的配置项。如果有，就通过配置禁用自定义界面。如果没有，你应该告诉该模组的开发者添加这样的配置项，然后在他们添加之前先移除该模组。你这边没有可行的绕过办法。
