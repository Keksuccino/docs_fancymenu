# 常见问题

### 我遇到了一个问题，需要帮助。我应该提供哪些信息？
为了获得最好的帮助，请尽可能提供更多上下文：
1.  **清晰的问题描述：** 你原本期望发生什么，实际又发生了什么？
2.  **你的 `latest.log` 文件：** 这是排查问题最重要的文件。请在你的实例 `/logs/` 文件夹中找到它。**不要发送崩溃日志**，除非特别要求；`latest.log` 更有用。你可以使用 https://gist.github.com 之类的网站来分享它。
3.  **你的 Minecraft 版本：**（例如 1.20.1）
4.  **你的 Mod 加载器及其版本：**（例如 Forge 47.2.0、Fabric 0.15.7）
5.  **你的 FancyMenu 版本：**（例如 3.5.2）
6.  **问题的截图或视频** 也会非常有帮助。

### 我该如何改变元素的层级（让某个元素显示在另一个元素前面或后面）？
*   **自定义 vs. 自定义：** 要更改你自己的自定义元素的渲染顺序，请使用 **Layers 小部件**。你可以通过菜单栏打开它：**Window -> Widgets -> Layers**。然后，你可以在层级结构中上下拖动元素。你也可以右键单击某个元素，并使用“Move One Layer Up/Down”。
*   **自定义 vs. 原版：** 要让所有自定义元素都渲染在所有原版元素后面（例如把背景图放在默认按钮后面），请**右键单击编辑器背景**，并切换 **“Render Custom Elements Behind Vanilla”** 选项。

### 我可以把某个通用按钮模板里的特定按钮排除掉吗？
**不可以。如果模板按钮设置了自定义纹理，这些纹理会始终与所有受影响的元素共享。你不能排除单个按钮。**

### 我该如何让按钮在被点击时执行某些操作？
使用 **Action Script**。
1.  在编辑器中右键单击按钮。
2.  选择 **Edit Action Script**。
3.  点击 **Add Action**，然后从列表中选择操作（例如 `Open Screen or Custom GUI`、`Join Server`、`Set Variable Value`）。
*   更多信息：[Action Scripts](https://docs.fancymenu.net/en/action-scripts)

### 我可以从零开始创建一个全新的菜单界面吗？
可以，这可以通过 **Custom GUIs** 来完成。
1.  在菜单栏中，前往 **Customization -> Custom GUIs -> Manage Custom GUIs**。
2.  点击 **“New GUI”** 并为其指定一个唯一标识符。
3.  然后你就可以打开这个新的空白界面并为其创建布局，添加任何你想要的元素。
4.  之后，这个 Custom GUI 就可以通过按钮动作打开。
*   更多信息：[Custom GUIs](https://docs.fancymenu.net/en/custom-guis)

### 启用预加载后，我的游戏加载时间变得很长。
这是预期行为。在初始启动期间预加载高分辨率动画或声音等大型资源，自然会增加游戏的加载时间。

### 我的 FMA 动画占用了太多内存！
经典 FMA 文件在包含许多高分辨率帧时会消耗大量内存。FancyMenu 3.9.0 添加了 AFMA，对于大型或复杂的动画纹理要好得多。对于经典 FMA 文件，请保持动画较短，避免使用过大的帧数/分辨率。动画适合短小的装饰性循环，不适合播放完整视频。

### FancyMenu 支持 OptiFine 吗？
不支持。OptiFine **不兼容**，并且已知会破坏许多模组，包括 FancyMenu。强烈建议使用现代替代方案，例如 Sodium/Embeddium + Iris/Oculus。
*   更多信息：[OptiFine Alternatives](https://docs.fancymenu.net/en/optifine-alternatives)

### 我的游戏崩溃了。如何判断是不是模组冲突？
检查模组冲突的最佳方法是**只运行 FancyMenu 及其依赖项**（Konkrete、Melody）。如果崩溃不再发生，你可以把其他模组按小批次逐步加回去，直到再次崩溃，从而找出冲突的模组。

### 另一个模组的按钮在我尝试编辑它时消失了，或者无法工作。
这通常意味着那个模组以一种非标准方式添加了按钮，FancyMenu 无法与其交互。这是另一个模组的开发者需要在其端修复的问题。FancyMenu 不能自定义它“看不见”的元素。

### 我可以在服务器上使用 FancyMenu 布局吗？
FancyMenu 是客户端模组。所有布局和自定义都在玩家客户端上。你不能把布局放到服务器上来强制玩家看到它们。不过，你可以把 `config/fancymenu` 文件夹作为整合包的一部分分发。如果你想在服务器上使用 `/fmvariable` 或 `/openguiscreen` 之类的命令，那么服务器上必须安装 FancyMenu（或其 Spigot 插件）。

### FancyMenu v2（适用于较旧的 MC 版本）和 v3 有什么区别？
FancyMenu v3 是一次全面重写，拥有许多新功能、更稳定的架构和更好的性能。V2 已经过时，不再受支持，并且缺少许多功能，例如高级占位符和脚本。强烈建议在现代 Minecraft 版本（1.18.2+）上使用 v3。加载 V2 布局时可以自动转换为 v3，但可能仍需要一些手动修复。

### 我在哪里可以找到预制布局和模板？
FancyMenu 社区会在官方 Keksuccino's Mods Discord 服务器的 `#layout-templates` 频道分享布局。

### 我怎样才能让 Player Entity 渲染在其他元素后面？
做不到。由于 Minecraft 的实体渲染方式，Player Entity 元素几乎总是会渲染在其他 2D 元素前面，无论层级设置如何。

### 我的 Player Entity 只有一条腿！怎么回事？
这是一种视觉故障，可能是由与其他会修改玩家动画或模型的模组冲突导致的。检查 Player Entity 的 Pose 设置，看看腿是否被意外旋转或移动了。

### 我该如何在脚本中的动作之间创建延迟？
FancyMenu 3.9.0 为动作脚本添加了 **Delay** 和 **Execute Later** 块。大多数延迟动作逻辑都应使用它们。对于重复性的后台逻辑，请使用 [Schedulers](https://docs.fancymenu.net/en/schedulers)。

### 我可以自定义 Create 模组的菜单吗？
不可以。FancyMenu 与 Create 的复杂 GUI 存在已知不兼容问题。为避免崩溃，已故意禁用对 Create 界面的自定义。

### 为什么模组 X 的按钮在编辑器里消失了？
这意味着该模组以自定义的、非原版的方式添加了按钮。FancyMenu 无法“看见”这些元素，也无法与其交互，因此不能自定义它们。另一个模组的开发者需要更改他们添加按钮的方式，才能使其兼容。

### 背景图片和按钮纹理推荐使用什么分辨率？
背景图：标准的 1920x1080（1080p）图片是很好的起点，并且对大多数用户来说缩放效果都很好。
按钮：大多数原版按钮宽约 150-200 像素，高约 20 像素。自定义纹理尽量匹配这个尺寸，有助于保持一致性。

### 有没有办法在玩家完成游戏内目标（例如任务）时自动打开菜单或执行命令？
FancyMenu 本身无法检测这类游戏内事件。不过，你可以将它与 FTB Quests 之类的任务模组集成。大多数任务模组都允许你将命令作为任务奖励执行。你可以把奖励设置为执行 `/openguiscreen` 或 `/fmvariable` 命令，以与你的菜单交互。

### 我该如何让按钮变成不可用或“灰掉”？
你可以使用 Loading Requirements 来控制按钮的可用状态。
在编辑器中右键单击按钮并选择“Active State”。
添加一个按钮需要满足的条件，使其处于可用状态。例如，如果你想永久禁用一个按钮，可以添加一个 Is Number 条件，检查 0 是否等于 1（这永远为假）。
现在该按钮将使用其“Inactive Background”纹理，并且无法点击。

### 我该如何移除可滚动界面上的页眉和页脚（泥土纹理条）？
在 FancyMenu v3 中，你可以自定义这些内容。在布局编辑器中，右键单击编辑器背景，并查找类似“Customize Header/Footer”的选项。你可以把它们的纹理设置为完全透明，从视觉上将其移除。请注意，这在所有界面上都不一定有效，尤其是较旧或高度模组化的界面。

### 我无法创建“当前界面”的布局。按钮是灰色的。
你需要先通过 **菜单栏 -> Customization -> Current Screen Customizations -> 将其切换为 Enabled** 来为该界面启用自定义。

### 在编辑器中打开某个界面时，我无法自定义它的任何元素。它只是一个空界面。

这可能意味着你不小心创建了一个通用布局，而不是一个**针对当前界面**的布局。

也可能是你正在自定义的是一个可滚动界面，而这类界面默认情况下 FancyMenu 无法自定义。

第三种可能是该界面来自一个以非原版方式添加元素的模组，这会导致 FancyMenu 无法自定义这些元素。

### 我的 Text 元素旁边有奇怪的灰色方块。

这些半透明（低不透明度）的方块/矩形可能出现在 Text 元素的右侧或底部边缘，它们不是 bug。这些是 Text 元素的滚动抓手，因为该元素是可滚动的。

如果你不想让这些方块可见，可以右键单击该元素并完全禁用滚动；或者如果你仍然希望该元素可滚动，也可以在同一个右键菜单中把抓手纹理设置为完全透明。

### 我怎样才能在菜单中显示最新的 Minecraft 更新日志？

有一个很棒的 [GitHub 项目](https://github.com/ClaytonTDM/minecraft-changelogs-markdown)，它可以把 Minecraft 的更新日志转换为 FancyMenu 兼容的 Markdown，这样你就可以在菜单中显示最新的 MC 更新日志了！它会每天更新以获取新的更新日志。

例如，要在 Text 元素中显示最新的 Minecraft 更新日志，请将其 **Source Mode** 设置为 **Resource**，并将资源来源设置为 **Web**。然后使用以下 URL 作为源：`https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`

### 将任意元素拉伸到屏幕大小，最简单的方法是什么？

大多数元素的右键菜单中都有一个选项，可以将其水平和垂直拉伸。启用后，它将始终拉伸到屏幕的全宽和/或全高。水平和垂直拉伸可以分别切换。

### 当按钮位于 Text 元素后面或前面时，我无法点击按钮，也无法与滑块交互。

这是因为 Text 元素默认是可交互的（这样才能拖动滚动抓手或点击 Markdown 超链接），这意味着它会占用鼠标点击和滚轮滚动事件。最好的办法是不要把按钮放在 Text 元素的前后，但如果实在无法避免，你可以**右键单击** Text 元素，然后把 **Interactable** 设置为 **Disabled**。请注意，这会使 Text 元素变成静态、不可交互文本，因此你将无法再滚动它，也无法点击超链接。

### 如何让在带有方向键和 Tab 键导航的界面中，按钮和滑块不再被选中/聚焦？

要让按钮和滑块不能被导航到，你需要**右键单击**它们，并将 **Navigable** 设置为 **Disabled**。按钮/滑块仍然可以点击，但你不能再通过方向键/Tab 导航聚焦它们。

如果你想在聊天界面中添加按钮/滑块，这也很有用，这样你仍然可以使用向上方向键滚动查看更早的消息，而不会不小心选中界面中的按钮/滑块。

### FancyMenu 的某个右键菜单缺少一个本该存在的选项。

FancyMenu 的右键菜单（即你在某处右键单击，或与菜单栏交互时打开的菜单）是**可滚动的**。这意味着当鼠标指针停在菜单上时，你可以使用滚轮向上或向下滚动，从而看到更多之前不可见的选项。
