# 常见问题

### 遇到问题需要帮助时，我应该提供哪些信息？

为了获得最有效的帮助，请尽可能提供详细的背景信息：
1.  **清晰描述问题：** 你预期会发生什么？实际发生了什么？
2.  **你的 `latest.log` 文件：** 在 `<game-directory>/logs/latest.log` 中可以找到。**除非有人特别要求，否则不要发送崩溃日志**；`latest.log` 通常包含所需的上下文信息。发布日志时，可以使用 https://gist.github.com 这类网站。
3.  **你的 Minecraft 版本：**（例如 1.20.1）
4.  **你的模组加载器及其版本：**（例如 Forge 47.2.0、Fabric 0.15.7）
5.  **你的 FancyMenu 版本：**（例如 3.5.2）
6.  **问题的截图或视频**也会很有帮助。

> [!TIP]
> 要向 Alice 或其他 AI 求助？请附上无法正常工作的内容的 [AI 导出](/export-for-ai)。这样 AI 就能准确了解你的设置，而且导出内容中已经包含你的 Minecraft、模组加载器和 FancyMenu 版本。

### 如何调整元素的层级（将某个元素移到另一个元素前面或后面）？

- **你自己的元素：** 在布局编辑器的“图层”小部件中拖动图层，或右键单击元素，然后单击 **上移一层** 或 **下移一层**。请参阅[图层和组](/layout-editor#layers-and-groups)。
- **你自己的元素和原版元素：** 原版元素的顺序无法更改。若要将自己的所有元素放到原版元素后面（例如将背景图片放到默认按钮后面），请右键单击编辑器背景，并将 **自定义元素置于原版元素后方** 设为 **已启用**。

### 能否从通用按钮模板中排除某些按钮？

**不能。如果模板按钮设置了自定义纹理，这些纹理就会应用于所有受影响的元素。你无法单独排除某个按钮。**

### 如何让按钮在点击时执行操作？

使用[**动作脚本**](/action-scripts)。
1.  在编辑器中右键单击按钮。
2.  选择 **编辑动作脚本**。
3. 单击 **添加动作** 并选择一个操作，例如[**打开界面或自定义 GUI**](/action-scripts#open-screen-or-custom-gui)、[**加入服务器**](/action-scripts#join-server)或[**设置变量值**](/action-scripts#set-variable-value-fm-variable)。

### 能否从头创建一个全新的菜单界面？

可以，使用[自定义 GUI](/custom-guis)即可：

1. 打开 **菜单栏 -> 自定义 -> 自定义 GUI -> 管理自定义 GUI**，然后单击 **新建 GUI**。
2. 为它设置一个标识符，例如 `modpack_info`，然后单击 **完成**。
3. 使用 **打开 GUI** 打开它，并像其他菜单一样为它创建布局。
4. 在按钮上使用[**打开界面或自定义 GUI**](/action-scripts#open-screen-or-custom-gui)动作，并填写它的标识符，即可打开该 GUI。

### 启用预加载后，游戏加载时间变长了。

这是正常现象。在启动游戏时预加载高分辨率动画或音效等大型资源，自然会延长游戏的加载时间。

### 我的动画占用大量内存，或者让游戏变卡了！

大尺寸帧和高帧率会占用更多内存并影响性能。请将帧的尺寸设为与屏幕上显示的大小大致相同，并降低每秒帧数。请参阅[动画](/animations#performance)。对于带有声音的长片段，请改用[视频](/video)。

### FancyMenu 能和 OptiFine 一起使用吗？

不能。OptiFine **不兼容**，而且已知会导致许多模组（包括 FancyMenu）出现问题。强烈建议改用 Sodium/Embeddium + Iris/Oculus 等现代替代方案。
请参阅 [OptiFine 替代方案](/optifine-alternatives)。

### 游戏崩溃了。如何判断是不是模组冲突？

检查模组冲突的最佳方法是**仅使用 FancyMenu 及其依赖项（Konkrete、Melody）运行游戏**。如果这样不再崩溃，可以分批重新加入其他模组，直到崩溃再次发生，从而找出冲突的模组。

### 编辑其他模组添加的按钮时，按钮消失了或无法使用。

有些模组添加小部件的方式无法被 FancyMenu 检测或自定义。请查看[原版/模组元素](/vanilla-elements)；对于基于列表的界面，请查看[自定义可滚动界面](/customizing-scrollable-screens)。如果小部件仍未显示，那么添加它的模组必须将其公开为受支持的界面小部件。

### 能在服务器上使用 FancyMenu 布局吗？

布局和视觉自定义内容保存在玩家客户端上；服务器无法强制未配置的客户端使用这些内容。请将它们作为整合包的一部分分发。如果需要使用[服务器命令](/commands)、[FM 数据](/fm-data)、[服务器端 NBT 访问](/nbt-data-placeholder#server-side-placeholder)、游戏规则、结构或服务器监听器，则需要在服务器上安装 FancyMenu。

### FancyMenu v2（适用于较旧的 MC 版本）和 v3 有什么区别？

FancyMenu v3 是一次全面重写，带来了许多新功能、更稳定的架构和更好的性能。v2 已过时，不再受支持，也缺少高级占位符和脚本等许多功能。强烈建议在现代 Minecraft 版本（1.18.2+）上使用 v3。加载 v2 布局时可以自动将其转换为 v3，但可能仍需手动修正。

### 在哪里可以找到预制布局和模板？

FancyMenu 社区会在官方 Discord 服务器（“Kekscord”）的 [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) 频道分享完整配置。请将它们作为独立配置文件安装，详见[布局模板](/profiles#layout-templates)。

### 如何让玩家实体渲染在其他元素后面？

通常无法通过[图层](/layout-editor#layers-and-groups)小部件强制让[玩家实体元素](/elements#player-entity)位于普通 2D 元素后面。它的渲染器可能会忽略常规 GUI 图层顺序。请围绕这一限制设计布局；如果必须严格控制图层顺序，可以使用预渲染图片。

### 我的玩家实体只显示一条腿！这是怎么回事？

这是一个视觉问题，很可能是与其他修改玩家动画或模型的模组发生冲突所致。请检查玩家实体的姿势设置，确认腿部是否被意外旋转或移动。

### 如何在脚本的动作之间添加延迟？

在动作脚本编辑器的脚本区域右键单击，单击 **添加“稍后执行”代码块**，并将需要延迟的动作放入其中。这些动作会在设定的毫秒数后执行一次，其余脚本则会立即继续运行。请参阅[稍后执行](/action-scripts#execute-later)。

如果需要重复执行某些操作，请使用[调度器](/schedulers)。

### 能自定义 Create 模组的菜单吗？

不能。Create 界面的自定义功能已被有意禁用。请参阅[有意禁用自定义功能的界面](/incompatibility-list#screens-where-customization-is-intentionally-disabled)。

### 背景图片和按钮纹理建议使用什么分辨率？

背景：标准的 1920x1080（1080p）图片是很好的起点，能够很好地适配大多数用户的屏幕。

按钮：大多数原版按钮宽约 150–200 像素，高约 20 像素。自定义纹理采用相近尺寸，有助于保持一致性。

### 玩家完成游戏内目标（例如任务）后，能否自动打开菜单或运行命令？
FancyMenu 提供了许多[内置游戏事件监听器](/listeners)，但没有适用于所有第三方任务系统的通用监听器。如果任务模组支持命令奖励，可以用它运行 [`/openguiscreen`](/commands#openguiscreen)、[`/fmvariable`](/commands#fmvariable) 或其他合适的 [FancyMenu 命令](/commands)。

### 如何让按钮无法使用或显示为灰色？

你可以使用[条件](/conditions)控制按钮的启用状态。
在编辑器中右键单击按钮，然后选择 **控制启用状态**。
添加一个必须满足的条件，按钮才会启用。若要永久禁用按钮，可以使用[**是数字**](/conditions#is-number)检查 0 是否等于 1。
此时按钮会使用“未启用背景”纹理，并且无法点击。

### 如何移除可滚动界面上的页眉和页脚（土色纹理条）？

在布局编辑器中打开 **布局属性 -> 页眉/页脚自定义**，并将纹理设为透明。某些模组界面可能没有此选项。

### 我无法为“当前界面”创建布局。按钮是灰色的。

先为该界面启用自定义功能：单击 **菜单栏 -> 自定义 -> 当前界面自定义**，直到显示 **已启用**。

### 在编辑器中打开界面时，我无法自定义其中任何元素，看到的只有空界面。

这可能是因为你创建的是[通用布局](/universal-layouts)，而不是**当前界面**的布局。

也可能是一个[可滚动界面](/customizing-scrollable-screens)，FancyMenu 默认无法自定义这类界面。

还有一种可能是，该界面来自以非原版方式添加元素的模组，因此 FancyMenu 无法自定义这些元素。

### 文本元素旁边出现了奇怪的灰色框。

这些是[文本元素](/elements#text)的滚动条。当文本内容超出元素范围时，就会显示滚动条，方便玩家滚动查看。

- 放大元素或缩短文本，滚动条就会消失。
- 右键单击元素并打开 **滚动条**。**显示**可以设置滚动条的显示时机：**始终**、**仅滚动时**或**从不**。设为**从不**时，仍然可以使用鼠标滚轮滚动。
- 在同一菜单中，**滚动滑块样式**、**滚动滑块纹理**和**滚动滑块颜色 [HEX]**可以更改滚动条的外观。

有关所有滚动条设置，请参阅[菜单中的文本](/text-in-menus#scroll-bars)。

### 如何在菜单中显示最新的 Minecraft 更新日志？

有一个很棒的 [GitHub 项目](https://github.com/ClaytonTDM/minecraft-changelogs-markdown)，可以将 Minecraft 更新日志转换为 FancyMenu 兼容的 Markdown，让你在菜单中显示最新的 MC 更新日志！它每天都会更新，以获取最新的更新日志。

要在[文本元素](/elements#text)中显示它，请将 **来源模式** 设为 **资源**，并将资源来源设为 **Web**。使用 `https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`。

### 将任意元素拉伸至屏幕大小，最简单的方法是什么？

大多数元素的右键菜单中都有水平和垂直拉伸选项。启用后，元素就会始终拉伸至屏幕的全部宽度和/或高度。水平和垂直拉伸可以分别启用或禁用。

### 文本元素后面或前面的按钮无法点击，滑块也无法操作。

默认情况下，文本元素可以交互（例如拖动滚动滑块或点击 Markdown 超链接），因此会占用鼠标点击和滚动事件。最简单的办法是避免将按钮放在文本元素的前面或后面。如果确实无法避免，可以**右键单击**文本元素，并将 **可交互** 设为 **已禁用**。请注意，这会让文本元素变成静态、不可交互的文本，因此无法再滚动文本或点击超链接。

### 如何避免使用方向键和 Tab 键浏览界面时选中或聚焦按钮和滑块？

若要让按钮和滑块无法通过键盘导航，请**右键单击**它，并将 **可导航** 设为 **已禁用**。按钮或滑块仍然可以点击，但无法再通过方向键或 Tab 键将其聚焦。

如果你想在聊天界面中添加按钮或滑块，这也很有用：这样就可以继续按向上方向键查看较早的消息，而不会意外选中界面中的按钮或滑块。

### FancyMenu 的某个右键菜单缺少本应存在的选项。

FancyMenu 的上下文菜单（右键单击某处或与菜单栏交互时打开的菜单）**可以滚动**。将鼠标指针悬停在菜单上时，可以使用滚轮上下滚动，查看之前未显示的更多选项。

### 我无法自定义标题界面，离开编辑器后它总是恢复成原来的样子。

另一个模组替换了原版的 `title_screen`。请在该模组的设置中禁用它自定义的标题界面。如果它没有提供相应选项，FancyMenu 就无法将布局应用到替换后的界面上。

### 我尝试自定义物品栏界面，但无法自定义物品栏容器。

这是正常现象。FancyMenu 不支持编辑任何类型物品栏界面中的实际容器（玩家物品栏、箱子、工作台等），因为添加这项支持非常困难。

不过，你仍然可以向这些界面添加新元素，只是无法编辑其中的容器。

顺便一提，SpiffyHUD 在这里也帮不上忙，因为它用于编辑 HUD（例如物品快捷栏），而不能编辑界面（例如物品栏界面）。
