# 菜单中的文本

FancyMenu 提供了两种文本元素：

- **Text** 可直接在菜单中显示文本，从单行文本到较长的可滚动页面（例如更新日志、规则或新闻）都适用。
- **Tooltip** 可在固定位置或鼠标旁显示文本框，例如鼠标悬停在按钮上时显示。

两者都支持 [Markdown](/text-formatting) 和 [占位符](/placeholders)，并且使用相同的外观和样式设置。

<img width="800" alt="编辑 Text 元素" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/text_editor_showcase.gif?raw=true">

> [!TIP]
> 本页介绍这些元素及其设置。关于文本中可以使用的内容（例如标题、列表、链接和颜色），请参阅[文本格式](/text-formatting)。

# 添加文本

1. 在布局编辑器中打开一个布局。
2. 右键单击编辑器背景，然后选择 **新建元素 -> Text**。
3. 右键单击新建的元素，然后选择 **文本内容**。
4. 输入文本，然后单击 **完成**。

# 文本内容

## 来源模式

右键单击元素并设置 **来源模式**：

- **直接**：在文本编辑器中手动输入文本。
- **资源**：文本来自文本文件。单击 **文本来源**，从 `<game-directory>/config/fancymenu/assets/` 中选择本地文件、网页 URL 或资源包文件。请参阅[资源](/resources)。

网页来源非常适合用于更新日志或新闻等内容，确保内容始终保持最新，而无需更新整合包。

FancyMenu 会将文件和网页来源的文本缓存到游戏关闭为止。若要重新加载，请通过 **菜单栏 -> 自定义 -> 重新加载 FancyMenu** 重新加载 FancyMenu。

## 动态文本

文本可以通过[占位符](/placeholders)显示实时数值，例如 `欢迎，{"placeholder":"playername"}！`。它也可以显示[变量](/variables)的值。这些值发生变化时，文本会自动更新。

## 文本编辑器

单击 **文本内容**即可打开文本编辑器。单击右上角的 **占位符**，浏览所有占位符并将其添加到文本中。

### 格式设置快捷键

Text 和 Tooltip 元素的文本编辑器提供了一些常用格式设置快捷键。在 macOS 上，请使用 `Cmd` 代替 `Ctrl`。

| 快捷键 | 功能 |
|---|---|
| `Ctrl + B` | 粗体 |
| `Ctrl + I` | 斜体 |
| `Ctrl + U` | 下划线 |
| `Ctrl + L` | 左对齐 |
| `Ctrl + E` | 居中对齐 |
| `Ctrl + R` | 右对齐 |

- 先选中文本，再设置格式。再次按下相同的快捷键即可移除格式。
- 如果没有选中文本，快捷键会插入格式标记，并将光标放在标记之间，方便你直接继续输入。
- 对齐快捷键会作用于选中的行，或光标所在的行。对已经采用相应对齐方式的行按下 `Ctrl + E` 或 `Ctrl + R`，会将其重新设置为左对齐。
- 在编辑器中右键单击并打开 **格式设置**，即可在菜单中查看这些快捷键。

### 其他快捷键

FancyMenu 中的大多数文本（例如操作值和许多元素设置）都会使用同一个文本编辑器。以下快捷键在这些编辑器中均可使用。在 macOS 上，请使用 `Cmd` 代替 `Ctrl`。

| 快捷键 | 功能 |
|---|---|
| `Ctrl + C` | 复制选中的文本 |
| `Ctrl + X` | 剪切选中的文本 |
| `Ctrl + V` | 粘贴 |
| `Ctrl + A` | 选中所有文本 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` | 重做 |
| `Ctrl + D` | 复制光标所在行 |
| `Alt + Arrow Up` / `Alt + Arrow Down` | 将光标所在行上移或下移 |
| `Shift + Arrow keys` | 选择文本 |
| `Ctrl + Home` / `Ctrl + End` | 跳转到文本开头或结尾 |
| `Ctrl + G` | 跳转到指定行：输入行号并按 `Enter` |
| `Ctrl + S` | 与 **完成**功能相同 |

布局编辑器的快捷键请参阅[布局编辑器](/layout-editor#shortcuts)。

# 外观和样式

右键单击元素并打开 **Markdown**，即可更改文本的外观。

## 外观

**外观**会一次性设置文本的所有样式选项：

- **像素风格**：为 Minecraft 字体设计的像素风格，采用暖色调、金色细节和手绘标记。
- **经典**：FancyMenu 的经典外观，使用白色文本、灰色文本框和灰色线条。
- **中性**：简洁的外观，采用当前 FancyMenu UI 主题的配色。颜色会与元素一同保存，因此之后切换主题时也会保持不变。

<img width="800" alt="三种 Markdown 外观" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/markdown_looks.png?raw=true">

新建元素默认使用像素风格。旧布局中的元素会保留原有的经典外观。

> [!NOTE]
> 选择外观会覆盖你自行修改的样式。如果想恢复之前的样式，只需按 `Ctrl + Z` 撤销即可。

## 样式选项

选择外观后，你仍然可以微调各个部分。**Markdown** 菜单提供了 **文本**、**标题**、**列表**、**链接**、**代码**、**引用**、**提示框**、**表格**、**图片**和**分隔线**的选项。将鼠标悬停在选项上即可查看其作用。

**Markdown -> 文本**包含基本设置，例如文本颜色、文本阴影、行间距，以及文本与元素边缘之间的内边距。

## 关闭 Markdown

如果完全不需要 Markdown，可以关闭 **Markdown -> Markdown 解析器**。此时文本会按输入内容原样显示，对于很长的文本来说，速度也会稍快一些。

## 其他文本设置

右键单击元素，还可以找到以下设置：

- **文本缩放**可放大或缩小文本。
- **大小写模式**可按正常大小写、全大写或全小写显示文本。
- **自动换行**会将过长的行自动换行。不启用时，长行会继续向后延伸。
- **移除 HTML 换行符**会从文本中移除 HTML 换行符（`<br>`），适用于来自网站的文本。

# 背景

Text 元素可以在文本后方绘制面板。在元素的右键菜单中打开 **背景**：

- **显示背景**可开启或关闭面板。新建的 Text 元素默认启用此选项。
- 默认情况下，背景是内置的深色面板。你也可以使用自己的纹理，并通过[九宫格切片](/nine-slicing-and-tiling)和平铺保持边缘形状。
- **内边距**用于设置背景超出文本的范围。
- **延伸至滚动条后方**可让背景覆盖滚动条。关闭时，滚动条会紧贴背景边缘。

Tooltip 元素也有单独的 **背景**菜单，可以在其中设置纹理及其九宫格切片。

# 滚动

当 Text 元素中的文本超出其显示范围时，可以滚动文本。使用鼠标滚轮滚动，按住 `Shift` 可横向滚动。

**滚动方向**可设置文本按**垂直**、**水平**或**双向**滚动。未启用滚动的方向上，超出显示范围的内容会被截断。

## 滚动设置

在元素的右键菜单中打开 **滚动**：

| 设置 | 功能 |
|---|---|
| **允许玩家滚动** | 设置玩家是否可以自行滚动文本。关闭时，文本只会自动滚动或通过操作滚动。 |
| **滚动速度** | 设置鼠标滚轮每滚动一格时移动的距离。 |
| **平滑滚动** | 让文本平滑移动，而不是跳跃式滚动。 |
| **拖动滚动** | 允许玩家用鼠标抓住文本并拖动，类似触摸屏上的操作。 |
| **使用键盘滚动** | 鼠标悬停在文本上时，按 `Page Up` 和 `Page Down` 可滚动一页，按 `Home` 和 `End` 可跳转到开头和结尾。 |
| **吸附** | 设置文本停止的位置：任意位置（**关闭**）、每次在完整行的顶部停止（**按行**）、在标题顶部停止（**按标题**），或每次滚动整页（**按页**）。 |
| **起始位置** | 设置文本从**开头**还是**结尾**开始显示。对于日志等最新内容位于末尾的文本，从结尾开始会很方便。 |
| **屏幕打开时重置** | 每次打开屏幕时，都将文本重置到开头。关闭时，文本会记住滚动位置，直到游戏关闭。 |

## 自动滚动

打开 **自动滚动**，可让文本缓慢自行滚动，适合制作片尾名单或新闻滚动条：

- **自动滚动**可开启此功能。
- **速度 [像素/秒]**可设置滚动速度。
- **到达结尾后重新开始**会在到达结尾后从顶部重新开始。
- **悬停时暂停**会在鼠标悬停于文本上时停止滚动，让玩家安心阅读。

## 滚动条

打开 **滚动条**，即可更改滚动条设置：

- **显示**可设置滚动条的显示时机：**始终**显示、仅在**滚动时**显示，或**从不**显示。选择**从不**时，仍可使用鼠标滚轮滚动。
- **粗细**可设置滚动条的宽度。
- **垂直滚动条置于左侧**和**水平滚动条置于顶部**可将滚动条移到另一侧。
- **滚动滑块样式**可选择滑块的外观：**主题滚动条**（采用 FancyMenu UI 主题的配色）或**像素手柄**（与像素风格搭配的像素画）。
- **滚动滑块纹理**和**滚动滑块颜色 [HEX]**可将滑块替换为自定义纹理或颜色。
- **滚动条背景**可在滑块移动的轨道后方添加纹理。

## 使用操作控制滚动

你也可以在 FancyMenu 的其他位置控制和监视滚动：

- **滚动元素**[操作](/action-scripts)可将 Text 元素滚动到开头、结尾、指定位置、指定行号，或首个包含指定文本的行。
- **元素滚动位置**、**元素滚动百分比**和**元素滚动内容大小**[占位符](/placeholders)可显示文本的滚动位置和内容大小。
- **元素已滚动到结尾**[条件](/conditions)可检查文本是否已滚动到结尾，例如，只有在玩家读完规则后才启用“接受”按钮。
- **元素滚动时**、**元素滚动到开头时**和**元素滚动到结尾时**[监听器](/listeners)可在文本滚动时执行操作。

以上功能都需要 Text 元素的[元素标识符](/element-identifiers)。

# 点击穿透文本元素

Text 元素会响应鼠标操作，因此其中的链接和滚动条可以正常使用。这也意味着它会拦截点击，因此 Text 元素后方或前方的按钮可能无法接收到点击。

如果遇到这种情况，右键单击 Text 元素并关闭 **可交互**。这样一来，文本将无法滚动，其中的链接也无法点击。

# Tooltip

Tooltip 元素与 Text 元素类似，但不支持滚动：

- 文本、外观和样式设置与 Text 元素相同。
- **跟随鼠标**可让提示框跟随鼠标移动。
- 使用[条件](/conditions)决定何时显示提示框，例如使用[**鼠标悬停于元素上**](/conditions#is-element-hovered)条件，在鼠标悬停于按钮上时显示提示框。
