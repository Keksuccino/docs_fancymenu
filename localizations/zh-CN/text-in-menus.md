# 菜单中的文本

FancyMenu 允许你通过 **Text** 元素向菜单/界面添加文本内容。

这个元素支持滚动，拥有完整的 Markdown 支持和自动换行功能，因此非常适合显示复杂文本内容，同时也很适合简单的一行文本。

## 文本内容

Text 元素可以通过多种方式获取内容。你可以为它设置文本来源，来源可以是直接输入的纯文本、FancyMenu `assets` 文件夹中的本地文本文件（`/config/fancymenu/assets/`）、网络文本文件（通过 URL）或通过资源包加载的本地文本文件。

将网络来源类型作为文本来源尤其适合用于制作始终保持最新的更新日志、新闻滚动条之类的内容，而无需为你的整合包发布更新。

请注意，FancyMenu 会缓存文本来源的内容，因此它不需要不断重新获取内容（这会严重影响性能）。内容只会在当前会话中缓存，因此重启游戏会清除缓存。你也可以通过 **菜单栏 -> 自定义 -> 重新加载 FancyMenu** 来清除缓存。

## 占位符

Text 元素还支持 FancyMenu 的占位符系统，这使得文本内容可以动态变化，并响应菜单、世界、玩家等各种变化。

## 自定义或禁用 Markdown

如果你想自定义标题或其他与 Markdown 相关内容的颜色，只需**右键单击** Text 元素并点击 **Markdown**。在打开的子上下文菜单中，你会看到许多用于自定义 Markdown 解析器外观和行为的选项。

如果你根本不想进行 Markdown 解析，这样可以提升长文本内容的性能，那么你可以在**右键单击** Text 元素后打开的 **Markdown** 菜单中将 Markdown 完全禁用。

## 禁用自动换行

如果你不想要自动换行，可以通过**右键单击** Text 元素来将其禁用。

## 禁用滚动

Text 元素默认可滚动，如果元素认为用户需要滚动才能查看全部内容，它会显示滚动条，这些滚动条是 Text 元素右侧和底部的小灰条（垂直和水平滚动条）。

你可以在**右键单击**该元素后打开的菜单中关闭 **Scrolling** 来禁用这些条。这会同时禁用滚动功能，而不仅仅是隐藏滚动条。如果你只是想让滚动条不可见，也可以通过右键单击该元素来设置自定义滚动条纹理。只需将其设置为完全透明的纹理即可。

## Minecraft 的原始组件文本格式（序列化 JSON 组件）

Text 元素**不**支持 Minecraft 的原始组件格式。此格式仅支持按钮和滑块标签。
