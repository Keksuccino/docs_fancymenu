# 菜单中的文本

FancyMenu 允许你通过 **文本** 元素向菜单/界面添加文本内容。

这个元素支持滚动，完整支持 Markdown 和自动换行，因此它非常适合展示复杂文本内容；同时，它也很适合显示简单的一两行文字。

# 文本内容

文本元素可以通过多种方式获取其内容。你可以为它设置文本内容来源，来源可以是直接输入的纯文本、本地文本文件（位于 FancyMenu 的资源目录 `(<game-directory>/config/fancymenu/assets/)`）、网络文本文件（通过 URL），或者通过资源包加载的本地文本文件。

如果你想制作类似始终保持最新的更新日志、新闻滚动条之类的内容，使用网页来源类型作为文本来源会特别有用，这样就不需要为了更新模组包而发布新版本。

请注意，FancyMenu 会缓存文本来源的内容，因此它不必反复获取内容（这会非常影响性能）。内容只会在当前会话中缓存，所以重启游戏会清空缓存。你也可以通过 **菜单栏 -> 自定义 -> 重新加载 FancyMenu** 来重新加载 FancyMenu，从而清除缓存。

# 占位符

文本元素还支持 FancyMenu 的占位符系统，这使得文本内容可以动态变化，并对菜单、世界、玩家等的各种变化作出响应。

# 自定义或禁用 Markdown

如果你想自定义标题或其他与 Markdown 相关内容的颜色，只需**右键点击**文本元素，然后点击 **Markdown**。在打开的子上下文菜单中，你会看到许多用于自定义 Markdown 解析器外观和行为的选项。

如果你根本不想使用 Markdown 解析，这对于较长的文本内容还能提升性能，那么你可以在**右键点击**文本元素后打开的 **Markdown** 菜单中将 Markdown 完全禁用。

# 禁用自动换行

如果你不想自动换行，可以通过**右键点击**文本元素来将其禁用。

# 禁用滚动并隐藏滚动条手柄

文本元素默认是可滚动的；如果元素认为用户需要滚动才能看到全部内容，它会显示滚动条/拖拽手柄，也就是文本元素右侧和底部那些小小的灰色半透明条（带圆角的垂直和水平滚动条）。这些滚动条手柄有时也会被误认为是阴影。

你可以在**右键点击**该元素后打开的菜单中关闭 **滚动** 来禁用这些手柄。这会完全禁用滚动，而不仅仅是隐藏手柄。如果你只是想让手柄不可见，但仍然可以滚动，可以通过右键点击元素来设置自定义滚动条手柄纹理。只需在这里设置为完全透明的纹理即可。

# Minecraft 的原始组件文本格式（序列化 JSON 组件）

文本元素**不**支持 Minecraft 的原始组件格式。此格式仅受按钮和滑块标签支持。
