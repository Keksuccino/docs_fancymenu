# 菜单中的文本

FancyMenu 允许你通过 **Text** 元素向菜单/界面添加文本内容。

这个元素支持滚动，拥有完整的 Markdown 支持和自动换行功能，因此它非常适合展示复杂的文本内容，同时也很适合简单的一行文本。

# 文本内容

Text 元素可以通过多种方式获取其内容。你可以为它设置文本内容来源，来源可以是直接输入的纯文本、FancyMenu 的 `assets` 文件夹中的本地文本文件（`/config/fancymenu/assets/`）、网页文本文件（通过 URL）或通过资源包加载的本地文本文件。

如果你想制作类似始终保持最新的更新日志、新闻滚动条之类的内容，而又不希望每次都为整合包发布更新，那么将网页来源类型用作文本来源尤其有用。

请注意，FancyMenu 会缓存文本来源的内容，因此它不必不断重新获取内容（这对性能会非常不利）。内容只会在当前会话中缓存，因此重启游戏会清除缓存。你也可以通过 **菜单栏 -> 自定义 -> 重新加载 FancyMenu** 来清除缓存。

# 占位符

Text 元素还支持 FancyMenu 的占位符系统，这使得文本内容可以动态变化，并对菜单、世界、玩家等的各种变化做出反应。

# 自定义或禁用 Markdown

如果你想自定义标题或其他与 Markdown 相关内容的颜色，只需**右键** Text 元素并点击 **Markdown**。在打开的子菜单中，你会看到许多用于自定义 Markdown 解析器外观和行为的选项。

如果你完全不想使用 Markdown 解析，这样可以提升长文本内容的性能，你可以在**右键** Text 元素时打开的 **Markdown** 菜单中将其完全禁用。

# 禁用自动换行

如果你不想使用自动换行，可以通过**右键** Text 元素将其禁用。

# 禁用滚动与隐藏滚动条

Text 元素默认可滚动，如果该元素认为用户需要滚动才能查看全部内容，它就会显示滚动条/拖块，即位于 Text 元素右侧和底部的小型灰色半透明条（带圆角边缘）（垂直和水平滚动条）。这些滚动拖块有时也会被误认为是阴影。

你可以通过在**右键**该元素后打开的菜单中关闭 **Scrolling** 来禁用这些拖块。这将会完全禁用滚动，而不仅仅是隐藏拖块。如果你只是想让拖块不可见，同时仍然可以滚动，你可以通过右键该元素来设置自定义滚动拖块纹理。只需在这里设置一个完全透明的纹理即可。

# Minecraft 的原始组件文本格式（序列化 JSON 组件）

Text 元素**不**支持 Minecraft 的原始组件格式。此格式仅受按钮和滑块标签支持。
