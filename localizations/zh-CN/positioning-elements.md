# 在 FancyMenu 中定位元素

在 FancyMenu 中，每个元素的位置都由**锚点**决定。锚点用于计算元素在屏幕上的显示位置，确保元素不会相互重叠、移出屏幕，或在调整窗口大小时发生错误移动。

## 了解锚点

锚点是计算元素位置时所依据的原点。默认情况下，添加到布局中的元素会关联到**“屏幕中心”**锚点。无论窗口大小如何变化，该锚点始终位于屏幕的正中央。

例如，如果某个元素关联到**“屏幕中心”**锚点，并且距离屏幕中心 2 厘米，那么无论窗口大小如何变化，它与屏幕中心的距离都会保持不变。

## 使用锚点

在编辑器中拖动元素时，与其关联的锚点会高亮显示。默认情况下，其他所有可用锚点也会同时显示。若要更改元素的锚点，可将元素拖到另一个锚点上，并等待进度条填满。

## 将元素锚定到其他元素

元素可以使用另一个元素作为锚点。这样一来，它会随另一个元素移动，并保持与另一个元素左上角之间的距离。这对于由多个元素组成的面板、原版按钮旁的标签，以及 [拖动器](/dragger)都很实用。

有两种操作方式，且两种方式都会让元素保持在当前位置。

### 拖动操作

1. 拖动元素，并将指针停留在另一个元素上。
2. 等待进度条填满，然后松开。

如果开始拖动时指针已经位于另一个元素上，请先将指针移出该元素，再移回去。从一开始就在指针下方的元素不会被识别。

此功能需要在**窗口**菜单中启用**锚点区域悬停**和**锚点元素悬停**；默认情况下两者均已启用。前者用于开启或关闭悬停锚定，后者则会将其他元素添加为锚点。该菜单中的**锚点区域/元素悬停充能时间（秒）**用于设置需要停留的时长，默认值为 2 秒。

### 通过 ID 操作

1. 右键单击另一个元素，然后单击**复制元素 ID**。
2. 右键单击要设置锚点的元素，然后单击**锚点 -> 其他元素**。
3. 将 ID 粘贴到**元素 ID**中，然后单击**完成**。

选中多个元素时，第 2 步和第 3 步会将它们同时锚定到该元素。有关 ID 的更多信息，请参阅[元素标识符](/element-identifiers)。

## 可滚动区域中的锚点

[可滚动区域](/scrollable-areas)中的元素也有锚点，不过这些锚点相对于区域内容，而不是屏幕：

- **左上角**是内容的左上角，**屏幕中心**是内容的中心，而底部锚点则固定在内容末尾。因此，元素可以放在长列表的最末尾，并在列表变长时继续留在那里。
- 区域中的元素只能使用同一区域内的其他元素作为锚点。
- 将元素移入或移出区域时，原本跨越区域边界锚定的元素会改用**左上角**锚点，并保持在原来的位置。

此功能适用于区域的**锚点**模式。在其他模式下，区域会自行放置元素。请参阅[可滚动区域](/scrollable-areas#anchors-mode)。

## 将元素移出屏幕

默认情况下，无法将元素移出屏幕。这是一种安全保护措施：当布局在非常小或尺寸异常的窗口中加载时，元素仍然可见且可以交互。

元素始终会留在屏幕内，并与屏幕边缘保持一小段距离。

你可以对单个元素**右键单击**，然后关闭**保持在屏幕内**，以**禁用**此功能。

> [!WARNING]
> 禁用此功能有时会导致元素消失，因为元素的实际位置可能在屏幕外，而此功能原本会强制让它保持可见。如果遇到这种情况，请通过撤销快捷键，或依次选择**菜单栏 -> 编辑 -> 撤销**，撤销上一步操作（关闭**保持在屏幕内**）；然后手动将元素移到屏幕中央，再次关闭**保持在屏幕内**。这样即使禁用此功能，元素也应该仍然可见。

## 居中元素

只要元素大小固定，将其居中就很简单：只需将它锚定到以中心为基准的锚点即可。

如果元素会根据条件或其他因素动态改变大小，操作就稍微复杂一些，但 FancyMenu 提供了一个很实用的功能！此时，先将元素锚定到以中心为基准的锚点，然后右键单击该元素。在上下文菜单中启用**粘性锚点**。此功能会改变 FancyMenu 计算元素位置的方式，使元素无论大小如何变化，都始终与锚点保持相同距离。对于以中心为基准的锚点，元素会始终以自身的绝对中心与锚点保持相同距离，因此使用这类锚点时，元素就会一直保持居中。（对于以左侧为基准的锚点，元素左侧会始终与锚点保持相同距离；对于以右侧为基准的锚点，元素右侧会始终与锚点保持相同距离。）

## 改进元素定位的其他方法

如果**所有锚点都设置正确**，但窗口太小时元素仍会相互重叠，那么布局可能只是超出了 Minecraft 默认 GUI 缩放逻辑的适用范围。

### 强制 GUI 缩放

改善布局元素定位的一种方法是为菜单强制指定 GUI 缩放比例：**右键单击编辑器背景**，然后选择**强制 GUI 缩放**。这样，无论 Minecraft 选项中设置了什么缩放比例，菜单都会始终使用相同的 GUI 缩放比例。

### 自动缩放

解决重叠问题的最后一种方法是使用**自动缩放**。
此设置会根据窗口大小自动缩放菜单，尽可能在调整窗口大小时保持元素的位置。若要启用自动缩放，请**右键单击编辑器背景**，然后单击**自动缩放**。

> [!WARNING]
> **自动缩放**可能会导致 Minecraft 渲染的**文本看起来很差**。这不是错误，而是 Minecraft 文本渲染本身的特性。对于按钮，一种实用的解决方法是将按钮标签做进按钮背景纹理中，并将原版按钮标签设为空白。
