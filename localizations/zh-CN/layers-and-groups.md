# 图层和组

通过 **Window -> Editor Widgets -> Layers** 打开图层小部件。

# 图层顺序

在列表中拖动图层即可更改其渲染顺序。你也可以右键单击某个元素，并使用 **Move One Layer Up** 或 **Move One Layer Down**。

[Player Entity](./elements#player-entity) 和 [Item](./elements#item) 元素可能具有渲染限制，从而阻止正常的图层排序。

# 组

组用于组织相关图层，并让你将它们一起移动或隐藏。

- 创建并重命名组。
- 重命名单个图层。
- 将图层拖入或拖出组。
- 拖动某个组可按顺序移动其所有图层。
- 折叠或展开组。
- 显示或隐藏组中的所有图层。
- 删除组而不删除其中的图层。

组成员关系和折叠状态会随布局一起保存。
