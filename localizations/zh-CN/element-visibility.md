# 元素可见性

元素不必始终显示。它们可以只在特定情况下显示、稍后再出现、淡入淡出，或者通过按钮切换显示和隐藏。

<img width="800" alt="欢迎文字在屏幕打开几秒后淡入，随后一个“服务器规则”按钮让规则面板淡入淡出" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/element_visibility_toggle.gif?raw=true">

在布局编辑器中，元素始终会显示，以便你继续编辑。本文介绍的所有功能在编辑器外都能生效。

> [!TIP]
> 所有条件都列在[条件](/conditions)中。

# 让元素只在特定情况下显示

右键点击一个元素，然后点击**加载条件**。只有当它的所有[条件](/conditions)都满足时，元素才会显示，例如“鼠标悬停在此按钮上”“现在是 12 月”或“某个变量具有此值”。FancyMenu 会持续检查这些条件，因此元素会立即显示或隐藏。

- **条件模式**中的“反转”会反转条件，例如将“现在是 12 月”变成“现在不是 12 月”。
- 使用条件组可以实现“这个或那个”。
- 原版元素也有**加载条件**。如需彻底移除原版元素，请参阅[已删除的原版元素](/deleted-vanilla-elements)。

添加和组合条件的方法请参阅：[条件](/conditions#adding-a-requirement)。

## 每次游戏会话只加载一次

右键点击一个元素，然后启用**每次会话只加载一次**。元素会在其所在屏幕首次打开时显示。玩家切换到其他屏幕后，它就会保持隐藏，直到游戏重新启动。

适用于每次启动游戏只应显示一次的提示，例如“按 F1 查看控制说明”。如需在动作脚本中使用相同功能，请使用[**每次会话仅一次**](/conditions#only-once-per-session)条件。

# 延迟显示和隐藏元素

## 延迟显示

右键点击一个元素，然后点击**延迟显示**：

- **延迟**：
  - **无延迟**：立即显示。
  - **首次**：游戏启动后，仅在元素首次显示时等待。
  - **每次**：每次打开屏幕，以及元素条件再次满足时，都会等待。
- **延迟秒数**：等待时长，例如 `1.5`。

调整窗口大小不会重新开始延迟。

## 延迟隐藏

右键点击一个元素，然后点击**延迟隐藏**。当元素的条件不再满足时，它会继续显示**延迟秒数**，然后才会隐藏。**延迟**选项与上文相同。

例如，信息框的条件设为按钮的[**鼠标悬停在元素上**](/conditions#is-element-hovered)后，鼠标离开按钮 1 秒后，信息框才会隐藏。

# 淡入淡出

右键点击一个元素，然后点击**淡入/淡出**：

- **淡入**和**淡出**：
  - **无淡入淡出**：立即显示或隐藏。
  - **仅一次**：游戏启动后仅淡入淡出一次。
  - **每次**：每次都淡入淡出。
- **淡入速度**和**淡出速度**：设为 `1` 时，淡入或淡出需要 2.5 秒。设为 `2` 时，速度加倍。

屏幕打开时，以及元素条件满足时，元素会淡入。使用**延迟显示**时，淡入会在延迟结束后开始。

只有当条件导致元素隐藏时才会淡出；关闭屏幕时不会淡出。

# 不透明度

右键点击一个元素，然后点击**不透明度**：`1.0` 表示完全可见，`0.5` 表示半透明，`0.0` 表示不可见。大多数元素都有此选项。

不透明度支持[占位符](/placeholders)和[变量](/variables)，例如 `$$panel_opacity`。淡入效果会在元素达到其不透明度时停止。

# 使用按钮切换元素的显示状态

按钮可以显示和隐藏元素，例如上方 GIF 中的规则面板。使用[变量](/variables)记录面板是否显示。

1. 右键点击面板，然后点击**加载条件**。添加[**变量值是否为（FM 变量）**](/conditions#is-variable-value-fm-variable)，变量设为 `show_rules`，值设为 `true`。
2. 右键点击按钮，然后点击**编辑动作脚本**。
3. 右键点击脚本区域，然后点击**添加 IF 语句**。为其设置与面板相同的条件。
4. 在 IF 语句中添加[**设置变量值（FM 变量）**](/action-scripts#set-variable-value-fm-variable)，并设置以下值：

   ```
   show_rules:false
   ```

5. 右键点击 IF 语句，然后点击**追加 ELSE 语句**。在 ELSE 语句中添加**设置变量值（FM 变量）**，并设置以下值：

   ```
   show_rules:true
   ```

这样，每次点击都会切换变量的值：显示的面板会隐藏，隐藏的面板会显示。所有具有相同条件的元素都会一起显示或隐藏。想要更流畅的效果，可将面板的**淡入**和**淡出**设置为**每次**。

有关 IF 和 ELSE 的更多信息，请参阅[动作脚本](/action-scripts#if-else-if-and-else)。

> [!NOTE]
> 游戏关闭后，变量仍会保留，因此下次启动时面板仍会打开。如需每次启动时都关闭面板，请在**管理变量**中右键点击该变量，并启用**游戏启动时清除变量**。

## 循环切换不同版本

按钮还可以在两个以上的版本之间切换，例如在三个背景之间切换：

1. 在**菜单栏 -> 自定义 -> 管理变量**中，添加文本变量 `background`，并将值设为 `0`。
2. 为三个[图像元素](/elements#image)设置**变量值是否为（FM 变量）**条件，变量为 `background`，值分别为 `0`、`1` 和 `2`。
3. 为按钮添加**设置变量值（FM 变量）**，并设置以下值。它会依次计数 `0`、`1`、`2`，然后重新从 `0` 开始：

   ```
   background:{"placeholder":"calc","values":{"decimal":"false","expression":"({"placeholder":"getvariable","values":{"name":"background"}} + 1) % 3"}}
   ```

如需更多版本，请修改末尾的 `3`。数学运算请参阅[**计算器**](/placeholders#calculator)。

# 启用和禁用布局

如需显示或隐藏整个布局：

- 编辑器背景的右键菜单中有**加载条件 [布局范围]**，其作用与元素条件相同。请参阅[布局范围条件](/conditions#layout-wide-requirements)。
- [**切换布局**](/action-scripts#toggle-layout)、[**启用布局**](/action-scripts#enable-layout)和[**禁用布局**](/action-scripts#disable-layout)操作可以通过布局名称启用或禁用布局。

请将按钮放在与它要禁用的布局不同的布局中。否则按钮会随布局一起消失，届时就无法重新启用该布局。
