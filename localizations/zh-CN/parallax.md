# 视差效果

视差效果会在鼠标移动时，让菜单背景或元素稍微移动。让远处的图层移动得少一些，近处的图层移动得多一些，菜单就会显得更有景深。

<img width="640" alt="标题屏幕上的黄昏景观分为四个图层：鼠标移动时，前景树木移动幅度最大，丘陵较小，而群山和天空只移动一点" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/parallax_scene.gif?raw=true">

此效果适用于[元素](/elements)，以及**图片**和**视频**[菜单背景](/menu-backgrounds)。

# 元素

<img width="640" alt="标题屏幕上的按钮在左侧排列成一列。在布局编辑器中，通过点击和 Ctrl + 点击选中五个按钮，将它们的视差效果设为已启用，并将视差强度 (X) 设为 1.0，然后保存并关闭编辑器。在标题屏幕上，鼠标左右移动时按钮会稍微移动，而徽标和景观保持不动" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/parallax_element_settings.gif?raw=true">

1. 在布局编辑器中右键点击元素，然后向下滚动到**视差效果**。
2. 点击**视差效果**，将其设为**已启用**。
3. 点击**视差强度 (X)** 和**视差强度 (Y)**，设置元素的移动幅度。
4. 保存布局并关闭编辑器。元素只会在编辑器外移动。

若要一次为多个元素启用此效果，请先[选中](/layout-editor#selecting)它们（按住 `Ctrl` 并点击可将元素添加到选区），然后右键点击其中一个元素。

| 设置 | 作用 |
|---|---|
| **视差效果** | 开启此效果。 |
| **视差强度 (X)** | 设置元素左右移动的幅度，范围为 `0.0`（完全不移动）到 `1.0`。新元素的默认值为 `0.5`。 |
| **视差强度 (Y)** | 设置元素上下移动的幅度。 |
| **反转视差移动方向** | 让元素与鼠标朝同一方向移动。未启用时，元素会朝相反方向移动。 |

强度设为 `1.0` 时，当鼠标位于屏幕边缘，元素最多会向左右移动屏幕宽度的 5%，或向上下移动屏幕高度的 5%。鼠标位于屏幕中央时，元素会保持在你放置的位置。

- 锚定到带有此效果的元素上的[元素](/positioning-elements)会随其一起移动，且自身的效果会叠加在此基础上。
- **保持在屏幕内**不会让带有此效果的元素保持在屏幕内，因此元素可能会移出屏幕边缘。
- 拉伸的元素不会沿拉伸的方向移动。
- [原版按钮和滑块](/vanilla-elements)只有在你移动过它们之后才会移动。锚点设为**原版 (Vanilla)** 时，它们会保持在游戏放置的位置。
- 按钮显示在哪里，就可以在哪里点击。
- [可滚动区域](/scrollable-areas)、其中的元素以及工具提示元素都不受视差效果影响。

# 菜单背景

<img width="800" alt="布局编辑器的右键菜单，已展开菜单背景和图片选项，可见视差效果、设置视差效果强度 (X)、设置视差效果强度 (Y)和反转视差移动方向" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/parallax_background_settings.png?raw=true">

1. 右键点击编辑器背景，然后打开**菜单背景 -> 图片**（或**视频**）。
2. 点击**视差效果**，将其设为**已启用**。
3. 设置**设置视差效果强度 (X)** 和**设置视差效果强度 (Y)**。

背景的移动幅度远大于元素。背景会根据强度放大，因此边缘不会露出来：强度为 `1.0` 时，背景尺寸是屏幕的两倍，最多可向左右移动半个屏幕的距离。请将数值设低一些：新背景的默认值为 `0.02`，使用 `0.01` 到 `0.1` 通常效果不错。

- **反转视差移动方向**会让背景与鼠标朝同一方向移动。
- **从左向右滑动宽图**和**视差效果**不能同时启用。
- **重复纹理**和**保持背景宽高比**可以与此效果配合使用。
- 背景在布局编辑器中也会移动。

# 打造有景深的场景

本页顶部的场景由标题屏幕上的天空和三个图层组成：

1. 从远到近分层绘制场景，例如天空、群山、丘陵和前景。除天空外，每个图层都应为带透明区域的 PNG 图片。
2. 将天空设为**图片**菜单背景，并开启其视差效果。
3. 将其他图层从远到近依次添加为[图片元素](/elements#image)，让最近的图层位于最上方。
4. 将图层尺寸设置得比屏幕稍大，避免移动时露出边缘。强度为 `1.0` 的图层需要在左右两侧各超出屏幕宽度的 5%，并在上下两侧各超出屏幕高度的 5%。关闭**保持在屏幕内**，即可将图层放置到屏幕边缘以外。
5. 开启每个图层的视差效果：远处图层使用较低的强度，近处图层使用较高的强度。
6. 右键点击编辑器背景，将**原版元素后方显示自定义元素**设为**已启用**，这样图层就会显示在按钮和徽标后方。

以下是此场景使用的强度：

| 图层 | 强度 (X) | 强度 (Y) |
|---|---|---|
| 天空（菜单背景） | `0.02` | `0.01` |
| 群山 | `0.35` | `0.2` |
| 丘陵 | `0.6` | `0.3` |
| 前景 | `1.0` | `0.5` |

> [!TIP]
> 将 Y 轴强度设为 X 轴强度的一半左右。这样，景观中的地面就不会上下晃动得太厉害。

# 实用须知

- 所有移动都以 GUI 的整像素为单位，因此较低的强度会以较小的步幅移动。
- 强度设置支持[占位符](/placeholders)：将鼠标指向某个占位符，然后在其旁边的小菜单中点击**设为纯文本**。使用[变量](/variables)，你还可以让玩家在自己的设置菜单中调低此效果。
