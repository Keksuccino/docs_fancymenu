# 什么是视差效果？

视差效果是一种很酷的视觉技巧，可以让你的菜单背景和元素看起来具有层次感。当你移动鼠标光标时，启用了视差的元素会轻微移动，从而在二维菜单中营造出三维空间的错觉。 

你可以把它想象成坐车时看到的景象——离你更近的东西（比如路牌）看起来移动得比远处的东西（比如山）更快。在 FancyMenu 中，这个原理可以创造出更生动、更具交互性的体验。

# 在 FancyMenu 中哪里可以使用视差？

在 FancyMenu 中，你可以在两个主要位置使用视差效果：

1. **菜单背景**：让整个菜单背景随着鼠标光标轻微移动
2. **元素**：让单个元素（如图片、按钮或文本）独立移动

# 如何为菜单背景使用视差

为菜单背景添加视差效果非常简单：

1. 按 **CTRL+ALT+C** 打开菜单栏，然后进入 **Customization**
2. 新建一个布局，或编辑现有布局
3. 点击 **布局 → 属性** 
4. 打开 **菜单背景**
5. 将背景类型选择为 **Image**
6. 配置你的图片背景：
   - 选择一张图片（本地或来自网络）
   - 点击开关启用 **Parallax Effect**
   - 设置 **Parallax Effect Intensity X** 和 **Parallax Effect Intensity Y**（范围为 0.0 到 1.0）
   - 可选地启用 **Invert Parallax Movement** 来改变方向

> **提示**：强度值越高，背景移动幅度越大。FancyMenu 3.9.0 允许你分别设置 X 和 Y 的强度，因此你可以让横向移动比纵向更强，或者反过来。

# 如何为单个元素使用视差

你也可以为单个元素添加视差，创建分层效果：

1. 在编辑器中点击任意元素将其选中
2. 右键单击该元素打开上下文菜单
3. 向下滚动并找到 **Parallax Effect: Enabled/Disabled**
4. 将其切换为 **Enabled**
5. 调整 **Parallax Intensity X** 和 **Parallax Intensity Y** 的值（范围为 0.0 到 1.0）
6. 可选地启用 **Invert Parallax** 来改变移动方向

# 创建出色视差效果的技巧

## 分层放置元素

通过为不同元素使用不同的视差强度值来营造深度感。你可以分别调整 X 和 Y：

- **背景**：较低强度（0.1-0.3）
- **中间层元素**：中等强度（0.3-0.6）
- **前景元素**：较高强度（0.6-0.9）

当你移动鼠标时，这样就能形成逼真的 3D 效果！

## 结合普通和反向视差

尝试将一些元素设置为 **Invert Parallax Movement: Enabled**，而另一些保持 **Disabled**。这样元素会朝相反方向移动，从而增强层次感。

## 不要过度使用

过多的移动效果可能会分散注意力。请谨慎使用视差效果，尤其是在高强度值下。

# 故障排除

## 视差不起作用？

1. 确认你已经启用了视差效果
2. 检查视差强度是否设置为 0
4. 确认已禁用 "Slide Wide Images From Left To Right" 选项（该选项与视差冲突）

## 视差移动太快/太慢？

调整 **Parallax Intensity X/Y** 的值：
- 较低的值（接近 0）= 移动更慢、更细微
- 较高的值（接近 1）= 移动更快、更明显

# 最后的想法

视差效果是让你的 Minecraft 菜单更生动、更具交互性的绝佳方式。尝试不同的背景和元素视差组合，创建令人惊艳、充满动态感、并且会随着鼠标移动而响应的布局吧！

请记住，最好的效果通常都是细腻而克制的——一点点移动就足以营造沉浸式体验。
