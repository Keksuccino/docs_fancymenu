# 视差效果

视差会根据鼠标移动偏移背景或元素，以营造视觉深度。

# 图片菜单背景

1. 右键单击布局编辑器背景。
2. 打开 [**菜单背景**](./menu-backgrounds) -> **图片**。
3. 设置图片源。
4. 启用 **视差效果**。
5. 设置 X 和 Y 强度值。
6. 可选地启用 **反转视差移动**。

X 和 Y 值分别控制水平和垂直移动。使用从 `0.0`（无）到 `1.0`（最大）的数值。

# 元素

1. 右键单击一个[元素](./elements)。
2. 启用 **视差效果**。
3. 设置 **视差强度 X** 和 **视差强度 Y**。
4. 可选地反转移动方向。

较远的图层使用较低强度，前景图层使用较高强度。较大的差异或反转的图层会产生更强的深度效果。

# 故障排除

- 强度为 `0` 时，该轴不会产生任何移动。
- **从左到右滑动宽图像** 会与背景视差冲突，必须禁用。
- 非常小的移动可能看起来是分段的，因为 GUI 位置使用整像素。
