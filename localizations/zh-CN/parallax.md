# 什么是视差效果？

视差效果是一种很酷的视觉技巧，可以让你的菜单背景和元素看起来更有层次感。当你移动鼠标光标时，启用了视差的元素会轻微移动，从而在二维菜单中营造出三维空间的错觉。

可以把它想象成你坐在车里时看到的景象——离你更近的东西（比如路牌）看起来会比远处的东西（比如山）移动得更快。在 FancyMenu 中，这种思路可以创造出更动态、更有互动感的体验。

# 在 FancyMenu 中哪里可以使用视差？

在 FancyMenu 中，你可以在两个主要位置使用视差效果：

1. **菜单背景**：让整个菜单背景随着鼠标光标轻微移动
2. **元素**：让单个元素（如图片、按钮或文本）独立移动

# 如何为菜单背景使用视差

给菜单背景添加视差效果非常简单：

1. 按 **CTRL+ALT+C** 打开菜单栏，然后进入 **自定义**
2. 新建一个布局或编辑现有布局
3. 点击 **布局 → 属性**
4. 打开 **菜单背景**
5. 将背景类型选择为 **图片**
6. 配置你的图片背景：
   - 选择一张图片（本地或来自网页）
   - 通过点击开关按钮启用 **视差效果**
   - 设置 **视差效果强度 X** 和 **视差效果强度 Y**（介于 0.0 和 1.0 之间）
   - 可选地启用 **反转视差移动** 来改变方向

> **提示**：强度值越高，背景移动得越明显。FancyMenu 3.9.0 允许你分别设置 X 和 Y 强度，因此你可以让水平移动比垂直移动更强，反之亦然。

# 如何为单个元素使用视差

你也可以为单个元素添加视差，以创建分层效果：

1. 在编辑器中点击任意元素将其选中
2. 右键单击该元素以打开上下文菜单
3. 向下滚动并找到 **视差效果：启用/禁用**
4. 将其切换为 **启用**
5. 调整 **视差强度 X** 和 **视差强度 Y** 的值（介于 0.0 和 1.0 之间）
6. 可选地启用 **反转视差** 来改变移动方向

# 创建出色视差效果的技巧

## 为元素分层

通过为不同元素使用不同的视差强度值来营造深度。你可以分别调整 X 和 Y：

- **背景**：较低强度（0.1-0.3）
- **中层元素**：中等强度（0.3-0.6）
- **前景元素**：较高强度（0.6-0.9）

这样在移动鼠标时就能形成更逼真的三维效果！

## 结合正常和反转视差

试着把一些元素设置为 **反转视差移动：启用**，而另一些设置为 **禁用**。这会让元素朝相反方向移动，从而增强层次感。

## 不要过度使用

移动幅度太大可能会分散注意力。请谨慎使用视差效果，尤其是在强度值较高时。

# 故障排除

## 视差效果不起作用？

1. 确认你已经启用了视差效果
2. 检查视差强度是否设置为 0
4. 确认“**从左到右滑动宽图片**”选项已禁用（此选项与视差冲突）

## 视差移动太快/太慢？

调整 **视差强度 X/Y** 的值：
- 较低的值（接近 0）= 移动更慢、更细微
- 较高的值（接近 1）= 移动更快、更明显

## 视差感觉不平滑或有卡顿？

这是视差效果的一个限制，因为 Minecraft 使用基于整数的坐标（整数），所以该效果有时可能会让元素看起来像在“跳动”。不过，如果你使用的是“正常”范围内的视差强度，而不是非常小或非常大的值，这种情况通常不会太明显。
