# 世界创建界面

如果你已经尝试过自定义世界创建界面（也就是“创建世界”、“新世界”、“新游戏”），你大概已经注意到它非常 _难搞_。这是因为这个界面相当复杂，并且其构建方式使得 FancyMenu 很难正确地对其进行自定义，因为按钮和其他 GUI 元素是堆叠在一起的。

在较新的 Minecraft 版本中，由于新的选项卡系统，可自定义性变得更差了。

这一切都导致**不建议**去自定义这个界面，至少不建议进行复杂的自定义，比如编辑现有的 GUI 元素（例如原版按钮等）或添加新的自定义元素。设置一个自定义背景可能还算可行，但除此之外就会变得很混乱，所以最好不要对它做太多自定义。
