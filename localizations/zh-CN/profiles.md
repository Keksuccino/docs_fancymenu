# 配置档案

配置档案包含一套完整的 FancyMenu 设置：布局、资源、变量、设置，以及 `config/fancymenu/` 中的所有其他内容（请参阅[数据存储位置](/data-storage-locations#your-setup)）。使用配置档案，你可以在同一个 Minecraft 实例中保存多套设置，在几秒内切换，还可以将它们打包成一个文件进行分享。

# 配置档案窗口

通过 **菜单栏 -> 自定义 -> 配置档案** 打开。

- 左侧列表显示所有配置档案。已加载的配置档案会排在最前，并标记为 **已激活**。你在 FancyMenu 中所做的每项更改都会直接保存到该档案中。
- 右侧显示所选配置档案的详细信息：图标、标题、版本、作者、布局数量、大小、链接和描述。
- 将鼠标悬停在列表和详细信息下方的按钮上，即可查看按钮名称。右键点击配置档案也能查看相关操作。

你的设置会自动成为第一个配置档案，名为 **我的配置档案**。

# 加载配置档案

选择一个配置档案，然后点击 **加载配置档案**、双击它，或按 `Enter`。

随后，FancyMenu 会使用该配置档案重新加载，就像游戏刚启动时一样。所有其他 FancyMenu 窗口都会关闭；如果你当前不在游戏世界中，游戏会打开标题屏幕。

> [!NOTE]
> 加载配置档案绝不会删除任何内容。当前设置会先另存为一个配置档案，因此你随时都可以切换回来。

# 创建配置档案

- **新建配置档案**（列表下方的 `+` 按钮）会创建一个空白配置档案，并立即打开其详细信息，供你命名。它会保留 FancyMenu 的偏好设置，例如界面缩放和主题，但不包含布局或其他自定义内容。新建的档案不会自动加载。
- **复制**会复制所选配置档案，方便你在不改动原档案的情况下尝试新内容。

# 编辑配置档案详细信息

选择一个配置档案，然后点击 **编辑** 来修改其详细信息：

- **标题**：配置档案唯一必需的信息。
- **版本**和**作者**。多个作者请用逗号分隔。
- **描述**：支持使用 [Markdown](/text-formatting#markdown) 添加粗体、标题和列表等格式。
- **问题反馈页面**：供用户报告配置档案问题的网站。它会显示为 **报告问题**。
- 指向 Discord 服务器、YouTube 频道、网站等的**链接**。点击 **添加链接** 并粘贴链接，FancyMenu 会自动识别平台。
- 图标：点击 **选择图标** 并选择 PNG 图片；点击 **移除图标** 可将其删除。非正方形图片会以中心位置为基准裁剪。

点击 **完成** 后才会保存更改。

# 分享配置档案

> [!CAUTION]
> 配置档案可以执行操作，例如打开链接或运行命令。请只从可信来源导入配置档案。

## 导出

选择一个配置档案，点击 **导出**，然后选择保存位置。系统会生成一个包含完整配置档案的 `.fmp` 文件，供你分享。

## 导入

点击列表下方的 **导入** 并选择一个 `.fmp` 文件，或者将文件拖放到配置档案窗口中。

- 导入的配置档案不会自动加载。像加载其他配置档案一样手动加载即可。
- 如果你已经有该配置档案（例如较旧的版本），可以选择 **替换** 或 **保留两者**。替换当前已加载的配置档案时，新导入的档案会立即加载，而旧档案中的更改将会丢失。
- 使用较新版本 FancyMenu 创建的配置档案会先显示警告，因为其中某些部分可能无法正常使用。
- 只有由 FancyMenu 导出的 `.fmp` 文件才能使用。若要导入普通文件夹，请参阅下一节。

## 添加设置文件夹

有些设置以普通的 `fancymenu` 文件夹形式提供（即他人 `config/fancymenu/` 文件夹的副本），而不是 `.fmp` 文件。要将其添加为配置档案：

1. 如果文件是 `.zip` 格式，请先解压。
2. 将文件夹移至 `<game-directory>/config/fancymenu/profiles/`。如果还没有 `profiles` 文件夹，请创建一个。
3. 打开配置档案窗口，或先关闭再重新打开。FancyMenu 会将该文件夹添加到配置档案列表中。

文件夹中必须直接包含 `customization/` 和 `options.txt` 等文件，而不能再套一层 `fancymenu` 文件夹。除非文件夹中自带配置档案详细信息，否则配置档案会以文件夹名称作为标题。你可以通过 **编辑** 修改标题。

## 布局模板

[Kekscord Discord 服务器](https://discord.gg/rhayah27GC)（Keksuccino 为模组支持设立的官方 Discord 服务器）中的 [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) 频道提供了社区制作的完整设置，适用于 FancyMenu 及其附属模组，例如 SpiffyHUD 和 Drippy Loading Screen。每条帖子都包含下载链接，链接指向 `.fmp` 文件或 `fancymenu` 文件夹。

模板结构复杂，因此不要尝试将其与自己的设置合并。请将模板作为独立的配置档案添加：

1. [导入](#importing) `.fmp` 文件，或[添加文件夹](#adding-setup-folders)。
2. 在配置档案窗口中选择模板，然后点击 **加载配置档案**。

你自己的设置会作为独立配置档案保留，因此随时都可以切换回来。

大多数模板允许你编辑并用于自己的项目（例如整合包），但并非所有模板都如此。请务必查看模板帖子，了解你可以如何使用该模板。

# 删除配置档案

选择一个配置档案并点击 **删除**，或按 `Delete`（macOS 上按 `Fn + Delete`）。删除操作无法撤销；如果想留作备份，请先导出配置档案。

已加载的配置档案无法删除。请先加载另一个配置档案。

# 配置档案的存储位置

- 已加载的配置档案对应 `<game-directory>/config/fancymenu/` 中的内容。
- 其他配置档案都存放在 `<game-directory>/config/fancymenu/profiles/` 中，每个档案各占一个文件夹。点击 **打开文件夹** 可打开所选配置档案所在的文件夹。

`<game-directory>` 是你的实例文件夹，可能与 `.minecraft` 不同。`<game-directory>/fancymenu_data/` 中的数据不属于配置档案，请参阅[数据存储位置](/data-storage-locations#instance-data)。

# 遇到问题时

- **某些文件仍在使用中：** 通常是游戏本身仍在加载内容，例如音频。请等待几秒后重试。如果问题持续存在，请关闭可能正在使用这些文件的程序，例如杀毒软件、云同步程序或文件管理器窗口。
- **上次配置档案切换尚未完成：** 没有任何内容丢失。再次加载一个配置档案，或重启游戏，即可完成切换。
- **磁盘可用空间不足：** 消息中会显示配置档案所需的空间。腾出一些空间后重试。
- 配置档案操作会逐个执行。导出、导入和复制大型配置档案可能需要一些时间；操作进行时会显示 **取消** 按钮。
