# 配置文件

配置文件是一套完整的 FancyMenu 设置：包括某个实例中的所有布局、资源、变量和 FancyMenu 设置。借助配置文件，你可以在同一个 Minecraft 实例中保存多套设置，在几秒内切换它们，还可以将整套设置作为单个文件分享给其他人。

# 打开配置文件窗口

通过 **菜单栏 -> 自定义 -> 配置文件** 打开配置文件窗口。

左侧列表显示你的所有配置文件，右侧显示当前选中配置文件的详细信息。已加载的配置文件会标记为 **当前使用**。你在 FancyMenu 中进行的所有更改都会直接保存到已加载的配置文件中。

你现有的设置会自动成为第一个配置文件，名称为 **我的配置文件**。

> [!TIP]
> 右键点击列表中的配置文件，可以查看针对它的所有操作。

# 切换配置文件

选择一个配置文件并点击 **加载配置文件**，或双击该配置文件。FancyMenu 随后会使用选中的设置重新加载。

> [!NOTE]
> 切换配置文件不会删除任何内容。在加载另一个配置文件之前，你当前的设置会被保存为一个独立的配置文件，因此你随时都可以切换回来。

# 创建配置文件

- **新建配置文件**（列表下方的 **+** 按钮）会创建一个空的配置文件并打开其编辑器。空配置文件会保留你的个人 FancyMenu 偏好设置，例如界面缩放比例和主题。
- **复制** 会创建选中配置文件的副本，方便你在不影响原配置文件的情况下进行尝试。

# 编辑配置文件

点击 **编辑** 可以修改配置文件的标题、版本、作者、描述、图标、问题跟踪器和链接。描述支持 Markdown，图标可以使用任意 PNG 图像。

只有点击 **完成** 后，修改才会保存。

# 分享配置文件

> [!CAUTION]
> 配置文件可以运行操作。请仅从你信任的来源导入配置文件。

## 导出

选择一个配置文件，点击 **导出**，然后选择保存位置。这会创建一个包含完整配置文件的 `.fmp` 文件。

## 导入

点击列表下方的 **导入** 并选择一个 `.fmp` 文件，或者直接将文件拖放到配置文件窗口中。

- 导入的配置文件不会自动加载。请像加载其他配置文件一样手动加载它们。
- 如果你已经拥有相同的配置文件（例如它的旧版本），可以选择 **替换** 或 **两者都保留**。替换当前已加载的配置文件后，会立即加载导入的版本。
- 使用较新版本 FancyMenu 创建的配置文件会显示警告，因为其中的某些部分可能无法正常工作。

## 添加设置文件夹

有些设置以普通的 `fancymenu` 文件夹形式提供，而不是 `.fmp` 文件。要将此类文件夹作为配置文件添加，请将其重命名为你想要的配置文件名称，然后将其移动到 `<game-directory>/config/fancymenu/profiles/`（如果 `profiles` 文件夹尚不存在，请创建该文件夹），最后打开配置文件窗口。FancyMenu 会自动将其添加到配置文件列表中。

# 删除配置文件

选择一个配置文件并点击 **删除**。删除操作无法撤销，因此如果你想保留备份，请先导出该配置文件。

当前已加载的配置文件无法删除。请先加载其他配置文件。

# 配置文件的存储位置

- 当前已加载的配置文件内容位于 `<game-directory>/config/fancymenu/`，与任何 FancyMenu 设置一样。
- 其他配置文件均存储在 `<game-directory>/config/fancymenu/profiles/` 中。点击 **打开文件夹** 可以打开某个配置文件所在的文件夹。

`<game-directory>` 是当前使用的实例文件夹，可能与 `.minecraft` 不同。FancyMenu 保存在 `config/fancymenu/` 之外的运行时状态不属于配置文件，详见[数据存储位置](./data-storage-locations#persistent-runtime-state)。
