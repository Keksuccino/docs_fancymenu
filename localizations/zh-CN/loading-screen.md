# 自定义加载界面

**FancyMenu 不能单独自定义 Minecraft 的加载/启动画面**。这正是我们提供 [Drippy Loading Screen](https://www.curseforge.com/minecraft/mc-mods/drippy-loading-screen) 附加组件的原因（你也可以在 Modrinth 上 [这里](https://modrinth.com/mod/drippy-loading-screen) 找到它）。

# Drippy Loading Screen

如果你是第一次安装 Drippy Loading Screen 附加组件，只需要点击下方高亮显示的小标签，就可以进入对应界面，然后你就能使用 [FancyMenu 编辑器](https://docs.fancymenu.net) 来自定义加载界面。
