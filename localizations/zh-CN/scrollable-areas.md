# 可滚动区域

**可滚动区域**可以容纳其他元素，并让玩家滚动浏览这些元素。它非常适合放置较长的按钮列表、世界或服务器选择器、物品展示、新闻面板，以及其他无法在一个屏幕内完整显示的内容。

区域中的所有内容都会随区域一起滚动，并在区域边缘被裁切。

<img width="800" alt="将按钮放入可滚动区域并进行堆叠" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/scroll_area_showcase.gif?raw=true">

> [!NOTE]
> 只有添加到布局中的元素才能放入区域。[原版元素](/vanilla-elements)不能放入，因为它们属于菜单本身。

# 添加可滚动区域

1. 在布局编辑器中打开一个布局。
2. 右键点击编辑器背景，然后选择 **新建元素 -> 可滚动区域**。
3. 将元素拖入区域。

# 放入和移出元素

- 将元素拖到区域上即可将其放入。区域接收元素时会亮起。只有当元素的一部分位于区域内时，它才会被放入。
- 要一次拖动多个已选元素，请在开始拖动时按住 `Ctrl`（macOS 上为 `Cmd`）。
- 将元素拖到区域边缘附近时，区域会滚动，方便你访问其中的所有部分。你也可以在编辑器中使用鼠标滚轮滚动区域。
- 要移出元素，可将它拖出区域，或右键点击它并选择 **移出可滚动区域**。元素会留在屏幕上的原位置。
- 区域也可以嵌套在其他区域中。

## 图层

在[图层小部件](/layout-editor#scrollable-areas)中，区域的元素会显示在该区域下方。拖动图层即可将元素放入或移出区域，也可以更改它们的顺序。点击区域图层上的折叠按钮，可在列表中隐藏其中的元素。

## 复制和删除

- 复制区域时，其中的所有内容也会一并复制。
- 删除仍包含元素的区域时，系统会询问如何处理这些元素：**删除元素**会一并删除它们；**保留元素**会让它们留在屏幕上的原位置。

# 排列元素

右键点击区域并打开 **排列方式**。**模式**用于设置区域如何放置其中的元素：

- **锚点**：像布局的其他部分一样，由你自行放置元素。新建区域默认使用此模式。
- **堆叠**：元素依次排列。
- **网格**：元素排列在大小相同的单元格中。
- **流式布局**：元素彼此相邻排列，排满一行后会另起一行。

<img width="800" alt="堆叠、网格和流式布局模式下的可滚动区域" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/scroll_area_modes.png?raw=true">

## 锚点模式

区域中的元素有自己的锚点，这些锚点参照的是区域内容，而不是屏幕。例如，**左上角**锚点指的是内容的左上角，底部锚点则会固定在内容末端。关于锚点的工作方式，请参阅[定位元素](/positioning-elements)。

- **水平拉伸**和**垂直拉伸**会让元素的宽度或高度与内容一致。
- 元素只能锚定到同一区域中的其他元素。将元素移入或移出区域时，跨越区域边界进行锚定的元素会改用**左上角**锚点，并保持在原位。

### 内容大小

在锚点模式下，你可以决定内容的大小，也就决定了区域可以滚动多远。

选中区域，然后拖动内容末端的控制柄。要继续拖动到区域边缘之外，请将控制柄拖过边缘，此时区域会随之滚动。

<img width="698" alt="已选中可滚动区域的内容控制柄" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/scroll_area_content_handle.png?raw=true">

你也可以右键点击区域并打开 **内容大小**：

- **内容宽度**和**内容高度**可通过数值设置大小。它们支持[占位符](/placeholders)。使用占位符时，无法拖动控制柄。
- **适应内容**会让内容恰好在最后一个元素的末端结束。锚定到内容中部或末端的元素会随内容移动，因此不会计入计算。

内容的大小不会小于区域，并且只会沿区域可滚动的方向扩大。

## 堆叠、网格和流式布局

- 区域会自动放置元素，内容也会随元素自动扩展。
- 拖动元素即可更改顺序。指示线会显示元素将被放置的位置。
- 从锚点模式切换到这些模式之一时，元素会保留其在屏幕上原有的顺序。切回锚点模式时，每个元素都会保留原位置。
- 被其[条件](/conditions)隐藏的元素不会留下空隙。
- 这些模式不支持拉伸。
- 这些模式只能沿一个方向滚动。设置为**双向**的区域会垂直滚动。

打开 **排列方式**可进行更精细的调整：

| 设置 | 功能 |
|---|---|
| **对齐方式** | 元素沿排列方向的垂直方向放置的位置：**起始**、**居中**、**末尾**或**填满**。选择**填满**后，元素会尽可能占满可用宽度（对于横向滚动的区域，则占满可用高度）。流式布局没有**填满**选项。 |
| **间距** | 元素之间的距离。 |
| **内边距** | 元素与内容边缘之间的距离。 |
| **每行元素数** | 仅适用于网格。设置每行放置多少个元素。 |
| **尽可能多地排列** | 仅适用于网格。每行放入空间允许的尽可能多的元素，而不是使用固定数量。**最小单元格大小**用于决定每行能放多少个元素。 |

# 滚动

玩家可以使用鼠标滚轮滚动区域。按住 `Shift` 可横向滚动。

- **滚动方向**用于设置区域的滚动方向：**垂直**、**水平**或**双向**。在无法滚动的方向上，内容大小与区域完全一致。
- 区域中的文本元素会优先滚动。文本滚动到末端后，区域才会继续滚动。
- 玩家按 `Tab` 在按钮间切换时，区域会滚动到选中的按钮。

**滚动**、**自动滚动**和**滚动条**菜单中的设置与文本元素相同。请参阅[菜单中的文本](/text-in-menus#scrolling-settings)了解所有设置。以下是不同之处：

- **吸附**可以让内容**吸附到元素**，使元素始终位于区域起始处；也可以选择**吸附到页面**。
- 开启**拖动滚动**后，按钮及区域中的其他元素仍可正常使用。
- 滚动滑块默认是像素手柄；你也可以为其设置自己的**滚动滑块纹理**或**滚动滑块颜色 [HEX]**。

# 背景

区域会在内容后方绘制一个面板。打开 **背景**可进行更改。其工作方式与[文本元素的背景](/text-in-menus#background)相同：使用**显示背景**关闭背景，使用[九宫格切片](/nine-slicing-and-tiling)或平铺来应用自定义纹理，并通过**内边距**更改背景的延伸范围。

# 使用操作控制滚动

你也可以在 FancyMenu 的其他部分控制和监视区域：

- **滚动元素**[操作](/action-scripts)可以将区域滚动到起始处、末端、某个位置或其中的某个元素。
- **元素滚动位置**、**元素滚动百分比**和**元素滚动内容大小**[占位符](/placeholders)会告知你区域的滚动距离以及内容大小。
- **元素已滚动到末端**[条件](/conditions)用于检查区域是否已滚动到末端。
- **元素滚动时**、**元素滚动到起始处时**和**元素滚动到末端时**[监听器](/listeners)会在区域滚动时运行操作。

所有这些功能都需要区域的[元素标识符](/element-identifiers)。例如，以下内容会显示区域的滚动百分比，范围为 0 到 100：

```
{"placeholder":"scroll_area_scroll_percent","values":{"element_identifier":"3f2a9c1e-7b4d-4e8a-9c2f-1d5e6a7b8c9d-1763950000000","axis":"vertical"}}
```

# 其他须知

- 隐藏区域会隐藏其中的所有内容，区域的不透明度也会应用于其中的所有内容。
- 区域不能旋转或倾斜，区域及其中的元素也不支持视差效果。
- 区域中的工具提示元素会在区域边缘被裁切，除非它们跟随鼠标移动。
