# 布局模板

如果你想下载 FancyMenu 或其某个扩展的设计模板，比如 SpiffyHud 或 Drippy Loading Screen，最好的查看地点是 Kekscord Discord 服务器（Keksuccino 官方的模组支持 Discord 服务器）中的 [#layout-templates](https://discord.com/channels/704163135787106365/1234093433795383316) 频道。这个频道包含社区制作的完整 FancyMenu 配置，并为它们提供下载链接。

其中的所有模板帖子都遵循相同的模式。它们都应该提供一个完整 FancyMenu 配置的下载链接，其中包含一个 `fancymenu` 文件夹，你应该用它来替换自己的 `/config/fancymenu/`，就像 [模组包](/modpacks) 页面中所描述的那样。

由于这些模板通常非常复杂，不建议尝试把模板与你现有的配置合并，这也是为什么你应该直接用模板中的 `fancymenu` 文件夹替换现有文件夹。

# 编辑模板或将其用于项目

频道中的大多数模板都允许你编辑它们，甚至可以将其用于你自己的项目中，比如模组包，但非常重要的是，你**必须先查看模板帖，确认你被允许对它做什么**！

并不是所有模板都允许你做所有事情。
