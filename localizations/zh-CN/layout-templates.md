# 布局模板

如果你想下载 FancyMenu 或其附加组件（例如 SpiffyHUD 或 Drippy Loading Screen）的设计模板，最佳去处是 [Kekscord Discord 服务器](https://discord.gg/rhayah27GC)（Keksuccino 官方的模组支持 Discord 服务器）中的 [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) 频道。该频道包含由社区制作的完整 FancyMenu 配置，并提供所有配置的下载链接。

其中的所有模板帖子都遵循相同的格式。每个帖子都应包含完整 FancyMenu 配置的下载链接，文件格式可能是配置文件（`.fmp`），也可能是 `fancymenu` 文件夹。

> [!CAUTION]
> 社区模板可能会运行操作。请仅从你信任的来源导入模板。

# 安装模板

模板是完整的 FancyMenu 配置，而且大多数都非常复杂，因此不建议尝试将模板与你现有的配置合并。请将其作为独立的[配置档案](./profiles)添加：

- **`.fmp` 文件：** 打开**菜单栏 -> 自定义 -> 配置档案**，然后[导入](./profiles#importing)该文件，例如将其拖放到窗口中。
- **`fancymenu` 文件夹：**[将文件夹添加为配置档案](./profiles#adding-setup-folders)。

然后在配置档案窗口中选择模板，并点击**加载配置档案**。你当前的配置仍会作为独立的配置档案保留，因此随时都可以切换回来。

# 编辑模板或将其用于项目

频道中的大多数模板都允许你进行编辑，甚至将其用于你自己的项目（例如整合包），但非常重要的一点是：**请查看模板帖子，确认你可以对其进行哪些操作**！

并非所有模板都允许你随意使用。
