# 修复音频文件

Minecraft 对它播放的音频文件有点挑剔。
有时会出现这样的情况：音频文件在其他音频播放器里都能正常播放，但 FancyMenu 却无法播放它们。
如果是这种情况，你可以尝试修复音频文件，让它能在 Minecraft 中正常工作。

# OGG 文件

在大多数情况下，修复 OGG 文件都很简单。

90% 的音频文件问题，只要重新转换一次文件就能解决。

1. 前往 https://convertio.co/ogg-mp3/，将你的 OGG 转换为 MP3。
2. 前往 https://convertio.co/mp3-ogg/，把上一步得到的 MP3 再转换回 OGG。

现在这个文件应该可以正常工作了。
如果还是不行，请确认它不是一个超大的音频文件，并检查该音频文件是否能在其他音频播放器中正常播放。

# WAV 文件

对于 WAV 文件，通常是因为采样率不受支持之类的问题，导致音频无法在 Minecraft 中正常工作。

请确保你的音频满足以下条件：

- 采样率为 48KHz
- 位深为 16bit
- 是一个有效的 WAV 文件，并且能在 MC 之外正常播放

你可以使用这个网站轻松地（重新）转换你的音频，使其具有正确的位深和采样率：
https://audio.online-convert.com/convert-to-wav

**重要：**
即使你认为你的音频已经具备正确的格式、位深和采样率，也请务必使用上面提到的网站再重新转换一次。

# 其他原因

有时问题并不在于文件本身损坏，而是其他内容没有正确配置等。

## 音量过低

也许你的 Minecraft 音量太低，以至于你听不到音频。
请确保 MASTER 通道以及所有其他通道的音量都足够大。

## 模组冲突

也许另一个模组与我所使用的音频系统不兼容。
在这种情况下，请在 GitHub 上提交一个 issue，非常感谢。
