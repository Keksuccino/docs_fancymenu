# 自定义 GUI

自定义 GUI 是你自己创建的菜单，例如整合包信息界面、服务器大厅或规则页面。它们初始为空，你可以像创建其他菜单一样，使用[布局](/layout-editor)填充内容。之后可通过按钮、按键和命令打开它们。

# 创建自定义 GUI

<img width="800" alt="打开管理自定义 GUI，点击新建 GUI，输入标识符 modpack_info，开启弹出模式，然后打开新建的自定义 GUI" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/custom_guis_new.gif?raw=true">

1. 打开 **菜单栏 -> 自定义 -> 自定义 GUI -> 管理自定义 GUI**。
2. 点击 **新建 GUI**。
3. 输入一个**自定义 GUI 标识符**，例如 `modpack_info`，设置好[选项](#设置)，然后点击**完成**。
4. 在列表中点击新建的自定义 GUI，然后点击**打开 GUI**。
5. 点击**完成**，关闭**管理自定义 GUI**。

只有点击**完成**或**打开 GUI**时，**管理自定义 GUI**才会保存更改。点击**取消**则会丢弃更改。

## 标识符

按钮、命令和布局通过标识符查找自定义 GUI。

- 只能使用小写字母、数字、`.`、`_` 和 `-`。每个自定义 GUI 的标识符都必须唯一。
- 不要使用[其他屏幕的标识符](/screen-identifiers)，例如 `title_screen`。否则，自定义 GUI 会与该屏幕共用布局。
- 如果之后更改标识符，使用旧标识符的布局、按钮和命令将无法再找到它。改回原来的标识符后，它们就会恢复。

## 构建布局

1. 打开自定义 GUI。
2. 点击 **菜单栏 -> 自定义 -> 布局 -> 新建 -> 当前屏幕**。自定义 GUI 始终启用自定义功能。
3. 添加元素并保存布局。请参阅[布局编辑器](/layout-editor)。

自定义 GUI 内没有任何内容，甚至没有返回按钮。添加一个带有[**返回上一个屏幕**](/action-scripts#back-to-last-screen)操作的[按钮](/elements#button)，或者保持开启**允许按 ESC 关闭 GUI**，这样玩家就能离开。

# 设置

在**管理自定义 GUI**中点击**编辑 GUI**，即可更改所选自定义 GUI 的设置。

| 设置 | 功能 |
|---|---|
| **自定义 GUI 标识符** | 自定义 GUI 的名称。请参阅[标识符](#标识符)。 |
| **屏幕标题（可选）** | 显示在 GUI 顶部的白色标题。留空则不显示标题。支持[占位符](/placeholders)；游戏、模组和资源包的本地化键会以玩家所用的语言显示。 |
| **允许按 ESC 关闭 GUI** | 按 `Esc` 关闭 GUI。默认开启。 |
| **暂停游戏/世界** | GUI 打开时暂停单人游戏世界。默认开启。 |
| **渲染世界背景** | 游戏过程中在 GUI 后方显示世界。若不在世界中，或此选项关闭，则显示 Minecraft 全景背景。默认开启。 |
| **渲染世界背景叠加层** | 模糊并调暗 GUI 后方的世界或全景背景，效果类似暂停菜单。仅在开启**渲染世界背景**时生效；若该选项关闭，全景背景始终会被模糊并调暗。默认开启。 |
| **弹出模式** | 在打开该自定义 GUI 的菜单上方显示它。请参阅[弹出模式](#弹出模式)。 |
| **弹出模式背景叠加层** | 模糊弹出窗口后方的菜单。仅在开启**弹出模式**时生效。默认开启。 |

- 模糊强度与 Minecraft 的**菜单背景模糊**选项相同。
- 如果布局中添加了[菜单背景](/menu-backgrounds)，它会覆盖所有这些背景：世界、全景背景以及弹出窗口后方的菜单。
- 无法在布局编辑器中更改自定义 GUI 的标题（**自定义屏幕标题**）。请改为更改**屏幕标题（可选）**。如果想使用单独设置字体、颜色或位置的标题，请将此项留空并添加一个[文本元素](/elements#text)。

## 弹出模式

启用**弹出模式**后，打开自定义 GUI 的菜单及其布局会继续显示在后方。弹出窗口打开时，无法点击后方菜单。

- 弹出窗口最适合用于信息框、确认框或设置面板等小型界面。请留出一些空白，让后方菜单能够显示出来。
- 不要为弹出窗口的布局添加菜单背景，否则后方菜单会消失。
- 如果在没有打开任何菜单时打开自定义 GUI（例如游戏过程中按下按键），后方就没有菜单可显示。这时它会显示常规背景。

# 打开自定义 GUI

所有能打开屏幕的方式都可以通过自定义 GUI 的标识符来打开它：

- **按钮：**使用[**打开屏幕或自定义 GUI**](/action-scripts#open-screen-or-custom-gui)操作，并将值设为 `modpack_info`。
- **按键：**添加一个[**按下键盘按键时**侦听器](/listeners#listener-variables)，并设置相同的操作。它可在菜单中和游戏过程中打开自定义 GUI。
- **命令：**使用 `/openguiscreen modpack_info`，也可以从服务器、命令方块和任务奖励中调用。请参阅[命令](/commands#openguiscreen)。
- **离开世界时：**使用带有该标识符的[**离开世界或服务器**](/action-scripts#leave-world-or-server)操作，即可在离开后打开自定义 GUI。

自定义 GUI 属于每位玩家自己的 FancyMenu 配置。服务器只能打开玩家本地已有的自定义 GUI，例如整合包提供的自定义 GUI。

离开自定义 GUI 的方式：

- 按 `Esc`（需开启**允许按 ESC 关闭 GUI**），或使用**返回上一个屏幕**操作，即可返回打开该 GUI 前所在的菜单。如果当时没有打开任何菜单，按 `Esc` 会返回游戏。
- 使用[**关闭屏幕**](/action-scripts#close-screen)操作即可关闭它。如果当前不在世界中，则会打开标题屏幕。

# 替换现有屏幕

自定义 GUI 可以替换游戏或模组中的菜单。每当该菜单原本要打开时，都会改为打开自定义 GUI。

> [!WARNING]
> 被替换的菜单将永远不会打开，因此它原本要执行的操作也不会发生；依赖该菜单的其他模组也可能因此出错。尽可能使用常规布局修改菜单。只有在布局无法满足需求时，才替换菜单。

1. 开启 **菜单栏 -> 自定义 -> 设置 -> 高级自定义模式**。
2. 打开要替换的菜单。
3. 点击 **菜单栏 -> 自定义 -> 自定义 GUI -> 用自定义 GUI 替换当前屏幕**。
4. 确认警告，然后在**选择自定义 GUI**中选择要使用的自定义 GUI。

自定义 GUI 会立即打开。按 `Esc` 或使用其中的**返回上一个屏幕**操作，会返回被替换的菜单打开之前所在的菜单。

要撤销替换，请打开 **菜单栏 -> 自定义 -> 自定义 GUI -> 管理已替换的屏幕**，点击该屏幕下方的**删除替换规则**，然后点击**完成**。

> [!TIP]
> 如果只想在某些情况下替换菜单，例如仅在某个[变量](/variables)已设置时替换，可以改用带有 IF 语句的[**屏幕打开时**侦听器](/listeners#on-screen-opened)。

# 管理自定义 GUI

- **管理自定义 GUI**中的**新建 GUI**、**编辑 GUI**和**打开 GUI**，分别用于添加、修改和打开自定义 GUI。
- 点击**删除 GUI**并确认后，即可删除所选自定义 GUI。其布局会保留，并在新建具有相同标识符的自定义 GUI 时重新显示。
- 使用搜索栏可按标识符查找自定义 GUI。
- **菜单栏 -> 帮助 -> 导出供 AI 使用 -> 自定义 GUI**可导出所有自定义 GUI 和替换规则，供[AI 对话](/export-for-ai)使用。

自定义 GUI 和替换规则保存在 `config/fancymenu/custom_gui_screens.txt` 中；其布局则与其他布局一样保存在 `config/fancymenu/customization/` 中（请参阅[数据存储位置](/data-storage-locations)）。每个[配置档案](/profiles)都有各自的自定义 GUI。
