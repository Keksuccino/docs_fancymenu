# 菜单背景

FancyMenu 允许你为菜单设置自定义背景。你可以使用图像、动画纹理、幻灯片放映、立方全景、颜色、浏览器、视频、GLSL 着色器等。

# 设置背景

在 FancyMenu 3.9.0+ 中，菜单背景自定义可直接从布局编辑器的上下文菜单中进行：

1. 打开布局编辑器。
2. 右键单击编辑器背景。
3. 打开 **菜单背景**。
4. 启用并配置你想要的背景类型。

常见的背景类型包括：

- 原版
- 图像
- 幻灯片放映
- 立方全景
- 颜色（HEX）
- 浏览器
- 视频
- GLSL 着色器
- 视频 [MCEF]（已弃用）
- 等等..

旧的 **视频 [MCEF]** 背景类型在 FancyMenu 3.9.0 中已弃用。对于新布局，请使用由 Watermedia V3 提供支持的新原生 **视频** 背景。

# 移除自定义背景

再次打开 **菜单背景**，并禁用/移除你不再需要的自定义背景类型。如果没有任何自定义背景类型处于活动状态，屏幕将回退到其正常的原版背景行为。

# 叠加背景

FancyMenu 3.9.0 允许在同一个布局中启用多个菜单背景类型。活动背景会以堆叠方式渲染，因此你可以将基础图像或全景与半透明叠层、浏览器层、着色器层、视差层以及其他效果组合起来。

如果你还启用了多个布局，它们的背景堆叠也可以相互组合。要对布局进行排序并让它们按特定顺序显示，请右键单击编辑器背景，然后点击 **布局索引**。

# 透明背景

由于背景后面没有任何内容，因此最底层的背景无法设置为透明，因为那样会导致图形故障。但在堆叠背景的设置中，完全可以使用透明度，只要最底层保持完全不透明即可。这样你就可以在底层之上添加半透明背景层。

要让背景图像变为半透明，请使用你喜欢的图像编辑器。

# 浏览器背景

**浏览器** 背景类型的工作方式与浏览器元素类似，但它会填满整个屏幕并自动获得焦点。这适用于全屏网页内容、本地 HTML 页面或网页视频层。

# GLSL 着色器背景

**GLSL 着色器** 背景类型可以渲染自定义 GLSL 着色器，并支持类似 Shadertoy 的着色器编写方式。有关支持的 uniform 和着色器结构，请参阅 [GLSL 着色器 API](/glsl-shader-api) 页面。
