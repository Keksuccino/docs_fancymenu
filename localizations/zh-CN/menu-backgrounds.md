# 菜单背景

FancyMenu 允许你为菜单设置自定义背景。你可以使用图片、动画纹理、幻灯片、立方全景、颜色、浏览器、视频、GLSL 着色器等。

# 设置背景

可通过布局编辑器的上下文菜单来配置菜单背景：

1. 打开布局编辑器。
2. 右键单击编辑器背景。
3. 打开 **菜单背景**。
4. 启用并配置你想要的背景类型。

常见的背景类型包括：

- 原版
- 图片
- 幻灯片
- 立方全景
- 颜色（HEX）
- 浏览器
- 视频
- GLSL 着色器
- 视频 [Rinku]（已弃用）
- 其他附加组件背景类型

旧的 **Video [Rinku]** 背景类型已弃用。新布局请使用由 Watermedia V3 提供支持的原生 **视频** 背景。详见 [此处](./video)。

# 移除自定义背景

再次打开 **菜单背景**，然后禁用/移除你不再需要的自定义背景类型。如果没有任何自定义背景类型处于启用状态，界面将回退到正常的原版背景行为。

# 背景叠加

一个布局中可以启用多个菜单背景类型。启用的背景会按层叠方式渲染，因此可以将基础图片或全景与半透明的浏览器层、着色器层、视差层或其他图层组合使用。

如果你还启用了多个布局，它们的背景层叠也可以相互组合。若要对布局进行排序并让它们按特定顺序显示，右键单击编辑器背景，然后点击 **布局索引**。

# 透明背景

FancyMenu 会在启用的自定义背景后方渲染一个黑色底层。因此，最底层背景中的透明像素会显示为黑色。请先使用不透明的基础背景，再在其上叠加半透明背景。

要让背景图片变为半透明，请使用你喜欢的图片编辑器进行处理。

# 浏览器背景

**浏览器** 背景类型的工作方式类似于 [浏览器元素](./elements#browser)，但它会填满整个屏幕并自动获得焦点。这适用于全屏网页内容、本地 HTML 页面或网页视频图层。

# GLSL 着色器背景

**GLSL 着色器** 背景类型可渲染自定义 GLSL 着色器，并支持 Shadertoy 风格的着色器编写。有关支持的 uniform 和着色器结构，请参阅 [GLSL 着色器 API](/glsl-shader-api) 页面。
