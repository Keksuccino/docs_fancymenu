# 菜单背景

FancyMenu 允许你为菜单设置自定义背景。你可以使用图片、动画纹理、幻灯片放映、立方全景、颜色、浏览器、视频、GLSL 着色器等。

# 设置背景

菜单背景自定义可通过布局编辑器的上下文菜单使用：

1. 打开布局编辑器。
2. 右键单击编辑器背景。
3. 打开 **菜单背景**。
4. 启用并配置你想要的背景类型。

常见的背景类型包括：

- 原版
- 图片
- 幻灯片放映
- 立方全景
- 颜色（HEX）
- 浏览器
- 视频
- GLSL 着色器
- 视频 [MCEF]（已弃用）
- 其他附加组件背景类型

旧的 **视频 [MCEF]** 背景类型已弃用。对于新布局，请使用由 Watermedia V3 支持的原生 **视频** 背景。参见 [视频](./video)。

# 移除自定义背景

再次打开 **菜单背景**，并禁用/移除你不再需要的自定义背景类型。如果没有任何自定义背景类型处于活动状态，屏幕将回退到其正常的原版背景行为。

# 叠加背景

一个布局中可以启用多个菜单背景类型。活动背景会以堆叠方式渲染，因此基础图片或全景可以与半透明的浏览器、着色器、视差或其他图层组合。

如果你还启用了多个布局，它们的背景堆叠也可以相互叠加。要对布局进行排序并让它们按特定顺序显示，右键单击编辑器背景，然后点击 **布局索引**。

# 透明背景

FancyMenu 会在活动的自定义背景后方渲染一个黑色底层。因此，最底部背景中的透明像素会显示为黑色。请使用不透明的基础背景，再在其上方叠加半透明背景。

要让背景图片变为半透明，请使用你喜欢的图片编辑器。

# 浏览器背景

**浏览器** 背景类型的工作方式类似于 [浏览器元素](./elements#browser)，但它会填满整个屏幕并自动获得焦点。这对于全屏网页内容、本地 HTML 页面或网页视频图层非常有用。

# GLSL 着色器背景

**GLSL 着色器** 背景类型可以渲染自定义 GLSL 着色器，并支持类似 Shadertoy 的着色器编写方式。有关支持的 uniform 和着色器结构，请参见 [GLSL 着色器 API](/glsl-shader-api) 页面。
