# 世界加载界面

当你加载进入一个世界或加入服务器时，你可能已经注意到那里会出现一些你实际上无法自定义的界面，因为它们会自动关闭。

要编辑它们，你需要打开一个会一直保持开启的实例，这可以通过打开它们的“虚拟界面实例”来实现。

“虚拟界面实例”是 FancyMenu 的一项功能，它可以让你打开一些消失得太快、无法直接自定义的界面。

要查看所有可以通过虚拟界面实例功能打开的界面，请点击 **菜单栏 -> 工具 -> 虚拟界面实例**。打开的菜单会显示所有可以作为虚拟界面实例打开的界面。**左键单击**菜单中的界面，会为你打开一个虚拟实例，方便你从容进行自定义。

例如，当加入一个世界或服务器时，加载过程中至少会显示以下两个界面：

- 关卡加载界面（即：世界加载界面）
- 通用泥土消息界面（即：泥土消息界面）

> **重要：**“世界加载界面”与“游戏加载界面”（即：启动画面或资源重新加载界面）并不是同一个界面。“游戏加载界面”可以使用 **Drippy Loading Screen** 进行自定义，它是 FancyMenu 的一个附加组件。
