# 自定义鼠标光标

向布局添加一个 [**光标**元素](/elements#cursor)，即可替换该屏幕上的系统光标：

1. 选择 **新建元素 -> 光标**。
2. 设置带有 RGBA 颜色的 PNG 纹理。
3. 将 **热点 X** 和 **热点 Y** 设置为纹理上应触发点击的像素位置。
4. 如果想在编辑时检查光标，请启用编辑器预览。
5. 如果希望同一个光标显示在多个受支持的屏幕上，请使用[通用布局](/universal-layouts)。

建议使用较小的光标纹理，例如 `32×32` 或 `64×64`。光标的外观和行为可能因操作系统而异。
