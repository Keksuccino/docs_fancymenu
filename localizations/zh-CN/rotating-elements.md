# 旋转元素

从 FancyMenu v3.8.0 开始，大多数元素都可以旋转了！

要旋转某个元素，请在布局编辑器中选中它。如果你看到元素周围有一个圆形，就表示它带有一个可拖拽的控制点，你可以抓住它来围绕元素轴心旋转。

如果元素周围没有圆形，就不能旋转它。

# 高级

你也可以右键单击该元素，通过直接文本输入手动设置旋转值。这个直接输入支持[占位符](/placeholders)，因此当你将其与占位符结合使用时，可以动态更改元素的旋转，从而获取 FancyMenu 变量值或类似内容。

# 按钮、滑块和其他可交互元素

对于可交互元素，也可以旋转它们，但这种旋转仅仅是视觉上的。例如，按钮仍然只会响应其原始区域内的点击，即使旋转后它可能已经部分移出了该区域。
