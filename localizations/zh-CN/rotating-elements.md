# 旋转和倾斜元素

大多数元素都可以旋转和倾斜。这两种操作都会围绕元素中心进行，且不会改变元素的位置和大小。

- **旋转**会像时钟指针一样转动元素。
- **垂直倾斜**会让元素向后倾斜，**水平倾斜**会让元素向一侧倾斜。倾斜后的元素不会显示透视效果，因此只会变矮或变窄。两种倾斜同时使用时，元素还会产生斜切效果。

# 在布局编辑器中

<img width="800" alt="在布局编辑器中，使用圆圈上的控制柄旋转 Season 3 贴纸，然后使用 Patch Notes 面板右侧和下方线条上的控制柄倾斜该面板" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/rotating_tilting_editor.gif?raw=true">

在[布局编辑器](/layout-editor)中选择一个元素，然后拖动它的控制柄：

- 元素周围圆圈上的控制柄用于旋转元素。
- 元素右侧线条上的控制柄用于设置**垂直倾斜**，下方线条上的控制柄用于设置**水平倾斜**。线条中点表示不倾斜。

拖动时：

- 按住 `Shift` 可按固定角度步进：旋转每步 45 度，倾斜每步 15 度。
- 接近 0 度时，控制柄会吸附到 0 度，方便将元素重新摆正。
- 元素左上方会显示其旋转和倾斜角度。

须知：

- 选框始终保持水平和垂直。点击选框内部即可选择或移动元素。
- 只有选中单个元素时才会显示控制柄。
- 没有圆圈或线条的元素无法旋转或倾斜。请参阅[无法旋转或倾斜的元素](#无法旋转或倾斜的元素)。
- **菜单栏 -> 窗口 -> 元素旋转控制**和**元素倾斜控制**可隐藏所有元素的控制柄。

# 精确数值

右键单击元素可找到以下设置。每项设置都有**通过数字选择器设置**、**设为纯文本**和**重置为默认值**选项。

| 设置 | 说明 |
|---|---|
| **旋转** | 顺时针旋转的角度，例如 `90` 表示旋转四分之一圈。负值表示逆时针旋转。 |
| **垂直倾斜** | 向后倾斜的角度，范围为 `-60` 到 `60` 度。 |
| **水平倾斜** | 向一侧倾斜的角度，范围为 `-60` 到 `60` 度。 |

单独使用一种倾斜时，正值和负值的显示效果相同。两种倾斜同时使用时，正负号会决定元素的斜切方向。

## 使用占位符

要通过[变量](/variables)或其他[占位符](/placeholders)旋转或倾斜元素：

1. 右键单击元素，然后启用**高级旋转模式**、**高级垂直倾斜模式**或**高级水平倾斜模式**。
2. 单击**旋转**、**垂直倾斜**或**水平倾斜**，选择**设为纯文本**，然后输入占位符。

高级模式会保存各自的数值并隐藏控制柄，因此拖动时不会覆盖占位符。关闭高级模式后，元素会恢复为原来的数值。

下面的 **Rotation（旋转）** 设置启用了**高级旋转模式**，可让徽标每 3.6 秒旋转一圈。将除数设为大于 `10` 的值可降低旋转速度：

```
{"placeholder":"calc","values":{"expression":"{"placeholder":"unix_time"} / 10 % 360"}}
```

下面的设置可让指针指向变量 `needle_angle` 指定的位置。你可以通过按钮或[滑块](/elements#slider)来设置该变量：

```
{"placeholder":"getvariable","values":{"name":"needle_angle"}}
```

# 点击和鼠标交互

<img width="800" alt="指针悬停在旋转后的 Join Server 按钮上：按钮原本的水平矩形四角处没有反应，而按钮当前显示出来的边缘位置会亮起" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/rotating_tilting_hover.gif?raw=true">

按钮、滑块以及文本元素中的链接和滚动条，都会在其实际显示的位置响应鼠标，即使它们已旋转或倾斜也是如此。条件[**元素是否被悬停**](/conditions#is-element-hovered)、[**是否有任意元素被悬停**](/conditions#is-any-element-hovered)和[**是否有任意按钮被悬停**](/conditions#is-any-button-hovered)也是如此。

> [!NOTE]
> 复选框、文本输入框、拖动器和浏览器仍会在未旋转或倾斜时所占的矩形区域内响应鼠标。请保持这些元素水平和垂直。

# 无法旋转或倾斜的元素

- 既不能旋转也不能倾斜：[可滚动区域](/scrollable-areas)、[GLSL 着色器](/elements#glsl-shader)、[方块/物品 JSON 模型](/elements#blockitem-json-model)、[玩家实体](/player-entities)和[原版元素](/vanilla-elements)，例如屏幕本身的按钮。
- 可以旋转但不能倾斜：[工具提示](/elements#tooltip)和[物品](/elements#item)。

可滚动区域中的元素可以旋转和倾斜，只有区域本身不能。

[启动文本](/splash-text)元素在其右键菜单靠下的位置还有自己的**旋转**设置，可用于调整其典型的倾斜效果。该设置会与本页介绍的旋转功能共同生效。
