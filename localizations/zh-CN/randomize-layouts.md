# 随机化

FancyMenu 提供了许多功能，可帮助你随机化布局或其中的一部分。

例如，如果你希望用户每次打开某个界面时都看到不同的屏幕背景，或者在加载界面中显示随机提示，这会很有用。

# 随机化布局

FancyMenu 中有一项功能，可以让你创建一组布局，系统会从中自动随机选择一个布局。这样，你基本上可以让用户每次启动游戏或打开某个界面时都看到完全不同的随机菜单设计；不过它也可以只用于更改屏幕的某些部分，例如背景。

## 随机模式

要随机化布局，你需要为每个应当作为随机候选项的布局启用 **随机模式**。要这样做，请**右键单击** **编辑器背景**，然后找到 **Random Mode** 选项。

## 随机组标识符

启用随机模式后，你需要设置它的 **Random Group Identifier**。
这个数字对于所有应属于**同一组**的布局都必须**相同**。

## 随机化行为

如果你只希望系统在**每次游戏会话中只随机选择一次**该组布局，请启用 **Randomize Only First Time**。这样，界面第一次打开时会选取一个布局，之后始终使用第一次选中的布局。如果禁用此选项，那么每次打开界面时都会随机选择一个布局。

# 示例场景 1：背景

假设你想随机化标题界面的背景。

为此，你需要为**每一种背景各创建一个布局**，并且_**只**_更改这些布局中的背景，同时启用随机模式并设置正确的随机组标识符。

在这个示例中，我们使用随机组标识符 **10**。这个标识符需要为这个随机布局组中的每个布局都设置相同的值。

最简单的方法是先准备一个已设置正确随机组标识符的布局，然后直接使用 **另存为**。每次以新名称保存布局时，修改一次背景，最终你会得到一堆具有不同背景的布局，而在每次打开界面或每个游戏会话中，其中一个布局都会被选中。

# 示例场景 2：元素

另一个常见用例是随机化文本或图像元素。

与背景一样，为你想随机选择的元素的每个版本分别创建一个布局。只把该元素添加到布局中，其他什么都不要加。不要自定义任何其他内容，也不要添加其他元素。

然后只需使用相同的随机组标识符保存所有布局，当你打开界面或启动游戏时，组中的一个布局就会被选中。
