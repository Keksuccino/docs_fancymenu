# 屏幕标识符

FancyMenu 使用屏幕标识符来识别某个布局属于哪个屏幕、将按钮定位到特定屏幕中的某个位置，以及执行其他需要模组与特定屏幕进行通信或自定义的操作。

# 查找屏幕的标识符

你可以通过 **调试覆盖层** 查看当前活动菜单的标识符。
它会显示当前屏幕的标识符，并且你可以通过左键单击将其复制到剪贴板。

>[!TIP]
>当你**不在布局编辑器中**时，按下 **CTRL + ALT + D** 即可启用 **调试覆盖层**。
