# 元素动画器

**Animator** 是一种允许你为其他元素制作动画的元素。使用这个元素，你可以通过关键帧随时间平滑地改变另一个元素的大小、位置和锚点。关键帧就像快照，记录元素在某一特定时刻应该呈现的样子。然后，Animator 元素会按顺序播放这些快照，以创建平滑的运动效果。

> [!WARNING]
> **Element Animator** 只能控制元素的**位置、大小和锚点**。**不能**控制元素的任何其他设置，例如不透明度、可见性、旋转等！

# 添加 Animator 元素

1. **右键单击背景：**  
   在布局编辑器中，右键单击背景。

2. **选择 New Element -> Element Animator：**  
   在弹出的菜单中，进入 **New Element** 并点击 **Element Animator**。这样就会把 Animator 元素添加到你的布局中。

3. **进行设置：**  
   添加后，Animator 元素会以默认设置显示。你可以通过右键单击 Animator 并从菜单中选择选项来更改循环、颜色等设置。

# 管理关键帧

关键帧就像书签，告诉 Animator 某个元素在特定时间应该是什么样子。

## 打开关键帧编辑器

- **打开编辑器：**  
  右键单击 Animator 元素并选择 **Edit Keyframes**（或 **Manage Keyframes**）。这会打开一个界面，你可以在其中添加、编辑或删除关键帧。

## 录制并添加关键帧

- **开始录制：**  
  在关键帧编辑器中，按 **`R` 键**开始录制。录制时，预览框会变色，表示它已激活。
  
- **更改预览：**  
  移动或调整预览框的大小，以设置你想要的外观。在偏移模式下，预览会始终以十字线为中心，因此更改会以偏移量的形式显示。
  
- **添加关键帧：**  
  按 **`K` 键**将当前外观保存为一个关键帧。这个关键帧会保存预览的位置、大小和锚点设置。

## 编辑关键帧

- **选择关键帧：**  
  点击时间轴上的一个关键帧标记。你也可以按住 **Ctrl** 并单击来选择多个。
  
- **移动关键帧：**  
  将关键帧标记向左或向右拖动以更改其时间。你也可以使用：
  - **左箭头：** 提前 100 毫秒。
  - **右箭头：** 推后 100 毫秒。
  
- **微调预览：**  
  选中关键帧后，可以通过移动或调整预览框大小来进行修改。如有需要，可使用 **Ctrl + Z** 撤销，使用 **Ctrl + Y** 重做。

## 删除关键帧

- **删除一个关键帧：**  
  选中一个关键帧后按 **Delete 键**即可删除。
  
- **删除多个关键帧：**  
  你可以选择多个关键帧（例如使用 **Ctrl + A** 全选），然后按 Delete 一次性删除它们。

## 关键帧平滑

关键帧平滑是一项帮助你均匀分布关键帧的功能。这样可以让动画看起来更一致、更平滑。

- **选择多个关键帧：**  
  首先，选择两个或更多你想要平滑处理的关键帧（使用 **Ctrl + 单击** 或 **Ctrl + A**）。

- **点击平滑按钮：**  
  在关键帧编辑器底部工具栏中，点击标有 **Distance Smoothing** 的按钮。

- **输入新的间距：**  
  会出现一个小输入框。输入一个数值（以毫秒为单位），为每个选中的关键帧设置相同的时间间隔。

- **应用平滑：**  
  按 Enter 应用平滑。关键帧之间的时间差会被调整为均匀一致。

# 预览你的动画

记录好关键帧后，你可以查看动画的效果：

- **播放动画：**  
  在关键帧编辑器中，按 **`P` 键**或点击播放按钮。预览将从头开始，并展示预览框如何随时间变化。
  
- **关于循环的说明：**  
  在关键帧编辑器中预览时，动画**不会循环**。这意味着它只会从头到尾播放一次。只有当 Animator 元素应用到最终布局中的目标元素时，循环才会生效。
  
- **暂停预览：**  
  再次按 **`P` 键**即可暂停动画，方便你停在某个时间点。
  
- **拖动进度条：**  
  如果可用，你可以拖动时间轴标记，查看动画在任意特定时间点的效果。

# 选择目标元素

设置好关键帧后，你需要选择哪些布局元素将被应用动画：

1. **打开目标管理器：**  
   右键单击 Animator 元素并选择 **Manage Targets**。
  
2. **添加目标：**  
   点击 **Add Target** 查看可用元素列表。选择你想要制作动画的元素。
  
3. **移除目标：**  
   要移除某个目标，请打开管理器并点击 **Remove Target**。

当动画在最终布局中播放时，Animator 会使用你的关键帧来改变所选元素的大小、位置等。如果你设置了循环，这里也会应用循环。

# 键盘快捷键

在关键帧编辑器中使用这些快捷键可以更快地操作：

- **`R` 键：** 开始或停止录制。
- **`T` 键：** 暂停或恢复录制。
- **`P` 键：** 播放或暂停动画预览。
- **`K` 键：** 在当前时间添加一个新关键帧。
- **左/右箭头键：**  
  - **左箭头：** 将关键帧提前 100 毫秒。
  - **右箭头：** 将关键帧推后 100 毫秒。
- **Delete 键：** 删除选中的关键帧。
- **Ctrl + A：** 选择所有关键帧。
- **Ctrl + Z：** 撤销上一步更改。
- **Ctrl + Y：** 重做刚刚撤销的更改。
- **Ctrl + 拖动关键帧：** 一次拖动多个已选中的关键帧。

# 额外设置和提示

- **循环动画：**  
  你可以将 Animator 设置为循环。开启循环后，动画会在最后一个关键帧之后重新开始——但请注意，这只会在最终目标元素上生效。在关键帧编辑器的预览中，不会发生循环。
  
- **忽略大小/位置：**  
  如果你不希望关键帧改变元素的大小或位置，请关闭这些选项。

- **时间偏移：**
  你可以为单个目标元素设置偏移，或者使用配置范围内的随机时间偏移，这样同一个动画会在不同目标上于不同时间开始。
  
- **偏移模式：**  
  在偏移模式下，动画会作为相对于元素原始位置的变化来应用。预览会以十字线为中心显示。
  
- **撤销和重做：**  
  使用 **Ctrl + Z** 撤销，使用 **Ctrl + Y** 重做更改。
  
- **检查顺序：**  
  确保关键帧按时间顺序排列。系统会自动帮你排序，但如果你移动了某个关键帧，请再检查一下顺序。
  
- **预览更改：**  
  在保存之前，使用播放按钮或 **`P` 键**查看动画效果。
