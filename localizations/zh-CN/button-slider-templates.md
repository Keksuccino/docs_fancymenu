# 将按钮元素用作按钮和滑块的模板

可以将一个按钮元素用作其他按钮甚至滑块的模板。这样做后，你就可以把某种特定的按钮/滑块设计应用到菜单中的所有按钮/滑块，甚至在使用通用布局时一次性应用到所有菜单。

> [!IMPORTANT]
> 对于广泛的原版按钮和滑块样式调整，请优先使用[全局自定义](./global-customizations)。只有当行为必须与布局相关时，才使用按钮/滑块模板。

# 开始前的重要说明

如果只想调整一个按钮或滑块，请在编辑器中**右键单击**它，并直接编辑其**背景纹理**或滑块手柄纹理。

# 什么是模板按钮？

模板按钮是 FancyMenu 中一种特殊的自定义按钮，它可以让你控制其他按钮和滑块的外观与行为。它就像创建一个主设计，许多其他元素都会遵循它。

创建模板按钮后，你可以让许多按钮或滑块共享相同的：
- 大小（宽度和高度）
- 位置
- 可见性
- 不透明度（透明程度）
- 文本标签
- **按钮纹理**（设置了自定义纹理后会自动共享）

当你想让菜单风格保持一致，或者需要一次更新很多按钮时，这非常有用！

# 谁可以使用模板？

只有**自定义按钮**可以作为模板。不过，这些模板可以应用于：
- 原版按钮（Minecraft 默认按钮）
- 自定义按钮（你在 FancyMenu 中创建的按钮）
- 原版滑块（例如音量控制）
- 自定义滑块（你在 FancyMenu 中创建的滑块）

# 如何创建模板按钮

1. 打开你想自定义的界面的 FancyMenu 编辑器
2. 向布局中添加一个新的自定义按钮元素
3. 右键单击你的新按钮
4. 在菜单中选择“Template Settings”
5. 点击“Is Template: ON”以启用模板模式

现在，你的按钮就可以作为其他按钮和滑块的模板了！

# 模板共享选项

你可以选择模板会影响哪些类型的元素：
- **Buttons** - 模板只会影响按钮（包括原版按钮和自定义按钮）
- **Sliders** - 模板只会影响滑块（包括原版滑块和自定义滑块）

设置此选项的方法：
1. 右键单击你的模板按钮
2. 进入“Template Settings”
3. 点击“Share With: [Current Option]”在不同选项之间循环切换

> [!WARNING]
> **重要**：你可以同时激活两个模板——一个用于按钮，另一个用于滑块。这意味着你可以在同一界面上为不同类型的元素创建独立的模板设计！


# 可被模板化的内容

你可以精确控制模板会与其他元素共享哪些属性：

## 可单独开关的属性：

1. 右键单击你的模板按钮
2. 进入“Template Settings”
3. 切换以下任意选项：
   - **Width** - 使所有受影响的元素宽度与模板相同
   - **Height** - 使所有受影响的元素高度与模板相同
   - **X Position** - 使所有受影响的元素位于与模板相同的 X 坐标
   - **Y Position** - 使所有受影响的元素位于与模板相同的 Y 坐标
   - **Opacity** - 使所有受影响的元素具有与模板相同的透明度
   - **Visibility** - 控制受影响的元素是显示还是隐藏
   - **Label** - 使所有受影响的元素使用与模板相同的文本

## 始终共享的属性：

- **按钮纹理** - 当你在模板上设置了自定义纹理时，它们会自动应用到所有受影响的元素
  - 与其他属性不同，纹理共享无法关闭
  - 只有在模板上实际设置了自定义纹理时，才会应用纹理
  - 如果未设置自定义纹理，则会使用原始元素纹理

# 自定义模板外观

你的模板按钮可以像其他按钮一样进行自定义：

1. 右键单击你的模板按钮
2. 你可以设置：
   - 按钮纹理（正常、悬停和非活动状态）
   - 标签（正常和悬停）
   - 声音（悬停和点击）
   - 工具提示

对于按钮，你可以为不同状态设置自定义纹理：
- 正常背景（未交互时）
- 悬停背景（鼠标悬停在其上时）
- 非活动背景（按钮被禁用时）

对于滑块，你还可以设置：
- 滑块手柄纹理
- 滑块背景纹理

# 重要提示

1. **模板按钮不会在游戏中显示** - 它们只在编辑器中可见，所以可以把它们放在任何方便的位置。

2. **你可以同时激活两个模板** - 一个按钮模板和一个滑块模板可以同时处于激活状态。

3. **每种类型只能有一个模板生效** - 如果你有多个按钮模板，只有元素列表中最上方的那个会用于按钮。滑块模板同理。

4. **对模板的修改会立即更新** - 当你编辑模板时，所有受影响的按钮和滑块都会立刻更新。

5. **使用正确的共享模式** - 请记住，“Buttons”模式不会影响滑块，“Sliders”模式也不会影响按钮。

6. **有选择地应用属性** - 你不必应用所有属性。例如，你可能只想模板化纹理和大小，同时保留元素原本的位置。

7. **纹理在设置后总会共享** - 与其他属性不同，你应用到模板上的任何自定义纹理都会自动与匹配的元素共享。你不需要开启或关闭这个功能。

# 使用示例

- 为界面上的所有按钮创建统一风格
- 使用单独的模板让所有滑块与自定义主题保持一致
- 创建一种“隐藏模式”，一次显示/隐藏多个按钮
- 只需一次编辑即可更改多个按钮的大小
- 为菜单中的所有按钮提供相同的自定义纹理和声音
