# 将按钮元素用作按钮和滑块的模板

可以将一个按钮元素用作其他按钮甚至滑块的模板。这样，你就可以把特定的按钮/滑块设计应用到菜单中的**所有**按钮/滑块，甚至在使用通用布局时一次应用到所有菜单。

> [!IMPORTANT]
> 自 FancyMenu 3.9.0 起，建议尽可能使用[全局自定义](/global-customizations)而不是按钮/滑块模板，它可以在不使用资源包的情况下，全局替换原版按钮和滑块纹理。对于更广泛的原版界面样式调整，请使用全局自定义；只有在你需要特定布局行为时，才使用模板。

# 开始前的重要说明

如果你只想更改单个按钮或滑块的纹理，最简单且推荐的方法是在编辑器中直接对该按钮或滑块（原版和自定义）**右键单击**。菜单中有一个选项可为按钮和滑块设置**背景纹理**（以及滑块把手纹理）。

# 什么是模板按钮？

模板按钮是 FancyMenu 中一种特殊的自定义按钮，它可以让你控制其他按钮和滑块的外观与行为。你可以把它理解为创建一个主设计，许多其他元素都会遵循它。

当你创建模板按钮时，可以让许多按钮或滑块共享相同的：
- 大小（宽度和高度）
- 位置
- 可见性
- 不透明度（透明程度）
- 文本标签
- **按钮纹理**（当设置了自定义纹理时会自动共享）

当你想让菜单风格保持一致，或者需要一次更新多个按钮时，这非常有用！

# 谁可以使用模板？

只有**自定义按钮**可以作为模板使用。不过，这些模板可以应用于：
- 原版按钮（Minecraft 默认按钮）
- 自定义按钮（你在 FancyMenu 中创建的按钮）
- 原版滑块（例如音量控制）
- 自定义滑块（你在 FancyMenu 中创建的滑块）

# 如何创建模板按钮

1. 打开 FancyMenu 编辑器，进入你要自定义的界面
2. 向布局中添加一个新的自定义按钮元素
3. 右键单击你的新按钮
4. 在菜单中选择“模板设置”
5. 点击“是否为模板：开启”来启用模板模式

现在你的按钮就可以作为其他按钮和滑块的模板了！

# 模板共享选项

你可以选择模板会影响哪些类型的元素：
- **按钮** - 你的模板只会影响按钮（原版和自定义）
- **滑块** - 你的模板只会影响滑块（原版和自定义）

设置此选项的方法：
1. 右键单击你的模板按钮
2. 进入“模板设置”
3. 点击“共享给：[当前选项]”来循环切换选项

> **重要**：你可以同时激活两个模板——一个用于按钮，另一个用于滑块。这意味着你可以在同一界面上为不同类型的元素创建不同的模板设计！

# 可以模板化的内容

你可以精确控制模板会与其他元素共享哪些属性：

## 可切换开/关的属性：

1. 右键单击你的模板按钮
2. 进入“模板设置”
3. 切换以下任意选项：
   - **宽度** - 让所有受影响的元素与模板具有相同宽度
   - **高度** - 让所有受影响的元素与模板具有相同高度
   - **X 位置** - 让所有受影响的元素与模板具有相同的 X 坐标
   - **Y 位置** - 让所有受影响的元素与模板具有相同的 Y 坐标
   - **不透明度** - 让所有受影响的元素与模板具有相同的透明度
   - **可见性** - 控制受影响的元素是显示还是隐藏
   - **标签** - 让所有受影响的元素使用与模板相同的文本

## 始终共享的属性：

- **按钮纹理** - 当你在模板上设置自定义纹理时，它们会自动应用到所有受影响的元素
  - 与其他属性不同，纹理共享不能关闭
  - 只有在模板上实际设置了自定义纹理时，才会应用纹理
  - 如果没有设置自定义纹理，则会使用原始元素纹理

# 自定义模板外观

你的模板按钮可以像任何其他按钮一样进行自定义：

1. 右键单击你的模板按钮
2. 你可以设置：
   - 按钮纹理（普通、悬停和不活跃状态）
   - 标签（普通和悬停）
   - 音效（悬停和点击）
   - 提示文本

对于按钮，你可以为不同状态设置自定义纹理：
- 普通背景（未交互时）
- 悬停背景（鼠标悬停时）
- 不活跃背景（按钮被禁用时）

对于滑块，你还可以设置：
- 滑块把手纹理
- 滑块背景纹理

# 重要提示

1. **模板按钮不会出现在游戏中** - 它们只在编辑器中可见，因此可以把它们放在任何方便的位置。

2. **你可以同时激活两个模板** - 一个按钮模板和一个滑块模板可以同时启用。

3. **每种类型只能有一个模板生效** - 如果你有多个按钮模板，只有元素列表中最上方的那个会用于按钮。滑块模板也是同样的规则。

4. **对模板的更改会立即更新** - 当你编辑模板时，所有受影响的按钮和滑块都会立刻更新。

5. **使用正确的共享模式** - 请记住，“按钮”模式不会影响滑块，“滑块”模式也不会影响按钮。

6. **选择性应用属性** - 你不必应用所有属性。例如，你可能只想模板化纹理和大小，但让元素保留它们原来的位置。

7. **设置了纹理后会始终共享** - 与其他属性不同，你应用到模板上的任何自定义纹理都会自动共享给匹配的元素。你不需要手动开关此功能。

# 示例用途

- 为屏幕上的所有按钮创建统一风格
- 使用单独的模板让所有滑块匹配你的自定义主题
- 创建一个“隐藏模式”，一次显示/隐藏多个按钮
- 只需一次编辑就能更改许多按钮的大小
- 为菜单中的所有按钮使用相同的自定义纹理和音效
