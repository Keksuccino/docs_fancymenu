# 发现已修改的 FancyMenu JAR

如果你遇到了这个错误，通常是由于 Minecraft 实例损坏、模组加载器损坏，或者使用了有问题的模组启动器。

它通常会在 FancyMenu 被修改时显示，但如果你的游戏未能按预期正确加载模组，也可能会出现这个提示。

这可能是因为你的 **Minecraft 实例以某种方式损坏**，这种情况下你应该 **重新安装游戏**。

另一个可能的原因是你的 **游戏在启动时半崩溃**，因为某些模组（包括 FancyMenu）**未能正确加载**。在这种情况下，请在 Discord 服务器中发布你的 `/logs/latest.log` 文件，或者在 GitHub 上创建一个 issue。

这个错误也可能是由于 **使用了有问题的模组启动器** 引起的（大多数破解版/盗版启动器都会触发这个 bug，所以请购买正版游戏）。推荐且稳定、与 FancyMenu 配合良好的启动器是 **官方 CurseForge 启动器和官方 Modrinth 启动器**。
