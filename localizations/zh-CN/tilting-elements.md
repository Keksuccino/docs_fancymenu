# 倾斜元素

从 FancyMenu v3.8.0 开始，大多数元素都可以在垂直和水平方向上进行倾斜！

要倾斜一个元素，请在布局编辑器中选中它。如果你看到两条带有拖拽手柄的线（ 一条竖线，一条横线），并且它们不是元素边框，那么你可以拖动这些手柄，将元素朝所需方向倾斜。

如果元素上没有带手柄的线，就表示它不能倾斜。

# 高级

你也可以右键单击元素，通过直接文本输入手动设置倾斜值。此直接输入支持 [占位符](/placeholders)，因此当你将其与占位符结合使用以获取 FancyMenu 变量值或类似内容时，就可以动态更改元素的倾斜效果。

# 按钮、滑块和其他可交互元素

对于可交互元素，倾斜是可以的，但这种倾斜只是视觉效果。因此，例如，按钮仍然只会对其原始区域内的点击作出反应，即使倾斜后它可能已经部分移出了该区域。
