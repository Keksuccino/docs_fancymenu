# 倾斜元素

大多数元素都可以在垂直和水平方向上倾斜。

在布局编辑器中选择一个元素。如果该元素支持倾斜，它周围会出现带有拖拽点的垂直和水平参考线。拖动拖拽点即可沿对应轴倾斜该元素。

如果元素上没有带拖拽点的线，就表示你不能倾斜它。

# 高级

你也可以右键单击该元素，通过直接文本输入手动设置倾斜值。此直接输入支持[占位符](/placeholders)，因此当你将它与占位符结合使用以获取 FancyMenu 变量值或类似内容时，可以动态更改元素的倾斜效果。

# 按钮、滑块和其他可交互元素

对于可交互元素来说，倾斜仅在视觉上生效。一个倾斜的按钮仍然会在其原始、未倾斜的区域内接受点击。
