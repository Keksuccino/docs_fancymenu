# 为 FancyMenu 优化纹理

FancyMenu 会原样使用你提供的纹理，这意味着它**不会**对图像文件进行压缩、缩小或放大。为了确保你的菜单既清晰又高效，在 UI 中使用纹理时，优化纹理非常重要。

# 纹理优化的关键提示

以下提示是你在 FancyMenu 中处理纹理时需要牢记的最重要的基础步骤。

## 1. 使用合适的分辨率
- **避免低分辨率图像**：如果图像太小，却被拉伸到更大的区域，它可能会显得模糊。
- **避免过高分辨率**：以很小尺寸显示的超大纹理也可能显得失真或“怪异”，并且会浪费性能。

> 📌 **提示：** 尽量使用与菜单中实际显示尺寸相同或接近的纹理。
{.is-info}

## 2. 保持宽高比
- 在缩放图像时，始终保持其宽高比。
- 不成比例地拉伸图像会导致视觉瑕疵，并影响美观。

> 📌 **提示：** 你可以右键单击图像元素并点击 **恢复宽高比**，将其调整为正确的宽高比；之后如果需要手动进一步调整大小，请在缩放时按住 **SHIFT**，以使缩放遵循该元素的宽高比。
{.is-info}

## 3. 考虑九宫格切片与平铺
- 对于可缩放的 UI 元素（如面板或按钮），请使用 FancyMenu 的 [九宫格切片与平铺](/nine-slicing-and-tiling) 功能。
- 这样可以确保纹理边缘在调整大小时依然保持清晰。
