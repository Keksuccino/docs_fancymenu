# 为 FancyMenu 优化纹理

FancyMenu 会按原样使用你提供的纹理，这意味着它**不会**对你的图像文件进行压缩、缩小或放大。为了确保你的菜单看起来清晰并且性能良好，在 UI 中使用纹理时，优化它们非常重要。

# 纹理优化的关键提示

以下提示是你在 FancyMenu 中处理纹理时需要牢记的最重要基础步骤。

## 1. 使用合适的分辨率
- **避免低分辨率图像**：如果一张图像太小，却被拉伸以适配更大的区域，它可能会显得模糊。
- **避免过高分辨率**：显示尺寸很小但纹理却非常大的情况下，也可能看起来失真或“怪异”，并且会浪费性能。

> [!NOTE]
> 📌 **提示：** 请尽量使用与它们在菜单中实际显示尺寸相同或接近的纹理。

## 2. 保持宽高比
- 缩放图像时始终保持其宽高比。
- 不成比例地拉伸图像会导致视觉瑕疵，并影响外观。

> [!NOTE]
> 📌 **提示：** 你可以右键单击图片元素，然后点击 **Restore Aspect Ratio** 将其恢复到正确的宽高比；之后如果要继续手动调整大小，请在缩放时按住 **SHIFT**，这样缩放就会尊重该元素的宽高比。

## 3. 考虑九宫切片和平铺
- 对于可缩放的 UI 元素（例如面板或按钮），请使用 FancyMenu 的 [Nine-Slicing & Tiling](/nine-slicing-and-tiling) 功能。
- 这样可以确保纹理边缘在调整大小后依然保持清晰。
