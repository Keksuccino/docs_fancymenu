# Ice 与 Fire 主菜单

要禁用 Ice and Fire 模组中的自定义标题界面，你需要修改它的配置。方法如下：

## 1. 找到配置文件
- **文件名：** 该设置位于名为 **`iceandfire-client.toml`** 的文件中。
- **文件夹位置：** 该文件通常位于 **`<game-directory>/config/`**，其中 **`<game-directory>`** 是当前启动器实例/配置文件的目录。

## 2. 编辑配置文件
- **打开文件：** 使用任何纯文本编辑器（例如 Windows 上的记事本或 macOS 上的 TextEdit）打开 `iceandfire-client.toml`。
- **找到设置：** 向下滚动，直到找到与自定义主菜单相关的选项。它可能是注释形式，并且看起来类似这样：
  ```toml
  # 是否在主菜单显示龙 [默认值: true]
  B:"Custom main menu"=true
  ```
- **修改数值：** 将此选项改为 **false**，把这一行改成：
  ```toml
  B:"Custom main menu"=false
  ```
  这个更改会告诉模组不要渲染它自定义的主菜单（通常会包含龙或其他主题视觉元素）。

## 3. 保存并重启
- **保存文件：** 完成修改后，保存文件。
- **重启 Minecraft：** 关闭并重新启动 Minecraft，使更改生效。游戏加载后，它应该会使用默认主菜单，而不是模组提供的自定义主菜单。

## 其他提示
- **确认你编辑的是正确的文件：** 可能还有一个单独的通用配置文件，所以请确保你编辑的是 **`iceandfire-client.toml`**（这是客户端专用配置，不是通用配置）。
- **先备份：** 在修改配置文件之前，最好先备份原文件。
- **整合包：** 如果你使用的是整合包，配置文件可能位于整合包的文件夹结构中，但原理是一样的。

按照这些步骤操作后，应该就能禁用模组提供的自定义主菜单，从而使用你的材质包自己的主菜单背景。
