# 无缝世界加载

无缝世界加载会在你离开一个世界或服务器时截取一张截图，并在下次加载时将其用作加载背景。

这样可以让加载过渡感觉更平滑，因为加载界面会与你加载完成后看到的内容相匹配。

# 在哪里找到它

在**不是**布局编辑器时，打开 FancyMenu 的**菜单栏**，然后选择 **Customization -> Global Customizations**。

# 启用 / 禁用

1. 打开 **Customization -> Global Customizations**。
2. 找到 **Seamless World Loading**。
3. 将其设置为 **Enabled** 或 **Disabled**。

# 工作原理

- 启用后，FancyMenu 会在你离开世界/服务器时保存一张截图。
- 下次加载时，这张截图会被用作加载背景。
- 首次使用：如果还没有截图，在你至少离开过一次世界/服务器之前，将不会显示任何内容。
