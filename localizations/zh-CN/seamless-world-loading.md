# 无缝世界加载

无缝世界加载会使用世界或服务器的最近画面作为下次加载界面的背景。

通过 [**自定义 -> 全局自定义**](/global-customizations) -> **无缝世界加载** 启用此功能。

# 工作原理

- 在你进入已追踪的世界或服务器时，FancyMenu 会定期捕获当前画面。
- 离开时会保存最新的截图。
- 每个世界和服务器都有各自经过哈希处理的 PNG 文件名。
- FancyMenu 最多会预加载最近的五张世界截图和五张服务器截图。
- 在目标对象保存第一张截图之前，不会显示任何内容。

截图存储在：

```text
<game-directory>/fancymenu_data/seamless_world_loading/
```

截图可能会包含捕获时世界中所有可见内容。禁用无缝世界加载会停止截图捕获和使用，但不会删除已有的 PNG 文件。请在游戏关闭时从该目录中删除不需要的截图。
