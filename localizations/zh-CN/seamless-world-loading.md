# 无缝世界加载

无缝世界加载会使用某个世界或服务器的最近画面作为下一次加载界面的背景。

通过 [**自定义 -> 全局自定义**](./global-customizations) -> **无缝世界加载** 启用它。

# 工作原理

- 当你位于已跟踪的世界或服务器中时，FancyMenu 会定期捕获当前画面。
- 你离开时，会保存最新的一次捕获。
- 每个世界和服务器都有自己经过哈希处理的 PNG 文件名。
- FancyMenu 最多会预加载最近的五张世界截图和五张服务器截图。
- 在某个目标首次保存截图之前，不会显示任何内容。

截图会存储在：

```text
<game-directory>/fancymenu_data/seamless_world_loading/
```

这些截图可能包含捕获时世界中可见的任何内容。禁用无缝世界加载会停止捕获和使用，但不会删除现有的 PNG 文件。请在游戏关闭时，从该目录中删除不需要的截图。
