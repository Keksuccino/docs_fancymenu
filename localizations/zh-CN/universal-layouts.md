# 通用布局

对于所有启用了屏幕自定义的受支持屏幕，都会考虑应用通用布局。它不适用于[被屏蔽](./incompatibility-list#screens-where-customization-is-intentionally-disabled)或以其他方式被排除的屏幕。

通用布局适用于跨多个屏幕都应保持一致的共享元素，例如徽标、导航、覆盖层，或 [音频元素](./elements#audio)。

# 创建一个通用布局

1. 打开一个受支持的屏幕，并显示 FancyMenu 菜单栏。
2. 选择 **布局 -> 新建 -> 适用于所有屏幕 [通用]**。
3. 添加并配置元素。
4. 保存布局。

普通屏幕仍然需要启用 **当前屏幕自定义**。之所以没有全局“全部启用”开关，是因为不受支持的模组屏幕在被自定义后可能会崩溃。

# 限制适用屏幕

从编辑器背景的右键菜单中打开通用布局设置。

- **白名单：** 该布局仅应用于列出的屏幕标识符。
- **黑名单：** 该布局会应用于所有符合条件的屏幕，但不包括列出的标识符。

使用 **自定义 -> 复制当前屏幕的标识符** 来复制一个[屏幕标识符](./screen-identifiers)。

你也可以添加[布局级要求](./conditions#layout-wide-requirements)来控制布局何时生效。

# 布局顺序

符合条件的通用布局和特定屏幕布局会按 **布局索引** 合并并堆叠。较低的索引会先应用；后续可堆叠的设置可以覆盖先前的设置。在相同索引下，通用布局会先于特定屏幕布局收集。
