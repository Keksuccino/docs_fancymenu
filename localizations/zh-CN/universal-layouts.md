# 什么是通用布局？

通用布局是 FancyMenu 中一项强大的功能，它允许你创建可以应用于**多个界面**的布局，而不只是单个特定界面。这使它们非常适合用于在整个游戏中保持一致的 UI 元素。

你可以把通用布局理解为可以出现在游戏中任何地方的“全局”布局。

# 为什么要使用通用布局？

当你想要以下效果时，通用布局会非常有帮助：

- 为所有界面添加相同的背景
- 创建会出现在许多界面上的标志或文字
- 让音频元素在多个界面之间持续播放
- 在整个游戏中建立统一的外观和风格

# 通用布局如何工作

当你创建一个通用布局时，默认情况下它会随着游戏中的**每个界面**一起加载。这意味着你添加到通用布局中的任何元素（如按钮、图片或文字）都会出现在所有界面上。

不过别担心！你也可以让通用布局只在特定界面中加载！为此，请向下查看**黑名单**和**白名单**部分。

# 创建通用布局

1. 打开游戏中的任意界面
2. 按 **Ctrl+Alt+C** 显示自定义菜单
3. 进入 **Layouts → New → For All Screens [Universal]**
4. 使用图片、文字或按钮等元素设计你的布局
5. 为布局保存一个具有描述性的名称

# 管理哪些界面加载你的通用布局

## 使用黑名单

黑名单可让你指定不希望显示通用布局的界面：

1. 在布局编辑器中，右键单击背景
2. 选择 **Layout Settings → Universal Layout Options**
3. 点击 **Add Screen To Blacklist**
4. 输入界面标识符（例如标题界面的 `title_screen`）

现在，你的通用布局将显示在所有界面上，**除了**你加入黑名单的那些界面。

## 使用白名单

白名单则相反——它只会让你的通用布局显示在特定界面上：

1. 在布局编辑器中，右键单击背景
2. 选择 **Layout Settings → Universal Layout Options**
3. 点击 **Add Screen To Whitelist**
4. 为你希望布局出现的每个界面输入对应的界面标识符

使用白名单时，你的通用布局将**只会**显示在你列出的那些界面上。

# 查找界面标识符

要将界面添加到白名单或黑名单中，你需要知道它们的标识符：

1. 前往你想识别的界面
2. 按 **Ctrl+Alt+C** 打开自定义菜单
3. 点击 **Customization → Copy Identifier of Current Screen**
4. 标识符现在已复制到你的剪贴板

你可以将这个标识符粘贴到白名单或黑名单中。

# 为所有界面启用自定义

无法一次性为所有界面启用自定义。
这样设计是为了防止用户不小心把游戏弄坏，因为他们可能会为一个不受支持的模组界面启用自定义。

# 高级提示

## 管理加载顺序

当你同时拥有通用布局和特定界面布局时，通用布局会**先**加载。这意味着特定界面布局可以覆盖通用布局中的元素。

## 加载条件

你可以为通用布局添加加载条件，让它只在某些条件下加载：

1. 在编辑器中右键单击
2. 选择 **Layout Settings → Layout-Wide Requirements**
3. 添加诸如一天中的时间、操作系统或其他要求之类的条件
