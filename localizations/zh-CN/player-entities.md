# 玩家实体

FancyMenu 允许你在界面中添加玩家实体，这样你就可以显示客户端玩家或其他玩家，甚至还可以显示并不代表真实玩家的自定义实体，并为其使用自定义皮肤、名称、披风等。

# 客户端玩家

要显示客户端玩家的“镜像”，只需右键单击 Player Entity 元素并启用 **Copy Client Player**。这会复制客户端玩家的皮肤、披风和名称。

# 其他玩家

如果你想显示另一个已存在的玩家，只需右键单击该元素并将 **Player Name** 设置为一个已存在的玩家名称。只要你没有设置自定义皮肤或披风，并且 **Copy Client Player** 处于**禁用**状态，这样就会自动显示该玩家的皮肤、披风和名称。

# 自定义玩家实体

如果你根本不想显示真实玩家，而是想完全自定义实体的皮肤、披风和名称，可以右键单击该元素。这里有选项可以设置自定义皮肤和披风纹理。如果启用了自定义皮肤和披风，你也可以随意设置任何你想要的玩家名称，而不会因为该玩家存在而自动复制其皮肤。

# 实体姿势

Player Entity 元素完全支持自定义姿势，也就是说，你可以自由移动它的所有肢体、身体部位等。

要这样做，请右键单击该元素并点击 **Player Pose**。这将打开一个界面，其中有滑块可用于配置所有身体部位的 X/Y/Z 旋转。

玩家姿势设置提供普通模式，你可以通过滑块自定义旋转；另外还有高级模式，允许你为所有旋转输入文本，并完整支持占位符，这甚至使你可以配合 Ticker 元素，通过设置旋转变量来为实体制作动画！

# 更改实体大小

在 Minecraft 1.20.1+ 中，你只需使用元素正常的缩放拖拽手柄即可缩放实体。

对于旧版本（1.19.2 及更早），Player Entity 元素不支持通过缩放拖拽手柄直接调整大小。你需要右键单击该元素并点击 **Scale**。这样可以为元素设置缩放比例。默认值应为 `30`，例如将其设置为 `60` 会使玩家变为正常大小的两倍，设置为 `15` 则会显示为一半大小，依此类推。

# 依赖项：Fancy Entity Renderer (FER)

对于 **Minecraft 1.20.1+**，要使 Player Entity 元素正常工作，还需要一个**额外的模组**。这个模组叫做 **Fancy Entity Renderer**，可在 [CurseForge](https://www.curseforge.com/minecraft/mc-mods/fancy-entity-renderer) 和 [Modrinth](https://modrinth.com/mod/fancy-entity-renderer) 上获取。

如果你所使用的 Minecraft 版本暂时还没有可用构建版本，大概率会在之后发布。

请注意，FER 并不是由 Keksuccino 开发的，因此他无法控制构建版本何时发布。
