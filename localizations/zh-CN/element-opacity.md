# 元素不透明度

FancyMenu 中的大多数元素（有少数例外）都支持通过右键菜单设置其不透明度。

元素的不透明度值支持占位符，这使得可以根据占位符动态更新它们的不透明度。

这使得在与 Ticker 元素结合使用时，可以创建自定义淡入淡出逻辑，用于更新变量值，然后通过占位符将其作为不透明度应用。

要设置元素的不透明度，**右键单击元素 -> 不透明度 -> 设置**。

# 元素淡入/淡出

如果你只是想让元素淡入或淡出，通常直接使用元素内置的淡入淡出功能会更简单。你可以在元素的右键菜单中启用淡入淡出。

此功能会让元素在每次加载时淡入，无论是打开菜单时的初始加载，还是元素的加载条件满足而加载时。每当它们的加载条件导致其卸载/不可见时，就会淡出。

淡入淡出功能支持设置淡入淡出速度，用于控制元素淡入或淡出的快慢。
