# OptiFine 替代方案

我**_并不_**官方支持 OptiFine。
它会像几乎所有模组一样出问题，而且由于它是闭源的，修复它引起的错误既让人非常沮丧，又非常耗时。

你应该改用 Oculus/Iris 和 Rubidium/Sodium。
它们稳定得多，也不会把一切都搞坏。

## Forge

- [Embeddium](https://www.curseforge.com/minecraft/mc-mods/embeddium)（性能）
- [Oculus](https://www.curseforge.com/minecraft/mc-mods/oculus)（着色器）
- [Capes](https://www.curseforge.com/minecraft/mc-mods/capes)（让你在未安装 OptiFine 的情况下使用 OptiFine 披风）
- [Just Zoom](https://legacy.curseforge.com/minecraft/mc-mods/just-zoom-forge)（让你像在 OptiFine 中一样按键缩放）

## Fabric

- [Sodium](https://www.curseforge.com/minecraft/mc-mods/sodium)（性能）
- [Lithium](https://modrinth.com/mod/lithium)（更多性能优化）
- [Iris](https://www.curseforge.com/minecraft/mc-mods/irisshaders)（着色器）
- [Capes](https://www.curseforge.com/minecraft/mc-mods/capes)（让你在未安装 OptiFine 的情况下使用 OptiFine 披风）
- [Zoomify](https://www.curseforge.com/minecraft/mc-mods/zoomify) 或 [Just Zoom](https://legacy.curseforge.com/minecraft/mc-mods/just-zoom-forge)（让你像在 OptiFine 中一样按键缩放）
- [CIT Resewn](https://www.curseforge.com/minecraft/mc-mods/cit-resewn)（在未安装 OptiFine 的情况下添加对 OptiFine 资源包的支持）
