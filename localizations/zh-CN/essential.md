# Essential

最近版本的 Essential 模组添加了对 FancyMenu 的兼容性，这意味着你现在应该能够完全自定义 Essential 添加到标题界面和暂停界面的所有元素！

关于如何自定义 Essential 界面的详细指南，请查看 [这篇 wiki 页面](https://essential.gg/wiki/fancymenu)（来自 Essential wiki）！

# 自定义问题

如果你在尝试自定义 Essential 的元素时遇到任何 bug 或不便，几乎总是由 Essential 本身引起的，需要由 Essential 的开发者在他们那边修复。

你应该通过他们的 Discord 或 GitHub 向 Essential 团队报告该 bug/问题。
