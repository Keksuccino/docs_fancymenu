# Essential

由于 [Essential](https://www.curseforge.com/minecraft/mc-mods/essential-mod) 模组方面添加了对 FancyMenu 的支持，该模组曾经与 FancyMenu 兼容，但现在这种兼容性似乎**已经不复存在**。

自从该模组或启动器的某次更新后，用户再次报告了 Essential 与 FancyMenu 一起使用时出现的大量问题，例如 Essential 元素在布局编辑器中不可见，或自定义的 Essential 元素在离开编辑器后恢复为默认状态。

[这个 GitHub issue](https://github.com/Keksuccino/FancyMenu/issues/1762) 讨论了其中一个问题。

> [!IMPORTANT]
> 此冲突/不兼容问题需要由 **ESSENTIAL 方面** 修复。FancyMenu **并没有过错**，想要恢复 Essential 支持，推荐的方式是向 Essential 团队报告此不兼容问题。
