# ขนาด UI ของ FancyMenu

UI ของ FancyMenu (เช่น แถบเมนูและเมนูคลิกขวา) ใช้สเกลแยกต่างหาก ซึ่งไม่ได้เชื่อมกับสเกล GUI ปกติของ Minecraft

หาก UI ของ FancyMenu ดูเล็กหรือใหญ่เกินไป คุณสามารถเปลี่ยนสเกลของ UI ได้ผ่าน **แถบเมนู -> การปรับแต่ง -> การตั้งค่า -> UI ของ FancyMenu**

FancyMenu 3.9.0 เพิ่มตัวเลือกสเกล UI มากขึ้น เมื่อกำหนดสเกล UI เป็น **อัตโนมัติ** สเกลอัตโนมัติที่เล็กที่สุดตอนนี้คือ `1.25`; คุณยังสามารถเลือกสเกล `1` เองได้หากต้องการ

ข้อยกเว้นเพียงอย่างเดียวคือหน้าจอแบบเต็มที่ FancyMenu เพิ่มเข้ามา เช่น หน้าจอสำหรับจัดการตัวแปรหรือเครื่องมือแก้ไขเลย์เอาต์ โดยส่วนใหญ่หน้าจอเหล่านี้จะใช้สเกล GUI ปกติของ Minecraft แต่ก็เป็นไปได้ว่าบางหน้าจอจะใช้ตรรกะการปรับสเกลอัตโนมัติแบบอื่น เพื่อแสดงผลในขนาดเล็กลงโดยอัตโนมัติเมื่อหน้าต่างมีขนาดเล็กเกินไปจนไม่สามารถแสดงเนื้อหาของหน้าจอทั้งหมดได้
