# ขนาด UI ของ FancyMenu

UI ของ FancyMenu (เช่น แถบเมนูและเมนูคลิกขวา) ใช้สเกลแยกต่างหาก ซึ่งไม่ได้เชื่อมกับขนาด GUI ปกติของ Minecraft

หาก UI ของ FancyMenu ดูเล็กหรือใหญ่เกินไป คุณสามารถเปลี่ยนขนาด UI ได้ที่ **แถบเมนู -> การปรับแต่ง -> การตั้งค่า -> UI ของ FancyMenu**

เมื่อกำหนดขนาด UI เป็น **Auto** ขนาดอัตโนมัติที่เล็กที่สุดคือ `1.25` คุณสามารถเลือกขนาด `1` ด้วยตนเองได้

ข้อยกเว้นเพียงอย่างเดียวคือหน้าจอแบบเต็มหน้าจอที่ FancyMenu เพิ่มเข้ามาจริง ๆ เช่น หน้าจอสำหรับจัดการตัวแปรหรือเครื่องมือแก้ไขเลย์เอาต์ โดยในกรณีส่วนใหญ่ หน้าจอเหล่านี้จะใช้ขนาด GUI ปกติของ Minecraft แต่เป็นไปได้ว่าบางหน้าจอจะใช้ตรรกะการปรับขนาดอัตโนมัติแบบอื่น เพื่อแสดงผลในขนาดที่เล็กลงโดยอัตโนมัติเมื่อหน้าต่างเล็กเกินไปจนแสดงเนื้อหาทั้งหมดของหน้าจอไม่ได้
