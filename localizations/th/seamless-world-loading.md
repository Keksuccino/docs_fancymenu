# โหลดโลกอย่างต่อเนื่อง

การโหลดโลกอย่างต่อเนื่องจะใช้ภาพมุมมองล่าสุดของโลกหรือเซิร์ฟเวอร์เป็นพื้นหลังของหน้าจอโหลดครั้งถัดไป

เปิดใช้ได้ที่ [**การปรับแต่ง -> การปรับแต่งส่วนกลาง**](/global-customizations) -> **โหลดโลกอย่างต่อเนื่อง**

# วิธีการทำงาน

- FancyMenu จะจับภาพเฟรมปัจจุบันเป็นระยะ ๆ ขณะที่คุณอยู่ในโลกหรือเซิร์ฟเวอร์ที่มีการติดตาม
- ระบบจะบันทึกภาพล่าสุดเมื่อคุณออกจากโลกหรือเซิร์ฟเวอร์
- แต่ละโลกและเซิร์ฟเวอร์จะมีชื่อไฟล์ PNG แบบแฮชเป็นของตัวเอง
- FancyMenu จะโหลดภาพจากโลก 5 ภาพล่าสุดและภาพจากเซิร์ฟเวอร์ 5 ภาพล่าสุดไว้ล่วงหน้า
- ระบบจะยังไม่แสดงภาพสำหรับโลกหรือเซิร์ฟเวอร์ใดจนกว่าจะมีการบันทึกภาพครั้งแรก

ภาพจะถูกจัดเก็บไว้ที่:

```text
<game-directory>/fancymenu_data/seamless_world_loading/
```

ภาพหน้าจออาจมีทุกสิ่งที่มองเห็นได้ในโลกขณะจับภาพ การปิดการโหลดโลกอย่างต่อเนื่องจะหยุดการจับภาพและการนำภาพมาใช้ แต่จะไม่ลบไฟล์ PNG ที่มีอยู่ หากต้องการลบภาพที่ไม่ต้องการ ให้ลบไฟล์เหล่านั้นออกจากไดเรกทอรีขณะปิดเกม
