# การโหลดโลกแบบไร้รอยต่อ

การโหลดโลกแบบไร้รอยต่อจะจับภาพหน้าจอเมื่อคุณออกจากโลกหรือเซิร์ฟเวอร์ แล้วนำมาใช้เป็นพื้นหลังระหว่างการโหลดในครั้งถัดไป

วิธีนี้ช่วยให้การเปลี่ยนผ่านระหว่างการโหลดดูราบรื่นขึ้น เพราะหน้าจอโหลดจะสอดคล้องกับสิ่งที่คุณจะเห็นเมื่อโหลดเสร็จ

# จะหาได้ที่ไหน

เปิด **แถบเมนู** ของ FancyMenu ขณะที่ **ไม่ได้** อยู่ในตัวแก้ไขเลย์เอาต์ จากนั้นไปที่ **Customization -> Global Customizations**

# เปิด / ปิด

1. เปิด **Customization -> Global Customizations**
2. หา **Seamless World Loading**
3. ตั้งค่าเป็น **Enabled** หรือ **Disabled**

# วิธีการทำงาน

- เมื่อเปิดใช้งาน FancyMenu จะบันทึกภาพหน้าจอเมื่อคุณออกจากโลก/เซิร์ฟเวอร์
- ในการโหลดครั้งถัดไป ภาพหน้าจอนั้นจะถูกใช้เป็นพื้นหลังระหว่างการโหลด
- การใช้งานครั้งแรก: หากยังไม่มีภาพหน้าจอ ก็จะยังไม่มีอะไรแสดงจนกว่าคุณจะออกจากโลก/เซิร์ฟเวอร์สักครั้ง
