# การโหลดโลกแบบไร้รอยต่อ

การโหลดโลกแบบไร้รอยต่อจะใช้มุมมองล่าสุดของโลกหรือเซิร์ฟเวอร์เป็นพื้นหลังหน้าจอโหลดถัดไป

เปิดใช้งานผ่าน [**การปรับแต่ง -> การปรับแต่งส่วนกลาง**](./global-customizations) -> **การโหลดโลกแบบไร้รอยต่อ**

# วิธีการทำงาน

- FancyMenu จะจับภาพเฟรมปัจจุบันเป็นระยะขณะที่คุณอยู่ในโลกหรือเซิร์ฟเวอร์ที่ติดตามอยู่
- ระบบจะบันทึกภาพที่จับได้ล่าสุดเมื่อคุณออกจากโลกหรือเซิร์ฟเวอร์นั้น
- แต่ละโลกและเซิร์ฟเวอร์จะมีชื่อไฟล์ PNG แบบแฮชของตัวเอง
- FancyMenu จะโหลดล่วงหน้าภาพจับล่าสุดของโลกได้สูงสุดห้าใบ และของเซิร์ฟเวอร์ได้สูงสุดห้าใบ
- จะไม่มีอะไรแสดงสำหรับเป้าหมายใด ๆ จนกว่าจะมีการบันทึกภาพจับครั้งแรก

ภาพที่จับได้จะถูกเก็บไว้ใน:

```text
<game-directory>/fancymenu_data/seamless_world_loading/
```

ภาพหน้าจออาจมีทุกอย่างที่มองเห็นได้ในโลกขณะทำการจับภาพ การปิดใช้งานการโหลดโลกแบบไร้รอยต่อจะหยุดการจับภาพและการใช้งาน แต่จะไม่ลบไฟล์ PNG ที่มีอยู่แล้ว ลบภาพที่ไม่ต้องการออกจากไดเรกทอรีเมื่อปิดเกมอยู่
