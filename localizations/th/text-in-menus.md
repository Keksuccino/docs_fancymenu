# ข้อความในเมนู

FancyMenu อนุญาตให้คุณเพิ่มเนื้อหาข้อความลงในเมนู/หน้าจอได้ผ่านองค์ประกอบ **Text**

องค์ประกอบนี้สามารถเลื่อนได้ รองรับ Markdown อย่างเต็มรูปแบบ และตัดบรรทัดอัตโนมัติ ซึ่งทำให้มันทรงพลังมากสำหรับการแสดงผลข้อความที่ซับซ้อน แต่ก็เหมาะอย่างยิ่งสำหรับข้อความสั้น ๆ บรรทัดเดียวด้วยเช่นกัน

# เนื้อหาข้อความ

องค์ประกอบ Text สามารถดึงเนื้อหาได้หลายวิธี โดยคุณสามารถกำหนดแหล่งที่มาของเนื้อหาข้อความได้ ซึ่งอาจเป็นข้อความธรรมดาแบบป้อนตรง ไฟล์ข้อความในเครื่องจากไดเรกทอรี assets ของ FancyMenu (`<game-directory>/config/fancymenu/assets/`) ไฟล์ข้อความบนเว็บ (ผ่าน URL) หรือไฟล์ข้อความในเครื่องที่โหลดผ่าน resource pack

การใช้แหล่งข้อมูลแบบเว็บเป็นแหล่งข้อความนั้นมีประโยชน์อย่างยิ่ง หากคุณต้องการทำสิ่งอย่างเช่น changelog ที่อัปเดตอยู่เสมอ หรือแถบข่าวสารและสิ่งคล้ายกัน โดยไม่จำเป็นต้องปล่อยอัปเดตสำหรับ modpack ของคุณ

โปรดทราบว่า FancyMenu จะเก็บแคชเนื้อหาจากแหล่งข้อความไว้ จึงไม่จำเป็นต้องดึงเนื้อหาซ้ำอยู่ตลอดเวลา (ซึ่งจะส่งผลเสียต่อประสิทธิภาพมาก) เนื้อหาจะถูกแคชไว้เฉพาะสำหรับเซสชันที่ใช้งานอยู่เท่านั้น ดังนั้นการเริ่มเกมใหม่จะล้างแคชได้ คุณยังสามารถล้างแคชได้โดยรีโหลด FancyMenu ผ่าน **menu bar -> Customization -> Reload FancyMenu**

# ตัวแปรแทนค่า

องค์ประกอบ Text ยังรองรับระบบตัวแปรแทนค่าของ FancyMenu ซึ่งทำให้สามารถทำให้เนื้อหาข้อความเปลี่ยนแปลงได้ตามสถานการณ์ และตอบสนองต่อการเปลี่ยนแปลงต่าง ๆ ของเมนู โลก ผู้เล่น และอื่น ๆ

# การปรับแต่งหรือปิดใช้งาน Markdown

หากคุณต้องการปรับแต่งสีของหัวข้อหรือสิ่งอื่น ๆ ที่เกี่ยวกับ Markdown เพียงแค่ **คลิกขวา** ที่องค์ประกอบ Text แล้วคลิก **Markdown** ในเมนูย่อยที่เปิดขึ้น คุณจะเห็นตัวเลือกมากมายสำหรับปรับแต่งรูปลักษณ์และพฤติกรรมของตัวแยกวิเคราะห์ Markdown

ถ้าคุณไม่ต้องการให้มีการแยกวิเคราะห์ Markdown เลย ซึ่งอาจช่วยเพิ่มประสิทธิภาพสำหรับข้อความยาว ๆ ได้ คุณสามารถปิด Markdown ทั้งหมดได้ในเมนู **Markdown** เมื่อ **คลิกขวา** ที่องค์ประกอบ Text

# ปิดการตัดบรรทัด

หากคุณไม่ต้องการให้ตัดบรรทัด คุณสามารถปิดได้โดย **คลิกขวา** ที่องค์ประกอบ Text

# ปิดการเลื่อนและซ่อนตัวจับเลื่อน

โดยปกติองค์ประกอบ Text สามารถเลื่อนได้ และหากองค์ประกอบคิดว่าผู้ใช้จำเป็นต้องเลื่อนเพื่อดูเนื้อหาทั้งหมด มันจะแสดงแถบเลื่อน/ตัวจับเลื่อน ซึ่งเป็นแถบสีเทากึ่งโปร่งแสงขนาดเล็ก (มีขอบมน) ที่ด้านขวาและด้านล่างขององค์ประกอบ Text (แถบเลื่อนแนวตั้งและแนวนอน) ตัวจับเลื่อนบางครั้งอาจถูกเข้าใจผิดว่าเป็นเงาได้

คุณสามารถปิดตัวจับเลื่อนเหล่านี้ได้โดยปิด **Scrolling** ในเมนูที่เปิดขึ้นเมื่อ **คลิกขวา** ที่องค์ประกอบ การทำเช่นนี้จะปิดการเลื่อนโดยรวม ไม่ใช่แค่ตัวจับเลื่อนเท่านั้น หากคุณเพียงต้องการให้ตัวจับเลื่อนมองไม่เห็น แต่ยังเลื่อนได้อยู่ คุณสามารถตั้งค่าพื้นผิวตัวจับเลื่อนแบบกำหนดเองได้โดยคลิกขวาที่องค์ประกอบ เพียงตั้งค่าพื้นผิวที่โปร่งใสทั้งหมดไว้ที่นั่น

# รูปแบบข้อความ Raw Component ของ Minecraft (Serialized JSON Components)

องค์ประกอบ Text ไม่รองรับรูปแบบ raw component ของ Minecraft รูปแบบนี้รองรับเฉพาะป้ายชื่อของปุ่มและสไลเดอร์เท่านั้น
