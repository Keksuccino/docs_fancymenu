# ข้อความในเมนู

FancyMenu ช่วยให้คุณเพิ่มเนื้อหาข้อความลงในเมนู/หน้าจอต่าง ๆ ได้ผ่านองค์ประกอบ **Text**

องค์ประกอบนี้เลื่อนได้ รองรับ Markdown อย่างเต็มรูปแบบ และตัดบรรทัดอัตโนมัติ ซึ่งทำให้มันทรงพลังมากสำหรับการแสดงเนื้อหาข้อความที่ซับซ้อน แต่ก็เหมาะมากสำหรับข้อความสั้น ๆ บรรทัดเดียวเช่นกัน

## เนื้อหาข้อความ

องค์ประกอบ Text สามารถดึงเนื้อหาได้หลายวิธี โดยคุณสามารถกำหนดแหล่งที่มาของเนื้อหาข้อความได้ ซึ่งอาจเป็นข้อความธรรมดาที่ป้อนโดยตรง, ไฟล์ข้อความในเครื่องจากโฟลเดอร์ `assets` ของ FancyMenu (`/config/fancymenu/assets/`), ไฟล์ข้อความบนเว็บ (ผ่าน URL) หรือไฟล์ข้อความในเครื่องที่โหลดผ่าน resource pack

การใช้แหล่งที่มาแบบเว็บสำหรับข้อความจะมีประโยชน์มาก โดยเฉพาะถ้าคุณต้องการทำสิ่งอย่างเช่น changelog ที่อัปเดตเสมอ หรือข่าววิ่ง และสิ่งที่คล้ายกัน โดยไม่จำเป็นต้องปล่อยอัปเดตใหม่ให้กับ modpack ของคุณ

โปรดทราบว่า FancyMenu จะเก็บแคชเนื้อหาของแหล่งที่มาข้อความไว้ เพื่อไม่ให้ต้องดึงเนื้อหาซ้ำอยู่ตลอดเวลา (ซึ่งจะส่งผลเสียต่อประสิทธิภาพมาก) เนื้อหาจะถูกแคชไว้เฉพาะสำหรับเซสชันที่ใช้งานอยู่เท่านั้น ดังนั้นการเริ่มเกมใหม่จะล้างแคชได้ คุณยังสามารถล้างแคชได้โดยรีโหลด FancyMenu ผ่าน **menu bar -> Customization -> Reload FancyMenu**

## Placeholder

องค์ประกอบ Text ยังรองรับระบบ placeholder ของ FancyMenu ซึ่งทำให้สามารถทำให้เนื้อหาข้อความเปลี่ยนแปลงแบบไดนามิกและตอบสนองต่อการเปลี่ยนแปลงต่าง ๆ ของเมนู, โลก, ผู้เล่น ฯลฯ ได้

## การปรับแต่งหรือปิด Markdown

หากคุณต้องการปรับแต่งสีของหัวข้อหรือสิ่งอื่น ๆ ที่เกี่ยวข้องกับ Markdown เพียงแค่ **คลิกขวา** องค์ประกอบ Text แล้วคลิก **Markdown** ในเมนูย่อยที่เปิดขึ้น คุณจะเห็นตัวเลือกมากมายสำหรับปรับแต่งรูปลักษณ์และพฤติกรรมของตัวแยกวิเคราะห์ Markdown

ในกรณีที่คุณไม่ต้องการให้มีการแยก Markdown เลย ซึ่งอาจช่วยเพิ่มประสิทธิภาพสำหรับเนื้อหาข้อความยาว ๆ ได้ คุณสามารถปิด Markdown ได้ทั้งหมดในเมนู **Markdown** เมื่อ **คลิกขวา** องค์ประกอบ Text

## การปิดการตัดบรรทัดอัตโนมัติ

ถ้าคุณไม่ต้องการให้ตัดบรรทัดอัตโนมัติ คุณสามารถปิดได้โดย **คลิกขวา** องค์ประกอบ Text

## การปิดการเลื่อน

โดยปกติองค์ประกอบ Text จะเลื่อนได้ และหากองค์ประกอบคิดว่าผู้ใช้จำเป็นต้องเลื่อนเพื่อดูเนื้อหาทั้งหมด มันจะแสดงแถบเลื่อน ซึ่งเป็นแถบสีเทาขนาดเล็กที่ด้านขวาและด้านล่างขององค์ประกอบ Text (แถบเลื่อนแนวตั้งและแนวนอน)

คุณสามารถปิดแถบเหล่านี้ได้โดยปิด **Scrolling** ในเมนูที่เปิดขึ้นเมื่อ **คลิกขวา** องค์ประกอบ การทำเช่นนี้จะปิดการเลื่อนโดยรวม ไม่ใช่แค่การแสดงแถบเท่านั้น หากคุณต้องการให้แถบมองไม่เห็นแทน คุณสามารถกำหนดพื้นผิวของแถบเลื่อนแบบกำหนดเองได้โดยคลิกขวาองค์ประกอบ แล้วตั้งค่า texture ที่โปร่งใสทั้งหมดไว้ที่นั่น

## รูปแบบข้อความ Raw Component ของ Minecraft (Serialized JSON Components)

องค์ประกอบ Text **ไม่รองรับ** รูปแบบ raw component ของ Minecraft โดยรูปแบบนี้รองรับเฉพาะป้ายกำกับของปุ่มและสไลเดอร์เท่านั้น
