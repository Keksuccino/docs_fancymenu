# ข้อความในเมนู

FancyMenu ช่วยให้คุณเพิ่มเนื้อหาข้อความลงในเมนู/หน้าจอได้ผ่านองค์ประกอบ **Text**

องค์ประกอบนี้เลื่อนได้ รองรับ Markdown เต็มรูปแบบ และตัดบรรทัดอัตโนมัติ ทำให้ทรงพลังมากสำหรับการแสดงข้อความที่ซับซ้อน แม้แต่เนื้อหาข้อความที่ซับซ้อนก็แสดงได้ดี แต่ก็เหมาะมากสำหรับข้อความสั้น ๆ เพียงหนึ่งบรรทัดเช่นกัน

# เนื้อหาข้อความ

องค์ประกอบ Text สามารถดึงเนื้อหาได้หลายวิธี คุณสามารถกำหนดแหล่งที่มาของเนื้อหาข้อความได้ ซึ่งอาจเป็นข้อความธรรมดาที่ป้อนโดยตรง, ไฟล์ข้อความในโฟลเดอร์ `assets` ของ FancyMenu (`/config/fancymenu/assets/`), ไฟล์ข้อความจากเว็บ (ผ่าน URL) หรือไฟล์ข้อความในเครื่องที่โหลดผ่าน resource pack

การใช้แหล่งข้อความจากเว็บมีประโยชน์อย่างยิ่งหากคุณต้องการทำสิ่งต่าง ๆ เช่น changelog ที่อัปเดตอยู่เสมอ หรือข่าววิ่ง และสิ่งที่คล้ายกัน โดยไม่จำเป็นต้องปล่อยอัปเดตสำหรับ modpack ของคุณ

โปรดทราบว่า FancyMenu จะเก็บแคชเนื้อหาจากแหล่งข้อความไว้ เพื่อไม่ต้องดึงเนื้อหาซ้ำตลอดเวลา (ซึ่งจะส่งผลเสียต่อประสิทธิภาพอย่างมาก) เนื้อหาจะถูกแคชเฉพาะในเซสชันปัจจุบันเท่านั้น ดังนั้นเมื่อเริ่มเกมใหม่ แคชจะถูกล้าง คุณยังสามารถล้างแคชได้โดยรีโหลด FancyMenu ผ่าน **แถบเมนู -> การปรับแต่ง -> โหลด FancyMenu ใหม่**

# ตัวแปรแทนค่า

องค์ประกอบ Text ยังรองรับระบบตัวแปรแทนค่าของ FancyMenu ซึ่งทำให้สามารถทำให้เนื้อหาข้อความเปลี่ยนแปลงได้ตามสถานการณ์ และตอบสนองต่อการเปลี่ยนแปลงต่าง ๆ ของเมนู โลก ผู้เล่น ฯลฯ

# การปรับแต่งหรือปิด Markdown

หากคุณต้องการปรับแต่งสีของหัวเรื่องหรือสิ่งอื่น ๆ ที่เกี่ยวข้องกับ Markdown เพียงแค่ **คลิกขวา** ที่องค์ประกอบ Text แล้วคลิก **Markdown** ในเมนูย่อยที่เปิดขึ้น คุณจะเห็นตัวเลือกมากมายสำหรับปรับแต่งรูปลักษณ์และพฤติกรรมของตัวแปล Markdown

หากคุณไม่ต้องการให้มีการแยกวิเคราะห์ Markdown เลย ซึ่งสามารถช่วยเพิ่มประสิทธิภาพสำหรับเนื้อหาข้อความยาว ๆ ได้ คุณสามารถปิด Markdown ทั้งหมดได้ในเมนู **Markdown** เมื่อ **คลิกขวา** ที่องค์ประกอบ Text

# การปิดการตัดบรรทัดอัตโนมัติ

หากคุณไม่ต้องการให้มีการตัดบรรทัดอัตโนมัติ คุณสามารถปิดได้โดย **คลิกขวา** ที่องค์ประกอบ Text

# การปิดการเลื่อนและการซ่อนตัวจับเลื่อน

โดยค่าเริ่มต้นองค์ประกอบ Text สามารถเลื่อนได้ และหากองค์ประกอบคิดว่าผู้ใช้จำเป็นต้องเลื่อนเพื่อดูเนื้อหาทั้งหมด มันจะแสดงแถบเลื่อน/ตัวจับเลื่อน ซึ่งเป็นแถบสีเทากึ่งโปร่งใสขนาดเล็ก (มีขอบมน) ที่ด้านขวาและด้านล่างขององค์ประกอบ Text (แถบเลื่อนแนวตั้งและแนวนอน) บางครั้งตัวจับเลื่อนอาจถูกเข้าใจผิดว่าเป็นเงา

คุณสามารถปิดตัวจับเลื่อนเหล่านี้ได้โดยปิด **Scrolling** ในเมนูที่เปิดขึ้นเมื่อ **คลิกขวา** ที่องค์ประกอบ การทำเช่นนี้จะปิดการเลื่อนโดยรวม ไม่ใช่แค่ตัวจับเลื่อน หากคุณเพียงต้องการให้ตัวจับเลื่อนมองไม่เห็น แต่ยังเลื่อนได้อยู่ คุณสามารถตั้งค่าพื้นผิวตัวจับเลื่อนแบบกำหนดเองได้โดยคลิกขวาที่องค์ประกอบ เพียงตั้งพื้นผิวที่โปร่งใสทั้งหมดไว้ที่นั่น

# รูปแบบข้อความ Raw Component ของ Minecraft (Serialized JSON Components)

องค์ประกอบ Text **ไม่รองรับ** รูปแบบ raw component ของ Minecraft รูปแบบนี้รองรับเฉพาะป้ายกำกับของปุ่มและสไลเดอร์เท่านั้น
