# ข้อความในเมนู

FancyMenu มีองค์ประกอบสำหรับข้อความ 2 แบบ:

- **Text** แสดงข้อความในเมนูโดยตรง ตั้งแต่ข้อความบรรทัดเดียวไปจนถึงหน้าเนื้อหายาวที่เลื่อนได้ เช่น บันทึกการเปลี่ยนแปลง กฎ หรือข่าวสาร
- **Tooltip** แสดงกล่องข้อความในตำแหน่งที่กำหนดไว้หรือข้างเมาส์ เช่น เมื่อวางเมาส์เหนือปุ่ม

ทั้งสองแบบรองรับ [Markdown](/text-formatting) และ [placeholders](/placeholders) และใช้การตั้งค่ารูปลักษณ์และสไตล์ชุดเดียวกัน

<img width="800" alt="กำลังแก้ไของค์ประกอบ Text" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/text_editor_showcase.gif?raw=true">

> [!TIP]
> หน้านี้อธิบายองค์ประกอบและการตั้งค่าต่าง ๆ หากต้องการดูทุกอย่างที่เขียนในข้อความได้ เช่น หัวข้อ รายการ ลิงก์ และสี โปรดดู [การจัดรูปแบบข้อความ](/text-formatting)

# การเพิ่มข้อความ

1. เปิดเลย์เอาต์ในตัวแก้ไขเลย์เอาต์
2. คลิกขวาที่พื้นหลังของตัวแก้ไข แล้วเลือก **New Element -> Text**
3. คลิกขวาที่องค์ประกอบใหม่ แล้วเลือก **Text Content**
4. พิมพ์ข้อความ แล้วคลิก **Done**

# เนื้อหาข้อความ

## โหมดแหล่งที่มา

คลิกขวาที่องค์ประกอบ แล้วตั้งค่า **Source Mode**:

- **Direct**: พิมพ์ข้อความเองในตัวแก้ไขข้อความ
- **Resource**: ดึงข้อความจากไฟล์ข้อความ คลิก **Text Source** เพื่อเลือกไฟล์ในเครื่องจาก `<game-directory>/config/fancymenu/assets/`, URL เว็บไซต์ หรือไฟล์จาก resource pack ดูรายละเอียดที่ [Resources](/resources)

แหล่งข้อมูลจากเว็บเหมาะอย่างยิ่งสำหรับสิ่งต่าง ๆ เช่น บันทึกการเปลี่ยนแปลงหรือข่าวสารที่อัปเดตอยู่เสมอ โดยไม่ต้องอัปเดต modpack

FancyMenu จะจดจำข้อความจากไฟล์และแหล่งข้อมูลบนเว็บจนกว่าจะปิดเกม หากต้องการโหลดอีกครั้ง ให้โหลด FancyMenu ใหม่ด้วย **menu bar -> Customization -> Reload FancyMenu**

## ข้อความแบบไดนามิก

ข้อความสามารถแสดงค่าปัจจุบันได้ด้วย [placeholders](/placeholders) เช่น `Welcome, {"placeholder":"playername"}!` นอกจากนี้ยังแสดงค่าของ [variables](/variables) ได้ด้วย ข้อความจะอัปเดตเองเมื่อค่าเหล่านี้เปลี่ยนแปลง

## ตัวแก้ไขข้อความ

คลิก **Text Content** เพื่อเปิดตัวแก้ไขข้อความ คลิก **Placeholders** ที่มุมขวาบนเพื่อเรียกดู placeholders ทั้งหมดและเพิ่มลงในข้อความ

### ปุ่มลัดสำหรับจัดรูปแบบ

ตัวแก้ไขข้อความขององค์ประกอบ Text และ Tooltip มีปุ่มลัดสำหรับการจัดรูปแบบที่ใช้บ่อย หากใช้ macOS ให้กด `Cmd` แทน `Ctrl`

| ปุ่มลัด | การทำงาน |
|---|---|
| `Ctrl + B` | ตัวหนา |
| `Ctrl + I` | ตัวเอียง |
| `Ctrl + U` | ขีดเส้นใต้ |
| `Ctrl + L` | จัดชิดซ้าย |
| `Ctrl + E` | จัดกึ่งกลาง |
| `Ctrl + R` | จัดชิดขวา |

- เลือกข้อความก่อนเพื่อจัดรูปแบบ กดปุ่มลัดเดิมอีกครั้งเพื่อนำรูปแบบออก
- หากไม่ได้เลือกข้อความ ปุ่มลัดจะเพิ่มอักขระจัดรูปแบบและวางเคอร์เซอร์ไว้ระหว่างอักขระเหล่านั้น เพื่อให้พิมพ์ต่อได้ทันที
- ปุ่มลัดสำหรับจัดแนวจะมีผลกับบรรทัดที่เลือก หรือบรรทัดที่เคอร์เซอร์อยู่ หากกด `Ctrl + E` หรือ `Ctrl + R` บนบรรทัดที่จัดแนวแบบนั้นอยู่แล้ว ระบบจะจัดบรรทัดกลับไปชิดซ้าย
- คลิกขวาในตัวแก้ไข แล้วเปิด **Formatting** เพื่อดูปุ่มลัดทั้งหมดในเมนู

### ปุ่มลัดอื่น ๆ

ตัวแก้ไขข้อความเดียวกันนี้ใช้กับข้อความส่วนใหญ่ใน FancyMenu เช่น ค่าของ action และการตั้งค่าองค์ประกอบหลายรายการ ปุ่มลัดเหล่านี้ใช้ได้กับทุกส่วน หากใช้ macOS ให้กด `Cmd` แทน `Ctrl`

| ปุ่มลัด | การทำงาน |
|---|---|
| `Ctrl + C` | คัดลอกข้อความที่เลือก |
| `Ctrl + X` | ตัดข้อความที่เลือก |
| `Ctrl + V` | วาง |
| `Ctrl + A` | เลือกข้อความทั้งหมด |
| `Ctrl + Z` | เลิกทำ |
| `Ctrl + Y` | ทำซ้ำ |
| `Ctrl + D` | ทำซ้ำบรรทัดที่เคอร์เซอร์อยู่ |
| `Alt + Arrow Up` / `Alt + Arrow Down` | ย้ายบรรทัดที่เคอร์เซอร์อยู่ขึ้นหรือลง |
| `Shift + Arrow keys` | เลือกข้อความ |
| `Ctrl + Home` / `Ctrl + End` | ไปยังจุดเริ่มต้นหรือจุดสิ้นสุดของข้อความ |
| `Ctrl + G` | ไปยังบรรทัดที่ต้องการ: พิมพ์หมายเลขบรรทัดแล้วกด `Enter` |
| `Ctrl + S` | ทำงานเหมือน **Done** |

ดูปุ่มลัดของตัวแก้ไขเลย์เอาต์ได้ที่ [Layout Editor](/layout-editor#shortcuts)

# รูปลักษณ์และสไตล์

คลิกขวาที่องค์ประกอบ แล้วเปิด **Markdown** เพื่อปรับรูปลักษณ์ของข้อความ

## รูปลักษณ์

**Look** จะตั้งค่าตัวเลือกสไตล์ทั้งหมดของข้อความพร้อมกัน:

- **Pixel**: ลายพิกเซลที่ออกแบบมาสำหรับฟอนต์ Minecraft ใช้สีโทนอุ่น รายละเอียดสีทอง และเครื่องหมายที่วาดด้วยมือ
- **Classic**: รูปลักษณ์ดั้งเดิมของ FancyMenu ใช้ข้อความสีขาว กล่องสีเทา และเส้นสีเทา
- **Neutral**: รูปลักษณ์เรียบสะอาด ใช้สีตามธีม UI ของ FancyMenu ที่ใช้อยู่ โดยสีจะถูกบันทึกไว้กับองค์ประกอบ จึงยังคงเดิมแม้ภายหลังจะเปลี่ยนธีม

<img width="800" alt="รูปลักษณ์ Markdown ทั้งสามแบบ" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/markdown_looks.png?raw=true">

องค์ประกอบใหม่จะเริ่มต้นด้วยรูปลักษณ์ Pixel ส่วนองค์ประกอบจากเลย์เอาต์เก่าจะยังคงใช้รูปลักษณ์ Classic แบบเดิม

> [!NOTE]
> การเลือกรูปลักษณ์จะเขียนทับการปรับสไตล์ที่คุณกำหนดเอง หากเปลี่ยนใจ ก็เลิกทำได้ด้วย `Ctrl + Z`

## ตัวเลือกสไตล์

หลังเลือกรูปลักษณ์แล้ว คุณยังปรับแต่งแต่ละส่วนได้ตามต้องการ เมนู **Markdown** มีตัวเลือกสำหรับ **Text**, **Headlines**, **Lists**, **Links**, **Code**, **Quotes**, **Callouts**, **Tables**, **Images** และ **Separators** วางเมาส์เหนือตัวเลือกเพื่อดูว่าทำอะไรได้บ้าง

**Markdown -> Text** มีการตั้งค่าพื้นฐาน เช่น สีข้อความ เงาข้อความ ระยะห่างระหว่างบรรทัด และระยะห่างระหว่างข้อความกับขอบขององค์ประกอบ

## ปิด Markdown

หากไม่ต้องการใช้ Markdown ให้ปิด **Markdown -> Markdown Parser** จากนั้นข้อความจะแสดงตรงตามที่พิมพ์ไว้ และยังช่วยให้การแสดงข้อความที่ยาวมากทำงานเร็วขึ้นเล็กน้อยด้วย

## การตั้งค่าข้อความอื่น ๆ

คลิกขวาที่องค์ประกอบเพื่อค้นหาการตั้งค่าเหล่านี้ด้วย:

- **Text Scale** ปรับขนาดข้อความให้ใหญ่ขึ้นหรือเล็กลง
- **Case Mode** แสดงข้อความตามปกติ เป็นตัวพิมพ์ใหญ่ทั้งหมด หรือตัวพิมพ์เล็กทั้งหมด
- **Auto Line Wrapping** ตัดบรรทัดที่ยาวเกินองค์ประกอบ หากปิดไว้ บรรทัดยาวจะต่อเนื่องไปเรื่อย ๆ
- **Remove HTML Line Breaks** ลบตัวแบ่งบรรทัด HTML (`<br>`) ออกจากข้อความ เหมาะสำหรับข้อความจากเว็บไซต์

# พื้นหลัง

องค์ประกอบ Text สามารถแสดงแผงพื้นหลังด้านหลังข้อความได้ เปิด **Background** จากเมนูคลิกขวาขององค์ประกอบ:

- **Show Background** เปิดหรือปิดแผงพื้นหลัง องค์ประกอบ Text ใหม่จะเปิดตัวเลือกนี้ไว้
- โดยค่าเริ่มต้นจะใช้แผงสีเข้มที่มีมาให้ คุณสามารถใช้เท็กซ์เจอร์ของตัวเองแทนได้ โดยใช้ [nine-slicing](/nine-slicing-and-tiling) และการปูกระเบื้องเพื่อรักษารูปทรงของขอบ
- **Padding** กำหนดให้พื้นหลังขยายออกไปจากข้อความมากแค่ไหน
- **Reach Behind Scroll Bars** ให้พื้นหลังครอบคลุมแถบเลื่อนด้วย หากปิดไว้ แถบเลื่อนจะอยู่ชิดกับพื้นหลัง

Tooltip มีเมนู **Background** ของตัวเอง ซึ่งใช้กำหนดเท็กซ์เจอร์และ nine-slicing ได้

# การเลื่อน

องค์ประกอบ Text จะเลื่อนได้เมื่อข้อความมีขนาดใหญ่เกินพื้นที่ ใช้ล้อเมาส์เพื่อเลื่อน กด `Shift` ค้างไว้เพื่อเลื่อนในแนวนอน

**Scroll Direction** กำหนดให้ข้อความเลื่อนแบบ **Vertical**, **Horizontal** หรือ **Both** หากเลื่อนในทิศทางใดไม่ได้ เนื้อหาส่วนที่พอดีไม่พอจะแสดงจะถูกตัดออก

## การตั้งค่าการเลื่อน

เปิด **Scrolling** จากเมนูคลิกขวาขององค์ประกอบ:

| การตั้งค่า | การทำงาน |
|---|---|
| **Let Players Scroll** | กำหนดว่าผู้เล่นจะเลื่อนข้อความเองได้หรือไม่ หากปิดไว้ ข้อความจะเลื่อนเองหรือเลื่อนผ่าน actions เท่านั้น |
| **Scroll Speed** | กำหนดระยะทางที่ล้อเมาส์เลื่อนในแต่ละขั้น |
| **Smooth Scrolling** | ทำให้ข้อความเลื่อนไหลต่อเนื่อง แทนที่จะกระโดดเป็นช่วง ๆ |
| **Drag to Scroll** | ให้ผู้เล่นจับข้อความด้วยเมาส์แล้วลากได้ เหมือนการเลื่อนบนหน้าจอสัมผัส |
| **Scroll with Keyboard** | ขณะวางเมาส์เหนือข้อความ กด `Page Up` และ `Page Down` เพื่อเลื่อนทีละหน้า หรือกด `Home` และ `End` เพื่อไปยังจุดเริ่มต้นและจุดสิ้นสุด |
| **Snap** | กำหนดตำแหน่งที่ข้อความหยุด: ตำแหน่งใดก็ได้ (**Off**), ให้มีบรรทัดเต็มอยู่ด้านบน (**To Lines**), ให้มีหัวข้ออยู่ด้านบน (**To Headlines**) หรือเลื่อนทีละหน้าเต็ม (**To Pages**) |
| **Start At** | กำหนดให้ข้อความเริ่มที่ **Start** หรือ **End** ตำแหน่งท้ายเหมาะกับสิ่งต่าง ๆ เช่น บันทึก ซึ่งข้อมูลใหม่สุดอยู่ท้ายสุด |
| **Reset When Screen Opens** | เริ่มข้อความกลับจากจุดเริ่มต้นทุกครั้งที่เปิดหน้าจอ หากปิดไว้ ข้อความจะจำตำแหน่งที่เลื่อนไว้จนกว่าจะปิดเกม |

## เลื่อนอัตโนมัติ

เปิด **Auto-Scroll** เพื่อให้ข้อความเลื่อนเองอย่างช้า ๆ เช่น เครดิตท้ายเรื่องหรือแถบข่าว:

- **Scroll on Its Own** เปิดการเลื่อนอัตโนมัติ
- **Speed [Pixels per Second]** กำหนดความเร็วในการเลื่อน
- **Start Over at the End** เริ่มใหม่จากด้านบนเมื่อเลื่อนถึงท้ายข้อความ
- **Pause While Hovered** หยุดเลื่อนเมื่อเมาส์อยู่เหนือข้อความ เพื่อให้ผู้เล่นอ่านได้อย่างสบายใจ

## แถบเลื่อน

เปิด **Scroll Bars** เพื่อปรับแถบเลื่อน:

- **Show** กำหนดว่าแถบเลื่อนจะแสดงเมื่อใด: **Always**, แสดงเฉพาะ **While Scrolling** หรือ **Never** แม้เลือก **Never** ก็ยังเลื่อนด้วยล้อเมาส์ได้
- **Thickness** กำหนดความหนาของแถบเลื่อน
- **Vertical Bar on the Left** และ **Horizontal Bar on Top** ย้ายแถบเลื่อนไปอยู่อีกด้าน
- **Scroll Grabber Style** เลือกรูปลักษณ์ของตัวจับแถบเลื่อน: **Theme Bar** (ใช้สีตามธีม UI ของ FancyMenu) หรือ **Pixel Handle** (ลายพิกเซลที่เข้ากันได้ดีกับรูปลักษณ์ Pixel)
- **Scroll Grabber Textures** และ **Scroll Grabber Color [HEX]** ใช้แทนตัวจับแถบเลื่อนด้วยเท็กซ์เจอร์หรือสีของคุณเอง
- **Scroll Bar Backgrounds** เพิ่มเท็กซ์เจอร์ไว้ด้านหลังตัวจับแถบเลื่อน ตลอดแนวที่ตัวจับเคลื่อนที่

## ควบคุมการเลื่อนด้วย Actions

คุณยังควบคุมและตรวจสอบการเลื่อนจากส่วนอื่น ๆ ของ FancyMenu ได้ด้วย:

- [action](/action-scripts) **Scroll an Element** เลื่อนองค์ประกอบ Text ไปยังจุดเริ่มต้น จุดสิ้นสุด ตำแหน่งที่กำหนด หมายเลขบรรทัด หรือบรรทัดแรกที่มีข้อความที่ระบุ
- [placeholders](/placeholders) **Element Scroll Position**, **Element Scroll Percent** และ **Element Scroll Content Size** ใช้บอกว่าข้อความเลื่อนไปไกลแค่ไหนและมีขนาดเท่าใด
- [requirement](/conditions) **Is Element Scrolled to End** ตรวจสอบว่าข้อความเลื่อนไปจนสุดแล้วหรือยัง เช่น ใช้เปิดปุ่ม "Accept" หลังจากอ่านกฎแล้วเท่านั้น
- [listeners](/listeners) **On Element Scrolled**, **On Element Scrolled to Start** และ **On Element Scrolled to End** เรียกใช้ actions ขณะที่ข้อความเลื่อน

ทั้งหมดนี้ต้องใช้ [ตัวระบุองค์ประกอบ](/element-identifiers) ขององค์ประกอบ Text

# การคลิกผ่านองค์ประกอบ Text

องค์ประกอบ Text ตอบสนองต่อเมาส์ เพื่อให้ลิงก์และแถบเลื่อนใช้งานได้ ซึ่งหมายความว่าองค์ประกอบจะรับการคลิกด้วย ดังนั้นปุ่มที่อยู่ด้านหลังหรือด้านหน้าองค์ประกอบ Text อาจไม่ได้รับการคลิก

หากเกิดปัญหานี้ ให้คลิกขวาที่องค์ประกอบ Text แล้วปิด **Interactable** จากนั้นจะเลื่อนข้อความไม่ได้และคลิกลิงก์ไม่ได้อีกต่อไป

# Tooltips

องค์ประกอบ Tooltip ทำงานเหมือนองค์ประกอบ Text แต่ไม่มีการเลื่อน:

- ใช้การตั้งค่าข้อความ รูปลักษณ์ และสไตล์แบบเดียวกับองค์ประกอบ Text
- **Follow Mouse** ทำให้ Tooltip เคลื่อนตามเมาส์
- ใช้ [requirements](/conditions) เพื่อกำหนดว่า Tooltip จะแสดงเมื่อใด เช่น requirement [**Is Element Hovered**](/conditions#is-element-hovered) สำหรับแสดง Tooltip เมื่อวางเมาส์เหนือปุ่ม
