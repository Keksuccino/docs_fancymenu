# เอนทิตีผู้เล่น

FancyMenu อนุญาตให้คุณเพิ่มเอนทิตีผู้เล่นลงในหน้าจอได้ เพื่อให้คุณแสดงผู้เล่นฝั่งไคลเอนต์หรือผู้เล่นคนอื่น ๆ รวมถึงเอนทิตีแบบกำหนดเองที่ไม่ได้แทนผู้เล่นจริงเลย โดยใช้สกิน ชื่อ ผ้าคลุม และอื่น ๆ แบบกำหนดเอง

# ผู้เล่นฝั่งไคลเอนต์

หากต้องการแสดง "ภาพสะท้อน" ของผู้เล่นฝั่งไคลเอนต์ เพียงคลิกขวาที่องค์ประกอบ Player Entity แล้วเปิดใช้งาน **Copy Client Player** การทำเช่นนี้จะคัดลอกสกิน ผ้าคลุม และชื่อของผู้เล่นฝั่งไคลเอนต์

# ผู้เล่นคนอื่น

หากคุณต้องการแสดงผู้เล่นที่มีอยู่คนอื่น เพียงคลิกขวาที่องค์ประกอบ แล้วตั้งค่า **Player Name** เป็นชื่อผู้เล่นที่มีอยู่ การทำเช่นนี้จะแสดงสกิน ผ้าคลุม และชื่อของผู้เล่นคนนั้นโดยอัตโนมัติ ตราบใดที่คุณไม่ได้ตั้งค่าสกินหรือผ้าคลุมแบบกำหนดเอง และ **Copy Client Player** ต้องเป็น **ปิดใช้งาน**

# เอนทิตีผู้เล่นแบบกำหนดเอง

หากคุณไม่ต้องการแสดงผู้เล่นจริง และต้องการปรับแต่งสกิน ผ้าคลุม และชื่อของเอนทิตีแบบเต็มที่ คุณสามารถคลิกขวาที่องค์ประกอบได้ โดยมีตัวเลือกให้ตั้งค่าสกินและเท็กซ์เจอร์ผ้าคลุมแบบกำหนดเอง หากเปิดใช้งานสกินและผ้าคลุมแบบกำหนดเองแล้ว คุณยังสามารถตั้งชื่อผู้เล่นอะไรก็ได้ตามต้องการ โดยที่ระบบจะไม่คัดลอกสกินของชื่อผู้เล่นนั้นแม้ผู้เล่นคนนั้นจะมีอยู่จริงก็ตาม

# ท่าทางของเอนทิตี

องค์ประกอบ Player Entity รองรับการปรับแต่งท่าทางได้อย่างเต็มที่ กล่าวคือ คุณสามารถขยับแขน ขา ลำตัว และส่วนต่าง ๆ ของร่างกายได้อย่างอิสระ

วิธีทำคือ คลิกขวาที่องค์ประกอบ แล้วคลิก **Player Pose** จากนั้นจะเปิดหน้าจอที่มีสไลเดอร์ให้ตั้งค่าการหมุน X/Y/Z ของทุกส่วนของร่างกาย

การตั้งค่าท่าทางของผู้เล่นมีโหมดปกติที่คุณสามารถปรับการหมุนด้วยสไลเดอร์ได้ และยังมีโหมดขั้นสูงที่ให้ป้อนข้อความสำหรับค่าการหมุนทั้งหมด พร้อมรองรับ placeholder อย่างเต็มรูปแบบ ซึ่งทำให้สามารถอนิเมตเอนทิตีด้วยองค์ประกอบ Ticker ที่ตั้งค่าตัวแปรการหมุนได้อีกด้วย!

# การเปลี่ยนขนาดของเอนทิตี

ใน Minecraft 1.20.1+ คุณสามารถใช้ตัวจับปรับขนาดปกติขององค์ประกอบเพื่อย่อ/ขยายเอนทิตีได้โดยตรง

สำหรับเวอร์ชันเก่า (1.19.2 และเก่ากว่า) องค์ประกอบ Player Entity ไม่รองรับการปรับขนาดโดยตรงผ่านตัวจับปรับขนาด แทนที่จะเป็นเช่นนั้น คุณต้องคลิกขวาที่องค์ประกอบแล้วคลิก **Scale** ซึ่งจะช่วยให้คุณตั้งค่าการสเกลขององค์ประกอบได้ ค่าเริ่มต้นควรเป็น `30` ดังนั้นการตั้งเป็น `60` จะทำให้ผู้เล่นมีขนาดใหญ่กว่าปกติเป็นสองเท่า การตั้งเป็น `15` จะแสดงผลครึ่งหนึ่งของขนาดปกติ และอื่น ๆ ตามลำดับ

# การพึ่งพา: Fancy Entity Renderer (FER)

สำหรับ **Minecraft 1.20.1+** จำเป็นต้องมี **ม็อดเพิ่มเติม** เพื่อให้ Player Entity ใช้งานได้ ม็อดนี้ชื่อ **Fancy Entity Renderer** และสามารถดาวน์โหลดได้จาก [CurseForge](https://www.curseforge.com/minecraft/mc-mods/fancy-entity-renderer) และ [Modrinth](https://modrinth.com/mod/fancy-entity-renderer)

หากยังไม่มีบิลด์สำหรับเวอร์ชัน Minecraft ที่คุณใช้อยู่ ก็มีแนวโน้มว่าจะถูกปล่อยในภายหลัง

โปรดทราบว่า FER ไม่ได้พัฒนาโดย Keksuccino ดังนั้นเขาจึงไม่สามารถควบคุมได้ว่าบิลด์จะถูกปล่อยเมื่อใด
