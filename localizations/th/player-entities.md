# เอนทิตีผู้เล่น

FancyMenu อนุญาตให้คุณเพิ่มเอนทิตีผู้เล่นลงในหน้าจอได้ เพื่อให้คุณแสดงผู้เล่นฝั่งไคลเอนต์หรือผู้เล่นอื่น ๆ รวมถึงเอนทิตีแบบกำหนดเองที่ไม่ได้แทนผู้เล่นจริงเลยก็ได้ โดยมีสกิน ชื่อ เคป และอื่น ๆ แบบกำหนดเอง

# ผู้เล่นฝั่งไคลเอนต์

หากต้องการแสดง "กระจกเงา" ของผู้เล่นฝั่งไคลเอนต์ ให้คลิกขวาที่องค์ประกอบ Player Entity แล้วเปิดใช้งาน **Copy Client Player** ค่านี้จะคัดลอกสกิน เคป และชื่อของผู้เล่นฝั่งไคลเอนต์

# ผู้เล่นอื่น

หากคุณต้องการแสดงผู้เล่นที่มีอยู่แล้วอีกคนหนึ่ง ให้คลิกขวาที่องค์ประกอบแล้วตั้งค่า **Player Name** เป็นชื่อผู้เล่นที่มีอยู่ ระบบจะแสดงสกิน เคป และชื่อของผู้เล่นคนนั้นโดยอัตโนมัติ ตราบใดที่คุณไม่ได้ตั้งสกินหรือเคปแบบกำหนดเอง และ **Copy Client Player** ถูก **ปิดใช้งาน**

# เอนทิตีผู้เล่นแบบกำหนดเอง

หากคุณไม่ต้องการแสดงผู้เล่นจริง และต้องการกำหนดสกิน เคป และชื่อของเอนทิตีด้วยตัวเองทั้งหมด คุณสามารถคลิกขวาที่องค์ประกอบได้ มีตัวเลือกสำหรับตั้งค่าสกินและเท็กซ์เจอร์เคปแบบกำหนดเอง หากมีการเปิดใช้งานสกินและเคปแบบกำหนดเอง คุณยังสามารถตั้งชื่อผู้เล่นเป็นอะไรก็ได้ โดยที่ชื่อดังกล่าวจะไม่ทำให้มันคัดลอกสกินของชื่อผู้เล่นนั้น แม้ว่าผู้เล่นคนนั้นจะมีอยู่จริงก็ตาม

# ท่าทางของเอนทิตี

องค์ประกอบ Player Entity รองรับการปรับแต่งท่าทางอย่างเต็มรูปแบบ กล่าวคือ คุณสามารถขยับแขน ขา ลำตัว และส่วนต่าง ๆ ของร่างกายได้อย่างอิสระ

ในการทำเช่นนั้น ให้คลิกขวาที่องค์ประกอบแล้วคลิก **Player Pose** จากนั้นจะเปิดหน้าจอที่มีแถบเลื่อนสำหรับกำหนดการหมุนแกน X/Y/Z ของส่วนต่าง ๆ ของร่างกายทั้งหมด

การตั้งค่าท่าทางของผู้เล่นมีโหมดปกติที่ให้คุณปรับการหมุนด้วยแถบเลื่อนได้ และยังมีโหมดขั้นสูงที่ให้ป้อนข้อความสำหรับค่าการหมุนทั้งหมดพร้อมรองรับ placeholder เต็มรูปแบบ ซึ่งทำให้สามารถแม้กระทั่งทำแอนิเมชันให้เอนทิตีด้วยองค์ประกอบ Ticker ที่ตั้งค่าตัวแปรการหมุนได้!

# การเปลี่ยนขนาดของเอนทิตี

ใน Minecraft 1.21.1+ คุณสามารถใช้ที่จับปรับขนาดปกติขององค์ประกอบเพื่อย่อ/ขยายเอนทิตีได้โดยตรง

สำหรับเวอร์ชันเก่า (1.21.0 และเก่ากว่า) องค์ประกอบ Player Entity ไม่รองรับการปรับขนาดโดยตรงผ่านที่จับปรับขนาด แทนที่จะเป็นเช่นนั้น คุณต้องคลิกขวาที่องค์ประกอบแล้วคลิก **Scale** วิธีนี้จะช่วยให้คุณตั้งค่าขนาดขององค์ประกอบได้ ค่าเริ่มต้นควรเป็น `30` ดังนั้นการตั้งเป็น `60` จะทำให้ผู้เล่นมีขนาดใหญ่กว่าปกติเป็นสองเท่า การตั้งเป็น `15` จะทำให้แสดงผลที่ครึ่งหนึ่งของขนาด และอื่น ๆ

# การพึ่งพา: Fancy Entity Renderer (FER)

สำหรับ Minecraft 1.21.1+ จำเป็นต้องมีม็อดเพิ่มเติมเพื่อให้ Player Entity element ทำงานได้ ม็อดนี้ชื่อ "Fancy Entity Renderer" และมีให้ดาวน์โหลดบน CurseForge และ Modrinth

หากยังไม่มีบิลด์สำหรับเวอร์ชัน Minecraft ที่คุณใช้อยู่ มีความเป็นไปได้สูงว่าจะถูกปล่อยออกมาในภายหลัง

โปรดทราบว่า FER ไม่ได้พัฒนาโดย Keksuccino ดังนั้นเขาจึงไม่สามารถควบคุมได้ว่าบิลด์จะถูกปล่อยเมื่อใด
