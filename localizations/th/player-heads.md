# หัวผู้เล่นในเมนู

ในการแสดงหัวของผู้เล่นเป็นภาพ 2D หรือ 3D โดยใช้องค์ประกอบ Image คุณสามารถใช้เว็บ API ของบุคคลที่สามที่ชื่อว่า "Minotar" ได้

## ภาพ 2D

### 1. เพิ่มองค์ประกอบ Image

ในตัวแก้ไข FancyMenu ให้คลิกขวาที่พื้นหลัง เลือก "New Element" แล้วเลือก "Image" (หรือ "Picture")

### 2. ตั้งค่าแหล่งที่มาจากเว็บ

คลิกขวาที่องค์ประกอบ Image เพื่อเข้าถึงคุณสมบัติของมัน สำหรับประเภทแหล่งที่มา ให้เลือก "Web"

### 3. สร้าง URL ด้วยตัวแทนที่ถูกต้อง

ในช่อง "Source" คุณจะต้องใส่ URL ต่อไปนี้:
`https://minotar.net/avatar/{"placeholder":"playername"}.png`

FancyMenu จะใช้ `{"placeholder":"playername"}` เพื่อแทรกชื่อผู้เล่นปัจจุบันลงใน URL แบบไดนามิก ทำให้องค์ประกอบ Image สามารถดึงและแสดงหัวของผู้เล่นจาก Minotar ได้

## ภาพ 3D

วิธีนี้คล้ายกับแบบ 2D มาก แต่เราต้องใช้ URL คนละแบบ:

`https://minotar.net/cube/{"placeholder":"playername"}/200.png`

`200` คือขนาดพิกเซลในกรณีนี้ ดังนั้นถ้าคุณต้องการเวอร์ชันที่เล็กกว่า ก็เพียงเปลี่ยนเป็น `100` เป็นต้น หรือถ้าต้องการขนาดใหญ่กว่า ก็ใช้ `300` และอื่น ๆ ได้
