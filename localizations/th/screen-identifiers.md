# ตัวระบุหน้าจอ

FancyMenu ใช้ตัวระบุหน้าจอเพื่อรู้ว่าเลย์เอาต์ใดเป็นของหน้าจอใด เพื่อชี้ไปยังปุ่มในหน้าจอที่ระบุ และงานอื่น ๆ ที่ต้องให้ม็อดสื่อสารกับหน้าจอเฉพาะหรือปรับแต่งหน้าจอเฉพาะนั้น

# การค้นหาตัวระบุของหน้าจอ

คุณสามารถดูตัวระบุของเมนูที่กำลังใช้งานอยู่ได้โดยใช้ **debug overlay**
ซึ่งจะแสดงตัวระบุของหน้าจอปัจจุบัน และให้คุณคัดลอกไปยังคลิปบอร์ดได้โดยการคลิกซ้ายที่มัน

>[!TIP]
>คุณสามารถเปิดใช้งาน **debug overlay** ได้โดยกด **CTRL + ALT + D** ในขณะที่คุณ **ไม่ได้** อยู่ในตัวแก้ไขเลย์เอาต์
