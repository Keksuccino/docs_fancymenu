# ตัวระบุหน้าจอ

FancyMenu ใช้ตัวระบุหน้าจอสำหรับเลย์เอาต์ วิดเจ็ต Vanilla, [การทำงานของหน้าจอ](/action-scripts#open-screen-or-custom-gui) และ [การแทนที่ Custom GUI](/custom-guis#overriding-an-existing-screen) ตัวระบุจะคำนึงถึงตัวพิมพ์เล็กและตัวพิมพ์ใหญ่ ดังนั้นให้คัดลอกจากโอเวอร์เลย์ดีบักให้ตรงทุกประการ

หน้าจอที่มีมาในตัวมักใช้ตัวระบุสากลแบบสั้น เช่น `title_screen` ส่วนหน้าจอจากม็อดอื่นอาจใช้ชื่อคลาส Java ส่วน Custom GUI จะใช้ตัวระบุที่กำหนดไว้ในตัวจัดการ ตัวระบุเหล่านี้เป็นตัวระบุหน้าจอของ FancyMenu ไม่ใช่พาธทรัพยากรของ Minecraft

# ค้นหาตัวระบุของหน้าจอ

คุณสามารถดูตัวระบุของเมนูที่กำลังใช้งานได้โดยใช้ **โอเวอร์เลย์ดีบัก**
โอเวอร์เลย์นี้จะแสดงตัวระบุของหน้าจอปัจจุบัน และให้คุณคัดลอกตัวระบุไปยังคลิปบอร์ดได้ด้วยการคลิกซ้ายที่ตัวระบุ

>[!TIP]
>คุณสามารถเปิดใช้ **โอเวอร์เลย์ดีบัก** ได้โดยกด **CTRL + ALT + D** ขณะที่ **ไม่ได้** อยู่ในตัวแก้ไขเลย์เอาต์

# เปิดหน้าจอ

การทำงาน [**เปิดหน้าจอหรือ Custom GUI**](/action-scripts#open-screen-or-custom-gui) จะเปิดได้เฉพาะหน้าจอที่ FancyMenu สร้างขึ้นได้ในสถานะปัจจุบันของเกม หน้าจอบางประเภทต้องอาศัยโลกที่โหลดแล้ว การเชื่อมต่อ ผู้เล่น หรือหน้าจอหลักเดิม

หาก FancyMenu สร้างหน้าจอตามตัวระบุไม่ได้ ระบบจะแสดงข้อผิดพลาด ให้ใช้ [**เลียนแบบปุ่ม Vanilla/ม็อด**](/action-scripts#mimic-vanillamod-button) กับวิดเจ็ตที่ปกติใช้เปิดหน้าจอนั้น
