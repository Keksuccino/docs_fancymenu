# ความทึบขององค์ประกอบ

องค์ประกอบส่วนใหญ่ใน FancyMenu (มีข้อยกเว้นบางส่วน) รองรับการตั้งค่าความทึบผ่านเมนูคลิกขวา

ค่าความทึบขององค์ประกอบรองรับตัวแทนข้อความ (placeholders) ซึ่งทำให้สามารถอัปเดตความทึบแบบไดนามิกตามตัวแทนข้อความได้

สิ่งนี้ทำให้สามารถสร้างตรรกะการเฟดแบบกำหนดเองได้ เมื่อใช้ร่วมกับองค์ประกอบ Ticker เพื่ออัปเดตค่าตัวแปร แล้วนำค่านั้นไปใช้เป็นความทึบผ่านตัวแทนข้อความ

หากต้องการตั้งค่าความทึบขององค์ประกอบ ให้ **คลิกขวาที่องค์ประกอบ -> Opacity -> Set**.

# การทำให้องค์ประกอบค่อยๆ ปรากฏ/หายไป

หากคุณต้องการเพียงให้ค่อยๆ ปรากฏหรือค่อยๆ หายไปขององค์ประกอบ การใช้ฟีเจอร์เฟดในตัวขององค์ประกอบน่าจะง่ายกว่า คุณสามารถเปิดใช้งานการเฟดได้จากเมนูคลิกขวาขององค์ประกอบ

ฟีเจอร์นี้จะทำให้องค์ประกอบค่อยๆ ปรากฏทุกครั้งที่โหลด ไม่ว่าจะเป็นการโหลดครั้งแรกเมื่อเปิดเมนู หรือเมื่อข้อกำหนดการโหลดขององค์ประกอบทำให้มันถูกโหลด องค์ประกอบจะค่อยๆ หายไปทุกครั้งที่ข้อกำหนดการโหลดทำให้มันถูกยกเลิกการโหลด/มองไม่เห็น

ฟีเจอร์เฟดรองรับการตั้งค่าความเร็วในการเฟด เพื่อควบคุมว่าองค์ประกอบจะค่อยๆ ปรากฏหรือหายไปเร็วแค่ไหน
