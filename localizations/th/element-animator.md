# ตัวสร้างแอนิเมชันขององค์ประกอบ

**Animator** เป็นองค์ประกอบที่ช่วยให้คุณทำให้องค์ประกอบอื่น ๆ เคลื่อนไหวได้ ด้วยองค์ประกอบนี้ คุณสามารถเปลี่ยนขนาด ตำแหน่ง และจุดยึดขององค์ประกอบอื่นอย่างราบรื่นตามเวลา โดยใช้คีย์เฟรม คีย์เฟรมเปรียบเสมือนภาพสแนปช็อตที่บันทึกว่าองค์ประกอบควรมีหน้าตาเป็นอย่างไรในช่วงเวลาหนึ่ง ๆ จากนั้นองค์ประกอบ Animator จะเล่นสแนปช็อตเหล่านี้ตามลำดับเพื่อสร้างการเคลื่อนไหวที่ลื่นไหล

> **Element Animator** ช่วยให้คุณควบคุม **ตำแหน่ง ขนาด และจุดยึด** ขององค์ประกอบได้ **ไม่สามารถ** ควบคุมการตั้งค่าอื่นใดขององค์ประกอบได้ เช่น ความทึบแสง การมองเห็น การหมุน เป็นต้น!

# การเพิ่มองค์ประกอบ Animator

1. **คลิกขวาที่พื้นหลัง:**  
   ในตัวแก้ไขเลย์เอาต์ ให้คลิกขวาที่พื้นหลัง

2. **เลือก New Element -> Element Animator:**  
   ในเมนูที่ปรากฏขึ้น ให้ไปที่ **New Element** แล้วคลิก **Element Animator** เพื่อเพิ่มองค์ประกอบ Animator ลงในเลย์เอาต์ของคุณ

3. **ตั้งค่าให้เรียบร้อย:**  
   หลังจากเพิ่มแล้ว องค์ประกอบ Animator จะปรากฏพร้อมค่าตั้งต้น คุณสามารถเปลี่ยนตัวเลือกต่าง ๆ เช่น การวนซ้ำหรือสี ได้โดยคลิกขวาที่ Animator แล้วเลือกจากเมนู

# การจัดการคีย์เฟรม

คีย์เฟรมเปรียบเสมือนที่คั่นหน้าที่บอก Animator ว่าองค์ประกอบควรมีหน้าตาเป็นอย่างไรในช่วงเวลาใดเวลาหนึ่ง

## การเปิดตัวแก้ไขคีย์เฟรม

- **เปิดตัวแก้ไข:**  
  คลิกขวาที่องค์ประกอบ Animator แล้วเลือก **Edit Keyframes** (หรือ **Manage Keyframes**) จะเปิดหน้าจอที่ให้คุณเพิ่ม แก้ไข หรือลบคีย์เฟรมได้

## การบันทึกและเพิ่มคีย์เฟรม

- **เริ่มบันทึก:**  
  ในตัวแก้ไขคีย์เฟรม ให้กดปุ่ม **`R`** เพื่อเริ่มบันทึก เมื่อกำลังบันทึก กล่องพรีวิวจะเปลี่ยนสีเพื่อแสดงว่าอยู่ในโหมดทำงาน
  
- **เปลี่ยนพรีวิว:**  
  ย้ายหรือปรับขนาดกล่องพรีวิวเพื่อกำหนดรูปลักษณ์ที่ต้องการ ในโหมด offset พรีวิวจะยังคงอยู่กึ่งกลางบนเส้นกากบาท เพื่อแสดงการเปลี่ยนแปลงแบบออฟเซ็ต
  
- **เพิ่มคีย์เฟรม:**  
  กดปุ่ม **`K`** เพื่อบันทึกรูปลักษณ์ปัจจุบันเป็นคีย์เฟรม คีย์เฟรมนี้จะบันทึกตำแหน่ง ขนาด และการตั้งค่าจุดยึดของพรีวิว

## การแก้ไขคีย์เฟรม

- **เลือกคีย์เฟรม:**  
  คลิกที่ตัวบ่งชี้คีย์เฟรมในไทม์ไลน์ คุณยังสามารถกด **Ctrl** ค้างไว้แล้วคลิกเพื่อเลือกได้หลายรายการ
  
- **ย้ายคีย์เฟรม:**  
  ลากตัวบ่งชี้คีย์เฟรมไปทางซ้ายหรือขวาเพื่อเปลี่ยนเวลา หรือใช้:
  - **ลูกศรซ้าย:** เพื่อเลื่อนให้เร็วขึ้น 100 มิลลิวินาที
  - **ลูกศรขวา:** เพื่อเลื่อนให้ช้าลง 100 มิลลิวินาที
  
- **ปรับพรีวิวอย่างละเอียด:**  
  เมื่อเลือกคีย์เฟรมแล้ว ให้ปรับกล่องพรีวิวโดยการย้ายหรือปรับขนาด ใช้ **Ctrl + Z** เพื่อเลิกทำ และ **Ctrl + Y** เพื่อทำซ้ำ หากจำเป็น

## การลบคีย์เฟรม

- **ลบคีย์เฟรม:**  
  เลือกคีย์เฟรมแล้วกดปุ่ม **Delete** เพื่อลบ
  
- **ลบหลายคีย์เฟรม:**  
  คุณสามารถเลือกคีย์เฟรมหลายรายการได้ (เช่น ใช้ **Ctrl + A** เพื่อเลือกทั้งหมด) แล้วกด Delete เพื่อลบทั้งหมด

## การทำให้คีย์เฟรมนุ่มนวล

การทำให้คีย์เฟรมนุ่มนวลเป็นฟีเจอร์ที่ช่วยจัดระยะคีย์เฟรมให้เท่ากันอย่างสม่ำเสมอ ทำให้แอนิเมชันดูต่อเนื่องและลื่นไหลมากขึ้น

- **เลือกคีย์เฟรมหลายรายการ:**  
  ก่อนอื่น ให้เลือกคีย์เฟรมตั้งแต่สองรายการขึ้นไปที่คุณต้องการทำให้ลื่นไหลขึ้น (ใช้ **Ctrl + คลิก** หรือ **Ctrl + A**)

- **คลิกปุ่ม Smoothing:**  
  ในแถบเครื่องมือด้านล่างของตัวแก้ไขคีย์เฟรม ให้คลิกปุ่ม **Distance Smoothing**

- **ใส่ระยะใหม่:**  
  จะมีกล่องป้อนข้อมูลเล็ก ๆ ปรากฏขึ้น ให้พิมพ์ค่า (เป็นมิลลิวินาที) เพื่อกำหนดช่วงเวลาห่างเท่ากันระหว่างคีย์เฟรมที่เลือกแต่ละรายการ

- **นำการทำให้ลื่นไหลไปใช้:**  
  กด Enter เพื่อใช้การทำให้ลื่นไหล คีย์เฟรมจะถูกปรับให้ความต่างของเวลาแต่ละรายการเท่ากัน

# การพรีวิวแอนิเมชันของคุณ

หลังจากบันทึกคีย์เฟรมแล้ว คุณสามารถดูว่าแอนิเมชันของคุณจะเป็นอย่างไร:

- **เล่นแอนิเมชัน:**  
  ในตัวแก้ไขคีย์เฟรม ให้กดปุ่ม **`P`** หรือคลิกปุ่มเล่น พรีวิวจะเริ่มจากต้นและแสดงว่ากล่องพรีวิวเปลี่ยนแปลงอย่างไรตามเวลา
  
- **หมายเหตุเกี่ยวกับการวนซ้ำ:**  
  ขณะพรีวิวในตัวแก้ไขคีย์เฟรม แอนิเมชันจะ **ไม่วนซ้ำ** หมายความว่ามันจะเล่นจากต้นจนจบเพียงครั้งเดียว การวนซ้ำจะทำงานก็ต่อเมื่อองค์ประกอบ Animator ถูกนำไปใช้กับองค์ประกอบเป้าหมายในเลย์เอาต์จริงเท่านั้น
  
- **หยุดพรีวิวชั่วคราว:**  
  กดปุ่ม **`P`** อีกครั้งเพื่อหยุดแอนิเมชันชั่วคราว หากคุณต้องการหยุดที่จุดใดจุดหนึ่ง
  
- **ลากแถบความคืบหน้า:**  
  หากมี ให้คุณลากตัวบ่งชี้ไทม์ไลน์เพื่อตรวจดูว่าแอนิเมชันเป็นอย่างไรในช่วงเวลาใดเวลาหนึ่ง

# การเลือกองค์ประกอบเป้าหมาย

หลังจากตั้งค่าคีย์เฟรมแล้ว คุณต้องเลือกว่าจะให้องค์ประกอบใดในเลย์เอาต์ถูกทำให้เคลื่อนไหว:

1. **เปิดตัวจัดการเป้าหมาย:**  
   คลิกขวาที่องค์ประกอบ Animator แล้วเลือก **Manage Targets**
  
2. **เพิ่มเป้าหมาย:**  
   คลิก **Add Target** เพื่อดูรายการองค์ประกอบที่มีอยู่ เลือกองค์ประกอบที่คุณต้องการทำให้เคลื่อนไหว
  
3. **ลบเป้าหมาย:**  
   หากต้องการลบเป้าหมาย ให้เปิดตัวจัดการแล้วคลิก **Remove Target**

เมื่อแอนิเมชันเล่นในเลย์เอาต์จริง Animator จะใช้คีย์เฟรมของคุณเพื่อเปลี่ยนขนาด ตำแหน่ง และอื่น ๆ ขององค์ประกอบที่เลือก การวนซ้ำจะถูกนำมาใช้ที่นี่หากคุณตั้งค่าไว้

# แป้นพิมพ์ลัด

ใช้แป้นพิมพ์ลัดเหล่านี้ในตัวแก้ไขคีย์เฟรมเพื่อทำงานได้เร็วขึ้น:

- **ปุ่ม `R`:** เริ่มหรือหยุดการบันทึก
- **ปุ่ม `T`:** หยุดชั่วคราวหรือกลับมาบันทึกต่อ
- **ปุ่ม `P`:** เล่นหรือหยุดพรีวิวแอนิเมชันชั่วคราว
- **ปุ่ม `K`:** เพิ่มคีย์เฟรมใหม่ในเวลาปัจจุบัน
- **ปุ่มลูกศรซ้าย/ขวา:**  
  - **ลูกศรซ้าย:** เลื่อนคีย์เฟรมให้เร็วขึ้น 100 มิลลิวินาที
  - **ลูกศรขวา:** เลื่อนคีย์เฟรมให้ช้าลง 100 มิลลิวินาที
- **ปุ่ม Delete:** ลบคีย์เฟรมที่เลือก
- **Ctrl + A:** เลือกคีย์เฟรมทั้งหมด
- **Ctrl + Z:** เลิกทำการเปลี่ยนแปลงล่าสุดของคุณ
- **Ctrl + Y:** ทำซ้ำการเปลี่ยนแปลงที่เพิ่งเลิกทำไป
- **Ctrl + ลากคีย์เฟรม**: ลากคีย์เฟรมที่เลือกหลายรายการพร้อมกัน

# การตั้งค่าเพิ่มเติมและเคล็ดลับ

- **วนซ้ำแอนิเมชัน:**  
  คุณสามารถตั้งค่า Animator ให้วนซ้ำได้ เมื่อเปิดการวนซ้ำ แอนิเมชันจะเริ่มใหม่หลังจากคีย์เฟรมสุดท้าย แต่โปรดทราบว่านี่จะเกิดขึ้นเฉพาะกับองค์ประกอบเป้าหมายสุดท้ายเท่านั้น ในพรีวิวของตัวแก้ไขคีย์เฟรมจะไม่มีการวนซ้ำ
  
- **ไม่สนใจขนาด/ตำแหน่ง:**  
  หากคุณไม่ต้องการให้คีย์เฟรมเปลี่ยนขนาดหรือตำแหน่งขององค์ประกอบ ให้ปิดตัวเลือกเหล่านี้

- **ออฟเซ็ตเวลา:**
  FancyMenu 3.9.0 เพิ่มออฟเซ็ตเวลาให้กับองค์ประกอบที่ถูกควบคุม คุณสามารถกำหนดออฟเซ็ตเวลาให้กับองค์ประกอบเป้าหมายแต่ละตัว หรือใช้ออฟเซ็ตเวลาแบบสุ่มภายในช่วงที่กำหนด เพื่อให้แอนิเมชันเดียวกันเริ่มในเวลาที่ต่างกันเล็กน้อยสำหรับแต่ละเป้าหมาย
  
- **โหมด Offset:**  
  ในโหมด offset แอนิเมชันจะถูกนำมาใช้เป็นการเปลี่ยนแปลงจากตำแหน่งเดิมขององค์ประกอบ พรีวิวจะแสดงอยู่กึ่งกลางบนเส้นกากบาท
  
- **เลิกทำและทำซ้ำ:**  
  ใช้ **Ctrl + Z** เพื่อเลิกทำ และ **Ctrl + Y** เพื่อทำซ้ำการเปลี่ยนแปลง
  
- **ตรวจสอบลำดับ:**  
  ตรวจสอบให้แน่ใจว่าคีย์เฟรมของคุณเรียงตามเวลาอย่างถูกต้อง ระบบจะจัดเรียงให้เอง แต่ถ้าคุณย้ายคีย์เฟรมใดคีย์เฟรมหนึ่ง ควรตรวจสอบลำดับอีกครั้ง
  
- **ดูการเปลี่ยนแปลงในพรีวิว:**  
  ใช้ปุ่มเล่นหรือปุ่ม **`P`** เพื่อดูแอนิเมชันของคุณก่อนบันทึก

# สรุป

ด้วยการทำตามขั้นตอนง่าย ๆ เหล่านี้ คุณสามารถเพิ่มองค์ประกอบ Animator ลงในเลย์เอาต์ของคุณและสร้างแอนิเมชันที่ลื่นไหลได้ ไม่ว่าคุณจะบันทึกการเปลี่ยนแปลงแบบสดด้วยพรีวิว ปรับคีย์เฟรมด้วยแป้นพิมพ์ เลือกองค์ประกอบที่จะทำให้เคลื่อนไหว หรือพรีวิวแอนิเมชันเพื่อดูว่ามันเป็นอย่างไร องค์ประกอบ Animator ก็ช่วยให้คุณสร้างชีวิตชีวาให้กับเมนูแบบกำหนดเองได้อย่างง่ายดาย

ขอให้สนุกกับการทำแอนิเมชัน!
