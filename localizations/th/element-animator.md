# Element Animator

**Animator** คือองค์ประกอบที่ช่วยให้คุณทำแอนิเมชันให้องค์ประกอบอื่น ๆ ได้ ด้วยองค์ประกอบนี้ คุณสามารถเปลี่ยนขนาด ตำแหน่ง และจุดยึด (anchor point) ของอีกองค์ประกอบหนึ่งได้อย่างราบรื่นตามเวลาโดยใช้คีย์เฟรม คีย์เฟรมก็เหมือนภาพสแนปช็อตที่บันทึกว่าองค์ประกอบควรมีหน้าตาอย่างไรในช่วงเวลาหนึ่ง ๆ จากนั้น Animator จะเล่นสแนปช็อตเหล่านี้ตามลำดับเพื่อสร้างการเคลื่อนไหวที่ลื่นไหล

> [!WARNING]
> **Element Animator** ให้คุณควบคุมได้เฉพาะ **ตำแหน่ง ขนาด และจุดยึด** ขององค์ประกอบเท่านั้น **ไม่สามารถ**ควบคุมการตั้งค่าอื่น ๆ ขององค์ประกอบได้ เช่น ความทึบ การมองเห็น การหมุน ฯลฯ!

# การเพิ่ม Element Animator

1. **คลิกขวาที่พื้นหลัง:**  
   ในตัวแก้ไขเลย์เอาต์ ให้คลิกขวาที่พื้นหลัง

2. **เลือก New Element -> Element Animator:**  
   ในเมนูที่ปรากฏขึ้น ให้ไปที่ **New Element** แล้วคลิก **Element Animator** วิธีนี้จะเพิ่ม Animator Element เข้าไปในเลย์เอาต์ของคุณ

3. **ตั้งค่าใช้งาน:**  
   หลังจากเพิ่มแล้ว Element Animator จะแสดงพร้อมค่าตั้งต้น คุณสามารถเปลี่ยนตัวเลือกต่าง ๆ เช่น การวนลูปหรือสีได้โดยคลิกขวาที่ Animator แล้วเลือกจากเมนู

# การจัดการคีย์เฟรม

คีย์เฟรมก็เหมือนบุ๊กมาร์กที่บอก Animator ว่าองค์ประกอบควรมีหน้าตาอย่างไรในช่วงเวลาหนึ่ง

## การเปิดตัวแก้ไขคีย์เฟรม

- **เปิดตัวแก้ไข:**  
  คลิกขวาที่ Element Animator แล้วเลือก **Edit Keyframes** (หรือ **Manage Keyframes**) จะเปิดหน้าจอที่ให้คุณเพิ่ม แก้ไข หรือลบคีย์เฟรมได้

## การบันทึกและเพิ่มคีย์เฟรม

- **เริ่มบันทึก:**  
  ในตัวแก้ไขคีย์เฟรม กดปุ่ม **`R`** เพื่อเริ่มบันทึก เมื่อกำลังบันทึก กล่องพรีวิวจะเปลี่ยนสีเพื่อแสดงว่าใช้งานอยู่
  
- **เปลี่ยนพรีวิว:**  
  ย้ายหรือปรับขนาดกล่องพรีวิวเพื่อกำหนดลักษณะที่ต้องการ ในโหมด offset พรีวิวจะยังคงอยู่กึ่งกลางบนเส้นกากบาท เพื่อให้การเปลี่ยนแปลงแสดงเป็นระยะเยื้อง
  
- **เพิ่มคีย์เฟรม:**  
  กดปุ่ม **`K`** เพื่อบันทึกลักษณะปัจจุบันเป็นคีย์เฟรม คีย์เฟรมนี้จะบันทึกตำแหน่ง ขนาด และการตั้งค่าจุดยึดของพรีวิว

## การแก้ไขคีย์เฟรม

- **เลือกคีย์เฟรม:**  
  คลิกที่ตัวบ่งชี้คีย์เฟรมในไทม์ไลน์ คุณยังสามารถกด **Ctrl** ค้างไว้แล้วคลิกเพื่อเลือกได้มากกว่าหนึ่งรายการ
  
- **ย้ายคีย์เฟรม:**  
  ลากตัวบ่งชี้คีย์เฟรมไปทางซ้ายหรือขวาเพื่อเปลี่ยนเวลา คุณยังสามารถใช้:
  - **ลูกศรซ้าย:** เพื่อเลื่อนให้เร็วขึ้น 100 มิลลิวินาที
  - **ลูกศรขวา:** เพื่อเลื่อนให้ช้าลง 100 มิลลิวินาที
  
- **ปรับพรีวิวอย่างละเอียด:**  
  เมื่อเลือกคีย์เฟรมแล้ว ให้ปรับกล่องพรีวิวโดยการย้ายหรือปรับขนาด ใช้ **Ctrl + Z** เพื่อเลิกทำ และ **Ctrl + Y** เพื่อทำซ้ำ หากจำเป็น

## การลบคีย์เฟรม

- **ลบคีย์เฟรม:**  
  เลือกคีย์เฟรมแล้วกดปุ่ม **Delete** เพื่อลบ
  
- **ลบหลายคีย์เฟรม:**  
  คุณสามารถเลือกคีย์เฟรมหลายรายการได้ (เช่น ใช้ **Ctrl + A** เพื่อเลือกทั้งหมด) แล้วกด Delete เพื่อลบทั้งหมด

## การทำให้คีย์เฟรมนุ่มนวล

การทำให้คีย์เฟรมนุ่มนวลเป็นฟีเจอร์ที่ช่วยจัดระยะห่างของคีย์เฟรมให้สม่ำเสมอ ทำให้แอนิเมชันดูต่อเนื่องและราบรื่นมากขึ้น

- **เลือกคีย์เฟรมหลายรายการ:**  
  ก่อนอื่น ให้เลือกคีย์เฟรมอย่างน้อยสองรายการที่ต้องการทำให้ระยะห่างสม่ำเสมอ (ใช้ **Ctrl + คลิก** หรือ **Ctrl + A**)

- **คลิกปุ่ม Smoothing:**  
  ในแถบเครื่องมือด้านล่างของตัวแก้ไขคีย์เฟรม ให้คลิกปุ่ม **Distance Smoothing**

- **ใส่ระยะทางใหม่:**  
  จะมีกล่องกรอกข้อมูลเล็ก ๆ ปรากฏขึ้น ให้พิมพ์ค่า (หน่วยเป็นมิลลิวินาที) เพื่อกำหนดช่วงเวลาห่างเท่ากันระหว่างคีย์เฟรมที่เลือกแต่ละรายการ

- **ใช้การทำให้สม่ำเสมอ:**  
  กด Enter เพื่อใช้การปรับค่านี้ คีย์เฟรมจะถูกปรับให้ความแตกต่างของเวลาดูสม่ำเสมอ

# การดูตัวอย่างแอนิเมชัน

หลังจากบันทึกคีย์เฟรมแล้ว คุณสามารถดูได้ว่าแอนิเมชันจะออกมาเป็นอย่างไร:

- **เล่นแอนิเมชัน:**  
  ในตัวแก้ไขคีย์เฟรม ให้กดปุ่ม **`P`** หรือคลิกปุ่มเล่น พรีวิวจะเริ่มจากจุดเริ่มต้นและแสดงการเปลี่ยนแปลงของกล่องพรีวิวตามเวลา
  
- **หมายเหตุเรื่องการวนลูป:**  
  ระหว่างดูตัวอย่างในตัวแก้ไขคีย์เฟรม แอนิเมชันจะ **ไม่วนลูป** หมายความว่าจะเล่นจากต้นจนจบเพียงครั้งเดียวเท่านั้น การวนลูปจะทำงานก็ต่อเมื่อ Element Animator ถูกนำไปใช้กับองค์ประกอบเป้าหมายในเลย์เอาต์จริงเท่านั้น
  
- **หยุดพรีวิวชั่วคราว:**  
  กดปุ่ม **`P`** อีกครั้งเพื่อหยุดแอนิเมชันชั่วคราว หากคุณต้องการหยุดที่จุดใดจุดหนึ่ง
  
- **ลากแถบความคืบหน้า:**  
  หากมีให้ใช้งาน คุณสามารถลากตัวบ่งชี้ไทม์ไลน์เพื่อดูว่าแอนิเมชันเป็นอย่างไรในช่วงเวลาที่ต้องการ

# การเลือกองค์ประกอบเป้าหมาย

หลังจากตั้งค่าคีย์เฟรมแล้ว คุณต้องเลือกองค์ประกอบในเลย์เอาต์ที่จะถูกทำแอนิเมชัน:

1. **เปิดตัวจัดการเป้าหมาย:**  
   คลิกขวาที่ Element Animator แล้วเลือก **Manage Targets**
  
2. **เพิ่มเป้าหมาย:**  
   คลิก **Add Target** เพื่อดูรายการองค์ประกอบที่มีอยู่ เลือกองค์ประกอบที่คุณต้องการทำแอนิเมชัน
  
3. **ลบเป้าหมาย:**  
   หากต้องการลบเป้าหมาย ให้เปิดตัวจัดการแล้วคลิก **Remove Target**

เมื่อแอนิเมชันทำงานในเลย์เอาต์จริง Animator จะใช้คีย์เฟรมของคุณเพื่อเปลี่ยนขนาด ตำแหน่ง และอื่น ๆ ขององค์ประกอบที่เลือก การวนลูปจะถูกนำมาใช้ตรงนี้หากคุณตั้งค่าไว้

# คีย์ลัด

ใช้คีย์ลัดเหล่านี้ในตัวแก้ไขคีย์เฟรมเพื่อทำงานได้เร็วขึ้น:

- **ปุ่ม `R`:** เริ่มหรือหยุดบันทึก
- **ปุ่ม `T`:** หยุดชั่วคราวหรือทำต่อการบันทึก
- **ปุ่ม `P`:** เล่นหรือหยุดพรีวิวแอนิเมชัน
- **ปุ่ม `K`:** เพิ่มคีย์เฟรมใหม่ในเวลาปัจจุบัน
- **ปุ่มลูกศรซ้าย/ขวา:**  
  - **ลูกศรซ้าย:** ย้ายคีย์เฟรมให้เร็วขึ้น 100 มิลลิวินาที
  - **ลูกศรขวา:** ย้ายคีย์เฟรมให้ช้าลง 100 มิลลิวินาที
- **ปุ่ม Delete:** ลบคีย์เฟรมที่เลือก
- **Ctrl + A:** เลือกคีย์เฟรมทั้งหมด
- **Ctrl + Z:** เลิกทำการเปลี่ยนแปลงล่าสุด
- **Ctrl + Y:** ทำซ้ำการเปลี่ยนแปลงที่เพิ่งเลิกทำ
- **Ctrl + การลากคีย์เฟรม**: ลากคีย์เฟรมที่เลือกหลายรายการพร้อมกัน

# การตั้งค่าและเคล็ดลับเพิ่มเติม

- **วนลูปแอนิเมชัน:**  
  คุณสามารถตั้งให้ Animator วนลูปได้ เมื่อเปิดการวนลูป แอนิเมชันจะเริ่มใหม่หลังคีย์เฟรมสุดท้าย — แต่โปรดทราบว่าสิ่งนี้จะเกิดขึ้นเฉพาะกับองค์ประกอบเป้าหมายสุดท้ายเท่านั้น ในพรีวิวของตัวแก้ไขคีย์เฟรมจะไม่มีการวนลูป
  
- **ไม่สนใจขนาด/ตำแหน่ง:**  
  หากคุณไม่ต้องการให้คีย์เฟรมเปลี่ยนขนาดหรือตำแหน่งขององค์ประกอบ ให้ปิดตัวเลือกเหล่านี้

- **การเยื้องเวลา:**
  คุณสามารถเยื้องเวลาขององค์ประกอบเป้าหมายแต่ละรายการ หรือใช้การเยื้องเวลาแบบสุ่มภายในช่วงที่กำหนด เพื่อให้แอนิเมชันเดียวกันเริ่มคนละเวลาในแต่ละเป้าหมาย
  
- **โหมด Offset:**  
  ในโหมด offset แอนิเมชันจะถูกนำไปใช้เป็นการเปลี่ยนแปลงจากตำแหน่งเดิมขององค์ประกอบ พรีวิวจะแสดงอยู่กึ่งกลางบนเส้นกากบาท
  
- **เลิกทำและทำซ้ำ:**  
  ใช้ **Ctrl + Z** เพื่อเลิกทำ และ **Ctrl + Y** เพื่อทำซ้ำการเปลี่ยนแปลง
  
- **ตรวจสอบลำดับ:**  
  ตรวจสอบให้แน่ใจว่าคีย์เฟรมของคุณเรียงตามเวลาถูกต้อง ระบบจะจัดเรียงให้อัตโนมัติ แต่ถ้าคุณย้ายคีย์เฟรม ให้ตรวจสอบลำดับอีกครั้ง
  
- **ดูตัวอย่างการเปลี่ยนแปลง:**  
  ใช้ปุ่มเล่นหรือปุ่ม **`P`** เพื่อดูแอนิเมชันของคุณก่อนบันทึก
