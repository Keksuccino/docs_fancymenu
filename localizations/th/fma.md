# ภาพเคลื่อนไหว

ไฟล์ AFMA และ FMA เป็นรูปแบบพื้นผิวภาพเคลื่อนไหวที่สร้างขึ้นสำหรับ FancyMenu

# ไฟล์ AFMA

**AFMA** (Advanced FancyMenu Animation) คือรุ่นต่อจากไฟล์ FMA แบบดั้งเดิม

AFMA ใช้รูปแบบที่ไม่ใช่ ZIP ทำให้ไฟล์มีขนาดเล็กลง ใช้หน่วยความจำน้อยลง และทำงานได้ดีกว่า FMA แบบดั้งเดิม

สำหรับพื้นผิวภาพเคลื่อนไหวขนาดใหญ่หรือซับซ้อน ให้ใช้ **AFMA** แทน FMA แบบดั้งเดิม

สร้างไฟล์ AFMA ได้ด้วยตัวสร้างในตัว:

1. เปิดแถบเมนูของ FancyMenu
2. ไปที่ **Tools -> AFMA Creator**
3. นำเข้าหรือแปลงเฟรมของคุณด้วยตัวสร้าง

> [!IMPORTANT]
> ไม่สามารถแพ็กไฟล์ AFMA ด้วยตนเองได้ ให้ใช้ **Tools -> AFMA Creator**

ไฟล์ FMA แบบดั้งเดิมยังคงรองรับอยู่ ดังนั้นเลย์เอาต์ที่มีอยู่ไม่จำเป็นต้องแปลงทันที

# ไฟล์ FMA แบบดั้งเดิม

## การสร้าง FMA

ไฟล์ FMA แบบดั้งเดิมคือไฟล์เก็บถาวร ZIP ที่มีนามสกุล `.fma`

### นามสกุลไฟล์

เปิดการแสดงนามสกุลไฟล์ในตัวจัดการไฟล์ของคุณก่อนสร้างหรือเปลี่ยนชื่อไฟล์ด้านล่าง

บน Windows ให้เปิด File Explorer แล้วเปิด **View -> File name extensions**

<br>
<img width="764" alt="Screenshot_9" src="https://gist.github.com/assets/35544624/1f0a0864-1ad8-4f63-be3a-ab18385539e6"> 

### การเตรียมไฟล์

สร้างโฟลเดอร์ชื่อ `fancymenu_animation` สำหรับเนื้อหาภายในไฟล์เก็บถาวร

สร้างไดเรกทอรี `frames` ซึ่งจำเป็นต้องมี และไดเรกทอรี `intro_frames` ซึ่งเป็นตัวเลือกไว้ภายใน

ในโฟลเดอร์เดียวกัน ให้สร้าง `metadata.json` ตรวจสอบให้แน่ใจว่านามสกุลไฟล์เป็น `.json` ไม่ใช่ `.txt`

ตอนนี้โฟลเดอร์ต้องมี `frames/`, `intro_frames/`, และ `metadata.json`

### JSON เมตาดาตา

เปิด `metadata.json` ในโปรแกรมแก้ไขข้อความ แล้วใช้เทมเพลตนี้:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
  },
  "custom_frame_times_intro": {
  }
}
```

แก้ไขค่าได้ตามต้องการ

#### `loop_count`

ควบคุมจำนวนครั้งที่ภาพเคลื่อนไหวเล่น ใช้ `0` เพื่อวนซ้ำไม่สิ้นสุด หากเป็นค่ามากกว่า 0 ภาพจะเล่นตามจำนวนนั้น แล้วค้างไว้ที่เฟรมสุดท้าย

#### `frame_time`

กำหนดระยะเวลาที่แต่ละเฟรมปกติแสดงผล หน่วยเป็นมิลลิวินาที

#### `frame_time_intro`

กำหนดระยะเวลาเฟรมสำหรับเฟรม **intro** ที่เป็นตัวเลือก

#### `custom_frame_times`

สามารถกำหนดระยะเวลาของเฟรมปกติแต่ละเฟรมแบบเฉพาะเจาะจงได้ ตัวอย่างนี้จะทำให้เฟรม `0` และ `1` แสดงเป็นเวลา `5000` มิลลิวินาที ส่วนเฟรมอื่นจะใช้ `frame_time`:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
    "0": 5000,
    "1": 5000
  },
  "custom_frame_times_intro": {
  }
}
```

ดัชนีของเฟรมเริ่มนับจากศูนย์: เฟรมแรกคือ `0` เฟรมที่สองคือ `1` และต่อไปเรื่อย ๆ

ใส่เครื่องหมายจุลภาคหลังทุกรายการ custom frame-time ยกเว้นรายการสุดท้าย

#### `custom_frame_times_intro`

ใช้รูปแบบเดียวกับ `custom_frame_times` แต่จะมีผลกับเฟรม intro ที่เป็นตัวเลือก

บันทึก `metadata.json`

### เฟรม

> [!CAUTION]
> จำกัด FMA แบบดั้งเดิมไว้ที่ไม่เกิน 200 เฟรมและความละเอียด 1080p ใช้ [Video](./video) สำหรับเนื้อหาที่ยาวหรือมีอัตราเฟรมสูง

วางเฟรมปกติไว้ใน `frames/` เฟรมต้องเป็นไฟล์ PNG ที่ตั้งชื่อเรียงลำดับจาก `0.png` เช่น `0.png`, `1.png`, และ `2.png` ไม่รองรับรูปแบบและชื่ออื่น

หากต้องการแยกเฟรมจากวิดีโอ ดู [การแยกเฟรมด้วย FFmpeg](./ffmpeg-frames)

### เฟรม Intro

วางเฟรม intro ที่เป็นตัวเลือกไว้ใน `intro_frames/` เฟรมเหล่านี้ใช้กฎการตั้งชื่อ PNG แบบเดียวกับเฟรมปกติ เล่นครั้งเดียวก่อนลำดับปกติ และไม่วนซ้ำ

### การแพ็กไฟล์ FMA

สร้างไฟล์ ZIP ที่มีเนื้อหาภายในโฟลเดอร์ โดย `metadata.json`, `frames/`, และไดเรกทอรี `intro_frames/` ที่เป็นตัวเลือก ต้องอยู่ที่รากของ ZIP ไม่ใช่ภายในไดเรกทอรีอื่น

บน Windows ให้เลือกเนื้อหาภายใน `fancymenu_animation` คลิกขวาที่ส่วนที่เลือก แล้วเลือก **Send to -> Compressed (zipped) folder**

# การใช้ไฟล์ AFMA และ FMA ใน FancyMenu

> [!IMPORTANT]
> ไฟล์ AFMA/FMA เป็นพื้นผิวภาพเคลื่อนไหว ดังนั้นให้เพิ่มผ่านอินพุต [**Image**](./elements#image) เกือบทุกอย่างที่รองรับรูปภาพก็รองรับไฟล์ AFMA และ FMA ด้วย

ใช้ไฟล์ AFMA/FMA ได้ทุกที่ที่รองรับรูปภาพ รวมถึง [Image elements](./elements#image) และ [Image menu backgrounds](./menu-backgrounds)

เก็บไฟล์ AFMA/FMA ไว้ใน `<game-directory>/config/fancymenu/assets/` เพื่อให้ปรากฏในตัวเลือกทรัพยากรภายในเครื่องของ FancyMenu
