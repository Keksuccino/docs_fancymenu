# แอนิเมชัน

ไฟล์ AFMA/FMA คือไฟล์เท็กซ์เจอร์แบบเคลื่อนไหวพิเศษที่สร้างขึ้นสำหรับ FancyMenu
มันแทบจะเหมือนกับ APNG ทุกอย่าง แต่ถูกปรับแต่งให้เหมาะกับ FancyMenu มากกว่าเยอะ

# ไฟล์ AFMA

FancyMenu 3.9.0 เพิ่ม **AFMA** (Advanced FancyMenu Animation) ซึ่งเป็นรุ่นต่อจากไฟล์ FMA แบบคลาสสิก

ไฟล์ AFMA จะไม่ใช่ไฟล์ ZIP อีกต่อไปแล้ว โดยใช้รูปแบบแอนิเมชันแบบใหม่ของ FancyMenu ซึ่งมีขนาดไฟล์ดีกว่า ใช้หน่วยความจำน้อยกว่า และให้ประสิทธิภาพที่ดีกว่า

สำหรับเท็กซ์เจอร์เคลื่อนไหวขนาดใหญ่หรือซับซ้อนแบบใหม่ ให้ใช้ **AFMA** แทน FMA แบบคลาสสิก

วิธีสร้างไฟล์ AFMA:

1. เปิดแถบเมนูของ FancyMenu
2. ไปที่ **Tools -> AFMA Creator**
3. นำเข้าหรือแปลงเฟรมของคุณด้วยตัวสร้าง

> [!IMPORTANT]
> ไฟล์ AFMA ไม่สามารถแพ็กด้วยตนเองเหมือน FMA แบบคลาสสิกได้ คุณต้องใช้ **AFMA Creator** เพื่อแพ็ก/สร้างไฟล์เหล่านี้

ไฟล์ FMA แบบคลาสสิกยังคงรองรับอยู่ และได้รับการปรับปรุงใน FancyMenu 3.9.0 ดังนั้นเลย์เอาต์เดิมจึงไม่จำเป็นต้องแปลงทันที

# ไฟล์ FMA แบบคลาสสิก

## การสร้าง FMA

การสร้างไฟล์ FMA นั้นง่ายพอๆ กับการสร้างไฟล์ ZIP! เอาจริงๆ ก็เพราะภายในมัน _ก็คือ_ ไฟล์ ZIP นั่นเอง

### นามสกุลไฟล์

คุณต้องมองเห็นนามสกุลไฟล์เพื่อทำตามเอกสารนี้ได้ ดังนั้นโปรด **เปิดการแสดงนามสกุลไฟล์** ก่อนเริ่ม

บน Windows ทำได้โดยเปิดโฟลเดอร์ใดก็ได้ แล้วคลิกลูกศรที่มุมขวาบนเพื่อขยายเมนูด้านล่าง

จากนั้นไปที่แท็บ **View** และเปิดใช้งาน **File Name Extensions**

### การเตรียมไฟล์

มาเริ่มจากการสร้างโฟลเดอร์ใหม่สำหรับเนื้อหาของไฟล์ FMA กันก่อน
ในตัวอย่างนี้ เราจะตั้งชื่อโฟลเดอร์ว่า `fancymenu_animation`

ภายในโฟลเดอร์นี้ ให้สร้างโฟลเดอร์เพิ่มอีกสองโฟลเดอร์ โฟลเดอร์แรก **ต้อง** ชื่อ `frames` และโฟลเดอร์ที่สอง **ต้อง** ชื่อ `intro_frames`

จากนั้นในโฟลเดอร์เดียวกัน ให้สร้างไฟล์ TXT ใหม่ แล้วเปลี่ยนชื่อเป็น `metadata.json`
โปรดตรวจสอบให้แน่ใจว่าไฟล์นั้นไม่ใช่ไฟล์ TXT อยู่ โปรด **เปลี่ยนนามสกุลไฟล์** เป็น `json` ด้วย

ตอนนี้คุณควรมีโฟลเดอร์ชื่อ `fancymenu_animation` และภายในโฟลเดอร์นี้มีโฟลเดอร์ชื่อ `frames` โฟลเดอร์ชื่อ `intro_frames` และไฟล์ JSON ชื่อ `metadata.json`

### ไฟล์ JSON เมทาดาทา

นี่คือไฟล์ที่บอก FancyMenu ว่าควรจัดการเท็กซ์เจอร์ FMA ของคุณอย่างไร
มันมีข้อมูล เช่น เวลาแต่ละเฟรม (แต่ละเฟรมแสดงนานแค่ไหน) และจำนวนรอบการวนลูป

โปรดเปิดไฟล์ `metadata.json` ด้วยโปรแกรมแก้ไขข้อความ

คัดลอกข้อความนี้ไปไว้ในไฟล์:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
  },
  "custom_frame_times_intro": {
  }
}
```

นี่คือเทมเพลตพื้นฐานว่าควรให้ไฟล์หน้าตาเป็นอย่างไร
จากนั้นคุณสามารถปรับแต่งได้ตามต้องการ

#### `loop_count`

ใช้ควบคุมว่าเท็กซ์เจอร์ควรวนซ้ำกี่ครั้ง (เริ่มแอนิเมชันใหม่)

ถ้าตั้งเป็น `0` หมายความว่าจะวนลูปไม่สิ้นสุด มันจะ *ไม่มีวันหยุด*

ค่าที่มากกว่า `0` หมายถึงจำนวนครั้งที่เท็กซ์เจอร์จะเล่น เช่น ถ้าตั้งค่าเป็น `1` เท็กซ์เจอร์จะเล่นเพียงครั้งเดียว แล้วหยุดที่เฟรมสุดท้าย, `2` หมายถึงจะเล่นสองครั้ง แล้วหยุดที่เฟรมสุดท้าย *และต่อไปเรื่อยๆ*

#### `frame_time`

นี่คือเวลาเฟรมแบบสากลในหน่วย **มิลลิวินาที** สำหรับเฟรมของเท็กซ์เจอร์เคลื่อนไหว
เวลาเฟรมหมายถึงระยะเวลาที่เฟรมนั้นแสดงอยู่ก่อนที่แอนิเมชันจะไปเฟรมถัดไป

#### `frame_time_intro`

โดยพื้นฐานแล้วเหมือนกับ `frame_time` แต่ใช้กับเฟรม **intro** ของเท็กซ์เจอร์เคลื่อนไหว
เฟรม intro เป็น **ตัวเลือกเสริม** และคุณจะได้เรียนรู้เพิ่มเติมเกี่ยวกับมันในภายหลัง

#### `custom_frame_times`

ส่วนนี้เป็น **ตัวเลือกเสริม** และใช้สำหรับกำหนดเวลาเฟรมเฉพาะสำหรับเฟรมบางเฟรม (ที่ไม่ใช่ intro)
ตัวอย่างเช่น คุณต้องการให้ทุกเฟรมแสดงเป็นเวลา `41` มิลลิวินาที ดังนั้นคุณตั้ง `frame_time` เป็น `41` แต่ต้องการให้เฟรมแรกและเฟรมที่สองแสดงนาน `5000` มิลลิวินาที

ในกรณีนั้น ให้ทำแบบนี้:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
    0: 5000,
    1: 5000
  },
  "custom_frame_times_intro": {
  }
}
```

เฟรมเริ่มนับจากศูนย์ ซึ่งหมายความว่าเฟรมแรกของแอนิเมชันคือ `0`, เฟรมที่สองคือ `1` และต่อไปเรื่อยๆ

ต้องมี **เครื่องหมายจุลภาค** ต่อท้ายทุกรายการของ custom frame time ยกเว้นรายการสุดท้าย!

#### `custom_frame_times_intro`

นี่เหมือนกับ `custom_frame_times` ทุกอย่าง แต่ในกรณีนี้ใช้กับเฟรม **intro** เฟรม intro เป็น **ตัวเลือกเสริม** และคุณจะได้เรียนรู้เพิ่มเติมเกี่ยวกับมันในภายหลัง

เท่านี้สำหรับไฟล์ `metadata.json` บันทึกไฟล์แล้วปิดโปรแกรมแก้ไขข้อความได้เลย

### เฟรม

> แนะนำให้ใช้ **สูงสุด 200 เฟรม** ที่ความละเอียด **สูงสุด 1080p** ต่อแอนิเมชัน เพราะแอนิเมชันใช้หน่วยความจำเยอะ และมันไม่ใช่วิดีโอ พวกมันถูกออกแบบมาเพื่อใช้เป็นลูปแอนิเมชันสั้นๆ ไม่ใช่สำหรับเล่นวิดีโอเต็มรูปแบบที่ 24 FPS
{.is-danger}

เฟรมของเท็กซ์เจอร์เคลื่อนไหวของคุณจะอยู่ในโฟลเดอร์ `frames`

เฟรมต้องเป็น **ไฟล์ PNG** เท่านั้น! **ไม่รองรับ JPEG และฟอร์แมตอื่นๆ**!

เฟรมแต่ละอัน **ต้อง** ตั้งชื่อเป็นเพียงหมายเลขของเฟรมและนามสกุลไฟล์
เฟรมแรกควรชื่อ `0.png`, เฟรมที่สอง `1.png`, เฟรมที่สาม `2.png` และต่อไปเรื่อยๆ
เท็กซ์เจอร์จะ **ไม่ทำงาน** หากเฟรมมีชื่อไฟล์ไม่ถูกต้อง!

### อินโทร

ฟีเจอร์นี้เป็น **ตัวเลือกเสริม**

ฟีเจอร์ **intro** ของไฟล์ FMA เป็นวิธีพิเศษในการเล่นเฟรมบางส่วน **ก่อน** ที่เฟรมจริงในโฟลเดอร์ `frames` จะเริ่มเล่น

intro จะ **ไม่วนลูป** และจะเล่นเฉพาะครั้งแรกที่แอนิเมชันเล่นเท่านั้น ซึ่งช่วยให้คุณเล่นอะไรบางอย่าง เช่น แอนิเมชันเฟดอิน ก่อนที่แอนิเมชันหลักจะเริ่มวนลูป

### การแพ็กไฟล์ FMA

ตอนนี้ข้อมูลสำคัญทั้งหมดอยู่ในโฟลเดอร์ `fancymenu_animation` แล้ว คุณก็สามารถแพ็กไฟล์ FMA ได้เลย!

การแพ็กไฟล์ FMA ก็คือการแพ็กเนื้อหาโฟลเดอร์ให้เป็นไฟล์ ZIP นั่นเอง
เนื้อหาต้องอยู่ที่ **รากของ ZIP** ดังนั้นจึงไม่สามารถอยู่ในโฟลเดอร์ย่อยอีกชั้นภายใน ZIP ได้

บน Windows วิธีที่ง่ายที่สุดในการแพ็กเนื้อหา FMA เป็นไฟล์ ZIP คือเลือกทุกอย่างในโฟลเดอร์ `fancymenu_animation` จากนั้น **คลิกขวา** ที่ไฟล์ `metadata.json` ในเมนูที่ปรากฏขึ้น ให้คลิก **Send To -> Compressed ZIP Folder**

# การใช้งานไฟล์ AFMA และ FMA ใน FancyMenu

> [!IMPORTANT]
> ไฟล์ AFMA/FMA ถูกมองว่าเป็น **เท็กซ์เจอร์เคลื่อนไหว** ดังนั้นให้เพิ่มผ่านอินพุตประเภท **Image** แทบทุกอย่างที่รับภาพได้ (PNG, JPEG, GIF ฯลฯ) จะรองรับไฟล์ FMA และ AFMA ด้วย

คุณสามารถใช้ไฟล์ AFMA/FMA ได้เหมือนกับรูปแบบเท็กซ์เจอร์/ภาพเคลื่อนไหวอื่นๆ FancyMenu มองมันเป็นรูปภาพปกติ ดังนั้นคุณจึงใช้ได้ทุกที่ที่สามารถกำหนดเท็กซ์เจอร์ได้ เช่น **Image elements หรือ Image menu backgrounds**

ตรวจสอบให้แน่ใจว่าไฟล์ AFMA/FMA อยู่ในโฟลเดอร์ `/config/fancymenu/assets/` เพราะ FancyMenu จะเลือกใช้ได้เฉพาะเท็กซ์เจอร์และทรัพยากรอื่นๆ จากโฟลเดอร์ `assets` เท่านั้น
