# แอนิเมชัน

FancyMenu เล่นภาพเคลื่อนไหวได้แทบทุกที่ที่คุณใช้รูปภาพได้ เช่น ใน[องค์ประกอบรูปภาพ](/elements#image), [พื้นหลังเมนูแบบรูปภาพ](/menu-backgrounds#image), พื้นผิวของปุ่มและแถบเลื่อน, [อินโทรเกม](/game-intro) และอื่น ๆ

ใช้ไฟล์ **APNG** หรือ **GIF** สำหรับแอนิเมชันของคุณ:

- **APNG** (PNG แบบเคลื่อนไหว) ให้คุณภาพดีกว่า โดยมีสีครบทุกสีเหมือน PNG ทั่วไป และรองรับความโปร่งใสอย่างเหมาะสมพร้อมขอบที่นุ่มนวล เหมาะที่สุดสำหรับโลโก้ พื้นหลัง และทุกอย่างที่ต้องการความโปร่งใส
- **GIF** เป็นรูปแบบที่ใช้กันแพร่หลายกว่า จึงมีเครื่องมือสำหรับสร้างและแก้ไข GIF ให้เลือกมากกว่า แต่ GIF มีสีได้เพียง 256 สีต่อเฟรม และแต่ละพิกเซลจะโปร่งใสทั้งหมดหรือไม่โปร่งใสเลย

> [!NOTE]
> รูปแบบแอนิเมชันเฉพาะของ FancyMenu อย่าง FMA และ AFMA เลิกใช้งานแล้ว ไฟล์เดิมของคุณยังใช้ได้ แต่ควรใช้ APNG หรือ GIF สำหรับแอนิเมชันใหม่ ดูที่ [FMA และ AFMA](#fma-and-afma)

# การใช้แอนิเมชัน

1. วางไฟล์ไว้ใน `<game-directory>/config/fancymenu/assets/` เพื่อให้ไฟล์ปรากฏในหน้าต่างเลือกไฟล์ของ FancyMenu นอกจากนี้ยังใช้ URL บนเว็บและไฟล์จากรีซอร์สแพ็กได้ด้วย ดูที่ [รีซอร์ส](/resources)
2. เลือกไฟล์เหมือนกับรูปภาพทั่วไป เช่น เลือกจาก **Image Source** ขององค์ประกอบรูปภาพ

> [!WARNING]
> ไฟล์ APNG ต้องลงท้ายด้วย `.apng` เครื่องมือหลายตัวบันทึก APNG เป็น `.png` ดังนั้นให้เปลี่ยนชื่อไฟล์ มิฉะนั้น FancyMenu จะแสดงเป็นภาพนิ่ง URL บนเว็บก็เช่นกัน โดยต้องลงท้ายด้วย `.apng`

## การเล่นแอนิเมชัน

- แอนิเมชันจะเล่นตามจำนวนรอบที่ระบุไว้ในไฟล์ จากนั้นจะค้างอยู่ที่เฟรมสุดท้าย คุณกำหนดจำนวนรอบที่ต้องการให้เล่นซ้ำได้ตอนสร้างไฟล์
- แอนิเมชันจะเล่นเฉพาะขณะที่แสดงอยู่บนหน้าจอ เมื่อกลับมาแสดงอีกครั้ง จะเล่นต่อจากจุดที่หยุดไว้
- **Restart Animated Textures When Opening Screen** ทำให้องค์ประกอบรูปภาพและพื้นหลังเมนูแบบรูปภาพเริ่มเล่นแอนิเมชันใหม่ทุกครั้งที่เปิดหน้าจอ
- **Restart Animated Textures On Hover** ทำให้พื้นผิวของปุ่มและแถบเลื่อนเริ่มเล่นใหม่ทุกครั้งที่เลื่อนเมาส์ไปวางบนปุ่มหรือแถบเลื่อนเหล่านั้น
- ตัวรับฟังเหตุการณ์ [**Animated Texture Started Playing**](/listeners#animated-texture-started-playing) และ [**Animated Texture Finished Playing**](/listeners#animated-texture-finished-playing) จะเรียกใช้การทำงานเมื่อแอนิเมชันเริ่มหรือจบ

## ประสิทธิภาพ

FancyMenu ถอดรหัส APNG และ GIF ระหว่างที่เล่น โดยเตรียมไว้ล่วงหน้าเพียงไม่กี่เฟรม ดังนั้นแม้แอนิเมชันยาว ๆ ก็ใช้หน่วยความจำน้อย

อย่างไรก็ตาม เฟรมขนาดใหญ่และอัตราเฟรมสูงยังคงส่งผลต่อประสิทธิภาพ ควรสร้างเฟรมให้มีขนาดใกล้เคียงกับขนาดที่แสดงบนหน้าจอ ดูที่[การปรับแต่งพื้นผิว](/optimizing-textures) สำหรับคลิปยาวที่มีเสียง ให้ใช้[วิดีโอ](/video) แทน

# การสร้างแอนิเมชัน

เครื่องมือฟรีเหล่านี้ใช้สร้าง APNG และ GIF จากเฟรมภาพนิ่งหรือวิดีโอได้:

- [ScreenToGif](https://www.screentogif.com/) (Windows): คลิก **Editor** แล้วลากเฟรม PNG ลงไป ตั้งค่าระยะเวลาแสดงแต่ละเฟรม แล้วบันทึกแอนิเมชันเป็น APNG หรือ GIF คุณกำหนดจำนวนรอบการเล่นซ้ำได้ในเมนูบันทึก
- [ezgif](https://ezgif.com/) (ออนไลน์ ไม่ต้องดาวน์โหลด): สร้าง [GIF](https://ezgif.com/maker) หรือ [APNG](https://ezgif.com/apng-maker) จากรูปภาพ แปลงวิดีโอเป็น [GIF](https://ezgif.com/video-to-gif) หรือ [APNG](https://ezgif.com/video-to-apng) หรือแปลง [GIF เป็น APNG](https://ezgif.com/gif-to-apng) และ [APNG เป็น GIF](https://ezgif.com/apng-to-gif)
- [FFmpeg](https://ffmpeg.org/download.html) (บรรทัดคำสั่ง): ดูด้านล่าง

## ใช้ FFmpeg

แปลงเฟรม PNG ที่มีหมายเลขกำกับ เช่น `frame_0001.png`, `frame_0002.png` และอื่น ๆ ให้เป็น APNG ที่เล่นวนตลอดไป `-framerate 20` จะเล่นที่ 20 เฟรมต่อวินาที:

```bash
ffmpeg -framerate 20 -i frame_%04d.png -plays 0 animation.apng
```

แปลงวิดีโอเป็น APNG `fps=20` จะคงอัตราไว้ที่ 20 เฟรมต่อวินาที และ `scale=960:-1` จะกำหนดความกว้างเป็น 960 พิกเซล:

```bash
ffmpeg -i trailer.mp4 -vf "fps=20,scale=960:-1" -plays 0 trailer.apng
```

แปลงวิดีโอเป็น GIF ที่เล่นวนตลอดไป ส่วน `palettegen` จะเลือกสีที่เหมาะสมที่สุด 256 สี:

```bash
ffmpeg -i trailer.mp4 -vf "fps=15,scale=640:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" -loop 0 trailer.gif
```

แปลง GIF เป็น APNG:

```bash
ffmpeg -i logo.gif -plays 0 logo.apng
```

# FMA และ AFMA

FMA และ AFMA เป็นรูปแบบแอนิเมชันเฉพาะของ FancyMenu ทั้งสองรูปแบบเลิกใช้งานแล้ว แต่ยังเล่นได้ อย่างไรก็ตาม APNG และ GIF เป็นตัวเลือกที่ดีกว่าสำหรับแอนิเมชันใหม่

หากต้องการสร้าง AFMA:

1. วางเฟรมของคุณเป็นไฟล์ PNG ไว้ในโฟลเดอร์เดียวกัน เฟรมจะเล่นตามลำดับชื่อไฟล์ เช่น `frame_1.png`, `frame_2.png`, ..., `frame_10.png`
2. เปิด **menu bar -> Tools -> AFMA Creator**
3. กำหนด **Main Frames Directory** ให้ชี้ไปยังโฟลเดอร์นั้น เฟรมใน **Intro Frames Directory** จะเล่นหนึ่งครั้งก่อนเฟรมหลัก
4. กำหนด **Main Frame Time (ms)** และ **Loop Count** จำนวนรอบเป็น `0` หมายถึงเล่นวนตลอดไป
5. กำหนด **Output AFMA File** แล้วคลิก **Export**
