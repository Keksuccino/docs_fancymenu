# พบ FancyMenu JAR ที่ถูกแก้ไข

หากคุณได้รับข้อผิดพลาดนี้ สาเหตุอาจมาจากอินสแตนซ์ Minecraft ที่เสีย, ตัวโหลดม็อดที่เสีย หรือโปรแกรมเปิดเกมม็อดที่ไม่ดี

โดยปกติแล้วข้อความนี้จะปรากฏเมื่อ FancyMenu ถูกแก้ไข แต่ก็อาจปรากฏได้เช่นกันหากเกมของคุณไม่สามารถโหลดม็อดได้อย่างถูกต้องตามที่ควรจะเป็น

สาเหตุนี้อาจเกิดจาก **อินสแตนซ์ Minecraft ของคุณเสียหาย** ในบางรูปแบบ ซึ่งควรทำให้คุณ **ติดตั้งเกมใหม่**

อีกสาเหตุที่เป็นไปได้ของข้อผิดพลาดนี้คือเมื่อ **เกมเกิดอาการค้าง/แครชบางส่วน** ตอนเปิดเกม เพราะม็อดบางตัว (รวมถึง FancyMenu) **โหลดไม่สำเร็จอย่างถูกต้อง** ในกรณีนั้น โปรดส่งไฟล์ `/logs/latest.log` ของคุณในเซิร์ฟเวอร์ Discord หรือเปิด issue บน GitHub

ข้อผิดพลาดนี้อาจถูกกระตุ้นได้จากการ **ใช้โปรแกรมเปิดม็อดที่ไม่ดี** (ตัวเปิดแบบเถื่อน/แคร็กส่วนใหญ่จะทำให้เกิดบั๊กนี้ ดังนั้นโปรดซื้อเกม) โปรแกรมเปิดที่แนะนำ ซึ่งเสถียรและใช้งานได้ดีกับ FancyMenu คือ **CurseForge launcher อย่างเป็นทางการ และ Modrinth launcher อย่างเป็นทางการ**
