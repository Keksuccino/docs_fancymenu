# GUI แบบกำหนดเอง

GUI แบบกำหนดเองคือหน้าจอใหม่ที่คุณสามารถใส่ [elements](./elements) ของ FancyMenu ลงไปได้

> [!CAUTION]
> GUI แบบกำหนดเองสามารถรันการกระทำได้ ให้นำเข้าเฉพาะจากแหล่งที่คุณเชื่อถือเท่านั้น

# การสร้าง GUI แบบกำหนดเอง

1. เปิด **Customization -> Custom GUIs -> Manage Custom GUIs**
2. เลือก **New GUI**
3. กรอกตัวระบุและกำหนดค่าการตั้งค่าหน้าจอ
4. เลือก **Done** แล้วเปิด GUI ใหม่จากตัวจัดการ
5. สร้างและแก้ไขเลย์เอาต์เหมือนกับหน้าจออื่น ๆ

ตัวระบุสามารถใช้ตัวอักษรภาษาอังกฤษตัวพิมพ์เล็ก ตัวเลข `.`, `_` และ `-` ได้ ไม่สามารถมีช่องว่าง และต้องไม่ซ้ำกัน ตัวระบุที่ว่าง ไม่ถูกต้อง หรือซ้ำกันจะไม่สามารถบันทึกได้

GUI แบบกำหนดเองจะเปิดใช้งานการปรับแต่งหน้าจอเสมอ สวิตช์การปรับแต่งของมันไม่สามารถปิดได้

# การตั้งค่าหน้าจอ

| การตั้งค่า | พฤติกรรม |
|---|---|
| Allow ESC | ให้ปุ่ม Escape ปิด GUI และกลับไปยังหน้าจอแม่ |
| Pause Game/World | หยุดเกมในโหมดผู้เล่นเดี่ยวชั่วคราวเมื่อ GUI เปิดอยู่ |
| Render World Background | แสดงโลกที่โหลดอยู่ด้านหลัง GUI |
| World Background Overlay | เพิ่มเอฟเฟกต์เบลอ/มืดมาตรฐานทับบนโลก |
| Popup Mode | คงให้หน้าจอแม่มองเห็นได้อยู่ด้านหลัง Custom GUI |
| Popup Background Overlay | เพิ่มเบลอ/สีทับบนหน้าจอแม่ใน Popup Mode |

Popup Mode จะไม่รวมสองหน้าจอเข้าด้วยกัน Custom GUI ยังคงเป็นหน้าจอที่ใช้งานอยู่ ขณะที่หน้าจอแม่ถูกเรนเดอร์อยู่ด้านหลัง การปิด Custom GUI จะกลับไปยังหน้าจอแม่นั้นเมื่อมีอยู่

# การเปิด Custom GUI

ใช้ตัวระบุของ Custom GUI ให้ตรงเป๊ะกับอย่างใดอย่างหนึ่งต่อไปนี้:

- [**Open Screen or Custom GUI** action](./action-scripts#open-screen-or-custom-gui-opengui)
- [`/openguiscreen` command](./commands#openguiscreen)

# การแทนที่หน้าจอที่มีอยู่แล้ว

Custom GUI สามารถแทนที่หน้าจอ Vanilla หรือหน้าจอของม็อดได้ทุกครั้งที่หน้าจอนั้นเปิดขึ้น

1. สร้าง Custom GUI ที่ต้องการใช้แทน
2. เปิดหน้าจอที่คุณต้องการแทนที่
3. เปิดใช้งาน **Customization -> Settings -> Advanced Customization Mode**
4. เลือก **Customization -> Custom GUIs -> Override Current with Custom GUI**
5. เลือก Custom GUI ที่จะใช้แทน

จัดการการแทนที่ที่บันทึกไว้ผ่าน **Customization -> Custom GUIs -> Manage Overridden Screens**

การแทนที่จะข้ามหน้าจอต้นฉบับไปเลย ดังนั้นควรทดสอบการนำทางและฟีเจอร์ใด ๆ ที่ขึ้นอยู่กับพฤติกรรมของหน้าจอต้นฉบับด้วย
