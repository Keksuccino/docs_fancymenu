# GUI แบบกำหนดเอง

FancyMenu ช่วยให้คุณปรับแต่งหน้าจอ GUI ที่มีอยู่แล้วได้ แต่ยังช่วยให้คุณเพิ่มหน้าจอใหม่ทั้งหมดและใส่องค์ประกอบต่าง ๆ ลงไปได้ด้วย

# การเพิ่มหน้าจอใหม่

หากต้องการเพิ่มหน้าจอใหม่ ให้ไปที่ **Customization -> Custom GUIs -> Manage Custom GUIs**.

![custom_gui_1](https://github.com/Keksuccino/FancyMenu/assets/35544624/23e704ee-ccb5-434d-b75f-f4418399d9b7)

ในเมนูถัดไป ให้คลิก **New GUI**.

![custom_gui_2](https://github.com/Keksuccino/FancyMenu/assets/35544624/035454e8-b089-4b9a-9092-89a193c0eacd)

ที่นี่คุณต้องตั้งตัวระบุเฉพาะสำหรับ GUI ใหม่ของคุณ และสามารถปรับแต่งส่วนอื่น ๆ ของพฤติกรรมพื้นฐานของหน้าจอได้
เมื่อเสร็จแล้ว ให้กด **Done**.

![custom_gui_3](https://github.com/Keksuccino/FancyMenu/assets/35544624/1fbed3f9-9c81-4c73-85c7-d152146c55d8)

ตอนนี้คุณจะมี GUI ว่าง ๆ ใหม่หนึ่งหน้าแล้ว หากต้องการเปิด ให้เลือก GUI นั้นในเมนู **Manage Custom GUIs** แล้วคลิก **Open GUI**.

![custom_gui_4](https://github.com/Keksuccino/FancyMenu/assets/35544624/b2e6a4b7-540d-4bf2-9dce-09bfff11ae7e)

จะเปิดหน้าจอ GUI ที่ยังค่อนข้างว่างอยู่ขึ้นมา หากต้องการให้ไม่ว่างเปล่าเกินไป ก็เพียงสร้างเลย์เอาต์ใหม่ให้เหมือนกับที่คุณทำกับหน้าจออื่น ๆ ได้เลย

![custom_gui_5](https://github.com/Keksuccino/FancyMenu/assets/35544624/e7e06a5f-46b3-48f1-9ad9-96a7565c97a9)

# การเปิด GUI ผ่านแอ็กชัน

ขั้นตอนสุดท้ายคือการเปิดให้ผู้ใช้ทั่วไปเข้าถึง GUI ของคุณได้ วิธีที่ง่ายที่สุดคือใช้แอ็กชัน **Open Screen or Custom GUI** ร่วมกับปุ่ม สไลเดอร์ หรือทิกเกอร์

![custom_gui_6](https://github.com/Keksuccino/FancyMenu/assets/35544624/b5cc6518-3fc4-4715-96d4-44b65ab7831d)

# การเปิด GUI ผ่านคำสั่ง

คุณยังสามารถเปิด GUI แบบกำหนดเองของคุณผ่าน [คำสั่งในเกม](./commands#openguiscreen) ได้ด้วย
วิธีนี้ยังช่วยให้คุณเปิด GUI จากระยะไกลให้ผู้ใช้อื่นได้อีกด้วย!

# โหมดป๊อปอัป

ตั้งแต่ FancyMenu v3.8.0 เป็นต้นไป Custom GUIs รองรับ "Popup Mode" ซึ่งจะทำให้หน้าตาของมันเหมือนป๊อปอัปที่ถูกเปิดซ้อนอยู่เหนือหน้าจออื่น (หน้าจอก่อนหน้าที่ Custom GUI ถูกเปิดมาจาก) การตั้งค่านี้สามารถเปิดหรือปิดแยกกันได้สำหรับ Custom GUI แต่ละตัวในหน้าการตั้งค่าของมัน

FancyMenu 3.9.0 ยังเพิ่มตัวเลือกให้สลับการซ้อนพื้นหลังของหน้าจอสำหรับ Custom GUIs ขณะอยู่ในโลกเกมด้วย ใช้ตัวเลือกนี้เมื่อคุณต้องการปิดหรือคงเอฟเฟกต์เบลอ/สีทึบมืดที่อยู่ด้านหลัง Custom GUI ที่เปิดทับการเล่นเกม
