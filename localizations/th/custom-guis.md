# GUI แบบกำหนดเอง

GUI แบบกำหนดเองคือเมนูที่คุณสร้างขึ้นเอง เช่น หน้าข้อมูลม็อดแพ็ก ฮับเซิร์ฟเวอร์ หรือหน้ากฎต่าง ๆ โดยจะเริ่มต้นเป็นเมนูว่าง แล้วคุณสามารถเพิ่ม [เลย์เอาต์](/layout-editor) ได้เหมือนกับเมนูอื่น ๆ จากนั้นจึงเปิดเมนูเหล่านี้ด้วยปุ่ม คีย์ และคำสั่ง

# สร้าง GUI แบบกำหนดเอง

<img width="800" alt="เปิดจัดการ GUI แบบกำหนดเอง คลิก GUI ใหม่ พิมพ์ตัวระบุ modpack_info เปิดโหมดป๊อปอัป แล้วเปิด GUI แบบกำหนดเองรายการใหม่" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/custom_guis_new.gif?raw=true">

1. เปิด **แถบเมนู -> การปรับแต่ง -> GUI แบบกำหนดเอง -> จัดการ GUI แบบกำหนดเอง**
2. คลิก **GUI ใหม่**
3. พิมพ์ **ตัวระบุ GUI แบบกำหนดเอง** เช่น `modpack_info` ตั้งค่า [การตั้งค่า](#settings) แล้วคลิก **เสร็จสิ้น**
4. คลิก GUI แบบกำหนดเองรายการใหม่ในรายการ แล้วคลิก **เปิด GUI**
5. คลิก **เสร็จสิ้น** เพื่อปิด **จัดการ GUI แบบกำหนดเอง**

**จัดการ GUI แบบกำหนดเอง** จะบันทึกการเปลี่ยนแปลงเมื่อคุณคลิก **เสร็จสิ้น** หรือ **เปิด GUI** เท่านั้น หากคลิก **ยกเลิก** การเปลี่ยนแปลงจะถูกละทิ้ง

## ตัวระบุ

ปุ่ม คำสั่ง และเลย์เอาต์จะค้นหา GUI แบบกำหนดเองด้วยตัวระบุของ GUI นั้น

- ใช้ได้เฉพาะตัวอักษรภาษาอังกฤษตัวพิมพ์เล็ก ตัวเลข `.`, `_` และ `-` GUI แบบกำหนดเองแต่ละรายการต้องมีตัวระบุไม่ซ้ำกัน
- อย่าใช้[ตัวระบุของหน้าจออื่น](/screen-identifiers) เช่น `title_screen` เพราะ GUI แบบกำหนดเองจะแชร์เลย์เอาต์กับหน้าจอนั้น
- หากเปลี่ยนตัวระบุในภายหลัง เลย์เอาต์ ปุ่ม และคำสั่งที่ใช้ตัวระบุเดิมจะค้นหา GUI นี้ไม่พบอีกต่อไป แต่ถ้าเปลี่ยนกลับมา รายการเหล่านั้นก็จะกลับมาใช้งานได้

## สร้างเลย์เอาต์

1. เปิด GUI แบบกำหนดเอง
2. คลิก **แถบเมนู -> การปรับแต่ง -> เลย์เอาต์ -> ใหม่ -> สำหรับหน้าจอปัจจุบัน** การปรับแต่งจะเปิดใช้งานอยู่เสมอสำหรับ GUI แบบกำหนดเอง
3. เพิ่มองค์ประกอบและบันทึกเลย์เอาต์ ดูที่ [ตัวแก้ไขเลย์เอาต์](/layout-editor)

GUI แบบกำหนดเองจะไม่มีอะไรอยู่ในนั้นเลย แม้แต่ปุ่มย้อนกลับ คุณสามารถเพิ่ม [ปุ่ม](/elements#button) ที่ใช้การทำงาน [**กลับไปยังหน้าจอก่อนหน้า**](/action-scripts#back-to-last-screen) หรือเปิด **อนุญาตให้กด ESC เพื่อปิด GUI** ไว้ เพื่อให้ผู้เล่นออกจาก GUI ได้

# การตั้งค่า

**แก้ไข GUI** ใน **จัดการ GUI แบบกำหนดเอง** ใช้เปลี่ยนการตั้งค่าของ GUI แบบกำหนดเองที่เลือกไว้

| การตั้งค่า | ทำอะไรได้บ้าง |
|---|---|
| **ตัวระบุ GUI แบบกำหนดเอง** | ชื่อของ GUI แบบกำหนดเอง ดูที่[ตัวระบุ](#the-identifier) |
| **ชื่อหน้าจอ (ไม่บังคับ)** | ชื่อสีขาวที่ด้านบนของ GUI เว้นว่างไว้หากไม่ต้องการใช้ [ตัวแทนค่า](/placeholders) ใช้งานได้ และคีย์การแปลภาษาของเกม ม็อด และแพ็กทรัพยากรจะแสดงเป็นภาษาของผู้เล่น |
| **อนุญาตให้กด ESC เพื่อปิด GUI** | กด `Esc` เพื่อปิด GUI เปิดใช้งานไว้เป็นค่าเริ่มต้น |
| **หยุดเกม/โลกชั่วคราว** | หยุดโลกเล่นคนเดียวชั่วคราวขณะที่ GUI เปิดอยู่ เปิดใช้งานไว้เป็นค่าเริ่มต้น |
| **แสดงพื้นหลังโลก** | แสดงโลกที่อยู่ด้านหลัง GUI ขณะเล่น หากอยู่นอกโลกหรือปิดตัวเลือกนี้ จะแสดงภาพพาโนรามาของ Minecraft เปิดใช้งานไว้เป็นค่าเริ่มต้น |
| **แสดงโอเวอร์เลย์พื้นหลังโลก** | เบลอและทำให้โลกหรือภาพพาโนรามาที่อยู่ด้านหลัง GUI มืดลง เช่นเดียวกับเมนูหยุดเกมชั่วคราว ใช้งานได้เฉพาะเมื่อเปิด **แสดงพื้นหลังโลก** เท่านั้น หากปิดตัวเลือกนี้ ภาพพาโนรามาจะเบลอและมืดลงเสมอ เปิดใช้งานไว้เป็นค่าเริ่มต้น |
| **โหมดป๊อปอัป** | แสดง GUI ซ้อนบนเมนูที่ใช้เปิด ดูที่[โหมดป๊อปอัป](#popup-mode) |
| **โอเวอร์เลย์พื้นหลังโหมดป๊อปอัป** | เบลอเมนูที่อยู่ด้านหลังป๊อปอัป ใช้งานได้เฉพาะเมื่อเปิด **โหมดป๊อปอัป** เปิดใช้งานไว้เป็นค่าเริ่มต้น |

- ระดับการเบลอจะเท่ากับตัวเลือก **การเบลอพื้นหลังเมนู** ของ Minecraft
- [พื้นหลังเมนู](/menu-backgrounds) ในเลย์เอาต์จะทับสิ่งเหล่านี้ทั้งหมด ทั้งโลก ภาพพาโนรามา และเมนูที่อยู่ด้านหลังป๊อปอัป
- ตัวแก้ไขเลย์เอาต์ไม่สามารถเปลี่ยนชื่อเรื่อง (**ชื่อหน้าจอแบบกำหนดเอง**) ของ GUI แบบกำหนดเองได้ ให้เปลี่ยน **ชื่อหน้าจอ (ไม่บังคับ)** แทน หากต้องการชื่อเรื่องที่กำหนดแบบอักษร สี หรือตำแหน่งได้เอง ให้เว้นช่องนี้ว่างไว้แล้วเพิ่ม[องค์ประกอบข้อความ](/elements#text)

## โหมดป๊อปอัป

เมื่อเปิด **โหมดป๊อปอัป** เมนูที่ใช้เปิด GUI แบบกำหนดเองจะยังคงปรากฏอยู่ด้านหลัง พร้อมเลย์เอาต์ของเมนูนั้น แต่จะคลิกเมนูด้านหลังไม่ได้ขณะที่ป๊อปอัปเปิดอยู่

- ป๊อปอัปเหมาะกับสิ่งเล็ก ๆ เช่น กล่องข้อมูล การยืนยัน หรือแผงการตั้งค่า เว้นพื้นที่บางส่วนไว้เพื่อให้เห็นเมนูด้านหลัง
- อย่าใส่พื้นหลังเมนูในเลย์เอาต์ของป๊อปอัป เพราะจะทำให้เมนูด้านหลังหายไป
- หากเปิด GUI แบบกำหนดเองขณะที่ไม่มีเมนูเปิดอยู่ เช่น กดคีย์ระหว่างเล่น ก็จะไม่มีเมนูให้แสดงอยู่ด้านหลัง ในกรณีนี้ GUI จะแสดงพื้นหลังตามปกติ

# เปิด GUI แบบกำหนดเอง

สิ่งใดก็ตามที่ใช้เปิดหน้าจอได้ ก็สามารถเปิด GUI แบบกำหนดเองได้ด้วยตัวระบุของ GUI นั้น

- **ปุ่ม:** ใช้การทำงาน [**เปิดหน้าจอหรือ GUI แบบกำหนดเอง**](/action-scripts#open-screen-or-custom-gui) โดยระบุค่า `modpack_info`
- **คีย์:** ใช้ตัวรับฟังเหตุการณ์ [**เมื่อกดคีย์บนแป้นพิมพ์**](/listeners#listener-variables) ร่วมกับการทำงานเดียวกัน โดยจะเปิด GUI แบบกำหนดเองได้ทั้งในเมนูและขณะเล่น
- **คำสั่ง:** ใช้ `/openguiscreen modpack_info` ได้จากเซิร์ฟเวอร์ บล็อกคำสั่ง และรางวัลเควสต์ด้วย ดูที่[คำสั่ง](/commands#openguiscreen)
- **ออกจากโลก:** ใช้การทำงาน [**ออกจากโลกหรือเซิร์ฟเวอร์**](/action-scripts#leave-world-or-server) พร้อมตัวระบุ เพื่อเปิด GUI แบบกำหนดเองหลังออกจากโลก

GUI แบบกำหนดเองเป็นส่วนหนึ่งของการตั้งค่า FancyMenu ของผู้เล่นแต่ละคน เซิร์ฟเวอร์เปิดได้เฉพาะ GUI แบบกำหนดเองที่ผู้เล่นมีอยู่แล้ว เช่น GUI ของม็อดแพ็ก

วิธีออกจาก GUI แบบกำหนดเอง:

- กด `Esc` (เมื่อเปิด **อนุญาตให้กด ESC เพื่อปิด GUI**) หรือใช้การทำงาน **กลับไปยังหน้าจอก่อนหน้า** เพื่อกลับไปยังเมนูที่ใช้เปิด GUI หากไม่มีเมนูเปิดอยู่ `Esc` จะพากลับไปที่เกม
- การทำงาน [**ปิดหน้าจอ**](/action-scripts#close-screen) จะปิด GUI หากอยู่นอกโลก หน้าจอชื่อเรื่องจะเปิดขึ้น

# ใช้แทนหน้าจอที่มีอยู่

GUI แบบกำหนดเองสามารถใช้แทนเมนูของเกมหรือม็อดได้ ทุกครั้งที่เมนูนั้นควรจะเปิด GUI แบบกำหนดเองจะเปิดขึ้นแทน

> [!WARNING]
> เมนูที่ถูกแทนที่จะไม่เปิดขึ้นเลย ดังนั้นสิ่งที่เมนูนั้นทำจะไม่เกิดขึ้น และม็อดอื่นที่ต้องใช้เมนูนั้นอาจทำงานผิดพลาดได้ หากทำได้ ให้เปลี่ยนเมนูด้วยเลย์เอาต์ปกติ และใช้การแทนที่เมนูเฉพาะเมื่อเลย์เอาต์ไม่สามารถทำสิ่งที่ต้องการได้เท่านั้น

1. เปิด **แถบเมนู -> การปรับแต่ง -> การตั้งค่า -> โหมดปรับแต่งขั้นสูง**
2. เปิดเมนูที่ต้องการแทนที่
3. คลิก **แถบเมนู -> การปรับแต่ง -> GUI แบบกำหนดเอง -> ใช้ GUI แบบกำหนดเองแทนหน้าจอปัจจุบัน**
4. ยืนยันคำเตือน แล้วเลือก GUI แบบกำหนดเองใน **เลือก GUI แบบกำหนดเอง**

GUI แบบกำหนดเองจะเปิดขึ้นทันที เมื่ออยู่ใน GUI นี้ การกด `Esc` หรือใช้ **กลับไปยังหน้าจอก่อนหน้า** จะพากลับไปยังเมนูที่เปิดอยู่ก่อนเมนูที่ถูกแทนที่

หากต้องการยกเลิก ให้เปิด **แถบเมนู -> การปรับแต่ง -> GUI แบบกำหนดเอง -> จัดการหน้าจอที่ถูกแทนที่** คลิก **ลบกฎการแทนที่** ใต้หน้าจอ แล้วคลิก **เสร็จสิ้น**

> [!TIP]
> หากต้องการแทนที่เมนูเฉพาะบางกรณี เช่น เฉพาะตอนที่ตั้งค่า[ตัวแปร](/variables)ไว้ ให้ใช้ตัวรับฟังเหตุการณ์ [**เมื่อเปิดหน้าจอ**](/listeners#on-screen-opened) พร้อมคำสั่ง IF แทน

# จัดการ GUI แบบกำหนดเอง

- **GUI ใหม่**, **แก้ไข GUI** และ **เปิด GUI** ใน **จัดการ GUI แบบกำหนดเอง** ใช้เพิ่ม เปลี่ยนแปลง และเปิด GUI แบบกำหนดเอง
- **ลบ GUI** จะลบ GUI แบบกำหนดเองที่เลือกหลังจากขอให้ยืนยัน เลย์เอาต์ของ GUI จะยังคงอยู่ และจะแสดงอีกครั้งเมื่อสร้าง GUI แบบกำหนดเองรายการใหม่โดยใช้ตัวระบุเดิม
- แถบค้นหาใช้ค้นหา GUI แบบกำหนดเองด้วยตัวระบุ
- **แถบเมนู -> วิธีใช้ -> ส่งออกสำหรับ AI -> GUI แบบกำหนดเอง** จะส่งออก GUI แบบกำหนดเองทั้งหมดและกฎการแทนที่สำหรับ[แชต AI](/export-for-ai)

GUI แบบกำหนดเองและกฎการแทนที่จะบันทึกไว้ใน `config/fancymenu/custom_gui_screens.txt` ส่วนเลย์เอาต์จะบันทึกไว้ใน `config/fancymenu/customization/` เช่นเดียวกับรายการอื่น ๆ (ดูที่[ตำแหน่งจัดเก็บข้อมูล](/data-storage-locations)) แต่ละ[โปรไฟล์](/profiles) มี GUI แบบกำหนดเองของตัวเอง
