# ส่งออกสำหรับ AI

**ส่งออกสำหรับ AI** จะแปลงส่วนหนึ่งของการตั้งค่า FancyMenu ให้เป็นข้อความที่จัดทำขึ้นสำหรับผู้ช่วย AI อย่าง Alice บอตผู้ช่วยใน [FancyMenu Discord](https://discord.gg/rhayah27GC) เพียงวางข้อความนี้ลงในแชต AI ก็จะเห็นการตั้งค่าต่าง ๆ อย่างชัดเจน แทนที่จะต้องคาดเดา

# ทำไมจึงมีฟีเจอร์นี้

ภาพหน้าจอแสดงให้เห็นว่าสิ่งต่าง ๆ มีหน้าตาอย่างไร แต่ไม่ได้บอกว่าตั้งค่าไว้อย่างไร การพิมพ์สคริปต์การทำงานหรือข้อกำหนดด้วยตนเองใช้เวลานาน และรายละเอียดสำคัญก็มักตกหล่นไป

ไฟล์ส่งออกมีข้อมูลทั้งหมดที่ AI ต้องใช้:

- การตั้งค่า การทำงาน ข้อกำหนด และค่าทั้งหมดของสิ่งที่คุณส่งออก
- เวอร์ชันของ FancyMenu, Minecraft, ตัวโหลดม็อด, Java และระบบของคุณ
- คำอธิบายสั้น ๆ เกี่ยวกับวิธีทำงานของ FancyMenu เพื่อให้ AI ตีความได้ถูกต้อง

ไฟล์ส่งออกจะเป็นภาษาอังกฤษเสมอ ไม่ว่าคุณจะเล่นด้วยภาษาใดก็ตาม ชื่อบัญชีของคุณในเส้นทางไฟล์จะถูกแทนที่ด้วย `<user>` คุณจึงแชร์ไฟล์ส่งออกในแชตสาธารณะได้

# ควรใช้เมื่อใด

- มีบางอย่างทำงานไม่เป็นไปตามที่ควร เช่น ปุ่มที่กดแล้วไม่ทำงาน หรือองค์ประกอบที่ไม่แสดงขึ้นมาเลย
- FancyMenu แสดงข้อผิดพลาดหรือคำเตือน
- คุณต้องการความช่วยเหลือในการสร้างบางอย่าง เช่น สคริปต์การทำงาน ข้อกำหนด หรือเมนูทั้งชุด
- คุณต้องการรู้ว่าในเกมทำอะไรได้บ้าง **Everything FancyMenu Can Do** จะแสดงองค์ประกอบ พื้นหลัง การทำงาน ข้อกำหนด ตัวแทนข้อความ และตัวฟังเหตุการณ์ทั้งหมดที่คุณมี รวมถึงรายการจากส่วนเสริมด้วย

ส่งออกเฉพาะสิ่งที่เกี่ยวข้องกับคำถามของคุณ เช่น ปุ่มที่ใช้งานไม่ได้เพียงปุ่มเดียว ไฟล์ส่งออกขนาดเล็กจะช่วยให้ AI จดจ่อกับประเด็นได้ จากนั้นบอก AI ว่าคุณคาดหวังให้เกิดอะไรขึ้น และเกิดอะไรขึ้นจริง

# วิธีส่งออก

แต่ละตำแหน่งด้านล่างจะเปิดเมนูขนาดเล็ก:

- **Copy to Clipboard** จะคัดลอกไฟล์ส่งออกเพื่อให้คุณวางลงในแชตด้วย `Ctrl + V` (`Cmd + V` บน macOS)
- **Save as File** จะบันทึกเป็นไฟล์ Markdown ใน `<game-directory>/fancymenu_data/ai_exports/` แล้วเปิดโฟลเดอร์นั้นให้คุณ เพื่อให้ลากไฟล์ไปใส่ในแชตได้ ใช้ตัวเลือกนี้กับไฟล์ส่งออกขนาดใหญ่ที่ใส่ในข้อความแชตไม่ได้

ไฟล์ส่งออกจากตัวแก้ไขเลย์เอาต์ รวมถึงหน้าต่างตัวฟังเหตุการณ์และตัวจัดตารางเวลา จะรวมการเปลี่ยนแปลงที่คุณยังไม่ได้บันทึกด้วย

# ตำแหน่งที่ส่งออกได้

## แถบเมนู

| สิ่งที่ส่งออก | ตำแหน่งที่ค้นหาได้ |
|---|---|
| หน้าจอปัจจุบัน พร้อมวิดเจ็ตและสิ่งที่ FancyMenu ทำงานบนหน้าจอนั้น | **menu bar -> Customization -> Export Current Screen for AI** |
| เลย์เอาต์ | **menu bar -> Customization -> Layouts** เลือกเลย์เอาต์ แล้วเลือก **Export Layout for AI** |
| เกม ฮาร์ดแวร์ และม็อดของคุณ รวมถึงความสามารถที่ FancyMenu ใช้งานได้ เช่น การรองรับวิดีโอและเบราว์เซอร์ | **menu bar -> Help -> Export for AI -> System Info** |
| การตั้งค่าทั้งหมดของ FancyMenu รวมถึง [การปรับแต่งส่วนกลาง](/global-customizations) | **menu bar -> Help -> Export for AI -> FancyMenu Settings** |
| [ตัวแปร](/variables)ทั้งหมด | **menu bar -> Help -> Export for AI -> All Variables** |
| [ตัวฟังเหตุการณ์](/listeners)ทั้งหมด | **menu bar -> Help -> Export for AI -> All Listeners** |
| [ตัวจัดตารางเวลา](/schedulers)ทั้งหมด | **menu bar -> Help -> Export for AI -> All Schedulers** |
| [Custom GUI](/custom-guis)ทั้งหมด | **menu bar -> Help -> Export for AI -> Custom GUIs** |
| [โปรไฟล์](/profiles)ทั้งหมด | **menu bar -> Help -> Export for AI -> Profiles** |
| องค์ประกอบ พื้นหลัง การทำงาน ข้อกำหนด ตัวแทนข้อความ และตัวฟังเหตุการณ์ทั้งหมดที่มีในเกมของคุณ | **menu bar -> Help -> Export for AI -> Everything FancyMenu Can Do** |

## ตัวแก้ไขเลย์เอาต์

| สิ่งที่ส่งออก | ตำแหน่งที่ค้นหาได้ |
|---|---|
| เลย์เอาต์ที่คุณกำลังแก้ไข | **Layout -> Export Layout for AI** ในแถบเมนูของตัวแก้ไข |
| เลย์เอาต์อื่นของหน้าจอ | **Layout -> Open** ในแถบเมนูของตัวแก้ไข เลือกเลย์เอาต์ แล้วเลือก **Export Layout for AI** |
| องค์ประกอบหนึ่งรายการ | คลิกขวาที่องค์ประกอบ แล้วเลือก **Export for AI** |
| องค์ประกอบที่เลือกทั้งหมด | **Edit -> Export Selected Elements for AI** ในแถบเมนูของตัวแก้ไข |
| [พื้นหลังเมนู](/menu-backgrounds) | คลิกขวาที่พื้นหลังของตัวแก้ไข แล้วเลือก **Menu Backgrounds** เลือกพื้นหลัง แล้วเลือก **Export for AI** |
| [โอเวอร์เลย์ตกแต่ง](/decoration-overlays) | คลิกขวาที่พื้นหลังของตัวแก้ไข แล้วเลือก **Decoration Overlays** เลือกโอเวอร์เลย์ แล้วเลือก **Export for AI** |

## ตัวแก้ไขและหน้าต่าง

| สิ่งที่ส่งออก | ตำแหน่งที่ค้นหาได้ |
|---|---|
| [สคริปต์การทำงาน](/action-scripts) | คลิกขวาในตัวแก้ไขสคริปต์การทำงาน แล้วเลือก **Export Action Script for AI** |
| [ข้อกำหนด](/conditions) | คลิกขวาในหน้าต่าง **Manage Requirements** แล้วเลือก **Export Requirements for AI** |
| ข้อความ เช่น เนื้อหาในองค์ประกอบข้อความ | คลิกขวาในตัวแก้ไขข้อความ แล้วเลือก **Export Text for AI** |
| ตัวแปรหนึ่งรายการหรือตัวแปรทั้งหมด | เปิด **menu bar -> Customization -> Manage Variables** คลิกขวา แล้วเลือก **Export Variable for AI** หรือ **Export All Variables for AI** |
| ตัวฟังเหตุการณ์หนึ่งรายการหรือตัวฟังเหตุการณ์ทั้งหมด | เปิด **menu bar -> Customization -> Manage Listeners** คลิก **Export for AI** แล้วเลือก **Selected Listener** หรือ **All Listeners** |
| ตัวจัดตารางเวลาหนึ่งรายการหรือตัวจัดตารางเวลาทั้งหมด | เปิด **menu bar -> Customization -> Manage Schedulers** คลิก **Export for AI** แล้วเลือก **Selected Scheduler** หรือ **All Schedulers** |

## ข้อผิดพลาดและคำเตือน

เมื่อ FancyMenu แสดงข้อผิดพลาดหรือคำเตือน ให้คลิก **Export for AI** ที่อยู่ถัดจาก **OK** เพื่อส่งออกข้อความ

## เซิร์ฟเวอร์

การตั้งค่า [FMData](/fm-data) ของเซิร์ฟเวอร์ ซึ่งประกอบด้วยตัวฟังเหตุการณ์ของเซิร์ฟเวอร์และข้อมูลต้อนรับ สามารถส่งออกได้ด้วยคำสั่ง โดยต้องมีระดับสิทธิ์ 2 เช่นเดียวกับคำสั่ง `/fmdata` ทั้งหมด

```mcfunction
/fmdata export_for_ai copy
/fmdata export_for_ai file
```

- `copy` จะส่งข้อความในแชตมาให้คุณ คลิกข้อความนั้นเพื่อคัดลอกไฟล์ส่งออก ส่วนในคอนโซลเซิร์ฟเวอร์ จะแสดงไฟล์ส่งออกทั้งหมดแทน
- `file` จะบันทึกไฟล์ส่งออกไว้บนเซิร์ฟเวอร์ใน `fancymenu_data/ai_exports/` ใช้ตัวเลือกนี้เมื่อไฟล์ส่งออกมีขนาดใหญ่เกินกว่าจะส่งในแชตได้
