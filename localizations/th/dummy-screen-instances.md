# หน้าจอโหลดโลก

เมื่อคุณกำลังโหลดเข้าไปในโลกหรือเข้าร่วมเซิร์ฟเวอร์ คุณอาจสังเกตเห็นว่ามีหน้าจอบางอย่างแสดงขึ้นมา ซึ่งคุณไม่สามารถปรับแต่งได้จริง ๆ เพราะมันจะปิดลงโดยอัตโนมัติ

หากต้องการแก้ไขหน้าจอเหล่านี้ คุณจำเป็นต้องเปิดอินสแตนซ์ของหน้าจอนั้นที่ยังคงเปิดอยู่ได้นานเท่าที่คุณต้องการ ซึ่งสามารถทำได้โดยการเปิด "อินสแตนซ์หน้าจอจำลอง" ของมัน

"Dummy Screen Instances" เป็นฟีเจอร์ของ FancyMenu ที่ทำให้สามารถเปิดหน้าจอบางประเภทที่หายไปเร็วเกินกว่าจะปรับแต่งได้

หากต้องการดูหน้าจอทั้งหมดที่สามารถเปิดได้ผ่านฟีเจอร์ Dummy Screen Instance ให้คลิกที่ **แถบเมนู -> Tools -> Dummy Screen Instances** เมนูที่เปิดขึ้นจะแสดงหน้าจอทั้งหมดที่คุณสามารถเปิดเป็นอินสแตนซ์หน้าจอจำลองได้ การ **คลิกซ้าย** ที่หน้าจอในเมนูจะเปิดอินสแตนซ์จำลองให้คุณเพื่อปรับแต่งได้อย่างสะดวก

ตัวอย่างเช่น เมื่อเข้าร่วมโลกหรือเซิร์ฟเวอร์ จะมีอย่างน้อยสองหน้าจอที่แสดงระหว่างการโหลด:

- Level Loading Screen (หรือ World Loading Screen)
- Generic Dirt Message Screen (หรือ Dirt Message Screen)

> [!WARNING]
> **สำคัญ:** "World Loading Screen" ไม่ใช่ "Game Loading Screen" (หรือ Splash Screen / Resource Reloading Screen) เดียวกัน "Game Loading Screen" สามารถปรับแต่งได้ด้วย **Drippy Loading Screen** ซึ่งเป็นแอดออนสำหรับ FancyMenu
