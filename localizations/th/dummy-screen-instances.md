# หน้าจอโหลดโลก

เมื่อคุณกำลังโหลดเข้าโลกหรือเข้าร่วมเซิร์ฟเวอร์ คุณคงสังเกตเห็นว่ามีหน้าจอบางอย่างแสดงขึ้นมา ซึ่งคุณแทบจะปรับแต่งไม่ได้ เพราะมันจะปิดเองโดยอัตโนมัติ

หากต้องการแก้ไข คุณจำเป็นต้องเปิดอินสแตนซ์ของหน้าจอนั้นที่ค้างอยู่ได้นานเท่าที่คุณต้องการ ซึ่งทำได้โดยการเปิด "อินสแตนซ์หน้าจอจำลอง" ของมัน

"อินสแตนซ์หน้าจอจำลอง" เป็นฟีเจอร์ของ FancyMenu ที่ทำให้สามารถเปิดหน้าจอบางประเภทที่หายไปเร็วเกินกว่าจะปรับแต่งได้

หากต้องการดูหน้าจอทั้งหมดที่สามารถเปิดผ่านฟีเจอร์ Dummy Screen Instance ได้ ให้คลิกที่ **แถบเมนู -> Tools -> Dummy Screen Instances** เมนูที่เปิดขึ้นจะแสดงหน้าจอทั้งหมดที่คุณสามารถเปิดเป็นอินสแตนซ์หน้าจอจำลองได้ การ **คลิกซ้าย** ที่หน้าจอในเมนูจะเปิดอินสแตนซ์จำลองของหน้าจอนั้น เพื่อให้คุณปรับแต่งได้อย่างสบายใจ

ตัวอย่างเช่น เมื่อเข้าร่วมโลกหรือเซิร์ฟเวอร์ จะมีอย่างน้อยสองหน้าจอที่แสดงขึ้นระหว่างการโหลด:

- Level Loading Screen (หรือ World Loading Screen)
- Generic Dirt Message Screen (หรือ Dirt Message Screen)

> **สำคัญ:** "World Loading Screen" ไม่ใช่หน้าจอเดียวกับ "Game Loading Screen" (หรือ Splash Screen หรือ Resource Reloading Screen) โดย "Game Loading Screen" สามารถปรับแต่งได้ด้วย **Drippy Loading Screen** ซึ่งเป็นแอดออนสำหรับ FancyMenu
