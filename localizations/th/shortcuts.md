# ทางลัดและคีย์ลัด

**ปุ่มปรับร่วมของทางลัด:** ใช้ `Ctrl` บน Windows/Linux และ `Command` บน macOS ในกรณีที่รองรับ

# ตัวแก้ไขเลย์เอาต์

| ทางลัด | การทำงาน |
|---|---|
| `Ctrl/Command + คลิกซ้าย` | เลือกหรือลากหลายองค์ประกอบพร้อมกัน |
| `Shift + ปรับขนาด` | คงอัตราส่วนขององค์ประกอบไว้ |
| ปุ่มลูกศร | ย้ายองค์ประกอบที่เลือกอย่างแม่นยำ |
| `Ctrl/Command + A` | เลือกองค์ประกอบทั้งหมด |
| `Ctrl/Command + C` | คัดลอกองค์ประกอบที่เลือก |
| `Ctrl/Command + V` | วางองค์ประกอบที่คัดลอกไว้ รวมถึงวางไปยังเลย์เอาต์อื่นได้ |
| `Ctrl/Command + S` | บันทึกเลย์เอาต์ |
| `Ctrl/Command + Z` | เลิกทำ |
| `Ctrl/Command + Y` | ทำซ้ำ |
| `Ctrl/Command + G` | เปิด/ปิดกริด |
| `O` | แสดงจุดยึดเมื่อกดค้างไว้ เมื่อ **Window -> Anchor Overlay Visibility** ตั้งเป็น **Show On Key Press** |
| `Delete` | ลบองค์ประกอบที่เลือก |

# ตัวแก้ไขข้อความ

| ทางลัด | การทำงาน |
|---|---|
| `Ctrl/Command + C` | คัดลอกข้อความที่เลือก |
| `Ctrl/Command + V` | วางข้อความ |
| `Ctrl/Command + Z` | เลิกทำ |
| `Ctrl/Command + Y` | ทำซ้ำ |
| `Ctrl/Command + A` | เลือกข้อความทั้งหมด |
| `Ctrl/Command + D` | ทำสำเนาบรรทัดปัจจุบัน |
| `Ctrl/Command + U` | ตัดข้อความที่เลือก |
| `Alt + ลูกศรขึ้น/ลง` | ย้ายบรรทัดปัจจุบัน |
| `Ctrl/Command + Home/End` | ไปยังจุดเริ่มต้นหรือจุดสิ้นสุดของข้อความ |
| `Ctrl/Command + G` | เปิด **Go To Line** |
| `Ctrl/Command + S` | ยืนยันตัวแก้ไข |
| `Shift + ปุ่มลูกศร` | ขยายการเลือกข้อความ |
| ปุ่มลูกศร | ย้ายเคอร์เซอร์ |

# ทางลัดเมนูส่วนกลาง

ทางลัดเหล่านี้ใช้การกด `Ctrl + Alt` ตามที่ระบุเป๊ะ ๆ:

| ทางลัด | การทำงาน |
|---|---|
| `Ctrl + Alt + L` | เปิดตัวแก้ไขเลย์เอาต์ด้วยเลย์เอาต์ที่แก้ไขล่าสุด |
| `Ctrl + Alt + C` | เปิด/ปิดแถบเมนูของ FancyMenu |
| `Ctrl + Alt + R` | โหลด FancyMenu และทรัพยากร/แคชที่ระบบจัดการใหม่ |
| `Ctrl + Alt + D` | เปิด/ปิดโอเวอร์เลย์ดีบักของ FancyMenu |

# หน้าต่างการแก้ไข

หน้าต่างการแก้ไขของ FancyMenu รองรับการนำทางด้วยแป้นพิมพ์ด้วยปุ่มลูกศรและ `Enter` หลายหน้าต่างยังใช้ `Ctrl/Command + S` สำหรับ **Done** และ `Escape` สำหรับ **Cancel** ด้วย

ตัวแก้ไข Action Script, Requirements และ Variables ยังรองรับเมนูคลิกขวา การค้นหา เลิกทำ/ทำซ้ำ และการนำทางรายการด้วยแป้นพิมพ์ด้วย
