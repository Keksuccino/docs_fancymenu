# คีย์ลัดและปุ่มลัด

FancyMenu มีคีย์ลัดที่มีประโยชน์มากมาย ซึ่งช่วยให้การทำงานกับ **ตัวแก้ไขเลย์เอาต์** และส่วนอื่น ๆ ของม็อดสะดวกและมีประสิทธิภาพมากขึ้น

# ตัวแก้ไขเลย์เอาต์

<br>

## CTRL + คลิกซ้าย

คุณสามารถเลือกหลายองค์ประกอบได้โดยกด **CTRL** ค้างไว้ขณะ **คลิกซ้าย** ที่องค์ประกอบต่าง ๆ
นอกจากนี้ยังสามารถ **ลาก/ย้ายหลายองค์ประกอบ** ด้วยเมาส์ได้โดยกด **CTRL** ค้างไว้

## SHIFT + ปรับขนาดองค์ประกอบ

การกด SHIFT ค้างไว้ขณะปรับขนาดองค์ประกอบจะคงอัตราส่วนเดิมขององค์ประกอบไว้

## ปุ่มลูกศร

สามารถใช้ปุ่มลูกศรเพื่อ **ย้าย** องค์ประกอบที่เลือกได้อย่างแม่นยำสูงสุด

## CTRL + A

เลือกองค์ประกอบทั้งหมดพร้อมกัน

## CTRL + C

**คัดลอก** องค์ประกอบที่เลือกทั้งหมดไปยังคลิปบอร์ด

## CTRL + V

**วาง** องค์ประกอบทั้งหมดที่อยู่ในคลิปบอร์ดในขณะนี้
สิ่งนี้ใช้ได้ระหว่างเลย์เอาต์ต่าง ๆ ด้วย ดังนั้นคุณสามารถคัดลอกองค์ประกอบจากเลย์เอาต์ A แล้ววางลงในเลย์เอาต์ B ได้

## CTRL + S

**บันทึก** เลย์เอาต์อย่างรวดเร็ว

## CTRL + ALT + L

เปิดตัวแก้ไขเลย์เอาต์พร้อมเลย์เอาต์ที่แก้ไขล่าสุดอย่างรวดเร็ว

## CTRL + Z

**เลิกทำ** การกระทำล่าสุด

## CTRL + Y

**ทำซ้ำ** การกระทำที่เพิกถอนไปก่อนหน้านี้

## CTRL + G

สลับการแสดงผล **กริด** อย่างรวดเร็ว

## O

การกด **O** ค้างไว้จะแสดงโอเวอร์เลย์จุดยึด หากตั้งค่าการมองเห็นไว้เป็น **แสดงเมื่อกดปุ่ม** ใน **Window -> Anchor Overlay Visibility**

## DEL

**ลบ** องค์ประกอบที่เลือกทั้งหมด

# ตัวแก้ไขข้อความ

<br>

## CTRL + C

**คัดลอก** ข้อความที่เลือกไปยังคลิปบอร์ด

## CTRL + V

**วาง** ข้อความที่อยู่ในคลิปบอร์ดขณะนี้

## CTRL + Z

**เลิกทำ** การกระทำล่าสุด

## CTRL + Y

**ทำซ้ำ** การกระทำที่เพิกถอนไปก่อนหน้านี้

## CTRL + A

**เลือก** ข้อความทั้งหมด

## CTRL + D

**ทำซ้ำ** บรรทัดปัจจุบัน

## CTRL + U

**ตัด** ข้อความที่เลือก

## ALT + ลูกศรขึ้น / ลูกศรลง

ย้ายบรรทัดปัจจุบันขึ้นหรือลง

## CTRL + Home / CTRL + End

ย้ายเคอร์เซอร์ไปยังจุดเริ่มต้นหรือจุดสิ้นสุดของข้อความ

## CTRL + G

เปิดช่องป้อนข้อมูล **ไปยังบรรทัด**

## CTRL + S

ยืนยันในตัวแก้ไข เช่นเดียวกับการคลิก **เสร็จสิ้น**

## SHIFT + ปุ่มลูกศร

เลือก/ไฮไลต์ข้อความขณะเคลื่อนที่เคอร์เซอร์

## ปุ่มลูกศร

สามารถใช้ปุ่มลูกศรเพื่อนำทางเคอร์เซอร์ในข้อความได้

# ในเมนู

<br>

## CTRL + ALT + C

สลับการแสดงผล **แถบเมนู** ของ FancyMenu ที่ด้านบนของเมนู

## CTRL + ALT + R

**โหลด FancyMenu ใหม่**
ซึ่งรวมถึงการโหลดทรัพยากร/แอสเซ็ตทั้งหมดใหม่ และล้างแคชส่วนใหญ่

## CTRL + ALT + D

สลับการแสดงผล **โอเวอร์เลย์ดีบัก** ของ FancyMenu

# หน้าต่างสำหรับการแก้ไข

หน้าต่างสำหรับการแก้ไขหลายรายการใน FancyMenu v3.9.0 รองรับการนำทางด้วยคีย์บอร์ดผ่าน **ปุ่มลูกศร** และ **Enter** หลายหน้าต่างยังใช้ **CTRL + S** เป็นคีย์ลัดสำหรับ **เสร็จสิ้น** และ **ESC** สำหรับ **ยกเลิก** ด้วย

หน้าต่าง Action Script Editor, Manage Requirements และ Manage Variables ที่ปรับปรุงใหม่ ยังรองรับเมนูบริบทเมื่อคลิกขวา, การค้นหา, เลิกทำ/ทำซ้ำ และการนำทางด้วยคีย์บอร์ดสำหรับรายการต่าง ๆ ภายในหน้าต่างด้วย
