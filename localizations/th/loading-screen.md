# ปรับแต่งหน้าจอโหลด

**FancyMenu ไม่สามารถปรับแต่งหน้าจอโหลด/หน้าจอสแปลชของ Minecraft ได้ด้วยตัวเอง** นี่คือเหตุผลที่เรามีส่วนเสริม [Drippy Loading Screen](https://www.curseforge.com/minecraft/mc-mods/drippy-loading-screen) (สามารถค้นหาได้ [ที่นี่](https://modrinth.com/mod/drippy-loading-screen) บน Modrinth เช่นกัน)

> [!IMPORTANT]
>สำหรับวิธีใช้งาน Drippy Loading Screen โปรดดูที่ [วิกิ](https://github.com/Keksuccino/Drippy-Loading-Screen/wiki) ของส่วนเสริม
