# หน้าจอโหลด

FancyMenu ไม่ได้ปรับแต่งหน้าจอสแปลช/หน้าจอโหลดของ Minecraft ให้ใช้ส่วนเสริม [Drippy Loading Screen](https://www.curseforge.com/minecraft/mc-mods/drippy-loading-screen) สำหรับสิ่งนั้น.
