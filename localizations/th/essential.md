# Essential

เวอร์ชันล่าสุดของม็อด Essential ได้เพิ่มความเข้ากันได้กับ FancyMenu ซึ่งหมายความว่าตอนนี้คุณน่าจะสามารถปรับแต่งองค์ประกอบทั้งหมดที่ Essential เพิ่มเข้ามาในหน้าจอ Title และหน้าจอ Pause ได้อย่างเต็มที่!

สำหรับคำแนะนำโดยละเอียดเกี่ยวกับวิธีปรับแต่ง UI ของ Essential คุณควรดูที่ [หน้า wiki นี้](https://essential.gg/wiki/fancymenu) ของ wiki ของ Essential!

# ปัญหาในการปรับแต่ง

หากคุณพบข้อบกพร่องหรือความไม่สะดวกบางอย่างขณะพยายามปรับแต่งองค์ประกอบของ Essential สาเหตุเกือบทั้งหมดมักมาจาก Essential และนักพัฒนาของ Essential จำเป็นต้องแก้ไขฝั่งของพวกเขาเอง

คุณควรรายงานบั๊ก/ปัญหานี้ไปยังทีม Essential ผ่าน Discord หรือ GitHub ของพวกเขา
