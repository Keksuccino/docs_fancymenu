# เปิด GUI ด้วยคำสั่ง

คำสั่ง `/openguiscreen` ใช้เปิด GUI ของ Vanilla, ม็อด และ [Custom GUI](./custom-guis) ได้ โดยสามารถกำหนดผู้เล่นคนอื่นเป็นเป้าหมายได้เมื่อมีการติดตั้ง FancyMenu ทั้งบนเซิร์ฟเวอร์และไคลเอนต์ของผู้เล่นนั้น

หากต้องการเปิด GUI ให้ใช้ `/openguiscreen <screen_identifier> [<target_players>]`.

แทนที่ `<screen_identifier>` ด้วยตัวระบุที่ตรงกันทุกตัวอักษรและแยกตัวพิมพ์เล็ก/ใหญ่ของ Custom GUI หรือหน้าจอของ Vanilla/ม็อด

หากต้องการหาตัวระบุ ให้เปิดหน้าจอที่ต้องการแล้วเปิดโอเวอร์เลย์ดีบักด้วย **CTRL + ALT + D** จากนั้นเลือกตัวระบุที่บรรทัดแรกเพื่อคัดลอก ดูรายละเอียดที่ [Screen Identifiers](./screen-identifiers).

![copy_identifier](https://github.com/Keksuccino/FancyMenu/assets/35544624/dd6c53d9-d2bd-4810-be03-3741e326bd5a)

ละเว้น `[<target_players>]` เพื่อเปิด GUI ให้กับตัวเอง หรือใช้ชื่อผู้เล่นหรือ selector เช่น `@a` เพื่อเปิดให้ผู้เล่นหนึ่งคนหรือหลายคน การระบุอาร์กิวเมนต์เป้าหมายต้องใช้สิทธิ์ระดับ 2 (Game Master / OP ระดับ 2) แม้จะระบุตัวเองเป็นเป้าหมายก็ตาม และผู้เล่นเป้าหมายทุกคนต้องติดตั้ง FancyMenu ไว้บนไคลเอนต์ของตน

ไม่ใช่ทุกหน้าจอของม็อดจะสามารถสร้างได้โดยตรง FancyMenu จะแสดงข้อผิดพลาดเมื่อหน้าจอเป้าหมายไม่รองรับ ในเลย์เอาต์แบบ local ให้ใช้ [**Mimic Vanilla/Mod Button**](./action-scripts#mimic-vanillamod-button-mimicbutton) กับวิดเจ็ตที่ปกติใช้เปิดหน้าจอนั้น

# ปิด GUI ด้วยคำสั่ง

ในกรณีที่จำเป็น `/closeguiscreen [<target_players>]` จะปิดหน้าจอปัจจุบัน หากไม่ระบุเป้าหมาย คำสั่งนี้จะมีผลกับคุณเอง; การระบุอาร์กิวเมนต์เป้าหมายต้องใช้สิทธิ์ระดับ 2
