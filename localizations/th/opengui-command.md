# เปิด GUI ด้วยคำสั่ง

คำสั่ง `/openguiscreen` ใช้เปิด GUI ของ Vanilla, ม็อด และ [GUI แบบกำหนดเอง](/custom-guis) ได้ เมื่อติดตั้ง FancyMenu บนเซิร์ฟเวอร์และไคลเอนต์ของผู้เล่น คำสั่งนี้จะเปิด GUI ให้ผู้เล่นคนอื่นได้ด้วย

หากต้องการเปิด GUI ให้ใช้ `/openguiscreen <screen_identifier> [<target_players>]`

แทนที่ `<screen_identifier>` ด้วยตัวระบุที่ตรงกันทุกประการและคำนึงถึงตัวพิมพ์เล็ก-ใหญ่ของ GUI แบบกำหนดเอง หรือหน้าจอของ Vanilla/ม็อด

หากต้องการค้นหาตัวระบุ ให้เปิดหน้าจอเป้าหมาย แล้วเปิดโอเวอร์เลย์ดีบักด้วย **CTRL + ALT + D** เลือกตัวระบุที่บรรทัดแรกเพื่อคัดลอก ดูเพิ่มเติมที่ [ตัวระบุหน้าจอ](/screen-identifiers)

![copy_identifier](https://github.com/Keksuccino/FancyMenu/assets/35544624/dd6c53d9-d2bd-4810-be03-3741e326bd5a)

ละ `[<target_players>]` ไว้เพื่อเปิด GUI ให้ตัวคุณเอง หรือระบุชื่อผู้เล่นหรือตัวเลือก เช่น `@a` เพื่อเปิดให้ผู้เล่นหนึ่งคนหรือหลายคน การระบุอาร์กิวเมนต์เป้าหมายต้องใช้สิทธิ์ระดับ 2 (Game Master / OP ระดับ 2) แม้จะระบุตัวคุณเองก็ตาม และผู้เล่นเป้าหมายทุกคนต้องติดตั้ง FancyMenu ในไคลเอนต์ของตน

ไม่สามารถสร้างหน้าจอของม็อดได้โดยตรงทุกหน้าจอ FancyMenu จะแสดงข้อผิดพลาดเมื่อหน้าจอเป้าหมายไม่รองรับ ในเลย์เอาต์ภายในเครื่อง ให้ใช้ [**จำลองปุ่ม Vanilla/ม็อด**](/action-scripts#mimic-vanillamod-button) กับวิดเจ็ตที่ใช้เปิดหน้าจอนั้นตามปกติ

# ปิด GUI ด้วยคำสั่ง

หากจำเป็นในกรณีที่พบได้ไม่บ่อย คำสั่ง `/closeguiscreen [<target_players>]` จะปิดหน้าจอปัจจุบัน หากไม่ระบุเป้าหมาย คำสั่งจะมีผลกับตัวคุณเอง การระบุอาร์กิวเมนต์เป้าหมายต้องใช้สิทธิ์ระดับ 2
