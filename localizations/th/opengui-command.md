# การเปิด GUI ด้วยคำสั่ง

FancyMenu มาพร้อมกับคำสั่งที่ช่วยให้คุณเปิด GUI แบบ Vanilla และแบบกำหนดเองได้ผ่านคำสั่ง
คุณยังสามารถเปิด GUI ให้กับผู้เล่น **คนอื่น** จากระยะไกลได้ด้วย เมื่อมีการติดตั้ง FancyMenu ทั้งบน **เซิร์ฟเวอร์และไคลเอนต์**

หากต้องการเปิด GUI ให้ใช้คำสั่ง `/openguiscreen <screen_identifier> <target_player>`

แทนที่ `<screen_identifier>` ด้วยตัวระบุเมนูจริงของ GUI ที่คุณต้องการเปิด
ซึ่งอาจเป็นตัวระบุของ Custom GUI ของคุณเอง (ที่สร้างด้วย FancyMenu) หรือเป็นตัวระบุเมนูปกติของ GUI แบบ Vanilla/ม็อดก็ได้

หากต้องการดู **ตัวระบุเมนูของ GUI แบบ Vanilla/ม็อด** ให้เปิดเมนูที่คุณต้องการทราบตัวระบุ แล้วเปิดใช้ **debug overlay** ของ FancyMenu ผ่าน **Customization -> Debug Overlay** จากนั้นคุณสามารถคลิกที่ตัวระบุที่แสดงเป็นบรรทัดแรกเพื่อคัดลอกลงคลิปบอร์ดได้

![copy_identifier](https://github.com/Keksuccino/FancyMenu/assets/35544624/dd6c53d9-d2bd-4810-be03-3741e326bd5a)

เว้นอาร์กิวเมนต์ `<target_player>` ว่างไว้เพื่อเปิด GUI ให้กับไคลเอนต์ของคุณ หรือจะระบุผู้เล่นหนึ่งคน (หรือหลายคน) เพื่อเปิด GUI ให้ก็ได้
โปรดจำไว้ว่า ผู้เล่นอีกฝ่ายต้องติดตั้ง FancyMenu ไว้บนไคลเอนต์ของตนด้วย

คำสั่งนี้จะใช้ไม่ได้กับทุกหน้าจอ โดยเฉพาะหน้าจอของม็อด หากคำสั่งไม่สามารถเปิดหน้าจอได้ ระบบจะแสดงข้อผิดพลาดออกมา ในกรณีนี้คุณทำอะไรได้ไม่มากนัก เพราะน่าจะเป็นหน้าจอที่ซับซ้อนเกินกว่าที่ FancyMenu จะเปิดอัตโนมัติได้

นอกจากนี้ ฉันจะไม่เพิ่มความเข้ากันได้สำหรับหน้าจอของม็อดด้วยตนเองอีกต่อไป เพราะการรองรับม็อดทั้งหมดที่มีอยู่นั้นคงใช้เวลานานมาก ขอโทษด้วย

# การปิด GUI ด้วยคำสั่ง

ในกรณีที่จำเป็น ก็มีคำสั่ง `/closeguiscreen <target_player>` สำหรับปิดหน้าจอปัจจุบันด้วย
