# ตัวระบุองค์ประกอบ

ทุกองค์ประกอบใน FancyMenu จะมีตัวระบุเฉพาะ ซึ่งระบบกำหนดให้โดยอัตโนมัติเมื่อสร้างองค์ประกอบนั้น

ตัวระบุเหล่านี้ใช้เพื่อระบุองค์ประกอบนั้น เพื่อให้ส่วนอื่น ๆ ของ FancyMenu เช่น ตัวแทน การกระทำ และข้อกำหนดในการโหลด สามารถสื่อสารกับองค์ประกอบได้

# วิธีรับตัวระบุขององค์ประกอบ

หากต้องการรับตัวระบุขององค์ประกอบ ให้คลิกขวาที่องค์ประกอบในตัวแก้ไข แล้วคลิก **คัดลอกรหัสองค์ประกอบ** ระบบจะคัดลอกตัวระบุไปยังคลิปบอร์ด เพื่อให้คุณนำไปวางในตำแหน่งที่ต้องการได้
