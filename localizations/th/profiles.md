# โปรไฟล์

โปรไฟล์คือการตั้งค่า FancyMenu ทั้งชุด ซึ่งประกอบด้วยเลย์เอาต์ แอสเซ็ต ตัวแปร และการตั้งค่า FancyMenu ทั้งหมดของอินสแตนซ์หนึ่ง ๆ โปรไฟล์ช่วยให้คุณเก็บการตั้งค่าหลายชุดไว้ในอินสแตนซ์ Minecraft เดียว สลับไปมาได้ภายในไม่กี่วินาที และแชร์ให้ผู้อื่นเป็นไฟล์เดียวได้

# การเปิดหน้าต่างโปรไฟล์

เปิดหน้าต่างโปรไฟล์ผ่าน **แถบเมนู -> การปรับแต่ง -> โปรไฟล์**

รายการทางด้านซ้ายจะแสดงโปรไฟล์ทั้งหมดของคุณ ส่วนด้านขวาจะแสดงรายละเอียดของโปรไฟล์ที่เลือก โปรไฟล์ที่โหลดอยู่จะมีป้ายกำกับว่า **ใช้งานอยู่** การเปลี่ยนแปลงทุกอย่างที่คุณทำใน FancyMenu จะถูกบันทึกลงในโปรไฟล์ที่โหลดอยู่โดยตรง

การตั้งค่าที่มีอยู่เดิมของคุณจะกลายเป็นโปรไฟล์แรกโดยอัตโนมัติ โดยใช้ชื่อว่า **โปรไฟล์ของฉัน**

> [!TIP]
> คลิกขวาที่โปรไฟล์ในรายการเพื่อดูการดำเนินการทั้งหมดที่ทำได้กับโปรไฟล์นั้น

# การสลับโปรไฟล์

เลือกโปรไฟล์แล้วคลิก **โหลดโปรไฟล์** หรือดับเบิลคลิกที่โปรไฟล์นั้น จากนั้น FancyMenu จะโหลดใหม่ด้วยการตั้งค่าที่เลือก

> [!NOTE]
> การสลับโปรไฟล์จะไม่ลบข้อมูลใด ๆ การตั้งค่าปัจจุบันของคุณจะถูกบันทึกเป็นโปรไฟล์ของตัวเองก่อนที่จะโหลดโปรไฟล์อื่น ดังนั้นคุณจึงสามารถสลับกลับมาได้เสมอ

# การสร้างโปรไฟล์

- **โปรไฟล์ใหม่** (ปุ่ม **+** ใต้รายการ) จะสร้างโปรไฟล์ว่างและเปิดตัวแก้ไข โปรไฟล์ว่างจะเก็บการตั้งค่า FancyMenu ส่วนตัวของคุณไว้ เช่น ขนาด UI และธีม
- **ทำซ้ำ** จะสร้างสำเนาของโปรไฟล์ที่เลือก เหมาะสำหรับทดลองสิ่งต่าง ๆ โดยไม่กระทบกับโปรไฟล์ต้นฉบับ

# การแก้ไขโปรไฟล์

คลิก **แก้ไข** เพื่อเปลี่ยนชื่อเรื่อง เวอร์ชัน ผู้เขียน คำอธิบาย ไอคอน ตัวติดตามปัญหา และลิงก์ของโปรไฟล์ คำอธิบายรองรับ Markdown และไอคอนสามารถเป็นรูปภาพ PNG ใดก็ได้

ข้อมูลจะยังไม่ถูกบันทึกจนกว่าคุณจะคลิก **เสร็จสิ้น**

# การแชร์โปรไฟล์

> [!CAUTION]
> โปรไฟล์สามารถเรียกใช้การดำเนินการต่าง ๆ ได้ ให้นำเข้าโปรไฟล์จากแหล่งที่คุณเชื่อถือเท่านั้น

## การส่งออก

เลือกโปรไฟล์ คลิก **ส่งออก** แล้วเลือกตำแหน่งที่จะบันทึก ระบบจะสร้างไฟล์ `.fmp` ที่มีข้อมูลโปรไฟล์ทั้งหมด

## การนำเข้า

คลิก **นำเข้า** ใต้รายการแล้วเลือกไฟล์ `.fmp` หรือเพียงลากไฟล์แล้ววางลงบนหน้าต่างโปรไฟล์

- โปรไฟล์ที่นำเข้าจะไม่ถูกโหลดโดยอัตโนมัติ ให้โหลดโปรไฟล์ดังกล่าวเช่นเดียวกับโปรไฟล์อื่น ๆ
- หากคุณมีโปรไฟล์เดียวกันอยู่แล้ว (เช่นเป็นเวอร์ชันเก่าของโปรไฟล์นั้น) คุณสามารถเลือก **แทนที่** หรือ **เก็บทั้งสองรายการ** ได้ หากแทนที่โปรไฟล์ที่โหลดอยู่ ระบบจะโหลดเวอร์ชันที่นำเข้าให้ทันที
- โปรไฟล์ที่สร้างด้วย FancyMenu เวอร์ชันใหม่กว่าจะแสดงคำเตือน เนื่องจากบางส่วนของโปรไฟล์อาจทำงานไม่ได้

## การเพิ่มโฟลเดอร์การตั้งค่า

การตั้งค่าบางชุดอาจมาในรูปแบบโฟลเดอร์ `fancymenu` ธรรมดาแทนไฟล์ `.fmp` หากต้องการเพิ่มโฟลเดอร์ดังกล่าวเป็นโปรไฟล์ ให้เปลี่ยนชื่อโฟลเดอร์เป็นชื่อโปรไฟล์ที่ต้องการ ย้ายไปไว้ที่ `<game-directory>/config/fancymenu/profiles/` (สร้างโฟลเดอร์ `profiles` หากยังไม่มี) แล้วเปิดหน้าต่างโปรไฟล์ FancyMenu จะเพิ่มโฟลเดอร์นั้นลงในโปรไฟล์ของคุณโดยอัตโนมัติ

# การลบโปรไฟล์

เลือกโปรไฟล์แล้วคลิก **ลบ** การลบไม่สามารถย้อนกลับได้ ดังนั้นให้ส่งออกโปรไฟล์ก่อนหากต้องการเก็บข้อมูลสำรอง

ไม่สามารถลบโปรไฟล์ที่โหลดอยู่ได้ ให้โหลดโปรไฟล์อื่นก่อน

# ตำแหน่งจัดเก็บโปรไฟล์

- โปรไฟล์ที่โหลดอยู่คือเนื้อหาภายใน `<game-directory>/config/fancymenu/` เช่นเดียวกับการตั้งค่า FancyMenu อื่น ๆ
- โปรไฟล์อื่น ๆ ทั้งหมดจะถูกจัดเก็บไว้ใน `<game-directory>/config/fancymenu/profiles/` คลิก **เปิดโฟลเดอร์** เพื่อเปิดโฟลเดอร์ของโปรไฟล์

`<game-directory>` คือโฟลเดอร์อินสแตนซ์ที่ใช้งานอยู่ ซึ่งอาจแตกต่างจาก `.minecraft` สถานะขณะทำงานที่ FancyMenu เก็บไว้นอก `config/fancymenu/` ไม่ถือเป็นส่วนหนึ่งของโปรไฟล์ โปรดดู [ตำแหน่งจัดเก็บข้อมูล](./data-storage-locations#persistent-runtime-state)
