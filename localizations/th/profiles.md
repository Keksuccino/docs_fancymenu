# โปรไฟล์

โปรไฟล์คือการตั้งค่า FancyMenu แบบครบชุด ซึ่งประกอบด้วยเลย์เอาต์ แอสเซ็ต ตัวแปร การตั้งค่า และทุกอย่างใน `config/fancymenu/` (ดู [ตำแหน่งจัดเก็บข้อมูล](/data-storage-locations#your-setup)) คุณสามารถเก็บการตั้งค่าหลายชุดไว้ใน Minecraft instance เดียว สลับไปมาได้ในไม่กี่วินาที และแชร์เป็นไฟล์เดียวได้ด้วยโปรไฟล์

# หน้าต่าง Profiles

เปิดหน้าต่างนี้ได้จาก **แถบเมนู -> Customization -> Profiles**

- รายการทางซ้ายจะแสดงโปรไฟล์ทั้งหมด โปรไฟล์ที่โหลดอยู่จะแสดงเป็นรายการแรกและมีป้าย **Active** การเปลี่ยนแปลงทุกอย่างที่คุณทำใน FancyMenu จะบันทึกลงในโปรไฟล์นี้ทันที
- ด้านขวาจะแสดงรายละเอียดของโปรไฟล์ที่เลือก ได้แก่ ไอคอน ชื่อ เวอร์ชัน ผู้สร้าง จำนวนเลย์เอาต์ ขนาด ลิงก์ และคำอธิบาย
- เมื่อเลื่อนเมาส์ไปบนปุ่มใต้รายการและรายละเอียด จะแสดงชื่อปุ่มนั้น นอกจากนี้ การคลิกขวาที่โปรไฟล์จะแสดงการทำงานต่าง ๆ ด้วย

การตั้งค่าของคุณจะกลายเป็นโปรไฟล์แรกโดยอัตโนมัติ โดยใช้ชื่อว่า **My Profile**

# โหลดโปรไฟล์

เลือกโปรไฟล์แล้วคลิก **Load Profile** ดับเบิลคลิกที่โปรไฟล์ หรือกด `Enter`

จากนั้น FancyMenu จะโหลดใหม่พร้อมโปรไฟล์นั้น เหมือนตอนเริ่มเกม หน้าต่าง FancyMenu อื่น ๆ ทั้งหมดจะปิด และหากไม่ได้อยู่ในโลกเกม หน้าจอไตเติลจะเปิดขึ้น

> [!NOTE]
> การโหลดโปรไฟล์จะไม่ลบสิ่งใด การตั้งค่าปัจจุบันของคุณจะถูกบันทึกเป็นโปรไฟล์ของตัวเองก่อน คุณจึงสลับกลับมาได้เสมอ

# สร้างโปรไฟล์

- **New Profile** (ปุ่ม `+` ใต้รายการ) จะสร้างโปรไฟล์เปล่าและเปิดหน้ารายละเอียดให้ทันที เพื่อให้คุณตั้งชื่อได้ โปรไฟล์นี้จะเก็บค่ากำหนดของ FancyMenu เช่น สเกล UI และธีมไว้ แต่จะไม่มีเลย์เอาต์หรือการปรับแต่งอื่น ๆ และจะไม่ถูกโหลดโดยอัตโนมัติ
- **Duplicate** จะคัดลอกโปรไฟล์ที่เลือก เหมาะสำหรับทดลองสิ่งต่าง ๆ โดยไม่กระทบโปรไฟล์ต้นฉบับ

# แก้ไขรายละเอียดโปรไฟล์

เลือกโปรไฟล์แล้วคลิก **Edit** เพื่อเปลี่ยนรายละเอียด:

- **Title** ชื่อโปรไฟล์ ซึ่งเป็นสิ่งเดียวที่โปรไฟล์จำเป็นต้องมี
- **Version** และ **Authors** หากมีผู้สร้างหลายคน ให้คั่นชื่อด้วยเครื่องหมายจุลภาค
- **Description** รองรับ [Markdown](/text-formatting#markdown) เช่น ตัวหนา หัวข้อ และรายการ
- **Issue Tracker** เว็บไซต์ที่ผู้ใช้สามารถแจ้งปัญหาเกี่ยวกับโปรไฟล์ได้ โดยจะแสดงเป็น **Report an Issue**
- **Links** สำหรับลิงก์ไปยังเซิร์ฟเวอร์ Discord ช่อง YouTube เว็บไซต์ และอื่น ๆ คลิก **Add Link** แล้ววางลิงก์ FancyMenu จะตรวจหาแพลตฟอร์มให้โดยอัตโนมัติ
- ไอคอน: **Choose Icon** ใช้เลือกภาพ PNG ส่วน **Remove Icon** ใช้ลบไอคอน ภาพที่ไม่ใช่สี่เหลี่ยมจัตุรัสจะถูกครอปบริเวณกึ่งกลาง

การเปลี่ยนแปลงจะยังไม่ถูกบันทึกจนกว่าคุณจะคลิก **Done**

# แชร์โปรไฟล์

> [!CAUTION]
> โปรไฟล์สามารถเรียกใช้การทำงานต่าง ๆ ได้ เช่น เปิดลิงก์หรือเรียกใช้คำสั่ง ให้นำเข้าโปรไฟล์จากแหล่งที่คุณเชื่อถือเท่านั้น

## ส่งออก

เลือกโปรไฟล์ คลิก **Export** แล้วเลือกตำแหน่งที่จะบันทึก ระบบจะสร้างไฟล์ `.fmp` ที่มีโปรไฟล์ทั้งชุด พร้อมสำหรับแชร์

## นำเข้า

คลิก **Import** ใต้รายการแล้วเลือกไฟล์ `.fmp` หรือลากไฟล์ไปวางในหน้าต่าง Profiles

- โปรไฟล์ที่นำเข้าจะไม่ถูกโหลดโดยอัตโนมัติ ให้โหลดเหมือนโปรไฟล์อื่น ๆ
- หากมีโปรไฟล์นี้อยู่แล้ว เช่น เป็นเวอร์ชันเก่า ให้เลือก **Replace** หรือ **Keep Both** หากแทนที่โปรไฟล์ที่กำลังโหลด โปรไฟล์ที่นำเข้าจะถูกโหลดทันที และการเปลี่ยนแปลงที่ทำไว้กับโปรไฟล์เดิมจะหายไป
- โปรไฟล์ที่สร้างด้วย FancyMenu เวอร์ชันใหม่กว่าจะแสดงคำเตือนก่อน เนื่องจากบางส่วนอาจใช้งานไม่ได้
- ใช้ได้เฉพาะไฟล์ `.fmp` ที่ส่งออกจาก FancyMenu เท่านั้น หากมีโฟลเดอร์ทั่วไป ให้ดูหัวข้อถัดไป

## เพิ่มโฟลเดอร์การตั้งค่า

การตั้งค่าบางชุดมาในรูปแบบโฟลเดอร์ `fancymenu` ทั่วไป (สำเนาจาก `config/fancymenu/` ของผู้อื่น) แทนที่จะเป็นไฟล์ `.fmp` หากต้องการเพิ่มเป็นโปรไฟล์ ให้ทำตามขั้นตอนต่อไปนี้:

1. แตกไฟล์ หากได้รับมาเป็นไฟล์ `.zip`
2. ย้ายโฟลเดอร์ไปไว้ที่ `<game-directory>/config/fancymenu/profiles/` หากยังไม่มีโฟลเดอร์ `profiles` ให้สร้างขึ้นมา
3. เปิดหน้าต่าง Profiles หรือปิดแล้วเปิดใหม่ FancyMenu จะเพิ่มโฟลเดอร์นั้นเข้าไปในโปรไฟล์ของคุณ

โฟลเดอร์ดังกล่าวต้องมีไฟล์อยู่ภายในโดยตรง เช่น `customization/` และ `options.txt` ไม่ใช่มีโฟลเดอร์ `fancymenu` อีกชั้นหนึ่ง โปรไฟล์จะใช้ชื่อโฟลเดอร์เป็นชื่อ เว้นแต่โฟลเดอร์นั้นจะมีรายละเอียดโปรไฟล์ของตัวเอง คุณเปลี่ยนชื่อได้ด้วย **Edit**

## เทมเพลตเลย์เอาต์

ช่อง [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) บน [เซิร์ฟเวอร์ Discord Kekscord](https://discord.gg/rhayah27GC) (เซิร์ฟเวอร์ Discord อย่างเป็นทางการของ Keksuccino สำหรับขอความช่วยเหลือเกี่ยวกับม็อด) มีการตั้งค่าแบบครบชุดที่ชุมชนสร้างขึ้นสำหรับ FancyMenu และส่วนเสริมต่าง ๆ เช่น SpiffyHUD และ Drippy Loading Screen ทุกโพสต์มีลิงก์ดาวน์โหลด ซึ่งอาจเป็นไฟล์ `.fmp` หรือโฟลเดอร์ `fancymenu`

เทมเพลตมีความซับซ้อน อย่าพยายามรวมเข้ากับการตั้งค่าของคุณ ให้เพิ่มเป็นโปรไฟล์แยกต่างหากแทน:

1. [นำเข้า](#importing) ไฟล์ `.fmp` หรือ [เพิ่มโฟลเดอร์](#adding-setup-folders)
2. เลือกเทมเพลตในหน้าต่าง Profiles แล้วคลิก **Load Profile**

การตั้งค่าของคุณจะยังอยู่ในโปรไฟล์แยกต่างหาก จึงสลับกลับมาได้เสมอ

เทมเพลตส่วนใหญ่อนุญาตให้แก้ไขและนำไปใช้ในโปรเจกต์ของคุณเอง เช่น ม็อดแพ็ก แต่ไม่ใช่ทุกเทมเพลต โปรดตรวจสอบโพสต์ของเทมเพลตทุกครั้งว่าคุณได้รับอนุญาตให้ทำอะไรได้บ้าง

# ลบโปรไฟล์

เลือกโปรไฟล์แล้วคลิก **Delete** หรือกด `Delete` (`Fn + Delete` บน macOS) การลบไม่สามารถย้อนกลับได้ หากต้องการสำรองข้อมูล ให้ส่งออกโปรไฟล์ก่อน

โปรไฟล์ที่กำลังโหลดอยู่จะลบไม่ได้ ให้โหลดโปรไฟล์อื่นก่อน

# ตำแหน่งจัดเก็บโปรไฟล์

- เนื้อหาของโปรไฟล์ที่กำลังโหลดอยู่จะอยู่ใน `<game-directory>/config/fancymenu/`
- โปรไฟล์อื่นทั้งหมดอยู่ใน `<game-directory>/config/fancymenu/profiles/` โดยแต่ละโปรไฟล์จะอยู่ในโฟลเดอร์ของตัวเอง **Open Folder** จะเปิดโฟลเดอร์ของโปรไฟล์ที่เลือก

`<game-directory>` คือโฟลเดอร์ของ instance ซึ่งอาจไม่ใช่ `.minecraft` ข้อมูลใน `<game-directory>/fancymenu_data/` ไม่ได้เป็นส่วนหนึ่งของโปรไฟล์ ดู [ตำแหน่งจัดเก็บข้อมูล](/data-storage-locations#instance-data)

# เมื่อเกิดปัญหา

- **ไฟล์บางส่วนยังถูกใช้งานอยู่:** มักเกิดจากตัวเกมกำลังโหลดบางอย่าง เช่น เสียง ให้รอสักครู่แล้วลองอีกครั้ง หากยังเกิดปัญหา ให้ปิดโปรแกรมที่อาจกำลังใช้ไฟล์ เช่น โปรแกรมป้องกันไวรัส ระบบซิงก์ข้อมูลบนคลาวด์ หรือหน้าต่างโปรแกรมจัดการไฟล์
- **การสลับโปรไฟล์ครั้งก่อนยังไม่เสร็จ:** ไม่มีข้อมูลสูญหาย โหลดโปรไฟล์อีกครั้งหรือเริ่มเกมใหม่เพื่อให้การสลับเสร็จสมบูรณ์
- **พื้นที่ว่างในดิสก์ไม่เพียงพอ:** ข้อความจะแจ้งว่าโปรไฟล์ต้องใช้พื้นที่เท่าใด เพิ่มพื้นที่ว่างแล้วลองอีกครั้ง
- การทำงานกับโปรไฟล์จะทำทีละรายการ การส่งออก นำเข้า หรือทำสำเนาโปรไฟล์ขนาดใหญ่อาจใช้เวลาสักครู่ ระหว่างดำเนินการจะแสดงปุ่ม **Cancel**
