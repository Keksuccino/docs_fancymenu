# รายการม็อดที่ไม่เข้ากัน

ม็อดต่อไปนี้ทราบกันว่าใช้งานร่วมกับ FancyMenu ไม่ได้ในบางรูปแบบ

ม็อดบางตัวมีวิธีแก้ชั่วคราวเพื่อให้ใช้งานร่วมกับ FancyMenu ได้
ถ้าเป็นกรณีนั้น จะมีระบุไว้หลังชื่อม็อดในรายการด้านล่าง

**หากคุณพบม็อดที่ไม่เข้ากันซึ่งยังไม่มีอยู่ในรายการนี้ กรุณาเปิด issue บน GitHub! ขอบคุณมาก!**

* [Animated Loading Screen](https://modrinth.com/mod/animated-loading-screen) (ทำให้เมนูดูเสีย/ผิดปกติ)
* [Animated Mojang Logo](https://www.curseforge.com/minecraft/mc-mods/animated-mojang-logo) (เลย์เอาต์บางครั้งไม่โหลด; และยังทำให้ Drippy Loading Screen ใช้งานไม่ได้ด้วย)
* [Bedrockify](https://www.curseforge.com/minecraft/mc-mods/bedrockify) (ใช้งานได้เมื่อคุณปิดการแก้ไขเมนูทั้งหมดของม็อดนี้ อย่างน้อยสำหรับเมนูที่คุณต้องการปรับแต่ง)
* [BetterFPS](https://www.curseforge.com/minecraft/mc-mods/betterfps) (ปุ่มและเมนูของม็อดนี้ไม่สามารถปรับแต่งได้)
* [Chat Colors](https://www.curseforge.com/minecraft/mc-mods/chat-colours) (แครชตอนเริ่มเกม)
* [Chloride](https://modrinth.com/mod/chloride) (ตัวแทน FPS ใช้งานไม่ได้เมื่อมีม็อดนี้ติดตั้งอยู่)
* [Colormatic](https://www.curseforge.com/minecraft/mc-mods/colormatic) (หน่วงมากตอนเริ่ม MC และทำให้ระบบเสียงของ FM ใช้งานไม่ได้)
* [Controllable](https://www.curseforge.com/minecraft/mc-mods/controllable) (ปุ่มที่เพิ่มเข้าไปในเมนูด้วย FancyMenu จะคลิกไม่ได้ผ่านฟีเจอร์ “Virtual Mouse” ของ Controllable)
* [Controlify](https://modrinth.com/mod/controlify) (ดูเหมือนจะทำให้เกมแครช แต่ฝั่งของฉันแก้ไม่ได้ - ดู [issue นี้](https://github.com/Keksuccino/FancyMenu/issues/1144) เพื่อรายละเอียดเพิ่มเติม)
* [Crash To Main Menu](https://www.curseforge.com/minecraft/mc-mods/crash-to-main-menu)
* [Custom Loading Screen](https://www.curseforge.com/minecraft/mc-mods/better-loading-screen)
* [Custom Main Menu](https://www.curseforge.com/minecraft/mc-mods/custom-main-menu)
* [Debugify](https://www.curseforge.com/minecraft/mc-mods/debugify) (ให้ใช้ [Modern Debugify](https://www.curseforge.com/minecraft/mc-mods/modern-debugify) แทน)
* [Dynamic Surroundings](https://www.curseforge.com/minecraft/mc-mods/dynamic-surroundings) (ทำให้ส่วนเสียงของ FancyMenu ใช้งานไม่ได้ แต่ส่วนอื่นควรทำงานได้ปกติ)
* [EnhancedVisuals](https://www.curseforge.com/minecraft/mc-mods/enhancedvisuals) (ดูเหมือนจะทำให้อนิเมชันเสีย ทำให้พื้นหลังโปร่งแสง และอาจมีอย่างอื่นอีก)
* [Entity Model Features](https://modrinth.com/mod/entity-model-features) (แครชเกม แต่ฝั่งของฉันแก้ไม่ได้ - ดู [issue นี้](https://github.com/Keksuccino/FancyMenu/issues/1115) เพื่อรายละเอียดเพิ่มเติม)
* [Fossils and Archeology Revival](https://www.curseforge.com/minecraft/mc-mods/fossils) (ใช้งานในเกมได้ แต่เมนูหลักแบบกำหนดเองไม่รองรับ—สามารถปิดได้ในไฟล์คอนฟิก)
* [Holographic Renderers](https://www.curseforge.com/minecraft/mc-mods/holographic-renderers) (แครชตอนเริ่มเกม)
* [Ice and Fire](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons) (ใช้งานได้หากปิดเมนูหลักแบบกำหนดเองในคอนฟิก)
* [Jurassicraft](https://www.curseforge.com/minecraft/mc-mods/jurassicraft) (แครชตอนเริ่มเกมเมื่อเปิดการปรับแต่ง GUI ของมัน—ให้ลบออกจาก `config/fancymenu/customizablemenus.txt`)
* [Legacy4J](https://www.curseforge.com/minecraft/mc-mods/legacy-minecraft) (ทำให้เกมแครช)
* [MalisisCore](https://www.curseforge.com/minecraft/mc-mods/malisiscore) (ทำให้การปรับแต่งหน้าเมนูหลักเสีย)
* [Main Menu Scale Mod](https://www.curseforge.com/minecraft/mc-mods/main-menu-scale)
* [MCA Reborn](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-reborn) (ใช้งานได้ แต่บางเมนูของมันทำให้แถบเมนูของ FM เสียและ/หรือไม่สามารถปรับแต่งได้)
* [Minecraft Comes Alive](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-mca) (ใช้งานได้ปกติ แต่เมนูของมันไม่สามารถปรับแต่งได้)
* [MineTogether](https://www.curseforge.com/minecraft/mc-mods/creeperhost-minetogether) (ดูเหมือนจะทำให้เลย์เอาต์เสียเมื่อ GUI scale > 2)
* [Mod Menu](https://www.curseforge.com/minecraft/mc-mods/modmenu) (**ใช้งานได้ปกติ** ในกรณีส่วนใหญ่ แต่ถ้าคุณเจอปุ่ม Mods ซ้ำหรือปรับแต่งไม่ได้ ให้เปลี่ยนการตั้งค่าปุ่ม Mod Menu เป็น "Adjacent": Main Menu > Mods > Mod Menu > Mods Button: Adjacent)
* [Modern Online Picture Frames](https://www.curseforge.com/minecraft/mc-mods/online-picture-frame) (แครช—ดู [issue นี้](https://github.com/Keksuccino/FancyMenu/issues/776))
* [Not Enough Animations](https://www.curseforge.com/minecraft/mc-mods/not-enough-animations) (ใช้งานได้ปกติใน 1.16+ แต่ทำให้ 1.12 ใช้งานไม่ได้)
* **OptiFine** (ทำให้ม็อดเสีย! ให้ใช้ [ทางเลือกเหล่านี้](./optifine-alternatives) แทน)
* [Optiscale](https://www.curseforge.com/minecraft/mc-mods/optiscale) (ทำให้ UI ของ FancyMenu เสีย; ปุ่มต่าง ๆ คลิกไม่ได้)
* [Pack Menu](https://www.curseforge.com/minecraft/mc-mods/packmenu)
* [Panorama Screens](https://modrinth.com/mod/panorama-screens) (จะใช้งานไม่ได้และก่อปัญหา เพราะการซ้อนม็อดที่ใช้ปรับแต่งเมนูไม่เคยเป็นความคิดที่ดี)
* [QuestCraft](https://github.com/QuestCraftPlusPlus/QuestCraft) (เกมโหลดไม่สำเร็จ)
* [RandomPatches](https://www.curseforge.com/minecraft/mc-mods/randompatches-forge) (ใช้งานได้หากตั้งค่า `patchMinecraftClass = false` ในคอนฟิก)
* [Remove Reloading Screen](https://www.curseforge.com/minecraft/mc-mods/rrls) (ทำให้ FM และ Drippy เสีย อย่าใช้ม็อดนี้)
* [Replay Mod](https://www.replaymod.com/download/) (ใช้งานได้เมื่อคุณตั้ง `mainMenuButton` เป็น **BIG** ใน `.minecraft/config/replaymod.json`)
* [Seamless Loading Screen](https://www.curseforge.com/minecraft/mc-mods/seamless-loading-screen) (ทำให้เกมแครช)
* [Slight Gui Modifications](https://www.curseforge.com/minecraft/mc-mods/slight-gui-modifications)
* [Skin Layers 3D](https://www.curseforge.com/minecraft/mc-mods/skin-layers-3d) (ใช้งานได้ปกติใน 1.16+ แต่ทำให้ 1.12 ใช้งานไม่ได้)
* [Smooth Scrolling Everywhere](https://www.curseforge.com/minecraft/mc-mods/smooth-scrolling-everywhere)
* [Sound Filters](https://www.curseforge.com/minecraft/mc-mods/sound-filters) (ส่วนขยายเสียงจะใช้งานไม่ได้เมื่อมีม็อดนี้ติดตั้งอยู่)
* [Sound Physics Remastered](https://www.curseforge.com/minecraft/mc-mods/sound-physics-remastered) (ส่วนขยายเสียงจะใช้งานไม่ได้เมื่อมีม็อดนี้ติดตั้งอยู่)
* [Stylish Effects](https://www.curseforge.com/minecraft/mc-mods/stylish-effects) (เมนูหลักไม่สามารถโหลดเลย์เอาต์ได้ในครั้งแรกที่แสดง)
* [Supplementaries](https://www.curseforge.com/minecraft/mc-mods/supplementaries) (บางครั้งแครชแบบสุ่มเมื่อปรับแต่งหน้าคอนฟิกของมัน; ให้ลบเลย์เอาต์ที่มีปัญหาออกจาก `.minecraft/config/fancymenu/customization`)
* [Terraria Craft](https://www.curseforge.com/minecraft/mc-mods/terraria-craft)
* [The Dalek Mod](https://www.curseforge.com/minecraft/mc-mods/the-dalek-mod) (ใช้งานได้หากปิดเมนูหลักแบบกำหนดเองในคอนฟิก)
* [ThonkUtil](https://www.curseforge.com/minecraft/mc-mods/thonkutil) (ใช้งานได้ แต่ปัจจุบันจะเพิ่มข้อความที่ลบออกไม่ได้บนเมนูหลัก)
* [Trade Uses](https://modrinth.com/mod/trade-uses) (ทำให้แครชในเมนูซื้อขายของชาวบ้าน—อาจเกิดขึ้นเฉพาะเมื่อมีการติดตั้ง “Easy Villagers” ด้วย)
* [VanillaFix](https://www.curseforge.com/minecraft/mc-mods/vanillafix) (ใช้งานได้ แต่ผู้ใช้บางรายรายงานปัญหากับหน้าจอแครชของ VanillaFix)
* [FireplaceMode](https://www.curseforge.com/minecraft/mc-mods/fireplacemode) (หน้าจอ Pause บางครั้งจะรีเซ็ตการปรับแต่งเมื่อมีม็อดนี้ติดตั้งอยู่)
* [Respackopts](https://www.curseforge.com/minecraft/mc-mods/respackopts) (ใช้งานได้ แต่ต้องปิดการปรับแต่งสำหรับหน้าจอ Resource Pack เท่านั้น)
* [Bind Pizzeria](https://modrinth.com/mod/jjpizza) (ทำให้การเรนเดอร์ข้อความในเมนูบริบทของ FancyMenu เสีย)
* [EnhancedTooltips](https://www.curseforge.com/minecraft/mc-mods/enhancedtooltips) (ทำให้ทูลทิปของ FancyMenu เสีย)
