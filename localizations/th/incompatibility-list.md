# หน้าจอที่ปิดการปรับแต่งโดยเจตนา

FancyMenu จะบล็อกหน้าจอที่ตรงกับเส้นทางแพ็กเกจของม็อดบางรายการ เพื่อป้องกันการแครชหรือพฤติกรรมที่ผิดปกติ ตัวเลือกการปรับแต่ง โอเวอร์เลย์ และเลย์เอาต์จะไม่พร้อมใช้งานบนหน้าจอที่ตรงตามเงื่อนไข

การบล็อกเหล่านี้ใช้แพ็กเกจ Java ของคลาสหน้าจอ แทนการระบุรายชื่อหน้าจอแต่ละรายการด้วยตนเอง ดังนั้นกฎเพียงข้อเดียวจึงอาจส่งผลต่อหน้าจอหลายหน้าจอจากม็อดเดียวกันหรือแพ็กเกจที่เกี่ยวข้องกัน

กลุ่มหน้าจอที่ถูกบล็อก ได้แก่:

- Create
- Panoramica
- Alex's Mobs
- Screenshot Viewer
- Twilight Forest
- Supplementaries
- OptiFine; ให้ใช้ [ทางเลือกสำหรับ OptiFine](./optifine-alternatives)
- SlimeKnights และ Tinkers' Construct
- ม็อด MidnightDust
- SkinSwapper
- Immersive Engineering
- Dungeonz
- RPG-Hud
- Cobblemon และหน้าจอบางส่วนที่เกี่ยวข้องกับ Cobblemon
- Applied Energistics 2
- ม็อดแผนที่ของ Xaero

# ความเข้ากันไม่ได้ที่ชุมชนรายงาน

รายการด้านล่างเป็นรายงานจากชุมชน ไม่ใช่หน้าจอที่ FancyMenu บล็อกด้วยตัวเอง ความเข้ากันได้อาจเปลี่ยนแปลงไปตามเวอร์ชันของ FancyMenu, Minecraft, loader และม็อดต่าง ๆ ในแพ็ก

* [Animated Loading Screen](https://modrinth.com/mod/animated-loading-screen) (ทำให้เมนูดูเหมือนมีบั๊ก)
* [Animated Mojang Logo](https://www.curseforge.com/minecraft/mc-mods/animated-mojang-logo) (บางครั้งเลย์เอาต์จะไม่โหลด และยังทำให้ Drippy Loading Screen ใช้งานไม่ได้)
* [Bedrockify](https://www.curseforge.com/minecraft/mc-mods/bedrockify) (ใช้งานร่วมกันได้เมื่อปิดการปรับแต่งเมนูทั้งหมดของม็อดนี้ อย่างน้อยสำหรับเมนูที่คุณต้องการปรับแต่ง)
* [BetterFPS](https://www.curseforge.com/minecraft/mc-mods/betterfps) (ไม่สามารถปรับแต่งปุ่มและเมนูของม็อดนี้ได้)
* [Chat Colors](https://www.curseforge.com/minecraft/mc-mods/chat-colours) (แครชขณะเริ่มต้นเกม)
* [Chloride](https://modrinth.com/mod/chloride) (ตัวแทนค่า FPS จะไม่ทำงานเมื่อติดตั้งม็อดนี้)
* [Colormatic](https://www.curseforge.com/minecraft/mc-mods/colormatic) (ทำให้เกิดอาการหน่วงอย่างมากขณะเริ่ม Minecraft และทำให้ระบบเสียงของ FM ใช้งานไม่ได้)
* [Controllable](https://www.curseforge.com/minecraft/mc-mods/controllable) (ปุ่มแบบกำหนดเองที่เพิ่มลงในเมนูด้วย FancyMenu จะไม่สามารถคลิกผ่านฟีเจอร์ “Virtual Mouse” ของ Controllable ได้)
* [Controlify](https://modrinth.com/mod/controlify) (มีรายงานว่าแครช ดู [issue #1144](https://github.com/Keksuccino/FancyMenu/issues/1144))
* [Crash To Main Menu](https://www.curseforge.com/minecraft/mc-mods/crash-to-main-menu)
* [Custom Loading Screen](https://www.curseforge.com/minecraft/mc-mods/better-loading-screen)
* [Custom Main Menu](https://www.curseforge.com/minecraft/mc-mods/custom-main-menu)
* [Debugify](https://www.curseforge.com/minecraft/mc-mods/debugify) (ให้ใช้ [Modern Debugify](https://www.curseforge.com/minecraft/mc-mods/modern-debugify) แทน)
* [Dynamic Surroundings](https://www.curseforge.com/minecraft/mc-mods/dynamic-surroundings) (มีรายงานว่าทำให้องค์ประกอบเสียงใช้งานไม่ได้)
* [EnhancedVisuals](https://www.curseforge.com/minecraft/mc-mods/enhancedvisuals) (มีรายงานปัญหาเกี่ยวกับแอนิเมชันและพื้นหลังโปร่งแสง)
* [Entity Model Features](https://modrinth.com/mod/entity-model-features) (มีรายงานว่าแครช ดู [issue #1115](https://github.com/Keksuccino/FancyMenu/issues/1115))
* [Fossils and Archeology Revival](https://www.curseforge.com/minecraft/mc-mods/fossils) (ใช้งานในเกมได้ แต่ไม่รองรับเมนูหลักแบบกำหนดเอง—สามารถปิดใช้งานได้ในการตั้งค่า)
* [Holographic Renderers](https://www.curseforge.com/minecraft/mc-mods/holographic-renderers) (แครชขณะเริ่มต้นเกม)
* [Ice and Fire](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons) (ใช้งานได้หากปิดเมนูหลักแบบกำหนดเองในการตั้งค่า)
* [Jurassicraft](https://www.curseforge.com/minecraft/mc-mods/jurassicraft) (แครชเมื่อเริ่มเกมหากเปิดใช้การปรับแต่ง GUI ของม็อดนี้—ให้ลบรายการเหล่านั้นออกจาก `<game-directory>/config/fancymenu/customizablemenus.txt`)
* [Legacy4J](https://www.curseforge.com/minecraft/mc-mods/legacy-minecraft) (ทำให้เกมแครช)
* [MalisisCore](https://www.curseforge.com/minecraft/mc-mods/malisiscore) (ทำให้การปรับแต่งเมนูหลักใช้งานไม่ได้)
* [Main Menu Scale Mod](https://www.curseforge.com/minecraft/mc-mods/main-menu-scale)
* [MCA Reborn](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-reborn) (ใช้งานได้ แต่เมนูบางส่วนของม็อดนี้ทำให้แถบเมนูของ FM มีปัญหา และ/หรือไม่สามารถปรับแต่งได้)
* [Minecraft Comes Alive](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-mca) (มีรายงานว่าใช้งานร่วมกันได้ แต่ไม่สามารถปรับแต่งเมนูของม็อดนี้ได้)
* [MineTogether](https://www.curseforge.com/minecraft/mc-mods/creeperhost-minetogether) (มีรายงานปัญหาเกี่ยวกับเลย์เอาต์เมื่อใช้ GUI scale สูงกว่า 2)
* [Mod Menu](https://www.curseforge.com/minecraft/mc-mods/modmenu) (โดยทั่วไปใช้งานร่วมกันได้ หากปุ่ม Mods ซ้ำหรือไม่สามารถปรับแต่งได้ ให้ตั้งค่า **Main Menu -> Mods -> Mod Menu -> Mods Button** เป็น **Adjacent**)
* [Modern Online Picture Frames](https://www.curseforge.com/minecraft/mc-mods/online-picture-frame) (แครช—ดู [ปัญหานี้](https://github.com/Keksuccino/FancyMenu/issues/776))
* [Not Enough Animations](https://www.curseforge.com/minecraft/mc-mods/not-enough-animations) (มีรายงานว่าใช้งานร่วมกันได้บน 1.16 ขึ้นไป และไม่เข้ากันบน 1.12)
* [Optiscale](https://www.curseforge.com/minecraft/mc-mods/optiscale) (ทำให้ UI ของ FancyMenu ใช้งานไม่ได้ ปุ่มต่าง ๆ ไม่สามารถคลิกได้)
* [Pack Menu](https://www.curseforge.com/minecraft/mc-mods/packmenu)
* [Panorama Screens](https://modrinth.com/mod/panorama-screens) (มีรายงานว่าระบบปรับแต่งเมนูขัดแย้งกัน)
* [QuestCraft](https://github.com/QuestCraftPlusPlus/QuestCraft) (เกมไม่สามารถโหลดได้)
* [RandomPatches](https://www.curseforge.com/minecraft/mc-mods/randompatches-forge) (ใช้งานได้หากตั้งค่า `patchMinecraftClass = false` ในการตั้งค่า)
* [Remove Reloading Screen](https://www.curseforge.com/minecraft/mc-mods/rrls) (มีรายงานว่าทำให้ FancyMenu และ Drippy Loading Screen ใช้งานไม่ได้)
* [Replay Mod](https://www.replaymod.com/download/) (ใช้งานได้เมื่อตั้งค่า `mainMenuButton` เป็น **BIG** ใน `<game-directory>/config/replaymod.json`)
* [Seamless Loading Screen](https://www.curseforge.com/minecraft/mc-mods/seamless-loading-screen) (ทำให้เกมแครช)
* [Slight Gui Modifications](https://www.curseforge.com/minecraft/mc-mods/slight-gui-modifications)
* [Skin Layers 3D](https://www.curseforge.com/minecraft/mc-mods/skin-layers-3d) (มีรายงานว่าใช้งานร่วมกันได้บน 1.16 ขึ้นไป และไม่เข้ากันบน 1.12)
* [Smooth Scrolling Everywhere](https://www.curseforge.com/minecraft/mc-mods/smooth-scrolling-everywhere)
* [Sound Filters](https://www.curseforge.com/minecraft/mc-mods/sound-filters) (ส่วนขยายเสียงจะไม่ทำงานเมื่อติดตั้งม็อดนี้)
* [Sound Physics Remastered](https://www.curseforge.com/minecraft/mc-mods/sound-physics-remastered) (ส่วนขยายเสียงจะไม่ทำงานเมื่อติดตั้งม็อดนี้)
* [Stylish Effects](https://www.curseforge.com/minecraft/mc-mods/stylish-effects) (เมนูหลักจะไม่โหลดเลย์เอาต์ในครั้งแรกที่แสดง)
* [Supplementaries](https://www.curseforge.com/minecraft/mc-mods/supplementaries) (แครชแบบสุ่มขณะปรับแต่งหน้าจอการตั้งค่า ให้ลบเลย์เอาต์ที่มีปัญหาออกจาก `<game-directory>/config/fancymenu/customization/`)
* [Terraria Craft](https://www.curseforge.com/minecraft/mc-mods/terraria-craft)
* [The Dalek Mod](https://www.curseforge.com/minecraft/mc-mods/the-dalek-mod) (ใช้งานได้หากปิดเมนูหลักแบบกำหนดเองในการตั้งค่า)
* [ThonkUtil](https://www.curseforge.com/minecraft/mc-mods/thonkutil) (ใช้งานได้ แต่ขณะนี้เพิ่มข้อความที่ไม่สามารถลบออกได้ลงในเมนูหลัก)
* [Trade Uses](https://modrinth.com/mod/trade-uses) (ทำให้เมนูแลกเปลี่ยนกับชาวบ้านแครช—อาจเกิดขึ้นเฉพาะเมื่อติดตั้ง “Easy Villagers” ร่วมด้วย)
* [VanillaFix](https://www.curseforge.com/minecraft/mc-mods/vanillafix) (ใช้งานได้ แต่ผู้ใช้บางรายรายงานปัญหากับหน้าจอแครชของ VanillaFix)
* [FireplaceMode](https://www.curseforge.com/minecraft/mc-mods/fireplacemode) (หน้าจอพักเกมจะรีเซ็ตการปรับแต่งเป็นบางครั้งเมื่อติดตั้งม็อดนี้)
* [Respackopts](https://www.curseforge.com/minecraft/mc-mods/respackopts) (ใช้งานได้ แต่ต้องปิดการปรับแต่งหน้าจอ Resource Pack)
* [Bind Pizzeria](https://modrinth.com/mod/jjpizza) (ทำให้การแสดงผลข้อความในเมนูบริบทของ FancyMenu มีปัญหา)
* [EnhancedTooltips](https://www.curseforge.com/minecraft/mc-mods/enhancedtooltips) (ทำให้คำแนะนำเครื่องมือของ FancyMenu ใช้งานไม่ได้)
* [Skin Shuffle](https://modrinth.com/mod/skinshuffle) (เอนทิตีผู้เล่นที่ม็อดนี้เพิ่มลงในเมนูไม่สามารถปรับแต่งผ่าน FancyMenu ได้
* [Wakes](https://modrinth.com/mod/wakes) (ทำให้เกมแครชขณะเปิด เนื่องจาก `IncompatibleClassChangeError` — ม็อดไม่สามารถเขียนทับเมธอดสุดท้าย `AbstractSliderButton.getSprite()` ได้ ซึ่งเป็นเมธอดสุดท้ายเพียงเพราะ Wakes เปลี่ยนการมองเห็นของเมธอดดังกล่าว ดูปัญหาใน GitHub เพื่อดูข้อมูลเพิ่มเติม: [Goby56/wakes #215](https://github.com/Goby56/wakes/issues/215), [Keksuccino/FancyMenu #1733](https://github.com/Keksuccino/FancyMenu/issues/1733))
* [Essential](https://www.curseforge.com/minecraft/mc-mods/essential-mod) (ดู [หน้านี้](/essential) สำหรับข้อมูลเพิ่มเติม)
