# ความไม่เข้ากัน

# หน้าจอที่ปิดการปรับแต่งโดยตั้งใจ

FancyMenu จะบล็อกหน้าจอที่ตรงกับเส้นทางแพ็กเกจของม็อดบางรายการ เพื่อป้องกันเกมแครชหรือการทำงานที่ผิดปกติ ตัวสลับการปรับแต่ง, ภาพซ้อนทับ และเลย์เอาต์จะไม่สามารถใช้งานได้บนหน้าจอที่ตรงเงื่อนไข

การบล็อกเหล่านี้อ้างอิงจากแพ็กเกจ Java ของคลาสหน้าจอ แทนที่จะเป็นรายการหน้าจอแต่ละอันที่คัดเลือกมาแบบแมนนวล ดังนั้นกฎเพียงข้อเดียวอาจส่งผลต่อหลายหน้าจอจากม็อดเดียวกันหรือแพ็กเกจที่เกี่ยวข้องกัน

กลุ่มหน้าจอที่ถูกบล็อกได้แก่:

- Create
- Panoramica
- Alex's Mobs
- Screenshot Viewer
- Twilight Forest
- Supplementaries
- OptiFine; ให้ใช้ [OptiFine Alternatives](./optifine-alternatives)
- SlimeKnights และ Tinkers' Construct
- ม็อดของ MidnightDust
- SkinSwapper
- หน้าจอการตั้งค่าของ FancyMenu เอง; ยกเว้น [Custom GUIs](./custom-guis)
- Immersive Engineering
- Dungeonz
- RPG-Hud
- Cobblemon และหน้าจอบางส่วนที่เกี่ยวข้องกับ Cobblemon
- Applied Energistics 2
- ม็อดแผนที่ของ Xaero

# ความไม่เข้ากันที่ชุมชนรายงาน

รายการด้านล่างเป็นรายงานจากชุมชน ไม่ใช่หน้าจอที่ FancyMenu บล็อกเองโดยตรง ความเข้ากันได้อาจเปลี่ยนไปตามเวอร์ชันของ FancyMenu, Minecraft, ตัวโหลด และม็อดต่าง ๆ ในแพ็ก

* [Animated Loading Screen](https://modrinth.com/mod/animated-loading-screen) (ทำให้เมนูดูมีบั๊ก)
* [Animated Mojang Logo](https://www.curseforge.com/minecraft/mc-mods/animated-mojang-logo) (บางครั้งเลย์เอาต์จะไม่โหลด; และยังทำให้ Drippy Loading Screen ใช้งานไม่ได้ด้วย)
* [Bedrockify](https://www.curseforge.com/minecraft/mc-mods/bedrockify) (ใช้งานร่วมกันได้เมื่อปิดการแก้ไขเมนูทั้งหมดของม็อดนี้ อย่างน้อยสำหรับเมนูที่คุณต้องการปรับแต่ง)
* [BetterFPS](https://www.curseforge.com/minecraft/mc-mods/betterfps) (ปุ่มและเมนูของม็อดนี้ไม่สามารถปรับแต่งได้)
* [Chat Colors](https://www.curseforge.com/minecraft/mc-mods/chat-colours) (แครชตอนเริ่มเกม)
* [Chloride](https://modrinth.com/mod/chloride) (ตัวแปรแทน FPS จะไม่ทำงานเมื่อมีม็อดนี้ติดตั้งอยู่)
* [Colormatic](https://www.curseforge.com/minecraft/mc-mods/colormatic) (หน่วงมากตอนเริ่ม MC และทำให้ระบบเสียงของ FM ใช้งานไม่ได้)
* [Controllable](https://www.curseforge.com/minecraft/mc-mods/controllable) (ปุ่มที่เพิ่มด้วย FancyMenu จะกดไม่ได้ผ่านฟีเจอร์ “Virtual Mouse” ของ Controllable)
* [Controlify](https://modrinth.com/mod/controlify) (รายงานว่าแครช; ดู [issue #1144](https://github.com/Keksuccino/FancyMenu/issues/1144))
* [Crash To Main Menu](https://www.curseforge.com/minecraft/mc-mods/crash-to-main-menu)
* [Custom Loading Screen](https://www.curseforge.com/minecraft/mc-mods/better-loading-screen)
* [Custom Main Menu](https://www.curseforge.com/minecraft/mc-mods/custom-main-menu)
* [Debugify](https://www.curseforge.com/minecraft/mc-mods/debugify) (ให้ใช้ [Modern Debugify](https://www.curseforge.com/minecraft/mc-mods/modern-debugify) แทน)
* [Dynamic Surroundings](https://www.curseforge.com/minecraft/mc-mods/dynamic-surroundings) (มีรายงานว่าทำให้ส่วนประกอบเสียงเสีย)
* [EnhancedVisuals](https://www.curseforge.com/minecraft/mc-mods/enhancedvisuals) (มีรายงานปัญหาเรื่องแอนิเมชันและพื้นหลังโปร่งแสง)
* [Entity Model Features](https://modrinth.com/mod/entity-model-features) (รายงานว่าแครช; ดู [issue #1115](https://github.com/Keksuccino/FancyMenu/issues/1115))
* [Fossils and Archeology Revival](https://www.curseforge.com/minecraft/mc-mods/fossils) (ใช้งานในเกมได้ แต่เมนูหลักแบบกำหนดเองไม่รองรับ—สามารถปิดได้ในไฟล์คอนฟิก)
* [Holographic Renderers](https://www.curseforge.com/minecraft/mc-mods/holographic-renderers) (แครชตอนเริ่มเกม)
* [Ice and Fire](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons) (ใช้งานได้หากปิดเมนูหลักแบบกำหนดเองในคอนฟิก)
* [Jurassicraft](https://www.curseforge.com/minecraft/mc-mods/jurassicraft) (แครชตอนเริ่มหากเปิดการปรับแต่งสำหรับ GUI ของมัน—ให้ลบออกจาก `<game-directory>/config/fancymenu/customizablemenus.txt`)
* [Legacy4J](https://www.curseforge.com/minecraft/mc-mods/legacy-minecraft) (ทำให้เกมแครช)
* [MalisisCore](https://www.curseforge.com/minecraft/mc-mods/malisiscore) (ทำให้การปรับแต่งเมนูหลักเสีย)
* [Main Menu Scale Mod](https://www.curseforge.com/minecraft/mc-mods/main-menu-scale)
* [MCA Reborn](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-reborn) (ใช้งานได้ แต่เมนูบางส่วนทำให้แถบเมนูของ FM เสีย และ/หรือไม่สามารถปรับแต่งได้)
* [Minecraft Comes Alive](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-mca) (มีรายงานว่าใช้งานร่วมกันได้ แต่เมนูของมันไม่สามารถปรับแต่งได้)
* [MineTogether](https://www.curseforge.com/minecraft/mc-mods/creeperhost-minetogether) (มีรายงานปัญหาเลย์เอาต์เมื่อ GUI scale สูงกว่า 2)
* [Mod Menu](https://www.curseforge.com/minecraft/mc-mods/modmenu) (โดยทั่วไปใช้งานร่วมกันได้; หากปุ่ม Mods ซ้ำหรือปรับแต่งไม่ได้ ให้ตั้งค่า **Main Menu -> Mods -> Mod Menu -> Mods Button** เป็น **Adjacent**)
* [Modern Online Picture Frames](https://www.curseforge.com/minecraft/mc-mods/online-picture-frame) (แครช—ดู [ปัญหานี้](https://github.com/Keksuccino/FancyMenu/issues/776))
* [Not Enough Animations](https://www.curseforge.com/minecraft/mc-mods/not-enough-animations) (มีรายงานว่าใช้งานร่วมกันได้ใน 1.16+ และไม่เข้ากันใน 1.12)
* [Optiscale](https://www.curseforge.com/minecraft/mc-mods/optiscale) (ทำให้ UI ของ FancyMenu เสีย; ปุ่มกดไม่ได้)
* [Pack Menu](https://www.curseforge.com/minecraft/mc-mods/packmenu)
* [Panorama Screens](https://modrinth.com/mod/panorama-screens) (มีรายงานความขัดแย้งระหว่างระบบปรับแต่งเมนู)
* [QuestCraft](https://github.com/QuestCraftPlusPlus/QuestCraft) (เกมโหลดไม่สำเร็จ)
* [RandomPatches](https://www.curseforge.com/minecraft/mc-mods/randompatches-forge) (ใช้งานได้หากตั้ง `patchMinecraftClass = false` ในคอนฟิก)
* [Remove Reloading Screen](https://www.curseforge.com/minecraft/mc-mods/rrls) (มีรายงานว่าทำให้ FancyMenu และ Drippy Loading Screen เสีย)
* [Replay Mod](https://www.replaymod.com/download/) (ใช้งานได้เมื่อคุณตั้ง `mainMenuButton` เป็น **BIG** ใน `<game-directory>/config/replaymod.json`)
* [Seamless Loading Screen](https://www.curseforge.com/minecraft/mc-mods/seamless-loading-screen) (ทำให้เกมแครช)
* [Slight Gui Modifications](https://www.curseforge.com/minecraft/mc-mods/slight-gui-modifications)
* [Skin Layers 3D](https://www.curseforge.com/minecraft/mc-mods/skin-layers-3d) (มีรายงานว่าใช้งานร่วมกันได้ใน 1.16+ และไม่เข้ากันใน 1.12)
* [Smooth Scrolling Everywhere](https://www.curseforge.com/minecraft/mc-mods/smooth-scrolling-everywhere)
* [Sound Filters](https://www.curseforge.com/minecraft/mc-mods/sound-filters) (ส่วนขยายเสียงจะไม่ทำงานเมื่อมีม็อดนี้ติดตั้งอยู่)
* [Sound Physics Remastered](https://www.curseforge.com/minecraft/mc-mods/sound-physics-remastered) (ส่วนขยายเสียงจะไม่ทำงานเมื่อมีม็อดนี้ติดตั้งอยู่)
* [Stylish Effects](https://www.curseforge.com/minecraft/mc-mods/stylish-effects) (เมนูหลักจะโหลดเลย์เอาต์ไม่สำเร็จในครั้งแรกที่แสดง)
* [Supplementaries](https://www.curseforge.com/minecraft/mc-mods/supplementaries) (บางครั้งแครชแบบสุ่มเมื่อปรับแต่งหน้าจอคอนฟิกของมัน; ให้ลบเลย์เอาต์ที่มีปัญหาออกจาก `<game-directory>/config/fancymenu/customization/`)
* [Terraria Craft](https://www.curseforge.com/minecraft/mc-mods/terraria-craft)
* [The Dalek Mod](https://www.curseforge.com/minecraft/mc-mods/the-dalek-mod) (ใช้งานได้หากปิดเมนูหลักแบบกำหนดเองในคอนฟิก)
* [ThonkUtil](https://www.curseforge.com/minecraft/mc-mods/thonkutil) (ใช้งานได้ แต่ปัจจุบันเพิ่มข้อความที่ลบไม่ได้ไว้ในเมนูหลัก)
* [Trade Uses](https://modrinth.com/mod/trade-uses) (ทำให้แครชในเมนูแลกเปลี่ยนของชาวบ้าน—อาจเกิดขึ้นเฉพาะเมื่อมีการติดตั้ง “Easy Villagers” ด้วย)
* [VanillaFix](https://www.curseforge.com/minecraft/mc-mods/vanillafix) (ใช้งานได้ แต่ผู้ใช้บางรายรายงานปัญหากับหน้าจอแครชของ VanillaFix)
* [FireplaceMode](https://www.curseforge.com/minecraft/mc-mods/fireplacemode) (หน้าจอ Pause จะรีเซ็ตการปรับแต่งเป็นบางครั้งเมื่อมีม็อดนี้ติดตั้งอยู่)
* [Respackopts](https://www.curseforge.com/minecraft/mc-mods/respackopts) (ใช้งานได้ แต่ต้องปิดการปรับแต่งสำหรับหน้าจอ Resource Pack)
* [Bind Pizzeria](https://modrinth.com/mod/jjpizza) (ทำให้การเรนเดอร์ข้อความในเมนูบริบทของ FancyMenu เสีย)
* [EnhancedTooltips](https://www.curseforge.com/minecraft/mc-mods/enhancedtooltips) (ทำให้ทูลทิปของ FancyMenu เสีย)
* [Skin Shuffle](https://modrinth.com/mod/skinshuffle) (เอนทิตีผู้เล่นที่ม็อดนี้เพิ่มเข้าไปในเมนูไม่สามารถปรับแต่งผ่าน FancyMenu ได้)
