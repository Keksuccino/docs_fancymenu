# หน้าจอที่ปิดใช้การปรับแต่งโดยตั้งใจ

FancyMenu จะบล็อกหน้าจอที่ตรงกับพาธแพ็กเกจของม็อดบางรายการ เพื่อป้องกันเกมแครชหรือทำงานผิดปกติ หน้าจอที่ตรงกับเงื่อนไขเหล่านี้จะไม่สามารถใช้ปุ่มสลับการปรับแต่ง โอเวอร์เลย์ และเลย์เอาต์ได้

การบล็อกเหล่านี้อ้างอิงแพ็กเกจ Java ของคลาสหน้าจอ แทนการระบุรายชื่อหน้าจอแต่ละหน้าไว้เอง ดังนั้นกฎเพียงข้อเดียวจึงอาจมีผลกับหน้าจอหลายหน้าจอจากม็อดเดียวกันหรือแพ็กเกจที่เกี่ยวข้องกัน

กลุ่มหน้าจอที่ถูกบล็อก ได้แก่:

- Create
- Panoramica
- Alex's Mobs
- Screenshot Viewer
- Twilight Forest
- Supplementaries
- OptiFine; ใช้ [ทางเลือกอื่นแทน OptiFine](/optifine-alternatives)
- SlimeKnights และ Tinkers' Construct
- ม็อด MidnightDust
- SkinSwapper
- Immersive Engineering
- Dungeonz
- RPG-Hud
- Cobblemon และหน้าจอบางส่วนที่เกี่ยวข้องกับ Cobblemon
- Applied Energistics 2
- ม็อดแผนที่ของ Xaero

# ความเข้ากันไม่ได้ที่ชุมชนรายงาน

รายการด้านล่างเป็นรายงานจากชุมชน ไม่ใช่หน้าจอที่ FancyMenu บล็อกเอง ความเข้ากันได้อาจเปลี่ยนไปตามเวอร์ชันของ FancyMenu, Minecraft, ตัวโหลดม็อด และม็อดต่าง ๆ ในแพ็ก

* [Animated Loading Screen](https://modrinth.com/mod/animated-loading-screen) (ทำให้เมนูดูเหมือนมีข้อผิดพลาด)
* [Animated Mojang Logo](https://www.curseforge.com/minecraft/mc-mods/animated-mojang-logo) (บางครั้งเลย์เอาต์ไม่โหลด และยังทำให้ Drippy Loading Screen ทำงานผิดปกติ)
* [Bedrockify](https://www.curseforge.com/minecraft/mc-mods/bedrockify) (ใช้งานร่วมกันได้เมื่อปิดการปรับแต่งเมนูทั้งหมดของม็อดนี้ อย่างน้อยก็สำหรับเมนูที่ต้องการปรับแต่ง)
* [BetterFPS](https://www.curseforge.com/minecraft/mc-mods/betterfps) (ไม่สามารถปรับแต่งปุ่มและเมนูของม็อดนี้ได้)
* [Chat Colors](https://www.curseforge.com/minecraft/mc-mods/chat-colours) (เกมแครชขณะเริ่มต้น)
* [Chloride](https://modrinth.com/mod/chloride) (ตัวแทนข้อความ FPS ใช้งานไม่ได้เมื่อติดตั้งม็อดนี้)
* [Colormatic](https://www.curseforge.com/minecraft/mc-mods/colormatic) (ทำให้เกมกระตุกอย่างมากขณะเริ่ม Minecraft และทำให้ระบบเสียงของ FM ทำงานผิดปกติ)
* [Controllable](https://www.curseforge.com/minecraft/mc-mods/controllable) (ไม่สามารถคลิกปุ่มที่เพิ่มลงในเมนูด้วย FancyMenu ผ่านฟีเจอร์ “Virtual Mouse” ของ Controllable ได้)
* [Controlify](https://modrinth.com/mod/controlify) (มีรายงานว่าเกมแครช ดู [ปัญหา #1144](https://github.com/Keksuccino/FancyMenu/issues/1144))
* [Crash To Main Menu](https://www.curseforge.com/minecraft/mc-mods/crash-to-main-menu)
* [Custom Loading Screen](https://www.curseforge.com/minecraft/mc-mods/better-loading-screen)
* [Custom Main Menu](https://www.curseforge.com/minecraft/mc-mods/custom-main-menu)
* [Debugify](https://www.curseforge.com/minecraft/mc-mods/debugify) (ให้ใช้ [Modern Debugify](https://www.curseforge.com/minecraft/mc-mods/modern-debugify) แทน)
* [Dynamic Surroundings](https://www.curseforge.com/minecraft/mc-mods/dynamic-surroundings) (มีรายงานว่าทำให้องค์ประกอบเสียงทำงานผิดปกติ)
* [EnhancedVisuals](https://www.curseforge.com/minecraft/mc-mods/enhancedvisuals) (มีรายงานปัญหาเกี่ยวกับแอนิเมชันและพื้นหลังโปร่งแสง)
* [Entity Model Features](https://modrinth.com/mod/entity-model-features) (มีรายงานว่าเกมแครช ดู [ปัญหา #1115](https://github.com/Keksuccino/FancyMenu/issues/1115))
* [Fossils and Archeology Revival](https://www.curseforge.com/minecraft/mc-mods/fossils) (ใช้งานในเกมได้ แต่ไม่รองรับเมนูหลักแบบกำหนดเอง ซึ่งปิดได้ในการตั้งค่าของม็อด)
* [Holographic Renderers](https://www.curseforge.com/minecraft/mc-mods/holographic-renderers) (เกมแครชขณะเริ่มต้น)
* [Ice and Fire](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons) (ใช้งานได้หากปิดเมนูหลักแบบกำหนดเองในการตั้งค่าของม็อด)
* [Jurassicraft](https://www.curseforge.com/minecraft/mc-mods/jurassicraft) (เกมแครชตอนเริ่มต้นเมื่อเปิดการปรับแต่ง GUI ของม็อดนี้—ลบรายการเหล่านั้นออกจาก `<game-directory>/config/fancymenu/customizablemenus.txt`)
* [Legacy4J](https://www.curseforge.com/minecraft/mc-mods/legacy-minecraft) (ทำให้เกมแครช)
* [MalisisCore](https://www.curseforge.com/minecraft/mc-mods/malisiscore) (ทำให้การปรับแต่งเมนูหลักทำงานผิดปกติ)
* [Main Menu Scale Mod](https://www.curseforge.com/minecraft/mc-mods/main-menu-scale)
* [MCA Reborn](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-reborn) (ใช้งานได้ แต่เมนูบางส่วนทำให้แถบเมนูของ FM ทำงานผิดปกติ และ/หรือไม่สามารถปรับแต่งได้)
* [Minecraft Comes Alive](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-mca) (มีรายงานว่าใช้งานร่วมกันได้ แต่ไม่สามารถปรับแต่งเมนูของม็อดนี้ได้)
* [MineTogether](https://www.curseforge.com/minecraft/mc-mods/creeperhost-minetogether) (มีรายงานปัญหาเลย์เอาต์เมื่อใช้ GUI scale สูงกว่า 2)
* [Mod Menu](https://www.curseforge.com/minecraft/mc-mods/modmenu) (โดยทั่วไปใช้งานร่วมกันได้ หากปุ่ม Mods ซ้ำหรือปรับแต่งไม่ได้ ให้ตั้งค่า **Main Menu -> Mods -> Mod Menu -> Mods Button** เป็น **Adjacent**)
* [Modern Online Picture Frames](https://www.curseforge.com/minecraft/mc-mods/online-picture-frame) (เกมแครช—ดู [ปัญหานี้](https://github.com/Keksuccino/FancyMenu/issues/776))
* [Not Enough Animations](https://www.curseforge.com/minecraft/mc-mods/not-enough-animations) (มีรายงานว่าใช้ได้กับเวอร์ชัน 1.16 ขึ้นไป และใช้ไม่ได้กับเวอร์ชัน 1.12)
* [Optiscale](https://www.curseforge.com/minecraft/mc-mods/optiscale) (ทำให้ UI ของ FancyMenu ทำงานผิดปกติ โดยปุ่มจะคลิกไม่ได้)
* [Pack Menu](https://www.curseforge.com/minecraft/mc-mods/packmenu)
* [Panorama Screens](https://modrinth.com/mod/panorama-screens) (มีรายงานว่าระบบปรับแต่งเมนูขัดแย้งกัน)
* [QuestCraft](https://github.com/QuestCraftPlusPlus/QuestCraft) (เกมโหลดไม่สำเร็จ)
* [RandomPatches](https://www.curseforge.com/minecraft/mc-mods/randompatches-forge) (ใช้งานได้หากตั้งค่า `patchMinecraftClass = false` ในการตั้งค่าของม็อด)
* [Remove Reloading Screen](https://www.curseforge.com/minecraft/mc-mods/rrls) (มีรายงานว่าทำให้ FancyMenu และ Drippy Loading Screen ทำงานผิดปกติ)
* [Replay Mod](https://www.replaymod.com/download/) (ใช้งานได้เมื่อตั้งค่า `mainMenuButton` เป็น **BIG** ใน `<game-directory>/config/replaymod.json`)
* [Seamless Loading Screen](https://www.curseforge.com/minecraft/mc-mods/seamless-loading-screen) (ทำให้เกมแครช)
* [Slight Gui Modifications](https://www.curseforge.com/minecraft/mc-mods/slight-gui-modifications)
* [Skin Layers 3D](https://www.curseforge.com/minecraft/mc-mods/skin-layers-3d) (มีรายงานว่าใช้ได้กับเวอร์ชัน 1.16 ขึ้นไป และใช้ไม่ได้กับเวอร์ชัน 1.12)
* [Smooth Scrolling Everywhere](https://www.curseforge.com/minecraft/mc-mods/smooth-scrolling-everywhere)
* [Sound Filters](https://www.curseforge.com/minecraft/mc-mods/sound-filters) (ส่วนเสริมเสียงจะใช้งานไม่ได้เมื่อติดตั้งม็อดนี้)
* [Sound Physics Remastered](https://www.curseforge.com/minecraft/mc-mods/sound-physics-remastered) (ส่วนเสริมเสียงจะใช้งานไม่ได้เมื่อติดตั้งม็อดนี้)
* [Stylish Effects](https://www.curseforge.com/minecraft/mc-mods/stylish-effects) (เมนูหลักโหลดเลย์เอาต์ไม่สำเร็จในครั้งแรกที่แสดง)
* [Supplementaries](https://www.curseforge.com/minecraft/mc-mods/supplementaries) (เกมแครชเป็นครั้งคราวขณะปรับแต่งหน้าจอตั้งค่าของม็อดนี้ ให้ลบเลย์เอาต์ที่มีปัญหาออกจาก `<game-directory>/config/fancymenu/customization/`)
* [Terraria Craft](https://www.curseforge.com/minecraft/mc-mods/terraria-craft)
* [The Dalek Mod](https://www.curseforge.com/minecraft/mc-mods/the-dalek-mod) (ใช้งานได้หากปิดเมนูหลักแบบกำหนดเองในการตั้งค่าของม็อด)
* [ThonkUtil](https://www.curseforge.com/minecraft/mc-mods/thonkutil) (ใช้งานได้ แต่ขณะนี้เพิ่มข้อความที่ลบออกไม่ได้ในเมนูหลัก)
* [Trade Uses](https://modrinth.com/mod/trade-uses) (ทำให้เกมแครชในเมนูแลกเปลี่ยนของชาวบ้าน—อาจเกิดขึ้นเฉพาะเมื่อติดตั้ง “Easy Villagers” ด้วย)
* [VanillaFix](https://www.curseforge.com/minecraft/mc-mods/vanillafix) (ใช้งานได้ แต่มีผู้ใช้บางรายรายงานปัญหาเกี่ยวกับหน้าจอแครชของ VanillaFix)
* [FireplaceMode](https://www.curseforge.com/minecraft/mc-mods/fireplacemode) (หน้าจอ Pause อาจรีเซ็ตการปรับแต่งเป็นครั้งคราวเมื่อติดตั้งม็อดนี้)
* [Respackopts](https://www.curseforge.com/minecraft/mc-mods/respackopts) (ใช้งานได้ แต่ต้องปิดการปรับแต่งหน้าจอ Resource Pack)
* [Bind Pizzeria](https://modrinth.com/mod/jjpizza) (ทำให้การแสดงผลข้อความในเมนูบริบทของ FancyMenu ทำงานผิดปกติ)
* [EnhancedTooltips](https://www.curseforge.com/minecraft/mc-mods/enhancedtooltips) (ทำให้คำแนะนำเครื่องมือของ FancyMenu ทำงานผิดปกติ)
* [Skin Shuffle](https://modrinth.com/mod/skinshuffle) (ไม่สามารถปรับแต่งเอนทิตีผู้เล่นที่ม็อดนี้เพิ่มลงในเมนูผ่าน FancyMenu ได้)
* [Wakes](https://modrinth.com/mod/wakes) (เกมแครชตอนเปิดใช้งานเนื่องจาก `IncompatibleClassChangeError` — ม็อดไม่สามารถแทนที่เมธอดสุดท้าย `AbstractSliderButton.getSprite()` ได้ ซึ่งเมธอดนี้เป็นเมธอดสุดท้ายเพราะ Wakes เปลี่ยนการมองเห็นของเมธอด ดูข้อมูลเพิ่มเติมได้ในปัญหาบน GitHub: [Goby56/wakes #215](https://github.com/Goby56/wakes/issues/215), [Keksuccino/FancyMenu #1733](https://github.com/Keksuccino/FancyMenu/issues/1733))
* [Essential](https://www.curseforge.com/minecraft/mc-mods/essential) (ดูข้อมูลเพิ่มเติมได้ที่ [หน้านี้](/essential))
