# การแสดงองค์ประกอบ

องค์ประกอบไม่จำเป็นต้องแสดงอยู่ตลอดเวลา คุณสามารถกำหนดให้แสดงเฉพาะในบางสถานการณ์ ให้ปรากฏช้าลงเล็กน้อย เฟดเข้าและออก หรือเปิดและปิดด้วยปุ่มก็ได้

<img width="800" alt="ข้อความต้อนรับค่อย ๆ ปรากฏขึ้นไม่กี่วินาทีหลังจากเปิดหน้าจอ จากนั้นปุ่มกฎเซิร์ฟเวอร์จะเฟดแผงกฎเข้าและออก" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/element_visibility_toggle.gif?raw=true">

ในตัวแก้ไขเลย์เอาต์ องค์ประกอบจะแสดงอยู่เสมอ เพื่อให้คุณแก้ไขได้ ทุกอย่างในหน้านี้จะมีผลนอกตัวแก้ไข

> [!TIP]
> ดูข้อกำหนดทั้งหมดได้ที่ [ข้อกำหนด](/conditions)

# แสดงองค์ประกอบเฉพาะบางเวลา

คลิกขวาที่องค์ประกอบ แล้วคลิก **ข้อกำหนดการโหลด** องค์ประกอบจะแสดงก็ต่อเมื่อเป็นไปตาม[ข้อกำหนด](/conditions)ทั้งหมด เช่น “เมาส์อยู่เหนือปุ่มนี้”, “เป็นเดือนธันวาคม” หรือ “ตัวแปรมีค่านี้” FancyMenu จะตรวจสอบข้อกำหนดตลอดเวลา องค์ประกอบจึงแสดงหรือซ่อนได้ทันที

- **โหมดข้อกำหนด** ตัวเลือกตรงข้ามจะกลับเงื่อนไขของข้อกำหนด เช่น “ไม่ใช่เดือนธันวาคม”
- ใช้กลุ่มเพื่อกำหนดเงื่อนไขแบบ “สิ่งนี้ หรือ สิ่งนั้น”
- องค์ประกอบดั้งเดิมของเกมก็มี **ข้อกำหนดการโหลด** เช่นกัน หากต้องการลบองค์ประกอบนั้นทั้งหมด โปรดดูที่ [องค์ประกอบดั้งเดิมที่ถูกลบ](/deleted-vanilla-elements)

วิธีเพิ่มข้อกำหนดและรวมข้อกำหนดเข้าด้วยกัน: [ข้อกำหนด](/conditions#adding-a-requirement)

## โหลดเพียงครั้งเดียวต่อเซสชัน

คลิกขวาที่องค์ประกอบ แล้วเปิดใช้ **โหลดเพียงครั้งเดียวต่อเซสชัน** องค์ประกอบจะแสดงในครั้งแรกที่เปิดหน้าจอ หลังจากผู้เล่นไปยังหน้าจออื่นแล้ว องค์ประกอบจะซ่อนอยู่จนกว่าจะเริ่มเกมใหม่

เหมาะสำหรับคำแนะนำที่ควรแสดงเพียงครั้งเดียวต่อการเริ่มเกม เช่น “กด F1 เพื่อดูปุ่มควบคุม” หากต้องการใช้แนวคิดเดียวกันในสคริปต์การกระทำ ให้ใช้ข้อกำหนด [**เพียงครั้งเดียวต่อเซสชัน**](/conditions#only-once-per-session)

# หน่วงเวลาการแสดงองค์ประกอบ

## หน่วงเวลาการปรากฏ

คลิกขวาที่องค์ประกอบ แล้วคลิก **หน่วงเวลาการปรากฏ**:

- **การหน่วงเวลา**:
  - **ไม่หน่วงเวลา**: แสดงทันที
  - **ครั้งแรกเท่านั้น**: หน่วงเวลาเฉพาะครั้งแรกที่องค์ประกอบแสดงหลังเริ่มเกม
  - **ทุกครั้ง**: หน่วงเวลาทุกครั้งที่เปิดหน้าจอ และทุกครั้งที่ข้อกำหนดเป็นจริงอีกครั้ง
- **หน่วงเวลาเป็นวินาที**: ระยะเวลาที่หน่วง เช่น `1.5`

การปรับขนาดหน้าต่างจะไม่เริ่มนับเวลาหน่วงใหม่

## หน่วงเวลาการหายไป

คลิกขวาที่องค์ประกอบ แล้วคลิก **หน่วงเวลาการหายไป** เมื่อข้อกำหนดไม่เป็นจริงอีกต่อไป องค์ประกอบจะยังคงแสดงต่อไปตามจำนวนวินาทีที่กำหนดใน **หน่วงเวลาเป็นวินาที** ก่อนจะหายไป ตัวเลือก **การหน่วงเวลา** มีตัวเลือกเหมือนกับด้านบน

ตัวอย่างเช่น กล่องข้อมูลที่มีข้อกำหนด [**เมาส์ชี้อยู่บนองค์ประกอบ**](/conditions#is-element-hovered) ของปุ่ม จะยังแสดงอยู่ต่ออีก 1 วินาทีหลังจากเลื่อนเมาส์ออกจากปุ่ม

# เฟดเข้าและออก

คลิกขวาที่องค์ประกอบ แล้วคลิก **เฟดเข้า/ออก**:

- **เฟดเข้า** และ **เฟดออก**:
  - **ไม่เฟด**: แสดงหรือซ่อนทันที
  - **ครั้งเดียวเท่านั้น**: เฟดเฉพาะครั้งแรกหลังเริ่มเกม
  - **ทุกครั้ง**: เฟดทุกครั้ง
- **ความเร็วในการเฟดเข้า** และ **ความเร็วในการเฟดออก**: ที่ค่า `1` การเฟดจะใช้เวลา 2.5 วินาที ค่า `2` จะเร็วขึ้นสองเท่า

องค์ประกอบจะเฟดเข้าเมื่อเปิดหน้าจอและเมื่อข้อกำหนดเป็นจริง หากใช้ **หน่วงเวลาการปรากฏ** การเฟดจะเริ่มหลังจากหมดเวลาหน่วง

การเฟดออกจะเกิดขึ้นเมื่อข้อกำหนดทำให้องค์ประกอบซ่อนเท่านั้น ไม่เกิดขึ้นเมื่อปิดหน้าจอ

# ความทึบแสง

คลิกขวาที่องค์ประกอบ แล้วคลิก **ความทึบแสง**: `1.0` คือมองเห็นได้เต็มที่, `0.5` คือโปร่งใสครึ่งหนึ่ง และ `0.0` คือมองไม่เห็น องค์ประกอบส่วนใหญ่มีตัวเลือกนี้

ความทึบแสงรองรับ[ตัวยึดตำแหน่ง](/placeholders)และ[ตัวแปร](/variables) เช่น `$$panel_opacity` การเฟดเข้าจะหยุดที่ค่าความทึบแสงขององค์ประกอบ

# สลับการแสดงองค์ประกอบด้วยปุ่ม

ปุ่มสามารถใช้แสดงและซ่อนองค์ประกอบได้ เช่น แผงกฎใน GIF ด้านบน โดยใช้[ตัวแปร](/variables)จดจำว่าแผงกำลังแสดงอยู่หรือไม่

1. คลิกขวาที่แผง แล้วคลิก **ข้อกำหนดการโหลด** เพิ่ม [**ค่าตัวแปรตรงตามที่กำหนด (ตัวแปร FM)**](/conditions#is-variable-value-fm-variable) โดยใช้ตัวแปร `show_rules` และค่า `true`
2. คลิกขวาที่ปุ่ม แล้วคลิก **แก้ไขสคริปต์การกระทำ**
3. คลิกขวาที่บริเวณสคริปต์ แล้วคลิก **เพิ่มคำสั่ง IF** กำหนดข้อกำหนดให้เหมือนกับของแผง
4. เพิ่ม [**ตั้งค่าตัวแปร (ตัวแปร FM)**](/action-scripts#set-variable-value-fm-variable) ภายใน IF โดยใช้ค่านี้:

   ```
   show_rules:false
   ```

5. คลิกขวาที่ IF แล้วคลิก **เพิ่มคำสั่ง ELSE ต่อท้าย** เพิ่ม **ตั้งค่าตัวแปร (ตัวแปร FM)** ภายใน ELSE โดยใช้ค่านี้:

   ```
   show_rules:true
   ```

ดังนั้นทุกครั้งที่คลิก ตัวแปรจะสลับค่า: แผงที่แสดงอยู่จะถูกซ่อน ส่วนแผงที่ซ่อนอยู่จะแสดง องค์ประกอบทั้งหมดที่ใช้ข้อกำหนดเดียวกันจะแสดงและซ่อนไปพร้อมกัน หากต้องการให้ดูราบรื่น ให้ตั้งค่า **เฟดเข้า** และ **เฟดออก** ของแผงเป็น **ทุกครั้ง**

ดูข้อมูลเพิ่มเติมเกี่ยวกับ IF และ ELSE ได้ที่ [สคริปต์การกระทำ](/action-scripts#if-else-if-and-else)

> [!NOTE]
> ตัวแปรจะยังคงอยู่หลังจากปิดเกม ดังนั้นแผงจะยังเปิดอยู่เมื่อเริ่มเกมครั้งถัดไป หากต้องการปิดแผงทุกครั้งที่เริ่มเกม ให้คลิกขวาที่ตัวแปรใน **จัดการตัวแปร** แล้วเปิดใช้ **ล้างตัวแปรเมื่อเริ่มเกม**

## สลับไปมาระหว่างหลายเวอร์ชัน

ปุ่มยังสามารถสลับระหว่างเวอร์ชันมากกว่าสองแบบได้ เช่น พื้นหลังสามแบบ:

1. ไปที่ **แถบเมนู -> การปรับแต่ง -> จัดการตัวแปร** แล้วเพิ่มตัวแปรข้อความ `background` โดยกำหนดค่าเป็น `0`
2. กำหนดข้อกำหนด [องค์ประกอบรูปภาพ](/elements#image) ทั้งสามรายการเป็น **ค่าตัวแปรตรงตามที่กำหนด (ตัวแปร FM)** สำหรับ `background` โดยใช้ค่า `0`, `1` และ `2`
3. กำหนดให้ปุ่มใช้ **ตั้งค่าตัวแปร (ตัวแปร FM)** ด้วยค่านี้ ซึ่งจะนับจาก `0` ไป `1` ไป `2` แล้วเริ่มที่ `0` อีกครั้ง:

   ```
   background:{"placeholder":"calc","values":{"decimal":"false","expression":"({"placeholder":"getvariable","values":{"name":"background"}} + 1) % 3"}}
   ```

หากต้องการเพิ่มเวอร์ชัน ให้เปลี่ยนเลข `3` ที่ท้าย ดูวิธีคำนวณได้ที่ [**เครื่องคำนวณ**](/placeholders#calculator)

# เปิดและปิดเลย์เอาต์

หากต้องการแสดงหรือซ่อนทั้งเลย์เอาต์:

- **ข้อกำหนดการโหลด [ใช้กับทั้งเลย์เอาต์]** ในเมนูคลิกขวาของพื้นหลังตัวแก้ไขทำงานเหมือนกับข้อกำหนดขององค์ประกอบ ดูที่ [ข้อกำหนดที่ใช้กับทั้งเลย์เอาต์](/conditions#layout-wide-requirements)
- การกระทำ [**สลับเลย์เอาต์**](/action-scripts#toggle-layout), [**เปิดใช้เลย์เอาต์**](/action-scripts#enable-layout) และ [**ปิดใช้เลย์เอาต์**](/action-scripts#disable-layout) จะเปิดและปิดเลย์เอาต์ตามชื่อ

วางปุ่มไว้ในเลย์เอาต์อื่น ไม่ใช่เลย์เอาต์ที่ปุ่มจะปิด มิฉะนั้นปุ่มจะหายไปพร้อมกับเลย์เอาต์ และจะไม่มีอะไรเปิดเลย์เอาต์นั้นกลับมาได้
