# องค์ประกอบข้อความ Splash แบบกำหนดเอง

องค์ประกอบ Splash Text ใน FancyMenu เป็นการอัปเกรดแบบปรับแต่งได้เต็มรูปแบบจากข้อความ splash กระเด้งของ Minecraft โดยยังคงความคุ้นเคยของการเด้งไปมาไว้ แต่ให้คุณควบคุมได้ว่าจะให้แสดงอะไร หน้าตาเป็นอย่างไร และจะอัปเดตเมื่อใด

> [!WARNING]
> โปรดทราบว่าคุณไม่สามารถปรับแต่งองค์ประกอบ Vanilla Splash Text ดั้งเดิมในหน้าจอ Title ได้จริง ๆ ดังนั้นคุณควร **ลบ** มันออก แล้วใช้องค์ประกอบ Splash Text แบบกำหนดเองแทน

## การเพิ่มและเลือกองค์ประกอบ
- เปิดตัวแก้ไขเลย์เอาต์ แล้วเพิ่มองค์ประกอบที่ชื่อ `Splash Text`
- คลิกซ้ายหนึ่งครั้งเพื่อเลือกและแสดงกรอบขอบเขต จากนั้นคลิกขวาเพื่อเปิดเมนูบริบท ตัวเลือกการตั้งค่าทั้งหมดจะอยู่ในเมนูนั้น

## การเลือกแหล่งที่มาของ Splash Text
- `Source Mode: Vanilla` จะใช้ข้อความ splash แบบสุ่มคลาสสิกที่มากับ Minecraft
- `Source Mode: Direct Input` ให้คุณป้อนข้อความของคุณเองผ่าน `Input Splash Text` ได้ รองรับเพียงหนึ่งบรรทัดของ splash text แต่บรรทัดนั้นสามารถมี placeholder ได้
- `Source Mode: Text File` จะดึงหนึ่งบรรทัดแบบสุ่มจากไฟล์ `.txt` ที่คุณเลือกด้วย `Set Source Text File` แต่ละบรรทัดที่ไม่ว่างสามารถกลายเป็น splash ที่ใช้งานอยู่ได้
- การสลับโหมดจะรีเซ็ตข้อความที่ใช้งานอยู่ เพื่อให้คุณทดลองได้อย่างปลอดภัย หากรู้สึกว่าข้อความค้างอยู่ ให้สลับไปโหมดอื่นหรือคลิก `Refresh On Screen Load: Enabled` เพื่อบังคับสุ่มใหม่ทุกครั้งที่เปิดเมนู

## ตัวอย่างไฟล์ข้อความ
เมื่อใช้โหมดแหล่งที่มาแบบ "Text File" ให้บันทึกรายการ splash ของคุณเป็นข้อความธรรมดา (UTF-8 without BOM) แต่ละบรรทัดคือ splash ที่เป็นไปได้:

```
Welcome to FancyMenu!
{"placeholder":"your_placeholder_id_here"}
{"text":"This is gold and bold text.","color":"gold","bold":true}
&6Use &lMinecraft formatting codes!
```

แทนที่ `your_placeholder_id_here` ด้วย placeholder ที่คุณต้องการให้ประมวลผลขณะรัน FancyMenu จะเลือกหนึ่งบรรทัดที่ไม่ว่างแบบสุ่มทุกครั้งที่มีการรีเฟรช splash

## การทำให้ดูตามที่คุณต้องการ
- ใช้ `Set Scale` และ `Set Rotation` เพื่อควบคุมขนาดและมุมการหมุน
- `Set Text Color` รองรับค่าสีแบบ hex (เช่น `#FFFF00`) เพื่อให้เข้ากับธีมของคุณ
- `Shadow: Enabled` จะเพิ่มเงาตกของ Minecraft; ปิดเพื่อให้เป็นข้อความแบบเรียบ
- `Bouncing: Enabled` จะคงการเด้งไปมาแบบคุ้นเคยไว้; ปิดเพื่อให้เป็นป้ายแบบคงที่
- FancyMenu เรนเดอร์ splash เป็น Minecraft component แบบเต็มรูปแบบ ดังนั้นรหัสสีและการตกแต่งข้อความอื่น ๆ จึงใช้งานได้ตามปกติ

## ฟีเจอร์ข้อความแบบไดนามิก
- Placeholder จะถูกแทนค่าก่อนการเรนเดอร์ ดังนั้นคุณสามารถอ้างอิงชื่อผู้เล่น วันที่ หรือค่าที่รองรับอื่น ๆ ภายในข้อความ splash ได้
- เนื่องจากองค์ประกอบนี้รองรับ Minecraft serialized component JSON คุณจึงสามารถวาง JSON ขั้นสูงลงใน Direct Input หรือไฟล์ข้อความของคุณได้ องค์ประกอบจะ deserialize โดยอัตโนมัติ และจะกลับไปใช้ข้อความตัวอักษรธรรมดาหากมีบางอย่างผิดพลาด

## การแก้ปัญหา
- หากใส่ข้อความว่างใน Direct Input จะเห็น `< empty splash element >` ระหว่างแก้ไข ให้ป้อนอะไรบางอย่างเข้าไป (แม้แต่ช่องว่าง) เพื่อปิดคำเตือน
- หากไฟล์ข้อความไม่มีบรรทัดที่ใช้งานได้ องค์ประกอบจะแสดง `ERROR: SPLASH FILE IS EMPTY` ให้เพิ่มอย่างน้อยหนึ่งบรรทัดที่ไม่ว่างแล้วเปิดหน้าจอใหม่
- ข้อผิดพลาดของ serialized JSON จะย้อนกลับไปใช้ข้อความธรรมดา ใช้โครงสร้าง JSON มาตรฐานของ Mojang หรือทดสอบสไนปเป็ตด้วยคำสั่ง vanilla `/tellraw` ก่อนวาง
