# องค์ประกอบข้อความ Splash แบบกำหนดเอง

องค์ประกอบ Splash Text ใน FancyMenu คือการอัปเกรดข้อความ splash แบบเด้งของ Minecraft ที่ปรับแต่งได้อย่างสมบูรณ์ มันยังคงการเด้งแบบคุ้นเคยไว้ แต่ให้คุณควบคุมได้ว่าจะแสดงอะไร หน้าตาเป็นอย่างไร และจะอัปเดตเมื่อใด

> โปรดทราบว่าคุณไม่สามารถปรับแต่งองค์ประกอบ Vanilla Splash Text เดิมในหน้าจอ Title ได้จริง ดังนั้นคุณควร **ลบ** มันออก แล้วใช้ Splash Text แบบกำหนดเองแทน
{.is-warning}

## การเพิ่มและเลือกองค์ประกอบ
- เปิดตัวแก้ไขเลย์เอาต์ แล้วเพิ่มองค์ประกอบที่ชื่อ `Splash Text`
- คลิกซ้ายหนึ่งครั้งเพื่อเลือกและแสดงกรอบขอบเขต จากนั้นคลิกขวาเพื่อเปิดเมนูบริบท ตัวเลือกการตั้งค่าทั้งหมดอยู่ในเมนูนั้น

## การเลือกแหล่งที่มาของ Splash Text
- `Source Mode: Vanilla` จะใช้ข้อความ splash แบบสุ่มดั้งเดิมที่มากับ Minecraft
- `Source Mode: Direct Input` ให้คุณพิมพ์ข้อความของคุณเองผ่าน `Input Splash Text` ซึ่งรองรับได้เพียงบรรทัดเดียว แต่บรรทัดนั้นสามารถมี placeholder ได้
- `Source Mode: Text File` จะดึงบรรทัดแบบสุ่มจากไฟล์ `.txt` ที่คุณเลือกด้วย `Set Source Text File` โดยแต่ละบรรทัดที่ไม่ว่างสามารถกลายเป็น splash ที่ใช้งานอยู่ได้
- การสลับโหมดจะรีเซ็ตข้อความที่ใช้งานอยู่ ดังนั้นคุณสามารถทดลองได้อย่างปลอดภัย หากรู้สึกว่าข้อความค้างอยู่ ให้สลับไปอีกโหมดหนึ่งหรือคลิก `Refresh On Screen Load: Enabled` เพื่อบังคับสุ่มใหม่ทุกครั้งที่เปิดเมนู

## ตัวอย่างไฟล์ข้อความ
เมื่อใช้โหมดแหล่งที่มาแบบ "Text File" ให้บันทึกรายการ splash ของคุณเป็นข้อความธรรมดา (UTF-8 without BOM) แต่ละบรรทัดคือ splash ที่เป็นไปได้:

```
Welcome to FancyMenu!
{"placeholder":"your_placeholder_id_here"}
{"text":"This is gold and bold text.","color":"gold","bold":true}
&6Use &lMinecraft formatting codes!
```

แทนที่ `your_placeholder_id_here` ด้วย placeholder ที่คุณต้องการให้แก้ค่าในขณะรัน FancyMenu จะเลือกบรรทัดที่ไม่ว่างแบบสุ่มทุกครั้งที่มีการรีเฟรช splash

## การทำให้ดูเป็นแบบที่คุณต้องการ
- ใช้ `Set Scale` และ `Set Rotation` เพื่อควบคุมขนาดและมุมหมุน
- `Set Text Color` รองรับค่าสีแบบ hex เช่น `#FFFF00` เพื่อให้เข้ากับธีมของคุณ
- `Shadow: Enabled` จะเพิ่มเงาแบบ Minecraft; ปิดเพื่อให้เป็นข้อความเรียบๆ
- `Bouncing: Enabled` จะคงการเด้งขึ้นลงแบบคุ้นเคยไว้; ปิดหากต้องการป้ายแบบนิ่ง
- FancyMenu เรนเดอร์ splash เป็นคอมโพเนนต์ Minecraft แบบเต็มรูปแบบ ดังนั้นโค้ดสีและการตกแต่งข้อความอื่นๆ จึงทำงานได้ตามปกติ

## ฟีเจอร์ข้อความแบบไดนามิก
- Placeholder จะถูกแก้ค่าก่อนเรนเดอร์ ดังนั้นคุณสามารถอ้างอิงชื่อตัวละคร วันที่ หรือค่าที่รองรับอื่นๆ ภายในข้อความ splash ได้
- เนื่องจากองค์ประกอบนี้รองรับ Minecraft serialized component JSON คุณจึงวาง JSON ขั้นสูงลงใน Direct Input หรือไฟล์ข้อความของคุณได้โดยตรง องค์ประกอบจะ deserialize ให้โดยอัตโนมัติ และจะย้อนกลับไปใช้ข้อความตามตัวอักษรหากมีอะไรผิดพลาด

## การแก้ปัญหา
- ข้อความว่างใน Direct Input จะแสดง `< empty splash element >` ระหว่างการแก้ไข ใส่อะไรก็ได้ (แม้แต่เว้นวรรค) เพื่อเอาคำเตือนออก
- หากไฟล์ข้อความไม่มีบรรทัดที่ถูกต้องเลย องค์ประกอบจะแสดง `ERROR: SPLASH FILE IS EMPTY` เพิ่มอย่างน้อยหนึ่งบรรทัดที่ไม่ว่าง แล้วเปิดหน้าจอใหม่
- ข้อผิดพลาดของ serialized JSON จะย้อนกลับไปใช้ข้อความธรรมดา ใช้โครงสร้าง JSON มาตรฐานของ Mojang หรือทดสอบสไนปเป็ตด้วยคำสั่ง `/tellraw` แบบ vanilla ก่อนวางลงไป
