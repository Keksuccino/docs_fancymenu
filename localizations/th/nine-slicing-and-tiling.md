# Nine-Slicing และ Tiling

เมื่อคุณกำลังออกแบบเมนูสวย ๆ ใน Minecraft ด้วย FancyMenu คุณอาจอยากใช้ภาพที่ต้องย่อขยายได้อย่างถูกต้องหรือทำซ้ำเป็นแพตเทิร์น คู่มือนี้จะอธิบายวิธีใช้ **Nine-Slicing** และ **Tiling** (หรือที่เรียกว่า repeating textures) เพื่อทำให้เมนูของคุณดูยอดเยี่ยม!

# Nine-Slicing คืออะไร?

Nine-slicing คือเทคนิคที่ช่วยให้คุณยืดภาพให้มีขนาดเท่าใดก็ได้โดยไม่ทำให้ภาพดูผิดเพี้ยน มันทำงานโดยแบ่งภาพออกเป็น 9 ส่วน (คล้ายกระดาน tic-tac-toe) มุมทั้งสี่จะคงขนาดเดิม ขอบจะยืดได้ในทิศทางเดียว และส่วนตรงกลางจะยืดได้ทั้งสองทิศทาง

## ใช้ Nine-Slicing ได้ที่ไหนบ้าง?

ใน FancyMenu, Nine-Slicing ใช้ได้กับ:
- **Button Elements** (ทั้งปุ่มแบบกำหนดเองและตอนแก้ไขปุ่ม Vanilla)
- **พื้นผิว Progress Bar** (พื้นผิวแถบและพื้นหลัง)

## วิธีใช้ Nine-Slicing กับปุ่ม

1. **สร้างหรือเลือก Button Element** ในตัวแก้ไขเลย์เอาต์ของคุณ
2. คลิกขวาที่ปุ่ม แล้วมองหาตัวเลือก "Button Textures"
3. ตั้งค่าพื้นผิวพื้นหลังของปุ่ม (สถานะปกติ, เมื่อชี้, ไม่ใช้งาน)
4. เปิดใช้งานตัวเลือก "Nine-Slice Custom Background"
5. ตั้งค่า **Nine-Slice Background X-Borders** (ขนาดขอบซ้ายและขวา)
6. ตั้งค่า **Nine-Slice Background Y-Borders** (ขนาดขอบบนและล่าง)

### เคล็ดลับสำหรับ Nine-Slicing ของปุ่ม

- ใช้ภาพที่มีขอบและมุมชัดเจน
- ค่าขอบ (X และ Y) จะบอก FancyMenu ว่าจะให้พิกเซลกี่พิกเซลจากแต่ละด้านถูกนับเป็นขอบ
- ค่าทั่วไปอาจเป็น 5 พิกเซลทั้ง X และ Y
- มุมจะคงขนาดเดิมเสมอ ส่วนตรงกลางจะยืดเพื่อเติมเต็มปุ่ม

# Tiling คืออะไร?

Tiling (หรือ repeating textures) ช่วยให้คุณเติมพื้นที่ขนาดใหญ่ด้วยภาพเล็ก ๆ โดยการทำซ้ำเหมือนกระเบื้องปูพื้น เหมาะมากสำหรับพื้นหลังหรือภาพขนาดใหญ่ที่คุณต้องการให้แพตเทิร์นต่อเนื่องกัน

## ใช้ Tiling ได้ที่ไหนบ้าง?

ใน FancyMenu, Tiling ใช้ได้กับ:
- **Image Elements**
- **Image Menu Backgrounds**

## วิธีใช้ Tiling กับ Image Elements

1. **สร้างหรือเลือก Image Element** ในตัวแก้ไขเลย์เอาต์ของคุณ
2. คลิกขวาที่ภาพ แล้วมองหาตัวเลือก "Image Source" เพื่อกำหนดเท็กซ์เจอร์ของคุณ
3. ค้นหาและเปิดใช้งานตัวเลือก **"Repeat Texture"**
4. ปรับขนาด Image Element ของคุณเพื่อดูเท็กซ์เจอร์ถูกทำซ้ำเติมเต็มพื้นที่

## วิธีใช้ Tiling กับพื้นหลังเมนู

1. เปิด **Menu Backgrounds** จากเมนูคลิกขวาของพื้นหลังในตัวแก้ไขเลย์เอาต์
2. เลือกชนิดพื้นหลังแบบ **Image**
3. เลือกภาพพื้นหลังของคุณ
4. เปิดใช้งานตัวเลือก **"Repeat Texture"**
5. จากนั้นพื้นหลังของคุณจะทำซ้ำเท็กซ์เจอร์เพื่อเติมเต็มทั้งหน้าจอ

# การสร้างเท็กซ์เจอร์ที่ดีสำหรับ Nine-Slicing และ Tiling

## สำหรับ Nine-Slicing:
- สร้างเท็กซ์เจอร์ที่มีขอบและมุมชัดเจน
- ตรวจสอบให้แน่ใจว่าขอบมีความชัดและมีความกว้างสม่ำเสมอ
- ทดสอบค่าขอบหลาย ๆ แบบเพื่อหาค่าที่เหมาะที่สุด
- ปุ่มมักจะใช้งานได้ดีเมื่อมีขอบขนาด 3-5 พิกเซล

## สำหรับ Tiling:
- สร้างเท็กซ์เจอร์แบบไร้รอยต่อที่สามารถต่อเข้ากับตัวเองได้ทุกด้าน
- ทำแพตเทิร์นให้เรียบง่ายเพื่อลดความสับสนทางสายตา
- ทดสอบเท็กซ์เจอร์ของคุณด้วยการทำซ้ำในพื้นที่เล็ก ๆ ก่อน

# ตัวอย่าง

## ตัวอย่างปุ่มแบบ Nine-Sliced
ปุ่มธรรมดาอาจเริ่มต้นจากภาพขนาด 30x30 ที่มีขอบ 5 พิกเซลทุกด้าน เมื่อคุณขยายปุ่มให้ใหญ่ขึ้น มุมทั้งสี่จะยังคงขนาด 5x5 พิกเซล ในขณะที่ขอบและตรงกลางจะยืดเพื่อให้พอดีกับขนาดปุ่ม

## ตัวอย่างพื้นหลังแบบ Tiled
ไทล์ขนาด 64x64 ที่มีแพตเทิร์นบาง ๆ สามารถทำซ้ำเพื่อเติมเต็มพื้นหลังเมนูทั้งหมดของคุณได้ ไม่ว่าหน้าจอจะมีขนาดเท่าใดก็ตาม

# ปัญหาที่พบบ่อยและวิธีแก้ไข

## ปุ่มแบบ nine-sliced ของฉันดูยืดหรือบิดเบี้ยว:
- ค่าขอบของคุณอาจเล็กหรือใหญ่เกินไป
- ลองเปลี่ยนค่าขอบให้ตรงกับเท็กซ์เจอร์จริงของคุณ

## พื้นหลังแบบ tiled ของฉันมีรอยต่อให้เห็น:
- เท็กซ์เจอร์ของคุณไม่ใช่แบบไร้รอยต่อ
- ลองแก้ไขภาพให้ขอบต่อกันได้พอดี

## เท็กซ์เจอร์ของฉันดูเบลอเมื่อปรับขนาด:
- ใช้เท็กซ์เจอร์ที่มีความละเอียดสูงขึ้น
- ทำดีไซน์ให้เรียบง่ายและมีเส้นคมชัด

# จำไว้

- **Nine-Slicing** เหมาะมากสำหรับองค์ประกอบ UI ที่ต้องเปลี่ยนขนาดแต่ยังคงรูปลักษณ์ไว้ (เช่น ปุ่ม)
- **Tiling** เหมาะสำหรับเติมพื้นที่ขนาดใหญ่ด้วยแพตเทิร์น (เช่น พื้นหลัง)
- ทั้งสองฟีเจอร์ช่วยให้ UI ของคุณดูดีได้ในทุกความละเอียดหรือทุกขนาดหน้าจอ!

ตอนนี้ไปสร้างเมนู Minecraft สุดเจ๋งด้วยปุ่มที่ยืดได้อย่างสมบูรณ์แบบและพื้นหลังแบบ tiled ที่สวยงามกันเลย!
