# การแบ่งภาพแบบเก้าส่วนและการเรียงซ้ำ

พื้นผิวที่คุณสร้างเองจะถูกยืดให้พอดีกับขนาดขององค์ประกอบ ซึ่งไม่เป็นปัญหาสำหรับภาพถ่าย แต่กรอบ แผง และปุ่มที่มีขอบจะดูบิดเบี้ยวเมื่อขยายให้กว้างหรือสูงขึ้น การตั้งค่าสองอย่างนี้ช่วยแก้ปัญหาได้:

- การแบ่งภาพแบบเก้าส่วนช่วยคงรูปทรงของมุมและขอบของพื้นผิวไว้ โดยเติมเฉพาะส่วนตรงกลาง
- การเรียงซ้ำจะแสดงพื้นผิวซ้ำแทนการยืดภาพ ทำให้ลวดลายยังคงขนาดเดิม

# การทำงานของการแบ่งภาพแบบเก้าส่วน

เส้นสี่เส้นจะแบ่งพื้นผิวออกเป็นเก้าส่วน มุมทั้งสี่จะคงขนาดเดิมเสมอ ขอบจะยาวขึ้นได้เท่านั้น และส่วนตรงกลางจะเติมพื้นที่ที่เหลือ

1. ตั้งค่าพื้นผิวของคุณ
2. เปิดการตั้งค่าการแบ่งภาพแบบเก้าส่วน ดูชื่อการตั้งค่าได้ที่ [ตำแหน่งที่ใช้งานได้](#where-it-works)
3. กำหนดขนาดขอบให้ตรงกับความหนาของกรอบพื้นผิว โดยใช้หน่วยพิกเซลของพื้นผิว หากกรอบหนา 4 พิกเซล ให้ใช้ค่า `4`

ข้อควรรู้:

- ขนาดขอบบนหน้าจอจะเท่ากับขนาดขอบในพื้นผิว ดังนั้นพื้นผิวที่มีขอบหนา 40 พิกเซลจะดูหนาเทอะทะเมื่ออยู่บนปุ่มขนาดเล็ก ควรสร้างพื้นผิวให้มีขนาดใกล้เคียงกับองค์ประกอบ
- พื้นผิวส่วนใหญ่จะใช้ขนาดเดียวกันสำหรับขอบซ้ายและขวา (ขอบ X) และอีกขนาดหนึ่งสำหรับขอบบนและล่าง (ขอบ Y) ส่วนแถบความคืบหน้า คำแนะนำเครื่องมือ และการปรับแต่งส่วนกลางจะกำหนดขนาดแยกสำหรับแต่ละด้าน
- หากขอบมีขนาดใหญ่เกินกว่าพื้นผิว ระบบจะย่อขนาดให้โดยอัตโนมัติ

# ตำแหน่งที่ใช้งานได้

| พื้นผิว | การแบ่งภาพแบบเก้าส่วน | การเรียงซ้ำ |
|---|---|---|
| พื้นผิว [ปุ่ม](/elements#button) ใน **พื้นผิวปุ่ม** | **พื้นหลังแบบกำหนดเองแบ่งเก้าส่วน** | - |
| พื้นผิว [แถบเลื่อน](/elements#slider) ใน **พื้นผิวแถบเลื่อน** | **พื้นหลังแบบกำหนดเองแบ่งเก้าส่วน** และ **ตัวจับแบบกำหนดเองแบ่งเก้าส่วน** | - |
| องค์ประกอบ [รูปภาพ](/elements#image) | **พื้นผิวแบ่งเก้าส่วน** | **เรียงพื้นผิวซ้ำ** |
| **พื้นหลัง** ขององค์ประกอบ [ข้อความ](/text-in-menus#background) และ [พื้นที่เลื่อนได้](/scrollable-areas#background) | **พื้นหลังแบบกำหนดเองแบ่งเก้าส่วน** | **เรียงพื้นผิวซ้ำ** |
| **พื้นหลังแถบเลื่อน** ขององค์ประกอบข้อความและพื้นที่เลื่อนได้ | เปิดใช้งานอยู่เสมอ | - |
| **พื้นหลัง** ขององค์ประกอบ [คำแนะนำเครื่องมือ](/elements#tooltip) | เปิดใช้งานอยู่เสมอ โดยกำหนดขนาดได้ใน **การตั้งค่าการแบ่งภาพแบบเก้าส่วน** | - |
| พื้นผิว [แถบความคืบหน้า](/elements#progress-bar) | **พื้นผิวแถบแบ่งเก้าส่วน** และ **พื้นหลังแบ่งเก้าส่วน** | - |
| [พื้นผิวปุ่มและแถบเลื่อนส่วนกลาง](/global-customizations#buttons-and-sliders) | **พื้นหลังปุ่มแบ่งเก้าส่วน**, **พื้นหลังแถบเลื่อนแบ่งเก้าส่วน** และ **ตัวจับแถบเลื่อนแบ่งเก้าส่วน** | - |
| [พื้นหลังเมนูรูปภาพ](/menu-backgrounds#image) | - | **เรียงพื้นผิวซ้ำ** |
| ส่วนหัวและส่วนท้ายของ [หน้าจอที่เลื่อนได้](/customizing-scrollable-screens) | - | **เรียงพื้นผิวส่วนหัวซ้ำ** และ **เรียงพื้นผิวส่วนท้ายซ้ำ** |

## พื้นหลังขององค์ประกอบข้อความและพื้นที่เลื่อนได้

เปิด **พื้นหลัง** จากเมนูคลิกขวาขององค์ประกอบข้อความหรือพื้นที่เลื่อนได้:

- **พื้นผิวพื้นหลังแบบกำหนดเอง** ใช้พื้นผิวของคุณแทนแผงสีเข้มที่มีมาให้ รีเซ็ตการตั้งค่านี้เพื่อให้แผงกลับมา
- **พื้นหลังแบบกำหนดเองแบ่งเก้าส่วน** เปิดใช้งานอยู่โดยค่าเริ่มต้น กำหนดขอบด้วย **ขอบ X ของพื้นหลังแบบแบ่งเก้าส่วน (ซ้ายและขวา)** และ **ขอบ Y ของพื้นหลังแบบแบ่งเก้าส่วน (บนและล่าง)**
- **เรียงพื้นผิวซ้ำ** จะแสดงพื้นผิวของคุณซ้ำแทนการยืดภาพ เมื่อใช้ร่วมกับการแบ่งภาพแบบเก้าส่วน ขอบและส่วนตรงกลางจะถูกเรียงซ้ำ ส่วนมุมจะคงรูปเดิม
- **แสดงพื้นหลัง** ใช้ปิดพื้นหลังทั้งหมด

## พื้นหลังแถบเลื่อน

เปิด **แถบเลื่อน -> พื้นหลังแถบเลื่อน** ขององค์ประกอบข้อความหรือพื้นที่เลื่อนได้ **พื้นผิวแถบแนวตั้ง** และ **พื้นผิวแถบแนวนอน** จะแสดงพื้นผิวไปตามแนวการเคลื่อนที่ของตัวจับแถบเลื่อน พื้นผิวเหล่านี้จะแบ่งแบบเก้าส่วนเสมอ เพื่อให้ปลายแถบคงรูปทรงเดิมไม่ว่าแถบจะยาวเท่าใด กำหนดขอบได้ด้วยการตั้งค่าสองรายการที่อยู่ด้านล่าง

# การทำงานของการเรียงซ้ำ

การเรียงซ้ำจะวางพื้นผิวต่อกันไปเรื่อย ๆ โดยใช้ขนาดเดิมจนเต็มพื้นที่ ควรใช้พื้นผิวที่ต่อกันได้อย่างแนบเนียน โดยขอบซ้ายต้องต่อกับขอบขวา และขอบบนต้องต่อกับขอบล่าง มิฉะนั้นจะเห็นเส้นแบ่งระหว่างพื้นผิวแต่ละชิ้น

สำหรับองค์ประกอบรูปภาพ **เรียงพื้นผิวซ้ำ** และ **พื้นผิวแบ่งเก้าส่วน** จะใช้ร่วมกันไม่ได้ หากเปิดทั้งสองอย่าง รูปภาพจะถูกเรียงซ้ำ
