# การแบ่งเก้าส่วนและการปูซ้ำ

การแบ่งเก้าส่วนจะคงมุมและขอบของพื้นผิวไว้ในขณะที่ยืดส่วนตรงกลาง ส่วนการปูซ้ำจะทำให้พื้นผิวถูกทำซ้ำแทนการยืด

<img src="https://raw.githubusercontent.com/Keksuccino/FancyMenu/refs/heads/master/assets/docs/nine_slicing_example.png" alt="Nine-slice regions" style="max-width:500px;height:auto;" />

# การรองรับการแบ่งเก้าส่วน

| พื้นที่ | เป้าหมายที่รองรับ |
|---|---|
| วิดเจ็ต | พื้นผิวของ [Button](./elements#button) และ [Slider](./elements#slider); [สไตล์ปุ่มและสไลเดอร์แบบ global](./global-customizations#button-visuals) |
| รูปภาพและแผง | [องค์ประกอบ Image](./elements#image) |
| แถบความคืบหน้า | [พื้นผิวของส่วนเติมและพื้นหลัง](./elements#progress-bar) |
| ทูลทิป | [พื้นผิวพื้นหลังแบบกำหนดเอง](./elements#tooltip) |

# การตั้งค่าการแบ่งเก้าส่วน

1. ตั้งค่าพื้นผิวเป้าหมาย
2. เปิดใช้งานตัวเลือก **Nine-Slice**
3. ตั้งค่าขนาดขอบให้ตรงกับพื้นที่ขอบคงที่ในพื้นผิวต้นฉบับ
4. ปรับขนาดองค์ประกอบและปรับค่าขอบหากมุมหรือขอบเกิดการบิดเบี้ยว

การตั้งค่า Button และ Image ใช้ขนาดขอบ X/Y ส่วน Progress Bar และ Tooltip จะแสดงค่าแยกสำหรับแต่ละด้านเมื่อจำเป็น

# การรองรับการปูซ้ำ

พื้นผิวแบบทำซ้ำมีให้สำหรับ:

- [องค์ประกอบ Image](./elements#image)
- [พื้นหลังเมนูแบบ Image](./menu-backgrounds)
- [พื้นผิวส่วนหัวและส่วนท้ายของรายการแบบเลื่อน](./customizing-scrollable-screens)

เปิดใช้ **Repeat Texture** บนองค์ประกอบ Image หรือพื้นหลังแบบ Image สำหรับหน้าจอแบบเลื่อน ให้ใช้ตัวเลือกการทำซ้ำในเมนูปรับแต่งส่วนหัว/ส่วนท้าย

ควรใช้พื้นผิวต้นฉบับที่ไร้รอยต่อ เพราะขอบที่ไม่ตรงกันจะทำให้เห็นเส้นระหว่างไทล์

การแบ่งเก้าส่วนและการทำซ้ำเป็นโหมดแยกกัน หากมีทั้งสองตัวเลือกสำหรับเป้าหมายเดียวกัน ให้เลือกโหมดที่ตรงกับพฤติกรรมการปรับขนาดที่ต้องการ
