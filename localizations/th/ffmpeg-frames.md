# วิธีดึงเฟรมจากวิดีโอด้วย FFmpeg

*หน้านี้ถูกสร้างขึ้นบางส่วนโดย AI ของ ChatGPT*

FFmpeg เป็นเครื่องมือฟรีที่ช่วยให้คุณทำงานกับไฟล์วิดีโอและไฟล์เสียงได้ หนึ่งในความสามารถที่น่าสนใจคือการดึงภาพนิ่ง (เฟรม) ออกมาจากวิดีโอ เช่น ไฟล์ MP4 มาดูวิธีทำแบบทีละขั้นตอนกัน

ในคำสั่งต่อไปนี้จะใช้ MP4 เป็นตัวอย่าง แต่ FFmpeg ก็รองรับรูปแบบวิดีโออื่น ๆ ด้วย เช่น AVI, MOV, MKV และ MPEG

# สิ่งที่ต้องมี

ก่อนเริ่มต้น ตรวจสอบให้แน่ใจว่าคุณมี:

1. **ติดตั้ง FFmpeg แล้ว**:

   - ดาวน์โหลด FFmpeg จาก [เว็บไซต์ทางการของ FFmpeg](https://ffmpeg.org/download.html) และตรวจสอบว่าได้ดาวน์โหลดชุดติดตั้งแบบ "full" แล้ว
   - ทำตามขั้นตอนการติดตั้งสำหรับระบบของคุณ

2. **เข้าถึง Command Line ได้**:

   - ใช้เทอร์มินัล (Linux/macOS) หรือ Command Prompt (Windows) เพื่อรันคำสั่ง FFmpeg

3. **ไฟล์วิดีโอ**:

    - เตรียมไฟล์วิดีโอ MP4, AVI, MOV, MKV หรือ MPEG ให้พร้อมใช้งาน

# ก่อนเริ่ม

ก่อนรันคำสั่งใด ๆ ให้เตรียมสิ่งต่อไปนี้:

## เปิดการแสดงนามสกุลไฟล์

  - การมองเห็นนามสกุลไฟล์ เช่น `.mp4` หรือ `.avi` มีความสำคัญเมื่อคุณเปลี่ยนชื่อไฟล์วิดีโอ

    - **บน Windows**:

      - เปิด File Explorer
      - คลิกแท็บ "View" ที่ด้านบน
      - ทำเครื่องหมายที่ช่อง "File name extensions"

    - **บน macOS**:

      - เปิด Finder
      - คลิก "Finder" ในแถบเมนู แล้วเลือก "Preferences"
      - ไปที่แท็บ "Advanced" และทำเครื่องหมายที่ช่อง "Show all filename extensions"

## สร้างโฟลเดอร์เอาต์พุต

- สร้างโฟลเดอร์ชื่อ `output_frames` ในไดเรกทอรีเดียวกับไฟล์ปฏิบัติการของ FFmpeg ซึ่งจะเป็นที่จัดเก็บเฟรมที่ดึงออกมา

## เตรียมไฟล์วิดีโอของคุณ

- วางไฟล์วิดีโอที่ต้องการดึงเฟรมไว้ในไดเรกทอรีเดียวกับไฟล์ปฏิบัติการของ FFmpeg
- เปลี่ยนชื่อไฟล์วิดีโอเป็น `input` ตามด้วยนามสกุลไฟล์ของมัน (เช่น `input.mp4`, `input.avi` เป็นต้น) เพื่อให้คำสั่งด้านล่างใช้งานได้โดยไม่ต้องแก้ไข

# วิธีเปิด FFmpeg

ก่อนจะใช้ FFmpeg ได้ คุณต้องเปิดใช้งานผ่าน command line ก่อน มาดูวิธีทำทีละขั้นตอนบน Windows และ macOS กัน

## บน Windows:

1. **เปิด Command Prompt**:
   - กดปุ่ม `Windows` และ `R` พร้อมกันเพื่อเปิดกล่อง Run
   - พิมพ์ `cmd` แล้วกด Enter เพื่อเปิด Command Prompt

2. **ไปยังโฟลเดอร์ของ FFmpeg**:
   - คุณต้องบอกคอมพิวเตอร์ว่า FFmpeg อยู่ที่ไหน ใช้คำสั่ง `cd` เพื่อไปยังโฟลเดอร์ที่คุณบันทึก FFmpeg ไว้
   - ตัวอย่างเช่น ถ้า FFmpeg อยู่ในโฟลเดอร์ชื่อ `ffmpeg-2024\bin` บนเดสก์ท็อป ให้พิมพ์:
     ```bash
     cd C:\Users\YourUsername\Desktop\ffmpeg-2024\bin
     ```
     (แทนที่ "YourUsername" ด้วยชื่อผู้ใช้จริงของคุณบนคอมพิวเตอร์เครื่องนั้น)

3. **ตรวจสอบว่า FFmpeg ใช้งานได้**:
   - เพื่อให้แน่ใจว่า FFmpeg ทำงานได้ ให้พิมพ์คำสั่งนี้:
     ```bash
     ffmpeg -version
     ```
   - หากใช้งานได้ คุณจะเห็นข้อมูลเกี่ยวกับ FFmpeg แสดงบนหน้าจอ

## บน macOS:

1. **เปิด Terminal**:
   - กด `Command` และ `Space` พร้อมกันเพื่อเปิด Spotlight Search
   - พิมพ์ `Terminal` แล้วกด Enter เพื่อเปิด

2. **ไปยังโฟลเดอร์ของ FFmpeg**:
   - ใช้คำสั่ง `cd` เพื่อไปยังโฟลเดอร์ที่คุณบันทึก FFmpeg ไว้
   - ตัวอย่างเช่น ถ้า FFmpeg อยู่ในโฟลเดอร์ `Downloads` ของคุณ ให้พิมพ์:
     ```bash
     cd ~/Downloads/ffmpeg-2024/bin
     ```

3. **ตรวจสอบว่า FFmpeg ใช้งานได้**:
   - เพื่อให้แน่ใจว่า FFmpeg พร้อมใช้งาน ให้พิมพ์คำสั่งนี้:
     ```bash
     ./ffmpeg -version
     ```
   - หาก FFmpeg ทำงานได้ คุณจะเห็นรายละเอียดเกี่ยวกับมันแสดงบนหน้าจอ

# วิธีบันทึกทุกเฟรม

หากต้องการบันทึกทุกเฟรมจากวิดีโอ ให้ใช้คำสั่งนี้:

```bash
ffmpeg -i input.mp4 output_frames/%d.png
```

## ความหมายของคำสั่ง:

- `-i input.mp4`: คือไฟล์วิดีโอที่เป็นอินพุตของคุณ ไฟล์นี้ควรอยู่ในไดเรกทอรีเดียวกับไฟล์ปฏิบัติการของ FFmpeg โปรดเปลี่ยน `input.mp4` ให้ตรงกับชื่อไฟล์และนามสกุลจริง
- `output_frames/frame_%04d.png`: คือรูปแบบการบันทึกเฟรม:
- `output_frames/`: บันทึกทุกเฟรมลงในโฟลเดอร์ชื่อ `output_frames`
- `%d.png`: เฟรมจะถูกตั้งชื่อเป็นตัวเลข เช่น `1.png`, `2.png` และต่อไปตามลำดับ

# บันทึกเฟรมตามช่วงเวลาที่กำหนด

ถ้าคุณไม่ต้องการทุกเฟรม คุณสามารถบันทึกเฟรมหนึ่งภาพต่อหนึ่งวินาที (หรือช่วงเวลาอื่น ๆ) ได้ ใช้คำสั่งนี้:

```bash
ffmpeg -i input.mp4 -vf "fps=1" output_frames/%d.png
```

## ความหมายของคำสั่ง:

- `-i input.mp4`: คือไฟล์วิดีโอที่เป็นอินพุตของคุณ ไฟล์นี้ควรอยู่ในไดเรกทอรีเดียวกับไฟล์ปฏิบัติการของ FFmpeg โปรดเปลี่ยน `input.mp4` ให้ตรงกับชื่อไฟล์และนามสกุลจริง
- `-vf "fps=1"`: บันทึกหนึ่งเฟรมต่อวินาที เปลี่ยน `1` เป็นค่าตัวเลขอื่นได้หากต้องการความถี่มากหรือน้อยกว่านี้ (เช่น `fps=0.5` จะบันทึกหนึ่งเฟรมทุกสองวินาที และ `fps=2` จะบันทึกสองเฟรมต่อวินาที)
- `output_frames/%d.png`: บันทึกเฟรมลงในโฟลเดอร์ชื่อ `output_frames` โดยตั้งชื่อเป็น `1.png`, `2.png` และต่อไปตามลำดับ

# เปลี่ยนขนาดและคุณภาพของเฟรม

คุณยังสามารถปรับขนาดและคุณภาพของเฟรมที่บันทึกได้ด้วย วิธีทำคือ:

```bash
ffmpeg -i input.mp4 -vf "scale=1280:720" -q:v 2 output_frames/%d.png
```

## ความหมายของคำสั่ง:

- `-i input.mp4`: คือไฟล์วิดีโอที่เป็นอินพุตของคุณ ไฟล์นี้ควรอยู่ในไดเรกทอรีเดียวกับไฟล์ปฏิบัติการของ FFmpeg โปรดเปลี่ยน `input.mp4` ให้ตรงกับชื่อไฟล์และนามสกุลจริง
- `-vf "scale=1280:720"`: เปลี่ยนขนาดเฟรมเป็น 1280x720 พิกเซล
- `-q:v 2`: ตั้งค่าคุณภาพของภาพ (1 คือดีที่สุด และตัวเลขที่มากกว่าจะหมายถึงคุณภาพที่ต่ำลง)
- `output_frames/%d.png`: บันทึกเฟรมลงในโฟลเดอร์ชื่อ `output_frames` โดยตั้งชื่อเป็น `1.png`, `2.png` และต่อไปตามลำดับ

# เคล็ดลับในการบันทึกเฟรม

1. **ประหยัดพื้นที่**:

   - หากวิดีโอยาว คุณสามารถบันทึกเฟรมเป็นช่วง ๆ แทนการบันทึกทุกเฟรมได้ ซึ่งมีประโยชน์เป็นพิเศษเมื่อใช้เป็นเฟรมอนิเมชัน FMA ใน FancyMenu

2. **เรียนรู้เพิ่มเติม**:

   - รัน `ffmpeg -h` ในเทอร์มินัลเพื่อดูสิ่งเจ๋ง ๆ ทั้งหมดที่ FFmpeg ทำได้
