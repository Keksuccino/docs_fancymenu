# แยกเฟรมวิดีโอด้วย FFmpeg

1. ติดตั้ง [FFmpeg](https://ffmpeg.org/download.html) และตรวจสอบให้แน่ใจว่าสามารถเรียกใช้คำสั่ง `ffmpeg` ได้
2. เปิดเทอร์มินัลในไดเรกทอรีที่มีวิดีโอของคุณอยู่
3. สร้างไดเรกทอรีเอาต์พุต:

   ```bash
   mkdir output_frames
   ```

4. รันคำสั่งที่ตรงกับเฟรมที่คุณต้องการ โดยแทนที่ `input.mp4` ด้วยชื่อไฟล์วิดีโอของคุณ

## แยกทุกเฟรม

```bash
ffmpeg -i input.mp4 output_frames/frame_%04d.png
```

## แยกด้วยอัตราเฟรมคงที่

ตัวอย่างนี้จะสร้าง 10 เฟรมต่อวินาที ปรับค่า `10` ได้ตามต้องการ

```bash
ffmpeg -i input.mp4 -vf "fps=10" output_frames/frame_%04d.png
```

## ปรับขนาดเฟรมที่แยกออกมา

ตัวอย่างนี้จะปรับขนาดทุกเฟรมเป็น `1280×720`

```bash
ffmpeg -i input.mp4 -vf "scale=1280:720" output_frames/frame_%04d.png
```

ไฟล์ PNG ที่มีหมายเลขใน `output_frames` สามารถนำไปใช้สร้างแอนิเมชันแบบ [AFMA หรือ FMA แบบคลาสสิก](./fma) ได้ การใช้เฟรมน้อยลงและขนาดเล็กลงจะช่วยลดขนาดไฟล์และการใช้หน่วยความจำ
