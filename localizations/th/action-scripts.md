# สคริปต์คำสั่ง

สคริปต์คำสั่งคือรายการสิ่งที่ FancyMenu จะทำเมื่อเกิดเหตุการณ์บางอย่าง เช่น เมื่อคลิกปุ่มหรือเปิดเมนู แต่ละรายการคือคำสั่ง เช่น เปิดเมนู เข้าร่วมเซิร์ฟเวอร์ แสดงข้อความ เล่นเสียง และอื่น ๆ คำสั่งอย่าง IF และ WHILE ใช้กำหนดว่าจะให้คำสั่งใดทำงาน และทำงานบ่อยแค่ไหน

> [!CAUTION]
> สคริปต์คำสั่งสามารถแก้ไขไฟล์ ติดต่อเซิร์ฟเวอร์ เปิดลิงก์ และเรียกใช้คำสั่งได้ ใช้เฉพาะสคริปต์จากเลย์เอาต์ที่คุณเชื่อถือเท่านั้น

# สร้างสคริปต์คำสั่ง

1. ในตัวแก้ไขเลย์เอาต์ ให้คลิกขวาที่ปุ่ม แล้วคลิก **Edit Action Script**
2. กด `A` เพื่อเปิดตัวเลือกคำสั่ง
3. ค้นหาคำสั่ง คลิกเลือก แล้วคลิก **Next Step**
4. ตั้งค่าคำสั่งในหน้าต่าง แล้วคลิก **Done** คำสั่งที่ไม่มีการตั้งค่าให้กำหนด เลือก **Done** ในตัวเลือกคำสั่งได้เลย
5. คลิก **Done** ในตัวแก้ไขสคริปต์ แล้วบันทึกเลย์เอาต์

เมื่ออยู่นอกตัวแก้ไข ปุ่มจะเรียกใช้สคริปต์เมื่อมีการคลิก:

<img width="800" alt="เมื่อคลิกปุ่ม What's New? บนหน้าจอชื่อเรื่อง จะมีการแจ้งเตือนแสดงชื่อเรื่องและข้อความอัปเดต" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/action_script_use.gif?raw=true">

> [!TIP]
> คลิกขวาที่พื้นที่สคริปต์ แล้วเปิด **Add Action** เพื่อดูรายการคำสั่งทั้งหมด คลิกขวาที่คำสั่งในรายการเพื่อเพิ่มเป็นรายการโปรด ซึ่งจะแสดงไว้ด้านบน

# ตำแหน่งที่ใช้สคริปต์คำสั่งได้

| ตำแหน่ง | ทำงานเมื่อ | วิธีแก้ไข |
|---|---|---|
| [ปุ่ม](/elements#button) | มีการคลิกปุ่ม | คลิกขวาที่ปุ่ม -> **Edit Action Script** |
| [แถบเลื่อน](/elements#slider) | ค่าแถบเลื่อนเปลี่ยน `$$value` คือค่าใหม่ | คลิกขวาที่แถบเลื่อน -> **Edit Action Script** |
| [ช่องทำเครื่องหมาย](/elements#checkbox) | มีการเลือกหรือยกเลิกช่องทำเครื่องหมาย `$$value` คือสถานะใหม่ ซึ่งเป็น `true` หรือ `false` | คลิกขวาที่ช่องทำเครื่องหมาย -> **Edit Action Script** |
| [ตัวจับเวลา](/elements#ticker) | ตามที่ระบุใน **Tick Mode**: ทำซ้ำไปเรื่อย ๆ หนึ่งครั้งต่อช่วงการเล่นเกม หรือหนึ่งครั้งเมื่อโหลดเมนู | คลิกขวาที่ตัวจับเวลา -> **Edit Action Script** |
| การเปิดเมนู | เมนูของเลย์เอาต์เปิดขึ้น | คลิกขวาที่พื้นหลังของตัวแก้ไข -> **Edit 'Open Screen' Action Script** |
| การปิดเมนู | เมนูของเลย์เอาต์ปิดลง | คลิกขวาที่พื้นหลังของตัวแก้ไข -> **Edit 'Close Screen' Action Script** |
| [ตัวรับฟังเหตุการณ์](/listeners) | เกิดเหตุการณ์ที่กำหนด เช่น กดปุ่มหรือมีข้อความในแชต | **แถบเมนู -> Customization -> Manage Listeners** |
| [ตัวจัดเวลา](/schedulers) | ถึงเวลาที่กำหนด แม้ไม่มีเมนูเปิดอยู่ | **แถบเมนู -> Customization -> Manage Schedulers** |

สคริปต์เปิดและปิดยังอยู่ในเมนู **Layout -> Layout Properties** ของตัวแก้ไขด้วย

# ตัวแก้ไขสคริปต์

- คำสั่งทำงานจากบนลงล่าง รายการภายในคำสั่งเงื่อนไขหรือโฟลเดอร์จะเยื้องเข้าไปด้านล่าง
- รายการใหม่จะเพิ่มไว้ใต้รายการที่เลือก หากเลือกคำสั่งเงื่อนไขหรือโฟลเดอร์ รายการใหม่จะเพิ่มที่ต้นรายการนั้น
- ดับเบิลคลิกค่าที่ต้องการเพื่อแก้ไขได้ทันทีในรายการ ส่วนค่าที่แสดงข้อมูลสรุปสั้น ๆ จะเปิดหน้าต่างสำหรับแก้ไขแทน
- ลากรายการเพื่อย้ายตำแหน่ง ชุดคำสั่ง IF, ลูป และโฟลเดอร์สามารถพับได้โดยใช้ปุ่มสลับขนาดเล็กด้านหน้า ซึ่งเปลี่ยนเฉพาะมุมมองเท่านั้น
- แถบด้านขวาแสดงแผนผังของสคริปต์ทั้งหมด คลิกเพื่อข้ามไปยังส่วนที่ต้องการ
- คลิกขวาที่พื้นที่สคริปต์เพื่อดูคำสั่งอื่น ๆ เช่น การเพิ่มคำสั่งเงื่อนไข และ **Export Action Script for AI** (ดู [ส่งออกสำหรับ AI](/export-for-ai))
- หากคลิก **Cancel** หรือปิดหน้าต่าง การเปลี่ยนแปลงจะถูกละทิ้ง หากมีการเปลี่ยนแปลง ตัวแก้ไขจะถามยืนยันก่อน

## ปุ่มลัด

`Ctrl` คือ `Cmd` บน macOS

| ปุ่มลัด | การทำงาน |
|---|---|
| `A` | เปิดตัวเลือกคำสั่ง |
| `Enter` | แก้ไขรายการที่เลือก |
| `Delete` | ลบรายการที่เลือก |
| `Up` / `Down` | เลือกรายการด้านบนหรือด้านล่าง |
| `Shift + Up` / `Shift + Down` | ย้ายรายการที่เลือกขึ้นหรือลง |
| `Ctrl + C` / `Ctrl + V` | คัดลอกและวางคำสั่ง ไม่สามารถคัดลอกคำสั่งเงื่อนไขและบล็อกได้ |
| `Ctrl + Z` | เลิกทำ |
| `Ctrl + Y` หรือ `Ctrl + Shift + Z` | ทำซ้ำ |
| `Ctrl + S` | บันทึกสคริปต์และปิดตัวแก้ไข เช่นเดียวกับ **Done** |

# คำสั่งเงื่อนไข

คำสั่งเงื่อนไขกำหนดว่าจะให้คำสั่งใดทำงานและทำงานบ่อยแค่ไหน เพิ่มได้โดยคลิกขวาที่พื้นที่สคริปต์

## If, Else-If และ Else

**Add IF Statement** จะให้ระบุ[เงื่อนไข](/conditions) คำสั่งภายใน IF จะทำงานเมื่อเงื่อนไขเป็นจริงเท่านั้น

คลิกขวาที่ IF เพื่อเพิ่มเงื่อนไขต่อท้ายชุดคำสั่ง:

- **Append ELSE-IF Statement**: ตรวจสอบเงื่อนไขของตัวเองเมื่อ IF ด้านบนไม่ทำงาน
- **Append ELSE Statement**: ทำงานเมื่อไม่มีคำสั่งใดก่อนหน้าในชุดนี้ทำงานเลย

ตัวอย่างเช่น IF ที่มีเงื่อนไข **Is Layout Enabled** สามารถแสดงการแจ้งเตือนได้เฉพาะเมื่อเปิดเลย์เอาต์ฤดูหนาวอยู่ และ ELSE จะเล่นเสียงในกรณีอื่น

## ลูป While

**Add WHILE Loop** จะทำซ้ำคำสั่งตราบใดที่[เงื่อนไข](/conditions)เป็นจริง

การทำงานแต่ละครั้งจะหยุดหลังผ่านไป 3 วินาที เพื่อป้องกันไม่ให้ลูปที่ไม่มีวันจบทำให้เกมค้าง นี่ไม่ใช่ตัวจับเวลา หากต้องการให้บางสิ่งเกิดขึ้นภายหลังหรือเกิดซ้ำ ให้ใช้ [Execute Later](#execute-later), [ตัวจับเวลา](/elements#ticker) หรือ [ตัวจัดเวลา](/schedulers)

## ลูป For Each

**Add FOR EACH Loop** จะเรียกใช้คำสั่งหนึ่งครั้งต่อรายการใน[ตัวแปรรายการ](/variables#text-and-list-variables) โดยเริ่มจากรายการแรกไปจนถึงรายการสุดท้าย

- `$$list_entry` คือรายการปัจจุบัน และ `$$list_index` คือดัชนีของรายการ ดัชนีของรายการแรกคือ 0
- ทั้งสองตัวแปรใช้ได้ในค่าของคำสั่งและเงื่อนไขภายในลูป
- ระบุชื่อรายการโดยไม่ใส่ `$$` เช่น `quest_log` สามารถใช้ตัวแทนข้อความในชื่อได้ด้วย
- ลูปจะอ่านรายการเพียงครั้งเดียวเมื่อเริ่มทำงาน ดังนั้นคำสั่งภายในลูปจึงเปลี่ยนรายการได้อย่างปลอดภัย
- เช่นเดียวกับลูป WHILE การทำงานแต่ละครั้งจะหยุดหลังผ่านไป 3 วินาที

ดูตัวอย่างได้ที่ [การไล่ดูรายการ](/variables#going-through-a-list)

# บล็อก

บล็อกใช้เปลี่ยนจังหวะการทำงานของคำสั่งหรือจัดระเบียบสคริปต์ เพิ่มได้โดยคลิกขวาที่พื้นที่สคริปต์

## บล็อก Delay Gate

**Add DELAY GATE Block** หน่วงคำสั่งภายในบล็อกตามระยะเวลาเป็นมิลลิวินาที (`1000` เท่ากับหนึ่งวินาที)

- เมื่อสคริปต์มาถึงบล็อกนี้เป็นครั้งแรก ตัวจับเวลาจะเริ่มทำงานและข้ามคำสั่งภายในบล็อก ส่วนที่เหลือของสคริปต์จะทำงานต่อทันที
- หากสคริปต์มาถึงบล็อกอีกครั้งก่อนหมดเวลา ก็จะข้ามคำสั่งภายในบล็อกอีกครั้ง
- หลังจากนั้น คำสั่งภายในบล็อกจะทำงานทุกครั้งที่สคริปต์มาถึงบล็อกนี้
- ในสคริปต์ขององค์ประกอบ ตัวจับเวลาจะเริ่มใหม่เมื่อเปิดเมนูอีกครั้งหรือปรับขนาดเมนู

บล็อกนี้จึงเหมาะกับ[ตัวจับเวลา](/elements#ticker) เช่น การแสดงบางอย่างหลังจากเปิดเมนูไปแล้วสองสามวินาที บล็อกนี้จะไม่เรียกใช้สิ่งใดด้วยตัวเอง หากต้องการทำเช่นนั้นให้ใช้ Execute Later

## Execute Later

**Add EXECUTE LATER Block** จะเรียกใช้คำสั่งภายในบล็อกหนึ่งครั้งหลังผ่านไประยะเวลาที่กำหนดเป็นมิลลิวินาที ส่วนที่เหลือของสคริปต์จะทำงานต่อทันที

ทุกครั้งที่สคริปต์มาถึงบล็อกนี้ จะเริ่มนับถอยหลังรอบใหม่ เหมาะกับสคริปต์ที่ทำงานเพียงครั้งเดียว เช่น การคลิกปุ่มหรือการเปิดเมนู

## โฟลเดอร์

**Add Folder** จัดกลุ่มคำสั่งไว้ใต้ชื่อหนึ่ง โฟลเดอร์จะเรียกใช้ทุกคำสั่งภายในและช่วยจัดระเบียบสคริปต์ที่ยาวเท่านั้น ดับเบิลคลิกชื่อโฟลเดอร์เพื่อเปลี่ยนชื่อ

## ความคิดเห็น

**Add Comment** เพิ่มบันทึกสำหรับตัวคุณเอง ไม่มีการทำงานใด ๆ ดับเบิลคลิกเพื่อแก้ไข

# การทำงานของสคริปต์

- คำสั่งทำงานจากบนลงล่าง หากคำสั่งทำงานไม่สำเร็จ จะเขียนข้อผิดพลาดลงในบันทึกเกม แต่สคริปต์ส่วนที่เหลือยังทำงานต่อ
- ตัวแทนข้อความในค่าจะถูกแทนด้วยค่าปัจจุบัน ณ เวลาที่คำสั่งทำงาน ดังนั้นคำสั่งจะเห็นการเปลี่ยนแปลงที่เกิดจากคำสั่งก่อนหน้า
- การดาวน์โหลด การแตกไฟล์ ZIP และคำขอเว็บจะทำงานอยู่เบื้องหลัง คำสั่งถัดไปจะไม่รอให้ทำงานเสร็จ หากต้องการเรียกใช้คำสั่งเมื่อทำงานเสร็จแล้ว ให้ใช้ตัวรับฟังเหตุการณ์ [**On File Downloaded via Action**](/listeners#on-file-downloaded-via-action) และ [**On ZIP Extracted via Action**](/listeners#on-zip-extracted-via-action) หรือใช้ตัวแปรผลตอบกลับของ [**Send HTTP Request**](#send-http-request)

# ค่าของคำสั่ง

คำสั่งส่วนใหญ่ต้องใช้ค่า เช่น ที่อยู่เซิร์ฟเวอร์ ค่าง่าย ๆ คือข้อความที่คุณพิมพ์ ส่วนคำสั่งที่มีการตั้งค่าเพิ่มเติมจะมีหน้าต่างของตัวเอง

## ตัวแทนข้อความ

ค่าสามารถมี[ตัวแทนข้อความ](/placeholders)ได้ เช่น ชื่อผู้เล่น ระบบจะแทนที่ตัวแทนข้อความเมื่อคำสั่งทำงาน:

```
/say ยินดีต้อนรับกลับมา, {"placeholder":"playername"}!
```

## ตัวแปร $$

พิมพ์ `$$` ตามด้วยชื่อตัวแปรเพื่อใช้ค่าของตัวแปรในคำสั่งหรือเงื่อนไข ตัวพิมพ์ใหญ่และตัวพิมพ์เล็กในชื่อมีความแตกต่างกัน วิธีนี้ใช้ได้กับตัวแปรสองประเภท:

### ตัวแปรที่คุณสร้างเอง

ตัวแปรทุกตัวที่สร้างใน **แถบเมนู -> Customization -> Manage Variables** ใช้ `$$` ตามด้วยชื่อได้ ตัวแปรชื่อ `coins` จะเขียนเป็น `$$coins` และใช้ได้ในทุกสคริปต์ ตัวอย่างเช่น หากใช้ค่านี้กับ **Display In Chat [Client-Side]** จะแสดงจำนวนเหรียญที่ผู้เล่นมี:

```
&6คุณมีเหรียญ $$coins เหรียญ!
```

ดูวิธีสร้างและเปลี่ยนตัวแปรได้ที่ [ตัวแปร](/variables)

### ตัวแปรของสคริปต์

ฟีเจอร์บางอย่างกำหนดตัวแปรเฉพาะให้กับสคริปต์ของตัวเอง:

- [แถบเลื่อน](/elements#slider) ให้ค่าใหม่ของแถบเลื่อนเป็น `$$value`
- [ช่องทำเครื่องหมาย](/elements#checkbox) ให้สถานะใหม่เป็น `$$value` ซึ่งเป็น `true` หรือ `false`
- [ลูป For Each](#for-each-loop) ให้ `$$list_entry` และ `$$list_index`
- [ตัวรับฟังเหตุการณ์](/listeners#listener-variables) แต่ละรายการจะบอกตัวแปรที่มีให้ เช่น ปุ่มที่ถูกกด

ตัวแปรเหล่านี้มีอยู่เฉพาะระหว่างที่สคริปต์ทำงานเท่านั้น หากชื่อตรงกับตัวแปรที่คุณสร้างเอง `$$name` จะหมายถึงตัวแปรของสคริปต์

# คำสั่งทั้งหมด

คำสั่งทั้งหมดที่ FancyMenu มีให้ จัดเรียงตามการทำงาน

## หน้าจอและเมนู

### เปิดหน้าจอหรือ GUI แบบกำหนดเอง

**Identifier:** `opengui`

เปิดเมนูของเกม ม็อด หรือ [GUI แบบกำหนดเอง](/custom-guis)

**Value:** [ตัวระบุหน้าจอ](/screen-identifiers) เช่น `options_screen`

ตัวพิมพ์ใหญ่และตัวพิมพ์เล็กมีความแตกต่างกัน เมนูของม็อดบางรายการไม่สามารถเปิดด้วยวิธีนี้ได้ ในกรณีนั้น ให้ใช้ [**Mimic Vanilla/Mod Button**](#mimic-vanillamod-button) กับปุ่มที่เปิดเมนูนั้น

### ปิดหน้าจอ

**Identifier:** `closegui`

ปิดเมนูที่เปิดอยู่ หากไม่ได้อยู่ในโลกใด หน้าจอชื่อเรื่องจะเปิดขึ้น

**Value:** ไม่มี

### อัปเดตหน้าจอ

**Identifier:** `update_screen`

สร้างเมนูที่เปิดอยู่ขึ้นใหม่ เช่นเดียวกับเมื่อปรับขนาดหน้าต่าง มีประโยชน์หลังเปลี่ยนสเกล GUI หรือตัวเลือกอื่น ๆ

**Value:** ไม่มี

### กลับไปยังหน้าจอก่อนหน้า

**Identifier:** `back_to_last_screen`

กลับไปยังเมนูที่เปิดอยู่ก่อนหน้า สำหรับ [GUI แบบกำหนดเอง](/custom-guis) จะกลับไปยังเมนูที่เปิด GUI นั้นขึ้นมา

**Value:** ไม่มี

### แสดงการแจ้งเตือน

**Identifier:** `show_toast`

แสดงการแจ้งเตือนที่มุมขวาบน โดยตั้งค่าในหน้าต่างของคำสั่ง:

- **Toast Width**: ความกว้างตั้งแต่ 120 ถึง 320 พิกเซล
- **Duration (ms)**: ระยะเวลาที่แสดง ตั้งแต่ 1 วินาที (`1000`) ถึง 10 นาที
- **Title** และ **Message**: ข้อความที่มี[รหัสจัดรูปแบบ](/text-formatting#minecraft-text-formatting) หรือ JSON ขององค์ประกอบข้อความ Minecraft
- **Icon Texture Source** และ **Background Texture Source**: [รูปภาพ](/resources)ที่ไม่บังคับ ไอคอนจะแสดงได้ดีที่สุดที่ขนาด 20x20 พิกเซล ส่วนพื้นหลังควรสูง 32 พิกเซลและกว้างเท่ากับการแจ้งเตือน

### เลียนแบบปุ่ม Vanilla/Mod

**Identifier:** `mimicbutton`

คลิกปุ่มของเกมหรือม็อดเสมือนผู้เล่นเป็นคนคลิก

**Value:** [ตัวระบุตำแหน่งวิดเจ็ต](/widget-locators) ของปุ่ม เช่น `title_screen:mc_titlescreen_options_button`

หากต้องการค่านี้ ให้คลิกขวาที่ปุ่มในตัวแก้ไข แล้วคลิก **Copy Widget Locator**

## เลย์เอาต์และองค์ประกอบ

### สลับสถานะเลย์เอาต์

**Identifier:** `toggle_layout`

ปิดเลย์เอาต์เมื่อเปิดอยู่ และเปิดเมื่อปิดอยู่

**Value:** ชื่อเลย์เอาต์โดยไม่ใส่ `.txt` เช่น `winter_title_screen`

### เปิดใช้งานเลย์เอาต์

**Identifier:** `enable_layout`

เปิดใช้งานเลย์เอาต์

**Value:** ชื่อเลย์เอาต์โดยไม่ใส่ `.txt`

### ปิดใช้งานเลย์เอาต์

**Identifier:** `disable_layout`

ปิดใช้งานเลย์เอาต์

**Value:** ชื่อเลย์เอาต์โดยไม่ใส่ `.txt`

คำสั่งเลย์เอาต์ทั้งสามรายการจะบันทึกการเปลี่ยนแปลงและอัปเดตเมนูที่เปิดอยู่ทันที ตัวพิมพ์ใหญ่และตัวพิมพ์เล็กในชื่อมีความแตกต่างกัน

### สลับสถานะตัวสร้างภาพเคลื่อนไหวขององค์ประกอบ

**Identifier:** `toggle_element_animator`

เปิด[ตัวสร้างภาพเคลื่อนไหวขององค์ประกอบ](/element-animator)เมื่อปิดอยู่ และปิดเมื่อเปิดอยู่ ภาพเคลื่อนไหวจะเริ่มตั้งแต่ต้น และบันทึกสถานะไว้

**Value:** ตัวระบุของตัวสร้างภาพเคลื่อนไหวขององค์ประกอบ

### เปิดใช้งานตัวสร้างภาพเคลื่อนไหวขององค์ประกอบ

**Identifier:** `enable_element_animator`

เปิดใช้งาน[ตัวสร้างภาพเคลื่อนไหวขององค์ประกอบ](/element-animator) หากปิดอยู่ ภาพเคลื่อนไหวจะเริ่มตั้งแต่ต้น

**Value:** ตัวระบุของตัวสร้างภาพเคลื่อนไหวขององค์ประกอบ

### ปิดใช้งานตัวสร้างภาพเคลื่อนไหวขององค์ประกอบ

**Identifier:** `disable_element_animator`

ปิดใช้งาน[ตัวสร้างภาพเคลื่อนไหวขององค์ประกอบ](/element-animator) และรีเซ็ตภาพเคลื่อนไหว

**Value:** ตัวระบุของตัวสร้างภาพเคลื่อนไหวขององค์ประกอบ

### รีเซ็ตตัวสร้างภาพเคลื่อนไหวขององค์ประกอบ

**Identifier:** `reset_element_animator`

เริ่มภาพเคลื่อนไหวของ[ตัวสร้างภาพเคลื่อนไหวขององค์ประกอบ](/element-animator) ตั้งแต่ต้น โดยไม่เปิดหรือปิดการทำงาน

**Value:** ตัวระบุของตัวสร้างภาพเคลื่อนไหวขององค์ประกอบ

### กำหนดค่าช่องกรอกข้อความ

**Identifier:** `set_text_input_field_value`

กำหนดข้อความให้กับ[ช่องกรอกข้อความ](/elements#text-input-field) ไม่ว่าจะเป็นช่องของ FancyMenu หรือของเกม

**Value:** `element_identifier|||text|||force`

เมื่อกำหนด `force` เป็น `true` ข้อความจะเปลี่ยนแม้ช่องนั้นจะปิดใช้งานอยู่

### เลื่อนองค์ประกอบ

**Identifier:** `scroll_scroll_area`

เลื่อน[พื้นที่เลื่อนได้](/scrollable-areas)หรือองค์ประกอบ[ข้อความ](/elements#text) โดยกำหนดค่าในหน้าต่างคำสั่ง:

- **Identifier of the Element to Scroll**: พื้นที่หรือข้อความที่ต้องการเลื่อน
- **Scroll To**:
  - **Start** หรือ **End**
  - **Position**: **Horizontal Position** และ **Vertical Position** เป็นพิกเซล เว้นช่องใดช่องหนึ่งว่างไว้เพื่อคงตำแหน่งเดิม
  - **Element** (ใช้ได้เฉพาะพื้นที่): เลื่อนไปจนกว่าองค์ประกอบที่มี **Identifier of the Element to Scroll To** จะอยู่ที่จุดเริ่มต้น
  - **Line Number** (ใช้ได้เฉพาะข้อความ): บรรทัดแรกคือ `1`
  - **Line with Text** (ใช้ได้เฉพาะข้อความ): บรรทัดแรกที่มี **Text in the Line** โดยไม่แยกตัวพิมพ์ใหญ่และตัวพิมพ์เล็ก
- **Glide There**: เลื่อนอย่างนุ่มนวลแทนการกระโดดไปยังตำแหน่งนั้น ต้องเปิดการเลื่อนอย่างนุ่มนวลขององค์ประกอบไว้

ไม่มีการทำงานใด ๆ หากไม่มีองค์ประกอบดังกล่าว

## เสียงและวิดีโอ

### แทร็กถัดไป

**Identifier:** `audio_next_track`

ข้ามไปยังแทร็กถัดไปของ[องค์ประกอบเสียง](/elements#audio)

**Value:** ตัวระบุขององค์ประกอบเสียง เช่น `menu_music`

### แทร็กก่อนหน้า

**Identifier:** `audio_previous_track`

ย้อนกลับไปยังแทร็กก่อนหน้าของ[องค์ประกอบเสียง](/elements#audio)

**Value:** ตัวระบุขององค์ประกอบเสียง

### กำหนดระดับเสียงของแทร็ก

**Identifier:** `set_audio_element_volume`

กำหนดระดับเสียงของ[องค์ประกอบเสียง](/elements#audio) ตั้งแต่ `0.0` (0%) ถึง `1.0` (100%)

**Value:** `element_identifier:volume` เช่น `menu_music:0.5`

### สลับเล่น/หยุดแทร็กชั่วคราว

**Identifier:** `audio_toggle_play`

หยุด[องค์ประกอบเสียง](/elements#audio)ที่กำลังเล่นชั่วคราว หรือเล่นองค์ประกอบเสียงที่หยุดชั่วคราวอยู่

**Value:** ตัวระบุขององค์ประกอบเสียง

### เล่นเสียง

**Identifier:** `play_audio`

เล่นไฟล์เสียงหนึ่งครั้ง โดยตั้งค่าในหน้าต่างคำสั่ง ได้แก่ **Audio Source**, **Sound Channel** และ **Base Volume** (สูงสุด 100%)

- FancyMenu จะรอโหลดเสียงไม่เกินสิบวินาที
- ใช้ไม่ได้ใน[ตัวจับเวลา](/elements#ticker)ที่ทำงานอยู่เบื้องหลัง (แบบอะซิงโครนัส) FancyMenu จะแสดงข้อผิดพลาดแทน

[**Stop All Action Audios**](#stop-all-action-audios) ใช้หยุดเสียงที่เริ่มเล่นด้วยคำสั่งนี้

### หยุดเสียงทั้งหมดจากคำสั่ง

**Identifier:** `stop_all_action_audios`

หยุดเสียงทั้งหมดที่เริ่มเล่นด้วย [**Play Audio**](#play-audio) องค์ประกอบเสียง เสียงเมนู และเสียงปุ่มจะเล่นต่อไป

**Value:** ไม่มี

### กำหนดระดับเสียงขององค์ประกอบวิดีโอ

**Identifier:** `set_video_element_volume`

กำหนดระดับเสียงของ[องค์ประกอบวิดีโอ](/video) ตั้งแต่ `0.0` (0%) ถึง `1.0` (100%)

**Value:** `video_element_identifier:volume`

### กำหนดเวลาเล่นขององค์ประกอบวิดีโอ

**Identifier:** `set_video_element_play_time`

ข้ามไปยังเวลาที่กำหนดของ[องค์ประกอบวิดีโอ](/video) หน่วยเป็นมิลลิวินาที

**Value:** `video_element_identifier:time_in_ms` เช่น `intro_video:30000`

### สลับสถานะหยุดชั่วคราวขององค์ประกอบวิดีโอ

**Identifier:** `toggle_video_element_pause_state`

หยุด[องค์ประกอบวิดีโอ](/video)ที่กำลังเล่นชั่วคราว หรือเล่นองค์ประกอบวิดีโอที่หยุดชั่วคราวอยู่

**Value:** ตัวระบุขององค์ประกอบวิดีโอ

### กำหนดระดับเสียงของพื้นหลังวิดีโอ

**Identifier:** `set_video_menu_background_volume`

กำหนดระดับเสียงของ[พื้นหลังเมนูวิดีโอ](/video) ตั้งแต่ `0.0` (0%) ถึง `1.0` (100%)

**Value:** `background_identifier:volume`

> [!NOTE]
> หากต้องการตัวระบุของพื้นหลังเมนู ให้คลิกขวาที่พื้นหลังของตัวแก้ไข แล้วคลิก **Copy Background Identifier**

### กำหนดเวลาเล่นของพื้นหลังวิดีโอ

**Identifier:** `set_video_menu_background_play_time`

ข้ามไปยังเวลาที่กำหนดของ[พื้นหลังเมนูวิดีโอ](/video) หน่วยเป็นมิลลิวินาที

**Value:** `background_identifier:time_in_ms`

### สลับสถานะหยุดชั่วคราวของพื้นหลังวิดีโอ

**Identifier:** `toggle_video_menu_background_pause_state`

หยุด[พื้นหลังเมนูวิดีโอ](/video)ที่กำลังเล่นชั่วคราว หรือเล่นพื้นหลังวิดีโอที่หยุดชั่วคราวอยู่

**Value:** ตัวระบุของพื้นหลังเมนู

## โลกและเซิร์ฟเวอร์

### เข้าร่วมเซิร์ฟเวอร์

**Identifier:** `joinserver`

เชื่อมต่อกับเซิร์ฟเวอร์ Minecraft

**Value:** `address` หรือ `address:port` เช่น `play.example.net`

หากไม่ระบุพอร์ต จะใช้ `25565` หากกำลังโหลดโลกหรือเซิร์ฟเวอร์อยู่ จะแสดงข้อผิดพลาดแทน เซิร์ฟเวอร์ที่ไม่มีในรายการเซิร์ฟเวอร์จะถูกเพิ่มเข้าไป

### เข้าโลก

**Identifier:** `loadworld`

โหลดโลกแบบผู้เล่นคนเดียว

**Value:** ชื่อโฟลเดอร์ของโลกใน `saves` เช่น `Survival Island`

ไม่มีการทำงานใด ๆ หากไม่มีโลกดังกล่าว หากกำลังโหลดโลกหรือเซิร์ฟเวอร์อยู่ จะแสดงข้อผิดพลาดแทน

### เข้า/เข้าร่วมโลกหรือเซิร์ฟเวอร์ล่าสุด

**Identifier:** `join_last_world`

โหลดโลกหรือเข้าร่วมเซิร์ฟเวอร์ที่ผู้เล่นเข้าเล่นครั้งล่าสุด

**Value:** ไม่มี

หากกำลังโหลดโลกหรือเซิร์ฟเวอร์อยู่ จะแสดงข้อผิดพลาดแทน เซิร์ฟเวอร์ที่ไม่มีในรายการเซิร์ฟเวอร์จะถูกเพิ่มเข้าไป

### ออกจากโลกหรือเซิร์ฟเวอร์

**Identifier:** `disconnect_server_or_world`

ออกจากโลกหรือเซิร์ฟเวอร์ แล้วเปิดเมนู

**Value:** [ตัวระบุหน้าจอ](/screen-identifiers)ของเมนูที่จะเปิด เช่น `title_screen`

ใช้ได้เฉพาะเมื่อมีการโหลดโลกอยู่เท่านั้น และใช้กับ [GUI แบบกำหนดเอง](/custom-guis)ได้ด้วย หากเปิดเมนูไม่ได้ หน้าจอชื่อเรื่องจะเปิดขึ้น

## แชตและคำสั่ง

### ส่งข้อความแชต/คำสั่ง

**Identifier:** `sendmessage`

ส่งข้อความแชตหรือเรียกใช้คำสั่งเสมือนผู้เล่นเป็นคนพิมพ์

**Value:** ข้อความ หรือคำสั่งที่ขึ้นต้นด้วย `/` เช่น `/spawn`

### เรียกใช้คำสั่งในฐานะเซิร์ฟเวอร์แบบรวม

**Identifier:** `execute_command_as_integrated_server`

เรียกใช้คำสั่งในโหมดผู้เล่นคนเดียวในฐานะเซิร์ฟเวอร์ ไม่ว่าผู้เล่นจะมีสิทธิ์ใดหรือตั้งค่าการโกงไว้อย่างไร

**Value:** คำสั่ง เช่น `/give @p minecraft:diamond 1`

> [!WARNING]
> ใช้ได้เฉพาะในโหมดผู้เล่นคนเดียวเมื่อไม่ได้เปิดโลกให้ LAN หากใช้งานในกรณีอื่น จะไม่มีการทำงานใด ๆ

### วางข้อความในแชต

**Identifier:** `paste_to_chat`

ใส่ข้อความลงในช่องพิมพ์แชตขณะโหลดโลกอยู่ หากแชตยังไม่เปิด จะเปิดแชตพร้อมข้อความนั้น

**Value:** `true:text` เพิ่มข้อความต่อจากที่พิมพ์ไว้แล้ว ส่วน `false:text` จะแทนที่ข้อความเดิม

### แสดงในแชต [ฝั่งไคลเอนต์]

**Identifier:** `display_in_chat_client_side`

แสดงข้อความแชตที่มีเพียงผู้เล่นคนนี้เท่านั้นที่เห็น โดยไม่มีการส่งข้อมูลไปยังเซิร์ฟเวอร์

**Value:** ข้อความที่มี[รหัสจัดรูปแบบ](/text-formatting#minecraft-text-formatting) หรือเป็น JSON ขององค์ประกอบข้อความ Minecraft เช่น `&aยินดีต้อนรับกลับมา!`

ไม่มีการทำงานใด ๆ เมื่อยังไม่ได้โหลดโลก

## ตัวแปรและรายการ

### กำหนดค่าตัวแปร (ตัวแปร FM)

**Identifier:** `set_variable`

กำหนดค่าให้กับ[ตัวแปร](/variables)

**Value:** `variable_name:value` เช่น `coins:100`

- เครื่องหมาย `:` ตัวแรกเท่านั้นที่ใช้แบ่งชื่อออกจากค่า
- [ตัวแปรรายการ](/variables#text-and-list-variables)จะยังคงเป็นรายการ: อาร์เรย์ JSON เช่น `["a","b"]` จะกลายเป็นรายการย่อย ส่วนข้อความอื่นจะกลายเป็นรายการเดียว และข้อความว่างจะทำให้รายการว่างเปล่า

### ลบตัวแปร (ตัวแปร FM)

**Identifier:** `delete_variable`

ลบ[ตัวแปร](/variables)ออกทั้งหมด ตัวแปรอื่นจะยังคงอยู่ หากต้องการเพียงทำให้ตัวแปรว่าง ให้ใช้ [**Set Variable Value (FM Variable)**](#set-variable-value-fm-variable)

**Value:** ชื่อตัวแปร

### ลบตัวแปรทั้งหมด (ตัวแปร FM)

**Identifier:** `clear_variables`

ลบ[ตัวแปร](/variables)ทั้งหมด ทั้งตัวแปรข้อความและตัวแปรรายการ

**Value:** ไม่มี

### เพิ่มรายการลงในลิสต์ (ตัวแปร FM)

**Identifier:** `add_to_list`

เพิ่มรายการหนึ่งเข้าไปใน[ตัวแปรรายการ](/variables#list-actions)

- **List Variable**: ชื่อรายการ หากยังไม่มีตัวแปรชื่อนี้ คำสั่งจะสร้างรายการขึ้นมา
- **New Entry**: ข้อความของรายการใหม่
- **Index (Optional)**: ตำแหน่งที่จะเพิ่ม หากเว้นว่างไว้จะเพิ่มที่ท้ายรายการ รายการตั้งแต่ตำแหน่งนั้นเป็นต้นไปจะเลื่อนไปข้างหลังหนึ่งตำแหน่ง
- **Skip If Already in List**: ไม่เพิ่มรายการหากมีรายการที่มีข้อความเดียวกันอยู่แล้ว **Ignore Case** จะทำให้ `Apple` ตรงกับ `apple`

### กำหนดรายการในลิสต์ (ตัวแปร FM)

**Identifier:** `set_list_entry`

แทนที่รายการที่ **Index** ใน[ตัวแปรรายการ](/variables#list-actions)ด้วย **New Value** ไม่มีการทำงานใด ๆ หากไม่มีรายการอยู่ที่ตำแหน่งนั้น

### นำออกจากลิสต์ (ตัวแปร FM)

**Identifier:** `remove_from_list`

นำรายการออกจาก[ตัวแปรรายการ](/variables#list-actions) **Remove** ใช้เลือกรายการที่จะนำออก:

- **Entry at Index**: รายการที่ตำแหน่งดัชนีที่กำหนด
- **First Match**: รายการแรกที่มีค่า **Value to Remove** ตรงกันทุกประการ
- **All Matches**: ทุกรายการที่มีค่าดังกล่าว

**Ignore Case** จะทำให้ `Apple` ตรงกับ `apple`

### ล้างลิสต์ (ตัวแปร FM)

**Identifier:** `clear_list`

นำรายการทั้งหมดออกจาก[ตัวแปรรายการ](/variables#list-actions) โดยรายการเปล่าจะยังคงอยู่

### กำหนดลิสต์ (ตัวแปร FM)

**Identifier:** `set_list`

แทนที่รายการทั้งหมดใน[ตัวแปรรายการ](/variables#list-actions) **Entries From** ใช้เลือกแหล่งที่มาของรายการ:

- **Split Text**: แบ่ง **Text to Split** ตรง **Separator** เช่น `,` หากตัวแบ่งว่าง จะใช้การขึ้นบรรทัดใหม่เป็นตัวแบ่ง **Trim Entries** จะลบช่องว่างที่ต้นและท้ายรายการ ส่วน **Skip Empty Entries** จะไม่รวมรายการว่าง
- **JSON Array**: ใช้รายการจากอาร์เรย์ เช่น `["Diamonds","Emeralds"]` หรือใช้ `$$other_list` เพื่อคัดลอกรายการอื่น ข้อความรูปแบบอื่นจะกลายเป็นรายการเดียว และข้อความว่างจะทำให้รายการว่างเปล่า

หน้าต่างจะแสดงตัวอย่างรายการ

### จัดเรียงลิสต์ (ตัวแปร FM)

**Identifier:** `arrange_list`

เปลี่ยนลำดับของ[ตัวแปรรายการ](/variables#list-actions) ตัวเลือก **Arrangement** มีดังนี้:

- **Sort A–Z** และ **Sort Z–A**: เรียงตามตัวอักษร
- **Numbers, Smallest First** และ **Numbers, Biggest First**: เรียงตามตัวเลข รายการที่ไม่ใช่ตัวเลขจะย้ายไปอยู่ท้ายสุด
- **Reverse Order**: ย้ายรายการสุดท้ายมาเป็นรายการแรก
- **Shuffle**: สุ่มลำดับ
- **Remove Duplicates**: เก็บเฉพาะรายการแรกของแต่ละค่า

ในคำสั่งเกี่ยวกับรายการทั้งหมด ดัชนีของรายการแรกคือ `0` และ `-1` หมายถึงรายการสุดท้าย ชื่อรายการสามารถมีตัวแทนข้อความได้ และหากขึ้นต้นด้วย `$$` คำสั่งจะใช้ค่าของตัวแปรนั้นเป็นชื่อรายการ ตัวแปรข้อความที่มีค่าอยู่จะไม่เปลี่ยนแปลง และคำสั่งจะเขียนคำเตือนลงในบันทึกเกม

## เว็บและเครือข่าย

### เปิด URL ในเบราว์เซอร์

**Identifier:** `openlink`

เปิดลิงก์ในเบราว์เซอร์เริ่มต้นโดยไม่ถามยืนยันก่อน

**Value:** ลิงก์ เช่น `https://discord.gg/example`

ใช้เฉพาะลิงก์ที่คุณเชื่อถือเท่านั้น

### ส่งคำขอ HTTP

**Identifier:** `send_http_request`

ส่งคำขอเว็บในเบื้องหลัง โดยสามารถเขียนคำตอบลงในบันทึกเกมหรือบันทึกไว้ในตัวแปรได้

| การตั้งค่า | การทำงาน |
|---|---|
| URL | ที่อยู่ HTTP หรือ HTTPS |
| Method | `GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `HEAD` หรือ `OPTIONS` |
| Body | ข้อมูลที่จะส่ง จะไม่ส่งพร้อม `GET` และ `HEAD` |
| Content type | ค่า `Content-Type` ของเนื้อหา เช่น `application/json` |
| Timeout | จำนวนวินาทีที่รอการเชื่อมต่อและคำตอบ |
| Log response | เขียนคำตอบลงในบันทึกเกม |
| Response variable | บันทึกคำตอบไว้ในตัวแปรนี้เมื่อได้รับคำตอบ |
| Single-line response | ลบการขึ้นบรรทัดใหม่จากคำตอบก่อนบันทึก |
| Authentication | ไม่มี, Basic, Bearer หรือ API key |
| Headers | ส่วนหัวคำขอเพิ่มเติม |

คำสั่งถัดไปจะไม่รอคำตอบ ข้อผิดพลาดจากคำตอบจะถูกบันทึกลงในบันทึกและตัวแปรด้วย อย่าใส่รหัสผ่านหรือโทเค็นการเข้าถึงไว้ในคำสั่ง เพราะทุกคนที่มีเลย์เอาต์นี้จะอ่านได้

### ส่งข้อมูล FM ไปยังเซิร์ฟเวอร์

**Identifier:** `send_fm_data_to_server`

ส่ง [FM Data](/fm-data) ไปยังเซิร์ฟเวอร์ ซึ่งต้องติดตั้ง FancyMenu ด้วย

**Value:** `data_identifier||data`

### เชื่อมต่อกับเซิร์ฟเวอร์ระยะไกล

**Identifier:** `connect_to_remote_server`

เชื่อมต่อกับเซิร์ฟเวอร์ระยะไกล หรือใช้การเชื่อมต่อที่เปิดอยู่แล้ว

**Value:** ที่อยู่เซิร์ฟเวอร์ เช่น `wss://example.com/ws`

ดูที่อยู่ที่ใช้ได้ที่ [การสื่อสารกับเซิร์ฟเวอร์ระยะไกล](/remote-server-communication#url-modes)

### ส่งข้อมูลไปยังเซิร์ฟเวอร์ระยะไกล

**Identifier:** `send_data_to_remote_server`

ส่งข้อความไปยังเซิร์ฟเวอร์ระยะไกล และเชื่อมต่อก่อนหากจำเป็น

**Value:** `server_address||data`

### ปิดการเชื่อมต่อเซิร์ฟเวอร์ระยะไกล

**Identifier:** `close_remote_server_connection`

ปิดการเชื่อมต่อเซิร์ฟเวอร์ระยะไกลหนึ่งรายการ

**Value:** ID ของคำขอ โดยทั่วไปคือ `$$request_id` จาก [**On Remote Server Connected**](/listeners#on-remote-server-connected)

### ปิดการเชื่อมต่อเซิร์ฟเวอร์ระยะไกลทั้งหมด

**Identifier:** `close_all_remote_server_connections`

ปิดการเชื่อมต่อเซิร์ฟเวอร์ระยะไกลทั้งหมดที่ FancyMenu เปิดไว้

**Value:** ไม่มี

## ไฟล์

### สร้างไฟล์ในโฟลเดอร์เกม

**Identifier:** `create_file_in_game_dir`

สร้างไฟล์เปล่า และสร้างโฟลเดอร์ที่ยังไม่มีให้ด้วย หากมีไฟล์อยู่แล้ว ไฟล์นั้นจะไม่เปลี่ยนแปลง

**Value:** เส้นทางไฟล์ เช่น `config/mymodpack/first_start.txt`

คำสั่งเกี่ยวกับไฟล์ทั้งหมดใช้ได้เฉพาะภายในโฟลเดอร์เกม (โฟลเดอร์อินสแตนซ์) เท่านั้น เส้นทางที่ขึ้นต้นด้วย `.minecraft/` จะใช้โฟลเดอร์ `.minecraft` เริ่มต้นแทน ซึ่งอาจเป็นคนละโฟลเดอร์กัน

### ลบไฟล์/โฟลเดอร์ในโฟลเดอร์เกม

**Identifier:** `delete_file_in_game_dir`

ลบไฟล์ หรือโฟลเดอร์พร้อมทุกอย่างที่อยู่ภายใน

**Value:** เส้นทาง เช่น `config/mymodpack/cache.txt`

หากใส่ `*` ไว้ท้ายเส้นทาง เช่น `config/downloads/*` คำสั่งจะลบไฟล์ทั้งหมดที่อยู่ในโฟลเดอร์นั้นโดยตรง แต่จะเก็บโฟลเดอร์นั้นและโฟลเดอร์ย่อยไว้

### คัดลอกไฟล์/โฟลเดอร์ในโฟลเดอร์เกม

**Identifier:** `copy_file_in_game_dir`

คัดลอกไฟล์ หรือโฟลเดอร์พร้อมทุกอย่างที่อยู่ภายใน

**Value:** `source||destination` เช่น `config/presets/default.json||config/mymod/settings.json`

- หากใส่ `*` ไว้ท้ายแหล่งที่มา เช่น `config/presets/*||config/mymod/` คำสั่งจะคัดลอกไฟล์ทั้งหมดที่อยู่ในโฟลเดอร์นั้นโดยตรง แต่จะไม่คัดลอกโฟลเดอร์ปลายทางจะเป็นโฟลเดอร์ และจะถูกสร้างขึ้นหากจำเป็น
- ไม่มีการเขียนทับไฟล์ หากมีไฟล์ปลายทางอยู่แล้ว คำสั่งจะล้มเหลว

### ย้ายไฟล์/โฟลเดอร์ในโฟลเดอร์เกม

**Identifier:** `move_file_in_game_dir`

ย้ายไฟล์ หรือโฟลเดอร์พร้อมทุกอย่างที่อยู่ภายใน

**Value:** `source||destination`

การใส่ `*` ไว้ท้ายแหล่งที่มาทำงานเช่นเดียวกับ [**Copy File/Folder in Game Directory**](#copy-filefolder-in-game-directory) ไม่มีการเขียนทับไฟล์

### เปลี่ยนชื่อไฟล์/โฟลเดอร์ในโฟลเดอร์เกม

**Identifier:** `rename_file_in_game_dir`

เปลี่ยนชื่อไฟล์หรือโฟลเดอร์ คำสั่งจะล้มเหลวหากมีรายการที่ใช้ชื่อใหม่อยู่แล้ว

**Value:** `path||new_name` เช่น `config/mymod/old_name.txt||new_name.txt`

### ดาวน์โหลดไฟล์ไปยังโฟลเดอร์เกม

**Identifier:** `download_file_to_game_dir`

ดาวน์โหลดไฟล์ไปยังโฟลเดอร์ในเบื้องหลัง

**Value:** `url||target_folder` เช่น `https://example.com/pack.zip||downloads`

- ส่วนที่สองคือโฟลเดอร์ ไม่ใช่ชื่อไฟล์ FancyMenu จะใช้ชื่อจากไฟล์ดาวน์โหลดหรือลิงก์
- ไฟล์ที่มีชื่อเดียวกันจะถูกเขียนทับ
- [**On File Downloaded via Action**](/listeners#on-file-downloaded-via-action) จะทำงานเมื่อดาวน์โหลดเสร็จหรือไม่สำเร็จ หากดาวน์โหลดสำเร็จ `$$target_file_path` จะเป็นเส้นทางของไฟล์ที่บันทึกไว้

### แตกไฟล์ ZIP ในโฟลเดอร์เกม

**Identifier:** `extract_zip_file_in_game_dir`

แตกไฟล์ ZIP ไปยังโฟลเดอร์ในเบื้องหลัง

**Value:** `zip_path||target_folder` เช่น `downloads/pack.zip||resourcepacks/MyPack`

ไฟล์ที่มีชื่อเดียวกันจะถูกแทนที่ และจะไม่มีการสร้างโฟลเดอร์เพิ่มเติมที่ใช้ชื่อเดียวกับไฟล์ ZIP [**On ZIP Extracted via Action**](/listeners#on-zip-extracted-via-action) จะทำงานเมื่อเสร็จแล้ว แตกไฟล์ ZIP เฉพาะที่คุณเชื่อถือเท่านั้น

### เปิดไฟล์/โฟลเดอร์ในโฟลเดอร์เกม

**Identifier:** `open_file_folder_in_game_dir`

เปิดไฟล์หรือโฟลเดอร์ด้วยโปรแกรมที่ระบบกำหนดไว้สำหรับรายการนั้น

**Value:** เส้นทาง เช่น `screenshots`

### เขียนไฟล์ในโฟลเดอร์เกม

**Identifier:** `write_file_in_game_dir`

เขียนข้อความลงในไฟล์ ระบบจะสร้างไฟล์และโฟลเดอร์ที่จำเป็นให้

**Value:** `path|||text|||append` เช่น `config/mymodpack/log.txt|||เข้าร่วมเซิร์ฟเวอร์แล้ว\n|||true`

`\n` ใช้ขึ้นบรรทัดใหม่ หากกำหนด `append` เป็น `true` จะเพิ่มข้อความต่อท้ายไฟล์ หากเป็น `false` จะแทนที่เนื้อหาเดิม

### เลือกไฟล์จากระบบ

**Identifier:** `select_file_to_game_dir`

เปิดตัวเลือกไฟล์ของระบบ แล้วคัดลอกไฟล์ที่เลือกไปยังโฟลเดอร์เกม

**Value:** `target_path|||filter_name|||extensions|||overwrite` เช่น `config/fancymenu/assets/background.png|||Images|||png;jpg|||true`

- `target_path` คือเส้นทางเต็มของสำเนา รวมถึงชื่อไฟล์
- คั่นนามสกุลด้วย `;` หรือ `,` หากไม่ระบุนามสกุล จะเลือกไฟล์ใดก็ได้
- หากกำหนด `overwrite` เป็น `false` คำสั่งจะล้มเหลวเมื่อมีไฟล์อยู่แล้ว

[**On File Selected**](/listeners#on-file-selected) จะทำงานเมื่อคัดลอกไฟล์แล้ว เมื่อยกเลิกตัวเลือกไฟล์ หรือเมื่อเกิดข้อผิดพลาด

### ตั้งค่าตัวเลือก Minecraft

**Identifier:** `edit_minecraft_option`

เปลี่ยนตัวเลือกของ Minecraft เช่น ระยะเรนเดอร์หรือสเกล GUI

**Value:** `option_name:value` เช่น `renderDistance:12`

ดูชื่อของตัวเลือกได้ที่ [ตัวเลือก Minecraft](/minecraft-options)

### เลียนแบบปุ่มผูกคำสั่ง

**Identifier:** `mimic_keybind`

กดปุ่มที่ผูกไว้กับคำสั่งของ Minecraft เช่น กระโดดหรือย่อตัว และสามารถกดปุ่มค้างไว้ได้

**Value:** `keybind|||hold|||duration_ms` เช่น `key.jump|||false|||1000`

| ส่วนประกอบ | ความหมาย |
|---|---|
| `keybind` | ID ของปุ่มที่ผูกไว้ เช่น `key.jump` หรือ `key.sneak` |
| `hold` | `true` คือกดปุ่มค้างไว้ ส่วน `false` คือกดหนึ่งครั้ง |
| `duration_ms` | ระยะเวลาที่กดค้าง หน่วยเป็นมิลลิวินาที ค่าเริ่มต้นคือ `1000` หากไม่ระบุ |

### จัดการแพ็กทรัพยากร

**Identifier:** `manage_resource_pack`

เปิดหรือปิดแพ็กทรัพยากร โดยตั้งค่าในหน้าต่างของคำสั่ง:

- **Target Resource Pack**: ชื่อแพ็กตามที่แสดงในหน้าจอ Resource Packs โดยไม่แยกตัวพิมพ์ใหญ่และตัวพิมพ์เล็ก
- **Action Mode**: **Enable**, **Disable** หรือ **Toggle**
- **Reload Resources**: โหลดแพ็กทรัพยากรใหม่ทันทีหลังเปลี่ยนค่า ปิดตัวเลือกนี้เพื่อโหลดใหม่ภายหลัง เช่น ใช้ [**Reload Resource Packs**](#reload-resource-packs)

แพ็กที่เกมจำเป็นต้องใช้จะปิดไม่ได้
