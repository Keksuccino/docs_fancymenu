# สคริปต์แอ็กชัน

FancyMenu ช่วยให้คุณเพิ่มการโต้ตอบให้กับเมนูได้โดยการกำหนด **แอ็กชัน** ให้กับองค์ประกอบต่าง ๆ แอ็กชันเหล่านี้จะทำงานเมื่อมีการคลิกปุ่ม ทิกเกอร์กำลังทำงาน สไลเดอร์ถูกใช้งาน หรือเมื่อหน้าจอถูกเปิดหรือปิด นอกจากนี้ คุณยังสามารถสร้างสคริปต์แอ็กชันขั้นสูงได้ด้วยคำสั่งควบคุมแบบง่าย เช่น **if**, **else-if**, **else** และ **while** เพื่อควบคุมว่าแอ็กชันใดจะทำงานและเมื่อใด

# แอ็กชันคืออะไร?

**แอ็กชัน** คือภารกิจหรืองานที่ FancyMenu จะทำเมื่อถูกเรียกใช้งาน ตัวอย่างเช่น แอ็กชันอาจเปิดหน้าจอใหม่ ส่งข้อความแชต หรือปรับระดับเสียงขององค์ประกอบเสียง ในตัวแก้ไขของ FancyMenu แอ็กชันจะถูกกำหนดค่าด้วยค่า (ถ้าจำเป็น) ที่ให้รายละเอียดเพิ่มเติม เช่น URL หรือที่อยู่เซิร์ฟเวอร์

# คำสั่งคืออะไร?

เพื่อสร้างพฤติกรรมที่ซับซ้อนมากขึ้น FancyMenu รองรับคำสั่งควบคุมพื้นฐานในสคริปต์แอ็กชัน ซึ่งประกอบด้วย:

- **If Statement:** รันชุดแอ็กชันเฉพาะเมื่อ [เงื่อนไข](/en/conditions) ที่กำหนดเป็นจริง
- **Else-If Statement:** ตรวจสอบ [เงื่อนไข](/en/conditions) อื่น หาก *if* ก่อนหน้า (หรือ *else-if* ก่อนหน้านั้น) ไม่เป็นจริง
- **Else Statement:** รันเมื่อไม่มี [เงื่อนไข](/en/conditions) ก่อนหน้าข้อใดเป็นจริง
- **While Statement:** รันชุดแอ็กชันซ้ำอย่างต่อเนื่องตราบใดที่ [เงื่อนไข](/en/conditions) ยังคงเป็นจริง (มีการกำหนด timeout ในตัวเพื่อป้องกันลูปไม่รู้จบ)
- **Delay Block:** รอก่อนเป็นเวลาที่กำหนด แล้วจึงรันแอ็กชันที่อยู่ภายใน ส่วนที่เหลือของสคริปต์จะยังคงทำงานต่อไปในระหว่างที่นับถอยหลัง
- **Execute Later Block:** จัดคิวแอ็กชันที่อยู่ภายในให้รันบนเธรดหลักหลังจากหน่วงเวลาเป็นมิลลิวินาที
- **Comment:** เพิ่มหมายเหตุภายในสคริปต์เพื่อจัดระเบียบ โดยคอมเมนต์จะไม่รันแอ็กชันใด ๆ

เมื่อผสานคำสั่งเหล่านี้เข้ากับแอ็กชัน คุณจะสร้างพฤติกรรมแบบไดนามิกและมีเงื่อนไขได้ เช่น ตรวจสอบว่าพลังชีวิตของผู้เล่นต่ำหรือไม่ก่อนส่งข้อความเตือน หรือทำการอัปเดตซ้ำจนกว่าเงื่อนไขจะเปลี่ยนแปลง

# ใช้สคริปต์แอ็กชันได้ที่ไหนบ้าง?

สคริปต์แอ็กชันมีความยืดหยุ่นสูงและสามารถใช้ได้ตลอดทั้งเลย์เอาต์ของคุณ คุณสามารถกำหนดให้ใช้กับตัวอย่างเช่น:

- **ปุ่ม:** รันแอ็กชันเมื่อมีการคลิกปุ่ม
- **ทิกเกอร์:** รันสคริปต์แอ็กชันต่อเนื่องเพื่ออัปเดตข้อมูลบนหน้าจอภายในเลย์เอาต์
- **สไลเดอร์:** ทริกเกอร์สคริปต์แอ็กชันทุกครั้งที่ค่าของสไลเดอร์เปลี่ยน
- **เหตุการณ์ของหน้าจอ:** รันสคริปต์เมื่อหน้าจอถูกเปิดหรือปิด (เช่น เล่นเสียงเมื่อเมนูปรากฏ)
- **ตัวฟังเหตุการณ์ (Listeners):** เมื่อตัวฟังเหตุการณ์ที่ฟังอีเวนต์เฉพาะถูกเรียกใช้งาน มันจะรันสคริปต์แอ็กชันของตนเอง
- **ตัวจัดตารางเวลา (Schedulers):** รันแอ็กชันตามกำหนดเวลา แม้ในขณะที่ไม่มีหน้าจอเปิดอยู่

# การใช้ Placeholder ในแอ็กชัน

ค่าของแอ็กชันรองรับเนื้อหาแบบไดนามิกผ่าน **placeholder** โดยส่วนใหญ่แล้ว placeholder เหล่านี้จะใช้ไวยากรณ์คล้าย JSON และจะถูกแทนที่ด้วยข้อมูลจริงเมื่อแอ็กชันทำงาน

## Placeholder แบบคล้าย JSON

นี่คือ [placeholder](/en/placeholders) แบบปกติที่สามารถใช้ได้ในหลายจุดภายในเลย์เอาต์

มีรูปแบบดังนี้:

```json
{"placeholder": "placeholder_id", "values": {"key1": "value1", "key2": "value2"}}
```

สามารถดึงข้อมูลเกม เช่น ชื่อผู้เล่น ขนาดหน้าจอ หรือค่าที่คำนวณได้โดยใช้ placeholder **Calculator** คุณยังสามารถซ้อน placeholder เพื่อใช้งานขั้นสูงขึ้นได้อีกด้วย

## `$$` Placeholder (ตัวแปร)

`$$` placeholder เป็นพิเศษ ฟีเจอร์บางอย่างของ FancyMenu จะส่ง placeholder พิเศษเหล่านี้ให้กับแอ็กชันย่อย เงื่อนไข และ placeholder ปกติของมัน เพื่อให้สามารถใช้ภายในเพื่อดึงข้อมูลเพิ่มเติมเกี่ยวกับสภาพแวดล้อม (องค์ประกอบ ตัวฟังเหตุการณ์ ฯลฯ) ที่มันอยู่ได้

ตัวอย่างเช่น หากใช้แอ็กชันภายในสไลเดอร์ การใช้ `$$value` ในแอ็กชันจะถูกแทนที่ด้วยค่าปัจจุบันของสไลเดอร์

เมื่อใช้แอ็กชันใน listener แต่ละ listener จะมีชุดตัวแปร/placeholder เฉพาะของตัวเองเพื่อดึงข้อมูลเพิ่มเติมเกี่ยวกับ listener เช่น ปุ่มเมาส์ที่กด โครงสร้างที่ป้อนเข้าไป เป็นต้น

# วิธีตั้งค่าและแก้ไขแอ็กชัน

หากต้องการเพิ่ม แก้ไข หรือลบแอ็กชัน (และบล็อกคำสั่ง) สำหรับองค์ประกอบ ให้เพียงแค่ **คลิกขวาที่องค์ประกอบ** (ไม่ว่าจะเป็นปุ่ม สไลเดอร์ ทิกเกอร์ หรือรายการโต้ตอบอื่น ๆ) แล้วเลือก **Manage Action Script** การทำเช่นนี้จะเปิดหน้าจอ Manage Actions ซึ่งคุณสามารถ:

- **เพิ่มแอ็กชันหรือคำสั่งใหม่:** แทรกรายการแอ็กชันใหม่หรือคำสั่งควบคุม (if, else-if, else, while) เพื่อสร้างสคริปต์ของคุณ
- **แก้ไขแอ็กชันหรือคำสั่งที่มีอยู่:** ปรับค่าของแอ็กชันหรือเปลี่ยนตรรกะการควบคุม
- **ลบแอ็กชันหรือคำสั่ง:** ลบแอ็กชันที่ไม่ต้องการออกจากสคริปต์

สำหรับ [listeners](/listeners) จะมีเมนูพิเศษสำหรับจัดการและสร้าง listener รวมถึงเข้าถึงสคริปต์แอ็กชันของมัน เพื่อให้มีประสบการณ์เหมือนกับการแก้ไขสคริปต์แอ็กชันของปุ่มหรือสไลเดอร์ เป็นต้น

> เมื่ออยู่ในหน้าจอ Action Script Editor เพียงคลิกขวาบริเวณสีเทาเข้มขนาดใหญ่เพื่อเปิดเมนูบริบทสำหรับการเพิ่มแอ็กชัน คำสั่ง และอื่น ๆ
{.is-info}


# ช็อตคัตและฟีเจอร์อื่น ๆ ของ Action Script Editor

ตัวแก้ไขสคริปต์แอ็กชันมีฟีเจอร์ช่วยอำนวยความสะดวกหลายอย่างที่ทำให้การแก้ไขสคริปต์ง่ายสุด ๆ

## ช็อตคัต

- `DEL` : ลบรายการที่เลือกอย่างรวดเร็ว
- `ENTER` : เริ่มแก้ไขรายการที่เลือกแบบอินไลน์ (หรือเปิดหน้าจอแก้ไข หากไม่มีการแก้ไขแบบอินไลน์สำหรับรายการที่เลือก)
- `CTRL + C` : คัดลอกแอ็กชันที่เลือก (ตอนนี้ใช้ได้เฉพาะกับแอ็กชัน)
- `CTRL + V` : วางแอ็กชันที่คัดลอกไว้ก่อนหน้านี้
- `CTRL + Z` : ย้อนกลับหนึ่งขั้น (undo)
- `CTRL + Y` : ไปข้างหน้าหนึ่งขั้น (redo)
- `ARROW UP` : เลื่อนไปยังรายการด้านบนหนึ่งรายการจากรายการที่เลือกอยู่
- `ARROW DOWN` : เลื่อนไปยังรายการด้านล่างหนึ่งรายการจากรายการที่เลือกอยู่
- `SHIFT + ARROW UP` : เลื่อนรายการที่เลือกขึ้นหนึ่งตำแหน่ง
- `SHIFT + ARROW DOWN` : เลื่อนรายการที่เลือกลงหนึ่งตำแหน่ง
- `A` : เปิดหน้าจอ Action Chooser อย่างรวดเร็วเพื่อเพิ่มแอ็กชันใหม่
- `CTRL + S` : เสร็จสิ้น/บันทึกจากหน้าต่างตัวแก้ไข

## ฟีเจอร์ช่วยใช้งานเพิ่มเติม

- ดับเบิลคลิกที่ค่าของแอ็กชันเพื่อแก้ไขค่าได้โดยไม่ต้องเข้าไปยังหน้าจอแก้ไขค่าเต็มรูปแบบ
- ชุดคำสั่ง IF (พร้อม ELSE/ELSE-IF ที่ต่อท้าย), ลูป WHILE และโฟลเดอร์ สามารถย่อ/ขยายได้ (เป็นเพียงการแสดงผล ไม่กระทบตรรกะของสคริปต์)
- ตัวแก้ไขจะเพิ่มแอ็กชันใหม่ไว้ใต้รายการที่เลือกเสมอ (หรือซ้อนอยู่ภายในชุด/ลูป/โฟลเดอร์ที่เลือก)
- การคลิกขวาที่พื้นหลังพื้นที่สคริปต์สีเทาเข้มจะเปิดเมนูบริบทพร้อมตัวเลือกสำหรับเพิ่มแอ็กชัน คำสั่ง และสิ่งสำคัญอื่น ๆ

# รายละเอียดแอ็กชัน

รายการนี้มีแอ็กชันส่วนใหญ่ที่มีอยู่ใน FancyMenu ถ้าไม่ใช่ทั้งหมด เป็นไปได้ว่ารายการนี้อาจล้าสมัยเล็กน้อยในบางครั้งเนื่องจากมีการอัปเดตของม็อด

## แทร็กถัดไป (`audio_next_track`)
- **คำอธิบาย:** ไปยังแทร็กถัดไปในองค์ประกอบเสียง
- **ต้องมีค่า:** ใช่ - `audio_element_identifier` (ID ขององค์ประกอบเสียงที่ต้องการควบคุม)

## แทร็กก่อนหน้า (`audio_previous_track`)
- **คำอธิบาย:** ไปยังแทร็กก่อนหน้าในองค์ประกอบเสียง
- **ต้องมีค่า:** ใช่ - `audio_element_identifier` (ID ขององค์ประกอบเสียงที่ต้องการควบคุม)

## ตั้งระดับเสียงของแทร็ก (`set_audio_element_volume`)
- **คำอธิบาย:** ตั้งระดับเสียงขององค์ประกอบเสียง (0.0 ถึง 1.0)
- **ต้องมีค่า:** ใช่ - `element_identifier:volume`

## สลับเล่น/หยุดชั่วคราวของแทร็ก (`audio_toggle_play`)
- **คำอธิบาย:** สลับสถานะเล่น/หยุดชั่วคราวของแทร็กปัจจุบันในองค์ประกอบเสียง
- **ต้องมีค่า:** ใช่ - `audio_element_identifier`

## เล่นเสียง (`play_audio`)
- **คำอธิบาย:** เล่นทรัพยากรเสียงหนึ่งครั้ง แอ็กชันจะติดตามเสียงที่เริ่มเล่นไว้ เพื่อให้สามารถหยุดได้ภายหลังด้วย `stop_all_action_audios`
- **ต้องมีค่า:** ใช่ - การตั้งค่า JSON ที่มี `audioSource`, `soundChannel`, และ `baseVolume`
- **ตัวอย่างค่า:** `{"audioSource":"[source:local]/config/fancymenu/assets/example.ogg","soundChannel":"master","baseVolume":1.0}`

## หยุดเสียงทั้งหมดของแอ็กชัน (`stop_all_action_audios`)
- **คำอธิบาย:** หยุดแทร็กเสียงทั้งหมดที่ถูกเริ่มโดยแอ็กชัน **Play Audio** ซึ่งจะไม่หยุดองค์ประกอบ Audio เสียงตอนเปิด/ปิดเมนู เสียงปุ่ม หรือระบบเสียงอื่น ๆ
- **ต้องมีค่า:** ไม่

## ตั้งระดับเสียงขององค์ประกอบวิดีโอ (`set_video_element_volume`)
- **คำอธิบาย:** ตั้งระดับเสียงขององค์ประกอบวิดีโอ (0.0 ถึง 1.0)
- **ต้องมีค่า:** ใช่ - `video_element_identifier:volume`

## ตั้งเวลาเล่นขององค์ประกอบวิดีโอ (`set_video_element_play_time`)
- **คำอธิบาย:** เลื่อนองค์ประกอบวิดีโอไปยังเวลาที่กำหนดเป็นมิลลิวินาที
- **ต้องมีค่า:** ใช่ - `video_element_identifier:timestamp_ms`

## สลับสถานะหยุดชั่วคราวขององค์ประกอบวิดีโอ (`toggle_video_element_pause_state`)
- **คำอธิบาย:** สลับสถานะหยุดชั่วคราวขององค์ประกอบวิดีโอ
- **ต้องมีค่า:** ใช่ - `video_element_identifier`

## ตั้งระดับเสียงพื้นหลังวิดีโอ (`set_video_menu_background_volume`)
- **คำอธิบาย:** ตั้งระดับเสียงของพื้นหลังเมนูวิดีโอ (0.0 ถึง 1.0)
- **ต้องมีค่า:** ใช่ - `background_identifier:volume`

> หากต้องการรับตัวระบุของพื้นหลัง ให้คลิกขวาที่พื้นหลังตัวแก้ไข แล้วคลิก 'Copy Background Identifier'
{.is-info}

## ตั้งเวลาเล่นของพื้นหลังวิดีโอ (`set_video_menu_background_play_time`)
- **คำอธิบาย:** เลื่อนพื้นหลังเมนูวิดีโอไปยังเวลาที่กำหนดเป็นมิลลิวินาที
- **ต้องมีค่า:** ใช่ - `background_identifier:timestamp_ms`

> หากต้องการรับตัวระบุของพื้นหลัง ให้คลิกขวาที่พื้นหลังตัวแก้ไข แล้วคลิก 'Copy Background Identifier'

- **ต้องมีค่า:** ใช่ - `source||destination`

- **ต้องมีค่า:** ใช่ - `path||new_name`

## ดาวน์โหลดไฟล์ไปยังไดเรกทอรีเกม (`download_file_to_game_dir`)
- **คำอธิบาย:** ดาวน์โหลดไฟล์แบบอะซิงโครนัสไปยังไดเรกทอรีเกม (รากของ instance); คำนำหน้า `.minecraft/` จะชี้ไปยังโปรไฟล์เริ่มต้นของ launcher (ไม่จำเป็นต้องเป็น instance ที่กำลังรันอยู่) ให้ระบุ **โฟลเดอร์ปลายทาง**; ชื่อไฟล์จะถูกกำหนดจากเฮดเดอร์/URL โดยอัตโนมัติ
- **ต้องมีค่า:** ใช่ - `url||target_folder`

## แตกไฟล์ ZIP ในไดเรกทอรีเกม (`extract_zip_file_in_game_dir`)
- **คำอธิบาย:** แตกไฟล์ ZIP ไปยังโฟลเดอร์ปลายทางภายในไดเรกทอรีเกมหรือไดเรกทอรี `.minecraft` เริ่มต้น เมื่อเสร็จแล้วจะทริกเกอร์ listener **On ZIP Extracted via Action**
- **ต้องมีค่า:** ใช่ - `source_zip_path||target_folder_path`

## เปิดไฟล์/โฟลเดอร์ในไดเรกทอรีเกม (`open_file_folder_in_game_dir`)
- **คำอธิบาย:** เปิดไฟล์หรือโฟลเดอร์ด้วยแอปเริ่มต้นของระบบปฏิบัติการ ปลายทางต้องยังอยู่ภายในไดเรกทอรีเกมหรือไดเรกทอรี `.minecraft` เริ่มต้นด้วยเหตุผลด้านความปลอดภัย
- **ต้องมีค่า:** ใช่ - `target_path`

## เขียนไฟล์ในไดเรกทอรีเกม (`write_file_in_game_dir`)
- **คำอธิบาย:** เขียนหรือเพิ่มข้อความภายในไดเรกทอรีเกม (รากของ instance); คำนำหน้า `.minecraft/` จะชี้ไปยังโปรไฟล์เริ่มต้นของ launcher (อาจต่างจาก instance นี้) สร้างไฟล์หากยังไม่มี รองรับ `\n` ในค่าเพื่อแทรกการขึ้นบรรทัดใหม่; โหมดเพิ่มต่อท้ายควบคุมด้วยบูลีนตัวสุดท้าย
- **ต้องมีค่า:** ใช่ - `path|||content|||append_bool`

## เลือกไฟล์จากระบบ (`select_file_to_game_dir`)
- **คำอธิบาย:** เปิดตัวเลือกไฟล์แบบเนทีฟ (ตำแหน่งใดก็ได้) แล้วคัดลอกไฟล์ที่เลือกไปยังไดเรกทอรีเกม (รากของ instance) หรือไปยัง `.minecraft/` เริ่มต้นเมื่อมีคำนำหน้า (ซึ่งค่าเริ่มต้นนั้นอาจต่างจาก instance นี้) รองรับตัวกรองนามสกุล ป้ายกำกับตัวกรองแบบกำหนดเอง และตัวเลือกเขียนทับได้
- **ต้องมีค่า:** ใช่ - การตั้งค่าการเลือก

## แสดง Toast (`show_toast`)
- **คำอธิบาย:** แสดงการแจ้งเตือนแบบ toast ที่กำหนดค่าได้
- **ต้องมีค่า:** ใช่ - การตั้งค่า toast

## เริ่ม Scheduler (`start_scheduler`)
- **คำอธิบาย:** เริ่ม scheduler ตาม scheduler ID ของมัน
- **ต้องมีค่า:** ใช่ - `scheduler_id`

## หยุด Scheduler (`stop_scheduler`)
- **คำอธิบาย:** หยุด scheduler ตาม scheduler ID ของมัน
- **ต้องมีค่า:** ใช่ - `scheduler_id`

## ตั้งค่า Minecraft Option (`edit_minecraft_option`)
- **คำอธิบาย:** แก้ไขตัวเลือกการตั้งค่าของ Minecraft
- **ต้องมีค่า:** ใช่ - `option_name:set_to_value`
