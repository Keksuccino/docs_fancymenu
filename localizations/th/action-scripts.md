# สคริปต์การกระทำ

สคริปต์การกระทำจะรันงานที่กำหนดไว้เมื่อมีการคลิก [Button](./elements#button), [Ticker](./elements#ticker) อัปเดต, [Slider](./elements#slider) เปลี่ยนค่า, หน้าจอถูกเปิดหรือปิด หรือเมื่อเกิดเหตุการณ์ที่รองรับอื่น ๆ คำสั่งอย่าง **if**, **else-if**, **else** และ **while** จะเพิ่มการควบคุมแบบมีเงื่อนไข

> [!CAUTION]
> สคริปต์การกระทำที่นำเข้ามาอาจแก้ไขไฟล์ ติดต่อเซิร์ฟเวอร์ เปิดลิงก์ หรือรันคำสั่ง ใช้เฉพาะแหล่งที่คุณเชื่อถือเท่านั้น

# การกระทำคืออะไร?

**การกระทำ** คือภารกิจหรืองานที่ FancyMenu จะรันเมื่อถูกเรียกใช้งาน ตัวอย่างเช่น การกระทำอาจเปิดหน้าจอใหม่ ส่งข้อความแชท หรือปรับระดับเสียงของ [Audio element](./elements#audio) ในตัวแก้ไขของ FancyMenu การกระทำจะถูกกำหนดค่าด้วยค่า (ถ้าจำเป็น) ที่ให้รายละเอียดเพิ่มเติม เช่น URL หรือที่อยู่เซิร์ฟเวอร์

# คำสั่งเงื่อนไข

เพื่อสร้างพฤติกรรมที่ซับซ้อนยิ่งขึ้น FancyMenu รองรับคำสั่งควบคุมในสคริปต์การกระทำ:

| คำสั่ง | พฤติกรรม |
|---|---|
| **If** | รันการกระทำของมันเฉพาะเมื่อ [ข้อกำหนด](./conditions) ถูกตรงตามเงื่อนไข |
| **Else-If** | ตรวจสอบชุด [ข้อกำหนด](./conditions) อื่นเมื่อ **If** หรือ **Else-If** ก่อนหน้าไม่ถูกรัน |
| **Else** | รันเมื่อไม่มีข้อกำหนดของ **If** หรือ **Else-If** ก่อนหน้าตรงตามเงื่อนไข |
| **While** | ทำซ้ำการกระทำของมันตราบใดที่ [ข้อกำหนด](./conditions) ยังเป็นจริง จะหยุดหลังจากสามวินาทีเพื่อป้องกันลูปไม่สิ้นสุด; อย่าใช้เป็นตัวตั้งเวลา |

# บล็อก

สามารถเพิ่มบล็อกลงในสคริปต์ได้ เพื่อช่วยควบคุมลำดับ/จังหวะการทำงานของสคริปต์ได้ดีขึ้น และมีฟีเจอร์ช่วยอำนวยความสะดวกบางอย่าง:

| บล็อก | พฤติกรรม |
|---|---|
| **Delay** | เริ่มนับถอยหลังโดยไม่หยุดส่วนอื่นของสคริปต์ การกระทำที่อยู่ภายในจะเริ่มทำงานได้หลังจากครบเวลา; การรีเริ่มหน้าจอจะรีเซ็ตการนับถอยหลัง |
| **Execute Later** | กำหนดให้การกระทำที่อยู่ภายในถูกรันใหม่หลังครบดีเลย์ทุกครั้งที่มาถึงบล็อกนี้ |
| **Comment** | เพิ่มหมายเหตุภายในสคริปต์เพื่อการจัดระเบียบ และไม่รันการกระทำใด ๆ |

# การรันสคริปต์

การกระทำจะรันจากบนลงล่าง การกระทำที่ล้มเหลวจะถูกบันทึกลงล็อก จากนั้นสคริปต์จะดำเนินต่อ

การดาวน์โหลด การแตก ZIP และคำขอ HTTP จะเสร็จในภายหลัง; การกระทำถัดไปจะไม่รอ ใช้ [**On File Downloaded via Action**](./listeners#on-file-downloaded-via-action-file_downloaded_via_action), [**On ZIP Extracted via Action**](./listeners#on-zip-extracted-via-action-zip_extracted_via_action) หรือใช้ตัวแปรการตอบกลับ HTTP เมื่อการทำงานต่อไปขึ้นอยู่กับผลลัพธ์

# จะใช้สคริปต์การกระทำได้ที่ไหนบ้าง?

สคริปต์การกระทำใช้งานได้หลากหลายและนำไปใช้ได้ทั่วทั้งเลย์เอาต์ คุณสามารถกำหนดให้กับสิ่งต่อไปนี้ได้ เช่น:

- [**Buttons**](./elements#button): รันการกระทำเมื่อมีการคลิกปุ่ม
- [**Tickers**](./elements#ticker): รันสคริปต์การกระทำอย่างต่อเนื่องเพื่ออัปเดตข้อมูลบนหน้าจอภายในเลย์เอาต์
- [**Sliders**](./elements#slider): เรียกสคริปต์การกระทำเมื่อค่าของสไลเดอร์เปลี่ยน
- **Screen Events:** รันสคริปต์เมื่อหน้าจอเปิดหรือปิด (เช่น เล่นเสียงเมื่อเมนูปรากฏ)
- [**Listeners**](./listeners): เมื่อลิสเนอร์ได้รับเหตุการณ์ที่กำหนดไว้ มันจะรันสคริปต์การกระทำของมัน
- [**Schedulers**](./schedulers): รันการกระทำตามช่วงเวลาที่กำหนด แม้ไม่มีหน้าจอเปิดอยู่ก็ตาม

# การใช้ตัวแทนใน Actions

ค่าของการกระทำรองรับเนื้อหาแบบไดนามิกผ่าน **ตัวแทน (placeholders)** โดยส่วนใหญ่ตัวแทนเหล่านี้ใช้ไวยากรณ์คล้าย JSON และจะถูกแทนที่ด้วยข้อมูลจริงเมื่อการกระทำทำงาน

## ตัวแทนแบบคล้าย JSON

นี่คือตัว [placeholders](./placeholders) ปกติที่สามารถใช้ได้ในหลายที่ภายในเลย์เอาต์

พวกมันมีรูปแบบดังนี้:

```json
{"placeholder": "placeholder_id", "values": {"key1": "value1", "key2": "value2"}}
```

สามารถดึงข้อมูลเกม เช่น ชื่อผู้เล่น ขนาดหน้าจอ หรือค่าที่คำนวณได้โดยใช้ [**Calculator** placeholder](./placeholders#calculator-calc) คุณยังสามารถซ้อนตัวแทนกันได้เพื่อการใช้งานขั้นสูงขึ้น

## ตัวแทน `$$` (ตัวแปร)

ค่า `$$` คือค่าที่อ่านได้อย่างเดียวซึ่งถูกส่งให้กับสคริปต์การกระทำเฉพาะตัวโดยฟีเจอร์ที่รันมัน

ตัวอย่างเช่น [Slider](./elements#slider) จะส่งค่าปัจจุบันของมันเป็น `$$value`

แต่ละ [listener](./listeners) จะระบุค่า `$$` ที่มันส่งให้ เช่น ปุ่มเมาส์ที่กดหรือโครงสร้างที่ป้อนเข้าไป

ชื่อ `$$` แยกแยะตัวพิมพ์เล็ก-ใหญ่ และใช้งานได้เฉพาะในสคริปต์ที่เป็นผู้ส่งให้เท่านั้น ดู [Listeners](./listeners#listener-variables)

## ตัวคั่นค่าการกระทำ

ใช้ตัวคั่นที่แสดงสำหรับแต่ละการกระทำอย่างเคร่งครัด: `:`, `||` หรือ `|||` ไม่มีไวยากรณ์สำหรับ escape ตัวคั่นภายในฟิลด์

ตัวแทนจะถูกแทนที่ก่อนที่ค่าจะถูกแยก สำหรับ `set_variable` จะใช้โคลอนตัวแรกเท่านั้นในการแยกชื่อออกจากค่า ดังนั้นโคลอนที่ตามมาจะยังคงเป็นส่วนหนึ่งของค่า

## ค่าข้อความ

โค้ดฟอร์แมต [FancyMenu formatting codes](./text-formatting#minecraft-text-formatting) ใช้ `&` แทนอักขระ `§` ของ Minecraft ในทุกที่ที่การกระทำยอมรับข้อความที่จัดรูปแบบ

- [**Send Chat Message/Command**](#send-chat-messagecommand-sendmessage) และ [**Paste to Chat**](#paste-to-chat-paste_to_chat) รองรับโค้ดฟอร์แมตเหล่านี้
- [**Display In Chat [Client-Side]**](#display-in-chat-client-side-display_in_chat_client_side) รองรับข้อความธรรมดาหรือ JSON ของ Minecraft text-component ที่ซีเรียลไลซ์แล้ว
- [**Open URL in Browser**](#open-url-in-browser-openlink) จะใช้การแปลงโค้ดฟอร์แมตแบบเดียวกันก่อนส่ง URL ไปยังระบบปฏิบัติการ

# วิธีตั้งค่าและแก้ไขการกระทำ

หากต้องการแก้ไขการกระทำและบล็อกคำสั่งขององค์ประกอบ ให้ **คลิกขวาที่องค์ประกอบ** แล้วเลือก **Manage Action Script** ในตัวแก้ไข คุณสามารถ:

- **เพิ่มการกระทำหรือคำสั่งใหม่:** แทรกรายการการกระทำใหม่หรือคำสั่งควบคุม (if, else-if, else, while) เพื่อสร้างสคริปต์ของคุณ
- **แก้ไขการกระทำหรือคำสั่งที่มีอยู่:** ปรับค่าการกระทำหรือเปลี่ยนตรรกะการควบคุม
- **ลบการกระทำหรือคำสั่ง:** ลบรายการที่ไม่ต้องการออกจากสคริปต์

สร้างและแก้ไขสคริปต์ของ listener ผ่าน [**Customization -> Manage Listeners**](./listeners#using-listeners)

# คีย์ลัดของตัวแก้ไขสคริปต์การกระทำ

## คีย์ลัด

- `DEL` : ลบรายการที่เลือกอย่างรวดเร็ว
- `ENTER` : เริ่มแก้ไขรายการที่เลือกแบบบรรทัดเดียว (หรือเปิดหน้าจอแก้ไขหากรายการนั้นไม่มีการแก้ไขแบบบรรทัดเดียว)
- `Ctrl/Command + C` : คัดลอกการกระทำที่เลือก (ตอนนี้ใช้ได้เฉพาะกับการกระทำเท่านั้น)
- `Ctrl/Command + V` : วางการกระทำที่คัดลอกไว้ก่อนหน้า
- `Ctrl/Command + Z` : ย้อนกลับหนึ่งขั้น (undo)
- `Ctrl/Command + Y` : ไปข้างหน้าหนึ่งขั้น (redo)
- `ARROW UP` : เลื่อนไปยังรายการหนึ่งแถวขึ้นจากรายการที่เลือกอยู่
- `ARROW DOWN` : เลื่อนไปยังรายการหนึ่งแถวลงจากรายการที่เลือกอยู่
- `SHIFT + ARROW UP` : ย้ายรายการที่เลือกขึ้นหนึ่งตำแหน่ง
- `SHIFT + ARROW DOWN` : ย้ายรายการที่เลือกลงหนึ่งตำแหน่ง
- `A` : เปิดหน้าจอ Action Chooser อย่างรวดเร็วเพื่อเพิ่มการกระทำใหม่
- `Ctrl/Command + S` : เสร็จสิ้น/บันทึกจากหน้าต่างตัวแก้ไข

## การแก้ไข

- การดับเบิลคลิกที่ค่าของการกระทำจะช่วยให้คุณแก้ไขค่าได้โดยไม่ต้องเข้าสู่หน้าจอแก้ไขค่าแบบเต็ม
- โซ่ของคำสั่ง IF (พร้อมคำสั่ง ELSE/ELSE-IF ที่ต่อท้าย), ลูป WHILE และโฟลเดอร์ สามารถยุบได้ (เป็นเพียงการแสดงผลเท่านั้น ไม่กระทบตรรกะของสคริปต์)
- ตัวแก้ไขจะเพิ่มการกระทำใหม่ไว้ใต้รายการที่เลือกเสมอ (หรือซ้อนอยู่ในโซ่/ลูป/โฟลเดอร์ที่เลือก)
- การคลิกขวาที่พื้นหลังพื้นที่สคริปต์สีเทาเข้มจะเปิดเมนูบริบทที่มีตัวเลือกสำหรับเพิ่มการกระทำ คำสั่ง และสิ่งสำคัญอื่น ๆ

# รายละเอียดการกระทำ

ส่วนนี้แสดงรายการการกระทำที่มีมาให้ใน FancyMenu

## ถัดไป ( `audio_next_track` )

**วัตถุประสงค์:** ไปยังแทร็กถัดไปใน [Audio element](./elements#audio)

**ค่า:** จำเป็น — `audio_element_identifier` (ID ของ audio element ที่จะควบคุม)

## แทร็กก่อนหน้า (`audio_previous_track`)

**วัตถุประสงค์:** ไปยังแทร็กก่อนหน้าใน [Audio element](./elements#audio)

**ค่า:** จำเป็น — `audio_element_identifier` (ID ของ audio element ที่จะควบคุม)

## ตั้งระดับเสียงแทร็ก (`set_audio_element_volume`)

**วัตถุประสงค์:** ตั้งระดับเสียงของ [Audio element](./elements#audio) (`0.0` ถึง `1.0`)

**ค่า:** จำเป็น — `element_identifier:volume`

## สลับเล่น/หยุดชั่วคราวแทร็ก (`audio_toggle_play`)

**วัตถุประสงค์:** สลับสถานะของแทร็กปัจจุบันใน [Audio element](./elements#audio) ระหว่างกำลังเล่นกับหยุดชั่วคราว

**ค่า:** จำเป็น — `audio_element_identifier`

## เล่นเสียง (`play_audio`)

**วัตถุประสงค์:** เล่นแหล่งเสียงหนึ่งครั้ง เสียงที่เริ่มด้วยการกระทำนี้สามารถหยุดได้ภายหลังด้วย [**Stop All Action Audios**](#stop-all-action-audios-stop_all_action_audios)

**ค่า:** จำเป็น — การกำหนดค่า JSON ที่มี `audioSource`, `soundChannel`, และ `baseVolume`

**ตัวอย่าง:** `{"audioSource":"[source:local]/config/fancymenu/assets/example.ogg","soundChannel":"master","baseVolume":1.0}`

**พฤติกรรม:**

- `baseVolume` จะถูกจำกัดให้อยู่ในช่วง `0.0`–`1.0`
- หากไม่รู้จัก sound channel จะใช้ช่อง Master
- การกระทำนี้ไม่สามารถรันจาก [Ticker](./elements#ticker) แบบ asynchronous ได้; FancyMenu จะแสดงข้อผิดพลาดแทน
- FancyMenu จะรอนานสูงสุดสิบวินาทีเพื่อให้แหล่งเสียงพร้อมใช้งาน
- แทร็กที่เริ่มสำเร็จสามารถหยุดได้ด้วย [**Stop All Action Audios**](#stop-all-action-audios-stop_all_action_audios)

## หยุดเสียงการกระทำทั้งหมด (`stop_all_action_audios`)

**วัตถุประสงค์:** หยุดแทร็กเสียงทั้งหมดที่เริ่มโดย [**Play Audio** action](#play-audio-play_audio) การกระทำนี้ไม่หยุด [Audio elements](./elements#audio), เสียงเปิด/ปิดเมนู, เสียงปุ่ม หรือระบบเสียงอื่น ๆ

**ค่า:** ไม่จำเป็น

## ตั้งระดับเสียงองค์ประกอบวิดีโอ (`set_video_element_volume`)

**วัตถุประสงค์:** ตั้งระดับเสียงของ [Video element](./video) (`0.0` ถึง `1.0`)

**ค่า:** จำเป็น — `video_element_identifier:volume`

## ตั้งเวลาเล่นขององค์ประกอบวิดีโอ (`set_video_element_play_time`)

**วัตถุประสงค์:** ข้ามไปยังเวลาประทับเป็นมิลลิวินาทีของ [Video element](./video)

**ค่า:** จำเป็น — `video_element_identifier:timestamp_ms`

## สลับสถานะหยุดชั่วคราวขององค์ประกอบวิดีโอ (`toggle_video_element_pause_state`)

**วัตถุประสงค์:** สลับสถานะหยุดชั่วคราวของ [Video element](./video)

**ค่า:** จำเป็น — `video_element_identifier`

## ตั้งระดับเสียงพื้นหลังวิดีโอ (`set_video_menu_background_volume`)

**วัตถุประสงค์:** ตั้งระดับเสียงของ [Video menu background](./video) (`0.0` ถึง `1.0`)

**ค่า:** จำเป็น — `background_identifier:volume`

## ส่งคำขอ HTTP (`send_http_request`)

**วัตถุประสงค์:** เริ่มคำขอ HTTP/HTTPS ในเบื้องหลัง; สามารถบันทึกและ/หรือเก็บการตอบกลับลงในตัวแปรได้

**ค่า:** จำเป็น — การกำหนดค่าคำขอ HTTP

| การตั้งค่า | พฤติกรรม |
|---|---|
| URL | จุดปลาย HTTP หรือ HTTPS |
| Method | `GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `HEAD`, หรือ `OPTIONS` |
| Body | ส่งสำหรับเมธอดอื่นที่ไม่ใช่ `GET` และ `HEAD` |
| Content type | ค่าของ `Content-Type` ของคำขอ |
| Timeout | จำนวนวินาทีที่ใช้ทั้งสำหรับการเชื่อมต่อและการอ่านการตอบกลับ |
| Log response | อ่านและเขียนการตอบกลับลงล็อก |
| Response variable | อ่านการตอบกลับและเก็บไว้หลังคำขอเสร็จสิ้น |
| Single-line response | ลบบรรทัดใหม่ของการตอบกลับก่อนเก็บ |
| Authentication | None, Basic, Bearer, หรือ API key |
| Headers | ส่วนหัวคำขอแบบกำหนดเองเพิ่มเติม |

คำขอจะรันแบบอะซิงโครนัส ดังนั้นการกระทำถัดไปจะไม่รอ เนื้อหาการตอบกลับจะถูกอ่านก็ต่อเมื่อเปิดการบันทึกลงล็อกหรือกำหนด response variable ไว้; เนื้อหาที่ไม่สำเร็จจะถูกอ่านจากการตอบกลับข้อผิดพลาด อย่าเก็บรหัสผ่านหรือ access token ไว้ในการกำหนดค่าการกระทำ

## ปิดใช้งาน Animator ขององค์ประกอบ (`disable_element_animator`)

**วัตถุประสงค์:** ปิดใช้งานการเล่นและรีเซ็ตไทม์ไลน์ Animator ที่กำลังใช้งานที่ตรงกัน

**ค่า:** จำเป็น — `animator_identifier`

## รีเซ็ต Animator ขององค์ประกอบ (`reset_element_animator`)

**วัตถุประสงค์:** รีเซ็ตไทม์ไลน์ Animator ที่กำลังใช้งานที่ตรงกันโดยไม่เปลี่ยนว่าการเล่นถูกเปิดใช้งานอยู่หรือไม่

**ค่า:** จำเป็น — `animator_identifier`

## เลียนแบบปุ่ม Vanilla/Mod (`mimicbutton`)

**วัตถุประสงค์:** เลียนแบบการคลิกของปุ่ม vanilla หรือ mod

**ค่า:** จำเป็น — [widget locator](./widget-locators) แบบครบถ้วน เช่น `example.menu.identifier:505280`

## เลียนแบบ Keybind (`mimic_keybind`)

**วัตถุประสงค์:** รัน keybind ของแป้นพิมพ์หรือเมาส์ใน Minecraft โดยอาจกดค้างไว้ได้

**ค่า:** จำเป็น — `keybind_id|||keep_pressed_bool|||duration_ms`

| ฟิลด์ | ความหมาย |
|---|---|
| `keybind_id` | ตัวระบุ keybind ของ Minecraft เช่น `key.jump` |
| `keep_pressed_bool` | `true` เพื่อกดค้าง; `false` สำหรับการกดปกติ |
| `duration_ms` | ระยะเวลากดค้างเมื่อ `keep_pressed_bool` เป็น `true`; ค่าเริ่มต้นคือ `1000` |

## ตั้งค่าค่าในช่องกรอกข้อความ (`set_text_input_field_value`)

**วัตถุประสงค์:** ตั้งค่าของ [Text Input Field](./elements#text-input-field) แบบกำหนดเองหรือ Vanilla ตาม identifier ขององค์ประกอบ

**ค่า:** จำเป็น — `element_identifier|||new_value|||force_set_when_inactive`

ฟิลด์ทั้งสามต้องคั่นด้วยตัวคั่นสามขีด `|||` ตั้งค่า `force_set_when_inactive` เป็น `true` เพื่ออัปเดตช่องกรอกข้อความที่ถูกปิดใช้งานด้วย; เมื่อเป็น `false` ช่องที่ไม่ active จะไม่ถูกเปลี่ยนแปลง

## สร้างไฟล์ในไดเรกทอรีเกม (`create_file_in_game_dir`)

**วัตถุประสงค์:** สร้างไฟล์ว่างที่อ้างอิงแบบสัมพันธ์กับไดเรกทอรีเกมที่ใช้งานอยู่ รองรับคำนำหน้า `.minecraft/` เพื่อชี้ไปยังไดเรกทอรี Minecraft แบบดั้งเดิม (ซึ่งอาจแตกต่างจาก instance ปัจจุบัน)

**ค่า:** จำเป็น — `file_path`

ตัวอย่าง: `config/some_mod_folder/new_file.txt` โฟลเดอร์แม่ที่ขาดหายไปจะถูกสร้างขึ้น; ไฟล์ที่มีอยู่แล้วจะไม่ถูกเปลี่ยนแปลง

## ลบไฟล์/โฟลเดอร์ในไดเรกทอรีเกม (`delete_file_in_game_dir`)

**วัตถุประสงค์:** ลบไฟล์ หรือโฟลเดอร์แบบ recursive ที่อ้างอิงกับไดเรกทอรีเกมที่ใช้งานอยู่ รองรับ `.minecraft/` เพื่อชี้ไปยังไดเรกทอรี Minecraft แบบดั้งเดิม ต่อท้าย `*` เพื่อลบ **ทุกไฟล์ที่อยู่ภายในโฟลเดอร์โดยตรง** (ไม่เข้าไปในโฟลเดอร์ย่อย และคงโฟลเดอร์ไว้)

**ค่า:** จำเป็น — `target_path`

ตัวอย่างเช่น `config/downloads/*` จะลบไฟล์ที่อยู่โดยตรงภายใน `config/downloads/` แต่จะไม่เข้าไปหรือ ลบโฟลเดอร์ย่อยของมัน

## คัดลอกไฟล์/โฟลเดอร์ในไดเรกทอรีเกม (`copy_file_in_game_dir`)

**วัตถุประสงค์:** คัดลอกภายในไดเรกทอรีเกมที่ใช้งานอยู่; `.minecraft/` จะชี้ไปยังไดเรกทอรี Minecraft แบบดั้งเดิม ไดเรกทอรีที่ระบุชื่อจะถูกคัดลอกแบบ recursive ต่อท้าย `*` ที่พาธ **ต้นทาง** เพื่อคัดลอกเฉพาะไฟล์ลูกโดยตรงทุกไฟล์; ปลายทางต้องเป็นไดเรกทอรีและไม่สามารถใช้ `*` ได้

**ค่า:** จำเป็น — `source||destination`

ตัวอย่างเช่น `config/source/*||config/destination/` จะคัดลอกเฉพาะไฟล์ที่อยู่โดยตรงภายใน `config/source/` เมื่อใช้ต้นทางแบบ wildcard FancyMenu จะสร้างโฟลเดอร์ปลายทางเมื่อจำเป็น แต่จะไม่คัดลอกโฟลเดอร์ย่อยใด ๆ ของต้นทาง การคัดลอกจะปฏิเสธปลายทางที่มีอยู่แล้ว/ไฟล์ที่ชนกัน แทนที่จะเขียนทับ

## ย้ายไฟล์/โฟลเดอร์ในไดเรกทอรีเกม (`move_file_in_game_dir`)

**วัตถุประสงค์:** ย้ายภายในไดเรกทอรีเกมที่ใช้งานอยู่; `.minecraft/` จะชี้ไปยังไดเรกทอรี Minecraft แบบดั้งเดิม ต่อท้าย `*` ที่พาธ **ต้นทาง** เพื่อย้ายเฉพาะไฟล์ลูกโดยตรงทุกไฟล์; ปลายทางต้องเป็นไดเรกทอรีและไม่สามารถใช้ `*` ได้

**ค่า:** จำเป็น — `source||destination`

ตัวอย่างเช่น `config/source/*||config/destination/` จะย้ายเฉพาะไฟล์ที่อยู่โดยตรงภายใน `config/source/` เมื่อใช้ต้นทางแบบ wildcard FancyMenu จะสร้างโฟลเดอร์ปลายทางเมื่อจำเป็น แต่จะคงโฟลเดอร์ย่อยของต้นทางไว้ในที่เดิม การย้ายจะปฏิเสธปลายทางที่มีอยู่แล้ว/ไฟล์ที่ชนกัน แทนที่จะเขียนทับ

## เปลี่ยนชื่อไฟล์/โฟลเดอร์ในไดเรกทอรีเกม (`rename_file_in_game_dir`)

**วัตถุประสงค์:** เปลี่ยนชื่อไฟล์หรือโฟลเดอร์ภายในโฟลเดอร์แม่ปัจจุบัน; `.minecraft/` จะชี้ไปยังไดเรกทอรี Minecraft แบบดั้งเดิม เก็บเนื้อหาภายในไว้ครบถ้วนและปฏิเสธชื่อปลายทางที่มีอยู่แล้ว

**ค่า:** จำเป็น — `path||new_name`

## ดาวน์โหลดไฟล์ไปยังไดเรกทอรีเกม (`download_file_to_game_dir`)

**วัตถุประสงค์:** ดาวน์โหลดไฟล์ในเบื้องหลังไปยังโฟลเดอร์ที่อ้างอิงกับไดเรกทอรีเกมที่ใช้งานอยู่; `.minecraft/` จะชี้ไปยังไดเรกทอรี Minecraft แบบดั้งเดิม

**ค่า:** จำเป็น — `url||target_folder`

ฟิลด์ที่สองคือ **ไดเรกทอรีปลายทาง** ไม่ใช่พาธไฟล์ปลายทางแบบสมบูรณ์ FancyMenu จะสร้างไดเรกทอรีเมื่อจำเป็นและกำหนดชื่อไฟล์จากส่วนหัว `Content-Disposition` ของการตอบกลับ จากนั้นจึง fallback ไปใช้ path ของ URL ชื่อที่ได้จะถูก decode จาก URL และทำความสะอาดก่อนใช้งาน; หากไม่มีแหล่งใดให้ชื่อที่ใช้ได้ FancyMenu จะสร้างชื่อขึ้นมาเอง ไฟล์ที่มีชื่อเดียวกันอยู่แล้วจะถูกเขียนทับ

[**On File Downloaded via Action** listener](./listeners#on-file-downloaded-via-action-file_downloaded_via_action) จะทำงานหลังทั้งความพยายามดาวน์โหลดที่สำเร็จและล้มเหลว และจะเปิดเผย URL, พาธปลายทางที่แก้ไขแล้ว และสถานะความสำเร็จ

เมื่อสำเร็จ `$$target_file_path` คือพาธของไฟล์ที่บันทึกไว้ เมื่อไม่สำเร็จ มันอาจมีเพียงไดเรกทอรีปลายทาง เพราะยังไม่สามารถแก้ไขชื่อไฟล์สุดท้ายได้

## แตกไฟล์ ZIP ในไดเรกทอรีเกม (`extract_zip_file_in_game_dir`)

**วัตถุประสงค์:** แตกไฟล์ ZIP ไปยังโฟลเดอร์ปลายในไดเรกทอรีเกมที่ใช้งานอยู่หรือไดเรกทอรี `.minecraft` แบบดั้งเดิม เมื่อเสร็จสิ้นจะเรียก [**On ZIP Extracted via Action**](./listeners#on-zip-extracted-via-action-zip_extracted_via_action)

**ค่า:** จำเป็น — `source_zip_path||target_folder_path`

ไฟล์ที่มีชื่อเดียวกันซึ่งมีอยู่แล้วจะถูกแทนที่ ควรแตกเฉพาะไฟล์ ZIP ที่เชื่อถือได้

## เปิดไฟล์/โฟลเดอร์ในไดเรกทอรีเกม (`open_file_folder_in_game_dir`)

**วัตถุประสงค์:** เปิดไฟล์หรือโฟลเดอร์ด้วยแอปเริ่มต้นของระบบปฏิบัติการ ปลายทางต้องอยู่ภายในไดเรกทอรีเกมหรือไดเรกทอรี `.minecraft` เริ่มต้นเพื่อความปลอดภัย

**ค่า:** จำเป็น — `target_path`

## เขียนไฟล์ในไดเรกทอรีเกม (`write_file_in_game_dir`)

**วัตถุประสงค์:** เขียนหรือเพิ่มข้อความแบบอ้างอิงกับไดเรกทอรีเกมที่ใช้งานอยู่; `.minecraft/` จะชี้ไปยังไดเรกทอรี Minecraft แบบดั้งเดิม สร้างไฟล์และโฟลเดอร์แม่หากยังไม่มี `\n` ใช้แทรกการขึ้นบรรทัดใหม่; `append_bool=false` จะเขียนทับไฟล์ที่มีอยู่

**ค่า:** จำเป็น — `path|||content|||append_bool`

## เลือกไฟล์จากระบบ (`select_file_to_game_dir`)

**วัตถุประสงค์:** เปิดตัวเลือกไฟล์แบบ native และคัดลอกไฟล์ที่เลือกเข้าไปในไดเรกทอรีเกมที่ใช้งานอยู่ หรือ `.minecraft/` แบบดั้งเดิมเมื่อมีคำนำหน้า รองรับตัวกรองนามสกุล ป้ายกำกับตัวกรองแบบกำหนดเอง และสวิตช์เขียนทับ

**ค่า:** จำเป็น — `target_path|||filter_description|||extensions|||overwrite_bool`

`target_path` คือพาธไฟล์ปลายทางแบบสมบูรณ์ แยกนามสกุลหลายตัวด้วย `;` หรือ `,` เช่น `png;jpg`; หากรายการนามสกุลว่างจะอนุญาตทุกไฟล์ หาก `overwrite_bool` เป็น `false` การกระทำจะล้มเหลวแทนที่จะเขียนทับไฟล์ปลายทางที่มีอยู่แล้ว

[**On File Selected** listener](./listeners#on-file-selected-file_selected_via_action) จะทำงานเมื่อไฟล์ถูกคัดลอก เมื่อยกเลิกตัวเลือกไฟล์ หรือเมื่อการเลือกไฟล์ล้มเหลว มันจะแสดงพาธที่เลือก พาธปลายทางที่แก้ไขแล้ว สถานะสำเร็จ/ยกเลิก และสาเหตุความล้มเหลว

## แสดง Toast (`show_toast`)

**วัตถุประสงค์:** แสดงการแจ้งเตือน toast ที่กำหนดค่าได้

**ค่า:** จำเป็น — การกำหนดค่า toast แบบ JSON

ตัวแก้ไขจะเก็บการกระทำนี้เป็น JSON ควรใช้หน้าต่างกำหนดค่าของมันแทนการแก้ไขค่าด้วยตนเอง

| ฟิลด์ | ความหมาย |
|---|---|
| `width` | จำกัดให้อยู่ในช่วง `120`–`320` พิกเซล |
| `durationMs` | จำกัดให้อยู่ในช่วง `1000`–`600000` มิลลิวินาที |
| `title` | ข้อความธรรมดา, Minecraft text component ที่ซีเรียลไลซ์แล้ว, หรือว่าง |
| `message` | ข้อความธรรมดา, text component ที่ซีเรียลไลซ์แล้ว, หรือว่าง |
| `iconSource` | [แหล่งรูปภาพ](./resources) แบบเลือกใช้ได้ |
| `backgroundSource` | [แหล่งรูปภาพ](./resources) แบบเลือกใช้ได้ |

**ค่า:** จำเป็น — `scheduler_id`

**วัตถุประสงค์:** แก้ไขตัวเลือกคอนฟิกของ Minecraft
