# เลเยอร์และกลุ่ม

เปิดวิดเจ็ต Layers ผ่าน **Window -> Editor Widgets -> Layers**.

# ลำดับเลเยอร์

ลากเลเยอร์ในรายการเพื่อเปลี่ยนลำดับการแสดงผล คุณยังสามารถคลิกขวาที่องค์ประกอบแล้วใช้ **Move One Layer Up** หรือ **Move One Layer Down**.

องค์ประกอบ [Player Entity](./elements#player-entity) และ [Item](./elements#item) สามารถมีข้อจำกัดในการแสดงผล ซึ่งจะป้องกันไม่ให้จัดลำดับเลเยอร์ตามปกติได้

# กลุ่ม

กลุ่มช่วยจัดระเบียบเลเยอร์ที่เกี่ยวข้องกัน และให้คุณย้ายหรือซ่อนพวกมันพร้อมกันได้

- สร้างและเปลี่ยนชื่อกลุ่ม
- เปลี่ยนชื่อเลเยอร์แต่ละรายการ
- ลากเลเยอร์เข้าไปในกลุ่มหรือออกจากกลุ่ม
- ลากกลุ่มเพื่อย้ายเลเยอร์ทั้งหมดของกลุ่มในลำดับ
- ยุบหรือขยายกลุ่ม
- แสดงหรือซ่อนทุกเลเยอร์ในกลุ่ม
- ลบกลุ่มโดยไม่ลบเลเยอร์ภายใน

สมาชิกของกลุ่มและสถานะการยุบจะถูกบันทึกไปพร้อมกับเลย์เอาต์
