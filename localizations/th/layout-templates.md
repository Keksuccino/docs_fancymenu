# เทมเพลตเลย์เอาต์

หากคุณต้องการดาวน์โหลดเทมเพลตดีไซน์สำหรับ FancyMenu หรือแอดออนของมันอย่าง SpiffyHud หรือ Drippy Loading Screen สถานที่ที่ดีที่สุดในการดูคือช่อง [#layout-templates](https://discord.com/channels/704163135787106365/1234093433795383316) ในเซิร์ฟเวอร์ Discord ของ Kekscord (เซิร์ฟเวอร์ Discord ทางการของ Keksuccino สำหรับการซัพพอร์ตม็อด) ช่องนี้มีชุด FancyMenu แบบสมบูรณ์ที่สร้างโดยชุมชน พร้อมลิงก์ดาวน์โหลดสำหรับทุกชุด

โพสต์เทมเพลตทั้งหมดในนั้นจะมีรูปแบบคล้ายกัน โดยควรมีลิงก์ดาวน์โหลดไปยังชุด FancyMenu แบบเต็ม ซึ่งมีโฟลเดอร์ `fancymenu` ที่คุณควรใช้แทนโฟลเดอร์ `/config/fancymenu/` ของคุณเอง ตามที่อธิบายไว้ในหน้า [Modpacks](/modpacks)

เนื่องจากเทมเพลตเหล่านี้มักมีความซับซ้อนมาก จึงไม่แนะนำให้พยายามผสานเทมเพลตเข้ากับการตั้งค่าที่มีอยู่ของคุณ นั่นคือเหตุผลที่คุณควรแทนที่โฟลเดอร์ `fancymenu` เดิมด้วยโฟลเดอร์จากเทมเพลต

# การแก้ไขเทมเพลตหรือการนำไปใช้กับโปรเจกต์ของคุณ

เทมเพลตส่วนใหญ่ในช่องนี้อนุญาตให้คุณแก้ไขได้ และยังสามารถนำไปใช้ในโปรเจกต์ของคุณเอง เช่น ม็อดแพ็กได้ แต่สิ่งสำคัญมากคือคุณต้อง **ตรวจสอบโพสต์ของเทมเพลตว่าอนุญาตให้ทำอะไรได้บ้างกับมัน**!

ไม่ใช่ทุกเทมเพลตที่จะให้สิทธิ์เต็มรูปแบบในการทำทุกอย่าง
