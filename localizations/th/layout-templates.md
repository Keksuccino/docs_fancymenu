# เทมเพลตเลย์เอาต์

หากคุณต้องการดาวน์โหลดเทมเพลตดีไซน์สำหรับ FancyMenu หรือแอดออนอย่าง SpiffyHUD หรือ Drippy Loading Screen แหล่งที่ควรตรวจสอบคือช่อง [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) ใน [เซิร์ฟเวอร์ Discord ของ Kekscord](https://discord.gg/rhayah27GC) (เซิร์ฟเวอร์ Discord อย่างเป็นทางการของ Keksuccino สำหรับการช่วยเหลือเกี่ยวกับม็อด) ช่องนี้มีชุดการตั้งค่า FancyMenu แบบเต็มรูปแบบที่สร้างโดยชุมชน พร้อมลิงก์ดาวน์โหลดทั้งหมด

โพสต์เทมเพลตทั้งหมดในช่องนี้ใช้รูปแบบเดียวกัน โดยแต่ละโพสต์ควรมีลิงก์ดาวน์โหลดชุดการตั้งค่า FancyMenu แบบเต็มรูปแบบ ซึ่งอยู่ในรูปไฟล์โปรไฟล์ (`.fmp`) หรือโฟลเดอร์ `fancymenu`

> [!CAUTION]
> เทมเพลตจากชุมชนอาจเรียกใช้แอ็กชันได้ โปรดนำเข้าเทมเพลตจากแหล่งที่คุณเชื่อถือเท่านั้น

# การติดตั้งเทมเพลต

เทมเพลตเป็นชุดการตั้งค่า FancyMenu แบบสมบูรณ์และส่วนใหญ่มักมีความซับซ้อนมาก จึงไม่แนะนำให้พยายามผสานเทมเพลตเข้ากับชุดการตั้งค่าที่มีอยู่ ให้เพิ่มเทมเพลตเป็น[โปรไฟล์](./profiles)แยกต่างหากแทน:

- **ไฟล์ `.fmp`:** เปิด **แถบเมนู -> Customization -> Profiles** แล้ว[นำเข้า](./profiles#importing)ไฟล์ดังกล่าว เช่น ลากไฟล์ไปวางบนหน้าต่าง
- **โฟลเดอร์ `fancymenu`:** [เพิ่มโฟลเดอร์เป็นโปรไฟล์](./profiles#adding-setup-folders)

จากนั้นเลือกเทมเพลตในหน้าต่าง Profiles แล้วคลิก **Load Profile** ชุดการตั้งค่าปัจจุบันของคุณจะยังคงอยู่ในรูปโปรไฟล์ของตัวเอง คุณจึงสามารถสลับกลับไปใช้ได้ทุกเมื่อ

# การแก้ไขเทมเพลตหรือการนำไปใช้กับโปรเจกต์

เทมเพลตส่วนใหญ่ในช่องนี้อนุญาตให้คุณแก้ไขและนำไปใช้ในโปรเจกต์ของคุณเอง เช่น ม็อดแพ็ก แต่สิ่งสำคัญอย่างยิ่งคือคุณต้อง **ตรวจสอบโพสต์ของเทมเพลตว่าอนุญาตให้คุณทำอะไรกับเทมเพลตได้บ้าง**!

เทมเพลตบางรายการไม่ได้อนุญาตให้คุณทำได้ทุกอย่าง
