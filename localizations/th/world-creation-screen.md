# หน้าจอการสร้างโลก

หากคุณเคยลองปรับแต่งหน้าจอการสร้างโลก (หรือที่เรียกว่า Create World, New World, New Game) มาก่อน คุณคงสังเกตแล้วว่ามัน _ยุ่งยาก_ มากในการปรับแต่ง นั่นเป็นเพราะหน้าจอนี้ค่อนข้างซับซ้อน และถูกสร้างขึ้นในลักษณะที่ทำให้ FancyMenu ปรับแต่งได้ยากมาก เนื่องจากปุ่มและองค์ประกอบ GUI อื่น ๆ ถูกซ้อนทับกันอยู่

ใน Minecraft เวอร์ชันใหม่ ๆ ความสามารถในการปรับแต่งกลับแย่ลงไปอีก เนื่องจากระบบแท็บแบบใหม่

ทั้งหมดนี้ทำให้ **ไม่แนะนำ** ให้ปรับแต่งหน้าจอนี้ อย่างน้อยก็ไม่ควรทำการปรับแต่งที่ซับซ้อน เช่น การแก้ไของค์ประกอบ GUI ที่มีอยู่ (เช่น ปุ่มแบบ Vanilla ฯลฯ) หรือการเพิ่มองค์ประกอบแบบกำหนดเองใหม่ ๆ การตั้งค่าพื้นหลังแบบกำหนดเองน่าจะยังพอทำได้ แต่ถ้าเกินกว่านั้นจะเริ่มยุ่งเหยิง ดังนั้นทางที่ดีที่สุดคืออย่าปรับแต่งมันมากเกินไป
