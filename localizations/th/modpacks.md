# FancyMenu ในม็อดแพ็ก

การรวมการตั้งค่า FancyMenu ของคุณไว้ในม็อดแพ็กทำได้ง่ายมาก และใช้เพียงไม่กี่ขั้นตอนเท่านั้น

> หน้านี้มีไว้สำหรับการตั้งค่า FancyMenu ที่สร้างขึ้นทั้งหมดใน **FancyMenu v3+** **เท่านั้น** ดังนั้นถ้าคุณใช้การตั้งค่าแบบเก่า (สร้างใน v2 และแปลงเป็น v3) บางขั้นตอนอาจแตกต่างออกไป
{.is-warning}

# การรวมการตั้งค่า FancyMenu ไว้ในม็อดแพ็กของคุณ

สิ่งสำคัญที่คุณต้องทำคือคัดลอกโฟลเดอร์พิเศษหนึ่งโฟลเดอร์ที่ FancyMenu ใช้เก็บดีไซน์ทั้งหมดของคุณ

## สิ่งที่คุณต้องหา

1. **โฟลเดอร์ "Minecraft Instance" ของคุณ:** นี่คือโฟลเดอร์หลักบนคอมพิวเตอร์ของคุณที่เก็บไฟล์ทั้งหมดของการติดตั้ง Minecraft เฉพาะชุดหนึ่ง (เช่น ชุดที่คุณใช้สร้างเมนูของคุณ) ตัว Launcher อย่าง CurseForge และ Modrinth จะเรียกสิ่งเหล่านี้ว่า "instances" หรือ "profiles"
2. **โฟลเดอร์ `config`:** ภายในโฟลเดอร์ Minecraft instance ของคุณ ปกติจะมีโฟลเดอร์ชื่อ `config` ซึ่งเป็นที่ที่ม็อดหลายตัวเก็บการตั้งค่าของตนไว้
3. **โฟลเดอร์ `fancymenu`:** ภายในโฟลเดอร์ `config` นั้น FancyMenu จะสร้างโฟลเดอร์ของตัวเองชื่อ `fancymenu` นี่คือโฟลเดอร์ทองคำที่เราต้องการ!

## วิธีค้นหาตำแหน่งบันทึกของ Instance

### ถ้าคุณใช้ CurseForge App

1. เปิด CurseForge
2. หาโปรไฟล์/instance ของ Minecraft ของคุณในรายการ แล้วเปิดมัน
3. คลิกจุดสามจุด
4. เลือก "Open Folder" ซึ่งจะเปิดโฟลเดอร์หลักของ Minecraft instance นั้น

3. คลิกจุดสามจุด
4. เลือก "Open Folder" ซึ่งจะเปิดโฟลเดอร์หลักของ Minecraft instance นั้น

### สำหรับตัว Launcher อื่น ๆ

ให้มองหาตัวเลือกที่คล้ายกัน เช่น "Open Folder", "Open Instance Folder" หรือ "View Files" สำหรับการตั้งค่า Minecraft ของคุณ

## การคัดลอกการตั้งค่า FancyMenu

1. ไปที่โฟลเดอร์ `config` ของ instance ม็อดแพ็กของคุณ (อันที่คุณต้องการคัดลอกการตั้งค่าไปไว้)
2. ถ้ามีโฟลเดอร์ `fancymenu` อยู่ข้างใน ให้ลบโฟลเดอร์นั้นทิ้ง
3. เปิดโฟลเดอร์ `config` ของ SOURCE instance (อันที่คุณต้องการใช้การตั้งค่าจาก)
4. คัดลอกโฟลเดอร์ `fancymenu` ภายในโฟลเดอร์ `config` ของ SOURCE instance ไปยังโฟลเดอร์ `config` ของ instance ม็อดแพ็กของคุณ
5. เสร็จเรียบร้อย แค่นั้นเอง ตอนนี้ให้รีสตาร์ต instance ม็อดแพ็กของคุณ แล้วคุณควรจะเห็นการตั้งค่าถูกโหลดขึ้นมา

> โปรดทราบว่า การตั้งค่าแบบ legacy เก่าที่สร้างใน FancyMenu v2 (แม้จะแปลงเป็น v3 แล้วก็ตาม) อนุญาตให้เก็บไฟล์ทรัพยากรของเลย์เอาต์ไว้นอกโฟลเดอร์ `/config/fancymenu/assets/` ของ FancyMenu ได้ ดังนั้นในกรณีนั้น คุณต้องแน่ใจว่าคุณได้รวมไฟล์ทรัพยากรทั้งหมดไว้ในม็อดแพ็กด้วย
{.is-danger}

# ปิดแถบเมนูและปุ่มลัด

แน่นอนว่าคุณคงไม่อยากให้แถบเมนูของ FancyMenu แสดงอยู่ในม็อดแพ็กของคุณ ดังนั้นคุณควรปิดมัน แต่เนื่องจากผู้เล่นยังสามารถกดปุ่มลัดเพื่อให้มันแสดงขึ้นมาได้อีก มาทำอะไรที่ *จริงจังกว่านี้* กันหน่อย

ไปที่ `/config/fancymenu/options.txt` แล้วเปิดไฟล์ด้วยโปรแกรมแก้ไขข้อความ

จากนั้นตั้งค่า `modpack_mode` เป็น `true` แล้วบันทึกไฟล์
การทำเช่นนี้จะปิดการแสดงโอเวอร์เลย์และปุ่มลัดทั้งหมดอย่างสมบูรณ์

หากต้องการแก้ไขเลย์เอาต์ของคุณอีกครั้ง ให้เปลี่ยนค่าตัวเลือกใน config กลับเป็น `false`

# ปิดหน้าจอต้อนรับ

โดยส่วนใหญ่แล้วขั้นตอนนี้ไม่จำเป็น แต่ถ้าคุณยังไม่ได้ปิดหน้าจอต้อนรับ (หน้าจอที่บอกให้คุณอ่านเอกสาร) ให้แน่ใจว่าตั้งค่า `show_welcome_screen` เป็น `false` ใน `/config/fancymenu/options.txt`

หน้าจอนี้จะแสดงเพียงครั้งเดียวและจะปิดตัวเองเมื่อคลิกปุ่ม **Open Documentation** ดังนั้นอีกครั้ง การทำด้วยตนเองจึงมักไม่จำเป็นในกรณีส่วนใหญ่
