# FancyMenu ในม็อดแพ็ก

การรวมการตั้งค่า FancyMenu ของคุณไว้ในม็อดแพ็กนั้นทำได้ง่ายมากและใช้เพียงไม่กี่ขั้นตอน

> [!CAUTION]
> การตั้งค่า FancyMenu สามารถเรียกใช้คำสั่งต่าง ๆ ได้ ดังนั้นควรนำเข้าเฉพาะการตั้งค่าจากแหล่งที่คุณไว้วางใจเท่านั้น

> [!WARNING]
> หน้านี้ใช้สำหรับการตั้งค่า FancyMenu ที่สร้างขึ้นด้วย **FancyMenu v3 ขึ้นไปเท่านั้น** ดังนั้นหากคุณใช้การตั้งค่าแบบเก่า (สร้างใน v2 และแปลงเป็น v3) ขั้นตอนบางอย่างอาจแตกต่างออกไป

# นำการตั้งค่าของคุณเข้าไปในม็อดแพ็ก

วิธีที่ง่ายที่สุดในการย้ายการตั้งค่าจากอินสแตนซ์ที่คุณออกแบบไว้ไปยังอินสแตนซ์ของม็อดแพ็ก คือการใช้ [โปรไฟล์](./profiles):

1. ในอินสแตนซ์ที่มีการตั้งค่าของคุณ ให้เปิด **แถบเมนู -> การปรับแต่ง -> โปรไฟล์** เลือกการตั้งค่าของคุณ แล้ว[ส่งออก](./profiles#exporting)เป็นไฟล์ `.fmp`
2. ในอินสแตนซ์ของม็อดแพ็ก ให้เปิดหน้าต่างโปรไฟล์ แล้ว[นำเข้า](./profiles#importing)ไฟล์ `.fmp` เช่น ลากไฟล์ไปวางบนหน้าต่าง
3. เลือกโปรไฟล์ที่นำเข้า แล้วคลิก **โหลดโปรไฟล์**

การตั้งค่า FancyMenu เดิมของอินสแตนซ์ม็อดแพ็กจะไม่สูญหาย แต่จะยังคงอยู่เป็นโปรไฟล์ของตัวเอง คุณจึงสามารถสลับกลับไปใช้ได้เสมอ

# รวมการตั้งค่าไว้กับม็อดแพ็ก

โปรไฟล์ที่โหลดอยู่คือเนื้อหาภายใน `<game-directory>/config/fancymenu/` ดังนั้นโปรไฟล์นี้จะถูกจัดส่งไปพร้อมกับโฟลเดอร์ `config` ของม็อดแพ็ก เช่นเดียวกับไฟล์กำหนดค่าของม็อดอื่น ๆ

โปรไฟล์อื่น ๆ ทั้งหมดของอินสแตนซ์จะถูกจัดเก็บไว้ใน `<game-directory>/config/fancymenu/profiles/` ให้ลบโปรไฟล์ที่ผู้เล่นไม่ควรได้รับก่อนส่งออกม็อดแพ็ก หรือไม่นำโฟลเดอร์ `profiles` ไปรวมไว้ในการส่งออกม็อดแพ็ก

> [!CAUTION]
> โปรดทราบว่าการตั้งค่าแบบเก่าที่สร้างใน FancyMenu v2 (แม้จะแปลงเป็น v3 แล้วก็ตาม) อนุญาตให้คุณจัดเก็บทรัพยากรของเลย์เอาต์ไว้นอกโฟลเดอร์ `<game-directory>/config/fancymenu/assets/` ของ FancyMenu ได้ โปรไฟล์จะมีเฉพาะโฟลเดอร์ config ของ FancyMenu เท่านั้น ดังนั้นในกรณีนี้คุณต้องตรวจสอบให้แน่ใจว่าได้รวมทรัพยากรทั้งหมดไว้ในม็อดแพ็กด้วย

## วิธีค้นหาโฟลเดอร์อินสแตนซ์

โฟลเดอร์อินสแตนซ์คือโฟลเดอร์หลักบนคอมพิวเตอร์ของคุณที่จัดเก็บไฟล์ทั้งหมดของการตั้งค่า Minecraft แต่ละชุดไว้ ลอนเชอร์อย่าง CurseForge และ Modrinth เรียกสิ่งเหล่านี้ว่า "อินสแตนซ์" หรือ "โปรไฟล์" (อย่าสับสนกับโปรไฟล์ของ FancyMenu)

### หากคุณใช้แอป CurseForge

1. เปิด CurseForge
2. ค้นหาโปรไฟล์/อินสแตนซ์ Minecraft ของคุณในรายการ แล้วเปิดขึ้นมา
3. คลิกจุดสามจุด
4. เลือก "เปิดโฟลเดอร์" การดำเนินการนี้จะเปิดโฟลเดอร์หลักของอินสแตนซ์ Minecraft นั้น

3. คลิกจุดสามจุด
4. เลือก "เปิดโฟลเดอร์" การดำเนินการนี้จะเปิดโฟลเดอร์หลักของอินสแตนซ์ Minecraft นั้น

# ปิดใช้งานแถบเมนูและปุ่มลัด

แน่นอนว่าคุณคงไม่ต้องการให้แถบเมนูของ FancyMenu แสดงอยู่ในม็อดแพ็ก ดังนั้นควรปิดใช้งาน แต่เนื่องจากผู้ใช้ยังสามารถกดปุ่มลัดเพื่อทำให้แถบเมนูกลับมาแสดงได้ เรามาทำให้เข้มงวดขึ้นอีกเล็กน้อยกัน

ไปที่ `<game-directory>/config/fancymenu/options.txt` แล้วเปิดไฟล์ด้วยโปรแกรมแก้ไขข้อความ

ตั้งค่า `modpack_mode` เป็น `true` แล้วบันทึกไฟล์
การดำเนินการนี้จะปิดใช้งานโอเวอร์เลย์และปุ่มลัดทั้งหมดโดยสมบูรณ์

หากต้องการแก้ไขเลย์เอาต์อีกครั้ง ให้เปลี่ยนตัวเลือกการกำหนดค่ากลับเป็น `false`

# ปิดใช้งานหน้าจอต้อนรับ

โดยส่วนใหญ่แล้วไม่จำเป็นต้องทำขั้นตอนนี้ แต่หากคุณยังไม่ได้ปิดหน้าจอต้อนรับ (หน้าจอที่แจ้งให้คุณอ่านเอกสาร) ให้ตรวจสอบว่าได้ตั้งค่า `show_welcome_screen` เป็น `false` ใน `<game-directory>/config/fancymenu/options.txt` แล้ว

หน้าจอนี้จะแสดงเพียงครั้งเดียวและจะปิดใช้งานตัวเองเมื่อคลิกปุ่ม **เปิดเอกสาร** ดังนั้นโดยส่วนใหญ่แล้วจึงไม่จำเป็นต้องตั้งค่าด้วยตนเอง
