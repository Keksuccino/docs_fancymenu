# FancyMenu ในม็อดแพ็ก

การรวมการตั้งค่า FancyMenu ของคุณไว้ในม็อดแพ็กนั้นทำได้ง่ายมาก และใช้เพียงไม่กี่ขั้นตอนเท่านั้น

> [!CAUTION]
> การตั้งค่า FancyMenu สามารถเรียกใช้การกระทำได้ ให้นำเข้าเฉพาะจากแหล่งที่คุณไว้ใจเท่านั้น

> [!WARNING]
> หน้านี้มีไว้ **เฉพาะ** สำหรับการตั้งค่า FancyMenu ที่สร้างขึ้นทั้งหมดใน **FancyMenu v3+** เท่านั้น ดังนั้นหากคุณใช้การตั้งค่าแบบเก่า (สร้างใน v2 แล้วแปลงเป็น v3) ขั้นตอนบางอย่างอาจแตกต่างออกไป

# การรวมการตั้งค่า FancyMenu ไว้ในม็อดแพ็กของคุณ

สิ่งหลักที่คุณต้องทำคือคัดลอกโฟลเดอร์พิเศษหนึ่งโฟลเดอร์ที่ FancyMenu ใช้บันทึกดีไซน์ทั้งหมดของคุณ

## สิ่งที่คุณต้องหา

1. **โฟลเดอร์ "Minecraft Instance" ของคุณ:** นี่คือโฟลเดอร์หลักบนคอมพิวเตอร์ของคุณที่เก็บไฟล์ทั้งหมดสำหรับการติดตั้ง Minecraft ชุดหนึ่งโดยเฉพาะ (เช่น ชุดที่คุณใช้สร้างเมนูของคุณ) ตัวเปิดเกมอย่าง CurseForge และ Modrinth จะเรียกสิ่งนี้ว่า "instances" หรือ "profiles"
2. **โฟลเดอร์ `config`:** ภายในโฟลเดอร์ Minecraft instance ของคุณ โดยปกติจะมีโฟลเดอร์ชื่อ `config` ซึ่งเป็นที่ที่ม็อดจำนวนมากเก็บการตั้งค่าของตน
3. **โฟลเดอร์ `fancymenu`:** ภายในโฟลเดอร์ `config` นั้น FancyMenu จะสร้างโฟลเดอร์ของตัวเองชื่อ `fancymenu` นี่แหละคือโฟลเดอร์สำคัญที่เราต้องใช้!

## วิธีหาโฟลเดอร์บันทึกของ Instance

### หากคุณใช้ CurseForge App

1. เปิด CurseForge
2. หาโปรไฟล์/instance ของ Minecraft ของคุณในรายการ แล้วเปิดมันขึ้นมา
3. คลิกจุดสามจุด
4. เลือก "Open Folder" ซึ่งจะเปิดโฟลเดอร์หลักของ Minecraft instance นั้น

3. คลิกจุดสามจุด
4. เลือก "Open Folder" ซึ่งจะเปิดโฟลเดอร์หลักของ Minecraft instance นั้น

### สำหรับตัวเปิดเกมอื่น ๆ

ให้มองหาตัวเลือกที่คล้ายกับ "Open Folder", "Open Instance Folder" หรือ "View Files" สำหรับการติดตั้ง Minecraft ของคุณโดยเฉพาะ

## การคัดลอกการตั้งค่า FancyMenu

1. ไปที่โฟลเดอร์ `config` ของ instance ม็อดแพ็กของคุณ (ตัวที่คุณต้องการคัดลอกการตั้งค่าไปไว้)
2. ถ้ามีโฟลเดอร์ `fancymenu` อยู่ข้างใน ให้ลบ `fancymenu` นั้นทิ้ง
3. เปิดโฟลเดอร์ `config` ของ SOURCE instance (ตัวที่คุณต้องการใช้การตั้งค่าจากมัน)
4. คัดลอกโฟลเดอร์ `fancymenu` ภายในโฟลเดอร์ `config` ของ SOURCE instance ไปไว้ในโฟลเดอร์ `config` ของ instance ม็อดแพ็กของคุณ
5. เสร็จแล้ว เพียงเท่านี้ รีสตาร์ท instance ม็อดแพ็กของคุณตอนนี้ แล้วคุณควรจะเห็นการตั้งค่าถูกโหลดขึ้นมา

> [!CAUTION]
> โปรดทราบว่าการตั้งค่าแบบเก่าใน FancyMenu v2 (แม้จะถูกแปลงเป็น v3 แล้ว) อนุญาตให้คุณเก็บไฟล์แอสเซ็ตของเลย์เอาต์ไว้นอกโฟลเดอร์ `<game-directory>/config/fancymenu/assets/` ของ FancyMenu ได้ ดังนั้นในกรณีนั้น คุณต้องตรวจสอบให้แน่ใจว่าคุณได้รวมแอสเซ็ตทั้งหมดไว้ในม็อดแพ็กด้วย

# ปิดใช้งานแถบเมนูและฮอตคีย์

แน่นอนว่าคุณคงไม่อยากให้แถบเมนูของ FancyMenu แสดงอยู่ในม็อดแพ็กของคุณ ดังนั้นคุณควรปิดมัน แต่เนื่องจากผู้เล่นยังสามารถกดฮอตคีย์เพื่อแสดงมันกลับมาได้ เรามาทำอะไรที่ *จริงจัง* ขึ้นอีกหน่อยกันดีกว่า

ไปที่ `<game-directory>/config/fancymenu/options.txt` แล้วเปิดไฟล์ด้วยโปรแกรมแก้ไขข้อความ

จากนั้นตั้งค่า `modpack_mode` เป็น `true` แล้วบันทึกไฟล์
การทำเช่นนี้จะปิดใช้งานโอเวอร์เลย์และฮอตคีย์ทั้งหมดโดยสมบูรณ์

หากต้องการกลับไปแก้ไขเลย์เอาต์ของคุณอีกครั้ง ให้เปลี่ยนค่าตัวเลือกในคอนฟิกกลับเป็น `false`

# ปิดใช้งานหน้าจอต้อนรับ

โดยปกติแล้วไม่จำเป็นต้องทำขั้นตอนนี้ แต่หากคุณยังไม่ได้ปิดหน้าจอต้อนรับ (หน้าจอที่บอกให้คุณอ่านเอกสาร) ให้ตั้งค่า `show_welcome_screen` เป็น `false` ใน `<game-directory>/config/fancymenu/options.txt`

หน้าจอนี้จะแสดงเพียงครั้งเดียวและจะปิดตัวเองเมื่อคลิกปุ่ม **Open Documentation** ดังนั้นอีกครั้ง การทำด้วยตนเองจึงไม่จำเป็นในกรณีส่วนใหญ่
