# การทำให้เลย์เอาต์เป็นภาษาท้องถิ่น

FancyMenu ช่วยให้คุณทำให้ข้อความและแม้แต่ทั้งองค์ประกอบหรือเลย์เอาต์รองรับหลายภาษาได้!

# เนื้อหาข้อความ

FancyMenu อนุญาตให้คุณเพิ่มการแปลภาษาของคุณเองลงในเกมได้
จากนั้นจึงนำไปใช้กับตัวแทน **Localize Text** เพื่อแปลข้อความให้ตรงกับภาษาของเกมที่ใช้อยู่ในปัจจุบัน

## การใช้คีย์แปลภาษาของ Vanilla Minecraft

ก่อนที่จะสร้างการแปลภาษาแบบกำหนดเอง คุณอาจต้องการใช้คีย์แปลภาษาที่มีอยู่แล้วของ Minecraft ซึ่งช่วยประหยัดเวลาและทำให้ข้อความสอดคล้องกับข้อความแบบ vanilla ของ Minecraft

### การค้นหาคีย์แปลภาษาแบบ Vanilla

วิธีที่ง่ายที่สุดในการหาคีย์แปลภาษาของ Minecraft คือการเปิดดูไฟล์ asset ของเกมผ่านเว็บไซต์ออนไลน์:

1. **ไปที่ MCAsset.cloud:**  
   ไปที่ [https://mcasset.cloud/](https://mcasset.cloud/) - เว็บไซต์นี้ช่วยให้คุณเรียกดู asset ของ Minecraft ได้โดยไม่ต้องแตกไฟล์ออกมาจากเกม

2. **ไปที่ไฟล์ภาษา:**  
   - เลือกเวอร์ชัน Minecraft ของคุณจากรายการแบบดรอปดาวน์
   - ไปที่: `assets` → `minecraft` → `lang`
   - เปิด `en_us.json` เพื่อดูการแปลภาษาอังกฤษทั้งหมด

3. **หาคีย์ที่คุณต้องการ:**  
   - ใช้ฟังก์ชันค้นหาของเบราว์เซอร์ (Ctrl+F หรือ Cmd+F) เพื่อค้นหาข้อความที่ต้องการ
   - รูปแบบจะเป็น `"key": "text"` - ส่วนแรกที่อยู่ในเครื่องหมายคำพูดก่อนเครื่องหมายโคลอน (`:`) คือคีย์
   - ตัวอย่าง: `"menu.singleplayer": "Singleplayer"` - คีย์คือ `menu.singleplayer`

### การใช้คีย์แปลภาษาของม็อด

ถ้าคุณติดตั้งม็อดอื่น ๆ อยู่ คุณสามารถใช้คีย์แปลภาษาของม็อดเหล่านั้นได้เช่นกัน:

1. ตรวจสอบเอกสารของม็อดเพื่อดูคีย์ที่มีให้ใช้งาน
2. เปิดดูไฟล์ภาษาของม็อดถ้าเป็นโอเพนซอร์ส

## ไฟล์แปลภาษาแบบกำหนดเอง

ไฟล์แปลภาษาเป็นไฟล์ข้อความที่เก็บเนื้อหาข้อความทั้งหมดที่ต้องการให้มีได้หลายภาษา โดยข้อความแต่ละรายการที่แปลได้จะมีคีย์เฉพาะของตัวเอง เพื่อให้ Minecraft ค้นหาข้อความที่แปลได้ถูกต้องในไฟล์แปลภาษา

- **ไฟล์เริ่มต้น (en_us.json):**  
  ภาษาอังกฤษ (สหรัฐฯ) ไฟล์นี้จะถูกใช้เมื่อไม่มีการเลือกไฟล์ภาษาอื่น และทำหน้าที่เป็นไฟล์สำรอง

- **ไฟล์ภาษาอื่น ๆ:**  
  เช่น คุณสามารถสร้างไฟล์ภาษาเยอรมันชื่อ `de_de.json` สำหรับผู้เล่นที่ใช้ภาษาเยอรมันได้

### วิธีสร้างไฟล์แปลภาษาแบบกำหนดเอง

คุณจะต้องมีไฟล์ `en_us.json` เสมอ! ถ้าไม่มี เกมจะไม่มีภาษาสำรองใช้เมื่อเกิดปัญหาหรือเมื่อมีการตั้งค่าภาษาที่ไม่รองรับ

1. **เปิดโปรแกรมแก้ไขข้อความ:**  
   ใช้ Notepad (Windows), TextEdit (Mac) หรือโปรแกรมแก้ไขข้อความธรรมดาใด ๆ ก็ได้

2. **เขียนโค้ด JSON ของคุณ:**  
   สร้างไฟล์ของคุณด้วยคีย์ที่กำหนดเอง คีย์คือชื่อเฉพาะที่ Minecraft ใช้ค้นหาข้อความ ตัวอย่างเช่น:
   
   ```json
   {
     "modpack_name.custom.localization.key": "ข้อความกำหนดเองของคุณที่นี่",
     "modpack_name.another.key": "ข้อความอีกหนึ่งบรรทัด"
   }
   ```

3. **บันทึกไฟล์:**  
   บันทึกไฟล์เป็น `en_us.json` สำหรับข้อความภาษาอังกฤษเริ่มต้น

หากคุณต้องการเพิ่มเวอร์ชันที่แปลแล้ว เช่น ภาษาเยอรมัน ให้คัดลอกเนื้อหาจากไฟล์ `en_us.json` ไปยังไฟล์ใหม่ แล้วแปลเฉพาะข้อความจริงเท่านั้น ไม่ใช่คีย์! คีย์ต้องคงเดิมไว้ เพื่อให้เกมยังค้นหาข้อความได้

สำหรับภาษาเยอรมัน คุณจะบันทึกไฟล์เป็น `de_de.json` สำหรับภาษาอื่น ๆ โปรดดู[หน้า Minecraft wiki นี้](https://minecraft.wiki/w/Language) เพื่อหารหัสภาษาที่ถูกต้องของภาษานั้นและตั้งชื่อไฟล์ตามรหัสดังกล่าว ให้ค้นหา **"in-game locale code"** สำหรับภาษาของคุณ

## การสร้าง Resource Pack ของ Minecraft สำหรับ MC 1.21.4

เมื่อไฟล์แปลภาษาพร้อมแล้ว เราต้องมีวิธีโหลดมันเข้าไปใน Minecraft สำหรับสิ่งนี้ เราจะใช้ resource pack เราจะทำให้แพ็กนี้เปิดใช้งานโดยค่าเริ่มต้นได้ และยังสามารถซ่อนไม่ให้ผู้ใช้ modpack ยุ่งกับมันได้ด้วย ถ้าเราไม่ต้องการ

**resource pack** คือไฟล์ ZIP ที่เก็บไฟล์ซึ่งเปลี่ยนรูปลักษณ์และบรรยากาศของเกม

### ขั้นตอนการสร้าง Resource Pack ของคุณ

1. **สร้างโฟลเดอร์ใหม่:**  
   สร้างโฟลเดอร์ชื่อประมาณ `my_custom_pack` ซึ่งจะเป็นที่ใส่ไฟล์แปลภาษาที่คุณกำหนดเอง

2. **สร้างไฟล์แพ็ก (`pack.mcmeta`):**  
   ภายในโฟลเดอร์ของคุณ ให้สร้างไฟล์ชื่อ `pack.mcmeta` ด้วยเนื้อหาต่อไปนี้:
   
   ```json
   {
     "pack": {
       "pack_format": 16,
       "description": "My Custom Pack with Localizations"
     }
   }
   ```
   
   *หมายเหตุ: `pack_format` 16 ใช้สำหรับ Minecraft 1.21.4.*

3. **เพิ่มไฟล์แปลภาษาของคุณ:**  
   ภายในโฟลเดอร์ resource pack ของคุณ ให้สร้างโครงสร้างโฟลเดอร์ตามนี้:
   
   ```
   my_custom_pack/
   ├── assets/
   │   └── minecraft/
   │       └── lang/
   │           ├── en_us.json
   │           └── de_de.json
   └── pack.mcmeta
   ```
   
   วางไฟล์ `en_us.json` ที่คุณสร้างขึ้นเอง (และไฟล์ภาษาอื่น ๆ เช่น `de_de.json`) ไว้ในโฟลเดอร์ `lang`

4. **บีบอัด Resource Pack เป็น ZIP:**  
   เมื่อโฟลเดอร์พร้อมแล้ว ให้ **บีบอัดทั้งโฟลเดอร์เป็นไฟล์ ZIP** ตั้งชื่อไฟล์ ZIP ว่า **my_custom_pack.zip** นี่คือตัวอย่างชื่อที่ใช้ตลอดทั้งคู่มือ

## ตำแหน่งที่ต้องวาง Resource Pack

วางไฟล์ **my_custom_pack.zip** ของคุณไว้ในโฟลเดอร์ **Minecraft Resourcepacks** โดยปกติจะอยู่ที่:

- **Windows:** `%appdata%\.minecraft\resourcepacks`
- **Mac:** `~/Library/Application Support/minecraft/resourcepacks`
- **Linux:** `~/.minecraft/resourcepacks`

> สำหรับ modpack โฟลเดอร์ `resourcepacks` จะอยู่ในไดเรกทอรี instance ของแพ็กของคุณ
{.is-warning}

## โหลดแพ็กอัตโนมัติด้วย "Resource Pack Overrides"

ม็อด **Resource Pack Overrides** ช่วยให้สามารถเปิด resource pack เป็นค่าเริ่มต้นได้

### ขั้นตอนการโหลดแพ็กของคุณอัตโนมัติ

1. **ติดตั้งม็อด:**  
   ดาวน์โหลดและติดตั้งม็อดจาก [CurseForge](https://www.curseforge.com/minecraft/mc-mods/resource-pack-overrides) หรือ [Modrinth](https://modrinth.com/mod/resource-pack-overrides)

2. **ค้นหาไฟล์คอนฟิก:**  
   หาไฟล์ที่ `.minecraft/config/resourcepackoverrides.json`  
   *ถ้าไฟล์นี้ไม่มี ให้สร้างขึ้นมาเองด้วยตนเอง*

3. **แก้ไขไฟล์คอนฟิก:**  
   เปิดไฟล์แล้วเพิ่ม resource pack ของคุณลงในรายการ `default_packs` โดยใช้ชื่อไฟล์:
   
   ```json
   {
     "schema_version": 2,
     "default_packs": [
       "file/my_custom_pack.zip"
     ]
   }
   ```
   
   สิ่งนี้บอก Minecraft ให้โหลด resource pack ของคุณโดยอัตโนมัติเมื่อเริ่มเกม

   **สำคัญ: ต้องใส่คำนำหน้า `file/` ด้วย!**


*หมายเหตุ: resource pack ในรายการจะถูกนำไปใช้ในลำดับย้อนกลับ ซึ่งหมายความว่าแพ็กที่อยู่บนสุดของรายการจะไปแสดงอยู่ต่ำกว่าแพ็กอื่นในเมนู resource pack ของเกม*

## การซ่อน Resource Pack ในหน้าจอเลือก

คุณสามารถซ่อน resource pack ของคุณได้ เพื่อให้ผู้เล่นไม่เห็นมันในหน้าจอเลือก resource pack

### วิธีซ่อน

1. **แก้ไขไฟล์คอนฟิกอีกครั้ง:**  
   ในไฟล์ `.minecraft/config/resourcepackoverrides.json` เดิม ให้เพิ่ม override สำหรับแพ็กของคุณ:
   
   ```json
   {
     "schema_version": 2,
     "default_packs": [
       "file/my_custom_pack.zip"
     ],
     "pack_overrides": {
       "file/my_custom_pack.zip": {
         "hidden": true
       }
     }
   }
   ```
   
   การตั้งค่านี้จะซ่อน **my_custom_pack.zip** จากหน้าจอเลือก แต่ยังคงโหลดมันโดยอัตโนมัติ

## การใช้คีย์แปลภาษาใหม่ของคุณกับ FancyMenu

เมื่อไฟล์แปลภาษาที่คุณกำหนดเองถูกโหลดแล้ว คุณสามารถใช้คีย์ใหม่ของคุณในเลย์เอาต์ของ FancyMenu ได้

1. **แก้ไของค์ประกอบที่เป็นข้อความ:**  
   เปิด FancyMenu แล้วเลือกองค์ประกอบ เช่น Button หรือ Text

2. **คลิกปุ่ม Placeholders:**  
   มองหาปุ่ม Placeholders ที่มุมขวาบนของตัวแก้ไขข้อความ (ถ้าคุณไม่เห็น องค์ประกอบนั้นอาจไม่รองรับ placeholders)

3. **แทรกตัวแทน Localize Text:**  
   ตัวแทน Localize Text จะแสดงเป็น snippet JSON ซึ่งมีลักษณะดังนี้:
   
   ```json
   {"placeholder":"local","values":{"key":"localization.key"}}
   ```
   
   แทนที่ `localization.key` ด้วยคีย์ที่คุณกำหนดเอง เช่น ถ้าคุณต้องการใช้คีย์จากไฟล์แปลภาษาของคุณ ให้เปลี่ยนเป็น:
   
   ```json
   {"placeholder":"local","values":{"key":"modpack_name.custom.localization.key"}}
   ```

และนั่นก็คือทั้งหมด! ตัวแทนควรถูกแทนที่ด้วยเนื้อหาที่แปลจริงเมื่อไม่ได้กำลังแก้ไขในตัวแก้ไขข้อความ

โปรดจำไว้ว่าตัวแทนนี้จะทำการแปลข้อความให้ตรงกับภาษาของเกมที่ใช้อยู่เสมอ

# เนื้อหาที่ไม่ใช่ข้อความ (รูปภาพ ฯลฯ)

FancyMenu ยังอนุญาตให้คุณทำให้รูปภาพและแทบทุกองค์ประกอบที่คุณต้องการรองรับหลายภาษาได้ด้วย

ในการทำเช่นนี้ คุณจะต้องใช้ **loading requirements**
โดยเฉพาะ **Is Game Language**

เงื่อนไข **Is Game Language** ช่วยให้คุณแสดงองค์ประกอบหรือเลย์เอาต์ได้เฉพาะเมื่อมีการตั้งค่าภาษาเกมที่กำหนดไว้ ดังนั้นคุณสามารถทำตัวอย่างเช่น สร้างองค์ประกอบ Image สองแบบที่มีข้อความ แล้วทำให้รูปภาพนั้นเป็นเวอร์ชันที่มีข้อความภาษาญี่ปุ่นเมื่อภาษาเป็นญี่ปุ่น หรือเป็นเวอร์ชันที่มีข้อความภาษาอังกฤษเมื่อภาษาเป็นอังกฤษ

หากต้องการตั้งค่า loading requirements ให้กับ **องค์ประกอบ** ให้คลิกขวาที่องค์ประกอบนั้นแล้วคลิก **Loading Requirements**

หากต้องการตั้งค่า loading requirements ให้กับ **ทั้งเลย์เอาต์** ให้คลิกขวาที่พื้นหลังของตัวแก้ไขเลย์เอาต์แล้วคลิก **Loading Requirements [Layout-Wide]**.
