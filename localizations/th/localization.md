# การแปลเลย์เอาต์

ใช้ [placeholder **แปลข้อความ**](/placeholders#localize-text) กับข้อความที่ต้องการแปล:

```text
{"placeholder":"local","values":{"key":"modpack.menu.play"}}
```

FancyMenu จะตรวจสอบข้อมูลภาษาที่ Minecraft ใช้งานอยู่ก่อน หากไม่มีคีย์ดังกล่าว FancyMenu จะตรวจสอบไฟล์แปลภาษาแบบกำหนดเองของ FancyMenu ต่อ หากไม่พบคีย์จากทั้งสองแหล่ง ระบบจะแสดงคีย์นั้นเอง

# ไฟล์แปลภาษาแบบกำหนดเองของ FancyMenu

วางไฟล์ไว้ในตำแหน่งต่อไปนี้:

```text
<game-directory>/config/fancymenu/custom_locals/
```

สร้างไดเรกทอรีย่อยสำหรับไฟล์แปลภาษาของคุณ:

```text
custom_locals/
└── my_pack/
    └── text.json
```

วางไฟล์แปลภาษาไว้ในไดเรกทอรีย่อยของ `custom_locals` อย่างน้อยหนึ่งระดับ ระบบจะไม่โหลดไฟล์ที่วางไว้ในไดเรกทอรีราก `custom_locals` โดยตรง รองรับไดเรกทอรีย่อยที่ซ้อนกัน

รูปแบบ UTF-8 ที่รองรับ:

| นามสกุล | รูปแบบ |
|---|---|
| `.json` | ออบเจ็กต์ JSON; ออบเจ็กต์ที่ซ้อนกันจะกลายเป็นคีย์ที่คั่นด้วยจุด |
| `.lang` | บรรทัดรูปแบบ `key=value` |
| `.properties` | รูปแบบ Java properties |

ตัวอย่าง JSON:

```json
{
  "modpack": {
    "menu": {
      "play": "Play"
    }
  }
}
```

ตัวอย่างนี้กำหนดคีย์ `modpack.menu.play`

FancyMenu จะรวมไฟล์ที่รองรับจากไดเรกทอรีย่อยเหล่านี้ไว้ในพจนานุกรมแปลภาษาแบบกำหนดเองชุดเดียว ใช้แต่ละคีย์ในไฟล์เพียงไฟล์เดียว ไฟล์แปลภาษาแบบกำหนดเองจะไม่เปลี่ยนตามภาษาที่เลือกใน Minecraft หากต้องการให้เปลี่ยนภาษาโดยอัตโนมัติ ให้ใช้วิธี resource pack ด้านล่าง

รีสตาร์ตไคลเอนต์หลังแก้ไขไฟล์แปลภาษาแบบกำหนดเอง

# ข้อความเฉพาะภาษา

หากต้องการให้เปลี่ยนภาษาตามภาษาที่เลือกใน Minecraft โดยอัตโนมัติ ให้เตรียมไฟล์ภาษามาตรฐานของ Minecraft ผ่าน [resource pack](/resources#minecraft-resources-resource-packs):

```text
assets/<namespace>/lang/en_us.json
assets/<namespace>/lang/de_de.json
```

ใช้คีย์เดียวกันในไฟล์ภาษาแต่ละไฟล์ เปิดใช้งาน resource pack แล้วอ่านคีย์เหล่านั้นด้วย [placeholder **แปลข้อความ**](/placeholders#localize-text)

# การแปลรูปภาพและองค์ประกอบ

ใช้ [เงื่อนไข **เป็นภาษาของเกม**](/conditions#is-game-language) เพื่อแสดงองค์ประกอบหรือเลย์เอาต์ที่แตกต่างกันตามรหัสภาษา เช่น `en_us` และ `de_de`
