# ทรัพยากร

ฟิลด์ทรัพยากรสามารถโหลดเนื้อหาได้จาก:

- **Minecraft:** ตำแหน่งทรัพยากรที่ Minecraft หรือ resource pack จัดให้
- **Local:** ไฟล์ในอินสแตนซ์เกมที่ใช้งานอยู่
- **Web:** URL ของไฟล์โดยตรง

ฟิลด์รูปภาพ เสียง วิดีโอ และข้อความส่วนใหญ่ใช้ตัวเลือกทรัพยากรแบบเดียวกัน โดยตัวเลือกนี้มีเบราว์เซอร์สำหรับเนื้อหา Minecraft และ resource pack ด้วย

# ทรัพยากร Minecraft (Resource Packs)

ตำแหน่งทรัพยากรใช้รูปแบบ `namespace:path` โดย namespace คือไดเรกทอรีที่อยู่ถัดลงมาทันทีใต้ `assets` และ path คือทุกอย่างที่อยู่ต่ำกว่านั้นภายใน namespace นั้น

ตัวอย่างเช่น ลองดูรูปภาพใน resource pack ที่เก็บไว้ที่ `/assets/custom_resources/images/image.png`
ตำแหน่งทรัพยากรของมันคือ `custom_resources:images/image.png`

> [!NOTE]
> ทรัพยากรที่มีมาใน Minecraft โดยปกติจะใช้ namespace `minecraft`

# ทรัพยากรในเครื่อง

เก็บทรัพยากรในเครื่องไว้ที่ `<game-directory>/config/fancymenu/assets/` โดย `<game-directory>` คือโฟลเดอร์ของอินสแตนซ์ที่ใช้งานอยู่ ซึ่งอาจแตกต่างจาก `.minecraft`

ฟิลด์ทรัพยากรอาจแสดงพาธเดียวกันในรูปแบบ `/config/fancymenu/assets/example.png` ในฟิลด์เหล่านั้น เครื่องหมาย `/` นำหน้ายังคงหมายถึง `<game-directory>`; ไม่ใช่พาธจากรากของระบบไฟล์

ไฟล์เหล่านี้สามารถ [รวมไปกับ modpack](./modpacks) ได้ผ่านโฟลเดอร์ config ของมัน

หากต้องการแผนผังแบบสมบูรณ์ของตำแหน่งไฟล์ layout, resource, configuration และ generated-state ของ FancyMenu โปรดดู [ตำแหน่งการเก็บข้อมูล](./data-storage-locations)

# ทรัพยากรบนเว็บ

ใช้ URL โดยตรงไปยังไฟล์ เช่น `https://example-domain.net/image.png` หน้าเว็บและลิงก์รีไดเร็กต์จะช้ากว่า และมีโอกาสล้มเหลวมากกว่า URL โดยตรงที่ลงท้ายด้วยชื่อไฟล์และนามสกุลของทรัพยากร

# ตัวแปรแทนในแหล่งที่มาของทรัพยากร

ฟิลด์ทรัพยากรที่ใช้ตัวเลือกสามารถใช้ [ตัวแปรแทน](./placeholders) ได้ในพาธ local, URL และตำแหน่งทรัพยากรของ Minecraft เลือก **Open in Editor** ข้างฟิลด์แหล่งที่มาเพื่อแก้ไขโดยตรง

> [!WARNING]
> อินพุตทรัพยากรที่ไม่ได้ใช้ตัวเลือกมาตรฐานอาจไม่รองรับตัวแปรแทนหรือการอัปเดตแหล่งที่มาแบบสด
