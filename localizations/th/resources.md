# ทรัพยากร

ระบบทรัพยากรของ FancyMenu ช่วยให้คุณใช้ทรัพยากรจากตัวโหลดทรัพยากรของ Minecraft เอง (**Resource Packs**), ทรัพยากร **Local** (ไฟล์จากระบบของไคลเอนต์) และแหล่งข้อมูลบน **Web** (ไฟล์ที่จัดเก็บออนไลน์)

อินพุตทรัพยากรแทบทั้งหมด ไม่ว่าจะเป็นรูปภาพ เสียง วิดีโอ หรือข้อความ จะถูกตั้งค่าผ่านตัวเลือกทรัพยากรของ FancyMenu มีข้อยกเว้นอยู่บ้าง เช่น เมื่อตั้งค่าเส้นทางต้นทางสำหรับ placeholder หรือ action แต่โดยส่วนใหญ่แล้ว คุณจะตั้งค่าทรัพยากรผ่านอินเทอร์เฟซตัวเลือกทรัพยากรเดียวกันนี้

เมื่อคุณตั้งค่าอินพุตทรัพยากรผ่านอินเทอร์เฟซตัวเลือกทรัพยากร โดยพื้นฐานแล้วคุณกำลังเลือกสิ่งที่เรียกว่า "resource source" (ซึ่งเป็นคำที่ FancyMenu ใช้เรียก) ซึ่งอาจเป็นพาธ ลิงก์ หรือ resource location ก็ได้ ขึ้นอยู่กับชนิดของแหล่งข้อมูล

FancyMenu 3.9.0 เพิ่มตัวเรียกดูทรัพยากรของ Minecraft เข้าไปในตัวเลือกทรัพยากร ทำให้คุณสามารถเรียกดูทรัพยากรที่โหลดผ่าน resource packs ได้เหมือนเป็นไดเรกทอรี แทนที่จะต้องพิมพ์ resource location ทุกครั้งด้วยตนเอง

# ทรัพยากรของ Minecraft (Resource Packs)

Minecraft ใช้สิ่งที่เรียกว่า "resource locations" เพื่อ "ชี้ไป" ยังทรัพยากร

resource location ที่เขียนเป็นข้อความประกอบด้วย 2 ส่วน คั่นด้วยเครื่องหมายโคลอน (`:`)
ส่วนแรกคือ **namespace** และส่วนที่สองคือพาธที่เหลือของ **path to the resource** รวมถึงชื่อไฟล์ของทรัพยากรพร้อมนามสกุลไฟล์

**namespace** ของ resource location จะเป็นเพียง **โฟลเดอร์ระดับบนสุด** ของพาธเต็มไปยังทรัพยากรเสมอ

สมมติว่าคุณโหลด resource pack ที่มีทรัพยากรชื่อ `image.png` ซึ่งเก็บอยู่ใน `/assets/custom_resources/images/image.png`
ในกรณีนี้ **namespace** ของ resource location จะเป็น `custom_resources` เพราะ `/assets/` เป็นเพียงตำแหน่งที่ Minecraft ใช้โหลดทรัพยากรทั้งหมด ดังนั้น `custom_resources` จึงเป็น **โฟลเดอร์ระดับบนสุด** ของทรัพยากร
นั่นหมายความว่า `images/image.png` คือ **ส่วนที่เหลือของพาธ** ไปยังทรัพยากร

ดังนั้น resource location ที่ถูกต้องสำหรับทรัพยากร `image.png` จะเป็น:
`custom_resources:images/image.png`

> **เกร็ดน่าสนุก**: เนื่องจาก Minecraft เก็บทรัพยากรส่วนใหญ่อยู่ใน `/assets/minecraft/` ดังนั้น **namespace** ของทรัพยากร Minecraft ส่วนใหญ่จึงเป็น `minecraft`
{.is-info}

# ทรัพยากรภายในเครื่อง

วิธีที่ง่ายที่สุดในการโหลดทรัพยากรคือใช้ไฟล์ภายในเครื่องที่เก็บอยู่บนไคลเอนต์โดยตรง (และในหลายกรณีจะมากับ modpack)

FancyMenu อนุญาตให้โหลดเฉพาะทรัพยากรภายในเครื่องที่เก็บอยู่ใน `/config/fancymenu/assets/` เท่านั้น ดังนั้นโปรดเก็บทรัพยากรทั้งหมดของคุณไว้ที่นั่น!

วิธีนี้ยังทำให้การ [ใส่ทรัพยากรภายในเครื่องไปพร้อมกับ modpacks ของคุณ](./modpacks) เป็นเรื่องง่ายมาก เพราะระบบ modpack ส่วนใหญ่ (CurseForge, Modrinth ฯลฯ) รองรับการจัดส่งโฟลเดอร์ config ของม็อดเป็นค่าเริ่มต้นอยู่แล้ว

# ทรัพยากรบนเว็บ

เมื่อคุณต้องการเปลี่ยนทรัพยากรแบบไดนามิกโดยไม่จำเป็นต้องอัปเดต modpack ของคุณ **web** resources คือทางเลือกที่ดีที่สุด

web resource โดยพื้นฐานแล้วก็คือ **URL** ไปยังไฟล์ที่เก็บอยู่บนเซิร์ฟเวอร์ เช่น `https://example-domain.net/image.png`

โปรดใช้เฉพาะ **DIRECT URLs** เสมอ ซึ่งหมายถึง URL ที่ลงท้ายด้วย **ชื่อไฟล์และนามสกุลไฟล์** ของทรัพยากร เหมือนกับตัวอย่าง URL ข้างต้น
การใช้ URL ที่ไม่ใช่ direct จะทำให้ประสิทธิภาพแย่ลงและมีโอกาสล้มเหลวมากกว่า

# Placeholder ใน Resource Sources

สามารถใช้ placeholders ของ FancyMenu ใน resource sources ได้ เช่น พาธไปยังแหล่งข้อมูลภายในเครื่อง, URL ไปยังแหล่งข้อมูลบนเว็บ หรือ resource location ไปยังทรัพยากรของ Minecraft

วิธีนี้ทำให้สามารถอัปเดตแหล่งข้อมูลได้แบบไดนามิก เช่น เปลี่ยนแหล่งที่มาของรูปภาพพื้นหลังเมนูเมื่อกำหนดค่า FancyMenu variable เพื่อแสดงพื้นหลังที่แตกต่างกันตามค่าของตัวแปร

คุณสามารถแก้ไข source ด้วยตนเองได้โดยคลิกปุ่ม **Open in Editor** ทางด้านขวาของช่องป้อน resource source

> โปรดทราบว่าสิ่งนี้ใช้ได้เฉพาะกับอินพุตทรัพยากรที่ใช้อินเทอร์เฟซตัวเลือกทรัพยากรแบบปกติเท่านั้น เป็นไปได้ว่า *อินพุตทรัพยากร* บางรายการที่ไม่ได้ใช้ตัวเลือกนี้อาจ **ไม่รองรับ** placeholders หรืออาจไม่อัปเดตแบบไดนามิกเมื่อ placeholder เปลี่ยนค่า
{.is-warning}
