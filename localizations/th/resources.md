# ทรัพยากร

ช่องทรัพยากรสามารถโหลดเนื้อหาจากแหล่งต่อไปนี้ได้:

- **Minecraft:** ตำแหน่งทรัพยากรที่ Minecraft หรือแพ็กทรัพยากรกำหนดไว้
- **ในเครื่อง:** ไฟล์ในอินสแตนซ์เกมที่ใช้งานอยู่
- **เว็บ:** URL ของไฟล์โดยตรง

ช่องรูปภาพ เสียง วิดีโอ และข้อความส่วนใหญ่ใช้ตัวเลือกทรัพยากรเดียวกัน ซึ่งมีเบราว์เซอร์สำหรับดูเนื้อหาของ Minecraft และแพ็กทรัพยากร

# ทรัพยากร Minecraft (แพ็กทรัพยากร)

ตำแหน่งทรัพยากรใช้รูปแบบ `namespace:path` โดย namespace คือไดเรกทอรีที่อยู่ถัดจาก `assets` และ path คือทุกอย่างที่อยู่ภายใน namespace นั้น

ตัวอย่างเช่น ลองนึกถึงรูปภาพในแพ็กทรัพยากรที่จัดเก็บไว้ที่ `/assets/custom_resources/images/image.png`
ตำแหน่งทรัพยากรของรูปภาพนี้คือ `custom_resources:images/image.png`

> [!NOTE]
> โดยปกติ ทรัพยากรในตัวของ Minecraft จะใช้ namespace `minecraft`

# ทรัพยากรในเครื่อง

จัดเก็บทรัพยากรในเครื่องไว้ใน `<game-directory>/config/fancymenu/assets/` โดย `<game-directory>` คือโฟลเดอร์ของอินสแตนซ์ที่ใช้งานอยู่ ซึ่งอาจแตกต่างจาก `.minecraft`

ช่องทรัพยากรอาจแสดง path เดียวกันนี้เป็น `/config/fancymenu/assets/example.png` ในช่องเหล่านั้น `/` ที่อยู่ข้างหน้ายังคงหมายถึง `<game-directory>` ไม่ใช่ path จากรากของระบบไฟล์

สามารถ [รวมไฟล์เหล่านี้ไปกับม็อดแพ็ก](/modpacks) ผ่านโฟลเดอร์ config ของม็อดแพ็กได้

หากต้องการดูแผนผังทั้งหมดของตำแหน่งเลย์เอาต์ ทรัพยากร การกำหนดค่า และสถานะที่สร้างขึ้นของ FancyMenu โปรดดู [ตำแหน่งจัดเก็บข้อมูล](/data-storage-locations)

# ทรัพยากรจากเว็บ

ใช้ URL โดยตรงไปยังไฟล์ เช่น `https://example-domain.net/image.png` ลิงก์ไปยังหน้าเว็บหรือลิงก์เปลี่ยนเส้นทางจะทำงานช้ากว่า และมีโอกาสล้มเหลวมากกว่า URL โดยตรงที่ลงท้ายด้วยชื่อไฟล์และนามสกุลของทรัพยากร

# Placeholder ในแหล่งที่มาของทรัพยากร

ช่องทรัพยากรที่ใช้ตัวเลือกสามารถใช้ [placeholder](/placeholders) ใน path ของไฟล์ในเครื่อง URL และตำแหน่งทรัพยากร Minecraft ได้ เลือก **เปิดในตัวแก้ไข** ที่อยู่ข้างช่องแหล่งที่มาเพื่อแก้ไขโดยตรง

> [!WARNING]
> ช่องป้อนข้อมูลทรัพยากรที่ไม่ได้ใช้ตัวเลือกตามปกติอาจไม่รองรับ placeholder หรือการอัปเดตแหล่งที่มาแบบเรียลไทม์
