# ตัวแปรใน FancyMenu

ตัวแปรเป็นฟีเจอร์ที่ทรงพลังใน FancyMenu ที่ช่วยให้คุณเก็บและนำข้อมูลกลับมาใช้ซ้ำได้ตลอดการปรับแต่งเมนูของคุณ ตัวแปรทำงานเหมือนกล่องบรรจุข้อมูลที่คุณสามารถใส่ข้อมูลได้หลายชนิด ตั้งชื่อให้แต่ละกล่อง แล้วค่อยเข้าถึงข้อมูลนั้นในภายหลังด้วยชื่อตัวแปร ตัวแปรเปิดโลกของความเป็นไปได้ในการสร้างเมนูแบบไดนามิกที่เปลี่ยนไปตามเงื่อนไขที่คุณกำหนด

## การสร้างตัวแปร

หากต้องการสร้างตัวแปรใน FancyMenu:

1. ตรวจสอบให้แน่ใจว่าคุณไม่ได้อยู่ใน Layout Editor อยู่ในขณะนั้น
2. คลิกแถบเมนูด้านบนของหน้าจอ
3. ไปที่ **Customization -> Variables -> Manage Variables**
4. ในหน้าจอ "Manage Variables" ที่ปรากฏขึ้น ให้คลิกปุ่ม **Add Variable**
5. พิมพ์ชื่อสำหรับตัวแปรใหม่ของคุณ แล้วคลิก **OK**

เพียงเท่านี้! ตัวแปรของคุณก็พร้อมใช้งานแล้ว คุณสามารถเห็นมันแสดงอยู่ในหน้าจอ "Manage Variables"

FancyMenu 3.9.0 ปรับโครงสร้างหน้าต่าง Manage Variables ใหม่ การทำงานสำคัญต่าง ๆ สามารถเข้าถึงได้ผ่านเมนูบริบทเมื่อคลิกขวา รายการรองรับการนำทางด้วยคีย์บอร์ด สามารถคัดลอก/วางตัวแปรได้ ยกเลิก/ทำซ้ำการเปลี่ยนแปลงได้ การพิมพ์จะเริ่มค้นหาได้ทันที ปุ่ม **DEL** จะลบตัวแปรที่เลือกไว้ และ **CTRL + S** จะยืนยันหน้าต่าง

## การตั้งค่าค่าของตัวแปร

ตัวแปรที่ว่างเปล่าไม่ได้มีประโยชน์มากนักในตัวมันเอง หากต้องการให้ตัวแปรช่วยงานคุณได้ คุณต้องใส่ข้อมูลลงไปในนั้น ใน FancyMenu ขั้นตอนนี้เรียกว่า "การตั้งค่าค่าของตัวแปร"

มีสองวิธีหลักในการตั้งค่าของตัวแปร:

1. ในหน้าจอ "Manage Variables" ให้ค้นหาตัวแปรในรายการ คลิกที่มัน แล้วคลิก **Set Value** จากนั้นพิมพ์ข้อมูลที่คุณต้องการเก็บไว้

2. ขณะกำลังปรับแต่งเมนูของคุณ ให้ใช้แอ็กชัน **Set Variable** กับองค์ประกอบ Button, Slider หรือ Ticker ด้วยแอ็กชันนี้ คุณจะระบุชื่อตัวแปรและค่าที่ต้องการเก็บไว้ได้ เมื่อมีคนกดปุ่มที่มีแอ็กชันนี้ ตัวแปรจะถูกอัปเดตเป็นค่าใหม่

ตัวอย่างเช่น สมมติว่าคุณสร้างตัวแปรชื่อ `clicks` เพื่อใช้เก็บจำนวนครั้งที่ปุ่มถูกกด คุณจะเพิ่มแอ็กชัน **Set Variable** ให้กับปุ่มนั้น และใช้ placeholder ในค่าของแอ็กชันเพื่อเพิ่มจำนวนคลิกในแต่ละครั้ง ดังนี้:

```
clicks:{"placeholder":"calc","values":{"expression":"{"placeholder":"getvariable","values":{"name":"clicks"}} + 1"}}
```

วิธีการทำงานมีดังนี้:
1. Placeholder **Get Stored Variable** ดึงค่าปัจจุบันของตัวแปร `clicks`
2. Placeholder **Calculator** นำค่านั้นมาบวกเพิ่มอีก 1
3. จากนั้นผลลัพธ์จะถูกบันทึกกลับเข้าไปในตัวแปร `clicks` ด้วยแอ็กชัน **Set Variable**

ดังนั้นทุกครั้งที่กดปุ่ม ตัวแปร `clicks` จะเพิ่มขึ้นทีละ 1 ซึ่งเท่ากับการนับจำนวนการกดทั้งหมด

## การใช้งานตัวแปร

ตอนนี้คุณมีตัวแปรที่เก็บข้อมูลแล้ว คุณสามารถนำข้อมูลนั้นไปใช้ในส่วนต่าง ๆ ของการปรับแต่งเมนูได้:

* **เงื่อนไขการโหลด**: คุณสามารถตรวจสอบค่าของตัวแปรใน loading requirement เพื่อควบคุมว่าองค์ประกอบเมนูบางอย่างจะปรากฏเมื่อใด ตัวอย่างเช่น คุณสามารถทำให้องค์ประกอบแสดงเฉพาะเมื่อค่าของตัวแปร `clicks` มากกว่า 5 โดยใช้การผสมกันของ requirement **Is Number** และ placeholder **Get Stored Variable**

* **Placeholder**: สามารถแทรกตัวแปรลงในข้อความได้ด้วย placeholder **Get Stored Variable** หากคุณมีองค์ประกอบข้อความ คุณสามารถใช้ `{"placeholder":"getvariable","values":{"name":"clicks"}}` เพื่อแสดงค่าปัจจุบันของตัวแปร "clicks"

* **Nested Placeholder**: คุณยังสามารถใช้ตัวแปรภายใน placeholder อื่น ๆ ได้อีกด้วย! ตัวอย่างการนับคลิกด้านบนแสดงให้เห็นสิ่งนี้โดยใช้ placeholder **Get Stored Variable** ภายใน placeholder **Calculator**

* **Actions**: ตัวแปรสามารถใช้ในแอ็กชันเพื่อสร้างพฤติกรรมแบบไดนามิกตามค่าของตัวแปรได้ ตัวอย่างเช่น:
    - ใช้คำสั่ง **IF** ในสคริปต์ของแอ็กชันเพื่อตรวจสอบค่าของตัวแปร โดยใช้การผสมกันของ loading requirement **Is Number** และแอ็กชัน **Get Stored Variable** แล้วทำแอ็กชันต่างกันตามผลลัพธ์ ตัวอย่างเช่น คุณอาจมีปุ่มที่แสดงข้อความว่า "You've clicked me X times!" และใช้บล็อก IF เพื่อแสดงข้อความพิเศษหากจำนวนครั้งที่คลิกมากกว่า 10
    - ผสม placeholder **Get Stored Variable** กับแอ็กชัน **Copy to Clipboard** เพื่อให้ผู้ใช้คัดลอกค่าของตัวแปรไปยังคลิปบอร์ดได้
    - ใช้ตัวแปรในแอ็กชัน **Open GUI** เพื่อโหลดหน้าจอที่แตกต่างกันตามความคืบหน้าหรือความชอบของผู้ใช้ ซึ่งคุณติดตามไว้ด้วยตัวแปร

## ตัวอย่างการใช้ตัวแปร

นี่คือตัวอย่างบางส่วนเพื่อเป็นแรงบันดาลใจในการใช้งานตัวแปรของคุณ:

1. **คะแนนสูงสุด**: สร้างตัวแปร `highscore` และปุ่มที่ตั้งค่าให้เป็นคะแนนปัจจุบันของผู้เล่นหากคะแนนนั้นสูงกว่าค่าที่มีอยู่เดิม แสดงคะแนนสูงสุดบนเมนูโดยใช้ placeholder **Get Stored Variable**

2. **ตัวเลือกความยาก**: สร้างตัวแปรสำหรับระดับความยากของเกม เช่น `easy`, `medium` และ `hard` ใช้ปุ่มเพื่อตั้งค่าตัวแปรความยาก และแสดง/ซ่อนองค์ประกอบตามระดับความยากที่เลือก

3. **ความคืบหน้าบทเรียนสอนเล่น**: เพิ่มตัวแปรเพื่อใช้ติดตามความคืบหน้าของผู้เล่นในบทเรียนสอนเล่น เช่น `tutorial_step` เพิ่มค่าของตัวแปรเมื่อพวกเขาทำแต่ละขั้นตอนเสร็จ และใช้ loading requirement เพื่อค่อย ๆ เผยให้เห็นเมนูส่วนอื่นเพิ่มเติม

ตัวแปรเมื่อรวมกับฟีเจอร์อื่น ๆ ของ FancyMenu จะทำให้คุณมีความยืดหยุ่นอย่างเหลือเชื่อในการสร้างเมนูที่ปรับแต่งตามการกระทำและความชอบของผู้เล่นแต่ละคน ลองทดลองตั้งค่าตัวแปรแบบต่าง ๆ เพื่อปลดล็อกศักยภาพสูงสุดของการปรับแต่งเมนูของคุณ!
