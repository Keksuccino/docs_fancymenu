# ตัวแปร

ตัวแปรคือค่าที่ FancyMenu จดจำไว้ แม้จะปิดเกมไปแล้วก็ตาม ใช้ตัวแปรเพื่อนับจำนวนคลิก จดจำตัวเลือก ติดตามความคืบหน้า หรือเก็บรายการต่าง ๆ เช่น เคล็ดลับระหว่างโหลด ข้อความ การกระทำ ข้อกำหนด ตัวฟังเหตุการณ์ และองค์ประกอบบางอย่างสามารถอ่านและเปลี่ยนแปลงตัวแปรได้

> [!TIP]
> ดูรายการการกระทำสำหรับตัวแปรได้ที่ [สคริปต์การกระทำ](/action-scripts) ข้อกำหนดที่ [ข้อกำหนด](/conditions) และตัวฟังเหตุการณ์ที่ [ตัวฟังเหตุการณ์](/listeners#on-variable-updated-fm-variable)

# ตัวแปรข้อความและรายการ

ตัวแปรมีอยู่สองชนิด:

- ตัวแปรข้อความเก็บข้อความหนึ่งค่า เช่น `dark`, `5` หรือ `true`
- ตัวแปรรายการเก็บรายการของหลายค่า เช่น เคล็ดลับระหว่างโหลดหรือชื่อเซิร์ฟเวอร์ แต่ละรายการจะเป็นข้อความแยกกัน

ตำแหน่งของรายการในรายการเรียกว่าดัชนี รายการแรกมีดัชนี `0` รายการที่สองมีดัชนี `1` และต่อไปเรื่อย ๆ ดัชนีติดลบจะนับจากท้ายรายการ ดังนั้น `-1` จึงเป็นรายการสุดท้าย

สิ่งที่รู้จักเฉพาะข้อความ เช่น `$$name` หรือ **ค่าในตัวแปรตรงกันหรือไม่ (FM Variable)** จะแสดงรายการในรูปอาร์เรย์ JSON ที่มีรายการทั้งหมด เช่น `["Craft a bed before your first night.","Torches keep most mobs away."]`

# จัดการตัวแปร

เปิด **แถบเมนู -> การปรับแต่ง -> จัดการตัวแปร** แถบเมนูจะแสดงตัวเลือกนี้เฉพาะเมื่อไม่ได้อยู่ในตัวแก้ไขเลย์เอาต์

## เพิ่มตัวแปร

1. คลิกขวาที่รายการ แล้วคลิก **เพิ่มตัวแปรข้อความ** หรือ **เพิ่มตัวแปรรายการ**
2. พิมพ์ชื่อ แล้วคลิก **เสร็จสิ้น**

ชื่อใช้ได้ทั้งตัวอักษรพิมพ์เล็ก ตัวเลข `.`, `_` และ `-` โดยแต่ละชื่อใช้ได้เพียงครั้งเดียว

## เปลี่ยนตัวแปร

คลิกขวาที่ตัวแปรเพื่อดูตัวเลือกต่อไปนี้:

| ตัวเลือก | การทำงาน |
|---|---|
| **กำหนดค่า** | กำหนดข้อความให้กับตัวแปรข้อความ |
| **แก้ไขรายการ** | เปิดตัวแก้ไขรายการของตัวแปรรายการ (ดูด้านล่าง) |
| **แปลงเป็นรายการ…** | แปลงตัวแปรข้อความเป็นตัวแปรรายการ โดยใช้ **ตัวคั่น** เพื่อแบ่งข้อความออกเป็นรายการต่าง ๆ: พิมพ์ `\n` เพื่อแบ่งตามบรรทัด **ตัดช่องว่างรอบรายการ** จะลบช่องว่างรอบแต่ละรายการ และ **ข้ามรายการว่าง** จะไม่นำรายการที่ว่างมาใช้ หากข้อความเป็นอาร์เรย์ JSON อยู่แล้ว เช่น `["a","b"]` จะอ่านเป็นรายการเดียว (**อ่านเป็นอาร์เรย์ JSON**) |
| **แปลงเป็นข้อความ…** | แปลงตัวแปรรายการเป็นตัวแปรข้อความ **ตัวคั่น** จะถูกแทรกระหว่างรายการ หรือเลือก **เก็บเป็นข้อความ JSON** เพื่อคงรายการไว้ในรูปอาร์เรย์ JSON |
| **ล้างตัวแปรเมื่อเริ่มเกม** | ล้างตัวแปรทุกครั้งที่เริ่มเกม เหมาะสำหรับค่าที่ควรอยู่เพียงในเซสชันเดียว |
| **ลบตัวแปร** | ลบตัวแปร |
| **คัดลอก** และ **วาง** | สร้างสำเนาของตัวแปร |
| **ส่งออกตัวแปรสำหรับ AI** | ส่งออกตัวแปรเพื่อใช้กับ[แชต AI](/export-for-ai) |

การเปลี่ยนแปลงมีผลทันที เลิกทำได้ด้วย `Ctrl + Z` และทำซ้ำได้ด้วย `Ctrl + Y` (ใช้ `Cmd` บน macOS) เริ่มพิมพ์เพื่อค้นหา กด `Enter` เพื่อแก้ไขตัวแปรที่เลือก หรือกด `Delete` เพื่อลบตัวแปร

## แก้ไขรายการ

ตัวแก้ไขรายการจะแสดงแต่ละรายการพร้อมดัชนี

- หากต้องการเพิ่มรายการ ให้คลิก **เพิ่มรายการ** ด้านล่างรายการ พิมพ์รายการ แล้วกด `Enter` ระบบจะเริ่มเพิ่มรายการถัดไปทันที กด `Enter` ขณะที่รายการว่างอยู่ หรือกด `Esc` เพื่อหยุดเพิ่ม
- หากต้องการแก้ไขรายการ ให้ดับเบิลคลิกที่รายการนั้น กด `Shift + Enter` เพื่อเปิดรายการในตัวแก้ไขข้อความ ซึ่งสามารถใส่ตัวแบ่งบรรทัดได้
- หากต้องการจัดเรียงรายการใหม่ ให้ลากรายการ หรือกด `Alt + Up` และ `Alt + Down`
- คลิกขวาที่รายการเพื่อเลือก **ทำซ้ำรายการ** (`Ctrl + D`), **ลบรายการ** (`Delete`), **คัดลอก**, **วาง**, **เลื่อนขึ้น** หรือ **เลื่อนลง**
- **แก้ไขเป็นข้อความ** จะแก้ไขรายการทั้งหมดพร้อมกัน โดยแยกหนึ่งรายการต่อหนึ่งบรรทัด

**เสร็จสิ้น** จะบันทึกรายการ ส่วน **ยกเลิก** จะละทิ้งทุกการเปลี่ยนแปลงที่ทำในตัวแก้ไขรายการ

# แสดงตัวแปรในข้อความ

พิมพ์ `$$` ตามด้วยชื่อตัวแปรเพื่อแสดงค่า เช่น ตัวแปรชื่อ `menu_theme` จะแสดงด้วย `$$menu_theme` วิธีนี้ใช้ได้กับข้อความทุกชนิดที่รองรับ[ตัวยึดตำแหน่ง](/placeholders) เช่น [องค์ประกอบข้อความ](/text-in-menus) ป้ายปุ่ม คำแนะนำเครื่องมือ และค่าของการกระทำกับข้อกำหนด ข้อความจะอัปเดตเองเมื่อตัวแปรเปลี่ยนแปลง

```
ธีมปัจจุบัน: $$menu_theme
```

- `$$name` ของตัวแปรที่ไม่มีอยู่จะยังคงแสดงเหมือนเดิม
- หากชื่อขึ้นต้นเหมือนกัน เช่น `coins` และ `coins_record` แล้ว `$$coins_record` จะหมายถึงชื่อที่ยาวกว่าเสมอ
- รายการจะแสดงเป็นอาร์เรย์ JSON ตัวยึดตำแหน่งต่อไปนี้จะแสดงรายการในรูปแบบที่อ่านง่ายขึ้น:

| ตัวยึดตำแหน่ง | ตัวอย่าง | ผลลัพธ์ |
|---|---|---|
| **รับค่าตัวแปร (FM Variable)** | `{"placeholder":"getvariable","values":{"name":"clicks"}}` | ค่าในตัวแปร หรือ `0` เมื่อตัวแปรว่างหรือไม่มีอยู่ เหมาะที่สุดสำหรับตัวเลข |
| **รับรายการจากดัชนี (FM Variable)** | `{"placeholder":"list_get","values":{"name":"tips","index":"0","fallback":"No tips yet"}}` | รายการที่ดัชนีที่ระบุ หรือค่า `fallback` หากไม่มีรายการดังกล่าว |
| **ขนาดรายการ (FM Variable)** | `{"placeholder":"list_size","values":{"name":"tips"}}` | จำนวนรายการทั้งหมด |
| **ดัชนีของรายการ (FM Variable)** | `{"placeholder":"list_index_of","values":{"name":"tips","value":"Torches keep most mobs away.","ignore_case":"false"}}` | ดัชนีของรายการแรกที่ตรงกับ `value` ทั้งหมด หรือ `-1` |
| **รวมรายการเป็นข้อความ (FM Variable)** | `{"placeholder":"list_join","values":{"name":"tips","separator":"\n"}}` | รวมรายการทั้งหมดเป็นข้อความเดียว โดยคั่นด้วย `separator` (หากไม่ระบุจะใช้ `, `) `\n` หมายถึงตัวแบ่งบรรทัด |

# เปลี่ยนตัวแปรด้วยการกระทำ

[สคริปต์การกระทำ](/action-scripts) ใช้เปลี่ยนตัวแปรเมื่อมีการคลิกปุ่ม เมื่อทิกเกอร์ทำงาน เมื่อตัวฟังเหตุการณ์ทำงาน และในกรณีอื่น ๆ

## ตัวแปรข้อความ

[**กำหนดค่าตัวแปร (FM Variable)**](/action-scripts#set-variable-value-fm-variable) รับชื่อและค่าใหม่ โดยคั่นด้วย `:` ระบบจะสร้างตัวแปรให้หากยังไม่มีอยู่

```
menu_theme:dark
```

มีเพียง `:` ตัวแรกเท่านั้นที่ใช้คั่นชื่อ ดังนั้นค่าอาจมี `:` เพิ่มได้ เช่น `last_server:play.example.net:25565`

หากต้องการนับจำนวนคลิกปุ่ม ให้บวก 1 เข้ากับค่าเดิม:

```
clicks:{"placeholder":"calc","values":{"decimal":"false","expression":"{"placeholder":"getvariable","values":{"name":"clicks"}} + 1"}}
```

**รับค่าตัวแปร (FM Variable)** จะคืนค่า `0` ขณะที่ `clicks` ยังว่างอยู่ ดังนั้นการคลิกครั้งแรกจะตั้งค่าเป็น `1`

การกำหนดค่าตัวแปรจะไม่แปลงรายการเป็นข้อความ อาร์เรย์ JSON จะกลายเป็นรายการต่าง ๆ ข้อความว่างจะล้างรายการ และข้อความอื่น ๆ จะกลายเป็นรายการเดียว

[**ลบตัวแปร (FM Variable)**](/action-scripts#delete-variable-fm-variable) จะลบตัวแปรหนึ่งรายการ ส่วน [**ล้างตัวแปรทั้งหมด (FM Variable)**](/action-scripts#clear-all-variables-fm-variable) จะลบตัวแปรทั้งหมด

## การกระทำกับรายการ

การกระทำกับรายการแต่ละแบบจะมีหน้าต่างของตัวเอง ทุกช่องรองรับตัวยึดตำแหน่ง

| การกระทำ | การทำงาน |
|---|---|
| [**เพิ่มลงในรายการ (FM Variable)**](/action-scripts#add-to-list-fm-variable) | เพิ่มรายการไว้ท้ายสุดหรือที่ดัชนีที่ระบุ **ข้ามหากมีอยู่ในรายการแล้ว** จะไม่เพิ่มรายการหากมีรายการนั้นอยู่แล้ว |
| [**กำหนดรายการในดัชนี (FM Variable)**](/action-scripts#set-list-entry-fm-variable) | แทนที่รายการที่ดัชนีที่ระบุ |
| [**นำออกจากรายการ (FM Variable)**](/action-scripts#remove-from-list-fm-variable) | ลบ **รายการที่ดัชนี**, **รายการแรกที่ตรงกัน** หรือ **รายการที่ตรงกันทั้งหมด** |
| [**ล้างรายการ (FM Variable)**](/action-scripts#clear-list-fm-variable) | ลบรายการทั้งหมด ตัวแปรรายการยังคงอยู่ แต่ไม่มีรายการเหลือ |
| [**กำหนดรายการ (FM Variable)**](/action-scripts#set-list-fm-variable) | แทนที่รายการทั้งหมดด้วยส่วนต่าง ๆ ของ **ข้อความที่แบ่ง** หรือรายการใน **อาร์เรย์ JSON** การใช้ `$$other_list` เป็นอาร์เรย์ JSON จะคัดลอกรายการอื่น |
| [**จัดเรียงรายการ (FM Variable)**](/action-scripts#arrange-list-fm-variable) | **เรียง A–Z**, **เรียง Z–A**, **ตัวเลขจากน้อยไปมาก**, **ตัวเลขจากมากไปน้อย**, **กลับลำดับ**, **สุ่มลำดับ** หรือ **ลบรายการซ้ำ** |

- การกระทำกับรายการจะสร้างรายการใหม่หากยังไม่มี และแปลงตัวแปรข้อความที่ว่างอยู่ให้เป็นรายการ แต่จะไม่เปลี่ยนตัวแปรข้อความที่มีค่าอยู่แล้ว: ให้[แปลงตัวแปรก่อน](#changing-variables)
- พิมพ์ชื่อรายการโดยไม่ใส่ `$$` หากใส่ `$$` การกระทำจะใช้ค่าของตัวแปรนั้นเป็นชื่อรายการ

ตัวอย่างเช่น องค์ประกอบข้อความแสดงรายการแรกจากรายการ `tips`:

```
{"placeholder":"list_get","values":{"name":"tips","index":"0"}}
```

ปุ่มถัดไปด้านล่างจะใช้การกระทำ **จัดเรียงรายการ (FM Variable)** พร้อมตัวเลือก **สุ่มลำดับ** ในสคริปต์การกระทำ:

## วนดูรายการ

[ลูป FOR EACH](/action-scripts#for-each-loop) จะเรียกใช้การกระทำที่อยู่ข้างในหนึ่งครั้งต่อหนึ่งรายการ โดยเริ่มจากรายการแรกไปจนถึงรายการสุดท้าย

1. คลิกขวาที่พื้นที่สคริปต์ในตัวแก้ไขสคริปต์การกระทำ แล้วคลิก **เพิ่มลูป FOR EACH**
2. พิมพ์ชื่อตัวแปรรายการโดยไม่ใส่ `$$` แล้วคลิก **เสร็จสิ้น**
3. เพิ่มการกระทำภายในลูป ในค่าของการกระทำเหล่านั้น `$$list_entry` คือรายการปัจจุบัน และ `$$list_index` คือดัชนีของรายการนั้น

ตัวอย่างเช่น รายการ `starter_commands` ที่มี `/time set day` และ `/weather clear` ร่วมกับการกระทำ [**ส่งข้อความ/คำสั่งในแชต**](/action-scripts#send-chat-messagecommand) ภายในลูป ซึ่งใช้ค่าต่อไปนี้ จะเรียกใช้ทั้งสองคำสั่ง:

```
$$list_entry
```

- ลูปจะอ่านรายการเพียงครั้งเดียวเมื่อเริ่มทำงาน การกระทำภายในลูปเปลี่ยนรายการได้ โดยไม่เปลี่ยนว่าลูปจะวนผ่านรายการใดบ้าง
- หากเป็นตัวแปรข้อความหรือรายการที่ไม่มีอยู่ ลูปจะทำงาน 0 ครั้ง
- เช่นเดียวกับลูป WHILE ลูปจะหยุดหลังผ่านไป 3 วินาที จึงไม่สามารถทำให้เกมค้างได้

# ตรวจสอบตัวแปร

[ข้อกำหนด](/conditions) จะแสดงองค์ประกอบหรือเรียกใช้บางส่วนของสคริปต์การกระทำเฉพาะเมื่อค่าของตัวแปรตรงตามที่กำหนด

- [**ค่าในตัวแปรตรงกันหรือไม่ (FM Variable)**](/conditions#is-variable-value-fm-variable) ตรวจสอบค่าทั้งหมด สำหรับรายการ จะเปรียบเทียบอาร์เรย์ JSON ที่มีรายการทั้งหมด
- [**รายการมีค่าที่ระบุหรือไม่ (FM Variable)**](/conditions#list-contains-entry-fm-variable) ตรวจสอบว่ารายการมีค่าที่ระบุหรือไม่ ค่าต้องตรงกับรายการทั้งหมด **ไม่สนใจตัวพิมพ์เล็ก-ใหญ่** จะทำให้ `Apple` ตรงกับ `apple`
- [**เป็นตัวเลขหรือไม่**](/conditions#is-number) ใช้เปรียบเทียบตัวเลข เช่น ตรวจว่า `$$clicks` มากกว่า `5` หรือไม่

ตัวอย่างเช่น ปุ่มหนึ่งเปิดโพสต์ข่าวล่าสุดและเพิ่ม `news_42` ลงในรายการ `read_news` ด้วยการกระทำ **เพิ่มลงในรายการ (FM Variable)** ป้าย "ใหม่!" ข้างปุ่มกำหนดข้อกำหนด **รายการมีค่าที่ระบุหรือไม่ (FM Variable)** สำหรับ `news_42` โดยตั้ง **โหมดข้อกำหนด** เป็น ตรงข้าม ดังนั้นป้ายจะหายไปเมื่อผู้เล่นอ่านโพสต์แล้ว

# เชื่อมตัวแปรกับองค์ประกอบ

- [ช่องป้อนข้อความ](/elements#text-input-field): **เชื่อมกับตัวแปร** จะบันทึกข้อความที่ผู้เล่นพิมพ์ลงในตัวแปร และช่องจะแสดงค่าของตัวแปร หากเชื่อมกับรายการ ข้อความที่พิมพ์จะแทนที่รายการทั้งหมด
- [ช่องทำเครื่องหมาย](/elements#checkbox): เปิด **โหมดตัวแปร** แล้วตั้งค่า **เชื่อมกับตัวแปร** ช่องทำเครื่องหมายจะบันทึก `true` หรือ `false` ลงในตัวแปร
- [แถบเลื่อน](/elements#slider) ประเภท **รายการค่า**: **ค่าจากตัวแปรรายการ** จะนำค่าของแถบเลื่อนจากรายการ เมื่อเพิ่มหรือลบรายการ ค่าในแถบเลื่อนจะอัปเดตทันที

# ตอบสนองต่อการเปลี่ยนแปลง

- ตัวฟังเหตุการณ์ [**เมื่ออัปเดตตัวแปร [FM Variable]**](/listeners#on-variable-updated-fm-variable) จะเรียกใช้สคริปต์การกระทำทุกครั้งที่มีการกำหนดค่าตัวแปร
- คำสั่ง [`/fmvariable`](/commands#fmvariable) ใช้กำหนดและอ่านค่าตัวแปรจากแชต บล็อกคำสั่ง และม็อดอื่น ๆ

# บันทึกตัวแปรไว้ที่ใด

FancyMenu บันทึกตัวแปรทันทีไว้ที่ `<game-directory>/config/fancymenu/user_variables.db` ตัวแปรจึงยังคงอยู่หลังเริ่มเกมใหม่

- ตัวแปรจะใช้ร่วมกันทั้งอินสแตนซ์ Minecraft และ[โปรไฟล์](/profiles)ที่ใช้งานอยู่ โดยไม่ได้แยกตามเลย์เอาต์ โลก เซิร์ฟเวอร์ หรือผู้เล่น
- ชื่อตัวแปรแยกตัวพิมพ์เล็กและตัวพิมพ์ใหญ่
- อย่าเก็บรหัสผ่าน โทเค็น หรือข้อมูลลับอื่น ๆ ไว้ในตัวแปร ผู้ที่เข้าถึงโฟลเดอร์เกมได้จะสามารถอ่านข้อมูลเหล่านั้นได้
