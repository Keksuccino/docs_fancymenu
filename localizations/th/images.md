# รูปภาพ

FancyMenu รองรับทรัพยากรรูปภาพในหลายส่วน เช่น พื้นหลังเมนู พื้นผิวปุ่ม และอื่น ๆ อีกมากมาย

คุณสามารถใช้ไฟล์รูปภาพ PNG, JPEG, GIF และ APNG ใน FancyMenu ได้ แต่แนะนำให้ใช้ PNG สำหรับรูปภาพแบบคงที่ whenever possible และแทนที่จะใช้ GIF และ APNG สำหรับภาพเคลื่อนไหว ควรใช้ [ไฟล์ AFMA](/fma) ซึ่งเป็นประเภทรูปภาพเคลื่อนไหวของ FancyMenu เอง เนื่องจาก AFMA ได้รับการปรับแต่งมาให้มีประสิทธิภาพมากกว่า GIF/APNG ใช้ RAM น้อยกว่า และส่งผลกระทบต่อประสิทธิภาพน้อยกว่า

# การแปลงรูปภาพเป็นรูปแบบที่รองรับ

เมื่อคุณต้องการแปลงรูปภาพเป็นรูปแบบใดรูปแบบหนึ่งที่ FancyMenu รองรับ หรือเพียงต้องการแปลงจากรูปแบบที่รองรับรูปแบบหนึ่งไปเป็นอีกรูปแบบหนึ่งด้วยเหตุผลต่าง ๆ ลองดูรายชื่อเว็บไซต์ต่อไปนี้ ซึ่งเหมาะสำหรับการแปลงรูปภาพออนไลน์โดยไม่จำเป็นต้องดาวน์โหลดซอฟต์แวร์ใด ๆ

## GIF เป็น APNG
สำหรับการแปลงรูปภาพ GIF เป็น APNG ให้ใช้เว็บไซต์นี้: https://ezgif.com/gif-to-apng

## APNG เป็น GIF
สำหรับการแปลง APNG เป็น GIF นี่คือเว็บไซต์ที่คุณต้องการ: https://ezgif.com/apng-to-gif

## MP4 เป็น APNG
หากคุณต้องการแปลงวิดีโอสั้น ๆ เป็น APNG ลองใช้เว็บไซต์นี้: https://ezgif.com/video-to-apng

## PNG เป็น JPEG
บางครั้งการใช้ JPEG อาจทำให้ทรัพยากรมีขนาดเล็กลง ดังนั้นในกรณีดังกล่าว การใช้ JPEG แทน PNG อาจเป็นตัวเลือกที่ดี: https://www.freeconvert.com/png-to-jpeg โปรดทราบว่า JPEG ไม่รองรับความโปร่งใส

## JPEG เป็น PNG
สำหรับกรณีทั่วไปที่ต้องการแปลง JPEG เป็น PNG ลองใช้เว็บไซต์นี้: https://jpg2png.com/

## WebP เป็น PNG
FancyMenu ไม่รองรับไฟล์ WebP ดังนั้นคุณต้องแปลงไฟล์เหล่านี้เป็น PNG: https://convertio.co/webp-png/

# ข้อจำกัดของพื้นผิวแบบเคลื่อนไหว

FancyMenu ใช้[รูปแบบ AFMA](/fma) ของตัวเองสำหรับภาพเคลื่อนไหวที่ได้รับการปรับแต่ง ซึ่งทำให้[ไฟล์ AFMA](/fma) สามารถมีเฟรมจำนวนมากที่ความละเอียดสูงได้ แต่สำหรับประเภทไฟล์ภาพเคลื่อนไหวแบบเก่าอย่าง GIF และ APNG คุณควรปฏิบัติตามขีดจำกัดที่แนะนำต่อไปนี้ เพื่อไม่ให้ใช้ RAM มากเกินไปหรือทำให้ประสิทธิภาพของเกมลดลงมากเกินไป:

- ใช้เฟรมไม่เกิน **200 เฟรม** ต่อภาพเคลื่อนไหว
- ใช้ความละเอียดสูงสุด **1080p** สำหรับเฟรมของคุณ
- ไม่ควรมีเฟรมรวมเกิน **1000 เฟรมสำหรับภาพเคลื่อนไหวทั้งหมดรวมกัน** เพราะแม้ว่าคุณจะใช้เพียง 200 เฟรมต่อภาพเคลื่อนไหว ระบบก็จะโหลดเฟรมทั้งหมดไว้ในหน่วยความจำ ดังนั้นการใช้ภาพเคลื่อนไหวพร้อมกันมากเกินไปจะยังคงใช้ RAM จนเต็มได้

> [!IMPORTANT]
> ขีดจำกัดเหล่านี้ไม่ใช้กับ[ไฟล์ AFMA](/fma) เนื่องจาก AFMA ไม่ได้โหลดเฟรมทั้งหมดไว้ในหน่วยความจำ และได้รับการปรับแต่งมาให้มีประสิทธิภาพมากกว่า จึงส่งผลกระทบต่อประสิทธิภาพน้อยกว่าประเภทภาพเคลื่อนไหวแบบเก่ามาก
