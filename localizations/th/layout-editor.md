# ตัวแก้ไขเลย์เอาต์

ตัวแก้ไขเลย์เอาต์เป็นที่ที่คุณใช้สร้าง[เลย์เอาต์](/home#your-first-layout): เพิ่มองค์ประกอบ ย้ายและปรับขนาดองค์ประกอบ รวมถึงเปลี่ยนเมนูที่อยู่รอบ ๆ ตัวแก้ไขจะแสดงเมนูในแบบเดียวกับที่ผู้เล่นเห็น คุณจึงดูได้ทันทีว่าเมนูมีหน้าตาอย่างไร

<img width="800" alt="การย้าย ขยายความกว้าง และขยับชื่อเรื่องเล็กน้อย จากนั้นเลือกปุ่มสองปุ่ม คัดลอกและวาง ลากสำเนาลงมา แล้วเลิกทำ" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/layout_editor_basics.gif?raw=true">

# การเปิดตัวแก้ไข

1. เปิดเมนูที่ต้องการแก้ไข เช่น หน้าจอชื่อเรื่อง
2. คลิก **แถบเมนู -> การปรับแต่ง -> การปรับแต่งหน้าจอปัจจุบัน** เพื่อให้แสดงสถานะ **เปิดใช้งาน**
3. คลิก **แถบเมนู -> การปรับแต่ง -> เลย์เอาต์ -> ใหม่ -> สำหรับหน้าจอปัจจุบัน**

- **สำหรับทุกหน้าจอ [ทั่วไป]** จะสร้าง[เลย์เอาต์ทั่วไป](/universal-layouts) ซึ่งจะแสดงในทุกเมนู
- เลย์เอาต์ที่คุณมีอยู่แล้วจะแสดงอยู่ใน **เลย์เอาต์** เช่นกัน วางเมาส์เหนือรายการแล้วคลิก **แก้ไขเลย์เอาต์**
- ในเมนูใดก็ได้ กด `Ctrl + Alt + L` เพื่อเปิดเลย์เอาต์ที่คุณแก้ไขล่าสุด ดู[ทางลัดแถบเมนู](/home#menu-bar-shortcuts)

# ภาพรวมตัวแก้ไข

<img width="800" alt="ตัวแก้ไขเลย์เอาต์ที่เลือกปุ่มเข้าร่วมเซิร์ฟเวอร์ มีแถบเมนูอยู่ด้านบนและวิดเจ็ตเลเยอร์อยู่ทางขวา" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/layout_editor_overview.png?raw=true">

- คลิกขวาที่พื้นหลังเพื่อเปิดการตั้งค่าของเลย์เอาต์ทั้งหมด และเพิ่มองค์ประกอบด้วย **องค์ประกอบใหม่**
- คลิกขวาที่องค์ประกอบเพื่อเปิดการตั้งค่า ดู[องค์ประกอบ](/elements#settings-of-all-elements)
- **เลเยอร์** ทางขวาจะแสดงองค์ประกอบทั้งหมดในเลย์เอาต์ ดู[เลเยอร์และกลุ่ม](#layers-and-groups)
- แถบเมนูด้านบน:

| เมนู | รายการที่มี |
|---|---|
| **เลย์เอาต์** | **ใหม่**, **เปิด**, **บันทึก**, **บันทึกเป็น**, **ส่งออกเลย์เอาต์สำหรับ AI**, **คุณสมบัติเลย์เอาต์** (เหมือนกับเมนูคลิกขวาที่พื้นหลัง), **การตั้งค่า** และ **ปิดตัวแก้ไข** |
| **แก้ไข** | **เลิกทำ**, **ทำซ้ำ**, **คัดลอก**, **วาง** และ **เลือกทั้งหมด** |
| **องค์ประกอบ** | **ใหม่** เพื่อเพิ่มองค์ประกอบ และ **องค์ประกอบวานิลลาที่ถูกลบ** เพื่อเรียกคืน[องค์ประกอบวานิลลาที่คุณลบไป](/deleted-vanilla-elements) |
| **หน้าต่าง** | **วิดเจ็ตตัวแก้ไข**, [เส้นตาราง](#grid-and-anchor-overlay), [โอเวอร์เลย์จุดยึด](#grid-and-anchor-overlay), **ตัวควบคุมการหมุนองค์ประกอบ** และ **ตัวควบคุมการเอียงองค์ประกอบ** |

## การตั้งค่าเลย์เอาต์

เมนูคลิกขวาที่พื้นหลังมีการตั้งค่าทุกอย่างเกี่ยวกับตัวเลย์เอาต์ เช่น:

- [**พื้นหลังเมนู**](/menu-backgrounds) และ [**โอเวอร์เลย์ตกแต่ง**](/decoration-overlays)
- **ชื่อหน้าจอที่กำหนดเอง** สำหรับข้อความด้านบนของบางเมนู เช่น "ตัวเลือก" โดยใช้[ตัวแทนข้อความ](/placeholders)ได้
- **การปรับแต่งส่วนหัว/ส่วนท้าย** สำหรับ[หน้าจอที่เลื่อนได้](/customizing-scrollable-screens)
- **ดัชนีเลย์เอาต์ [การจัดลำดับหลายเลย์เอาต์]** และ **โหมดสุ่ม** สำหรับ[การใช้หลายเลย์เอาต์ในเมนูเดียว](/randomize-layouts)
- **เงื่อนไขการโหลด [ทั้งเลย์เอาต์]** ดู[เงื่อนไข](/conditions#layout-wide-requirements)
- **แก้ไขสคริปต์การกระทำ 'เปิดหน้าจอ'** และ **แก้ไขสคริปต์การกระทำ 'ปิดหน้าจอ'** ดู[สคริปต์การกระทำ](/action-scripts)
- **ตัวเลือกเลย์เอาต์ทั่วไป** ซึ่งมีเฉพาะใน[เลย์เอาต์ทั่วไป](/universal-layouts)

# การทำงานกับองค์ประกอบ

## การเลือก

- คลิกองค์ประกอบเพื่อเลือก คลิกพื้นหลังเพื่อยกเลิกการเลือกทั้งหมด
- ลากกรอบบนพื้นหลังเพื่อเลือกองค์ประกอบทั้งหมดที่อยู่ภายในกรอบสี่เหลี่ยม
- กด `Ctrl` ค้างไว้แล้วคลิกเพื่อเพิ่มองค์ประกอบลงในการเลือก หรือนำองค์ประกอบที่เลือกอยู่ออกจากการเลือก
- `Ctrl + A` เลือกองค์ประกอบทั้งหมด

การคลิก การลากกรอบ และ `Ctrl + A` จะข้ามองค์ประกอบที่คุณ[ซ่อนไว้ในเลเยอร์](#hiding-and-renaming)

## การย้าย

- ลากองค์ประกอบเพื่อย้าย หากต้องการย้ายองค์ประกอบที่เลือกไว้หลายรายการ ให้กด `Ctrl` ค้างไว้ขณะเริ่มลาก หากไม่กด `Ctrl` การคลิกจะเลือกเฉพาะองค์ประกอบที่คลิก
- ใช้ปุ่มลูกศรเพื่อย้ายองค์ประกอบที่เลือกครั้งละหนึ่งพิกเซล
- จุดยึดจะแสดงขึ้นขณะลาก วางองค์ประกอบค้างไว้เหนือจุดยึดหรือองค์ประกอบอื่นเพื่อยึดไว้ตรงนั้น ดู[การจัดตำแหน่งองค์ประกอบ](/positioning-elements)
- วางองค์ประกอบบน[พื้นที่เลื่อนได้](/scrollable-areas)เพื่อใส่องค์ประกอบไว้ภายใน

## การปรับขนาด

ลากขอบหรือมุมขององค์ประกอบที่เลือก กด `Shift` ค้างไว้เพื่อรักษาอัตราส่วนภาพ

การปรับขนาดทำได้เมื่อเลือกองค์ประกอบไว้เพียงรายการเดียวเท่านั้น

## การหมุนและการเอียง

องค์ประกอบที่เลือกซึ่งรองรับจะแสดงตัวควบคุมสำหรับ[หมุนและเอียง](/rotating-elements) กด `Shift` ค้างไว้ขณะลากเพื่อให้ปรับเป็นช่วง ๆ ได้แก่ 45° สำหรับการหมุน และ 15° สำหรับการเอียง

**หน้าต่าง -> ตัวควบคุมการหมุนองค์ประกอบ** และ **ตัวควบคุมการเอียงองค์ประกอบ** ใช้ซ่อนตัวควบคุมเหล่านี้

## การคัดลอก วาง และลบ

- `Ctrl + C` คัดลอกองค์ประกอบที่เลือก และ `Ctrl + V` วางสำเนา สำเนาจะปรากฏซ้อนอยู่บนต้นฉบับและถูกเลือกไว้ คุณจึงลากแยกออกมาได้ทันที
- คุณยังวางองค์ประกอบลงในเลย์เอาต์อื่นได้จนกว่าจะปิดเกม
- `Delete` ลบองค์ประกอบที่เลือก องค์ประกอบวานิลลาจะถูกซ่อนไว้เท่านั้น เรียกคืนได้ด้วย **องค์ประกอบ -> องค์ประกอบวานิลลาที่ถูกลบ**
- เมื่อลบพื้นที่เลื่อนได้ ระบบจะถามว่าต้องการลบเนื้อหาภายในด้วยหรือให้คงไว้ในเลย์เอาต์

## เลิกทำและทำซ้ำ

`Ctrl + Z` ย้อนกลับการเปลี่ยนแปลงล่าสุด ส่วน `Ctrl + Y` ทำการเปลี่ยนแปลงนั้นซ้ำ ทั้งสองคำสั่งมีอยู่ในเมนู **แก้ไข** ด้วย

## องค์ประกอบที่มองไม่เห็น

ผู้เล่นจะมองไม่เห็นองค์ประกอบ [เสียง](/elements#audio), [ตัวลาก](/dragger), [ตัวทำแอนิเมชันองค์ประกอบ](/element-animator), [ตัวควบคุมเพลง](/elements#music-controller) และ [ตัวเลื่อนข้อความ](/elements#ticker) ในตัวแก้ไข องค์ประกอบเหล่านี้จะแสดงเป็นกล่องสีพร้อมชื่อ คุณจึงค้นหา ย้าย และปรับขนาดได้

- **สีในตัวแก้ไข** ในเมนูคลิกขวาขององค์ประกอบ ใช้เปลี่ยนสีของกล่อง เช่น เพื่อแยกตัวเลื่อนข้อความหลายรายการออกจากกัน สีใช้รูปแบบ `#RRGGBB` หรือ `#RRGGBBAA` หากต้องการความโปร่งใส สีโปร่งแสงอย่าง `#E30E2366` จะทำให้มองเห็นสิ่งที่อยู่ด้านหลังกล่อง
- ชื่อที่แสดงในกล่องคือชื่อเลเยอร์ขององค์ประกอบ ดู[การซ่อนและเปลี่ยนชื่อ](#hiding-and-renaming)

ผู้เล่นจะไม่เห็นกล่อง สี หรือชื่อของกล่องนี้

# เลเยอร์และกลุ่ม

**เลเยอร์** แสดงองค์ประกอบทั้งหมดในเลย์เอาต์ โดยเรียงจากบนสุดลงมาก่อน องค์ประกอบจะแสดงอยู่ด้านหน้าองค์ประกอบทั้งหมดที่อยู่ต่ำกว่าในรายการ เลือก **หน้าต่าง -> วิดเจ็ตตัวแก้ไข -> เลเยอร์** เพื่อแสดงหรือซ่อนรายการนี้

<img width="800" alt="ลากเลเยอร์พื้นหลังข่าวสารลงไปไว้ใต้ข้อความข่าวสาร เพื่อให้บันทึกการอัปเดตแสดงหลังยกเลิกการเลือก จากนั้นเพิ่มกลุ่ม ใส่ทั้งสองเลเยอร์ไว้ในกลุ่ม ซ่อนและแสดงกลุ่มด้วยไอคอนรูปตา แล้วพับกลุ่ม" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/layout_editor_layers.gif?raw=true">

## การเปลี่ยนลำดับ

- คลิกเลเยอร์เพื่อเลือกองค์ประกอบ จากนั้นลากขึ้นหรือลง เส้นจะแสดงตำแหน่งที่องค์ประกอบจะไป เลเยอร์ที่เลือกไว้ทั้งหมดจะย้ายไปพร้อมกัน
- หรือคลิกขวาที่องค์ประกอบหรือเลเยอร์ แล้วคลิก **เลื่อนขึ้นหนึ่งเลเยอร์** หรือ **เลื่อนลงหนึ่งเลเยอร์**

ในตัวแก้ไข องค์ประกอบที่เลือกจะแสดงอยู่ด้านหน้าองค์ประกอบอื่นเสมอ ยกเลิกการเลือกเพื่อดูการจัดลำดับจริง

ใน Minecraft บางเวอร์ชัน องค์ประกอบ[เอนทิตีผู้เล่น](/elements#player-entity) และ[ไอเทม](/elements#item) จะแสดงอยู่ด้านหน้าทุกอย่าง ไม่ว่าจะอยู่เลเยอร์ใดก็ตาม ดู[ปัญหาที่ทราบ](/known-issues#1-player-entity--item-elements-are-always-in-front-of-everything)

## องค์ประกอบวานิลลา

แถว **องค์ประกอบวานิลลา** หมายถึงองค์ประกอบทั้งหมดของตัวเมนูเอง เช่น ปุ่มต่าง ๆ คุณเปลี่ยนลำดับขององค์ประกอบเหล่านี้ไม่ได้ แต่ปุ่มทางขวาของแถวใช้ย้ายองค์ประกอบทั้งหมดของคุณไปไว้ด้านหลังหรือด้านหน้าองค์ประกอบเหล่านั้นได้ ซึ่งให้ผลเหมือนกับตัวเลือก **องค์ประกอบที่กำหนดเองอยู่ด้านหลังวานิลลา** ในเมนูคลิกขวาที่พื้นหลัง

## การซ่อนและเปลี่ยนชื่อ

- คลิกไอคอนรูปตาของเลเยอร์เพื่อซ่อนองค์ประกอบในตัวแก้ไข จะได้ไม่เกะกะขณะทำงานกับองค์ประกอบอื่น คลิกอีกครั้งเพื่อแสดงองค์ประกอบ
- องค์ประกอบที่ซ่อนจะคลิก ย้าย คัดลอก หรือลบไม่ได้ ผู้เล่นยังคงเห็นองค์ประกอบเหล่านั้น โดยจะซ่อนเฉพาะในตัวแก้ไขเท่านั้น เลย์เอาต์จะจดจำองค์ประกอบที่คุณซ่อนไว้
- คลิกขวาที่เลเยอร์แล้วคลิก **เปลี่ยนชื่อเลเยอร์** เพื่อตั้งชื่อที่ค้นหาได้ง่ายขึ้น เช่น `News Panel` ซึ่งเป็นค่าเดียวกับ **ชื่อแสดงผลในตัวแก้ไข** ขององค์ประกอบ และผู้เล่นจะไม่เห็นชื่อนี้

## กลุ่ม

กลุ่มใช้จัดเลเยอร์ที่เกี่ยวข้องกันไว้ภายใต้ชื่อเดียว เช่น ทุกส่วนของแผงข่าวสาร กลุ่มมีไว้จัดระเบียบรายการเท่านั้น องค์ประกอบยังคงแสดงและทำงานเหมือนเดิม

- คลิกขวาภายในรายการเลเยอร์ แล้วคลิก **เพิ่มกลุ่ม** กลุ่มจะปรากฏใต้เลเยอร์
- ลากเลเยอร์ไปวางบนกลุ่มเพื่อเพิ่มเข้าไป ลากออกจากกลุ่มเพื่อนำออก
- คลิกกลุ่มเพื่อเลือกองค์ประกอบทั้งหมดในกลุ่ม ลากกลุ่มเพื่อย้ายองค์ประกอบทั้งหมดขึ้นหรือลงพร้อมกัน
- ใช้ลูกศรของกลุ่มเพื่อพับหรือขยายเลเยอร์ และใช้ไอคอนรูปตาเพื่อซ่อนหรือแสดงเลเยอร์ทั้งหมด
- คลิกขวาที่กลุ่มเพื่อเปลี่ยนชื่อ เลื่อนขึ้นหรือลงหนึ่งเลเยอร์ หรือลบกลุ่ม **ลบกลุ่ม** จะเก็บองค์ประกอบภายในไว้

คำสั่ง **เลื่อนขึ้นหนึ่งเลเยอร์** และ **เลื่อนลงหนึ่งเลเยอร์** จะคงองค์ประกอบไว้ภายในกลุ่ม หากต้องการนำออก ให้ลากเลเยอร์ออกจากกลุ่ม

เลย์เอาต์จะบันทึกกลุ่มและสถานะการพับของแต่ละกลุ่มไว้

## พื้นที่เลื่อนได้

องค์ประกอบใน[พื้นที่เลื่อนได้](/scrollable-areas)จะแสดงอยู่ใต้เลเยอร์ของพื้นที่นั้น โดยเยื้องเข้ามา

- ลากเลเยอร์ไปวางบนครึ่งล่างของเลเยอร์พื้นที่ เพื่อใส่องค์ประกอบเข้าไปในพื้นที่ ลากออกไปวางระหว่างเลเยอร์อื่นเพื่อนำองค์ประกอบออก โดยองค์ประกอบจะยังคงอยู่ที่ตำแหน่งเดิมบนหน้าจอ
- ใช้ลูกศรของเลเยอร์พื้นที่เพื่อพับหรือขยายองค์ประกอบภายใน
- องค์ประกอบในพื้นที่จะไม่อยู่ในกลุ่มใด และจะย้ายไปพร้อมกับพื้นที่

# เส้นตารางและโอเวอร์เลย์จุดยึด

เมนู **หน้าต่าง** มีการตั้งค่าตัวช่วยในตัวแก้ไขดังนี้:

- **เส้นตาราง** แสดงเส้นตาราง กด `Ctrl + G` เพื่อเปิดหรือปิด **ขนาดตาราง** ใช้กำหนดระยะห่างระหว่างเส้น
- **การจัดแนวกับเส้นตาราง** ทำให้องค์ประกอบที่ลากไปยึดกับเส้นตารางขณะที่แสดงเส้นตารางอยู่ **ความแรงในการจัดแนวกับเส้นตาราง** ใช้กำหนดระดับการยึด
- **การแสดงโอเวอร์เลย์จุดยึด** ใช้กำหนดเวลาที่จุดยึดจะแสดง:
  - **แสดงขณะลากองค์ประกอบ**: แสดงขณะลากองค์ประกอบ
  - **แสดงตลอดเวลา**: แสดงตลอดเวลา
  - **แสดงเมื่อกดปุ่ม (ปุ่ม "O")**: แสดงขณะกด `O` ค้างไว้
  - **ปิดใช้งาน**: ไม่แสดง
- **การยึดเมื่อวางเมาส์เหนือพื้นที่จุดยึด** ใช้กำหนดว่าการวางองค์ประกอบค้างไว้เหนือจุดยึดจะเปลี่ยนจุดยึดขององค์ประกอบหรือไม่ **การยึดเมื่อวางเมาส์เหนือองค์ประกอบ** จะเพิ่มองค์ประกอบอื่นเป็นจุดยึด และจะทำงานเมื่อเปิด **การยึดเมื่อวางเมาส์เหนือพื้นที่จุดยึด** ด้วยเท่านั้น

# การบันทึกและปิดตัวแก้ไข

- กด `Ctrl + S` หรือเลือก **เลย์เอาต์ -> บันทึก** เพื่อบันทึกเลย์เอาต์ ในครั้งแรก FancyMenu จะขอให้คุณตั้งชื่อไฟล์
- เลือก **เลย์เอาต์ -> บันทึกเป็น** เพื่อบันทึกเลย์เอาต์เป็นไฟล์ใหม่
- หากมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก แถบเมนูจะแสดง **\* การเปลี่ยนแปลงที่ยังไม่ได้บันทึก! \***
- คลิก X ทางขวาของแถบเมนู หรือเลือก **เลย์เอาต์ -> ปิดตัวแก้ไข** เพื่อปิดตัวแก้ไข หากมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก ระบบจะถามยืนยันก่อน

# ทางลัด

บน macOS ให้ใช้ `Cmd` แทน `Ctrl`

| ทางลัด | การทำงาน |
|---|---|
| `Ctrl + S` | บันทึก |
| `Ctrl + Z` | เลิกทำ |
| `Ctrl + Y` | ทำซ้ำ |
| `Ctrl + C` | คัดลอกองค์ประกอบที่เลือก |
| `Ctrl + V` | วาง |
| `Ctrl + A` | เลือกองค์ประกอบทั้งหมด |
| `Delete` | ลบองค์ประกอบที่เลือก |
| ปุ่มลูกศร | ย้ายองค์ประกอบที่เลือกครั้งละหนึ่งพิกเซล |
| คลิกพร้อมกด `Ctrl` | เพิ่มองค์ประกอบในการเลือก หรือนำออกจากการเลือก |
| ลากพร้อมกด `Ctrl` | ย้ายองค์ประกอบที่เลือกหลายรายการ |
| ปรับขนาดพร้อมกด `Shift` | รักษาอัตราส่วนภาพ |
| หมุนหรือเอียงพร้อมกด `Shift` | ปรับเป็นช่วง ๆ |
| `Ctrl + G` | เปิดหรือปิดเส้นตาราง |
| กด `O` ค้างไว้ | แสดงจุดยึด โดยตั้งค่า **แสดงเมื่อกดปุ่ม (ปุ่ม "O")** |

> [!TIP]
> ตัวแก้ไขข้อความมีทางลัดของตัวเอง ดู[ข้อความในเมนู](/text-in-menus#the-text-editor) ส่วนหน้าต่างต่าง ๆ เช่น[สคริปต์การกระทำ](/action-scripts#shortcuts) จะแสดงทางลัดไว้ในหน้าของตัวเอง
