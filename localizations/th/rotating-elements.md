# การหมุนและการเอียงองค์ประกอบ

องค์ประกอบส่วนใหญ่หมุนและเอียงได้ ทั้งสองอย่างเกิดขึ้นรอบจุดกึ่งกลางขององค์ประกอบ โดยตำแหน่งและขนาดจะยังคงเดิม

- **Rotation** คือการหมุนองค์ประกอบเหมือนเข็มนาฬิกา
- **Vertical Tilt** คือการกดองค์ประกอบให้เอนไปด้านหลัง ส่วน **Horizontal Tilt** คือการหันองค์ประกอบไปด้านข้าง องค์ประกอบที่เอียงจะแสดงผลโดยไม่มีมิติทัศนียภาพ จึงมีเพียงความสูงหรือต่ำลง หรือแคบลงเท่านั้น หากเอียงทั้งสองแบบ องค์ประกอบจะเอียงเฉียงด้วย

<img width="800" alt="องค์ประกอบ Text สี่ชิ้นบนพื้นหลังเมนู: ชิ้นหนึ่งหมุน 15 องศา ชิ้นหนึ่งเอียง Vertical Tilt 45 องศาจนเตี้ยลง ชิ้นหนึ่งเอียง Horizontal Tilt 45 องศาจนแคบลง และอีกชิ้นเอียงทั้งสองแบบจนดูเฉียง กล่องสีอ่อนด้านหลังแสดงตำแหน่งขององค์ประกอบหากไม่มีการหมุนหรือเอียง" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/rotating_tilting_axes.png?raw=true">

# ในตัวแก้ไขเลย์เอาต์

<img width="800" alt="ในตัวแก้ไขเลย์เอาต์ สติกเกอร์ Season 3 ถูกหมุนด้วยจุดจับบนวงกลมรอบสติกเกอร์ จากนั้นแผง Patch Notes ถูกเอียงด้วยจุดจับบนเส้นด้านขวาและด้านล่าง" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/rotating_tilting_editor.gif?raw=true">

เลือกองค์ประกอบใน[ตัวแก้ไขเลย์เอาต์](/layout-editor) แล้วลากจุดจับ:

- จุดจับบนวงกลมรอบองค์ประกอบใช้หมุนองค์ประกอบ
- จุดจับบนเส้นด้านขวาใช้กำหนด **Vertical Tilt** ส่วนจุดจับบนเส้นด้านล่างใช้กำหนด **Horizontal Tilt** กึ่งกลางเส้นคือจุดที่ไม่มีการเอียง

ขณะลาก:

- กด `Shift` ค้างไว้เพื่อให้ค่าปรับเป็นขั้น ๆ: 45 องศาสำหรับการหมุน และ 15 องศาสำหรับการเอียง
- เมื่ออยู่ใกล้ 0 จุดจับจะปรับเข้าหา 0 เพื่อให้จัดองค์ประกอบให้ตรงได้ง่ายอีกครั้ง
- มุมซ้ายบนขององค์ประกอบจะแสดงค่าการหมุนและการเอียง

ข้อควรรู้:

- กรอบเลือกจะยังคงตรง คลิกด้านในกรอบเพื่อเลือกหรือย้ายองค์ประกอบ
- จุดจับจะแสดงขึ้นเมื่อเลือกองค์ประกอบไว้เพียงชิ้นเดียวเท่านั้น
- องค์ประกอบที่ไม่มีวงกลมหรือเส้นจะหมุนหรือเอียงไม่ได้ ดูที่[องค์ประกอบที่หมุนหรือเอียงไม่ได้](#elements-without-rotation-or-tilt)
- **menu bar -> Window -> Element Rotation Controls** และ **Element Tilt Controls** ใช้ซ่อนจุดจับขององค์ประกอบทั้งหมด

# กำหนดค่าอย่างเจาะจง

คลิกขวาที่องค์ประกอบเพื่อดูการตั้งค่าเหล่านี้ แต่ละรายการมีตัวเลือก **Set Via Number Picker**, **Set As Plain Text** และ **Reset to Default**

| การตั้งค่า | ใช้ทำอะไร |
|---|---|
| **Rotation** | องศาที่หมุนตามเข็มนาฬิกา เช่น `90` คือหมุนหนึ่งในสี่รอบ ค่าติดลบจะหมุนทวนเข็มนาฬิกา |
| **Vertical Tilt** | ระดับการเอนไปด้านหลัง ตั้งแต่ `-60` ถึง `60` องศา |
| **Horizontal Tilt** | ระดับการหันไปด้านข้าง ตั้งแต่ `-60` ถึง `60` องศา |

การเอียงเพียงแบบเดียวจะดูเหมือนกันไม่ว่าจะใช้ค่าบวกหรือลบ แต่เมื่อเอียงทั้งสองแบบ เครื่องหมายของค่าจะกำหนดทิศทางที่องค์ประกอบเอียง

## ใช้ตัวแทนค่า

หากต้องการหมุนหรือเอียงองค์ประกอบด้วย[ตัวแปร](/variables)หรือ[ตัวแทนค่า](/placeholders)อื่น:

1. คลิกขวาที่องค์ประกอบ แล้วเปิด **Advanced Rotation Mode**, **Advanced Vertical Tilt Mode** หรือ **Advanced Horizontal Tilt Mode**
2. คลิก **Rotation**, **Vertical Tilt** หรือ **Horizontal Tilt** จากนั้นเลือก **Set As Plain Text** แล้วป้อนตัวแทนค่า

โหมดขั้นสูงจะเก็บค่าของตัวเองและซ่อนจุดจับ เพื่อไม่ให้การลากไปแทนที่ตัวแทนค่าของคุณ เมื่อปิดโหมด องค์ประกอบจะกลับไปใช้ค่าเดิม

โลโก้ที่หมุนครบหนึ่งรอบทุก 3.6 วินาที โดยใช้ **Rotation** นี้ใน **Advanced Rotation Mode** หากต้องการให้หมุนช้าลง ให้หารด้วยค่าที่มากกว่า `10`:

```
{"placeholder":"calc","values":{"expression":"{"placeholder":"unix_time"} / 10 % 360"}}
```

เข็มที่ชี้ไปยังค่าที่ระบุโดยตัวแปร `needle_angle` ซึ่งกำหนดค่าได้ด้วยปุ่มหรือ[Slider](/elements#slider):

```
{"placeholder":"getvariable","values":{"name":"needle_angle"}}
```

# การคลิกและเมาส์

<img width="800" alt="ตัวชี้เมาส์อยู่บนปุ่ม Join Server ที่หมุนแล้ว: บริเวณมุมของปุ่มที่ไม่หมุนจะไม่ตอบสนอง แต่ส่วนปลายของปุ่มที่แสดงสว่างจะตอบสนอง" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/rotating_tilting_hover.gif?raw=true">

ปุ่ม แถบเลื่อน ลิงก์ และแถบเลื่อนขององค์ประกอบ Text จะตอบสนองต่อเมาส์ตรงบริเวณที่แสดงผล แม้จะหมุนหรือเอียงอยู่ก็ตาม เงื่อนไข [**Is Element Hovered**](/conditions#is-element-hovered), [**Is Any Element Hovered**](/conditions#is-any-element-hovered) และ [**Is Any Button Hovered**](/conditions#is-any-button-hovered) ก็ทำงานในลักษณะเดียวกัน

> [!NOTE]
> Checkboxes, Text Input Fields, Draggers และ Browsers ยังคงตอบสนองภายในกรอบที่องค์ประกอบจะมีหากไม่มีการหมุนหรือเอียง ควรวางองค์ประกอบเหล่านี้ให้ตรง

# องค์ประกอบที่หมุนหรือเอียงไม่ได้

- หมุนและเอียงไม่ได้: [Scrollable Areas](/scrollable-areas), [GLSL Shaders](/elements#glsl-shader), [Block/Item JSON Models](/elements#blockitem-json-model), [Player Entities](/player-entities) และ [vanilla elements](/vanilla-elements) เช่น ปุ่มของหน้าจอเอง
- หมุนได้ แต่เอียงไม่ได้: [Tooltips](/elements#tooltip) และ [Items](/elements#item)

องค์ประกอบภายใน Scrollable Area หมุนและเอียงได้ แต่ตัวพื้นที่เองทำไม่ได้

องค์ประกอบ [Splash Text](/splash-text) ยังมี **Rotation** ของตัวเองอยู่ด้านล่างในเมนูคลิกขวา เพื่อใช้กำหนดความเอียงแบบที่พบได้ทั่วไป โดยทำงานร่วมกับการหมุนที่อธิบายไว้ในหน้านี้
