# องค์ประกอบที่หมุนได้

องค์ประกอบส่วนใหญ่สามารถหมุนได้

เลือกองค์ประกอบในตัวแก้ไขเลย์เอาต์ หากรองรับการหมุน จะมีเส้นนำทางรูปวงกลมและจุดจับปรากฏรอบๆ องค์ประกอบนั้น ลากจุดจับเพื่อหมุนองค์ประกอบ

หากไม่มีวงกลมล้อมรอบองค์ประกอบ แสดงว่าคุณไม่สามารถหมุนมันได้

# ขั้นสูง

คุณยังสามารถคลิกขวาที่องค์ประกอบเพื่อกำหนดค่าการหมุนด้วยตนเองผ่านการป้อนข้อความโดยตรงได้ การป้อนข้อมูลโดยตรงนี้รองรับ [placeholders](/placeholders) ดังนั้นคุณจึงสามารถเปลี่ยนการหมุนขององค์ประกอบแบบไดนามิกได้เมื่อใช้งานร่วมกับ placeholders เพื่อดึงค่าตัวแปรของ FancyMenu หรือสิ่งที่คล้ายกัน

# ปุ่ม สไลเดอร์ และองค์ประกอบโต้ตอบอื่นๆ

การหมุนมีผลเฉพาะในเชิงภาพสำหรับองค์ประกอบที่โต้ตอบได้เท่านั้น ปุ่มที่ถูกหมุนยังคงรับการคลิกได้ภายในพื้นที่เดิมที่ยังไม่ได้หมุน
