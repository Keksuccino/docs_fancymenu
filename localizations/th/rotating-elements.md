# การหมุนองค์ประกอบ

ตั้งแต่ FancyMenu v3.8.0 เป็นต้นไป คุณสามารถหมุนองค์ประกอบ **ส่วนใหญ่** ได้!

หากต้องการหมุนองค์ประกอบ ให้เลือกองค์ประกอบนั้นในตัวแก้ไขเลย์เอาต์ และถ้าคุณเห็นรูปวงกลมรอบองค์ประกอบ แสดงว่ามีจุดจับติดอยู่ ซึ่งคุณสามารถลากเพื่อหมุนองค์ประกอบรอบแกนของมันได้

ถ้าไม่มีรูปวงกลมรอบองค์ประกอบ คุณจะไม่สามารถหมุนมันได้

# ขั้นสูง

คุณยังสามารถคลิกขวาที่องค์ประกอบเพื่อกำหนดค่าการหมุนด้วยตนเองผ่านการป้อนข้อความโดยตรงได้อีกด้วย การป้อนข้อมูลแบบตรงนี้รองรับ [placeholders](/placeholders) ดังนั้นคุณจึงสามารถเปลี่ยนการหมุนขององค์ประกอบแบบไดนามิกได้เมื่อใช้ร่วมกับ placeholders เพื่อดึงค่าตัวแปรของ FancyMenu หรือสิ่งที่คล้ายกัน

# ปุ่ม, สไลเดอร์ และองค์ประกอบอื่นๆ ที่โต้ตอบได้

ในกรณีขององค์ประกอบที่โต้ตอบได้ การหมุนทำได้ แต่การหมุนนั้นเป็นเพียงภาพเท่านั้น ดังนั้นตัวอย่างเช่น ปุ่มจะยังคงตอบสนองเฉพาะการคลิกภายในพื้นที่เดิมของมัน แม้ว่าการหมุนอาจทำให้มันเลื่อนออกจากพื้นที่นั้นไปบางส่วนแล้วก็ตาม
