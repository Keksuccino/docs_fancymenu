# ไอคอนมรกต/เพชรบนหน้าจอชื่อเรื่อง

หากคุณกำลังพยายามซ่อนไอคอนเล็กๆ ที่ยังคงปรากฏบนหน้าจอชื่อเรื่องของคุณ และมันดูเหมือนเพชรหรือมรกตเล็กๆ (ไอคอนสีเขียวหรือสีน้ำเงิน) นี่มักจะเป็นการแจ้งเตือนอัปเดตม็อดของ Mod Menu (ม็อด Fabric) หรือ Forge (ฟีเจอร์ของตัวจัดการม็อดในตัว)

ในบางกรณี มันอาจเป็นส่วนหนึ่งของปุ่ม Realms ของ Minecraft แบบ Vanilla (เพื่อแสดงการแจ้งเตือน)

# การซ่อนไอคอนของ Mod Menu

หากต้องการซ่อนสัญลักษณ์จาก Mod Menu คุณต้องปิด "update indicator" ในการตั้งค่าของมัน

คลิกปุ่ม **Mods** -> เอาเมาส์ชี้ที่ไอคอนของม็อด Mod Menu ในรายการม็อด -> คลิกที่มัน -> ตั้งค่า "Update Indicator" เป็น "Hidden"

# การซ่อนไอคอนของ Forge

Forge ใช้ตัวตรวจสอบเวอร์ชันในตัวเพื่อแสดงไอคอนมรกตนั้นเมื่อม็อดล้าสมัย คุณสามารถปิดมันได้:

1. เปิดไฟล์ config/fml.toml ของคุณ
2. ค้นหาการตั้งค่า `versionCheck`
3. ตั้งค่าเป็น `false`: `versionCheck = false`
4. บันทึกและรีสตาร์ท Minecraft

การทำเช่นนี้จะปิดการตรวจสอบเวอร์ชันทั้งหมด ซึ่งจะซ่อนไอคอนมรกตตอนเปิดเกมด้วย

อีกวิธีในการซ่อนไอคอนคือซ่อนปุ่ม Mods ทั้งหมดด้วย FancyMenu ไปเลย การซ่อนปุ่มจะทำให้ไอคอนถูกซ่อนด้วยเช่นกัน

# การซ่อนไอคอน Realms ของ Vanilla

หากไม่ใช่ไอคอนของ Mod Menu หรือ Forge ก็น่าจะเป็นไอคอนแจ้งเตือน Realms ของ Minecraft เอง ไอคอนเหล่านี้จะแสดงบริเวณตำแหน่งของปุ่ม Realms และสามารถซ่อนได้ด้วย FancyMenu ในตัวแก้ไขเลย์เอาต์ คุณต้องสร้างเลย์เอาต์ "for the current screen" (ในกรณีนี้คือหน้าจอชื่อเรื่อง) แล้วคุณจะเห็นไอคอน Realms เป็นองค์ประกอบเฉพาะในตัวแก้ไข หากต้องการซ่อน ให้ **คลิกขวา** ที่มัน แล้วคลิก **Delete**

ไอคอน Realms อาจเป็นไอคอนหนังสือพิมพ์ สัญลักษณ์รูปเพชร และแบบอื่นๆ เช่น วงกลมสีแดงพร้อมตัวเลขแจ้งเตือน
