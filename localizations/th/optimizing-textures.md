# การปรับแต่งพื้นผิวสำหรับ FancyMenu

FancyMenu จะใช้พื้นผิวที่คุณจัดเตรียมมาแบบเดิม ๆ หมายความว่าโปรแกรม **จะไม่** บีบอัด ย่อ หรือขยายไฟล์รูปภาพของคุณ ดังนั้นเพื่อให้เมนูของคุณดูคมชัดและทำงานได้ดี ควรปรับแต่งพื้นผิวให้เหมาะสมเมื่อใช้งานใน UI ของคุณ

# เคล็ดลับสำคัญสำหรับการปรับแต่งพื้นผิว

เคล็ดลับต่อไปนี้เป็นขั้นตอนพื้นฐานที่สำคัญที่สุดที่คุณควรคำนึงถึงเมื่อทำงานกับพื้นผิวใน FancyMenu

## 1. ใช้ความละเอียดที่เหมาะสม
- **หลีกเลี่ยงรูปความละเอียดต่ำ**: หากรูปมีขนาดเล็กเกินไปแล้วถูกยืดให้พอดีกับพื้นที่ที่ใหญ่กว่า อาจทำให้ภาพดูเบลอ
- **หลีกเลี่ยงการใช้ความละเอียดสูงเกินจำเป็น**: พื้นผิวที่มีขนาดใหญ่มากแต่แสดงผลในขนาดเล็กก็อาจดูผิดเพี้ยนหรือ "แปลก" ได้ และอาจทำให้ประสิทธิภาพลดลง

> 📌 **เคล็ดลับ:** ใช้พื้นผิวที่มีความละเอียดใกล้เคียงกับขนาดที่จะแสดงจริงในเมนู
{.is-info}

## 2. รักษาอัตราส่วนภาพ
- ควรรักษาอัตราส่วนภาพของรูปภาพไว้เสมอเมื่อปรับขนาด
- การยืดรูปภาพแบบไม่สมส่วนอาจทำให้เกิดความผิดเพี้ยนทางภาพและดูไม่สวยงาม

> 📌 **เคล็ดลับ:** คุณสามารถคลิกขวาที่องค์ประกอบ Image แล้วคลิก **Restore Aspect Ratio** เพื่อปรับขนาดให้กลับไปเป็นอัตราส่วนภาพที่ถูกต้อง จากนั้นเมื่อปรับขนาดเพิ่มเติมด้วยตนเอง ให้กด **SHIFT** ค้างไว้ขณะปรับขนาด เพื่อให้การย่อขยายเคารพอัตราส่วนภาพขององค์ประกอบ
{.is-info}

## 3. พิจารณาใช้ Nine-Slicing และ Tiling
- สำหรับองค์ประกอบ UI ที่ต้องปรับขนาดได้ เช่น แผงหรือปุ่ม ให้ใช้ฟีเจอร์ [Nine-Slicing & Tiling](/nine-slicing-and-tiling) ของ FancyMenu
- วิธีนี้จะช่วยให้ขอบของพื้นผิวยังคมชัดเมื่อถูกปรับขนาด
