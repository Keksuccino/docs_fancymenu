# การปรับแต่งพื้นผิวสำหรับ FancyMenu

FancyMenu จะใช้พื้นผิวที่คุณให้มาแบบตรงๆ หมายความว่ามัน **จะไม่** บีบอัด ลดขนาด หรือขยายไฟล์ภาพของคุณ ดังนั้นเพื่อให้เมนูของคุณดูคมชัดและทำงานได้ดี จึงสำคัญมากที่จะต้องปรับแต่งพื้นผิวของคุณเมื่อใช้งานใน UI

# เคล็ดลับสำคัญในการปรับแต่งพื้นผิว

เคล็ดลับต่อไปนี้คือขั้นตอนพื้นฐานที่สำคัญที่สุดที่ควรคำนึงถึงเมื่อทำงานกับพื้นผิวใน FancyMenu

## 1. ใช้ความละเอียดที่เหมาะสม
- **หลีกเลี่ยงภาพความละเอียดต่ำ**: หากภาพมีขนาดเล็กเกินไปแล้วถูกยืดให้พอดีกับพื้นที่ที่ใหญ่กว่า ภาพอาจดูเบลอ
- **หลีกเลี่ยงความละเอียดสูงเกินจำเป็น**: พื้นผิวที่มีขนาดใหญ่มากแต่แสดงผลในขนาดเล็กก็อาจดูผิดเพี้ยนหรือ "แปลกๆ" ได้ และยังอาจเปลืองประสิทธิภาพด้วย

> [!NOTE]
> 📌 **เคล็ดลับ:** ใช้พื้นผิวที่มีความละเอียดเท่ากับหรือใกล้เคียงกับขนาดที่จะแสดงในเมนู

## 2. รักษาอัตราส่วนภาพ
- ควรรักษาอัตราส่วนภาพของรูปภาพไว้เสมอเมื่อปรับขนาด
- การยืดรูปภาพแบบไม่สมส่วนอาจทำให้เกิดความผิดเพี้ยนของภาพและดูไม่สวยงาม

> [!NOTE]
> 📌 **เคล็ดลับ:** คุณสามารถคลิกขวาที่องค์ประกอบรูปภาพแล้วคลิก **Restore Aspect Ratio** เพื่อปรับขนาดให้กลับมาเป็นอัตราส่วนภาพที่ถูกต้อง จากนั้นเมื่อจะปรับขนาดเพิ่มเติมด้วยตนเอง ให้กด **SHIFT** ค้างไว้ขณะปรับขนาด เพื่อให้การปรับขนาดคำนึงถึงอัตราส่วนภาพขององค์ประกอบ

## 3. พิจารณาใช้ Nine-Slicing และ Tiling
- สำหรับองค์ประกอบ UI ที่ต้องปรับขนาดได้ (เช่น แผงหรือปุ่ม) ให้ใช้ฟีเจอร์ [Nine-Slicing & Tiling](/nine-slicing-and-tiling) ของ FancyMenu
- วิธีนี้จะช่วยให้ขอบของพื้นผิวคงความคมชัดเมื่อมีการปรับขนาด
