# การกำหนดตำแหน่งและขนาดขั้นสูง

การกำหนดตำแหน่งและขนาดขั้นสูงช่วยให้คุณควบคุมพิกัดและขนาดขององค์ประกอบได้โดยตรง

> [!WARNING]
> หากต้องการปรับให้เข้ากับสเกล GUI ให้ลองใช้ **Auto-Scaling** กับเลย์เอาต์ทั้งหมดก่อน คลิกขวาที่พื้นหลังของตัวแก้ไข บังคับใช้สเกล GUI แล้วเปิดใช้ **Auto-Scaling** ในเมนูเดียวกัน


# การเปิดหรือปิดโหมดกำหนดตำแหน่ง/ขนาดขั้นสูง

หากต้องการเปิดใช้การกำหนดตำแหน่งหรือขนาดขั้นสูงสำหรับองค์ประกอบ ให้ **คลิกขวา** ที่องค์ประกอบ แล้วเลือก **Advanced Positioning** หรือ **Advanced Sizing**
องค์ประกอบจะเปลี่ยนเป็นโหมดขั้นสูงโดยอัตโนมัติเมื่อคุณตั้งค่าตำแหน่งหรือขนาดขั้นสูง

หากต้องการ **ปิดใช้** และกลับไปใช้การกำหนดตำแหน่ง/ขนาดแบบปกติ ให้ **ล้างค่าตำแหน่ง/ขนาดทั้งหมด**

> [!WARNING]
> ขณะที่องค์ประกอบอยู่ในโหมดกำหนดขนาด/ตำแหน่งขั้นสูง การปรับขนาดและ/หรือการย้ายองค์ประกอบอาจถูกปิดใช้หรือมีข้อจำกัด

# การคำนวณตำแหน่ง/ขนาด

ค่าตำแหน่งและขนาดขั้นสูงรองรับ [ตัวยึดตำแหน่ง](/placeholders)

คุณจึงสามารถใช้ตัวยึดตำแหน่ง [**Calculator**](/placeholders#calculator) ร่วมกับตัวยึดตำแหน่ง GUI เช่น [**Screen Width**](/placeholders#screen-width), [**GUI Scale**](/placeholders#gui-scale) และ [**Element Width**](/placeholders#element-width) ได้

> [!NOTE]
> คุณสามารถเพิ่มตัวยึดตำแหน่งได้โดยคลิกปุ่ม **Placeholders** ที่มุมขวาบนของตัวแก้ไขข้อความ หากไม่เห็นปุ่มนี้ แสดงว่าเนื้อหาที่คุณต้องการแก้ไข **ไม่รองรับ** ตัวยึดตำแหน่ง

หากต้องการคำนวณด้วย [ตัวยึดตำแหน่ง **Calculator**](/placeholders#calculator) ให้แทนที่นิพจน์ตัวอย่างด้วยนิพจน์ของคุณเอง ตัวยึดตำแหน่งที่ซ้อนกันสามารถใช้ระบุขนาดของหน้าจอหรือองค์ประกอบได้

ตัวอย่างนี้ให้ผลลัพธ์เป็น `2`:

`{"placeholder":"calc","values":{"expression":"1 + 1","decimal":"false"}}`

ตั้งค่า `decimal` เป็น `false` เพื่อให้การคำนวณตำแหน่งและขนาดใช้หน่วยพิกเซลจำนวนเต็ม

ตัวคำนวณต่อไปนี้ใช้ตัวยึดตำแหน่ง [**Screen Width**](/placeholders#screen-width) แล้วหารด้วย `2`:

`{"placeholder":"calc","values":{"expression":"{"placeholder":"guiwidth"} / 2","decimal":"false"}}`

> [!IMPORTANT]
> **Advanced Positioning** จะไม่สนใจจุดยึดขององค์ประกอบ และใช้มุมซ้ายบนของหน้าจอ (`X0 Y0`) เป็นจุดกำเนิด โดยยังคงมีผลจาก **Stay on Screen**
