# การกำหนดตำแหน่งและขนาดขั้นสูง

การกำหนดตำแหน่ง/ขนาดขั้นสูงช่วยให้คุณมี **การควบคุมตำแหน่งและขนาดขององค์ประกอบได้อย่างเต็มที่** ซึ่งทรงพลังมาก แต่ก็ **ใช้เวลามากกว่าอย่างมาก** เมื่อเทียบกับการใช้ระบบกำหนดขนาดและตำแหน่งอัตโนมัติของ FancyMenu

> หากคุณเพียงต้องการให้องค์ประกอบปรับสเกลได้ดีกับ **GUI scale** ของ Minecraft แนะนำให้ใช้ **auto-scaling** ระดับเลย์เอาต์แทน ซึ่งสามารถเปิดใช้งานได้โดยบังคับ GUI scale ก่อนในเมนูที่เปิดเมื่อคลิกขวาพื้นหลังของตัวแก้ไข แล้วจึงเปิดใช้งาน **Auto-Scaling** ในเมนูเดียวกัน
{.is-warning}


# การเปิด/ปิดโหมดการกำหนดตำแหน่ง/ขนาดขั้นสูง

หากต้องการ **เปิดใช้งาน** การกำหนดตำแหน่ง/ขนาดขั้นสูงสำหรับองค์ประกอบ ให้ **คลิกขวา** ที่องค์ประกอบนั้น แล้วคลิก **Advanced Positioning** หรือ **Advanced Sizing**
องค์ประกอบจะสลับไปเป็นโหมดขั้นสูงโดยอัตโนมัติเมื่อคุณตั้งค่าตำแหน่งหรือขนาดแบบขั้นสูง

หากต้องการ **ปิดใช้งาน** และกลับไปใช้การกำหนดตำแหน่ง/ขนาดแบบปกติ ให้ **ล้างค่าตำแหน่ง/ขนาดทั้งหมด**

> ขณะที่องค์ประกอบอยู่ในโหมด Advanced Sizing/Positioning การปรับขนาดและ/หรือการย้ายตำแหน่งขององค์ประกอบอาจถูกปิดใช้งานหรือถูกจำกัด
{.is-warning}

# การคำนวณตำแหน่ง/ขนาด

เหตุผลที่การกำหนดตำแหน่ง/ขนาดขั้นสูงทรงพลังมากก็คือ คุณสามารถใช้ **placeholder** ในค่าตำแหน่ง/ขนาดได้

สิ่งนี้ทำให้คุณสามารถใช้ placeholder **Calculator** (อยู่ในหมวด placeholder **Advanced**) ร่วมกับ placeholder ในหมวด **GUI** เช่น **Screen Width**, **GUI Scale**, **Element Width** และอื่น ๆ

> คุณสามารถเพิ่ม placeholder ได้โดยคลิกปุ่ม **Placeholders** ที่มุมขวาบนของตัวแก้ไขข้อความ หากคุณไม่เห็นปุ่มนี้ แสดงว่าเนื้อหาที่คุณต้องการแก้ไข **ไม่รองรับ** placeholder
{.is-info}

หากต้องการคำนวณอะไรด้วย placeholder **Calculator** ให้แทนที่ตัวอย่างนิพจน์ด้วยของคุณเอง คุณสามารถใช้ placeholder ซ้อนกันภายในนิพจน์ได้ จึงสามารถนำ placeholder ของขนาดหน้าจอ ขนาดองค์ประกอบ ฯลฯ มาใช้ได้

ตัวอย่างเช่น placeholder นี้จะคำนวณ `1 + 1` และจะแสดงเป็น `2` ในภายหลัง:

`{"placeholder":"calc","values":{"expression":"1 + 1","decimal":"false"}}`

ตัวแปร `decimal` ถูกตั้งเป็น `false` ซึ่งสำคัญมากสำหรับการคำนวณด้านขนาด/ตำแหน่งส่วนใหญ่ ดังนั้นให้ตั้งค่านี้เป็น `false` เสมอเมื่อทำงานกับการกำหนดตำแหน่ง/ขนาดขั้นสูง

Calculator ต่อไปนี้ใช้ placeholder **Screen Width** และหารด้วย `2`:

`{"placeholder":"calc","values":{"expression":"{"placeholder":"guiwidth"} / 2","decimal":"false"}}`

> [!IMPORTANT]
> ขณะที่เปิดใช้งาน **Advanced Positioning** ค่า **anchor** และฟีเจอร์อื่นใดที่เกี่ยวข้องกับตำแหน่งขององค์ประกอบจะถูก **ละเว้น** Advanced Positioning จะใช้มุมซ้ายบน (X0 Y0) เป็นจุดกำเนิดเสมอ เช่นเดียวกับตรรกะ GUI เริ่มต้นของ Minecraft สิ่งเดียวที่ Advanced Positioning จะคำนึงถึงคือ **Stay on Screen**
