# การกำหนดตำแหน่งและขนาดขั้นสูง

การกำหนดตำแหน่ง/ขนาดขั้นสูงช่วยให้คุณมี **การควบคุมตำแหน่งและขนาดขององค์ประกอบได้อย่างเต็มที่** ซึ่งทรงพลังมาก แต่ก็ **ใช้เวลามากกว่า** การใช้การกำหนดขนาดและตำแหน่งอัตโนมัติของ FancyMenu

> หากคุณเพียงต้องการให้องค์ประกอบปรับสเกลให้เข้ากับ **GUI scale** ของ Minecraft ได้ดีขึ้น ขอแนะนำให้ใช้ **auto-scaling** ระดับเลย์เอาต์แทน ซึ่งสามารถเปิดใช้งานได้โดยบังคับ GUI scale ก่อนในเมนูที่เปิดขึ้นเมื่อคลิกขวาที่พื้นหลังของตัวแก้ไข จากนั้นเปิดใช้งาน **Auto-Scaling** ในเมนูเดียวกัน
{.is-warning}


# การสลับโหมดการกำหนดตำแหน่ง/ขนาดขั้นสูง

หากต้องการ **เปิดใช้งาน** การกำหนดตำแหน่ง/ขนาดขั้นสูงสำหรับองค์ประกอบ ให้ **คลิกขวา** ที่องค์ประกอบนั้น แล้วคลิก **Advanced Positioning** หรือ **Advanced Sizing**
องค์ประกอบจะสลับไปยังโหมดขั้นสูงโดยอัตโนมัติเมื่อคุณตั้งค่าตำแหน่งหรือขนาดแบบขั้นสูง

หากต้องการ **ปิดใช้งาน** และกลับไปใช้การกำหนดตำแหน่ง/ขนาดแบบปกติ ให้ **ล้างค่าตำแหน่ง/ขนาดทั้งหมด**

> ขณะที่องค์ประกอบอยู่ในโหมด Advanced Sizing/Positioning การปรับขนาดและ/หรือการย้ายองค์ประกอบอาจถูกปิดใช้งานหรือถูกจำกัด
{.is-warning}

# การคำนวณตำแหน่ง/ขนาด

เหตุผลที่การกำหนดตำแหน่ง/ขนาดขั้นสูงทรงพลังมาก เพราะคุณสามารถใช้ **placeholders** ในค่าตำแหน่ง/ขนาดได้

สิ่งนี้ช่วยให้คุณใช้ placeholder **Calculator** (อยู่ในหมวด placeholder **Advanced**) ร่วมกับ placeholder หมวด **GUI** เช่น **Screen Width**, **GUI Scale**, **Element Width** และอื่น ๆ

> คุณสามารถเพิ่ม placeholder ได้โดยคลิกปุ่ม **Placeholders** ที่มุมขวาบนของตัวแก้ไขข้อความ หากคุณไม่เห็นปุ่มนี้ แสดงว่าเนื้อหาที่คุณต้องการแก้ไข **ไม่รองรับ** placeholder
{.is-info}

หากต้องการคำนวณสิ่งใดด้วย placeholder **Calculator** ให้แทนที่ตัวอย่างนิพจน์ด้วยของคุณเอง คุณสามารถใช้ placeholder แบบซ้อนกันในนิพจน์ได้ ดังนั้นคุณจึงนำขนาดหน้าจอ ขนาดองค์ประกอบ ฯลฯ มาใช้ได้

ตัวอย่างเช่น placeholder นี้จะคำนวณ `1 + 1` และจะแสดงผลเป็น `2` ในภายหลัง:

`{"placeholder":"calc","values":{"expression":"1 + 1","decimal":"false"}}`

ตัวแปร `decimal` ถูกตั้งเป็น `false` ซึ่งสำคัญสำหรับการคำนวณขนาด/ตำแหน่งส่วนใหญ่ ดังนั้นเมื่อทำงานกับการกำหนดตำแหน่ง/ขนาดขั้นสูง ให้ตั้งค่านี้เป็น `false` เสมอ

Calculator ต่อไปนี้ใช้ placeholder **Screen Width** และหารด้วย `2`:

`{"placeholder":"calc","values":{"expression":"{"placeholder":"guiwidth"} / 2","decimal":"false"}}`
