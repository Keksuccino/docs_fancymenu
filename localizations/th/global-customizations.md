# การปรับแต่งแบบทั่วทั้งระบบ

การปรับแต่งแบบทั่วทั้งระบบคือการตั้งค่า FancyMenu ที่มีผลกับ UI ของเกมในทุกส่วน
ใช้เมื่อคุณต้องการสไตล์/พฤติกรรมแบบเดียวกันให้เหมือนกันทุกที่ แทนที่จะต้องแก้ไขเลย์เอาต์ของแต่ละหน้าจอแยกกัน

> [!INFO]
> ต่างจากฟีเจอร์ปรับแต่งส่วนใหญ่ของ FancyMenu การปรับแต่งแบบทั่วทั้งระบบจะทำงานได้แม้จะปิดการปรับแต่งหน้าจอปกติไว้ก็ตาม
> ฟีเจอร์นี้ **ไม่ต้อง** เปิดการปรับแต่งแยกตามหน้าจอ ทำให้การเปลี่ยนแปลงเพียงครั้งเดียวมีผลกับทุกหน้าจอได้ทันที

ตัวอย่างที่พบบ่อย:

- ใช้สไตล์ปุ่มและสไตล์สไลเดอร์ร่วมกันแบบเดียวสำหรับทุกหน้าจอ
- เปลี่ยนพื้นหลังเมนู, พาโนรามา และเพลงเมนูแบบทั่วทั้งระบบ
- ใช้พฤติกรรมเริ่มต้น/หน้าต่างแบบทั่วทั้งระบบ (GUI scale, โหมดเต็มจอ, ชื่อ/ไอคอนหน้าต่าง)
- แทนที่พื้นผิวปุ่มแบบดั้งเดิมทั่วทั้งระบบโดยไม่ต้องใช้ resource pack
- แทนที่เพลงเมนูแบบดั้งเดิมทั่วทั้งระบบโดยไม่ต้องใช้ resource pack

# จะหาได้ที่ไหน

เปิด **แถบเมนู** ของ FancyMenu ขณะที่ **ไม่ได้อยู่** ในตัวแก้ไขเลย์เอาต์ จากนั้นไปที่ **Customization -> Global Customizations**

# เริ่มต้นอย่างรวดเร็ว

1. เปิด **Customization -> Global Customizations**
2. เลือกหนึ่งหมวดหมู่เพื่อเริ่มต้น (เช่น **Custom Button Textures**)
3. กำหนดค่าตัวเลือกในหมวดนั้น (ตัวเลือกแหล่งทรัพยากร, สวิตช์เปิด/ปิด หรือช่องกรอกตัวเลข)
4. ทดสอบผลลัพธ์ในหลาย ๆ หน้าจอ
5. ปรับแต่งค่าที่เกี่ยวข้องเพิ่มเติม (เช่น ความโปร่งใส, สไตล์ป้ายกำกับ, ขอบแบบ nine-slice)

# สิ่งที่คุณปรับแต่งได้

## พฤติกรรมและการเริ่มต้นของระบบ

- **Game Intro** (วิดีโอหรือแอนิเมชันเปิดเกมที่เล่นก่อนหน้าจอ Title จะแสดงขึ้น)
- **Singleplayer Screen World Icons**
- **Multiplayer Screen Server Icons**
- **Seamless World Loading** (ใช้ภาพหน้าจอของโลกเป็นพื้นหลังหน้าจอโหลดโลก)
- **Custom Window Icon**
- **Custom Window Title**
- **Default GUI Scale**
- **Force Fullscreen on Launch**

## ลักษณะปุ่ม

- **Custom Button Textures** (สถานะ Normal/Hover/Inactive, โหมดโปร่งใส, nine-slice + ขนาดขอบ)
- **Button Labels** (ขีดเส้นใต้เมื่อชี้เมาส์, สีพื้นฐาน/สีเมื่อชี้, ขนาด, เงา)

## ลักษณะสไลเดอร์

- **Custom Slider Textures**
- **Slider Background Texture** (พื้นผิว, โหมดโปร่งใส, nine-slice + ขนาดขอบ)
- **Slider Handle Textures** (สถานะ Normal/Hover/Inactive, nine-slice + ขนาดขอบ)
- **Slider Labels** (ขีดเส้นใต้เมื่อชี้เมาส์, สีพื้นฐาน/สีเมื่อชี้, ขนาด, เงา)

## ลักษณะเมนูและเสียง

- **Custom Menu Background Texture**
- **Custom Menu Background Panorama**
- **Play Vanilla Menu Music** (เปิด/ปิดการเล่นเพลงเมนูแบบ Vanilla)
- **Custom Menu Music Tracks**
- **Custom Button/Slider Click Sound**

# Custom Menu Music Tracks

ใช้ **Custom Menu Music Tracks** เพื่อสร้างรายการเพลงแบบสุ่มสำหรับเมนู

แทร็กที่กำหนดเองจะมาแทนที่เพลงเมนูแบบ Vanilla ในเมนู

- เปิด **Custom Menu Music Tracks** เพื่อเปิด **Manage Menu Music Tracks**
- ใช้ **Add Track** เพื่อเพิ่มแหล่งเสียง
- ใช้ **Remove Track** เพื่อลบรายการหนึ่งรายการ
- ใช้ **Clear Tracks** เพื่อลบทั้งหมด
