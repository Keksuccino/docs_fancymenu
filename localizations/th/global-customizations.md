# การปรับแต่งส่วนกลาง

การปรับแต่งส่วนกลางจะเปลี่ยนทุกหน้าจอพร้อมกัน ทั้งปุ่ม แถบเลื่อน พื้นหลังเมนู เพลง หน้าต่างเกม และอื่น ๆ โดยไม่ต้องใช้เลย์เอาต์ และยังใช้ได้กับหน้าจอที่ปิดการปรับแต่งไว้ด้วย

เปิดใช้งานได้จาก **แถบเมนู -> การปรับแต่ง -> การปรับแต่งส่วนกลาง** บนหน้าจอใดก็ได้ที่อยู่นอกตัวแก้ไขเลย์เอาต์ การเปลี่ยนแปลงจะมีผลทันทีและบันทึกโดยอัตโนมัติ

> [!TIP]
> หากต้องการเปลี่ยนเพียงบางหน้าจอ ให้ใช้[เลย์เอาต์](/layout-editor) หากต้องการกำหนดรูปลักษณ์เฉพาะให้ปุ่มของบางเลย์เอาต์ ให้ใช้[เทมเพลตปุ่มและแถบเลื่อน](/button-slider-templates)

# ปุ่มและแถบเลื่อน

การตั้งค่าเหล่านี้จะเปลี่ยนปุ่มและแถบเลื่อนทั้งหมดในทุกหน้าจอ รวมถึงปุ่มและแถบเลื่อนจากม็อดอื่นด้วย

- ปุ่มและแถบเลื่อนที่กำหนดพื้นผิวหรือการตั้งค่าป้ายข้อความของตัวเองไว้จาก[เลย์เอาต์](/layout-editor) หรือ[เทมเพลต](/button-slider-templates) จะยังคงใช้การตั้งค่าเหล่านั้น
- ปุ่มที่เป็นเพียงรูปภาพ เช่น ปุ่มหนังสือสูตรอาหาร จะยังคงมีรูปลักษณ์เดิม

## พื้นผิวปุ่ม

**พื้นผิวปุ่มแบบกำหนดเอง** มีพื้นผิวสำหรับแต่ละสถานะของปุ่ม ดังนี้

- **ปกติ**
- **เมื่อชี้เมาส์**: ขณะที่เมาส์อยู่บนปุ่ม หรือเลือกปุ่มด้วยแป้นพิมพ์
- **ไม่ทำงาน**: ขณะที่ไม่สามารถคลิกปุ่มได้

กำหนดพื้นผิวให้ครบทั้งสามสถานะ หากสถานะใดไม่มีพื้นผิว ระบบจะแสดงปุ่มแบบดั้งเดิมของ Minecraft

การตั้งค่าเพิ่มเติมในเมนูเดียวกัน:

- **พื้นหลังโปร่งใส** ซ่อนพื้นหลังของปุ่มทั้งหมด ให้แสดงเฉพาะป้ายข้อความ โดยการตั้งค่านี้จะมีผลเหนือพื้นผิว
- **พื้นหลังปุ่มแบบเก้าส่วน** ช่วยให้ขอบของพื้นผิวคมชัดไม่ว่าปุ่มจะมีขนาดเท่าใด โดยกำหนดขนาดขอบทั้งสี่ได้จากตัวเลือกด้านล่าง ดู[การแบ่งเก้าส่วนและการปูกระเบื้อง](/nine-slicing-and-tiling)

> [!TIP]
> หากไม่ใช้การแบ่งเก้าส่วน พื้นผิวจะถูกยืดให้พอดีกับขนาดของปุ่มแต่ละปุ่ม ปุ่มของ Minecraft สูง 20 พิกเซล และส่วนใหญ่กว้าง 200 หรือ 150 พิกเซล เมื่อใช้การแบ่งเก้าส่วน พื้นผิวขนาดเล็กภาพเดียวก็ใช้ได้กับปุ่มทุกขนาด

## พื้นผิวแถบเลื่อน

**พื้นผิวแถบเลื่อนแบบกำหนดเอง** มีสองส่วน:

- **พื้นผิวพื้นหลังแถบเลื่อน**: แถบของแถบเลื่อน กำหนดพื้นผิวโดยใช้ **ตั้งค่าพื้นผิว** ตัวเลือก **พื้นหลังโปร่งใส** และ **พื้นหลังแถบเลื่อนแบบเก้าส่วน** ทำงานเหมือนกับตัวเลือกของปุ่ม
- **พื้นผิวที่จับแถบเลื่อน**: ส่วนที่ลากได้ มีพื้นผิวสถานะ **ปกติ**, **เมื่อชี้เมาส์** และ **ไม่ทำงาน** รวมถึงตัวเลือก **ที่จับแถบเลื่อนแบบเก้าส่วน**

ที่จับแถบเลื่อนของ Minecraft กว้าง 8 พิกเซล และสูงเท่ากับแถบเลื่อน ซึ่งส่วนใหญ่สูง 20 พิกเซล หากไม่ใช้การแบ่งเก้าส่วน พื้นผิวของที่จับจะถูกยืดให้ได้ขนาดดังกล่าว

## ป้ายข้อความ

**ป้ายข้อความปุ่ม** และ **ป้ายข้อความแถบเลื่อน** มีการตั้งค่าเหมือนกัน:

| การตั้งค่า | การทำงาน |
|---|---|
| **ขีดเส้นใต้ป้ายข้อความเมื่อชี้เมาส์** | ขีดเส้นใต้ป้ายข้อความขณะที่เมาส์อยู่บนป้าย |
| **สีพื้นฐานของป้ายข้อความ** | สีของป้ายข้อความ กำหนดโดยใช้ตัวเลือกสีหรือรหัส HEX เช่น `#FFF1D6` |
| **สีป้ายข้อความเมื่อชี้เมาส์** | สีของป้ายข้อความขณะที่เมาส์อยู่บนป้าย |
| **ขนาดป้ายข้อความ** | ขนาดของป้ายข้อความ ค่า `1` คือขนาดปกติ |
| **การจัดแนวป้ายข้อความ** | **ชิดซ้าย**, **กึ่งกลาง** หรือ **ชิดขวา** |
| **เงาป้ายข้อความ** | เงาสีเข้มด้านหลังป้ายข้อความ หากปิดไว้ ป้ายข้อความทั้งหมดจะไม่มีเงา แม้แต่ป้ายจากเลย์เอาต์ |

ป้ายข้อความที่กำหนดการตั้งค่าของตัวเองไว้จากเลย์เอาต์หรือเทมเพลตจะยังคงใช้การตั้งค่าเหล่านั้น สำหรับ **ขนาดป้ายข้อความ** และ **การจัดแนวป้ายข้อความ** จะใช้การตั้งค่าส่วนกลางเฉพาะกับป้ายข้อความที่มีขนาดปกติและจัด **กึ่งกลาง** เท่านั้น

## เสียงคลิก

- **เสียงคลิกปุ่มแบบกำหนดเอง** ใช้แทนเสียงคลิกปุ่มและแถบเลื่อนของ Minecraft ปุ่มที่กำหนดเสียงคลิกของตัวเองไว้จากเลย์เอาต์จะยังคงใช้เสียงนั้น
- **ระดับเสียงคลิกปุ่มแบบกำหนดเอง** ปรับได้ตั้งแต่ 0% ถึง 100% โดยตัวเลื่อนระดับเสียงของช่องเสียงนั้นในการตั้งค่าเสียงของ Minecraft จะมีผลเพิ่มเติมด้วย
- **ช่องเสียงคลิกปุ่มแบบกำหนดเอง** คือช่องเสียงที่ใช้เล่นเสียง เช่น เพลง ค่าเริ่มต้นคือระดับเสียงหลัก ซึ่งเป็นช่องของเสียงทั้งหมด

# พื้นหลังเมนู

**พื้นผิวพื้นหลังเมนูแบบกำหนดเอง** คือรูปภาพที่อยู่ด้านหลังเมนูทั้งหมด ยกเว้นหน้าจอชื่อเรื่อง:

- รูปภาพจะแสดงด้านหลังเมนูหยุดชั่วคราวและหน้าตัวเลือกขณะเล่นด้วย จึงบดบังโลกในบริเวณนั้น ส่วนคลังสิ่งของ ป้าย และหนังสือยังคงโปร่งใส
- **รักษาสัดส่วนพื้นผิวพื้นหลัง** จะคงสัดส่วนของรูปภาพไว้ โดยรูปภาพยังคงเต็มทั้งหน้าจอ แต่ส่วนที่ไม่พอดีจะถูกตัดออก หากปิดไว้ รูปภาพจะถูกยืดให้พอดีกับหน้าจอ

**พาโนรามาพื้นหลังเมนูแบบกำหนดเอง** ใช้แทนพาโนรามาของ Minecraft บนหน้าจอชื่อเรื่องและในเมนูทั้งหมดก่อนเข้าร่วมโลก:

- **เลือกพาโนรามา** ใช้เลือกหนึ่งใน[พาโนรามา](/panoramas)ของคุณ
- **ล้างพาโนรามา** คืนค่าพาโนรามาของ Minecraft
- **พาโนรามาปัจจุบัน** แสดงพาโนรามาที่เลือกไว้

หากกำหนดทั้งสองอย่างไว้ พื้นผิวจะบังพาโนรามา ทำให้เห็นพาโนรามาเฉพาะบนหน้าจอชื่อเรื่องเท่านั้น

หน้าจอที่เลย์เอาต์กำหนด[พื้นหลังเมนู](/menu-backgrounds)ของตัวเองไว้จะแสดงพื้นหลังนั้นแทน

# เพลงเมนู

- **เล่นเพลงเมนูดั้งเดิม** ใช้เปิดหรือปิดเพลงของ Minecraft ในเมนู
- **แทร็กเพลงเมนูแบบกำหนดเอง** เปิดหน้าต่าง **จัดการแทร็กเพลงเมนู** โดย **เพิ่มแทร็ก** จะเพิ่มเสียง, **ลบแทร็ก** จะลบแทร็กที่เลือก, **ล้างแทร็ก** จะลบทั้งหมด และ **เสร็จสิ้น** จะบันทึกรายการ

แทร็กจะเล่นแบบสุ่มในเมนูก่อนเข้าร่วมโลก โดยใช้แทนเพลงเมนูของ Minecraft ดูข้อมูลเพิ่มเติมเกี่ยวกับแทร็กและเพลงในหน้าจอเดียวได้ที่[เพลงพื้นหลังเมนู](/background-music)

# หน้าจอและป๊อปอัป

| การตั้งค่า | การทำงาน |
|---|---|
| [**อินโทรเกม**](/game-intro) | เล่นแอนิเมชันหรือวิดีโอก่อนแสดงหน้าจอชื่อเรื่อง |
| **ไอคอนโลกในหน้าจอผู้เล่นคนเดียว** | ไอคอนของโลกในรายการโลก หากปิดไว้ ไอคอนจะถูกซ่อน |
| **ไอคอนเซิร์ฟเวอร์ในหน้าจอผู้เล่นหลายคน** | ไอคอนของเซิร์ฟเวอร์ในรายการเซิร์ฟเวอร์ หากปิดไว้ ไอคอนจะถูกซ่อน |
| [**การโหลดโลกอย่างต่อเนื่อง**](/seamless-world-loading) | ถ่ายภาพหน้าจอเมื่อออกจากโลกหรือเซิร์ฟเวอร์ และแสดงภาพนั้นเป็นพื้นหลังระหว่างโหลดเมื่อกลับเข้าไปอีกครั้ง |
| **ป๊อปอัปความสำเร็จ** | ป๊อปอัปที่มุมขวาบนเมื่อปลดล็อกความสำเร็จ รวมถึงเสียงของป๊อปอัป หากปิดไว้ ป๊อปอัปจะถูกซ่อน ข้อความความสำเร็จในแชทยังคงแสดง และตัวดักฟัง [เมื่อปลดล็อกความสำเร็จ](/listeners#on-achievement-unlocked)ยังคงทำงาน |

# หน้าต่างและการเริ่มเกม

| การตั้งค่า | การทำงาน |
|---|---|
| [**ไอคอนหน้าต่างแบบกำหนดเอง**](/window-customization#custom-icon) | ไอคอนของหน้าต่างเกม ต้องมีไอคอน PNG ขนาด 16x16 และ 32x32 รวมถึงไอคอนสำหรับ macOS |
| [**ชื่อหน้าต่างแบบกำหนดเอง**](/window-customization#custom-title) | ใช้แทนชื่อหน้าต่างของ Minecraft โดยใช้[ตัวแทนข้อความ](/placeholders)ได้ และชื่อจะอัปเดตเมื่อค่าของตัวแทนข้อความเปลี่ยนแปลง |
| **ขนาด GUI เริ่มต้น** | กำหนดขนาด GUI ของ Minecraft หนึ่งครั้งเมื่อเริ่มอินสแตนซ์เกมเป็นครั้งแรก เช่น `2` หรือ `3` ค่า `-1` จะปิดการตั้งค่านี้ ออกแบบมาสำหรับม็อดแพ็ก |
| **บังคับใช้โหมดเต็มหน้าจอเมื่อเริ่มเกม** | เปลี่ยนเกมเป็นโหมดเต็มหน้าจอทุกครั้งที่เริ่มเกม |

FancyMenu จะจดจำว่าตั้งค่า **ขนาด GUI เริ่มต้น** ไว้แล้วใน `fancymenu_data/default_scale_set.fm` ลบไฟล์นั้นเพื่อให้ตั้งค่าขนาดอีกครั้งเมื่อเริ่มเกมครั้งถัดไป (ดู[ตำแหน่งจัดเก็บข้อมูล](/data-storage-locations#instance-data))

# ข้อมูลที่ควรทราบ

- การปรับแต่งส่วนกลางจะบันทึกไว้ใน `options.txt` ของ FancyMenu จึงเป็นส่วนหนึ่งของ[โปรไฟล์](/profiles)ที่โหลดอยู่ และติดไปกับม็อดแพ็กที่มี `config/fancymenu/`
- พื้นผิวและเสียงอาจเป็นไฟล์ในอินสแตนซ์ ลิงก์เว็บ หรือไฟล์จากแพ็กทรัพยากร ดู[ทรัพยากร](/resources)
- **แถบเมนู -> ช่วยเหลือ -> ส่งออกสำหรับ AI -> การตั้งค่า FancyMenu** จะรวมการตั้งค่าเหล่านี้ไว้ด้วย สำหรับคำถามที่ต้องการถาม[แชต AI](/export-for-ai)
