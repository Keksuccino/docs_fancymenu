# Dragger

Dragger คือองค์ประกอบที่มองไม่เห็น ซึ่งผู้ใช้สามารถลากด้วยเมาส์นอกตัวแก้ไขเลย์เอาต์ได้ คุณสามารถยึดองค์ประกอบอื่นเข้ากับมันได้ เพื่อให้องค์ประกอบเหล่านั้นถูกย้ายไปพร้อมกับ Dragger

1. เพิ่ม[**Dragger** element](./elements#dragger)
2. ยึดองค์ประกอบที่ควรเคลื่อนที่เข้ากับ Dragger
3. ปรับขนาดและตำแหน่งของ Dragger ให้อยู่ครอบพื้นที่ที่มองเห็นซึ่งผู้ใช้ควรลาก

เปิดใช้ **Save User Drag Offset** เพื่อเก็บตำแหน่งที่ลากไว้ระหว่างการเปิดหน้าจอและการรีสตาร์ทเกม หากต้องการให้ค่า offset รีเซ็ต ให้ปิดตัวเลือกนี้

Dragger จะมองเห็นได้เฉพาะในตัวแก้ไขเท่านั้น ใช้ [Image](./elements#image), [Shape](./elements#rectangle-shape) หรือองค์ประกอบอื่นที่ยึดไว้เป็นส่วนที่มองเห็นได้ของมัน
