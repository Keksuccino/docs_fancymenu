# Dragger

Dragger คือพื้นที่ที่มองไม่เห็น ซึ่งผู้เล่นสามารถใช้เมาส์คว้าและลากไปมาได้ ทุกอย่างที่ยึดติดกับ Dragger จะเคลื่อนที่ตามไปด้วย เช่น แผงบันทึกการอัปเดตหรือโน้ตกฎของเซิร์ฟเวอร์ เมนูจะจดจำตำแหน่งที่ผู้เล่นวางไว้ แม้จะปิดแล้วเปิดเกมใหม่ก็ตาม

<img width="800" alt="ผู้เล่นคว้าแบนเนอร์บันทึกการอัปเดตตรงด้ามจับหนังของก้าน แล้วลากจากด้านซ้ายไปด้านขวาของหน้าจอไตเติล เปิดตัวเลือก จากนั้นกลับมาและพบว่าแบนเนอร์ยังอยู่ทางขวา" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/dragger_hero.gif?raw=true">

ผู้เล่นจะลากได้เฉพาะเมื่ออยู่นอกตัวแก้ไขเลย์เอาต์ ในตัวแก้ไข Dragger จะแสดงเป็นกรอบสีแดงพร้อมชื่อของมัน (**สีในตัวแก้ไข** ในเมนูคลิกขวาใช้เปลี่ยนสีแดงได้) และทุกอย่างจะอยู่ในตำแหน่งที่กำหนดไว้ในเลย์เอาต์

# ทำให้สิ่งต่าง ๆ เคลื่อนย้ายได้

<img width="800" alt="เพิ่ม Dragger ผ่านเมนู New Element ปรับขนาดให้เท่ากับแบนเนอร์ ลากไปวางบนแบนเนอร์ แล้วย้ายลงไปสองชั้น จากนั้นลากแบนเนอร์ออกจาก Dragger แล้วลากกลับมา กดค้างไว้จนแถบเต็ม เพื่อยึดแบนเนอร์เข้ากับ Dragger" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/dragger_setup.gif?raw=true">

1. สร้างสิ่งที่ต้องการให้เคลื่อนที่ เช่น รูปแบนเนอร์ที่มีองค์ประกอบ Text อยู่ด้านบน
2. คลิกขวาบริเวณว่างในตัวแก้ไขเลย์เอาต์ แล้วคลิก **New Element -> Dragger**
3. ปรับขนาด Dragger ให้เท่ากับแบนเนอร์ แล้วลากไปวางบนแบนเนอร์
4. คลิกขวาที่ Dragger แล้วคลิก **Move One Layer Down** จนกว่า Dragger จะอยู่ใต้ทุกองค์ประกอบของแบนเนอร์ องค์ประกอบที่เลือกจะแสดงอยู่ด้านบนเสมอ ให้คลิกบริเวณว่างเพื่อดูการเปลี่ยนแปลง
5. ยึดแบนเนอร์เข้ากับ Dragger: ลากแบนเนอร์ออกจาก Dragger เล็กน้อย แล้วลากกลับมาและกดค้างไว้จนกว่าแถบจะเต็ม ดูข้อมูลเพิ่มเติมที่ [การจัดตำแหน่งองค์ประกอบ](/positioning-elements#anchoring-elements-to-other-elements)
6. บันทึกเลย์เอาต์ แล้วลองใช้งานนอกตัวแก้ไข

องค์ประกอบที่ยึดติดกับสิ่งที่เคลื่อนที่จะเคลื่อนที่ตามไปด้วย ใน GIF ข้อความยึดติดกับแบนเนอร์ ดังนั้นจึงต้องใช้ Dragger กับแบนเนอร์เพียงองค์ประกอบเดียว

หากต้องการยึดองค์ประกอบหลายรายการพร้อมกัน ให้คลิกขวาที่ Dragger แล้วคลิก **Copy Element ID** ก่อนทำขั้นตอนที่ 4 จากนั้นเลือกองค์ประกอบที่ต้องการ คลิกขวาที่รายการใดรายการหนึ่ง คลิก **Anchor Point -> Other Element** แล้ววาง ID

> [!TIP]
> ผู้เล่นมองไม่เห็น Dragger ดังนั้นควรแสดงให้เห็นว่าคว้าตรงไหนได้บ้าง เช่น ทำเป็นแถบชื่อเรื่องหรือมีที่จับ

# บันทึกตำแหน่ง

ตัวเลือก **Save User Drag Offset** ในเมนูคลิกขวาของ Dragger จะเปิดใช้งานไว้สำหรับ Dragger ที่สร้างใหม่

- **เปิดใช้งาน**: ระบบจะบันทึกตำแหน่งเมื่อผู้เล่นปล่อยเมาส์ ตำแหน่งจะยังคงอยู่แม้ปิดหน้าจอและเริ่มเกมใหม่
- **ปิดใช้งาน**: ทุกอย่างจะกลับไปยังตำแหน่งในเลย์เอาต์เมื่อเปิดหน้าจออีกครั้ง หรือเมื่อขนาดหน้าต่างหรือสเกล GUI เปลี่ยนไป

หากปิดตัวเลือกนี้ในตัวแก้ไข ระบบจะลืมตำแหน่งที่ผู้เล่นบันทึกไว้สำหรับ Dragger นี้ด้วย

ระบบจะบันทึกตำแหน่งของ Dragger แต่ละรายการโดยใช้ [element ID](/element-identifiers) ไว้ใน `fancymenu_data/dragger_metas.json` โฟลเดอร์นี้ไม่ได้รวมอยู่ใน [โปรไฟล์](/profiles) ดังนั้นตำแหน่งที่ลากไปไว้ขณะทดสอบจะไม่ไปอยู่ในโฟลเดอร์ `config/fancymenu/` ของม็อดแพ็ก ดูข้อมูลเพิ่มเติมที่ [ตำแหน่งจัดเก็บข้อมูล](/data-storage-locations#instance-data)

หากต้องการให้ Dragger ทุกตัวกลับไปยังตำแหน่งในเลย์เอาต์ ให้ลบ `dragger_metas.json` ขณะที่เกมปิดอยู่

# สิ่งที่ผู้เล่นคว้าได้

ผู้เล่นจะคว้า Dragger ได้ตรงบริเวณที่ไม่มีสิ่งอื่นอยู่ด้านบนมารับการคลิกแทน:

- รูปภาพที่อยู่ด้านบนจะปล่อยให้คลิกทะลุได้ ผู้เล่นจึงคว้าแบนเนอร์ได้โดยตรง
- ปุ่มและข้อความขององค์ประกอบ Text ที่อยู่ด้านบนจะรับการคลิก ทำให้ยังใช้งานได้บนแผงที่เคลื่อนย้ายได้
- บริเวณที่ Dragger อยู่ด้านบนปุ่มจะไม่รับการคลิก นี่จึงเป็นเหตุผลที่ขั้นตอนด้านบนให้วาง Dragger ไว้ใต้แบนเนอร์

ขณะที่ [ข้อกำหนด](/element-visibility#showing-elements-only-sometimes) ซ่อน Dragger ผู้เล่นจะคว้ามันไม่ได้

# ให้อยู่ในหน้าจอ

ตัวเลือก **Stay on Screen** จะเปิดใช้งานสำหรับองค์ประกอบใหม่ เพื่อหยุด Dragger ไว้ที่ขอบหน้าจอ ผู้เล่นจึงลากมันออกนอกจอไม่ได้ หาก Dragger มีขนาดเท่ากับแบนเนอร์ทั้งชิ้น แบนเนอร์ก็จะหยุดอยู่ที่ขอบหน้าจอไปพร้อมกัน

Dragger ที่ครอบคลุมเพียงบางส่วน เช่น แถบชื่อเรื่อง ก็ใช้งานได้เช่นกัน แต่องค์ประกอบที่ยึดติดกับ Dragger จะมีตัวเลือก **Stay on Screen** ของตัวเอง เมื่อถึงขอบหน้าจอ องค์ประกอบเหล่านั้นจะหยุดอยู่กับที่ ขณะที่ Dragger เคลื่อนที่ต่อ ทำให้แผงแยกออกจากกัน ปิด **Stay on Screen** สำหรับองค์ประกอบเหล่านั้น เพื่อให้เคลื่อนที่ตาม Dragger และมีเพียงแถบชื่อเรื่องที่อยู่ในหน้าจอ
