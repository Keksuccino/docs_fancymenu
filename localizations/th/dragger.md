# Dragger

Dragger element คือองค์ประกอบใน FancyMenu ที่ช่วยให้คุณทำให้เมนูมีการโต้ตอบได้ในรูปแบบที่ค่อนข้างไม่ธรรมดา Dragger เป็นองค์ประกอบที่สามารถลากด้วยเมาส์ได้ภายนอกตัวแก้ไข ซึ่งหมายความว่าผู้ใช้สามารถจับองค์ประกอบแล้วลากไปมาได้เลย

ฟังดูเจ๋งดี แต่การลากองค์ประกอบที่ไม่ได้ทำอะไรอย่างอื่นดูจะไร้ประโยชน์ใช่ไหม? จริง ๆ แล้วไม่ใช่ เพราะคุณสามารถแนบองค์ประกอบอื่นเข้ากับมันได้ โดยตั้งค่า Dragger element เป็นจุดยึด (anchor point) สำหรับองค์ประกอบอื่น ๆ ที่ควรเคลื่อนที่ไปพร้อมกับ Dragger

ค่าตำแหน่งออฟเซ็ตของ Dragger element จะถูกเก็บถาวรและบันทึกข้ามการรีสตาร์ทเกม ซึ่งโดยพื้นฐานแล้วหมายความว่าเมื่อผู้ใช้ย้าย Dragger ไปยังตำแหน่งใหม่ มันจะคงอยู่ที่ตำแหน่ง "กำหนดเอง" นั้น แม้จะปิดแล้วเปิดเกมใหม่ก็ตาม

Dragger element จะมองเห็นได้เฉพาะในตัวแก้ไข และมองไม่เห็นภายนอก ดังนั้นโปรดใช้องค์ประกอบอื่นเป็น "body" ให้มัน หากคุณต้องการให้ผู้ใช้เห็นว่าพื้นที่ที่ลากได้อยู่ตรงไหน
