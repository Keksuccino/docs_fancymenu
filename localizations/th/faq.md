# คำถามที่พบบ่อย

### ฉันต้องการความช่วยเหลือเกี่ยวกับปัญหา ฉันควรให้ข้อมูลอะไรบ้าง?

เพื่อให้ได้รับความช่วยเหลือที่ดีที่สุด โปรดให้ข้อมูลประกอบให้มากที่สุดเท่าที่จะทำได้:
1.  **คำอธิบายปัญหาอย่างชัดเจน:** คุณคาดว่าจะเกิดอะไรขึ้น และเกิดอะไรขึ้นจริง?
2.  **ไฟล์ `latest.log` ของคุณ:** หาได้ที่ `<game-directory>/logs/latest.log` **อย่าส่ง crash log** เว้นแต่มีการร้องขอเป็นพิเศษ; โดยปกติ `latest.log` จะมีข้อมูลที่จำเป็นอยู่แล้ว ใช้เว็บไซต์เช่น https://gist.github.com เมื่อโพสต์ไฟล์นี้
3.  **เวอร์ชัน Minecraft ของคุณ:** (เช่น 1.20.1)
4.  **Mod Loader และเวอร์ชันของคุณ:** (เช่น Forge 47.2.0, Fabric 0.15.7)
5.  **เวอร์ชัน FancyMenu ของคุณ:** (เช่น 3.5.2)
6.  **ภาพหน้าจอหรือวิดีโอ** ของปัญหาก็จะช่วยได้มากเช่นกัน

### ฉันจะเปลี่ยนลำดับชั้นการวางขององค์ประกอบได้อย่างไร (ย้ายบางอย่างไปด้านหน้าหรือด้านหลังของอีกอย่าง)?

*   **Custom vs. Custom:** เปิด **Window -> Editor Widgets -> Layers** แล้วลากองค์ประกอบในโครงสร้างลำดับชั้น คุณยังสามารถคลิกขวาที่องค์ประกอบและใช้ **Move One Layer Up/Down** ดูเพิ่มเติมที่ [Layers and Groups](./layers-and-groups)
*   **Custom vs. Vanilla:** หากต้องการให้ทุกองค์ประกอบแบบกำหนดเองแสดงอยู่ด้านหลังองค์ประกอบแบบวานิลลาทั้งหมด (เช่น วางภาพพื้นหลังไว้หลังปุ่มเริ่มต้น) ให้ **คลิกขวาที่พื้นหลังของ editor** แล้วเปิด/ปิดตัวเลือก **"Render Custom Elements Behind Vanilla"**

### ฉันสามารถยกเว้นปุ่มบางปุ่มจาก template ปุ่มแบบรวมได้ไหม?

**ไม่ได้ หากปุ่มใน template ถูกตั้งค่าพื้นผิวแบบกำหนดเองไว้ พื้นผิวเหล่านี้จะถูกแชร์ร่วมกับองค์ประกอบที่ได้รับผลกระทบทั้งหมดเสมอ คุณไม่สามารถยกเว้นปุ่มรายตัวได้**

### ฉันจะทำให้ปุ่มทำงานบางอย่างเมื่อคลิกได้อย่างไร?

ใช้ [**Action Script**](./action-scripts)
1.  คลิกขวาที่ปุ่มใน editor
2.  เลือก **Edit Action Script**
3. คลิก **Add Action** แล้วเลือก action เช่น [**Open Screen or Custom GUI**](./action-scripts#open-screen-or-custom-gui-opengui), [**Join Server**](./action-scripts#join-server-joinserver) หรือ [**Set Variable Value**](./action-scripts#set-variable-value-fm-variable-set_variable)

### ฉันสามารถสร้างหน้าจอเมนูใหม่ทั้งหมดจากศูนย์ได้ไหม?

ใช้ [**Custom GUI**](./custom-guis)
1.  ในแถบเมนู ไปที่ **Customization -> Custom GUIs -> Manage Custom GUIs**
2.  คลิก **"New GUI"** แล้วตั้งค่าตัวระบุที่ไม่ซ้ำกัน
3.  จากนั้นคุณสามารถเปิดหน้าจอว่างใหม่นี้และออกแบบเลย์เอาต์ของมัน พร้อมเพิ่มองค์ประกอบใดก็ได้ตามต้องการ
4. เปิด Custom GUI ด้วย [**Open Screen or Custom GUI** action](./action-scripts#open-screen-or-custom-gui-opengui)

### เกมของฉันใช้เวลาโหลดนานมากหลังจากเปิดใช้งานการโหลดล่วงหน้า

นี่เป็นพฤติกรรมที่คาดไว้ การโหลดทรัพยากรขนาดใหญ่ล่วงหน้า เช่น แอนิเมชันความละเอียดสูงหรือเสียง ในช่วงเริ่มต้นจะทำให้เวลาโหลดเกมนานขึ้นเป็นธรรมดา

### แอนิเมชัน FMA ของฉันกิน RAM มากเกินไป!

แอนิเมชัน [FMA](./fma) แบบคลาสสิกอาจใช้หน่วยความจำมากเมื่อมีเฟรมความละเอียดสูงจำนวนมาก AFMA เหมาะกับเท็กซ์เจอร์เคลื่อนไหวที่มีขนาดใหญ่หรือซับซ้อนมากกว่า ควรทำแอนิเมชัน FMA แบบคลาสสิกให้สั้น และใช้ [Video](./video) สำหรับการเล่นวิดีโอเต็มรูปแบบ

### FancyMenu ใช้กับ OptiFine ได้ไหม?

ไม่ได้ OptiFine **ไม่รองรับ** และเป็นที่ทราบกันว่าสามารถทำให้ม็อดหลายตัว รวมถึง FancyMenu ทำงานผิดพลาดได้ แนะนำอย่างยิ่งให้ใช้ทางเลือกสมัยใหม่อย่าง Sodium/Embeddium + Iris/Oculus
ดู [OptiFine Alternatives](./optifine-alternatives)

### เกมของฉันแครช ฉันจะรู้ได้อย่างไรว่ามีความขัดแย้งกับม็อดอื่นหรือไม่?

วิธีที่ดีที่สุดในการตรวจสอบความขัดแย้งกับม็อดอื่นคือ **รันเกมด้วย FancyMenu และ dependencies ของมันเท่านั้น** (Konkrete, Melody) หากไม่เกิดแครชอีกแล้ว คุณสามารถค่อย ๆ เพิ่มม็อดอื่นกลับเข้ามาทีละกลุ่มเล็ก ๆ จนกว่าแครชจะเกิดขึ้นอีก เพื่อระบุม็อดที่ขัดแย้งกัน

### ปุ่มจากม็อดอื่นหายไปหรือใช้งานไม่ได้เมื่อฉันพยายามแก้ไขมัน

ม็อดบางตัวเพิ่มวิดเจ็ตในรูปแบบที่ FancyMenu ตรวจจับหรือปรับแต่งไม่ได้ ดูที่ [Vanilla/Mod Elements](./vanilla-elements) และสำหรับหน้าจอแบบรายการ ดู [Customizing Scrollable Screens](./customizing-scrollable-screens) หากวิดเจ็ตยังไม่ปรากฏ ม็อดที่เพิ่มวิดเจ็ตนั้นต้องเปิดเผยมันเป็นวิดเจ็ตของหน้าจอที่รองรับ

### ฉันใช้เลย์เอาต์ FancyMenu บนเซิร์ฟเวอร์ได้ไหม?

เลย์เอาต์และการปรับแต่งด้านภาพจะถูกเก็บไว้บนไคลเอนต์ของผู้เล่น เซิร์ฟเวอร์ไม่สามารถบังคับให้ใช้กับไคลเอนต์ที่ยังไม่ได้ตั้งค่าได้ ควรแจกเป็นส่วนหนึ่งของม็อดแพ็ก ติดตั้ง FancyMenu บนเซิร์ฟเวอร์เมื่อคุณต้องการ [server commands](./commands), [FM Data](./fm-data), [server-side NBT access](./nbt-data-placeholder#server-side-placeholder), gamerules, structures หรือ server listeners

### ความแตกต่างระหว่าง FancyMenu v2 (สำหรับ Minecraft เวอร์ชันเก่า) กับ v3 คืออะไร?

FancyMenu v3 เป็นการเขียนใหม่ทั้งหมด มีฟีเจอร์ใหม่มากมาย สถาปัตยกรรมที่เสถียรกว่า และประสิทธิภาพดีกว่า V2 ล้าสมัย ไม่ได้รับการสนับสนุนแล้ว และขาดฟีเจอร์หลายอย่าง เช่น placeholders ขั้นสูงและการสคริปต์ แนะนำอย่างยิ่งให้ใช้ v3 บน Minecraft เวอร์ชันใหม่ (1.18.2+) เลย์เอาต์ V2 สามารถแปลงเป็น v3 ได้อัตโนมัติเมื่อโหลด แต่บางส่วนอาจต้องแก้ไขด้วยตนเอง

### ฉันหาดีไซน์เลย์เอาต์และ template สำเร็จรูปได้ที่ไหน?

ชุมชน FancyMenu แชร์เลย์เอาต์ไว้ในช่อง `#layout-templates` บนเซิร์ฟเวอร์ Discord อย่างเป็นทางการของ Keksuccino's Mods ("Kekscord")

### ฉันจะทำให้ Player Entity แสดงอยู่ด้านหลังองค์ประกอบอื่นได้อย่างไร?

โดยทั่วไปคุณไม่สามารถบังคับ [Player Entity element](./elements#player-entity) ให้อยู่ด้านหลังองค์ประกอบ 2D ปกติผ่าน [Layers widget](./layers-and-groups) ได้ ตัวเรนเดอร์ของมันสามารถไม่สนลำดับเลเยอร์ปกติของ GUI ได้ ให้ออกแบบเลย์เอาต์โดยคำนึงถึงข้อจำกัดนี้ หรือใช้ภาพที่เรนเดอร์ไว้ล่วงหน้าเมื่อจำเป็นต้องเรียงลำดับเลเยอร์อย่างเคร่งครัด

### Player Entity ของฉันมีแค่ขาเดียว! เกิดอะไรขึ้น?

นี่เป็นอาการภาพผิดปกติ ซึ่งน่าจะเกิดจากความขัดแย้งกับม็อดอื่นที่ปรับแต่งแอนิเมชันหรือโมเดลของผู้เล่น ตรวจสอบการตั้งค่า Pose ของ Player Entity เพื่อดูว่าขาถูกหมุนหรือเลื่อนไปโดยไม่ตั้งใจหรือไม่

### ฉันจะสร้างช่วงหน่วงระหว่าง action ในสคริปต์ได้อย่างไร?

ใช้บล็อก [**Delay** หรือ **Execute Later**](./action-scripts#what-are-statements) สำหรับตรรกะการหน่วงการทำงาน หากต้องการตรรกะเบื้องหลังที่ทำซ้ำ ให้ใช้ [Schedulers](./schedulers)

### ฉันสามารถปรับแต่งเมนูจากม็อด Create ได้ไหม?

ไม่ได้ การปรับแต่งถูกปิดใช้งานโดยตั้งใจสำหรับหน้าจอของ Create ดู [Screens where customization is intentionally disabled](./incompatibility-list#screens-where-customization-is-intentionally-disabled)

### ความละเอียดที่แนะนำสำหรับภาพพื้นหลังและเท็กซ์เจอร์ปุ่มคือเท่าไร?

พื้นหลัง: ภาพมาตรฐาน 1920x1080 (1080p) เป็นจุดเริ่มต้นที่ดี และจะปรับขนาดได้ดีสำหรับผู้ใช้ส่วนใหญ่
ปุ่ม: ปุ่มวานิลลาส่วนใหญ่มักกว้างประมาณ 150-200 พิกเซล และสูง 20 พิกเซล การทำเท็กซ์เจอร์แบบกำหนดเองให้ใกล้เคียงขนาดนี้เป็นแนวทางที่ดีเพื่อความสม่ำเสมอ

### มีวิธีเปิดเมนูหรือรันคำสั่งอัตโนมัติเมื่อผู้เล่นทำวัตถุประสงค์ในเกมเสร็จสิ้น (เช่น เควสต์) ไหม?
FancyMenu มี [built-in game-event listeners](./listeners) หลายแบบ แต่ไม่มี listener ทั่วไปสำหรับระบบเควสต์ของบุคคลที่สามทุกแบบ หากม็อดเควสต์รองรับรางวัลเป็นคำสั่ง ให้ใช้คำสั่งนั้นเพื่อรัน [`/openguiscreen`](./commands#openguiscreen), [`/fmvariable`](./commands#fmvariable) หรือ [FancyMenu command](./commands) อื่นที่เหมาะสม

### ฉันจะทำให้ปุ่มไม่ทำงานหรือ "เป็นสีเทา" ได้อย่างไร?

คุณสามารถควบคุมสถานะ active ของปุ่มได้ด้วย [Loading Requirements](./conditions)
คลิกขวาที่ปุ่มใน editor แล้วเลือก **Control Active State**
เพิ่มเงื่อนไขที่ต้องเป็นจริงเพื่อให้ปุ่ม active หากต้องการปิดถาวร ให้ใช้ [**Is Number**](./conditions#is-number-fancymenu_visibility_requirement_is_number) เพื่อตรวจว่า 0 เท่ากับ 1 หรือไม่
ตอนนี้ปุ่มจะใช้เท็กซ์เจอร์ "Inactive Background" และจะคลิกไม่ได้

### ฉันจะเอา header และ footer ออกได้อย่างไร (แถบพื้นผิวดินบนหน้าจอแบบเลื่อน)?

ในตัวแก้ไขเลย์เอาต์ ให้เปิด **Layout Properties -> Header/Footer Customizations** ตั้งค่าเท็กซ์เจอร์ให้เป็นแบบโปร่งใส ตัวเลือกนี้อาจไม่พร้อมใช้งานในบางหน้าจอของม็อดอื่น

### ฉันไม่สามารถสร้างเลย์เอาต์ "for the current screen" ได้ ปุ่มถูกทำให้เป็นสีเทา

คุณต้องเปิดใช้งานการปรับแต่งสำหรับหน้าจอนั้นก่อนผ่าน **menu bar -> Customization -> Current Screen Customizations -> Enabled**

### ฉันไม่สามารถปรับแต่งองค์ประกอบใด ๆ ของหน้าจอเมื่อเปิดใน editor ได้ มันเป็นเพียงหน้าจอว่างเปล่า

อาจหมายความว่าคุณสร้าง [Universal Layout](./universal-layouts) แทนที่จะเป็นแบบ **for the current screen**

อีกกรณีหนึ่งอาจเป็น [scrollable screen](./customizing-scrollable-screens) ซึ่ง FancyMenu ไม่สามารถปรับแต่งได้ตามค่าเริ่มต้น

ความเป็นไปได้ข้อที่สามคือเป็นหน้าจอจากม็อดที่เพิ่มองค์ประกอบในรูปแบบที่ไม่ใช่วานิลลา ทำให้ FancyMenu ไม่สามารถปรับแต่งองค์ประกอบเหล่านั้นได้

### มีกรอบสีเทาแปลก ๆ ที่องค์ประกอบ Text ของฉัน

กล่องโปร่งแสงเหล่านี้คือที่จับเลื่อนของ [Text element](./elements#text) ไม่ใช่บั๊กการแสดงผล

หากคุณไม่ต้องการให้กล่องเหล่านี้แสดง คุณสามารถคลิกขวาที่องค์ประกอบแล้วปิดการเลื่อนทั้งหมด หรือจะตั้งค่า grabber textures ให้เป็นแบบโปร่งใสทั้งหมดในเมนูคลิกขวาเดียวกันก็ได้ หากคุณยังต้องการให้องค์ประกอบเลื่อนได้อยู่

### ฉันจะให้แสดง changelog ล่าสุดของ Minecraft ในเมนูได้อย่างไร?

มี [โปรเจกต์ GitHub](https://github.com/ClaytonTDM/minecraft-changelogs-markdown) ที่ยอดเยี่ยมซึ่งแปลง changelog ของ Minecraft เป็น Markdown ที่เข้ากันได้กับ FancyMenu เพื่อให้คุณแสดง changelog ล่าสุดของ MC ในเมนูได้! โปรเจกต์นี้อัปเดตทุกวันเพื่อดึง changelog ใหม่

หากต้องการแสดงใน [Text element](./elements#text) ให้ตั้งค่า **Source Mode** เป็น **Resource** และตั้งค่า resource source เป็น **Web** ใช้ `https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`

### วิธีที่ง่ายที่สุดในการยืดองค์ประกอบใด ๆ ให้เต็มขนาดของหน้าจอคืออะไร?

องค์ประกอบส่วนใหญ่มีตัวเลือกในเมนูคลิกขวาสำหรับยืดในแนวนอนและแนวตั้ง การเปิดใช้งานจะทำให้องค์ประกอบยืดเต็มความกว้างและ/หรือความสูงของหน้าจอเสมอ การยืดแนวนอนและแนวตั้งสามารถเปิด/ปิดแยกกันได้

### ฉันไม่สามารถคลิกปุ่มหรือโต้ตอบกับสไลเดอร์ได้เมื่อมันอยู่ด้านหลังหรือด้านหน้าของ Text element

สิ่งนี้เกิดขึ้นเพราะ Text elements สามารถโต้ตอบได้โดยค่าเริ่มต้น (เพื่อให้สามารถจับ scroll grabber หรือคลิกลิงก์ Markdown ได้) ซึ่งหมายความว่ามันจะรับคลิกเมาส์และเหตุการณ์การเลื่อน วิธีที่ดีที่สุดคืออย่าย้ายปุ่มไปอยู่ด้านหลัง/ด้านหน้าของ Text elements แต่ถ้าเลี่ยงไม่ได้ คุณสามารถทำให้ Text element ไม่โต้ตอบได้โดย **คลิกขวา** แล้วตั้งค่า **Interactable** เป็น **Disabled** โปรดทราบว่าสิ่งนี้จะทำให้ Text element เป็นข้อความแบบคงที่ที่ไม่โต้ตอบ ดังนั้นคุณจะไม่สามารถเลื่อนหรือคลิกลิงก์ได้อีก

### ฉันจะทำอย่างไรไม่ให้ปุ่มและสไลเดอร์ถูกเลือก/โฟกัสอีกเมื่อใช้งานหน้าจอด้วยปุ่มลูกศรและ Tab บนคีย์บอร์ด?

หากต้องการไม่ให้ปุ่มและสไลเดอร์ถูกนำทางได้ คุณต้อง **คลิกขวา** แล้วตั้งค่า **Navigable** เป็น **Disabled** ปุ่ม/สไลเดอร์จะยังคลิกได้ แต่คุณจะไม่สามารถโฟกัสด้วยการนำทางผ่าน Arrow/Tab ได้อีก

สิ่งนี้ยังมีประโยชน์หากคุณต้องการเพิ่มปุ่ม/สไลเดอร์ในหน้าจอแชต เพื่อให้ยังสามารถใช้ปุ่ม Arrow Up เพื่อเลื่อนดูข้อความเก่าได้โดยไม่เผลอเลือกปุ่ม/สไลเดอร์ในหน้าจอ

### เมนูบริบทของ FancyMenu อันหนึ่งหายตัวเลือกที่ควรจะมี

เมนูบริบทของ FancyMenu (เมนูที่เปิดเมื่อคุณคลิกขวาที่จุดใดจุดหนึ่งหรือเมื่อโต้ตอบกับแถบเมนู) สามารถเลื่อนได้ ซึ่งหมายความว่าคุณสามารถใช้ล้อเลื่อนเมาส์ขณะวางเคอร์เซอร์ไว้บนเมนูเพื่อเลื่อนขึ้นหรือลง ทำให้คุณเห็นตัวเลือกเพิ่มเติมที่ก่อนหน้านี้มองไม่เห็น

### ฉันไม่สามารถปรับแต่งหน้าจอ Title ได้ มันยังคงแสดงหน้าจอเดิมเมื่อฉันออกจาก editor

ม็อดอื่นกำลังแทนที่ `title_screen` เดิมอยู่ ให้ปิดการใช้งานหน้าจอ Title แบบกำหนดเองของม็อดนั้นในการตั้งค่า หากไม่มีตัวเลือกดังกล่าว FancyMenu จะไม่สามารถนำเลย์เอาต์ไปใช้กับหน้าจอที่ถูกแทนที่ได้
