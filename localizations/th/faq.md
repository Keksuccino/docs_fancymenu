# คำถามที่พบบ่อย

### ฉันต้องการความช่วยเหลือเกี่ยวกับปัญหา ควรให้ข้อมูลอะไรบ้าง?

เพื่อให้ได้รับความช่วยเหลือที่ดีที่สุด โปรดระบุบริบทให้มากที่สุดเท่าที่จะทำได้:
1.  **คำอธิบายปัญหาที่ชัดเจน:** คุณคาดหวังให้เกิดอะไรขึ้น และสิ่งที่เกิดขึ้นจริงคืออะไร?
2.  **ไฟล์ `latest.log` ของคุณ:** ค้นหาได้ที่ `<game-directory>/logs/latest.log` **อย่าส่ง crash log** เว้นแต่จะมีการร้องขอเป็นกรณีพิเศษ โดยทั่วไป `latest.log` จะมีข้อมูลบริบทที่จำเป็น ใช้เว็บไซต์อย่าง https://gist.github.com เมื่อโพสต์ไฟล์ดังกล่าว
3.  **เวอร์ชัน Minecraft ของคุณ:** (เช่น 1.20.1)
4.  **Mod Loader และเวอร์ชันของคุณ:** (เช่น Forge 47.2.0, Fabric 0.15.7)
5.  **เวอร์ชัน FancyMenu ของคุณ:** (เช่น 3.5.2)
6.  **ภาพหน้าจอหรือวิดีโอ** ของปัญหาก็มีประโยชน์อย่างมากเช่นกัน

### ฉันจะเปลี่ยนลำดับชั้นขององค์ประกอบได้อย่างไร (ย้ายบางสิ่งไปไว้ด้านหน้าหรือด้านหลังสิ่งอื่น)?

*   **Custom กับ Custom:** เปิด **Window -> Editor Widgets -> Layers** แล้วลากองค์ประกอบในลำดับชั้น คุณยังสามารถคลิกขวาที่องค์ประกอบและใช้ **Move One Layer Up/Down** ได้ ดูที่ [Layers and Groups](./layers-and-groups)
*   **Custom กับ Vanilla:** หากต้องการแสดงองค์ประกอบแบบกำหนดเองทั้งหมดไว้ด้านหลังองค์ประกอบ Vanilla ทั้งหมด (เช่น วางภาพพื้นหลังไว้ด้านหลังปุ่มเริ่มต้น) ให้ **คลิกขวาที่พื้นหลังของตัวแก้ไข** แล้วเปิดใช้งานตัวเลือก **"Render Custom Elements Behind Vanilla"**

### ฉันสามารถยกเว้นปุ่มบางปุ่มจากเทมเพลตปุ่มแบบสากลได้หรือไม่?

**ไม่ได้ หากปุ่มเทมเพลตกำหนดพื้นผิวแบบกำหนดเองไว้ พื้นผิวเหล่านี้จะแชร์กับองค์ประกอบที่ได้รับผลกระทบทั้งหมดเสมอ คุณไม่สามารถยกเว้นปุ่มแต่ละปุ่มได้**

### ฉันจะทำให้ปุ่มทำบางอย่างเมื่อถูกคลิกได้อย่างไร?

ใช้ [**Action Script**](./action-scripts)
1.  คลิกขวาที่ปุ่มในตัวแก้ไข
2.  เลือก **Edit Action Script**
3.  คลิก **Add Action** แล้วเลือกการกระทำ เช่น [**Open Screen or Custom GUI**](./action-scripts#open-screen-or-custom-gui-opengui), [**Join Server**](./action-scripts#join-server-joinserver) หรือ [**Set Variable Value**](./action-scripts#set-variable-value-fm-variable-set_variable)

### ฉันสามารถสร้างหน้าจอเมนูใหม่ทั้งหมดตั้งแต่ต้นได้หรือไม่?

ใช้ [**Custom GUI**](./custom-guis)
1.  ในแถบเมนู ไปที่ **Customization -> Custom GUIs -> Manage Custom GUIs**
2.  คลิก **"New GUI"** และกำหนดตัวระบุที่ไม่ซ้ำกัน
3.  จากนั้นคุณสามารถเปิดหน้าจอว่างใหม่นี้และสร้างเลย์เอาต์ โดยเพิ่มองค์ประกอบใดก็ได้ตามต้องการ
4.  เปิด Custom GUI ด้วยการกระทำ [**Open Screen or Custom GUI**](./action-scripts#open-screen-or-custom-gui-opengui)

### เกมของฉันใช้เวลาโหลดนานหลังจากเปิดใช้งานการโหลดล่วงหน้า

นี่เป็นพฤติกรรมที่คาดไว้ การโหลดทรัพยากรขนาดใหญ่ เช่น แอนิเมชันความละเอียดสูงหรือเสียง ระหว่างการเริ่มต้นเกมจะทำให้เวลาโหลดเกมเพิ่มขึ้นตามธรรมชาติ

### แอนิเมชัน FMA ของฉันใช้ RAM มากเกินไป!

[แอนิเมชัน FMA](./fma) แบบคลาสสิกอาจใช้หน่วยความจำมากเมื่อมีเฟรมความละเอียดสูงจำนวนมาก AFMA เหมาะกับพื้นผิวแอนิเมชันขนาดใหญ่หรือซับซ้อนมากกว่า ควรใช้แอนิเมชัน FMA แบบคลาสสิกที่มีความยาวสั้น และใช้ [Video](./video) สำหรับการเล่นวิดีโอเต็มรูปแบบ

### FancyMenu ใช้งานร่วมกับ OptiFine ได้หรือไม่?

ไม่ได้ OptiFine **เข้ากันไม่ได้** และเป็นที่ทราบกันว่าสร้างปัญหาให้กับม็อดจำนวนมาก รวมถึง FancyMenu ขอแนะนำอย่างยิ่งให้ใช้ทางเลือกสมัยใหม่ เช่น Sodium/Embeddium + Iris/Oculus
ดูที่ [OptiFine Alternatives](./optifine-alternatives)

### เกมของฉันแครช ฉันจะตรวจสอบได้อย่างไรว่าเกิดจากม็อดขัดแย้งกัน?

วิธีที่ดีที่สุดในการตรวจสอบม็อดขัดแย้งกันคือ **เปิดเกมโดยมีเพียง FancyMenu และ dependencies ของมัน** (Konkrete, Melody) หากเกมไม่แครชอีกต่อไป ให้ทยอยเพิ่มม็อดอื่นกลับเข้าไปทีละกลุ่มเล็ก ๆ จนกว่าเกมจะแครชอีกครั้ง เพื่อระบุม็อดที่ขัดแย้งกัน

### ปุ่มจากม็อดอื่นหายไปหรือใช้งานไม่ได้เมื่อฉันพยายามแก้ไข

ม็อดบางตัวเพิ่มวิดเจ็ตด้วยวิธีที่ FancyMenu ตรวจจับหรือปรับแต่งไม่ได้ ดูที่ [Vanilla/Mod Elements](./vanilla-elements) และสำหรับหน้าจอแบบรายการ ดูที่ [Customizing Scrollable Screens](./customizing-scrollable-screens) หากวิดเจ็ตยังไม่ปรากฏ ม็อดที่เพิ่มวิดเจ็ตนั้นจะต้องเปิดเผยวิดเจ็ตดังกล่าวเป็นวิดเจ็ตหน้าจอที่รองรับ

### ฉันสามารถใช้เลย์เอาต์ของ FancyMenu บนเซิร์ฟเวอร์ได้หรือไม่?

เลย์เอาต์และการปรับแต่งด้านภาพจะถูกจัดเก็บไว้ในไคลเอนต์ของผู้เล่น เซิร์ฟเวอร์ไม่สามารถบังคับใช้กับไคลเอนต์ที่ไม่ได้ตั้งค่าไว้ได้ ให้แจกจ่ายเลย์เอาต์เหล่านี้เป็นส่วนหนึ่งของ modpack ติดตั้ง FancyMenu บนเซิร์ฟเวอร์เมื่อคุณต้องการใช้ [คำสั่งเซิร์ฟเวอร์](./commands), [FM Data](./fm-data), [การเข้าถึง NBT ฝั่งเซิร์ฟเวอร์](./nbt-data-placeholder#server-side-placeholder), gamerules, structures หรือ server listeners

### FancyMenu v2 (สำหรับ Minecraft เวอร์ชันเก่า) แตกต่างจาก v3 อย่างไร?

FancyMenu v3 เป็นการเขียนใหม่ทั้งหมด พร้อมฟีเจอร์ใหม่มากมาย สถาปัตยกรรมที่เสถียรกว่า และประสิทธิภาพที่ดีกว่า V2 ล้าสมัย ไม่ได้รับการสนับสนุนอีกต่อไป และขาดฟีเจอร์มากมาย เช่น placeholder ขั้นสูงและการเขียนสคริปต์ ขอแนะนำอย่างยิ่งให้ใช้ v3 บน Minecraft เวอร์ชันใหม่ (1.18.2 ขึ้นไป) เลย์เอาต์ V2 จะถูกแปลงเป็น v3 โดยอัตโนมัติเมื่อคุณโหลด แต่บางส่วนอาจต้องแก้ไขด้วยตนเอง

### ฉันจะหาเลย์เอาต์และเทมเพลตที่สร้างไว้ล่วงหน้าได้จากที่ไหน?

ชุมชน FancyMenu แชร์เลย์เอาต์ในช่อง [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) ของเซิร์ฟเวอร์ Discord อย่างเป็นทางการของ Keksuccino's Mods ("Kekscord")

### ฉันจะทำให้ Player Entity แสดงผลอยู่ด้านหลังองค์ประกอบอื่นได้อย่างไร?

โดยทั่วไป คุณไม่สามารถบังคับให้ [องค์ประกอบ Player Entity](./elements#player-entity) อยู่ด้านหลังองค์ประกอบ 2D ปกติผ่าน [วิดเจ็ต Layers](./layers-and-groups) ได้ ตัวเรนเดอร์ของมันอาจไม่สนใจลำดับเลเยอร์ GUI ปกติ ให้ออกแบบเลย์เอาต์โดยคำนึงถึงข้อจำกัดนี้ หรือใช้ภาพที่เรนเดอร์ไว้ล่วงหน้าเมื่อต้องการควบคุมลำดับเลเยอร์อย่างเคร่งครัด

### Player Entity ของฉันมีขาเพียงข้างเดียว! เกิดอะไรขึ้น?

นี่เป็นข้อผิดพลาดด้านภาพ ซึ่งน่าจะเกิดจากม็อดขัดแย้งกับม็อดอื่นที่ปรับเปลี่ยนแอนิเมชันหรือโมเดลของผู้เล่น ตรวจสอบการตั้งค่า Pose ของ Player Entity เพื่อดูว่าขาถูกหมุนหรือย้ายโดยไม่ได้ตั้งใจหรือไม่

### ฉันจะสร้างการหน่วงเวลาระหว่างการกระทำในสคริปต์ได้อย่างไร?

ใช้บล็อก [**Delay** หรือ **Execute Later**](./action-scripts#what-are-statements) สำหรับตรรกะการกระทำที่ต้องหน่วงเวลา หากต้องการตรรกะเบื้องหลังที่ทำซ้ำ ให้ใช้ [Schedulers](./schedulers)

### ฉันสามารถปรับแต่งเมนูจากม็อด Create ได้หรือไม่?

ไม่ได้ การปรับแต่งหน้าจอของ Create ถูกปิดใช้งานโดยตั้งใจ ดูที่ [หน้าจอที่ปิดการปรับแต่งโดยตั้งใจ](./incompatibility-list#screens-where-customization-is-intentionally-disabled)

### ความละเอียดที่แนะนำสำหรับภาพพื้นหลังและพื้นผิวปุ่มคือเท่าใด?

พื้นหลัง: ภาพมาตรฐานขนาด 1920x1080 (1080p) เป็นจุดเริ่มต้นที่ดีและปรับขนาดได้เหมาะสมสำหรับผู้ใช้ส่วนใหญ่
ปุ่ม: ปุ่ม Vanilla ส่วนใหญ่มีความกว้างประมาณ 150-200 พิกเซล และสูง 20 พิกเซล การใช้พื้นผิวแบบกำหนดเองที่มีขนาดใกล้เคียงกันเป็นแนวทางที่ดีเพื่อให้สอดคล้องกัน

### มีวิธีเปิดเมนูหรือเรียกใช้คำสั่งโดยอัตโนมัติเมื่อผู้เล่นทำเป้าหมายในเกมสำเร็จ (เช่น ภารกิจ) หรือไม่?

FancyMenu มี [ตัวรับฟังเหตุการณ์ในเกมในตัว](./listeners) มากมาย แต่ไม่มีตัวรับฟังทั่วไปสำหรับระบบภารกิจจากบุคคลที่สามทุกระบบ หากม็อดภารกิจรองรับรางวัลเป็นคำสั่ง ให้ใช้คำสั่งดังกล่าวเพื่อเรียกใช้ [`/openguiscreen`](./commands#openguiscreen), [`/fmvariable`](./commands#fmvariable) หรือ [คำสั่ง FancyMenu](./commands) อื่นที่เหมาะสม

### ฉันจะทำให้ปุ่มไม่ทำงานหรือเป็นสีเทาได้อย่างไร?

คุณสามารถควบคุมสถานะการทำงานของปุ่มได้โดยใช้ [Loading Requirements](./conditions)
คลิกขวาที่ปุ่มในตัวแก้ไข แล้วเลือก **Control Active State**
เพิ่มเงื่อนไขที่ต้องเป็นจริงเพื่อให้ปุ่มทำงาน หากต้องการปิดใช้งานอย่างถาวร ให้ใช้ [**Is Number**](./conditions#is-number-fancymenu_visibility_requirement_is_number) เพื่อตรวจสอบว่า 0 เท่ากับ 1
ปุ่มจะใช้พื้นผิว "Inactive Background" และไม่สามารถคลิกได้

### ฉันจะลบส่วนหัวและส่วนท้าย (แถบพื้นผิวดิน) บนหน้าจอแบบเลื่อนได้อย่างไร?

ในตัวแก้ไขเลย์เอาต์ เปิด **Layout Properties -> Header/Footer Customizations** แล้วตั้งค่าพื้นผิวให้โปร่งใส ตัวเลือกนี้อาจไม่พร้อมใช้งานบนหน้าจอจากม็อดบางตัว

### ฉันสร้างเลย์เอาต์ "สำหรับหน้าจอปัจจุบัน" ไม่ได้ ปุ่มเป็นสีเทา

คุณต้องเปิดใช้งานการปรับแต่งสำหรับหน้าจอนั้นก่อนผ่าน **แถบเมนู -> Customization -> Current Screen Customizations -> Enabled**

### ฉันปรับแต่งองค์ประกอบใด ๆ ของหน้าจอไม่ได้เมื่อเปิดหน้าจอนั้นในตัวแก้ไข มันเป็นเพียงหน้าจอว่างเปล่า

อาจหมายความว่าคุณสร้าง [Universal Layout](./universal-layouts) แทนเลย์เอาต์ **สำหรับหน้าจอปัจจุบัน**

อีกสาเหตุหนึ่งอาจเป็น [หน้าจอแบบเลื่อนได้](./customizing-scrollable-screens) ซึ่ง FancyMenu ไม่สามารถปรับแต่งได้ตามค่าเริ่มต้น

ความเป็นไปได้ประการที่สามคือหน้าจอนั้นมาจากม็อดที่เพิ่มองค์ประกอบด้วยวิธีที่ไม่ใช่แบบ Vanilla ทำให้ FancyMenu ไม่สามารถปรับแต่งองค์ประกอบเหล่านั้นได้

### มีกรอบสีเทาแปลก ๆ อยู่ที่องค์ประกอบ Text ของฉัน

กรอบโปร่งแสงเหล่านี้คือปุ่มจับเพื่อเลื่อนของ [องค์ประกอบ Text](./elements#text) ไม่ใช่ข้อผิดพลาดในการเรนเดอร์

หากคุณไม่ต้องการให้กรอบเหล่านี้แสดง คุณสามารถคลิกขวาที่องค์ประกอบแล้วปิดการเลื่อนทั้งหมด หรือกำหนดพื้นผิวของปุ่มจับให้โปร่งใสทั้งหมดจากเมนูคลิกขวาเดียวกัน หากยังต้องการให้องค์ประกอบเลื่อนได้

### ฉันจะแสดง changelog ล่าสุดของ Minecraft ในเมนูได้อย่างไร?

มี [โปรเจกต์ GitHub](https://github.com/ClaytonTDM/minecraft-changelogs-markdown) ที่ยอดเยี่ยมซึ่งแปลง changelog ของ Minecraft เป็น Markdown ที่เข้ากันได้กับ FancyMenu ทำให้คุณสามารถแสดง changelog ล่าสุดของ MC ในเมนูได้ โปรเจกต์นี้จะอัปเดตทุกวันเพื่อดึง changelog ใหม่

หากต้องการแสดงใน [องค์ประกอบ Text](./elements#text) ให้ตั้งค่า **Source Mode** เป็น **Resource** และตั้งแหล่งทรัพยากรเป็น **Web** ใช้ `https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`

### วิธีที่ง่ายที่สุดในการขยายองค์ประกอบใด ๆ ให้มีขนาดเท่าหน้าจอคืออะไร?

องค์ประกอบส่วนใหญ่มีตัวเลือกในเมนูบริบทเมื่อคลิกขวา เพื่อขยายองค์ประกอบในแนวนอนและแนวตั้ง การเปิดใช้งานจะทำให้องค์ประกอบขยายเต็มความกว้างและ/หรือความสูงของหน้าจอเสมอ สามารถเปิดหรือปิดการขยายแนวนอนและแนวตั้งแยกจากกันได้

### ฉันคลิกปุ่มหรือโต้ตอบกับแถบเลื่อนไม่ได้เมื่อปุ่มหรือแถบเลื่อนอยู่ด้านหลังหรือด้านหน้าองค์ประกอบ Text

สิ่งนี้เกิดขึ้นเพราะองค์ประกอบ Text สามารถโต้ตอบได้ตามค่าเริ่มต้น (เพื่อให้สามารถลากปุ่มจับการเลื่อนหรือคลิกลิงก์ Markdown ได้) ซึ่งหมายความว่าองค์ประกอบเหล่านี้จะรับการคลิกเมาส์และเหตุการณ์การเลื่อน วิธีที่ดีที่สุดคือไม่วางปุ่มไว้ด้านหลังหรือด้านหน้าองค์ประกอบ Text แต่หากหลีกเลี่ยงไม่ได้ คุณสามารถทำให้องค์ประกอบ Text ไม่สามารถโต้ตอบได้โดย **คลิกขวาที่องค์ประกอบ** แล้วตั้งค่า **Interactable** เป็น **Disabled** โปรดทราบว่าวิธีนี้จะทำให้องค์ประกอบ Text เป็นข้อความแบบคงที่และโต้ตอบไม่ได้ จึงไม่สามารถเลื่อนหรือคลิกลิงก์ได้อีก

### ฉันจะทำให้ปุ่มและแถบเลื่อนไม่ถูกเลือกหรือได้รับโฟกัสเมื่อใช้งานปุ่มลูกศรและ Tab เพื่อนำทางในหน้าจอได้อย่างไร?

หากต้องการไม่ให้สามารถนำทางไปยังปุ่มและแถบเลื่อนได้ ให้ **คลิกขวา** ที่องค์ประกอบนั้นแล้วตั้งค่า **Navigable** เป็น **Disabled** ปุ่มหรือแถบเลื่อนยังคงคลิกได้ แต่คุณจะไม่สามารถโฟกัสด้วยการนำทางด้วยปุ่มลูกศรหรือ Tab ได้อีก

สิ่งนี้มีประโยชน์เช่นกันหากคุณต้องการเพิ่มปุ่มหรือแถบเลื่อนไว้ในหน้าจอ Chat เพื่อให้ยังใช้ปุ่มลูกศรขึ้นเลื่อนดูข้อความเก่าได้ โดยไม่เลือกปุ่มหรือแถบเลื่อนในหน้าจอโดยไม่ได้ตั้งใจ

### เมนูบริบทหนึ่งของ FancyMenu ขาดตัวเลือกที่ควรมี

เมนูบริบทของ FancyMenu (เมนูที่เปิดขึ้นเมื่อคุณคลิกขวาที่ใดที่หนึ่งหรือโต้ตอบกับแถบเมนู) **สามารถเลื่อนได้** ซึ่งหมายความว่าคุณสามารถใช้ล้อเลื่อนของเมาส์ขณะที่เคอร์เซอร์อยู่เหนือเมนูเพื่อเลื่อนขึ้นหรือลง และดูตัวเลือกเพิ่มเติมที่ก่อนหน้านี้ไม่แสดงได้

### ฉันปรับแต่งหน้าจอ Title ไม่ได้ เมื่อออกจากตัวแก้ไข หน้าจอเดิมยังคงแสดงอยู่

ม็อดอื่นกำลังแทนที่ `title_screen` เดิม ให้ปิดใช้งานหน้าจอ Title แบบกำหนดเองของม็อดนั้นในการตั้งค่า หากไม่มีตัวเลือกดังกล่าว FancyMenu จะไม่สามารถใช้เลย์เอาต์กับหน้าจอที่ถูกแทนที่ได้
