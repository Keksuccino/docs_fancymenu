# คำถามที่พบบ่อย

### ฉันต้องการความช่วยเหลือเกี่ยวกับปัญหา ควรให้ข้อมูลอะไรบ้าง?

เพื่อให้ได้รับความช่วยเหลือที่ดีที่สุด โปรดให้ข้อมูลพร้อมบริบทมากที่สุดเท่าที่จะทำได้:
1.  **คำอธิบายปัญหาที่ชัดเจน:** คุณคาดหวังให้เกิดอะไรขึ้น และสิ่งที่เกิดขึ้นจริงคืออะไร?
2.  **ไฟล์ `latest.log` ของคุณ:** ค้นหาได้ที่ `<game-directory>/logs/latest.log` **อย่าส่ง crash log** เว้นแต่จะมีการร้องขอโดยเฉพาะ โดยทั่วไป `latest.log` จะมีบริบทที่จำเป็นอยู่แล้ว ใช้เว็บไซต์อย่าง https://gist.github.com เมื่อโพสต์ไฟล์
3.  **เวอร์ชัน Minecraft ของคุณ:** (เช่น 1.20.1)
4.  **ตัวโหลดม็อดและเวอร์ชัน:** (เช่น Forge 47.2.0, Fabric 0.15.7)
5.  **เวอร์ชัน FancyMenu:** (เช่น 3.5.2)
6.  **ภาพหน้าจอหรือวิดีโอ** ของปัญหาก็ช่วยได้มากเช่นกัน

### ฉันจะเปลี่ยนลำดับการซ้อนขององค์ประกอบได้อย่างไร (ย้ายสิ่งหนึ่งไปด้านหน้าหรือด้านหลังอีกสิ่งหนึ่ง)?

*   **Custom กับ Custom:** เปิด **Window -> Editor Widgets -> Layers** แล้วลากองค์ประกอบในลำดับชั้น คุณยังสามารถคลิกขวาที่องค์ประกอบและใช้ **Move One Layer Up/Down** ได้ ดู [Layers and Groups](./layers-and-groups)
*   **Custom กับ Vanilla:** หากต้องการให้แสดงองค์ประกอบ Custom ทั้งหมดไว้ด้านหลังองค์ประกอบ Vanilla ทั้งหมด (เช่น วางภาพพื้นหลังไว้ด้านหลังปุ่มเริ่มต้น) ให้ **คลิกขวาที่พื้นหลังของตัวแก้ไข** แล้วเปิดใช้ตัวเลือก **"Render Custom Elements Behind Vanilla"**

### ฉันสามารถไม่รวมปุ่มบางปุ่มจากเทมเพลตปุ่มแบบ Universal ได้หรือไม่?

**ไม่ได้ หากปุ่มเทมเพลตกำหนดพื้นผิวแบบ Custom ไว้ พื้นผิวเหล่านี้จะแชร์กับองค์ประกอบทั้งหมดที่ได้รับผลกระทบเสมอ คุณไม่สามารถยกเว้นปุ่มแต่ละปุ่มได้**

### ฉันจะทำให้ปุ่มทำบางอย่างเมื่อคลิกได้อย่างไร?

ใช้ [**Action Script**](./action-scripts)
1.  คลิกขวาที่ปุ่มในตัวแก้ไข
2.  เลือก **Edit Action Script**
3. คลิก **Add Action** แล้วเลือกการกระทำ เช่น [**Open Screen or Custom GUI**](./action-scripts#open-screen-or-custom-gui-opengui), [**Join Server**](./action-scripts#join-server-joinserver) หรือ [**Set Variable Value**](./action-scripts#set-variable-value-fm-variable-set_variable)

### ฉันสามารถสร้างหน้าจอเมนูใหม่ทั้งหมดตั้งแต่ต้นได้หรือไม่?

ใช้ [**Custom GUI**](./custom-guis)
1.  ในแถบเมนู ไปที่ **Customization -> Custom GUIs -> Manage Custom GUIs**
2.  คลิก **"New GUI"** และตั้งตัวระบุที่ไม่ซ้ำกัน
3.  จากนั้นคุณสามารถเปิดหน้าจอว่างใหม่นี้และสร้างเลย์เอาต์ โดยเพิ่มองค์ประกอบใดก็ได้ตามต้องการ
4. เปิด Custom GUI ด้วยการกระทำ [**Open Screen or Custom GUI**](./action-scripts#open-screen-or-custom-gui-opengui)

### เกมของฉันใช้เวลาโหลดนานขึ้นหลังจากเปิดใช้การโหลดล่วงหน้า

นี่เป็นพฤติกรรมที่คาดไว้ การโหลดทรัพยากรขนาดใหญ่ เช่น แอนิเมชันความละเอียดสูงหรือเสียง ระหว่างการเริ่มต้นเกมจะทำให้เวลาโหลดเกมนานขึ้นโดยธรรมชาติ

### แอนิเมชัน FMA ของฉันใช้ RAM มากเกินไป!

[FMA animations](./fma) แบบคลาสสิกอาจใช้หน่วยความจำมากเมื่อมีเฟรมความละเอียดสูงจำนวนมาก AFMA เหมาะสมกว่าสำหรับพื้นผิวเคลื่อนไหวขนาดใหญ่หรือซับซ้อน ควรทำแอนิเมชัน FMA แบบคลาสสิกให้สั้น และใช้ [Video](./video) สำหรับการเล่นวิดีโอแบบเต็มรูปแบบ

### FancyMenu ใช้งานร่วมกับ OptiFine ได้หรือไม่?

ไม่ได้ OptiFine **ไม่รองรับการใช้งานร่วมกัน** และเป็นที่ทราบกันว่าสร้างปัญหาให้ม็อดจำนวนมาก รวมถึง FancyMenu ขอแนะนำอย่างยิ่งให้ใช้ทางเลือกสมัยใหม่ เช่น Sodium/Embeddium + Iris/Oculus
ดู [OptiFine Alternatives](./optifine-alternatives)

### เกมของฉันแครช ฉันจะตรวจสอบได้อย่างไรว่าเกิดจากม็อดขัดแย้งกัน?

วิธีตรวจสอบม็อดที่ขัดแย้งกันที่ดีที่สุดคือ **เปิดเกมโดยมีเพียง FancyMenu และ Dependencies ของมัน** (Konkrete, Melody) หากเกมไม่แครชอีก ให้ทยอยเพิ่มม็อดอื่นกลับเข้าไปทีละกลุ่มเล็ก ๆ จนกระทั่งเกิดแครชอีกครั้ง เพื่อระบุม็อดที่ขัดแย้งกัน

### ปุ่มจากม็อดอื่นหายไปหรือใช้งานไม่ได้เมื่อฉันพยายามแก้ไข

ม็อดบางตัวเพิ่มวิดเจ็ตในลักษณะที่ FancyMenu ตรวจจับหรือปรับแต่งไม่ได้ โปรดดู [Vanilla/Mod Elements](./vanilla-elements) และสำหรับหน้าจอแบบรายการ ให้ดู [Customizing Scrollable Screens](./customizing-scrollable-screens) หากวิดเจ็ตยังไม่ปรากฏ ม็อดที่เพิ่มวิดเจ็ตนั้นจะต้องเปิดเผยวิดเจ็ตดังกล่าวในรูปแบบที่รองรับโดยหน้าจอ

### ฉันสามารถใช้เลย์เอาต์ของ FancyMenu บนเซิร์ฟเวอร์ได้หรือไม่?

เลย์เอาต์และการปรับแต่งรูปลักษณ์จะถูกจัดเก็บไว้ในไคลเอนต์ของผู้เล่น เซิร์ฟเวอร์ไม่สามารถบังคับใช้กับไคลเอนต์ที่ไม่ได้กำหนดค่าไว้ได้ ให้แจกจ่ายเลย์เอาต์เหล่านี้เป็นส่วนหนึ่งของม็อดแพ็ก ติดตั้ง FancyMenu บนเซิร์ฟเวอร์เมื่อคุณต้องการใช้ [คำสั่งเซิร์ฟเวอร์](./commands), [FM Data](./fm-data), [การเข้าถึง NBT ฝั่งเซิร์ฟเวอร์](./nbt-data-placeholder#server-side-placeholder), gamerules, structures หรือ server listeners

### FancyMenu v2 (สำหรับเวอร์ชัน MC รุ่นเก่า) แตกต่างจาก v3 อย่างไร?

FancyMenu v3 เป็นการเขียนใหม่ทั้งหมด พร้อมฟีเจอร์ใหม่มากมาย สถาปัตยกรรมที่เสถียรกว่า และประสิทธิภาพที่ดีขึ้น ส่วน V2 ล้าสมัย ไม่ได้รับการสนับสนุนอีกต่อไป และขาดฟีเจอร์มากมาย เช่น Placeholder ขั้นสูงและการเขียนสคริปต์ ขอแนะนำอย่างยิ่งให้ใช้ v3 บน Minecraft เวอร์ชันใหม่ (1.18.2 ขึ้นไป) เลย์เอาต์ V2 จะถูกแปลงเป็น v3 โดยอัตโนมัติเมื่อคุณโหลด แต่บางส่วนอาจต้องแก้ไขด้วยตนเอง

### ฉันจะหาเลย์เอาต์และเทมเพลตที่สร้างไว้ล่วงหน้าได้จากที่ไหน?

ชุมชน FancyMenu แชร์เลย์เอาต์ไว้ในช่อง [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) ของเซิร์ฟเวอร์ Discord อย่างเป็นทางการของ Keksuccino's Mods ("Kekscord")

### ฉันจะทำให้ Player Entity แสดงอยู่ด้านหลังองค์ประกอบอื่นได้อย่างไร?

โดยทั่วไปคุณไม่สามารถบังคับให้ [Player Entity element](./elements#player-entity) อยู่ด้านหลังองค์ประกอบ 2D ปกติผ่านวิดเจ็ต [Layers](./layers-and-groups) ได้ ตัวเรนเดอร์ของมันอาจไม่สนใจลำดับเลเยอร์ GUI ปกติ ให้ออกแบบเลย์เอาต์โดยคำนึงถึงข้อจำกัดนี้ หรือใช้ภาพที่เรนเดอร์ไว้ล่วงหน้าเมื่อต้องการกำหนดลำดับเลเยอร์อย่างเคร่งครัด

### Player Entity ของฉันมีขาเพียงข้างเดียว! เกิดอะไรขึ้น?

นี่เป็นข้อผิดพลาดด้านการแสดงผล ซึ่งน่าจะเกิดจากม็อดขัดแย้งกับม็อดอื่นที่เปลี่ยนแอนิเมชันหรือโมเดลของผู้เล่น ตรวจสอบการตั้งค่า Pose ของ Player Entity เพื่อดูว่าขาถูกหมุนหรือย้ายโดยไม่ตั้งใจหรือไม่

### ฉันจะสร้างการหน่วงเวลาระหว่างการกระทำในสคริปต์ได้อย่างไร?

ใช้บล็อก [**Delay** หรือ **Execute Later**](./action-scripts#what-are-statements) สำหรับตรรกะการกระทำที่ต้องหน่วงเวลา หากต้องการตรรกะเบื้องหลังที่ทำซ้ำ ให้ใช้ [Schedulers](./schedulers)

### ฉันสามารถปรับแต่งเมนูจากม็อด Create ได้หรือไม่?

ไม่ได้ การปรับแต่งถูกปิดใช้งานโดยตั้งใจสำหรับหน้าจอของ Create ดู [Screens where customization is intentionally disabled](./incompatibility-list#screens-where-customization-is-intentionally-disabled)

### ควรใช้ความละเอียดเท่าใดสำหรับภาพพื้นหลังและพื้นผิวปุ่ม?

พื้นหลัง: ภาพมาตรฐานขนาด 1920x1080 (1080p) เป็นจุดเริ่มต้นที่ดีและจะปรับขนาดได้เหมาะสมสำหรับผู้ใช้ส่วนใหญ่
ปุ่ม: ปุ่ม Vanilla ส่วนใหญ่กว้างประมาณ 150-200 พิกเซล และสูง 20 พิกเซล การใช้พื้นผิว Custom ที่มีขนาดใกล้เคียงกันเป็นแนวทางที่ดีเพื่อให้มีความสอดคล้อง

### มีวิธีเปิดเมนูหรือเรียกใช้คำสั่งโดยอัตโนมัติเมื่อผู้เล่นทำเป้าหมายในเกมสำเร็จ (เช่น ภารกิจ) หรือไม่?
FancyMenu มี [ตัวรับฟังอีเวนต์ของเกมในตัว](./listeners) หลายรายการ แต่ไม่มีตัวรับฟังทั่วไปสำหรับระบบภารกิจจากผู้พัฒนารายอื่นทุกระบบ หากม็อดภารกิจรองรับรางวัลเป็นคำสั่ง ให้ใช้คำสั่งดังกล่าวเพื่อเรียกใช้ [`/openguiscreen`](./commands#openguiscreen), [`/fmvariable`](./commands#fmvariable) หรือ [คำสั่ง FancyMenu](./commands) อื่นที่เหมาะสม

### ฉันจะทำให้ปุ่มไม่ทำงานหรือเป็นสีเทาได้อย่างไร?

คุณสามารถควบคุมสถานะการทำงานของปุ่มได้โดยใช้ [Loading Requirements](./conditions)
คลิกขวาที่ปุ่มในตัวแก้ไข แล้วเลือก **Control Active State**
เพิ่ม Requirement ที่ต้องผ่านเพื่อให้ปุ่มทำงาน หากต้องการปิดใช้งานอย่างถาวร ให้ใช้ [**Is Number**](./conditions#is-number-fancymenu_visibility_requirement_is_number) เพื่อตรวจสอบว่า 0 เท่ากับ 1 หรือไม่
ปุ่มจะใช้พื้นผิว "Inactive Background" และไม่สามารถคลิกได้

### ฉันจะลบส่วนหัวและส่วนท้าย (แถบพื้นผิวดิน) บนหน้าจอแบบเลื่อนได้อย่างไร?

ในตัวแก้ไขเลย์เอาต์ ให้เปิด **Layout Properties -> Header/Footer Customizations** แล้วกำหนดพื้นผิวเป็นแบบโปร่งใส ตัวเลือกนี้อาจไม่พร้อมใช้งานในหน้าจอจากม็อดบางตัว

### ฉันไม่สามารถสร้างเลย์เอาต์ "สำหรับหน้าจอปัจจุบัน" ได้ ปุ่มเป็นสีเทา

คุณต้องเปิดใช้การปรับแต่งสำหรับหน้าจอนั้นก่อนผ่าน **menu bar -> Customization -> Current Screen Customizations -> Enabled**

### ฉันไม่สามารถปรับแต่งองค์ประกอบใด ๆ ของหน้าจอเมื่อเปิดในตัวแก้ไขได้ หน้าจอเป็นหน้าจอว่างเปล่า

อาจหมายความว่าคุณสร้าง [Universal Layout](./universal-layouts) แทนเลย์เอาต์ **สำหรับหน้าจอปัจจุบัน**

อีกกรณีหนึ่งอาจเป็น [หน้าจอแบบเลื่อนได้](./customizing-scrollable-screens) ซึ่ง FancyMenu ไม่สามารถปรับแต่งได้ตามค่าเริ่มต้น

ความเป็นไปได้ที่สามคือหน้าจอนั้นมาจากม็อดที่เพิ่มองค์ประกอบด้วยวิธีที่ไม่ใช่แบบ Vanilla ทำให้ FancyMenu ไม่สามารถปรับแต่งองค์ประกอบเหล่านี้ได้

### มีกรอบสีเทาแปลก ๆ อยู่ที่องค์ประกอบ Text ของฉัน

กรอบโปร่งแสงเหล่านี้คือตัวจับแถบเลื่อนของ [Text element](./elements#text) ไม่ใช่ข้อผิดพลาดในการแสดงผล

หากไม่ต้องการให้กรอบเหล่านี้แสดง คุณสามารถคลิกขวาที่องค์ประกอบแล้วปิดการเลื่อนทั้งหมด หรือกำหนดพื้นผิวของตัวจับแถบเลื่อนให้โปร่งใสทั้งหมดในเมนูคลิกขวาเดียวกัน หากยังต้องการให้องค์ประกอบเลื่อนได้

### ฉันจะแสดงบันทึกการเปลี่ยนแปลง Minecraft ล่าสุดในเมนูได้อย่างไร?

มี [โปรเจกต์ GitHub](https://github.com/ClaytonTDM/minecraft-changelogs-markdown) ที่ยอดเยี่ยมซึ่งแปลงบันทึกการเปลี่ยนแปลงของ Minecraft เป็น Markdown ที่ FancyMenu รองรับ คุณจึงสามารถแสดงบันทึกการเปลี่ยนแปลง MC ล่าสุดในเมนูได้ โปรเจกต์นี้อัปเดตทุกวันเพื่อดึงบันทึกการเปลี่ยนแปลงใหม่

หากต้องการแสดงใน [Text element](./elements#text) ให้ตั้งค่า **Source Mode** เป็น **Resource** และแหล่งทรัพยากรเป็น **Web** ใช้ `https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`

### วิธีที่ง่ายที่สุดในการขยายองค์ประกอบใด ๆ ให้มีขนาดเท่าหน้าจอคืออะไร?

องค์ประกอบส่วนใหญ่มีตัวเลือกในเมนูคลิกขวาเพื่อขยายในแนวนอนและแนวตั้ง เมื่อเปิดใช้ องค์ประกอบจะขยายเต็มความกว้างและ/หรือความสูงของหน้าจอเสมอ คุณสามารถเปิดหรือปิดการขยายแนวนอนและแนวตั้งแยกกันได้

### ฉันไม่สามารถคลิกปุ่มหรือโต้ตอบกับแถบเลื่อนได้เมื่อปุ่มหรือแถบเลื่อนอยู่ด้านหลังหรือด้านหน้าของ Text element

สิ่งนี้เกิดขึ้นเพราะ Text elements สามารถโต้ตอบได้ตามค่าเริ่มต้น (เพื่อให้สามารถจับตัวเลื่อนหรือคลิกลิงก์ Markdown ได้) ซึ่งหมายความว่าองค์ประกอบเหล่านี้จะรับการคลิกเมาส์และเหตุการณ์การเลื่อน วิธีที่ดีที่สุดคือไม่ย้ายปุ่มไปไว้ด้านหลังหรือด้านหน้าของ Text elements แต่หากหลีกเลี่ยงไม่ได้ คุณสามารถทำให้ Text element ไม่สามารถโต้ตอบได้โดย **คลิกขวาที่องค์ประกอบ** แล้วตั้งค่า **Interactable** เป็น **Disabled** โปรดทราบว่าการทำเช่นนี้จะทำให้ Text element เป็นข้อความแบบคงที่และไม่สามารถโต้ตอบได้ คุณจึงไม่สามารถเลื่อนหรือคลิกลิงก์ได้อีก

### ฉันจะทำให้ปุ่มและแถบเลื่อนไม่ถูกเลือกหรือโฟกัสเมื่อใช้ปุ่มลูกศรและ Tab นำทางในหน้าจอได้อย่างไร?

หากต้องการไม่ให้ปุ่มและแถบเลื่อนอยู่ในลำดับการนำทาง ให้ **คลิกขวา** ที่องค์ประกอบแล้วตั้งค่า **Navigable** เป็น **Disabled** ปุ่มหรือแถบเลื่อนจะยังคลิกได้ แต่คุณจะไม่สามารถโฟกัสด้วยการนำทางด้วยปุ่มลูกศรหรือ Tab ได้อีก

สิ่งนี้มีประโยชน์เช่นกันหากคุณต้องการเพิ่มปุ่มหรือแถบเลื่อนในหน้าจอ Chat เพื่อให้ยังใช้ปุ่มลูกศรขึ้นเลื่อนดูข้อความเก่าได้ โดยไม่เผลอเลือกปุ่มหรือแถบเลื่อนในหน้าจอ

### เมนูบริบทหนึ่งของ FancyMenu ไม่มีตัวเลือกที่ควรมี

เมนูบริบทของ FancyMenu (เมนูที่เปิดขึ้นเมื่อคลิกขวาบริเวณใดบริเวณหนึ่งหรือเมื่อโต้ตอบกับแถบเมนู) สามารถเลื่อนได้ ซึ่งหมายความว่าคุณสามารถใช้ล้อเลื่อนขณะวางเคอร์เซอร์เมาส์ไว้เหนือเมนูเพื่อเลื่อนขึ้นหรือลง ทำให้เห็นตัวเลือกเพิ่มเติมที่ก่อนหน้านี้ไม่แสดง

### ฉันไม่สามารถปรับแต่งหน้าจอ Title ได้ เมื่อออกจากตัวแก้ไข มันยังแสดงหน้าจอเดิม

ม็อดอื่นกำลังแทนที่ `title_screen` เดิม ให้ปิดใช้งาน Title screen แบบ Custom ของม็อดนั้นในการตั้งค่า หากไม่มีตัวเลือกดังกล่าว FancyMenu จะไม่สามารถใช้เลย์เอาต์กับหน้าจอที่มาแทนที่ได้

### เมื่อพยายามปรับแต่งหน้าจออินเวนทอรี ฉันไม่สามารถปรับแต่งคอนเทนเนอร์อินเวนทอรีได้

นี่เป็นสิ่งที่คาดไว้ FancyMenu ไม่รองรับการแก้ไขคอนเทนเนอร์จริงของหน้าจออินเวนทอรีทุกประเภท (อินเวนทอรีผู้เล่น หีบ โต๊ะคราฟต์ ฯลฯ) เนื่องจากการเพิ่มการรองรับดังกล่าวทำได้ยากมาก

อย่างไรก็ตาม คุณยังสามารถเพิ่มองค์ประกอบใหม่ลงในหน้าจอเหล่านี้ได้ เพียงแต่ไม่สามารถแก้ไขคอนเทนเนอร์ได้

อนึ่ง SpiffyHUD ก็ไม่ช่วยในกรณีนี้ เพราะใช้สำหรับแก้ไข HUD (เช่น แถบไอเท็มด่วน) แต่ไม่สามารถแก้ไขหน้าจอ (เช่น หน้าจออินเวนทอรี) ได้
