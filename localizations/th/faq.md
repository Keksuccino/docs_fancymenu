# คำถามที่พบบ่อย

### ฉันต้องการความช่วยเหลือเกี่ยวกับปัญหา ควรให้ข้อมูลอะไรบ้าง?
เพื่อให้ได้รับความช่วยเหลือที่ดีที่สุด โปรดให้บริบทให้มากที่สุดเท่าที่จะทำได้:
1.  **คำอธิบายปัญหาอย่างชัดเจน:** คุณคาดว่าจะเกิดอะไรขึ้น และเกิดอะไรขึ้นจริง?
2.  **ไฟล์ `latest.log` ของคุณ:** นี่คือไฟล์ที่สำคัญที่สุดสำหรับการแก้ปัญหา หาได้ในโฟลเดอร์ `/logs/` ของ instance ของคุณ **อย่าส่ง crash log** เว้นแต่ถูกขอโดยเฉพาะ เพราะ `latest.log` มีประโยชน์มากกว่า ใช้เว็บไซต์อย่าง https://gist.github.com เพื่อแชร์ไฟล์นี้
3.  **เวอร์ชัน Minecraft ของคุณ:** (เช่น 1.20.1)
4.  **Mod Loader และเวอร์ชันของคุณ:** (เช่น Forge 47.2.0, Fabric 0.15.7)
5.  **เวอร์ชันของ FancyMenu ของคุณ:** (เช่น 3.5.2)
6.  **ภาพหน้าจอหรือวิดีโอ** ของปัญหาก็ช่วยได้มากเช่นกัน

### ฉันจะเปลี่ยนลำดับการซ้อนทับขององค์ประกอบได้อย่างไร (ให้อยู่หน้าหรือหลังอีกองค์ประกอบหนึ่ง)?
*   **กำหนดเอง vs. กำหนดเอง:** หากต้องการเปลี่ยนลำดับการเรนเดอร์ขององค์ประกอบกำหนดเองของคุณเอง ให้ใช้ **วิดเจ็ต Layers** คุณสามารถเปิดได้จากแถบเมนู: **Window -> Widgets -> Layers** จากนั้นคุณสามารถลากองค์ประกอบขึ้นหรือลงในลำดับชั้นได้ คุณยังสามารถคลิกขวาที่องค์ประกอบแล้วใช้ "Move One Layer Up/Down" ได้
*   **กำหนดเอง vs. Vanilla:** หากต้องการให้เรนเดอร์องค์ประกอบกำหนดเองทั้งหมดของคุณอยู่หลังองค์ประกอบ Vanilla ทั้งหมด (เช่น วางภาพพื้นหลังไว้หลังปุ่มเริ่มต้น) ให้ **คลิกขวาที่พื้นหลังของตัวแก้ไข** แล้วสลับตัวเลือก **"Render Custom Elements Behind Vanilla"**

### ฉันสามารถยกเว้นปุ่มบางปุ่มจากเทมเพลตปุ่มแบบสากลได้ไหม?
**ไม่ได้ หากปุ่มในเทมเพลตตั้งค่าพื้นผิวแบบกำหนดเองไว้ พื้นผิวเหล่านี้จะถูกแชร์ร่วมกันกับองค์ประกอบที่ได้รับผลกระทบทั้งหมดเสมอ คุณไม่สามารถยกเว้นปุ่มแต่ละปุ่มเป็นรายตัวได้**

### ฉันจะทำให้ปุ่มทำงานบางอย่างเมื่อถูกคลิกได้อย่างไร?
ใช้ **Action Script**
1.  คลิกขวาที่ปุ่มในตัวแก้ไข
2.  เลือก **Edit Action Script**
3.  คลิก **Add Action** และเลือกจากรายการ (เช่น `Open Screen or Custom GUI`, `Join Server`, `Set Variable Value`)
*   ข้อมูลเพิ่มเติม: [Action Scripts](https://docs.fancymenu.net/en/action-scripts)

### ฉันสามารถสร้างหน้าจอเมนูใหม่เอี่ยมจากศูนย์ได้ไหม?
ได้ โดยใช้ **Custom GUIs**
1.  ในแถบเมนู ไปที่ **Customization -> Custom GUIs -> Manage Custom GUIs**
2.  คลิก **"New GUI"** และตั้งค่า identifier ที่ไม่ซ้ำกัน
3.  จากนั้นคุณสามารถเปิดหน้าจอว่างใหม่นี้และสร้างเลย์เอาต์สำหรับมันได้ โดยเพิ่มองค์ประกอบใดก็ได้ที่ต้องการ
4.  แล้ว Custom GUI นี้สามารถเปิดได้ผ่านแอ็กชันของปุ่ม
*   ข้อมูลเพิ่มเติม: [Custom GUIs](https://docs.fancymenu.net/en/custom-guis)

### เกมของฉันใช้เวลาโหลดนานมากหลังจากเปิดใช้การโหลดล่วงหน้า
นี่เป็นพฤติกรรมปกติ การโหลดทรัพยากรขนาดใหญ่ล่วงหน้า เช่น แอนิเมชันความละเอียดสูงหรือเสียง ในช่วงเริ่มต้นเกมจะทำให้เวลาโหลดของเกมนานขึ้นเป็นธรรมดา

### แอนิเมชัน FMA ของฉันใช้ RAM มากเกินไป!
ไฟล์ FMA แบบคลาสสิกอาจใช้หน่วยความจำมากเมื่อมีเฟรมความละเอียดสูงจำนวนมาก FancyMenu 3.9.0 เพิ่ม AFMA ซึ่งเหมาะกับพื้นผิวเคลื่อนไหวขนาดใหญ่หรือซับซ้อนมากกว่า สำหรับไฟล์ FMA แบบคลาสสิก ควรทำให้แอนิเมชันสั้นและหลีกเลี่ยงจำนวนเฟรม/ความละเอียดที่ใหญ่เกินไป แอนิเมชันมีไว้สำหรับลูปสั้น ๆ เพื่อการตกแต่ง ไม่ได้มีไว้สำหรับเล่นวิดีโอเต็มรูปแบบ

### FancyMenu ใช้งานร่วมกับ OptiFine ได้ไหม?
ไม่ได้ OptiFine **ไม่เข้ากัน** และเป็นที่ทราบกันว่าทำให้ม็อดหลายตัว รวมถึง FancyMenu มีปัญหา แนะนำอย่างยิ่งให้ใช้ทางเลือกสมัยใหม่อย่าง Sodium/Embeddium + Iris/Oculus
*   ข้อมูลเพิ่มเติม: [OptiFine Alternatives](https://docs.fancymenu.net/en/optifine-alternatives)

### เกมของฉันแครช ฉันจะรู้ได้อย่างไรว่ามีม็อดขัดแย้งกัน?
วิธีที่ดีที่สุดในการตรวจสอบม็อดขัดแย้งกันคือ **รันเกมด้วย FancyMenu และ dependencies ของมันเท่านั้น** (Konkrete, Melody) หากแครชไม่เกิดขึ้นอีก คุณสามารถค่อย ๆ เพิ่มม็อดอื่นกลับเข้ามาทีละกลุ่มจนกว่าแครชจะเกิดขึ้นอีกครั้ง เพื่อระบุม็อดที่ขัดแย้งกัน

### ปุ่มจากม็อดอื่นหายไปหรือใช้งานไม่ได้เมื่อฉันพยายามแก้ไขมัน
โดยทั่วไปหมายความว่าม็อดนั้นเพิ่มปุ่มของมันด้วยวิธีที่ไม่เป็นมาตรฐาน ซึ่ง FancyMenu ไม่สามารถโต้ตอบได้ นี่เป็นปัญหาที่นักพัฒนาของม็อดนั้นต้องแก้ไขฝั่งของเขาเอง FancyMenu ไม่สามารถปรับแต่งองค์ประกอบที่มันมองไม่เห็นได้

### ฉันใช้เลย์เอาต์ FancyMenu บนเซิร์ฟเวอร์ได้ไหม?
FancyMenu เป็นม็อดฝั่งไคลเอนต์ เลย์เอาต์และการปรับแต่งทั้งหมดอยู่ที่ฝั่งไคลเอนต์ของผู้เล่น คุณไม่สามารถใส่เลย์เอาต์บนเซิร์ฟเวอร์เพื่อบังคับให้ผู้เล่นเห็นได้ อย่างไรก็ตาม คุณสามารถแจกจ่ายโฟลเดอร์ `config/fancymenu` ของคุณเป็นส่วนหนึ่งของ modpack ได้ หากคุณต้องการใช้คำสั่งอย่าง `/fmvariable` หรือ `/openguiscreen` จากเซิร์ฟเวอร์ FancyMenu (หรือปลั๊กอิน Spigot ของมัน) จะต้องติดตั้งอยู่บนเซิร์ฟเวอร์

### ความแตกต่างระหว่าง FancyMenu v2 (สำหรับ MC เวอร์ชันเก่า) กับ v3 คืออะไร?
FancyMenu v3 เป็นการเขียนใหม่ทั้งหมดพร้อมฟีเจอร์ใหม่จำนวนมาก โครงสร้างที่เสถียรกว่า และประสิทธิภาพที่ดีขึ้น V2 ล้าสมัยแล้ว ไม่ได้รับการสนับสนุนอีกต่อไป และขาดฟีเจอร์หลายอย่าง เช่น placeholders ขั้นสูงและการเขียนสคริปต์ แนะนำอย่างยิ่งให้ใช้ v3 บน Minecraft เวอร์ชันใหม่ (1.18.2+) เลย์เอาต์จาก V2 สามารถแปลงเป็น v3 อัตโนมัติเมื่อโหลดได้ แต่บางครั้งอาจต้องแก้ไขด้วยตนเองเพิ่มเติม

### ฉันจะหาเลย์เอาต์และเทมเพลตสำเร็จรูปได้ที่ไหน?
ชุมชน FancyMenu แชร์เลย์เอาต์กันในช่อง `#layout-templates` บนเซิร์ฟเวอร์ Discord อย่างเป็นทางการของ Keksuccino's Mods

### ฉันจะทำให้ Player Entity เรนเดอร์อยู่หลังองค์ประกอบอื่นได้อย่างไร?
ทำไม่ได้ เนื่องจากวิธีที่ Minecraft เรนเดอร์ entity ทำให้องค์ประกอบ Player Entity มักจะเรนเดอร์อยู่หน้ากว่าองค์ประกอบ 2D อื่น ๆ เกือบเสมอ ไม่ว่าการตั้งค่าชั้นลำดับจะเป็นอย่างไร

### Player Entity ของฉันมีขาแค่ข้างเดียว! เกิดอะไรขึ้น?
นี่เป็นภาพบั๊กที่มองเห็นได้ ซึ่งน่าจะเกิดจากม็อดขัดแย้งกับม็อดอื่นที่เปลี่ยนแอนิเมชันหรือโมเดลของผู้เล่น ตรวจสอบการตั้งค่า Pose ของ Player Entity เพื่อดูว่าขาอาจถูกหมุนหรือเลื่อนโดยไม่ตั้งใจหรือไม่

### ฉันจะสร้างดีเลย์ระหว่างแอ็กชันในสคริปต์ได้อย่างไร?
FancyMenu 3.9.0 เพิ่มบล็อก **Delay** และ **Execute Later** ให้กับ action script ใช้บล็อกเหล่านี้สำหรับตรรกะของการหน่วงแอ็กชันส่วนใหญ่ สำหรับตรรกะเบื้องหลังที่ทำซ้ำ ให้ใช้ [Schedulers](https://docs.fancymenu.net/en/schedulers)

### ฉันสามารถปรับแต่งเมนูจากม็อด Create ได้ไหม?
ไม่ได้ FancyMenu มีความไม่เข้ากันที่ทราบกันแล้วกับ GUI ที่ซับซ้อนของ Create การปรับแต่งหน้าจอของ Create จึงถูกปิดใช้งานไว้โดยตั้งใจเพื่อป้องกันการแครช

### ทำไมปุ่มจากม็อด X ถึงหายไปในตัวแก้ไข?
หมายความว่าม็อดนั้นเพิ่มปุ่มของมันด้วยวิธีแบบกำหนดเองที่ไม่ใช่ Vanilla FancyMenu ไม่สามารถ "เห็น" หรือโต้ตอบกับองค์ประกอบเหล่านี้ได้ จึงไม่สามารถปรับแต่งได้ นักพัฒนาของม็อดอื่นจะต้องเปลี่ยนวิธีเพิ่มปุ่มของพวกเขาเพื่อให้เข้ากันได้

### ความละเอียดที่แนะนำสำหรับภาพพื้นหลังและพื้นผิวปุ่มคือเท่าไร?
พื้นหลัง: ภาพมาตรฐาน 1920x1080 (1080p) เป็นจุดเริ่มต้นที่ดีและสเกลได้ดีสำหรับผู้ใช้ส่วนใหญ่

ปุ่ม: ปุ่ม Vanilla ส่วนใหญ่มักกว้างประมาณ 150-200 พิกเซล และสูง 20 พิกเซล การทำให้พื้นผิวกำหนดเองมีขนาดใกล้เคียงกันเป็นแนวทางที่ดีเพื่อความสม่ำเสมอ

### มีวิธีเปิดเมนูหรือรันคำสั่งโดยอัตโนมัติเมื่อผู้เล่นทำภารกิจในเกมสำเร็จ (เช่น เควสต์) ไหม?
FancyMenu เองไม่สามารถตรวจจับอีเวนต์ในเกมแบบนี้ได้ อย่างไรก็ตาม คุณสามารถผสานมันกับม็อดทำเควสต์อย่าง FTB Quests ได้ ม็อดเควสต์ส่วนใหญ่จะให้คุณรันคำสั่งเป็นรางวัลของเควสต์ได้ คุณจะตั้งค่ารางวัลให้รันคำสั่ง `/openguiscreen` หรือ `/fmvariable` เพื่อโต้ตอบกับเมนูของคุณ

### ฉันจะทำให้ปุ่มเป็นแบบไม่ทำงานหรือ "เทา" ได้อย่างไร?
คุณสามารถควบคุมสถานะ active ของปุ่มได้โดยใช้ Loading Requirements
คลิกขวาที่ปุ่มในตัวแก้ไขแล้วเลือก "Active State"
เพิ่มเงื่อนไขที่ต้องผ่านเพื่อให้ปุ่ม active ตัวอย่างเช่น หากต้องการปิดใช้งานปุ่มถาวร คุณสามารถเพิ่ม requirement แบบ Is Number ที่ตรวจสอบว่า 0 เท่ากับ 1 หรือไม่ (ซึ่งจะเป็น false เสมอ)
ตอนนี้ปุ่มจะใช้พื้นผิว "Inactive Background" และจะคลิกไม่ได้

### ฉันจะลบส่วนหัวและส่วนท้าย (แถบพื้นผิวดิน) บนหน้าจอแบบเลื่อนได้อย่างไร?
ใน FancyMenu v3 คุณสามารถปรับแต่งส่วนเหล่านี้ได้ ในตัวแก้ไขเลย์เอาต์ ให้คลิกขวาที่พื้นหลังของตัวแก้ไขและมองหาตัวเลือกเช่น "Customize Header/Footer" คุณสามารถตั้งค่าพื้นผิวให้โปร่งใสทั้งหมดเพื่อให้ดูเหมือนลบออกไปได้ โปรดทราบว่าวิธีนี้อาจใช้ไม่ได้กับทุกหน้าจอ โดยเฉพาะหน้าจอรุ่นเก่าหรือหน้าจอที่ถูกม็อดมาก

### ฉันไม่สามารถสร้างเลย์เอาต์ "สำหรับหน้าจอปัจจุบัน" ได้ ปุ่มเป็นสีเทา
คุณต้องเปิดใช้งานการปรับแต่งสำหรับหน้าจอนั้นก่อนผ่าน **menu bar -> Customization -> Current Screen Customizations -> toggle it to Enabled**

### ฉันไม่สามารถปรับแต่งองค์ประกอบใด ๆ ของหน้าจอได้เมื่อเปิดมันในตัวแก้ไข มันเป็นแค่หน้าจอว่างเปล่า

สิ่งนี้อาจหมายความว่าคุณสร้างเลย์เอาต์แบบสากลแทนที่จะเป็นแบบ **สำหรับหน้าจอปัจจุบัน** โดยไม่ตั้งใจ

อีกความเป็นไปได้คือหน้าจอที่คุณกำลังปรับแต่งเป็นหน้าจอแบบเลื่อนได้ ซึ่งเป็นหน้าจอที่ FancyMenu ไม่สามารถปรับแต่งได้ตามค่าเริ่มต้น

ความเป็นไปได้ที่สามคือเป็นหน้าจอจากม็อดที่เพิ่มองค์ประกอบในลักษณะที่ไม่ใช่ Vanilla ซึ่งทำให้ FancyMenu ไม่สามารถปรับแต่งองค์ประกอบเหล่านั้นได้

### มีกรอบสีเทาแปลก ๆ อยู่ที่องค์ประกอบ Text ของฉัน

กรอบ/สี่เหลี่ยมโปร่งแสงเหล่านี้ (ความทึบต่ำ) อาจอยู่ที่ขวาหรือขอบล่างขององค์ประกอบ Text ของคุณ และไม่ใช่บั๊ก นี่คือ scroll grabbers ขององค์ประกอบ Text เนื่องจากองค์ประกอบนี้สามารถเลื่อนได้

หากคุณไม่ต้องการให้กรอบเหล่านี้แสดงอยู่ คุณสามารถคลิกขวาที่องค์ประกอบแล้วปิดการเลื่อนทั้งหมด หรือคุณสามารถตั้งค่าพื้นผิวของ grabber ให้โปร่งใสทั้งหมดได้ในเมนูคลิกขวาเดียวกัน หากคุณต้องการให้องค์ประกอบยังคงเลื่อนได้อยู่

### ฉันจะแสดง changelog ล่าสุดของ Minecraft ในเมนูของฉันได้อย่างไร?

มีโปรเจกต์ [GitHub](https://github.com/ClaytonTDM/minecraft-changelogs-markdown) ที่ยอดเยี่ยมซึ่งแปลง changelog ของ Minecraft ให้เป็น Markdown ที่เข้ากันได้กับ FancyMenu ดังนั้นคุณจึงสามารถแสดง changelog ล่าสุดของ MC ในเมนูของคุณได้! โปรเจกต์นี้อัปเดตทุกวันเพื่อดึง changelog ใหม่ ๆ

ตัวอย่างเช่น หากต้องการแสดง changelog ล่าสุดของ Minecraft ในองค์ประกอบ Text ให้ตั้งค่า **Source Mode** เป็น **Resource** และตั้งค่าแหล่งทรัพยากรเป็น **Web** จากนั้นใช้ URL นี้เป็น source: `https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`

### วิธีที่ง่ายที่สุดในการยืดองค์ประกอบใด ๆ ให้เต็มขนาดหน้าจอคืออะไร?

องค์ประกอบส่วนใหญ่มีตัวเลือกในเมนูคลิกขวาให้ยืดในแนวนอนและแนวตั้ง การเปิดใช้งานจะทำให้มันยืดเต็มความกว้างและ/หรือความสูงของหน้าจอเสมอ สามารถเปิดหรือปิดการยืดแนวนอนและแนวตั้งแยกกันได้

### ฉันคลิกปุ่มหรือโต้ตอบกับสไลเดอร์ไม่ได้เมื่อมันอยู่หลังหรือหน้าต่อองค์ประกอบ Text

สิ่งนี้เกิดขึ้นเพราะองค์ประกอบ Text สามารถโต้ตอบได้ตามค่าเริ่มต้น (เพื่อให้สามารถจับ scroll grabber หรือคลิกลิงก์ Markdown ได้) ซึ่งหมายความว่ามันจะรับคลิกเมาส์และเหตุการณ์การเลื่อนเอง วิธีที่ดีที่สุดคือไม่ย้ายปุ่มไปไว้หลัง/หน้าต่อองค์ประกอบ Text แต่ถ้าเลี่ยงไม่ได้ คุณสามารถทำให้องค์ประกอบ Text ไม่สามารถโต้ตอบได้โดย **คลิกขวา** แล้วตั้งค่า **Interactable** เป็น **Disabled** โปรดทราบว่านี่จะทำให้องค์ประกอบ Text กลายเป็นข้อความแบบคงที่ที่โต้ตอบไม่ได้ ดังนั้นคุณจะไม่สามารถเลื่อนมันหรือคลิกลิงก์ไฮเปอร์ลิงก์ได้อีก

### ฉันจะทำให้ปุ่มและสไลเดอร์ไม่ถูกเลือก/โฟกัสอีกต่อไปเมื่อใช้นำทางในหน้าจอด้วยปุ่มลูกศรและ Tab บนคีย์บอร์ดได้อย่างไร?

หากต้องการไม่ให้ปุ่มและสไลเดอร์สามารถนำทางได้ คุณต้อง **คลิกขวา** ที่มันแล้วตั้งค่า **Navigable** เป็น **Disabled** ปุ่ม/สไลเดอร์จะยังคลิกได้ แต่คุณจะไม่สามารถโฟกัสมันด้วยการนำทางด้วย Arrow/Tab ได้อีก

สิ่งนี้ยังมีประโยชน์หากคุณต้องการเพิ่มปุ่ม/สไลเดอร์ในหน้าจอแชต เพราะคุณจะยังคงใช้ปุ่มลูกศรขึ้นเพื่อเลื่อนดูข้อความเก่าได้โดยไม่เผลอเลือกปุ่ม/สไลเดอร์ในหน้าจอ

### เมนูคลิกขวาบางอันของ FancyMenu หายตัวเลือกที่ควรมีอยู่

เมนูคลิกขวาของ FancyMenu (เมนูที่เปิดเมื่อคุณคลิกขวาที่ไหนสักแห่งหรือเมื่อคุณโต้ตอบกับแถบเมนู) เป็นแบบเลื่อนได้ ซึ่งหมายความว่าคุณสามารถใช้ล้อเมาส์ขณะที่เคอร์เซอร์อยู่เหนือเมนูเพื่อเลื่อนขึ้นหรือลงได้ ทำให้คุณเห็นตัวเลือกเพิ่มเติมที่ก่อนหน้านี้มองไม่เห็น
