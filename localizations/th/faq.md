# คำถามที่พบบ่อย

### ฉันต้องการความช่วยเหลือเกี่ยวกับปัญหา ควรให้ข้อมูลอะไรบ้าง?

เพื่อให้ได้รับความช่วยเหลือที่ดีที่สุด โปรดให้บริบทให้มากที่สุดเท่าที่จะทำได้:
1.  **อธิบายปัญหาให้ชัดเจน:** คุณคาดหวังให้เกิดอะไรขึ้น และเกิดอะไรขึ้นจริง?
2.  **ไฟล์ `latest.log` ของคุณ:** หาไฟล์ได้ที่ `<game-directory>/logs/latest.log` **อย่าส่ง crash log** เว้นแต่จะมีการร้องขอโดยเฉพาะ โดยปกติ `latest.log` จะมีบริบทที่จำเป็นอยู่แล้ว ใช้เว็บไซต์อย่าง https://gist.github.com เพื่อโพสต์ไฟล์
3.  **เวอร์ชัน Minecraft ของคุณ:** (เช่น 1.20.1)
4.  **Mod Loader และเวอร์ชัน:** (เช่น Forge 47.2.0, Fabric 0.15.7)
5.  **เวอร์ชัน FancyMenu ของคุณ:** (เช่น 3.5.2)
6.  **ภาพหน้าจอหรือวิดีโอ** ของปัญหาก็ช่วยได้มากเช่นกัน

> [!TIP]
> ขอความช่วยเหลือจาก Alice หรือ AI ตัวอื่นอยู่ใช่ไหม? เพิ่ม [Export for AI](/export-for-ai) ของส่วนที่ใช้งานไม่ได้ไปด้วย ซึ่งจะแสดงให้ AI เห็นการตั้งค่าของคุณอย่างชัดเจน และมีเวอร์ชัน Minecraft, mod loader และ FancyMenu ของคุณอยู่แล้ว

### ฉันจะเปลี่ยนลำดับเลเยอร์ขององค์ประกอบได้อย่างไร (ย้ายสิ่งหนึ่งไปไว้ด้านหน้าหรือด้านหลังอีกสิ่งหนึ่ง)?

- **องค์ประกอบของคุณเอง:** ลากเลเยอร์ในวิดเจ็ต Layers ของตัวแก้ไขเลย์เอาต์ หรือคลิกขวาที่องค์ประกอบ แล้วคลิก **Move One Layer Up** หรือ **Move One Layer Down** ดูที่ [Layers and Groups](/layout-editor#layers-and-groups)
- **องค์ประกอบของคุณและองค์ประกอบวานิลลา:** ไม่สามารถเปลี่ยนลำดับขององค์ประกอบวานิลลาได้ หากต้องการวางองค์ประกอบทั้งหมดไว้ด้านหลัง เช่น วางภาพพื้นหลังไว้ด้านหลังปุ่มเริ่มต้น ให้คลิกขวาที่พื้นหลังของตัวแก้ไข แล้วตั้งค่า **Custom Elements Behind Vanilla** เป็น **Enabled**

### ฉันสามารถยกเว้นปุ่มบางปุ่มจากเทมเพลตปุ่มสากลได้ไหม?

**ไม่ได้ หากปุ่มในเทมเพลตกำหนดพื้นผิวแบบกำหนดเองไว้ พื้นผิวเหล่านั้นจะถูกใช้ร่วมกับองค์ประกอบทั้งหมดที่ได้รับผลเสมอ คุณไม่สามารถยกเว้นปุ่มแต่ละปุ่มได้**

### ฉันจะทำให้ปุ่มทำงานบางอย่างเมื่อคลิกได้อย่างไร?

ใช้ [**Action Script**](/action-scripts)
1.  คลิกขวาที่ปุ่มในตัวแก้ไข
2.  เลือก **Edit Action Script**
3. คลิก **Add Action** แล้วเลือกการกระทำ เช่น [**Open Screen or Custom GUI**](/action-scripts#open-screen-or-custom-gui), [**Join Server**](/action-scripts#join-server) หรือ [**Set Variable Value**](/action-scripts#set-variable-value-fm-variable)

### ฉันสามารถสร้างหน้าจอเมนูใหม่ทั้งหมดตั้งแต่ต้นได้ไหม?

ได้ โดยใช้ [Custom GUI](/custom-guis):

1. เปิด **menu bar -> Customization -> Custom GUIs -> Manage Custom GUIs** แล้วคลิก **New GUI**
2. กำหนดตัวระบุให้ เช่น `modpack_info` แล้วคลิก **Done**
3. เปิดด้วย **Open GUI** แล้วสร้างเลย์เอาต์ให้เหมือนกับเมนูอื่น ๆ
4. เปิดจากปุ่มด้วยการกระทำ [**Open Screen or Custom GUI**](/action-scripts#open-screen-or-custom-gui) และระบุตัวระบุของ GUI

### เกมใช้เวลาโหลดนานหลังจากเปิดใช้การโหลดล่วงหน้า

นี่เป็นพฤติกรรมที่คาดไว้ การโหลดทรัพยากรขนาดใหญ่ เช่น แอนิเมชันความละเอียดสูงหรือเสียง ตั้งแต่เริ่มเปิดเกม ย่อมทำให้เกมใช้เวลาโหลดนานขึ้น

### แอนิเมชันของฉันใช้ RAM เยอะหรือทำให้เกมกระตุก!

เฟรมขนาดใหญ่และอัตราเฟรมสูงใช้หน่วยความจำและทรัพยากรประมวลผลมาก ควรทำให้เฟรมมีขนาดใกล้เคียงกับขนาดที่แสดงบนหน้าจอ และใช้อัตราเฟรมต่อวินาทีให้น้อยลง ดูที่ [Animations](/animations#performance) หากเป็นคลิปยาวที่มีเสียง ให้ใช้ [Video](/video) แทน

### FancyMenu ใช้กับ OptiFine ได้ไหม?

ไม่ได้ OptiFine **เข้ากันไม่ได้** และเป็นที่ทราบกันว่าทำให้ม็อดหลายตัวทำงานผิดปกติ รวมถึง FancyMenu ด้วย ขอแนะนำอย่างยิ่งให้ใช้ทางเลือกสมัยใหม่ เช่น Sodium/Embeddium + Iris/Oculus
ดูที่ [OptiFine Alternatives](/optifine-alternatives)

### เกมของฉันแครช จะตรวจสอบได้อย่างไรว่าเกิดจากม็อดขัดแย้งกันหรือไม่?

วิธีตรวจสอบม็อดที่ขัดแย้งกันได้ดีที่สุดคือ **เปิดเกมโดยใช้แค่ FancyMenu และส่วนเสริมที่จำเป็น** (Konkrete, Melody) หากเกมไม่แครชอีก ให้นำม็อดอื่นกลับมาใส่ทีละกลุ่มเล็ก ๆ จนเกิดการแครชอีกครั้ง เพื่อหาม็อดที่ขัดแย้งกัน

### ปุ่มจากม็อดอื่นหายไปหรือใช้งานไม่ได้เมื่อฉันพยายามแก้ไข

ม็อดบางตัวเพิ่มวิดเจ็ตด้วยวิธีที่ FancyMenu ตรวจจับหรือปรับแต่งไม่ได้ ดูที่ [Vanilla/Mod Elements](/vanilla-elements) และสำหรับหน้าจอที่ใช้รายการ ให้ดูที่ [Customizing Scrollable Screens](/customizing-scrollable-screens) หากยังไม่พบวิดเจ็ต ม็อดที่เพิ่มวิดเจ็ตนั้นจะต้องเปิดให้ใช้งานเป็นวิดเจ็ตหน้าจอที่รองรับ

### ฉันใช้เลย์เอาต์ FancyMenu บนเซิร์ฟเวอร์ได้ไหม?

เลย์เอาต์และการปรับแต่งภาพจะเก็บไว้บนไคลเอนต์ของผู้เล่น เซิร์ฟเวอร์ไม่สามารถบังคับใช้กับไคลเอนต์ที่ไม่ได้ตั้งค่าไว้ได้ ให้แจกจ่ายเลย์เอาต์เหล่านี้ไปพร้อมกับม็อดแพ็ก ติดตั้ง FancyMenu บนเซิร์ฟเวอร์เมื่อต้องใช้ [คำสั่งเซิร์ฟเวอร์](/commands), [FM Data](/fm-data), [การเข้าถึง NBT ฝั่งเซิร์ฟเวอร์](/nbt-data-placeholder#server-side-placeholder), gamerule, โครงสร้าง หรือ listener ของเซิร์ฟเวอร์

### FancyMenu v2 (สำหรับ MC เวอร์ชันเก่า) กับ v3 ต่างกันอย่างไร?

FancyMenu v3 เขียนขึ้นใหม่ทั้งหมด พร้อมฟีเจอร์ใหม่มากมาย สถาปัตยกรรมที่เสถียรขึ้น และประสิทธิภาพที่ดีกว่า ส่วน v2 ล้าสมัย ไม่ได้รับการสนับสนุนอีกต่อไป และขาดฟีเจอร์มากมาย เช่น placeholder ขั้นสูงและการเขียนสคริปต์ ขอแนะนำอย่างยิ่งให้ใช้ v3 กับ Minecraft เวอร์ชันใหม่ (1.18.2 ขึ้นไป) เลย์เอาต์ v2 สามารถแปลงเป็น v3 โดยอัตโนมัติเมื่อโหลด แต่บางส่วนอาจต้องแก้ไขด้วยตนเอง

### ฉันจะหาเลย์เอาต์และเทมเพลตสำเร็จรูปได้จากที่ไหน?

ชุมชน FancyMenu แชร์ชุดการตั้งค่าที่พร้อมใช้ไว้ในช่อง [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) ของเซิร์ฟเวอร์ Discord ทางการ (“Kekscord”) ให้ติดตั้งเป็นโปรไฟล์แยกต่างหาก ดูที่ [Layout Templates](/profiles#layout-templates)

### ฉันจะทำให้ Player Entity แสดงผลอยู่ด้านหลังองค์ประกอบอื่นได้อย่างไร?

โดยทั่วไป คุณไม่สามารถบังคับให้ [องค์ประกอบ Player Entity](/elements#player-entity) อยู่ด้านหลังองค์ประกอบ 2D ปกติผ่านวิดเจ็ต [Layers](/layout-editor#layers-and-groups) ได้ ตัวเรนเดอร์อาจไม่สนใจลำดับเลเยอร์ GUI ปกติ ให้ออกแบบเลย์เอาต์โดยคำนึงถึงข้อจำกัดนี้ หรือใช้ภาพที่เรนเดอร์ไว้ล่วงหน้าเมื่อต้องการควบคุมลำดับเลเยอร์อย่างเคร่งครัด

### Player Entity ของฉันมีขาแค่ข้างเดียว! เกิดอะไรขึ้น?

นี่เป็นปัญหาภาพแสดงผลผิดปกติ ซึ่งน่าจะเกิดจากม็อดขัดแย้งกับม็อดอื่นที่เปลี่ยนแอนิเมชันหรือโมเดลของผู้เล่น ตรวจสอบการตั้งค่า Pose ของ Player Entity เพื่อดูว่าขาถูกหมุนหรือย้ายตำแหน่งโดยไม่ตั้งใจหรือไม่

### ฉันจะหน่วงเวลาระหว่างการกระทำในสคริปต์ได้อย่างไร?

คลิกขวาที่พื้นที่สคริปต์ของตัวแก้ไข action script แล้วคลิก **Add EXECUTE LATER Block** จากนั้นใส่การกระทำที่ต้องการหน่วงเวลาไว้ข้างใน การกระทำเหล่านั้นจะทำงานหนึ่งครั้งหลังจากเวลาที่กำหนดเป็นมิลลิวินาที ส่วนที่เหลือของสคริปต์จะทำงานต่อทันที ดูที่ [Execute Later](/action-scripts#execute-later)

หากต้องการให้สิ่งต่าง ๆ เกิดขึ้นซ้ำ ๆ ให้ใช้ [Schedulers](/schedulers)

### ฉันปรับแต่งเมนูจากม็อด Create ได้ไหม?

ไม่ได้ ระบบปิดการปรับแต่งหน้าจอของ Create ไว้โดยตั้งใจ ดูที่ [Screens where customization is intentionally disabled](/incompatibility-list#screens-where-customization-is-intentionally-disabled)

### ความละเอียดที่แนะนำสำหรับภาพพื้นหลังและพื้นผิวปุ่มคือเท่าใด?

พื้นหลัง: ภาพมาตรฐานขนาด 1920x1080 (1080p) เป็นจุดเริ่มต้นที่ดี และปรับขนาดได้เหมาะกับผู้ใช้ส่วนใหญ่
ปุ่ม: ปุ่มวานิลลาส่วนใหญ่กว้างประมาณ 150–200 พิกเซล และสูง 20 พิกเซล การกำหนดพื้นผิวแบบกำหนดเองให้มีขนาดใกล้เคียงกันเป็นวิธีที่ดีเพื่อให้ดูสอดคล้องกัน

### มีวิธีเปิดเมนูหรือเรียกใช้คำสั่งโดยอัตโนมัติเมื่อผู้เล่นทำเป้าหมายในเกมสำเร็จ (เช่น เควสต์) ไหม?

FancyMenu มี [listener สำหรับเหตุการณ์ในเกมที่ติดตั้งมาให้](/listeners) มากมาย แต่ไม่มี listener ทั่วไปที่ครอบคลุมระบบเควสต์ของม็อดภายนอกทุกตัว หากม็อดเควสต์รองรับรางวัลเป็นคำสั่ง ให้ใช้รางวัลดังกล่าวเพื่อเรียก [`/openguiscreen`](/commands#openguiscreen), [`/fmvariable`](/commands#fmvariable) หรือ[คำสั่ง FancyMenu](/commands) อื่นที่เหมาะสม

### ฉันจะทำให้ปุ่มไม่ทำงานหรือ “เป็นสีเทา” ได้อย่างไร?

คุณควบคุมสถานะการทำงานของปุ่มได้โดยใช้ [เงื่อนไข](/conditions)
คลิกขวาที่ปุ่มในตัวแก้ไข แล้วเลือก **Control Active State**
เพิ่มเงื่อนไขที่ต้องเป็นจริงเพื่อให้ปุ่มทำงาน หากต้องการปิดใช้งานถาวร ให้ใช้ [**Is Number**](/conditions#is-number) เพื่อตรวจสอบว่า 0 เท่ากับ 1 หรือไม่
ปุ่มจะใช้พื้นผิว “Inactive Background” และไม่สามารถคลิกได้

### ฉันจะเอาส่วนหัวและส่วนท้าย (แถบพื้นผิวดิน) ออกจากหน้าจอที่เลื่อนได้อย่างไร?

ในตัวแก้ไขเลย์เอาต์ ให้เปิด **Layout Properties -> Header/Footer Customizations** แล้วตั้งค่าพื้นผิวให้โปร่งใส ตัวเลือกนี้อาจไม่มีในหน้าจอม็อดบางหน้าจอ

### ฉันสร้างเลย์เอาต์ “สำหรับหน้าจอปัจจุบัน” ไม่ได้ ปุ่มเป็นสีเทา

เปิดใช้การปรับแต่งสำหรับหน้าจอนั้นก่อน โดยคลิก **menu bar -> Customization -> Current Screen Customization** ให้แสดงสถานะ **Enabled**

### ฉันปรับแต่งองค์ประกอบของหน้าจอไม่ได้เลยเมื่อเปิดในตัวแก้ไข พอเข้าไปแล้วหน้าจอว่างเปล่า

อาจเป็นเพราะคุณสร้าง [Universal Layout](/universal-layouts) แทนที่จะสร้างเลย์เอาต์ **สำหรับหน้าจอปัจจุบัน**

อีกกรณีหนึ่งคืออาจเป็น[หน้าจอที่เลื่อนได้](/customizing-scrollable-screens) ซึ่ง FancyMenu ไม่สามารถปรับแต่งได้ตามค่าเริ่มต้น

ความเป็นไปได้ข้อที่สามคือเป็นหน้าจอจากม็อดที่เพิ่มองค์ประกอบด้วยวิธีที่ไม่ใช่แบบวานิลลา ทำให้ FancyMenu ปรับแต่งองค์ประกอบเหล่านั้นไม่ได้

### มีกรอบสีเทาแปลก ๆ ที่องค์ประกอบ Text ของฉัน

นี่คือแถบเลื่อนของ[องค์ประกอบ Text](/elements#text) ซึ่งจะแสดงเมื่อข้อความไม่พอดีกับองค์ประกอบ เพื่อให้ผู้เล่นเลื่อนดูข้อความได้

- ขยายองค์ประกอบให้ใหญ่ขึ้นหรือทำให้ข้อความสั้นลง แล้วแถบเลื่อนจะหายไป
- คลิกขวาที่องค์ประกอบแล้วเปิด **Scroll Bars** ตัวเลือก **Show** ใช้กำหนดเวลาที่แถบเลื่อนจะแสดง: **Always**, แสดงเฉพาะ **While Scrolling** หรือ **Never** เมื่อเลือก **Never** ล้อเมาส์ยังใช้เลื่อนข้อความได้
- ในเมนูเดียวกัน ตัวเลือก **Scroll Grabber Style**, **Scroll Grabber Textures** และ **Scroll Grabber Color [HEX]** ใช้เปลี่ยนรูปลักษณ์ของแถบเลื่อน

ดูการตั้งค่าแถบเลื่อนทั้งหมดได้ที่ [Text in Menus](/text-in-menus#scroll-bars)

### ฉันจะแสดงบันทึกการเปลี่ยนแปลง Minecraft ล่าสุดในเมนูได้อย่างไร?

มี[โปรเจกต์ GitHub](https://github.com/ClaytonTDM/minecraft-changelogs-markdown) ที่ยอดเยี่ยมซึ่งแปลงบันทึกการเปลี่ยนแปลงของ Minecraft เป็น Markdown ที่ใช้กับ FancyMenu ได้ ทำให้คุณแสดงบันทึกการเปลี่ยนแปลง MC ล่าสุดในเมนูได้! โปรเจกต์นี้อัปเดตทุกวันเพื่อดึงบันทึกการเปลี่ยนแปลงใหม่ ๆ

หากต้องการแสดงใน[องค์ประกอบ Text](/elements#text) ให้ตั้งค่า **Source Mode** เป็น **Resource** และตั้งค่าแหล่งทรัพยากรเป็น **Web** ใช้ `https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`

### วิธีที่ง่ายที่สุดในการขยายองค์ประกอบใด ๆ ให้เต็มหน้าจอคืออะไร?

องค์ประกอบส่วนใหญ่มีตัวเลือกในเมนูที่เปิดเมื่อคลิกขวา เพื่อขยายองค์ประกอบทั้งแนวนอนและแนวตั้ง เมื่อเปิดใช้ ตัวเลือกนี้จะขยายองค์ประกอบให้เต็มความกว้างและ/หรือความสูงของหน้าจอเสมอ คุณสามารถเปิดหรือปิดการขยายแนวนอนและแนวตั้งแยกจากกันได้

### ฉันคลิกปุ่มหรือปรับแถบเลื่อนไม่ได้เมื่ออยู่ด้านหน้าหรือด้านหลังองค์ประกอบ Text

ปัญหานี้เกิดขึ้นเพราะองค์ประกอบ Text โต้ตอบได้ตามค่าเริ่มต้น (เพื่อให้จับแถบเลื่อนหรือคลิกลิงก์ Markdown ได้) จึงรับการคลิกเมาส์และเหตุการณ์เลื่อน วิธีที่ดีที่สุดคือหลีกเลี่ยงการย้ายปุ่มไปไว้ด้านหน้าหรือด้านหลังองค์ประกอบ Text แต่หากเลี่ยงไม่ได้ คุณสามารถปิดการโต้ตอบขององค์ประกอบ Text ได้โดย **คลิกขวาที่องค์ประกอบ** แล้วตั้งค่า **Interactable** เป็น **Disabled** โปรดทราบว่าการทำเช่นนี้จะเปลี่ยนองค์ประกอบ Text ให้เป็นข้อความแบบคงที่ที่โต้ตอบไม่ได้ จึงเลื่อนข้อความหรือคลิกลิงก์ไม่ได้อีกต่อไป

### ฉันจะทำให้ปุ่มและแถบเลื่อนไม่ถูกเลือกหรือโฟกัสเมื่อใช้ปุ่มลูกศรและ Tab บนแป้นพิมพ์นำทางในหน้าจอได้อย่างไร?

หากต้องการไม่ให้ปุ่มและแถบเลื่อนถูกเลือกขณะนำทาง ให้ **คลิกขวา** ที่องค์ประกอบ แล้วตั้งค่า **Navigable** เป็น **Disabled** ปุ่มหรือแถบเลื่อนยังคลิกได้ แต่จะไม่สามารถโฟกัสด้วยการนำทางด้วยปุ่มลูกศรหรือ Tab ได้อีกต่อไป

วิธีนี้ยังมีประโยชน์เมื่อเพิ่มปุ่มหรือแถบเลื่อนลงในหน้าจอ Chat เพราะคุณจะยังใช้ปุ่มลูกศรขึ้นเพื่อเลื่อนดูข้อความเก่าได้ โดยไม่เผลอเลือกปุ่มหรือแถบเลื่อนบนหน้าจอ

### ตัวเลือกหนึ่งที่ควรมีหายไปจากเมนูบริบทของ FancyMenu

เมนูบริบทของ FancyMenu (เมนูที่เปิดขึ้นเมื่อคลิกขวาที่ใดที่หนึ่งหรือเมื่อโต้ตอบกับแถบเมนู) **เลื่อนได้** ซึ่งหมายความว่าคุณสามารถใช้ล้อเมาส์เลื่อนขึ้นหรือลงได้เมื่อเคอร์เซอร์อยู่เหนือเมนู เพื่อดูตัวเลือกเพิ่มเติมที่ก่อนหน้านี้มองไม่เห็น

### ฉันปรับแต่งหน้าจอ Title ไม่ได้ พอออกจากตัวแก้ไขก็กลับไปแสดงหน้าจอเดิม

ม็อดอีกตัวกำลังแทนที่ `title_screen` เดิม ให้ปิดหน้าจอ Title แบบกำหนดเองของม็อดนั้นในการตั้งค่า หากม็อดไม่มีตัวเลือกดังกล่าว FancyMenu จะใช้เลย์เอาต์กับหน้าจอที่ถูกแทนที่ไม่ได้

### เมื่อพยายามปรับแต่งหน้าจอช่องเก็บของ ฉันปรับแต่งช่องเก็บของไม่ได้

เป็นเรื่องปกติ FancyMenu ไม่รองรับการแก้ไขช่องเก็บของจริงในหน้าจอช่องเก็บของทุกประเภท (ช่องเก็บของผู้เล่น หีบ โต๊ะคราฟต์ ฯลฯ) เพราะการเพิ่มการรองรับส่วนนี้ทำได้ยากมาก

อย่างไรก็ตาม คุณยังเพิ่มองค์ประกอบใหม่ลงในหน้าจอเหล่านี้ได้ เพียงแต่แก้ไขช่องเก็บของไม่ได้

อีกอย่าง SpiffyHUD ก็ช่วยเรื่องนี้ไม่ได้ เพราะใช้สำหรับแก้ไข HUD (เช่น แถบไอเท็มด่วน) แต่ไม่สามารถแก้ไขหน้าจออย่างหน้าจอช่องเก็บของได้
