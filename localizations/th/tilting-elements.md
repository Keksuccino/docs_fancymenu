# การเอียงองค์ประกอบ

องค์ประกอบส่วนใหญ่สามารถเอียงได้ทั้งในแนวตั้งและแนวนอน

เลือกองค์ประกอบในตัวแก้ไขเลย์เอาต์ หากรองรับการเอียง จะมีเส้นไกด์แนวตั้งและแนวนอนพร้อมจุดจับปรากฏรอบๆ องค์ประกอบนั้น ลากจุดจับเพื่อเอียงองค์ประกอบตามแกนนั้น

หากไม่มีเส้นพร้อมจุดจับบนองค์ประกอบ แสดงว่าคุณไม่สามารถเอียงมันได้

# ขั้นสูง

คุณยังสามารถคลิกขวาที่องค์ประกอบเพื่อกำหนดค่าเอียงด้วยตนเองผ่านการป้อนข้อความโดยตรงได้อีกด้วย การป้อนค่าโดยตรงนี้รองรับ [placeholders](/placeholders) ดังนั้นคุณจึงสามารถเปลี่ยนการเอียงขององค์ประกอบแบบไดนามิกได้เมื่อใช้ร่วมกับ placeholders เพื่อดึงค่าตัวแปรของ FancyMenu หรือสิ่งที่คล้ายกัน

# ปุ่ม สไลเดอร์ และองค์ประกอบแบบโต้ตอบอื่นๆ

การเอียงจะมีผลเฉพาะด้านภาพสำหรับองค์ประกอบแบบโต้ตอบเท่านั้น ปุ่มที่ถูกเอียงยังคงรับการคลิกได้ภายในพื้นที่เดิมที่ยังไม่เอียง
