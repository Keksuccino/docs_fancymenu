# องค์ประกอบการเอียง

ตั้งแต่ FancyMenu v3.8.0 เป็นต้นไป คุณสามารถเอียง **องค์ประกอบส่วนใหญ่** ได้ทั้งในแนวตั้งและแนวนอน!

ในการเอียงองค์ประกอบ ให้เลือกองค์ประกอบนั้นในตัวแก้ไขเลย์เอาต์ หากคุณเห็นเส้นสองเส้นที่มีตัวจับอยู่ด้วย (เส้นแนวตั้งหนึ่งเส้น และเส้นแนวนอนหนึ่งเส้น) ซึ่งไม่ใช่ขอบขององค์ประกอบ คุณสามารถลากตัวจับเพื่อเอียงองค์ประกอบไปในทิศทางที่ต้องการได้

หากไม่มีเส้นที่มีตัวจับบนองค์ประกอบนั้น คุณจะไม่สามารถเอียงมันได้

# ขั้นสูง

คุณยังสามารถคลิกขวาที่องค์ประกอบเพื่อกำหนดค่าเอียงด้วยตนเองผ่านช่องกรอกข้อความโดยตรงได้อีกด้วย การกรอกข้อความโดยตรงนี้รองรับ [placeholders](/placeholders) ดังนั้นคุณจึงสามารถเปลี่ยนการเอียงขององค์ประกอบแบบไดนามิกได้เมื่อใช้งานร่วมกับ placeholders เพื่อดึงค่าตัวแปรของ FancyMenu หรือค่าในลักษณะเดียวกัน

# ปุ่ม ตัวเลื่อน และองค์ประกอบที่โต้ตอบได้อื่น ๆ

สำหรับองค์ประกอบที่โต้ตอบได้ การเอียงยังคงทำได้ แต่การเอียงจะมีผลแค่ในเชิงภาพเท่านั้น ดังนั้นปุ่ม เช่น จะยังคงตอบสนองต่อการคลิกภายในพื้นที่เดิมของมันเท่านั้น แม้ว่าการเอียงอาจทำให้ตำแหน่งของมันเลื่อนออกจากพื้นที่นั้นไปบางส่วนก็ตาม
