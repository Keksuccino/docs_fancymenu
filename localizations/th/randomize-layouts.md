# การสุ่ม

FancyMenu มีฟีเจอร์มากมายที่ช่วยให้คุณสุ่มเลย์เอาต์หรือบางส่วนของมันได้

สิ่งนี้มีประโยชน์ เช่น ถ้าคุณต้องการให้ผู้ใช้เห็นพื้นหลังหน้าจอที่แตกต่างกันทุกครั้งที่เปิดหน้าจอ หรือให้มีเคล็ดลับแบบสุ่มบนหน้าจอโหลด

# การสุ่มเลย์เอาต์

FancyMenu มีฟีเจอร์ที่ช่วยให้คุณสร้างกลุ่มของเลย์เอาต์ และระบบจะเลือกเลย์เอาต์แบบสุ่มจากกลุ่มนี้ให้อัตโนมัติ ด้วยวิธีนี้ คุณสามารถแสดงดีไซน์เมนูที่สุ่มและแตกต่างกันโดยสิ้นเชิงได้ทุกครั้งที่ผู้ใช้เปิดเกมหรือเปิดหน้าจอ แต่ก็สามารถใช้เพื่อเปลี่ยนแค่บางส่วนของหน้าจอ เช่น พื้นหลัง ได้เช่นกัน

## โหมดสุ่ม

ในการสุ่มเลย์เอาต์ คุณต้องเปิดใช้งาน **Random Mode** สำหรับทุกเลย์เอาต์ที่ต้องการให้เป็นตัวเลือกในการสุ่ม โดยให้ **คลิกขวา** ที่ **พื้นหลังของตัวแก้ไข** แล้วค้นหารายการ **Random Mode**

## ตัวระบุกลุ่มสุ่ม

หลังจากเปิดใช้งานโหมดสุ่มแล้ว คุณต้องตั้งค่า **ตัวระบุกลุ่มสุ่ม (Random Group Identifier)**
หมายเลขนี้ต้อง **เหมือนกัน** สำหรับทุกเลย์เอาต์ที่ควรอยู่ใน **กลุ่มเดียวกัน**

## พฤติกรรมการสุ่ม

ถ้าคุณต้องการให้ระบบเลือกเลย์เอาต์แบบสุ่มของกลุ่ม **เพียงครั้งเดียวต่อหนึ่งเซสชันของเกม** ให้เปิดใช้งาน **Randomize Only First Time** ฟีเจอร์นี้จะทำให้ระบบเลือกเลย์เอาต์ในครั้งแรกที่เปิดหน้าจอ จากนั้นจะใช้เลย์เอาต์เดิมที่ถูกเลือกไว้ครั้งแรกเสมอ หากปิดใช้งาน ระบบจะสุ่มเลย์เอาต์ใหม่ทุกครั้งที่เปิดหน้าจอ

# ตัวอย่างสถานการณ์ที่ 1: พื้นหลัง

สมมติว่าคุณต้องการสุ่มพื้นหลังของหน้าจอ Title Screen

ในการทำเช่นนั้น คุณต้องสร้าง **หนึ่งเลย์เอาต์ต่อหนึ่งพื้นหลัง** และ _**เฉพาะ**_ เปลี่ยนพื้นหลังของเลย์เอาต์เหล่านี้เท่านั้น พร้อมทั้งเปิดใช้งานโหมดสุ่มด้วยตัวระบุกลุ่มสุ่มที่ถูกต้อง

ในตัวอย่างนี้ เราใช้ตัวระบุกลุ่มสุ่ม **10** โดยตัวระบุนี้ต้องถูกตั้งค่าให้กับทุกเลย์เอาต์ในกลุ่มเลย์เอาต์สุ่มนี้

วิธีที่ง่ายที่สุดคือเตรียมเลย์เอาต์ที่ตั้งค่าตัวระบุกลุ่มสุ่มไว้ถูกต้อง แล้วใช้ **Save As** จากนั้นเปลี่ยนพื้นหลังทุกครั้งที่บันทึกเลย์เอาต์ด้วยชื่อใหม่ วิธีนี้คุณจะได้เลย์เอาต์หลายแบบที่มีพื้นหลังแตกต่างกัน และหนึ่งในเลย์เอาต์เหล่านี้จะถูกเลือกทุกครั้งที่คุณเปิดหน้าจอ หรือเลือกเพียงครั้งเดียวต่อหนึ่งเซสชันของเกม

# ตัวอย่างสถานการณ์ที่ 2: องค์ประกอบ

อีกกรณีการใช้งานที่พบบ่อยคือการสุ่มองค์ประกอบข้อความหรือรูปภาพ

เช่นเดียวกับพื้นหลัง ให้สร้างหนึ่งเลย์เอาต์ต่อหนึ่งเวอร์ชันขององค์ประกอบที่คุณต้องการให้สุ่มเลือก เพิ่มเฉพาะองค์ประกอบนั้นลงในเลย์เอาต์เท่านั้น และอย่าเพิ่มอย่างอื่น อย่าปรับแต่งอะไรเพิ่มเติม และอย่าเพิ่มองค์ประกอบอื่น

จากนั้นบันทึกทุกเลย์เอาต์ด้วยตัวระบุกลุ่มสุ่มเดียวกัน แล้วเลย์เอาต์หนึ่งจากกลุ่มนั้นจะถูกเลือกเมื่อคุณเปิดหน้าจอหรือเปิดเกม
