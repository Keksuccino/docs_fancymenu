# การโหลดทรัพยากรล่วงหน้า

การโหลดล่วงหน้าจะเตรียมทรัพยากรที่เลือกไว้ก่อนที่เมนูจะต้องใช้งาน ใช้กับทรัพยากรที่อาจกะพริบ แสดงเฟรมแรกเป็นสีดำ หรือเริ่มแสดงผลช้า

# เพิ่มทรัพยากรไปยังตัวโหลดล่วงหน้า

เปิด **Customization -> Pre-Load Resources**.

<br>

<img width="350" alt="Screenshot_1" src="https://github.com/Keksuccino/FancyMenu/assets/35544624/3265da80-1bbc-4634-bd94-ba2795d7e3f2">

รายการนี้รองรับทรัพยากรรูปภาพ แอนิเมชัน เสียง วิดีโอ และข้อความ จากไฟล์ในเครื่อง URL บนเว็บ หรือ resource pack โดยจะไม่โหลดหน้าสดของ [Browser](./elements#browser) ล่วงหน้า

ตัวโหลดล่วงหน้าจะเริ่มทำงานระหว่างการเริ่มต้นเกมและการโหลดทรัพยากรของ Minecraft โดยจะรอให้แต่ละรายการเสร็จสิ้นหรือเกิดข้อผิดพลาดก่อนดำเนินการต่อ โดยจำกัดเวลาสูงสุดรายการละสองนาที

ทรัพยากรที่โหลดแล้วจะยังคงถูกแคชไว้จนกว่า FancyMenu จะปล่อยทรัพยากรระหว่างการโหลดใหม่หรือเมื่อไคลเอนต์ปิดตัวลง **Customization -> Reload FancyMenu** จะปล่อยแคช แต่จะไม่เรียกใช้ตัวโหลดล่วงหน้าอีกครั้ง

การโหลดล่วงหน้าจะเพิ่มเวลาในการโหลดและการใช้ RAM/VRAM เพิ่มเฉพาะทรัพยากรที่จำเป็นต้องพร้อมใช้งานทันทีเท่านั้น และลบรายการขนาดใหญ่ออกหากไคลเอนต์ใช้หน่วยความจำหมด

# การโหลดสไลด์โชว์และพาโนรามาล่วงหน้า

การเพิ่ม [slideshow](./slideshows) จะโหลดรูปภาพทั้งหมดและโอเวอร์เลย์ที่เลือกไว้เพิ่มเติม การเพิ่ม [panorama](./panoramas) จะโหลดทั้งหกด้านและโอเวอร์เลย์ที่เลือกไว้เพิ่มเติม

**Customization -> Reload FancyMenu** จะไม่เรียกใช้ตัวโหลดล่วงหน้า ให้ใช้การโหลดทรัพยากรของ Minecraft ใหม่หรือรีสตาร์ตเกมหลังจากเปลี่ยนรายการโหลดล่วงหน้า
