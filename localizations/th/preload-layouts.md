# โหลดทรัพยากรล่วงหน้า

การโหลดล่วงหน้าจะเตรียมทรัพยากรที่เลือกไว้ก่อนที่เมนูจะต้องใช้ ใช้กับทรัพยากรที่อาจกะพริบ แสดงเฟรมแรกเป็นสีดำ หรือเริ่มทำงานช้า

# เพิ่มทรัพยากรในรายการโหลดล่วงหน้า

เปิด **Customization -> Pre-Load Resources**

<br>

<img width="350" alt="Screenshot_1" src="https://github.com/Keksuccino/FancyMenu/assets/35544624/3265da80-1bbc-4634-bd94-ba2795d7e3f2">

รายการนี้รองรับทรัพยากรรูปภาพ ภาพเคลื่อนไหว เสียง วิดีโอ และข้อความจากไฟล์ในเครื่อง URL บนเว็บ หรือชุดทรัพยากร โดยจะไม่โหลดหน้า [Browser](/elements#browser) ที่ทำงานอยู่แบบเรียลไทม์ล่วงหน้า

ตัวโหลดล่วงหน้าจะเริ่มทำงานระหว่างเริ่มเกมและเมื่อ Minecraft โหลดทรัพยากรใหม่ โดยจะรอให้แต่ละรายการโหลดเสร็จหรือเกิดข้อผิดพลาดก่อนดำเนินการต่อ แต่ละรายการมีเวลาสูงสุดสองนาที

ทรัพยากรที่โหลดแล้วจะยังอยู่ในแคชจนกว่า FancyMenu จะปล่อยทรัพยากรระหว่างโหลดใหม่หรือปิดไคลเอนต์ **Customization -> Reload FancyMenu** จะล้างแคช แต่จะไม่เรียกใช้ตัวโหลดล่วงหน้าอีกครั้ง

การโหลดล่วงหน้าทำให้เวลาโหลดนานขึ้นและใช้ RAM/VRAM มากขึ้น เพิ่มเฉพาะทรัพยากรที่จำเป็นต้องพร้อมใช้งานทันที หากไคลเอนต์มีหน่วยความจำไม่พอ ให้ลบรายการขนาดใหญ่ออก

# โหลดสไลด์โชว์และพาโนรามาล่วงหน้า

การเพิ่ม[สไลด์โชว์](/slideshows)จะโหลดรูปภาพทั้งหมดและภาพซ้อนทับ (ถ้ามี) การเพิ่ม[พาโนรามา](/panoramas)จะโหลดพื้นผิวทั้งหกด้านและภาพซ้อนทับ (ถ้ามี)

**Customization -> Reload FancyMenu** จะไม่เรียกใช้ตัวโหลดล่วงหน้า ใช้การโหลดทรัพยากรของ Minecraft ใหม่หรือเริ่มเกมอีกครั้งหลังเปลี่ยนรายการโหลดล่วงหน้า
