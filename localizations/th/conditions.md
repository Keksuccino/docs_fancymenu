# ข้อกำหนด
ข้อกำหนด (หรือ "ข้อกำหนดการโหลด") ช่วยให้คุณกำหนดให้บางส่วนของเลย์เอาต์แสดงหรือไม่แสดง โดยอ้างอิงจากเงื่อนไขต่าง ๆ เช่น เมื่อองค์ประกอบถูกโฮเวอร์, หน้าต่างมีขนาดเฉพาะ, หรือคุณอยู่ในโลกอยู่ในขณะนี้

นอกจากนี้ยังสามารถใช้ในสคริปต์การกระทำของปุ่ม, สไลเดอร์, ทิกเกอร์ และทุกอย่างที่มีช่องป้อนสคริปต์การกระทำ

# การเพิ่มข้อกำหนดให้กับองค์ประกอบ
หากต้องการเพิ่มข้อกำหนดหนึ่งรายการหรือหลายรายการให้กับองค์ประกอบ ให้คลิกขวาที่องค์ประกอบ แล้วคลิก **Loading Requirements**

# ข้อกำหนดทั้งเลย์เอาต์
คุณยังสามารถเปลี่ยนการมองเห็นของทั้งเลย์เอาต์ได้ด้วยการคลิกขวาที่ **พื้นหลังตัวแก้ไข** แล้วคลิก **Loading Requirements [Layout-Wide]**

# สคริปต์การกระทำ
ข้อกำหนดสามารถใช้ในสคริปต์การกระทำได้เช่นกัน
คุณสามารถเพิ่มได้ในหน้าจอแก้ไขสคริปต์การกระทำ และใช้เพื่อให้ดำเนินการบางอย่างเฉพาะเมื่อเงื่อนไขของข้อกำหนดเป็นจริงเท่านั้น

# ค่าของข้อกำหนด
ข้อกำหนดบางรายการจำเป็นต้องให้คุณตั้งค่าบางอย่างเพื่อให้ทำงานได้อย่างถูกต้อง ถ้าเป็นกรณีนั้น หน้าจอข้อกำหนดควรบอกให้คุณตั้งค่าทั้งหมดก่อน แต่ถ้าไม่ ก็ให้ตรวจสอบว่าปุ่ม **Edit Requirement Value** กดได้หรือไม่เมื่อเพิ่มข้อกำหนด
หากไม่แน่ใจว่าควรตั้งค่าอะไร ให้ดูคำอธิบายของข้อกำหนดนั้นเสมอ
ช่องป้อนค่าบางช่องยังรองรับ **การเติมข้อความอัตโนมัติด้วย TAB** อีกด้วย

FancyMenu 3.9.0 ได้ปรับหน้าต่าง Manage Requirements ใหม่ให้ใช้เมนูบริบทเมื่อคลิกขวา, การนำทางด้วยแป้นพิมพ์, การค้นหา, undo/redo (`CTRL + Z` / `CTRL + Y`) และใช้ `CTRL + S` เป็นคีย์ลัด **Done**

# ข้อกำหนดโดยละเอียด
รายการต่อไปนี้มีข้อกำหนดส่วนใหญ่หรือทั้งหมดที่มีอยู่ใน FancyMenu แต่อาจมีบางครั้งที่รายการล้าสมัยเล็กน้อยเนื่องจากมีการอัปเดตม็อด

## Is Element Hovered
ตรวจสอบว่าองค์ประกอบที่ระบุถูกโฮเวอร์ด้วยเคอร์เซอร์เมาส์หรือไม่  
**ต้องมีค่า**: ใช่ - Element ID ขององค์ประกอบเป้าหมาย (เช่น `some_element_ID`) คุณสามารถดู ID ได้โดยคลิกขวาที่องค์ประกอบในตัวแก้ไข

## Is Element Focused
ตรวจสอบว่าองค์ประกอบที่ระบุกำลังมีโฟกัสจากคีย์บอร์ดอยู่หรือไม่ (เช่น ช่องข้อความหรือปุ่มที่มีโฟกัส)
**ต้องมีค่า**: ใช่ - Element ID ขององค์ประกอบเป้าหมาย (ID เดียวกับที่แสดงในตัวแก้ไข)

> นี่ไม่เหมือนกับการที่องค์ประกอบถูกโฮเวอร์อยู่เฉย ๆ ถึงแม้จะดูคล้ายกันก็ตาม องค์ประกอบที่มีโฟกัสจะยังคงดูเหมือน "ถูกโฮเวอร์" แม้จะไม่ได้ถูกโฮเวอร์แล้วก็ตาม องค์ประกอบจะได้รับโฟกัสเมื่อคลิก หรือเมื่อใช้คีย์บอร์ดนำทางในเมนู
{.is-info}

## Is Any Element Hovered
ตรวจสอบว่ามีองค์ประกอบใดในเลย์เอาต์กำลังถูกโฮเวอร์ด้วยเคอร์เซอร์เมาส์อยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Any Button Hovered
ตรวจสอบว่ามีปุ่มใด ๆ (ของเกมปกติหรือแบบกำหนดเอง) กำลังถูกโฮเวอร์ด้วยเคอร์เซอร์เมาส์อยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Layout Enabled
ตรวจสอบว่าเลย์เอาต์ที่ระบุกำลังถูกเปิดใช้อยู่หรือไม่  
**ต้องมีค่า**: ใช่ - ชื่อของเลย์เอาต์ (เช่น `my_cool_main_menu_layout`)

## Is Scheduler Running
ตรวจสอบว่ากำลังมี scheduler ทำงานอยู่หรือไม่
**ต้องมีค่า**: ใช่ - Scheduler ID (เช่น `my_scheduler`)

## Is GUI Scale
ตรวจสอบว่าสเกล GUI ปัจจุบันตรงกับเงื่อนไขที่กำหนดหรือไม่  
**ต้องมีค่า**: ใช่ - รับค่าตัวเลข เช่น `1`, `2` เป็นต้น

## Is Button Active
ตรวจสอบว่าปุ่มที่ระบุอยู่ในสถานะ active (กดได้) หรือไม่  
**ต้องมีค่า**: ใช่ - Element ID ของปุ่มเป้าหมาย (เช่น "some_element_ID")

## Is Screen Title
ตรวจสอบว่าชื่อที่แสดงบนหน้าจอ (DISPLAY title) ตรงกับข้อความหรือคีย์การแปลที่กำหนดหรือไม่ จะตรวจเฉพาะชื่อที่แสดง/หัวเรื่องของหน้าจอ เช่น "Options" หรือ "Pause" เท่านั้น และจะไม่ตรวจตัวระบุเมนู/หน้าจอ (เช่น `title_screen`)!

**ต้องมีค่า**: ใช่ - ข้อความชื่อหน้าจอหรือคีย์การแปลที่แน่นอน

## Is Key Pressed
ตรวจสอบว่าปุ่มคีย์บอร์ดที่ระบุกำลังถูกกดอยู่หรือไม่  
**ต้องมีค่า**: ใช่ - key code ของปุ่มเป้าหมาย เลือกผ่าน UI เมื่อแก้ไขค่าของข้อกำหนด

## Is Any Screen Open
ตรวจสอบว่ามีหน้าจอ/เมนูใดเปิดอยู่หรือไม่ (จะคืนค่า false ถ้าไม่มีหน้าจอแสดงอยู่)  
**ต้องมีค่า**: ไม่จำเป็น

## Is MC Debug Overlay Enabled
ตรวจสอบว่าโอเวอร์เลย์ดีบัก F3 แสดงอยู่หรือไม่
**ต้องมีค่า**: ไม่จำเป็น

## Is Active Cursor Type
ตรวจสอบว่าประเภทเคอร์เซอร์ที่ใช้งานอยู่ใน FancyMenu ตรงกับประเภทเคอร์เซอร์มาตรฐานที่กำหนดหรือไม่
**ต้องมีค่า**: ใช่ - ประเภทเคอร์เซอร์: `normal`, `writing`, `crosshair`, `pointing_hand`, `resize_horizontal`, `resize_vertical`, `resize_nwse`, `resize_nesw`, `resize_all`, หรือ `not_allowed`

## Is Customization Menu Bar Visible
ตรวจสอบว่าแถบเมนูการปรับแต่งของ FancyMenu แสดงอยู่หรือไม่
**ต้องมีค่า**: ไม่จำเป็น

## Is Modpack Mode Enabled
ตรวจสอบว่า Modpack Mode ของ FancyMenu เปิดใช้อยู่หรือไม่
**ต้องมีค่า**: ไม่จำเป็น

## Mouse Clicked
ตรวจสอบว่ามีการกดปุ่มเมาส์ที่ระบุอยู่หรือไม่  
**ต้องมีค่า**: ใช่ - `left` หรือ `right` เพื่อระบุว่าจะตรวจปุ่มเมาส์ใด

## Is Fullscreen
ตรวจสอบว่าเกมอยู่ในโหมดเต็มหน้าจอหรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Window Width
ตรวจสอบว่าความกว้างของหน้าต่างเกมตรงกับค่าที่กำหนดหรือไม่  
**ต้องมีค่า**: ใช่ - ความกว้างหน้าต่างเป็นพิกเซล (เช่น "1920") สามารถระบุได้หลายค่าโดยคั่นด้วยเครื่องหมายจุลภาค

## Is Window Height
ตรวจสอบว่าความสูงของหน้าต่างเกมตรงกับค่าที่กำหนดหรือไม่  
**ต้องมีค่า**: ใช่ - ความสูงหน้าต่างเป็นพิกเซล (เช่น "1080") สามารถระบุได้หลายค่าโดยคั่นด้วยเครื่องหมายจุลภาค

## Is Window Width Bigger Than
ตรวจสอบว่าความกว้างของหน้าต่างเกมมากกว่าค่าที่กำหนดหรือไม่  
**ต้องมีค่า**: ใช่ - ความกว้างหน้าต่างเป็นพิกเซล (เช่น "1920")

## Is Window Height Bigger Than
ตรวจสอบว่าความสูงของหน้าต่างเกมมากกว่าค่าที่กำหนดหรือไม่  
**ต้องมีค่า**: ใช่ - ความสูงหน้าต่างเป็นพิกเซล (เช่น "1080")

## Is Multiplayer
ตรวจสอบว่าผู้เล่นกำลังอยู่ในโลกแบบผู้เล่นหลายคนหรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Singleplayer
ตรวจสอบว่าผู้เล่นกำลังอยู่ในโลกแบบผู้เล่นคนเดียวหรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is World Loaded
ตรวจสอบว่ามีโลกใดกำลังถูกโหลดอยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Adventure
ตรวจสอบว่าผู้เล่นกำลังอยู่ในโหมดผจญภัยหรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Creative
ตรวจสอบว่าผู้เล่นกำลังอยู่ในโหมดสร้างสรรค์หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Spectator
ตรวจสอบว่าผู้เล่นกำลังอยู่ในโหมดผู้ชม (spectator) หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Survival
ตรวจสอบว่าผู้เล่นกำลังอยู่ในโหมดเอาชีวิตรอดหรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Game Mode
ตรวจสอบว่าผู้เล่นอยู่ในโหมดเกมที่ระบุหรือไม่  
**ต้องมีค่า**: ใช่ - ชื่อโหมดเกม (เช่น "creative", "survival", "adventure", "spectator")

## Is Difficulty
ตรวจสอบว่าความยากของเกมปัจจุบันตรงกับค่าที่กำหนดหรือไม่  
**ต้องมีค่า**: ใช่ - ชื่อระดับความยาก (เช่น "peaceful", "easy", "normal", "hard")

## Is Hardcore
ตรวจสอบว่าโลกที่กำลังโหลดอยู่เป็นโหมด Hardcore หรือไม่
**ต้องมีค่า**: ไม่จำเป็น

## Is Camera Perspective
ตรวจสอบว่ามุมมองกล้องปัจจุบันตรงกับมุมมองที่กำหนดหรือไม่
**ต้องมีค่า**: ใช่ - `first_person`, `third_person_back`, หรือ `third_person_front`

## Is Raining
ตรวจสอบว่ากำลังฝนตกในตำแหน่งของผู้เล่นอยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Thundering
ตรวจสอบว่ากำลังมีพายุฝนฟ้าคะนองในโลกของผู้เล่นอยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Clear Weather
ตรวจสอบว่าสภาพอากาศปัจจุบันปลอดโปร่ง (ไม่มีฝนหรือฟ้าร้อง) หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Snowing
ตรวจสอบว่ากำลังหิมะตกในตำแหน่งของผู้เล่นอยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Running
ตรวจสอบว่าผู้เล่นกำลังวิ่งเร็ว (sprint) อยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Sneaking
ตรวจสอบว่าผู้เล่นกำลังย่อง/หมอบอยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Using Item
ตรวจสอบว่าผู้เล่นกำลังใช้งานไอเท็มอยู่หรือไม่
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Swimming
ตรวจสอบว่าผู้เล่นกำลังว่ายน้ำอยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Jumping or Falling
ตรวจสอบว่าผู้เล่นกำลังกระโดดอยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Under Water
ตรวจสอบว่าผู้เล่นอยู่ใต้น้ำทั้งหมดหรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player In Water
ตรวจสอบว่าผู้เล่นอยู่ในน้ำหรือไม่ (อาจจมอยู่บางส่วน)  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player In Lava
ตรวจสอบว่าผู้เล่นอยู่ในลาวาหรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player In Fluid
ตรวจสอบว่าผู้เล่นอยู่ในของไหลใด ๆ (น้ำ, ลาวา ฯลฯ) หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Riding Entity/Vehicle
ตรวจสอบว่าผู้เล่นกำลังขี่เอนทิตีใด ๆ อยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Riding Jumpable Entity
ตรวจสอบว่าผู้เล่นกำลังขี่เอนทิตีที่สามารถกระโดดได้ (เช่น ม้า) หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Riding Entity With Health
ตรวจสอบว่าผู้เล่นกำลังขี่เอนทิตีมีชีวิตที่มีค่าพลังชีวิตอยู่หรือไม่ (เช่น สัตว์ ไม่ใช่เรือ)  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player In Powder Snow
ตรวจสอบว่าผู้เล่นกำลังอยู่ในหิมะผงหรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Was Player In Powder Snow
ตรวจสอบว่าผู้เล่นเคยอยู่ในหิมะผงหรือไม่ (ใช้สำหรับเอฟเฟกต์ที่คงอยู่หลังจากออกมาแล้ว)  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Wearing Pumpkin
ตรวจสอบว่าผู้เล่นสวมฟักทองแกะสลักอยู่บนศีรษะหรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Flying With Elytra
ตรวจสอบว่าผู้เล่นกำลังบินด้วย elytra อยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Creative Flying
ตรวจสอบว่าผู้เล่นกำลังบินในโหมดสร้างสรรค์อยู่หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Has Player Absorption Hearts
ตรวจสอบว่าผู้เล่นมีหัวใจดูดซับ (หัวใจสีทอง) หรือไม่  
**ต้องมีค่า**: ไม่จำเป็น

## Is Player Withered
ตรวจสอบว่าผู้เล่นได้รับผลเอฟเฟกต์ wither หรือไม่

## Is Number

**ต้องมีค่า**: ใช่ - รูปแบบซับซ้อน: `["mode":"comparison_mode","text":"text1","compare_with":"text2"]$` โดย `comparison_mode` อาจเป็น `equals`, `contains`, `starts-with`, หรือ `ends-with`
