# ข้อกำหนด

ข้อกำหนด (เรียกว่า **ข้อกำหนดการโหลด** ในบางเมนู) ใช้แสดงหรือซ่อนเนื้อหาตามเงื่อนไขต่าง ๆ เช่น สถานะการชี้เมาส์ ขนาดหน้าต่าง หรือมีการโหลดโลกอยู่หรือไม่

คุณสามารถใช้ข้อกำหนดกับ[องค์ประกอบ](./elements) เลย์เอาต์ทั้งหมด และ[สคริปต์แอ็กชัน](./action-scripts) ได้

# การเพิ่มข้อกำหนดให้กับองค์ประกอบ

หากต้องการเพิ่มข้อกำหนดให้กับองค์ประกอบ ให้คลิกขวาที่องค์ประกอบนั้นแล้วเลือก **ข้อกำหนดการโหลด**

ระบบจะตรวจสอบข้อกำหนดขณะที่เมนูเปิดอยู่ ดังนั้นองค์ประกอบจึงอัปเดตเมื่อเงื่อนไขเปลี่ยนแปลง

# ข้อกำหนดที่ใช้กับทั้งเลย์เอาต์

คุณยังสามารถเปลี่ยนการมองเห็นของเลย์เอาต์ทั้งหมดได้ โดยคลิกขวาที่ **พื้นหลังตัวแก้ไข** แล้วคลิก **ข้อกำหนดการโหลด [ทั้งเลย์เอาต์]**

เมื่อผลลัพธ์ของข้อกำหนดที่ใช้กับทั้งเลย์เอาต์เปลี่ยนแปลง FancyMenu จะสร้างหน้าจอปัจจุบันใหม่ และใช้เลย์เอาต์ที่ข้อกำหนดผ่านในขณะนั้น

# สคริปต์แอ็กชัน

สามารถใช้ข้อกำหนดในสคริปต์แอ็กชันได้เช่นกัน
คุณสามารถเพิ่มข้อกำหนดในหน้าตัวแก้ไขสคริปต์แอ็กชัน และใช้เพื่อเรียกใช้แอ็กชันเฉพาะเมื่อเงื่อนไขของข้อกำหนดเป็นจริง

# การรวมข้อกำหนด

- ข้อกำหนดที่อยู่นอกกลุ่มจะใช้ **AND** ดังนั้นข้อกำหนดทั้งหมดต้องผ่าน
- ภายในกลุ่ม ให้เลือก **AND** หรือ **OR**
- ใช้ **IF NOT** เพื่อกลับค่าของข้อกำหนดหนึ่งข้อ

กฎเหล่านี้ใช้เหมือนกันกับองค์ประกอบ เลย์เอาต์ และสคริปต์แอ็กชัน

# ค่าของข้อกำหนด

สำหรับข้อกำหนดที่ต้องใช้ค่า ให้ใช้ **แก้ไขค่าข้อกำหนด** และทำตามคำอธิบายที่แสดงในตัวแก้ไข ช่องบางประเภทรองรับการเติมข้อความด้วย **TAB**

หากข้อกำหนดที่นำเข้าไม่ทำงานหลังจากเปลี่ยน FancyMenu หรือส่วนเสริม ให้แก้ไขข้อกำหนดนั้นในหน้าข้อกำหนด และตรวจสอบ `logs/latest.log` เพื่อดูข้อผิดพลาด

ตัวแก้ไขข้อกำหนดรองรับเมนูบริบทเมื่อคลิกขวา การควบคุมด้วยแป้นพิมพ์ การค้นหา การเลิกทำ/ทำซ้ำ (`Ctrl/Command + Z` / `Ctrl/Command + Y`) และ `Ctrl/Command + S` เพื่อบันทึก

# รายละเอียดข้อกำหนด

ส่วนนี้แสดงข้อกำหนดในตัวของ FancyMenu

## Is Element Hovered (`fancymenu_visibility_requirement_is_element_hovered`)

**จุดประสงค์:** ตรวจสอบว่าเคอร์เซอร์เมาส์กำลังชี้อยู่เหนือองค์ประกอบที่ระบุหรือไม่

**ค่า:** จำเป็น — [ตัวระบุองค์ประกอบ](./element-identifiers) ขององค์ประกอบเป้าหมาย (เช่น `some_element_ID`)

## Is Element Focused (`is_element_focused`)

**จุดประสงค์:** ตรวจสอบว่าองค์ประกอบที่ระบุมีโฟกัสจากแป้นพิมพ์อยู่ในขณะนั้นหรือไม่ (เช่น ช่องข้อความหรือปุ่มที่มีโฟกัส)

**ค่า:** จำเป็น — ID ขององค์ประกอบเป้าหมาย (เป็น ID เดียวกับที่แสดงในตัวแก้ไข)

> [!NOTE]
> โฟกัสและการชี้เมาส์เป็นสถานะที่แตกต่างกัน องค์ประกอบอาจยังคงแสดงลักษณะเมื่อมีโฟกัสหลังจากตัวชี้เลื่อนออกไปแล้ว การคลิกหรือการนำทางด้วยแป้นพิมพ์สามารถทำให้องค์ประกอบมีโฟกัสได้

## Is Any Element Hovered (`fancymenu_visibility_requirement_is_any_element_hovered`)

**จุดประสงค์:** ตรวจสอบองค์ประกอบที่มองเห็นได้/แสดงผลได้ในเลเยอร์การปรับแต่งที่ใช้งานอยู่ รวมถึงองค์ประกอบจากเลย์เอาต์ที่ซ้อนกัน

**ค่า:** ไม่จำเป็น

## Is Any Button Hovered (`fancymenu_visibility_requirement_is_any_button_hovered`)

**จุดประสงค์:** ตรวจสอบว่ามีการชี้เมาส์อยู่เหนือปุ่ม vanilla หรือปุ่มแบบกำหนดเองที่มองเห็นได้/แสดงผลได้ในเลเยอร์การปรับแต่งที่ใช้งานอยู่หรือไม่ รวมถึงปุ่มจากเลย์เอาต์ที่ซ้อนกัน

**ค่า:** ไม่จำเป็น

## Is Layout Enabled (`fancymenu_visibility_requirement_is_layout_enabled`)

**จุดประสงค์:** ตรวจสอบว่าเลย์เอาต์ที่ระบุเปิดใช้งานอยู่ในขณะนั้นหรือไม่

**ค่า:** จำเป็น — ชื่อเลย์เอาต์ (เช่น `my_cool_main_menu_layout`)

## Is Scheduler Running (`fancymenu_visibility_requirement_is_scheduler_running`)

**จุดประสงค์:** ตรวจสอบว่า[ตัวจัดตารางเวลา](./schedulers) กำลังทำงานอยู่หรือไม่

**ค่า:** จำเป็น — ID ของตัวจัดตารางเวลา (เช่น `my_scheduler`)

## Is GUI Scale (`fancymenu_loading_requirement_is_gui_scale`)

**จุดประสงค์:** ตรวจสอบว่ามาตราส่วน GUI ปัจจุบันตรงตามเงื่อนไขที่กำหนดหรือไม่

**ค่า:** จำเป็น — ใช้ตัวเลขสำหรับการเท่ากัน ใช้ `>` สำหรับมากกว่า หรือใช้ `<` สำหรับน้อยกว่า

เงื่อนไขหลายรายการที่คั่นด้วยจุลภาคจะรวมกันด้วย AND ตัวอย่างเช่น `>1,<4` จะผ่านเฉพาะเมื่อมาตราส่วน GUI มากกว่า `1` และน้อยกว่า `4`

## Is Button Active (`fancymenu_visibility_requirement_is_button_active`)

**จุดประสงค์:** ตรวจสอบว่าปุ่มที่ระบุใช้งานอยู่ (สามารถคลิกได้) หรือไม่

**ค่า:** จำเป็น — ID ขององค์ประกอบปุ่มเป้าหมาย (เช่น "some_element_ID")

## Is Screen Title (`is_menu_title`)

**จุดประสงค์:** ตรวจสอบว่าชื่อหน้าจอที่แสดงตรงกับข้อความหรือคีย์การแปลที่กำหนดหรือไม่ ข้อกำหนดนี้จะตรวจสอบเฉพาะชื่อ/ชื่อเรื่องที่แสดงของหน้าจอ เช่น "ตัวเลือก" หรือ "หยุดเกม" เท่านั้น จะไม่ตรวจสอบตัวระบุเมนู/หน้าจอ (เช่น `title_screen`)

**ค่า:** จำเป็น — ข้อความชื่อเรื่องหรือคีย์การแปลของหน้าจอที่ตรงกันทุกประการ

## Is Key Pressed (`is_key_pressed`)

**จุดประสงค์:** ตรวจสอบว่ากำลังกดปุ่มบนแป้นพิมพ์ที่ระบุอยู่หรือไม่

**ค่า:** จำเป็น — รหัสปุ่มของปุ่มเป้าหมาย เลือกผ่าน UI ขณะแก้ไขค่าข้อกำหนด

## Is Any Screen Open (`is_any_screen_open`)

**จุดประสงค์:** ตรวจสอบว่ามีหน้าจอ/เมนูใดเปิดอยู่ในขณะนั้นหรือไม่ (จะคืนค่า false หากไม่มีหน้าจอแสดงอยู่)

**ค่า:** ไม่จำเป็น

## Is MC Debug Overlay Enabled (`is_debug_overlay_enabled`)

**จุดประสงค์:** ตรวจสอบว่าโอเวอร์เลย์ดีบัก F3 กำลังแสดงอยู่หรือไม่

**ค่า:** ไม่จำเป็น

## Is Active Cursor Type (`is_active_cursor_type`)

**จุดประสงค์:** ตรวจสอบว่าประเภทเคอร์เซอร์ที่ FancyMenu ใช้งานอยู่ตรงกับประเภทเคอร์เซอร์มาตรฐานที่ระบุหรือไม่

**ค่า:** จำเป็น — ประเภทเคอร์เซอร์: `normal`, `writing`, `crosshair`, `pointing_hand`, `resize_horizontal`, `resize_vertical`, `resize_nwse`, `resize_nesw`, `resize_all` หรือ `not_allowed`

## Is Customization Menu Bar Visible (`is_customization_menu_bar_visible`)

**จุดประสงค์:** ตรวจสอบว่าแถบเมนูการปรับแต่งของ FancyMenu กำลังแสดงอยู่หรือไม่

**ค่า:** ไม่จำเป็น

## Is Modpack Mode Enabled (`is_modpack_mode_enabled`)

**จุดประสงค์:** ตรวจสอบว่าโหมด Modpack ของ FancyMenu เปิดใช้งานอยู่หรือไม่

**ค่า:** ไม่จำเป็น

## Mouse Button Is Pressed (`mouse_click`)

**จุดประสงค์:** คืนค่า true ขณะที่กดปุ่มเมาส์ที่ระบุค้างอยู่ นี่ไม่ใช่อีเวนต์การคลิกแบบทำงานครั้งเดียว หากต้องการให้แอ็กชันทำงานครั้งเดียวต่อการคลิก ให้ใช้[ตัวรับฟัง **เมื่อคลิกปุ่มเมาส์**](./listeners#on-mouse-button-clicked-mouse_button_clicked)

**ค่า:** จำเป็น — `left` หรือ `right` เพื่อระบุปุ่มเมาส์ที่ต้องการตรวจสอบ

## Is Fullscreen (`fancymenu_loading_requirement_is_fullscreen`)

**จุดประสงค์:** ตรวจสอบว่าเกมอยู่ในโหมดเต็มหน้าจอหรือไม่

**ค่า:** ไม่จำเป็น

## Is Window Width (`fancymenu_loading_requirement_is_window_width`)

**จุดประสงค์:** ตรวจสอบว่าความกว้างหน้าต่างเกมตรงกับค่าที่กำหนดหรือไม่

**ค่า:** จำเป็น — ความกว้างหน้าต่างเป็นพิกเซล (เช่น "1920") สามารถระบุหลายค่าโดยคั่นด้วยจุลภาค

## Is Window Height (`fancymenu_loading_requirement_is_window_height`)

**จุดประสงค์:** ตรวจสอบว่าความสูงหน้าต่างเกมตรงกับค่าที่กำหนดหรือไม่

**ค่า:** จำเป็น — ความสูงหน้าต่างเป็นพิกเซล (เช่น "1080") สามารถระบุหลายค่าโดยคั่นด้วยจุลภาค

## Is Window Width Bigger Than (`fancymenu_loading_requirement_is_window_width_bigger_than`)

**จุดประสงค์:** ตรวจสอบว่าความกว้างหน้าต่างเกมมากกว่าค่าที่กำหนดหรือไม่

**ค่า:** จำเป็น — ความกว้างหน้าต่างเป็นพิกเซล (เช่น "1920")

## Is Window Height Bigger Than (`fancymenu_loading_requirement_is_window_height_bigger_than`)

**จุดประสงค์:** ตรวจสอบว่าความสูงหน้าต่างเกมมากกว่าค่าที่กำหนดหรือไม่

**ค่า:** จำเป็น — ความสูงหน้าต่างเป็นพิกเซล (เช่น "1080")

## Is Multiplayer (`fancymenu_loading_requirement_is_multiplayer`)

**จุดประสงค์:** ตรวจสอบว่าผู้เล่นอยู่ในโลกผู้เล่นหลายคนหรือไม่

**ค่า:** ไม่จำเป็น

## Is Singleplayer (`fancymenu_loading_requirement_is_singpleplayer`)

**จุดประสงค์:** ตรวจสอบว่าผู้เล่นอยู่ในโลกผู้เล่นคนเดียวหรือไม่

**ค่า:** ไม่จำเป็น

## Is World Loaded (`fancymenu_loading_requirement_is_world_loaded`)

**จุดประสงค์:** ตรวจสอบว่ามีโลกใดกำลังโหลดอยู่หรือไม่

**ค่า:** ไม่จำเป็น

**จุดประสงค์:** ตรวจสอบว่าผู้เล่นอยู่ในโหมดเกมผจญภัยหรือไม่

**ค่า:** ไม่จำเป็น

**จุดประสงค์:** ตรวจสอบว่าผู้เล่นอยู่ในโหมดเกมสร้างสรรค์หรือไม่

**ค่า:** ไม่จำเป็น

## Is Survival (`fancymenu_visibility_requirement_is_survival`)

**จุดประสงค์:** ตรวจสอบว่าผู้เล่นอยู่ในโหมดเอาชีวิตรอดหรือไม่

**ค่า:** ไม่จำเป็น

## Is Game Mode (`is_gamemode`)

**จุดประสงค์:** ตรวจสอบว่าผู้เล่นอยู่ในโหมดเกมที่ระบุหรือไม่

**ค่า:** จำเป็น — ชื่อโหมดเกม (เช่น "creative", "survival", "adventure", "spectator")

## Is Difficulty (`is_difficulty`)

**จุดประสงค์:** ตรวจสอบว่าความยากของเกมปัจจุบันตรงกับค่าที่ระบุหรือไม่

**ค่า:** จำเป็น — ชื่อระดับความยาก (เช่น "peaceful", "easy", "normal", "hard")

## Is Hardcore (`is_hardcore`)

**จุดประสงค์:** ตรวจสอบว่าโลกที่โหลดอยู่ในโหมดฮาร์ดคอร์หรือไม่

**ค่า:** ไม่จำเป็น

**จุดประสงค์:** ตรวจสอบว่ามุมมองกล้องปัจจุบันตรงกับมุมมองที่ระบุหรือไม่

**ค่า:** จำเป็น — `first_person`, `third_person_back` หรือ `third_person_front`

## Is Raining (`is_raining`)

**จุดประสงค์:** ตรวจสอบว่าขณะนี้ฝนกำลังตกในตำแหน่งของผู้เล่นหรือไม่

**ค่า:** ไม่จำเป็น

**ค่า:** ไม่จำเป็น
