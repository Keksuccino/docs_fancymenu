# ข้อกำหนด

ข้อกำหนดคือเงื่อนไขต่าง ๆ เช่น “เมาส์อยู่เหนือปุ่มนี้” “ตอนนี้เป็นเดือนธันวาคม” หรือ “โหลดโลกแล้ว” ใช้ข้อกำหนดเพื่อ:

- แสดง [องค์ประกอบ](/elements) เฉพาะบางเวลา
- โหลดเลย์เอาต์ทั้งหมดเฉพาะบางเวลา
- เปิดให้คลิกปุ่ม แถบเลื่อน และช่องทำเครื่องหมายเฉพาะบางเวลา
- เรียกใช้บางส่วนของ [สคริปต์การทำงาน](/action-scripts) เฉพาะบางเวลา

FancyMenu จะตรวจสอบข้อกำหนดตลอดเวลาที่เมนูเปิดอยู่ ดังนั้นสิ่งต่าง ๆ จึงแสดง ซ่อน หรือเปลี่ยนแปลงได้ทันที กล่องข้อมูลนี้จะแสดงเฉพาะเมื่อเมาส์อยู่เหนือ “Multiplayer”:

<img width="800" alt="เมื่อเลื่อนเมาส์ไปเหนือปุ่ม Multiplayer บนหน้าจอไตเติล กล่องข้อมูลพร้อมที่อยู่เซิร์ฟเวอร์จะแสดงขึ้นข้าง ๆ" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/requirements_hover.gif?raw=true">

# ตำแหน่งที่ใช้งานได้

| ตำแหน่ง | ข้อกำหนดทำอะไรได้บ้าง |
|---|---|
| คลิกขวาที่องค์ประกอบ -> **ข้อกำหนดการโหลด** | องค์ประกอบจะแสดงเฉพาะเมื่อข้อกำหนดเป็นจริง ใช้ได้กับ [องค์ประกอบ Vanilla](/vanilla-elements) ด้วย |
| คลิกขวาที่พื้นหลังของตัวแก้ไข -> **ข้อกำหนดการโหลด [ทั้งเลย์เอาต์]** | เลย์เอาต์ทั้งหมดจะโหลดเฉพาะเมื่อข้อกำหนดเป็นจริง ดู [ข้อกำหนดทั้งเลย์เอาต์](#layout-wide-requirements) |
| คลิกขวาที่ปุ่ม แถบเลื่อน หรือช่องทำเครื่องหมาย -> **สถานะการควบคุมที่ใช้งานได้** | จะคลิกได้เฉพาะเมื่อข้อกำหนดเป็นจริง มิฉะนั้นจะเป็นสีเทา ปุ่ม Vanilla ก็มีตัวเลือกนี้เช่นกัน |
| IF, ELSE-IF และ WHILE ใน [สคริปต์การทำงาน](/action-scripts#statements) | การทำงานภายในจะทำงานเฉพาะเมื่อข้อกำหนดเป็นจริง |

ในตัวแก้ไขเลย์เอาต์ องค์ประกอบจะแสดงอยู่เสมอ เพื่อให้คุณยังแก้ไขได้ ข้อกำหนดขององค์ประกอบจะมีผลนอกตัวแก้ไข

> [!TIP]
> [การแสดงองค์ประกอบ](/element-visibility) แสดงวิธีอื่น ๆ ในการแสดงและซ่อนองค์ประกอบ เช่น การหน่วงเวลา การค่อย ๆ ปรากฏ และการสลับด้วยปุ่ม

# เพิ่มข้อกำหนด

<img width="800" alt="คัดลอก ID ของปุ่ม Multiplayer แล้วกำหนดข้อกำหนด Is Element Hovered พร้อม ID ดังกล่าวให้กล่องข้อมูลใน Manage Requirements" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/requirements_add.gif?raw=true">

1. คลิกขวาที่องค์ประกอบ แล้วคลิก **ข้อกำหนดการโหลด** หน้าต่าง **จัดการข้อกำหนด** จะเปิดขึ้น
2. คลิกขวาที่รายการว่าง แล้วคลิก **เพิ่มข้อกำหนด** หรือกด `A`
3. คลิกหมวดหมู่ใน **ข้อกำหนดที่ใช้ได้** หรือเริ่มพิมพ์เพื่อค้นหาชื่อและคำอธิบาย **คำอธิบายข้อกำหนด** จะอธิบายข้อกำหนดที่เลือก
4. คลิก **ขั้นตอนถัดไป** เพื่อตั้งค่า ข้อกำหนดที่ไม่ต้องใช้ค่าจะแสดงปุ่ม **เสร็จสิ้น** แทน ดับเบิลคลิกข้อกำหนดเพื่อทำเช่นเดียวกัน
5. กรอกค่าแล้วคลิก **เสร็จสิ้น** ตัวอย่างเช่น **Is Element Hovered** ต้องใช้ ID ขององค์ประกอบ คลิกขวาที่องค์ประกอบแล้วคลิก **คัดลอก ID องค์ประกอบ** เพื่อคัดลอก ID
6. คลิก **เสร็จสิ้น** ในหน้าต่าง **จัดการข้อกำหนด**

## โหมดข้อกำหนด

ปุ่ม **โหมดข้อกำหนด** ในหน้าต่างเลือกข้อกำหนดใช้สลับระหว่าง:

- **ปกติ**: เป็นจริงเมื่อเงื่อนไขเป็นจริง
- **ตรงข้าม**: เป็นจริงเมื่อเงื่อนไขไม่เป็นจริง ตัวอย่างเช่น **Is World Loaded** ในโหมดตรงข้ามจะเป็นจริงเฉพาะในเมนูหลัก

**จัดการข้อกำหนด** จะแสดงโหมดและค่าของข้อกำหนดแต่ละรายการ

## ค่า

- ค่ารองรับ [ตัวแทนข้อความ](/placeholders) และ [ตัวแปร](/variables#showing-variables-in-text) ของคุณ เช่น `$$coins` FancyMenu จะเติมค่าให้ทุกครั้งที่ตรวจสอบข้อกำหนด
- ช่องค่าหลายช่องจะแนะนำค่าขณะพิมพ์ เช่น ไบโอม ID ของม็อด ภาษา หรือชื่อตัวแปร คลิกคำแนะนำหรือกด `Tab`
- ข้อกำหนดที่ใช้ค่าธรรมดาจะแสดงตัวแก้ไขข้อความแบบบรรทัดเดียว ชื่อหน้าต่างจะบอกว่าต้องพิมพ์อะไร เช่น **Target Element ID**

## จัดการข้อกำหนด

คลิกขวาที่รายการ ข้อกำหนด หรือกลุ่มใน **จัดการข้อกำหนด** เพื่อใช้ตัวเลือกต่อไปนี้:

| ตัวเลือก | ปุ่มลัด | การทำงาน |
|---|---|---|
| **เพิ่มข้อกำหนด** | `A` | เพิ่มข้อกำหนด |
| **เพิ่มกลุ่ม** | `G` | เพิ่มกลุ่ม (ดูด้านล่าง) |
| **แก้ไขข้อกำหนด** | `Enter` หรือดับเบิลคลิก | เปิดหน้าต่างเลือกข้อกำหนดพร้อมชนิด โหมด และค่า |
| **ลบข้อกำหนด** / **ลบกลุ่ม** | `Delete` | ลบรายการนั้น |
| **เลิกทำ** / **ทำซ้ำ** | `Ctrl + Z` / `Ctrl + Y` | เลิกทำและทำซ้ำการเปลี่ยนแปลงในหน้าต่างนี้ |
| **ส่งออกข้อกำหนดให้ AI** | | ส่งออกข้อกำหนดทั้งหมดในหน้าต่างนี้สำหรับ [แชต AI](/export-for-ai) รวมการเปลี่ยนแปลงที่ยังไม่ได้บันทึก |

กด `Up` และ `Down` เพื่อเลือกข้อกำหนดก่อนหน้าหรือถัดไป **เสร็จสิ้น** (`Ctrl + S`) จะบันทึก ส่วน **ยกเลิก** จะละทิ้งการเปลี่ยนแปลงทั้งหมดในหน้าต่างนี้ บน macOS ให้ใช้ `Cmd` แทน `Ctrl`

เมื่อเลือกองค์ประกอบหลายรายการ **ข้อกำหนดการโหลด** จะเปลี่ยนข้อกำหนดของทุกรายการ หากข้อกำหนดเดิมแตกต่างกัน FancyMenu จะถามยืนยันก่อน เพราะข้อกำหนดทั้งหมดจะถูกแทนที่

# รวมข้อกำหนดเข้าด้วยกัน

ข้อกำหนดทั้งหมดใน **จัดการข้อกำหนด** ต้องเป็นจริง หากต้องการระบุว่า “อย่างใดอย่างหนึ่งก็ได้” ให้ใช้กลุ่ม

กลุ่มทำงานเหมือนข้อกำหนดหนึ่งรายการ:

- โหมด **And**: ทุกข้อในกลุ่มต้องเป็นจริง กลุ่มใหม่จะเริ่มต้นด้วยโหมดนี้
- โหมด **Or**: มีข้อใดข้อหนึ่งในกลุ่มเป็นจริงก็เพียงพอ

1. คลิกขวาที่รายการแล้วคลิก **เพิ่มกลุ่ม** หรือกด `G` กลุ่มจะได้ชื่อ เช่น `group_1`
2. คลิกขวาที่กลุ่มแล้วคลิก **โหมดกลุ่ม** เพื่อสลับระหว่าง **And** และ **Or**
3. คลิก **แก้ไขข้อกำหนดของกลุ่ม** หรือดับเบิลคลิกกลุ่ม หน้าต่างคล้ายกับ **จัดการข้อกำหนด** จะเปิดขึ้นสำหรับกลุ่มนั้น
4. เพิ่มข้อกำหนดของกลุ่มแล้วคลิก **เสร็จสิ้น**

ตัวอย่างเช่น คำทักทายวันคริสต์มาสที่แสดงในเดือนธันวาคม หรือเมื่อผู้เล่นเปิด `xmas_lights`: สร้างกลุ่ม Or ที่มี **Is Real Time Month** เป็น `12` และ **Is Variable Value (FM Variable)** สำหรับตัวแปร `xmas_lights` โดยมีค่าเป็น `on`

<img width="800" alt="เพิ่มกลุ่มใน Manage Requirements เปลี่ยนโหมดเป็น Or แล้วเพิ่ม Is Real Time Month และ Is Variable Value (FM Variable) ลงในกลุ่ม" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/requirements_group.gif?raw=true">

- กลุ่มสามารถมีกลุ่มอื่นอยู่ภายในได้ เช่น “(A และ B) หรือ (C และ D)” ชื่อหน้าต่างจะแสดงตำแหน่งปัจจุบัน เช่น `Edit Group: group_1 › group_2`
- **แก้ไขตัวระบุกลุ่ม** ใช้เปลี่ยนชื่อกลุ่ม แต่ละชื่อใช้ได้เพียงครั้งเดียว รวมถึงภายในกลุ่มอื่นด้วย
- กลุ่มว่างในโหมด **Or** จะไม่มีวันเป็นจริง

# ข้อกำหนดทั้งเลย์เอาต์

ข้อกำหนดทั้งเลย์เอาต์ใช้ตัดสินว่าจะโหลดเลย์เอาต์ทั้งหมดหรือไม่ ใช้กับหน้าจอไตเติลเวอร์ชันกลางคืน เลย์เอาต์แยกตามภาษา หรือเลย์เอาต์ที่แสดงเฉพาะในโหมดเล่นคนเดียวได้

คลิกขวาที่พื้นหลังของตัวแก้ไข แล้วคลิก **ข้อกำหนดการโหลด [ทั้งเลย์เอาต์]** หรือไปที่ **แถบเมนู -> เลย์เอาต์ -> คุณสมบัติเลย์เอาต์**

- หากผลลัพธ์เปลี่ยนขณะที่เมนูเปิดอยู่ FancyMenu จะสร้างหน้าจอใหม่โดยใช้เลย์เอาต์ที่เป็นจริงในขณะนั้น
- ใช้ได้กับ [เลย์เอาต์สากล](/universal-layouts) ด้วย
- หากต้องการเปิดและปิดเลย์เอาต์ด้วยปุ่ม ให้วางปุ่มไว้ในเลย์เอาต์อื่น ดู [เปิดและปิดเลย์เอาต์](/element-visibility#turning-layouts-on-and-off)

# ข้อมูลที่ควรรู้

- ข้อกำหนดเกี่ยวกับโลกและผู้เล่นจะไม่เป็นจริงเมื่อยังไม่ได้โหลดโลก เช่น ขณะอยู่ในเมนูหลัก
- ข้อกำหนดเกี่ยวกับองค์ประกอบ เคอร์เซอร์เมาส์ ช่องเก็บของ ผู้เล่น และโลกจะใช้ไม่ได้กับ [Ticker](/elements#ticker) เมื่อเปิด **Async** ในกรณีนั้น FancyMenu จะแสดงข้อผิดพลาดพร้อมชื่อข้อกำหนด
- ข้อกำหนดจากส่วนเสริมที่คุณนำออกจะถูกข้าม การบันทึกเลย์เอาต์ในตัวแก้ไขจะลบข้อกำหนดเหล่านั้นอย่างถาวร
- **แถบเมนู -> การปรับแต่ง -> การตั้งค่า -> ระยะเวลาแคชข้อกำหนด [MS]** จะนำผลลัพธ์ของข้อกำหนดกลับมาใช้ซ้ำเป็นเวลาหลายมิลลิวินาที เพื่อให้เลย์เอาต์ขนาดใหญ่ทำงานเร็วขึ้น ค่า `0` จะปิดฟีเจอร์นี้ ซึ่งเป็นค่าเริ่มต้น การแคชอาจทำให้สคริปต์การทำงานและการเปลี่ยนแปลงอย่างรวดเร็วทำงานผิดไปจากที่คาด

# ข้อกำหนดทั้งหมด

ข้อกำหนดเรียงตามลำดับเดียวกับในหน้าต่างเลือกข้อกำหนด คือเรียงตามหมวดหมู่แล้วตามชื่อ ข้อกำหนดที่ไม่มีหมวดหมู่จะอยู่ท้ายรายการในหน้าต่างเลือก และอยู่ในหมวด [อื่น ๆ](#other) ที่นี่

## GUI

### Is Active Cursor Type

**ตัวระบุ:** `is_active_cursor_type`

เป็นจริงเมื่อเคอร์เซอร์เมาส์มีรูปร่างตามที่กำหนด เช่น **มือชี้** เมื่ออยู่เหนือลิงก์ หรือ **เคอร์เซอร์เขียนข้อความ** เมื่ออยู่เหนือช่องข้อความ

- ค่า: คลิก **ชนิดเคอร์เซอร์** เพื่อเลือก **ปกติ**, **เคอร์เซอร์เขียนข้อความ**, **เป้าเล็ง**, **มือชี้**, **ปรับขนาดแนวนอน**, **ปรับขนาดแนวตั้ง**, **ปรับขนาด NWSE**, **ปรับขนาด NESW**, **ปรับขนาดทุกทิศทาง** หรือ **ไม่อนุญาต**

### Is Any Button Hovered

**ตัวระบุ:** `fancymenu_visibility_requirement_is_any_button_hovered`

เป็นจริงเมื่อเมาส์อยู่เหนือปุ่มที่มองเห็นได้ ไม่ว่าจะเป็นปุ่ม Vanilla หรือปุ่มที่กำหนดเอง

### Is Any Element Hovered

**ตัวระบุ:** `fancymenu_visibility_requirement_is_any_element_hovered`

เป็นจริงเมื่อเมาส์อยู่เหนือองค์ประกอบใด ๆ ที่มองเห็นได้ ไม่จำกัดเฉพาะปุ่ม

### Is Any Screen Open

**ตัวระบุ:** `is_any_screen_open`

เป็นจริงเมื่อมีเมนูใด ๆ เปิดอยู่ เช่น เมนูหยุดเกมหรือช่องเก็บของ จะไม่เป็นจริงเมื่อกำลังเล่นโดยไม่มีเมนูเปิดอยู่

### Is Button Active

**ตัวระบุ:** `fancymenu_visibility_requirement_is_button_active`

เป็นจริงเมื่อปุ่มคลิกได้

- ค่า: [ID องค์ประกอบ](/element-identifiers) ของปุ่ม คลิกขวาที่ปุ่มในตัวแก้ไขแล้วคลิก **คัดลอก ID องค์ประกอบ**

### Is Customization Menu Bar Visible

**ตัวระบุ:** `is_customization_menu_bar_visible`

เป็นจริงเมื่อแถบเมนูของ FancyMenu แสดงอยู่ จะไม่เป็นจริงในโหมด Modpack หรือเมื่อปิดแถบเมนู

### Is Element Focused

**ตัวระบุ:** `is_element_focused`

เป็นจริงเมื่อองค์ประกอบได้รับโฟกัส ปุ่มและแถบเลื่อนจะได้รับโฟกัสเมื่อคลิก หรือเมื่อเลื่อนไปหาโดยใช้ปุ่มลูกศรหรือ `Tab` การเลื่อนไปหาโดยใช้ปุ่มจะไม่นับว่าเมาส์ชี้อยู่เหนือองค์ประกอบ ดังนั้นให้ใส่ข้อกำหนดนี้และ **Is Element Hovered** ไว้ใน [กลุ่ม Or](#combining-requirements) เพื่อรองรับผู้เล่นที่ใช้แป้นพิมพ์

- ค่า: [ID องค์ประกอบ](/element-identifiers) เช่น `mc_titlescreen_multiplayer_button`

### Is Element Hovered

**ตัวระบุ:** `fancymenu_visibility_requirement_is_element_hovered`

เป็นจริงเมื่อเมาส์อยู่เหนือองค์ประกอบ องค์ประกอบนั้นต้องมองเห็นได้

- ค่า: [ID องค์ประกอบ](/element-identifiers) เช่น `mc_titlescreen_multiplayer_button` สำหรับปุ่ม Multiplayer บนหน้าจอไตเติล คลิกขวาที่องค์ประกอบในตัวแก้ไขแล้วคลิก **คัดลอก ID องค์ประกอบ** เพื่อคัดลอก ID

### Is Element Scrolled to End

**ตัวระบุ:** `is_scroll_area_scrolled_to_end`

เป็นจริงเมื่อเลื่อน [พื้นที่เลื่อนได้](/scrollable-areas) หรือองค์ประกอบข้อความลงจนสุดแล้ว องค์ประกอบที่ไม่มีเนื้อหาให้เลื่อนจะถือว่าเลื่อนถึงท้ายแล้ว เหมาะสำหรับปุ่ม **ยอมรับ** ที่ใช้งานได้หลังจากผู้เล่นเลื่อนอ่านกฎจนจบเท่านั้น

- ค่า: [ID องค์ประกอบ](/element-identifiers) ของพื้นที่เลื่อนได้หรือองค์ประกอบข้อความ

### Is GUI Scale

**ตัวระบุ:** `fancymenu_loading_requirement_is_gui_scale`

เป็นจริงเมื่อสเกล GUI ของ Minecraft ตรงกับค่าที่กำหนด

- ค่า: ตัวเลข เช่น `2` เพื่อกำหนดให้ตรงกับสเกลนั้นพอดี, `>2` เพื่อกำหนดให้มากกว่า 2 หรือ `<4` เพื่อกำหนดให้น้อยกว่า 4 ใช้ทศนิยมได้ด้วย เช่น `<3.5`
- แยกหลายเงื่อนไขด้วยเครื่องหมายจุลภาค ตัวเลขธรรมดาต้องตรงกับอย่างน้อยหนึ่งค่า เช่น `2,3` ส่วนเงื่อนไข `>` และ `<` ทุกข้อจะต้องเป็นจริง เช่น `>1,<4`

### Is Key Pressed

**ตัวระบุ:** `is_key_pressed`

เป็นจริงขณะที่กดปุ่มค้างไว้ หากต้องการเรียกใช้การทำงานเพียงครั้งเดียวต่อการกดปุ่ม ให้ใช้ตัวรับฟัง [**On Keyboard Key Pressed**](/listeners#on-keyboard-key-pressed) แทน

- ค่า: คลิก **เปลี่ยนปุ่ม** ใน **การเลือกปุ่ม** แล้วกดปุ่มที่ต้องการ

### Is Layout Enabled

**ตัวระบุ:** `fancymenu_visibility_requirement_is_layout_enabled`

เป็นจริงเมื่อเปิดใช้เลย์เอาต์

- ค่า: ชื่อเลย์เอาต์ เช่น `winter_title_screen`

### Is MC Debug Overlay Enabled

**ตัวระบุ:** `is_debug_overlay_enabled`

เป็นจริงเมื่อหน้าจอดีบัก F3 แสดงอยู่ จะไม่เป็นจริงเมื่อซ่อน HUD ด้วย F1

### Is Modpack Mode Enabled

**ตัวระบุ:** `is_modpack_mode_enabled`

เป็นจริงเมื่อเปิดโหมด Modpack ของ FancyMenu

### Is Screen Title

**ตัวระบุ:** `is_menu_title`

เป็นจริงเมื่อชื่อหน้าจอที่เปิดอยู่ตรงกับค่าที่กำหนด เช่น “ตัวเลือก” หรือ “เมนูเกม” นี่คือชื่อที่ผู้เล่นเห็น ไม่ใช่ [ตัวระบุหน้าจอ](/screen-identifiers)

- ค่า: ข้อความชื่อหน้าจอหรือคีย์การแปล เช่น `options.title` หน้าต่างค่าจะแสดงทั้งสองอย่างสำหรับหน้าจอที่คุณกำลังแก้ไข และแนะนำคีย์การแปลให้ด้วย
- คีย์การแปลใช้ได้กับทุกภาษา ส่วนข้อความชื่อหน้าจอต้องตรงกันทุกตัวอักษร

## เรียลไทม์

ข้อกำหนดเหล่านี้ตรวจสอบนาฬิกาของคอมพิวเตอร์ผู้เล่น หากระบุหลายค่าให้คั่นด้วยเครื่องหมายจุลภาค โดยต้องตรงกับค่าใดค่าหนึ่ง

### Is Real Time Day

**ตัวระบุ:** `fancymenu_visibility_requirement_is_realtime_day`

เป็นจริงในวันที่กำหนดของเดือน

- ค่า: `1` ถึง `31` เช่น `24,25,26`

### Is Real Time Hour

**ตัวระบุ:** `fancymenu_visibility_requirement_is_realtime_hour`

เป็นจริงในช่วงเวลาที่กำหนด

- ค่า: `0` ถึง `23` เช่น `20,21,22,23` สำหรับช่วงเย็น

### Is Real Time Minute

**ตัวระบุ:** `fancymenu_visibility_requirement_is_realtime_minute`

เป็นจริงในนาทีที่กำหนดของชั่วโมง

- ค่า: `0` ถึง `59`

### Is Real Time Month

**ตัวระบุ:** `fancymenu_visibility_requirement_is_realtime_month`

เป็นจริงในเดือนที่กำหนด

- ค่า: `1` (มกราคม) ถึง `12` (ธันวาคม) เช่น `12` สำหรับช่วงคริสต์มาส

### Is Real Time Second

**ตัวระบุ:** `fancymenu_visibility_requirement_is_realtime_second`

เป็นจริงในวินาทีที่กำหนดของนาที

- ค่า: `0` ถึง `59`

### Is Real Time Week Day

**ตัวระบุ:** `fancymenu_visibility_requirement_is_realtime_week_day`

เป็นจริงในวันที่กำหนดของสัปดาห์

- ค่า: `1` (วันอาทิตย์) ถึง `7` (วันเสาร์) เช่น `1,7` สำหรับวันสุดสัปดาห์

### Is Real Time Year

**ตัวระบุ:** `fancymenu_visibility_requirement_is_realtime_year`

เป็นจริงในปีที่กำหนด

- ค่า: ปีเต็ม เช่น `2027`

## ระบบ

### File/Folder Exists

**ตัวระบุ:** `fancymenu_loading_requirement_file_exists`

เป็นจริงเมื่อมีไฟล์หรือโฟลเดอร์อยู่

- ค่า: เส้นทางภายในโฟลเดอร์เกม เช่น `config/mymodpack/welcome_seen.txt` เส้นทางที่ขึ้นต้นด้วย `.minecraft/` จะอ้างอิงไปยังโฟลเดอร์ `.minecraft` เริ่มต้น

### Is Internet Connection Available

**ตัวระบุ:** `is_internet_connection_available`

เป็นจริงเมื่อคอมพิวเตอร์เชื่อมต่ออินเทอร์เน็ต FancyMenu จะตรวจสอบเป็นระยะ ๆ ในเบื้องหลัง

### Is OS Linux

**ตัวระบุ:** `fancymenu_loading_requirement_is_os_linux`

เป็นจริงบน Linux หรือในทางเทคนิคคือทุกระบบที่ไม่ใช่ Windows หรือ macOS

### Is OS macOS

**ตัวระบุ:** `fancymenu_loading_requirement_is_os_macos`

เป็นจริงบน macOS

### Is OS Windows

**ตัวระบุ:** `fancymenu_loading_requirement_is_os_windows`

เป็นจริงบน Windows

### Scheduler Is Running

**ตัวระบุ:** `fancymenu_visibility_requirement_is_scheduler_running`

เป็นจริงขณะที่ [ตัวจัดตารางเวลา](/schedulers) กำลังทำงาน

- ค่า: ตัวระบุของตัวจัดตารางเวลา เช่น `my_scheduler`

### Is Window Width

- ค่า: ความกว้าง เช่น `1920` หากระบุหลายค่าให้คั่นด้วยเครื่องหมายจุลภาค โดยต้องตรงกับค่าใดค่าหนึ่ง

### Is Window Width Bigger Than

เป็นจริงเมื่อหน้าต่างกว้างกว่าค่าที่กำหนด

## โลก

ข้อกำหนดเหล่านี้จะไม่เป็นจริงเมื่อยังไม่ได้โหลดโลก **Is Player In Structure** และ **Is In Active Raid Area** ต้องติดตั้ง FancyMenu บนเซิร์ฟเวอร์ ในโหมดเล่นคนเดียวจะใช้ได้เสมอ

### Has Player Absorption Hearts

**ตัวระบุ:** `has_player_absorption_hearts`

เป็นจริงเมื่อผู้เล่นมีหัวใจดูดซับสีทอง

### Has Player Permission Level

**ตัวระบุ:** `fancymenu_loading_requirement_has_player_permission_level`

เป็นจริงเมื่อผู้เล่นมีระดับสิทธิ์อย่างน้อยตามที่กำหนดในโลกหรือบนเซิร์ฟเวอร์ เช่น เป็นผู้ดูแลระบบ

- ค่า: `0` ถึง `4` โดย `0` เป็นจริงเสมอ, `2` เพียงพอสำหรับคำสั่งอย่าง `/gamemode` และ `4` คือระดับที่คำสั่ง `/op` มอบให้

### Is Adventure

**ตัวระบุ:** `fancymenu_visibility_requirement_is_adventure`

เป็นจริงเมื่อผู้เล่นอยู่ในโหมดผจญภัย

### Is Any Effect Active

**ตัวระบุ:** `is_any_effect_active`

เป็นจริงเมื่อผู้เล่นมีเอฟเฟกต์ใด ๆ เช่น ความเร็วหรือพิษ

### Is Attack Strength Weakened

**ตัวระบุ:** `is_attack_strength_weakened`

เป็นจริงเมื่อการโจมตีของผู้เล่นยังชาร์จไม่เต็ม ซึ่งจะเห็นได้จากตัวบ่งชี้การโจมตี

### Is Block/Item In Tag

**ตัวระบุ:** `is_in_tag`

เป็นจริงเมื่อบล็อกหรือไอเทมอยู่ในแท็กที่กำหนด เช่น `minecraft:logs` หรือ `c:tools` แท็กจะมีอยู่เฉพาะเมื่อโหลดโลกแล้ว

- ค่า: คลิก **ชนิดแท็ก** เพื่อเลือก **บล็อก** หรือ **ไอเทม** จากนั้นกรอก **คีย์บล็อก/ไอเทม** และ **แท็ก** ทั้งสองช่องจะแนะนำค่าให้ เครื่องหมาย `#` หน้าแท็กเป็นตัวเลือก
- คีย์ใช้งานได้ดีกับตัวแปรจากตัวรับฟัง เช่น `$$block_key` ตัวอย่างเช่น เพิ่มคำสั่ง IF ในสคริปต์ของตัวรับฟัง [**On Block Broke**](/listeners#on-block-broke) เพื่อแสดงข้อความแจ้งเตือนเฉพาะเมื่อขุดท่อนไม้

### Is Camera Perspective

**ตัวระบุ:** `is_camera_perspective`

เป็นจริงเมื่อกล้องอยู่ในมุมมองที่กำหนด (F5)

- ค่า: คลิกปุ่มเพื่อเลือก **มุมมองบุคคลที่หนึ่ง**, **มุมมองบุคคลที่สาม** หรือ **มุมมองด้านหน้า**

### Is Clear Weather

**ตัวระบุ:** `is_clear_weather`

เป็นจริงเมื่อไม่มีฝนหรือพายุฝนฟ้าคะนอง

### Is Creative

**ตัวระบุ:** `fancymenu_visibility_requirement_is_creative`

เป็นจริงเมื่อผู้เล่นอยู่ในโหมดสร้างสรรค์

### Is Cursor Holding Inventory Item

**ตัวระบุ:** `is_cursor_holding_inventory_item`

เป็นจริงเมื่อเคอร์เซอร์เมาส์ถือไอเทมอยู่ในหน้าช่องเก็บของ

### Is Difficulty

**ตัวระบุ:** `is_difficulty`

เป็นจริงเมื่อโลกมีระดับความยากตามที่กำหนด

- ค่า: `peaceful`, `easy`, `normal` หรือ `hard`

### Is Effect Active

**ตัวระบุ:** `is_effect_active`

เป็นจริงเมื่อผู้เล่นมีเอฟเฟกต์ตามที่กำหนด

- ค่า: คีย์ของเอฟเฟกต์ เช่น `minecraft:speed` ช่องนี้จะแนะนำเอฟเฟกต์เมื่อคุณอยู่ในโลก

### Is Entity Nearby

**ตัวระบุ:** `is_entity_nearby`

เป็นจริงเมื่อมีเอนทิตีชนิดที่กำหนดอยู่ใกล้ผู้เล่น

- ค่า: **คีย์รีจิสทรีเอนทิตี** เช่น `minecraft:creeper` และ **ระยะตรวจสอบเป็นบล็อก** เช่น `10` ช่องคีย์จะแนะนำเอนทิตีเมื่อคุณอยู่ในโลก

### Is Game Mode

**ตัวระบุ:** `is_gamemode`

เป็นจริงเมื่อผู้เล่นอยู่ในโหมดเกมที่กำหนด

- ค่า: `survival`, `creative`, `adventure` หรือ `spectator`

### Is Hardcore

**ตัวระบุ:** `is_hardcore`

เป็นจริงในโลกฮาร์ดคอร์

### Is Hotbar Slot Selected

**ตัวระบุ:** `is_hotbar_slot_active`

เป็นจริงเมื่อเลือกช่องแถบไอเทมด่วนที่กำหนด

- ค่า: `0` (ช่องซ้ายสุด) ถึง `8`

### Is In Active Raid Area

**ตัวระบุ:** `is_in_active_raid_area`

เป็นจริงเมื่อผู้เล่นอยู่ในพื้นที่ที่กำลังมีการบุกโจมตี ซึ่งจะแสดงแถบการบุกโจมตี ต้องติดตั้ง FancyMenu บนเซิร์ฟเวอร์

### Is Inventory Slot Filled

**ตัวระบุ:** `is_inventory_slot_filled`

เป็นจริงเมื่อช่องในช่องเก็บของของผู้เล่นมีไอเทม

- ค่า: หมายเลขช่อง `0` ถึง `8` คือแถบไอเทมด่วน ส่วน `9` ถึง `35` คือช่องเก็บของที่เหลือ

### Is Item Hovered In Inventory

**ตัวระบุ:** `is_item_hovered_in_inventory`

เป็นจริงเมื่อเมาส์อยู่เหนือไอเทมในหน้าช่องเก็บของ เช่น ช่องเก็บของของผู้เล่นหรือหีบ

### Is Multiplayer

**ตัวระบุ:** `fancymenu_loading_requirement_is_multiplayer`

เป็นจริงเมื่อผู้เล่นอยู่บนเซิร์ฟเวอร์

### Is Player Creative Flying

**ตัวระบุ:** `is_player_creative_flying`

เป็นจริงเมื่อผู้เล่นบินอยู่ในโหมดสร้างสรรค์

### Is Player Flying With Elytra

**ตัวระบุ:** `is_player_flying_with_elytra`

เป็นจริงเมื่อผู้เล่นร่อนด้วยปีกเอลิทรา

## อื่น ๆ

### Is Game Language

**ตัวระบุ:** `fancymenu_loading_requirement_is_language`

เป็นจริงเมื่อ Minecraft ใช้ภาษาที่กำหนด

- ค่า: รหัสภาษา เช่น `en_us` หรือ `de_de` ช่องนี้จะแนะนำภาษาทั้งหมด

### Is Mod Loaded

**ตัวระบุ:** `fancymenu_loading_requirement_is_mod_loaded`

เป็นจริงเมื่อติดตั้งม็อดที่กำหนด

- ค่า: ID ของม็อด เช่น `jei` ช่องนี้จะแนะนำ ID ของม็อดที่ติดตั้ง หากระบุหลาย ID ให้คั่นด้วยเครื่องหมายจุลภาค โดยต้องติดตั้งม็อดทั้งหมด `optifine` ใช้ตรวจสอบ OptiFine

### Is Number

**ตัวระบุ:** `fancymenu_visibility_requirement_is_number`

ใช้เปรียบเทียบตัวเลขสองค่า ใส่ตัวแทนข้อความหรือตัวแปรในช่องได้ เช่น `$$coins`

- **โหมดเปรียบเทียบ**: **เท่ากับ**, **มากกว่า**, **น้อยกว่า**, **มากกว่าหรือเท่ากับ** หรือ **น้อยกว่าหรือเท่ากับ**
- **ตัวเลข**: ตัวเลขที่ต้องการตรวจสอบ เช่น `$$coins`
- **เปรียบเทียบกับตัวเลข**: ตัวเลขที่ใช้เปรียบเทียบ เช่น `100`

ใช้เลขทศนิยมได้ เช่น `2.5` หากช่องใดไม่ใช่ตัวเลข ข้อกำหนดจะไม่เป็นจริง

### Is Resource Pack Enabled

**ตัวระบุ:** `is_resource_pack_enabled`

เป็นจริงเมื่อเปิดใช้รีซอร์สแพ็ก

- ค่า: ชื่อแพ็กตามที่แสดงในหน้าจอรีซอร์สแพ็ก เช่น `Programmer Art` หรือ ID ของแพ็ก การใช้ตัวพิมพ์ใหญ่หรือเล็กไม่มีผล

### Is Rinku Loaded

เป็นจริงเมื่อติดตั้งม็อด [Rinku](https://modrinth.com/mod/rinku) องค์ประกอบ [Browser](/elements#browser) และ[ประเภทวิดีโอที่ใช้ Rinku แบบเก่า](/video#requirements) ต้องใช้ม็อดนี้

### Is Server IP

**ตัวระบุ:** `fancymenu_visibility_requirement_is_server_ip`

เป็นจริงเมื่อผู้เล่นอยู่บนเซิร์ฟเวอร์ที่กำหนด

- ค่า: ที่อยู่เซิร์ฟเวอร์ เช่น `play.example.net` หากระบุพอร์ต เช่น `play.example.net:25566` พอร์ตนั้นก็ต้องตรงกันด้วย

### Is Server Online

**ตัวระบุ:** `fancymenu_loading_requirement_is_server_online`

เป็นจริงเมื่อเซิร์ฟเวอร์ออนไลน์ FancyMenu จะส่ง ping ไปตรวจสอบในเบื้องหลังประมาณทุก 30 วินาที ดังนั้นหลังเริ่มเกมอาจต้องรอสักครู่

- ค่า: ที่อยู่เซิร์ฟเวอร์ เช่น `play.example.net`

### Is Text

**ตัวระบุ:** `fancymenu_visibility_requirement_is_text`

ใช้เปรียบเทียบข้อความสองข้อความ ใส่ตัวแทนข้อความหรือตัวแปรในช่องได้ เช่น `$$key_name`

- **โหมดเปรียบเทียบ**: **เท่ากับ**, **มีข้อความ**, **ขึ้นต้นด้วย** หรือ **ลงท้ายด้วย**
- **ข้อความ**: ข้อความที่ต้องการตรวจสอบ
- **เปรียบเทียบกับข้อความ**: ข้อความที่ใช้เปรียบเทียบ

ตัวพิมพ์ใหญ่และตัวพิมพ์เล็กมีผล

### Is Variable Value (FM Variable)

**ตัวระบุ:** `fancymenu_visibility_requirement_is_variable_value`

เป็นจริงเมื่อตัวแปร [ตัวใดตัวหนึ่งของคุณ](/variables) มีค่าตามที่กำหนด

- **ชื่อตัวแปร**: ชื่อตัวแปรโดยไม่รวม `$$` ช่องนี้จะแนะนำตัวแปรของคุณ
- **ค่าตัวแปรที่ต้องการตรวจสอบ**: ค่า เช่น `on` ต้องตรงกับค่าทั้งหมด รวมถึงตัวพิมพ์ใหญ่และตัวพิมพ์เล็ก

จะไม่เป็นจริงเมื่อตัวแปรไม่มีอยู่ หากเป็นตัวแปรรายการ ระบบจะเปรียบเทียบอาร์เรย์ JSON ของทุกรายการ เช่น `["apple","banana"]` หากต้องการตรวจสอบรายการใดรายการหนึ่ง ให้ใช้ **List Contains Entry (FM Variable)**

### List Contains Entry (FM Variable)

**ตัวระบุ:** `list_contains_entry`

เป็นจริงเมื่อตัวแปรรายการ [มีรายการที่กำหนด](/variables#text-and-list-variables)

- **ชื่อตัวแปรรายการ**: ชื่อรายการโดยไม่รวม `$$` ช่องนี้จะแนะนำตัวแปรรายการของคุณ และเตือนเมื่อคุณพิมพ์ชื่อตัวแปรข้อความ
- **รายการที่ต้องการค้นหา**: รายการที่ต้องการค้นหา ต้องตรงกับรายการทั้งหมด ไม่ใช่เพียงบางส่วน
- **ไม่สนใจตัวพิมพ์เล็กใหญ่**: เมื่อเปิดใช้ `Apple` จะตรงกับ `apple` ด้วย

จะไม่เป็นจริงเมื่อไม่มีรายการนั้น

### Mouse Button Is Pressed

**ตัวระบุ:** `mouse_click`

เป็นจริงขณะที่กดปุ่มเมาส์ค้างไว้ หากต้องการเรียกใช้การทำงานเพียงครั้งเดียวต่อการคลิก ให้ใช้ตัวรับฟัง [**On Mouse Button Clicked**](/listeners#on-mouse-button-clicked) แทน

- ค่า: `left` หรือ `right`

### Only Once Per Session

**ตัวระบุ:** `once_per_session`

เป็นจริงในครั้งแรกที่มีการตรวจสอบ จากนั้นจะไม่เป็นจริงอีกจนกว่าจะเริ่มเกมใหม่ สำเนาแต่ละชุดจะนับแยกกัน

หากต้องการให้องค์ประกอบแสดงเพียงครั้งเดียวต่อเซสชันเกม ตัวเลือก [**โหลดเพียงครั้งเดียวต่อเซสชัน**](/element-visibility#load-once-per-session) ขององค์ประกอบจะใช้งานง่ายกว่า โดยองค์ประกอบจะยังคงอยู่จนกว่าจะเปิดหน้าจอใหม่
