# ตัวยึดตำแหน่ง

ตัวยึดตำแหน่งคือรหัสสั้น ๆ ที่ FancyMenu จะแทนที่ด้วยค่าปัจจุบัน เช่น ชื่อผู้เล่น เวลา หรือจำนวนผู้เล่นในเซิร์ฟเวอร์ ใช้ได้กับข้อความขององค์ประกอบ ป้ายปุ่ม คำแนะนำเครื่องมือ ค่าของการกระทำและข้อกำหนด รวมถึงข้อความอื่น ๆ ส่วนใหญ่ที่คุณพิมพ์ได้

<img width="800" alt="เพิ่มตัวยึดตำแหน่งชื่อผู้เล่นลงในองค์ประกอบข้อความในตัวแก้ไขเลย์เอาต์: ตัวยึดตำแหน่งในตัวแก้ไขข้อความ หมวดผู้เล่น และข้อความทักทายผู้เล่นด้วยชื่อ" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/placeholders_add.gif?raw=true">

> [!TIP]
> [ตัวแปร](/variables)ของคุณเองก็ใช้ในข้อความเดียวกันได้ โดยใส่ `$$` ตามด้วยชื่อ เช่น `$$coins`

# เพิ่มตัวยึดตำแหน่ง

1. เปิดข้อความในตัวแก้ไขข้อความ เช่น **เนื้อหาข้อความ** ของ[องค์ประกอบข้อความ](/text-in-menus) ช่องข้อความในหน้าต่างต่าง ๆ เช่น ค่าของการกระทำ จะมีปุ่ม **เปิดในตัวแก้ไข** อยู่ข้าง ๆ
2. คลิกตำแหน่งที่ต้องการวางตัวยึดตำแหน่ง
3. คลิก **ตัวยึดตำแหน่ง** ที่มุมขวาบนของตัวแก้ไขข้อความ
4. คลิกหมวดหมู่ หรือค้นหาด้วยชื่อ ตัวระบุ หรือคำอธิบาย ปุ่ม **ย้อนกลับ** จะพากลับไปยังหมวดหมู่ ตัวยึดตำแหน่งที่ไม่มีหมวดหมู่จะแสดงอยู่ใต้หมวดหมู่
5. เลื่อนเมาส์ไปวางบนตัวยึดตำแหน่งเพื่อดูว่าทำอะไร แล้วคลิกเพื่อเพิ่ม
6. แทนที่ค่าตัวอย่าง เช่น ID ของม็อดใน **เวอร์ชันม็อด**

ข้อความที่ตัวแก้ไขไม่มีปุ่ม **ตัวยึดตำแหน่ง** จะไม่รองรับตัวยึดตำแหน่ง

# วิธีทำงานของตัวยึดตำแหน่ง

ตัวยึดตำแหน่งมีรูปแบบดังนี้:

```
{"placeholder":"playername"}
```

ตัวยึดตำแหน่งที่มีการตั้งค่าจะเก็บค่าไว้ใน `values`:

```
{"placeholder":"modversion","values":{"modid":"fancymenu"}}
```

- ตัวระบุ เช่น `playername` แยกตัวพิมพ์เล็กและใหญ่ ตัวยึดตำแหน่งแต่ละรายการด้านล่างจะแสดงตัวระบุและค่าที่ใช้ได้
- ลำดับของค่าไม่มีผล ค่าที่ระบุว่าไม่บังคับสามารถละไว้ได้
- หาก FancyMenu แทนที่ตัวยึดตำแหน่งไม่ได้ เช่น พิมพ์ผิด ตัวยึดตำแหน่งนั้นจะคงอยู่ในข้อความตามที่คุณพิมพ์
- ตัวยึดตำแหน่งจะแสดงผลเป็นข้อความเสมอ หากไม่มีอะไรให้แสดง จะใช้ค่าแทน เช่น `0`, `0.0`, `---` หรือไม่แสดงอะไรเลย
- [รหัสจัดรูปแบบ](/text-formatting)ใช้ร่วมกับตัวยึดตำแหน่งได้: `&6{"placeholder":"playername"}` จะแสดงชื่อเป็นสีทอง

> [!IMPORTANT]
> ตัวยึดตำแหน่งดูเหมือน JSON แต่ไม่ใช่ JSON อย่านำไปจัดรูปแบบหรือตรวจสอบด้วยเครื่องมือ JSON เพราะตัวยึดตำแหน่งที่ซ้อนอยู่ในตัวยึดตำแหน่งอื่นไม่ใช่ JSON ที่ถูกต้อง

## ตัวยึดตำแหน่งซ้อนกัน

ค่าต่าง ๆ สามารถมีตัวยึดตำแหน่งอื่นและ[ตัวแปร](/variables#showing-variables-in-text)ได้ FancyMenu จะแทนที่รายการด้านในก่อน ไม่จำเป็นต้อง escape เครื่องหมายคำพูดภายในค่า

ตัวอย่างนี้แปลง RAM สูงสุดจาก MB เป็น GB:

```
{"placeholder":"calc","values":{"decimal":"true","expression":"{"placeholder":"maxram"} / 1024"}}
```

ตัวอย่างนี้แสดงตัวแปร `rank` เป็นตัวพิมพ์ใหญ่:

```
{"placeholder":"uppercase_text","values":{"text":"$$rank"}}
```

หากตัวยึดตำแหน่งแสดงข้อความที่มีตัวยึดตำแหน่งอยู่ด้วย เช่น ข้อความจากไฟล์ที่อ่านด้วย [**ข้อความจากไฟล์**](#file-text) FancyMenu จะแทนที่ตัวยึดตำแหน่งเหล่านั้นด้วย

# ข้อมูลที่ควรรู้

- ตัวยึดตำแหน่งอัปเดตโดยอัตโนมัติ FancyMenu จะเก็บข้อความที่แทนที่แล้วไว้ 30 มิลลิวินาที ก่อนแทนที่ตัวยึดตำแหน่งอีกครั้ง เปลี่ยนค่านี้ได้ที่ **ระยะเวลาแคชตัวยึดตำแหน่ง [MS]** ใน **แถบเมนู -> การปรับแต่ง -> การตั้งค่า** ค่า `0` จะทำการแทนที่ทุกเฟรม ซึ่งใช้ประสิทธิภาพมากขึ้น
- ตัวยึดตำแหน่งที่อ่านเว็บไซต์ ไฟล์ หรือเซิร์ฟเวอร์ เช่น **ข้อความจากเว็บ** หรือ **สถานะเซิร์ฟเวอร์** จะโหลดอยู่เบื้องหลัง ระหว่างรอจะไม่แสดงอะไรหรือแสดงค่าแทน
- ใน[การกระทำ](/action-scripts) ตัวยึดตำแหน่งจะรับค่าปัจจุบัน ณ เวลาที่การกระทำทำงาน
- ตัวยึดตำแหน่งเกี่ยวกับโลก หน้าจอ และองค์ประกอบจะทำงานบนเธรดหลักของเกมเท่านั้น หากใช้ใน [Ticker](/elements#ticker) ที่ทำงานเบื้องหลัง (แบบอะซิงโครนัส) FancyMenu จะแสดงข้อผิดพลาดแทน
- **ตัวเลขสุ่ม** จะให้ตัวเลขใหม่ทุกครั้งที่ข้อความอัปเดต หากต้องการเก็บค่าไว้ ให้บันทึกลงใน[ตัวแปร](/variables)ด้วย [**กำหนดค่าตัวแปร (FM Variable)**](/action-scripts#set-variable-value-fm-variable)

> [!CAUTION]
> ตัวยึดตำแหน่งอย่าง **ตัวแยกวิเคราะห์ JSON**, **ข้อความจากไฟล์** และ **เนื้อหาในคลิปบอร์ด** สามารถอ่านไฟล์ในโฟลเดอร์เกมและคลิปบอร์ดของคุณได้ เมื่อใช้ร่วมกับการกระทำที่ติดต่อเว็บไซต์ เลย์เอาต์อาจส่งข้อมูลเหล่านั้นออกไปได้ ใช้เฉพาะเลย์เอาต์ที่คุณเชื่อถือเท่านั้น

# ตัวยึดตำแหน่งทั้งหมด

ตัวยึดตำแหน่งทั้งหมดที่ FancyMenu มี หมวดใหญ่ **ขั้นสูง** และ **โลก** ในเมนูตัวยึดตำแหน่งแบ่งเป็นกลุ่มย่อยไว้ที่นี่

## ตัวแปรและรายการ

รายการเหล่านี้อยู่ในหมวด **ขั้นสูง** ดูวิธีสร้างตัวแปรและรายการได้ที่[ตัวแปร](/variables)

### รับค่าตัวแปร (FM Variable)

**ตัวระบุ:** `getvariable`

ค่าของตัวแปรรายการหนึ่ง หากตัวแปรว่างหรือไม่มีอยู่ จะให้ค่า `0` จึงเหมาะกับตัวเลข รายการจะแสดงค่าทั้งหมดเป็นอาร์เรย์ JSON เช่น `["Steve","Alex"]`

- `name`: ชื่อตัวแปร โดยไม่ต้องใส่ `$$`

```
{"placeholder":"getvariable","values":{"name":"clicks"}}
```

### รับรายการในลิสต์ (FM Variable)

**ตัวระบุ:** `list_get`

ค่าหนึ่งรายการจากตัวแปรชนิดลิสต์

- `name`: ชื่อลิสต์
- `index`: ตำแหน่งของรายการ รายการแรกคือ `0` ส่วนตัวเลขติดลบจะนับจากท้ายลิสต์ ดังนั้น `-1` คือรายการสุดท้าย
- `fallback` (ไม่บังคับ): ค่าที่ให้เมื่อไม่มีรายการ ณ ตำแหน่งนั้น หรือไม่มีลิสต์ชื่อนี้ ค่าเริ่มต้นคือข้อความว่าง

```
{"placeholder":"list_get","values":{"name":"tips","index":"0","fallback":"No tips yet"}}
```

### ขนาดลิสต์ (FM Variable)

**ตัวระบุ:** `list_size`

จำนวนรายการในลิสต์ หากไม่มีลิสต์ชื่อนี้จะได้ `0`

- `name`: ชื่อลิสต์

```
{"placeholder":"list_size","values":{"name":"tips"}}
```

### ดัชนีของรายการในลิสต์ (FM Variable)

**ตัวระบุ:** `list_index_of`

ดัชนีของรายการแรกที่ตรงกับ `value` ทั้งหมด หรือ `-1` หากไม่มีค่านั้นในลิสต์

- `name`: ชื่อลิสต์
- `value`: รายการที่ต้องการค้นหา
- `ignore_case` (ไม่บังคับ): `true` จะทำให้ `Apple` ตรงกับ `apple` ค่าเริ่มต้นคือ `false`

```
{"placeholder":"list_index_of","values":{"name":"read_news","value":"news_42","ignore_case":"false"}}
```

### รวมรายการในลิสต์ (FM Variable)

**ตัวระบุ:** `list_join`

รวมรายการทั้งหมดในลิสต์เป็นข้อความเดียว หากไม่มีลิสต์ชื่อนี้จะได้ข้อความว่าง

- `name`: ชื่อลิสต์
- `separator` (ไม่บังคับ): ข้อความคั่นระหว่างรายการ `\n` คือการขึ้นบรรทัดใหม่ ค่าเริ่มต้นคือ `, `

```
{"placeholder":"list_join","values":{"name":"tips","separator":"\n"}}
```

## คณิตศาสตร์

รายการเหล่านี้อยู่ในหมวด **ขั้นสูง** ตัวเลขทศนิยมใช้จุด เช่น `2.5`

### เครื่องคิดเลข

**ตัวระบุ:** `calc`

คำนวณนิพจน์ทางคณิตศาสตร์ เช่น `2 + 3 * 4`

- `expression`: นิพจน์ที่ต้องการคำนวณ
- `decimal` (ไม่บังคับ): `false` จะปัดผลลัพธ์เป็นจำนวนเต็ม ค่าเริ่มต้นคือ `true` ซึ่งให้ผลลัพธ์อย่าง `14.0`

```
{"placeholder":"calc","values":{"decimal":"false","expression":"{"placeholder":"usedram"} * 100 / {"placeholder":"maxram"}"}}
```

| ในนิพจน์ | การทำงาน |
|---|---|
| `+` `-` `*` `/` | บวก ลบ คูณ หาร |
| `^` | ยกกำลัง เช่น `2 ^ 3` ได้ 8 |
| `%` | เศษจากการหาร เช่น `7 % 3` ได้ 1 |
| `( )` | จัดกลุ่มนิพจน์ เช่น `(2 + 3) * 4` |
| `pi`, `e` | ค่าคงที่ π และ e |
| `abs(x)` | ค่าสัมบูรณ์ของตัวเลข |
| `sqrt(x)`, `cbrt(x)` | รากที่สองและรากที่สาม |
| `pow(x, y)` | x ยกกำลัง y |
| `floor(x)`, `ceil(x)` | ปัดลงและปัดขึ้น |
| `sin(x)`, `cos(x)`, `tan(x)`, `cot(x)` | ตรีโกณมิติ โดยมุมมีหน่วยเป็นเรเดียน |
| `asin(x)`, `acos(x)`, `atan(x)` | ฟังก์ชันตรีโกณมิติผกผัน |
| `sinh(x)`, `cosh(x)`, `tanh(x)` | ฟังก์ชันไฮเพอร์โบลิก |
| `log(x)`, `log2(x)`, `log10(x)` | ลอการิทึมฐาน e, 2 และ 10 |
| `exp(x)` | e ยกกำลัง x |
| `signum(x)` | `1`, `-1` หรือ `0` เช่นเดียวกับ [**เครื่องหมาย (คณิตศาสตร์)**](#sign-math) |

### ตัวเลขสุ่ม

**ตัวระบุ:** `random_number`

จำนวนเต็มสุ่มระหว่าง `min` และ `max` ค่านี้จะเปลี่ยนทุกครั้งที่ข้อความอัปเดต

- `min`, `max`: ค่าต่ำสุดและสูงสุด

```
{"placeholder":"random_number","values":{"min":"1","max":"6"}}
```

### จำนวนที่มากกว่า

**ตัวระบุ:** `maxnum`

ค่าที่มากกว่าจากตัวเลขสองจำนวน

- `first`, `second`: ตัวเลขที่นำมาเปรียบเทียบ

```
{"placeholder":"maxnum","values":{"first":"$$score","second":"$$best_score"}}
```

### จำนวนที่น้อยกว่า

**ตัวระบุ:** `minnum`

ค่าที่น้อยกว่าจากตัวเลขสองจำนวน

- `first`, `second`: ตัวเลขที่นำมาเปรียบเทียบ

```
{"placeholder":"minnum","values":{"first":"10","second":"15"}}
```

### ค่าสัมบูรณ์

**ตัวระบุ:** `absnum`

ตัวเลขที่ตัดเครื่องหมายลบออก เช่น `-10.5` จะได้ `10.5`

- `num`: ตัวเลข

```
{"placeholder":"absnum","values":{"num":"-10.5"}}
```

### กลับเครื่องหมายตัวเลข

**ตัวระบุ:** `negnum`

เปลี่ยนจำนวนบวกเป็นลบ เช่น `10.5` จะได้ `-10.5` ส่วนศูนย์และจำนวนลบจะคงเดิม

- `num`: ตัวเลข

```
{"placeholder":"negnum","values":{"num":"10.5"}}
```

### ปัดเศษ (คณิตศาสตร์)

**ตัวระบุ:** `math_round`

ปัดเศษตัวเลข `2.5` จะปัดขึ้นเป็น `3`

- `num`: ตัวเลข
- `decimals` (ไม่บังคับ): จำนวนตำแหน่งทศนิยมที่ต้องการเก็บ เช่น `2` จะเปลี่ยน `3.14159` เป็น `3.14` ค่า `0`, `-1` หรือเว้นว่างจะปัดเป็นจำนวนเต็ม

```
{"placeholder":"math_round","values":{"num":"3.14159","decimals":"2"}}
```

### ปัดลง (คณิตศาสตร์)

**ตัวระบุ:** `math_floor`

ปัดตัวเลขลงเป็นจำนวนเต็ม เช่น `3.7` ได้ `3` และ `-3.2` ได้ `-4`

- `num`: ตัวเลข

```
{"placeholder":"math_floor","values":{"num":"3.7"}}
```

## ข้อความ

รายการเหล่านี้อยู่ในหมวด **ขั้นสูง**

### เปลี่ยนข้อความเป็นตัวพิมพ์ใหญ่

- `text`: ข้อความ

```
{"placeholder":"trim_text","values":{"text":"  Welcome!  "}}
```

### ตัดข้อความ

**ตัวระบุ:** `crop_text`

ลบจำนวนอักขระที่กำหนดจากต้นและท้ายข้อความ หากตัด `hello world` ด้านละ 1 อักขระ จะได้ `ello worl`

- `text`: ข้อความ
- `remove_from_start`: จำนวนอักขระที่จะลบจากต้นข้อความ
- `remove_from_end`: จำนวนอักขระที่จะลบจากท้ายข้อความ

```
{"placeholder":"crop_text","values":{"text":"hello world","remove_from_start":"1","remove_from_end":"1"}}
```

### แยกข้อความ

**ตัวระบุ:** `split_text`

แยกข้อความแล้วเลือกส่วนหนึ่ง เช่น แยก `Steve,Alex,Notch` ด้วย `,` จะได้ `Alex` เมื่อเลือกส่วนที่ `1`

- `input`: ข้อความ
- `regex`: จุดที่ใช้แยก โดยระบุเป็นนิพจน์ปกติ อักขระอย่าง `.`, `|` และ `?` ต้องมี `\` นำหน้า เช่น `\.`
- `max_parts` (ไม่บังคับ): จำนวนส่วนสูงสุดที่จะแยก ค่าเริ่มต้น `-1` จะแยกทุกตำแหน่งที่ตรงกัน
- `split_index`: ส่วนที่ต้องการรับ ส่วนแรกคือ `0`

```
{"placeholder":"split_text","values":{"input":"Steve,Alex,Notch","regex":",","max_parts":"-1","split_index":"1"}}
```

### แทนที่ข้อความ

**ตัวระบุ:** `replace_text`

แทนที่บางส่วนของข้อความ: หากแทนที่ `World` ใน `Hello World!` ด้วย `FancyMenu` จะได้ `Hello FancyMenu!`

- `text`: ข้อความ
- `search`: ข้อความที่ต้องการค้นหา
- `replacement` (ไม่บังคับ): ข้อความที่จะใช้แทน ค่าเริ่มต้นเป็นข้อความว่าง ซึ่งจะลบส่วนที่พบ
- `use_regex` (ไม่บังคับ): `true` จะทำให้ `search` เป็นนิพจน์ปกติ ในกรณีนี้ `$1`, `$2` และอื่น ๆ ใน `replacement` หมายถึงกลุ่มที่ค้นพบ ค่าเริ่มต้นคือ `false`
- `replace_all` (ไม่บังคับ): `false` จะแทนที่เฉพาะรายการแรก ค่าเริ่มต้นคือ `true`

```
{"placeholder":"replace_text","values":{"text":"Hello World!","search":"World","replacement":"FancyMenu","use_regex":"false","replace_all":"true"}}
```

### เลือกตามค่า

**ตัวระบุ:** `switch_case`

แสดงผลลัพธ์ของกรณีที่ตรงกับค่า หากตัวแปร `difficulty_level` มีค่า `2` ตัวอย่างนี้จะแสดง `Hard Mode`

- `value`: ค่าที่ต้องการตรวจสอบ
- `cases`: คู่ของค่าและผลลัพธ์ เช่น `1:Easy Mode,2:Hard Mode` ค่าและผลลัพธ์ต้องไม่มี `,` หรือ `:`
- `default` (ไม่บังคับ): ผลลัพธ์เมื่อไม่มีกรณีใดตรงกัน หากไม่กำหนด ตัวยึดตำแหน่งจะคงเดิม

```
{"placeholder":"switch_case","values":{"value":"$$difficulty_level","cases":"1:Easy Mode,2:Hard Mode","default":"Normal Mode"}}
```

### แปลข้อความ

**ตัวระบุ:** `local`

แสดงข้อความของคีย์คำแปลในภาษาปัจจุบันของเกม เช่น `Singleplayer` สำหรับ `menu.singleplayer` ใช้ได้กับคีย์ของ Minecraft ม็อด และคีย์ที่คุณสร้างเอง (ดู[การแปลภาษา](/localization))

- `key`: คีย์คำแปล

```
{"placeholder":"local","values":{"key":"menu.singleplayer"}}
```

### แปลงข้อความเป็นสตริงปลอดภัย

**ตัวระบุ:** `stringify`

แทนที่ตัวยึดตำแหน่งในข้อความ แล้วใส่ `\` หน้า `"`, `{` และ `}` ทุกตัว วิธีนี้ช่วยป้องกันไม่ให้ข้อความจากภายนอก เช่น เว็บไซต์ กลายเป็นตัวยึดตำแหน่ง

- `text`: ข้อความ

```
{"placeholder":"stringify","values":{"text":"{"placeholder":"webtext","values":{"link":"https://example.com/motd.txt"}}"}}
```

## ข้อมูลและไฟล์

รายการเหล่านี้อยู่ในหมวด **ขั้นสูง** พาธภายในเครื่องจะเริ่มจากโฟลเดอร์เกม เช่น `/config/fancymenu/assets/news.txt` และไม่สามารถออกนอกโฟลเดอร์นี้ได้ (ดู[ทรัพยากร](/resources#local-resources))

### ตัวแยกวิเคราะห์ JSON

**ตัวระบุ:** `json`

อ่านค่าจาก JSON หากมีผลลัพธ์หลายรายการ จะแสดงรายการละหนึ่งบรรทัด

- `source`: ข้อความ JSON ไฟล์ JSON ในโฟลเดอร์เกม หรือ URL ของไฟล์ JSON
- `json_path`: พาธไปยังค่า เช่น `$.name` หรือ `$.players[0].name` ดูข้อมูลเพิ่มเติมเกี่ยวกับพาธ JSON ได้ที่ [json.fancymenu.net](https://json.fancymenu.net)

```
{"placeholder":"json","values":{"source":"https://example.com/server_info.json","json_path":"$.news.title"}}
```

JSON จากเว็บจะโหลดครั้งเดียวและโหลดอีกครั้งเมื่อ FancyMenu รีโหลด การเปลี่ยนแปลงในไฟล์จะแสดงทันที

| พาธ | ค่าที่ได้ |
|---|---|
| `$.name` | ค่า `name` ระดับบนสุด |
| `$.player.level` | ค่า `level` ภายใน `player` |
| `$.items[0].id` | ค่า `id` ของรายการแรกใน `items` |
| `$.scores.*` | ค่าทั้งหมดภายใน `scores` |

### ข้อความจากไฟล์

**ตัวระบุ:** `file_text`

อ่านข้อความจากไฟล์หรือ URL ไฟล์จะถูกอ่านใหม่ทุกวินาที ส่วน URL จะถูกอ่านใหม่ทุก 10 วินาที ระหว่างโหลดหรือเมื่ออ่านไม่ได้ จะไม่แสดงอะไร

- `path_or_url`: ไฟล์ในโฟลเดอร์เกม หรือ URL พาธที่ขึ้นต้นด้วย `.minecraft/` จะอ้างถึงโฟลเดอร์ Minecraft เริ่มต้น
- `mode` (ไม่บังคับ): `all` เพื่ออ่านข้อความทั้งหมด หรือ `last` เพื่ออ่านข้อความบรรทัดสุดท้าย ค่าเริ่มต้นคือ `all`
- `separator` (ไม่บังคับ): ข้อความคั่นระหว่างบรรทัด ค่าเริ่มต้นคือ `\n` (ขึ้นบรรทัดใหม่)
- `last_lines` (ไม่บังคับ): จำนวนบรรทัดที่ `last` จะแสดง ค่าเริ่มต้นคือ `1`

```
{"placeholder":"file_text","values":{"path_or_url":"/config/fancymenu/assets/changelog.txt","mode":"all","separator":"\n","last_lines":"1"}}
```

### ขนาดไฟล์

**ตัวระบุ:** `file_size`

ขนาดไฟล์เป็นไบต์ หากไม่มีไฟล์จะได้ `0` พาธที่ขึ้นต้นด้วย `.minecraft/` จะอ้างถึงโฟลเดอร์ Minecraft เริ่มต้น

### รับข้อมูล NBT (ฝั่งไคลเอนต์)

**ตัวระบุ:** `nbt_data_get`

อ่านข้อมูล NBT คล้ายคำสั่ง `/data get` จากข้อมูลโลกที่เกมของคุณรู้จัก ทำงานรวดเร็ว แต่เซิร์ฟเวอร์ไม่ได้ส่งข้อมูลทุกอย่างให้ผู้เล่น

- `source_type`: `entity` หรือ `block`
- `entity_selector`: สำหรับ `entity` ให้ใช้ตัวเลือก เช่น `@s` (ตัวคุณ), `@p`, `@e[type=minecraft:horse,limit=1,sort=nearest]` หรือชื่อหรือ UUID ของเอนทิตี ตัวเลือกใช้ `type`, `name`, `tag`, `limit`, `sort`, `distance`, `x`, `y`, `z`, `dx`, `dy` และ `dz` ได้ โดยจะใช้ผลลัพธ์แรกที่ตรงกัน
- `block_pos`: สำหรับ `block` ระบุตำแหน่งของบล็อกเอนทิตี เช่น หีบ: `120 64 -35`
- `nbt_path`: พาธ NBT เช่น `foodLevel` หรือ `Inventory[0].id`
- `scale` (ไม่บังคับ): ตัวคูณตัวเลข ค่าเริ่มต้นคือ `1.0`
- `return_type` (ไม่บังคับ): `value` (ตัวเลขและข้อความตามเดิม), `string`, `snbt` หรือ `json` ค่าเริ่มต้นคือ `value`

```
{"placeholder":"nbt_data_get","values":{"source_type":"entity","entity_selector":"@s","nbt_path":"foodLevel","scale":"1.0","return_type":"value"}}
```

### รับข้อมูล NBT (ฝั่งเซิร์ฟเวอร์)

**ตัวระบุ:** `nbt_data_get_server`

อ่านข้อมูล NBT จากเซิร์ฟเวอร์เหมือนคำสั่ง `/data get` ทุกประการ ต้องติดตั้ง FancyMenu บนเซิร์ฟเวอร์ ในโหมดผู้เล่นคนเดียวจะทำงานได้เสมอ ระหว่างรอเซิร์ฟเวอร์ตอบจะไม่แสดงอะไร จากนั้นจะอัปเดตประมาณทุก 100 มิลลิวินาที

- `source_type`: `entity`, `block` หรือ `storage`
- `entity_selector`: สำหรับ `entity` ใช้ตัวเลือกใดก็ได้ของ `/data get` ที่ค้นหาเอนทิตีเดียว เช่น `@s` หรือ `@e[type=minecraft:villager,limit=1,sort=nearest]`
- `block_pos`: สำหรับ `block` ระบุตำแหน่ง เช่น `120 64 -35`, `~ ~-1 ~` หรือ `^ ^ ^1`
- `storage_id`: สำหรับ `storage` ระบุ ID ของ command storage เช่น `mypack:quests`
- `nbt_path` (ไม่บังคับ): พาธ NBT หากไม่ระบุจะได้รับข้อมูลทั้งหมด
- `scale` (ไม่บังคับ): ตัวคูณตัวเลข ค่าเริ่มต้นคือ `1.0`
- `return_type` (ไม่บังคับ): `value`, `string`, `snbt` หรือ `json` ค่าเริ่มต้นคือ `value`

```
{"placeholder":"nbt_data_get_server","values":{"source_type":"storage","storage_id":"mypack:quests","nbt_path":"completed","return_type":"value"}}
```

## เสียง

รายการเหล่านี้อ่านข้อมูลจาก[องค์ประกอบเสียง](/elements#audio) ในเมนูที่เปิดอยู่ คลิกขวาองค์ประกอบเสียงในตัวแก้ไขเลย์เอาต์ แล้วคลิก **คัดลอก ID องค์ประกอบ** เพื่อคัดลอก ID

### ระดับเสียงขององค์ประกอบเสียง

**ตัวระบุ:** `audio_element_vol`

ระดับเสียงขององค์ประกอบเสียง ตั้งแต่ `0.0` (0%) ถึง `1.0` (100%)

- `element_identifier`: ID ขององค์ประกอบเสียง

```
{"placeholder":"audio_element_vol","values":{"element_identifier":"5f1c2a9e-7b3d-4c8e-9a21-6d0f4e8b3c17-1732456789012"}}
```

### แทร็กเสียงปัจจุบัน

**ตัวระบุ:** `audio_element_current_track`

ชื่อไฟล์ของแทร็กที่กำลังเล่น เช่น `menu_theme.ogg` หากไม่มีแทร็กเล่นอยู่จะแสดง `---`

- `element_identifier`: ID ขององค์ประกอบเสียง
- `display_name_mappings` (ไม่บังคับ): ชื่อที่จะแสดงแทนชื่อไฟล์ ใช้ `=>` คั่นระหว่างชื่อไฟล์กับชื่อที่แสดง และใช้ `%:%` คั่นระหว่างคู่ข้อมูล

```
{"placeholder":"audio_element_current_track","values":{"element_identifier":"5f1c2a9e-7b3d-4c8e-9a21-6d0f4e8b3c17-1732456789012","display_name_mappings":"menu_theme.ogg=>Menu Theme%:%credits.ogg=>Credits Theme"}}
```

### ระยะเวลาเสียง

**ตัวระบุ:** `audio_duration`

ความยาวของแทร็กปัจจุบัน เช่น `03:45` ระหว่างโหลดจะแสดง `00:00`

- `element_identifier`: ID ขององค์ประกอบเสียง

```
{"placeholder":"audio_duration","values":{"element_identifier":"5f1c2a9e-7b3d-4c8e-9a21-6d0f4e8b3c17-1732456789012"}}
```

### เวลาเล่นเสียง

**ตัวระบุ:** `audio_playtime`

ตำแหน่งปัจจุบันของแทร็ก เช่น `01:30` หากหยุดเล่นจะแสดง `00:00` (หรือ `0`)

- `element_identifier`: ID ขององค์ประกอบเสียง
- `show_percentage` (ไม่บังคับ): `true` จะแสดงความคืบหน้าตั้งแต่ `0` ถึง `100` ค่าเริ่มต้นคือ `false`

```
{"placeholder":"audio_playtime","values":{"element_identifier":"5f1c2a9e-7b3d-4c8e-9a21-6d0f4e8b3c17-1732456789012","show_percentage":"false"}}
```

### สถานะการเล่นเสียง

**ตัวระบุ:** `audio_playing_state`

เป็น `true` ขณะที่องค์ประกอบเสียงกำลังเล่น และเป็น `false` เมื่อหยุดชั่วคราวหรือหยุดเล่น

- `element_identifier`: ID ขององค์ประกอบเสียง

```

**ตัวระบุ:** `keybind_key`

- `keybind`: ชื่อปุ่มลัด เช่น `key.jump` หรือ `key.inventory` ชื่อเหล่านี้อยู่ใน `options.txt` โดยตัด `key_` ที่ขึ้นต้นออก ดังนั้น `key_key.jump` จะเป็น `key.jump`

```

```

### โลกหรือเซิร์ฟเวอร์ล่าสุด

**ตัวระบุ:** `last_world_server`

- `type`: `both` สำหรับทั้งโลกและเซิร์ฟเวอร์, `world` สำหรับเฉพาะโลก หรือ `server` สำหรับเฉพาะเซิร์ฟเวอร์ หากเลือก `world` หรือ `server` แล้วรายการล่าสุดเป็นอีกประเภทหนึ่งจะแสดงค่าว่าง
- `full_world_path` (ไม่บังคับ): `false` จะแสดงเฉพาะชื่อโลก เช่น `New World` ส่วน `true` จะแสดงพาธของโฟลเดอร์ ค่าเริ่มต้นคือ `true`

```
{"placeholder":"last_world_server","values":{"type":"world","full_world_path":"false"}}
```

## เซิร์ฟเวอร์

รายการเหล่านี้สอบถามสถานะเซิร์ฟเวอร์เหมือนกับรายการเซิร์ฟเวอร์ FancyMenu จะสอบถามทุก 30 วินาทีขณะที่หน้าจอที่ปรับแต่งเปิดอยู่ ก่อนตอบกลับครั้งแรกจะถือว่าเซิร์ฟเวอร์ออฟไลน์

- `ip`: ที่อยู่เซิร์ฟเวอร์ โดยใส่พอร์ตเมื่อไม่ใช่พอร์ตเริ่มต้น เช่น `play.example.net` หรือ `play.example.net:25566`

### สถานะเซิร์ฟเวอร์

**ตัวระบุ:** `serverstatus`

แสดง `Online` เป็นสีเขียว หรือ `Offline` เป็นสีแดง

```
{"placeholder":"serverstatus","values":{"ip":"play.example.net"}}
```

### จำนวนผู้เล่นในเซิร์ฟเวอร์

**ตัวระบุ:** `serverplayercount`

จำนวนผู้เล่นที่ออนไลน์และจำนวนผู้เล่นสูงสุด เช่น `12/100` ก่อนเซิร์ฟเวอร์ตอบกลับจะแสดง `0/0`

```
{"placeholder":"serverplayercount","values":{"ip":"play.example.net"}}
```

### MOTD ของเซิร์ฟเวอร์

**ตัวระบุ:** `servermotd`

ข้อความประจำวันของเซิร์ฟเวอร์หนึ่งบรรทัด

- `line`: `1` หรือ `2`

```
{"placeholder":"servermotd","values":{"ip":"play.example.net","line":"1"}}
```

### PING ของเซิร์ฟเวอร์

**ตัวระบุ:** `serverping`

ค่า ping ไปยังเซิร์ฟเวอร์เป็นมิลลิวินาที เช่น `54` หากออฟไลน์จะแสดง `-1`

```
{"placeholder":"serverping","values":{"ip":"play.example.net"}}
```

### เวอร์ชันเซิร์ฟเวอร์

**ตัวระบุ:** `serverversion`

เวอร์ชัน Minecraft ของเซิร์ฟเวอร์ เช่น `1.21.1` เซิร์ฟเวอร์บางแห่งอาจแสดงข้อความของตัวเองแทน ก่อนเซิร์ฟเวอร์ตอบกลับจะแสดง `---`

```
{"placeholder":"serverversion","values":{"ip":"play.example.net"}}
```

## วิดีโอ

รายการเหล่านี้อ่านข้อมูลจาก[องค์ประกอบวิดีโอและพื้นหลังเมนูวิดีโอ](/video)ของเมนูที่เปิดอยู่ สำหรับองค์ประกอบวิดีโอ ให้คลิกขวาในตัวแก้ไขเลย์เอาต์แล้วคลิก **คัดลอก ID องค์ประกอบ** สำหรับพื้นหลัง ให้คลิกขวาพื้นหลังของตัวแก้ไขแล้วคลิก **คัดลอกตัวระบุพื้นหลัง**

### ระดับเสียงองค์ประกอบวิดีโอ

**ตัวระบุ:** `video_element_vol`

ระดับเสียงขององค์ประกอบวิดีโอ ตั้งแต่ `0.0` (0%) ถึง `1.0` (100%)

- `element_identifier`: ID ขององค์ประกอบวิดีโอ

```
{"placeholder":"video_element_vol","values":{"element_identifier":"5f1c2a9e-7b3d-4c8e-9a21-6d0f4e8b3c17-1732456789012"}}
```

### ระยะเวลาขององค์ประกอบวิดีโอ

**ตัวระบุ:** `video_element_duration`

ความยาววิดีโอขององค์ประกอบ เช่น `02:00` ระหว่างโหลดจะแสดง `00:00` (หรือ `0`)

- `element_identifier`: ID ขององค์ประกอบวิดีโอ
- `output_as_timestamp` (ไม่บังคับ): `true` จะแสดงเป็นมิลลิวินาที เช่น `120000` ค่าเริ่มต้นคือ `false`

```
{"placeholder":"video_element_duration","values":{"element_identifier":"5f1c2a9e-7b3d-4c8e-9a21-6d0f4e8b3c17-1732456789012","output_as_timestamp":"false"}}
```

### เวลาเล่นขององค์ประกอบวิดีโอ

**ตัวระบุ:** `video_element_playtime`

ตำแหน่งปัจจุบันของวิดีโอในองค์ประกอบ เช่น `00:45` ระหว่างโหลดจะแสดง `00:00` (หรือ `0`)

- `element_identifier`: ID ขององค์ประกอบวิดีโอ
- `show_percentage` (ไม่บังคับ): `true` จะแสดงความคืบหน้าตั้งแต่ `0` ถึง `100` ค่าเริ่มต้นคือ `false`
- `output_as_timestamp` (ไม่บังคับ): `true` จะแสดงเป็นมิลลิวินาที หากทั้งสองค่าเป็น `true` จะใช้ `show_percentage` ค่าเริ่มต้นคือ `false`

```
{"placeholder":"video_element_playtime","values":{"element_identifier":"5f1c2a9e-7b3d-4c8e-9a21-6d0f4e8b3c17-1732456789012","show_percentage":"false","output_as_timestamp":"false"}}
```

### สถานะหยุดชั่วคราวขององค์ประกอบวิดีโอ

**ตัวระบุ:** `video_element_paused_state`

เป็น `true` ขณะที่องค์ประกอบวิดีโอหยุดชั่วคราว มิฉะนั้นเป็น `false`

- `element_identifier`: ID ขององค์ประกอบวิดีโอ

```

```

{"placeholder":"world_daytime_hour"}:{"placeholder":"world_daytime_minute"}

```
{"placeholder":"current_biome","values":{"as_key":"false"}}
```

### Seed ของโลกปัจจุบัน

Seed ของโลกผู้เล่นคนเดียว เช่น `-4172144997902289642` หากอยู่บนเซิร์ฟเวอร์จะแสดงค่าว่าง

{"placeholder":"current_world_seed"}
```

### ค่ากฎของเกม

**ตัวระบุ:** `gamerule_value`

ค่าของกฎเกม เช่น `true` หรือ `3` ในโหมดผู้เล่นคนเดียวจะทำงานได้เสมอ ส่วนบนเซิร์ฟเวอร์ต้องติดตั้ง FancyMenu บนเซิร์ฟเวอร์ หากไม่มีกฎเกมชื่อนี้จะแสดงค่าว่าง

- `name`: ชื่อกฎเกม เช่น `keep_inventory` ใน Minecraft 1.21.10 และเวอร์ชันเก่ากว่า กฎเกมใช้ชื่ออย่าง `keepInventory` โดยชื่อเดิมเหล่านี้ยังใช้ได้ในเวอร์ชันใหม่

```
{"placeholder":"gamerule_value","values":{"name":"keep_inventory"}}
```

ที่อยู่เซิร์ฟเวอร์ที่ผู้เล่นอยู่ เช่น `play.example.net` หากเล่นคนเดียวจะแสดงค่าว่าง

{"placeholder":"current_server_ip"}

- `separator` (ไม่บังคับ): ข้อความคั่นระหว่างชื่อ ค่าเริ่มต้นคือ `, `

{"placeholder":"world_players_list","values":{"separator":", "}}

## โลก: โลกที่บันทึกไว้

รายการเหล่านี้อยู่ในหมวด **โลก** และใช้ได้ในทุกเมนูแม้ไม่มีโลกโหลดอยู่

### จำนวนโลกที่บันทึกไว้

**ตัวระบุ:** `level_save_count`

จำนวนโลกผู้เล่นคนเดียวที่มีอยู่

```
{"placeholder":"level_save_count"}
```

### ชื่อโลกที่บันทึกไว้

**ตัวระบุ:** `level_save_names`

ชื่อโลกผู้เล่นคนเดียวทั้งหมด เรียงตามรายการโลก เช่น `Survival World, Creative Test`

- `separator` (ไม่บังคับ): ข้อความคั่นระหว่างชื่อ ค่าเริ่มต้นคือ `, `

```
{"placeholder":"level_save_names","values":{"separator":", "}}
```

### ข้อมูลโลกที่บันทึกไว้

**ตัวระบุ:** `level_save_data`

ข้อมูลทั้งหมดของโลกผู้เล่นคนเดียวในรูปแบบ JSON เช่น `{"file_name":"Survival World","game_type":"survival","difficulty":"normal",...}` มีข้อมูล `file_name`, `display_name`, `game_type`, `difficulty`, `allow_commands`, `last_played` (เป็น Unix timestamp), `minecraft_version_name` และอื่น ๆ อ่านค่าแต่ละค่าได้ด้วย[**ตัวแยกวิเคราะห์ JSON**](#json-parser)

- `level_name`: ชื่อโลกตามที่แสดงในรายการโลกทุกประการ

```
{"placeholder":"json","values":{"source":"{"placeholder":"level_save_data","values":{"level_name":"Survival World"}}","json_path":"$.game_type"}}
```

- `output_as_millis` (ไม่บังคับ): `true` จะแสดงเป็นมิลลิวินาที ค่าเริ่มต้นคือ `false`

```
{"placeholder":"uptime_duration","values":{"output_as_millis":"false"}}
```

### ข้อความสุ่ม

**ตัวระบุ:** `randomtext`

สุ่มหนึ่งบรรทัดจากไฟล์ข้อความ URL หรือข้อความที่คุณพิมพ์ เช่น เคล็ดลับแบบสุ่ม ไฟล์และ URL จะถูกอ่านใหม่ทุก 30 วินาที

- `source`: ไฟล์ `.txt` ในโฟลเดอร์เกม URL หรือบรรทัดที่คั่นด้วย `\n` เช่น `Tip 1\nTip 2\nTip 3`
- `interval` (ไม่บังคับ): จำนวนวินาทีก่อนสุ่มบรรทัดใหม่ ค่า `0` จะสุ่มหนึ่งบรรทัดต่อการเล่นหนึ่งเซสชัน ค่าเริ่มต้นคือ `10`

```
{"placeholder":"randomtext","values":{"source":"/config/fancymenu/assets/tips.txt","interval":"10"}}
```

### ข้อความจากเว็บ

**ตัวระบุ:** `webtext`

บรรทัดแรกของข้อความจากหน้าเว็บ เช่น ไฟล์ข้อความบนเว็บไซต์ของคุณ จะโหลดครั้งเดียวและโหลดอีกครั้งเมื่อ FancyMenu รีโหลด ระหว่างโหลดจะแสดงค่าว่าง

- `link`: URL ของหน้าเว็บ

```
{"placeholder":"webtext","values":{"link":"https://example.com/motd.txt"}}
```

### พาธไฟล์/โฟลเดอร์แบบเต็ม

**ตัวระบุ:** `absolute_path`

พาธแบบเต็มของไฟล์หรือโฟลเดอร์ในโฟลเดอร์เกม เช่น `C:/Users/Steve/AppData/Roaming/.minecraft/config/fancymenu`

- `short_path`: พาธภายในโฟลเดอร์เกม

```
{"placeholder":"absolute_path","values":{"short_path":"config/fancymenu"}}
```

### จำนวนอักขระในข้อความ

**ตัวระบุ:** `text_character_count`

จำนวนอักขระในข้อความ: `Hello World!` มี `12` อักขระ

- `text`: ข้อความ

```
{"placeholder":"text_character_count","values":{"text":"$$player_nickname"}}
```

### ความกว้างข้อความ

**ตัวระบุ:** `text_width`

ความกว้างของข้อความเป็นพิกเซล GUI: `Hello World!` มีความกว้าง `57` รหัสจัดรูปแบบอย่าง `&l` จะนับเช่นเดียวกับในเกม ดังนั้นข้อความตัวหนาจึงกว้างกว่า

- `text`: ข้อความ

```
{"placeholder":"text_width","values":{"text":"Hello World!"}}
```

### ความสูงข้อความ

**ตัวระบุ:** `text_height`

ความสูงของข้อความเป็นพิกเซล GUI โดยนับทุกบรรทัด การขึ้นบรรทัดใหม่ใช้ `\n` หากต้องการให้พอดีกับองค์ประกอบข้อความ ให้ใช้[**ความสูงเนื้อหาขององค์ประกอบข้อความ**](#text-element-content-height) ซึ่งนับขนาดข้อความ ระยะห่างระหว่างบรรทัด และบรรทัดที่ตัดขึ้นบรรทัดใหม่ด้วย

- `text`: ข้อความ

```
{"placeholder":"text_height","values":{"text":"First line\nSecond line"}}
```

### เนื้อหาในคลิปบอร์ด

**ตัวระบุ:** `clipboard_content`

ข้อความในคลิปบอร์ดของคอมพิวเตอร์ หากไม่มีข้อความจะแสดงค่าว่าง
