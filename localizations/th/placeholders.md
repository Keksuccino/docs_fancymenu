# ตัวยึดตำแหน่ง

ตัวยึดตำแหน่งจะใส่ค่าจริงลงในข้อความ ปุ่ม ข้อกำหนด และฟิลด์อื่น ๆ ที่รองรับ

# ข้อมูลทั่วไป

## ไวยากรณ์พื้นฐาน
ตัวยึดตำแหน่งใน FancyMenu ใช้ไวยากรณ์คล้าย JSON:
```
{"placeholder":"modversion","values":{"modid":"fancymenu"}}
```

ตัวอย่างเช่น หากต้องการแสดงชื่อผู้เล่น:
```
{"placeholder":"playername"}
```

## การซ้อนตัวยึดตำแหน่ง
คุณสามารถใช้ตัวยึดตำแหน่งหนึ่งไว้ภายในค่าของตัวยึดตำแหน่งอีกตัวได้

ตัวอย่างการซ้อนตัวยึดตำแหน่ง:
```
{"placeholder":"calc","values":{"decimal":"true","expression":"{"placeholder":"maxram"} / 1024"}}
```
ตัวอย่างนี้นำค่า RAM สูงสุดมาหารด้วย 1024 เพื่อแปลงจาก MB เป็น GB

> [!IMPORTANT]
> นี่คือไวยากรณ์ของ FancyMenu ไม่ใช่ JSON ตัวยึดตำแหน่งที่ซ้อนกันจะใช้รูปแบบที่ไม่ต้อง escape ตามที่แสดงด้านบนแบบเป๊ะ ๆ ดังนั้นตัวจัดรูปแบบ JSON จะปฏิเสธหรือแก้ไขมัน ชื่อตัวยึดตำแหน่งแยกแยะตัวพิมพ์ใหญ่-เล็ก และตัวยึดตำแหน่งที่ผิดรูปแบบหรือไม่รู้จักจะยังคงแสดงเป็นข้อความและถูกบันทึกลงล็อก

# การใช้งานตัวยึดตำแหน่ง

องค์ประกอบส่วนใหญ่ที่มีช่องกรอกข้อความรองรับตัวยึดตำแหน่งได้ คุณสามารถดูได้ว่าช่องกรอกข้อความรองรับตัวยึดตำแหน่งหรือไม่เมื่อกำลังแก้ไขมัน หากเปิด **ตัวแก้ไขข้อความ** แบบเต็มหน้าจอเมื่อแก้ไขข้อความ แสดงว่ามันรองรับตัวยึดตำแหน่ง

หากต้องการดู **รายการตัวยึดตำแหน่งทั้งหมด** เพียงคลิกปุ่ม **Placeholders** ที่ **มุมขวาบน** ของ **ตัวแก้ไขข้อความ**

มี **แถบค้นหา** อยู่ด้านบนของรายการตัวยึดตำแหน่ง เพื่อให้คุณค้นหาตัวยึดตำแหน่งได้

การคลิกตัวยึดตำแหน่งในรายการ จะเป็นการวางมันลงในเนื้อหาข้อความ

# รายละเอียดของตัวยึดตำแหน่ง

ส่วนนี้แสดงตัวยึดตำแหน่งในตัวที่มาพร้อมกับ FancyMenu

## ผลลัพธ์ที่ไม่พร้อมใช้งาน

ผลลัพธ์ของตัวยึดตำแหน่งจะเป็นข้อความเสมอ เมื่อข้อมูลไม่พร้อมใช้งาน ผลลัพธ์จะขึ้นอยู่กับตัวยึดตำแหน่งนั้น ๆ: ค่าทดแทนที่พบบ่อยคือสตริงว่าง `0`, `0.0`, `00:00`, `false`, `UNKNOWN`, หรือ `ERROR` รายการที่มีค่าทดแทนเฉพาะจะระบุไว้โดยตรง; ให้ทดสอบค่าทดแทนก่อนใช้ผลลัพธ์ที่ขึ้นกับสภาพแวดล้อมใน [ข้อกำหนด](./conditions), path, คำสั่ง หรือ URL

## โลกหรือเซิร์ฟเวอร์ล่าสุด (`last_world_server`)

**วัตถุประสงค์:** คืนข้อมูลเกี่ยวกับโลกหรือเซิร์ฟเวอร์ล่าสุดที่เข้าถึง

**ค่า:** `type`, `full_world_path`

**ตัวอย่าง:**

```
{"placeholder":"last_world_server","values":{"type":"both","full_world_path":"true"}}
```
พารามิเตอร์:
- `type`: กำหนดว่าจะคืนข้อมูลประเภทใด
  - `"both"`: คืนโลกหรือเซิร์ฟเวอร์ล่าสุดที่เข้าถึง (ค่าเริ่มต้น)
  - `"server"`: คืนเฉพาะเมื่อสิ่งล่าสุดที่เข้าถึงคือเซิร์ฟเวอร์
  - `"world"`: คืนเฉพาะเมื่อสิ่งล่าสุดที่เข้าถึงคือโลก
- `full_world_path`: ควบคุมวิธีแสดงพาธของโลก
  - `"true"`: คืนพาธของโลกแบบเต็ม (ค่าเริ่มต้น)
  - `"false"`: คืนเฉพาะชื่อโลกโดยไม่รวมพาธ (ไม่ส่งผลต่อเซิร์ฟเวอร์)

ตัวอย่าง:
- เซิร์ฟเวอร์: `mc.hypixel.net`
- โลกแบบพาธเต็ม: `saves/New World`
- โลกแบบไม่พาธเต็ม: `New World`

**ผลลัพธ์ที่ไม่พร้อมใช้งาน:** `00:00` หรือ `0` ในโหมดเปอร์เซ็นต์ ค่าปัจจุบันจะพร้อมใช้งานเมื่อแทร็กกำลังเล่นหรือพักอยู่ ส่วนแทร็กที่หยุด หายไป หรือยังไม่พร้อมใช้งานจะใช้ผลลัพธ์ที่ไม่พร้อมใช้งาน

## เครื่องคิดเลข (`calc`)

**วัตถุประสงค์:** ตัวยึดตำแหน่งเครื่องคิดเลขเป็นเครื่องมือทรงพลังที่ช่วยให้คุณทำการคำนวณทางคณิตศาสตร์ภายในเลย์เอาต์ได้ รองรับการดำเนินการทางคณิตศาสตร์หลากหลายและใช้งานได้ทั้งตัวเลขทศนิยมและจำนวนเต็ม

**ค่า:** `decimal`, `expression`

### ไวยากรณ์พื้นฐาน

**ตัวอย่าง:**

```

```

เครื่องคิดเลขมีพารามิเตอร์หลักสองตัว:
- `decimal`: กำหนดว่าผลลัพธ์ควรมีทศนิยมหรือไม่ (`true`) หรือปัดเป็นจำนวนเต็ม (`false`)
- `expression`: นิพจน์ทางคณิตศาสตร์ที่ต้องการประเมิน

### การดำเนินการที่รองรับ
เครื่องคิดเลขรองรับการดำเนินการทางคณิตศาสตร์เหล่านี้:
- เลขคณิตพื้นฐาน: `+` (บวก), `-` (ลบ), `*` (คูณ), `/` (หาร)
- วงเล็บ: `( )` สำหรับจัดกลุ่มการดำเนินการ
- ยกกำลัง: `^`
- รากที่สอง: `sqrt()`
- ฟังก์ชันตรีโกณมิติ: `sin()`, `cos()`, `tan()`
- ค่าคงที่ทางคณิตศาสตร์: `pi`, `e`
- ค่าสัมบูรณ์: `abs()`
- ลอการิทึม: `log()`, `ln()`

## ข้อความแบบสุ่ม (`randomtext`)

**วัตถุประสงค์:** คืนหนึ่งบรรทัดแบบสุ่มจากไฟล์ข้อความ URL หรือข้อความธรรมดาที่ป้อนโดยตรง ข้อความจะเปลี่ยนตามช่วงเวลาที่กำหนด เนื้อหาจากไฟล์และ URL จะถูกรีเฟรชประมาณทุก 30 วินาที; ข้อความธรรมดาที่ป้อนโดยตรงจะยังคงถูกแคชไว้ เพราะไม่จำเป็นต้องโหลดใหม่

**ค่า:** `source`, `interval`

ในค่าของตัวยึดตำแหน่ง `/config/...` หมายถึง `<game-directory>/config/...` ไม่ใช่พาธที่เป็นรากของระบบไฟล์ ดู [ทรัพยากร](./resources#local-resources)

**ตัวอย่าง:**

```
{"placeholder":"randomtext","values":{"source":"/config/fancymenu/assets/<file_name.txt>","interval":"10"}}
```
พารามิเตอร์:
- `source`: แหล่งที่มาของบรรทัดข้อความ (แทนพารามิเตอร์ `path` แบบเก่า)
  - พาธไฟล์: `/config/fancymenu/assets/quotes.txt`
  - URL: `https://example.com/quotes.txt`
  - ข้อความธรรมดา: `Line 1\nLine 2\nLine 3`
- `interval`: เวลาหน่วยวินาทีระหว่างการเปลี่ยนข้อความ

ตอนนี้ตัวยึดตำแหน่งรองรับแหล่งที่มา 3 แบบ:
1. **ไฟล์ในเครื่อง**: ไฟล์ข้อความจากไดเรกทอรีเกมของคุณ
   ```
   {"placeholder":"randomtext","values":{"source":"/config/fancymenu/assets/quotes.txt","interval":"10"}}
   ```
2. **URL**: ไฟล์ข้อความระยะไกลจากอินเทอร์เน็ต
   ```
   {"placeholder":"randomtext","values":{"source":"https://example.com/quotes.txt","interval":"10"}}
   ```
3. **ข้อความธรรมดา**: ข้อความที่ป้อนตรง ๆ โดยแยกบรรทัดด้วย `\n`
   ```
   {"placeholder":"randomtext","values":{"source":"First line\nSecond line\nThird line","interval":"5"}}
   ```

หมายเหตุ: ตัวยึดตำแหน่งแบบเก่าที่ใช้ `path` แทน `source` ยังใช้งานได้อยู่

## ตัวแยกวิเคราะห์ JSON (`json`)

**วัตถุประสงค์:** แยกวิเคราะห์ข้อมูล JSON จากไฟล์ URL หรือเนื้อหา JSON โดยตรง และดึงค่าด้วยนิพจน์ JSON path

**ค่า:** `source`, `json_path`

**ตัวอย่าง:**

```
{"placeholder":"json","values":{"source":"path_or_link_or_json_content","json_path":"$.some.json.path"}}
```
พารามิเตอร์:
- `source`: แหล่งที่มาของข้อมูล JSON
  - พาธไฟล์: `/config/fancymenu/assets/data.json`
  - URL: `https://api.example.com/data.json`
  - JSON โดยตรง: `{"name":"Steve","level":42}`
- `json_path`: นิพจน์ JSON path สำหรับดึงข้อมูล

ตอนนี้ตัวยึดตำแหน่งรองรับแหล่งที่มา 3 แบบ:
1. **ไฟล์ในเครื่อง**: ไฟล์ JSON จากไดเรกทอรีเกมของคุณ
   ```
   {"placeholder":"json","values":{"source":"/config/fancymenu/assets/playerdata.json","json_path":"$.player.name"}}
   ```
2. **URL**: ข้อมูล JSON ระยะไกลจาก API หรือบริการเว็บ
   ```
   {"placeholder":"json","values":{"source":"https://api.minecraft.com/server/status","json_path":"$.online"}}
   ```
3. **JSON โดยตรง**: เนื้อหา JSON แบบอินไลน์
   ```
   {"placeholder":"json","values":{"source":"{"name":"Steve","score":42,"rank":"Diamond"}","json_path":"$.rank"}}
   ```

ตัวอย่าง JSON path:
- `$.name` - ดึงฟิลด์ "name" จากรูท
- `$.player.level` - ดึงฟิลด์ "level" ที่ซ้อนอยู่ภายใน "player"
- `$.items[0].id` - ดึงค่า "id" ของรายการแรกในอาร์เรย์
- `$.scores.*` - ดึงค่าทั้งหมดจากออบเจ็กต์ "scores"

## ดึงข้อมูล NBT (`nbt_data_get`)

**วัตถุประสงค์:** ดึงข้อมูล NBT ฝั่งไคลเอนต์ (คล้ายคำสั่ง `/data get`) ใช้เวอร์ชันเซิร์ฟเวอร์ `nbt_data_get_server` เมื่อเชื่อมต่อกับเซิร์ฟเวอร์และต้องการค่าฝั่งเซิร์ฟเวอร์ที่เป็นแหล่งอ้างอิง

**ค่า:** `source_type`, `entity_selector`, `nbt_path`, `scale`, `return_type`

**ตัวอย่าง:**

```
{"placeholder":"nbt_data_get","values":{"source_type":"entity","entity_selector":"@s","nbt_path":"foodLevel","scale":"1.0","return_type":"value"}}
```
พารามิเตอร์:
- `source_type`: `"entity"` หรือ `"block"`
- `entity_selector`: ตัวเลือกเอนทิตี เช่น `@s`, `@p`, `@e` หรือ UUID/ชื่อ (สำหรับเอนทิตี)
- `block_pos`: ตำแหน่งบล็อกในรูปแบบ `"x y z"` (สำหรับบล็อก)
- `nbt_path`: พาธ NBT ที่ต้องการดึง
- `scale`: ตัวคูณสเกลเสริมสำหรับค่าตัวเลข (ค่าเริ่มต้น: `"1.0"`)
- `return_type`: วิธีคืนข้อมูล:
  - `"value"`: ค่าเริ่มต้น คืนค่าโดยตรง (พร้อมสเกลเสริมสำหรับตัวเลข)
  - `"string"`: คืนข้อมูล NBT จริงเป็นสตริง
  - `"snbt"`: คืนเป็น SNBT (NBT ที่จัดรูปแบบแล้ว)
  - `"json"`: คืนเป็นคอมโพเนนต์แบบ JSON (สำหรับแท็กชนิด compound)

**ผลลัพธ์:** `20` (สำหรับ food level)

# แนวปฏิบัติที่ดีที่สุด

1. **แคชการทำงานที่ใช้ทรัพยากรสูง**: ตัวยึดตำแหน่งบางตัว (เช่น ตัวที่อ่านข้อมูลระบบ) อาจใช้ทรัพยากรค่อนข้างมาก ควรพิจารณาใช้ตัวแปรเก็บค่าของมันหากต้องใช้ซ้ำหลายครั้ง

2. **ใช้การตั้งค่าทศนิยมให้เหมาะสม**: เมื่อทำการคำนวณ ให้ใช้พารามิเตอร์ `decimal` อย่างเหมาะสม ตั้งเป็น `false` เมื่อคุณต้องการจำนวนเต็ม และ `true` เมื่อคุณต้องการค่าทศนิยมที่แม่นยำ

3. **จัดการค่าที่หายไป**: ควรคิดเสมอว่าจะเกิดอะไรขึ้นหากตัวยึดตำแหน่งคืนค่าไม่ได้ คุณอาจต้องการกำหนดค่าเริ่มต้นไว้ในกรณีดังกล่าว

4. **ทดสอบประสิทธิภาพ**: เมื่อใช้ตัวยึดตำแหน่งจำนวนมากหรือโครงสร้างซ้อนที่ซับซ้อน ให้ทดสอบผลกระทบต่อประสิทธิภาพ โดยเฉพาะบนเครื่องสเปกต่ำ

5. **ใช้การปรับขนาด/ตำแหน่งขั้นสูง**: สำหรับองค์ประกอบ UI แบบไดนามิก ให้รวมตัวยึดตำแหน่งกับการปรับขนาดและการวางตำแหน่งขั้นสูงเพื่อสร้างเลย์เอาต์ที่ตอบสนองได้

6. **ใช้ร่วมกับตัวแปร**: ใช้ตัวยึดตำแหน่งร่วมกับตัวแปรเพื่อสร้างเนื้อหาแบบไดนามิกมากยิ่งขึ้นที่อัปเดตได้ผ่าน actions

# ปัญหาที่พบบ่อยและวิธีแก้ไข

## ตัวยึดตำแหน่งไม่อัปเดต
หากค่าของตัวยึดตำแหน่งไม่อัปเดตตามที่คาดไว้ ให้ตรวจสอบ:
- ว่าตัวยึดตำแหน่งมีรูปแบบถูกต้องหรือไม่
- คุณใช้ตัวพิมพ์เล็ก-ใหญ่ของ ID ตัวยึดตำแหน่งถูกต้องหรือไม่
- ตัวยึดตำแหน่งนั้นต้องมีเงื่อนไขเฉพาะเพื่ออัปเดตหรือไม่

## ตัวยึดตำแหน่งที่ซ้อนไม่ทำงาน
เมื่อซ้อนตัวยึดตำแหน่ง:
- ตรวจสอบให้แน่ใจว่า escape เครื่องหมายคำพูดถูกต้อง
- ยืนยันว่าตัวยึดตำแหน่งที่ซ้อนแต่ละตัวถูกต้องด้วยตัวของมันเอง

## ปัญหาด้านประสิทธิภาพ
หากคุณพบปัญหาด้านประสิทธิภาพ:
- ลดจำนวนตัวยึดตำแหน่งที่ใช้ลง
- หลีกเลี่ยงการซ้อนที่ไม่จำเป็น
- พิจารณาใช้ตัวแปรกับค่าที่เรียกใช้บ่อย
- ใช้ตัวยึดตำแหน่งที่เหมาะสมกับงาน (เช่น อย่าใช้ตัวยึดตำแหน่งแบบเรียลไทม์เมื่อค่าคงที่เพียงพอ)
