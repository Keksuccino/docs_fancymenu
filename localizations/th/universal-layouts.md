# เลย์เอาต์สากล

ระบบจะพิจารณาเลย์เอาต์สากลกับหน้าจอที่รองรับทุกหน้าจอซึ่งเปิดการปรับแต่งหน้าจอไว้ เลย์เอาต์นี้จะไม่ใช้กับหน้าจอที่ [ถูกบล็อก](/incompatibility-list#screens-where-customization-is-intentionally-disabled) หรือหน้าจออื่นที่ถูกยกเว้น

ใช้เลย์เอาต์สากลกับองค์ประกอบที่ใช้ร่วมกัน เช่น โลโก้ การนำทาง ภาพซ้อนทับ หรือ [องค์ประกอบเสียง](/elements#audio) ที่ควรแสดงต่อเนื่องกันในหลายหน้าจอ

# การสร้างเลย์เอาต์

1. เปิดหน้าจอที่รองรับ แล้วแสดงแถบเมนู FancyMenu
2. เลือก **Layouts -> New -> For All Screens [Universal]**
3. เพิ่มและกำหนดค่าองค์ประกอบ
4. บันทึกเลย์เอาต์

หน้าจอทั่วไปยังคงต้องเปิดใช้ **Current Screen Customization** ไม่มีสวิตช์ส่วนกลางสำหรับเปิดใช้กับทุกหน้าจอ เพราะหน้าจอจากม็อดที่ไม่รองรับอาจทำงานผิดพลาดเมื่อมีการปรับแต่ง

# การจำกัดหน้าจอ

เปิดการตั้งค่าเลย์เอาต์สากลจากเมนูบริบทที่พื้นหลังของตัวแก้ไข

- **Whitelist:** เลย์เอาต์จะใช้กับตัวระบุหน้าจอที่อยู่ในรายการเท่านั้น
- **Blacklist:** เลย์เอาต์จะใช้กับหน้าจอที่เข้าเกณฑ์ทุกหน้าจอ ยกเว้นตัวระบุที่อยู่ในรายการ

ใช้ **Customization -> Copy Identifier of Current Screen** เพื่อคัดลอก [ตัวระบุหน้าจอ](/screen-identifiers)

คุณยังเพิ่ม[ข้อกำหนดที่มีผลกับทั้งเลย์เอาต์](/conditions#layout-wide-requirements) เพื่อกำหนดเงื่อนไขการใช้เลย์เอาต์ได้

# ลำดับเลย์เอาต์

ระบบจะรวมเลย์เอาต์สากลที่เข้าเกณฑ์กับเลย์เอาต์เฉพาะหน้าจอ แล้วเรียงซ้อนกันตาม **Layout Index** ดัชนีที่ต่ำกว่าจะถูกใช้ก่อน ส่วนการตั้งค่าแบบซ้อนทับในลำดับถัดไปอาจเขียนทับการตั้งค่าก่อนหน้าได้ หากมีดัชนีเดียวกัน ระบบจะรวบรวมเลย์เอาต์สากลก่อนเลย์เอาต์เฉพาะหน้าจอ
