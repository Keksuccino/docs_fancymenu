# เลย์เอาต์สากล

เลย์เอาต์สากลจะถูกพิจารณาสำหรับหน้าจอที่รองรับทุกหน้าจอซึ่งเปิดใช้การปรับแต่งหน้าจออยู่ เลย์เอาต์นี้จะไม่ใช้กับหน้าจอที่ [ถูกบล็อก](./incompatibility-list#screens-where-customization-is-intentionally-disabled) หรือหน้าจอที่ถูกยกเว้นด้วยเหตุผลอื่น

ใช้เลย์เอาต์สากลสำหรับองค์ประกอบที่ใช้ร่วมกัน เช่น โลโก้ การนำทาง โอเวอร์เลย์ หรือ [องค์ประกอบเสียง](./elements#audio) ที่ควรแสดงต่อเนื่องในหลายหน้าจอ

# การสร้างเลย์เอาต์สากล

1. เปิดหน้าจอที่รองรับและแสดงแถบเมนู FancyMenu
2. เลือก **Layouts -> New -> For All Screens [Universal]**
3. เพิ่มและกำหนดค่าองค์ประกอบ
4. บันทึกเลย์เอาต์

หน้าจอทั่วไปยังคงต้องเปิดใช้ **Current Screen Customization** ไม่มีสวิตช์เปิดใช้ทั้งหมดในระดับสากล เนื่องจากหน้าจอของม็อดที่ไม่รองรับอาจทำงานผิดพลาดเมื่อถูกปรับแต่ง

# การจำกัดหน้าจอ

เปิดการตั้งค่าเลย์เอาต์สากลจากเมนูบริบทของพื้นหลังในเครื่องมือแก้ไข

- **Whitelist:** เลย์เอาต์จะใช้เฉพาะกับตัวระบุหน้าจอที่ระบุไว้
- **Blacklist:** เลย์เอาต์จะใช้กับหน้าจอที่เข้าเกณฑ์ทุกหน้าจอ ยกเว้นตัวระบุที่ระบุไว้

ใช้ **Customization -> Copy Identifier of Current Screen** เพื่อคัดลอก[ตัวระบุหน้าจอ](./screen-identifiers)

คุณยังสามารถเพิ่ม[ข้อกำหนดที่ครอบคลุมทั้งเลย์เอาต์](./conditions#layout-wide-requirements) เพื่อควบคุมว่าจะใช้เลย์เอาต์เมื่อใดได้อีกด้วย

# ลำดับเลย์เอาต์

เลย์เอาต์สากลที่เข้าเกณฑ์และเลย์เอาต์เฉพาะหน้าจอจะถูกรวมและจัดซ้อนกันตาม **Layout Index** ดัชนีที่ต่ำกว่าจะถูกใช้ก่อน ส่วนการตั้งค่าที่ซ้อนทับได้ซึ่งอยู่ในลำดับถัดไปอาจเขียนทับการตั้งค่าก่อนหน้าได้ หากมีดัชนีเดียวกัน ระบบจะรวบรวมเลย์เอาต์สากลก่อนเลย์เอาต์เฉพาะหน้าจอ
