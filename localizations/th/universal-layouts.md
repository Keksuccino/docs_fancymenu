# เลย์เอาต์สากลคืออะไร?

เลย์เอาต์สากล (Universal Layouts) เป็นฟีเจอร์ทรงพลังใน FancyMenu ที่ช่วยให้คุณสร้างเลย์เอาต์ที่สามารถนำไปใช้กับ **หลายหน้าจอ** แทนที่จะใช้ได้เพียงหน้าจอเดียวโดยเฉพาะ ซึ่งทำให้มีประโยชน์มากสำหรับการสร้างองค์ประกอบ UI ที่สอดคล้องกันและแสดงผลทั่วทั้งเกมของคุณ

ให้คิดว่าเลย์เอาต์สากลเป็นเลย์เอาต์แบบ "ส่วนกลาง" ที่สามารถแสดงได้ทุกที่ในเกมของคุณ

# ทำไมต้องใช้เลย์เอาต์สากล?

เลย์เอาต์สากลมีประโยชน์มากเมื่อคุณต้องการ:

- เพิ่มพื้นหลังเดียวกันให้กับทุกหน้าจอ
- สร้างโลโก้หรือข้อความที่แสดงบนหลายหน้าจอ
- ทำให้องค์ประกอบเสียงเล่นต่อเนื่องข้ามหลายหน้าจอ
- สร้างรูปลักษณ์และความรู้สึกที่สอดคล้องกันตลอดทั้งเกม

# เลย์เอาต์สากลทำงานอย่างไร

เมื่อคุณสร้างเลย์เอาต์สากล มันจะถูกโหลดพร้อมกับ **ทุกหน้าจอ** ในเกมโดยค่าเริ่มต้น ซึ่งหมายความว่าองค์ประกอบใดก็ตามที่คุณเพิ่มลงในเลย์เอาต์สากล (เช่น ปุ่ม รูปภาพ หรือข้อความ) จะปรากฏบนทุกหน้าจอ

แต่ไม่ต้องกังวล! คุณสามารถตั้งค่าให้เลย์เอาต์สากลโหลดเฉพาะในหน้าจอบางหน้าได้เช่นกัน สำหรับสิ่งนั้น ให้เลื่อนลงไปดูส่วน **blacklist** และ **whitelist**

# การสร้างเลย์เอาต์สากล

1. เปิดหน้าจอใดก็ได้ในเกม
2. กด **Ctrl+Alt+C** เพื่อแสดงเมนูปรับแต่ง
3. ไปที่ **Layouts → New → For All Screens [Universal]**
4. ออกแบบเลย์เอาต์ของคุณด้วยองค์ประกอบต่าง ๆ เช่น รูปภาพ ข้อความ หรือปุ่ม
5. บันทึกเลย์เอาต์ด้วยชื่อที่อธิบายได้ชัดเจน

# การจัดการว่าหน้าจอใดจะได้รับเลย์เอาต์สากลของคุณ

## การใช้ Blacklist

Blacklist ช่วยให้คุณระบุหน้าจอที่คุณ **ไม่ต้องการ** ให้เลย์เอาต์สากลแสดงผล:

1. ใน Layout Editor ให้คลิกขวาที่พื้นหลัง
2. เลือก **Layout Settings → Universal Layout Options**
3. คลิก **Add Screen To Blacklist**
4. ป้อนตัวระบุของหน้าจอ (เช่น `title_screen` สำหรับหน้าจอชื่อเรื่อง)

ตอนนี้เลย์เอาต์สากลของคุณจะแสดงบนทุกหน้าจอ **ยกเว้น** หน้าจอที่คุณใส่ไว้ใน blacklist

## การใช้ Whitelist

Whitelist เป็นตรงข้ามกัน - มันจะให้แสดงเลย์เอาต์สากลของคุณบนหน้าจอที่ระบุเท่านั้น:

1. ใน Layout Editor ให้คลิกขวาที่พื้นหลัง
2. เลือก **Layout Settings → Universal Layout Options**
3. คลิก **Add Screen To Whitelist**
4. ป้อนตัวระบุของหน้าจอสำหรับแต่ละหน้าจอที่คุณต้องการให้เลย์เอาต์แสดง

เมื่อใช้ whitelist เลย์เอาต์สากลของคุณจะแสดงเฉพาะบนหน้าจอที่คุณระบุไว้เท่านั้น

# การค้นหาตัวระบุของหน้าจอ

ในการเพิ่มหน้าจอลงใน whitelist หรือ blacklist คุณจำเป็นต้องรู้ตัวระบุของมัน:

1. ไปที่หน้าจอที่คุณต้องการระบุ
2. กด **Ctrl+Alt+C** เพื่อเปิดเมนูปรับแต่ง
3. คลิก **Customization → Copy Identifier of Current Screen**
4. ตอนนี้ตัวระบุถูกคัดลอกไปยังคลิปบอร์ดของคุณแล้ว

คุณสามารถวางตัวระบุนี้ลงใน whitelist หรือ blacklist ได้

# การเปิดใช้งานการปรับแต่งสำหรับทุกหน้าจอ

ไม่สามารถเปิดใช้งานการปรับแต่งสำหรับทุกหน้าจอพร้อมกันได้
นี่เป็นการออกแบบโดยตั้งใจ และช่วยป้องกันไม่ให้ผู้ใช้ทำให้เกมเสียหายโดยไม่ตั้งใจ เพราะไปเปิดการปรับแต่งให้กับหน้าจอที่ม็อดไม่รองรับ

# เคล็ดลับขั้นสูง

## การจัดการลำดับการโหลด

เมื่อคุณมีทั้งเลย์เอาต์สากลและเลย์เอาต์เฉพาะหน้าจอ เลย์เอาต์สากลจะถูกโหลด **ก่อน** เสมอ ซึ่งหมายความว่าเลย์เอาต์เฉพาะหน้าจอสามารถทับซ้อนหรือแทนที่องค์ประกอบจากเลย์เอาต์สากลได้

## ข้อกำหนดในการโหลด

คุณสามารถเพิ่มข้อกำหนดในการโหลดให้กับเลย์เอาต์สากลของคุณ เพื่อให้มันโหลดเฉพาะภายใต้เงื่อนไขบางอย่าง:

1. คลิกขวาในตัวแก้ไข
2. เลือก **Layout Settings → Layout-Wide Requirements**
3. เพิ่มเงื่อนไข เช่น ช่วงเวลาของวัน ระบบปฏิบัติการ หรือข้อกำหนดอื่น ๆ
