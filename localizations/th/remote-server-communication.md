# การสื่อสารกับเซิร์ฟเวอร์ระยะไกล

ระบบ "การสื่อสารกับเซิร์ฟเวอร์ระยะไกล" ช่วยให้ไคลเอนต์ FancyMenu สามารถสื่อสารกับเซิร์ฟเวอร์ภายนอกโดยใช้การเชื่อมต่อ WebSocket

ข้อมูลทั้งหมดเป็นแบบข้อความ:

- รองรับข้อความธรรมดา
- รองรับ JSON (ในฐานะข้อความปกติ)

แต่ละ URL ของเซิร์ฟเวอร์จะได้รับ **request ID** ที่แคชไว้หนึ่งค่าในระหว่างการทำงาน
FancyMenu ใช้ ID นี้เพื่อติดตามการเชื่อมต่อและเปิดให้ใช้งานในตัวแปรของ listener

# เริ่มใช้งานอย่างรวดเร็ว

1. เพิ่มแอ็กชัน **Connect To Remote Server** (ไม่บังคับ แต่มีประโยชน์หากต้องการเปิดการเชื่อมต่อไว้ล่วงหน้า)
2. เพิ่มแอ็กชัน **Send Data To Remote Server** โดยใช้ URL เดียวกัน
3. เพิ่ม listener **On Remote Server Data Received** เพื่อโต้ตอบกับการตอบกลับ
4. ใช้ **On Remote Server Connected** / **On Remote Server Connection Closed** สำหรับตรรกะเกี่ยวกับสถานะการเชื่อมต่อ
5. ปิดการเชื่อมต่อเมื่อจำเป็นด้วยแอ็กชันปิดการเชื่อมต่อ

# แอ็กชัน

## Connect To Remote Server

เริ่มต้นการเชื่อมต่อกับเซิร์ฟเวอร์ระยะไกลโดยไม่ส่งข้อมูล payload

Input:

- Remote Server URL

## Send Data To Remote Server

เชื่อมต่อ (หรือใช้การเชื่อมต่อที่มีอยู่เดิมซ้ำ) และส่งข้อมูลข้อความ

Inputs:

1. Remote Server URL
2. Data

## Close Remote Server Connection

ปิดการเชื่อมต่อหนึ่งรายการตาม request ID

Input:

- Connection Request ID

## Close All Remote Server Connections

ปิดการเชื่อมต่อกับเซิร์ฟเวอร์ระยะไกลที่กำลังใช้งานอยู่ทั้งหมด

# Listeners

## On Remote Server Connected

ทำงานเมื่อมีการเริ่มต้นการเชื่อมต่อกับเซิร์ฟเวอร์ระยะไกล

Variables:

- `$$request_id`
- `$$remote_server_url`

## On Remote Server Data Received

ทำงานเมื่อได้รับข้อมูลจากเซิร์ฟเวอร์ระยะไกลที่เชื่อมต่ออยู่

Variables:

- `$$request_id`
- `$$remote_server_url`
- `$$data`

## On Remote Server Connection Closed

ทำงานเมื่อการเชื่อมต่อกับเซิร์ฟเวอร์ระยะไกลถูกปิดลง

Variables:

- `$$request_id`
- `$$remote_server_url`
- `$$intentionally_closed`
- `$$crashed`
- `$$unknown_close_reason`

# พฤติกรรมของการเชื่อมต่อ

- การเชื่อมต่อเป็นแบบ **เริ่มจากฝั่งไคลเอนต์**
- FancyMenu จะคงการเชื่อมต่อไว้เบื้องหลัง
- หากการเชื่อมต่อล่มหรือหมดเวลา FancyMenu จะลองใหม่ทุก 10 วินาที
- เมื่อการเชื่อมต่อที่ล่มถูกกู้คืน FancyMenu จะบันทึกข้อความแจ้งการกู้คืน
- ข้อความที่ส่งออกแต่ยังไม่ได้ส่งจะถูกจัดคิวไว้ โดยมี **อายุสูงสุด 30 วินาที**
- ข้อความในคิวที่เกิน 30 วินาทีจะถูกทิ้ง

# โหมดของ URL

- `wss://` = ปลอดภัย (TLS), แนะนำ
- `ws://` = ไม่เข้ารหัส, เหมาะสำหรับการทดสอบในเครื่อง

ตัวอย่าง URL ในเครื่อง:

- `ws://127.0.0.1:8765`

# แนวปฏิบัติที่ดีที่สุด

1. ใช้ URL ที่คงที่หนึ่งรายการต่อบริการแบ็กเอนด์หนึ่งตัว
2. คงรูปแบบ payload ให้สอดคล้องกันสำหรับแต่ละกรณีใช้งาน
3. จัดการการเชื่อมต่อที่ปิดหรือขาดหายด้วยตรรกะ UI สำรอง
4. ใช้แอ็กชันปิดการเชื่อมต่อเมื่อโฟลว์ของคุณเสร็จสิ้นแล้ว
5. ใช้ `wss://` สำหรับสภาพแวดล้อมใช้งานจริง
