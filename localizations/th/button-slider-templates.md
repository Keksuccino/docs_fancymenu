# เทมเพลตปุ่มและแถบเลื่อน

เทมเพลตคือ [องค์ประกอบปุ่ม](/elements#button) ที่ถ่ายทอดรูปลักษณ์ของตัวเองให้กับปุ่มอื่นทั้งหมดหรือแถบเลื่อนทั้งหมดบนหน้าจอ ไม่ว่าจะเป็นองค์ประกอบดั้งเดิมหรือองค์ประกอบที่คุณสร้างเอง เมื่อเปลี่ยนเทมเพลต องค์ประกอบทั้งหมดที่ใช้เทมเพลตก็จะเปลี่ยนตาม

> [!TIP]
> หากต้องการให้ทุกเมนูในเกมมีรูปลักษณ์เหมือนกัน ให้ใช้ [การปรับแต่งส่วนกลาง](/global-customizations) แทน เทมเพลตใช้กับหน้าจอเดียว หรือทุกหน้าจอที่ [เลย์เอาต์สากล](/universal-layouts) โหลดเข้ามา

# การสร้างเทมเพลต

1. เพิ่มองค์ประกอบปุ่มลงในเลย์เอาต์
2. คลิกขวาที่ปุ่ม เปิด **Template Settings** แล้วเปิด **Template Mode**
3. ตั้งค่า **Share Settings With** เป็น **Buttons** หรือ **Sliders**
4. กำหนดพื้นผิว เสียง และการตั้งค่าป้ายกำกับตามต้องการ เช่นเดียวกับปุ่มทั่วไป หากตั้งค่าเป็น **Sliders** การตั้งค่าพื้นผิวจะใช้กับพื้นผิวของแถบเลื่อน

เทมเพลตจะไม่แสดงเมื่ออยู่นอกตัวแก้ไข ดังนั้นจะวางไว้ตรงไหนก็ได้ที่ไม่กีดขวาง ในตัวแก้ไข เทมเพลตสำหรับแถบเลื่อนจะมีลักษณะเหมือนแถบเลื่อน

# สิ่งที่เทมเพลตถ่ายทอด

## ถ่ายทอดเสมอ

- พื้นผิวปุ่ม (หรือพื้นผิวแถบเลื่อน) รวมถึงการตั้งค่า [การแบ่งภาพเก้าส่วน](/nine-slicing-and-tiling)
- เสียงเมื่อชี้เมาส์ออกจากปุ่ม เสียงเมื่อชี้เมาส์เข้าไป และเสียงคลิก

ขณะที่เทมเพลตทำงาน ปุ่มจะใช้พื้นผิวและเสียงของเทมเพลตแทนของตัวเอง หากเทมเพลตไม่มีพื้นผิว ปุ่มก็จะไม่ใช้พื้นผิวของตัวเองเช่นกัน

## เปิดใช้เมื่อต้องการ

เปิดการตั้งค่าเหล่านี้ใน **Template Settings** ของเทมเพลต:

| การตั้งค่า | สิ่งที่ปุ่มได้รับจากเทมเพลต |
|---|---|
| **Share Label in Template Mode** | **Label** และ **Hover Label** ของเทมเพลต รวมถึงรูปแบบป้ายกำกับทั้งหมด ได้แก่ **Label Alignment**, **Label Scale**, **Label Base Color**, **Label Hover Color**, **Label Shadow** และ **Underline Label On Hover** |
| **Share X-Position in Template Mode** และ **Share Y-Position in Template Mode** | ตำแหน่งของเทมเพลต ปุ่มดั้งเดิมจะขยับก็ต่อเมื่อ **Anchor Point** ไม่ได้ตั้งเป็น **Vanilla (Original)** |
| **Share Opacity in Template Mode** | ความทึบของเทมเพลต |

## การจัดแนวป้ายกำกับของปุ่มทั้งหมด

เมื่อเปิด **Share Label in Template Mode** ปุ่มทั้งหมดจะได้รับข้อความของเทมเพลตด้วย จึงเหมาะสำหรับหน้าจอที่ต้องการให้ปุ่มทุกปุ่มแสดงข้อความเดียวกัน

หากต้องการจัดแนวป้ายกำกับเท่านั้นโดยคงข้อความเดิมไว้:

- สำหรับหน้าจอเดียว ให้เลือกปุ่มโดยกด `Ctrl` ค้างไว้แล้วคลิก (ดู [การเลือก](/layout-editor#selecting)) จากนั้นคลิกขวาที่ปุ่มใดปุ่มหนึ่ง แล้วตั้งค่า **Label Alignment** ให้ปุ่มทั้งหมดพร้อมกัน
- สำหรับทุกเมนู ให้ใช้ **Label Alignment** ใน [การปรับแต่งส่วนกลาง](/global-customizations#labels)

# ข้อควรรู้

- ใช้ได้เฉพาะองค์ประกอบปุ่มเป็นเทมเพลต แต่เทมเพลตใช้ได้กับปุ่มและแถบเลื่อนทั้งแบบดั้งเดิมและแบบกำหนดเอง
- หน้าจอหนึ่งมีเทมเพลตสำหรับปุ่มและเทมเพลตสำหรับแถบเลื่อนพร้อมกันได้ หากมีเทมเพลตชนิดเดียวกันมากกว่าหนึ่งรายการ จะมีเพียงรายการเดียวที่ทำงาน
- เทมเพลตจะทำงานเฉพาะเมื่อมองเห็นเท่านั้น คุณสามารถเปิดหรือปิดเทมเพลตได้โดยกำหนด[เงื่อนไข](/element-visibility)ให้กับเทมเพลต
