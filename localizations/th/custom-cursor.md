# เคอร์เซอร์เมาส์แบบกำหนดเอง

เพิ่ม[องค์ประกอบ **Cursor**](/elements#cursor) ลงในเลย์เอาต์เพื่อแทนที่เคอร์เซอร์ของระบบในหน้าจอนั้น:

1. เลือก **New Element -> Cursor**
2. ตั้งค่าเท็กซ์เจอร์ PNG ที่มีสี RGBA
3. ตั้งค่า **Hotspot X** และ **Hotspot Y** เป็นพิกเซลบนเท็กซ์เจอร์ที่ต้องการให้คลิกเกิดขึ้น
4. เปิดใช้ตัวอย่างในเอดิเตอร์เมื่อต้องการตรวจสอบเคอร์เซอร์ขณะแก้ไข
5. ใช้[เลย์เอาต์สากล](/universal-layouts) เมื่อเคอร์เซอร์เดียวกันควรปรากฏบนหลายหน้าจอที่รองรับ

แนะนำให้ใช้เท็กซ์เจอร์เคอร์เซอร์ขนาดเล็ก เช่น `32×32` หรือ `64×64` ลักษณะและการทำงานของเคอร์เซอร์อาจแตกต่างกันไปตามระบบปฏิบัติการ
