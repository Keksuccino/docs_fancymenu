# เคอร์เซอร์เมาส์แบบกำหนดเอง

เพิ่ม [**องค์ประกอบ Cursor**](./elements#cursor) ลงในเลย์เอาต์เพื่อแทนที่เคอร์เซอร์ของระบบบนหน้าจอนั้น:

1. เลือก **New Element -> Cursor**.
2. ตั้งค่าพื้นผิว PNG ที่มีสีแบบ RGBA.
3. ตั้งค่า **Hotspot X** และ **Hotspot Y** ให้เป็นพิกเซลของพื้นผิวที่ต้องการให้จุดคลิกเกิดขึ้น.
4. เปิดการแสดงตัวอย่างในตัวแก้ไขเมื่อคุณต้องการตรวจสอบเคอร์เซอร์ขณะกำลังแก้ไข.
5. ใช้ [Universal Layout](./universal-layouts) เมื่อคุณต้องการให้เคอร์เซอร์แบบเดียวกันแสดงบนหลายหน้าจอที่รองรับ.

แนะนำให้ใช้พื้นผิวเคอร์เซอร์ขนาดเล็ก เช่น `32×32` หรือ `64×64` ลักษณะและพฤติกรรมของเคอร์เซอร์อาจแตกต่างกันไปตามระบบปฏิบัติการ.
