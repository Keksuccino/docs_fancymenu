# สลับส่วนต่าง ๆ ของเลย์เอาต์

บางครั้งการให้ผู้ใช้มีตัวเลือกก็เป็นเรื่องดี! บางทีผู้ใช้ของคุณอาจไม่ชอบฟัง Rick Astley เป็นเพลงเมนูตลอดเวลา หรืออยากใช้ภาพพื้นหลังเมนูเป็นสาวอนิเมะน่ารักคนอื่นแทน

ไม่เป็นปัญหา! คุณสามารถทำให้ผู้ใช้สลับเปิด/ปิดส่วนต่าง ๆ ของเลย์เอาต์ หรือวนสลับไปมาระหว่างหลายเวอร์ชันของส่วนนั้นได้

# สลับเปิด/ปิด

ถ้าต้องการสลับ เช่น การแสดงผลขององค์ประกอบโดยการคลิกปุ่ม คุณเพียงแค่ต้องใช้ตัวแปรที่ถูกกำหนดค่าเมื่อกดปุ่ม และให้องค์ประกอบที่ต้องการสลับตรวจสอบในเงื่อนไขการโหลดว่า ตัวแปรนั้นมีค่าตรงตามที่ต้องการหรือไม่

## ตัวแปร

สิ่งแรกคือการสร้างตัวแปรที่จะใช้เก็บสถานะการแสดงผลขององค์ประกอบที่คุณต้องการสลับ

เพื่อเพิ่มตัวแปรใหม่ ให้ไปที่แท็บ **Customization** ในแถบเมนู แล้วคลิก **Variables -> Manage Variables** จากนั้นเพิ่มตัวแปรใหม่ด้วยชื่อที่ **ไม่ซ้ำ**! โปรดตรวจสอบให้แน่ใจว่าใช้ชื่อที่ **ไม่ซ้ำจริง ๆ** และไม่ได้ถูกใช้อยู่แล้ว

หลังจากสร้างตัวแปรแล้ว ให้ตั้งค่าเป็น `true`

<br>
<img width="494" alt="Screenshot_9" src="https://gist.github.com/assets/35544624/1e29be13-e601-4669-8fa2-d78db945b07f">

## องค์ประกอบ

ขั้นตอนถัดไปคือการเพิ่มองค์ประกอบที่คุณต้องการสลับเปิด/ปิด

<br>
<img width="270" alt="Screenshot_3" src="https://gist.github.com/assets/35544624/317460fc-310b-4941-ab9a-b56490c5ebb9">

จากนั้นคลิกขวาที่องค์ประกอบ แล้วคลิก **Loading Requirements**
การดำเนินการนี้จะเปิดหน้าจอ Manage Requirements ให้คลิก **Add Requirement**

ค้นหาเงื่อนไข **Is Variable Value** เลือกมัน แล้วคลิก **Edit Requirement Value**

<br>
<img width="501" alt="Screenshot_1" src="https://gist.github.com/assets/35544624/d0d342f5-617c-415e-b6f7-05087fc204b7">

ตอนนี้ให้ใส่ชื่อตัวแปรที่คุณสร้างไว้ก่อนหน้านี้ และตั้งให้เงื่อนไขตรวจสอบค่าเป็น `true`

<br>
<img width="500" alt="Screenshot_2" src="https://gist.github.com/assets/35544624/a1f356e9-7f96-4d8b-87b0-51f05898409a">

แค่นี้สำหรับส่วนนี้ องค์ประกอบของคุณจะมองเห็นได้เมื่อค่าของตัวแปรเป็น `true`

## ปุ่ม

ตอนนี้เราต้องเพิ่มองค์ประกอบแบบ Button ใหม่

<br>
<img width="270" alt="Screenshot_4" src="https://gist.github.com/assets/35544624/1bd1b781-0cdb-4b52-80a0-db8f44ead0db">

หลังจากเพิ่มแล้ว ให้คลิกขวาและคลิก **Edit Action Script**
การดำเนินการนี้จะเปิดหน้าจอ Manage Action Script ของปุ่ม

คลิก **Add IF Statement** เพิ่มเงื่อนไข **Is Variable Value** เข้าไป แล้วตั้งโหมดของเงื่อนไขเป็น **OPPOSITE**

<br>
<img width="520" alt="Screenshot_5" src="https://gist.github.com/assets/35544624/a024ea21-2244-4ca6-b44b-1a80f7936b8f">

ตอนนี้คลิก **Edit Requirement Value** เหมือนที่ทำกับองค์ประกอบก่อนหน้านี้ แล้วใส่ชื่อตัวแปรและค่าที่ต้องการตรวจสอบให้ตรงกันทุกอย่าง

<br>
<img width="500" alt="Screenshot_2" src="https://gist.github.com/assets/35544624/a1f356e9-7f96-4d8b-87b0-51f05898409a">

เพราะเราตั้งโหมดเงื่อนไขเป็น **OPPOSITE** ตอนนี้มันจะตรวจสอบว่าค่าของตัวแปรไม่ใช่ `true` ซึ่งตรงกับสิ่งที่เราต้องการพอดี

กลับไปที่หน้าจอ Edit Action Script คุณจะเห็น IF statement ที่เราเพิ่งเพิ่มเข้ามา

<br>
<img width="495" alt="Screenshot_6" src="https://gist.github.com/assets/35544624/6ac8444c-ca15-43ff-a633-df63e76e7433">

ตอนนี้คลิก **Add Action** ค้นหาแอ็กชัน **Set Variable Value** เลือกมัน แล้วคลิก **Edit Action Value**

<br>
<img width="494" alt="Screenshot_7" src="https://gist.github.com/assets/35544624/8568e539-b4d0-49bd-89c4-4659ee71754c">

ในค่าแอ็กชัน ให้ใส่ชื่อตัวแปรก่อน แล้วตามด้วยค่าที่คุณต้องการตั้งค่า แยกชื่อและค่าด้วย `:`
ในกรณีนี้เราต้องการตั้งค่าเป็น `true` เพราะแอ็กชันนี้จะถูกเรียกใช้เมื่อค่าปัจจุบันไม่ใช่ `true`

<br>
<img width="496" alt="Screenshot_8" src="https://gist.github.com/assets/35544624/fab440ad-b335-4751-9651-4bb0b65bc968">

จากนั้นให้นำแอ็กชันไปต่อเข้ากับ IF statement โดยลากแล้ววางไว้บน IF statement เพื่อให้มันถูกเรียกใช้เฉพาะเมื่อค่าของตัวแปรไม่ใช่ `true`

<br>
<img width="496" alt="Screenshot_8" src="https://gist.github.com/assets/35544624/d1ac3ea9-44d7-4ad6-a4b2-455b21f6d1c4">

หลังจากนั้น ให้เลือก IF statement แล้วคลิก **Append ELSE Statement**

ตอนนี้เพิ่มแอ็กชัน **Set Variable Value** อีกอัน แต่แทนที่จะตั้งค่าตัวแปรเป็น `true` ให้ตั้งเป็น `false`

<br>
<img width="494" alt="Screenshot_9" src="https://gist.github.com/assets/35544624/d05400dc-b9b7-4c1a-8657-9e34939ed599">

จากนั้นให้นำแอ็กชันตัวที่สองไปต่อเข้ากับ ELSE statement เพื่อให้มันถูกเรียกใช้เมื่อค่าของตัวแปรเป็น `true`

<br>
<img width="494" alt="Screenshot_9" src="https://gist.github.com/assets/35544624/3191a1cc-c5c2-4cf1-a620-23bdbe639bf2">

แค่นั้นเอง! ตอนแรกอาจดูเหมือนมีหลายขั้นตอน แต่จริง ๆ แล้วพอคุ้นแล้วมันเป็นเรื่องที่ทำได้ง่ายและเร็วมาก

ตอนนี้คุณสามารถบันทึกเลย์เอาต์ ออกจากตัวแก้ไข แล้วกดปุ่มเพื่อดูว่ามันทำงานหรือไม่!

<br>
<img width="494" alt="Screenshot_9" src="https://gist.github.com/assets/35544624/e9a87aca-ba0f-4ce6-a39e-1e1d3796c9e3">

คุณสามารถใช้ตัวแปรเดียวกันกับองค์ประกอบอื่น ๆ ได้ด้วย เพื่อให้คุณ **สลับหลายองค์ประกอบพร้อมกัน** ด้วยการกดปุ่ม

คุณยังสามารถสลับทั้งเลย์เอาต์ได้โดยใช้ **Layout-Wide Loading Requirements** ด้วยนะ หากต้องการตั้งค่าเงื่อนไขระดับเลย์เอาต์ ให้คลิกขวาที่พื้นหลังของตัวแก้ไข เพียงแค่ต้องแน่ใจว่าเพิ่มปุ่มไว้ในอีกเลย์เอาต์หนึ่ง ไม่ใช่เลย์เอาต์ที่คุณต้องการสลับ

# วนสลับไปมา

นอกจากการสลับระหว่างสองค่าแล้ว การวนสลับค่าจะต้องใช้อีกับสคริปต์ที่สามารถวนระหว่างค่ามากกว่าสองค่าได้

ตรรกะของ action script คล้ายกับที่ใช้สำหรับการสลับเปิด/ปิดมาก ดังนั้นฉันจะอธิบายสั้น ๆ ที่นี่ โปรดอ่านส่วนเกี่ยวกับการสลับเปิด/ปิดด้วย

ฉันเพิ่มรูปภาพ 3 รูป รูปแรกจะแสดงเมื่อค่าของตัวแปรเป็น `1` รูปที่สองเมื่อค่าเป็น `2` และรูปที่สามเมื่อค่าเป็น `3`

<br>
<img width="494" alt="Screenshot_9" src="https://gist.github.com/assets/35544624/731c13cf-6f81-470b-8e1b-cba264ffbe05">

หลังจากนั้นฉันเพิ่มปุ่มสำหรับวนค่า และทำให้มันเปลี่ยนค่าของตัวแปรจาก `1` ไป `2` ไป `3` แล้วกลับไป `1`

<br>
<img width="609" alt="Screenshot_1" src="https://gist.github.com/assets/35544624/9f2052b1-8d3d-4a35-884a-4a234e63d5e5">

แค่นั้นเอง ตอนนี้ให้บันทึกเลย์เอาต์ ออกจากตัวแก้ไข แล้วตรวจสอบว่าปุ่มสำหรับวนค่านั้นทำงานถูกต้องหรือไม่
