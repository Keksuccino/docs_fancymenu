# เพลงพื้นหลังเมนู

คุณสามารถแทนที่เพลงพื้นหลังเมนูเริ่มต้นของ Minecraft ด้วยเพลงที่กำหนดเอง หรือจะปิดเพลง Vanilla ปกติที่เล่นในเมนูก็ได้

# การปิดเพลง Vanilla

FancyMenu มีหลายวิธีในการปิดเพลงเมนู Vanilla วิธีนี้มีประโยชน์หากคุณวางแผนจะเล่นเสียงอื่นในหน้าจอ หรือถ้าคุณแค่ไม่ต้องการให้มีเพลงเล่นเลยในบางหน้าจอ

## ทั่วทั้งระบบ

หากคุณไม่ต้องการให้มีเพลงในเมนูเลย นี่เป็นวิธีที่ง่ายที่สุด

หากต้องการปิดหรือแทนที่เพลงเมนู Vanilla แบบทั่วทั้งระบบใน FancyMenu 3.9.0+ ให้ไปที่แถบเมนูของ FancyMenu ที่ด้านบนของหน้าจอ แล้วคลิก **Customization -> Global Customizations**. Global Customizations สามารถแทนที่เพลงเมนูได้โดยไม่ต้องใช้ resource pack และไม่ต้องเปิดใช้งานการปรับแต่งสำหรับทุกหน้าจอ

## แยกตามหน้าจอ

หากคุณต้องการควบคุมมากขึ้นว่าเพลงเมนู Vanilla ควรเล่นที่ไหน ให้ใช้เอลิเมนต์ **Music Controller** เอลิเมนต์นี้จะถูกเพิ่มเข้าไปในเลย์เอาต์เหมือนกับเอลิเมนต์อื่น ๆ โดย **คลิกขวาที่พื้นหลังของตัวแก้ไข** แล้วคลิก **New Element -> Music Controller**

โดยการ **คลิกขวา** ที่เอลิเมนต์ คุณสามารถกำหนดได้ว่าควรปิดเพลงประเภทใดบ้างที่เล่นในเมนู (เพลงเมนูปกติ และเพลงโลกที่ยังเล่นต่อในหน้าจอที่ไม่หยุดเกม เช่นหน้าจอ Inventory)

> เอลิเมนต์นี้รองรับ **เงื่อนไขการโหลด** จึงให้คุณควบคุมได้มากขึ้นว่าเมื่อใดเพลง Vanilla ควรเล่น!
{.is-info}


# การเพิ่มเพลงแบบกำหนดเอง

ตอนนี้เรามาเพิ่มเพลงพื้นหลังแบบกำหนดเองจริง ๆ กัน

หากคุณต้องการเล่นเพลงแบบกำหนดเองเดียวกันในทุกหน้าจอ และต้องการควบคุมในระดับเลย์เอาต์ ควรใช้ **universal layout** ซึ่งจะถูกโหลดในทุกหน้าจอที่เปิดใช้งานการปรับแต่ง สำหรับการแทนที่เพลงเมนูแบบทั่วทั้งระบบอย่างง่าย ให้ใช้ [Global Customizations](/global-customizations) แทน

เมื่อใช้ universal layout เพลงจะ **เล่นต่อเนื่อง** เมื่อเปลี่ยนจากเมนูหนึ่งที่เปิดใช้งานเลย์เอาต์นี้ไปยังอีกเมนูหนึ่งที่เปิดใช้งานเลย์เอาต์เดียวกัน

หากคุณต้องการเล่นเพลงแตกต่างกันในแต่ละหน้าจอ ให้ใช้เลย์เอาต์ปกติ

ในตัวอย่างนี้ เราจะใช้ **universal layouts**

เพิ่มเอลิเมนต์ **Audio** ใหม่ลงใน universal layout ซึ่งจะทำหน้าที่เป็นเครื่องเล่นเพลงพื้นหลังของเรา

บันทึกเลย์เอาต์และออกจากตัวแก้ไข

# เปิดใช้งานการปรับแต่งสำหรับทุกเมนู

เราใช้ **universal layout** ในตัวอย่างนี้ เพราะเราต้องการให้เพลงพื้นหลังของเราเล่นได้ในหลายหน้าจอ

เนื่องจากเลย์เอาต์จะถูกโหลดเฉพาะในหน้าจอที่เปิดใช้งาน **customizations** เท่านั้น ตอนนี้เราจึงต้องเปิดใช้งานสำหรับทุกหน้าจอที่เราต้องการให้เพลงของเราเล่น

ในการทำเช่นนั้น ให้คลิก **Customization** และเปิดใช้งาน **Current Screen Customization**

<br>
<img width="320" alt="Screenshot_5" src="https://gist.github.com/assets/35544624/2f6527b7-ae14-4e82-abc6-3572cc6490b2">

ทำซ้ำขั้นตอนนี้สำหรับทุกหน้าจอที่คุณต้องการให้เพลงพื้นหลังแบบกำหนดเองเล่น

และนั่นก็เสร็จเรียบร้อยแล้ว! ตอนนี้คุณมีเพลงพื้นหลังแบบกำหนดเองในเมนู Minecraft ของคุณแล้ว!
