# สไลด์โชว์

FancyMenu ช่วยให้คุณเพิ่มสไลด์โชว์และแสดงผลในเมนู รวมถึงใช้เป็นพื้นหลังของเมนูได้

> **สำคัญ**: หากคุณใช้ Windows อย่าลืมเปิดแสดง [นามสกุลไฟล์](https://vtcri.kayako.com/article/296-view-file-extensions-windows-10) ไว้ด้วย ไม่เช่นนั้นคุณจะมองไม่เห็นส่วนสำคัญของชื่อไฟล์ในภายหลัง!
{.is-warning}

# การสร้างสไลด์โชว์

สไลด์โชว์แต่ละชุดต้องอยู่ในโฟลเดอร์ของตัวเอง **ภายใน** ไดเรกทอรี slideshows ที่อยู่ที่ `/config/fancymenu/slideshows/`.

![1](https://user-images.githubusercontent.com/35544624/105209961-b823e600-5b4a-11eb-8ed2-1016d3b05815.png)

เพื่อให้ระบบรู้จักว่าเป็นสไลด์โชว์ จะต้องมีไฟล์ properties อยู่ในโฟลเดอร์ของสไลด์โชว์นั้น ดังนั้นถ้าคุณตั้งชื่อโฟลเดอร์สไลด์โชว์ว่า `myslideshow` ไฟล์ properties ควรอยู่ที่ `/config/fancymenu/slideshows/myslideshow/properties.txt`.

**ไฟล์นี้ต้องมีชื่อว่า `properties.txt` เสมอ!**
ตอนนี้ให้สร้างไฟล์ properties แบบ **ว่างเปล่า** ก่อน แล้วไปขั้นตอนถัดไป

![2](https://user-images.githubusercontent.com/35544624/105210016-cbcf4c80-5b4a-11eb-84ad-9aa735340287.png)

## การเพิ่มรูปภาพ

สไลด์โชว์ต้องมีรูปภาพ (ก็แน่นอนอยู่แล้ว) งั้นมาเพิ่มกันเลย!

> รูปภาพของสไลด์โชว์ต้องเป็นไฟล์ **PNG** เท่านั้น! ไม่มี JPEG, GIF, APNG หรือ FMA!
{.is-danger}

รูปภาพทั้งหมดของสไลด์โชว์จะอยู่ในโฟลเดอร์เพิ่มเติม **ภายใน** โฟลเดอร์สไลด์โชว์ของคุณ (`myslideshow` ในตัวอย่างด้านบน)
โฟลเดอร์นี้ต้องมีชื่อว่า `images`

![3](https://user-images.githubusercontent.com/35544624/105210833-d9d19d00-5b4b-11eb-8ae7-528ad156e27a.png)

จากนั้นให้นำรูปภาพสไลด์โชว์ทั้งหมดไปไว้ในโฟลเดอร์ `images`
รูปภาพจะถูกเรียงตามลำดับตัวอักษร (โดยคำนึงถึงตัวเลข) ดังนั้นให้ตั้งชื่อประมาณ `image_1.png`, `image_2.png` และต่อๆ ไป
ในตัวอย่างของฉัน `image_1.png` จะแสดงก่อน และ `image_2.png` จะแสดงถัดมา

## การเพิ่มเนื้อหาในไฟล์ Properties

ตอนแรกคุณได้สร้างไฟล์ `properties.txt` แบบว่างเปล่าไว้ในโฟลเดอร์สไลด์โชว์ของคุณแล้ว
ตอนนี้ไฟล์นี้ต้องถูกเติมด้วยข้อมูลสำคัญบางอย่าง

ไฟล์ properties ของสไลด์โชว์แต่ละชุดควรมีลักษณะดังนี้:

```
type = slideshow

slideshow-meta {
   name = cool_slideshow
   width = 1920
   height = 1080
   x = 0
   y = 0
   duration = 5.0
   fadespeed = 12.0
   randomize = false
}
```
เฉพาะตัวแปรภายในส่วน `slideshow-meta` เท่านั้นที่สามารถเปลี่ยนได้!

### name

นี่คือชื่อ หรือให้ชัดกว่านั้นคือรหัสระบุ ของสไลด์โชว์ของคุณ
ชื่อสไลด์โชว์ต้องไม่ซ้ำกัน ดังนั้นจึงไม่สามารถมีสไลด์โชว์สองชุดที่ใช้ชื่อเดียวกันได้!

### width | height

ค่า `width` และ `height` พื้นฐานของสไลด์โชว์ของคุณ
FancyMenu ใช้ค่านี้เพื่อคำนวณอัตราส่วนภาพ

### x | y

ตำแหน่ง `x` และ `y` ของสไลด์โชว์ของคุณ
มีไว้เพื่อการดีบักเป็นหลัก ดังนั้นให้ตั้งทั้งสองค่าเป็น `0`

### duration

ระยะเวลาเป็น **วินาที** ที่แต่ละภาพจะแสดงก่อนจะเปลี่ยนไปภาพถัดไป
รองรับค่าทศนิยม!

### fadespeed

ความเร็วของแอนิเมชันเฟดเมื่อเปลี่ยนไปยังภาพถัดไป
ค่านี้เป็นตัวคูณความเร็ว ตัวอย่างเช่น `1.0` คือความเร็วปกติ, `2.0` คือเร็วขึ้นสองเท่า และ `0.5` คือช้ากว่าปกติครึ่งหนึ่ง
ไม่รองรับค่าติดลบ

### randomize

กำหนดให้รูปภาพในสไลด์โชว์เล่นแบบสุ่มลำดับ (`true`) หรือไม่ (`false`)

# การใช้งานสไลด์โชว์

ทุกขั้นตอนสำคัญเสร็จแล้ว และตอนนี้สไลด์โชว์ของคุณน่าจะพร้อมใช้งานแล้ว งั้นมาทดสอบกัน!

หากต้องการโหลดสไลด์โชว์ใหม่ (หรือสไลด์โชว์ที่แก้ไขแล้ว) เข้า FancyMenu ให้รีโหลดม็อดผ่าน **การปรับแต่ง -> โหลด FancyMenu ใหม่**

ตอนนี้คุณสามารถใช้สไลด์โชว์ของคุณในองค์ประกอบ **Slideshow** หรือใช้เป็นพื้นหลังเมนูได้ (คลิกขวาพื้นหลังของตัวแก้ไขเลย์เอาต์ -> **Menu Background**).
