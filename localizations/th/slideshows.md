# สไลด์โชว์

สไลด์โชว์จะแสดงภาพต่อเนื่องทีละภาพ พร้อมเอฟเฟกต์จางเปลี่ยนจากภาพหนึ่งไปยังอีกภาพอย่างนุ่มนวล เช่น ภาพหน้าจอจากโลกในม็อดแพ็กของคุณ

คุณจะแสดงสไลด์โชว์เป็น[พื้นหลังเมนู](/menu-backgrounds)ของเลย์เอาต์ หรือใช้[องค์ประกอบสไลด์โชว์](/elements#slideshow)ในส่วนหนึ่งของหน้าจอก็ได้

<img width="800" alt="หน้าจอ Title ที่ใช้สไลด์โชว์เป็นพื้นหลัง โดยภาพค่อย ๆ เปลี่ยนจากหุบเขาริมแม่น้ำไปเป็นป่าซากุระและชายฝั่ง ซึ่งเป็นภาพหน้าจอจากโลก Minecraft" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/slideshows_title.gif?raw=true">

# สร้างสไลด์โชว์

1. เปิดโฟลเดอร์ `slideshows` ใน `config/fancymenu/` ภายในโฟลเดอร์เกมของคุณ โดยเลือก **แถบเมนู -> Tools -> Open FancyMenu Directory** เพื่อเปิด `config/fancymenu/`
2. สร้างโฟลเดอร์สำหรับสไลด์โชว์ไว้ข้างใน เช่น `world_tour` จะตั้งชื่อว่าอะไรก็ได้
3. ใส่ไฟล์ [`properties.txt`](#propertiestxt) และโฟลเดอร์ชื่อ `images` ที่มี[ภาพของคุณ](#the-images)ไว้ข้างใน คุณจะใส่ไฟล์ [`overlay.png`](#overlay) เพิ่มด้วยก็ได้
4. โหลด FancyMenu ใหม่โดยเลือก **แถบเมนู -> Customization -> Reload FancyMenu** หรือกด `Ctrl + Alt + R` (`Cmd + Alt + R` บน macOS) หรือเริ่มเกมใหม่

```text
config/fancymenu/slideshows/
└── world_tour/
    ├── properties.txt
    ├── overlay.png
    └── images/
        ├── 01_river_valley.png
        ├── 02_cherry_grove.png
        └── 03_coast.png
```

# รูปภาพ

- ระบบจะนับเฉพาะไฟล์ PNG และ JPG ที่ชื่อไฟล์ลงท้ายด้วย `.png` หรือ `.jpg` ให้เปลี่ยนนามสกุลไฟล์ `.jpeg` เป็น `.jpg`
- ภาพจะแสดงตามลำดับชื่อไฟล์จาก A ถึง Z ตัวเลขจะเรียงเหมือนตัวอักษร ดังนั้น `10.png` จะมาก่อน `2.png` ให้เติมเลขศูนย์นำหน้า เช่น `01`, `02` … `10`
- กำหนดให้ภาพทุกภาพมีขนาดเท่ากัน ภาพแรกจะเป็นตัวกำหนดสัดส่วนของสไลด์โชว์ ส่วนภาพอื่น ๆ จะถูกยืดให้พอดี
- ระบบจะไม่นับไฟล์ที่อยู่ในโฟลเดอร์ย่อยภายใน `images`

# properties.txt

```text
type = slideshow

slideshow-meta {
  name = world_tour
  duration = 5.0
  fadespeed = 5.0
  randomize = false
}
```

| การตั้งค่า | หน้าที่ |
|---|---|
| `name` | ชื่อที่ใช้เลือกสไลด์โชว์ ตั้งชื่อให้แต่ละสไลด์โชว์ไม่ซ้ำกัน |
| `duration` | จำนวนวินาทีตั้งแต่เปลี่ยนภาพหนึ่งไปยังภาพถัดไป โดยนับรวมช่วงจางเปลี่ยนภาพด้วย หากใช้เวลาจางนานขึ้น การเปลี่ยนภาพครั้งถัดไปจะรอจนกว่าจะจางเสร็จ |
| `fadespeed` | ความเร็วในการจางเปลี่ยนจากภาพหนึ่งไปยังภาพถัดไป เมื่อกำหนดเป็น `1.0` การจางจะใช้เวลาประมาณ 6 วินาที ส่วน `3.0` จะใช้เวลาประมาณ 2 วินาที ค่านี้ต้องมากกว่า `0` |
| `randomize` | `true` จะแสดงภาพแบบสุ่ม โดยจะไม่แสดงภาพเดิมซ้ำติดกัน ส่วน `false` จะแสดงภาพตามลำดับชื่อไฟล์ |

จำเป็นต้องระบุเพียง `name` เท่านั้น การตั้งค่าที่ไม่ได้ระบุจะใช้ค่า `duration = 10.0`, `fadespeed = 1.0` และ `randomize = false` ให้คงบรรทัด `type = slideshow` และ `slideshow-meta {` ไว้ตามเดิม เขียนการตั้งค่าหนึ่งรายการต่อบรรทัด และใช้จุดสำหรับทศนิยม เช่น `2.5`

สไลด์โชว์ที่สร้างด้วยเวอร์ชันเก่าอาจมีบรรทัด `width`, `height`, `x` และ `y` ซึ่งไม่มีผลใด ๆ เพราะพื้นหลังหรือองค์ประกอบเป็นตัวกำหนดตำแหน่งและขนาดของสไลด์โชว์

# Overlay

ไฟล์ `overlay.png` ที่อยู่ข้าง `properties.txt` จะถูกวาดทับบนภาพทุกภาพ และยืดให้มีขนาดเท่ากับสไลด์โชว์ ไฟล์นี้จะไม่จางไปพร้อมกับภาพ จึงเหมาะสำหรับทำกรอบ เอฟเฟกต์ขอบมืด หรือโลโก้ตรงมุม ส่วนที่โปร่งใสจะเผยให้เห็นภาพด้านล่าง

Overlay เป็นส่วนหนึ่งของสไลด์โชว์ จึงจะแสดงทุกที่ที่สไลด์โชว์แสดงอยู่ หากต้องการใช้ภาพชุดเดียวกันทั้งแบบมีและไม่มีกรอบ ให้สร้างสไลด์โชว์สองชุด

# ใช้สไลด์โชว์

## ใช้เป็นพื้นหลังเมนู

<img width="800" alt="เปิด Menu Backgrounds และเลือก Slideshow ในตัวแก้ไขเลย์เอาต์ จากนั้นเปิด Show Background และเลือก world_tour ใน Choose Slideshow โดยตัวอย่างทางขวาจะแสดงภาพถัดไปที่ค่อย ๆ จางเข้ามา แล้วสไลด์โชว์จะแสดงอยู่ด้านหลังปุ่มบนหน้าจอ Title" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/slideshows_background.gif?raw=true">

1. ใน[ตัวแก้ไขเลย์เอาต์](/layout-editor) คลิกขวาที่พื้นหลัง แล้วเปิด **Menu Backgrounds -> Slideshow**
2. คลิก **Show Background** เพื่อเปิดใช้งาน
3. คลิก **Slideshow Name** เลือกสไลด์โชว์ของคุณ แล้วคลิก **Done** ตัวอย่างทางขวาจะแสดงสไลด์โชว์

เลือก **Clear Slideshow** เพื่อลบสไลด์โชว์ออก หากต้องการใช้ร่วมกับพื้นหลังอื่น โปรดดู[พื้นหลังเมนู](/menu-backgrounds)

สไลด์โชว์จะถูกยืดให้เต็มหน้าจอ หากต้องการคงสัดส่วนของภาพ ให้เปิด **Preserve Background Aspect Ratio** ใน **Menu Backgrounds** สไลด์โชว์จะเต็มหน้าจอ โดยส่วนขอบหรือด้านบนและด้านล่างจะถูกตัดออก

## ใช้เป็นองค์ประกอบ

<img width="800" alt="หน้าจอ Title ที่มีปุ่มอยู่ทางซ้ายและองค์ประกอบสไลด์โชว์อยู่ทางขวา โดยแสดงภาพหน้าจอจากโลก Minecraft สลับภาพอย่างนุ่มนวล" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/slideshows_element.gif?raw=true">

1. ในตัวแก้ไขเลย์เอาต์ คลิกขวาบริเวณว่าง แล้วเพิ่มสไลด์โชว์โดยเลือก **New Element**
2. คลิกขวาที่องค์ประกอบ คลิก **Slideshow** แล้วเลือกสไลด์โชว์ของคุณ องค์ประกอบจะปรับสัดส่วนตามภาพ
3. ย้ายและปรับขนาดได้เหมือนองค์ประกอบอื่น ๆ ปุ่ม **Restore Aspect Ratio** จะปรับความกว้างให้พอดีกับความสูงอีกครั้ง เพื่อไม่ให้ภาพถูกยืด

## โหลดล่วงหน้า

สไลด์โชว์จะโหลดภาพแต่ละภาพเมื่อแสดงภาพนั้นเป็นครั้งแรก ดังนั้นภาพขนาดใหญ่อาจปรากฏช้าไปชั่วขณะในครั้งแรก หากต้องการโหลดภาพทั้งหมดและ overlay ระหว่างเริ่มเกม ให้เพิ่มสไลด์โชว์ด้วย **Add Slideshow** ใน **แถบเมนู -> Customization -> Pre-Load Resources** ดูเพิ่มเติมที่ [Pre-Load Resources](/preload-layouts#pre-loading-slideshows--panoramas)

# เรื่องน่ารู้

- ทุกตำแหน่งที่แสดงสไลด์โชว์เดียวกันจะแสดงภาพเดียวกันในเวลาเดียวกัน แม้จะอยู่ในเมนูคนละหน้า
- สไลด์โชว์จะทำงานเฉพาะเมื่อมีสิ่งใดแสดงสไลด์โชว์นั้น หากกลับมาแสดงอีกครั้งหลังหยุดไปนานกว่า `duration` สไลด์โชว์จะจางเปลี่ยนไปยังภาพถัดไปทันที
- การโหลด FancyMenu ใหม่จะเริ่มสไลด์โชว์ทุกชุดใหม่ ภาพแรกหลังเริ่มต้นจะแสดงเพียงครึ่งหนึ่งของระยะเวลาที่ภาพอื่นแสดง
- สไลด์โชว์เป็นของ[โปรไฟล์](/profiles)ที่โหลดอยู่
- หากไม่พบสไลด์โชว์ใน **Choose Slideshow** แสดงว่าโหลดไม่สำเร็จ บันทึกของเกมที่ `logs/latest.log` จะระบุสาเหตุ เช่น ไม่มี `name`, `properties.txt` หรือโฟลเดอร์ `images`
- ใน Windows ให้เปิดการแสดงนามสกุลไฟล์ใน File Explorer เพื่อป้องกันไม่ให้ไฟล์ `properties.txt` กลายเป็น `properties.txt.txt` โดยไม่ตั้งใจ
- ลายตารางหมากรุกสีม่วงและดำหมายถึงยังไม่ได้เลือกสไลด์โชว์ หรือเลย์เอาต์ใช้ชื่อสไลด์โชว์ที่ไม่มีอยู่แล้ว
- หากสไลด์โชว์สองชุดมี `name` เหมือนกัน ระบบจะแสดงเพียงชุดเดียว
- **Debug Overlay** (`Ctrl + Alt + D`) จะแสดงจำนวนสไลด์โชว์และภาพที่ FancyMenu โหลดไว้
