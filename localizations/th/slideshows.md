# สไลด์โชว์

สไลด์โชว์แต่ละชุดจะมีไดเรกทอรีของตัวเองอยู่ด้านล่าง:

```text
<game-directory>/config/fancymenu/slideshows/
```

`<game-directory>` คืออินสแตนซ์ตัวเรียกเกมที่ใช้งานอยู่ ซึ่งอาจแตกต่างจากไดเรกทอรี `.minecraft` แบบปกติ

# โครงสร้างไดเรกทอรี

```text
<game-directory>/config/fancymenu/slideshows/
└── myslideshow/
    ├── properties.txt
    ├── overlay.png          # ไม่บังคับ
    └── images/
        ├── image_01.png
        └── image_02.jpg
```

รูปภาพต้องใช้นามสกุล `.png` หรือ `.jpg`; นามสกุลอื่น ๆ รวมถึง `.jpeg` จะถูกละเว้น

เมื่อ `randomize = false` รูปภาพจะเล่นตามลำดับชื่อไฟล์ตามตัวอักษรแบบไม่คำนึงถึงตัวพิมพ์เล็ก/ใหญ่ ใช้ชื่อแบบมีเลขนำหน้าด้วยศูนย์ เช่น `image_01.png`, `image_02.png`, และ `image_10.png`

# `properties.txt`

```text
type = slideshow

slideshow-meta {
  name = cool_slideshow
  width = 1920
  height = 1080
  x = 0
  y = 0
  duration = 5.0
  fadespeed = 12.0
  randomize = false
}
```

| Property | ความหมาย |
|---|---|
| `name` | จำเป็น เป็นตัวระบุที่ใช้ขณะรันแบบคำนึงถึงตัวพิมพ์เล็ก/ใหญ่ ต้องไม่ซ้ำกัน |
| `width`, `height` | ขนาดฐานในพิกเซลที่ปรับสเกลตาม GUI และอัตราส่วนภาพต้นฉบับ |
| `x`, `y` | ตำแหน่งมุมซ้ายบนฐาน; องค์ประกอบปกติและพื้นหลังจะใช้ตำแหน่งของตนเอง จึงควรตั้งค่านี้เป็น `0` |
| `duration` | จำนวนวินาทีขั้นต่ำระหว่างการเริ่มเปลี่ยนภาพ; รวมเวลาจางและต้องมากกว่า `0` |
| `fadespeed` | ตัวคูณความเร็วการจาง; `1.0` คือค่าเริ่มต้น ค่าที่มากกว่าจะจางเร็วขึ้น และค่าต้องมากกว่า `0` |
| `randomize` | `true` เพื่อสุ่ม หรือ `false` เพื่อเรียงตามชื่อไฟล์ |

จำเป็นต้องมีเพียง `name` เท่านั้น ค่าเริ่มต้นคือ `width = 50`, `height = 50`, `x = 0`, `y = 0`, `duration = 10.0`, `fadespeed = 1.0`, และ `randomize = false` ให้คง `type = slideshow` และ `slideshow-meta` ไว้เหมือนเดิม; เขียน `key = value` เพียงหนึ่งบรรทัดต่อหนึ่งรายการ และใช้จุดสำหรับทศนิยม

เลย์เอาต์จะเลือกค่าของ `name` ไม่ใช่ชื่อไดเรกทอรี ชื่อที่ซ้ำกันจะไม่ถูกปฏิเสธ และลำดับการสแกนไดเรกทอรีจะเป็นตัวกำหนดว่าสไลด์โชว์ใดจะยังคงใช้งานได้ ให้ตั้งชื่อไม่ซ้ำกันภายในไดเรกทอรี slideshows

โหมดสุ่มจะเลือกใหม่ในแต่ละรอบการเปลี่ยนภาพอย่างอิสระ และจะหลีกเลี่ยงการซ้ำกับภาพก่อนหน้าทันทีเมื่อมีรูปภาพหลายภาพ เวลาใช้ตามเวลาจริง; การจางที่ใช้เวลานานกว่า `duration` จะทำให้การเปลี่ยนภาพครั้งถัดไปล่าช้า และเมื่อกลับมาใช้สไลด์โชว์หลังจากถูกซ่อนไว้ อาจทำให้มันเลื่อนไปภาพถัดไปได้ทันที

# การใช้สไลด์โชว์

รีโหลด FancyMenu ผ่าน **Customization -> Reload FancyMenu** หรือรีสตาร์ตไคลเอนต์ ใช้ [**Slideshow** element](./elements#slideshow) หรือคลิกขวาที่พื้นหลังของตัวแก้ไขเลย์เอาต์ แล้วเลือก [**Menu Backgrounds**](./menu-backgrounds) -> **Slideshow**
