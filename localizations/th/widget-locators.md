# ตัวระบุตำแหน่งวิดเจ็ต

ตัวระบุตำแหน่งวิดเจ็ตใช้สำหรับชี้ไปยัง Vanilla widget เฉพาะเจาะจง (ปุ่ม, สไลเดอร์, ช่องป้อนข้อความ) ในเมนู ซึ่งจำเป็นสำหรับฟีเจอร์บางอย่างของ FancyMenu ที่ต้องโต้ตอบกับวิดเจ็ตในบางรูปแบบ

# การรับตัวระบุตำแหน่งของวิดเจ็ต

มีสองวิธีในการรับตัวระบุตำแหน่งของ Vanilla widget

วิธีแรกคือเปิดใช้งาน **debug overlay** ในเมนูที่มีวิดเจ็ตนั้น โดยกด **CTRL + ALT + D** จากนั้น **คลิกขวาที่วิดเจ็ต** ซึ่งจะเปิดเมนูบริบทพร้อมตัวเลือกให้คัดลอกตัวระบุตำแหน่งไปยังคลิปบอร์ด

วิธีที่สองคือเปิด **layout editor** สำหรับเมนูที่มีวิดเจ็ตนั้น จากนั้น **คลิกขวาที่องค์ประกอบวิดเจ็ต** ซึ่งจะเปิดเมนูบริบทเช่นกัน พร้อมตัวเลือกให้คัดลอกตัวระบุตำแหน่งไปยังคลิปบอร์ด

>[!WARNING]
>หากคุณ **ไม่สามารถคลิกขวาที่วิดเจ็ต** ผ่าน debug overlay ได้ หรือ **วิดเจ็ตไม่ปรากฏ** ใน layout editor ก็เป็นไปได้ว่าวิดเจ็ตนั้นไม่สามารถมองเห็นได้สำหรับ FancyMenu ซึ่งหมายความว่าในกรณีนั้นจะไม่มีตัวระบุตำแหน่ง โดยมักเกิดกับปุ่มของม็อดที่ถูกเพิ่มเข้าไปในเมนูด้วยวิธีแปลก ๆ
