# ตัวระบุตำแหน่งวิดเจ็ต

ตัวระบุตำแหน่งวิดเจ็ตใช้สำหรับระบุวิดเจ็ต Vanilla/ม็อดที่ต้องการ (ปุ่ม แถบเลื่อน ช่องกรอกข้อความ) ในเมนู ซึ่งจำเป็นสำหรับฟีเจอร์บางอย่างของ FancyMenu ที่ต้องโต้ตอบกับวิดเจ็ตในรูปแบบใดรูปแบบหนึ่ง

# การรับตัวระบุตำแหน่งของวิดเจ็ต

มีสองวิธีในการรับตัวระบุตำแหน่งของวิดเจ็ต Vanilla/ม็อด

วิธีแรกคือเปิดใช้งาน **โอเวอร์เลย์ดีบัก** ในเมนูที่มีวิดเจ็ตดังกล่าว โดยกด **CTRL + ALT + D** จากนั้น **คลิกขวาที่วิดเจ็ต** ซึ่งจะเปิดเมนูบริบทที่มีตัวเลือกสำหรับคัดลอกตัวระบุตำแหน่งไปยังคลิปบอร์ด

วิธีที่สองคือเปิด **ตัวแก้ไขเลย์เอาต์** ของเมนูที่มีวิดเจ็ตดังกล่าว จากนั้น **คลิกขวาที่องค์ประกอบวิดเจ็ต** ซึ่งจะเปิดเมนูบริบทที่มีตัวเลือกสำหรับคัดลอกตัวระบุตำแหน่งไปยังคลิปบอร์ดเช่นกัน

>[!WARNING]
>หากคุณ **ไม่สามารถคลิกขวา** ที่วิดเจ็ตผ่านโอเวอร์เลย์ดีบักได้ หรือวิดเจ็ตนั้น **ไม่ปรากฏ** ในตัวแก้ไขเลย์เอาต์ วิดเจ็ตดังกล่าวอาจไม่สามารถมองเห็นได้โดย FancyMenu ซึ่งหมายความว่าในกรณีนี้วิดเจ็ตจะไม่มีตัวระบุตำแหน่ง โดยส่วนใหญ่จะเกิดขึ้นกับปุ่มของม็อดที่ถูกเพิ่มลงในเมนูด้วยวิธีการที่ไม่ปกติ
