# คำสั่ง

FancyMenu เพิ่มคำสั่งบางอย่างให้กับเกม ซึ่งมีประโยชน์มากเมื่อนำไปใช้ร่วมกับม็อดอื่น ๆ เช่น FTB Quests

> [!WARNING]
> หากต้องการใช้คำสั่งในโหมดผู้เล่นหลายคน ต้องติดตั้ง FancyMenu บน **เซิร์ฟเวอร์** (และไคลเอนต์) ด้วย!

## ผู้เล่นเป้าหมายและสิทธิ์

อาร์กิวเมนต์ผู้เล่นเป้าหมายของ `/openguiscreen`, `/closeguiscreen` และ `/fmlayout` เป็นตัวเลือก เมื่อผู้เล่นไม่ระบุอาร์กิวเมนต์นี้ คำสั่งจะมีผลกับผู้เล่นคนนั้น หากระบุเป้าหมาย สามารถใช้ชื่อผู้เล่นทั่วไปและตัวเลือก เช่น `@a` ได้

- การระบุอาร์กิวเมนต์เป้าหมายให้กับ `/openguiscreen` หรือ `/closeguiscreen` ต้องมี **ระดับสิทธิ์ 2** (Game Master / OP ระดับ 2) แม้จะระบุชื่อผู้สั่งคำสั่งเองก็ตาม
- การระบุอาร์กิวเมนต์เป้าหมายให้กับ `/fmlayout` ต้องมี **ระดับสิทธิ์ 3** (Admin / OP ระดับ 3) แม้จะระบุชื่อผู้สั่งคำสั่งเองก็ตาม
- คำสั่งย่อยทุกคำสั่งของ `/fmdata` ต้องมี **ระดับสิทธิ์ 2** (Game Master / OP ระดับ 2)

สำหรับคำสั่งทั้งสามที่มีเป้าหมายให้เลือกใช้ การไม่ระบุเป้าหมายจะใช้ได้ก็ต่อเมื่อผู้สั่งคำสั่งเป็นผู้เล่นเท่านั้น คอนโซลเซิร์ฟเวอร์ต้องระบุเป้าหมายและมีระดับสิทธิ์ตามที่อาร์กิวเมนต์เป้าหมายกำหนด

## /openguiscreen

คำสั่ง `/openguiscreen` ใช้เปิดหน้าจอ Vanilla, ม็อด หรือ [GUI แบบกำหนดเอง](/custom-guis) หากติดตั้ง FancyMenu ไว้บนเซิร์ฟเวอร์และไคลเอนต์ของผู้เล่น คำสั่งนี้สามารถกำหนดเป้าหมายเป็นผู้เล่นคนอื่นได้

ดู [การเปิด GUI ด้วยคำสั่ง](/opengui-command) และ [ตัวระบุหน้าจอ](/screen-identifiers)

หน้าจอของม็อดบางหน้าจอไม่สามารถสร้างได้โดยตรง หากหน้าจอเป้าหมายไม่รองรับ FancyMenu จะแสดงข้อผิดพลาด ในเลย์เอาต์ภายในเครื่อง ให้ใช้ [**เลียนแบบปุ่ม Vanilla/ม็อด**](/action-scripts#mimic-vanillamod-button) กับวิดเจ็ตที่ปกติใช้เปิดหน้าจอนั้น

**รูปแบบการใช้งาน:** `/openguiscreen <screen_identifier> [<target_players>]`

## /closeguiscreen

คำสั่ง `/closeguiscreen` ใช้ปิดหน้าจอปัจจุบันของผู้สั่งคำสั่งหรือผู้เล่นที่เลือก คำสั่งนี้มีประโยชน์เมื่อใช้ร่วมกับม็อดเควสต์ อีเวนต์ หรือระบบอัตโนมัติที่เรียกใช้คำสั่งได้

**รูปแบบการใช้งาน:** `/closeguiscreen [<target_players>]`

## /fmlayout

คำสั่ง `/fmlayout` ใช้กำหนดว่าจะเปิดใช้งานเลย์เอาต์บนไคลเอนต์หนึ่งเครื่องหรือหลายเครื่องหรือไม่ ใช้ชื่อเลย์เอาต์ให้ตรงกับที่แสดงใน FancyMenu และใส่เครื่องหมายอัญประกาศครอบชื่อที่มีช่องว่าง

**รูปแบบการใช้งาน:** `/fmlayout <layout_name> <true|false> [<target_players>]`

ตัวอย่าง:

- `/fmlayout quest_complete true` เปิดใช้งาน `quest_complete` สำหรับผู้เล่นที่เรียกใช้คำสั่ง
- `/fmlayout quest_complete false @a` ปิดใช้งานเลย์เอาต์นี้สำหรับผู้เล่นออนไลน์ทุกคน การระบุอาร์กิวเมนต์เป้าหมายต้องมีระดับสิทธิ์ 3

## /fmvariable

คำสั่ง `/fmvariable` ใช้ตั้งค่าและอ่าน[ตัวแปรของ FancyMenu](/variables)

หากต้องการเรียกใช้คำสั่งนี้ในฐานะผู้เล่นคนอื่น ให้ใช้คำสั่ง Vanilla `/execute as`:
`/execute as ExamplePlayer run fmvariable ...`

**รูปแบบการใช้งาน:**

- `/fmvariable get <variable_name>`
- `/fmvariable set <variable_name> <send_chat_feedback> <set_to_value>`

### อ่านค่า

หากต้องการ**อ่านค่าตัวแปร** ให้ใช้คำสั่งย่อย `get` ดังนี้:
`/fmvariable get some_variable`

ค่าของตัวแปรนี้จะแสดงในแชตของคุณ

### ตั้งค่า

หากต้องการ**ตั้งค่าตัวแปร** ให้ใส่ค่าบูลีนสำหรับการแจ้งผลในแชตก่อนค่าใหม่:
`/fmvariable set some_variable true new_value`

อาร์กิวเมนต์ `send_chat_feedback` ใช้กำหนดว่า FancyMenu จะแจ้งยืนยันการเปลี่ยนแปลงในแชตหรือไม่ ส่วนอาร์กิวเมนต์ `set_to_value` จะใช้ข้อความที่เหลือทั้งหมดของคำสั่ง ทำให้ค่ามีช่องว่างได้ ตัวอย่างเช่น `/fmvariable set greeting false Hello from FancyMenu` จะบันทึกค่า `Hello from FancyMenu` โดยไม่ส่งข้อความแจ้งว่าสำเร็จ

## /fmdata

คำสั่ง `/fmdata` ใช้ส่งข้อมูลที่กำหนดเองระหว่างเซิร์ฟเวอร์กับไคลเอนต์ FancyMenu จัดการตัวรับฟังข้อมูลฝั่งเซิร์ฟเวอร์ กำหนดข้อมูลที่จะส่งเมื่อผู้เล่นเข้าร่วม และส่งออกการตั้งค่านี้เพื่อใช้กับ[แชต AI](/export-for-ai#servers) คำสั่งย่อยทุกคำสั่งของ `/fmdata` ต้องมีระดับสิทธิ์ 2

ดู [FM Data](/fm-data) สำหรับรายการคำสั่งย่อยทั้งหมด รูปแบบไวยากรณ์ และตัวอย่าง
