# คำสั่ง

FancyMenu เพิ่มคำสั่งบางอย่างเข้าไปในเกม ซึ่งมีประโยชน์มากเมื่อนำไปใช้ร่วมกับม็อดอื่น ๆ เช่น FTB Quests

> [!WARNING]
> FancyMenu ต้องอยู่บนฝั่ง **SERVER** (และไคลเอนต์) จึงจะใช้คำสั่งในโหมดผู้เล่นหลายคนได้!

## ผู้เล่นเป้าหมายและสิทธิ์

อาร์กิวเมนต์เป้าหมายผู้เล่นของ `/openguiscreen`, `/closeguiscreen` และ `/fmlayout` เป็นตัวเลือกเสริม เมื่อผู้เล่นไม่ระบุ ระบบจะใช้คำสั่งกับผู้เล่นคนนั้นโดยตรง เมื่อระบุเป้าหมายแล้ว สามารถใช้ชื่อผู้เล่นปกติและตัวเลือกเช่น `@a` ได้

- การระบุอาร์กิวเมนต์เป้าหมายให้กับ `/openguiscreen` หรือ `/closeguiscreen` ต้องมี **ระดับสิทธิ์ 2** (Game Master / OP ระดับ 2) แม้จะระบุเป็นแหล่งที่มาของคำสั่งก็ตาม
- การระบุอาร์กิวเมนต์เป้าหมายให้กับ `/fmlayout` ต้องมี **ระดับสิทธิ์ 3** (Admin / OP ระดับ 3) แม้จะระบุเป็นแหล่งที่มาของคำสั่งก็ตาม
- ทุกซับคำสั่งของ `/fmdata` ต้องมี **ระดับสิทธิ์ 2** (Game Master / OP ระดับ 2)

สำหรับคำสั่งทั้งสามที่มีเป้าหมายแบบเลือกได้ การไม่ระบุเป้าหมายจะใช้ได้เฉพาะเมื่อแหล่งที่มาของคำสั่งเป็นผู้เล่นเท่านั้น คอนโซลของเซิร์ฟเวอร์ต้องระบุเป้าหมายและต้องมีสิทธิ์ตามที่อาร์กิวเมนต์เป้าหมายกำหนด

## /openguiscreen

คำสั่ง `/openguiscreen` ใช้เปิดหน้าจอ Vanilla, ม็อด หรือ [Custom GUI](./custom-guis) สามารถกำหนดเป้าหมายไปยังผู้เล่นคนอื่นได้เมื่อมีการติดตั้ง FancyMenu ทั้งบนเซิร์ฟเวอร์และไคลเอนต์ของพวกเขา

ดู [การเปิด GUI ด้วยคำสั่ง](./opengui-command) และ [ตัวระบุหน้าจอ](./screen-identifiers)

ไม่ใช่ทุกหน้าจอของม็อดที่จะสร้างได้โดยตรง FancyMenu จะแสดงข้อผิดพลาดเมื่อหน้าจอเป้าหมายไม่รองรับ สำหรับเลย์เอาต์แบบโลคัล ให้ใช้ [**Mimic Vanilla/Mod Button**](./action-scripts#mimic-vanillamod-button-mimicbutton) กับวิดเจ็ตที่ปกติใช้เปิดมัน

**วิธีใช้:** `/openguiscreen <screen_identifier> [<target_players>]`

## /closeguiscreen

คำสั่ง `/closeguiscreen` ใช้ปิดหน้าจอปัจจุบันสำหรับผู้ที่เป็นแหล่งที่มาของคำสั่งหรือผู้เล่นที่เลือกไว้ เหมาะสำหรับม็อดประเภทเควสต์ อีเวนต์ หรือออโตเมชันที่สามารถรันคำสั่งได้

**วิธีใช้:** `/closeguiscreen [<target_players>]`

## /fmlayout

คำสั่ง `/fmlayout` ใช้กำหนดว่าเลย์เอาต์หนึ่ง ๆ จะถูกเปิดใช้งานบนไคลเอนต์หนึ่งคนหรือหลายคนหรือไม่ ให้ใช้ชื่อเลย์เอาต์ตรงตามที่แสดงใน FancyMenu และหากชื่อมีช่องว่างให้ใส่เครื่องหมายคำพูด

**วิธีใช้:** `/fmlayout <layout_name> <true|false> [<target_players>]`

ตัวอย่าง:

- `/fmlayout quest_complete true` จะเปิดใช้งาน `quest_complete` สำหรับผู้เล่นที่รันคำสั่ง
- `/fmlayout quest_complete false @a` จะปิดใช้งานสำหรับผู้เล่นออนไลน์ทุกคน การระบุอาร์กิวเมนต์เป้าหมายต้องใช้ระดับสิทธิ์ 3

## /fmvariable

คำสั่ง `/fmvariable` ใช้ตั้งค่าและอ่าน [ตัวแปร FancyMenu](./variables)

หากต้องการรันคำสั่งนี้ในฐานะผู้เล่นคนอื่น ให้ใช้คำสั่ง `/execute as` ของ Vanilla:
`/execute as ExamplePlayer run fmvariable ...`

**วิธีใช้:**

- `/fmvariable get <variable_name>`
- `/fmvariable set <variable_name> <send_chat_feedback> <set_to_value>`

### Get

หากต้องการ **อ่านค่าตัวแปร** ให้ใช้ซับคำสั่ง `get` ดังนี้:
`/fmvariable get some_variable`

จากนั้นค่าของตัวแปรนี้จะถูกพิมพ์ไปที่แชตของคุณ

### Set

หากต้องการ **ตั้งค่าตัวแปร** ให้ใส่ค่าบูลีนสำหรับการแจ้งผลในแชตไว้ก่อนค่าที่จะตั้งใหม่:
`/fmvariable set some_variable true new_value`

อาร์กิวเมนต์ `send_chat_feedback` จะควบคุมว่า FancyMenu จะแจ้งยืนยันการเปลี่ยนแปลงในแชตหรือไม่ ส่วนอาร์กิวเมนต์ `set_to_value` จะกินส่วนที่เหลือของคำสั่งทั้งหมด ดังนั้นค่าจึงมีช่องว่างได้ ตัวอย่างเช่น `/fmvariable set greeting false Hello from FancyMenu` จะเก็บค่า `Hello from FancyMenu` โดยไม่แสดงข้อความยืนยันความสำเร็จ

## /fmdata

คำสั่ง `/fmdata` ใช้ส่งข้อมูลแบบกำหนดเองระหว่างเซิร์ฟเวอร์และไคลเอนต์ของ FancyMenu จัดการตัวรับฟังฝั่งเซิร์ฟเวอร์ และกำหนดค่าข้อมูลที่จะส่งเมื่อผู้เล่นเข้าร่วม ทุกซับคำสั่งของ `/fmdata` ต้องมีระดับสิทธิ์ 2

ดู [FM Data](./fm-data) สำหรับซับคำสั่งทั้งหมด ไวยากรณ์ และตัวอย่าง
