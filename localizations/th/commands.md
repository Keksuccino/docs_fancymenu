# คำสั่ง

FancyMenu เพิ่มคำสั่งบางอย่างเข้าไปในเกม ซึ่งมีประโยชน์มากเมื่อใช้ร่วมกับม็อดอื่น ๆ เช่น FTB Quests

> FancyMenu จำเป็นต้องอยู่บน **เซิร์ฟเวอร์** (และไคลเอนต์) เพื่อใช้คำสั่งในโหมดผู้เล่นหลายคน!
{.is-warning}

## /openguiscreen

คำสั่ง `/openguiscreen` ช่วยให้คุณเปิด GUI ได้ (ทั้ง GUI แบบวานิลลา/ม็อด และ GUI แบบกำหนดเอง)
มันสามารถเปิด GUI จากระยะไกลให้ผู้เล่นคนอื่นได้ด้วย เมื่อมีการติดตั้ง FancyMenu ทั้งบนเซิร์ฟเวอร์และไคลเอนต์

สำหรับคำอธิบายของคำสั่งนี้แบบละเอียดมากขึ้น โปรดดูหน้า [Open GUIs by Command](/opengui-command)

คำสั่งนี้จะไม่ทำงานกับทุกหน้าจอ โดยเฉพาะหน้าจอของม็อด หากคำสั่งเปิดหน้าจอไม่สำเร็จ จะแสดงข้อผิดพลาดขึ้นมา ในกรณีนั้นคุณคงทำอะไรได้ไม่มาก เพราะน่าจะเป็นหน้าจอที่ซับซ้อนเกินกว่าที่ FancyMenu จะเปิดอัตโนมัติได้

ผมก็จะไม่เพิ่มความเข้ากันได้สำหรับหน้าจอของม็อดด้วยตัวเองอีกต่อไป เพราะการเพิ่มความเข้ากันได้ให้ม็อดทั้งหมดที่มีอยู่คงใช้เวลานานมาก ขอโทษด้วย

**วิธีใช้:** `/openguiscreen <screen_identifier> <target_player>`

## /closeguiscreen

คำสั่ง `/closeguiscreen` ช่วยให้คุณปิด GUI ปัจจุบันได้

หืม? คุณคิดว่ามันไร้ประโยชน์สุด ๆ ใช่ไหม?
ก็ใช่ แต่จริง ๆ แล้วไม่เชิง

คำสั่งนี้มีประโยชน์เมื่อใช้กับม็อดที่ทริกเกอร์คำสั่งตามการกระทำบางอย่าง
ดังนั้นใช่ คำสั่งนี้แทบจะไร้ประโยชน์อย่างสิ้นเชิงหากใช้โดยไม่มีม็อดอื่น ๆ แต่ถ้าคุณติดตั้งม็อดที่เหมาะสม มันก็ช่วยได้มากทีเดียว!

**วิธีใช้:** `/closeguiscreen <target_player>`

## /fmvariable

คำสั่ง `/fmvariable` ช่วยให้คุณตั้งค่าและเรียกดูตัวแปรของ FancyMenu ได้

หากต้องการรันคำสั่งนี้ในนามของผู้เล่นคนอื่นบนเซิร์ฟเวอร์ คุณสามารถใช้คำสั่ง Vanilla `/execute as` ได้
สมมติว่าคุณต้องการรันคำสั่ง `/fmvariable` ในนามของผู้เล่น `ExamplePlayer` ในกรณีนั้นให้พิมพ์:
`/execute as ExamplePlayer run fmvariable...`

**วิธีใช้:** `/fmvariable <get_or_set> <variable_name> [<set_to_value>] [<send_chat_feedback>]`

### Get
หากต้องการ **เรียกดูค่าของตัวแปร** ให้ใช้ซับคำสั่ง `get` แบบนี้:
`/fmvariable get some_variable`

จากนั้นค่าของตัวแปรนี้จะถูกแสดงในแชตของคุณ

### Set
หากต้องการ **ตั้งค่าตัวแปร** ให้ใช้ซับคำสั่ง `set` แบบนี้:
`/fmvariable set some_variable new_value true`

อาร์กิวเมนต์ตัวสุดท้ายใช้กำหนดว่าคุณต้องการรับข้อความแจ้งเตือนในแชตหรือไม่ ซึ่งหมายความว่าคุณต้องการให้คำสั่งนี้พิมพ์ข้อความลงในแชตของคุณหรือไม่
