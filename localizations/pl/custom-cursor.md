# Niestandardowy kursor myszy

FancyMenu umożliwia ustawienie niestandardowego kursora myszy dla każdego ekranu osobno.

Aby to zrobić, po prostu dodaj nowy element **Kursor** do układu i kliknij go prawym przyciskiem myszy, aby ustawić teksturę kursora.

Jeśli chcesz, aby niestandardowy kursor był widoczny na wszystkich ekranach, powinieneś użyć **uniwersalnego układu**.
