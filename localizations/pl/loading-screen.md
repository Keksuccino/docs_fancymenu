# Ekran ładowania

FancyMenu nie dostosowuje ekranu powitalnego/ładowania Minecrafta. Użyj do tego dodatku [Drippy Loading Screen](https://www.curseforge.com/minecraft/mc-mods/drippy-loading-screen).
