# Ekrany, których dostosowywanie jest celowo wyłączone

FancyMenu blokuje ekrany pasujące do określonych ścieżek pakietów modów, aby zapobiec awariom lub nieprawidłowemu działaniu. Na pasujących ekranach niedostępne są przełącznik dostosowywania, nakładka i układy.

Blokady te dotyczą pakietu Java klasy ekranu, a nie ręcznie wybranej listy pojedynczych ekranów. Jedna reguła może więc obejmować kilka ekranów z tego samego moda lub powiązanych pakietów.

Blokowane grupy ekranów obejmują:

- Create
- Panoramica
- Alex's Mobs
- Screenshot Viewer
- Twilight Forest
- Supplementaries
- OptiFine; użyj [alternatyw dla OptiFine](/optifine-alternatives)
- SlimeKnights i Tinkers' Construct
- mody MidnightDust
- SkinSwapper
- Immersive Engineering
- Dungeonz
- RPG-Hud
- Cobblemon i niektóre powiązane z nim ekrany
- Applied Energistics 2
- mody map Xaero's

# Niezgodności zgłoszone przez społeczność

Poniższe wpisy to zgłoszenia społeczności, a nie ekrany blokowane przez samo FancyMenu. Zgodność może się zmieniać w zależności od wersji FancyMenu, Minecrafta, loadera i modów w danym zestawie.

* [Animated Loading Screen](https://modrinth.com/mod/animated-loading-screen) (Sprawia, że menu wyglądają na uszkodzone)
* [Animated Mojang Logo](https://www.curseforge.com/minecraft/mc-mods/animated-mojang-logo) (Układy czasami się nie ładują; powoduje też problemy z Drippy Loading Screen)
* [Bedrockify](https://www.curseforge.com/minecraft/mc-mods/bedrockify) (Działa, jeśli wyłączysz wszystkie modyfikacje menu tego moda — przynajmniej w menu, które chcesz dostosować)
* [BetterFPS](https://www.curseforge.com/minecraft/mc-mods/betterfps) (Przycisków i menu dodawanych przez ten mod nie można dostosowywać)
* [Chat Colors](https://www.curseforge.com/minecraft/mc-mods/chat-colours) (Awaria przy uruchamianiu)
* [Chloride](https://modrinth.com/mod/chloride) (Po zainstalowaniu tego moda symbol zastępczy FPS nie działa)
* [Colormatic](https://www.curseforge.com/minecraft/mc-mods/colormatic) (Powoduje duże opóźnienia podczas uruchamiania Minecrafta i psuje funkcje audio FancyMenu)
* [Controllable](https://www.curseforge.com/minecraft/mc-mods/controllable) (Niestandardowych przycisków dodanych do menu przez FancyMenu nie można klikać za pomocą funkcji „Wirtualna mysz” moda Controllable)
* [Controlify](https://modrinth.com/mod/controlify) (Zgłoszono awarię; zobacz [zgłoszenie nr 1144](https://github.com/Keksuccino/FancyMenu/issues/1144))
* [Crash To Main Menu](https://www.curseforge.com/minecraft/mc-mods/crash-to-main-menu)
* [Custom Loading Screen](https://www.curseforge.com/minecraft/mc-mods/better-loading-screen)
* [Custom Main Menu](https://www.curseforge.com/minecraft/mc-mods/custom-main-menu)
* [Debugify](https://www.curseforge.com/minecraft/mc-mods/debugify) (Zamiast tego użyj [Modern Debugify](https://www.curseforge.com/minecraft/mc-mods/modern-debugify))
* [Dynamic Surroundings](https://www.curseforge.com/minecraft/mc-mods/dynamic-surroundings) (Zgłoszono, że powoduje problemy z elementami audio)
* [EnhancedVisuals](https://www.curseforge.com/minecraft/mc-mods/enhancedvisuals) (Zgłoszono problemy z animacjami i półprzezroczystym tłem)
* [Entity Model Features](https://modrinth.com/mod/entity-model-features) (Zgłoszono awarię; zobacz [zgłoszenie nr 1115](https://github.com/Keksuccino/FancyMenu/issues/1115))
* [Fossils and Archeology Revival](https://www.curseforge.com/minecraft/mc-mods/fossils) (Działa w grze, ale niestandardowe menu główne nie jest obsługiwane — można je wyłączyć w konfiguracji moda)
* [Holographic Renderers](https://www.curseforge.com/minecraft/mc-mods/holographic-renderers) (Awaria przy uruchamianiu)
* [Ice and Fire](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons) (Działa, jeśli niestandardowe menu główne zostanie wyłączone w konfiguracji moda)
* [Jurassicraft](https://www.curseforge.com/minecraft/mc-mods/jurassicraft) (Gra ulega awarii przy uruchamianiu po włączeniu dostosowywania interfejsów graficznych tego moda — usuń je z pliku `<game-directory>/config/fancymenu/customizablemenus.txt`)
* [Legacy4J](https://www.curseforge.com/minecraft/mc-mods/legacy-minecraft) (Powoduje awarię gry)
* [MalisisCore](https://www.curseforge.com/minecraft/mc-mods/malisiscore) (Psuje dostosowywanie menu głównego)
* [Main Menu Scale Mod](https://www.curseforge.com/minecraft/mc-mods/main-menu-scale)
* [MCA Reborn](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-reborn) (Działa, ale niektóre menu tego moda psują pasek menu FancyMenu i/lub nie można ich dostosowywać)
* [Minecraft Comes Alive](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-mca) (Zgłoszono, że jest zgodny, ale jego menu nie można dostosowywać)
* [MineTogether](https://www.curseforge.com/minecraft/mc-mods/creeperhost-minetogether) (Zgłoszono problemy z układem przy skali interfejsu większej niż 2)
* [Mod Menu](https://www.curseforge.com/minecraft/mc-mods/modmenu) (Zwykle działa poprawnie; jeśli przycisk Mods jest zdublowany lub nie można go dostosować, ustaw **Main Menu -> Mods -> Mod Menu -> Mods Button** na **Adjacent**)
* [Modern Online Picture Frames](https://www.curseforge.com/minecraft/mc-mods/online-picture-frame) (Awaria — zobacz [to zgłoszenie](https://github.com/Keksuccino/FancyMenu/issues/776))
* [Not Enough Animations](https://www.curseforge.com/minecraft/mc-mods/not-enough-animations) (Zgłoszono zgodność z wersjami 1.16+ i niezgodność z wersją 1.12)
* [Optiscale](https://www.curseforge.com/minecraft/mc-mods/optiscale) (Psuje interfejs FancyMenu — nie można klikać przycisków)
* [Pack Menu](https://www.curseforge.com/minecraft/mc-mods/packmenu)
* [Panorama Screens](https://modrinth.com/mod/panorama-screens) (Zgłoszono konflikt między systemami dostosowywania menu)
* [QuestCraft](https://github.com/QuestCraftPlusPlus/QuestCraft) (Gra nie uruchamia się)
* [RandomPatches](https://www.curseforge.com/minecraft/mc-mods/randompatches-forge) (Działa, jeśli w konfiguracji moda ustawisz `patchMinecraftClass = false`)
* [Remove Reloading Screen](https://www.curseforge.com/minecraft/mc-mods/rrls) (Zgłoszono, że powoduje problemy z FancyMenu i Drippy Loading Screen)
* [Replay Mod](https://www.replaymod.com/download/) (Działa, jeśli ustawisz `mainMenuButton` na **BIG** w pliku `<game-directory>/config/replaymod.json`)
* [Seamless Loading Screen](https://www.curseforge.com/minecraft/mc-mods/seamless-loading-screen) (Powoduje awarię gry)
* [Slight Gui Modifications](https://www.curseforge.com/minecraft/mc-mods/slight-gui-modifications)
* [Skin Layers 3D](https://www.curseforge.com/minecraft/mc-mods/skin-layers-3d) (Zgłoszono zgodność z wersjami 1.16+ i niezgodność z wersją 1.12)
* [Smooth Scrolling Everywhere](https://www.curseforge.com/minecraft/mc-mods/smooth-scrolling-everywhere)
* [Sound Filters](https://www.curseforge.com/minecraft/mc-mods/sound-filters) (Rozszerzenie audio nie będzie działać po zainstalowaniu tego moda)
* [Sound Physics Remastered](https://www.curseforge.com/minecraft/mc-mods/sound-physics-remastered) (Rozszerzenie audio nie będzie działać po zainstalowaniu tego moda)
* [Stylish Effects](https://www.curseforge.com/minecraft/mc-mods/stylish-effects) (Przy pierwszym wyświetleniu menu główne nie wczytuje układów)
* [Supplementaries](https://www.curseforge.com/minecraft/mc-mods/supplementaries) (Podczas dostosowywania ekranu konfiguracji moda mogą występować losowe awarie; usuń problematyczny układ z katalogu `<game-directory>/config/fancymenu/customization/`)
* [Terraria Craft](https://www.curseforge.com/minecraft/mc-mods/terraria-craft)
* [The Dalek Mod](https://www.curseforge.com/minecraft/mc-mods/the-dalek-mod) (Działa, jeśli niestandardowe menu główne moda zostanie wyłączone w konfiguracji)
