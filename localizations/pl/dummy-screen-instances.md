# Ekrany ładowania świata

Gdy ładujesz świat albo dołączasz do serwera, prawdopodobnie zauważyłeś, że pojawiają się tam ekrany, których nie da się tak naprawdę dostosować, ponieważ są automatycznie zamykane.

Aby je edytować, musisz otworzyć ich instancję, która pozostanie otwarta tak długo, jak chcesz — jest to możliwe dzięki otwarciu dla nich „dummy screen instance”.

„Dummy Screen Instances” to funkcja FancyMenu, która umożliwia otwieranie NIEKTÓRYCH ekranów, które znikają zbyt szybko, aby je dostosować.

Aby zobaczyć wszystkie ekrany, które można otworzyć za pomocą funkcji Dummy Screen Instance, kliknij **pasek menu -> Tools -> Dummy Screen Instances**. Otworzone menu pokazuje wszystkie ekrany, które możesz otworzyć jako dummy screen instance. **Kliknięcie lewym przyciskiem myszy** na ekran w menu otworzy jego dummy instancję, dzięki czemu będziesz mógł spokojnie ją dostosować.

Na przykład podczas dołączania do świata lub serwera podczas ładowania pojawiają się co najmniej dwa ekrany:

- Ekran ładowania poziomu (ang. Level Loading Screen; znany też jako World Loading Screen)
- Ogólny ekran komunikatu o ziemi (ang. Generic Dirt Message Screen; znany też jako Dirt Message Screen)

> [!WARNING]
> **Ważne:** „World Loading Screen” to nie to samo co „Game Loading Screen” (czyli Splash Screen albo Resource Reloading Screen). „Game Loading Screen” można dostosować za pomocą **Drippy Loading Screen**, który jest dodatkiem do FancyMenu.
