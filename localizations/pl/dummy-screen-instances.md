# Ekrany ładowania świata

Gdy ładujesz świat albo dołączasz do serwera, prawdopodobnie zauważyłeś, że pojawiają się tam ekrany, których tak naprawdę nie da się dostosować, ponieważ są automatycznie zamykane.

Aby je edytować, musisz otworzyć ich instancję, która pozostanie otwarta tak długo, jak chcesz — jest to możliwe dzięki otwarciu dla nich „pozornej instancji ekranu” ("dummy screen instance").

„Pozorne instancje ekranu” to funkcja FancyMenu, która umożliwia otwieranie NIEKTÓRYCH ekranów, które znikają zbyt szybko, aby dało się je dostosować.

Aby zobaczyć wszystkie ekrany, które można otworzyć za pomocą funkcji Pozornych instancji ekranu, kliknij **menu bar -> Tools -> Dummy Screen Instances**. Otworzone menu pokaże wszystkie ekrany, które możesz uruchomić jako pozorną instancję ekranu. **Kliknięcie lewym przyciskiem myszy** na ekran w menu otworzy dla Ciebie jego pozorną instancję, abyś mógł spokojnie ją dostosować.

Na przykład podczas dołączania do świata lub serwera podczas ładowania pojawiają się co najmniej dwa ekrany:

- Ekran ładowania poziomu (ang. Level Loading Screen, czyli ekran ładowania świata)
- Ogólny ekran komunikatu z ziemią (ang. Generic Dirt Message Screen, czyli ekran komunikatu z ziemią)

> **Ważne:** „Ekran ładowania świata” nie jest tym samym co „Ekran ładowania gry” (ang. Game Loading Screen, czyli ekran startowy lub ekran ponownego wczytywania zasobów). „Ekran ładowania gry” można dostosować za pomocą **Drippy Loading Screen**, czyli dodatku do FancyMenu.
