# Płynne ładowanie świata

Płynne ładowanie świata robi zrzut ekranu, gdy opuszczasz świat lub serwer, i używa go jako tła podczas następnego ładowania.

Dzięki temu przejścia podczas ładowania wydają się bardziej płynne, ponieważ ekran ładowania będzie odpowiadał temu, co zobaczysz po zakończeniu ładowania.

# Gdzie to znaleźć

Otwórz **pasek menu** FancyMenu, gdy **nie** znajdujesz się w edytorze układu, a następnie wybierz **Customization -> Global Customizations**.

# Włączanie / wyłączanie

1. Otwórz **Customization -> Global Customizations**.
2. Znajdź **Seamless World Loading**.
3. Ustaw **Enabled** lub **Disabled**.

# Jak to działa

- Gdy opcja jest włączona, FancyMenu zapisuje zrzut ekranu podczas opuszczania świata/serwera.
- Podczas następnego ładowania ten zrzut ekranu jest używany jako tło ładowania.
- Pierwsze użycie: jeśli nie ma jeszcze żadnego zrzutu ekranu, nie będzie nic do wyświetlenia, dopóki nie opuścisz świata/serwera po raz pierwszy.
