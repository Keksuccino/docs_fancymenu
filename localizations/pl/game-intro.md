# Intros gry

Intros gry odtwarzają animowany obraz lub wideo, zanim po raz pierwszy pojawi się ekran tytułowy.

# Konfiguracja

Otwórz [**Globalne dostosowania**](./global-customizations) przez **Dostosowanie -> Globalne dostosowania**, a następnie skonfiguruj te ustawienia:

| Ustawienie | Działanie |
|---|---|
| Ustaw intro gry | Wybiera lokalny, internetowy lub pochodzący z zasobów Minecrafta animowany obraz albo wideo |
| Pomijanie intro gry | Pozwala pominąć intro dowolnym klawiszem lub kliknięciem myszy |
| Zanikanie intro gry | Wygasza intro do docelowego ekranu |
| Niestandardowy tekst pomijania | Zastępuje domyślny komunikat o pominięciu zwykłym tekstem lub kluczem lokalizacji |
| Głośność intro gry | Ustawia podstawową głośność od `0.0` do `1.0` |
| Kanał dźwięku intro gry | Wybiera kategorię dźwięku Minecrafta |
| Ponownie uruchom intro gry | Odtwarza skonfigurowane intro ponownie w celach testowych |

Intro wideo wymagają **Watermedia V3**, **Watermedia Binaries V3** oraz renderera OpenGL. Odtwarzanie wideo Watermedia jest niedostępne z Vulkanem. Gdy odtwarzanie jest niedostępne, FancyMenu wyświetla wyjaśnienie na ekranie intro. Zobacz [Wideo](./video#requirements).
