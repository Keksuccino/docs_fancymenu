# Warstwy i grupy

Otwórz widżet Warstwy przez **Window -> Editor Widgets -> Layers**.

# Kolejność warstw

Przeciągaj warstwy na liście, aby zmienić kolejność ich renderowania. Możesz też kliknąć element prawym przyciskiem myszy i użyć opcji **Move One Layer Up** lub **Move One Layer Down**.

Elementy [Player Entity](./elements#player-entity) oraz [Item](./elements#item) mogą mieć limity renderowania, które uniemożliwiają zwykłe porządkowanie warstw.

# Grupy

Grupy porządkują powiązane warstwy i pozwalają przenosić je lub ukrywać razem.

- Twórz i zmieniaj nazwy grup.
- Zmieniaj nazwy pojedynczych warstw.
- Przeciągaj warstwy do grup i z grup.
- Przeciągnij grupę, aby przesunąć wszystkie jej warstwy w kolejności.
- Zwiń lub rozwiń grupę.
- Pokaż lub ukryj każdą warstwę w grupie.
- Usuń grupę bez usuwania jej warstw.

Przynależność do grupy i stan zwinięcia są zapisywane razem z układem.
