# Skróty i skróty klawiszowe

FancyMenu ma wiele przydatnych skrótów, które ułatwiają i usprawniają pracę z **edytorem układu** oraz innymi częściami moda.

# Edytor układu

<br>

## CTRL + lewy klik

Możesz zaznaczać wiele elementów, przytrzymując **CTRL** podczas **klikania lewym przyciskiem myszy** na elementach.
Możliwe jest również **przeciąganie/przenoszenie wielu elementów** myszą przytrzymując **CTRL**.

## SHIFT + zmiana rozmiaru elementu

Przytrzymanie SHIFT podczas zmiany rozmiaru elementów zachowa ich proporcje.

## Klawisze strzałek

Klawiszy strzałek można używać do **przesuwania** zaznaczonych elementów z maksymalną precyzją.

## CTRL + A

Zaznacza wszystkie elementy naraz.

## CTRL + C

**Kopiuje** wszystkie zaznaczone elementy do schowka.

## CTRL + V

**Wkleja** wszystkie elementy, które aktualnie znajdują się w schowku.
Działa to również między różnymi układami, więc możesz skopiować elementy w układzie A i wkleić je do układu B.

## CTRL + S

Szybko **zapisuje** układ.

## CTRL + ALT + L

Szybko otwiera edytor układu z ostatnio edytowanym układem.

## CTRL + Z

**Cofa** ostatnią czynność.

## CTRL + Y

**Ponawia** wcześniej cofniętą czynność.

## CTRL + G

Szybko przełącza **siatkę**.

## O

Przytrzymanie **O** pokazuje nakładkę punktu zakotwiczenia, jeśli jej widoczność jest ustawiona na **Pokaż po naciśnięciu klawisza** w **Window -> Anchor Overlay Visibility**.

## DEL

**Usuwa** wszystkie zaznaczone elementy.

# Edytor tekstu

<br>

## CTRL + C

**Kopiuje** zaznaczony tekst do schowka.

## CTRL + V

**Wkleja** tekst, który aktualnie znajduje się w schowku.

## CTRL + Z

**Cofa** ostatnią czynność.

## CTRL + Y

**Ponawia** wcześniej cofniętą czynność.

## CTRL + A

**Zaznacza** cały tekst.

## CTRL + D

**Duplikuje** bieżącą linię.

## CTRL + U

**Wycina** zaznaczony tekst.

## ALT + Strzałka w górę / ALT + Strzałka w dół

Przesuwa bieżącą linię w górę lub w dół.

## CTRL + Home / CTRL + End

Przenosi kursor na początek lub koniec tekstu.

## CTRL + G

Otwiera pole **Przejdź do linii**.

## CTRL + S

Zatwierdza edytor, tak samo jak kliknięcie **Gotowe**.

## SHIFT + klawisze strzałek

Zaznacza/podświetla tekst podczas przesuwania kursora.

## Klawisze strzałek

Klawiszy strzałek można używać do poruszania kursorem w tekście.

# W menu

<br>

## CTRL + ALT + C

Przełącza widoczność **paska menu** FancyMenu u góry menu.

## CTRL + ALT + R

**Przeładowuje** FancyMenu.
Obejmuje to pełne przeładowanie zasobów/assetów, a większość pamięci podręcznych zostaje wyczyszczona.

## CTRL + ALT + D

Przełącza widoczność **nakładki debugowania** FancyMenu.

# Okna edycji

Wiele okien edycji FancyMenu w wersji v3.9.0 obsługuje nawigację klawiaturą za pomocą **klawiszy strzałek** i **Enter**. Wiele okien używa również **CTRL + S** jako skrótu dla **Gotowe** oraz **ESC** jako **Anuluj**.

Przeprojektowane okna Edytora skryptów akcji, Zarządzania wymaganiami i Zarządzania zmiennymi obsługują także menu kontekstowe po kliknięciu prawym przyciskiem myszy, wyszukiwanie, cofanie/ponawianie oraz nawigację klawiaturą po listach.
