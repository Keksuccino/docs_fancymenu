# Skróty i skróty klawiszowe

**Modyfikator skrótu:** Używaj `Ctrl` w systemach Windows/Linux oraz `Command` w macOS, tam gdzie jest to obsługiwane.

# Edytor układu

| Skrót | Działanie |
|---|---|
| `Ctrl/Command + lewy klik` | Zaznaczanie lub przeciąganie wielu elementów |
| `Shift + zmiana rozmiaru` | Zachowanie proporcji elementu |
| Klawisze strzałek | Precyzyjne przesuwanie zaznaczonych elementów |
| `Ctrl/Command + A` | Zaznacz wszystkie elementy |
| `Ctrl/Command + C` | Kopiuj zaznaczone elementy |
| `Ctrl/Command + V` | Wklej skopiowane elementy, także do innego układu |
| `Ctrl/Command + S` | Zapisz układ |
| `Ctrl/Command + Z` | Cofnij |
| `Ctrl/Command + Y` | Ponów |
| `Ctrl/Command + G` | Włącz/wyłącz siatkę |
| `O` | Pokazuje punkty zakotwiczenia podczas przytrzymania, gdy **Okno -> Widoczność nakładki zakotwiczenia** jest ustawione na **Pokaż po naciśnięciu klawisza** |
| `Delete` | Usuń zaznaczone elementy |

# Edytor tekstu

| Skrót | Działanie |
|---|---|
| `Ctrl/Command + C` | Kopiuj zaznaczony tekst |
| `Ctrl/Command + V` | Wklej tekst |
| `Ctrl/Command + Z` | Cofnij |
| `Ctrl/Command + Y` | Ponów |
| `Ctrl/Command + A` | Zaznacz cały tekst |
| `Ctrl/Command + D` | Zduplikuj bieżącą linię |
| `Ctrl/Command + U` | Wytnij zaznaczony tekst |
| `Alt + strzałka w górę/w dół` | Przesuń bieżącą linię |
| `Ctrl/Command + Home/End` | Przejdź na początek lub koniec tekstu |
| `Ctrl/Command + G` | Otwórz **Przejdź do linii** |
| `Ctrl/Command + S` | Zatwierdź edytor |
| `Shift + klawisze strzałek` | Rozszerz zaznaczenie tekstu |
| Klawisze strzałek | Przesuwanie kursora |

# Globalne skróty menu

Te skróty używają dokładnej kombinacji `Ctrl + Alt`:

| Skrót | Działanie |
|---|---|
| `Ctrl + Alt + L` | Otwórz edytor układu z ostatnio edytowanym układem |
| `Ctrl + Alt + C` | Włącz/wyłącz pasek menu FancyMenu |
| `Ctrl + Alt + R` | Przeładuj FancyMenu i zarządzane przez nie zasoby/cache |
| `Ctrl + Alt + D` | Włącz/wyłącz nakładkę debugowania FancyMenu |

# Okna edycji

Okna edycji FancyMenu obsługują nawigację klawiaturą za pomocą klawiszy strzałek i `Enter`. W wielu przypadkach `Ctrl/Command + S` służy do **Gotowe**, a `Escape` do **Anuluj**.

Edytory Action Script, Requirements i Variables obsługują także menu kontekstowe po kliknięciu prawym przyciskiem myszy, wyszukiwanie, cofanie/ponawianie oraz nawigację po listach za pomocą klawiatury.
