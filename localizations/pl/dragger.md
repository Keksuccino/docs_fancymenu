# Dragger

Element Dragger w FancyMenu to element, który pozwala sprawić, że menu stają się interaktywne w dość nietypowy sposób. Dragger to element, który można przeciągać myszą POZA edytorem, co oznacza, że użytkownicy mogą po prostu chwycić element i przesuwać go po ekranie.

To wszystko brzmi świetnie, ale przesuwanie elementu, który nie robi nic więcej, jest raczej bez sensu, prawda? Cóż, nie, ponieważ możesz dołączyć do niego inne elementy, ustawiając element Dragger jako punkt zakotwiczenia dla innych elementów, które mają poruszać się razem z Draggerem.

Przesunięcie pozycji elementów Dragger jest trwałe i zapisywane między ponownymi uruchomieniami gry, co oznacza, że gdy użytkownik przesunie Dragger, pozostanie on w tej „niestandardowej” pozycji nawet po restarcie gry.

Element Dragger jest widoczny tylko w edytorze i niewidoczny poza nim, więc pamiętaj, aby użyć innego elementu jako jego „bryły”, jeśli chcesz, żeby użytkownik widział, gdzie znajduje się obszar przeciągania.
