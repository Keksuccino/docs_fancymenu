# Ikona i tytuł okna

FancyMenu umożliwia zmianę ikony i tytułu okna Minecrafta.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# Własna ikona

Aby ustawić własną ikonę, otwórz sekcję [**Globalne dostosowania**](./global-customizations), wybierając **Dostosowywanie -> Globalne dostosowania**.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- Ikony muszą być plikami **PNG** (oraz **ICNS** w systemie macOS)
- Ikony muszą zawierać co najmniej **1 przezroczysty piksel**, aby nie wyglądały na uszkodzone (błąd MC/LWJGL)
- Aby włączyć przełącznik własnej ikony, musisz ustawić prawidłowe pliki dla wszystkich 3 wersji ikon (16x16, 32x32, macOS)

> [!CAUTION]
> **Jeszcze raz**: ikony muszą zawierać co najmniej **1 przezroczysty piksel**, aby nie wyglądały na uszkodzone (błąd MC/LWJGL). Ikona będzie wyglądać na uszkodzoną, jeśli nie będzie zawierać co najmniej jednego całkowicie przezroczystego piksela!


# Własny tytuł

Aby ustawić własny tytuł, otwórz sekcję [**Globalne dostosowania**](./global-customizations), wybierając **Dostosowywanie -> Globalne dostosowania**.
