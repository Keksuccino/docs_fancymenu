# ゲームイントロ

ゲームイントロは、Minecraftのロード画面の直後、ゲームの起動時にアニメーションや動画を再生します。再生が終わると、タイトル画面へフェードします。ロゴやスタジオのイントロ、短いトレーラーなど、Modパック向けに作られています。

<img width="800" alt="Skyhavenのイントロ：浮島の上で夜が明け、ロゴが1文字ずつ現れます。その後イントロがフェードし、背景に同じ浮島が表示されたタイトル画面に切り替わります" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/game_intro_showcase.gif?raw=true">

プレイヤーは、任意のキーを押すかクリックするとスキップできます。ゲームイントロは[グローバルカスタマイズ](/global-customizations)の一つなので、レイアウトは必要ありません。

# イントロの設定

<img width="800" alt="メニューバーからグローバルカスタマイズとゲームイントロを開き、Set Game Introでskyhaven_intro.apngを選択し、Re-Trigger Game Introで再生して、Spaceキーでスキップする様子" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/game_intro_setup.gif?raw=true">

1. アニメーションまたは動画を`<game-directory>/config/fancymenu/assets/`に入れます。
2. **メニューバー -> カスタマイズ -> グローバルカスタマイズ -> ゲームイントロ**を開きます。
3. **ゲームイントロを設定**をクリックします。**ソースタイプ**が**ローカル**になっていることを確認し、**ローカルリソースファイルを選択**をクリックしてファイルを選び、**OK**をクリックします。
4. **ゲームイントロを再トリガー**をクリックすると、すぐに再生できます。

イントロを削除するには、マウスを**ゲームイントロを設定**に合わせて、**デフォルトに戻す**をクリックします。

## アニメーションと動画

- **アニメーション：** APNGまたはGIFファイルです。作り方は[アニメーション](/animations)を参照してください。
- **動画：** MP4ファイルです。Watermedia V3とWatermedia Binaries V3のMODが必要です。詳しくは[動画](/video#requirements)を参照してください。これらがない場合、動画イントロにはダウンロードリンク付きの赤いメッセージが数秒間表示されるだけです。
- インスタンス内のファイルとリソースパックのファイルは使えますが、Webリンクは使えません。[リソース](/resources)を参照してください。

イントロは画面全体に表示され、縦横比を維持するため、画面の縦横比が異なる場合は一部が切り取られます。ほとんどの画面は16:9なので、イントロも1920x1080のような16:9で作成してください。透明部分は黒く表示されます。

> [!TIP]
> ゲームを起動するたびにプレイヤーにイントロが表示されるため、5～10秒ほどの短いものにしましょう。

## 無料のサンプルイントロ

このページのGIFで使われているSkyhavenのイントロは、テストやModパックで自由に使用できます。

- [skyhaven_intro.apng](https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/skyhaven_intro.apng?raw=true)：イントロ本編です。サイズは1280x720、長さは5.4秒で、1回だけ再生されます。
- [skyhaven_menu.png](https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/skyhaven_menu.png?raw=true)：ロゴのない最後のシーンです。サイズは1280x720です。タイトル画面レイアウトの[画像背景](/menu-backgrounds#image)に設定すると、最初のGIFのようにイントロから統一感のあるメニューへフェードできます。

# 設定

すべての設定は**メニューバー -> カスタマイズ -> グローバルカスタマイズ -> ゲームイントロ**にあります。

| 設定 | 内容 |
|---|---|
| **ゲームイントロを設定** | アニメーションまたは動画を設定します。 |
| **ゲームイントロのスキップ** | 任意のキーを押すかクリックするとイントロをスキップできます。画面下部には**何かキーを押してスキップ**と表示されます。スキップするとフェードせずにイントロがすぐ終了します。オフにすると、イントロは最後まで再生されます。 |
| **ゲームイントロのフェードアウト** | イントロの終了時に、タイトル画面へフェードします。オフにすると、タイトル画面がすぐに表示されます。 |
| **ゲームイントロのループを無視** | アニメーションがループする設定でも、1回再生した時点でイントロを終了します。オフにすると、アニメーションのループがすべて再生されます。動画は常に1回だけ再生されます。 |
| **スキップ時のカスタムテキスト** | **何かキーを押してスキップ**を、`冒険を始めるには何かキーを押してください`のようなテキストに置き換えます。リソースパックの`skyhaven.intro.skip`のようなローカライズキーを指定すると、プレイヤーの言語でテキストが表示されます。 |
| **ゲームイントロの音量** | 動画イントロの音量を0%～100%で設定します。 |
| **ゲームイントロのサウンドチャンネル** | 動画イントロのサウンドチャンネルを設定します（例：音楽）。Minecraftのサウンド設定でのそのチャンネルの音量とマスター音量も適用されます。 |
| **ゲームイントロを再トリガー** | イントロを、現在表示中の画面の上にすぐ再生します。 |

**ゲームイントロのスキップ**、**ゲームイントロのフェードアウト**、**ゲームイントロのループを無視**は、デフォルトでオンになっています。

> [!WARNING]
> **ゲームイントロのスキップ**と**ゲームイントロのループを無視**の両方をオフにすると、無限ループするアニメーションは終わらず、プレイヤーがタイトル画面に進めなくなります。

# 知っておくと便利なこと

- イントロはゲームの起動ごとに1回、ロード画面の次に表示される最初の画面の前に再生されます。通常、次の画面はタイトル画面です。
- その前に表示されるMinecraftのロード画面を変更するには、[ロード画面](/loading-screen)を参照してください。
- イントロのソースには[プレースホルダー](/resources#placeholders-in-resource-sources)を含められます。
- ゲームイントロの設定はFancyMenuの`options.txt`に保存されるため、読み込まれた[プロファイル](/profiles)に属します。`config/fancymenu/`を含むModパックには、`assets/`内のファイルとともにイントロが同梱されます。[Modパック](/modpacks)を参照してください。
