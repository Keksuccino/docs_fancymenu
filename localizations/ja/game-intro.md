# ゲームイントロ

ゲームイントロは、タイトル画面が最初に表示される前に、アニメーション画像または動画を再生します。

# セットアップ

[**グローバルカスタマイズ**](./global-customizations) を **Customization -> Global Customizations** から開き、次の設定を行います:

| 設定 | 動作 |
|---|---|
| ゲームイントロを設定 | ローカル、Web、または Minecraft リソースのアニメーション画像や動画を選択します |
| ゲームイントロのスキップ | 任意のキー操作またはマウスクリックでイントロをスキップできるようにします |
| ゲームイントロのフェードアウト | イントロを対象画面へフェードさせます |
| カスタムスキップテキスト | デフォルトのスキップ表示を、プレーンテキストまたはローカリゼーションキーに置き換えます |
| ゲームイントロ音量 | 基本音量を `0.0` から `1.0` の範囲で設定します |
| ゲームイントロのサウンドチャンネル | Minecraft のサウンドカテゴリを選択します |
| ゲームイントロを再実行 | 設定したイントロをテスト用に再生します |

動画イントロには **Watermedia V3**、**Watermedia Binaries V3**、および OpenGL レンダラーが必要です。Watermedia の動画再生は Vulkan では利用できません。再生できない場合、FancyMenu はイントロ画面上にその理由を表示します。[動画](./video#requirements) を参照してください。
