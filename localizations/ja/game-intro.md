# ゲームイントロ

ゲームを起動したときに流れる、あのかっこいい短い動画をご存じですか？
FancyMenu を使えば、Minecraft でもそれを実現できます！

# イントロとしての APNG、GIF、動画

FancyMenu はアニメーションテクスチャに対応しており、FancyMenu 3.9.0 以降では動画をゲームイントロのコンテンツとして使用できます。

FancyMenu 3.9.0 以降でイントロコンテンツを設定するには、FancyMenu の**メニューバー**から **Customization -> Global Customizations** に移動し、そこで **Game Intro** を設定します。

動画イントロは音声に対応しており、音量やサウンドチャンネルの設定も利用できます。ネイティブ動画サポートには **Watermedia V3** と **Watermedia Binaries V3** が必要です。
