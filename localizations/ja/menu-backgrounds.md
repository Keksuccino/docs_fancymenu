# メニューバックグラウンド

FancyMenu を使うと、メニューにカスタム背景を設定できます。画像、アニメーションテクスチャ、スライドショー、立方体パノラマ、色、ブラウザ、動画、GLSL シェーダーなどを使用できます。

# 背景の設定

メニューバックグラウンドのカスタマイズは、レイアウトエディターのコンテキストメニューから行えます。

1. レイアウトエディターを開きます。
2. エディター背景を右クリックします。
3. **Menu Backgrounds** を開きます。
4. 使用したい背景タイプを有効化して設定します。

一般的な背景タイプには次のものがあります。

- Vanilla
- Image
- Slideshow
- Cubic Panorama
- Color (HEX)
- Browser
- Video
- GLSL Shader
- Video [Rinku]（非推奨）
- 追加のアドオン背景タイプ

旧 **Video [Rinku]** 背景タイプは非推奨です。新しいレイアウトでは、Watermedia V3 に対応したネイティブの [**Video** 背景](./video) を使用してください。

# カスタム背景の削除

もう一度 **Menu Backgrounds** を開き、不要になったカスタム背景タイプを無効化または削除します。カスタム背景タイプが有効になっていない場合、画面は通常の vanilla 背景動作に戻ります。

# 背景の重ね合わせ

1つのレイアウトで複数のメニューバックグラウンドタイプを有効にできます。有効な背景はスタックとして描画されるため、ベースとなる画像やパノラマに、透過ブラウザ、シェーダー、パララックスなどのレイヤーを重ねることができます。

複数のレイアウトを同時に有効にしている場合、それぞれの背景スタックも重ねて表示されます。レイアウトの並び順を調整して特定の順序で表示したい場合は、エディター背景を右クリックして **Layout Index** をクリックします。

# 透過背景

FancyMenu は、有効なカスタム背景の背後に黒い下地レイヤーを描画します。そのため、最も下の背景にある透過ピクセルは黒として表示されます。まず不透明なベース背景を使い、その上に半透明の背景を重ねてください。

背景画像を半透明にするには、お好みの画像編集ソフトを使用してください。

# ブラウザ背景

**Browser** 背景タイプは [Browser エレメント](./elements#browser) と同様に動作しますが、画面全体に広がり、自動でフォーカスされます。フルスクリーンの Web コンテンツ、ローカル HTML ページ、Web 動画レイヤーなどに便利です。

# GLSL シェーダー背景

**GLSL Shader** 背景タイプでは、カスタム GLSL シェーダーを描画でき、Shadertoy 形式のシェーダー作成にも対応しています。対応する uniform やシェーダー構造については、[GLSL Shader API](/glsl-shader-api) ページを参照してください。
