# メニューの背景

レイアウトでは、画面に独自の背景を設定できます。画像、アニメーション、パノラマ、スライドショー、動画、色、ウェブサイト、シェーダーなどを使えます。タイトル画面のパノラマや、ほかのメニューのぼかし、一時停止メニューの背後にあるワールドなど、画面の通常の背景に置き換わります。

<img width="800" alt="夜の雪深い谷を描いたピクセルアートの背景が表示されたタイトル画面。オーロラ、満月、窓に明かりが灯った小屋がある" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_hero.png?raw=true">

> [!TIP]
> レイアウトを作成せずに、すべてのメニューに同じ背景を設定するには、[グローバルカスタマイズ](/global-customizations#menu-backgrounds)を使ってください。

# 背景の設定

<img width="800" alt="タイトル画面のエディター背景を右クリックして、メニューの背景と画像を開き、背景を表示をオンにして、画像を選択から画像を選んでいる" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_image.gif?raw=true">

1. [レイアウトエディター](/layout-editor)で、画面のレイアウトを開きます。
2. エディターの背景を右クリックし、**メニューの背景**を開きます。**メニューバー -> レイアウト -> レイアウトのプロパティ**からも開けます。
3. **画像**など、背景の種類を開きます。
4. **背景を表示**をクリックして、**有効**に設定します。
5. 画像背景の場合は**画像を選択**を使うなど、背景を設定します。

<img width="800" alt="メニューの背景メニュー。画像の前にはチェックマーク、ほかの種類の前にはバツ印があり、その下にすべての背景の設定が表示されている" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_menu.png?raw=true">

**メニューの背景**では、有効な種類の前には✔、無効な種類の前には✖が表示されます。種類にカーソルを合わせると、説明が表示されます。

画面の通常の背景に戻すには、その種類の**背景を表示**を再び**無効**に設定します。設定はそのまま残るので、後から再び有効にできます。

# 背景の種類

## 画像

ファイル、ウェブサイト、またはゲームのリソースから画像を選び、画面全体に引き伸ばして表示します。アニメーション画像も再生できます。対応ファイルについては、[画像](/images)を参照してください。

- **画像を選択**: 画像を選びます。画像の取得元については、[リソース](/resources)を参照してください。
- **代替画像を選択**: 画像を読み込めないときに表示する画像を選びます。たとえば、オフライン時のウェブ画像の代わりに表示されます。
- **画面を開くときにアニメーションテクスチャを再開**: 画面を開くたびに[アニメーション画像](/animations)を最初から再生します。無効の場合は、前回の続きから再生します。
- **テクスチャを繰り返す**: 画像を引き伸ばす代わりに、画面全体にタイル状に並べます。[9スライスとタイル表示](/nine-slicing-and-tiling)を参照してください。
- **横長画像を左から右にスライド**: 風景全体の写真のような横長画像を画面の高さに合わせ、左右にゆっくりスライドさせます。両端では少し停止します。
- **視差効果**とその設定: マウスの動きに合わせて画像が少し動きます。[視差効果](/parallax#menu-backgrounds)を参照してください。

**横長画像を左から右にスライド**は、**テクスチャを繰り返す**または**視差効果**と同時に有効にできません。

## 色

画面全体を1色で塗りつぶします。

- **色 [HEX]**: `#1B2440`のように色を指定します。末尾に2桁追加すると、`#1B2440C8`のように透過度を設定できます。[プレースホルダー](/placeholders)も使用できます。

色の背景は、レイアウトのほかのすべての背景より下に配置されるため、ほかの背景の透明な部分を塗りつぶします。[背景の重ね合わせ](#stacking-backgrounds)を参照してください。

## キュービックパノラマ

タイトル画面の背景のように、ゆっくりと回転するパノラマです。パノラマは`config/fancymenu/panoramas/`に作成します。[パノラマ](/panoramas)を参照してください。

- **パノラマ名**: **パノラマを選択**を開き、作成済みのパノラマを選んでプレビューを表示します。
- **パノラマをクリア**: パノラマを削除します。

パノラマが設定されていない場合、背景にはMinecraftの紫と黒の欠損テクスチャが表示されます。

## スライドショー

スライドショーの画像を順番に表示します。スライドショーは`config/fancymenu/slideshows/`に作成します。[スライドショー](/slideshows)を参照してください。

- **スライドショー名**: **スライドショーを選択**を開き、作成済みのスライドショーを選びます。
- **スライドショーをクリア**: スライドショーを削除します。

スライドショーが設定されていない場合も、背景にはMinecraftの欠損テクスチャが表示されます。

## 動画

ファイル、ウェブサイト、またはゲームのリソースから動画を再生します。Watermediaが必要です。[動画](/video#requirements)を参照してください。Watermediaがない場合、背景にはダウンロードリンク付きの案内が表示されます。

- **動画ソース**: 動画を指定します。
- **動画をループ**、**音量**、**サウンドチャンネル**: 再生方法を設定します。
- **視差効果**とその設定: 画像背景と同様です。
- **レイアウトエディターで動画を再生**: 無効にすると、レイアウトエディターでは動画が一時停止したままになります。

[アクション](/video)を使うと、動画の一時停止や音量、再生時間の変更ができます。背景のIDが必要です。設定画面で**背景IDをコピー**をクリックしてください。

## ブラウザー

[ブラウザー要素](/elements#browser)のように、ウェブサイトを画面全体に表示します。

> [!IMPORTANT]
> ブラウザーを使うには、[Rinku](https://modrinth.com/mod/rinku) MODが必要です。ない場合、背景は赤く表示され、Rinkuが見つからないというメッセージが表示されます。

- **URL**: ウェブサイトを指定します。[プレースホルダー](/placeholders)を含めることもできます。
- **マウスクリックを処理**、**マウススクロールを処理**、**キーボード入力を処理**: ウェブサイト上でクリック、スクロール、入力できるようにします。画面を開くとすぐにキーボード入力を受け取ります。
- **マウスクリックを消費**、**マウススクロールを消費**、**キーボード入力を消費**: クリック、スクロール、キー入力がウェブサイトで処理され、画面自体が反応しないようにします。
- **ブラウザーをミュート**、**音声/動画の音量**、**動画をループ**、**動画コントロールを非表示**: ウェブサイト上のメディアを設定します。

背景の前にあるボタンや要素が、常にクリックを優先して受け取ります。レイアウトエディターでは、ウェブサイトの代わりに縞模様が表示されます。

## GLSLシェーダー

アニメーションする波、星、模様など、グラフィックカード用の小さなプログラムであるシェーダーを描画します。Shadertoyのシェーダーも使用できます。

- **シェーダーソース**: シェーダーのコードを指定します。
- **コンパイルエラーを表示**: コードの間違いを画面に表示します。完成したレイアウトでは無効にしてください。

追加パス、テクスチャ、時間など、ほかの設定については[GLSLシェーダーAPI](/glsl-shader-api)で説明しています。

## 動画 [Rinku]

Rinkuが必要な旧式の動画背景です。古いバージョンで作成したレイアウトのように、この機能が有効な場合にのみ一覧に表示されます。代わりに**動画**を使ってください。

# すべての背景に適用される設定

背景の種類の下にある**メニューの背景**には、レイアウト内のすべての背景に適用される設定があります。

- **背景の縦横比を維持**: 画像、スライドショー、動画の背景の比率を維持します。画面全体を覆うように表示されますが、画面に収まらない部分は切り取られます。無効にすると、画面に合わせて引き伸ばされます。
- **カスタム背景に暗いオーバーレイを表示**: Minecraftのメニューにある暗く半透明なレイヤーを背景に重ね、ボタンやテキストを見やすくします。
- **バニラの背景ぼかしを適用**: Minecraftがメニューの背後にあるワールドをぼかすのと同じように、背景をぼかします。ぼかしの強さは、Minecraftの**アクセシビリティ設定**にあるプレイヤーの**メニュー背景のぼかし**によって決まります。`0`の場合、ぼかしは適用されません。

<img width="800" alt="同じ背景を3つ並べた画像。左から、通常の背景、カスタム背景に暗いオーバーレイを表示で暗くした背景、バニラの背景ぼかしを適用でぼかした背景" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_effects.png?raw=true">

左から、設定なし、**カスタム背景に暗いオーバーレイを表示**、**バニラの背景ぼかしを適用**です。

# 背景の重ね合わせ

1つのレイアウトで複数の種類を有効にできます。背景は次の順番で、下から上に重なって描画されます。

1. 色
2. キュービックパノラマ
3. 画像
4. スライドショー
5. 動画
6. 動画 [Rinku]
7. ブラウザー
8. GLSLシェーダー

ほかのMODが追加する種類は、最前面に描画されます。

FancyMenuは背景の後ろを黒く描画するため、画像の透明な部分には黒が表示されます。その下に色の背景を置くと、透明な部分をその色で塗りつぶせます。

<img width="800" alt="空が透明なピクセルアートの風景。左半分では空が黒く、右半分では青い色の背景で塗りつぶされている" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_stacking.png?raw=true">

左側では画像のみが有効です。右側では色の背景が空を塗りつぶしています。

- キュービックパノラマの上に透明な画像、スライドショー、シェーダーを重ねると、回転するパノラマを額縁で囲むように表示できます。
- 動画背景は透明になりません。動画が映っていない部分も含め、下にあるすべてを覆います。

## 複数のレイアウト

[ユニバーサルレイアウト](/universal-layouts)と画面専用のレイアウトなど、画面上で複数のレイアウトが有効な場合は、背景も重なります。

- **レイアウトインデックス [複数レイアウトの順序]**の値が大きいレイアウトが上に表示されます。エディターの背景を右クリックして設定してください。
- いずれかのレイアウトで[すべての背景に適用される設定](#settings-for-all-backgrounds)を有効にすると、すべてのレイアウトの背景に適用されます。
- レイアウトエディターに表示されるのは、編集中のレイアウトの背景だけです。

# 補足

- レイアウトの要素は、常に背景の前に表示されます。
- 各種類の設定にある**背景IDをコピー**をクリックすると、その背景を操作するアクションやプレースホルダーで使うIDをコピーできます。[動画背景](/video)などが該当します。
- 各種類の設定にある**AI用にエクスポート**をクリックすると、[AIチャット](/export-for-ai)用に背景をコピーできます。
- ワールド一覧など、リストのある画面のヘッダーとフッターには、それぞれ独自のテクスチャがあります。エディターの背景を右クリックして、**ヘッダー/フッターのカスタマイズ**を開いてください。
