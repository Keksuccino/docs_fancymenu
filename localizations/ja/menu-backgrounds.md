# メニューの背景

FancyMenuでは、メニューにカスタム背景を設定できます。画像、アニメーション付きテクスチャ、スライドショー、立方体パノラマ、色、ブラウザー、動画、GLSLシェーダーなどを使用できます。

# 背景を設定する

メニュー背景のカスタマイズは、レイアウトエディターのコンテキストメニューから行えます。

1. レイアウトエディターを開きます。
2. エディターの背景を右クリックします。
3. **メニューの背景** を開きます。
4. 使いたい背景タイプを有効にして設定します。

一般的な背景タイプには次のものがあります。

- Vanilla
- Image
- Slideshow
- Cubic Panorama
- Color (HEX)
- Browser
- Video
- GLSL Shader
- Video [MCEF]（非推奨）
- 追加のアドオン背景タイプ

旧 **Video [MCEF]** 背景タイプは非推奨です。新しいレイアウトでは、Watermedia V3 による [ネイティブの **Video** 背景](./video) を使用してください。

# カスタム背景を削除する

**メニューの背景** をもう一度開き、不要になったカスタム背景タイプを無効化または削除します。カスタム背景タイプが有効でなければ、画面は通常のバニラ背景の動作に戻ります。

# 背景を重ねる

1つのレイアウトで複数のメニュー背景タイプを有効にできます。有効な背景は重なって描画されるため、ベースとなる画像やパノラマに、半透明のブラウザー、シェーダー、パララックス、その他のレイヤーを組み合わせられます。

複数のレイアウトを有効にしている場合は、それらの背景スタックも組み合わせられます。レイアウトの順序を並べ替えて特定の順番で表示するには、エディターの背景を右クリックして **Layout Index** をクリックします。

# 透明な背景

FancyMenu は、有効なカスタム背景の背面に黒い下地レイヤーを描画します。そのため、最下層の背景にある透明ピクセルは黒として表示されます。まず不透明なベース背景を用意し、その上に半透明の背景を重ねてください。

背景画像を半透明にするには、お好みの画像編集ソフトを使用してください。

# ブラウザー背景

**Browser** 背景タイプは [Browser 要素](./elements#browser) と同様に動作しますが、画面全体を埋め、自動でフォーカスされます。フルスクリーンのウェブコンテンツ、ローカル HTML ページ、またはウェブ動画レイヤーに便利です。

# GLSLシェーダー背景

**GLSL Shader** 背景タイプはカスタム GLSL シェーダーを描画し、Shadertoy 形式のシェーダー作成をサポートします。対応する uniform とシェーダー構造については、[GLSL Shader API](/glsl-shader-api) のページを参照してください。
