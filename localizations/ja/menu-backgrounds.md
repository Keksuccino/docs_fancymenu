# メニュー背景

FancyMenu を使うと、メニューにカスタム背景を設定できます。画像、アニメーション付きテクスチャ、スライドショー、立方体パノラマ、色、ブラウザ、動画、GLSL シェーダーなどを使用できます。

# 背景の設定

FancyMenu 3.9.0 以降では、メニュー背景のカスタマイズはレイアウトエディタのコンテキストメニューから直接行えます。

1. レイアウトエディタを開きます。
2. エディタ背景を右クリックします。
3. **メニュー背景** を開きます。
4. 使用したい背景タイプを有効にして設定します。

一般的な背景タイプには以下が含まれます。

- Vanilla
- Image
- Slideshow
- Cubic Panorama
- Color (HEX)
- Browser
- Video
- GLSL Shader
- Video [MCEF]（非推奨）
- その他..

従来の **Video [MCEF]** 背景タイプは、FancyMenu 3.9.0 で非推奨になりました。新しいレイアウトでは、Watermedia V3 を利用したネイティブの **Video** 背景を使用してください。

# カスタム背景の削除

**メニュー背景** をもう一度開き、不要になったカスタム背景タイプを無効化または削除します。アクティブなカスタム背景タイプがない場合、画面は通常のバニラ背景の動作に戻ります。

# 背景の重ね合わせ

FancyMenu 3.9.0 では、同じレイアウト内で複数のメニュー背景タイプを有効にできます。アクティブな背景は重ねて描画されるため、ベースの画像やパノラマに、半透明のオーバーレイ、ブラウザレイヤー、シェーダーレイヤー、パララックスレイヤーなどの効果を組み合わせられます。

複数のレイアウトを同時に有効にしている場合は、それぞれの背景スタックも組み合わせられます。レイアウトの順序を整理して特定の順番で表示したい場合は、エディタ背景を右クリックし、**Layout Index** をクリックします。

# 透明な背景

背景の後ろには何もないため、一番下の背景を透明にすることはできません。そうすると描画の不具合が起きるためです。ただし、一番下の背景が完全不透明である限り、重ねた背景構成で透明度を使うことはまったく問題ありません。これにより、一番下の背景の上に半透明の背景レイヤーを重ねられます。

背景画像を半透明にするには、任意の画像編集ソフトを使用してください。

# ブラウザ背景

**Browser** 背景タイプは Browser 要素と同様に動作しますが、画面全体を埋めて自動フォーカスされます。フルスクリーンのウェブコンテンツ、ローカル HTML ページ、またはウェブ動画レイヤーに便利です。

# GLSL シェーダー背景

**GLSL Shader** 背景タイプはカスタム GLSL シェーダーを描画し、Shadertoy 風のシェーダー作成をサポートします。対応している uniform とシェーダー構造については、[GLSL Shader API](/glsl-shader-api) のページを参照してください。
