# Element Animator

**Animator** は、他の要素をアニメーションさせるための要素です。この要素を使うと、キーフレームを利用して、別の要素のサイズ、位置、アンカーポイントを時間経過とともに滑らかに変化させることができます。キーフレームは、特定の瞬間に要素がどう見えるべきかを記録したスナップショットのようなものです。Animator 要素はこれらのスナップショットを順番に再生し、滑らかな動きを作り出します。

> [!WARNING]
> **Element Animator** では、要素の **位置、サイズ、アンカーポイント** を制御できます。**不透明度、表示/非表示、回転** など、要素の他の設定を制御することは**できません**！

# Animator 要素の追加

1. **背景を右クリックする:**  
   レイアウトエディターで、背景を右クリックします。

2. **New Element -> Element Animator を選択する:**  
   表示されたメニューで **New Element** に移動し、**Element Animator** をクリックします。これで Animator 要素がレイアウトに追加されます。

3. **設定する:**  
   追加後、Animator 要素にはデフォルト設定が表示されます。Animator を右クリックしてメニューから選ぶことで、ループや色などのオプションを変更できます。

# キーフレームの管理

キーフレームは、ある時点で要素がどう見えるべきかを Animator に伝えるブックマークのようなものです。

## キーフレームエディターを開く

- **エディターを開く:**  
  Animator 要素を右クリックし、**Edit Keyframes**（または **Manage Keyframes**）を選択します。これで、キーフレームの追加・編集・削除を行える画面が開きます。

## 記録してキーフレームを追加する

- **記録を開始する:**  
  キーフレームエディターで **`R` キー** を押して記録を開始します。記録中は、プレビュー बॉックスの色が変わり、アクティブであることが分かります。
  
- **プレビューを変更する:**  
  プレビュー बॉックスを移動またはサイズ変更して、好きな見た目を設定します。オフセットモードでは、プレビューは十字線の中心に固定されたままになり、変更はオフセットとして表示されます。
  
- **キーフレームを追加する:**  
  **`K` キー** を押して、現在の見た目をキーフレームとして保存します。このキーフレームには、プレビューの位置、サイズ、アンカー設定が保存されます。

## キーフレームの編集

- **キーフレームを選択する:**  
  タイムライン上のキーフレームマーカーをクリックします。**Ctrl** を押しながらクリックすると、複数選択もできます。
  
- **キーフレームを移動する:**  
  キーフレームマーカーを左右にドラッグして、時間を変更します。次の方法でも移動できます。
  - **左矢印:** 100ms 早める。
  - **右矢印:** 100ms 遅らせる。
  
- **プレビューを細かく調整する:**  
  キーフレームを選択した状態で、プレビュー बॉックスを移動またはサイズ変更して調整します。必要に応じて **Ctrl + Z** で元に戻し、**Ctrl + Y** でやり直せます。

## キーフレームの削除

- **キーフレームを削除する:**  
  キーフレームを選択して **Delete キー** を押すと削除できます。
  
- **複数のキーフレームを削除する:**  
  複数のキーフレームを選択して（たとえば **Ctrl + A** で全選択）、Delete を押すとまとめて削除できます。

## キーフレームのスムージング

キーフレームのスムージングは、キーフレームの間隔を均等に整える機能です。これにより、アニメーションがより自然で滑らかに見えます。

- **複数のキーフレームを選択する:**  
  まず、整えたい 2 つ以上のキーフレームを選択します（**Ctrl + クリック** または **Ctrl + A** を使用）。

- **スムージングボタンをクリックする:**  
  キーフレームエディター下部のツールバーで、**Distance Smoothing** と書かれたボタンをクリックします。

- **新しい間隔を入力する:**  
  小さな入力欄が表示されるので、各選択キーフレーム間の時間差を同じにするための値（ミリ秒）を入力します。

- **スムージングを適用する:**  
  Enter を押してスムージングを適用します。キーフレーム間の時間差が均等になるように調整されます。

# アニメーションのプレビュー

キーフレームを記録した後、アニメーションの見た目を確認できます。

- **アニメーションを再生する:**  
  キーフレームエディターで **`P` キー** を押すか、再生ボタンをクリックします。プレビューは最初から再生され、時間の経過とともにプレビュー बॉックスがどう変化するかを確認できます。
  
- **ループについて:**  
  キーフレームエディターでのプレビュー中は、アニメーションは**ループしません**。つまり、最初から最後まで 1 回だけ再生されます。ループは、最終的なレイアウトで Animator 要素が対象要素に適用されたときのみ有効になります。
  
- **プレビューを一時停止する:**  
  止めたい位置で **`P` キー** をもう一度押すと、一時停止できます。
  
- **進行バーをドラッグする:**  
  利用できる場合は、タイムラインマーカーをドラッグして、任意の時点でアニメーションの見た目を確認できます。

# 対象要素の選択

キーフレームを設定したら、どのレイアウト要素をアニメーションさせるかを選びます。

1. **Target Manager を開く:**  
   Animator 要素を右クリックし、**Manage Targets** を選択します。
  
2. **対象を追加する:**  
   **Add Target** をクリックすると、利用可能な要素の一覧が表示されます。アニメーションさせたい要素を選びます。
  
3. **対象を削除する:**  
   対象を削除するには、マネージャーを開いて **Remove Target** をクリックします。

最終レイアウトでアニメーションが再生されると、Animator はキーフレームを使って選択した要素のサイズ、位置、その他の設定を変更します。ループを設定していれば、ここでループが適用されます。

# キーボードショートカット

キーフレームエディターでは、次のショートカットを使うと素早く操作できます。

- **`R` キー:** 記録の開始/停止。
- **`T` キー:** 記録の一時停止/再開。
- **`P` キー:** アニメーションプレビューの再生/一時停止。
- **`K` キー:** 現在の時刻に新しいキーフレームを追加。
- **左/右矢印キー:**  
  - **左矢印:** キーフレームを 100ms 早める。
  - **右矢印:** キーフレームを 100ms 遅らせる。
- **Delete キー:** 選択中のキーフレームを削除。
- **Ctrl + A:** すべてのキーフレームを選択。
- **Ctrl + Z:** 直前の変更を元に戻す。
- **Ctrl + Y:** 取り消した変更をやり直す。
- **Ctrl + キーフレームのドラッグ**: 複数選択したキーフレームをまとめてドラッグする。

# 追加設定とヒント

- **アニメーションをループさせる:**  
  Animator をループさせることができます。ループを有効にすると、最後のキーフレームの後でアニメーションが最初に戻ります。ただし、これは最終的な対象要素に対してのみ発生します。キーフレームエディターのプレビューではループしません。
  
- **サイズ/位置を無視する:**  
  キーフレームで要素のサイズや位置を変更したくない場合は、これらのオプションをオフにします。

- **タイミングオフセット:**
  個別の対象要素にオフセットを付けたり、設定した範囲内でランダムなタイミングオフセットを使ったりして、1 つのアニメーションが各対象で異なるタイミングで開始するようにできます。
  
- **オフセットモード:**  
  オフセットモードでは、アニメーションは要素の元の位置からの変化として適用されます。プレビューは十字線の中心に表示されます。
  
- **元に戻す / やり直す:**  
  **Ctrl + Z** で元に戻し、**Ctrl + Y** でやり直せます。
  
- **順序を確認する:**  
  キーフレームが時間順に正しく並んでいることを確認してください。システムが自動で並べ替えますが、移動した後は順序を再確認してください。
  
- **変更をプレビューする:**  
  保存する前に、再生ボタンまたは **`P` キー** を使ってアニメーションを確認できます。
