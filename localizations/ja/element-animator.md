# Element Animator

**Animator** は、ほかの要素をアニメーションさせるための要素です。この要素を使うと、キーフレームを利用して、別の要素のサイズ、位置、アンカーポイントを時間経過とともに滑らかに変化させることができます。キーフレームは、ある特定の瞬間に要素がどのように見えるべきかを記録したスナップショットのようなものです。Animator 要素はこれらのスナップショットを順番に再生し、滑らかな動きを作り出します。

> **Element Animator** では、要素の **位置、サイズ、アンカーポイント** を制御できます。要素の不透明度、表示/非表示、回転など、その他の設定を制御することは **できません**。

# Animator 要素の追加

1. **背景を右クリックする:**  
   レイアウトエディターで、背景を右クリックします。

2. **New Element -> Element Animator を選択する:**  
   表示されたメニューで **New Element** に移動し、**Element Animator** をクリックします。これで Animator 要素がレイアウトに追加されます。

3. **設定する:**  
   追加すると、Animator 要素はデフォルト設定で表示されます。Animator を右クリックしてメニューから選ぶことで、ループや色などのオプションを変更できます。

# キーフレームの管理

キーフレームは、ある時点で要素がどう見えるべきかを Animator に伝えるブックマークのようなものです。

## キーフレームエディターを開く

- **エディターを開く:**  
  Animator 要素を右クリックし、**Edit Keyframes**（または **Manage Keyframes**）を選択します。これにより、キーフレームの追加、編集、削除ができる画面が開きます。

## キーフレームの記録と追加

- **記録を開始する:**  
  キーフレームエディターで **`R` キー** を押して記録を開始します。記録中は、プレビュー枠の色が変わり、有効になっていることが分かります。
  
- **プレビューを変更する:**  
  プレビュー枠を移動またはサイズ変更して、希望する見た目を設定します。オフセットモードでは、プレビューは十字線を中心に表示され、変更内容がオフセットとして扱われます。
  
- **キーフレームを追加する:**  
  **`K` キー** を押して、現在の見た目をキーフレームとして保存します。このキーフレームには、プレビューの位置、サイズ、アンカー設定が保存されます。

## キーフレームの編集

- **キーフレームを選択する:**  
  タイムライン上のキーフレームマーカーをクリックします。**Ctrl** を押しながらクリックすると、複数選択もできます。
  
- **キーフレームを移動する:**  
  キーフレームマーカーを左右にドラッグして、時間を変更します。次の操作もできます。
  - **左矢印:** 100ms 早く移動します。
  - **右矢印:** 100ms 遅く移動します。
  
- **プレビューを微調整する:**  
  キーフレームを選択すると、プレビュー枠を移動またはサイズ変更して調整できます。必要に応じて **Ctrl + Z** で元に戻し、**Ctrl + Y** でやり直せます。

## キーフレームの削除

- **キーフレームを削除する:**  
  キーフレームを選択して **Delete キー** を押すと削除できます。
  
- **複数のキーフレームを削除する:**  
  複数のキーフレームを選択して（たとえば **Ctrl + A** で全選択して）、Delete キーを押すとまとめて削除できます。

## キーフレームのスムージング

キーフレームのスムージングは、キーフレームの間隔を均等に整えるための機能です。これにより、アニメーションがより一貫して滑らかに見えるようになります。

- **複数のキーフレームを選択する:**  
  まず、スムージングしたい 2 つ以上のキーフレームを選択します（**Ctrl + クリック** または **Ctrl + A** を使用）。

- **スムージングボタンをクリックする:**  
  キーフレームエディター下部のツールバーで、**Distance Smoothing** と書かれたボタンをクリックします。

- **新しい距離を入力する:**  
  小さな入力欄が表示されます。各キーフレーム間の時間差を同じにするための値（ミリ秒）を入力します。

- **スムージングを適用する:**  
  Enter キーを押して適用します。キーフレーム間の時間差が均等になるように調整されます。

# アニメーションのプレビュー

キーフレームを記録したら、アニメーションの見た目を確認できます。

- **アニメーションを再生する:**  
  キーフレームエディターで **`P` キー** を押すか、再生ボタンをクリックします。プレビューは最初から再生され、時間経過に伴ってプレビュー枠がどう変化するかを表示します。
  
- **ループについて:**  
  キーフレームエディターでプレビューしている間、アニメーションは **ループしません**。つまり、最初から最後まで 1 回だけ再生されます。ループは、最終レイアウトで Animator 要素が対象要素に適用されたときにのみ有効になります。
  
- **プレビューを一時停止する:**  
  特定の位置で止めたい場合は、もう一度 **`P` キー** を押してアニメーションを一時停止します。
  
- **進行バーをドラッグする:**  
  利用できる場合は、タイムラインのマーカーをドラッグして、任意の時点でのアニメーションの見た目を確認できます。

# 対象要素の選択

キーフレームを設定したら、どのレイアウト要素をアニメーションさせるかを選ぶ必要があります。

1. **ターゲットマネージャーを開く:**  
   Animator 要素を右クリックし、**Manage Targets** を選択します。
  
2. **ターゲットを追加する:**  
   **Add Target** をクリックすると、利用可能な要素の一覧が表示されます。アニメーションさせたい要素を選択します。
  
3. **ターゲットを削除する:**  
   ターゲットを削除するには、マネージャーを開いて **Remove Target** をクリックします。

最終レイアウトでアニメーションが再生されると、Animator はキーフレームを使って選択した要素のサイズや位置などを変化させます。設定していれば、ここでループも適用されます。

# キーボードショートカット

キーフレームエディターでは、次のショートカットを使うと作業をすばやく行えます。

- **`R` キー:** 記録を開始または停止します。
- **`T` キー:** 記録を一時停止または再開します。
- **`P` キー:** アニメーションプレビューを再生または一時停止します。
- **`K` キー:** 現在時刻に新しいキーフレームを追加します。
- **左右矢印キー:**  
  - **左矢印:** キーフレームを 100ms 早く移動します。
  - **右矢印:** キーフレームを 100ms 遅く移動します。
- **Delete キー:** 選択したキーフレームを削除します。
- **Ctrl + A:** すべてのキーフレームを選択します。
- **Ctrl + Z:** 直前の変更を元に戻します。
- **Ctrl + Y:** 元に戻した変更をやり直します。
- **Ctrl + キーフレームのドラッグ**: 複数選択したキーフレームをまとめてドラッグします。

# 追加設定とヒント

- **アニメーションをループする:**  
  Animator をループさせるように設定できます。ループを有効にすると、最後のキーフレームの後でアニメーションが再び開始されます。ただし、これは最終的なターゲット要素に対してのみ適用されます。キーフレームエディターのプレビューではループしません。
  
- **サイズ/位置を無視する:**  
  キーフレームで要素のサイズや位置を変更したくない場合は、これらのオプションをオフにします。

- **タイミングオフセット:**
  FancyMenu 3.9.0 では、制御された要素に対するタイミングオフセットが追加されています。個々のターゲット要素ごとにオフセットを設定したり、設定した範囲内でランダムなタイミングオフセットを使用したりできるため、1 つのアニメーションを各ターゲットで少しずつ異なる時間に開始できます。
  
- **オフセットモード:**  
  オフセットモードでは、アニメーションは要素の元の位置からの変化として適用されます。プレビューは十字線を中心に表示されます。
  
- **元に戻す / やり直す:**  
  **Ctrl + Z** で変更を元に戻し、**Ctrl + Y** でやり直せます。
  
- **順序を確認する:**  
  キーフレームが時間順に正しく並んでいることを確認してください。システムが自動で並べ替えますが、1 つ移動した後は順序を再確認しましょう。
  
- **プレビューで確認する:**  
  保存する前に、再生ボタンまたは **`P` キー** を使ってアニメーションの見た目を確認できます。

# まとめ

これらの簡単な手順に従えば、Animator 要素をレイアウトに追加し、滑らかなアニメーションを作成できます。プレビューでライブに変更を記録したり、キーボードでキーフレームを調整したり、どの要素をアニメーションさせるかを選んだり、プレビューで見た目を確認したりと、Animator 要素を使えばカスタムメニューに簡単に動きを加えられます。

楽しくアニメーションしましょう！
