# 要素の不透明度

FancyMenu のほとんどの要素（いくつかの例外を除く）は、右クリックメニューから不透明度を設定できます。

要素の不透明度の値はプレースホルダーに対応しており、プレースホルダーに応じて不透明度を動的に更新できます。

これにより、Ticker 要素と組み合わせて変数の値を更新し、その値をプレースホルダー経由で不透明度として適用することで、独自のフェード処理を作成できます。

要素の不透明度を設定するには、**要素を右クリック -> 不透明度 -> 設定** を選択します。

# 要素のフェードイン/フェードアウト

単純に要素をフェードインまたはフェードアウトさせたいだけなら、要素に組み込まれているフェード機能を使うほうが簡単です。要素の右クリックメニューからフェードを有効にできます。

この機能では、要素が読み込まれるたびにフェードインします。メニューを開いたときの初回読み込みでも、要素の読み込み条件によって読み込まれる場合でも同様です。読み込み条件を満たさなくなって非表示になったときは、フェードアウトします。

フェード機能ではフェード速度を設定でき、要素がどれくらい速くフェードイン/アウトするかを制御できます。
