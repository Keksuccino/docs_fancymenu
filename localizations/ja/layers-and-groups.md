# レイヤーとグループ

**ウィンドウ -> エディタウィジェット -> レイヤー** からレイヤーウィジェットを開きます。

# レイヤーの順序

リスト内のレイヤーをドラッグして、描画順を変更します。要素を右クリックして **レイヤーを1つ上へ移動** または **レイヤーを1つ下へ移動** を使うこともできます。

[Player Entity](./elements#player-entity) と [Item](./elements#item) の要素には描画制限があり、通常のレイヤー順序が適用されない場合があります。

# グループ

グループは関連するレイヤーをまとめ、まとめて移動したり非表示にしたりできるようにします。

- グループの作成と名前変更。
- 個々のレイヤーの名前変更。
- レイヤーをグループ内外へドラッグ。
- グループをドラッグして、その中のすべてのレイヤーを順序内で移動。
- グループの折りたたみと展開。
- グループ内のすべてのレイヤーの表示/非表示。
- レイヤーを削除せずにグループを削除。

グループへの所属と折りたたみ状態は、レイアウトと一緒に保存されます。
