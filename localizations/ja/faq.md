# よくある質問

### 問題について助けが必要です。どのような情報を提供すればよいですか？

適切なサポートを受けるため、できるだけ多くの状況を提供してください。
1.  **問題の明確な説明:** 何が起こることを期待していて、実際には何が起こりましたか？
2.  **`latest.log` ファイル:** `<game-directory>/logs/latest.log` にあります。特に要求されない限り、**クラッシュログは送信しないでください**。通常、必要な状況情報は `latest.log` に含まれています。投稿する際は https://gist.github.com のようなサイトを使用してください。
3.  **Minecraft のバージョン:** （例: 1.20.1）
4.  **Mod ローダーとバージョン:** （例: Forge 47.2.0、Fabric 0.15.7）
5.  **FancyMenu のバージョン:** （例: 3.5.2）
6.  問題の**スクリーンショットや動画**も非常に役立ちます。

### 要素の重なり順（何かを別のものの前や後ろに移動する方法）を変更するにはどうすればよいですか？

*   **カスタム要素同士:** **ウィンドウ -> エディターウィジェット -> レイヤー**を開き、階層内で要素をドラッグします。要素を右クリックして **1 レイヤー上へ移動 / 1 レイヤー下へ移動** を使用することもできます。[レイヤーとグループ](./layers-and-groups)を参照してください。
*   **カスタム要素とバニラ要素:** すべてのカスタム要素をすべてのバニラ要素の後ろに描画する（デフォルトのボタンの後ろに背景画像を配置するなど）には、**エディターの背景を右クリック**し、**「カスタム要素をバニラ要素の後ろに描画」**を切り替えます。

### ユニバーサルボタンテンプレートから特定のボタンを除外できますか？

**いいえ。テンプレートボタンにカスタムテクスチャが設定されている場合、それらのテクスチャは影響を受けるすべての要素で常に共有されます。個別のボタンを除外することはできません。**

### ボタンをクリックしたときに何かを実行させるにはどうすればよいですか？

[**アクションスクリプト**](./action-scripts)を使用します。
1.  エディターでボタンを右クリックします。
2.  **アクションスクリプトを編集**を選択します。
3. **アクションを追加**をクリックし、[**画面またはカスタム GUI を開く**](./action-scripts#open-screen-or-custom-gui-opengui)、[**サーバーに参加**](./action-scripts#join-server-joinserver)、[**変数の値を設定**](./action-scripts#set-variable-value-fm-variable-set_variable)などのアクションを選択します。

### 完全に新しいメニュー画面をゼロから作成できますか？

[**カスタム GUI**](./custom-guis)を使用します。
1.  メニューバーで **カスタマイズ -> カスタム GUI -> カスタム GUI を管理**に移動します。
2.  **「新しい GUI」**をクリックし、一意の識別子を付けます。
3.  その後、この新しい空の画面を開いてレイアウトを作成し、好きな要素を追加できます。
4. [**画面またはカスタム GUI を開く**アクション](./action-scripts#open-screen-or-custom-gui-opengui)でカスタム GUI を開きます。

### 事前読み込みを有効にした後、ゲームの読み込みに時間がかかるようになりました。

これは想定された動作です。高解像度のアニメーションやサウンドなど、大きなリソースを初回起動時に事前読み込みすると、ゲームの読み込み時間は自然に長くなります。

### FMA アニメーションが RAM を使いすぎています！

従来の [FMA アニメーション](./fma)は、高解像度のフレームを多数含む場合、多くのメモリを消費することがあります。大規模または複雑なアニメーションテクスチャには AFMA の方が適しています。従来の FMA アニメーションは短く保ち、完全な動画再生には [動画](./video)を使用してください。

### FancyMenu は OptiFine に対応していますか？

いいえ。OptiFine は**互換性がなく**、FancyMenu を含む多くの Mod を壊すことが知られています。Sodium/Embeddium + Iris/Oculus のような最新の代替 Mod を使用することを強くおすすめします。
[OptiFine の代替](./optifine-alternatives)を参照してください。

### ゲームがクラッシュします。Mod の競合かどうかを確認するにはどうすればよいですか？

Mod の競合を確認する最善の方法は、**FancyMenu とその依存関係（Konkrete、Melody）だけを有効にしてゲームを実行すること**です。クラッシュが発生しなくなった場合は、クラッシュが再発するまで他の Mod を少数のグループに分けて戻していき、競合している Mod を特定できます。

### 他の Mod のボタンが消えたり、編集しようとしても機能しなかったりします。

一部の Mod は、FancyMenu が検出またはカスタマイズできない方法でウィジェットを追加します。[バニラ/Mod 要素](./vanilla-elements)と、リスト形式の画面については[スクロール可能な画面のカスタマイズ](./customizing-scrollable-screens)を確認してください。それでもウィジェットが表示されない場合、そのウィジェットを追加している Mod が、対応する画面ウィジェットとして公開する必要があります。

### FancyMenu のレイアウトをサーバーで使用できますか？

レイアウトと視覚的なカスタマイズはプレイヤーのクライアントに保存されるため、サーバーから未設定のクライアントに強制適用することはできません。Mod パックの一部として配布してください。[サーバーコマンド](./commands)、[FM Data](./fm-data)、[サーバー側 NBT アクセス](./nbt-data-placeholder#server-side-placeholder)、ゲームルール、ストラクチャー、サーバーリスナーが必要な場合は、サーバーに FancyMenu をインストールしてください。

### FancyMenu v2（古い MC バージョン向け）と v3 の違いは何ですか？

FancyMenu v3 は完全に書き直されたバージョンで、多くの新機能、より安定したアーキテクチャ、優れたパフォーマンスを備えています。v2 は古く、サポートが終了しており、高度なプレースホルダーやスクリプトなど多くの機能がありません。最新の Minecraft バージョン（1.18.2 以降）では v3 を使用することを強くおすすめします。v2 のレイアウトは読み込む際に v3 へ自動変換できますが、一部手動で修正が必要になる場合があります。

### あらかじめ作成されたレイアウトやテンプレートはどこにありますか？

FancyMenu のコミュニティは、公式 Keksuccino's Mods Discord サーバー（「Kekscord」）の [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) チャンネルでレイアウトを共有しています。

### プレイヤーエンティティを他の要素の後ろに描画するにはどうすればよいですか？

通常、[レイヤーウィジェット](./layers-and-groups)を使って、[プレイヤーエンティティ要素](./elements#player-entity)を通常の 2D 要素の後ろに強制配置することはできません。プレイヤーエンティティのレンダラーは、通常の GUI レイヤー順を無視することがあります。この制限を考慮してレイアウトを設計するか、厳密なレイヤー順が必要な場合は事前にレンダリングした画像を使用してください。

### プレイヤーエンティティの脚が 1 本しかありません！何が起きたのですか？

これは視覚的な不具合で、プレイヤーのアニメーションやモデルを変更する別の Mod との競合が原因である可能性があります。プレイヤーエンティティのポーズ設定を確認し、脚が誤って回転または移動されていないか確認してください。

### スクリプト内のアクション間に遅延を作成するにはどうすればよいですか？

遅延アクションのロジックには、[**遅延**または**後で実行**ブロック](./action-scripts#what-are-statements)を使用します。繰り返し実行するバックグラウンド処理には、[スケジューラー](./schedulers)を使用してください。

### Create Mod のメニューをカスタマイズできますか？

いいえ。Create の画面では、意図的にカスタマイズが無効化されています。[カスタマイズが意図的に無効化されている画面](./incompatibility-list#screens-where-customization-is-intentionally-disabled)を参照してください。

### 背景画像やボタンテクスチャに推奨される解像度は何ですか？

背景: 標準的な 1920x1080（1080p）画像は優れた出発点であり、ほとんどのユーザー環境で適切に拡大縮小されます。
ボタン: バニラのボタンの多くは、幅が約 150～200 ピクセル、高さが 20 ピクセルです。統一感を保つため、カスタムテクスチャもこのサイズに合わせるとよいでしょう。

### プレイヤーがゲーム内の目標（クエストなど）を達成したときに、メニューを自動的に開いたりコマンドを実行したりできますか？

FancyMenu には多くの[組み込みゲームイベントリスナー](./listeners)がありますが、すべてのサードパーティ製クエストシステムに対応する汎用リスナーはありません。クエスト Mod がコマンド報酬に対応している場合は、それを使って [`/openguiscreen`](./commands#openguiscreen)、[`/fmvariable`](./commands#fmvariable)、またはその他の適切な [FancyMenu コマンド](./commands)を実行してください。

### ボタンを非アクティブまたは「グレーアウト」するにはどうすればよいですか？

[読み込み要件](./conditions)を使ってボタンのアクティブ状態を制御できます。
エディターでボタンを右クリックし、**アクティブ状態を制御**を選択します。
ボタンをアクティブにするために満たす必要がある要件を追加します。恒久的に無効化するには、[**数値判定**](./conditions#is-number-fancymenu_visibility_requirement_is_number)を使い、0 と 1 が等しいかどうかを確認します。
これでボタンは「非アクティブ背景」テクスチャを使用し、クリックできなくなります。

### スクロール可能な画面からヘッダーとフッター（土のテクスチャのバー）を削除するにはどうすればよいですか？

レイアウトエディターで、**レイアウトプロパティ -> ヘッダー/フッターのカスタマイズ**を開きます。テクスチャを透明に設定してください。このオプションは、一部の Mod 画面では利用できない場合があります。

### 「現在の画面用」のレイアウトを作成できません。ボタンがグレーアウトしています。

まず、**メニューバー -> カスタマイズ -> 現在の画面のカスタマイズ -> 有効**から、その画面のカスタマイズを有効にする必要があります。

### エディターで画面を開くと、どの要素もカスタマイズできません。空の画面になっています。

現在の画面**用**ではなく、[ユニバーサルレイアウト](./universal-layouts)を作成した可能性があります。

また、FancyMenu がデフォルトではカスタマイズできない[スクロール可能な画面](./customizing-scrollable-screens)である可能性もあります。

3 つ目の可能性は、バニラとは異なる方法で要素を追加する Mod の画面であることです。この場合、FancyMenu はそれらの要素をカスタマイズできません。

### テキスト要素の周りに奇妙な灰色のボックスがあります。

この半透明のボックスは[テキスト要素](./elements#text)のスクロールつまみであり、描画の不具合ではありません。

ボックスを表示したくない場合は、要素を右クリックしてスクロール自体を無効にするか、要素をスクロール可能なままにしたい場合は、同じ右クリックメニューでつまみのテクスチャを完全に透明なものに設定できます。

### 最新の Minecraft の変更履歴をメニューに表示するにはどうすればよいですか？

Minecraft の変更履歴を FancyMenu 対応の Markdown に変換する優れた [GitHub プロジェクト](https://github.com/ClaytonTDM/minecraft-changelogs-markdown)があります。これを使えば、最新の MC の変更履歴をメニューに表示できます！毎日更新され、新しい変更履歴を取得します。

[テキスト要素](./elements#text)に表示するには、**ソースモード**を**リソース**に設定し、リソースソースを**Web**にします。`https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md` を使用してください。

### 要素を画面サイズいっぱいに引き伸ばす最も簡単な方法は何ですか？

ほとんどの要素には、右クリックのコンテキストメニューに水平方向および垂直方向に引き伸ばすオプションがあります。これを有効にすると、画面の幅いっぱい、または高さいっぱいに常に引き伸ばされます。水平方向と垂直方向の引き伸ばしは個別に切り替えられます。

### テキスト要素の後ろや前にあるボタンをクリックしたり、スライダーを操作したりできません。

テキスト要素はデフォルトで操作可能です（スクロールつまみをつかんだり、Markdown のハイパーリンクをクリックしたりするため）。そのため、マウスクリックやスクロールイベントを消費します。最善の方法は、ボタンをテキスト要素の後ろや前に移動しないことです。しかし避けられない場合は、**テキスト要素を右クリック**し、**操作可能**を**無効**に設定して、操作できないようにできます。ただし、この場合テキスト要素は静的で操作できないテキストになるため、スクロールしたりハイパーリンクをクリックしたりできなくなる点に注意してください。

### 画面内を矢印キーや Tab キーで移動するときに、ボタンやスライダーが選択・フォーカスされないようにするにはどうすればよいですか？

ボタンやスライダーをナビゲーション対象外にするには、対象を**右クリック**して**ナビゲーション可能**を**無効**に設定します。ボタンやスライダーは引き続きクリックできますが、矢印キーや Tab キーの移動でフォーカスできなくなります。

これは Chat 画面にボタンやスライダーを追加する場合にも便利です。画面内のボタンやスライダーを誤って選択せずに、上矢印キーで過去のメッセージをスクロールできます。

### FancyMenu のコンテキストメニューに、本来あるはずのオプションがありません。

FancyMenu のコンテキストメニュー（どこかを右クリックしたとき、またはメニューバーを操作したときに開くメニュー）は**スクロール可能**です。つまり、マウスカーソルをメニュー上に置いた状態でマウスホイールを使って上下にスクロールすると、これまで表示されていなかった追加のオプションを確認できます。

### タイトル画面をカスタマイズできません。エディターを離れると元の画面が表示されます。

別の Mod が元の `title_screen` を置き換えています。その Mod の設定でカスタムタイトル画面を無効にしてください。そのようなオプションがない場合、FancyMenu は置き換え後の画面にレイアウトを適用できません。
