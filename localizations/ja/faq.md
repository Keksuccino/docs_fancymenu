# FAQ

### 問題について助けが必要です。どのような情報を提供すればよいですか？
最適なサポートを受けるには、できるだけ多くの情報を提供してください。
1.  **問題の明確な説明:** 何を期待していて、実際には何が起こったのか？
2.  **`latest.log` ファイル:** これはトラブルシューティングで最も重要なファイルです。インスタンスの `/logs/` フォルダ内にあります。**クラッシュログは送らないでください**。特に求められない限り、`latest.log` のほうがはるかに役立ちます。共有には https://gist.github.com のようなサイトを使ってください。
3.  **Minecraft のバージョン:** （例: 1.20.1）
4.  **Mod ローダーとそのバージョン:** （例: Forge 47.2.0、Fabric 0.15.7）
5.  **FancyMenu のバージョン:** （例: 3.5.2）
6.  **問題のスクリーンショットや動画** も非常に役立ちます。

### 要素の重なり順を変更するにはどうすればいいですか？（何かを他の前面/背面に移動する）
*   **カスタム vs. カスタム:** 自分で作成したカスタム要素の描画順を変更するには、**Layers ウィジェット**を使用します。メニューバーの **Window -> Widgets -> Layers** から開けます。そこで要素を階層内で上下にドラッグできます。また、要素を右クリックして **"Move One Layer Up/Down"** を使うこともできます。
*   **カスタム vs. バニラ:** すべてのカスタム要素をすべてのバニラ要素の背面に描画するには（例: デフォルトのボタンの背面に背景画像を置く）、**エディターの背景を右クリック**して **"Render Custom Elements Behind Vanilla"** オプションを切り替えてください。

### すべてのボタンに共通のテンプレートから、特定のボタンだけを除外できますか？
**いいえ。テンプレートのボタンにカスタムテクスチャが設定されている場合、そのテクスチャは影響を受けるすべての要素で常に共有されます。個別のボタンだけを除外することはできません。**

### ボタンをクリックしたときに何か動作させるにはどうすればいいですか？
**Action Script** を使用します。
1.  エディターでボタンを右クリックします。
2.  **Edit Action Script** を選択します。
3.  **Add Action** をクリックし、一覧から選択します（例: `Open Screen or Custom GUI`、`Join Server`、`Set Variable Value`）。
*   詳細: [Action Scripts](https://docs.fancymenu.net/en/action-scripts)

### まったく新しいメニュー画面を一から作成できますか？
はい、**Custom GUIs** を使って作成できます。
1.  メニューバーで **Customization -> Custom GUIs -> Manage Custom GUIs** に移動します。
2.  **"New GUI"** をクリックし、一意の識別子を付けます。
3.  その後、この新しい空の画面を開いてレイアウトを作成し、好きな要素を追加できます。
4.  この Custom GUI は、ボタンのアクションから開けるようになります。
*   詳細: [Custom GUIs](https://docs.fancymenu.net/en/custom-guis)

### プリロードを有効にした後、ゲームの読み込みにとても時間がかかります。
これは想定された動作です。高解像度のアニメーションやサウンドのような大きなリソースを初回起動時にプリロードすると、当然ゲームの読み込み時間は長くなります。

### FMA アニメーションが RAM を使いすぎます！
従来の FMA ファイルは、高解像度フレームが多いと大量のメモリを消費することがあります。FancyMenu 3.9.0 では AFMA が追加され、より大きく複雑なアニメーションテクスチャに適しています。従来の FMA ファイルでは、アニメーションを短く保ち、フレーム数や解像度を過度に大きくしないでください。アニメーションはフル動画を再生するためではなく、短い装飾ループ向けです。

### FancyMenu は OptiFine と互換性がありますか？
いいえ。OptiFine は**互換性がなく**、FancyMenu を含む多くの mod を壊すことが知られています。Sodium/Embeddium + Iris/Oculus のような最新の代替手段を使うことを強くおすすめします。
*   詳細: [OptiFine Alternatives](https://docs.fancymenu.net/en/optifine-alternatives)

### ゲームがクラッシュします。mod 同士の競合かどうかを確認するにはどうすればいいですか？
mod 競合を確認する最善の方法は、**FancyMenu とその依存関係（Konkrete、Melody）だけでゲームを実行する**ことです。クラッシュしなくなった場合は、他の mod を少しずつ戻しながら、再びクラッシュするまで試すことで競合している mod を特定できます。

### 他の mod のボタンが、編集しようとすると消えたり動作しなくなったりします。
これは通常、その mod が FancyMenu が操作できない非標準的な方法でボタンを追加していることを意味します。これは、その mod の開発者が自分側で修正する必要がある問題です。FancyMenu は「見えない」要素をカスタマイズできません。

### FancyMenu のレイアウトをサーバーで使えますか？
FancyMenu はクライアント側 mod です。すべてのレイアウトとカスタマイズはプレイヤーのクライアント上にあります。サーバーにレイアウトを置いて、プレイヤーに強制的に表示させることはできません。ただし、`config/fancymenu` フォルダを modpack の一部として配布することはできます。サーバーから `/fmvariable` や `/openguiscreen` のようなコマンドを使いたい場合は、FancyMenu（またはその Spigot プラグイン）をサーバーにインストールする必要があります。

### FancyMenu v2（古い MC バージョン向け）と v3 の違いは何ですか？
FancyMenu v3 は完全な再実装で、多くの新機能、より安定したアーキテクチャ、そしてより良いパフォーマンスを備えています。v2 は古く、現在はサポートされておらず、高度なプレースホルダーやスクリプトなど多くの機能が欠けています。現代の Minecraft バージョン（1.18.2 以上）では v3 の使用を強くおすすめします。v2 のレイアウトは読み込み時に自動的に v3 に変換できますが、一部手動で修正が必要な場合があります。

### 既製のレイアウトやテンプレートはどこで見つかりますか？
FancyMenu コミュニティでは、公式 Keksuccino's Mods Discord サーバーの `#layout-templates` チャンネルでレイアウトを共有しています。

### Player Entity を他の要素の背面に表示するにはどうすればいいですか？
できません。Minecraft のエンティティ描画の仕組み上、Player Entity 要素は、レイヤー設定に関係なく、ほとんど常に他の 2D 要素の前面に描画されます。

### Player Entity の脚が 1 本しかありません！何が起きたのですか？
これは表示上の不具合で、プレイヤーのアニメーションやモデルを変更する他の mod との競合が原因である可能性が高いです。Player Entity の Pose 設定を確認して、脚が誤って回転または移動していないか見てください。

### スクリプト内のアクション間に遅延を入れるにはどうすればいいですか？
FancyMenu 3.9.0 では、Action Script に **Delay** と **Execute Later** ブロックが追加されました。多くの遅延処理はそれらを使ってください。繰り返し実行されるバックグラウンド処理には、[Schedulers](https://docs.fancymenu.net/en/schedulers) を使用します。

### Create mod のメニューをカスタマイズできますか？
いいえ。FancyMenu は Create の複雑な GUI と既知の非互換があります。クラッシュを防ぐため、Create の画面に対するカスタマイズは意図的に無効化されています。

### なぜ mod X のボタンがエディターで消えるのですか？
これは、その mod がバニラとは異なる独自の方法でボタンを追加していることを意味します。FancyMenu はこれらの要素を「見たり」操作したりできないため、カスタマイズできません。他の mod の開発者が、互換性のある追加方法に変更する必要があります。

### 背景画像やボタンテクスチャに推奨される解像度はありますか？
背景: 標準的な 1920x1080（1080p）画像は良い出発点で、多くのユーザーに対してよくスケールします。
ボタン: 多くのバニラのボタンは幅 150〜200 ピクセル、高さ 20 ピクセル程度です。カスタムテクスチャでもこのサイズに合わせると、一貫性を保ちやすくなります。

### プレイヤーがゲーム内の目標（クエストなど）を達成したときに、自動でメニューを開いたりコマンドを実行したりできますか？
FancyMenu 単体では、このようなゲーム内イベントを検知できません。ただし、FTB Quests のようなクエスト mod と連携できます。多くのクエスト mod では、報酬としてコマンドを実行できます。報酬に `/openguiscreen` または `/fmvariable` コマンドを実行するよう設定して、メニューを操作します。

### ボタンを無効化、または「グレー表示」にするにはどうすればいいですか？
Loading Requirements を使ってボタンの有効状態を制御できます。
エディターでボタンを右クリックし、「Active State」を選択します。
ボタンを有効にするために満たす必要のある条件を追加します。たとえば、ボタンを恒久的に無効化したい場合は、0 が 1 に等しいかを確認する Is Number 条件を追加できます（これは常に false です）。
これでボタンは "Inactive Background" テクスチャを使用し、クリックできなくなります。

### スクロール可能な画面のヘッダーとフッター（dirt テクスチャのバー）を削除するにはどうすればいいですか？
FancyMenu v3 では、これらをカスタマイズできます。レイアウトエディターでエディターの背景を右クリックし、"Customize Header/Footer" のようなオプションを探してください。テクスチャを完全に透明に設定することで、見た目上は実質的に削除できます。ただし、すべての画面、特に古い画面や大きく改造された画面では動作しない場合があります。

### 「現在の画面用」のレイアウトを作成できません。ボタンがグレーアウトしています。
まず、その画面のカスタマイズを **メニューバー -> Customization -> Current Screen Customizations -> Enabled に切り替える** 必要があります。

### エディターで画面を開いても、その要素を何もカスタマイズできません。空の画面になってしまいます。

これは、うっかり **現在の画面用** ではなく、汎用レイアウトを作成してしまった可能性があります。

また、カスタマイズしている画面がスクロール可能な画面で、FancyMenu が標準ではカスタマイズできない場合もあります。

3 つ目の可能性としては、その画面がバニラではない方法で要素を追加する mod の画面であり、そのため FancyMenu がこれらの要素をカスタマイズできない場合です。

### Text 要素のところに変な灰色の箱があります。

これらの半透明（低不透明度）の箱/長方形は、Text 要素の右端または下端に表示されることがあり、バグではありません。要素がスクロール可能であるため、これは Text 要素のスクロール用つまみです。

これらの箱を表示したくない場合は、要素を右クリックしてスクロールを完全に無効化するか、スクロールは維持したい場合は、同じ右クリックメニューでつまみのテクスチャを完全に透明なものに設定できます。

### 最新の Minecraft の変更履歴をメニューに表示するにはどうすればいいですか？

Minecraft の変更履歴を FancyMenu 互換の Markdown に変換する素晴らしい [GitHub プロジェクト](https://github.com/ClaytonTDM/minecraft-changelogs-markdown) があります。これを使えば、最新の MC の変更履歴をメニューに表示できます。毎日更新され、新しい変更履歴を取得します。

たとえば、Text 要素に最新の Minecraft の変更履歴を表示するには、その **Source Mode** を **Resource** に設定し、リソースソースを **Web** に設定します。そしてソースとして次の URL を使用します: `https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`

### どんな要素でも画面サイズいっぱいに引き伸ばす最も簡単な方法は何ですか？

ほとんどの要素には、右クリックのコンテキストメニューから水平方向と垂直方向に引き伸ばすオプションがあります。これを有効にすると、要素は常に画面の幅および/または高さいっぱいに伸びます。水平方向と垂直方向の引き伸ばしは個別に切り替えられます。

### Text 要素の前後にあるボタンやスライダーをクリックしたり操作したりできません。

これは、Text 要素がデフォルトで操作可能になっているためです（スクロール用つまみをつかんだり Markdown のハイパーリンクをクリックしたりできるようにするため）。そのため、マウスクリックやスクロールイベントを消費します。最善の方法は、そもそもボタンを Text 要素の前後に移動させないことです。どうしても必要なら、**右クリック**して **Interactable** を **Disabled** に設定し、Text 要素を操作不可にできます。ただし、これにより Text 要素は静的な非操作テキストになり、スクロールやハイパーリンクのクリックはできなくなります。

### 矢印キーや Tab キーで画面を移動するときに、ボタンやスライダーが選択/フォーカスされないようにするにはどうすればいいですか？

ボタンやスライダーをナビゲーション対象から外すには、**右クリック**して **Navigable** を **Disabled** に設定する必要があります。ボタン/スライダーは引き続きクリックできますが、Arrow/Tab ナビゲーションでフォーカスできなくなります。

これは、Chat 画面にボタンやスライダーを追加したい場合にも便利です。これにより、誤って画面内のボタン/スライダーを選択することなく、Arrow Up キーで古いメッセージをスクロールできます。

### FancyMenu のコンテキストメニューに、本来あるはずのオプションがありません。

FancyMenu のコンテキストメニュー（何かを右クリックしたときやメニューバーを操作したときに開くメニュー）は**スクロール可能**です。つまり、マウスカーソルをメニュー上に置いた状態でマウスホイールを使うと上下にスクロールでき、これまで見えていなかった他のオプションを表示できます。
