# よくある質問

### 問題についてサポートが必要です。どのような情報を提供すればよいですか？

適切なサポートを受けるため、できるだけ多くの情報を提供してください：
1.  **問題の明確な説明：** 何が起こると思っていたのか、実際には何が起こったのかを説明してください。
2.  **`latest.log` ファイル：** `<game-directory>/logs/latest.log` にあります。特に要求されない限り、**クラッシュログは送信しないでください**。通常、必要な情報は `latest.log` に含まれています。投稿には https://gist.github.com のようなサイトを利用してください。
3.  **Minecraftのバージョン：**（例：1.20.1）
4.  **Modローダーとそのバージョン：**（例：Forge 47.2.0、Fabric 0.15.7）
5.  **FancyMenuのバージョン：**（例：3.5.2）
6.  問題の**スクリーンショットや動画**も非常に役立ちます。

### 要素の重なり順を変更するにはどうすればよいですか？（要素を別の要素の前後に移動する方法）

*   **カスタム要素同士の場合：** **ウィンドウ -> エディターウィジェット -> レイヤー**を開き、階層内で要素をドラッグしてください。要素を右クリックして、**1レイヤー上へ移動／1レイヤー下へ移動**を使用することもできます。[レイヤーとグループ](./layers-and-groups)を参照してください。
*   **カスタム要素とバニラ要素の場合：** すべてのカスタム要素をすべてのバニラ要素の後ろに描画するには（たとえば、デフォルトのボタンの後ろに背景画像を配置する場合）、**エディターの背景を右クリック**し、**「カスタム要素をバニラ要素の後ろに描画」**を切り替えてください。

### ユニバーサルボタンテンプレートから特定のボタンを除外できますか？

**いいえ。テンプレートボタンにカスタムテクスチャが設定されている場合、それらのテクスチャは影響を受けるすべての要素で常に共有されます。個々のボタンを除外することはできません。**

### ボタンをクリックしたときに何かを実行させるにはどうすればよいですか？

[**アクションスクリプト**](./action-scripts)を使用してください。
1.  エディターでボタンを右クリックします。
2.  **アクションスクリプトを編集**を選択します。
3. **アクションを追加**をクリックし、[**画面またはカスタムGUIを開く**](./action-scripts#open-screen-or-custom-gui-opengui)、[**サーバーに参加**](./action-scripts#join-server-joinserver)、[**変数の値を設定**](./action-scripts#set-variable-value-fm-variable-set_variable)などのアクションを選択します。

### 完全に新しいメニュースクリーンを最初から作成できますか？

[**カスタムGUI**](./custom-guis)を使用してください。
1.  メニューバーで**カスタマイズ -> カスタムGUI -> カスタムGUIを管理**を開きます。
2.  **「新しいGUI」**をクリックし、一意の識別子を付けます。
3.  その後、この新しい空の画面を開いてレイアウトを作成し、好きな要素を追加できます。
4. [**画面またはカスタムGUIを開く**アクション](./action-scripts#open-screen-or-custom-gui-opengui)でカスタムGUIを開きます。

### プリロードを有効にした後、ゲームの読み込みに時間がかかります。

これは想定された動作です。高解像度のアニメーションやサウンドなど、大きなリソースを初回起動時にプリロードすると、ゲームの読み込み時間は自然に長くなります。

### FMAアニメーションがRAMを使いすぎます！

クラシックな[FMAアニメーション](./fma)に高解像度のフレームが多数含まれている場合、メモリを大量に消費することがあります。大規模または複雑なアニメーションテクスチャにはAFMAの方が適しています。クラシックFMAアニメーションは短く保ち、動画全体を再生する場合は[動画](./video)を使用してください。

### FancyMenuはOptiFineに対応していますか？

いいえ。OptiFineは**互換性がなく**、FancyMenuを含む多くのModを壊すことが知られています。Sodium/Embeddium + Iris/Oculusのような最新の代替Modを使用することを強くおすすめします。
[OptiFineの代替](./optifine-alternatives)も参照してください。

### ゲームがクラッシュします。Modの競合かどうかを確認するにはどうすればよいですか？

Modの競合を確認する最善の方法は、**FancyMenuとその依存関係（Konkrete、Melody）だけを有効にしてゲームを起動する**ことです。クラッシュが発生しなくなった場合は、他のModを少数ずつ追加し、再びクラッシュするまで確認することで、競合しているModを特定できます。

### 他のModのボタンが消えたり、編集しようとしても動作しなかったりします。

一部のModは、FancyMenuが検出またはカスタマイズできない方法でウィジェットを追加します。[バニラ／Mod要素](./vanilla-elements)と、リストベースの画面については[スクロール可能な画面のカスタマイズ](./customizing-scrollable-screens)を確認してください。それでもウィジェットが表示されない場合、そのウィジェットを追加しているModが、対応している画面ウィジェットとして公開する必要があります。

### FancyMenuのレイアウトをサーバーで使用できますか？

レイアウトと見た目のカスタマイズはプレイヤーのクライアントに保存されるため、サーバーから未設定のクライアントに強制適用することはできません。Modパックの一部として配布してください。[サーバーコマンド](./commands)、[FMデータ](./fm-data)、[サーバー側のNBTアクセス](./nbt-data-placeholder#server-side-placeholder)、ゲームルール、ストラクチャー、サーバーリスナーが必要な場合は、サーバーにFancyMenuをインストールしてください。

### 古いMinecraftバージョン向けのFancyMenu v2とv3の違いは何ですか？

FancyMenu v3は完全な書き直しで、多くの新機能、より安定したアーキテクチャ、優れたパフォーマンスを備えています。v2は古く、サポートが終了しており、高度なプレースホルダーやスクリプトなど多くの機能がありません。最新のMinecraftバージョン（1.18.2以降）ではv3を使用することを強くおすすめします。v2のレイアウトは読み込み時に自動的にv3へ変換できますが、一部は手動で修正が必要になる場合があります。

### 作成済みのレイアウトやテンプレートはどこで入手できますか？

FancyMenuコミュニティでは、公式Keksuccino's Mods Discordサーバー（「Kekscord」）の[`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316)チャンネルでレイアウトを共有しています。

### プレイヤーエンティティを他の要素の後ろに描画するにはどうすればよいですか？

通常、[レイヤーウィジェット](./layers-and-groups)を使って、[プレイヤーエンティティ要素](./elements#player-entity)を通常の2D要素の後ろに強制配置することはできません。プレイヤーエンティティの描画処理が、通常のGUIレイヤー順を無視する場合があるためです。この制限を考慮してレイアウトを設計するか、厳密なレイヤー順が必要な場合は事前に描画した画像を使用してください。

### プレイヤーエンティティの脚が1本しかありません！どうなったのですか？

これは視覚的な不具合で、プレイヤーのアニメーションやモデルを変更する別のModとの競合が原因である可能性が高いです。プレイヤーエンティティのポーズ設定を確認し、脚が誤って回転または移動されていないか確認してください。

### スクリプト内のアクション間に遅延を作成するにはどうすればよいですか？

遅延アクションの処理には、[**遅延**または**後で実行**ブロック](./action-scripts#what-are-statements)を使用してください。繰り返し実行するバックグラウンド処理には、[スケジューラー](./schedulers)を使用します。

### Create Modのメニューをカスタマイズできますか？

いいえ。Createの画面では意図的にカスタマイズが無効化されています。[カスタマイズが意図的に無効化されている画面](./incompatibility-list#screens-where-customization-is-intentionally-disabled)を参照してください。

### 背景画像とボタンテクスチャには、どの解像度が推奨されますか？

背景：標準的な1920x1080（1080p）画像から始めるのがよく、ほとんどのユーザーに対して適切に拡大縮小されます。
ボタン：バニラのボタンの多くは幅150～200ピクセル、高さ20ピクセル程度です。一貫性を保つため、カスタムテクスチャもこのサイズに合わせるとよいでしょう。

### プレイヤーがゲーム内の目標（クエストなど）を達成したときに、メニューを自動的に開いたりコマンドを実行したりする方法はありますか？

FancyMenuには多くの[組み込みゲームイベントリスナー](./listeners)がありますが、すべてのサードパーティ製クエストシステムに対応する汎用リスナーはありません。クエストModがコマンド報酬に対応している場合は、それを使って[`/openguiscreen`](./commands#openguiscreen)、[`/fmvariable`](./commands#fmvariable)、またはその他の適切な[FancyMenuコマンド](./commands)を実行してください。

### ボタンを無効化、または「グレー表示」にするにはどうすればよいですか？

[読み込み要件](./conditions)を使ってボタンの有効状態を制御できます。
エディターでボタンを右クリックし、**有効状態を制御**を選択します。
ボタンを有効にするために満たす必要がある要件を追加してください。恒久的に無効化するには、[**数値判定**](./conditions#is-number-fancymenu_visibility_requirement_is_number)を使い、0と1が等しいかどうかを確認します。
これでボタンは「無効時の背景」テクスチャを使用し、クリックできなくなります。

### スクロール可能な画面からヘッダーとフッター（土のテクスチャのバー）を削除するにはどうすればよいですか？

レイアウトエディターで、**レイアウトプロパティ -> ヘッダー／フッターのカスタマイズ**を開きます。テクスチャを透明に設定してください。このオプションは、一部のMod製画面では利用できない場合があります。

### 「現在の画面用」のレイアウトを作成できません。ボタンがグレー表示されています。

まず、**メニューバー -> カスタマイズ -> 現在の画面のカスタマイズ -> 有効**から、その画面のカスタマイズを有効にする必要があります。

### エディターで画面を開いても要素をカスタマイズできません。空の画面になっています。

[ユニバーサルレイアウト](./universal-layouts)を、「**現在の画面用**」のレイアウトではなく作成した可能性があります。

また、[スクロール可能な画面](./customizing-scrollable-screens)である可能性もあります。FancyMenuでは、デフォルトでスクロール可能な画面をカスタマイズできません。

3つ目の可能性として、バニラとは異なる方法で要素を追加するModの画面であることが考えられます。この場合、FancyMenuはそれらの要素をカスタマイズできません。

### テキスト要素に奇妙な灰色のボックスがあります。

これらの半透明のボックスは、[テキスト要素](./elements#text)のスクロールつまみであり、描画バグではありません。

ボックスを表示したくない場合は、要素を右クリックしてスクロール自体を無効にするか、要素をスクロール可能なままにしたい場合は、同じ右クリックメニューでつまみのテクスチャを完全に透明なものに設定できます。

### 最新のMinecraftの変更履歴をメニューに表示するにはどうすればよいですか？

Minecraftの変更履歴をFancyMenu対応のMarkdownに変換してくれる優れた[GitHubプロジェクト](https://github.com/ClaytonTDM/minecraft-changelogs-markdown)があります。これを使えば、最新のMinecraft変更履歴をメニューに表示できます。新しい変更履歴を取得するため、毎日更新されます。

[テキスト要素](./elements#text)に表示するには、**ソースモード**を**リソース**に設定し、リソースソースを**Web**にします。`https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`を使用してください。

### 要素を画面いっぱいのサイズに引き伸ばす最も簡単な方法は何ですか？

多くの要素には、右クリックのコンテキストメニューに水平方向および垂直方向に引き伸ばすオプションがあります。これを有効にすると、要素は常に画面の幅や高さいっぱいに引き伸ばされます。水平方向と垂直方向の引き伸ばしは、それぞれ個別に切り替えられます。

### テキスト要素の後ろや前にあるボタンをクリックしたり、スライダーを操作したりできません。

テキスト要素は、スクロールつまみをつかんだりMarkdownのハイパーリンクをクリックしたりできるよう、デフォルトで操作可能になっています。そのため、マウスクリックやスクロールイベントを消費します。最善の方法は、ボタンをテキスト要素の前後に移動しないことです。しかし避けられない場合は、テキスト要素を**右クリック**し、**操作可能**を**無効**に設定することで、操作できないようにできます。ただし、テキスト要素は静的で操作できないテキストになり、スクロールやハイパーリンクのクリックができなくなる点に注意してください。

### 画面内を矢印キーやTabキーで移動するときに、ボタンやスライダーが選択・フォーカスされないようにするにはどうすればよいですか？

ボタンやスライダーを移動対象から外すには、対象を**右クリック**し、**ナビゲーション可能**を**無効**に設定します。ボタンやスライダーは引き続きクリックできますが、矢印キーやTabキーによる移動でフォーカスできなくなります。

これは、チャット画面にボタンやスライダーを追加したい場合にも便利です。画面上のボタンやスライダーを誤って選択せず、上矢印キーで古いメッセージをスクロールできるようになります。

### FancyMenuのコンテキストメニューに、本来あるはずのオプションがありません。

FancyMenuのコンテキストメニュー（どこかを右クリックしたとき、またはメニューバーを操作したときに開くメニュー）は**スクロール可能**です。マウスカーソルをメニュー上に置いてスクロールホイールを使うと、上下にスクロールでき、これまで表示されていなかった追加のオプションを確認できます。

### タイトル画面をカスタマイズできません。エディターを閉じると元の画面が表示されます。

別のModが元の `title_screen` を置き換えています。そのModの設定でカスタムタイトル画面を無効にしてください。そのようなオプションがない場合、FancyMenuは置き換え後の画面にレイアウトを適用できません。

### インベントリ画面をカスタマイズしようとしても、インベントリのコンテナをカスタマイズできません。

これは仕様です。FancyMenuは、あらゆる種類のインベントリ画面（プレイヤーインベントリ、チェスト、作業台など）の実際のコンテナを編集できません。これらへの対応は非常に困難なためです。

ただし、これらの画面に新しい要素を追加することはできます。コンテナ自体を編集することはできません。

なお、SpiffyHUDもこの問題の解決にはなりません。SpiffyHUDはHUD（たとえばアイテムホットバー）を編集するためのものであり、インベントリ画面のような画面を編集することはできないためです。
