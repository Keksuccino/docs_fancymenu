# FAQ

### 問題の解決を手伝ってほしいです。どんな情報を提供すればよいですか？

よりよいサポートを受けるには、できるだけ詳しい情報を提供してください。
1.  **問題の明確な説明:** 何を期待していて、実際には何が起きましたか？
2.  **`latest.log` ファイル:** `<game-directory>/logs/latest.log` にあります。**クラッシュログは送らないでください。** 特に求められた場合を除き、通常は `latest.log` に必要な情報が含まれています。投稿する際は https://gist.github.com などのサイトを使ってください。
3.  **Minecraft のバージョン:**（例: 1.20.1）
4.  **Mod ローダーとそのバージョン:**（例: Forge 47.2.0、Fabric 0.15.7）
5.  **FancyMenu のバージョン:**（例: 3.5.2）
6.  **問題のスクリーンショットや動画** も非常に役立ちます。

### 要素の重なり順を変更するにはどうすればいいですか？（何かを前面／背面に移動する）

*   **カスタム vs. カスタム:** **Window -> Editor Widgets -> Layers** を開き、階層内で要素をドラッグしてください。要素を右クリックして **Move One Layer Up/Down** を使うこともできます。[Layers and Groups](./layers-and-groups) を参照してください。
*   **カスタム vs. Vanilla:** すべてのカスタム要素をすべての Vanilla 要素の背面に描画したい場合（たとえば、背景画像を標準のボタンの背面に置きたい場合）は、**エディタの背景を右クリック**して **"Render Custom Elements Behind Vanilla"** オプションを切り替えてください。

### 汎用ボタンテンプレートから特定のボタンだけを除外できますか？

**いいえ。テンプレートボタンにカスタムテクスチャが設定されている場合、そのテクスチャは常に影響を受けるすべての要素で共有されます。個別のボタンを除外することはできません。**

### ボタンをクリックしたときに何か動作するようにするにはどうすればいいですか？

[**Action Script**](./action-scripts) を使います。
1.  エディタでボタンを右クリックします。
2.  **Edit Action Script** を選びます。
3. **Add Action** をクリックし、[**Open Screen or Custom GUI**](./action-scripts#open-screen-or-custom-gui-opengui)、[**Join Server**](./action-scripts#join-server-joinserver)、[**Set Variable Value**](./action-scripts#set-variable-value-fm-variable-set_variable) などのアクションを選びます。

### まったく新しいメニュー画面を一から作れますか？

[**Custom GUI**](./custom-guis) を使います。
1.  メニューバーで **Customization -> Custom GUIs -> Manage Custom GUIs** に移動します。
2.  **"New GUI"** をクリックし、一意の識別子を付けます。
3.  その後、この新しい空の画面を開いて、好きな要素を追加しながらレイアウトを作成できます。
4. [**Open Screen or Custom GUI** アクション](./action-scripts#open-screen-or-custom-gui-opengui) で Custom GUI を開きます。

### プリロードを有効にした後、ゲームの読み込みに時間がかかります。

これは想定された動作です。高解像度のアニメーションや音声などの大きなリソースを初期起動時にプリロードすると、当然ながら読み込み時間は長くなります。

### FMA アニメーションが RAM を使いすぎます！

従来の [FMA アニメーション](./fma) は、高解像度のフレームを多く含むとかなりのメモリを消費することがあります。AFMA は、より大きく複雑なアニメーションテクスチャに向いています。従来の FMA アニメーションは短めにし、フル動画の再生には [Video](./video) を使ってください。

### FancyMenu は OptiFine と互換性がありますか？

いいえ。OptiFine は **互換性がなく**、FancyMenu を含む多くの Mod を壊すことが知られています。Sodium/Embeddium + Iris/Oculus のような現代的な代替手段を使うことを強くおすすめします。
[OptiFine Alternatives](./optifine-alternatives) を参照してください。

### ゲームがクラッシュします。Mod の競合かどうかはどうやって調べればいいですか？

Mod の競合を確認する最善の方法は、**FancyMenu とその依存関係（Konkrete、Melody）だけでゲームを起動すること**です。クラッシュが発生しなくなった場合は、他の Mod を少しずつ追加し、再びクラッシュするまで確認して、競合している Mod を特定できます。

### 他の Mod のボタンが消えたり、編集しようとすると動かなくなったりします。

一部の Mod は、FancyMenu が検出またはカスタマイズできない方法でウィジェットを追加します。[Vanilla/Mod Elements](./vanilla-elements) を確認し、リスト型の画面については [Customizing Scrollable Screens](./customizing-scrollable-screens) も確認してください。ウィジェットがそれでも表示されない場合、そのウィジェットを追加する Mod 側が、対応済みの画面ウィジェットとして公開している必要があります。

### FancyMenu のレイアウトをサーバーで使えますか？

レイアウトや見た目のカスタマイズはプレイヤーのクライアント側に保存されるため、サーバーが未設定のクライアントに強制することはできません。これらは Modpack の一部として配布してください。`[server commands](./commands)`、`[FM Data](./fm-data)`、`[server-side NBT access](./nbt-data-placeholder#server-side-placeholder)`、gamerules、structures、または server listeners が必要な場合は、サーバーにも FancyMenu をインストールしてください。

### FancyMenu v2（古い MC バージョン向け）と v3 の違いは何ですか？

FancyMenu v3 は全面的に書き直されたもので、多くの新機能、より安定したアーキテクチャ、そしてより高いパフォーマンスを備えています。v2 は古く、現在はサポートされておらず、高度なプレースホルダーやスクリプトなど多くの機能が不足しています。現代の Minecraft バージョン（1.18.2 以降）では v3 の使用を強くおすすめします。v2 のレイアウトは読み込む際に自動的に v3 に変換できますが、一部は手動で修正が必要な場合があります。

### 事前に用意されたレイアウトやテンプレートはどこで見つかりますか？

FancyMenu コミュニティは、公式の Keksuccino's Mods Discord サーバー（"Kekscord"）の `#layout-templates` チャンネルでレイアウトを共有しています。

### Player Entity を他の要素の背面に描画するにはどうすればよいですか？

通常、[Layers ウィジェット](./layers-and-groups) で [Player Entity element](./elements#player-entity) を通常の 2D 要素の背面に強制することはできません。そのレンダラーは通常の GUI の重なり順を無視する場合があります。この制限を前提にレイアウトを設計するか、厳密な重なり順が必要な場合は事前描画した画像を使用してください。

### Player Entity の脚が 1 本しかありません！ 何が起きたのですか？

これは表示上の不具合で、プレイヤーのアニメーションやモデルを変更する別の Mod との競合が原因である可能性が高いです。Player Entity の Pose 設定を確認して、脚が誤って回転または移動していないか見てください。

### スクリプト内のアクション間に遅延を入れるにはどうすればよいですか？

遅延を伴う処理には、[**Delay** または **Execute Later** ブロック](./action-scripts#what-are-statements) を使ってください。繰り返し実行されるバックグラウンド処理には、[Schedulers](./schedulers) を使います。

### Create Mod のメニューをカスタマイズできますか？

いいえ。Create の画面は意図的にカスタマイズが無効になっています。[カスタマイズが意図的に無効化されている画面](./incompatibility-list#screens-where-customization-is-intentionally-disabled) を参照してください。

### 背景画像やボタンテクスチャに推奨される解像度はありますか？

背景: 標準的な 1920x1080（1080p）の画像は非常によい出発点で、多くのユーザーに対して適切に拡大縮小されます。
ボタン: ほとんどの標準ボタンは幅 150〜200 ピクセル、高さ 20 ピクセル程度です。カスタムテクスチャでもこのサイズに合わせると、一貫性の面で良いでしょう。

### プレイヤーがゲーム内の目標（クエストなど）を達成したときに、自動でメニューを開いたりコマンドを実行したりできますか？
FancyMenu には多くの [組み込みのゲームイベントリスナー](./listeners) がありますが、サードパーティのクエストシステムすべてに対応する汎用リスナーはありません。クエスト Mod がコマンド報酬をサポートしている場合は、それを使って [`/openguiscreen`](./commands#openguiscreen)、[`/fmvariable`](./commands#fmvariable)、または適切な他の [FancyMenu コマンド](./commands) を実行してください。

### ボタンを無効化したり「グレー表示」にしたりするにはどうすればよいですか？

[Loading Requirements](./conditions) を使って、ボタンの有効状態を制御できます。
エディタでボタンを右クリックし、**Control Active State** を選択します。
ボタンを有効にするために満たす必要のある条件を追加してください。恒久的に無効にするには、[**Is Number**](./conditions#is-number-fancymenu_visibility_requirement_is_number) を使って 0 と 1 が等しいかを確認します。
これでボタンは "Inactive Background" テクスチャを使い、クリックできなくなります。

### スクロール可能な画面のヘッダーとフッター（dirt テクスチャの帯）を消すにはどうすればよいですか？

レイアウトエディタで **Layout Properties -> Header/Footer Customizations** を開きます。テクスチャを透明に設定してください。このオプションは一部の Mod 画面では利用できない場合があります。

### 「現在の画面用」のレイアウトを作成できません。ボタンがグレーアウトしています。

まず、その画面のカスタマイズを **メニューバー -> Customization -> Current Screen Customizations -> Enabled** で有効にする必要があります。

### エディタで画面を開いても、その画面の要素をカスタマイズできません。空の画面が表示されるだけです。

これは、**現在の画面用** ではなく [Universal Layout](./universal-layouts) を作成してしまった可能性があります。

または、その画面が [スクロール可能な画面](./customizing-scrollable-screens) で、FancyMenu が既定ではカスタマイズできない可能性もあります。

3 つ目の可能性として、Vanilla とは異なる方法で要素を追加する Mod の画面であり、そのため FancyMenu がそれらの要素をカスタマイズできない場合があります。

### Text 要素のところに変な灰色の箱が表示されます。

この半透明の箱は、[Text element](./elements#text) のスクロールグラバーであり、描画バグではありません。

これらの箱を表示したくない場合は、要素を右クリックしてスクロールを完全に無効にするか、スクロール可能なままにしたい場合は同じ右クリックメニューでグラバーテクスチャを完全に透明なものに設定してください。

### 最新の Minecraft の変更ログをメニューに表示するにはどうすればよいですか？

Minecraft の変更ログを FancyMenu 互換の Markdown に変換する素晴らしい [GitHub プロジェクト](https://github.com/ClaytonTDM/minecraft-changelogs-markdown) があります。これを使えば、最新の MC 変更ログをメニューに表示できます。新しい変更ログを取得するため、毎日更新されます。

[Text element](./elements#text) に表示するには、**Source Mode** を **Resource** に設定し、リソースソースを **Web** にします。`https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md` を使用してください。

### どの要素でも、画面いっぱいのサイズに簡単に引き伸ばすにはどうすればよいですか？

ほとんどの要素には、右クリックのコンテキストメニューで水平方向と垂直方向に引き伸ばすオプションがあります。これを有効にすると、常に画面の幅や高さいっぱいまで伸びるようになります。水平方向と垂直方向の伸縮は個別に切り替えられます。

### Text 要素の背後や前面にあるボタンやスライダーをクリックしたり操作したりできません。

これは、Text 要素がデフォルトで操作可能であり（スクロールグラバーをつかんだり、Markdown のハイパーリンクをクリックしたりできるようにするため）、マウスクリックやスクロールイベントを消費してしまうためです。最善の方法はボタンを Text 要素の前面／背面に移動しないことですが、それが避けられない場合は、**右クリック**して **Interactable** を **Disabled** に設定することで、Text 要素を操作不可にできます。ただし、これにより Text 要素は静的な、操作できないテキストになり、スクロールやハイパーリンクのクリックはできなくなります。

### 矢印キーや Tab キーで画面を移動するときに、ボタンやスライダーが選択／フォーカスされないようにするにはどうすればよいですか？

ボタンやスライダーを移動可能にしないには、**右クリック**して **Navigable** を **Disabled** に設定する必要があります。ボタン／スライダーは引き続きクリックできますが、矢印キーや Tab による移動ではフォーカスできなくなります。

これは、チャット画面にボタン／スライダーを追加したい場合にも便利です。そうすれば、スクリーン上のボタン／スライダーを誤って選択することなく、上矢印キーで過去のメッセージをスクロールできます。

### FancyMenu のコンテキストメニューに、本来あるはずの項目がありません。

FancyMenu のコンテキストメニュー（どこかを右クリックしたときやメニューバーを操作したときに開くメニュー）は、**スクロール可能**です。つまり、メニューの上にマウスカーソルを置いたままマウスホイールを使って上下にスクロールでき、これまで見えなかった他の項目も表示できます。

### Title 画面をカスタマイズできません。エディタを離れると元の画面に戻ってしまいます。

別の Mod が元の `title_screen` を置き換えています。その Mod の設定でカスタム Title 画面を無効にしてください。そのような設定がない場合、FancyMenu は置き換えられた画面にレイアウトを適用できません。
