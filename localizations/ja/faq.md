# よくある質問

### 問題が発生しました。どのような情報を提供すればよいですか？

適切なサポートを受けるため、できるだけ多くの情報をお知らせください。
1.  **問題の明確な説明：** 何が起きると予想していて、実際には何が起きましたか？
2.  **`latest.log` ファイル：** `<game-directory>/logs/latest.log` にあります。**特に依頼されない限り、クラッシュログは送らないでください。** 通常、必要な情報は `latest.log` に含まれています。投稿には https://gist.github.com などのサイトを利用してください。
3.  **Minecraft のバージョン：**（例：1.20.1）
4.  **Mod ローダーとそのバージョン：**（例：Forge 47.2.0、Fabric 0.15.7）
5.  **FancyMenu のバージョン：**（例：3.5.2）
6.  **問題のスクリーンショットや動画**も大いに役立ちます。

> [!TIP]
> Alice やほかの AI に助けを求めていますか？うまく動かないものの [AI 用エクスポート](/export-for-ai) を追加してください。設定内容を AI に正確に伝えられ、Minecraft、Mod ローダー、FancyMenu のバージョンも含まれています。

### 要素の重なり順を変えるにはどうすればよいですか？（別の要素の前面または背面に移動する）

- **自分で追加した要素：** レイアウトエディターのレイヤーウィジェットでレイヤーをドラッグするか、要素を右クリックして **レイヤーを 1 つ上へ移動** または **レイヤーを 1 つ下へ移動** をクリックします。[レイヤーとグループ](/layout-editor#layers-and-groups)を参照してください。
- **自分で追加した要素とバニラ要素：** バニラ要素の順序は変更できません。背景画像をデフォルトのボタンの背後に置くなど、すべての要素をバニラ要素の背面に配置するには、エディターの背景を右クリックし、**カスタム要素をバニラ要素の背面に表示** を **有効** に設定します。

### ユニバーサルボタンテンプレートから特定のボタンを除外できますか？

**いいえ。テンプレートのボタンにカスタムテクスチャが設定されている場合、そのテクスチャは常に対象となるすべての要素で共有されます。個々のボタンを除外することはできません。**

### ボタンをクリックしたときに何かを実行させるにはどうすればよいですか？

[**アクションスクリプト**](/action-scripts)を使います。
1.  エディターでボタンを右クリックします。
2.  **アクションスクリプトを編集** を選択します。
3. **アクションを追加** をクリックし、[**画面またはカスタム GUI を開く**](/action-scripts#open-screen-or-custom-gui)、[**サーバーに参加**](/action-scripts#join-server)、[**変数の値を設定**](/action-scripts#set-variable-value-fm-variable)などのアクションを選択します。

### 一からまったく新しいメニュー画面を作成できますか？

はい。[カスタム GUI](/custom-guis)を使います。

1. **メニューバー -> カスタマイズ -> カスタム GUI -> カスタム GUI を管理** を開き、**新しい GUI** をクリックします。
2. `modpack_info` のような識別子を入力し、**完了** をクリックします。
3. **GUI を開く** で開き、ほかのメニューと同じようにレイアウトを作成します。
4. ボタンから [**画面またはカスタム GUI を開く**](/action-scripts#open-screen-or-custom-gui) アクションとその識別子を指定して開きます。

### プリロードを有効にしたら、ゲームの読み込みに時間がかかるようになりました。

これは想定された動作です。高解像度のアニメーションや音声など、大きなリソースを起動時にプリロードすると、ゲームの読み込み時間は自然と長くなります。

### アニメーションが大量の RAM を使う、またはゲームが重くなります！

フレームのサイズが大きいことやフレームレートが高いことは、メモリとパフォーマンスに影響します。フレームは画面上に表示されるサイズに合わせ、1 秒あたりのフレーム数を減らしてください。[アニメーション](/animations#performance)を参照してください。音声付きの長いクリップには、代わりに[動画](/video)を使ってください。

### FancyMenu は OptiFine と一緒に使えますか？

いいえ。OptiFine は**互換性がなく**、FancyMenu を含む多くの Mod で問題を起こすことが知られています。Sodium/Embeddium + Iris/Oculus など、最新の代替 Mod を使用することを強くおすすめします。
[OptiFine の代替 Mod](/optifine-alternatives)を参照してください。

### ゲームがクラッシュします。Mod の競合かどうかを調べるにはどうすればよいですか？

Mod の競合を調べる最善の方法は、**FancyMenu とその依存 Mod（Konkrete、Melody）だけを入れてゲームを起動する**ことです。クラッシュしなくなった場合は、ほかの Mod を少しずつ追加し、再びクラッシュするまで試すことで、競合している Mod を特定できます。

### ほかの Mod のボタンが消えたり、編集しようとしても動作しなかったりします。

FancyMenu が検出やカスタマイズに対応できない方法でウィジェットを追加する Mod もあります。[バニラ／Mod 要素](/vanilla-elements)と、リスト形式の画面については[スクロール可能な画面のカスタマイズ](/customizing-scrollable-screens)を確認してください。それでもウィジェットが表示されない場合は、その Mod がウィジェットを対応済みの画面ウィジェットとして公開する必要があります。

### サーバーで FancyMenu のレイアウトを使えますか？

レイアウトや見た目のカスタマイズはプレイヤー側のクライアントに保存されるため、サーバーから設定されていないクライアントに適用することはできません。Mod パックの一部として配布してください。[サーバーコマンド](/commands)、[FM データ](/fm-data)、[サーバー側の NBT アクセス](/nbt-data-placeholder#server-side-placeholder)、ゲームルール、構造物、サーバーリスナーを使う場合は、サーバーにも FancyMenu をインストールしてください。

### 古い MC バージョン向けの FancyMenu v2 と v3 の違いは何ですか？

FancyMenu v3 は全面的に書き直されており、多くの新機能、より安定したアーキテクチャ、より優れたパフォーマンスを備えています。v2 は古く、サポートが終了しており、高度なプレースホルダーやスクリプトなど多くの機能がありません。最新の Minecraft バージョン（1.18.2 以降）では v3 の使用を強くおすすめします。v2 のレイアウトは読み込み時に v3 へ自動変換できますが、手動での修正が必要になる場合があります。

### 既成のレイアウトやテンプレートはどこで見つかりますか？

FancyMenu コミュニティでは、公式 Discord サーバー（「Kekscord」）の [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) チャンネルで、完成済みの設定を共有しています。専用のプロファイルとしてインストールしてください。[レイアウトテンプレート](/profiles#layout-templates)を参照してください。

### プレイヤーエンティティをほかの要素の背面に表示するにはどうすればよいですか？

通常、[レイヤーウィジェット](/layout-editor#layers-and-groups)を使って[プレイヤーエンティティ要素](/elements#player-entity)を通常の 2D 要素の背面に配置することはできません。レンダラーが通常の GUI レイヤー順を無視する場合があるためです。この制限を前提にレイアウトを設計するか、レイヤー順を厳密に制御する必要がある場合は、あらかじめレンダリングした画像を使ってください。

### プレイヤーエンティティの脚が片方しかありません！何が起きたのでしょうか？

これは視覚的な不具合で、プレイヤーのアニメーションやモデルを変更する別の Mod との競合が原因と思われます。脚が誤って回転または移動されていないか、プレイヤーエンティティのポーズ設定を確認してください。

### スクリプトのアクションの間に待ち時間を入れるにはどうすればよいですか？

アクションスクリプトエディターのスクリプト領域を右クリックし、**EXECUTE LATER ブロックを追加** をクリックして、待機させたいアクションをブロック内に入れます。ブロック内のアクションは指定したミリ秒数の経過後に 1 回実行され、スクリプトの残りの部分はその間もすぐに実行されます。[後で実行](/action-scripts#execute-later)を参照してください。

繰り返し実行したい処理には、[スケジューラー](/schedulers)を使ってください。

### Create mod のメニューをカスタマイズできますか？

いいえ。Create の画面は意図的にカスタマイズできないようになっています。[カスタマイズが意図的に無効化されている画面](/incompatibility-list#screens-where-customization-is-intentionally-disabled)を参照してください。

### 背景画像やボタンテクスチャにおすすめの解像度はありますか？

背景：標準的な 1920x1080（1080p）の画像から始めるのがおすすめです。ほとんどのユーザーの環境で適切に拡大縮小されます。
ボタン：バニラのボタンの多くは幅が約 150～200 ピクセル、高さが 20 ピクセルです。統一感を出すため、カスタムテクスチャもこのサイズに合わせるとよいでしょう。

### プレイヤーがゲーム内の目標（クエストなど）を達成したときに、メニューを自動で開いたりコマンドを実行したりできますか？

FancyMenu には多くの[組み込みゲームイベントリスナー](/listeners)がありますが、あらゆるサードパーティ製クエストシステムに対応する汎用リスナーはありません。クエスト Mod がコマンド報酬に対応している場合は、それを使って [`/openguiscreen`](/commands#openguiscreen)、[`/fmvariable`](/commands#fmvariable)、または用途に合ったほかの[FancyMenu コマンド](/commands)を実行してください。

### ボタンを無効化したり、グレーアウトしたりするにはどうすればよいですか？

[条件](/conditions)を使ってボタンの有効状態を制御できます。
エディターでボタンを右クリックし、**有効状態を制御** を選択します。
ボタンを有効にするために満たす必要がある条件を追加します。永久に無効にするには、[**数値かどうか**](/conditions#is-number)を使い、0 が 1 と等しいかどうかを確認してください。
これでボタンには「非アクティブ背景」テクスチャが使われ、クリックできなくなります。

### スクロール可能な画面のヘッダーとフッター（泥のテクスチャのバー）を取り除くにはどうすればよいですか？

レイアウトエディターで **レイアウトのプロパティ -> ヘッダー／フッターのカスタマイズ** を開き、テクスチャを透明に設定します。このオプションは一部の Mod 画面では利用できない場合があります。

### 「現在の画面用」のレイアウトを作成できません。ボタンがグレーアウトしています。

まず、その画面のカスタマイズを有効にしてください。**メニューバー -> カスタマイズ -> 現在の画面のカスタマイズ** をクリックし、**有効** と表示されるようにします。

### エディターで画面を開くと、要素をカスタマイズできません。画面が空のままです。

[ユニバーサルレイアウト](/universal-layouts)を作成しており、「現在の画面用」のレイアウトではない可能性があります。

また、[スクロール可能な画面](/customizing-scrollable-screens)の可能性もあります。FancyMenu はデフォルトではスクロール可能な画面をカスタマイズできません。

3 つ目の可能性として、バニラとは異なる方法で要素を追加する Mod の画面であるため、FancyMenu がその要素をカスタマイズできないことが考えられます。

### テキスト要素に奇妙な灰色のボックスが表示されます。

これは[テキスト要素](/elements#text)のスクロールバーです。テキストが要素の中に収まらないと表示され、プレイヤーがスクロールできるようになります。

- 要素を大きくするか、テキストを短くすると表示されなくなります。
- 要素を右クリックして **スクロールバー** を開きます。**表示** では表示方法を設定できます。**常に表示**、**スクロール中のみ**、**表示しない**から選択してください。**表示しない**にしても、マウスホイールでスクロールできます。
- 同じメニューの **スクロールつまみのスタイル**、**スクロールつまみのテクスチャ**、**スクロールつまみの色 [HEX]** で見た目を変更できます。

スクロールバーの設定については、[メニュー内のテキスト](/text-in-menus#scroll-bars)を参照してください。

### 最新の Minecraft の更新履歴をメニューに表示するにはどうすればよいですか？

Minecraft の更新履歴を FancyMenu 対応の Markdown に変換する、便利な[GitHub プロジェクト](https://github.com/ClaytonTDM/minecraft-changelogs-markdown)があります。これを使えば、最新の MC 更新履歴をメニューに表示できます！新しい更新履歴を取得するため、毎日更新されます。

[テキスト要素](/elements#text)に表示するには、**ソースモード** を **リソース** に設定し、リソースソースを **Web** にします。`https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md` を使用してください。

### 画面サイズに合わせて要素を引き伸ばす一番簡単な方法は何ですか？

多くの要素では、右クリックのコンテキストメニューから横方向と縦方向に引き伸ばす設定を利用できます。有効にすると、要素は画面の幅や高さいっぱいに引き伸ばされます。横方向と縦方向は個別に切り替えられます。

### テキスト要素の背面または前面にあるボタンをクリックしたり、スライダーを操作したりできません。

テキスト要素はデフォルトで操作可能になっています（スクロールつまみをつかんだり、Markdown のリンクをクリックしたりできるようにするため）。そのため、マウスクリックやスクロールイベントを消費します。できればボタンをテキスト要素の背面や前面に配置しないようにしてください。どうしても避けられない場合は、テキスト要素を**右クリック**し、**操作可能** を **無効** に設定できます。ただし、テキスト要素は操作できない静的なテキストとなり、スクロールやリンクのクリックができなくなります。

### 画面内で矢印キーや Tab キーを使って移動するとき、ボタンやスライダーにフォーカスが当たらないようにするにはどうすればよいですか？

ボタンやスライダーをキーボード操作の対象から外すには、対象を**右クリック**し、**ナビゲーション可能** を **無効** に設定します。ボタンやスライダーは引き続きクリックできますが、矢印キーや Tab キーでフォーカスできなくなります。

チャット画面にボタンやスライダーを追加するときにも便利です。画面内のボタンやスライダーを誤って選択することなく、上矢印キーで古いメッセージをさかのぼれます。

### FancyMenu のコンテキストメニューにあるはずの項目が見つかりません。

FancyMenu のコンテキストメニュー（何かを右クリックしたときや、メニューバーを操作したときに開くメニュー）は**スクロールできます**。メニュー上にマウスカーソルを置いた状態でスクロールホイールを使って上下にスクロールすると、最初は表示されていなかった項目も確認できます。

### タイトル画面をカスタマイズできません。エディターを閉じると元の画面に戻ります。

別の Mod が元の `title_screen` を置き換えています。その Mod の設定で、カスタムタイトル画面を無効にしてください。そのような設定がない場合、FancyMenu は置き換え後の画面にレイアウトを適用できません。

### インベントリ画面をカスタマイズしようとすると、インベントリのコンテナを編集できません。

これは想定された動作です。FancyMenu はプレイヤーインベントリ、チェスト、作業台など、あらゆる種類のインベントリ画面のコンテナ本体の編集には対応していません。対応を追加するのが非常に難しいためです。

ただし、これらの画面に新しい要素を追加することはできます。コンテナ自体は編集できません。

なお、SpiffyHUD もこの問題の解決には役立ちません。SpiffyHUD は HUD（たとえばアイテムのホットバー）を編集するためのもので、インベントリ画面のような画面を編集することはできません。
