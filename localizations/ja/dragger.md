# ドラッガー

ドラッガーは、プレイヤーがマウスでつかんで移動できる透明な領域です。ドラッガーに固定された要素はすべて一緒に移動します。たとえば、パッチノートのパネルやサーバーのルールを記載したメモなどです。メニューはプレイヤーが最後に配置した場所を記憶するため、再起動しても位置はそのままです。

<img width="800" alt="プレイヤーがタイトル画面のパッチノートバナーの棒に付いた革のグリップをつかみ、左から右へ移動します。オプションを開いて戻ってきても、バナーは右側に残っています" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/dragger_hero.gif?raw=true">

プレイヤーがドラッガーをドラッグできるのは、レイアウトエディターの外だけです。エディター内ではドラッガーは赤いボックスで表示され、名前も表示されます（右クリックメニューの **エディター内の色** で赤色を変更できます）。要素はすべてレイアウトで配置した場所にとどまります。

# 動かせる要素を作る

<img width="800" alt="新しい要素からドラッガーを追加し、バナーと同じ大きさに変更してバナーの上に移動し、2つ下のレイヤーに移動します。次にバナーをドラッガーから少し外して戻し、バーがいっぱいになるまでその位置で押さえると、バナーがドラッガーに固定されます" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/dragger_setup.gif?raw=true">

1. テキスト要素を重ねたバナー画像など、動かしたいものを作ります。
2. レイアウトエディターの何もない場所を右クリックし、**新しい要素 -> ドラッガー** をクリックします。
3. ドラッガーをバナーと同じ大きさにして、バナーの上に移動します。
4. ドラッガーを右クリックし、**1つ下のレイヤーへ移動** をクリックして、バナーのすべての要素より下に配置します。選択中の要素は常に一番上に表示されるため、何もない場所をクリックして変化を確認してください。
5. バナーをドラッガーに固定します。バナーをドラッガーから少し外して戻し、バーがいっぱいになるまでその位置で押さえます。詳しくは[要素の配置](/positioning-elements#anchoring-elements-to-other-elements)をご覧ください。
6. レイアウトを保存し、エディターの外で動作を確認します。

動く要素に固定された要素も、一緒に移動します。このGIFではテキストがバナーに固定されているため、ドラッガーが必要なのはバナーだけです。

複数の要素を一度に固定するには、手順4の前にドラッガーを右クリックし、**要素 ID をコピー** をクリックします。次に、固定したい要素を選択し、そのうちの1つを右クリックして **アンカーポイント -> 別の要素** をクリックし、IDを貼り付けます。

> [!TIP]
> プレイヤーにはドラッガーが見えないため、タイトルバーやグリップなどを使って、どこをつかめばよいか分かるようにしましょう。

# 位置を保存する

新しいドラッガーでは、右クリックメニューの **ユーザーのドラッグ位置を保存** が有効になっています。

- **有効**: プレイヤーがドラッガーを放したときに位置が保存されます。画面を閉じたりゲームを再起動したりしても、位置は保持されます。
- **無効**: 画面を再び開いたときや、ウィンドウサイズまたはGUIスケールを変更したときに、要素はレイアウト上の位置に戻ります。

エディターでこの設定を無効にすると、このドラッガーについてプレイヤーが保存した位置も消去されます。

位置は各ドラッガーの[要素 ID](/element-identifiers)を使って、`fancymenu_data/dragger_metas.json` に保存されます。このフォルダーは[プロファイル](/profiles)に含まれないため、テスト中にドラッグした位置が、Modパックの `config/fancymenu/` フォルダーに保存されることはありません。[データの保存場所](/data-storage-locations#instance-data)をご覧ください。

すべてのドラッガーをレイアウト上の位置に戻すには、ゲームを終了した状態で `dragger_metas.json` を削除します。

# プレイヤーがつかめる場所

プレイヤーがドラッガーをつかめるのは、ドラッガーの上にある要素がクリックを受け取らない場所です。

- ドラッガーの上に画像があってもクリックは画像を通り抜けるため、プレイヤーはバナー自体をつかめます。
- ドラッガーの上にあるボタンやテキスト要素の文字はクリックを受け取るため、動かせるパネル上でも引き続き操作できます。
- ドラッガーがボタンより前面にある場所では、ボタンはクリックを受け取りません。そのため、上記の手順ではドラッガーをバナーより下に配置しています。

ドラッガーが[要件](/element-visibility#showing-elements-only-sometimes)によって非表示になっている間、プレイヤーはドラッガーをつかめません。

# 画面内にとどめる

新しい要素では **画面内にとどめる** が有効になっています。この設定により、ドラッガーは画面の端で止まり、画面外へドラッグできなくなります。ドラッガーをバナー全体と同じ大きさにすると、バナーも一緒に画面の端で止まります。

タイトルバーのように一部分だけを覆うドラッガーでも問題ありません。ただし、ドラッガーに固定された要素にも、それぞれ **画面内にとどめる** の設定があります。画面の端では、ドラッガーが動き続ける一方で固定された要素が個別に止まり、パネルが分断されてしまいます。それらの要素では **画面内にとどめる** を無効にし、ドラッガーと一緒に動くようにします。そうすれば、タイトルバーだけが画面内にとどまります。
