# ドラッガー

ドラッガーは、レイアウトエディターの外でユーザーがマウスで移動できる目に見えない要素です。他の要素をドラッガーにアンカーすると、それらも一緒に移動します。

1. [**ドラッガー**要素](./elements#dragger)を追加します。
2. ドラッガーに移動させたい要素をアンカーします。
3. ユーザーがつかむ表示領域の上に、ドラッガーのサイズと位置を合わせます。

**Save User Drag Offset** を有効にすると、ドラッグした位置が画面を開き直してもゲームを再起動しても保持されます。オフセットをリセットしたい場合は無効にしてください。

ドラッガーはエディター内でのみ表示されます。表示用の本体として、アンカーされた [Image](./elements#image)、[Shape](./elements#rectangle-shape)、または他の要素を使用してください。
