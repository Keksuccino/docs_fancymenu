# 高度な位置調整とサイズ調整

高度な位置調整/サイズ調整を使うと、**要素の位置とサイズを完全に制御**できます。これは非常に強力ですが、FancyMenu の自動サイズ調整や自動位置調整を使う場合よりも **かなり時間がかかります**。

> Minecraft の **GUI スケール** に合わせて要素をより適切に拡大縮小したいだけなら、代わりにレイアウト全体の **自動スケーリング** を使うことをおすすめします。これは、エディターの背景を右クリックしたときに開くメニューで GUI スケールを強制的に設定し、その同じメニューで **Auto-Scaling** を有効にすることで使えます。
{.is-warning}


# 高度な位置調整/サイズ調整モードの切り替え

要素の高度な位置調整/サイズ調整を**有効にする**には、その要素を**右クリック**して **Advanced Positioning** または **Advanced Sizing** をクリックします。
高度な位置またはサイズの値を設定すると、要素は自動的に高度なモードに切り替わります。

通常の位置調整/サイズ調整に戻して**無効にする**には、**すべての位置調整/サイズ調整の値を削除**します。

> 要素が高度なサイズ調整/位置調整モードにある間は、その要素のサイズ変更や移動が無効化されるか、制限される場合があります。
{.is-warning}

# 位置/サイズの計算

高度な位置調整/サイズ調整が非常に強力なのは、位置/サイズの値に**プレースホルダー**を使えるためです。

これにより、**Calculator** プレースホルダー（**Advanced** プレースホルダーカテゴリにあります）を、**Screen Width**、**GUI Scale**、**Element Width** などの **GUI** カテゴリのプレースホルダーと組み合わせて使えます。

> プレースホルダーは、テキストエディター右上の **Placeholders** ボタンをクリックして追加できます。このボタンが表示されない場合、編集したいコンテンツはプレースホルダーを**サポートしていません**。
{.is-info}

**Calculator** プレースホルダーで計算するには、例の式を自分の式に置き換えます。式の中ではネストしたプレースホルダーを使えるので、画面サイズや要素サイズなどのプレースホルダーを利用できます。

たとえば、このプレースホルダーは単純に `1 + 1` を計算し、後で `2` と表示されます:

`{"placeholder":"calc","values":{"expression":"1 + 1","decimal":"false"}}`

`decimal` 変数は `false` に設定されています。これはほとんどのサイズ調整/位置調整の計算で重要なので、高度な位置調整/サイズ調整を使うときは常に `false` に設定してください。

次の Calculator は **Screen Width** プレースホルダーを使い、それを `2` で割っています:

`{"placeholder":"calc","values":{"expression":"{"placeholder":"guiwidth"} / 2","decimal":"false"}}`
