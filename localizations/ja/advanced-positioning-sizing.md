# 高度な配置とサイズ設定

高度な配置/サイズ設定を使うと、**要素の位置とサイズを完全に制御**できます。これは非常に強力ですが、FancyMenu の自動サイズ設定や自動配置を使う場合と比べて、**かなり手間がかかります**。

> もし要素を Minecraft の **GUI スケール** に合わせてより適切に拡大縮小したいだけなら、代わりにレイアウト全体の **自動スケーリング** を使うことをおすすめします。まず、エディタの背景を右クリックしたときに開くメニューで GUI スケールを強制設定し、その後同じメニューで **Auto-Scaling** を有効にしてください。
{.is-warning}


# 高度な配置/サイズ設定モードの切り替え

要素で高度な配置/サイズ設定を**有効にする**には、その要素を**右クリック**して **Advanced Positioning** または **Advanced Sizing** をクリックします。
高度な位置またはサイズの値を設定すると、その要素は自動的に高度なモードに切り替わります。

通常の配置/サイズ設定に戻して**無効にする**には、**すべての配置/サイズ設定値を消去**してください。

> 要素が高度なサイズ設定/配置モードになっている間は、要素のサイズ変更や移動が無効化または制限される場合があります。
{.is-warning}

# 位置/サイズの計算

高度な配置/サイズ設定が非常に強力な理由は、位置/サイズの値に**プレースホルダー**を使えるからです。

これにより、**Calculator** プレースホルダー（**Advanced** プレースホルダーカテゴリ内）を、**GUI** カテゴリのプレースホルダー、たとえば **Screen Width**、**GUI Scale**、**Element Width** などと組み合わせて使えます。

> テキストエディタ右上の **Placeholders** ボタンをクリックすると、プレースホルダーを追加できます。このボタンが表示されない場合、編集したいコンテンツはプレースホルダーを**サポートしていません**。
{.is-info}

**Calculator** プレースホルダーで計算するには、例の式を自分の式に置き換えてください。式の中にネストしたプレースホルダーを使えるので、画面サイズや要素サイズなどのプレースホルダーも利用できます。

たとえば、次のプレースホルダーは単純に `1 + 1` を計算し、後で `2` と表示されます。

`{"placeholder":"calc","values":{"expression":"1 + 1","decimal":"false"}}`

`decimal` 変数は `false` に設定されています。これは多くのサイズ/配置計算で重要なので、高度な配置/サイズ設定を使う場合は常に `false` にしてください。

次の計算機は **Screen Width** プレースホルダーを使い、それを `2` で割ります。

`{"placeholder":"calc","values":{"expression":"{"placeholder":"guiwidth"} / 2","decimal":"false"}}`

> [!IMPORTANT]
> **Advanced Positioning** が有効な間は、要素の **アンカー** やその他の位置関連機能は**無視**されます。Advanced Positioning は、デフォルトの Minecraft GUI の処理と同じように、常に左上（X0 Y0）を原点として使用します。Advanced Positioning で尊重される唯一の設定は **Stay on Screen** です。
