# 立方体パノラマ

FancyMenu は、メニューの背景としてカスタムの 6 枚画像パノラマキューブを読み込むことができます。

これらのパノラマは、Minecraft のタイトル画面の背景として使われる特別な立方体パノラマ形式で、6 枚の画像（面）から構成され、立方体（より正確にはスカイボックス）として描画されます。

> **重要**: Windows を使っている場合は、[ファイル拡張子](https://cdn.discordapp.com/attachments/795308330746511390/801561308012347482/unknown.png) をオンにするのを忘れないでください。そうしないと、あとでファイル名の重要な部分が見えなくなります！
{.is-warning}

# パノラマの作成

Minecraft が背景パノラマをどのように扱うのか、またそれをどう作成するのかわからない場合は、[この動画](https://www.youtube.com/watch?v=F7jMd3zsjZQ&t) を確認してください。
Minecraft のパノラマの仕組みと作り方をとてもよく理解できます！

動画を見たあと、これらのパノラマの作成には少し時間がかかることに気づくでしょう。
少しでも時間を節約したいなら、パノラマを自動で作成してくれる mod を使うことを考えてみてください。
`minecraft panorama mod` で検索するといくつか見つかりますが、そのうちの 1 つが [Panoramica](https://www.curseforge.com/minecraft/mc-mods/panoramica)（私が作成しました）です。

# パノラマの準備

6 枚のパノラマ画像を用意したら、正しい場所へ移動する必要があります！

FancyMenu のパノラマディレクトリは `.minecraft/config/fancymenu/panoramas` にあります。
これは、この mod で使いたいすべてのパノラマの保存先です。

## パノラマフォルダ

各パノラマには専用のフォルダがあります。
新しいパノラマを追加したい場合は、`.minecraft/config/fancymenu/panoramas` の中に新しいフォルダを作成する必要があります。
この例では、フォルダ名を `mypanorama` にします。

![1](https://user-images.githubusercontent.com/35544624/100791916-2802d380-341a-11eb-8e32-f9913e93a38c.png)

## フォルダの内容

フォルダを作成したら、中身を入れる必要があります。

### プロパティファイル
各パノラマには、動作に必要なプロパティファイルがあります。
このファイル名は常に `properties.txt` である必要があり、重要な内容を記述しなければなりません。

パノラマのプロパティファイルの内容は、常に次のようになります:
```
type = panorama

panorama-meta {
  name = name_of_your_panorama
  speed = 1.0
  fov = 85.0
  angle = 25.0
  start_rotation = 0
}
```
変更できるのは `panorama-meta` セクション内の変数だけです！

#### name
これはあなたのパノラマの **一意** の名前でなければなりません。
同じ名前のパノラマを 2 つ読み込むことはできません！
この名前は、後でパノラマを識別するために使います。

#### speed
パノラマが回転する速度です。
この値は速度の倍率です。たとえば、`1.0` はデフォルト速度、`2.0` は 2 倍、`0.5` は半分になります。
負の値はサポートされていません。速度を遅くしたい場合は小数値を使ってください。

#### fov
視野角です。
デフォルトの FOV は `85.0` です。
ここに大きすぎる値や小さすぎる値を使うとパノラマが壊れます。欲しい FOV が見つかるまで調整してみてください。

#### angle
パノラマを見下ろす垂直角度です。
デフォルトの角度は `25.0` です。

#### start_rotation
パノラマの開始回転角度（水平）です。値は 0 から 360 の間です。

<br>

### パノラマ画像フォルダ

パノラマフォルダに必要な 2 つ目の必須要素は、パノラマ画像を入れる実際の画像フォルダです。

このフォルダ名は `panorama` にする必要があります。

すべてのパノラマ画像をここに入れてください。ただし、上の [動画](https://www.youtube.com/watch?v=F7jMd3zsjZQ&t) で示されている通りに、正しい名前を付けるのを忘れないでください！

![3](https://user-images.githubusercontent.com/35544624/100791922-29340080-341a-11eb-8174-874a180d0485.png)

> パノラマ画像としてサポートされているのは PNG のみです！
{.is-warning}

### パノラマオーバーレイ

最後の手順は **任意** で、パノラマの上にオーバーレイを載せたくない場合は省略できます。

パノラマにビネットや他の種類のオーバーレイを追加したい場合は、`overlay.png` という名前のファイルを追加できます。
オーバーレイとしてサポートされているのは PNG のみで、ファイル名は必ず `overlay.png` であることに注意してください！

### もう一度確認

これで、`.minecraft/config/fancymenu/panoramas` に `properties.txt` ファイル、`panorama` という名前の別フォルダ、そして場合によっては `overlay.png` というオーバーレイが入ったフォルダができているはずです。

![2](https://user-images.githubusercontent.com/35544624/100791920-29340080-341a-11eb-8e26-98a7fd2ad7eb.png)

# パノラマの使用

ゲームを再起動するか、**Customization -> Reload FancyMenu** から FancyMenu を再読み込みしたあと、パノラマをメニュー背景として設定できるようになります。これを行うには、レイアウトエディタの背景を右クリックし、**Menu Background** をクリックしてください。
