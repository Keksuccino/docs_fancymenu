# 要素ID

FancyMenuの各要素には、作成時に自動で固有のIDが割り当てられます。

このIDは要素を識別するために使われます。プレースホルダー、アクション、読み込み要件など、FancyMenuのほかの機能が要素と連携する際に利用します。

# 要素のIDを取得する

要素のIDを取得するには、エディターでその要素を右クリックし、**要素IDをコピー**をクリックします。IDがクリップボードにコピーされるので、必要な場所に貼り付けてください。
