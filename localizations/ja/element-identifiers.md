# 要素ID

FancyMenu のすべての要素には、作成時に自動的に適用される一意の識別子があります。

これらの識別子は、その名のとおり要素を識別するために使われます。これにより、プレースホルダー、アクション、読み込み要件など、FancyMenu のほかの機能がその要素とやり取りできるようになります。

# 要素の識別子を取得する

別の場所で使うために要素の識別子が必要な場合は、エディター内でその要素を **右クリック** し、**要素IDをコピー** をクリックしてください。これで要素の識別子がクリップボードにコピーされるので、必要な場所へ簡単に貼り付けられます。
