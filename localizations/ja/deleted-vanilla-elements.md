# Vanilla要素の削除

レイアウトエディタで表示されている、すべてのデフォルト/Vanilla要素（いくつかのmod要素を含む）を非表示にできます。表示されている場合は、要素を**右クリック**して**削除**をクリックしてください。


# 削除したVanilla要素を元に戻す

ボタン、ロゴ、その他の要素など、削除/非表示にしたVanilla要素を再び表示するには、それらを削除したレイアウトを開き、**メニューバー -> 要素 -> 削除されたVanilla要素**へ移動して、再び表示したい要素を**左クリック**してください。

削除した要素がメニューに表示されない場合は、別のレイアウトを開いている可能性があります。削除したレイアウトを見つける必要があります。
