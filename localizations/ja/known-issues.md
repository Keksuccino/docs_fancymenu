# FancyMenu の既知の問題

この一覧には、最新の FancyMenu バージョンに存在する、まだ修正されていない問題、または Minecraft の制限や他の MOD との競合などのために修正できない問題が常に含まれています。

# 修正可能

これらの問題は、今後修正される予定です。

## 現在、既知の問題はありません。

# 修正不可

これらの問題は修正できず、おそらく Minecraft 側や他の MOD 側などで修正されない限り、今後も残り続けます。

## Player Entity と Item の要素は常にすべての前面に表示されます。

FancyMenu のレイヤーシステムは、Minecraft の描画方法の都合により、Player Entity と Item の要素には機能しません。少なくとも古い Minecraft のバージョンでは、これらは常に他のすべての GUI 要素より前面に描画されます。Minecraft 1.21.8 以降では、この影響を受けなくなっている可能性があります。
