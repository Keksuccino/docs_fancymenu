# スケジューラー

スケジューラーは、アクションスクリプトをタイマーで実行します。

これはグローバルであり（特定の画面に紐づきません）、GUI が開いていないときでも実行を続けられます。

スケジューラーは、一度だけの処理ではなく、時間経過に応じた自動化を行いたいときに使います。
繰り返し処理、遅延処理、バックグラウンドでのロジックに便利です。

代表的な例:

- 数秒ごとに変数やテキスト要素を更新する（例: カスタム時計/ステータス表示）
- 定期的にチェックを行い、条件が満たされたらアクションを実行する
- メニューの演出、サウンド、その他のスクリプト動作を一定間隔で開始する
- 画面を開いたままにしなくても、あとでアクションを実行するために遅延させる

# 見つけ方

レイアウトエディターを**開いていない**状態で FancyMenu の**メニューバー**を開き、**カスタマイズ -> スケジューラーを管理** を選択します。

# クイックスタート

1. **カスタマイズ -> スケジューラーを管理** を開きます。
2. **スケジューラーを追加** をクリックします。
3. スケジューラーの **アクションスクリプト** を作成します（これはスケジューラーの各ティックごとに1回実行されます）。
4. スケジューラーを選択し、**設定を編集** をクリックします。
5. 以下を設定します:
   - **スケジューラー ID**（一意のスケジューラー名。Start/Stop アクションや要件で使用します。使用可能文字: `a-z`, `0-9`, `.`, `_`, `-`）
   - **開始遅延 (ms)**（最初のティックが実行される前の待機時間）
   - **ティック遅延 (ms)**（ティック間の待機時間。`0` = 毎ゲームティック）
   - **実行ティック数**（自動停止するまでに実行するティック数。`0` = 永続）
   - **起動時に開始**（FancyMenu の読み込み時にこのスケジューラーを自動的に開始します）
6. **今すぐ開始** を使って即座に実行します。
7. **今すぐ停止** を使って停止します。

# スケジューラーの制御と確認

スケジューラーを制御したり、実行中かどうかを確認したりするためのアクションと要件があります。

## アクション

- **スケジューラーを開始** はスケジューラーの ID を受け取り、すでに実行中でなければ開始します。
- **スケジューラーを停止** もスケジューラーの ID を受け取り、停止します。

## 要件

スケジューラーが現在実行中かどうかを確認するには、**スケジューラーは実行中** 要件を使います。これはスケジューラーの ID を受け取ります。

# ヒント

1. `hud_update`、`menu_animation`、`music_fade` のような分かりやすい ID を使いましょう。
2. まずは高めのティック遅延（たとえば `200`〜`1000` ms）から始め、必要な場合だけ下げるとパフォーマンスを節約できます。
3. スケジューラー一覧では、スケジューラーを右クリックするとアクションを素早く編集できます。
4. スケジューラー一覧では、スケジューラー ID をダブルクリックすると名前を変更できます。
