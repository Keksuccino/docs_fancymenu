# スケジューラー

スケジューラーは、タイマーに従って[アクションスクリプト](/action-scripts)を実行します。待機後に1回だけ実行することも、数回実行することも、停止されるまで繰り返し実行することもできます。すべてのメニューやゲームプレイ中に動作し、メニューが開いていないときでも実行されます。また、レイアウトには属しません。

後から実行したい処理や繰り返し実行したい処理には、スケジューラーの使用をおすすめします。できる限り、[Ticker要素](/elements#ticker)の代わりにスケジューラーを使ってください。

<img width="800" alt="スケジューラーがヒントのリストをシャッフルするため、サバイバルのヒントボックスに4秒ごとに別のヒントが表示される" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/schedulers_tips.gif?raw=true">

> [!CAUTION]
> スケジューラーは、メニューが開いていないときでもファイル、ネットワーク、コマンド、クリップボード、リソースパック、リンクに関するアクションを実行できます。信頼できる人のプロフィールやファイルに含まれるスケジューラーだけを使用してください。

# スケジューラーの追加

<img width="800" alt="スケジューラーの管理を開き、スケジューラーを追加をクリックして、tipsリストにシャッフル付きのリストを並べ替えるアクションを設定する" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/schedulers_add.gif?raw=true">

1. **メニューバー -> カスタマイズ -> スケジューラーの管理**を開きます。
2. **スケジューラーを追加**をクリックします。アクションスクリプトエディターが開きます。
3. 実行するアクションを追加し、**完了**をクリックします。[アクションスクリプト](/action-scripts#making-an-action-script)を参照してください。

<img width="800" alt="設定の編集で新しいスケジューラーにrandom_tipという名前を付け、Tick Delayを4000、Start on Launchを有効にしてから開始すると、メニューのヒントが切り替わる" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/schedulers_start.gif?raw=true">

4. 新しいスケジューラーがランダムなIDで表示されます。クリックして、**設定を編集**をクリックします。
5. `random_tip`のような**スケジューラーID**を設定し、[タイマー](#settings)を設定して、**完了**をクリックします。
6. **今すぐ開始**をクリックして動作を確認します。

**スケジューラーの管理**で行った変更は、すべてすぐに保存されます。

GIFのスケジューラーは、4秒ごとにリスト`tips`に対して**シャッフル**付きの[**リストを並べ替え（FM変数）**](/action-scripts#arrange-list-fm-variable)を実行します。テキスト要素にはリストの最初の項目が表示されるため、ランダムなヒントが表示されます。リストとテキストの仕組みについては、[リストアクション](/variables#list-actions)を参照してください。

# 設定

| 設定 | 説明 |
|---|---|
| **スケジューラーID** | アクションや条件から参照する名前です。使用できるのは小文字、数字、`.`, `_`, `-`のみです。 |
| **開始遅延（ms）** | 開始後、初回の実行までに待機する時間です。`0`にするとすぐに実行されます。 |
| **実行間隔（ms）** | 2回の実行間の時間です。`0`にすると毎ティック（1秒間に20回）実行されます。 |
| **実行回数** | 自動停止するまでに実行する回数です。`0`にすると、停止されるまで実行し続けます。 |
| **起動時に開始** | ゲームを起動するたびに開始します。 |

時間の単位はミリ秒です。`1000`は1秒、`60000`は1分、`1800000`は30分です。

# 開始と停止

スケジューラーは、開始されて初めて実行されます。

- **起動時に開始**を有効にすると、ゲーム起動時と[プロフィール](/profiles)の切り替え後に開始します。
- **スケジューラーの管理**で**今すぐ開始**をクリックすると開始します。実行中はボタンが**今すぐ停止**に変わります。
- ボタンのスクリプトや[リスナー](/listeners)などから、スケジューラーIDを指定して[**スケジューラーを開始**](/action-scripts#start-scheduler)アクションを実行すると開始します。

次の場合、スケジューラーは停止します。

- **実行回数**で設定した回数だけ実行した後、自動で停止します。
- **今すぐ停止**をクリックするか、IDを指定して[**スケジューラーを停止**](/action-scripts#stop-scheduler)アクションを実行します。
- 名前を変更または削除したとき、[プロフィール](/profiles)を切り替えたとき、またはゲームを終了したときに停止します。再起動後に再び実行されるのは、**起動時に開始**が有効なスケジューラーだけです。

実行中のスケジューラーを再度開始することはできません。停止するまで**スケジューラーを開始**アクションは何も行いません。もう一度開始するには、**スケジューラーを停止**してから**スケジューラーを開始**してください。

[**スケジューラーが実行中**](/conditions#scheduler-is-running)条件を使うと、スケジューラーが実行中かどうかを確認できます。たとえば、実行中だけ停止ボタンを表示する場合に使えます。

## 画面が開いている間だけ実行する

タイトル画面など、特定の画面が開いている間だけスケジューラーを実行するには、次の手順を行います。

1. レイアウトエディターで、その画面のレイアウトを開きます。
2. エディターの背景を右クリックし、**「画面を開いたとき」のアクションスクリプトを編集**をクリックして、スケジューラーIDを指定した**スケジューラーを開始**を追加します。
3. 背景をもう一度右クリックし、**「画面を閉じたとき」のアクションスクリプトを編集**をクリックして、同じIDを指定した**スケジューラーを停止**を追加します。

# スケジューラーの管理

<img width="800" alt="3つのスケジューラーが表示されたスケジューラーの管理画面。random_tipが選択され、右側に設定と実行中のステータスが表示されている" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/schedulers_manage.png?raw=true">

- スケジューラーをクリックすると、右側に設定、実行状態、アクションスクリプトが表示されます。
- **アクションを編集**をクリックするか、スケジューラーを右クリックすると、アクションスクリプトが開きます。
- スケジューラーIDをダブルクリックすると名前を変更できます。`Enter`で確定し、`Esc`でキャンセルします。名前を変更するとスケジューラーは停止し、以前のIDを使ったアクションからは見つからなくなります。
- **スケジューラーを削除**をクリックすると、確認後に選択中のスケジューラーが削除されます。
- **AI用にエクスポート**をクリックすると、選択中のスケジューラーまたはすべてのスケジューラーが[AIチャット](/export-for-ai)用にコピーされます。
- 検索バーでは、スケジューラーIDを使って検索できます。

スケジューラーは`config/fancymenu/scheduler_instances.txt`に保存されます（[データの保存場所](/data-storage-locations)を参照）。各[プロフィール](/profiles)には、それぞれ別のスケジューラーが保存されます。

# 例：休憩のリマインダー

ゲーム起動後、30分ごとにトースト通知を表示する例です。

1. [**トーストを表示**](/action-scripts#show-toast)を使ったスケジューラーを追加します。**タイトル**を`Time for a Break`、**メッセージ**を`Stand up, stretch and drink some water.`に設定します。
2. **設定を編集**で、**スケジューラーID**を`break_reminder`に設定します。**開始遅延（ms）**と**実行間隔（ms）**を`1800000`に設定し、**起動時に開始**を**有効**にします。

**開始遅延（ms）**を設定しないと、ゲーム起動直後に最初のトーストが表示されます。

# 知っておくと便利なこと

- **実行間隔（ms）**は、処理に必要な範囲でできるだけ長く設定してください。`0`にするとアクションが1秒間に20回実行され、処理の重いアクションはゲームの動作を遅くします。
- ゲームの動作が遅くなると、複数回の実行が立て続けに発生することがあります。
- アクションスクリプトへの変更は、スケジューラーの実行中でもすぐに反映されます。設定への変更は、次に開始したときに反映されます。
- アクションが失敗しても、スケジューラーは実行を続けます。エラーはゲームのログファイル`logs/latest.log`に記録されます。
- 1つのアクションスクリプト内で「クリックから2秒後に画面を開く」のように一度だけ待機する場合は、[後で実行](/action-scripts#execute-later)ブロックの方が簡単です。
