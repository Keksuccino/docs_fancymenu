# スクロロール可能領域

**スクロール可能領域**にはほかの要素を入れ、プレイヤーがスクロールして表示できるようにします。長いボタン一覧、ワールドやサーバーの選択画面、アイテムのショーケース、ニュースパネルなど、1画面に収まらないものに最適です。

領域内のすべての要素は領域と一緒にスクロールし、領域の端で見切れます。

<img width="800" alt="スクロール可能領域にボタンを入れて縦に並べる" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/scroll_area_showcase.gif?raw=true">

> [!NOTE]
> レイアウトに追加した要素のみ、領域に入れることができます。[バニラ要素](/vanilla-elements)はメニュー自体に属するため、領域には入れられません。

# スクロール可能領域を追加する

1. レイアウトエディターでレイアウトを開きます。
2. エディターの背景を右クリックし、**新しい要素 -> スクロール可能領域**を選択します。
3. 要素を領域にドラッグします。

# 要素を領域に出し入れする

- 要素を領域にドラッグすると、領域に入ります。領域が要素を受け入れると、領域が光ります。要素の一部が領域内に入った場合にのみ、要素が領域に入ります。
- 選択した複数の要素をまとめてドラッグするには、ドラッグを開始するときに`Ctrl`（macOSでは`Cmd`）を押したままにします。
- 要素を領域の端に近づけながらドラッグすると、領域がスクロールするため、隅々まで移動できます。エディターではマウスホイールでもスクロールできます。
- 要素を領域から出すには、領域の外にドラッグするか、要素を右クリックして**スクロール可能領域から移動**を選択します。要素は画面上の現在の位置に留まります。
- 領域を別の領域に入れることもできます。

## レイヤー

[レイヤーウィジェット](/layout-editor#scrollable-areas)では、領域内の要素は領域の下に表示されます。レイヤーをドラッグすると、領域に入れたり、領域から出したり、順序を変更したりできます。領域のレイヤーにある折りたたみボタンを押すと、一覧でその領域の要素が非表示になります。

## コピーと削除

- 領域をコピーすると、その中の要素もすべてコピーされます。
- 要素が入ったままの領域を削除すると、それらの要素をどうするか確認されます。**要素を削除**を選ぶと要素も削除され、**要素を保持**を選ぶと画面上の現在の位置に残ります。

# 要素を配置する

領域を右クリックして**配置**を開きます。**モード**では、領域内の要素の配置方法を設定します。

- **アンカー**: レイアウトのほかの部分と同様に、要素を自分で配置します。新しい領域ではこのモードが使用されます。
- **スタック**: 要素を順番に並べます。
- **グリッド**: 要素を同じサイズのセルに並べます。
- **フロー**: 要素を隣り合わせに並べ、1行がいっぱいになると次の行に移ります。

<img width="800" alt="スタック、グリッド、フローモードのスクロール可能領域" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/scroll_area_modes.png?raw=true">

## アンカーモード

領域内の要素にはそれぞれ独自のアンカーがあり、画面ではなく領域のコンテンツを基準にします。たとえば、**左上隅**アンカーはコンテンツの左上隅を基準とし、下側のアンカーはコンテンツの末端に固定されます。アンカーの仕組みについては、[要素の配置](/positioning-elements)を参照してください。

- **水平方向に引き伸ばす**と**垂直方向に引き伸ばす**を有効にすると、要素の幅または高さがコンテンツと同じになります。
- 要素をアンカーで固定できるのは、同じ領域にあるほかの要素に対してのみです。要素を領域に入れたり、領域から出したりするときに、領域の境界をまたいでアンカーが設定されていた要素は、**左上隅**アンカーに変更され、現在の位置に留まります。

### コンテンツサイズ

アンカーモードでは、コンテンツのサイズを決めることで、領域のスクロール範囲を設定します。

領域を選択し、コンテンツの端にあるハンドルをドラッグします。領域の端を越えてドラッグすると、領域も一緒にスクロールします。

<img width="698" alt="選択したスクロール可能領域のコンテンツハンドル" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/scroll_area_content_handle.png?raw=true">

領域を右クリックして**コンテンツサイズ**を開いて設定することもできます。

- **コンテンツの幅**と**コンテンツの高さ**では、数値でサイズを設定します。[プレースホルダー](/placeholders)にも対応しています。プレースホルダーを使うと、ハンドルをドラッグできなくなります。
- **コンテンツに合わせる**を選ぶと、コンテンツの末端が最後の要素の末端と一致します。コンテンツの中央または末端にアンカーで固定された要素はコンテンツと一緒に移動するため、サイズの計算には含まれません。

コンテンツのサイズが領域より小さくなることはなく、領域がスクロールする方向にのみ大きくなります。

## スタック、グリッド、フロー

- 領域が要素を自動で配置し、コンテンツも要素に合わせて自動的に大きくなります。
- 要素をドラッグすると、順序を変更できます。移動先は線で示されます。
- アンカーモードからいずれかのモードに切り替えると、画面上での要素の並び順が引き継がれます。アンカーモードに戻すと、すべての要素が元の位置に保たれます。
- [条件](/conditions)によって非表示になった要素の場所には、隙間ができません。
- これらのモードでは、要素を引き伸ばすことはできません。
- これらのモードでは、一方向にのみスクロールします。**両方**に設定された領域は、垂直方向にスクロールします。

細かい設定をするには、**配置**を開きます。

| 設定 | 説明 |
|---|---|
| **配置** | 要素が並ぶ方向に対して、要素をどこに置くかを設定します。**先頭**、**中央**、**末尾**、**幅に合わせる**から選択します。**幅に合わせる**を選ぶと、要素は利用可能なスペースいっぱいの幅になります（横方向にスクロールする領域では高さになります）。フローでは**幅に合わせる**は使用できません。 |
| **間隔** | 要素間のスペースを設定します。 |
| **パディング** | 要素とコンテンツの端との間隔を設定します。 |
| **1行あたりの要素数** | グリッドのみ。1行に配置する要素の数を設定します。 |
| **可能な限り詰める** | グリッドのみ。固定数ではなく、スペースに収まるだけの要素を1行に配置します。配置数は**最小セルサイズ**で決まります。 |

# スクロール

プレイヤーはマウスホイールで領域をスクロールします。横方向にスクロールするには`Shift`を押したままにします。

- **スクロール方向**では、領域を**垂直**、**水平**、**両方**のどの方向にスクロールするかを設定します。スクロールしない方向のコンテンツサイズは、領域と同じになります。
- 領域内のテキスト要素が先にスクロールします。テキスト要素の末端まで到達すると、領域がスクロールします。
- プレイヤーが`Tab`でボタン間を移動すると、選択されたボタンが見えるように領域がスクロールします。

**スクロール**、**自動スクロール**、**スクロールバー**メニューには、テキスト要素と同じ設定があります。設定の詳細は[メニュー内のテキスト](/text-in-menus#scrolling-settings)を参照してください。異なる点は次のとおりです。

- **スナップ**では、コンテンツを**要素**にスナップして要素が常に領域の先頭に来るようにするか、**ページ**にスナップするかを選べます。
- **ドラッグしてスクロール**を有効にしても、領域内のボタンなどは引き続き操作できます。
- スクロールつまみにはピクセルハンドルが使われます。独自の**スクロールつまみテクスチャ**または**スクロールつまみの色 [HEX]**を設定することもできます。

# 背景

領域はコンテンツの背後にパネルを描画します。変更するには**背景**を開きます。設定方法は[テキスト要素の背景](/text-in-menus#background)と同じです。**背景を表示**をオフにして非表示にしたり、[9スライス](/nine-slicing-and-tiling)やタイリングを使って独自のテクスチャを設定したり、**パディング**で背景の広がりを変更したりできます。

# アクションによるスクロール

FancyMenuのほかの機能から、領域を操作したり状態を確認したりすることもできます。

- **要素をスクロール**[アクション](/action-scripts)を使うと、領域を先頭、末尾、指定位置、または領域内の要素までスクロールできます。
- **要素のスクロール位置**、**要素のスクロール率**、**要素のスクロールコンテンツサイズ**[プレースホルダー](/placeholders)では、領域のスクロール量とコンテンツのサイズを確認できます。
- **要素が末尾までスクロールしている**[条件](/conditions)では、領域が末尾までスクロールしているかを確認できます。
- **要素のスクロール時**、**要素が先頭までスクロールした時**、**要素が末尾までスクロールした時**[リスナー](/listeners)を使うと、領域のスクロール中にアクションを実行できます。

これらの機能にはすべて、領域の[要素識別子](/element-identifiers)が必要です。たとえば、次の設定では領域のスクロール量を0から100の値で表示します。

```
{"placeholder":"scroll_area_scroll_percent","values":{"element_identifier":"3f2a9c1e-7b4d-4e8a-9c2f-1d5e6a7b8c9d-1763950000000","axis":"vertical"}}
```

# 知っておくと便利なこと

- 領域を非表示にすると、その中のすべての要素も非表示になります。また、領域の不透明度は中のすべての要素にも適用されます。
- 領域は回転や傾斜ができず、領域やその中の要素には視差効果も適用されません。
- 領域内のツールチップ要素は、マウスに追従する場合を除き、領域の端で見切れます。
