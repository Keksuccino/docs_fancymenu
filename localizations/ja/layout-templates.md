# レイアウトテンプレート

FancyMenu や、そのアドオンである SpiffyHud や Drippy Loading Screen などのデザインテンプレートをダウンロードしたい場合は、Kekscord Discord サーバー（Keksuccino の Mod サポート用公式 Discord サーバー）の [#layout-templates](https://discord.com/channels/704163135787106365/1234093433795383316) チャンネルを確認するのが最適です。このチャンネルには、コミュニティが作成した完全な FancyMenu セットアップがあり、それぞれのダウンロードリンクが掲載されています。

そこにあるテンプレート投稿は、すべて同じ形式です。どれも完全な FancyMenu セットアップへのダウンロードリンクがあり、その中には `fancymenu` フォルダが含まれています。これは [Modpacks](/modpacks) ページにある説明のとおり、自分の `/config/fancymenu/` と置き換えてください。

これらのテンプレートは多くの場合かなり複雑なため、テンプレートを既存のセットアップに統合しようとするのはおすすめしません。そのため、既存の `fancymenu` フォルダをテンプレート内のものに置き換えるべきです。

# テンプレートの編集、またはプロジェクトへの利用

チャンネル内のテンプレートの多くは、編集したり、モッドパックのように自分のプロジェクトで使用したりすることができます。ただし、**そのテンプレートで何が許可されているかを必ず投稿で確認することが非常に重要です**！

すべてのテンプレートが、あらゆることを自由に行える完全な権限を与えているわけではありません。
