# レイアウトテンプレート

FancyMenu、または SpiffyHUD や Drippy Loading Screen などのアドオン用のデザインテンプレートをダウンロードしたい場合は、[Kekscord Discord サーバー](https://discord.gg/rhayah27GC)（MOD サポート用の Keksuccino 公式 Discord サーバー）にある [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) チャンネルを確認するのがおすすめです。このチャンネルにはコミュニティによって作成された FancyMenu の完全なセットアップが投稿されており、それぞれにダウンロードリンクが用意されています。

そこに投稿されているすべてのテンプレートは、同じ形式に従っています。いずれも、プロファイルファイル（`.fmp`）または `fancymenu` フォルダーとして、完全な FancyMenu セットアップへのダウンロードリンクが含まれているはずです。

> [!CAUTION]
> コミュニティ製のテンプレートはアクションを実行できます。信頼できる提供元からのみインポートしてください。

# テンプレートのインストール

テンプレートは FancyMenu の完全なセットアップであり、ほとんどの場合非常に複雑です。そのため、テンプレートを既存のセットアップと統合しようとすることはおすすめしません。代わりに、独自の [プロファイル](./profiles) として追加してください。

- **`.fmp` ファイル:** **メニューバー -> カスタマイズ -> プロファイル** を開き、ファイルをウィンドウにドラッグするなどして、[インポート](./profiles#importing)します。
- **`fancymenu` フォルダー:** [フォルダーをプロファイルとして追加](./profiles#adding-setup-folders)します。

その後、プロファイルウィンドウでテンプレートを選択し、**プロファイルを読み込む** をクリックします。現在のセットアップは独自のプロファイルとして引き続き利用できるため、いつでも元に戻せます。

# テンプレートの編集またはプロジェクトでの使用

このチャンネルにあるほとんどのテンプレートは、編集したり、MOD パックなどの自分のプロジェクトで使用したりできます。ただし、テンプレートをどのように利用してよいかについては、**必ずテンプレートの投稿を確認してください**！

すべてのテンプレートで、何をしてもよいとは限りません。
