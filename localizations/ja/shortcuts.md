# ショートカットとキー割り当て

FancyMenu には、**レイアウトエディター** やその他の機能での作業をより簡単かつ効率的にする、便利なショートカットがたくさんあります。

# レイアウトエディター

<br>

## CTRL + 左クリック

**CTRL** を押しながら要素を**左クリック**すると、複数の要素を選択できます。
**CTRL** を押しながらマウスで**複数の要素をドラッグ/移動**することもできます。

## SHIFT + 要素のサイズ変更

要素のサイズ変更中に SHIFT を押し続けると、縦横比が維持されます。

## 矢印キー

矢印キーを使って、選択した要素を**最高精度で移動**できます。

## CTRL + A

すべての要素を一度に選択します。

## CTRL + C

選択中のすべての要素をクリップボードに**コピー**します。

## CTRL + V

現在クリップボードにあるすべての要素を**貼り付け**ます。
これは別のレイアウト間でも機能するため、レイアウト A の要素をコピーしてレイアウト B に貼り付けることができます。

## CTRL + S

レイアウトをすばやく**保存**します。

## CTRL + ALT + L

最後に編集したレイアウトでレイアウトエディターをすばやく開きます。

## CTRL + Z

最後の操作を**元に戻す**ます。

## CTRL + Y

以前に元に戻した操作を**やり直し**ます。

## CTRL + G

**グリッド**の表示/非表示をすばやく切り替えます。

## O

**Window -> Anchor Overlay Visibility** で表示設定が **Show On Key Press** に設定されている場合、**O** を押し続けるとアンカーポイントのオーバーレイが表示されます。

## DEL

選択中のすべての要素を**削除**します。

# テキストエディター

<br>

## CTRL + C

選択したテキストをクリップボードに**コピー**します。

## CTRL + V

現在クリップボードにあるテキストを**貼り付け**ます。

## CTRL + Z

最後の操作を**元に戻す**ます。

## CTRL + Y

以前に元に戻した操作を**やり直し**ます。

## CTRL + A

全文を**選択**します。

## CTRL + D

現在の行を**複製**します。

## CTRL + U

選択したテキストを**切り取り**ます。

## ALT + 上矢印 / 下矢印

現在の行を上または下に移動します。

## CTRL + Home / CTRL + End

カーソルをテキストの先頭または末尾に移動します。

## CTRL + G

**Go To Line** 入力を開きます。

## CTRL + S

エディターを確定します。**Done** をクリックした場合と同じです。

## SHIFT + 矢印キー

カーソルを移動しながらテキストを選択/ハイライトします。

## 矢印キー

矢印キーでテキスト内のカーソルを移動できます。

# メニュー内

<br>

## CTRL + ALT + C

メニュー上部にある FancyMenu の **メニューバー** の表示/非表示を切り替えます。

## CTRL + ALT + R

FancyMenu を**再読み込み**します。
これにはリソース/アセットの完全な再読み込みが含まれ、ほとんどのキャッシュがクリアされます。

## CTRL + ALT + D

FancyMenu の **デバッグオーバーレイ** の表示/非表示を切り替えます。

# 編集ウィンドウ

v3.9.0 の多くの FancyMenu 編集ウィンドウは、**矢印キー** と **Enter** によるキーボード操作に対応しています。多くのウィンドウでは **CTRL + S** が **Done**、**ESC** が **Cancel** のショートカットとしても使われます。

再設計された Action Script Editor、Manage Requirements、Manage Variables の各ウィンドウでは、右クリックのコンテキストメニュー、検索、元に戻す/やり直し、そして各リストのキーボード操作にも対応しています。
