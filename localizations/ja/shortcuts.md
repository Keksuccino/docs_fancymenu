# ショートカット & キーバインド

**ショートカット修飾キー:** 対応している場合、Windows/Linux では `Ctrl`、macOS では `Command` を使用します。

# レイアウトエディター

| ショートカット | 動作 |
|---|---|
| `Ctrl/Command + 左クリック` | 複数の要素を選択またはドラッグします |
| `Shift + リサイズ` | 要素のアスペクト比を維持します |
| 矢印キー | 選択した要素を正確に移動します |
| `Ctrl/Command + A` | すべての要素を選択します |
| `Ctrl/Command + C` | 選択した要素をコピーします |
| `Ctrl/Command + V` | コピーした要素を貼り付けます。別のレイアウトにも貼り付け可能です |
| `Ctrl/Command + S` | レイアウトを保存します |
| `Ctrl/Command + Z` | 元に戻します |
| `Ctrl/Command + Y` | やり直します |
| `Ctrl/Command + G` | グリッドの表示/非表示を切り替えます |
| `O` | **Window -> Anchor Overlay Visibility** が **Show On Key Press** に設定されている場合、押している間アンカーポイントを表示します |
| `Delete` | 選択した要素を削除します |

# テキストエディター

| ショートカット | 動作 |
|---|---|
| `Ctrl/Command + C` | 選択したテキストをコピーします |
| `Ctrl/Command + V` | テキストを貼り付けます |
| `Ctrl/Command + Z` | 元に戻します |
| `Ctrl/Command + Y` | やり直します |
| `Ctrl/Command + A` | すべてのテキストを選択します |
| `Ctrl/Command + D` | 現在の行を複製します |
| `Ctrl/Command + U` | 選択したテキストを切り取ります |
| `Alt + 上/下矢印` | 現在の行を移動します |
| `Ctrl/Command + Home/End` | テキストの先頭または末尾に移動します |
| `Ctrl/Command + G` | **Go To Line** を開きます |
| `Ctrl/Command + S` | エディターを確定します |
| `Shift + 矢印キー` | テキスト選択範囲を拡張します |
| 矢印キー | カーソルを移動します |

# グローバルメニューのショートカット

これらのショートカットは、正確に `Ctrl + Alt` の組み合わせを使用します。

| ショートカット | 動作 |
|---|---|
| `Ctrl + Alt + L` | 最後に編集したレイアウトでレイアウトエディターを開きます |
| `Ctrl + Alt + C` | FancyMenu のメニューバーの表示/非表示を切り替えます |
| `Ctrl + Alt + R` | FancyMenu と、その管理するリソース/キャッシュを再読み込みします |
| `Ctrl + Alt + D` | FancyMenu のデバッグオーバーレイの表示/非表示を切り替えます |

# 編集ウィンドウ

FancyMenu の編集ウィンドウでは、矢印キーと `Enter` によるキーボード操作が可能です。多くの画面では、**Done** に `Ctrl/Command + S`、**Cancel** に `Escape` を使用します。

Action Script、Requirements、Variables の各エディターでは、右クリックのコンテキストメニュー、検索、元に戻す/やり直し、キーボードによるリスト操作にも対応しています。
