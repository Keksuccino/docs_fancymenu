# 画面識別子

FancyMenu は、レイアウトがどの画面に属するかを判断したり、特定の画面上のボタンを指定したり、その他モッドが特定の画面と通信またはカスタマイズする必要がある場面で、画面識別子を使用します。

# 画面の識別子を見つける

**デバッグオーバーレイ** を使うと、現在アクティブなメニューの識別子を確認できます。
これには現在の画面の識別子が表示され、左クリックすることでクリップボードにコピーできます。

>[!TIP]
>**レイアウトエディタ** を開いていない状態で **CTRL + ALT + D** を押すと、**デバッグオーバーレイ** を有効にできます。
