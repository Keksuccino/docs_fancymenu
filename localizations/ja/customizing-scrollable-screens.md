# スクロール可能な画面のカスタマイズ

オプション画面のようなスクロール可能な画面のカスタマイズは少し難しい場合があります。FancyMenu はスクロール領域の中身を「見る」ことも、カスタマイズすることもできないためです。

一部のスクロール可能な画面では、スクロール領域内のウィジェットを公開することでカスタマイズ可能にできます。これは実験的な機能であり、すべての画面で動作するわけではありません。

特定の画面でこの公開機能を有効にするには、**メニューバー -> カスタマイズ -> 現在の画面のスクロール領域の内容を公開** をクリックします。この機能をすべての画面に一括で有効にすることはできません。また、シングルプレイヤーやマルチプレイヤーのメニューのように、そもそも有効化できない画面もあります。

この機能を有効にすると、スクロール領域内のすべてのウィジェットが画面の左上にまとめて表示されます。これは仕様であり、バグではありません。その後、**現在の画面用の**レイアウトを開くと、エディタ上でこれらのウィジェットを確認し、編集（移動、サイズ変更など）できるはずです。

この機能を使う際に最も重要なのは、スクロール領域のウィジェットを公開すると、元のスクロール領域が画面から**削除**され、スクロール領域内にある通常のウィジェットではないものはすべて**失われる**という点です。そのため、公開機能が有効な間は表示も操作もできません。
