# スクロール可能な画面のカスタマイズ

Options 画面のようなスクロール可能な画面のカスタマイズは少し難しい場合があります。FancyMenu はスクロール領域内のコンテンツを「見る」ことも、カスタマイズすることもできないためです。

FancyMenu v3.6.0 以降では、特定の画面のスクロール領域内にあるウィジェットを自動的に公開することで、一部の画面をカスタマイズ可能にできます。これは非常に強力ですが、かなり実験的でもあるため、すべての画面で動作するわけではありません。

特定の画面で公開機能を有効にするには、**メニューバー -> Customization -> Expose Scroll Area Content Of Current Screen** をクリックします。この機能をすべての画面で一括して有効にすることはできず、Singleplayer や Multiplayer メニューのように、まったく有効にできない画面もあります。

この機能を有効にすると、スクロール領域内で見つかったすべてのウィジェットが画面の左上にまとめて配置されます。これは仕様であり、不具合ではありません。その後、**現在の画面用の**レイアウトを開くと、エディタ内でこれらのウィジェットを表示して編集（移動、サイズ変更など）できるはずです。

この機能を使う際に最も重要なのは、スクロール領域のウィジェットを公開すると、画面から元のスクロール領域が**削除**されることです。また、スクロール領域内の通常のウィジェットではない要素はすべて**失われる**ため、公開機能が有効な間は表示も操作もできなくなります。
