# メニュー内のテキスト

FancyMenu では、**テキスト**要素を使ってメニュー/画面にテキストコンテンツを追加できます。

この要素はスクロール可能で、完全な Markdown サポートと折り返しに対応しているため、複雑なテキストでも非常に強力に表示できます。もちろん、シンプルな1行テキストにも最適です。

# テキストコンテンツ

テキスト要素は、さまざまな方法でコンテンツを取得できます。テキストコンテンツのソースとして、直接入力したプレーンテキスト、FancyMenu の `assets` フォルダ内にあるローカルテキストファイル（`/config/fancymenu/assets/`）、Web 上のテキストファイル（URL 経由）、またはリソースパック経由で読み込まれるローカルテキストファイルを設定できます。

Web ソースをテキストソースとして使う方法は、たとえば常に最新の状態を保ちたい変更履歴やニュースティッカーなどを、Modpack の更新をリリースせずに実現したい場合に特に便利です。

FancyMenu はテキストソースのコンテンツをキャッシュするため、毎回内容を取得し直す必要がありません（これはパフォーマンス上、非常に良くありません）。このキャッシュは現在のセッション中のみ有効で、ゲームを再起動するとクリアされます。また、**メニューバー -> カスタマイズ -> FancyMenu を再読み込み** から FancyMenu を再読み込みすることでもキャッシュをクリアできます。

# プレースホルダー

テキスト要素は FancyMenu のプレースホルダーシステムにも対応しており、テキストコンテンツを動的にし、メニュー・ワールド・プレイヤーなどのさまざまな変化に反応させることができます。

# Markdown のカスタマイズまたは無効化

見出しの色など、Markdown に関連する設定をカスタマイズしたい場合は、テキスト要素を**右クリック**して **Markdown** をクリックしてください。開いたサブコンテキストメニューで、Markdown パーサーの見た目や動作をカスタマイズするための多くのオプションが表示されます。

Markdown の解析自体が不要で、長いテキストコンテンツのパフォーマンスを向上させたい場合は、テキスト要素を**右クリック**したときに開く **Markdown** メニューで Markdown を完全に無効化できます。

# 折り返しの無効化

折り返しが不要な場合は、テキスト要素を**右クリック**することで無効化できます。

# スクロールの無効化とスクロールつまみの非表示

テキスト要素はデフォルトでスクロール可能であり、要素がユーザーに全コンテンツを表示するためにスクロールが必要だと判断すると、テキスト要素の右側と下側にスクロールバー/つまみを表示します。これは小さな灰色の半透明バー（角が丸い）で、縦方向と横方向のスクロールバーとして表示されます。スクロールつまみは、影と見間違えられることもあります。

これらのつまみは、要素を**右クリック**したときに開くメニューで **Scrolling** をオフにすることで無効化できます。これにより、つまみだけでなくスクロール自体が無効になります。つまみを見えなくしつつスクロールは可能なままにしたい場合は、要素を右クリックしてカスタムのスクロールつまみテクスチャを設定できます。そこに完全に透明なテクスチャを設定してください。

# Minecraft の生コンポーネントテキスト形式（シリアライズ済み JSON コンポーネント）

テキスト要素は Minecraft の生コンポーネント形式に対応していません。この形式に対応しているのはボタンとスライダーのラベルのみです。
