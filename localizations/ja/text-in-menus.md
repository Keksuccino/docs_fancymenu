# メニュー内のテキスト

FancyMenu では、**Text** 要素を使ってメニューや画面にテキストコンテンツを追加できます。

この要素はスクロール可能で、Markdown を完全にサポートし、折り返しにも対応しているため、複雑なテキストコンテンツの表示にも非常に強力です。もちろん、短い一文の表示にも便利です。

## テキストコンテンツ

Text 要素は、さまざまな方法でコンテンツを取得できます。テキストコンテンツのソースを設定でき、直接入力するプレーンテキスト、FancyMenu の `assets` フォルダ内のローカルテキストファイル（`/config/fancymenu/assets/`）、Web 上のテキストファイル（URL 経由）、またはリソースパック経由で読み込まれるローカルテキストファイルを使用できます。

テキストソースとして Web ソースタイプを使うと、更新のたびに MOD パックを再配布しなくても、常に最新の変更ログやニュースティッカーのようなものを作れるので特に便利です。

FancyMenu はテキストソースの内容をキャッシュするため、毎回コンテンツを取得し直す必要がありません（パフォーマンス上、これは望ましくありません）。キャッシュは現在のセッション中のみ保持されるため、ゲームを再起動するとキャッシュは消去されます。**メニューバー -> Customization -> Reload FancyMenu** から FancyMenu を再読み込みしてもキャッシュをクリアできます。

## プレースホルダー

Text 要素は FancyMenu のプレースホルダーシステムにも対応しており、テキストコンテンツを動的にし、メニュー、ワールド、プレイヤーなどのさまざまな変化に反応させることができます。

## Markdown のカスタマイズまたは無効化

見出しの色など、Markdown に関連する見た目をカスタマイズしたい場合は、Text 要素を**右クリック**して **Markdown** をクリックしてください。開いたサブコンテキストメニューで、Markdown パーサーの外観や動作をカスタマイズするための多くのオプションが表示されます。

Markdown の解析がまったく不要で、長いテキストコンテンツのパフォーマンスを向上させたい場合は、Text 要素を**右クリック**したときに開く **Markdown** メニューで Markdown を完全に無効化できます。

## 行の折り返しを無効化

行の折り返しが不要な場合は、Text 要素を**右クリック**して無効化できます。

## スクロールを無効化

Text 要素は既定でスクロール可能で、要素がすべてのコンテンツを表示するためにスクロールが必要だと判断すると、Text 要素の右側と下側にある小さな灰色のバー（縦スクロールバーと横スクロールバー）を表示します。

**右クリック**で開くメニューで **Scrolling** をオフにすると、これらのバーを無効化できます。これにより、バーだけでなくスクロール機能全体が無効になります。バーを非表示にしたいだけの場合は、要素を右クリックしてカスタムのスクロールバー テクスチャを設定できます。そこに完全に透明なテクスチャを指定してください。

## Minecraft の生コンポーネントテキスト形式（シリアライズ済み JSON コンポーネント）

Text 要素は Minecraft の生コンポーネント形式には対応していません。この形式に対応しているのは、ボタンとスライダーのラベルのみです。
