# メニュー内のテキスト

FancyMenu では、**Text** エレメントを使ってメニューや画面にテキストコンテンツを追加できます。

このエレメントはスクロール可能で、Markdown を完全にサポートし、折り返しにも対応しているため、複雑なテキストでも非常に柔軟に表示できます。もちろん、簡単な1行テキストの表示にも最適です。

# テキストコンテンツ

Text エレメントは、さまざまな方法で内容を取得できます。テキスト内容のソースを設定でき、直接入力したプレーンテキスト、FancyMenu のアセットディレクトリ内のローカルテキストファイル (`<game-directory>/config/fancymenu/assets/`)、Web 上のテキストファイル（URL 経由）、またはリソースパック経由で読み込まれるローカルテキストファイルを指定できます。

テキストソースとして Web ソースを使う方法は、更新しなくても常に最新に保ちたい変更履歴やニュースティッカーのようなものを作る場合に特に便利です。Modpack を更新リリースする必要がありません。

FancyMenu はテキストソースの内容をキャッシュするため、毎回内容を取得し直す必要がありません（これはパフォーマンスにとって非常に悪いためです）。このキャッシュはアクティブなセッション中のみ保持されるので、ゲームを再起動するとクリアされます。また、**メニューバー -> カスタマイズ -> FancyMenu を再読み込み** から FancyMenu を再読み込みして、キャッシュを消去することもできます。

# プレースホルダー

Text エレメントは FancyMenu のプレースホルダーシステムにも対応しており、テキスト内容を動的にし、メニュー、ワールド、プレイヤーなどのさまざまな変化に反応させることができます。

# Markdown のカスタマイズまたは無効化

見出しや Markdown に関連するその他の要素の色をカスタマイズしたい場合は、Text エレメントを**右クリック**して **Markdown** をクリックしてください。開いたサブコンテキストメニューで、Markdown パーサーの見た目や動作をカスタマイズするための多くのオプションが表示されます。

Markdown の解析をまったく使いたくない場合は、長いテキストコンテンツのパフォーマンスを改善できることがあります。Text エレメントを**右クリック**したときに開く **Markdown** メニューで、Markdown を完全に無効化できます。

# 行折り返しの無効化

行折り返しを使いたくない場合は、Text エレメントを**右クリック**して無効化できます。

# スクロールの無効化とスクロールつまみの非表示

Text エレメントはデフォルトでスクロール可能で、要素が「すべての内容を表示するにはスクロールが必要」と判断すると、スクロールバー／つまみを表示します。これらは Text エレメントの右側と下側に表示される、小さな半透明のグレーのバー（角が丸い）です（縦および横のスクロールバー）。このスクロールつまみは、影と見間違えられることもあります。

これらのつまみは、要素を**右クリック**したときに開くメニューで **Scrolling** をオフにすることで無効化できます。これにより、つまみだけでなくスクロール全般が無効になります。スクロールは使えるまま、つまみだけを見えなくしたい場合は、要素を右クリックしてカスタムのスクロールつまみテクスチャを設定できます。ここでは完全に透明なテクスチャを設定してください。

# Minecraft の Raw Component Text 形式（シリアライズされた JSON コンポーネント）

Text エレメントは Minecraft の raw component 形式には対応していません。この形式に対応しているのは、ボタンとスライダーのラベルのみです。
