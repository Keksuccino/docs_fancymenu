# 要件

要件とは、「マウスカーソルがこのボタンの上にある」「12月である」「ワールドが読み込まれている」などの条件です。次のような用途に使えます。

- [要素](/elements)を必要なときだけ表示する
- レイアウト全体を必要なときだけ読み込む
- ボタン、スライダー、チェックボックスを必要なときだけクリック可能にする
- [アクションスクリプト](/action-scripts)の一部を必要なときだけ実行する

FancyMenuはメニューが開いている間、常に要件を確認します。そのため、表示・非表示や変更がすぐに反映されます。この情報ボックスは、マウスカーソルが「マルチプレイ」の上にあるときだけ表示されます。

<img width="800" alt="タイトル画面のマルチプレイボタンにマウスカーソルを合わせると、横にサーバーアドレスの情報ボックスが表示される" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/requirements_hover.gif?raw=true">

# 場所

| 場所 | 要件の動作 |
|---|---|
| 要素を右クリック -> **読み込み要件** | 条件を満たしている間だけ要素が表示されます。[バニラ要素](/vanilla-elements)にも使えます。 |
| エディターの背景を右クリック -> **読み込み要件 [レイアウト全体]** | 条件を満たしている間だけレイアウト全体が読み込まれます。[レイアウト全体の要件](#レイアウト全体の要件)を参照してください。 |
| ボタン、スライダー、チェックボックスを右クリック -> **コントロールの有効状態** | 条件を満たしている間だけクリックできます。満たしていない場合はグレー表示になります。バニラのボタンにも設定できます。 |
| [アクションスクリプト](/action-scripts#statements)内のIF、ELSE-IF、WHILE | 条件を満たしている間だけ、内部のアクションが実行されます。 |

レイアウトエディターでは、編集できるように要素が常に表示されます。要素の要件はエディターの外で機能します。

> [!TIP]
> [要素の表示設定](/element-visibility)では、遅延、フェード、ボタンによる切り替えなど、要素を表示・非表示にする別の方法を紹介しています。

# 要件を追加する

<img width="800" alt="マルチプレイボタンのIDをコピーし、要件の管理で情報ボックスにそのIDを使った「要素にマウスカーソルが乗っている」要件を設定する" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/requirements_add.gif?raw=true">

1. 要素を右クリックし、**読み込み要件**をクリックします。**要件の管理**が開きます。
2. 空のリストを右クリックして**要件を追加**をクリックするか、`A`を押します。
3. **利用可能な要件**でカテゴリーをクリックするか、名前や説明を検索するために入力を始めます。選択した要件の説明は**要件の説明**に表示されます。
4. **次のステップ**をクリックして値を設定します。値が不要な要件の場合は、代わりに**完了**が表示されます。要件をダブルクリックしても同じ操作ができます。
5. 値を入力して**完了**をクリックします。たとえば、**要素にマウスカーソルが乗っている**では要素のIDが必要です。エディターで要素を右クリックして**要素IDをコピー**をクリックすると取得できます。
6. **要件の管理**で**完了**をクリックします。

## 要件モード

要件選択画面の**要件モード**ボタンで、次のモードを切り替えます。

- **通常**: 条件が真の場合に満たされた状態になります。
- **反転**: 条件が真ではない場合に満たされた状態になります。たとえば、**ワールドが読み込まれている**を反転モードにすると、メインメニューでのみ満たされます。

**要件の管理**には、それぞれの要件のモードと値が表示されます。

## 値

- 値では[プレースホルダー](/placeholders)と[変数](/variables#showing-variables-in-text)が使えます（例: `$$coins`）。FancyMenuは要件を確認するたびに、これらを値に置き換えます。
- 多くの値フィールドでは入力中に候補が表示されます。候補にはバイオーム、Mod ID、言語、変数名などがあります。候補をクリックするか、`Tab`を押して選択します。
- 単純な値を入力する要件では、1行のテキストエディターが開きます。タイトルには、**対象要素ID**のように入力内容が表示されます。

## 要件を管理する

**要件の管理**でリスト、要件、グループを右クリックすると、次の操作を選べます。

| 操作 | ショートカット | 内容 |
|---|---|---|
| **要件を追加** | `A` | 要件を追加します。 |
| **グループを追加** | `G` | グループを追加します（下記参照）。 |
| **要件を編集** | `Enter`またはダブルクリック | 種類、モード、値を設定する要件選択画面を開きます。 |
| **要件を削除** / **グループを削除** | `Delete` | 要件またはグループを削除します。 |
| **元に戻す** / **やり直す** | `Ctrl + Z` / `Ctrl + Y` | このウィンドウ内の変更を元に戻す、またはやり直します。 |
| **AI用に要件をエクスポート** | | 未保存の変更も含め、このウィンドウの要件を[AIチャット](/export-for-ai)用にエクスポートします。 |

`上`と`下`で、1つ上または下の要件を選択します。**完了**（`Ctrl + S`）で保存し、**キャンセル**ですべての変更を破棄します。macOSでは`Ctrl`の代わりに`Cmd`を使います。

複数の要素を選択した状態で**読み込み要件**を開くと、選択中のすべての要素の要件が変更されます。異なる要件が設定されている場合は、すべて置き換わるため、FancyMenuが確認を求めます。

# 要件を組み合わせる

**要件の管理**にある要件は、すべて満たす必要があります。「これ、またはあれ」のような条件を作るには、グループを使います。

グループは1つの要件のように機能します。

- **And**モード: グループ内の条件をすべて満たす必要があります。新しいグループはこのモードで作成されます。
- **Or**モード: グループ内の条件のうち、1つを満たせば十分です。

1. リストを右クリックして**グループを追加**をクリックするか、`G`を押します。グループには`group_1`のような名前が付きます。
2. グループを右クリックして**グループモード**をクリックし、**And**と**Or**を切り替えます。
3. **グループ要件を編集**をクリックするか、グループをダブルクリックします。**要件の管理**に似たウィンドウが開きます。
4. グループに要件を追加し、**完了**をクリックします。

たとえば、12月、またはプレイヤーが`xmas_lights`をオンにしたときに表示するクリスマスの挨拶を作成できます。**現実の月**が`12`である要件と、変数`xmas_lights`の値が`on`である**変数の値（FM変数）**を含むOrグループを作成します。

<img width="800" alt="要件の管理でグループを追加し、Orに切り替えて、「現実の月」と「変数の値（FM変数）」を追加する" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/requirements_group.gif?raw=true">

- 「(A and B) or (C and D)」のように、グループの中に別のグループを入れることもできます。ウィンドウのタイトルには、`Edit Group: group_1 › group_2`のように現在の場所が表示されます。
- **グループ識別子を編集**でグループ名を変更できます。グループ内も含め、それぞれの名前は1回しか使えません。
- **Or**モードの空のグループは、条件を満たしません。

# レイアウト全体の要件

レイアウト全体の要件は、レイアウト全体を読み込むかどうかを決めます。タイトル画面の夜間バージョン、言語ごとのレイアウト、シングルプレイでのみ表示するレイアウトなどに使えます。

エディターの背景を右クリックして**読み込み要件 [レイアウト全体]**をクリックします。**メニューバー -> レイアウト -> レイアウトのプロパティ**からも開けます。

- メニューを開いている間に条件の結果が変わると、FancyMenuはその時点で条件を満たしているレイアウトを使って画面を再構築します。
- [汎用レイアウト](/universal-layouts)でも機能します。
- ボタンでレイアウトを切り替えるには、ボタンを別のレイアウトに配置します。[レイアウトを切り替える](/element-visibility#turning-layouts-on-and-off)を参照してください。

# 知っておくと便利なこと

- ワールドが読み込まれていない間（メインメニューなど）は、ワールドとプレイヤーに関する要件は満たされません。
- 要素、マウスカーソル、インベントリ、プレイヤー、ワールドに関する要件は、[Ticker](/elements#ticker)で**非同期**をオンにすると機能しません。その場合、FancyMenuは要件名を含むエラーを表示します。
- 削除したアドオンの要件は無視されます。エディターでレイアウトを保存すると、それらは完全に削除されます。
- **メニューバー -> カスタマイズ -> 設定 -> 要件のキャッシュ期間 [MS]**では、要件の結果を指定したミリ秒間再利用します。大きなレイアウトの処理を高速化できます。`0`にすると無効になり、これがデフォルトです。キャッシュを有効にすると、アクションスクリプトや素早い変更が予想外の動作をすることがあります。

# すべての要件

要件は要件選択画面と同じく、カテゴリーごと、その後に名前順で並んでいます。カテゴリーのない要件は、選択画面の一番下と、ここでは[その他](#other)にあります。

## GUI

### アクティブなカーソルの種類

**識別子:** `is_active_cursor_type`

リンク上の**指差しカーソル**やテキスト欄上の**入力カーソル**など、マウスカーソルが特定の形になっている間に条件を満たします。

- 値: **カーソルの種類**をクリックし、**通常**、**入力カーソル**、**十字カーソル**、**指差しカーソル**、**水平リサイズ**、**垂直リサイズ**、**斜めリサイズ（NWSE）**、**斜めリサイズ（NESW）**、**全方向リサイズ**、**禁止**から選択します。

### いずれかのボタンにカーソルが乗っている

**識別子:** `fancymenu_visibility_requirement_is_any_button_hovered`

バニラまたはカスタムの、表示中のいずれかのボタンにマウスカーソルが乗っている間に条件を満たします。

### いずれかの要素にカーソルが乗っている

**識別子:** `fancymenu_visibility_requirement_is_any_element_hovered`

ボタンに限らず、表示中のいずれかの要素にマウスカーソルが乗っている間に条件を満たします。

### いずれかの画面が開いている

**識別子:** `is_any_screen_open`

一時停止メニューやインベントリなど、何らかのメニューが開いている間に条件を満たします。メニューを開かずにプレイしている間は満たされません。

### ボタンが有効

**識別子:** `fancymenu_visibility_requirement_is_button_active`

ボタンがクリック可能な間に条件を満たします。

- 値: ボタンの[要素ID](/element-identifiers)。エディターで右クリックし、**要素IDをコピー**をクリックします。

### カスタマイズメニューバーが表示されている

**識別子:** `is_customization_menu_bar_visible`

FancyMenuのメニューバーが表示されている間に条件を満たします。Modpackモード中、またはメニューバーが無効な場合は満たされません。

### 要素にフォーカスがある

**識別子:** `is_element_focused`

要素にフォーカスがある間に条件を満たします。ボタンやスライダーは、クリックしたとき、または矢印キーや`Tab`で移動したときにフォーカスを得ます。キー操作による移動は、マウスカーソルを合わせた状態とはみなされません。キーボードを使うプレイヤーにも対応するには、この要件と**要素にマウスカーソルが乗っている**を[Orグループ](#要件を組み合わせる)に入れてください。

- 値: [要素ID](/element-identifiers)。例: `mc_titlescreen_multiplayer_button`。

### 要素にマウスカーソルが乗っている

**識別子:** `fancymenu_visibility_requirement_is_element_hovered`

マウスカーソルが要素の上にある間に条件を満たします。要素は表示されている必要があります。

- 値: [要素ID](/element-identifiers)。例: タイトル画面のマルチプレイボタンなら`mc_titlescreen_multiplayer_button`です。エディターで要素を右クリックし、**要素IDをコピー**をクリックして取得します。

### スクロール領域の末尾までスクロールされている

**識別子:** `is_scroll_area_scrolled_to_end`

[スクロール可能領域](/scrollable-areas)またはテキスト要素が一番下までスクロールされていると条件を満たします。スクロールする内容がない要素も、末尾までスクロールされたものとみなされます。プレイヤーがルールを最後まで読んだ後にのみ有効になる**承諾**ボタンなどに便利です。

- 値: スクロール可能領域またはテキスト要素の[要素ID](/element-identifiers)。

### GUIスケール

**識別子:** `fancymenu_loading_requirement_is_gui_scale`

MinecraftのGUIスケールが一致すると条件を満たします。

- 値: `2`のように指定するとそのスケールと完全一致し、`>2`なら2より大きく、`<4`なら4より小さい値に一致します。`<3.5`のように小数も使えます。
- 複数の条件はカンマで区切ります。単独の数値は、そのうち1つが一致すれば十分です（例: `2,3`）。`>`と`<`の条件はすべて一致する必要があります（例: `>1,<4`）。

### キーが押されている

**識別子:** `is_key_pressed`

キーを押し続けている間に条件を満たします。キーを押すたびに一度だけアクションを実行するには、代わりに[**キーボードキーが押されたとき**](/listeners#on-keyboard-key-pressed)リスナーを使います。

- 値: **キー選択**の**キーを変更**をクリックし、キーを押します。

### レイアウトが有効

**識別子:** `fancymenu_visibility_requirement_is_layout_enabled`

レイアウトが有効な間に条件を満たします。

- 値: `winter_title_screen`のようなレイアウト名。

### Minecraftのデバッグ表示が有効

**識別子:** `is_debug_overlay_enabled`

F3のデバッグ画面が表示されている間に条件を満たします。F1でHUDを非表示にしている間は満たされません。

### Modpackモードが有効

**識別子:** `is_modpack_mode_enabled`

FancyMenuのModpackモードが有効な間に条件を満たします。

### 画面タイトル

**識別子:** `is_menu_title`

開いている画面のタイトルが「設定」や「ゲームメニュー」などと一致すると条件を満たします。これはプレイヤーに表示されるタイトルであり、[画面識別子](/screen-identifiers)ではありません。

- 値: タイトル文字列またはその翻訳キー（例: `options.title`）。値のウィンドウには編集中の画面の両方が表示され、翻訳キーの候補も表示されます。
- 翻訳キーはすべての言語で機能します。タイトル文字列は完全一致する必要があります。

## 現実の時刻

プレイヤーのコンピューターの時計を確認します。複数の値はカンマで区切ります。いずれか1つが一致すれば条件を満たします。

### 現実の日

**識別子:** `fancymenu_visibility_requirement_is_realtime_day`

月の特定の日に条件を満たします。

- 値: `1`から`31`。例: `24,25,26`。

### 現実の時

**識別子:** `fancymenu_visibility_requirement_is_realtime_hour`

特定の時間帯に条件を満たします。

- 値: `0`から`23`。夕方なら`20,21,22,23`のように指定します。

### 現実の分

**識別子:** `fancymenu_visibility_requirement_is_realtime_minute`

1時間内の特定の分に条件を満たします。

- 値: `0`から`59`。

### 現実の月

**識別子:** `fancymenu_visibility_requirement_is_realtime_month`

特定の月に条件を満たします。

- 値: `1`（1月）から`12`（12月）。クリスマスなら`12`を指定します。

### 現実の秒

**識別子:** `fancymenu_visibility_requirement_is_realtime_second`

1分内の特定の秒に条件を満たします。

- 値: `0`から`59`。

### 現実の曜日

**識別子:** `fancymenu_visibility_requirement_is_realtime_week_day`

特定の曜日に条件を満たします。

- 値: `1`（日曜日）から`7`（土曜日）。週末なら`1,7`を指定します。

### 現実の年

**識別子:** `fancymenu_visibility_requirement_is_realtime_year`

特定の年に条件を満たします。

- 値: `2027`のように西暦を指定します。

## システム

### ファイル/フォルダーが存在する

**識別子:** `fancymenu_loading_requirement_file_exists`

ファイルまたはフォルダーが存在すると条件を満たします。

- 値: `config/mymodpack/welcome_seen.txt`のように、ゲームフォルダー内のパスを指定します。`.minecraft/`で始まるパスは、デフォルトの`.minecraft`フォルダーを参照します。

### インターネット接続が利用可能

**識別子:** `is_internet_connection_available`

コンピューターがインターネットに接続されている間に条件を満たします。FancyMenuはバックグラウンドで定期的に接続を確認します。

### OSがLinux

**識別子:** `fancymenu_loading_requirement_is_os_linux`

Linuxで条件を満たします。厳密には、WindowsでもmacOSでもないすべてのシステムが対象です。

### OSがmacOS

**識別子:** `fancymenu_loading_requirement_is_os_macos`

macOSで条件を満たします。

### OSがWindows

**識別子:** `fancymenu_loading_requirement_is_os_windows`

Windowsで条件を満たします。

### スケジューラーが実行中

**識別子:** `fancymenu_visibility_requirement_is_scheduler_running`

[スケジューラー](/schedulers)が実行中に条件を満たします。

- 値: `my_scheduler`のようなスケジューラーの識別子。

## ウィンドウ

ウィンドウサイズはGUI上のピクセルではなく、ゲームウィンドウの実際のピクセル数です。要件の説明には現在のサイズが表示されます。

### 全画面表示

**識別子:** `fancymenu_loading_requirement_is_fullscreen`

ゲームが全画面表示になっている間に条件を満たします。

### ウィンドウの高さ

**識別子:** `fancymenu_loading_requirement_is_window_height`

ウィンドウの高さが指定した値と一致すると条件を満たします。

- 値: `1080`のように高さを指定します。複数の高さはカンマで区切り、いずれか1つが一致すれば条件を満たします。

### ウィンドウの高さが次の値より大きい

**識別子:** `fancymenu_loading_requirement_is_window_height_bigger_than`

ウィンドウの高さが指定した値を超えている間に条件を満たします。

- 値: `1080`のように高さを指定します。

### ウィンドウの幅

**識別子:** `fancymenu_loading_requirement_is_window_width`

ウィンドウの幅が指定した値と一致すると条件を満たします。

- 値: `1920`のように幅を指定します。複数の幅はカンマで区切り、いずれか1つが一致すれば条件を満たします。

### ウィンドウの幅が次の値より大きい

**識別子:** `fancymenu_loading_requirement_is_window_width_bigger_than`

ウィンドウの幅が指定した値を超えている間に条件を満たします。

- 値: `1920`のように幅を指定します。

## ワールド

ワールドが読み込まれていない間、これらの要件は満たされません。**プレイヤーが構造物内にいる**と**襲撃エリア内にいる**を使うには、サーバーにもFancyMenuが必要です。シングルプレイでは常に機能します。

### プレイヤーに吸収ハートがある

**識別子:** `has_player_absorption_hearts`

プレイヤーに金色の吸収ハートがある間に条件を満たします。

### プレイヤーの権限レベル

**識別子:** `fancymenu_loading_requirement_has_player_permission_level`

プレイヤーがワールドまたはサーバーで、指定した権限レベル以上（オペレーターなど）を持っている間に条件を満たします。

- 値: `0`から`4`。`0`は常に条件を満たします。`/gamemode`などのコマンドには`2`で十分で、`4`は`/op`コマンドで付与されるレベルです。

## その他

### ゲームの言語

**識別子:** `fancymenu_loading_requirement_is_language`

Minecraftの言語が特定の言語である場合に条件を満たします。

- 値: `en_us`や`de_de`のような言語コード。フィールドにはすべての言語候補が表示されます。

### Modが読み込まれている

**識別子:** `fancymenu_loading_requirement_is_mod_loaded`

特定のModがインストールされている場合に条件を満たします。

- 値: `jei`のようなMod ID。フィールドにはインストール済みModのID候補が表示されます。複数のIDはカンマで区切り、すべてがインストールされている必要があります。`optifine`を指定するとOptiFineの有無を確認します。

### 数値

**識別子:** `fancymenu_visibility_requirement_is_number`

2つの数値を比較します。フィールドには`$$coins`のようなプレースホルダーや変数を入力できます。

- **比較モード**: **等しい**、**より大きい**、**より小さい**、**以上**、**以下**。
- **数値**: `$$coins`のように確認する数値を入力します。
- **比較対象の数値**: `100`のように比較する数値を入力します。

`2.5`のような小数も使用できます。フィールドの値が数値でない場合、条件は満たされません。

### リソースパックが有効

**識別子:** `is_resource_pack_enabled`

リソースパックが有効な間に条件を満たします。

- 値: リソースパック画面に表示される`Programmer Art`のようなパック名、またはIDを指定します。大文字と小文字は区別されません。

### Rinkuが読み込まれている

**識別子:** `is_rinku_loaded`

[Rinku](https://modrinth.com/mod/rinku) Modがインストールされている場合に条件を満たします。[ブラウザー要素](/elements#browser)と、古い[Rinkuベースの動画タイプ](/video#requirements)にはこのModが必要です。

### サーバーIP

**識別子:** `fancymenu_visibility_requirement_is_server_ip`

プレイヤーが特定のサーバーにいる間に条件を満たします。

- 値: `play.example.net`のようなサーバーアドレスを指定します。`play.example.net:25566`のようにポートを指定した場合、ポートも一致する必要があります。

### サーバーがオンライン

**識別子:** `fancymenu_loading_requirement_is_server_online`

サーバーがオンラインの間に条件を満たします。FancyMenuはバックグラウンドで約30秒ごとにサーバーへPingを送るため、ゲーム起動直後は判定まで少し時間がかかる場合があります。

- 値: `play.example.net`のようなサーバーアドレスを指定します。

### テキスト

**識別子:** `fancymenu_visibility_requirement_is_text`

2つのテキストを比較します。フィールドには`$$key_name`のようなプレースホルダーや変数を入力できます。

- **比較モード**: **等しい**、**含む**、**次の文字列で始まる**、**次の文字列で終わる**。
- **テキスト**: 確認するテキストを入力します。
- **比較対象のテキスト**: 比較するテキストを入力します。

大文字と小文字は区別されます。

### 変数の値（FM変数）

**識別子:** `fancymenu_visibility_requirement_is_variable_value`

[変数](/variables)の値が特定の値と一致すると条件を満たします。

- **変数名**: `$$`を付けずに変数名を入力します。フィールドには変数候補が表示されます。
- **確認する変数の値**: `on`のような値を入力します。大文字と小文字を含め、値全体が一致する必要があります。

変数が存在しない場合は条件を満たしません。リスト変数の場合は、`["apple","banana"]`のようにすべてのエントリを含むJSON配列と比較します。エントリを1つだけ確認するには、**リストにエントリが含まれる（FM変数）**を使います。

### リストにエントリが含まれる（FM変数）

**識別子:** `list_contains_entry`

[リスト変数](/variables#text-and-list-variables)に特定のエントリが含まれている場合に条件を満たします。

- **リスト変数名**: `$$`を付けずにリスト名を入力します。フィールドにはリスト変数候補が表示されます。また、テキスト変数の名前を入力すると警告が表示されます。
- **検索するエントリ**: エントリを入力します。一部ではなく、エントリ全体が一致する必要があります。
- **大文字と小文字を無視**: オンにすると、`Apple`と`apple`の両方が一致します。

リストが存在しない場合は条件を満たしません。

### マウスボタンが押されている

**識別子:** `mouse_click`

マウスボタンを押し続けている間に条件を満たします。クリックごとに一度だけアクションを実行するには、代わりに[**マウスボタンがクリックされたとき**](/listeners#on-mouse-button-clicked)リスナーを使います。

- 値: `left`または`right`。

### セッション中に一度だけ

**識別子:** `once_per_session`

最初に確認されたときに条件を満たし、その後はゲームを再起動するまで満たされません。複数設定した場合、それぞれ個別に動作します。

ゲームセッション中に一度だけ表示する要素には、要素の[**セッション中に一度だけ読み込む**](/element-visibility#load-once-per-session)オプションを使うほうが簡単です。この設定では、新しい画面が開くまで要素が表示されたままになります。
