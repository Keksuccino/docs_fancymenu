# FancyMenuでのテクスチャ最適化

FancyMenu は、あなたが提供したテクスチャをそのまま使用します。つまり、画像ファイルの圧縮、縮小、拡大は**行いません**。メニューを鮮明に見せ、快適に動作させるためには、UI でテクスチャを使う際に最適化しておくことが重要です。

# テクスチャ最適化の重要なポイント

以下のヒントは、FancyMenu でテクスチャを扱う際に覚えておくべき、基本的で最も重要な手順です。

## 1. 適切な解像度を使う
- **低解像度の画像は避ける**: 画像が小さすぎて大きな領域に引き伸ばされると、ぼやけて見えることがあります。
- **高解像度すぎる画像も避ける**: 非常に大きなテクスチャを小さく表示すると、見た目が歪んだり「変」に見えたりするほか、パフォーマンスを無駄に消費することがあります。

> 📌 **ヒント:** メニュー内で表示される解像度に近い、または同じ解像度のテクスチャを使用してください。
{.is-info}

## 2. アスペクト比を維持する
- 拡大・縮小する際は、必ず画像のアスペクト比を維持してください。
- 画像を不均等に引き伸ばすと、見た目の乱れや印象の悪化につながります。

> 📌 **ヒント:** 画像要素を右クリックして **Restore Aspect Ratio** をクリックすると、正しいアスペクト比にサイズを戻せます。その後、さらに手動でサイズ変更する場合は、**SHIFT** を押しながらリサイズすると、要素のアスペクト比を保ったまま変更できます。
{.is-info}

## 3. ナインスライスとタイリングを検討する
- パネルやボタンのような拡大可能な UI 要素には、FancyMenu の [ナインスライスとタイリング](/nine-slicing-and-tiling) 機能を使ってください。
- これにより、サイズ変更してもテクスチャの端が鮮明なまま保たれます。
