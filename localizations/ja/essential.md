# Essential

Essential は、Title 画面と Pause 画面に追加する要素の FancyMenu 連携を提供しています。

対応しているカスタマイズの手順については、[Essential の FancyMenu ガイド](https://essential.gg/wiki/fancymenu) を参照してください。

# カスタマイズの問題

Essential は FancyMenu 連携を提供しています。Essential が所有するウィジェットが見つからない場合、または通常の Minecraft ウィジェットと異なる動作をする場合は、最新バージョンで問題を再現し、影響を受けるウィジェットを管理しているプロジェクトに報告してください。
