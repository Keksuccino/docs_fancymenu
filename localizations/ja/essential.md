# Essential

最近の Essential mod のバージョンでは FancyMenu との互換性が追加されました。つまり、Essential がタイトル画面と一時停止画面に追加するすべての要素を、完全にカスタマイズできるようになっているはずです！

Essential の UI を詳しくカスタマイズする方法については、Essential wiki の [こちらの wiki ページ](https://essential.gg/wiki/fancymenu) をご覧ください！

# カスタマイズの問題

Essential の要素をカスタマイズしようとしてバグや不便な点に遭遇した場合、その原因はほとんどの場合 Essential 側にあり、Essential の開発者が修正する必要があります。

そのバグや問題は、Discord または GitHub を通じて Essential チームに報告してください。
