# Essential

[Essential](https://www.curseforge.com/minecraft/mc-mods/essential-mod) Mod は、Essential 側で FancyMenu のサポートを追加したため、以前は FancyMenu と互換性がありました。しかし、この互換性は**現在は存在しないようです**。

Essential またはランチャーのアップデート以降、Essential と FancyMenu を併用すると、レイアウトエディターで Essential の要素が表示されない、エディターを終了するとカスタマイズした Essential の要素がデフォルトに戻るなど、再び深刻な問題が報告されています。

[こちらの GitHub Issue](https://github.com/Keksuccino/FancyMenu/issues/1762) では、問題の一つについて説明されています。

> [!IMPORTANT]
> この競合・互換性の問題は、**ESSENTIAL 側**で修正する必要があります。FancyMenu に非は**ありません**。Essential のサポートを再び利用できるようにするための推奨方法は、Essential チームにこの互換性の問題を報告することです。
