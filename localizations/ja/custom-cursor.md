# カスタムマウスカーソル

レイアウトに[**カーソル**要素](/elements#cursor)を追加すると、その画面でシステムカーソルを置き換えられます。

1. **新しい要素 -> カーソル**を選択します。
2. RGBAカラーのPNGテクスチャを設定します。
3. クリック位置となるテクスチャ上のピクセルに合わせて、**ホットスポット X**と**ホットスポット Y**を設定します。
4. 編集中にカーソルを確認したい場合は、エディターのプレビューを有効にします。
5. 複数の対応画面で同じカーソルを表示する場合は、[ユニバーサルレイアウト](/universal-layouts)を使用します。

`32×32`や`64×64`など、小さなカーソルテクスチャがおすすめです。カーソルの表示や動作は、オペレーティングシステムによって異なる場合があります。
