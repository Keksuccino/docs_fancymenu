# カスタムマウスカーソル

[**Cursor** 要素](./elements#cursor)をレイアウトに追加すると、その画面のシステムカーソルを置き換えられます:

1. **New Element -> Cursor** を選択します。
2. RGBAカラーの PNG テクスチャを設定します。
3. **Hotspot X** と **Hotspot Y** を、クリックが発生するテクスチャ上のピクセル位置に設定します。
4. 編集中にカーソルを確認したい場合は、エディタのプレビューを有効にします。
5. 同じカーソルを複数の対応画面に表示したい場合は、[Universal Layout](./universal-layouts) を使用します。

`32×32` や `64×64` のような小さめのカーソルテクスチャが推奨されます。カーソルの見た目や動作は、OS によって異なる場合があります。
