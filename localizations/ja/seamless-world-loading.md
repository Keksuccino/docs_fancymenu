# シームレスなワールド読み込み

シームレスなワールド読み込みは、ワールドやサーバーを離れたときにスクリーンショットを撮影し、次回の読み込み時にその画像を背景として使用します。

これにより、読み込み完了後に表示される画面と一致するため、読み込み時の切り替えがより自然に見えます。

# 見つけ方

レイアウトエディタでは**ない**状態で FancyMenu の**メニューバー**を開き、**Customization -> Global Customizations** に進みます。

# 有効化 / 無効化

1. **Customization -> Global Customizations** を開きます。
2. **Seamless World Loading** を見つけます。
3. **Enabled** または **Disabled** に設定します。

# 動作の仕組み

- 有効にすると、FancyMenu はワールド/サーバーを離れたときにスクリーンショットを保存します。
- 次回の読み込み時、そのスクリーンショットが読み込み背景として使用されます。
- 初回使用時は、まだスクリーンショットが存在しないため、ワールド/サーバーを一度離れるまでは表示されるものがありません。
