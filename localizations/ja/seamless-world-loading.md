# シームレスなワールド読み込み

シームレスなワールド読み込みでは、ワールドまたはサーバーで最近表示した画面を、次回の読み込み画面の背景として使用します。

[**カスタマイズ -> グローバルカスタマイズ**](/global-customizations) -> **シームレスなワールド読み込み**から有効にできます。

# 仕組み

- FancyMenuは、対象のワールドまたはサーバーにいる間、現在の画面を定期的にキャプチャします。
- 退出時に最新のキャプチャが保存されます。
- ワールドとサーバーごとに、ハッシュ化されたPNGファイル名が割り当てられます。
- FancyMenuは、最近のワールドのキャプチャを最大5件、最近のサーバーのキャプチャを最大5件、事前に読み込みます。
- その対象の初回キャプチャが保存されるまでは、何も表示されません。

キャプチャは次の場所に保存されます。

```text
<game-directory>/fancymenu_data/seamless_world_loading/
```

スクリーンショットには、キャプチャ時にワールド内で見えていたものがすべて写る可能性があります。シームレスなワールド読み込みを無効にすると、キャプチャとその使用は停止しますが、既存のPNGファイルは削除されません。不要なキャプチャは、ゲームを終了した状態でディレクトリから削除してください。
