# シームレスなワールド読み込み

シームレスなワールド読み込みは、ワールドまたはサーバーの最近の表示を次の読み込み画面の背景として使用します。

[**Customization -> Global Customizations**](./global-customizations) -> **Seamless World Loading** から有効にできます。

# 動作の仕組み

- FancyMenu は、追跡対象のワールドまたはサーバーにいる間、現在のフレームを定期的にキャプチャします。
- 最後に離れたとき、最新のキャプチャが保存されます。
- 各ワールドと各サーバーには、それぞれ独自のハッシュ化された PNG ファイル名が付きます。
- FancyMenu は、最新のワールドキャプチャを最大5件、最新のサーバーキャプチャを最大5件まで事前読み込みします。
- そのターゲットに対する最初のキャプチャが保存されるまでは、何も表示されません。

キャプチャは次の場所に保存されます:

```text
<game-directory>/fancymenu_data/seamless_world_loading/
```

スクリーンショットには、キャプチャ時点でワールド内に表示されていたものがそのまま含まれる場合があります。シームレスなワールド読み込みを無効にすると、キャプチャと利用は停止しますが、既存の PNG ファイルは削除されません。不要なキャプチャは、ゲームを終了した状態でディレクトリから削除してください。
