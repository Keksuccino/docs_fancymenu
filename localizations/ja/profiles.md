# プロフィール

プロフィールは、あるインスタンスの FancyMenu の完全な設定です。すべてのレイアウト、アセット、変数、FancyMenu の設定が含まれます。プロフィールを使うと、1つの Minecraft インスタンス内に複数の設定を保存し、数秒で切り替えたり、1つのファイルとして他の人と共有したりできます。

<img width="800" alt="profiles" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/profiles_showcase.gif?raw=true">

# プロフィールウィンドウを開く

**メニューバー -> カスタマイズ -> プロフィール** からプロフィールウィンドウを開きます。

左側のリストにはすべてのプロフィールが表示され、右側には選択したプロフィールの詳細が表示されます。読み込まれているプロフィールには **アクティブ** と表示されます。FancyMenu で行った変更はすべて、読み込まれているプロフィールに直接反映されます。

既存の設定は自動的に最初のプロフィールになり、名前は **マイプロフィール** になります。

> [!TIP]
> リスト内のプロフィールを右クリックすると、そのプロフィールで実行できるすべての操作が表示されます。

# プロフィールを切り替える

プロフィールを選択して **プロフィールを読み込む** をクリックするか、プロフィールをダブルクリックします。FancyMenu が再読み込みされ、選択した設定が適用されます。

> [!NOTE]
> 切り替えによってデータが削除されることはありません。別のプロフィールを読み込む前に、現在の設定が独自のプロフィールとして保存されるため、いつでも元に戻せます。

# プロフィールを作成する

- **新しいプロフィール**（リスト下部の **+** ボタン）をクリックすると、空のプロフィールが作成され、編集画面が開きます。空のプロフィールには、UI スケールやテーマなど、個人用の FancyMenu 設定が保持されます。
- **複製** をクリックすると、選択したプロフィールのコピーが作成されます。元のプロフィールに手を加えずに試したい場合に便利です。

# プロフィールを編集する

**編集** をクリックすると、プロフィールのタイトル、バージョン、作成者、説明、アイコン、課題トラッカー、リンクを変更できます。説明には Markdown を使用でき、アイコンには任意の PNG 画像を指定できます。

**完了** をクリックするまで、変更は保存されません。

# プロフィールを共有する

> [!CAUTION]
> プロフィールにはアクションが含まれている場合があります。信頼できる入手元のプロフィールだけをインポートしてください。

## エクスポート

プロフィールを選択して **エクスポート** をクリックし、保存先を選択します。プロフィール全体を含む `.fmp` ファイルが作成されます。

## インポート

リストの下にある **インポート** をクリックして `.fmp` ファイルを選択するか、ファイルをプロフィールウィンドウにドラッグ＆ドロップします。

- インポートしたプロフィールは自動的には読み込まれません。他のプロフィールと同じように読み込んでください。
- 同じプロフィール（古いバージョンなど）がすでにある場合は、**置き換える** か **両方保持** するかを選択できます。読み込まれているプロフィールを置き換えると、インポートしたバージョンがすぐに読み込まれます。
- 新しいバージョンの FancyMenu で作成されたプロフィールには、一部が正常に動作しない可能性があるため、警告が表示されます。

## 設定フォルダーを追加する

設定によっては、`.fmp` ファイルではなく、通常の `fancymenu` フォルダーとして提供されることがあります。このようなフォルダーをプロフィールとして追加するには、希望するプロフィール名に名前を変更し、`<game-directory>/config/fancymenu/profiles/` に移動してから、プロフィールウィンドウを開きます（`profiles` フォルダーがまだ存在しない場合は作成してください）。FancyMenu が自動的にプロフィールへ追加します。

# プロフィールを削除する

プロフィールを選択して **削除** をクリックします。削除は取り消せないため、バックアップを残したい場合は、先にプロフィールをエクスポートしてください。

読み込まれているプロフィールは削除できません。先に別のプロフィールを読み込んでください。

# プロフィールの保存場所

- 読み込まれているプロフィールは、他の FancyMenu 設定と同様に `<game-directory>/config/fancymenu/` の内容です。
- その他のプロフィールはすべて `<game-directory>/config/fancymenu/profiles/` に保存されます。**フォルダーを開く** をクリックすると、プロフィールのフォルダーを開けます。

`<game-directory>` はアクティブなインスタンスのフォルダーです。`.minecraft` とは異なる場合があります。FancyMenu が `config/fancymenu/` の外部に保持する実行時状態はプロフィールに含まれません。詳しくは [データの保存場所](./data-storage-locations#persistent-runtime-state) を参照してください。
