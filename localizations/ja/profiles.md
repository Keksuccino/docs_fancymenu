# プロファイル

プロファイルは、レイアウト、アセット、変数、設定など、`config/fancymenu/` 内のすべてを含む FancyMenu の設定一式です（[データの保存場所](/data-storage-locations#your-setup)を参照）。プロファイルを使えば、1つの Minecraft インスタンスに複数の設定一式を保存し、数秒で切り替えたり、単一のファイルとして共有したりできます。

# プロファイルウィンドウ

**メニューバー -> カスタマイズ -> プロファイル**から開きます。

- 左側のリストにはすべてのプロファイルが表示されます。読み込み中のプロファイルは先頭に表示され、**アクティブ**とマークされます。FancyMenu で行った変更はすべて、そのプロファイルに直接反映されます。
- 右側には選択中のプロファイルのアイコン、タイトル、バージョン、作成者、レイアウト数、サイズ、リンク、説明が表示されます。
- リストの下にあるボタンや詳細欄のボタンは、カーソルを合わせると名前が表示されます。プロファイルを右クリックすると、その操作も表示されます。

現在の設定一式は自動的に最初のプロファイルとなり、**My Profile**という名前が付きます。

# プロファイルの読み込み

プロファイルを選択し、**プロファイルを読み込む**をクリックするか、ダブルクリックするか、`Enter`を押します。

すると、ゲーム起動後と同じように、FancyMenu がそのプロファイルで再読み込みされます。FancyMenu のほかのウィンドウはすべて閉じ、ワールドに入っていない場合はタイトル画面が開きます。

> [!NOTE]
> 読み込みによって何かが削除されることはありません。現在の設定一式は先にプロファイルとして保存されるため、いつでも元に戻せます。

# プロファイルの作成

- **新しいプロファイル**（リストの下にある`+`ボタン）をクリックすると、空のプロファイルが作成され、すぐに詳細欄が開くので名前を付けられます。UIスケールやテーマなどの FancyMenu の設定は引き継がれますが、レイアウトやその他のカスタマイズは含まれません。自動的に読み込まれることもありません。
- **複製**をクリックすると、選択中のプロファイルがコピーされます。元のプロファイルに手を加えずに試したい場合に便利です。

# プロファイルの詳細を編集

プロファイルを選択し、**編集**をクリックすると詳細を変更できます。

- **タイトル**。プロファイルに必須なのはこれだけです。
- **バージョン**と**作成者**。作成者を複数指定する場合は、カンマで区切ります。
- **説明**。[Markdown](/text-formatting#markdown)を使って、太字、見出し、リストなどを記述できます。
- **問題報告先**。プロファイルの問題を報告できるWebサイトです。**問題を報告**として表示されます。
- Discord サーバー、YouTube チャンネル、Webサイトなどへの**リンク**。**リンクを追加**をクリックしてリンクを貼り付けると、FancyMenu が自動的にプラットフォームを判別します。
- アイコン。**アイコンを選択**で PNG 画像を指定でき、**アイコンを削除**で削除できます。正方形でない画像は中央部分が切り抜かれます。

**完了**をクリックするまで、変更は保存されません。

# プロファイルの共有

> [!CAUTION]
> プロファイルは、リンクを開いたりコマンドを実行したりする操作を行う場合があります。信頼できる配布元からのみインポートしてください。

## エクスポート

プロファイルを選択し、**エクスポート**をクリックして保存先を選びます。プロファイル一式を含む`.fmp`ファイルが作成され、共有できるようになります。

## インポート

リストの下にある**インポート**をクリックして`.fmp`ファイルを選ぶか、ファイルをプロファイルウィンドウにドラッグ＆ドロップします。

- インポートしたプロファイルは自動的に読み込まれません。他のプロファイルと同じように読み込んでください。
- 古いバージョンなど、すでに同じプロファイルがある場合は、**置き換える**か**両方を残す**かを選びます。読み込み中のプロファイルを置き換えると、インポートしたプロファイルがすぐに読み込まれ、古いプロファイルへの変更は失われます。
- 新しいバージョンの FancyMenu で作成されたプロファイルには、警告が表示されます。一部の内容が動作しない可能性があるためです。
- FancyMenu からエクスポートした`.fmp`ファイルのみ使用できます。通常のフォルダーの場合は、次のセクションを参照してください。

## 設定フォルダーの追加

設定一式は、`.fmp`ファイルではなく、通常の`fancymenu`フォルダー（誰かの`config/fancymenu/`のコピー）として配布されることもあります。プロファイルとして追加するには、次の手順に従ってください。

1. `.zip`ファイルで配布されている場合は、解凍します。
2. フォルダーを`<game-directory>/config/fancymenu/profiles/`に移動します。`profiles`フォルダーがまだない場合は作成してください。
3. プロファイルウィンドウを開くか、いったん閉じてから開き直します。FancyMenu がそのフォルダーをプロファイルに追加します。

フォルダーには、別の`fancymenu`フォルダーではなく、`customization/`や`options.txt`などのファイルが直接入っている必要があります。フォルダー内に独自のプロファイル詳細がない場合、フォルダー名がプロファイルのタイトルになります。**編集**から変更できます。

## レイアウトテンプレート

[Kekscord Discord サーバー](https://discord.gg/rhayah27GC)（Keksuccino 公式の MOD サポート用 Discord サーバー）の[`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316)チャンネルには、FancyMenu や SpiffyHUD、Drippy Loading Screen などのアドオン用にコミュニティが作成した設定一式が投稿されています。各投稿には、`.fmp`ファイルまたは`fancymenu`フォルダーのダウンロードリンクがあります。

テンプレートは複雑なため、自分の設定一式と統合しようとしないでください。代わりに、独立したプロファイルとして追加します。

1. `.fmp`ファイルを[インポート](#インポート)するか、[フォルダーを追加](#設定フォルダーの追加)します。
2. プロファイルウィンドウでテンプレートを選択し、**プロファイルを読み込む**をクリックします。

自分の設定一式は別のプロファイルとして残るため、いつでも元に戻せます。

ほとんどのテンプレートは編集したり、MODパックなどの自分のプロジェクトで使用したりできますが、すべてがそうとは限りません。テンプレートをどのように利用できるか、必ず投稿で確認してください。

# プロファイルの削除

プロファイルを選択し、**削除**をクリックするか、`Delete`（macOSでは`Fn + Delete`）を押します。削除は取り消せないため、バックアップが必要な場合は先にプロファイルをエクスポートしてください。

読み込み中のプロファイルは削除できません。先に別のプロファイルを読み込んでください。

# プロファイルの保存場所

- 読み込み中のプロファイルは、`<game-directory>/config/fancymenu/`の内容です。
- それ以外のプロファイルは、`<game-directory>/config/fancymenu/profiles/`内にそれぞれ別のフォルダーとして保存されます。**フォルダーを開く**をクリックすると、選択中のプロファイルのフォルダーが開きます。

`<game-directory>`はインスタンスのフォルダーを指し、`.minecraft`とは異なる場合があります。`<game-directory>/fancymenu_data/`内のデータはプロファイルに含まれません。[データの保存場所](/data-storage-locations#instance-data)を参照してください。

# 問題が発生した場合

- **一部のファイルがまだ使用中です：**ゲーム自体が音声などを読み込んでいる場合によく発生します。数秒待ってからもう一度試してください。何度も発生する場合は、ウイルス対策ソフト、クラウド同期ソフト、ファイルエクスプローラーのウィンドウなど、ファイルを使用している可能性のあるプログラムを閉じてください。
- **前回のプロファイル切り替えがまだ完了していません：**データが失われたわけではありません。もう一度プロファイルを読み込むか、ゲームを再起動して切り替えを完了してください。
- **ディスクの空き容量が不足しています：**メッセージに必要な空き容量が表示されます。空き容量を増やしてから、もう一度試してください。
- プロファイルの操作は一度に1つずつ実行されます。大きなプロファイルのエクスポート、インポート、複製には時間がかかることがあるため、処理中は**キャンセル**ボタンが表示されます。
