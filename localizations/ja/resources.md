# リソース

FancyMenu のリソースシステムでは、Minecraft 本体のリソースローダー（**リソースパック**）、**ローカル**リソース（クライアント側システム上のファイル）、および **Web** ソース（オンラインに保存されたファイル）からリソースを使用できます。

画像、音声、動画、テキストなど、ほぼすべてのリソース入力は FancyMenu のリソース選択画面で設定します。プレースホルダーやアクションのソースパスを設定する場合のような例外もありますが、ほとんどの場面では同じリソース選択インターフェースからリソースを設定します。

リソース選択インターフェースからリソース入力を設定すると、基本的にはいわゆる「リソースソース」（FancyMenu での呼び方）を選ぶことになります。これはソースの種類に応じて、パス、リンク、またはリソースロケーションになります。

FancyMenu 3.9.0 では、リソース選択画面に Minecraft リソースブラウザが追加されました。これにより、リソースロケーションを毎回手入力する代わりに、リソースパック経由で読み込まれたリソースをディレクトリのように参照できます。

# Minecraft のリソース（リソースパック）

Minecraft では、リソースを「指し示す」ためにいわゆる「リソースロケーション」を使用します。

テキストとして書かれたリソースロケーションは、コロン (`:`) で区切られた 2 つの部分で構成されます。
最初の部分は **名前空間**、2 番目の部分は **リソースへのパス** の残りで、拡張子を含むリソース名もここに含まれます。

リソースロケーションの **名前空間** は、常にそのリソースへの完全なパスの **最上位のディレクトリ/フォルダ** です。

たとえば、`/assets/custom_resources/images/image.png` に保存された `image.png` というリソースを含むリソースパックを読み込んだとします。
この場合、リソースロケーションの **名前空間** は `custom_resources` になります。`/assets/` は Minecraft がすべてのリソースを読み込む場所にすぎないため、`custom_resources` がそのリソースの **最上位ディレクトリ** だからです。
つまり、`images/image.png` がリソースへの **残りのパス** になります。

したがって、`image.png` リソースへの正しいリソースロケーションは次のとおりです。
`custom_resources:images/image.png`

> **豆知識**: Minecraft のリソースの多くは `/assets/minecraft/` に保存されているため、ほとんどの Minecraft リソースの **名前空間** は `minecraft` です。
{.is-info}

# ローカルリソース

リソースを読み込む最も簡単な方法は、クライアント上に保存されたローカルファイル（多くの場合は modpack に同梱されるファイル）をそのまま使用することです。

FancyMenu は `/config/fancymenu/assets/` に保存されたローカルリソースのみ読み込みを許可しているため、すべてのリソースをそこに保存してください。

これにより、ほとんどの modpack システム（CurseForge、Modrinth など）が標準で mod の設定フォルダを同梱できるため、[ローカルリソースを modpack に同梱する](./modpacks) のも非常に簡単になります。

# Web リソース

modpack を更新することなくリソースを動的に変更したい場合は、**Web** リソースが最適です。

Web リソースとは、基本的にはサーバー上に保存されたファイルの **URL** のことです。たとえば `https://example-domain.net/image.png` のようなものです。

必ず **直接 URL** を使用してください。これは、上の例のようにリソースの **ファイル名と拡張子** で終わる URL のことです。
直接 URL でないものを使うとパフォーマンスが低下し、失敗しやすくなります。

# リソースソース内のプレースホルダー

FancyMenu のプレースホルダーは、ローカルソースのパス、Web ソースの URL、Minecraft リソースのリソースロケーションなど、リソースソース内で使用できます。

これにより、FancyMenu の変数を設定したときにメニュー背景の画像ソースを変更し、変数の値に応じて別の背景を表示する、といった動的なソース更新が可能になります。

ソースは、リソースソース入力欄の右側にある **エディターで開く** ボタンをクリックすると、手動で編集できます。

> これは通常のリソース選択インターフェースを使用するリソース入力にのみ適用されます。選択画面を使用しない *一部* のリソース入力では、プレースホルダーを **サポートしない** 場合や、プレースホルダーが変化しても動的に更新されない場合があります。
{.is-warning}
