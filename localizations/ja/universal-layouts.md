# ユニバーサルレイアウト

ユニバーサルレイアウトは、画面のカスタマイズが有効になっているすべての対応画面に適用されます。[ブロックされている画面](./incompatibility-list#screens-where-customization-is-intentionally-disabled)や、その他の理由で除外されている画面には適用されません。

ユニバーサルレイアウトは、ロゴ、ナビゲーション、オーバーレイ、複数の画面にわたって表示し続けたい[オーディオ要素](./elements#audio)など、共有要素に使用します。

# 作成方法

1. 対応画面を開き、FancyMenuのメニューバーを表示します。
2. **Layouts -> New -> For All Screens [Universal]** を選択します。
3. 要素を追加して設定します。
4. レイアウトを保存します。

通常の画面では、引き続き **Current Screen Customization** を有効にする必要があります。対応していないModの画面はカスタマイズすると正常に動作しなくなる可能性があるため、すべての画面を一括で有効にするグローバル設定はありません。

# 画面の制限

エディターの背景にあるコンテキストメニューから、ユニバーサルレイアウトの設定を開きます。

- **Whitelist:** リストに記載された画面識別子にのみレイアウトを適用します。
- **Blacklist:** リストに記載された画面識別子を除く、適用可能なすべての画面にレイアウトを適用します。

**Customization -> Copy Identifier of Current Screen** を使用すると、[画面識別子](./screen-identifiers)をコピーできます。

[レイアウト全体に適用される要件](./conditions#layout-wide-requirements)を追加して、レイアウトを適用するタイミングを制御することもできます。

# レイアウトの順序

適用可能なユニバーサルレイアウトと画面固有のレイアウトは、**Layout Index** によって結合され、順番に重ねて適用されます。インデックスが小さいものから先に適用され、後から適用される重ね合わせ可能な設定によって、先の設定を上書きできます。同じインデックスの場合、ユニバーサルレイアウトが画面固有のレイアウトより先にまとめられます。
