# ユニバーサルレイアウトとは？

ユニバーサルレイアウトは FancyMenu の強力な機能で、1つの特定の画面だけでなく、**複数の画面**に適用できるレイアウトを作成できます。これにより、ゲーム全体で一貫して表示される UI 要素を作るのに非常に便利です。

ユニバーサルレイアウトは、ゲーム内のどこにでも表示できる「グローバル」なレイアウトだと考えてください。

# なぜユニバーサルレイアウトを使うのか？

ユニバーサルレイアウトは、次のような場合にとても役立ちます。

- すべての画面に同じ背景を追加する
- 多くの画面に表示されるロゴやテキストを作る
- オーディオ要素を複数の画面にわたって再生し続ける
- ゲーム全体で一貫した見た目と操作感を作る

# ユニバーサルレイアウトの仕組み

ユニバーサルレイアウトを作成すると、デフォルトではゲーム内の**すべての画面**で読み込まれます。つまり、ユニバーサルレイアウトに追加した要素（ボタン、画像、テキストなど）は、すべての画面に表示されます。

でも心配はいりません！ユニバーサルレイアウトを特定の画面だけに読み込むようにすることもできます。その場合は、下の **ブラックリスト** と **ホワイトリスト** の項目を確認してください。

# ユニバーサルレイアウトの作成

1. ゲーム内の任意の画面を開く
2. **Ctrl+Alt+C** を押してカスタマイズメニューを表示する
3. **Layouts → New → For All Screens [Universal]** に移動する
4. 画像、テキスト、ボタンなどの要素を使ってレイアウトを作成する
5. 分かりやすい名前を付けてレイアウトを保存する

# ユニバーサルレイアウトを表示する画面の管理

## ブラックリストを使う

ブラックリストを使うと、ユニバーサルレイアウトを**表示したくない**画面を指定できます。

1. レイアウトエディタで背景を右クリックする
2. **Layout Settings → Universal Layout Options** を選択する
3. **Add Screen To Blacklist** をクリックする
4. 画面識別子を入力する（例: タイトル画面なら `title_screen`）

これで、ブラックリストに入れた画面**以外**のすべてにユニバーサルレイアウトが表示されます。

## ホワイトリストを使う

ホワイトリストはブラックリストの逆で、ユニバーサルレイアウトを**特定の画面だけ**に表示します。

1. レイアウトエディタで背景を右クリックする
2. **Layout Settings → Universal Layout Options** を選択する
3. **Add Screen To Whitelist** をクリックする
4. レイアウトを表示したい各画面の識別子を入力する

ホワイトリストを使用すると、ユニバーサルレイアウトは、一覧に入れた画面に**のみ**表示されます。

# 画面識別子の見つけ方

ホワイトリストやブラックリストに画面を追加するには、その識別子を知っている必要があります。

1. 識別したい画面に移動する
2. **Ctrl+Alt+C** を押してカスタマイズメニューを開く
3. **Customization → Copy Identifier of Current Screen** をクリックする
4. 識別子がクリップボードにコピーされる

この識別子をホワイトリストまたはブラックリストに貼り付けられます。

# すべての画面でカスタマイズを有効にする

すべての画面で一括してカスタマイズを有効にすることはできません。
これは意図された仕様であり、サポートされていない改造済み画面でカスタマイズを有効にして、誤ってゲームを壊してしまうのを防ぐためです。

# 上級者向けのヒント

## 読み込み順の管理

ユニバーサルレイアウトと画面固有のレイアウトの両方がある場合、ユニバーサルレイアウトが**最初に**読み込まれます。つまり、画面固有のレイアウトはユニバーサルレイアウトの要素を上書きできます。

## 読み込み条件

ユニバーサルレイアウトに読み込み条件を追加して、特定の条件下でのみ読み込まれるようにできます。

1. エディタ内を右クリックする
2. **Layout Settings → Layout-Wide Requirements** を選ぶ
3. 時刻、OS、その他の条件などを追加する
