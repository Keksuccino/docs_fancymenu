# ユニバーサルレイアウト

ユニバーサルレイアウトは、画面のカスタマイズが有効になっているすべての対応画面で適用対象になります。[ブロック対象](/incompatibility-list#screens-where-customization-is-intentionally-disabled)の画面や、その他の除外された画面には適用されません。

複数の画面にわたって表示したいロゴ、ナビゲーション、オーバーレイ、[オーディオ要素](/elements#audio)などの共通要素には、ユニバーサルレイアウトを使用します。

# 作成方法

1. 対応画面を開き、FancyMenuのメニューバーを表示します。
2. **Layouts -> New -> For All Screens [Universal]** を選択します。
3. 要素を追加して設定します。
4. レイアウトを保存します。

通常の画面では、引き続き **Current Screen Customization** を有効にする必要があります。カスタマイズすると未対応のMod画面で不具合が発生する場合があるため、すべての画面を一括で有効にする設定はありません。

# 適用する画面の制限

エディターの背景を右クリックして表示されるコンテキストメニューから、ユニバーサルレイアウトの設定を開きます。

- **Whitelist:** リストにある画面識別子の画面にのみレイアウトを適用します。
- **Blacklist:** リストにある画面識別子を除く、適用可能なすべての画面にレイアウトを適用します。

**Customization -> Copy Identifier of Current Screen** を使うと、[画面識別子](/screen-identifiers)をコピーできます。

また、[レイアウト全体に適用する要件](/conditions#layout-wide-requirements)を追加して、レイアウトを適用する条件を設定できます。

# レイアウトの順序

適用対象のユニバーサルレイアウトと画面固有のレイアウトは、**Layout Index** の順に組み合わされ、重ねて表示されます。インデックスの小さいものから適用され、後から適用される重ね合わせ可能な設定は、先に適用された設定を上書きできます。同じインデックスの場合、ユニバーサルレイアウトが画面固有のレイアウトより先に読み込まれます。
