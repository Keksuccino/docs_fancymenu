# AI向けエクスポート

**AI向けエクスポート**を使うと、FancyMenuの設定の一部を、[FancyMenu Discord](https://discord.gg/rhayah27GC)のヘルパーボットAliceなどのAIアシスタント向けのテキストに変換できます。チャットに貼り付ければ、AIが推測することなく、設定内容を正確に確認できます。

<img width="800" alt="Discordのサポート投稿。Aliceがエクスポートを依頼し、内容から問題を見つけて、ボタンの修正方法をプレイヤーに案内している" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/export_for_ai_chat.gif?raw=true">

# この機能がある理由

スクリーンショットでわかるのは見た目だけで、設定内容まではわかりません。アクションスクリプトや条件を手入力するのには時間がかかり、その途中で重要な情報が抜け落ちてしまうこともあります。

エクスポートには、AIに必要な情報がすべて含まれています。

- エクスポート対象のすべての設定、アクション、条件、値。
- FancyMenu、Minecraft、MODローダー、Java、システムの各バージョン。
- AIが正しく読み取れるようにするための、FancyMenuの動作に関する簡単な説明。

エクスポートは、ゲームの表示言語にかかわらず、常に英語で作成されます。ファイルパスに含まれるアカウント名は`<user>`に置き換えられるため、公開チャットでも安心して共有できます。

# 使用する場面

- ボタンを押しても何も起きない、要素が表示されないなど、期待どおりに動作しないとき。
- FancyMenuにエラーや警告が表示されたとき。
- アクションスクリプト、条件、メニュー全体などを作る手助けがほしいとき。
- ゲームで何ができるか知りたいとき。**FancyMenuでできることすべて**では、アドオンのものも含め、利用可能なすべての要素、背景、アクション、条件、プレースホルダー、リスナーを確認できます。

質問に関係するものだけをエクスポートしてください。たとえば、動作しないボタンだけをエクスポートします。エクスポートの内容を絞ると、AIが問題に集中しやすくなります。そのうえで、期待していた動作と、実際に起きたことを伝えましょう。

# エクスポート方法

以下の各項目を選ぶと、小さなメニューが開きます。

- **クリップボードにコピー**を選ぶとエクスポートがコピーされ、`Ctrl + V`（macOSでは`Cmd + V`）でチャットに貼り付けられます。
- **ファイルとして保存**を選ぶと、`<game-directory>/fancymenu_data/ai_exports/`にMarkdownファイルとして保存され、そのフォルダーが開きます。ファイルをチャットにドラッグして送信できます。チャットに収まらない大きなエクスポートには、この方法を使ってください。

レイアウトエディター、リスナーウィンドウ、スケジューラーウィンドウからのエクスポートには、まだ保存していない変更も含まれます。

# エクスポートできる場所

## メニューバー

| エクスポートされる内容 | 場所 |
|---|---|
| ウィジェットと、その画面でFancyMenuが行う処理を含む現在の画面 | **メニューバー -> カスタマイズ -> 現在の画面をAI向けにエクスポート** |
| レイアウト | **メニューバー -> カスタマイズ -> レイアウト**でレイアウトを選び、**レイアウトをAI向けにエクスポート** |
| ゲーム、ハードウェア、MODの情報、および動画やブラウザーのサポートなどFancyMenuで利用できる機能 | **メニューバー -> ヘルプ -> AI向けエクスポート -> システム情報** |
| [グローバルカスタマイズ](/global-customizations)を含むFancyMenuのすべての設定 | **メニューバー -> ヘルプ -> AI向けエクスポート -> FancyMenuの設定** |
| すべての[変数](/variables) | **メニューバー -> ヘルプ -> AI向けエクスポート -> すべての変数** |
| すべての[リスナー](/listeners) | **メニューバー -> ヘルプ -> AI向けエクスポート -> すべてのリスナー** |
| すべての[スケジューラー](/schedulers) | **メニューバー -> ヘルプ -> AI向けエクスポート -> すべてのスケジューラー** |
| すべての[カスタムGUI](/custom-guis) | **メニューバー -> ヘルプ -> AI向けエクスポート -> カスタムGUI** |
| すべての[プロファイル](/profiles) | **メニューバー -> ヘルプ -> AI向けエクスポート -> プロファイル** |
| ゲームで利用できるすべての要素、背景、アクション、条件、プレースホルダー、リスナー | **メニューバー -> ヘルプ -> AI向けエクスポート -> FancyMenuでできることすべて** |

## レイアウトエディター

| エクスポートされる内容 | 場所 |
|---|---|
| 編集中のレイアウト | エディターのメニューバーで**レイアウト -> レイアウトをAI向けにエクスポート** |
| 画面の別のレイアウト | エディターのメニューバーで**レイアウト -> 開く**を選び、レイアウトを選択してから**レイアウトをAI向けにエクスポート** |
| 1つの要素 | 要素を右クリックし、**AI向けにエクスポート**を選択 |
| 選択中のすべての要素 | エディターのメニューバーで**編集 -> 選択した要素をAI向けにエクスポート** |
| [メニュー背景](/menu-backgrounds) | エディターの背景を右クリックし、**メニュー背景**を選んで背景を選択してから、**AI向けにエクスポート** |
| [装飾オーバーレイ](/decoration-overlays) | エディターの背景を右クリックし、**装飾オーバーレイ**を選んでオーバーレイを選択してから、**AI向けにエクスポート** |

## エディターとウィンドウ

| エクスポートされる内容 | 場所 |
|---|---|
| [アクションスクリプト](/action-scripts) | アクションスクリプトエディターを右クリックし、**アクションスクリプトをAI向けにエクスポート**を選択 |
| [条件](/conditions) | **条件の管理**ウィンドウを右クリックし、**条件をAI向けにエクスポート**を選択 |
| テキスト要素の内容などのテキスト | テキストエディターを右クリックし、**テキストをAI向けにエクスポート**を選択 |
| 1つまたはすべての変数 | **メニューバー -> カスタマイズ -> 変数を管理**を開いて右クリックし、**変数をAI向けにエクスポート**または**すべての変数をAI向けにエクスポート**を選択 |
| 1つまたはすべてのリスナー | **メニューバー -> カスタマイズ -> リスナーを管理**を開き、**AI向けにエクスポート**をクリックして、**選択したリスナー**または**すべてのリスナー**を選択 |
| 1つまたはすべてのスケジューラー | **メニューバー -> カスタマイズ -> スケジューラーを管理**を開き、**AI向けにエクスポート**をクリックして、**選択したスケジューラー**または**すべてのスケジューラー**を選択 |

## エラーと警告

FancyMenuにエラーや警告が表示されたときは、**OK**の隣にある**AI向けにエクスポート**をクリックして、メッセージをエクスポートします。

## サーバー

サーバーの[FMData](/fm-data)設定とサーバーリスナー、ウェルカムデータは、コマンドでエクスポートできます。すべての`/fmdata`コマンドと同様に、権限レベル2が必要です。

```mcfunction
/fmdata export_for_ai copy
/fmdata export_for_ai file
```

- `copy`を指定するとチャットメッセージが送信されます。それをクリックするとエクスポートをコピーできます。サーバーコンソールでは、エクスポート全体が表示されます。
- `file`を指定すると、エクスポートがサーバー上の`fancymenu_data/ai_exports/`に保存されます。チャットに収まらない大きなエクスポートには、この方法を使ってください。
