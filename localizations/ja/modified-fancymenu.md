# Modified FancyMenu JAR Found

このエラーが表示された場合、Minecraft のインスタンスが壊れている、Mod ローダーが壊れている、または Mod ランチャーに問題がある可能性が高いです。

通常は FancyMenu が改変されたときに表示されますが、本来のようにゲームが Mod を正しく読み込めなかった場合にも表示されることがあります。

これは、何らかの理由で **Minecraft のインスタンスが壊れている** 可能性があり、その場合は **ゲームを再インストール** してください。

別の原因として、いくつかの Mod（FancyMenu を含む）が **正しく読み込めず**、起動時に **ゲームが半クラッシュ** している場合もあります。その場合は、Discord サーバーに `/logs/latest.log` ファイルを投稿するか、GitHub で issue を作成してください。

このエラーは、**不適切な Mod ランチャーを使用している** 場合にも発生します（多くのクラック版／海賊版ランチャーでこの不具合が発生するため、ゲームを購入してください）。FancyMenu で安定して問題なく動作する推奨ランチャーは、**公式 CurseForge ランチャー** と **公式 Modrinth ランチャー** です。
