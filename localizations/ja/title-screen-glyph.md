# タイトル画面のエメラルド／ダイヤのアイコン

タイトル画面に何度も表示される小さなアイコンを非表示にしたい場合、それが小さなダイヤやエメラルドのように見える（緑または青の小さな）アイコンであれば、これは主に Mod Menu（Fabric の mod）の更新通知、または Forge（内蔵 mod ローダー機能）の通知です。

場合によっては、Vanilla Minecraft の Realms ボタン（通知を表示するため）の一部であることもあります。

# Mod Menu のアイコンを非表示にする

Mod Menu のグリフを非表示にするには、設定で「update indicator」を無効にする必要があります。

**Mods** ボタンをクリック -> mods 一覧で Mod Menu mod のアイコンにカーソルを合わせる -> クリックする -> 「Update Indicator」を「Hidden」に設定する。

# Forge のアイコンを非表示にする

Forge は内蔵のバージョンチェッカーを使って、mods が古いときにあのエメラルド色のアイコンを表示します。これをオフにできます。

1. `config/fml.toml` ファイルを開きます。
2. `versionCheck` 設定を見つけます。
3. これを `false` に設定します: `versionCheck = false`
4. 保存して Minecraft を再起動します。

これでバージョンチェック自体が無効になり、起動時のエメラルドのグリフも非表示になります。

もう一つの方法として、FancyMenu を使って Mods ボタン全体を非表示にすることでもアイコンを隠せます。ボタンを隠せば、グリフも一緒に非表示になります。

# Vanilla の Realms アイコンを非表示にする

Mod Menu でも Forge のグリフでもない場合は、Minecraft 本体の Realms 通知アイコンである可能性が高いです。これらのアイコンは Realms ボタンのあたりに表示され、FancyMenu のレイアウトエディタで非表示にできます。現在の画面（この場合はタイトル画面）用のレイアウトを作成すると、エディタ内に Realms アイコンが独立した要素として表示されます。非表示にするには、**右クリック**して **Delete** をクリックするだけです。

Realms のアイコンには、新聞アイコン、ダイヤのグリフ、通知数付きの赤い丸など、いくつかの種類があります。
