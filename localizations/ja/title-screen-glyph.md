# タイトル画面のエメラルド／ダイヤ形アイコン

タイトル画面に何度も表示される小さなアイコンが気になる場合、それが小さなダイヤ形やエメラルド形（緑または青）のアイコンなら、これは多くの場合、Mod Menu（Fabric mod）または Forge（内蔵の mod ローダー機能）の更新通知です。

場合によっては、Minecraft バニラの Realms ボタン（通知表示用）の一部であることもあります。

# Mod Menu のアイコンを非表示にする

Mod Menu のグリフを非表示にするには、設定で「更新インジケーター」を無効にする必要があります。

**Mods** ボタンをクリック -> mods 一覧で Mod Menu のアイコンにカーソルを合わせる -> クリック -> 「Update Indicator」を「Hidden」に設定します。

# Forge のアイコンを非表示にする

Forge は、mod が古いことを示すために、組み込みのバージョンチェック機能を使ってこのエメラルド形アイコンを表示します。これをオフにできます。

1. `/config/fml.toml` ファイルを開きます。
2. `versionCheck` 設定を探します。
3. これを `false` に設定します: `versionCheck = false`
4. 保存して Minecraft を再起動します。

これでバージョンチェック全体が無効になり、起動時のエメラルド形グリフも非表示になります。

別の方法として、FancyMenu を使って Mods ボタン全体を非表示にすることでもアイコンを隠せます。ボタンを隠せば、グリフも一緒に表示されなくなります。

# NeoForge のアイコンを非表示にする

NeoForge でも、従来の Forge とまったく同じ方法で動作します。

1. `/config/fml.toml` ファイルを開きます。
2. `versionCheck` 設定を探します。
3. これを `false` に設定します: `versionCheck = false`
4. 保存して Minecraft を再起動します。

# バニラの Realms アイコンを非表示にする

Mod Menu でも Forge のグリフでもない場合は、Minecraft 標準の Realms 通知アイコンである可能性が高いです。これらのアイコンは Realms ボタン付近に表示され、FancyMenu のレイアウトエディタで非表示にできます。まず「現在の画面用」のレイアウト（この場合はタイトル画面）を作成すると、エディタ内に Realms アイコンが専用要素として表示されます。非表示にするには、その要素を**右クリック**して **Delete** をクリックします。

Realms のアイコンには、新聞アイコン、ダイヤ形グリフ、通知件数付きの赤い丸など、いくつかの種類があります。
