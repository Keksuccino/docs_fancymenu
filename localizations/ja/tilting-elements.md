# 要素を傾ける

ほとんどの要素は、垂直方向および水平方向に傾けることができます。

レイアウトエディターで要素を選択します。傾きに対応している場合は、要素の周囲にドラッグ用つまみの付いた垂直・水平のガイドが表示されます。つまみをドラッグすると、その軸に沿って要素を傾けられます。

要素にドラッグ用つまみの付いた線が表示されない場合、その要素は傾けられません。

# 詳細設定

要素を右クリックすると、直接テキスト入力で傾きの値を手動設定することもできます。この直接入力は[プレースホルダー](/placeholders)に対応しているため、プレースホルダーと組み合わせてFancyMenuの変数値などを取得すれば、要素の傾きを動的に変更できます。

# ボタン、スライダー、その他の操作可能な要素

操作可能な要素では、傾きは見た目にのみ反映されます。傾いたボタンでも、元の傾いていない状態の範囲内でクリックを受け付けます。
