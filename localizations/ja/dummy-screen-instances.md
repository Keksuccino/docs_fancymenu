# ワールド読み込み画面

ワールドに読み込むときやサーバーに参加するとき、カスタマイズできそうに見えても実際にはすぐ閉じられてしまう画面が表示されることに、たぶん気づいたことがあるでしょう。

それらを編集するには、好きなだけ開いたままにできるその画面のインスタンスを開く必要があります。これは、「ダミー画面インスタンス」を開くことで可能です。

「ダミー画面インスタンス」は FancyMenu の機能で、カスタマイズするには消えるのが早すぎる一部の画面を開けるようにするものです。

ダミー画面インスタンス機能で開けるすべての画面を確認するには、**メニューバー -> Tools -> Dummy Screen Instances** をクリックしてください。開いたメニューには、ダミー画面インスタンスとして開けるすべての画面が表示されます。メニュー内の画面を**左クリック**すると、その画面のダミーインスタンスが開き、落ち着いてカスタマイズできます。

たとえば、ワールドやサーバーに参加するとき、読み込み中に少なくとも次の2つの画面が表示されます。

- Level Loading Screen（別名: World Loading Screen）
- Generic Dirt Message Screen（別名: Dirt Message Screen）

> **重要:** 「World Loading Screen」は「Game Loading Screen」（別名: Splash Screen または Resource Reloading Screen）とは異なります。"Game Loading Screen" は、FancyMenu のアドオンである **Drippy Loading Screen** でカスタマイズできます。
