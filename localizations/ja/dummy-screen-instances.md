# ワールド読み込み画面

ワールドに入ったりサーバーに参加したりすると、たぶん編集できない画面が表示されるのに気づくでしょう。これは自動的に閉じられてしまうためです。

それを編集するには、その画面を好きなだけ開いたままにできるインスタンスを開く必要があります。これは、その画面の「ダミー画面インスタンス」を開くことで可能です。

「ダミー画面インスタンス」は FancyMenu の機能で、すぐに消えてしまうため通常は編集しづらい一部の画面を開けるようにするものです。

ダミー画面インスタンス機能で開けるすべての画面を確認するには、**メニューバー -> Tools -> Dummy Screen Instances** をクリックしてください。開くメニューには、ダミー画面インスタンスとして開けるすべての画面が表示されます。メニュー内の画面を**左クリック**すると、その画面のダミーインスタンスが開き、落ち着いてカスタマイズできます。

たとえば、ワールドやサーバーに参加すると、読み込み中に少なくとも次の2つの画面が表示されます。

- レベル読み込み画面（別名: ワールド読み込み画面）
- 汎用 Dirt メッセージ画面（別名: Dirt メッセージ画面）

> [!WARNING]
> **重要:** 「ワールド読み込み画面」は「ゲーム読み込み画面」（別名: スプラッシュ画面、またはリソース再読み込み画面）とは別物です。「ゲーム読み込み画面」は、FancyMenu のアドオンである **Drippy Loading Screen** を使ってカスタマイズできます。
