# リソースの事前読み込み

事前読み込みは、メニューで必要になる前に選択したリソースを準備しておく機能です。ちらつき、最初の1フレームが黒くなる、表示開始が遅れるといった問題があるリソースに使います。

# リソースをプリローダーに追加する

**Customization -> Pre-Load Resources** を開きます。

<br>

<img width="350" alt="Screenshot_1" src="https://github.com/Keksuccino/FancyMenu/assets/35544624/3265da80-1bbc-4634-bd94-ba2795d7e3f2">

この一覧には、ローカルファイル、Web URL、またはリソースパックから、対応している画像、アニメーション、音声、動画、テキストのリソースを追加できます。ライブの [Browser](./elements#browser) ページは事前読み込みされません。

プリローダーはゲーム起動時と Minecraft のリソース再読み込み時に開始されます。各項目は、次の処理に進む前に完了または失敗するまで待機し、1項目あたり最大2分の制限があります。

読み込まれたリソースは、再読み込み時またはクライアント終了時に FancyMenu がリソースを解放するまでキャッシュされたままです。**Customization -> Reload FancyMenu** はキャッシュを解放しますが、プリローダーを再実行しません。

事前読み込みは読み込み時間と RAM/VRAM 使用量を増やします。すぐに利用できる必要があるリソースだけを追加し、クライアントのメモリ不足が起きる場合は大きな項目を削除してください。

# スライドショーとパノラマの事前読み込み

[slideshow](./slideshows) を追加すると、そのすべての画像とオプションのオーバーレイが読み込まれます。[panorama](./panoramas) を追加すると、6面すべてとオプションのオーバーレイが読み込まれます。

**Customization -> Reload FancyMenu** ではプリローダーは実行されません。事前読み込みリストを変更した後は、Minecraft のリソース再読み込みを行うか、ゲームを再起動してください。
