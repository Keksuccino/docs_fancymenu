# リソースの事前読み込み

事前読み込みでは、メニューで必要になる前に選択したリソースを準備します。表示がちらつく、最初のフレームが黒くなる、または表示開始が遅れるリソースに使用してください。

# プリローダーにリソースを追加する

**Customization -> Pre-Load Resources** を開きます。

<br>

<img width="350" alt="Screenshot_1" src="https://github.com/Keksuccino/FancyMenu/assets/35544624/3265da80-1bbc-4634-bd94-ba2795d7e3f2">

リストには、ローカルファイル、ウェブ URL、またはリソースパックに含まれる、対応形式の画像、アニメーション、音声、動画、テキストリソースを追加できます。ライブ表示の [ブラウザー](/elements#browser) ページは事前読み込みできません。

プリローダーは、ゲームの起動時および Minecraft のリソース再読み込み時に実行されます。各項目の読み込みが完了するか失敗するまで待ってから次の項目に進みます。1 項目あたりの待機時間は最大 2 分です。

読み込まれたリソースは、再読み込みまたはクライアントの終了時に FancyMenu がリソースを解放するまでキャッシュに保持されます。**Customization -> Reload FancyMenu** を実行するとキャッシュは解放されますが、プリローダーは再実行されません。

事前読み込みを行うと、読み込み時間が長くなり、RAM/VRAM の使用量も増えます。すぐに使用できる必要があるリソースだけを追加してください。クライアントのメモリが不足する場合は、大きな項目を削除してください。

# スライドショーとパノラマの事前読み込み

[スライドショー](/slideshows) を追加すると、すべての画像と任意のオーバーレイが読み込まれます。[パノラマ](/panoramas) を追加すると、6 面すべてと任意のオーバーレイが読み込まれます。

**Customization -> Reload FancyMenu** を実行してもプリローダーは起動しません。プリロードリストを変更した後は、Minecraft のリソースを再読み込みするか、ゲームを再起動してください。
