# リソースの事前読み込み

いくつかの状況では、リソースを事前に読み込むことをおすすめします。
これは主に、高解像度画像、音声ファイル、そして一般的なWebリソースで必要になります。

リソースを事前に読み込むことで、画像のちらつきや、音声ファイルの再生開始が遅すぎる問題を軽減できます。

また、アニメーション（AFMA/FMAファイル）も事前に読み込むことをおすすめします。そうすることで、最初に読み込まれたときにスムーズに再生され、ラグが出たり黒い画面が表示されたりしにくくなります。

# リソースをプリローダーに追加する

FancyMenu のリソースプリローダーにリソースを追加するには、**カスタマイズ** の **リソースの事前読み込み** をクリックするだけです。

<br>

<img width="350" alt="Screenshot_1" src="https://github.com/Keksuccino/FancyMenu/assets/35544624/3265da80-1bbc-4634-bd94-ba2795d7e3f2">

するとメニューが開き、ローカルリソース、Webリソース、リソースパックのリソースをリストに追加できます。

このリストにある各リソースは、ゲームがリソースを再読み込みするたびに事前読み込みされます。つまり、リソース読み込み画面が表示されるたびに読み込まれます。

<br>

# スライドショーとパノラマを事前読み込みする

事前読み込みするリソースのリストには、スライドショーとパノラマも追加できます。これにより、パノラマやスライドショーの画像が最初に黒く表示されたり、画像が見つからなかったり、少しちらついたりする問題の修正に役立ちます。
