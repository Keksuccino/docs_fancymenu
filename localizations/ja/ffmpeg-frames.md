# FFmpeg を使って動画からフレームを取得する方法

*このページの一部は ChatGPT AI によって生成されました。*

FFmpeg は、動画や音声ファイルを扱うための無料ツールです。これを使うと、MP4 などの動画から画像（フレーム）を取り出すことができます。ここでは、その方法をステップごとに説明します。

以下のコマンドでは MP4 を使用しますが、FFmpeg は AVI、MOV、MKV、MPEG などの他の動画形式にも対応しています。

# 必要なもの

始める前に、次のものを用意してください。

1. **FFmpeg のインストール**:

   - 公式の [FFmpeg website](https://ffmpeg.org/download.html) から FFmpeg をダウンロードします。必ず「full」ビルドをダウンロードしてください。
   - お使いのコンピューター向けのセットアップ手順に従ってください。

2. **コマンドラインへのアクセス**:

   - FFmpeg コマンドを実行するために、ターミナル（Linux/macOS）またはコマンドプロンプト（Windows）を使用します。

3. **動画ファイル**:

    - MP4、AVI、MOV、MKV、または MPEG の動画ファイルを用意します。

# 始める前に

コマンドを実行する前に、次の準備をしてください。

## ファイル拡張子を表示する

  - 動画ファイルの名前を変更するときに、`.mp4` や `.avi` のような拡張子が見えることが重要です。

    - **Windows の場合**:

      - エクスプローラーを開きます。
      - 上部の「表示」タブをクリックします。
      - 「ファイル名拡張子」のチェックボックスをオンにします。

    - **macOS の場合**:

      - Finder を開きます。
      - メニューバーの「Finder」をクリックし、「設定」を選択します。
      - 「詳細」タブに移動し、「すべてのファイル名拡張子を表示」にチェックを入れます。

## 出力フォルダーを作成する

- FFmpeg 実行ファイルがあるディレクトリに、`output_frames` という名前のフォルダーを作成します。抽出したフレームはここに保存されます。

## 動画ファイルを準備する

- フレームを抽出したい動画ファイルを、FFmpeg 実行ファイルと同じディレクトリに置きます。
- 動画ファイル名を `input` に続けて拡張子を付けた名前に変更します（例: `input.mp4`、`input.avi` など）。これにより、下のコマンドを変更せずにそのまま使えます。

# FFmpeg の開き方

FFmpeg を使うには、まずコマンドラインから開く必要があります。Windows と macOS での手順を順番に説明します。

## Windows の場合:

1. **コマンドプロンプトを開く**:
   - `Windows` キーと `R` キーを同時に押して、「ファイル名を指定して実行」ボックスを開きます。
   - `cmd` と入力して Enter を押します。これでコマンドプロンプトが開きます。

2. **FFmpeg フォルダーへ移動する**:
   - FFmpeg がどこにあるかをコンピューターに伝える必要があります。`cd` コマンドを使って、FFmpeg を保存したフォルダーへ移動します。
   - たとえば、デスクトップの `ffmpeg-2024\bin` フォルダーに FFmpeg がある場合は、次のように入力します。
     ```bash
     cd C:\Users\YourUsername\Desktop\ffmpeg-2024\bin
     ```
     （`YourUsername` は実際のユーザー名に置き換えてください。）

3. **FFmpeg が動作するか確認する**:
   - FFmpeg が正しく動くか確認するには、次のコマンドを入力します。
     ```bash
     ffmpeg -version
     ```
   - 正しく動作していれば、画面に FFmpeg の情報が表示されます。

## macOS の場合:

1. **ターミナルを開く**:
   - `Command` キーと `Space` キーを同時に押して Spotlight 検索を開きます。
   - `Terminal` と入力して Enter を押し、ターミナルを開きます。

2. **FFmpeg フォルダーへ移動する**:
   - `cd` コマンドを使って、FFmpeg を保存したフォルダーへ移動します。
   - たとえば、FFmpeg が `Downloads` フォルダーにある場合は、次のように入力します。
     ```bash
     cd ~/Downloads/ffmpeg-2024/bin
     ```

3. **FFmpeg が動作するか確認する**:
   - FFmpeg の準備ができているか確認するには、次のコマンドを入力します。
     ```bash
     ./ffmpeg -version
     ```
   - FFmpeg が正しく動作していれば、詳細情報が画面に表示されます。

# すべてのフレームを保存する方法

動画からすべてのフレームを保存するには、次のコマンドを使います。

```bash
ffmpeg -i input.mp4 output_frames/%d.png
```

## これは何を意味するのか:

- `-i input.mp4`: 入力動画ファイルです。FFmpeg 実行ファイルと同じディレクトリに置いてください。`input.mp4` は正しいファイル名と拡張子に置き換えてください。
- `output_frames/frame_%04d.png`: フレームの保存方法を指定します。
- `output_frames/`: すべてのフレームを `output_frames` というフォルダーに保存します。
- `%d.png`: フレームは `1.png`、`2.png` のように番号付きで保存され、順番が保たれます。

# 特定の間隔でフレームを保存する

すべてのフレームが不要な場合は、1 秒ごと（または別の間隔）に 1 フレームを保存できます。次のコマンドを使います。

```bash
ffmpeg -i input.mp4 -vf "fps=1" output_frames/%d.png
```

## これは何を意味するのか:

- `-i input.mp4`: 入力動画ファイルです。FFmpeg 実行ファイルと同じディレクトリに置いてください。`input.mp4` は正しいファイル名と拡張子に置き換えてください。
- `-vf "fps=1"`: 1 秒あたり 1 フレームを保存します。フレームの取得頻度を変えたい場合は `1` を別の数値に変更してください（例: `fps=0.5` は 2 秒ごとに 1 フレーム、`fps=2` は 1 秒ごとに 2 フレームを保存します）。
- `output_frames/%d.png`: `output_frames` というフォルダーに `1.png`、`2.png` のような名前でフレームを保存します。

# フレームのサイズと品質を変更する

保存するフレームのサイズや品質も調整できます。方法は次のとおりです。

```bash
ffmpeg -i input.mp4 -vf "scale=1280:720" -q:v 2 output_frames/%d.png
```

## これは何を意味するのか:

- `-i input.mp4`: 入力動画ファイルです。FFmpeg 実行ファイルと同じディレクトリに置いてください。`input.mp4` は正しいファイル名と拡張子に置き換えてください。
- `-vf "scale=1280:720"`: フレームサイズを 1280x720 ピクセルに変更します。
- `-q:v 2`: 画質を設定します（1 が最も高品質で、数字が大きいほど品質は低くなります）。
- `output_frames/%d.png`: `output_frames` というフォルダーに `1.png`、`2.png` のような名前でフレームを保存します。

# フレームを保存する際のヒント

1. **容量を節約する**:

   - 動画が長い場合は、すべてのフレームを保存するのではなく、間隔を空けて保存するとよいでしょう。これは、FancyMenu で FMA アニメーションフレームとして使う場合に特に便利です。

2. **さらに詳しく知る**:

   - ターミナルで `ffmpeg -h` を実行すると、FFmpeg でできることをすべて確認できます。
