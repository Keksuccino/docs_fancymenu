# ボタンとスライダーのテンプレート

テンプレートとは、画面上のほかのすべてのボタン、またはすべてのスライダー（標準のものも自作のものも含む）に見た目を適用する[ボタン要素](/elements#button)です。テンプレートを変更すると、それに合わせてすべてのボタンやスライダーが変わります。

> [!TIP]
> ゲーム内のすべてのメニューで同じ見た目にするには、代わりに[グローバルカスタマイズ](/global-customizations)を使ってください。テンプレートは1つの画面、または[ユニバーサルレイアウト](/universal-layouts)が読み込まれるすべての画面に適用されます。

# テンプレートの作成

1. レイアウトにボタン要素を追加します。
2. 右クリックして**テンプレート設定**を開き、**テンプレートモード**をオンにします。
3. **設定を共有する対象**を**ボタン**または**スライダー**に設定します。
4. ほかのボタンと同じように、テンプレートに使いたいテクスチャ、サウンド、ラベル設定を指定します。**スライダー**を選ぶと、テクスチャ設定はスライダー用のテクスチャになります。

テンプレートはエディターの外では表示されないため、邪魔にならない場所に配置してください。エディターでは、スライダー用のテンプレートはスライダーのように表示されます。

# テンプレートで共有されるもの

## 常に共有されるもの

- ボタンのテクスチャ（またはスライダーのテクスチャ）と、その[9スライス](/nine-slicing-and-tiling)設定。
- ホバー時、ホバー解除時、クリック時のサウンド。

テンプレートが有効な間、ボタンは自身のテクスチャやサウンドの代わりに、テンプレートのものを使います。テンプレートにテクスチャが設定されていない場合、ボタン自身のテクスチャも使われません。

## 有効にした場合に共有されるもの

テンプレートの**テンプレート設定**で、以下を有効にしてください。

| 設定 | ボタンに適用されるテンプレートの内容 |
|---|---|
| **テンプレートモードでラベルを共有** | テンプレートの**ラベル**と**ホバーラベル**、およびラベルのスタイル全体（**ラベルの配置**、**ラベルの拡大率**、**ラベルの基本色**、**ラベルのホバー色**、**ラベルの影**、**ホバー時にラベルに下線を表示**）。 |
| **テンプレートモードでX位置を共有**および**テンプレートモードでY位置を共有** | テンプレートの位置。標準のボタンは、**アンカーポイント**が**標準（オリジナル）**以外に設定されている場合にのみ移動します。 |
| **テンプレートモードで不透明度を共有** | テンプレートの不透明度。 |

## すべてのボタンのラベル配置

**テンプレートモードでラベルを共有**を有効にすると、すべてのボタンにテンプレートのテキストも適用されます。そのため、すべてのボタンに同じ文言を表示する画面で使う設定です。

ラベルのテキストはそのままに、配置だけをそろえるには、次の方法を使います。

- 1つの画面で設定する場合は、`Ctrl` + クリックでボタンを選択し（[選択](/layout-editor#selecting)を参照）、いずれかのボタンを右クリックして、すべてのボタンの**ラベルの配置**を一度に設定します。
- すべてのメニューに適用する場合は、[グローバルカスタマイズ](/global-customizations#labels)の**ラベルの配置**を使います。

# 知っておくと便利なこと

- テンプレートにできるのはボタン要素だけですが、標準のボタンや自作のボタン、スライダーに適用できます。
- 1つの画面に、ボタン用とスライダー用のテンプレートを同時に1つずつ設定できます。同じ種類のテンプレートを複数設定した場合、有効になるのはそのうち1つだけです。
- テンプレートは表示されている間だけ有効です。テンプレートに[表示条件](/element-visibility)を設定すると、有効・無効を切り替えられます。
