# 互換性のない Mod 一覧

以下の Mod は、何らかの形で FancyMenu と互換性がないことが判明しています。

一部の Mod には、FancyMenu と併用するための回避策があります。
その場合は、下の一覧で Mod 名の後ろに記載しています。

**この一覧にまだ載っていない互換性のない Mod を見つけた場合は、GitHub で issue を開いてください！よろしくお願いします！**

* [Animated Loading Screen](https://modrinth.com/mod/animated-loading-screen)（メニューの見た目がバグって見える）
* [Animated Mojang Logo](https://www.curseforge.com/minecraft/mc-mods/animated-mojang-logo)（レイアウトが読み込まれないことがある。また、Drippy Loading Screen も壊れる）
* [Bedrockify](https://www.curseforge.com/minecraft/mc-mods/bedrockify)（少なくともカスタマイズしたいメニューについては、この Mod のメニュー変更をすべて無効にすれば互換性あり）
* [BetterFPS](https://www.curseforge.com/minecraft/mc-mods/betterfps)（この Mod のボタンとメニューはカスタマイズ不可）
* [Chat Colors](https://www.curseforge.com/minecraft/mc-mods/chat-colours)（起動時にクラッシュ）
* [Chloride](https://modrinth.com/mod/chloride)（この Mod が入っていると FPS プレースホルダーが動作しない）
* [Colormatic](https://www.curseforge.com/minecraft/mc-mods/colormatic)（MC 起動時に大きなラグが発生し、FM の音声関連機能が壊れる）
* [Controllable](https://www.curseforge.com/minecraft/mc-mods/controllable)（FancyMenu で追加したカスタムボタンは、Controllable の「Virtual Mouse」機能からはクリックできない）
* [Controlify](https://modrinth.com/mod/controlify)（ゲームがクラッシュするようです。こちらでは修正できません。詳細は[この issue](https://github.com/Keksuccino/FancyMenu/issues/1144) を参照してください）
* [Crash To Main Menu](https://www.curseforge.com/minecraft/mc-mods/crash-to-main-menu)
* [Custom Loading Screen](https://www.curseforge.com/minecraft/mc-mods/better-loading-screen)
* [Custom Main Menu](https://www.curseforge.com/minecraft/mc-mods/custom-main-menu)
* [Debugify](https://www.curseforge.com/minecraft/mc-mods/debugify)（代わりに [Modern Debugify](https://www.curseforge.com/minecraft/mc-mods/modern-debugify) を使用してください）
* [Dynamic Surroundings](https://www.curseforge.com/minecraft/mc-mods/dynamic-surroundings)（FancyMenu の Audio 要素が壊れますが、それ以外は正常に動作するはずです）
* [EnhancedVisuals](https://www.curseforge.com/minecraft/mc-mods/enhancedvisuals)（アニメーションが壊れ、背景が半透明になるほか、他にも問題が起きる可能性があります）
* [Entity Model Features](https://modrinth.com/mod/entity-model-features)（ゲームがクラッシュします。こちらでは修正できません。詳細は[この issue](https://github.com/Keksuccino/FancyMenu/issues/1115) を参照してください）
* [Fossils and Archeology Revival](https://www.curseforge.com/minecraft/mc-mods/fossils)（ゲーム内では動作しますが、カスタムメインメニューはサポートされません。設定で無効化できます）
* [Holographic Renderers](https://www.curseforge.com/minecraft/mc-mods/holographic-renderers)（起動時にクラッシュ）
* [Ice and Fire](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons)（設定でカスタムメインメニューを無効にすれば動作します）
* [Jurassicraft](https://www.curseforge.com/minecraft/mc-mods/jurassicraft)（GUI のカスタマイズを有効にすると起動時にクラッシュします。`config/fancymenu/customizablemenus.txt` から削除してください）
* [Legacy4J](https://www.curseforge.com/minecraft/mc-mods/legacy-minecraft)（ゲームがクラッシュする）
* [MalisisCore](https://www.curseforge.com/minecraft/mc-mods/malisiscore)（メインメニューのカスタマイズが壊れる）
* [Main Menu Scale Mod](https://www.curseforge.com/minecraft/mc-mods/main-menu-scale)
* [MCA Reborn](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-reborn)（動作しますが、一部のメニューで FM のメニューバーが壊れる、またはカスタマイズできません）
* [Minecraft Comes Alive](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-mca)（問題なく動作しますが、メニューはカスタマイズできません）
* [MineTogether](https://www.curseforge.com/minecraft/mc-mods/creeperhost-minetogether)（GUI スケールが 2 より大きいとレイアウトが壊れるようです）
* [Mod Menu](https://www.curseforge.com/minecraft/mc-mods/modmenu)（ほとんどの場合 **問題なく動作** しますが、Mods ボタンが重複したりカスタマイズできなかったりする場合は、Mod Menu のボタン設定を「Adjacent」に変更してください: Main Menu > Mods > Mod Menu > Mods Button: Adjacent）
* [Modern Online Picture Frames](https://www.curseforge.com/minecraft/mc-mods/online-picture-frame)（クラッシュします。詳細は[この issue](https://github.com/Keksuccino/FancyMenu/issues/776) を参照してください）
* [Not Enough Animations](https://www.curseforge.com/minecraft/mc-mods/not-enough-animations)（1.16 以降では問題なく動作しますが、1.12 では壊れます）
* **OptiFine**（この Mod と競合します！代わりに[これらの代替](./optifine-alternatives)を使用してください）
* [Optiscale](https://www.curseforge.com/minecraft/mc-mods/optiscale)（FancyMenu の UI が壊れ、ボタンがクリックできなくなります）
* [Pack Menu](https://www.curseforge.com/minecraft/mc-mods/packmenu)
* [Panorama Screens](https://modrinth.com/mod/panorama-screens)（メニューカスタマイズ Mod を重ねて使うのはあまり良くないため、動作せず問題を引き起こします）
* [QuestCraft](https://github.com/QuestCraftPlusPlus/QuestCraft)（ゲームの読み込みに失敗します）
* [RandomPatches](https://www.curseforge.com/minecraft/mc-mods/randompatches-forge)（設定で `patchMinecraftClass = false` にすると動作します）
* [Remove Reloading Screen](https://www.curseforge.com/minecraft/mc-mods/rrls)（FM と Drippy が壊れます。この Mod は使用しないでください）
* [Replay Mod](https://www.replaymod.com/download/)（`.minecraft/config/replaymod.json` で `mainMenuButton` を **BIG** に設定すると動作します）
* [Seamless Loading Screen](https://www.curseforge.com/minecraft/mc-mods/seamless-loading-screen)（ゲームがクラッシュします）
* [Slight Gui Modifications](https://www.curseforge.com/minecraft/mc-mods/slight-gui-modifications)
* [Skin Layers 3D](https://www.curseforge.com/minecraft/mc-mods/skin-layers-3d)（1.16 以降では問題なく動作しますが、1.12 では壊れます）
* [Smooth Scrolling Everywhere](https://www.curseforge.com/minecraft/mc-mods/smooth-scrolling-everywhere)
* [Sound Filters](https://www.curseforge.com/minecraft/mc-mods/sound-filters)（この Mod を入れると audio 拡張が動作しません）
* [Sound Physics Remastered](https://www.curseforge.com/minecraft/mc-mods/sound-physics-remastered)（この Mod を入れると audio 拡張が動作しません）
* [Stylish Effects](https://www.curseforge.com/minecraft/mc-mods/stylish-effects)（メインメニューが最初に表示されたとき、レイアウトの読み込みに失敗します）
* [Supplementaries](https://www.curseforge.com/minecraft/mc-mods/supplementaries)（設定画面のカスタマイズ時にランダムでクラッシュします。問題のあるレイアウトを `.minecraft/config/fancymenu/customization` から削除してください）
* [Terraria Craft](https://www.curseforge.com/minecraft/mc-mods/terraria-craft)
* [The Dalek Mod](https://www.curseforge.com/minecraft/mc-mods/the-dalek-mod)（設定でカスタムメインメニューを無効にすれば動作します）
* [ThonkUtil](https://www.curseforge.com/minecraft/mc-mods/thonkutil)（動作しますが、現在は削除できないテキストがメインメニューに追加されます）
* [Trade Uses](https://modrinth.com/mod/trade-uses)（村人の取引メニューでクラッシュの原因になります。おそらく「Easy Villagers」も入っている場合のみ）
* [VanillaFix](https://www.curseforge.com/minecraft/mc-mods/vanillafix)（使用は可能ですが、VanillaFix のクラッシュ画面に問題があるという報告があります）
* [FireplaceMode](https://www.curseforge.com/minecraft/mc-mods/fireplacemode)（この Mod を入れると一時停止画面のカスタマイズが時々リセットされます）
* [Respackopts](https://www.curseforge.com/minecraft/mc-mods/respackopts)（リソースパック画面のカスタマイズを無効にすれば動作します）
* [Bind Pizzeria](https://modrinth.com/mod/jjpizza)（FancyMenu のコンテキストメニューでのテキスト描画が壊れます）
* [EnhancedTooltips](https://www.curseforge.com/minecraft/mc-mods/enhancedtooltips)（FancyMenu のツールチップが壊れます）
* [Skin Shuffle](https://modrinth.com/mod/skinshuffle)（その Mod によってメニューに追加されるプレイヤーエンティティは、FancyMenu ではカスタマイズできません）
