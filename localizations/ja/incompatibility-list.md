# 非互換モッド一覧

以下のモッドは、何らかの形で FancyMenu と互換性がないことが確認されています。

いくつかのモッドには、FancyMenu で動作させるための回避策があります。
その場合は、下の一覧でモッド名の後に記載しています。

**この一覧にまだ載っていない非互換モッドを見つけた場合は、GitHub で issue を開いてください！よろしくお願いします！**

* [Animated Loading Screen](https://modrinth.com/mod/animated-loading-screen)（メニューがバグって見える）
* [Animated Mojang Logo](https://www.curseforge.com/minecraft/mc-mods/animated-mojang-logo)（レイアウトが読み込まれないことがある。また、Drippy Loading Screen も壊れる）
* [Bedrockify](https://www.curseforge.com/minecraft/mc-mods/bedrockify)（このモッドのメニュー改変をすべて無効化すれば互換性あり。少なくとも、カスタマイズしたいメニューについてはそうする必要があります）
* [BetterFPS](https://www.curseforge.com/minecraft/mc-mods/betterfps)（このモッドのボタンとメニューはカスタマイズできません）
* [Chat Colors](https://www.curseforge.com/minecraft/mc-mods/chat-colours)（起動時にクラッシュ）
* [Chloride](https://modrinth.com/mod/chloride)（このモッドを導入すると FPS プレースホルダーが機能しない）
* [Colormatic](https://www.curseforge.com/minecraft/mc-mods/colormatic)（MC 起動時に大きなラグが発生し、FM のオーディオ関連機能が壊れる）
* [Controllable](https://www.curseforge.com/minecraft/mc-mods/controllable)（FancyMenu で追加したカスタムボタンは、Controllable の「Virtual Mouse」機能ではクリックできません）
* [Controlify](https://modrinth.com/mod/controlify)（ゲームがクラッシュするようですが、こちらでは修正できません。詳しくは[この issue](https://github.com/Keksuccino/FancyMenu/issues/1144) を参照してください）
* [Crash To Main Menu](https://www.curseforge.com/minecraft/mc-mods/crash-to-main-menu)
* [Custom Loading Screen](https://www.curseforge.com/minecraft/mc-mods/better-loading-screen)
* [Custom Main Menu](https://www.curseforge.com/minecraft/mc-mods/custom-main-menu)
* [Debugify](https://www.curseforge.com/minecraft/mc-mods/debugify)（代わりに [Modern Debugify](https://www.curseforge.com/minecraft/mc-mods/modern-debugify) を使用してください）
* [Dynamic Surroundings](https://www.curseforge.com/minecraft/mc-mods/dynamic-surroundings)（FancyMenu のオーディオ要素が壊れますが、それ以外は問題なく動作するはずです）
* [EnhancedVisuals](https://www.curseforge.com/minecraft/mc-mods/enhancedvisuals)（アニメーションが壊れ、背景が半透明になるほか、さらに不具合があるようです）
* [Entity Model Features](https://modrinth.com/mod/entity-model-features)（ゲームがクラッシュしますが、こちらでは修正できません。詳しくは[この issue](https://github.com/Keksuccino/FancyMenu/issues/1115) を参照してください）
* [Fossils and Archeology Revival](https://www.curseforge.com/minecraft/mc-mods/fossils)（ゲーム内では動作しますが、カスタムメインメニューは非対応です。設定で無効化できます）
* [Holographic Renderers](https://www.curseforge.com/minecraft/mc-mods/holographic-renderers)（起動時にクラッシュ）
* [Ice and Fire](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons)（設定でカスタムメインメニューを無効化すれば動作します）
* [Jurassicraft](https://www.curseforge.com/minecraft/mc-mods/jurassicraft)（GUI のカスタマイズを有効にすると起動時にクラッシュします。`config/fancymenu/customizablemenus.txt` から削除してください）
* [Legacy4J](https://www.curseforge.com/minecraft/mc-mods/legacy-minecraft)（ゲームがクラッシュ）
* [MalisisCore](https://www.curseforge.com/minecraft/mc-mods/malisiscore)（メインメニューのカスタマイズが壊れる）
* [Main Menu Scale Mod](https://www.curseforge.com/minecraft/mc-mods/main-menu-scale)
* [MCA Reborn](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-reborn)（動作はしますが、いくつかのメニューが FM のメニューバーを壊すか、カスタマイズできません）
* [Minecraft Comes Alive](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-mca)（問題なく動作しますが、メニューはカスタマイズできません）
* [MineTogether](https://www.curseforge.com/minecraft/mc-mods/creeperhost-minetogether)（GUI スケールが 2 を超えるとレイアウトが壊れるようです）
* [Mod Menu](https://www.curseforge.com/minecraft/mc-mods/modmenu)（ほとんどの場合は**問題なく動作**しますが、Mods ボタンが重複したりカスタマイズできなかったりする場合は、Mod Menu のボタン設定を「Adjacent」に変更してください: Main Menu > Mods > Mod Menu > Mods Button: Adjacent）
* [Modern Online Picture Frames](https://www.curseforge.com/minecraft/mc-mods/online-picture-frame)（クラッシュします。[この issue](https://github.com/Keksuccino/FancyMenu/issues/776) を参照してください）
* [Not Enough Animations](https://www.curseforge.com/minecraft/mc-mods/not-enough-animations)（1.16 以降では問題なく動作しますが、1.12 では壊れます）
* **OptiFine**（このモッドは壊れます！ 代わりに[こちらの代替手段](./optifine-alternatives)を使用してください）
* [Optiscale](https://www.curseforge.com/minecraft/mc-mods/optiscale)（FancyMenu の UI が壊れ、ボタンがクリックできません）
* [Pack Menu](https://www.curseforge.com/minecraft/mc-mods/packmenu)
* [Panorama Screens](https://modrinth.com/mod/panorama-screens)（メニューカスタマイズ系モッドを重ねて使うのはそもそも良くないため、動作せず問題を引き起こします）
* [QuestCraft](https://github.com/QuestCraftPlusPlus/QuestCraft)（ゲームの読み込みに失敗します）
* [RandomPatches](https://www.curseforge.com/minecraft/mc-mods/randompatches-forge)（設定で `patchMinecraftClass = false` にすれば動作します）
* [Remove Reloading Screen](https://www.curseforge.com/minecraft/mc-mods/rrls)（FM と Drippy を壊します。このモッドは使わないでください）
* [Replay Mod](https://www.replaymod.com/download/)（`.minecraft/config/replaymod.json` で `mainMenuButton` を **BIG** に設定すれば動作します）
* [Seamless Loading Screen](https://www.curseforge.com/minecraft/mc-mods/seamless-loading-screen)（ゲームがクラッシュ）
* [Slight Gui Modifications](https://www.curseforge.com/minecraft/mc-mods/slight-gui-modifications)
* [Skin Layers 3D](https://www.curseforge.com/minecraft/mc-mods/skin-layers-3d)（1.16 以降では問題なく動作しますが、1.12 では壊れます）
* [Smooth Scrolling Everywhere](https://www.curseforge.com/minecraft/mc-mods/smooth-scrolling-everywhere)
* [Sound Filters](https://www.curseforge.com/minecraft/mc-mods/sound-filters)（これを導入するとオーディオ拡張は動作しません）
* [Sound Physics Remastered](https://www.curseforge.com/minecraft/mc-mods/sound-physics-remastered)（これを導入するとオーディオ拡張は動作しません）
* [Stylish Effects](https://www.curseforge.com/minecraft/mc-mods/stylish-effects)（メインメニューが初めて表示されたとき、レイアウトの読み込みに失敗します）
* [Supplementaries](https://www.curseforge.com/minecraft/mc-mods/supplementaries)（設定画面のカスタマイズ時にランダムにクラッシュします。問題のあるレイアウトを `.minecraft/config/fancymenu/customization` から削除してください）
* [Terraria Craft](https://www.curseforge.com/minecraft/mc-mods/terraria-craft)
* [The Dalek Mod](https://www.curseforge.com/minecraft/mc-mods/the-dalek-mod)（設定でカスタムメインメニューを無効化すれば動作します）
* [ThonkUtil](https://www.curseforge.com/minecraft/mc-mods/thonkutil)（動作しますが、現在はメインメニューに削除できないテキストが追加されます）
* [Trade Uses](https://modrinth.com/mod/trade-uses)（村人の取引メニューでクラッシュの原因になります。もしかすると「Easy Villagers」も入っている場合のみかもしれません）
* [VanillaFix](https://www.curseforge.com/minecraft/mc-mods/vanillafix)（使用はできますが、VanillaFix のクラッシュ画面に問題があると報告するユーザーがいます）
* [FireplaceMode](https://www.curseforge.com/minecraft/mc-mods/fireplacemode)（このモッドを入れていると、一時停止画面のカスタマイズが時々リセットされます）
* [Respackopts](https://www.curseforge.com/minecraft/mc-mods/respackopts)（リソースパック画面のカスタマイズを無効にした場合にのみ動作します）
* [Bind Pizzeria](https://modrinth.com/mod/jjpizza)（FancyMenu のコンテキストメニューでのテキスト描画が壊れます）
* [EnhancedTooltips](https://www.curseforge.com/minecraft/mc-mods/enhancedtooltips)（FancyMenu のツールチップが壊れます）
