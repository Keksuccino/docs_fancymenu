# グローバルカスタマイズ

グローバルカスタマイズでは、ボタン、スライダー、メニュー背景、音楽、ゲームウィンドウなど、すべての画面を一度に変更できます。レイアウトは不要で、カスタマイズが無効になっている画面にも適用されます。

レイアウトエディター以外の画面で、**メニューバー -> カスタマイズ -> グローバルカスタマイズ**から開けます。変更はすぐに反映され、自動的に保存されます。

> [!TIP]
> 一部の画面だけを変更するには、[レイアウト](/layout-editor)を使います。特定のレイアウトのボタンに独自の見た目を設定するには、[ボタンとスライダーのテンプレート](/button-slider-templates)を使います。

# ボタンとスライダー

これらの設定では、他のMODのものも含め、すべての画面のボタンとスライダーを変更できます。

- [レイアウト](/layout-editor)または[テンプレート](/button-slider-templates)で独自のテクスチャやラベル設定が指定されているボタンとスライダーは、その設定が維持されます。
- レシピブックボタンのような、画像だけでできたボタンは見た目が変わりません。

## ボタンのテクスチャ

**カスタムボタンテクスチャ**では、ボタンの各状態にテクスチャを設定します。

- **通常**
- **ホバー**: マウスカーソルをボタンに重ねているとき、またはキーボードで選択しているとき。
- **無効**: ボタンをクリックできないとき。

3つすべての状態に設定してください。テクスチャが設定されていない状態では、Minecraft標準のボタンが表示されます。

同じメニューには、次の設定もあります。

- **背景を透明にする**を有効にすると、すべてのボタンの背景が非表示になり、ラベルだけが表示されます。この設定はテクスチャより優先されます。
- **ボタン背景を9スライス**にすると、その下にある4つの枠線サイズに基づいて、ボタンのサイズが変わってもテクスチャの縁がくっきり保たれます。[9スライスとタイル表示](/nine-slicing-and-tiling)を参照してください。

> [!TIP]
> 9スライスを使わない場合、テクスチャは各ボタンのサイズに合わせて引き伸ばされます。Minecraftのボタンの高さは20ピクセルで、幅は主に200ピクセルまたは150ピクセルです。9スライスを使えば、小さなテクスチャ1つですべてのボタンに対応できます。

## スライダーのテクスチャ

**カスタムスライダーテクスチャ**には、次の2つの部分があります。

- **スライダー背景テクスチャ**: スライダーのバーです。**テクスチャを設定**から設定します。**背景を透明にする**と**スライダー背景を9スライス**は、ボタンの場合と同じように機能します。
- **スライダーハンドルのテクスチャ**: ドラッグする部分です。**通常**、**ホバー**、**無効**のテクスチャと、**スライダーハンドルを9スライス**を設定できます。

Minecraftのスライダーのハンドルは幅が8ピクセルで、高さはスライダーと同じ（通常は20ピクセル）です。9スライスを使わない場合、ハンドルのテクスチャはこのサイズに引き伸ばされます。

## ラベル

**ボタンラベル**と**スライダーラベル**には、同じ設定があります。

| 設定 | 機能 |
|---|---|
| **ホバー時にラベルに下線を引く** | マウスカーソルをラベルに重ねている間、下線を表示します。 |
| **ラベルの基本色** | ラベルの色です。カラーピッカー、または`#FFF1D6`のようなHEXコードで設定します。 |
| **ラベルのホバー色** | マウスカーソルをラベルに重ねている間の色です。 |
| **ラベルの拡大率** | ラベルのサイズです。`1`は標準サイズです。 |
| **ラベルの配置** | **左**、**中央**、**右**から選びます。 |
| **ラベルの影** | ラベルの背後に表示する暗い影です。無効にすると、レイアウト由来のラベルも含め、すべてのラベルから影がなくなります。 |

レイアウトまたはテンプレートで独自の設定が指定されているラベルは、その設定が維持されます。**ラベルの拡大率**と**ラベルの配置**については、サイズが標準で配置が**中央**のラベルにのみグローバル設定が適用されます。

## クリック音

- **カスタムボタンクリック音**を設定すると、ボタンとスライダーのMinecraft標準のクリック音が置き換わります。レイアウトで独自のクリック音が設定されているボタンは、その音が維持されます。
- **カスタムボタンクリック音の音量**は0%から100%まで設定できます。Minecraftのサウンド設定にある、そのサウンドチャンネルの音量スライダーも適用されます。
- **カスタムボタンクリック音のチャンネル**は、音楽などの再生先となるサウンドチャンネルです。初期設定は、すべてのサウンドが再生されるチャンネルであるマスター音量です。

# メニュー背景

**カスタムメニュー背景テクスチャ**は、タイトル画面を除くすべてのメニューの背後に表示する画像です。

- ゲームプレイ中のポーズメニューやオプション画面の背後にも表示されるため、その部分のワールドが隠れます。インベントリ、看板、書物は透過表示のままです。
- **背景テクスチャの縦横比を維持**を有効にすると、画像の縦横比を保ちます。画面全体を覆うように表示され、収まらない部分は切り取られます。無効にすると、画像が画面に合わせて引き伸ばされます。

**カスタムメニューパノラマ**を設定すると、タイトル画面とワールドに参加する前のすべてのメニューでMinecraftのパノラマが置き換わります。

- **パノラマを選択**から、[パノラマ](/panoramas)を選びます。
- **パノラマをクリア**すると、Minecraftのパノラマに戻ります。
- **現在のパノラマ**には、設定中のパノラマが表示されます。

テクスチャとパノラマの両方を設定した場合、テクスチャがパノラマを覆うため、パノラマが表示されるのはタイトル画面だけです。

レイアウトに独自の[メニュー背景](/menu-backgrounds)が設定されている画面では、そちらが表示されます。

# メニュー音楽

- **バニラのメニュー音楽を再生**を有効または無効にすると、メニューで流れるMinecraftの音楽を切り替えられます。
- **カスタムメニュー音楽トラック**を選択すると、**メニュー音楽トラックを管理**が開きます。**トラックを追加**でサウンドを追加し、**削除**で選択中のトラックを削除します。**すべてのトラックをクリア**ですべて削除し、**完了**でリストを保存します。

トラックはワールドに参加する前のメニューで、Minecraft標準のメニュー音楽の代わりにランダムな順序で再生されます。トラックや個別画面の音楽について詳しくは、[メニュー背景音楽](/background-music)を参照してください。

# 画面とポップアップ

| 設定 | 機能 |
|---|---|
| [**ゲームイントロ**](/game-intro) | タイトル画面が表示される前に、アニメーションまたは動画を再生します。 |
| **シングルプレイヤー画面のワールドアイコン** | ワールド一覧に表示するワールドのアイコンです。無効にすると非表示になります。 |
| **マルチプレイヤー画面のサーバーアイコン** | サーバー一覧に表示するサーバーのアイコンです。無効にすると非表示になります。 |
| [**シームレスなワールド読み込み**](/seamless-world-loading) | ワールドまたはサーバーを退出するときにスクリーンショットを撮影し、再び参加するときに読み込み背景として表示します。 |
| **実績のトースト通知** | 実績を解除したときに画面右上に表示されるポップアップと、そのサウンドです。無効にすると非表示になります。チャットの実績メッセージはそのまま表示され、リスナー[実績解除時](/listeners#on-achievement-unlocked)も引き続き動作します。 |

# ウィンドウとゲームの起動

| 設定 | 機能 |
|---|---|
| [**カスタムウィンドウアイコン**](/window-customization#custom-icon) | ゲームウィンドウのアイコンです。16x16と32x32のPNGアイコン、およびmacOS用アイコンが必要です。 |
| [**カスタムウィンドウタイトル**](/window-customization#custom-title) | Minecraftのウィンドウタイトルを置き換えます。[プレースホルダー](/placeholders)を使用でき、値が変わるとタイトルも更新されます。 |
| **デフォルトのGUIスケール** | ゲームインスタンスの初回起動時に、MinecraftのGUIスケールを`2`や`3`のように設定します。`-1`にすると無効になります。MODパック向けの機能です。 |
| **起動時に全画面表示を強制** | 起動するたびにゲームを全画面表示に切り替えます。 |

FancyMenuは、`fancymenu_data/default_scale_set.fm`に**デフォルトのGUIスケール**を設定したことを記録します。次回起動時にスケールを再設定するには、このファイルを削除してください（[データ保存場所](/data-storage-locations#instance-data)を参照）。

# 知っておくと便利なこと

- グローバルカスタマイズはFancyMenuの`options.txt`に保存されるため、読み込まれている[プロファイル](/profiles)に属します。また、`config/fancymenu/`を含むMODパックにも同梱されます。
- テクスチャやサウンドには、インスタンス内のファイル、ウェブリンク、リソースパック内のファイルを使用できます。[リソース](/resources)を参照してください。
- **メニューバー -> ヘルプ -> AI向けにエクスポート -> FancyMenuの設定**に、この設定が含まれます。[AIチャット](/export-for-ai)に質問するときに使えます。
