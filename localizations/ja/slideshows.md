# スライドショー

スライドショーでは、画像を順番に表示し、次の画像へゆっくりとフェードして切り替えます。Modpackの世界を撮影したスクリーンショットなどを表示できます。

レイアウトの[メニュー背景](/menu-backgrounds)として表示するか、画面の一部に[スライドショー要素](/elements#slideshow)を配置して表示できます。

# スライドショーの作成

1. ゲームディレクトリ内の `config/fancymenu/` にある `slideshows` フォルダーを開きます。**メニューバー -> ツール -> FancyMenuディレクトリを開く**を選ぶと、`config/fancymenu/` が開きます。
2. その中に、`world_tour` のようなスライドショー用のフォルダーを作成します。フォルダー名は自由です。
3. フォルダー内に [`properties.txt`](#propertiestxt) と、[画像](#the-images)を入れる `images` フォルダーを作成します。[`overlay.png`](#overlay) は省略できます。
4. **メニューバー -> カスタマイズ -> FancyMenuを再読み込み**または `Ctrl + Alt + R`（macOSでは `Cmd + Alt + R`）でFancyMenuを再読み込みするか、ゲームを再起動します。

```text
config/fancymenu/slideshows/
└── world_tour/
    ├── properties.txt
    ├── overlay.png
    └── images/
        ├── 01_river_valley.png
        ├── 02_cherry_grove.png
        └── 03_coast.png
```

# 画像

- PNGファイルとJPGファイルのみが対象です。ファイル名の末尾が `.png` または `.jpg` である必要があります。`.jpeg` ファイルは `.jpg` に名前を変更してください。
- ファイル名のアルファベット順に表示されます。数字もアルファベットと同じように並ぶため、`10.png` は `2.png` より先に表示されます。`01`、`02` … `10` のように、先頭にゼロを付けてください。
- すべての画像を同じサイズにしてください。最初の画像によってスライドショーの縦横比が決まり、残りの画像はそのサイズに引き伸ばされます。
- `images` フォルダー内にあるサブフォルダーのファイルは対象になりません。

# properties.txt

```text
type = slideshow

slideshow-meta {
  name = world_tour
  duration = 5.0
  fadespeed = 5.0
  randomize = false
}
```

| 設定 | 説明 |
|---|---|
| `name` | スライドショーを選ぶときに使う名前です。スライドショーごとに異なる名前を付けてください。 |
| `duration` | フェードを含め、画像が切り替わってから次に切り替わるまでの秒数です。フェードに時間がかかる場合は、フェードが終わるまで次の切り替えが待機します。 |
| `fadespeed` | 次の画像へフェードする速さです。`1.0` では約6秒、`3.0` では約2秒かかります。`0` より大きい値にしてください。 |
| `randomize` | `true` の場合、画像をランダムな順番で表示します。同じ画像が連続して表示されることはありません。`false` の場合、ファイル名順に表示します。 |

必須なのは `name` のみです。省略した設定には、`duration = 10.0`、`fadespeed = 1.0`、`randomize = false` が使われます。`type = slideshow` と `slideshow-meta {` の行はそのままにし、設定は1行に1つずつ記述してください。小数点には `2.5` のようにピリオドを使います。

古いバージョン向けに作られたスライドショーには、`width`、`height`、`x`、`y` の行が含まれている場合があります。これらの設定は機能しません。スライドショーの表示位置とサイズは、背景または要素によって決まります。

# オーバーレイ

`properties.txt` と同じ場所にある `overlay.png` は、すべての画像の上に重ねて描画され、スライドショーのサイズに引き伸ばされます。画像と一緒にはフェードしないため、フレームやビネット、隅に表示するロゴなどに適しています。透明な部分からは画像が見えます。

オーバーレイはスライドショーに属するため、スライドショーが表示される場所にはどこでも表示されます。同じ画像をフレームあり・なしで使いたい場合は、スライドショーを2つ作成してください。

# スライドショーの使用

## メニュー背景として使う

<img width="800" alt="背景メニューを開き、レイアウトエディターでスライドショーを選択。「背景を表示」をオンにして「スライドショーを選択」からworld_tourを選ぶと、右側のプレビューで次の画像へフェードし、その後タイトル画面のボタンの背後にスライドショーが表示される" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/slideshows_background.gif?raw=true">

1. [レイアウトエディター](/layout-editor)で背景を右クリックし、**メニュー背景 -> スライドショー**を開きます。
2. **背景を表示**をクリックして有効にします。
3. **スライドショー名**をクリックしてスライドショーを選び、**完了**をクリックします。右側のプレビューで再生中の様子を確認できます。

**スライドショーをクリア**をクリックすると、選択を解除できます。他の背景と組み合わせる方法は、[メニュー背景](/menu-backgrounds)を参照してください。

スライドショーは画面全体に引き伸ばされます。画像の縦横比を保つには、**メニュー背景**で**背景の縦横比を維持**を有効にしてください。その場合、画面いっぱいに表示されるように拡大され、左右または上下が切り取られます。

## 要素として使う

<img width="800" alt="左側にボタンがあり、右側にMinecraftの世界のスクリーンショットを次々とフェード表示するスライドショー要素があるタイトル画面" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/slideshows_element.gif?raw=true">

1. レイアウトエディターで空いている場所を右クリックし、**新しい要素**からスライドショーを追加します。
2. 要素を右クリックして**スライドショー**をクリックし、使用するスライドショーを選びます。要素の縦横比は画像に合わせて設定されます。
3. 他の要素と同じように移動・サイズ変更できます。**縦横比を復元**をクリックすると、高さに合わせて幅が変更され、画像が引き伸ばされなくなります。

## 事前読み込み

スライドショーは各画像を初めて表示するときに読み込むため、サイズの大きな画像は初回表示時に少し遅れて表示されることがあります。ゲームの起動中にすべての画像とオーバーレイを読み込むには、**メニューバー -> カスタマイズ -> リソースを事前読み込み**で**スライドショーを追加**を選びます。[リソースの事前読み込み](/preload-layouts#pre-loading-slideshows--panoramas)を参照してください。

# 知っておくと便利なこと

- 同じスライドショーを表示しているものは、別々のメニューであっても、同じ画像を同時に表示します。
- スライドショーは、何かに表示されている間だけ再生されます。`duration` より長い時間が空いてから再び表示されると、すぐに次の画像へフェードします。
- FancyMenuを再読み込みすると、すべてのスライドショーが最初から再生されます。再生開始後、最初の画像が表示される時間は、他の画像の半分だけです。
- スライドショーは、読み込まれている[プロファイル](/profiles)に属します。
- **スライドショーを選択**に表示されないスライドショーは、読み込みに失敗しています。ゲームのログ `logs/latest.log` に、`name`、`properties.txt`、`images` フォルダーの不足など、原因が記録されています。
- Windowsでは、誤って `properties.txt.txt` にならないよう、エクスプローラーでファイル名拡張子を表示してください。
- 紫と黒の市松模様が表示される場合、スライドショーが選択されていないか、レイアウトで指定されているスライドショー名が存在しなくなっています。
- `name` が同じスライドショーが2つある場合、表示されるのはそのうち1つだけです。
- **デバッグオーバーレイ**（`Ctrl + Alt + D`）では、FancyMenuが読み込んだスライドショーと画像の数を確認できます。
