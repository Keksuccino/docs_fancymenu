# バニラ要素

FancyMenuでは、画面に新しい要素を追加できるだけでなく、ベースゲーム（バニラ）の既存要素、さらには他のMODの要素までカスタマイズできます。

## バニラのボタンとスライダー（ウィジェット）

既存のバニラ/MODウィジェットをカスタマイズするには、**「現在の画面用」**の新しいレイアウトを作成し（**ユニバーサルではありません！**）、カスタム要素と同じようにエディタ内でそれらを**右クリック**します。

カスタムのボタンやスライダーと同じように、**ラベル**や**テクスチャ**をカスタマイズできます。

バニラ/MODウィジェットで**できない**唯一のことは、**アクションスクリプト**のカスタマイズです（たとえば、操作時の動作を変更するなど）。これはカスタムのボタンとスライダーでのみ可能です。

バニラ/MODウィジェットを**移動**したり**サイズ変更**したりするには、まずアンカーポイントを設定する必要があります。そのためには、それらを**右クリック**して **Anchor Point** をクリックします。バニラ/MOD要素の既定のアンカーは **Original** なので、それ以外の値に設定してください。

バニラ/MODウィジェットは、**右クリック**して **Delete** をクリックするだけで**非表示**にもできます。実際に削除されるわけではなく、非表示になるだけです。再び表示したい場合は、**メニューバー -> Element -> Deleted Vanilla Elements** をクリックし、再表示したい要素を**左クリック**してください。

> タイトル画面の **Copyright** ウィジェットだけは、**非表示/削除できません**。これは仕様です。著作権表記は削除しないでください。

## タイトル画面の要素

タイトル画面には、ロゴやスプラッシュテキストなど、通常のウィジェットではないため移動やカスタマイズができない要素があります。これらは削除して、カスタム要素（ロゴ用の Image 要素や、バニラのスプラッシュテキスト用のカスタム Splash Text 要素など）に置き換えることを想定しています。

削除するには、単にそれらを右クリックします。あとで復元したい場合は、**メニューバー -> Element -> Deleted Vanilla Elements** をクリックし、再表示したい要素を**左クリック**してください。

## トラブルシューティング: エディタでバニラ要素が表示されない

エディタでバニラ要素が見えない場合、**現在の画面用**ではなく**ユニバーサルレイアウト**を使用していることが原因である可能性が高いです。必ず現在の画面用のレイアウトを作成してください。現在の画面用のレイアウトは、その画面でカスタマイズが有効になっている場合にのみ作成できます。

## トラブルシューティング: カスタマイズが適用されない

バニラ要素へのカスタマイズがエディタ外で適用されない場合、通常は別のMODがバニラ要素の親メニューを上書きまたは変更していることが原因です。

画面/メニューを上書きするMODのわかりやすい例としては、タイトル画面を上書きする **Ice and Fire** があります。

メニューにカスタマイズが適用されないのは、バニラ要素に限った話ではありません。MODが画面を上書きまたは変更している場合、画面に追加したカスタム要素もメニューに適用されない可能性があります。
