# バニラ要素

FancyMenuでは、画面に新しい要素を追加できるだけでなく、ゲーム本体（バニラ）や他のModに含まれる既存の要素もカスタマイズできます。

## バニラのボタンとスライダー（ウィジェット）

既存のバニラ／Modのウィジェットをカスタマイズするには、**「現在の画面用」**の新しいレイアウトを作成します（ユニバーサルレイアウトではありません）。その後、カスタム要素の場合と同じように、エディター上で要素を**右クリック**します。

カスタムボタンやスライダーと同じように、**ラベルとテクスチャ**をカスタマイズできます。

バニラ／Modのウィジェットで**できない**ことは、**アクションスクリプト**のカスタマイズです（操作したときの動作を変更することなど）。これはカスタムボタンとスライダーでのみ可能です。

## 自動クリック

バニラおよびModのウィジェットには、**自動クリック**プロパティがあります。これを `0` より大きい整数に設定すると、画面の読み込み時に、そのウィジェット本来の左クリック動作を指定した回数だけ実行します。たとえば `2` に設定すると、新しく開いた各画面の最初の更新時に、ウィジェットが2回クリックされます。デフォルト値の `0` は自動クリックを無効にします。

これは実際のウィジェットクリックとして処理されます。クリックごとにスライダーや切り替えボタンの値が変更されたり、ウィジェット通常のコールバックが実行されたり、別の画面が開いたりする可能性があります。特にクリック回数を複数に設定する場合は、結果を慎重に確認してください。

バニラ／Modのウィジェットを**移動**または**サイズ変更**するには、まずアンカーポイントを設定する必要があります。設定するには、対象を**右クリック**して、**Anchor Point**をクリックします。バニラ／Mod要素のデフォルトアンカーは**Original**なので、それ以外の値を設定してください。

バニラ／Modのウィジェットは、対象を**右クリック**して**Delete**をクリックするだけで**非表示**にすることもできます。実際に削除されるわけではなく非表示になるだけなので、**メニューバー -> Element -> Deleted Vanilla Elements**をクリックし、再び表示したい要素を**左クリック**すれば復元できます。

> [!WARNING]
> タイトル画面の**Copyright**ウィジェットだけは、**非表示／削除できません**。これは仕様です。著作権表示を削除しないでください。

## タイトル画面の要素

タイトル画面には、通常のウィジェットではない要素（ロゴやスプラッシュテキストなど）があり、移動やカスタマイズはできません。これらは削除して、カスタム要素に置き換えることを想定しています（ロゴなら画像要素、バニラのスプラッシュテキストならカスタムのスプラッシュテキスト要素など）。

削除するには、対象を右クリックします。後で復元したい場合は、**メニューバー -> Element -> Deleted Vanilla Elements**をクリックし、再び表示したい要素を**左クリック**してください。

## トラブルシューティング：エディターでバニラ要素が表示されない

エディターでバニラ要素が表示されない場合は、**現在の画面用**ではなく、**ユニバーサルレイアウト**を使用していることが原因である可能性があります。必ず現在の画面用のレイアウトを作成してください。現在の画面用のレイアウトは、その画面でカスタマイズが有効になっている場合にのみ作成できます。

## トラブルシューティング：カスタマイズが適用されない

エディターの外でバニラ要素へのカスタマイズが適用されない場合、通常は別のModがバニラ要素の親メニューを上書きまたは変更していることが原因です。

画面／メニューを上書きするModのわかりやすい例として、タイトル画面を上書きする**Ice and Fire**があります。

メニューにカスタマイズが適用されない問題は、バニラ要素に限ったものではありません。Modが画面やメニューを上書きまたは変更している場合、画面に追加したカスタム要素もメニューに適用されない可能性があります。
