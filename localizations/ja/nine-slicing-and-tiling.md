# 九分割とタイル表示

独自のテクスチャは、要素のサイズに合わせて引き伸ばされます。写真なら問題ありませんが、枠線のあるフレーム、パネル、ボタンは、幅や高さを変えるとゆがんで見えます。次の2つの設定で解決できます。

- 九分割では、テクスチャの角と辺の形を保ち、中央部分だけを埋めます。
- タイル表示では、テクスチャを引き伸ばさずに繰り返し表示するため、パターンのサイズが保たれます。

# 九分割の仕組み

テクスチャを4本の線で9つの部分に分割します。4つの角は常に同じサイズを保ち、辺だけが長くなり、中央部分が残りを埋めます。

1. テクスチャを設定します。
2. 九分割の設定を有効にします。設定名は[対応箇所](#対応箇所)をご覧ください。
3. テクスチャの枠の太さに合わせて、境界線のサイズをテクスチャ上のピクセル数で設定します。枠の太さが4ピクセルなら、`4`を指定します。

知っておくと便利なこと：

- 境界線は、テクスチャ上と同じ大きさで画面に表示されます。そのため、境界線が40ピクセルのテクスチャは、小さなボタンでは太く見えます。テクスチャは要素と同じくらいのサイズにしてください。
- ほとんどのテクスチャでは、左右の境界線（X境界線）と上下の境界線（Y境界線）にそれぞれ1つのサイズを指定します。プログレスバー、ツールチップ、グローバルカスタマイズでは、各辺のサイズを個別に指定できます。
- テクスチャに対して境界線が大きすぎる場合は、自動的に小さくなります。

# 対応箇所

| テクスチャ | 九分割 | タイル表示 |
|---|---|---|
| [ボタン](/elements#button)テクスチャ（**ボタンテクスチャ**内） | **カスタム背景を九分割** | - |
| [スライダー](/elements#slider)テクスチャ（**スライダーテクスチャ**内） | **カスタム背景を九分割**および**カスタムハンドルを九分割** | - |
| [画像](/elements#image)要素 | **テクスチャを九分割** | **テクスチャを繰り返す** |
| [テキスト](/text-in-menus#background)要素と[スクロール可能な領域](/scrollable-areas#background)の**背景** | **カスタム背景を九分割** | **テクスチャをタイル表示** |
| テキスト要素とスクロール可能な領域の**スクロールバーの背景** | 常に有効 | - |
| [ツールチップ](/elements#tooltip)要素の**背景** | 常に有効。サイズは**九分割設定**で指定 | - |
| [プログレスバー](/elements#progress-bar)のテクスチャ | **バーのテクスチャを九分割**および**背景テクスチャを九分割** | - |
| [ボタンとスライダーのグローバルテクスチャ](/global-customizations#buttons-and-sliders) | **ボタンの背景を九分割**、**スライダーの背景を九分割**、**スライダーのハンドルを九分割** | - |
| [画像メニューの背景](/menu-backgrounds#image) | - | **テクスチャを繰り返す** |
| [スクロール可能な画面](/customizing-scrollable-screens)のヘッダーとフッター | - | **ヘッダーテクスチャを繰り返す**および**フッターテクスチャを繰り返す** |

## テキスト要素とスクロール可能な領域の背景

テキスト要素またはスクロール可能な領域の右クリックメニューから、**背景**を開きます。

- **カスタム背景テクスチャ**を設定すると、組み込みの暗いパネルが独自のテクスチャに置き換わります。パネルを元に戻すには、設定をリセットしてください。
- **カスタム背景を九分割**は、デフォルトで有効です。**九分割背景のX境界線（左右）**と**九分割背景のY境界線（上下）**で境界線を設定します。
- **テクスチャをタイル表示**を有効にすると、テクスチャが引き伸ばされずに繰り返し表示されます。九分割と併用すると、辺と中央部分は繰り返され、角はそのままの形を保ちます。
- **背景を表示**を無効にすると、背景全体が非表示になります。

## スクロールバーの背景

テキスト要素またはスクロール可能な領域の**スクロールバー -> スクロールバーの背景**を開きます。**縦バーのテクスチャ**と**横バーのテクスチャ**は、スクロールつまみが移動する方向に沿ってテクスチャを描画します。常に九分割されるため、バーの長さにかかわらず両端の形が保たれます。下にある2つの境界線設定で境界線を指定します。

# タイル表示の仕組み

タイル表示では、テクスチャを本来のサイズのまま、収まるだけ並べて表示します。左端と右端、上端と下端がそれぞれ自然につながるシームレスなテクスチャを使用してください。そうでない場合、タイルの境目に線が見えてしまいます。

画像要素では、**テクスチャを繰り返す**と**テクスチャを九分割**を同時に使用できません。両方を有効にすると、画像は繰り返し表示されます。
