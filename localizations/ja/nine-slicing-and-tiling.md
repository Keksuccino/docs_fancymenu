# ナインスライスとタイリング

FancyMenu で Minecraft のかっこいいメニューをデザインするとき、サイズを適切に変えたり、パターンとして繰り返したりしたい画像を使いたくなることがあります。このガイドでは、**ナインスライス** と **タイリング**（**リピートテクスチャ** とも呼ばれます）を使って、メニューをもっと魅力的に見せる方法を説明します！

# ナインスライスとは？

ナインスライスは、画像を見た目を崩さずに任意のサイズへ拡大できる手法です。画像を 9 つの部分（○×ゲームの盤面のような形）に分けて扱います。四隅は同じサイズのまま、辺の部分は一方向に伸び、中央部分は縦横両方に伸びます。

## ナインスライスはどこで使えますか？

FancyMenu では、ナインスライスは以下で利用できます。
- **ボタン要素**（カスタムボタンと、バニラボタンを編集する場合の両方）
- **進捗バーのテクスチャ**（バーと背景テクスチャ）

## ボタンでナインスライスを使う方法

1. レイアウトエディタで **ボタン要素** を作成または選択します。
2. ボタンを右クリックし、「Button Textures」オプションを探します。
3. ボタンの背景テクスチャ（通常、ホバー時、非アクティブ時）を設定します。
4. 「Nine-Slice Custom Background」オプションを有効にします。
5. **Nine-Slice Background X-Borders**（左右の境界サイズ）を設定します。
6. **Nine-Slice Background Y-Borders**（上下の境界サイズ）を設定します。

### ボタンのナインスライスのヒント

- 境界線と角がはっきりした画像を使いましょう。
- 境界値（X と Y）は、各辺から何ピクセルを境界として扱うかを FancyMenu に伝えます。
- 一般的な値は、X と Y の両方で 5 ピクセル程度です。
- 四隅は常に同じサイズのままで、中央部分がボタンの大きさに合わせて伸縮します。

# タイリングとは？

タイリング（リピートテクスチャとも呼ばれます）は、小さな画像を床のタイルのように繰り返して、大きな領域を埋める方法です。背景や、模様を途切れずに続けたい大きな画像に最適です。

## タイリングはどこで使えますか？

FancyMenu では、タイリングは以下で利用できます。
- **画像要素**
- **画像メニュー背景**

## 画像要素でタイリングを使う方法

1. レイアウトエディタで **画像要素** を作成または選択します。
2. 画像を右クリックし、「Image Source」からテクスチャを設定します。
3. **「Repeat Texture」** オプションを見つけて有効にします。
4. 画像要素のサイズを変更すると、テクスチャが繰り返されて領域を埋めるのが確認できます。

## メニュー背景でタイリングを使う方法

1. レイアウトエディタの背景コンテキストメニューから **Menu Backgrounds** を開きます。
2. 背景タイプとして **Image** を選択します。
3. 背景画像を選びます。
4. **「Repeat Texture」** オプションを有効にします。
5. これで背景全体にテクスチャが繰り返され、画面いっぱいに表示されます。

# ナインスライスとタイリング用の良いテクスチャを作るには

## ナインスライスの場合:
- 境界線と角がはっきりしたテクスチャを作成します。
- 境界線は見やすく、幅が一定であることを確認します。
- いくつかの境界サイズを試して、最適なものを見つけましょう。
- ボタンは通常、3〜5 ピクセルの境界でうまく機能します。

## タイリングの場合:
- どの辺でも自然につながる、シームレスなテクスチャを作成します。
- 見た目の混乱を避けるため、パターンはシンプルに保ちましょう。
- まずは小さな領域で繰り返して、テクスチャをテストします。

# 例

## ナインスライスされたボタンの例
シンプルなボタンは、最初 30x30 の画像で、四辺すべてに 5 ピクセルの境界を持つ形から始められます。ボタンを大きくすると、四隅は 5x5 ピクセルのまま残り、辺と中央はボタンサイズに合わせて伸縮します。

## タイル状の背景の例
さりげない模様のある小さな 64x64 のタイルを、画面サイズに関係なくメニュー背景全体に繰り返して表示できます。

# よくある問題と解決策

## ナインスライスしたボタンが引き伸ばされたり歪んで見える:
- 境界値が小さすぎる、または大きすぎる可能性があります
- 実際のテクスチャに合うように境界値を調整してみてください

## タイル状の背景に継ぎ目が見える:
- テクスチャがシームレスではありません
- 画像の端がぴったり一致するように編集してみてください

## テクスチャを拡大するとぼやけて見える:
- より高解像度のテクスチャを使ってください
- シンプルなデザインと、はっきりした線を保ちましょう

# 覚えておきましょう

- **ナインスライス** は、サイズを変えつつ見た目を保ちたい UI 要素（ボタンなど）に最適です。
- **タイリング** は、パターンで大きな領域を埋めたい場合（背景など）に便利です。
- どちらの機能も、どんな解像度や画面サイズでも UI をきれいに見せるのに役立ちます！

さあ、ぴったり伸縮するボタンと美しいタイル状背景で、素晴らしい Minecraft メニューを作ってみましょう！
