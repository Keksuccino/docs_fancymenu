# 9スライスとタイリング

9スライスは、テクスチャの角と境界を保持したまま中央部分を伸縮します。タイリングは、テクスチャを引き伸ばす代わりに繰り返します。

<img src="https://raw.githubusercontent.com/Keksuccino/FancyMenu/refs/heads/master/assets/docs/nine_slicing_example.png" alt="9スライスの領域" style="max-width:500px;height:auto;" />

# 9スライス対応

| 領域 | 対応対象 |
|---|---|
| ウィジェット | [ボタン](./elements#button) と [スライダー](./elements#slider) のテクスチャ、[グローバルなボタンとスライダーのスタイル](./global-customizations#button-visuals) |
| 画像とパネル | [画像要素](./elements#image) |
| プログレスバー | [塗りつぶしと背景のテクスチャ](./elements#progress-bar) |
| ツールチップ | [カスタム背景テクスチャ](./elements#tooltip) |

# 9スライスの設定

1. 対象のテクスチャを設定します。
2. **Nine-Slice** オプションを有効にします。
3. ソーステクスチャ内の固定エッジ領域に合わせて、境界サイズを設定します。
4. 要素をリサイズし、角やエッジが崩れる場合は境界値を調整します。

ボタンと画像の設定では、X/Y の境界サイズを使用します。プログレスバーとツールチップでは、必要に応じて各エッジごとの値を個別に設定できます。

# タイリング対応

繰り返しテクスチャは次で使用できます。

- [画像要素](./elements#image)。
- [画像メニューの背景](./menu-backgrounds)。
- [スクロール可能なリストのヘッダーとフッターのテクスチャ](./customizing-scrollable-screens)。

画像要素または画像背景で **Repeat Texture** を有効にします。スクロール可能な画面では、ヘッダー/フッターのカスタマイズメニューにある繰り返しオプションを使用します。

シームレスなソーステクスチャを使用してください。端が一致しないと、タイル間に目に見える線ができます。

9スライスと繰り返しは別々のモードです。対象に両方のオプションが表示される場合は、意図した拡大縮小の動作に合う方を選んでください。
