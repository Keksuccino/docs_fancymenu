# アニメーション

AFMA/FMA ファイルは、FancyMenu 向けに作成された特別なアニメーション画像ファイルです。
APNG とほぼ同じですが、FancyMenu 用により最適化されています。

# AFMA ファイル

FancyMenu 3.9.0 では、従来の FMA ファイルの後継である **AFMA**（Advanced FancyMenu Animation）が追加されました。

AFMA ファイルはもはや ZIP ファイルではありません。より良いファイルサイズ、より少ないメモリ使用量、そしてより高いパフォーマンスを実現した、FancyMenu の新しいアニメーション形式を使用します。

新しく大きい、または複雑なアニメーション画像には、従来の FMA ではなく **AFMA** を使用してください。

AFMA ファイルを作成するには、次のようにします。

1. FancyMenu のメニューバーを開きます。
2. **Tools -> AFMA Creator** に移動します。
3. 作成ツールでフレームをインポート/変換します。

> [!IMPORTANT]
> AFMA ファイルは、従来の FMA ファイルのように手動でパックできません。パック/作成するには **AFMA Creator** を使用する必要があります。

従来の FMA ファイルも引き続きサポートされており、FancyMenu 3.9.0 で最適化されたため、既存のレイアウトをすぐに変換する必要はありません。

# 従来の FMA ファイル

## FMA の作成

FMA ファイルの作成は、ZIP ファイルを作るのと同じくらい簡単です。というのも、内部的にはほぼ ZIP ファイルだからです。

### ファイル拡張子

このドキュメントに従うにはファイル拡張子を表示する必要があるので、作業を始める前に必ず **ファイル拡張子を有効に** してください。

Windows では、適当なフォルダを開いてから、右上の矢印をクリックしてメニューを展開します。

次に **表示** タブへ移動し、**ファイル名拡張子** を有効にします。

<br>
<img width="764" alt="Screenshot_9" src="https://gist.github.com/assets/35544624/1f0a0864-1ad8-4f63-be3a-ab18385539e6"> 

### 準備

まず、FMA ファイルの内容を入れる新しいフォルダを作成します。
この例では、そのフォルダ名を `fancymenu_animation` とします。

このフォルダの中に、さらに 2 つのフォルダを作成します。1 つ目のフォルダは **必ず** `frames`、2 つ目のフォルダは **必ず** `intro_frames` という名前にしてください。

次に、同じフォルダ内に新しい TXT ファイルを作成し、`metadata.json` に名前を変更します。
まだ TXT ファイルのままになっていないことを確認してください。ファイル拡張子を **必ず** `json` に変更する必要があります。

これで、`fancymenu_animation` というフォルダがあり、その中に `frames` フォルダ、`intro_frames` フォルダ、そして `metadata.json` という JSON ファイルがある状態になっているはずです。

<br>

### メタデータ JSON

これは、FancyMenu に FMA テクスチャの扱い方を伝えるファイルです。
フレーム時間（1 フレームが表示される時間）やループ回数などの情報が含まれています。

`metadata.json` ファイルをテキストエディタで開いてください。

次のテキストをファイルにコピーします。

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
  },
  "custom_frame_times_intro": {
  }
}
```

これは、ファイルの基本的なテンプレートです。
ここから好みに合わせてカスタマイズできます。

#### `loop_count`

これは、テクスチャを何回ループさせるか（アニメーションを最初から再生し直すか）を制御します。

これを `0` にすると無限にループします。**決して停止しません**。

`0` より大きい値は、テクスチャを再生する回数を意味します。たとえば、値を `1` にすると 1 回だけ再生されて最後のフレームで停止し、`2` にすると 2 回再生されて最後のフレームで停止します。**以下同様です**。

#### `frame_time`

これは、アニメーションテクスチャの各フレームに対する共通のフレーム時間で、単位は **ミリ秒** です。
フレーム時間とは、アニメーションが次のフレームへ進む前に、1 つのフレームがどれくらいの間表示されるかを意味します。

#### `frame_time_intro`

これは基本的に `frame_time` と同じですが、アニメーションテクスチャの **イントロ** フレーム用です。
イントロフレームは **任意** で、詳しくは後で説明します。

#### `custom_frame_times`

これは **任意** で、特定の（イントロ以外の）フレームのフレーム時間を上書きするために使えます。
たとえば、すべてのフレームを `41` ミリ秒表示したいので `frame_time` を `41` に設定したが、最初と 2 番目のフレームだけは `5000` ミリ秒表示したい、という場合です。

その場合は次のようにします。

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
    0: 5000,
    1: 5000
  },
  "custom_frame_times_intro": {
  }
}
```

フレーム番号は 0 から始まるため、アニメーションの最初のフレームは `0`、2 番目は `1`、以下同様です。

カスタムフレーム時間の各項目の末尾には **カンマ** が必要ですが、**最後の項目だけ** は不要です。

#### `custom_frame_times_intro`

これは `custom_frame_times` とまったく同じですが、この場合は **イントロ** フレーム用です。イントロフレームは **任意** で、詳しくは後で説明します。

`metadata.json` ファイルについては以上です。保存してテキストエディタを閉じてください。

### フレーム

> 1 つのアニメーションにつき、**最大 200 フレーム**、**最大解像度 1080p** までにすることをおすすめします。アニメーションは大量のメモリを消費し、動画ではありません。24 FPS のフル動画を再生するためではなく、短いループアニメーションに使うものです。
{.is-danger}

アニメーションテクスチャのフレームは `frames` フォルダに入れます。

フレームは **PNG ファイル** である必要があります！ **JPEG やその他の形式はサポートされていません**！

各フレームの名前は、フレーム番号とファイル拡張子だけにしてください。
最初のフレームは `0.png`、2 番目は `1.png`、3 番目は `2.png`、以下同様です。
フレーム名が無効だと、そのテクスチャは **動作しません**！

**動画からフレームを抽出する** には、[このドキュメントページ](/ffmpeg-frames) を参照してください。

### イントロ

この機能は **任意** です。

FMA ファイルの **イントロ** 機能は、`frames` フォルダの実際のフレームが再生される前に、いくつかのフレームを特別に再生するための仕組みです。

イントロは **絶対にループしません**。アニメーションが最初に再生されるときに一度だけ再生されるため、実際のループアニメーションが始まる前にフェードインのような演出を入れられます。

イントロフレームは `intro_frames` フォルダに入れ、通常のフレームと同じように扱います。

フレームは **PNG ファイル** である必要があります！ **JPEG やその他の形式はサポートされていません**！

各フレームの名前は、フレーム番号とファイル拡張子だけにしてください。
最初のフレームは `0.png`、2 番目は `1.png`、3 番目は `2.png`、以下同様です。
フレーム名が無効だと、そのテクスチャは **動作しません**！

### FMA ファイルのパック

これで `fancymenu_animation` フォルダに必要なものはすべて入ったので、FMA ファイルをパックできます。

FMA ファイルをパックするとは、フォルダの内容を ZIP ファイルとしてまとめることを意味します。
内容は ZIP ファイルの **ルート** に配置する必要があり、ZIP 内の追加フォルダの中に入っていてはいけません。

Windows では、`fancymenu_animation` フォルダ内のすべてを選択し、そのうえで `metadata.json` ファイルを **右クリック** するのが、FMA の内容を ZIP にする最も簡単な方法です。開いたコンテキストメニューで、**送る -> 圧縮 (ZIP 形式) フォルダー** をクリックします。

これで `fancymenu_animation` フォルダ内に `metadata.zip`、`frames.zip`、または `intro_frames.zip` という新しい ZIP ファイルができているはずです。

このファイルを開くと、内容は次のようになっているはずです。

次に、ファイル名を `fancymenu_animation.fma` に変更します。`.zip` を `.fma` に **置き換える** ことを忘れないでください。これで ZIP ファイルではなくなります。

もちろん `fancymenu_animation` の部分は好きな名前に変更できますが、拡張子が `.fma` のままであることを確認してください。

これで完了です！ これで（うまくいけば）動作する FMA ファイルが作成できました！

# FancyMenu で AFMA & FMA ファイルを使う

> [!IMPORTANT]
> AFMA/FMA ファイルは **アニメーションテクスチャ** として扱われるため、**Image** 入力から追加します。画像を受け付けるほとんどすべての場所（PNG、JPEG、GIF など）で、FMA と AFMA ファイルも使用できます。

AFMA/FMA ファイルは、他のアニメーションテクスチャ/画像形式と同じように使用できます。FancyMenu からは通常の画像として認識されるため、**画像要素** や **画像のメニューバックグラウンド** など、テクスチャを設定できるあらゆる場所で使えます。

AFMA/FMA ファイルは必ず `/config/fancymenu/assets/` フォルダに入れてください。FancyMenu がテクスチャやその他のリソースを取得できるのは `assets` フォルダ内だけだからです。
