# カスタムスプラッシュテキスト要素

FancyMenu のスプラッシュテキスト要素は、Minecraft の跳ねるタイトルスプラッシュを完全にカスタマイズできる拡張版です。おなじみの跳ねる動きはそのままに、表示する内容、見た目、更新タイミングを自由にコントロールできます。

> なお、Title 画面にある元の Vanilla のスプラッシュテキスト要素は、実際にはあまりカスタマイズできません。そのため、そちらは **削除** して、代わりにカスタムのスプラッシュテキスト要素を使うことをおすすめします。
{.is-warning}

## 要素の追加と選択
- レイアウトエディタを開き、`Splash Text` という要素を追加します。
- 1回左クリックして選択し、バウンディングボックスを表示します。次に右クリックしてコンテキストメニューを開きます。すべての設定項目はそのメニュー内にあります。

## スプラッシュテキストの取得元を選ぶ
- `Source Mode: Vanilla` は、Minecraft に元から入っている従来のランダムなスプラッシュをそのまま使います。
- `Source Mode: Direct Input` では、`Input Splash Text` に自分でテキストを入力できます。1行のスプラッシュテキストのみ対応していますが、その1行の中にプレースホルダーを含めることができます。
- `Source Mode: Text File` は、`Set Source Text File` で指定した `.txt` ファイルからランダムな1行を取得します。空でない各行が、有効なスプラッシュ候補になります。
- モードを切り替えると現在のテキストはリセットされるため、安心して試せます。もしテキストが固定されたように見える場合は、別のモードに切り替えるか、`Refresh On Screen Load: Enabled` を有効にして、メニューを開くたびに再抽選させてください。

## テキストファイルの例
`Text File` 取得モードを使う場合、スプラッシュ一覧はプレーンテキスト（BOM なし UTF-8）で保存してください。各行がスプラッシュ候補になります。

```
Welcome to FancyMenu!
{"placeholder":"your_placeholder_id_here"}
{"text":"This is gold and bold text.","color":"gold","bold":true}
&6Use &lMinecraft formatting codes!
```

`your_placeholder_id_here` を、実行時に解決したいプレースホルダー ID に置き換えてください。FancyMenu は、スプラッシュが更新されるたびに空でない行をランダムに1つ選びます。

## 見た目を思いどおりにする
- サイズと回転角度は `Set Scale` と `Set Rotation` で調整できます。
- `Set Text Color` には 16進数の色コード（例: `#FFFF00`）を指定でき、テーマに合わせられます。
- `Shadow: Enabled` で Minecraft のドロップシャドウが追加されます。オフにするとフラットな文字になります。
- `Bouncing: Enabled` でおなじみのバウンド動作を維持できます。無効にすると静止したラベルになります。
- FancyMenu はスプラッシュを完全な Minecraft コンポーネントとして描画するため、カラーコードやその他の文字装飾も期待どおりに機能します。

## 動的テキスト機能
- プレースホルダーは描画前に解決されるため、スプラッシュテキスト内でプレイヤー名、日付、その他対応している値を参照できます。
- この要素は Minecraft のシリアライズ済みコンポーネント JSON を受け付けるため、Direct Input やテキストファイルに高度な JSON スニペットを貼り付けることができます。要素は自動的にデシリアライズし、何か問題があればリテラルテキストとしてフォールバックします。

## トラブルシューティング
- Direct Input でテキストが空のままだと、編集中は `< empty splash element >` と表示されます。警告を消すには、何かを入力してください（スペース1つでも可）。
- テキストファイルに有効な行が1つもない場合、要素には `ERROR: SPLASH FILE IS EMPTY` と表示されます。少なくとも1行の空でない行を追加して、画面を開き直してください。
- シリアライズ済み JSON にエラーがある場合は、プレーンテキストにフォールバックします。Mojang の標準 JSON 構造に従うか、貼り付ける前にバニラの `/tellraw` コマンドでスニペットをテストしてください。
