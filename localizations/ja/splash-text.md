# カスタムスプラッシュテキスト要素

FancyMenuのスプラッシュテキスト要素は、Minecraftでおなじみの弾むタイトルスプラッシュを完全にカスタマイズできるようにしたものです。おなじみの弾む動きはそのままに、表示する内容や見た目、更新タイミングを自由に設定できます。

> [!WARNING]
> タイトル画面にある元のバニラ版スプラッシュテキスト要素は、実際にはカスタマイズできません。そのため、**削除**して代わりにカスタムスプラッシュテキスト要素を使用してください。

## 要素の追加と選択
- レイアウトエディターを開き、`Splash Text`という名前の要素を追加します。
- その要素を左クリックして選択し、バウンディングボックスを表示します。その後、右クリックしてコンテキストメニューを開きます。すべての設定項目はこのメニューにあります。

## スプラッシュテキストの取得元を選択する
- `Source Mode: Vanilla`では、Minecraftに標準搭載されている従来のランダムなスプラッシュテキストを使用します。
- `Source Mode: Direct Input`では、`Input Splash Text`から独自のテキストを入力できます。対応するスプラッシュテキストは1行のみですが、その行にはプレースホルダーを含められます。
- `Source Mode: Text File`では、`Set Source Text File`で選択した`.txt`ファイルからランダムに1行を読み込みます。空でない各行が、表示対象のスプラッシュテキストになります。
- モードを切り替えると現在のテキストがリセットされるため、安全に試すことができます。テキストが固定されているように感じる場合は、別のモードに切り替えるか、`Refresh On Screen Load: Enabled`をクリックして、メニューを開くたびに再抽選されるようにしてください。

## テキストファイルの例
「Text File」ソースモードを使用する場合は、スプラッシュテキストの一覧をプレーンテキスト（BOMなしのUTF-8）として保存します。各行がスプラッシュテキストの候補になります。

```
Welcome to FancyMenu!
{"placeholder":"your_placeholder_id_here"}
{"text":"This is gold and bold text.","color":"gold","bold":true}
&6Use &lMinecraft formatting codes!
```

`your_placeholder_id_here`を、実行時に解決したいプレースホルダーに置き換えてください。スプラッシュテキストが更新されるたびに、FancyMenuは空でない行からランダムに1行を選択します。

## 好みの見た目に設定する
- `Set Scale`と`Set Rotation`を使って、サイズと回転角度を調整します。
- `Set Text Color`には16進数の値（例：`#FFFF00`）を指定して、テーマに合わせることができます。
- `Shadow: Enabled`を有効にすると、Minecraftのドロップシャドウが追加されます。平面的なテキストにしたい場合は無効にしてください。
- `Bouncing: Enabled`を有効にすると、おなじみの上下に弾む動きが維持されます。静的なラベルにする場合は無効にしてください。
- FancyMenuはスプラッシュテキストを完全なMinecraftコンポーネントとして描画するため、カラーコードやその他のテキスト装飾も期待どおりに機能します。

## 動的なテキスト機能
- プレースホルダーは描画前に解決されるため、スプラッシュテキスト内でプレイヤー名や日付、その他の対応する値を参照できます。
- この要素はMinecraftのシリアライズ済みコンポーネントJSONに対応しているため、Direct Inputやテキストファイルに高度なJSONスニペットを貼り付けることもできます。要素は自動的にデシリアライズし、問題が発生した場合はリテラルテキストとして扱います。

## トラブルシューティング
- Direct Inputが空の場合、編集中は`< empty splash element >`と表示されます。警告を消すには、何か（スペース1つでも可）を入力してください。
- テキストファイルに有効な行が1つもない場合、要素には`ERROR: SPLASH FILE IS EMPTY`と表示されます。空でない行を少なくとも1行追加し、画面を開き直してください。
- シリアライズ済みJSONにエラーがある場合は、プレーンテキストとして扱われます。Mojangの標準JSON構造を使用するか、貼り付ける前にバニラの`/tellraw`コマンドでスニペットをテストしてください。
