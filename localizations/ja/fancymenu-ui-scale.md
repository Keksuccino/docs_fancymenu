# FancyMenu の UI スケール

FancyMenu の UI（メニューバーやコンテキストメニューなど）には、Minecraft の通常の GUI スケールとは連動しない、別のスケールが使用されています。

FancyMenu の UI が小さすぎる、または大きすぎると感じる場合は、**メニューバー -> カスタマイズ -> 設定 -> FancyMenu の UI** から UI スケールを変更できます。

FancyMenu 3.9.0 では、UI スケールの選択肢がさらに増えました。UI スケールが **Auto** に設定されている場合、最小の自動スケールは `1.25` になりました。必要であれば、これまでどおり手動で `1` を選択することもできます。

唯一の例外は、FancyMenu によって追加される実際のフルスクリーン画面です。たとえば、変数を管理する画面やレイアウトエディターなどがこれに当たります。これらの画面は、ほとんどの場合 Minecraft の通常の GUI スケールを使用しますが、画面内のすべての内容を収めるにはウィンドウが小さすぎる場合に、より小さいスケールで自動表示するため、別の自動スケーリングの仕組みを使っている画面もあります。
