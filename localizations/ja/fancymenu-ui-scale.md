# FancyMenu の UI スケール

FancyMenu の UI（メニューバーやコンテキストメニューなど）は、Minecraft の通常の GUI スケールとは連動しない、別のスケールを使用しています。

FancyMenu の UI が小さすぎる、または大きすぎると感じる場合は、**メニューバー -> カスタマイズ -> 設定 -> FancyMenu の UI** から UI スケールを変更できます。

UI スケールが **自動** に設定されている場合、最小の自動スケールは `1.25` です。手動ではスケール `1` を選択できます。

これに対する唯一の例外は、FancyMenu によって追加される実際のフルスクリーン画面です。たとえば、変数を管理する画面やレイアウトエディターがこれにあたります。これらの画面は、ほとんどの場合 Minecraft の通常の GUI スケールを使用しますが、ウィンドウが小さくて画面内の内容をすべて表示できない場合に、より小さいスケールで自動表示する別の自動スケーリング処理を使う画面もあります。
