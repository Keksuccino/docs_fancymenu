# ウィンドウアイコンとタイトル

FancyMenu では、Minecraft ウィンドウのアイコンとタイトルを変更できます。

![ウィンドウのカスタマイズ](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# カスタムアイコン

カスタムアイコンを設定するには、**カスタマイズ -> グローバルカスタマイズ**から[**グローバルカスタマイズ**](/global-customizations)を開きます。

![ウィンドウアイコン](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- アイコンは **PNG** ファイルである必要があります（macOS の場合は **ICNS**）。
- 正常に表示するには、アイコンに**少なくとも 1 ピクセルの透明部分**が必要です（MC/LWJGL のバグ）。
- カスタムアイコンの切り替えを有効にするには、3 種類すべてのアイコン（16x16、32x32、macOS）に有効なファイルを設定する必要があります。

> [!CAUTION]
> **もう一度ご注意ください**：正常に表示するには、アイコンに**少なくとも 1 ピクセルの透明部分**が必要です（MC/LWJGL のバグ）。完全に透明なピクセルが 1 つもない場合、アイコンは正しく表示されません！


# カスタムタイトル

カスタムタイトルを設定するには、**カスタマイズ -> グローバルカスタマイズ**から[**グローバルカスタマイズ**](/global-customizations)を開きます。

![ウィンドウタイトル](https://github.com/Keksuccino/FancyMenu/assets/35544624/06ecd207-c2d2-4f7c-83f4-18d94c66c5ff)
