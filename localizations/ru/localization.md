# Локализация макетов

FancyMenu позволяет локализовать текстовый контент и даже целые элементы или макеты!

# Текстовый контент

FancyMenu позволяет добавлять собственные локализации в игру.
Их затем можно использовать с плейсхолдером **Localize Text**, чтобы локализовать текст на текущий язык игры.

## Использование стандартных ключей локализации Minecraft

Перед созданием собственных локализаций вы, возможно, захотите использовать уже существующие ключи локализации Minecraft. Это экономит время и обеспечивает согласованность со стандартным текстом Minecraft.

### Поиск стандартных ключей локализации

Проще всего найти ключи локализации Minecraft, просматривая файлы ресурсов игры онлайн:

1. **Откройте MCAsset.cloud:**  
   Перейдите на [https://mcasset.cloud/](https://mcasset.cloud/) — этот сайт позволяет просматривать ресурсы Minecraft, не извлекая их из игры.

2. **Перейдите к языковым файлам:**  
   - Выберите вашу версию Minecraft в выпадающем списке
   - Перейдите в: `assets` → `minecraft` → `lang`
   - Откройте `en_us.json`, чтобы увидеть все английские локализации

3. **Найдите нужный ключ:**  
   - Используйте поиск в браузере (Ctrl+F или Cmd+F), чтобы найти нужный текст
   - Формат такой: `"key": "text"` — первая часть в кавычках перед двоеточием (`:`) и есть ключ
   - Например: `"menu.singleplayer": "Singleplayer"` — ключ здесь `menu.singleplayer`

### Использование ключей локализации модов

Если у вас установлены другие моды, вы также можете использовать их ключи локализации:

1. Проверьте документацию мода на наличие доступных ключей
2. Просмотрите языковые файлы мода, если он с открытым исходным кодом

## Собственные файлы локализации

Файлы локализации — это текстовые файлы со всем текстовым содержимым, которое должно быть доступно на нескольких языках. Каждому переводимому тексту соответствует уникальный ключ, чтобы Minecraft мог найти нужный перевод в файлах локализации.

- **Файл по умолчанию (en_us.json):**  
  Английский (США). Этот файл используется, когда не выбран другой языковой файл. Он служит резервным языковым файлом.

- **Файлы для других языков:**  
  Например, вы можете создать немецкий файл `de_de.json` для игроков, использующих немецкий язык.

### Как создать собственный файл локализации

Вам всегда нужен файл `en_us.json`! Без него у игры не будет резервного варианта, если что-то пойдёт не так или будет выбран неподдерживаемый язык.

1. **Откройте текстовый редактор:**  
   Используйте Блокнот (Windows), TextEdit (Mac) или любой простой текстовый редактор.

2. **Напишите JSON-код:**  
   Создайте файл со своими собственными ключами. Ключ — это уникальное имя, которое Minecraft использует для поиска текста. Например:
   
   ```json
   {
     "modpack_name.custom.localization.key": "Ваш собственный текст здесь",
     "modpack_name.another.key": "Ещё одно сообщение"
   }
   ```

3. **Сохраните файл:**  
   Сохраните файл как `en_us.json` для текста по умолчанию на английском.

Если теперь вы хотите добавить переведённые версии, например на немецкий, скопируйте содержимое файла `en_us.json` в новый файл и переводите только сам текст, НО НЕ ключи! Ключи должны остаться теми же, чтобы игра по-прежнему могла найти текст.

Для немецкого языка файл следует сохранить как `de_de.json`. Для других языков, пожалуйста, проверьте [эту страницу Minecraft Wiki](https://minecraft.wiki/w/Language), чтобы найти правильный код языка для вашего языка, и назовите файл соответственно. Ищите **"in-game locale code"** для вашего языка.

## Создание ресурс-пака Minecraft для MC 1.21.4

Теперь, когда ваши файлы локализации готовы, нам нужен способ загрузить их в Minecraft. Для этого мы будем использовать ресурс-пак. Мы сделаем так, чтобы он включался по умолчанию, и даже сможем скрыть его, если не хотим, чтобы пользователи модпака могли его менять.

**Ресурс-пак** — это ZIP-файл, который содержит файлы, изменяющие внешний вид и поведение игры.

### Шаги по созданию ресурс-пака

1. **Создайте новую папку:**  
   Создайте папку с названием вроде `my_custom_pack`, куда вы добавите свои собственные файлы локализации.

2. **Создайте файл пакета (`pack.mcmeta`):**  
   Внутри папки создайте файл `pack.mcmeta` со следующим содержимым:
   
   ```json
   {
     "pack": {
       "pack_format": 16,
       "description": "Мой собственный пакет с локализациями"
     }
   }
   ```
   
   *Примечание: `pack_format` 16 предназначен для Minecraft 1.21.4.*

3. **Добавьте файлы локализации:**  
   Внутри папки ресурс-пака создайте следующую структуру папок:
   
   ```
   my_custom_pack/
   ├── assets/
   │   └── minecraft/
   │       └── lang/
   │           ├── en_us.json
   │           └── de_de.json
   └── pack.mcmeta
   ```
   
   Поместите ваш собственный `en_us.json` (и любые другие языковые файлы, например `de_de.json`) в папку `lang`.

4. **Сделайте ZIP-архив ресурс-пака:**  
   Когда папка будет готова, **сожмите всю папку в ZIP-файл**. Назовите ZIP-файл **my_custom_pack.zip**. Это пример имени, которое используется по всему руководству.

## Куда поместить ресурс-пак

Поместите файл **my_custom_pack.zip** в папку **Minecraft Resourcepacks**. Обычно она находится здесь:

- **Windows:** `%appdata%\.minecraft\resourcepacks`
- **Mac:** `~/Library/Application Support/minecraft/resourcepacks`
- **Linux:** `~/.minecraft/resourcepacks`

> Для модпаков папка `resourcepacks` находится в каталоге экземпляра вашего пака.

## Автозагрузка пака с помощью "Resource Pack Overrides"

Мод **Resource Pack Overrides** позволяет включать ресурс-паки по умолчанию.

### Шаги для автозагрузки вашего пака

1. **Установите мод:**  
   Скачайте и установите мод с [CurseForge](https://www.curseforge.com/minecraft/mc-mods/resource-pack-overrides) или [Modrinth](https://modrinth.com/mod/resource-pack-overrides).

2. **Найдите файл конфигурации:**  
   Найдите файл `.minecraft/config/resourcepackoverrides.json`.  
   *Если файла нет, создайте его вручную.*

3. **Отредактируйте файл конфигурации:**  
   Откройте файл и добавьте ваш ресурс-пак в список `default_packs`, используя имя файла:
   
   ```json
   {
     "schema_version": 2,
     "default_packs": [
       "file/my_custom_pack.zip"
     ]
   }
   ```
   
   Это говорит Minecraft автоматически загружать ваш ресурс-пак при запуске игры.

   **Важно добавить префикс `file/`!**


*Примечание: ресурс-паки в списке применяются в обратном порядке. Это означает, что пак вверху списка будет отображаться ниже остальных в меню ресурс-паков игры.*

## Скрытие ресурс-пака на экране выбора

Вы можете скрыть свой ресурс-пак, чтобы игроки не видели его на экране выбора ресурс-паков.

### Как его скрыть

1. **Снова отредактируйте файл конфигурации:**  
   В том же файле `.minecraft/config/resourcepackoverrides.json` добавьте переопределение для вашего пака:
   
   ```json
   {
     "schema_version": 2,
     "default_packs": [
       "file/my_custom_pack.zip"
     ],
     "pack_overrides": {
       "file/my_custom_pack.zip": {
         "hidden": true
       }
     }
   }
   ```
   
   Эта конфигурация скроет **my_custom_pack.zip** с экрана выбора, но при этом будет автоматически загружать его.

## Использование новых ключей локализации в FancyMenu

Теперь, когда ваши собственные файлы локализации загружены, вы можете использовать новые ключи в макетах FancyMenu.

1. **Отредактируйте текстовый элемент:**  
   Откройте FancyMenu и выберите элемент, например Button или Text.

2. **Нажмите кнопку Placeholders:**  
   Найдите кнопку Placeholders в правом верхнем углу текстового редактора. (Если вы её не видите, возможно, элемент не поддерживает плейсхолдеры.)

3. **Вставьте плейсхолдер Localize Text:**  
   Плейсхолдер Localize Text отображается как JSON-фрагмент. Он выглядит так:
   
   ```json
   {"placeholder":"local","values":{"key":"localization.key"}}
   ```
   
   Замените `localization.key` на свой собственный ключ. Например, если вы хотите использовать свой ключ из файла локализации, измените его на:
   
   ```json
   {"placeholder":"local","values":{"key":"modpack_name.custom.localization.key"}}
   ```

Вот и всё! Плейсхолдер должен заменяться на фактический локализованный текст, когда вы не редактируете его в текстовом редакторе.

Имейте в виду, что плейсхолдер всегда будет локализовать текстовое содержимое в соответствии с текущим языком игры.

# Нетекстовый контент (изображения и т. д.)

FancyMenu также позволяет локализовать изображения и практически любой нужный вам элемент.

Для этого вам нужно использовать **loading requirements**.
Если точнее, требование **Is Game Language**.

Требование **Is Game Language** позволяет показывать элементы или макеты только при выборе определённого языка игры, так что, например, вы можете сделать два элемента Image с текстом: один для японского текста, если язык установлен на японский, и другой для английского текста, если язык установлен на английский.

Чтобы задать loading requirements для **элемента**, щёлкните по нему правой кнопкой мыши и выберите **Loading Requirements**.

Чтобы задать loading requirements для **всего макета**, щёлкните правой кнопкой мыши по фону редактора макета и выберите **Loading Requirements [Layout-Wide]**.
