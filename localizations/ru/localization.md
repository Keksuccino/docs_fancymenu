# Локализация макетов

Используйте плейсхолдер [**Localize Text**](/placeholders#localize-text) для переводимого текста:

```text
{"placeholder":"local","values":{"key":"modpack.menu.play"}}
```

Сначала FancyMenu проверяет активные языковые данные Minecraft. Если ключ там отсутствует, FancyMenu проверяет собственные файлы локализации. Если ключа нет ни в одном из источников, отображается сам ключ.

# Пользовательские файлы локализации FancyMenu

Поместите файлы в каталог:

```text
<game-directory>/config/fancymenu/custom_locals/
```

Создайте подкаталог для файлов локализации:

```text
custom_locals/
└── my_pack/
    └── text.json
```

Помещайте файлы локализации как минимум в один подкаталог `custom_locals`: файлы, расположенные непосредственно в корневом каталоге `custom_locals`, не загружаются. Вложенные подкаталоги поддерживаются.

Поддерживаемые форматы UTF-8:

| Расширение | Формат |
|---|---|
| `.json` | Объект JSON; вложенные объекты преобразуются в ключи, разделённые точками |
| `.lang` | Строки в формате `key=value` |
| `.properties` | Синтаксис Java Properties |

Пример JSON:

```json
{
  "modpack": {
    "menu": {
      "play": "Play"
    }
  }
}
```

Этот файл задаёт ключ `modpack.menu.play`.

FancyMenu объединяет поддерживаемые файлы из этих подкаталогов в один пользовательский словарь локализации. Используйте каждый ключ только в одном файле. Пользовательские файлы локализации не переключаются при смене выбранного в Minecraft языка. Для автоматического переключения используйте описанный ниже способ с пакетом ресурсов.

После изменения пользовательских файлов локализации перезапустите клиент.

# Текст для разных языков

Чтобы автоматически переключать текст в соответствии с выбранным в Minecraft языком, добавьте стандартные языковые файлы Minecraft в [пакет ресурсов](/resources#minecraft-resources-resource-packs):

```text
assets/<namespace>/lang/en_us.json
assets/<namespace>/lang/de_de.json
```

Укажите одинаковые ключи в файлах для каждого языка, включите пакет ресурсов, а затем получайте значения с помощью плейсхолдера [**Localize Text**](/placeholders#localize-text).

# Локализация изображений и элементов

Используйте условие [**Is Game Language**](/conditions#is-game-language), чтобы показывать разные элементы или макеты для разных кодов языков, например `en_us` и `de_de`.
