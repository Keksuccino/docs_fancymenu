# Локализация макетов

Используйте [**Localize Text** placeholder](./placeholders#localize-text-local) для переводимого текста:

```text
{"placeholder":"local","values":{"key":"modpack.menu.play"}}
```

FancyMenu сначала проверяет активные языковые данные Minecraft. Если ключ там отсутствует, он проверяет пользовательские файлы локализации FancyMenu. Если ни один из источников не содержит этот ключ, отображается сам ключ.

# Пользовательские файлы локализации FancyMenu

Поместите файлы сюда:

```text
<game-directory>/config/fancymenu/custom_locals/
```

Создайте подкаталог для файлов локализации:

```text
custom_locals/
└── my_pack/
    └── text.json
```

Размещайте файлы локализации как минимум в одном подкаталоге `custom_locals`; файлы, помещённые прямо в корень `custom_locals`, не загружаются. Поддерживаются вложенные подкаталоги.

Поддерживаемые форматы UTF-8:

| Расширение | Формат |
|---|---|
| `.json` | Объект JSON; вложенные объекты становятся ключами, разделёнными точками |
| `.lang` | Строки в формате `key=value` |
| `.properties` | Синтаксис свойств Java |

Пример JSON:

```json
{
  "modpack": {
    "menu": {
      "play": "Играть"
    }
  }
}
```

Это определяет `modpack.menu.play`.

FancyMenu объединяет поддерживаемые файлы из этих подкаталогов в один пользовательский словарь локализации. Используйте каждый ключ только в одном файле. Пользовательские файлы локализации не переключаются в зависимости от выбранного языка Minecraft; если вам нужно автоматическое переключение языка, используйте метод с ресурс-паком ниже.

Перезапустите клиент после редактирования пользовательских файлов локализации.

# Текст, зависящий от языка

Для автоматического переключения в соответствии с выбранным языком Minecraft предоставьте обычные языковые файлы Minecraft через [resource pack](./resources#minecraft-resources-resource-packs):

```text
assets/<namespace>/lang/en_us.json
assets/<namespace>/lang/de_de.json
```

Используйте одинаковые ключи в каждом языковом файле, включите ресурс-пак, затем считывайте их с помощью [**Localize Text** placeholder](./placeholders#localize-text-local).

# Локализация изображений и элементов

Используйте [**Is Game Language** requirement](./conditions#is-game-language-fancymenu_loading_requirement_is_language), чтобы показывать разные элементы или макеты для разных кодов языка, таких как `en_us` и `de_de`.
