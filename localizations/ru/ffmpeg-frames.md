# Как извлечь кадры из видео с помощью FFmpeg

*Эта страница была частично сгенерирована ИИ ChatGPT.*

FFmpeg — это бесплатный инструмент, который помогает работать с видео- и аудиофайлами. Одна из удобных возможностей — извлекать изображения (кадры) из видео, например из MP4-файла. Ниже показано, как сделать это шаг за шагом.

В следующих командах будет использоваться MP4, но FFmpeg также поддерживает другие видеоформаты, такие как AVI, MOV, MKV и MPEG.

# Что вам понадобится

Перед началом убедитесь, что у вас есть:

1. **Установленный FFmpeg**:

   - Скачайте FFmpeg с официального [сайта FFmpeg](https://ffmpeg.org/download.html). Обязательно загрузите сборку "full".
   - Следуйте инструкциям по установке для вашей операционной системы.

2. **Доступ к командной строке**:

   - Используйте терминал (Linux/macOS) или командную строку (Windows) для запуска команд FFmpeg.

3. **Видео файл**:

    - Подготовьте видеофайл MP4, AVI, MOV, MKV или MPEG.

# Перед началом

Перед запуском любых команд подготовьте следующее:

## Включите отображение расширений файлов

  - Важно видеть расширения файлов, такие как `.mp4` или `.avi`, при переименовании видеофайла.

    - **В Windows**:

      - Откройте Проводник.
      - Нажмите вкладку "Вид" вверху.
      - Поставьте галочку "Расширения имен файлов".

    - **В macOS**:

      - Откройте Finder.
      - Нажмите "Finder" в строке меню и выберите "Настройки".
      - Перейдите на вкладку "Дополнительно" и отметьте "Показывать все расширения имен файлов".

## Создайте папку для вывода

- Создайте папку с именем `output_frames` в каталоге, где находится исполняемый файл FFmpeg. Сюда будут сохраняться извлеченные кадры.

## Подготовьте видеофайл

- Поместите видеофайл, из которого нужно извлечь кадры, в ту же папку, где находится исполняемый файл FFmpeg.
- Переименуйте видеофайл в `input` и добавьте его расширение (например, `input.mp4`, `input.avi` и т. д.). Это гарантирует, что приведенные ниже команды будут работать без изменений.

# Как открыть FFmpeg

Прежде чем использовать FFmpeg, нужно открыть его через командную строку. Ниже описано, как сделать это шаг за шагом в Windows и macOS.

## В Windows:

1. **Откройте командную строку**:
   - Нажмите клавиши `Windows` и `R` одновременно, чтобы открыть окно "Выполнить".
   - Введите `cmd` и нажмите Enter. Откроется командная строка.

2. **Перейдите в папку FFmpeg**:
   - Нужно указать компьютеру, где находится FFmpeg. Используйте команду `cd`, чтобы перейти в папку, где вы сохранили FFmpeg.
   - Например, если FFmpeg находится в папке `ffmpeg-2024\bin` на рабочем столе, введите:
     ```bash
     cd C:\Users\YourUsername\Desktop\ffmpeg-2024\bin
     ```
     (Замените "YourUsername" на ваше фактическое имя пользователя на компьютере.)

3. **Проверьте, что FFmpeg работает**:
   - Чтобы убедиться, что FFmpeg работает, введите команду:
     ```bash
     ffmpeg -version
     ```
   - Если всё работает, на экране появится информация о FFmpeg.

## В macOS:

1. **Откройте Терминал**:
   - Нажмите `Command` и `Space` одновременно, чтобы открыть поиск Spotlight.
   - Введите `Terminal` и нажмите Enter, чтобы открыть его.

2. **Перейдите в папку FFmpeg**:
   - Используйте команду `cd`, чтобы перейти в папку, где вы сохранили FFmpeg.
   - Например, если FFmpeg находится в папке `Downloads`, введите:
     ```bash
     cd ~/Downloads/ffmpeg-2024/bin
     ```

3. **Проверьте, что FFmpeg работает**:
   - Чтобы убедиться, что FFmpeg готов к работе, введите команду:
     ```bash
     ./ffmpeg -version
     ```
   - Если FFmpeg работает, на экране появятся сведения о нем.

# Как сохранить все кадры

Чтобы сохранить все кадры из видео, используйте команду:

```bash
ffmpeg -i input.mp4 output_frames/%d.png
```

## Что это означает:

- `-i input.mp4`: это входной видеофайл. Он должен находиться в той же папке, что и исполняемый файл FFmpeg. Не забудьте заменить `input.mp4` на правильное имя файла и расширение.
- `output_frames/frame_%04d.png`: так будут сохраняться кадры:
- `output_frames/`: сохраняет все кадры в папку `output_frames`.
- `%d.png`: кадры будут называться числами вроде `1.png`, `2.png` и так далее, сохраняя порядок.

# Сохранение кадров в определенные моменты времени

Если вам не нужны все кадры, можно сохранять по одному кадру каждую секунду (или через другие интервалы). Используйте эту команду:

```bash
ffmpeg -i input.mp4 -vf "fps=1" output_frames/%d.png
```

## Что это означает:

- `-i input.mp4`: это входной видеофайл. Он должен находиться в той же папке, что и исполняемый файл FFmpeg. Не забудьте заменить `input.mp4` на правильное имя файла и расширение.
- `-vf "fps=1"`: сохраняет один кадр в секунду. Замените `1` на другое число, если хотите сохранять кадры чаще или реже (например, `fps=0.5` сохраняет один кадр каждые две секунды, а `fps=2` — два кадра в секунду).
- `output_frames/%d.png`: сохраняет кадры в папку `output_frames` с именами вроде `1.png`, `2.png` и так далее.

# Изменение размера и качества кадров

Вы также можете настроить размер и качество сохраняемых кадров. Вот как:

```bash
ffmpeg -i input.mp4 -vf "scale=1280:720" -q:v 2 output_frames/%d.png
```

## Что это означает:

- `-i input.mp4`: это входной видеофайл. Он должен находиться в той же папке, что и исполняемый файл FFmpeg. Не забудьте заменить `input.mp4` на правильное имя файла и расширение.
- `-vf "scale=1280:720"`: изменяет размер кадра до 1280x720 пикселей.
- `-q:v 2`: задает качество изображения (1 — лучшее, более высокие числа означают более низкое качество).
- `output_frames/%d.png`: сохраняет кадры в папку `output_frames` с именами вроде `1.png`, `2.png` и так далее.

# Советы по сохранению кадров

1. **Экономьте место**:

   - Если видео длинное, можно сохранять кадры через интервалы, а не каждый кадр. Это особенно полезно, если вы используете их как кадры анимации FMA в FancyMenu.

2. **Узнайте больше**:

   - Запустите `ffmpeg -h` в терминале, чтобы увидеть все возможности FFmpeg.
