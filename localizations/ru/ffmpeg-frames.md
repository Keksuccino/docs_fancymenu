# Извлечение кадров видео с помощью FFmpeg

1. Установите [FFmpeg](https://ffmpeg.org/download.html) и убедитесь, что команда `ffmpeg` доступна.
2. Откройте терминал в каталоге, где находится ваше видео.
3. Создайте выходной каталог:

   ```bash
   mkdir output_frames
   ```

4. Выполните команду, соответствующую нужному вам способу извлечения кадров. Замените `input.mp4` на имя файла вашего видео.

## Извлечь каждый кадр

```bash
ffmpeg -i input.mp4 output_frames/frame_%04d.png
```

## Извлечь с фиксированной частотой кадров

В этом примере создаётся 10 кадров в секунду. При необходимости измените `10`.

```bash
ffmpeg -i input.mp4 -vf "fps=10" output_frames/frame_%04d.png
```

## Изменить размер извлечённых кадров

В этом примере каждый кадр масштабируется до `1280×720`.

```bash
ffmpeg -i input.mp4 -vf "scale=1280:720" output_frames/frame_%04d.png
```

Нумерованные PNG-файлы в `output_frames` можно использовать для создания [анимации AFMA или классической FMA](./fma). Меньшее количество кадров и меньшие размеры снижают размер файла и расход памяти.
