# Редактор макетов

В редакторе макетов вы создаёте [макеты](/home#your-first-layout): добавляете элементы, перемещаете их, изменяете их размер и меняете меню вокруг них. Редактор показывает меню таким, каким его видят игроки, поэтому вы сразу можете оценить результат.

# Открытие редактора

1. Откройте меню, которое хотите изменить, например экран заголовка.
2. Нажмите **панель меню -> Настройка -> Настройка текущего экрана**, чтобы появился статус **Включено**.
3. Нажмите **панель меню -> Настройка -> Макеты -> Создать -> Для текущего экрана**.

- Пункт **Для всех экранов [универсальный]** создаёт [универсальный макет](/universal-layouts), который отображается во всех меню.
- Уже созданные макеты также перечислены в разделе **Макеты**. Наведите указатель на нужный макет и нажмите **Редактировать макет**.
- В любом меню сочетание `Ctrl + Alt + L` открывает макет, который вы редактировали последним. См. [сочетания клавиш панели меню](/home#menu-bar-shortcuts).

# Краткий обзор редактора

- Щёлкните правой кнопкой мыши по фону, чтобы открыть настройки всего макета и добавить элементы с помощью пункта **Новый элемент**.
- Щёлкните правой кнопкой мыши по элементу, чтобы открыть его настройки. См. [Элементы](/elements#settings-of-all-elements).
- Справа в разделе **Слои** перечислены все элементы макета. См. [Слои и группы](#layers-and-groups).
- Панель меню вверху:

| Меню | Содержимое |
|---|---|
| **Макет** | **Создать**, **Открыть**, **Сохранить**, **Сохранить как**, **Экспортировать макет для ИИ**, **Свойства макета** (то же, что и в контекстном меню фона), **Настройки** и **Закрыть редактор** |
| **Правка** | **Отменить**, **Повторить**, **Копировать**, **Вставить** и **Выбрать всё** |
| **Элемент** | Пункт **Создать** для добавления элементов и пункт **Удалённые элементы ванильной игры** для восстановления [удалённых элементов ванильной игры](/deleted-vanilla-elements) |
| **Окно** | **Виджеты редактора**, [сетка](#grid-and-anchor-overlay), [отображение привязок](#grid-and-anchor-overlay), **Элементы управления поворотом** и **Элементы управления наклоном** |

## Настройки макета

В контекстном меню фона собраны настройки самого макета, например:

- [**Фоны меню**](/menu-backgrounds) и [**Декоративные наложения**](/decoration-overlays)
- **Пользовательский заголовок экрана** — текст в верхней части некоторых меню, например «Настройки». В нём можно использовать [подстановки](/placeholders).
- **Настройки верхнего и нижнего колонтитулов** для [экранов с прокруткой](/customizing-scrollable-screens)
- **Индекс макета [порядок нескольких макетов]** и **Случайный режим** для [нескольких макетов в одном меню](/randomize-layouts)
- **Требования к загрузке [для всего макета]** — см. [Требования](/conditions#layout-wide-requirements)
- **Редактировать сценарий действия «Открыть экран»** и **Редактировать сценарий действия «Закрыть экран»** — см. [Сценарии действий](/action-scripts)
- **Параметры универсального макета** — только в [универсальных макетах](/universal-layouts)

# Работа с элементами

## Выбор элементов

- Щёлкните по элементу, чтобы выбрать его. Щёлкните по фону, чтобы снять выделение со всех элементов.
- Протяните указатель по фону, чтобы выделить все элементы внутри прямоугольной области.
- Щёлкните по элементу, удерживая `Ctrl`, чтобы добавить его к выделению или снять с него выделение.
- Нажмите `Ctrl + A`, чтобы выбрать все элементы.

Щелчки, выделение прямоугольной областью и сочетание `Ctrl + A` не затрагивают элементы, [скрытые в разделе «Слои»](#hiding-and-renaming).

## Перемещение

- Перетащите элемент, чтобы переместить его. Чтобы переместить несколько выбранных элементов, удерживайте `Ctrl` в начале перетаскивания. Если не удерживать `Ctrl`, щелчок выделит только тот элемент, по которому вы щёлкнули.
- Клавиши со стрелками перемещают выбранные элементы на один пиксель.
- Во время перетаскивания отображаются точки привязки. Наведите элемент на другую точку привязки или элемент, чтобы привязать его к ним. См. [Расположение элементов](/positioning-elements).
- Перетащите элемент в [область прокрутки](/scrollable-areas), чтобы поместить его внутрь.

## Изменение размера

Перетащите край или угол выбранного элемента. Удерживайте `Shift`, чтобы сохранить пропорции.

Изменять размер можно, только если выбран один элемент.

## Поворот и наклон

У выбранных элементов, поддерживающих эту функцию, отображаются элементы управления для [поворота и наклона](/rotating-elements). Удерживайте `Shift` во время перетаскивания, чтобы поворачивать или наклонять элемент с заданным шагом: 45° для поворота и 15° для наклона.

Пункты **Окно -> Элементы управления поворотом** и **Элементы управления наклоном** скрывают соответствующие элементы управления.

## Копирование, вставка и удаление

- `Ctrl + C` копирует выбранные элементы, а `Ctrl + V` вставляет их. Копии размещаются поверх оригиналов и выделяются — вы можете сразу перетащить их в другое место.
- Копировать элементы в другой макет тоже можно, пока игра не закрыта.
- Клавиша `Delete` удаляет выбранные элементы. Элементы ванильной игры только скрываются: восстановить их можно через **Элемент -> Удалённые элементы ванильной игры**.
- При удалении области прокрутки появится вопрос, нужно ли также удалить её содержимое или оставить его в макете.

## Отмена и повтор действий

`Ctrl + Z` отменяет последнее изменение, а `Ctrl + Y` повторяет его. Эти команды также доступны в меню **Правка**.

## Невидимые элементы

Игроки не видят элементы [«Аудио»](/elements#audio), [«Перетаскиватель»](/dragger), [«Аниматор элементов»](/element-animator), [«Контроллер музыки»](/elements#music-controller) и [«Бегущая строка»](/elements#ticker). В редакторе они отображаются в виде цветных прямоугольников с названиями, чтобы их можно было находить, перемещать и изменять их размер.

- Пункт **Цвет в редакторе** в контекстном меню элемента меняет цвет прямоугольника. Это, например, помогает различать несколько бегущих строк. Цвета задаются в формате `#RRGGBB`, а с прозрачностью — `#RRGGBBAA`: через полупрозрачный цвет, например `#E30E2366`, видно, что находится за прямоугольником.
- Название в прямоугольнике — это имя слоя элемента. См. [Скрытие и переименование](#hiding-and-renaming).

Игроки никогда не видят прямоугольник, его цвет или название.

# Слои и группы

В разделе **Слои** перечислены все элементы макета, начиная с самого верхнего: элемент отображается поверх всех элементов, находящихся ниже него в списке. Пункт **Окно -> Виджеты редактора -> Слои** показывает и скрывает этот раздел.

<img width="800" alt="Перетаскивание слоя «Фон новостей» ниже слоя «Текст новостей», чтобы после снятия выделения появились примечания к обновлению; затем добавление группы, помещение в неё обоих слоёв, скрытие и показ группы с помощью значка глаза и сворачивание группы" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/layout_editor_layers.gif?raw=true">

## Изменение порядка

- Щёлкните по слою, чтобы выбрать соответствующий элемент, а затем перетащите слой вверх или вниз. Линия покажет, куда он будет перемещён. Все выбранные слои перемещаются вместе.
- Или щёлкните правой кнопкой мыши по элементу или его слою и выберите **Переместить на один слой вверх** или **Переместить на один слой вниз**.

В редакторе выбранные элементы всегда отображаются поверх остальных. Снимите с них выделение, чтобы увидеть фактический порядок.

В некоторых версиях Minecraft элементы [«Сущность игрока»](/elements#player-entity) и [«Предмет»](/elements#item) отображаются поверх всех остальных независимо от своего слоя. См. [Известные проблемы](/known-issues#1-player-entity--item-elements-are-always-in-front-of-everything).

## Элементы ванильной игры

Строка **Элементы ванильной игры** обозначает все элементы самого меню, например его кнопки. Их порядок изменить нельзя, но кнопка справа от строки позволяет поместить все ваши элементы позади них или перед ними. Она выполняет то же действие, что и пункт **Пользовательские элементы позади элементов ванильной игры** в контекстном меню фона.

## Скрытие и переименование

- Значок глаза у слоя скрывает соответствующий элемент в редакторе, чтобы он не мешал работе с другими элементами. Нажмите на значок ещё раз, чтобы показать элемент.
- Скрытые элементы нельзя выбирать, перемещать, копировать или удалять. Игроки по-прежнему видят их — они скрыты только в редакторе. Макет запоминает, какие элементы вы скрыли.
- Щёлкните правой кнопкой мыши по слою и выберите **Переименовать слой**, чтобы дать ему более понятное имя, например `Панель новостей`. Это то же самое, что и параметр **Отображаемое имя в редакторе** у элемента. Игроки его не видят.

## Группы

Группы объединяют связанные слои под одним именем, например все части панели новостей. Они только упорядочивают список: элементы отображаются и работают как прежде.

- Щёлкните правой кнопкой мыши в разделе «Слои» и выберите **Добавить группу**. Группа появится под слоями.
- Перетащите слои на группу, чтобы добавить их в неё. Чтобы извлечь слои из группы, перетащите их за её пределы.
- Щёлкните по группе, чтобы выбрать все её элементы. Перетащите её, чтобы одновременно переместить все элементы вверх или вниз.
- Стрелка у группы сворачивает и разворачивает её слои, а значок глаза скрывает или показывает их все.
- Щёлкните правой кнопкой мыши по группе, чтобы переименовать её, переместить на один слой вверх или вниз либо удалить. При выборе пункта **Удалить группу** её элементы сохраняются.

Команды **Переместить на один слой вверх** и **Переместить на один слой вниз** оставляют элемент внутри группы. Чтобы извлечь его из группы, перетащите его слой за её пределы.

Макет сохраняет группы и сведения о том, какие из них свёрнуты.

## Области прокрутки

Элементы в [области прокрутки](/scrollable-areas) отображаются в списке с отступом под слоем этой области.

- Перетащите слой на нижнюю половину слоя области, чтобы поместить элемент внутрь. Чтобы извлечь его, перетащите слой в промежуток между другими слоями. Элемент останется на прежнем месте на экране.
- Стрелка у слоя области сворачивает и разворачивает её элементы.
- Элементы в области не входят ни в одну группу. Они перемещаются вместе с областью.

# Сетка и отображение привязок

В меню **Окно** находятся настройки вспомогательных инструментов редактора:

- Пункт **Сетка** показывает линии сетки; сочетание `Ctrl + G` включает и выключает их. Параметр **Размер сетки** задаёт расстояние между линиями.
- **Привязка к сетке** заставляет перетаскиваемый элемент привязываться к линиям сетки, когда она отображается. Параметр **Сила привязки к сетке** задаёт, насколько сильно работает привязка.
- **Видимость отображения привязок** задаёт, когда показываются точки привязки:
  - **Показывать при перетаскивании элементов** — во время перетаскивания элементов.
  - **Всегда показывать** — постоянно.
  - **Показывать при нажатии клавиши («O»)** — пока удерживается клавиша `O`.
  - **Отключено** — не показывать никогда.
- **Привязка при наведении на область** определяет, будет ли изменяться привязка элемента, если навести его на точку привязки. Параметр **Привязка при наведении на элемент** добавляет другие элементы в качестве точек привязки. Для его работы также должен быть включён параметр **Привязка при наведении на область**.

# Сохранение и закрытие

- Сочетание `Ctrl + S` или пункт **Макет -> Сохранить** сохраняет макет. При первом сохранении FancyMenu запросит имя файла.
- Пункт **Макет -> Сохранить как** сохраняет макет в новый файл.
- Если есть несохранённые изменения, на панели меню отображается надпись **\* Несохранённые изменения! \***.
- Кнопка X справа на панели меню или пункт **Макет -> Закрыть редактор** закрывает редактор. Если есть несохранённые изменения, сначала появится запрос на подтверждение.

# Сочетания клавиш

В macOS используйте `Cmd` вместо `Ctrl`.

| Сочетание клавиш | Действие |
|---|---|
| `Ctrl + S` | Сохранить |
| `Ctrl + Z` | Отменить |
| `Ctrl + Y` | Повторить |
| `Ctrl + C` | Копировать выбранные элементы |
| `Ctrl + V` | Вставить |
| `Ctrl + A` | Выбрать все элементы |
| `Delete` | Удалить выбранные элементы |
| Клавиши со стрелками | Переместить выбранные элементы на один пиксель |
| Щелчок с `Ctrl` | Добавить элемент к выделению или снять с него выделение |
| Перетаскивание с `Ctrl` | Переместить несколько выбранных элементов |
| Изменение размера с `Shift` | Сохранить пропорции |
| Поворот или наклон с `Shift` | Поворачивать или наклонять с заданным шагом |
| `Ctrl + G` | Включить или выключить сетку |
| Удерживать `O` | Показывать точки привязки при выборе параметра **Показывать при нажатии клавиши («O»)** |

> [!TIP]
> В текстовом редакторе используются собственные сочетания клавиш. См. [Текст в меню](/text-in-menus#the-text-editor). В окнах, например в окне [сценариев действий](/action-scripts#shortcuts), сочетания клавиш перечислены на соответствующих страницах.
