# Слайд-шоу

Слайд-шоу показывает изображения одно за другим, плавно переходя от одного к следующему. Например, так можно демонстрировать скриншоты из мира вашей сборки.

Слайд-шоу можно использовать как [фон меню](/menu-backgrounds) или разместить в отдельной области экрана с помощью [элемента «Слайд-шоу»](/elements#slideshow).

# Создание слайд-шоу

1. Откройте папку `slideshows` в каталоге `config/fancymenu/` вашей игры. Пункт **строка меню -> Tools -> Open FancyMenu Directory** открывает каталог `config/fancymenu/`.
2. Создайте в ней папку для слайд-шоу, например `world_tour`. Название может быть любым.
3. Поместите в неё файл [`properties.txt`](#propertiestxt) и папку `images` с [изображениями](#the-images). Файл [`overlay.png`](#overlay) добавлять необязательно.
4. Перезагрузите FancyMenu через **строка меню -> Customization -> Reload FancyMenu** или сочетанием `Ctrl + Alt + R` (`Cmd + Alt + R` в macOS) либо перезапустите игру.

```text
config/fancymenu/slideshows/
└── world_tour/
    ├── properties.txt
    ├── overlay.png
    └── images/
        ├── 01_river_valley.png
        ├── 02_cherry_grove.png
        └── 03_coast.png
```

# Изображения

- Поддерживаются только файлы PNG и JPG с расширениями `.png` или `.jpg`. Файлы `.jpeg` нужно переименовать в `.jpg`.
- Изображения показываются в алфавитном порядке по именам файлов. Числа сортируются как буквы, поэтому `10.png` будет перед `2.png`. Добавляйте нули в начале, например `01`, `02` … `10`.
- У всех изображений должен быть одинаковый размер. Формат слайд-шоу определяется первым изображением, а остальные растягиваются под него.
- Файлы в папках внутри `images` не учитываются.

# properties.txt

```text
type = slideshow

slideshow-meta {
  name = world_tour
  duration = 5.0
  fadespeed = 5.0
  randomize = false
}
```

| Параметр | Описание |
|---|---|
| `name` | Название, по которому можно выбрать слайд-шоу. У каждого слайд-шоу должно быть своё название. |
| `duration` | Время в секундах от смены одного изображения до следующего, включая переход. Если переход длится дольше, следующая смена произойдёт после его завершения. |
| `fadespeed` | Скорость перехода от одного изображения к следующему. При значении `1.0` переход занимает около 6 секунд, при `3.0` — около 2 секунд. Значение должно быть больше `0`. |
| `randomize` | При значении `true` изображения показываются в случайном порядке, без повторения одного и того же изображения дважды подряд. При значении `false` они показываются в порядке имён файлов. |

Обязателен только параметр `name`. Для остальных параметров по умолчанию используются значения `duration = 10.0`, `fadespeed = 1.0` и `randomize = false`. Не изменяйте строки `type = slideshow` и `slideshow-meta {`, указывайте по одному параметру на строку и используйте точку в десятичных числах, например `2.5`.

В слайд-шоу, созданных для старых версий, могут встречаться строки `width`, `height`, `x` и `y`. Они ни на что не влияют: положение и размер слайд-шоу определяются фоном или элементом.

# Наложение

Файл `overlay.png`, расположенный рядом с `properties.txt`, отображается поверх каждого изображения и растягивается до размера слайд-шоу. Он не меняется вместе с изображениями, поэтому подходит для рамок, виньеток или логотипа в углу. Изображения видны через прозрачные участки наложения.

Наложение относится к слайд-шоу, поэтому оно отображается везде, где показывается слайд-шоу. Чтобы использовать одни и те же изображения с рамкой и без неё, создайте два слайд-шоу.

# Использование слайд-шоу

## В качестве фона меню

<img width="800" alt="Открытие раздела Menu Backgrounds, выбор Slideshow в редакторе макета, включение Show Background и выбор world_tour в Choose Slideshow; предварительный просмотр переключается на следующее изображение, после чего слайд-шоу показывается за кнопками экрана заголовка" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/slideshows_background.gif?raw=true">

1. В [редакторе макета](/layout-editor) щёлкните правой кнопкой мыши по фону и откройте **Menu Backgrounds -> Slideshow**.
2. Нажмите **Show Background**, чтобы включить отображение фона.
3. Нажмите **Slideshow Name**, выберите слайд-шоу и нажмите **Done**. Справа будет отображаться его предварительный просмотр.

Кнопка **Clear Slideshow** удаляет слайд-шоу. Информацию о сочетании слайд-шоу с другими фонами см. в разделе [Фоны меню](/menu-backgrounds).

Слайд-шоу растягивается на весь экран. Чтобы сохранить пропорции изображений, включите параметр **Preserve Background Aspect Ratio** в разделе **Menu Backgrounds**. В этом случае слайд-шоу заполнит экран, а изображение будет обрезано по бокам либо сверху и снизу.

## В качестве элемента

<img width="800" alt="Экран заголовка с кнопками слева и элементом «Слайд-шоу» справа, который плавно переключает скриншоты из мира Minecraft" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/slideshows_element.gif?raw=true">

1. В редакторе макета щёлкните правой кнопкой мыши по свободному месту и добавьте слайд-шоу через **New Element**.
2. Щёлкните правой кнопкой мыши по элементу, нажмите **Slideshow** и выберите слайд-шоу. Форма элемента будет соответствовать форме его изображений.
3. Перемещайте и изменяйте его размер, как любой другой элемент. Параметр **Restore Aspect Ratio** изменяет ширину, подстраивая её под высоту, чтобы изображения не растягивались.

## Предварительная загрузка

Каждое изображение загружается при первом показе, поэтому крупные изображения могут появиться с небольшой задержкой. Чтобы загрузить все изображения и наложение во время запуска игры, добавьте слайд-шоу через **Add Slideshow** в разделе **строка меню -> Customization -> Pre-Load Resources**. См. [Предварительная загрузка ресурсов](/preload-layouts#pre-loading-slideshows--panoramas).

# Полезно знать

- Все места, где показывается одно и то же слайд-шоу, отображают одно и то же изображение одновременно, даже если это разные меню.
- Слайд-шоу работает только тогда, когда где-либо отображается. Если после перерыва дольше, чем значение `duration`, оно снова появится, то сразу перейдёт к следующему изображению.
- При перезагрузке FancyMenu все слайд-шоу запускаются заново. Первое изображение после запуска показывается вдвое меньше времени, чем остальные.
- Слайд-шоу относятся к загруженному [профилю](/profiles).
- Если слайд-шоу отсутствует в списке **Choose Slideshow**, значит, оно не загрузилось. В журнале игры `logs/latest.log` указана причина, например отсутствие `name`, `properties.txt` или папки `images`.
- В Windows включите отображение расширений файлов в Проводнике, чтобы случайно не создать файл `properties.txt.txt`.
- Фиолетовая с чёрным шахматная сетка означает, что слайд-шоу не выбрано или в макете указано название слайд-шоу, которого больше нет.
- Если у двух слайд-шоу совпадает значение `name`, будет показано только одно из них.
- В **Debug Overlay** (`Ctrl + Alt + D`) отображается количество слайд-шоу и изображений, загруженных FancyMenu.
