# Слайд-шоу

У каждого слайд-шоу есть свой каталог ниже:

```text
<game-directory>/config/fancymenu/slideshows/
```

`<game-directory>` — это активный экземпляр лаунчера, который может отличаться от обычного каталога `.minecraft`.

# Структура каталога

```text
<game-directory>/config/fancymenu/slideshows/
└── myslideshow/
    ├── properties.txt
    ├── overlay.png          # необязательно
    └── images/
        ├── image_01.png
        └── image_02.jpg
```

Изображения должны иметь расширение `.png` или `.jpg`; другие расширения, включая `.jpeg`, игнорируются.

Если `randomize = false`, изображения воспроизводятся в алфавитном порядке имени файла без учёта регистра. Используйте имена с ведущими нулями, например `image_01.png`, `image_02.png` и `image_10.png`.

# `properties.txt`

```text
type = slideshow

slideshow-meta {
  name = cool_slideshow
  width = 1920
  height = 1080
  x = 0
  y = 0
  duration = 5.0
  fadespeed = 12.0
  randomize = false
}
```

| Свойство | Значение |
|---|---|
| `name` | Обязательный, чувствительный к регистру идентификатор во время выполнения; держите его уникальным |
| `width`, `height` | Базовый размер в пикселях с учётом масштаба GUI и исходное соотношение сторон |
| `x`, `y` | Базовая позиция верхнего левого угла; обычные элементы и фоны используют собственную позицию, поэтому оставляйте здесь `0` |
| `duration` | Минимальное количество секунд между началом переходов; включает время затухания и должно быть больше `0` |
| `fadespeed` | Множитель скорости затухания; `1.0` — значение по умолчанию, более высокие значения ускоряют затухание, и значение должно быть больше `0` |
| `randomize` | `true` для случайного выбора или `false` для порядка по имени файла |

Только `name` является обязательным. Значения по умолчанию: `width = 50`, `height = 50`, `x = 0`, `y = 0`, `duration = 10.0`, `fadespeed = 1.0` и `randomize = false`. Оставляйте `type = slideshow` и `slideshow-meta` без изменений; записывайте по одной паре `key = value` на строку и используйте точку для десятичных чисел.

Макеты выбирают значение `name`, а не имя каталога. Дубликаты имён не отклоняются, и порядок сканирования каталогов определяет, какое слайд-шоу останется доступным. Старайтесь делать имена уникальными в пределах каталога слайд-шоу.

В случайном режиме выбор делается независимо при каждом переходе, и система избегает немедленного повтора, когда доступно несколько изображений. Время измеряется в реальном времени; если затухание длится дольше, чем `duration`, следующий переход откладывается, а возврат к слайд-шоу после его скрытия может сразу продвинуть его вперёд.

# Использование слайд-шоу

Перезагрузите FancyMenu через **Настройка -> Перезагрузить FancyMenu** или перезапустите клиент. Используйте элемент [**Слайд-шоу**](./elements#slideshow) или щёлкните правой кнопкой мыши по фону редактора макетов и выберите [**Фоны меню**](./menu-backgrounds) -> **Слайд-шоу**.
