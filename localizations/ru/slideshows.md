# Слайд-шоу

FancyMenu позволяет добавлять слайд-шоу и отображать их в меню и в качестве фона меню.

> **ВАЖНО**: Если вы используете Windows, не забудьте включить [отображение расширений файлов](https://vtcri.kayako.com/article/296-view-file-extensions-windows-10), иначе позже вы не сможете увидеть важные части имён файлов!
{.is-warning}

# Создание слайд-шоу

Каждое слайд-шоу должно находиться в собственной папке **внутри** каталога slideshows, расположенного по пути `/config/fancymenu/slideshows/`.

![1](https://user-images.githubusercontent.com/35544624/105209961-b823e600-5b4a-11eb-8ed2-1016d3b05815.png)

Чтобы система распознала слайд-шоу как таковое, в папке слайд-шоу должен быть файл свойств. Поэтому, если вы назвали папку слайд-шоу `myslideshow`, файл свойств должен находиться по пути `/config/fancymenu/slideshows/myslideshow/properties.txt`.

**Этот файл всегда должен называться `properties.txt`!**
Пока что просто создайте **пустой** файл свойств и переходите к следующему шагу.

![2](https://user-images.githubusercontent.com/35544624/105210016-cbcf4c80-5b4a-11eb-84ad-9aa735340287.png)

## Добавление изображений

Слайд-шоу нужны изображения (ну да), так что давайте добавим их!

> Изображения для слайд-шоу должны быть файлами **PNG**! Никаких JPEG, GIF, APNG или FMA!
{.is-danger}

Все изображения вашего слайд-шоу помещаются в дополнительную папку **внутри** папки слайд-шоу (`myslideshow` в примере выше).
Эта папка должна называться `images`.

![3](https://user-images.githubusercontent.com/35544624/105210833-d9d19d00-5b4b-11eb-8ae7-528ad156e27a.png)

Теперь поместите все изображения слайд-шоу в папку `images`.
Они сортируются по алфавиту (с учётом чисел), так что просто называйте их, например, `image_1.png`, `image_2.png` и так далее.
В моём примере `image_1.png` будет показан первым, а `image_2.png` — после него.

## Добавление содержимого в файл свойств

Сначала вы создали пустой файл `properties.txt` в папке слайд-шоу.
Теперь в этот файл нужно добавить несколько важных параметров.

Каждый файл свойств слайд-шоу должен выглядеть так:

```
type = slideshow

slideshow-meta {
   name = cool_slideshow
   width = 1920
   height = 1080
   x = 0
   y = 0
   duration = 5.0
   fadespeed = 12.0
   randomize = false
}
```
Изменять можно только переменные внутри секции `slideshow-meta`!

### name

Это имя, а точнее идентификатор, вашего слайд-шоу.
Имена слайд-шоу должны быть **уникальными**, поэтому невозможно иметь два слайд-шоу с одинаковым именем!

### width | height

Базовые `width` и `height` вашего слайд-шоу.
Используются FancyMenu для расчёта соотношения сторон.

### x | y

Позиция `x` и `y` вашего слайд-шоу.
Скорее для отладки, так что просто установите оба значения в `0`.

### duration

Длительность в **секундах**, в течение которой каждое изображение отображается перед переходом к следующему.
Поддерживаются десятичные значения!

### fadespeed

Скорость анимации затухания при переходе к следующему изображению.
Это значение является множителем скорости. Например, `1.0` — скорость по умолчанию, `2.0` удваивает скорость, а `0.5` сделает её в два раза медленнее обычной.
Отрицательные значения не поддерживаются.

### randomize

Должны ли изображения слайд-шоу воспроизводиться в случайном порядке (`true`) или нет (`false`).

# Использование слайд-шоу

Все важные шаги выполнены, и теперь ваше слайд-шоу должно быть готово, так что давайте проверим его!

Чтобы загрузить ваше новое (или отредактированное) слайд-шоу в FancyMenu, перезагрузите мод через **Customization -> Reload FancyMenu**.

Теперь вы можете использовать своё слайд-шоу в элементе **Slideshow** или как фон меню (щелкните правой кнопкой мыши по фону редактора макета -> **Menu Background**).
