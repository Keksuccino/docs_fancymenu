# Предзагрузка ресурсов

В некоторых случаях рекомендуется предварительно загружать ресурсы.
Это особенно полезно для изображений высокого разрешения, аудиофайлов и веб-ресурсов в целом.

Предзагрузка ресурсов может помочь устранить возможное мерцание изображений или ситуацию, когда аудиофайлы запускаются недостаточно быстро.

Также рекомендуется предварительно загружать анимации (файлы AFMA/FMA), чтобы они воспроизводились плавно, без задержек и без появления чёрного экрана при первой загрузке.

# Добавление ресурсов в предзагрузчик

Чтобы добавить ресурс в предзагрузчик ресурсов FancyMenu, просто нажмите **Предзагрузка ресурсов** в разделе **Настройка**.

<br>

<img width="350" alt="Скриншот_1" src="https://github.com/Keksuccino/FancyMenu/assets/35544624/3265da80-1bbc-4634-bd94-ba2795d7e3f2">

Это откроет меню, в котором можно добавить локальные ресурсы, веб-ресурсы и ресурсы пакетов ресурсов в список.

Каждый ресурс из этого списка будет предварительно загружаться каждый раз, когда игра перезагружает свои ресурсы, то есть по сути каждый раз, когда виден экран загрузки ресурсов.

# Предзагрузка слайдшоу и панорам

Вы также можете добавить слайдшоу и панорамы в список ресурсов для предзагрузки — это поможет устранить проблемы, когда изображения панорамы или слайдшоу сначала отображаются чёрными/отсутствующими либо на мгновение мерцают.
