# Фоны меню

У экрана макета может быть собственный фон: изображение, анимация, панорама, слайд-шоу, видео, цвет, веб-сайт или шейдер. Он заменяет обычный фон экрана — например, панораму главного экрана, размытие других меню или мир на заднем плане меню паузы.

<img width="800" alt="Главный экран с пиксельным фоном: заснеженная долина ночью, северное сияние, полная луна и хижина с освещёнными окнами" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_hero.png?raw=true">

> [!TIP]
> Чтобы задать одинаковый фон для всех меню, не создавая макеты, воспользуйтесь разделом [Глобальные настройки](/global-customizations#menu-backgrounds).

# Настройка фона

<img width="800" alt="Щелчок правой кнопкой мыши по фону редактора главного экрана, открытие раздела «Фоны меню» и пункта «Изображение», включение параметра «Показывать фон» и выбор изображения с помощью кнопки «Выбрать изображение»" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_image.gif?raw=true">

1. Откройте макет экрана в [редакторе макетов](/layout-editor).
2. Щёлкните правой кнопкой мыши по фону редактора и откройте раздел **Фоны меню**. Он также доступен в меню **строка меню -> Макет -> Свойства макета**.
3. Откройте тип фона, например **Изображение**.
4. Нажмите **Показывать фон**, чтобы установить значение **Включено**.
5. Настройте фон. Например, для фона типа «Изображение» нажмите **Выбрать изображение**.

<img width="800" alt="Меню «Фоны меню»: напротив пункта «Изображение» стоит галочка, а напротив всех остальных типов — крестик; ниже показаны настройки всех типов фона" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_menu.png?raw=true">

В разделе **Фоны меню** у каждого включённого типа стоит ✔, а у выключенного — ✖. Наведите курсор на тип, чтобы узнать, что он делает.

Чтобы вернуть обычный фон экрана, снова установите для параметра **Показывать фон** значение **Выключено**. Настройки сохранятся, и вы сможете включить фон позже.

# Типы фона

## Изображение

Изображение из ваших файлов, с веб-сайта или из ресурсов игры, растянутое на весь экран. Анимированные изображения тоже воспроизводятся. Поддерживаемые форматы перечислены в разделе [Изображения](/images).

- **Выбрать изображение**: изображение. Источники: [Ресурсы](/resources).
- **Выбрать запасное изображение**: показывается, если основное изображение не удаётся загрузить, например изображение из интернета при отсутствии подключения.
- **Перезапускать анимированные текстуры при открытии экрана**: [анимированное изображение](/animations) каждый раз запускается с начала при открытии экрана. Если параметр выключен, воспроизведение продолжается с того места, на котором остановилось.
- **Повторять текстуру**: изображение повторяется по всему экрану, а не растягивается. Подробнее: [Разбиение на девять частей и замощение](/nine-slicing-and-tiling).
- **Прокручивать широкие изображения слева направо**: широкое изображение, например фотография целого пейзажа, заполняет экран по высоте и медленно перемещается из стороны в сторону, ненадолго останавливаясь в каждом конце.
- **Эффект параллакса** и его настройки: изображение немного перемещается вслед за курсором мыши. Подробнее: [Эффект параллакса](/parallax#menu-backgrounds).

Параметр **Прокручивать широкие изображения слева направо** нельзя включить одновременно с параметром **Повторять текстуру** или **Эффект параллакса**.

## Цвет

Один цвет на весь экран.

- **Цвет [HEX]**: цвет, например `#1B2440`. Добавьте ещё две цифры, чтобы задать прозрачность, например `#1B2440C8`. Здесь также можно использовать [плейсхолдер](/placeholders).

Цвет располагается под всеми остальными фонами макета и заполняет их прозрачные участки. Подробнее: [Наложение фонов](#stacking-backgrounds).

## Кубическая панорама

Панорама, которая медленно вращается, как на главном экране. Панорамы создаются в папке `config/fancymenu/panoramas/`. Подробнее: [Панорамы](/panoramas).

- **Название панорамы**: открывает окно **Выбрать панораму**, где можно выбрать панораму и посмотреть её предварительный просмотр.
- **Очистить панораму**: удаляет панораму.

Если панорама не выбрана, на фоне отображается отсутствующая текстура Minecraft — фиолетово-чёрная шахматная сетка.

## Слайд-шоу

Последовательно показывает изображения из слайд-шоу. Слайд-шоу создаются в папке `config/fancymenu/slideshows/`. Подробнее: [Слайд-шоу](/slideshows).

- **Название слайд-шоу**: открывает окно **Выбрать слайд-шоу**, где можно выбрать одно из слайд-шоу.
- **Очистить слайд-шоу**: удаляет слайд-шоу.

Если слайд-шоу не выбрано, на фоне также отображается отсутствующая текстура Minecraft.

## Видео

Воспроизводит видео из ваших файлов, с веб-сайта или из ресурсов игры. Для этого нужен Watermedia. Подробнее: [Видео](/video#requirements). Если Watermedia не установлен, на фоне отображается сообщение со ссылками для скачивания.

- **Источник видео**: видео.
- **Зациклить видео**, **Громкость** и **Звуковой канал**: настройки воспроизведения.
- **Эффект параллакса** и его настройки: работают так же, как и для фона типа «Изображение».
- **Воспроизводить видео в редакторе макетов**: если параметр выключен, в редакторе макетов видео будет приостановлено.

С помощью [действий](/video) можно приостанавливать видео и менять его громкость и время воспроизведения. Для этого нужен идентификатор фона: нажмите **Скопировать идентификатор фона** в его настройках.

## Браузер

Веб-сайт на весь экран, как в элементе [«Браузер»](/elements#browser).

> [!IMPORTANT]
> Для работы браузера нужен мод [Rinku](https://modrinth.com/mod/rinku). Если он не установлен, фон будет красным и на нём появится сообщение об отсутствии Rinku.

- **URL-адрес**: веб-сайт. В URL можно использовать [плейсхолдеры](/placeholders).
- **Обрабатывать щелчки мышью**, **Обрабатывать прокрутку колёсиком мыши** и **Обрабатывать нажатия клавиш**: позволяют игрокам щёлкать по сайту, прокручивать его и вводить текст. Фокус ввода передаётся сайту при открытии экрана.
- **Перехватывать щелчки мышью**, **Перехватывать прокрутку колёсиком мыши** и **Перехватывать нажатия клавиш**: не позволяют событиям щелчка, прокрутки и нажатия клавиш выйти за пределы сайта, чтобы экран тоже на них не реагировал.
- **Выключить звук в браузере**, **Громкость аудио/видео**, **Зациклить видео** и **Скрыть элементы управления видео**: настройки мультимедиа на веб-сайте.

Кнопки и элементы перед фоном всегда первыми получают щелчки. В редакторе макетов вместо веб-сайта фон отображается в виде полос.

## Шейдер GLSL

Запускает шейдер — небольшую программу для видеокарты, которая может создавать, например, анимированные волны, звёзды или узоры. Поддерживаются и шейдеры с Shadertoy.

- **Исходный код шейдера**: код шейдера.
- **Показывать ошибки компиляции**: отображает на экране ошибки в коде. Выключите этот параметр для готовых макетов.

Остальные настройки, такие как дополнительные проходы, текстуры и время, описаны в [API шейдеров GLSL](/glsl-shader-api).

## Видео [Rinku]

Старый тип видеофона, для которого нужен Rinku. Он отображается в списке, только если включён, например в макетах, созданных в старых версиях. Вместо него используйте тип **Видео**.

# Настройки для всех фонов

Под списком типов в разделе **Фоны меню** находятся настройки, которые применяются ко всем фонам макета:

- **Сохранять соотношение сторон фона**: сохраняет пропорции фонов типа «Изображение», «Слайд-шоу» и «Видео». Они по-прежнему заполняют весь экран, а не поместившиеся части обрезаются. Если параметр выключен, фон растягивается на весь экран.
- **Затемнять пользовательский фон**: накладывает на фон тёмный полупрозрачный слой, как в меню Minecraft, чтобы кнопки и текст были заметнее.
- **Применять стандартное размытие фона**: размывает фон так же, как Minecraft размывает мир за меню. Сила размытия зависит от настройки **Размытие фона меню** в разделе **Настройки специальных возможностей** Minecraft. При значении `0` размытия нет.

Слева направо: без настроек, с параметром **Затемнять пользовательский фон** и с параметром **Применять стандартное размытие фона**.

# Наложение фонов

В одном макете можно включить несколько типов фона. Они накладываются друг на друга в следующем порядке, снизу вверх:

1. Цвет
2. Кубическая панорама
3. Изображение
4. Слайд-шоу
5. Видео
6. Видео [Rinku]
7. Браузер
8. Шейдер GLSL

Типы, добавленные другими модами, отображаются поверх всех остальных.

FancyMenu рисует за фонами чёрный слой, поэтому прозрачные участки изображения будут чёрными. Цветной фон под изображением заполнит эти участки своим цветом:

<img width="800" alt="Пиксельный пейзаж с прозрачным небом. На левой половине небо чёрное, а на правой его заполняет синий фон типа «Цвет»" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_stacking.png?raw=true">

Слева включено только изображение. Справа небо заполнено фоном типа «Цвет».

- Прозрачное изображение, слайд-шоу или шейдер поверх кубической панорамы работают по тому же принципу. Например, из них можно сделать рамку вокруг вращающейся панорамы.
- Видео никогда не бывает прозрачным. Оно перекрывает все фоны под ним, даже если не заполняет весь экран.

## Несколько макетов

Если на экране активны несколько макетов — например, [универсальный макет](/universal-layouts) и макет самого экрана, — их фоны тоже накладываются друг на друга:

- Макет с более высоким значением **Индекс макета [Порядок нескольких макетов]** находится сверху. Установите его в контекстном меню, открываемом щелчком правой кнопкой мыши по фону редактора.
- Если в одном из макетов включена [настройка для всех фонов](#settings-for-all-backgrounds), она применяется к фонам всех макетов.
- В редакторе макетов отображаются только фоны редактируемого макета.

# Полезно знать

- Элементы макета всегда отображаются поверх его фонов.
- Параметр **Скопировать идентификатор фона** в настройках каждого типа копирует идентификатор фона. Он нужен для действий и плейсхолдеров, управляющих фоном, например для [видео](/video).
- Параметр **Экспорт для ИИ** в настройках каждого типа копирует фон для [чата с ИИ](/export-for-ai).
- У экранов со списками, например у списка миров, есть собственные текстуры заголовка и нижнего колонтитула. Чтобы настроить их, щёлкните правой кнопкой мыши по фону редактора и откройте раздел **Настройки заголовка/нижнего колонтитула**.
