# Работа с параметрами Minecraft в FancyMenu

FancyMenu позволяет получать и изменять игровые настройки Minecraft (параметры) с помощью разных элементов интерфейса. В этом руководстве показано, как использовать кнопки, слайдеры и тикеры для работы с параметрами Minecraft в ваших пользовательских меню.

# Понимание параметров Minecraft

В Minecraft есть множество встроенных параметров, которые управляют всем: от графики до громкости звука. FancyMenu позволяет обращаться к этим параметрам по их именам.

Некоторые распространённые имена параметров:
- `soundCategory_master` - Основная громкость
- `soundCategory_music` - Громкость музыки
- `soundCategory_ambient` - Громкость фоновых звуков
- `soundCategory_players` - Громкость звуков игроков
- `soundCategory_blocks` - Громкость звуков блоков
- `fov` - Поле зрения
- `gamma` - Яркость
- `renderDistance` - Дальность прорисовки

# Отображение значений параметров

Вы можете показывать текущее значение любого параметра Minecraft с помощью специального плейсхолдера.

Плейсхолдер выглядит так:
```
{"placeholder":"minecraft_option_value","values":{"name":"option_name"}}
```

Замените `option_name` на фактическое имя параметра, значение которого нужно отобразить.

# Установка параметров с помощью кнопок

Кнопки можно использовать, чтобы задавать конкретные значения параметров Minecraft.

## Как настроить кнопку:

1. Создайте новый элемент Button
2. Установите надпись кнопки (то, что будет отображаться на ней)
3. Добавьте действие: щёлкните по кнопке правой кнопкой мыши → Edit Action Script → Add Action → Set Minecraft Option Value
4. В окне "Set Minecraft Option Value":
   - Name: введите имя параметра (например, `renderDistance`)
   - Value: введите значение, которое нужно установить (например, `16`)

## Пример: 

Создание кнопки, которая устанавливает дальность прорисовки на 16 чанков:
- Option Name: `renderDistance`
- Value: `16`
- Label: "Установить дальность прорисовки на 16 чанков"

# Установка параметров с помощью слайдеров

Слайдеры отлично подходят для параметров с диапазоном значений, например громкости или яркости.

## Как настроить слайдер:

1. Создайте новый элемент Slider
2. Укажите тип слайдера:
   - Для целых чисел (например, дальности прорисовки): выберите "Integer Range"
   - Для дробных чисел (например, громкости): выберите "Decimal Range"
3. Задайте минимальное и максимальное значения
4. Добавьте действие для установки параметра Minecraft:
   - Щёлкните правой кнопкой мыши → Edit Action Script → Add Action → Set Minecraft Option Value
   - Name: имя параметра
   - Value: `$$value` (эта специальная переменная содержит текущее значение слайдера)
5. Установите предварительно выбранное значение в текущее значение параметра:
   - Задайте "Pre-Selected Value" как `{"placeholder":"minecraft_option_value","values":{"name":"option_name"}}`

## Примеры форматов надписей на слайдере:

Чтобы показать текущее значение параметра в надписи слайдера, используйте:
```
Громкость: {"placeholder":"minecraft_option_value","values":{"name":"soundCategory_master"}}
```

Чтобы показать процент (полезно для громкости):
```
Громкость: {"placeholder":"calc","values":{"expression":"$$value * 100.0","decimal":"false"}}%
```

# Установка параметров с помощью тикеров

Тикеры — это невидимые элементы, которые могут автоматически менять параметры по расписанию.

## Как настроить тикер:

1. Создайте новый элемент Ticker
2. Настройте параметры тика:
   - Tick Mode: выберите, когда параметр должен обновляться
   - Tick Delay: задайте, как часто он обновляется (в миллисекундах)
3. Добавьте действие для установки параметра Minecraft:
   - Щёлкните правой кнопкой мыши → Edit Action Script → Add Action → Set Minecraft Option Value
   - Укажите имя параметра и значение

## Пример:

Установка gamma (яркости) на максимум при загрузке меню:
- Tick Mode: On Load Screen
- Name: `gamma`
- Value: `1.0`

# Частые сценарии использования

Вот несколько распространённых вариантов того, что можно делать, используя FancyMenu для установки и получения параметров Minecraft.

## Создание пользовательских слайдеров громкости

Слайдеры громкости — один из самых частых вариантов использования интеграции с параметрами Minecraft. Вот как создать пользовательский слайдер громкости музыки:

1. Создайте новый элемент Slider
2. Установите "Slider Type" в "Decimal Range"
3. Установите "Minimum Range Value" в "0.0"
4. Установите "Maximum Range Value" в "1.0"
5. Edit Action Script → Add Action → Set Minecraft Option Value
   - Установите Name в `soundCategory_music`
   - Установите Value в `$$value`
6. Установите "Pre-Selected Value" в `{"placeholder":"minecraft_option_value","values":{"name":"soundCategory_music"}}`
7. Чтобы отображать громкость в процентах, установите надпись так: 
   ```
   Музыка: {"placeholder":"calc","values":{"expression":"$$value * 100.0","decimal":"false"}}%
   ```

Можно создать похожие слайдеры для других категорий звука:
- Основная громкость: `soundCategory_master`
- Музыка: `soundCategory_music`
- Фоновые звуки: `soundCategory_ambient`
- Блоки: `soundCategory_blocks`
- Игроки: `soundCategory_players`
- Погода: `soundCategory_weather`

## Создание пользовательского слайдера FOV

Поле зрения (FOV) — важный графический параметр, определяющий, насколько широко вы видите в игре. Внутри параметр FOV использует значения от -1.0 до 1.0, но в интерфейсе отображается как от 30 до 110.

### Понимание сопоставления значений FOV
- Внутренний диапазон значений: от -1.0 до 1.0
- Отображаемый диапазон значений: от 30 до 110
- Формула сопоставления: `(internal_value + 1) * 40 + 30`

### Шаг 1: Создайте элемент Ticker для обновления текста FOV

Сначала нужен тикер, который будет проверять текущее значение FOV и устанавливать переменную с подходящим описанием:

1. Создайте новый элемент Ticker
2. Установите "Tick Mode" в "Normal" (чтобы он обновлялся постоянно)
3. Установите "Tick Delay" примерно на "10" (миллисекунд), чтобы избежать слишком частых проверок

Теперь нужно настроить действия для подписей FOV. Структура вашего сценария действий должна выглядеть так:

```
▶ Action Script
│
├─▶ IF (mapped FOV = 70)
│  └─■ Set Variable Value: fov_text:Normal
│
├─▶ ELSE-IF (mapped FOV = 110)
│  └─■ Set Variable Value: fov_text:Quake Pro
│
└─▶ ELSE
   └─■ Set Variable Value: fov_text:[calculated numeric value]
```

Настроим каждый пункт:

#### Настройка подписи FOV "Normal":
1. Щёлкните правой кнопкой мыши → Edit Action Script → Add Action
2. Нажмите "IF Statement", чтобы добавить условный блок
3. Задайте условие "Is Number" со следующими параметрами:
   - Compare Mode: "equals"
   - Number: `{"placeholder":"calc","values":{"decimal":"false","expression":"({"placeholder":"minecraft_option_value","values":{"name":"fov"}} + 1) * 40 + 30"}}`
   - Compare With: "70"
4. Внутри этого блока IF добавьте действие "Set Variable Value (FM Variable)" со значением:
   - Value: `fov_text:Normal`

#### Настройка подписи FOV "Quake Pro":
1. Внутри Action Script добавьте "ELSE-IF Statement"
2. Задайте условие "Is Number" со следующими параметрами:
   - Compare Mode: "equals"
   - Number: `{"placeholder":"calc","values":{"decimal":"false","expression":"({"placeholder":"minecraft_option_value","values":{"name":"fov"}} + 1) * 40 + 30"}}`
   - Compare With: "110"
3. Внутри этого блока ELSE-IF добавьте действие "Set Variable Value (FM Variable)" со значением:
   - Value: `fov_text:Quake Pro`

#### Настройка числовой подписи FOV:
1. Добавьте блок "ELSE Statement"
2. Внутри этого блока ELSE добавьте действие "Set Variable Value (FM Variable)" со значением:
   - Value: `fov_text:{"placeholder":"calc","values":{"decimal":"false","expression":"({"placeholder":"minecraft_option_value","values":{"name":"fov"}} + 1) * 40 + 30"}}`

### Шаг 2: Создайте слайдер FOV

1. Создайте новый элемент Slider
2. Установите "Slider Type" в "Decimal Range"
3. Установите "Minimum Range Value" в "-1.0"
4. Установите "Maximum Range Value" в "1.0"
5. Edit Action Script → Add Action → Set Minecraft Option Value
   - Установите Name в `fov`
   - Установите Value в `$$value`
6. Установите "Pre-Selected Value" в `{"placeholder":"minecraft_option_value","values":{"name":"fov"}}`

### Шаг 3: Задайте подпись слайдера

Установите подпись слайдера так, чтобы она просто отображала переменную текста FOV:

```
FOV: {"placeholder":"getvariable","values":{"name":"fov_text"}}
```

Эта подпись будет показывать:
- "FOV: Normal" при значении 70
- "FOV: Quake Pro" при значении 110  
- "FOV: 85" (или любое другое число) для всех остальных значений

### Советы по слайдерам FOV

- Внутренний диапазон значений слайдера — от -1.0 до 1.0, и его нужно преобразовать в диапазон от 30 до 110 для отображения
- Формула преобразования: `(internal_value + 1) * 40 + 30`
- Только два значения имеют специальные подписи: 70 (Normal) и 110 (Quake Pro)
- Значение FOV по умолчанию в Minecraft — 70 (что соответствует внутреннему значению 0.0)
- Переменная `fov_text` автоматически содержит либо специальную подпись, либо числовое значение

## Отображение значений параметров в текстовых элементах

Вы также можете показывать текущие значения параметров в элементах Text:

1. Создайте элемент Text
2. Для содержимого текста используйте плейсхолдер: `{"placeholder":"minecraft_option_value","values":{"name":"option_name"}}`

Например, чтобы показать текущую дальность прорисовки:
```
Текущая дальность прорисовки: {"placeholder":"minecraft_option_value","values":{"name":"renderDistance"}} чанков
```

# Поиск имён параметров

Вы можете узнать имена всех доступных параметров следующим образом:

  1. Создайте кнопку
  2. Щёлкните по ней правой кнопкой мыши
  3. Нажмите "Edit Action Script"
  4. Добавьте действие "Set Minecraft Option Value"
  5. При редактировании значения действия смотрите на подсказки выпадающего списка, когда начинаете вводить текст в поле "Name"
  
# Важные советы

- **Допустимые значения**: не все параметры принимают любые значения. Например:
  - Параметры громкости принимают значения от 0.0 до 1.0
  - Дальность прорисовки обычно принимает целые числа от 2 до 32
  - Булевы параметры (true/false), например `pauseOnLostFocus`, принимают "true" или "false"

- **Тестирование**: всегда проверяйте свои настройки, чтобы убедиться, что они работают как ожидается!

- **Визуальная обратная связь**: показывайте пользователям текущее значение с помощью описанных выше плейсхолдеров.
