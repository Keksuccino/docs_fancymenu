# Глобальные настройки

Глобальные настройки — это изменения FancyMenu, которые применяются ко всему интерфейсу игры.
Используйте их, когда вам нужен единый стиль и единое поведение везде, вместо редактирования каждого экрана отдельно.

> [!INFO]
> В отличие от большинства функций настройки FancyMenu, глобальные настройки работают даже если обычные настройки экранов отключены.
> Для них **не** требуется включать настройки для каждого экрана, поэтому одно изменение может сразу повлиять на все экраны.

Примеры использования:

- Использовать один общий стиль кнопок и ползунков для всех экранов.
- Глобально заменить фон меню, панораму и музыку меню.
- Применить глобальное поведение при запуске/в окне (масштаб GUI, полноэкранный режим, заголовок/значок окна).
- Глобально заменить стандартные текстуры кнопок без ресурс-пака.
- Глобально заменить стандартную музыку меню без ресурс-пака.

# Где их найти

Откройте **строку меню** FancyMenu, когда вы **не** находитесь в редакторе макетов, затем выберите **Customization -> Global Customizations**.

# Быстрый старт

1. Откройте **Customization -> Global Customizations**.
2. Выберите одну категорию для начала (например, **Custom Button Textures**).
3. Настройте параметры в этой категории (выбор ресурсов, переключатели или числовые поля).
4. Проверьте результат на нескольких экранах.
5. Точно настройте связанные параметры (например, прозрачность, стили подписей, границы nine-slice).

# Что можно настроить

## Глобальное поведение и запуск

- **Game Intro** (вступительное видео или анимация, которая воспроизводится до появления экрана титула)
- **Singleplayer Screen World Icons**
- **Multiplayer Screen Server Icons**
- **Seamless World Loading** (использует скриншот мира в качестве фона экрана загрузки мира)
- **Custom Window Icon**
- **Custom Window Title**
- **Default GUI Scale**
- **Force Fullscreen on Launch**

## Внешний вид кнопок

- **Custom Button Textures** (состояния Normal/Hover/Inactive, режим прозрачности, nine-slice + размеры границ)
- **Button Labels** (подчёркивание при наведении, базовый/наведённый цвет, масштаб, тень)

## Внешний вид ползунков

- **Custom Slider Textures**
- **Slider Background Texture** (текстура, режим прозрачности, nine-slice + размеры границ)
- **Slider Handle Textures** (состояния Normal/Hover/Inactive, nine-slice + размеры границ)
- **Slider Labels** (подчёркивание при наведении, базовый/наведённый цвет, масштаб, тень)

## Внешний вид меню и звук

- **Custom Menu Background Texture**
- **Custom Menu Background Panorama**
- **Play Vanilla Menu Music** (включение/отключение воспроизведения стандартной музыки меню)
- **Custom Menu Music Tracks**
- **Custom Button/Slider Click Sound**

# Custom Menu Music Tracks

Используйте **Custom Menu Music Tracks**, чтобы собрать случайный список треков для меню.

Настроенные пользовательские треки заменяют стандартную музыку меню в меню.

- Откройте **Custom Menu Music Tracks**, чтобы открыть **Manage Menu Music Tracks**.
- Используйте **Add Track**, чтобы добавить источники аудио.
- Используйте **Remove Track**, чтобы удалить одну запись.
- Используйте **Clear Tracks**, чтобы удалить все записи.
