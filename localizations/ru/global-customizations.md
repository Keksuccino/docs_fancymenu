# Глобальные настройки

Глобальные настройки применяют общие параметры интерфейса и запуска без редактирования макета каждого экрана. Они работают даже тогда, когда обычная настройка экранов отключена.

Типичные примеры:

- Использовать один общий стиль кнопок и ползунков для всех экранов.
- Глобально заменить фон меню, панораму и музыку меню.
- Применить общие параметры запуска/окна (масштаб интерфейса, полноэкранный режим, заголовок/значок окна).
- Глобально заменить текстуры ванильных кнопок без ресурс-пака.
- Глобально заменить ванильную музыку меню без ресурс-пака.

# Где их найти

Откройте **панель меню** FancyMenu, **не** находясь в редакторе макетов, затем выберите **Customization -> Global Customizations**.

# Что можно настроить

## Глобальное поведение и запуск

- [**Game Intro**](./game-intro) (видео или анимация заставки, которая воспроизводится перед экраном титульного меню)
- **Singleplayer Screen World Icons**
- **Multiplayer Screen Server Icons**
- [**Seamless World Loading**](./seamless-world-loading) (использует недавний скриншот мира в качестве фона экрана загрузки)
- [**Custom Window Icon**](./window-customization#custom-icon)
- [**Custom Window Title**](./window-customization#custom-title)
- **Default GUI Scale**
- **Force Fullscreen on Launch**

## Внешний вид кнопок

- **Custom Button Textures** (состояния Normal/Hover/Inactive, прозрачный режим, [nine-slice](./nine-slicing-and-tiling) + размеры рамок)
- **Button Labels** (подчеркивание при наведении, базовый/hover-цвет, масштаб, тень)

## Внешний вид ползунков

- **Custom Slider Textures**
- **Slider Background Texture** (текстура, прозрачный режим, [nine-slice](./nine-slicing-and-tiling) + размеры рамок)
- **Slider Handle Textures** (состояния Normal/Hover/Inactive, [nine-slice](./nine-slicing-and-tiling) + размеры рамок)
- **Slider Labels** (подчеркивание при наведении, базовый/hover-цвет, масштаб, тень)

## Внешний вид и звук меню

- [**Custom Menu Background Texture**](./menu-backgrounds)
- [**Custom Menu Background Panorama**](./panoramas)
- **Play Vanilla Menu Music** (включение/отключение воспроизведения ванильной музыки меню)
- [**Custom Menu Music Tracks**](./background-music)
- **Custom Button/Slider Click Sound**

# Custom Menu Music Tracks

Используйте **Custom Menu Music Tracks**, чтобы создать случайный список треков для меню.

> [!IMPORTANT]
> Глобальные пользовательские треки меню воспроизводятся только тогда, когда мир не загружен, например на экране титульного меню. Используйте элемент [**Audio**](./elements#audio) для звука меню внутри мира.

Настроенные треки используют звуковой канал Music и заменяют ванильную музыку меню в поддерживаемых меню без мира.

- Первый трек начинается примерно через пять секунд.
- Последующие треки запускаются через случайную задержку примерно от одной до тридцати секунд.
- Треки выбираются случайным образом.
- При наличии нескольких треков предыдущий трек не выбирается два раза подряд.

Управляйте списком треков через **Custom Menu Music Tracks**:

- Откройте **Custom Menu Music Tracks**, чтобы открыть **Manage Menu Music Tracks**.
- Используйте **Add Track**, чтобы добавить источники аудио.
- Используйте **Remove Track**, чтобы удалить одну запись.
- Используйте **Clear Tracks**, чтобы удалить все записи.
