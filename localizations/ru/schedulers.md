# Планировщики

Планировщики запускают [сценарий действий](/action-scripts) по таймеру: один раз после ожидания, несколько раз или многократно, пока их что-нибудь не остановит. Они работают в любом меню и во время игры, даже когда ни одно меню не открыто, и не привязаны к макету.

Планировщики — рекомендуемый способ настроить действия, которые должны произойти позже или повторяться. По возможности используйте их вместо [элементов «Тикер»](/elements#ticker).

<img width="800" alt="В блоке «Совет по выживанию» каждые 4 секунды появляется новый совет, потому что планировщик перемешивает список советов" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/schedulers_tips.gif?raw=true">

> [!CAUTION]
> Планировщик может запускать действия с файлами, сетью, командами, буфером обмена, пакетами ресурсов и ссылками, когда ни одно меню не открыто. Используйте планировщики только из профилей и файлов людей, которым доверяете.

# Добавление планировщика

<img width="800" alt="Открываем раздел «Управление планировщиками», нажимаем «Добавить планировщик» и назначаем ему действие Arrange List with Shuffle для списка tips" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/schedulers_add.gif?raw=true">

1. Откройте **строка меню -> Настройка -> Управление планировщиками**.
2. Нажмите **Добавить планировщик**. Откроется редактор сценариев действий.
3. Добавьте действия, которые должны выполняться при каждом запуске, и нажмите **Готово**. См. раздел [Сценарии действий](/action-scripts#making-an-action-script).

<img width="800" alt="Задаём новому планировщику имя random_tip в разделе «Изменить настройки», указываем задержку тика 4000 и включаем запуск при запуске игры, затем запускаем его — и подсказка в меню меняется" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/schedulers_start.gif?raw=true">

4. Новый планировщик появится со случайным ID. Нажмите на него, а затем — **Изменить настройки**.
5. Задайте ему **ID планировщика**, например `random_tip`, настройте [таймер](#settings) и нажмите **Готово**.
6. Нажмите **Запустить сейчас**, чтобы проверить его.

Все изменения, внесённые в разделе **Управление планировщиками**, сохраняются сразу.

В GIF-анимациях планировщик каждые 4 секунды выполняет действие [**Arrange List (FM Variable)**](/action-scripts#arrange-list-fm-variable) с параметром **Shuffle** для списка `tips`. Текстовый элемент показывает первую запись списка, поэтому на экране появляется случайный совет. Подробнее о работе списков и текста: [Действия со списками](/variables#list-actions).

# Настройки

| Настройка | Описание |
|---|---|
| **ID планировщика** | Имя, которое используют действия и условия. Допустимы только строчные буквы, цифры, `.`, `_` и `-`. |
| **Задержка запуска (мс)** | Время ожидания после запуска до первого выполнения. Значение `0` запускает планировщик сразу. |
| **Задержка тика (мс)** | Интервал между запусками. Значение `0` запускает его при каждом тике — 20 раз в секунду. |
| **Количество запусков** | Сколько раз планировщик выполнится, прежде чем остановится сам. Значение `0` оставляет его работающим, пока что-нибудь его не остановит. |
| **Запускать при запуске игры** | Запускает планировщик при каждом запуске игры. |

Время указывается в миллисекундах: `1000` — одна секунда, `60000` — одна минута, а `1800000` — полчаса.

# Запуск и остановка

Планировщик выполняется только после запуска:

- Если включён параметр **Запускать при запуске игры** — при запуске игры и после переключения [профилей](/profiles).
- При нажатии **Запустить сейчас** в разделе **Управление планировщиками**. Пока планировщик работает, эта кнопка называется **Остановить сейчас**.
- С помощью действия [**Start Scheduler**](/action-scripts#start-scheduler), указав ID планировщика. Например, это можно сделать в сценарии кнопки или [обработчика](/listeners).

Планировщик останавливается:

- Самостоятельно, после выполнения указанного **количества запусков**.
- При нажатии **Остановить сейчас** или с помощью действия [**Stop Scheduler**](/action-scripts#stop-scheduler), указав его ID.
- При переименовании или удалении, переключении [профиля](/profiles) и закрытии игры. После перезапуска снова выполняются только планировщики с включённым параметром **Запускать при запуске игры**.

Работающий планировщик нельзя запустить повторно: действие **Start Scheduler** ничего не сделает, пока он не остановится. Чтобы запустить его заново, сначала используйте **Stop Scheduler**, а затем **Start Scheduler**.

Условие [**Scheduler Is Running**](/conditions#scheduler-is-running) проверяет, работает ли планировщик. Например, с его помощью можно показывать кнопку остановки, только пока планировщик работает.

## Только при открытом экране

Чтобы планировщик работал, только когда открыт определённый экран, например главный экран:

1. Откройте макет этого экрана в редакторе макетов.
2. Щёлкните правой кнопкой мыши по фону редактора, нажмите **Изменить сценарий действия «Открытие экрана»** и добавьте действие **Start Scheduler**, указав ID планировщика.
3. Снова щёлкните правой кнопкой мыши по фону, нажмите **Изменить сценарий действия «Закрытие экрана»** и добавьте действие **Stop Scheduler** с тем же ID.

# Управление планировщиками

<img width="800" alt="Окно управления планировщиками: три планировщика, выбран random_tip, справа показаны его настройки и статус «Работает»" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/schedulers_manage.png?raw=true">

- Нажмите на планировщик, чтобы увидеть его настройки, состояние и сценарий действий справа.
- Нажмите **Изменить действия** или щёлкните правой кнопкой мыши по планировщику, чтобы открыть его сценарий действий.
- Дважды щёлкните по ID планировщика, чтобы переименовать его. Нажмите `Enter`, чтобы сохранить имя, или `Esc`, чтобы отменить изменения. При переименовании планировщик останавливается, а действия со старым ID больше не смогут его найти.
- Нажмите **Удалить планировщик**, чтобы удалить выбранный планировщик после подтверждения.
- Нажмите **Экспорт для ИИ**, чтобы скопировать выбранный планировщик или все планировщики для [чата с ИИ](/export-for-ai).
- Найдите планировщик по его ID с помощью строки поиска.

Планировщики сохраняются в файле `config/fancymenu/scheduler_instances.txt` (см. раздел [Расположение данных](/data-storage-locations)). У каждого [профиля](/profiles) свой набор планировщиков.

# Пример: напоминание о перерыве

Уведомление каждые 30 минут после запуска игры:

1. Добавьте планировщик с действием [**Show Toast**](/action-scripts#show-toast). Укажите для параметра **Заголовок** значение `Time for a Break`, а для параметра **Сообщение** — `Stand up, stretch and drink some water.`
2. В разделе **Изменить настройки** задайте для параметра **ID планировщика** значение `break_reminder`, установите для параметров **Задержка запуска (мс)** и **Задержка тика (мс)** значение `1800000`, а для параметра **Запускать при запуске игры** выберите **Включено**.

Без параметра **Задержка запуска (мс)** первое уведомление появилось бы сразу после запуска игры.

# Полезно знать

- Устанавливайте для параметра **Задержка тика (мс)** максимально возможное значение, подходящее для задачи. При значении `0` действия выполняются 20 раз в секунду, а медленные действия могут вызывать задержки в игре.
- Если игра тормозит, несколько запусков могут произойти подряд.
- Изменения сценария действий вступают в силу сразу, даже во время работы планировщика. Изменения настроек вступают в силу при следующем запуске.
- Если действие завершается с ошибкой, планировщик продолжает работать. Ошибка записывается в журнал игры: `logs/latest.log`.
- Если нужно подождать один раз в рамках сценария действий, например «открыть экран через 2 секунды после нажатия», проще использовать блок [Execute Later](/action-scripts#execute-later).
