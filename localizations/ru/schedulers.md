# Планировщики

Планировщики запускают скрипт действий по таймеру.

Они являются глобальными (не привязаны к одному конкретному экрану), поэтому могут продолжать работу даже когда GUI не открыт.

Используйте планировщики, когда вам нужна автоматизация во времени, а не одноразовое действие.
Они полезны для повторяющихся задач, отложенных задач и фоновой логики.

Типичные примеры:

- Обновлять переменные или текстовые элементы каждые несколько секунд (например, пользовательские часы/индикатор состояния).
- Выполнять периодические проверки и запускать действия при выполнении условий.
- Запускать эффекты меню, звуки или другое сценарное поведение по таймеру в цикле.
- Отложить действие и выполнить его позже, не требуя, чтобы экран оставался открытым.

# Где их найти

Откройте **строку меню** FancyMenu, **не** находясь в редакторе макета, затем выберите **Customization -> Manage Schedulers**.

# Быстрый старт

1. Откройте **Customization -> Manage Schedulers**.
2. Нажмите **Add Scheduler**.
3. Создайте **Action Script** планировщика (это то, что выполняется один раз за каждый тик планировщика).
4. Выберите планировщик и нажмите **Edit Settings**.
5. Настройте:
   - **Scheduler ID** (уникальное имя планировщика; используется действиями Start/Stop и требованиями; допустимы: `a-z`, `0-9`, `.`, `_`, `-`)
   - **Start Delay (ms)** (время ожидания до первого тика)
   - **Tick Delay (ms)** (время ожидания между тиками; `0` = каждый игровой тик)
   - **Ticks to Run** (сколько тиков выполнять до автоостановки; `0` = постоянно)
   - **Start on Launch** (автоматически запускает этот планировщик при загрузке FancyMenu)
6. Используйте **Start Now**, чтобы запустить его немедленно.
7. Используйте **Stop Now**, чтобы остановить его.

# Управление и отслеживание планировщиков

Есть действия и требования, которые позволяют управлять планировщиками и проверять, запущены ли они.

## Действия

- **Start Scheduler** принимает ID планировщика и запускает его, если он ещё не запущен.
- **Stop Scheduler** также принимает ID планировщика и останавливает его.

## Требование

Чтобы проверить, запущен ли планировщик в данный момент, используйте требование **Scheduler Is Running**, которое принимает ID планировщика.

# Советы

1. Используйте понятные ID, например `hud_update`, `menu_animation`, `music_fade`.
2. Начните с более большого значения задержки тика (например, `200`–`1000` мс), а затем уменьшайте его только при необходимости, чтобы сэкономить производительность.
3. В списке планировщиков щёлкните правой кнопкой мыши по планировщику, чтобы быстро отредактировать его действия.
4. В списке планировщиков дважды щёлкните по ID планировщика, чтобы переименовать его.
