# Случайная генерация

FancyMenu предлагает множество функций, которые помогают вам случайным образом выбирать целые макеты или их части.

Это может быть полезно, например, если вы хотите, чтобы пользователи видели разные фоны экрана каждый раз при открытии экрана, или случайные подсказки на экране загрузки.

# Случайный выбор макетов

В FancyMenu есть функция, которая позволяет создать группу макетов, а система будет автоматически выбирать случайный макет из этой группы. Благодаря этому вы можете показывать полностью разный случайный дизайн меню каждый раз, когда пользователь запускает игру или открывает экран, но это также можно использовать и для изменения только части экрана, например фона.

## Режим случайного выбора

Чтобы случайным образом выбирать макеты, нужно включить **Режим случайного выбора** для каждого макета, который должен входить в список возможных вариантов. Для этого **щёлкните правой кнопкой мыши** по **фону редактора** и найдите пункт **Режим случайного выбора**.

## Идентификатор случайной группы

После включения режима случайного выбора вам нужно задать **Идентификатор случайной группы**.
Это число должно быть **одинаковым** для каждого макета, который должен входить в **одну и ту же группу**.

## Поведение случайного выбора

Если вы хотите, чтобы система выбирала случайный макет из группы **только один раз за игровую сессию**, включите **Случайный выбор только в первый раз**. В этом случае макет будет выбран при первом открытии экрана, а затем будет всегда использоваться именно тот макет, который был выбран в первый раз. Если эта опция отключена, случайный макет будет выбираться каждый раз при открытии экрана.

# Пример 1: фон

Допустим, вы хотите случайным образом менять фон экрана заголовка.

Для этого вам нужно создать **один макет на каждый фон** и _**ТОЛЬКО**_ менять фон в этих макетах, а также включить режим случайного выбора с правильным идентификатором случайной группы.

В этом примере мы используем идентификатор случайной группы **10**. Этот идентификатор нужно задать для каждого макета этой группы случайных макетов.

Проще всего сделать это так: подготовьте макет с правильным идентификатором случайной группы, а затем используйте **Сохранить как**. Меняйте фон каждый раз, когда сохраняете макет под новым именем; в итоге у вас получится набор макетов с разными фонами, и один из них будет выбираться каждый раз при открытии экрана или один раз за игровую сессию.

# Пример 2: элемент

Ещё один распространённый сценарий — случайный выбор текстового или графического элемента.

Как и в случае с фоном, создайте по одному макету на каждую версию элемента, которую вы хотите выбирать случайным образом. Добавляйте в макеты только этот элемент и ничего больше. Не настраивайте ничего лишнего и не добавляйте другие элементы.

Затем просто сохраните все макеты с одним и тем же идентификатором случайной группы, и один из макетов группы будет выбран при открытии экрана или запуске игры.
