# Форматирование текста

FancyMenu предлагает три способа форматирования текста:

- **Markdown** для [текстовых элементов и элементов подсказок](/text-in-menus): заголовки, списки, цвета, изображения, таблицы и многое другое.
- **Коды форматирования Minecraft**, например `&c`, для быстрой смены цвета. Они работают почти во всех текстовых полях, в том числе в тексте Markdown.
- **Текстовые компоненты Minecraft** для подписей кнопок и ползунков.

> [!TIP]
> На этой странице рассказывается о том, *как записывать* форматированный текст. Чтобы узнать, как добавлять текст в меню, менять его внешний вид или включать прокрутку, см. раздел [Текст в меню](/text-in-menus).

# Markdown

Markdown форматирует текст с помощью нескольких специальных символов. Например, `**жирный**` превращается в **жирный** текст.

Markdown работает в [текстовых элементах](/elements#text) и [элементах подсказок](/elements#tooltip). Символы, которые вы вводите, задают *тип* текста (заголовок, список, цитата). А [внешний вид](/text-in-menus#looks-and-styles) элемента определяет, как он будет выглядеть: например, его цвета и размеры.

## Краткий обзор

| Вы вводите | Получаете |
|---|---|
| `**жирный**` или `__жирный__` | Жирный текст |
| `*курсив*` или `_курсив_` | Текст курсивом |
| `++подчёркнутый++` | Подчёркнутый текст |
| `~~зачёркнутый~~` | Зачёркнутый текст |
| `` `код` `` | Встроенный код |
| `[Открыть сайт](https://example.com)` | Кликабельную ссылку |
| `%#ff5555%красный текст%#%` | Цветной текст |
| `# Заголовок` | Заголовок |
| `- Элемент` | Маркированный список |
| `1. Элемент` | Нумерованный список |
| `> Текст` | Цитату |
| `> [!TIP]` | Блок с заметкой |
| `---` | Разделительную линию |

## Стили текста

| Стиль | Как записать |
|---|---|
| **Жирный** | `**текст**` или `__текст__` |
| **Курсив** | `*текст*` или `_текст_` |
| **Подчёркивание** | `++текст++` |
| **Зачёркивание** | `~~текст~~` (одиночный символ `~` с обеих сторон тоже работает) |

Стили можно сочетать, например: `***жирный курсив***`.

Одиночные символы подчёркивания внутри слов остаются обычными символами, поэтому `my_cool_layout` не станет курсивом. Имена вроде `C++` тоже останутся без изменений.

> [!TIP]
> В текстовом редакторе выделите текст и нажмите `Ctrl + B`, `Ctrl + I` или `Ctrl + U` (на macOS — `Cmd`), чтобы сделать его жирным, курсивным или подчёркнутым. См. раздел [Сочетания клавиш для форматирования](/text-in-menus#formatting-shortcuts).

## Цвет текста (HEX)

Поставьте `%<HEX color>%` перед текстом, а `%#%` — после него:

```
%#77fc03%Этот текст зелёный!%#%
```

HEX-код цвета должен начинаться с `#`. Также можно использовать названия цветов:

```
%#red%Этот текст красный!%#%
```

Поддерживаемые названия: `black`, `silver`, `gray`, `grey`, `white`, `maroon`, `red`, `purple`, `fuchsia`, `magenta`, `green`, `lime`, `olive`, `yellow`, `navy`, `blue`, `teal`, `aqua`, `cyan` и `transparent`.

## Шрифты

Чтобы показать текст другим шрифтом, поставьте `%!!<font name>%` перед ним, а `%!!%` — после. Шрифт может быть из Minecraft или набора ресурсов.

```
%!!uniform%Этот текст отображается шрифтом uniform%!!%
```

## Выравнивание текста

По умолчанию текст выравнивается по левому краю. Чтобы выровнять строки по центру или по правому краю, поставьте код выравнивания на отдельной строке до и после них:

- `^^^` выравнивает строки по центру.
- `|||` выравнивает строки по правому краю.

```
Эта строка выровнена по левому краю.

^^^
Эта строка выровнена по центру.
И эта тоже.
^^^

|||
Эта строка выровнена по правому краю.
|||
```

> [!TIP]
> В текстовом редакторе сочетания `Ctrl + L`, `Ctrl + E` и `Ctrl + R` (на macOS — `Cmd`) выравнивают выделенные строки по левому краю, по центру или по правому краю.

## Заголовки

Начните строку с `# ` (самый крупный), `## ` (крупный) или `### ` (маленький):

```
# Добро пожаловать!
## Новости
### Маленький заголовок
```

## Списки

<img width="460" alt="Списки Markdown" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/markdown_lists.png?raw=true">

### Маркированные списки

Начните строку с `- `. Для каждого уровня вложенности добавляйте перед ним по два пробела:

```
- Первый элемент
- Второй элемент
  - Вложенный элемент
    - Ещё глубже
```

### Нумерованные списки

Начните строку с числа и точки или закрывающей скобки:

```
1. Откройте панель меню
2. Нажмите «Настройка»
3) Так тоже работает
```

### Маркеры заметок об обновлении

Строки также могут начинаться с `+`, `-`, `~` или `*`. Для каждого символа используется свой маркер — идеально для заметок об обновлении и журналов изменений:

```
+ Добавлено новое главное меню
- Удалён старый логотип
~ Изменены цвета кнопок
* Исправлен сбой при запуске
```

| Маркер | Значение |
|---|---|
| `+` | Что-то добавлено |
| `-` | Что-то удалено |
| `~` | Что-то изменено |
| `*` | Что-то важное, на что стоит обратить внимание |

Элемент со знаком `-` получает маркер «удалено», только если в этом же списке есть элемент со знаком `+`. Иначе это обычный элемент маркированного списка. Это можно изменить в меню **Markdown -> Lists -> Extra Markers (+ - ~ \*) -> - Marker Used**.

> [!NOTE]
> В новых текстовых элементах и элементах подсказок включены нумерованные списки, маркеры заметок об обновлении и [блоки с заметками](#callouts). В элементах из старых макетов они отключены, чтобы текст не менялся неожиданно. Включить их можно в меню элемента **Markdown**: **Lists -> Numbered Lists**, **Lists -> Extra Markers (+ - ~ \*)** и **Callouts**.

## Цитаты

Начните строку с `> `, чтобы создать цитату. Она продолжается до следующей пустой строки:

```
> Это цитата.
И эта строка тоже относится к ней.

А эта строка снова обычный текст.
```

Строки внутри цитаты тоже могут начинаться с `>`, а строка, состоящая только из `>`, добавляет в цитату пустую строку:

```
> Первый абзац цитаты.
>
> Второй абзац цитаты.
```

## Блоки с заметками

Блоки с заметками — это цветные рамки со значком и заголовком, отлично подходящие для советов и предупреждений. Создайте цитату, первая строка которой указывает тип блока:

```
> [!WARNING]
> Не забудьте сохранить макет!
```

<img width="640" alt="Блоки с заметками Markdown" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/markdown_callouts.png?raw=true">

Доступно пять типов: `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]` и `[!CAUTION]`.

## Гиперссылки

Заключите текст в `[ ]`, а ссылку укажите после него в `( )`:

```
[Посетите наш сайт](https://example.com)
```

В ссылках могут встречаться круглые скобки, например `https://en.wikipedia.org/wiki/Minecraft_(video_game)`. Чтобы показать квадратные скобки в тексте ссылки, поставьте перед ними `\`: `[Нажмите \[здесь\]](https://example.com)`.

## События клика и наведения

Текст может запускать [обработчики событий](/listeners), а не открывать сайт. Используйте префикс `click:` или `hover:` и придумайте идентификатор:

```
[некоторый кликабельный текст](click:unique_text_click_event_id)
[некоторый текст при наведении](hover:unique_text_hover_event_id)
```

Обрабатывайте эти события с помощью обработчиков [**On Markdown Text Clicked**](/listeners#on-markdown-text-clicked) и [**On Markdown Text Hovered**](/listeners#on-markdown-text-hovered). Оба передают идентификатор в переменной `$$text_event_id`.

## Изображения

Чтобы добавить изображение, поместите его на отдельную строку в формате `![](` + источник изображения + `)`:

```
![](https://example.com/image.png)
```

В качестве источника можно указать веб-ссылку, локальный файл, например `/config/fancymenu/assets/image.png`, или изображение из набора ресурсов. Все варианты источников описаны в разделе [Ресурсы](/resources).

Текст в квадратных скобках станет подписью к изображению:

```
![Мой классный скриншот](/config/fancymenu/assets/screenshot.png)
```

Подпись отображается под изображением, если включён параметр элемента **Markdown -> Images -> Caption**.

Чтобы сделать изображение кликабельным, заключите его в ссылку:

```
[![](https://example.com/image.png)](https://example.com)
```

## Таблицы

Разделяйте ячейки символом `|`. Первая строка — заголовок, а во второй строке для каждого столбца укажите `---`:

```
| Предмет | Цена |
|:---|---:|
| Алмазный меч | 10 |
| Золотое яблоко | 5 |
```

Двоеточия во второй строке задают выравнивание столбца: `:---` — по левому краю, `:---:` — по центру, `---:` — по правому краю. Чтобы вставить `|` внутрь ячейки, напишите `\|`.

<img width="640" alt="Таблица и код Markdown" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/markdown_table_code.png?raw=true">

## Разделители

Строка, состоящая только из `---`, добавляет разделитель на всю ширину текста.

## Код

Код отображает текст без форматирования.

- **Встроенный код:** заключите часть строки в `` ` ``, например `` `/spawn` ``.
- **Блоки кода:** поставьте строку с `` ``` `` до и после блока. Строки в блоках кода не переносятся.

````
```
/give @p minecraft:diamond 64
```
````

После первых `` ``` `` можно указать название языка, например `` ```json ``. FancyMenu принимает его, но внешний вид кода от этого не меняется.

[Заполнители](/placeholders) по-прежнему заменяются внутри кода.

## Обычный текст

Обычный текст показывает символы форматирования как есть, но не оформляет текст как код. Заключите часть строки в `;;`:

```
Здесь ;;**звёздочки**;; показываются вместо жирного текста.
```

Чтобы сделать то же самое для целых строк, поставьте `;;;` на отдельной строке до и после них:

```
;;;
**Не жирный**, _не курсив_.
;;;
```

## Экранирование символов

Чтобы показать символ форматирования как обычный текст, поставьте перед ним `\`. Например, `\*не курсив\*` отображается как `*не курсив*`.

Это работает с символами `\` `` ` `` `*` `_` `{` `}` `[` `]` `(` `)` `#` `+` `-` `.` `!` `|` `>` `~` и `^`.

# Форматирование текста Minecraft

Коды форматирования Minecraft работают в большинстве текстовых полей FancyMenu. Используйте `&` вместо `§` из Minecraft. Например, `&cПредупреждение` делает текст красным, а `&l` — жирным. Код `&r` сбрасывает форматирование.

Все коды перечислены в [Minecraft Wiki](https://minecraft.wiki/w/Formatting_codes).

Коды форматирования также работают в тексте Markdown, кроме блоков кода и обычного текста. Для таких стилей, как жирный и курсив, обычно удобнее использовать Markdown, но коды позволяют быстро менять цвет.

# Текстовые компоненты Minecraft (система Raw Component)

Текстовые компоненты Minecraft — это форматированный текст в формате JSON. Они подходят для **однострочного** текста, например **подписей кнопок и ползунков**, но не для текстовых элементов.

Чтобы использовать компонент, укажите в качестве подписи только его:

```
{"text":"Текст подписи кнопки","font":"uniform"}
```

Текст `Текст подписи кнопки` будет отображаться шрифтом `uniform`. В значении `text` можно использовать [заполнители](/placeholders).

Подробнее см. в статьях Minecraft Wiki о [формате текстовых компонентов](https://minecraft.wiki/w/Raw_JSON_text_format) и [шрифтах](https://minecraft.wiki/w/Resource_pack#Fonts).
