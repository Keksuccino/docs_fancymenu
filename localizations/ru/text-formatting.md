# Форматирование текста

[Текстовые элементы](./elements#text) поддерживают Markdown. В других текстовых полях используются коды форматирования Minecraft, а подписи кнопок могут использовать текстовые компоненты Minecraft.

# Markdown

**Текстовые элементы** FancyMenu полностью поддерживают Markdown, что означает, что вы можете форматировать текст, добавляя к нему специальные символы.

Например, чтобы сделать текст жирным, нужно добавить `**` перед и после жирного текста, и `**Какой-то очень жирный текст.**` будет выглядеть так:
**Какой-то очень жирный текст.**

FancyMenu также поддерживает расширения, описанные ниже.

> [!CAUTION]
> Markdown работает только в **Текстовых элементах**. Для подписей кнопок и других текстовых полей используйте [коды форматирования Minecraft](#minecraft-text-formatting).

## Шрифты

Вы можете отобразить текст в пользовательском шрифте, загруженном через ресурс-пак, добавив `%!!<font_name>%` перед текстом и `%!!%` после него.

Допустимый шрифт, входящий в базовую игру, — `uniform`, поэтому чтобы отобразить текст шрифтом `uniform`, сделайте так:
`%!!uniform%this is a custom font%!!%`

Это отобразит `this is a custom font` шрифтом `uniform`.

## Цвет текста (HEX)

Показать текст в определённом HEX-цвете можно, добавив `%<HEX_color>%` перед текстом и `%#%` после него.

Допустимый HEX-цвет для зелёного — `#77fc03`, поэтому чтобы показать текст этим цветом, сделайте так:
`%#77fc03%this text is green!%#%`

Это покажет `this text is green!` цветом `#77fc03` (зелёным).

Убедитесь, что HEX-цвет начинается с `#`!

Текстовые названия цветов, похожие на HTML, поддерживаются в том же коде форматирования цвета:

```
%#red%Этот текст красный!%#%
```

Поддерживаемые названия: `black`, `silver`, `gray`, `grey`, `white`, `maroon`, `red`, `purple`, `fuchsia`, `magenta`, `green`, `lime`, `olive`, `yellow`, `navy`, `blue`, `teal`, `aqua`, `cyan` и `transparent`.

## Выравнивание текста

Вы можете выравнивать строки текста, начиная строку с определённого кода форматирования выравнивания, затем ничего не добавляя, затем размещая строки текста, которые нужно показать с этим выравниванием, и после этого снова указывая код выравнивания на отдельной строке.

Весь текст по умолчанию **выравнивается по левому краю**, поэтому существуют только коды форматирования для **центровки** и **выравнивания по правому краю**.

### По центру

Чтобы выровнять строки текста по центру, используйте код форматирования `^^^`.

Пример:
```
Этот текст не по центру.

^^^
Этот текст по центру.
Этот текст тоже по центру.
^^^

Этот текст больше не по центру.
```

### По правому краю

Чтобы показать строки текста, выровненные по правому краю, используйте код форматирования `|||`.

Пример:
```
Этот текст не выровнен по правому краю.

|||
Этот текст выровнен по правому краю.
Этот текст тоже выровнен по правому краю.
|||

Этот текст больше не выровнен по правому краю.
```

## Заголовки

Чтобы показать **строку текста** как заголовок (больше и с подчёркиванием), добавьте перед строкой текста `# ` (очень большой), `## ` (большой) или `### ` (маленький).

Пример:
`## Большой заголовок`

## Жирный

Добавьте `**` перед текстом и после него, чтобы сделать его **жирным**.

Пример:
`**жирный текст**`

## Курсив

Добавьте `_` ИЛИ `*` перед текстом и после него, чтобы сделать его *курсивом*.

Пример:
`*текст курсивом*`

## Зачёркнутый текст

Добавьте `~` перед текстом и после него, чтобы сделать его ~~зачёркнутым~~.

Пример:
`~зачёркнутый текст~`

## Гиперссылки

Вы можете добавлять гиперссылки в текст, которые открывают сайт при щелчке.

Текст, который должен отображаться как [гиперссылка](https://google.com), нужно заключить в `[ ]`, а затем добавить саму ссылку в `( )`.

Так что если вы хотите сделать `example text content` кликабельным и открыть `https://example-website.net`, сделайте так:
`[example text content](https://example-website.net)`

## События клика и наведения

События Markdown-клика и наведения доступны для [Текстовых элементов](./elements#text) и другого Markdown-текста. Используйте [**При нажатии на Markdown-текст**](./listeners#on-markdown-text-clicked-text_clicked) и [**При наведении на Markdown-текст**](./listeners#on-markdown-text-hovered-text_hovered), чтобы реагировать на них.

События клика используют префикс `click:`:

```
[какой-то кликабельный текст](click:unique_text_click_event_id)
```

События наведения используют префикс `hover:`:

```
[какой-то текст с наведением](hover:unique_text_hover_event_id)
```

Оба слушателя передают ID события как `$$text_event_id`.

## Изображения

Markdown поддерживает отображение изображений в текстовом содержимом.

FancyMenu поддерживает ресурсы Minecraft, локальные ресурсы и веб-ресурсы в Markdown.

Чтобы добавить изображение, начните строку текста с `![](`, затем укажите [URL, расположение ресурса или путь к ресурсу](./resources), а затем `)`.

Так, чтобы показать веб-ресурс `https://example-website.net/image.png`, сделайте так:
`![](https://example-website.net/image.png)`

Изображения также могут быть **гиперссылками**, если заключить всю строку изображения в **гиперссылку**, вот так:
`[![](https://example-website.net/image.png)](https://example-website.net)`

> [!WARNING]
> Локальные ресурсы должны находиться в `<game-directory>/config/fancymenu/assets/`!

## Цитата

Чтобы отформатировать текст как цитату, начните строку текста с `> `.
Это будет форматировать все следующие строки как цитату, пока не встретится **пустая** строка.

Пример:
```
Это не будет выглядеть как цитата.

> Это будет выглядеть как цитата.
Это тоже будет выглядеть как цитата.

Это снова не будет выглядеть как цитата.
```

## Маркированные списки

Чтобы показать текст как маркированный список, например так:
- Пункт 1
- Пункт 2
  - Подпункт

Вам нужно просто начать строку с `- `.

Пример:
```
- Пункт 1
- Пункт 2
  - Подпункт
```

## Разделительная линия

Чтобы добавить в текст разделительную линию на всю ширину строки, просто начните строку с `---` и больше ничего не добавляйте.

Выглядеть это будет примерно так:

---

## Блоки кода

Блоки кода помогают отображать текст как `обычный текст`, не позволяя Markdown его форматировать, или просто показывать текст в стиле кода без автоматического переноса строк.

Однострочный блок кода (внутри другого текста) начинается и заканчивается с помощью \` , что на самом деле очень трудно показать внутри Markdown-текста..

Строка текста, содержащая однострочный блок кода, выглядит так:

![single_line_code_block](https://github.com/Keksuccino/FancyMenu/assets/35544624/e78fd38b-7b1a-4f00-9b11-797d964b3b43)

Многострочные блоки кода объединяют несколько строк в один большой блок кода и начинаются со строки, которая содержит только \`\`\`, затем идёт текстовое содержимое, а затем снова \`\`\`:

![multi_line_code_block](https://github.com/Keksuccino/FancyMenu/assets/35544624/bf8c77eb-a97e-48cd-9270-8302c2995856) 

## Обычный текст

Код форматирования обычного текста обходит все другие коды форматирования внутри него.

Он работает похоже на блоки кода, но не форматирует текст как блок кода. Вместо этого он отображается как обычный текст, но без какого-либо форматирования.

Чтобы обернуть фрагмент текста внутри строки в код форматирования обычного текста, нужно добавить `;;` перед текстом и после него, чтобы показать его как обычный текст, вот так:

```
Это строка текста с фрагментом ;;**этот фрагмент**;;, который отображается как неформатированный текст с видимым кодом ** (жирный), а _этот фрагмент_ — как обычный форматированный курсивный текст.
```

Обычный текст также работает как многострочный код-обёртка. Чтобы обернуть целые строки, добавьте `;;;` перед строкой(ами), которые нужно показать как обычный текст, и после них, вот так:

```
;;;
Эта строка будет показана **без форматирования** с видимыми кодами форматирования ** (жирный).
Эта строка также будет показана _без форматирования_ с видимыми кодами форматирования _ (курсив).
;;;

Эта строка снова будет выглядеть **обычно**, а слово "обычно" будет выделено жирным.
```

# Форматирование текста Minecraft

Коды форматирования Minecraft работают в поддерживаемых полях форматированного текста во всём FancyMenu. Используйте `&` вместо префикса `§` из Minecraft; например, `&cWarning` отображает красный текст.

См. [справочник по кодам форматирования Minecraft Wiki](https://minecraft.wiki/w/Formatting_codes), чтобы узнать о доступных цветах и стилях.

> [!CAUTION]
> Коды форматирования Minecraft ненадёжны в **Текстовых элементах**, потому что эти элементы разбирают Markdown. Вместо этого используйте описанное выше форматирование Markdown.

# Текстовые компоненты Minecraft (система сырых компонентов)

Система текстовых компонентов Minecraft довольно мощная для **однострочного** текстового содержимого, например **подписей кнопок**.

В Vanilla Minecraft её можно использовать в командах `/tellraw` и `/title` (и, вероятно, в других местах).
Это форматированный текст, сериализованный в JSON, поэтому вы можете добавлять атрибуты форматирования к тексту.

Чтобы подробнее узнать о текстовых компонентах, пожалуйста, посмотрите [эту страницу Minecraft Wiki](https://minecraft.wiki/w/Raw_JSON_text_format).
Чтобы подробнее узнать о шрифтах в Minecraft, посмотрите [эту страницу Minecraft Wiki](https://minecraft.wiki/w/Resource_pack#Fonts).

Чтобы FancyMenu распознал подпись кнопки как **текстовый компонент**, не указывайте ничего, кроме сериализованного текста компонента в качестве подписи, вот так:
`{"text":"Текст подписи кнопки","font":"uniform"}`

Приведённый выше пример покажет подпись кнопки `Текст подписи кнопки` шрифтом `uniform`.

> [!NOTE]
> Вы можете использовать заполнители FancyMenu в значении `text` компонентов.
