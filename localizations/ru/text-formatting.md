# Форматирование текста

У FancyMenu есть множество возможностей, чтобы делать текст в макетах *красивее*!

Текстовые элементы полностью поддерживают **Markdown** с несколькими классными дополнениями, а большинство других текстовых полей поддерживает систему **форматирования текста Minecraft**, а в подписях кнопок даже есть поддержка **текстовых компонентов Minecraft**, которые позволяют использовать пользовательские шрифты и многое другое.

# Markdown

**Текстовые элементы** FancyMenu полностью поддерживают Markdown, а это значит, что вы можете форматировать текст, добавляя к нему специальные символы.

Например, чтобы сделать текст жирным, нужно добавить `**` до и после жирного фрагмента, и `**Какой-то очень жирный текст.**` будет выглядеть так:
**Какой-то очень жирный текст.**

Markdown в FancyMenu даже имеет некоторые особые возможности, которые делают его ещё мощнее!

> Markdown **НЕ РАБОТАЕТ** для других текстовых данных, таких как подписи кнопок. Он работает только для **ТЕКСТОВЫХ ЭЛЕМЕНТОВ**. Для всего остального используйте [коды форматирования Minecraft](/text-formatting#minecraft-text-formatting).
{.is-danger}

## Шрифты

Вы можете отображать текст в пользовательском шрифте, загруженном через ресурс-пак, добавив `%!!<font_name>%` перед текстом и `%!!%` после него.

Допустимый шрифт, включённый в базовую игру, — `uniform`, поэтому чтобы отобразить текст шрифтом `uniform`, сделайте так:
`%!!uniform%это пользовательский шрифт%!!%`

Это отобразит `это пользовательский шрифт` шрифтом `uniform`.

## Цвет текста (HEX)

Отображать текст в заданном HEX-цвете можно, добавив `%<HEX_color>%` перед текстом и `%#%` после него.

Допустимый HEX-цвет для зелёного — `#77fc03`, поэтому чтобы показать текст этим цветом, сделайте так:
`%#77fc03%этот текст зелёный!%#%`

Это покажет `этот текст зелёный!` цветом `#77fc03` (зелёным).

Обязательно указывайте HEX-цвет, начиная с `#`!

FancyMenu 3.9.0 также поддерживает распространённые HTML-подобные названия цветов в этом же коде форматирования цвета:

```
%#red%Этот текст красный!%#%
```

Поддерживаемые названия: `black`, `silver`, `gray`, `grey`, `white`, `maroon`, `red`, `purple`, `fuchsia`, `magenta`, `green`, `lime`, `olive`, `yellow`, `navy`, `blue`, `teal`, `aqua`, `cyan` и `transparent`.

## Выравнивание текста

Вы можете выравнивать строки текста, начиная строку с нужного кода форматирования выравнивания, затем ничего больше, затем строки, которые нужно показать с этим выравниванием, и затем снова код выравнивания на отдельной строке.

Весь текст по умолчанию **выравнивается по левому краю**, поэтому коды форматирования есть только для **по центру** и **по правому краю**.

### По центру

Чтобы выровнять строки по центру, используйте код форматирования `^^^`.

Пример:
```
Этот текст не по центру.

^^^
Этот текст по центру.
Этот текст тоже по центру.
^^^

Этот текст больше не по центру.
```

### По правому краю

Чтобы показать строки текста, выровненные по правому краю, используйте код форматирования `|||`.

Пример:
```
Этот текст не выровнен по правому краю.

|||
Этот текст выровнен по правому краю.
Этот текст тоже выровнен по правому краю.
|||

Этот текст больше не выровнен по правому краю.
```

## Заголовки

Чтобы показать **одну строку текста** как заголовок (крупнее и с подчёркиванием), добавьте `# ` (очень большой), `## ` (большой) или `### ` (маленький) перед строкой текста.

Пример:
`## Большой заголовок`

## Жирный

Добавьте `**` до и после текста, чтобы сделать его **жирным**.

Пример:
`**жирный текст**`

## Курсив

Добавьте `_` ИЛИ `*` до и после текста, чтобы сделать его *курсивом*.

Пример:
`*текст курсивом*`

## Зачёркивание

Добавьте `~` до и после текста, чтобы сделать его ~~зачёркнутым~~.

Пример:
`~зачёркнутый текст~`

## Гиперссылки

Вы можете добавлять к тексту гиперссылки, которые откроют сайт при нажатии.

Текст, который должен отображаться как [гиперссылка](https://google.com), нужно заключить в `[ ]`, а затем указать саму ссылку в `( )`.

Если вы хотите сделать `пример текста` кликабельным и открывать `https://example-website.net`, сделайте так:
`[пример текста](https://example-website.net)`

## События нажатия и наведения

FancyMenu 3.9.0 добавляет события Markdown для нажатия и наведения в текстовых элементах и другом Markdown-тексте.

Для событий нажатия используется префикс `click:`:

```
[какой-то кликабельный текст](click:unique_text_click_event_id)
```

Для событий наведения используется префикс `hover:`:

```
[какой-то текст с наведением](hover:unique_text_hover_event_id)
```

Используйте слушатели **On Markdown Text Clicked** и **On Markdown Text Hovered**, чтобы реагировать на эти события. Оба слушателя передают ID события как `$$text_event_id`.

## Изображения

Markdown поддерживает отображение изображений в текстовом содержимом.

FancyMenu поддерживает ресурсы Minecraft, локальные ресурсы и веб-ресурсы в Markdown.

Чтобы добавить изображение, начните строку текста с `![](`, затем укажите [URL, расположение ресурса или путь к ресурсу](/resources), и затем `)`.

Так, чтобы показать веб-ресурс `https://example-website.net/image.png`, сделайте так:
`![](https://example-website.net/image.png)`

Изображения также могут быть **гиперссылками**, если обернуть всю строку изображения в **гиперссылку** вот так:
`[![](https://example-website.net/image.png)](https://example-website.net)`

> Локальные ресурсы должны находиться в `/config/fancymenu/assets/` !
{.is-warning}

## Цитата

Чтобы оформить текст как цитату, начните строку текста с `> `.
Это будет форматировать все последующие строки как цитату, пока не встретится **пустая** строка.

Пример:
```
Это не будет выглядеть как цитата.

> Это будет выглядеть как цитата.
Это тоже будет выглядеть как цитата.

Это больше не будет выглядеть как цитата.
```

## Маркированные списки

Чтобы показать текст как маркированный список, например такой:
- Пункт 1
- Пункт 2
  - Подпункт

Вам нужно просто начинать строку с `- `.

Пример:
```
- Пункт 1
- Пункт 2
  - Подпункт
```

## Разделительная линия

Чтобы добавить в текст разделительную линию шириной во всю строку текста, просто начните строку с `---` и больше ничего не добавляйте.

Она будет выглядеть примерно так:

---

## Блоки кода

Блоки кода помогают отображать текст как `обычный текст`, чтобы Markdown не пытался его форматировать, или просто показывать текст в стиле кода без автоматического переноса строк.

Однострочный блок кода (внутри другого текста) начинается и заканчивается символом \` , который на самом деле довольно сложно показать в Markdown-тексте..

Строка текста, содержащая однострочный блок кода, выглядит так:

![single_line_code_block](https://github.com/Keksuccino/FancyMenu/assets/35544624/e78fd38b-7b1a-4f00-9b11-797d964b3b43)

Многострочные блоки кода объединяют несколько строк в один большой блок кода и начинаются со строки, которая содержит только \`\`\`, затем идёт содержимое текста, и затем снова \`\`\`:

![multi_line_code_block](https://github.com/Keksuccino/FancyMenu/assets/35544624/bf8c77eb-a97e-48cd-9270-8302c2995856) 

## Обычный текст

Код форматирования обычного текста обходит все другие коды форматирования внутри него.

Он работает похоже на блоки кода, но не форматирует текст как блок кода. Вместо этого он отображается как обычный текст, но без какого-либо форматирования.

Чтобы обернуть фрагмент текста внутри строки в код форматирования обычного текста, нужно добавить `;;` до и после нужного фрагмента, как здесь:

```
Это строка текста с ;;**этой частью**;;, которая отображается как неформатированный текст с видимым кодом форматирования ** (жирный), а _эта часть_ — как обычный отформатированный курсивный текст.
```

Обычный текст также работает как многострочный код-обёртка. Чтобы обернуть целые строки, добавьте `;;;` до и после строки(строк), которые нужно показать как обычный текст, как здесь:

```
;;;
Эта строка будет отображаться **без форматирования** с видимыми кодами форматирования ** (жирный).
Эта строка также будет отображаться _без форматирования_ с видимыми кодами форматирования _ (курсив).
;;;

Эта строка снова будет выглядеть **нормально** — слово "normal" будет выделено жирным.
```

# Форматирование текста Minecraft

Сам Minecraft имеет довольно хорошую систему форматирования, похожую на Markdown, где вы добавляете специальные символы к тексту, чтобы его форматировать.

Чтобы узнать больше о системе форматирования Minecraft, пожалуйста, посмотрите [эту страницу вики Minecraft](https://minecraft.wiki/w/Formatting_codes).

> В вики будет указано, что префикс кода форматирования — это `§`, но в FancyMenu нужно заменить его на `&`. Всё остальное остаётся без изменений.
{.is-warning}

> **Текстовые элементы** очень сложные, и ради поддержки Markdown пришлось пойти на **слом ванильных кодов форматирования Minecraft**, поэтому в текстовых элементах эти коды будут работать некорректно (после кода форматирования форматируется только первое слово и т. п.). Вместо этого в текстовых элементах следует использовать коды форматирования Markdown.
{.is-danger}

# Текстовые компоненты Minecraft (система сырых компонентов)

Система текстовых компонентов Minecraft довольно мощная для **однострочного** текста, например **подписей кнопок**.

В ванильном Minecraft её можно использовать в командах `/tellraw` и `/title` (и, вероятно, в других местах).
Это форматированный текст, сериализованный в JSON, поэтому к тексту можно добавлять атрибуты форматирования.

Чтобы FancyMenu распознал подпись кнопки как **текстовый компонент**, в качестве подписи нужно указать только сериализованный текст компонента, вот так:
`{"text":"Текст подписи кнопки","font":"uniform"}`

Пример выше покажет подпись кнопки `Текст подписи кнопки` шрифтом `uniform`.

> Вы можете использовать плейсхолдеры FancyMenu в значении `text` компонентов.
{.is-info}
