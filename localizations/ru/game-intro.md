# Вступительная заставка

Вступительная заставка воспроизводит анимацию или видео при запуске игры — сразу после экрана загрузки Minecraft. Когда она заканчивается, изображение плавно сменяется главным меню. Эта функция создана для модпаков: можно показать логотип, заставку студии или короткий трейлер.

<img width="800" alt="Заставка Skyhaven: ночь сменяется рассветом над парящим островом, а логотип появляется по буквам. Затем заставка плавно сменяется главным меню, на фоне которого изображён тот же остров" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/game_intro_showcase.gif?raw=true">

Игроки могут пропустить заставку нажатием любой клавиши или щелчком мыши. Вступительная заставка относится к [глобальным настройкам](/global-customizations), поэтому для неё не нужен макет.

# Настройка заставки

<img width="800" alt="Открываем «Глобальные настройки» и «Вступительную заставку» в строке меню, выбираем skyhaven_intro.apng с помощью кнопки «Установить вступительную заставку», запускаем её кнопкой «Повторно запустить вступительную заставку» и пропускаем нажатием пробела" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/game_intro_setup.gif?raw=true">

1. Поместите анимацию или видео в папку `<game-directory>/config/fancymenu/assets/`.
2. Откройте **строка меню -> Настройка -> Глобальные настройки -> Вступительная заставка**.
3. Нажмите **Установить вступительную заставку**. Если в поле **Тип источника** выбрано **Локальный**, нажмите **Выбрать локальный файл ресурса**, выберите файл и нажмите **ОК**.
4. Нажмите **Повторно запустить вступительную заставку**, чтобы сразу её посмотреть.

Чтобы убрать заставку, наведите курсор на **Установить вступительную заставку** и нажмите **Сбросить до значения по умолчанию**.

## Анимации и видео

- **Анимации:** файлы APNG или GIF. Инструкции по созданию: [Анимации](/animations).
- **Видео:** файлы MP4. Для них нужны моды Watermedia V3 и Watermedia Binaries V3. Подробнее: [Видео](/video#requirements). Без этих модов вместо видео на несколько секунд появится красное уведомление со ссылками для скачивания.
- Поддерживаются файлы из папки игры и наборов ресурсов, но не веб-ссылки. Подробнее: [Ресурсы](/resources).

Заставка заполняет весь экран, сохраняя пропорции, поэтому на экранах с другими пропорциями её части будут обрезаны. Большинство экранов имеют формат 16:9, поэтому и заставку лучше сделать в формате 16:9, например 1920x1080. Прозрачные участки будут отображаться чёрным цветом.

> [!TIP]
> Игроки видят заставку при каждом запуске игры, поэтому не делайте её слишком длинной — примерно 5–10 секунд.

## Бесплатный пример заставки

Заставку Skyhaven из GIF-анимаций на этой странице можно бесплатно использовать для тестирования и в своих модпаках:

- [skyhaven_intro.apng](https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/skyhaven_intro.apng?raw=true): заставка размером 1280x720 и длительностью 5,4 секунды. Воспроизводится один раз.
- [skyhaven_menu.png](https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/skyhaven_menu.png?raw=true): последний кадр заставки без логотипа, размером 1280x720. Установите его в качестве [фона-изображения](/menu-backgrounds#image) макета главного меню. Тогда заставка будет плавно переходить в подходящее по стилю меню, как на первой GIF-анимации.

# Настройки

Все настройки находятся в разделе **строка меню -> Настройка -> Глобальные настройки -> Вступительная заставка**:

| Настройка | Описание |
|---|---|
| **Установить вступительную заставку** | Анимация или видео. |
| **Пропуск вступительной заставки** | Заставку можно пропустить нажатием любой клавиши или щелчком мыши. Внизу экрана появится надпись **Нажмите любую клавишу, чтобы пропустить**. При пропуске заставка сразу заканчивается, без плавного перехода. Если отключить этот параметр, заставка всегда будет проигрываться до конца. |
| **Плавное завершение вступительной заставки** | При завершении заставка плавно сменяется главным меню. Если отключить этот параметр, главное меню появится сразу. |
| **Игнорировать повторы вступительной заставки** | Завершает заставку после однократного воспроизведения анимации, даже если она зациклена. Если отключить этот параметр, анимация будет воспроизводиться все циклы. Видео всегда воспроизводится один раз. |
| **Свой текст для пропуска** | Заменяет надпись **Нажмите любую клавишу, чтобы пропустить**, например на `Нажмите любую клавишу, чтобы начать приключение`. Если указать ключ локализации из набора ресурсов, например `skyhaven.intro.skip`, текст будет отображаться на языке игрока. |
| **Громкость вступительной заставки** | Громкость видео во вступительной заставке: от 0% до 100%. |
| **Звуковой канал вступительной заставки** | Звуковой канал для видео во вступительной заставке, например «Музыка». Также учитываются громкость этого канала и общая громкость в настройках звука Minecraft. |
| **Повторно запустить вступительную заставку** | Сразу воспроизводит заставку поверх текущего экрана. |

Параметры **Пропуск вступительной заставки**, **Плавное завершение вступительной заставки** и **Игнорировать повторы вступительной заставки** включены по умолчанию.

> [!WARNING]
> Если отключить и **Пропуск вступительной заставки**, и **Игнорировать повторы вступительной заставки**, зацикленная анимация не закончится, и игроки не смогут перейти в главное меню.

# Полезно знать

- Заставка воспроизводится один раз при каждом запуске игры, перед первым экраном после экрана загрузки. Обычно это главное меню.
- О том, как изменить экран загрузки Minecraft, отображающийся перед заставкой, читайте в разделе [Экран загрузки](/loading-screen).
- В источнике заставки можно использовать [подстановки](/resources#placeholders-in-resource-sources).
- Настройки вступительной заставки сохраняются в файле FancyMenu `options.txt`, поэтому они относятся к загруженному [профилю](/profiles). Модпаки с папкой `config/fancymenu/` включают заставку и её файл в папке `assets/`. Подробнее: [Модпаки](/modpacks).
