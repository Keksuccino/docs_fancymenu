# Вступления в игру

Вступления в игру воспроизводят анимированное изображение или видео перед первым появлением экрана с заголовком.

# Настройка

Откройте [**Глобальные настройки**](./global-customizations) через **Настройка -> Глобальные настройки**, затем задайте следующие параметры:

| Параметр | Поведение |
|---|---|
| Установить вступление в игру | Выбирает локальное, веб- или ресурсное Minecraft-анимированное изображение или видео |
| Пропуск вступления в игру | Позволяет пропустить вступление любой клавишей или щелчком мыши |
| Затемнение вступления в игру | Плавно переводит вступление в целевой экран |
| Пользовательский текст пропуска | Заменяет стандартную подсказку о пропуске обычным текстом или ключом локализации |
| Громкость вступления в игру | Устанавливает базовую громкость от `0.0` до `1.0` |
| Канал звука вступления в игру | Выбирает категорию звука Minecraft |
| Повторно запустить вступление в игру | Снова воспроизводит настроенное вступление для тестирования |

Для видео-вступлений требуются **Watermedia V3**, **Watermedia Binaries V3** и рендерер OpenGL. Воспроизведение видео через Watermedia недоступно с Vulkan. Когда воспроизведение недоступно, FancyMenu отображает объяснение поверх экрана вступления. См. [Видео](./video#requirements).
