# Ресурсы

Поля ресурсов могут загружать содержимое из следующих источников:

- **Minecraft:** ресурсный путь, предоставленный Minecraft или ресурсным пакетом.
- **Локальный:** файл в активном экземпляре игры.
- **Веб:** прямой URL файла.

Большинство полей изображений, аудио, видео и текста используют один и тот же выбор ресурсов. В этом выборе есть браузер для содержимого Minecraft и ресурсных пакетов.

# Ресурсы Minecraft (ресурсные пакеты)

Ресурсные пути используют формат `namespace:path`. Namespace — это каталог сразу под `assets`, а path — всё, что находится ниже этого namespace.

Например, рассмотрим изображение из ресурсного пакета, сохранённое по пути `/assets/custom_resources/images/image.png`.
Его ресурсный путь: `custom_resources:images/image.png`.

> [!NOTE]
> Встроенные ресурсы Minecraft обычно используют namespace `minecraft`.

# Локальные ресурсы

Храните локальные ресурсы в `<game-directory>/config/fancymenu/assets/`. `<game-directory>` — это папка активного экземпляра игры, которая может отличаться от `.minecraft`.

В полях ресурсов может отображаться тот же путь, например `/config/fancymenu/assets/example.png`. В таких полях начальный `/` по-прежнему означает `<game-directory>`; это не путь от корня файловой системы.

Эти файлы можно [включать в модпак](./modpacks) через его папку config.

Полную схему путей FancyMenu для макета, ресурсов, конфигурации и сгенерированного состояния см. в разделе [Расположение хранилищ данных](./data-storage-locations).

# Веб-ресурсы

Используйте прямой URL к файлу, например `https://example-domain.net/image.png`. Страницы и ссылки с перенаправлением работают медленнее и чаще дают сбой, чем прямые URL, заканчивающиеся именем и расширением ресурса.

# Подстановки в источниках ресурсов

Поля ресурсов с выбором через браузер могут использовать [подстановки](./placeholders) в локальных путях, URL и ресурсных путях Minecraft. Чтобы отредактировать источник напрямую, нажмите **Открыть в редакторе** рядом с полем источника.

> [!WARNING]
> Входные поля ресурсов, которые не используют обычный выбор, могут не поддерживать подстановки или обновление источника в реальном времени.
