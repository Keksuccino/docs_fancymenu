# 9-слайсинг и тайлинг

9-слайсинг сохраняет углы и границы текстуры, растягивая при этом её центр. Тайлинг повторяет текстуру вместо её растягивания.

<img src="https://raw.githubusercontent.com/Keksuccino/FancyMenu/refs/heads/master/assets/docs/nine_slicing_example.png" alt="Области nine-slice" style="max-width:500px;height:auto;" />

# Поддержка 9-слайсинга

| Область | Поддерживаемые цели |
|---|---|
| Виджеты | Текстуры [Button](./elements#button) и [Slider](./elements#slider); [глобальные стили кнопок и слайдеров](./global-customizations#button-visuals) |
| Изображения и панели | [Элементы Image](./elements#image) |
| Полосы прогресса | [Текстуры заливки и фона](./elements#progress-bar) |
| Подсказки | [Пользовательские текстуры фона](./elements#tooltip) |

# Настройка 9-слайсинга

1. Укажите целевую текстуру.
2. Включите для неё опцию **Nine-Slice**.
3. Задайте размеры границ так, чтобы они соответствовали фиксированной краевой области в исходной текстуре.
4. Измените размер элемента и при необходимости скорректируйте значения границ, если углы или края искажаются.

Настройки Button и Image используют размеры границ по осям X/Y. Для Progress Bars и Tooltips при необходимости доступны отдельные значения краёв.

# Поддержка тайлинга

Повторяющиеся текстуры доступны для:

- [Элементов Image](./elements#image).
- [Фонов меню Image](./menu-backgrounds).
- [Текстур заголовка и подвала scroll-list](./customizing-scrollable-screens).

Включите **Repeat Texture** для элемента Image или фонового изображения Image. Для прокручиваемых экранов используйте параметры повторения в меню настройки заголовка/подвала.

Используйте бесшовную исходную текстуру; несовпадающие края создают видимые линии между плитками.

9-слайсинг и повторение — это разные режимы. Если для цели отображаются обе опции, выберите ту, которая соответствует нужному поведению масштабирования.
