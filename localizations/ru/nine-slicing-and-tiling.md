# Девятисегментное масштабирование и замощение

Пользовательские текстуры растягиваются до размера элемента. Для фотографий это нормально, но рамки, панели и кнопки с границами при увеличении ширины или высоты выглядят искажёнными. Это исправляют две настройки:

- Девятисегментное масштабирование сохраняет форму углов и краёв текстуры и заполняет только середину.
- Замощение повторяет текстуру вместо её растягивания, поэтому узор сохраняет свой размер.

# Как работает девятисегментное масштабирование

Четыре линии разделяют текстуру на девять частей. Четыре угла всегда сохраняют размер, края только удлиняются, а середина заполняет оставшееся пространство.

1. Выберите текстуру.
2. Включите для неё девятисегментное масштабирование. Название настройки указано в разделе [Где это работает](#where-it-works).
3. Задайте размеры границ, соответствующие толщине рамки текстуры в пикселях. Например, если рамка имеет толщину 4 пикселя, укажите `4`.

Полезно знать:

- На экране границы отображаются в том же масштабе, что и в текстуре. Поэтому текстура с границами шириной 40 пикселей будет выглядеть громоздко на маленькой кнопке. Размер текстуры должен быть примерно равен размеру элемента.
- У большинства текстур один размер для левой и правой границ (границы по X) и один для верхней и нижней (границы по Y). У индикаторов выполнения, всплывающих подсказок и глобальных настроек можно задать размер каждой границы отдельно.
- Если границы слишком велики для текстуры, они автоматически уменьшаются.

## Фоны текстовых элементов и прокручиваемых областей

Откройте раздел **Фон** в контекстном меню текстового элемента или прокручиваемой области:

- **Пользовательская текстура фона** заменяет встроенную тёмную панель вашей текстурой. Сбросьте настройку, чтобы вернуть панель.
- **Пользовательский фон с девятисегментным масштабированием** включён по умолчанию. Настройте границы с помощью параметров **Границы фона по X (слева и справа)** и **Границы фона по Y (сверху и снизу)**.
- **Замощать текстуру** повторяет текстуру вместо её растягивания. При включённом девятисегментном масштабировании повторяются края и середина, а углы сохраняют исходный вид.
- **Показывать фон** отключает фон целиком.

## Фоны полос прокрутки

Откройте раздел **Полосы прокрутки -> Фоны полос прокрутки** текстового элемента или прокручиваемой области. Параметры **Текстура вертикальной полосы** и **Текстура горизонтальной полосы** задают текстуру вдоль пути, по которому перемещается бегунок прокрутки. Для них всегда применяется девятисегментное масштабирование, поэтому концы полос сохраняют форму при любой длине. Настройте границы с помощью двух расположенных ниже параметров.

# Как работает замощение

При замощении текстура многократно размещается рядом с собой в исходном размере, насколько это возможно. Используйте бесшовную текстуру, у которой левый край стыкуется с правым, а верхний — с нижним. Иначе между фрагментами будут видны линии.

Для элементов изображений параметры **Повторять текстуру** и **Текстура с девятисегментным масштабированием** нельзя использовать одновременно. Если включить оба, изображение будет повторяться.
