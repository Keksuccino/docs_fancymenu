# Скрипты действий

Скрипт действий — это список операций, которые FancyMenu выполняет при наступлении какого-либо события, например при нажатии кнопки или открытии меню. Каждая операция — это действие: открыть меню, подключиться к серверу, показать сообщение, воспроизвести звук и многое другое. Операторы, например IF и WHILE, определяют, какие действия выполнять и как часто.

> [!CAUTION]
> Скрипты действий могут изменять файлы, подключаться к серверам, открывать ссылки и выполнять команды. Используйте только скрипты из макетов, которым доверяете.

# Создание скрипта действий

1. В редакторе макетов щёлкните правой кнопкой мыши по кнопке и выберите **Edit Action Script**.
2. Нажмите `A`, чтобы открыть список действий.
3. Найдите нужное действие, выберите его и нажмите **Next Step**.
4. Настройте действие в открывшемся окне и нажмите **Done**. Для действий без настроек достаточно нажать **Done** в списке.
5. Нажмите **Done** в редакторе скриптов, затем сохраните макет.

Вне редактора скрипт запускается при нажатии кнопки:

<img width="800" alt="Нажатие кнопки What's New? на главном экране показывает уведомление с заголовком и сообщением об обновлении" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/action_script_use.gif?raw=true">

> [!TIP]
> Щёлкните правой кнопкой мыши по области скрипта и выберите **Add Action**, чтобы открыть список всех действий. Чтобы добавить действие в избранное и переместить его в начало списка, щёлкните по нему правой кнопкой мыши.

# Где можно использовать скрипты действий

| Где | Когда запускается | Где редактировать |
|---|---|---|
| [Кнопка](/elements#button) | При нажатии кнопки. | Щёлкните по кнопке правой кнопкой мыши -> **Edit Action Script** |
| [Ползунок](/elements#slider) | При изменении значения ползунка. `$$value` — новое значение. | Щёлкните по ползунку правой кнопкой мыши -> **Edit Action Script** |
| [Флажок](/elements#checkbox) | При установке или снятии флажка. `$$value` — новое состояние: `true` или `false`. | Щёлкните по флажку правой кнопкой мыши -> **Edit Action Script** |
| [Тикер](/elements#ticker) | Согласно параметру **Tick Mode**: многократно, один раз за игровой сеанс или один раз при загрузке меню. | Щёлкните по тикеру правой кнопкой мыши -> **Edit Action Script** |
| Открытие меню | Когда открывается меню макета. | Щёлкните правой кнопкой мыши по фону редактора -> **Edit 'Open Screen' Action Script** |
| Закрытие меню | Когда закрывается меню макета. | Щёлкните правой кнопкой мыши по фону редактора -> **Edit 'Close Screen' Action Script** |
| [Слушатели](/listeners) | При наступлении соответствующего события, например нажатии клавиши или получении сообщения в чате. | **строка меню -> Customization -> Manage Listeners** |
| [Планировщики](/schedulers) | По таймеру, даже если меню не открыто. | **строка меню -> Customization -> Manage Schedulers** |

Скрипты открытия и закрытия также доступны в редакторе через меню **Layout -> Layout Properties**.

# Редактор скриптов

- Действия выполняются сверху вниз. Элементы внутри оператора или папки отображаются с отступом.
- Новые элементы добавляются под выбранным элементом. Если выбран оператор или папка, новые элементы добавляются в их начало.
- Дважды щёлкните по значению, чтобы изменить его прямо в списке. Если вместо значения отображается краткое описание, откроется окно настройки.
- Перетаскивайте элементы, чтобы переместить их. Цепочки IF, циклы и папки можно сворачивать с помощью небольшого переключателя перед ними. Это влияет только на отображение.
- Полоса справа показывает схему всего скрипта. Нажмите на неё, чтобы перейти к нужной части.
- Щёлкните правой кнопкой мыши по области скрипта, чтобы открыть остальные команды, например добавление операторов и **Export Action Script for AI** (см. [Экспорт для ИИ](/export-for-ai)).
- Кнопка **Cancel** или закрытие окна отменяет изменения. Если вы что-то изменили, редактор сначала запросит подтверждение.

## Сочетания клавиш

В macOS вместо `Ctrl` используется `Cmd`.

| Сочетание клавиш | Действие |
|---|---|
| `A` | Открывает список действий. |
| `Enter` | Редактирует выбранный элемент. |
| `Delete` | Удаляет выбранный элемент. |
| `Up` / `Down` | Выбирает элемент выше или ниже. |
| `Shift + Up` / `Shift + Down` | Перемещает выбранный элемент вверх или вниз. |
| `Ctrl + C` / `Ctrl + V` | Копирует и вставляет действие. Операторы и блоки копировать нельзя. |
| `Ctrl + Z` | Отменяет действие. |
| `Ctrl + Y` или `Ctrl + Shift + Z` | Повторяет отменённое действие. |
| `Ctrl + S` | Сохраняет скрипт и закрывает редактор, как кнопка **Done**. |

# Операторы

Операторы определяют, какие действия выполняются и как часто. Чтобы добавить оператор, щёлкните правой кнопкой мыши по области скрипта.

## If, Else-If и Else

Команда **Add IF Statement** запрашивает [условия](/conditions). Действия внутри IF выполняются, только если условия выполнены.

Щёлкните по IF правой кнопкой мыши, чтобы добавить продолжение цепочки:

- **Append ELSE-IF Statement**: проверяет собственные условия, если предыдущий IF не выполнился.
- **Append ELSE Statement**: выполняется, если ни один из предыдущих операторов в цепочке не сработал.

Например, IF с условием **Is Layout Enabled** может показывать уведомление, только пока включён зимний макет, а ELSE — воспроизводить звук в противном случае.

## Цикл While

Команда **Add WHILE Loop** повторяет входящие в него действия, пока выполняются [условия](/conditions).

Каждый запуск останавливается через 3 секунды, поэтому бесконечный цикл не сможет зависнуть и заморозить игру. Это не таймер: для действий, которые нужно выполнить позже или повторять, используйте [Execute Later](#execute-later), [тикер](/elements#ticker) или [планировщик](/schedulers).

## Цикл For Each

Команда **Add FOR EACH Loop** выполняет входящие в неё действия для каждого элемента [списковой переменной](/variables#text-and-list-variables), от первого элемента до последнего.

- `$$list_entry` — текущий элемент, а `$$list_index` — его индекс. Индекс первого элемента — 0.
- Обе переменные можно использовать в значениях действий и условиях внутри цикла.
- Укажите имя списка без `$$`, например `quest_log`. В имени можно использовать плейсхолдеры.
- При запуске цикла список считывается один раз, поэтому действия внутри цикла могут безопасно изменять список.
- Как и цикл WHILE, каждый запуск останавливается через 3 секунды.

Примеры см. в разделе [Перебор списка](/variables#going-through-a-list).

# Блоки

Блоки изменяют порядок выполнения действий или помогают упорядочить скрипт. Чтобы добавить блок, щёлкните правой кнопкой мыши по области скрипта.

## Блок Delay Gate

Блок **Add DELAY GATE Block** задерживает выполнение входящих в него действий на указанное время в миллисекундах (`1000` — одна секунда).

- При первом достижении блока скрипт запускает таймер и пропускает действия внутри него. Остальная часть скрипта сразу выполняется дальше.
- Если скрипт снова достигает блока до истечения времени, действия опять пропускаются.
- После истечения времени действия выполняются при каждом последующем достижении блока скриптом.
- В скриптах элементов таймер запускается заново при повторном открытии или изменении размера меню.

Этот блок подходит для [тикеров](/elements#ticker), например чтобы показать что-либо, только если меню открыто уже несколько секунд. Сам по себе он ничего не запускает: для этого используйте Execute Later.

## Execute Later

Блок **Add EXECUTE LATER Block** выполняет входящие в него действия один раз по истечении указанного времени в миллисекундах. Остальная часть скрипта сразу выполняется дальше.

Каждый раз, когда скрипт достигает блока, запускается новый обратный отсчёт. Это подходит для скриптов, которые выполняются только один раз, например при нажатии кнопки или открытии меню.

## Папка

Команда **Add Folder** группирует действия под общим именем. Она выполняет всё, что в неё вложено, и нужна лишь для упорядочивания длинных скриптов. Дважды щёлкните по имени папки, чтобы переименовать её.

## Комментарий

Команда **Add Comment** добавляет заметку. Она ничего не выполняет. Дважды щёлкните по комментарию, чтобы изменить его.

# Как выполняются скрипты

- Действия выполняются сверху вниз. Если действие завершается с ошибкой, она записывается в журнал игры, а скрипт продолжает выполняться.
- Плейсхолдеры в значениях заменяются текущими значениями непосредственно при выполнении действия. Поэтому действие учитывает изменения, внесённые предыдущими действиями.
- Загрузка файлов, распаковка ZIP-архивов и веб-запросы выполняются в фоновом режиме. Следующее действие не ждёт их завершения. Чтобы запускать действия после завершения этих операций, используйте слушатели [**On File Downloaded via Action**](/listeners#on-file-downloaded-via-action) и [**On ZIP Extracted via Action**](/listeners#on-zip-extracted-via-action) или переменную ответа действия [**Send HTTP Request**](#send-http-request).

# Значения действий

Большинству действий нужно значение, например адрес сервера. Простые значения — это текст, который вы вводите. Для действий с дополнительными настройками предусмотрены отдельные окна.

## Плейсхолдеры

В значениях можно использовать [плейсхолдеры](/placeholders), например имя игрока. Они заменяются при выполнении действия:

```
/say С возвращением, {"placeholder":"playername"}!
```

## Переменные $$

Введите `$$` и имя переменной, чтобы использовать её значение в действии или условии. Регистр букв в именах важен. Так можно обращаться к двум типам переменных:

### Собственные переменные

Любая переменная, созданная через **строка меню -> Customization -> Manage Variables**, доступна по `$$` и своему имени. Переменная с именем `coins` обозначается как `$$coins` во всех скриптах. Например, действие **Display In Chat [Client-Side]** с таким значением сообщит игроку, сколько у него монет:

```
&6У вас $$coins монет!
```

О создании и изменении переменных см. раздел [Переменные](/variables).

### Переменные скрипта

Некоторые возможности предоставляют скриптам собственные переменные:

- [Ползунок](/elements#slider) предоставляет `$$value` — новое значение.
- [Флажок](/elements#checkbox) предоставляет `$$value` — новое состояние: `true` или `false`.
- [Цикл For Each](#for-each-loop) предоставляет `$$list_entry` и `$$list_index`.
- В описании каждого [слушателя](/listeners#listener-variables) перечислены предоставляемые им переменные, например нажатая клавиша.

Эти переменные существуют только во время выполнения скрипта. Если имя такой переменной совпадает с именем вашей переменной, `$$name` обозначает переменную скрипта.

# Все действия

Все действия FancyMenu, сгруппированные по назначению.

## Экраны и меню

### Открыть экран или пользовательский интерфейс

**Идентификатор:** `opengui`

Открывает меню игры, мода или [пользовательский интерфейс](/custom-guis).

**Значение:** [идентификатор экрана](/screen-identifiers), например `options_screen`

Регистр букв важен. Некоторые меню модов нельзя открыть таким способом. В этом случае используйте действие [**Mimic Vanilla/Mod Button**](#mimic-vanillamod-button) для кнопки, которая открывает это меню.

### Закрыть экран

**Идентификатор:** `closegui`

Закрывает открытое меню. Если вы не находитесь в мире, откроется главное меню.

**Значение:** нет

### Обновить экран

**Идентификатор:** `update_screen`

Пересоздаёт открытое меню, как при изменении размера окна. Полезно после изменения масштаба интерфейса или других настроек.

**Значение:** нет

### Вернуться к предыдущему экрану

**Идентификатор:** `back_to_last_screen`

Возвращает меню, которое было открыто ранее. Для [пользовательского интерфейса](/custom-guis) это меню, из которого он был открыт.

**Значение:** нет

### Показать уведомление

**Идентификатор:** `show_toast`

Показывает уведомление в правом верхнем углу. Настройте его в отдельном окне:

- **Toast Width**: ширина от 120 до 320 пикселей.
- **Duration (ms)**: длительность показа — от 1 секунды (`1000`) до 10 минут.
- **Title** и **Message**: текст с [кодами форматирования](/text-formatting#minecraft-text-formatting) или JSON-компонент текста Minecraft.
- **Icon Texture Source** и **Background Texture Source**: необязательные [изображения](/resources). Для значков лучше всего подходит размер 20x20 пикселей, высота фона должна составлять 32 пикселя, а его ширина — соответствовать ширине уведомления.

### Имитировать нажатие кнопки игры или мода

**Идентификатор:** `mimicbutton`

Нажимает кнопку игры или мода так, как если бы её нажал игрок.

**Значение:** [идентификатор виджета](/widget-locators) кнопки, например `title_screen:mc_titlescreen_options_button`

Чтобы получить идентификатор, щёлкните по кнопке в редакторе правой кнопкой мыши и выберите **Copy Widget Locator**.

## Макеты и элементы

### Переключить макет

**Идентификатор:** `toggle_layout`

Отключает включённый макет или включает отключённый.

**Значение:** имя макета без `.txt`, например `winter_title_screen`

### Включить макет

**Идентификатор:** `enable_layout`

Включает макет.

**Значение:** имя макета без `.txt`

### Отключить макет

**Идентификатор:** `disable_layout`

Отключает макет.

**Значение:** имя макета без `.txt`

Все три действия с макетами сохраняют изменение и сразу обновляют открытое меню. Регистр букв в имени важен.

### Переключить аниматор элемента

**Идентификатор:** `toggle_element_animator`

Включает выключенный [аниматор элемента](/element-animator) или выключает включённый. Анимация начинается с самого начала. Состояние сохраняется.

**Значение:** идентификатор аниматора элемента

### Включить аниматор элемента

**Идентификатор:** `enable_element_animator`

Включает [аниматор элемента](/element-animator). Если он был выключен, анимация начинается с самого начала.

**Значение:** идентификатор аниматора элемента

### Выключить аниматор элемента

**Идентификатор:** `disable_element_animator`

Выключает [аниматор элемента](/element-animator) и сбрасывает его анимацию.

**Значение:** идентификатор аниматора элемента

### Сбросить аниматор элемента

**Идентификатор:** `reset_element_animator`

Запускает анимацию [аниматора элемента](/element-animator) с самого начала, не включая и не выключая его.

**Значение:** идентификатор аниматора элемента

### Задать значение поля ввода текста

**Идентификатор:** `set_text_input_field_value`

Задаёт текст для [поля ввода текста](/elements#text-input-field) FancyMenu или игры.

**Значение:** `element_identifier|||text|||force`

Если для `force` указать `true`, текст изменится и в выключенном (неактивном) поле.

### Прокрутить элемент

**Идентификатор:** `scroll_scroll_area`

Прокручивает [область прокрутки](/scrollable-areas) или элемент [текст](/elements#text). Настройте действие в отдельном окне:

- **Identifier of the Element to Scroll**: область или текстовый элемент для прокрутки.
- **Scroll To**:
  - **Start** или **End**: начало или конец.
  - **Position**: значения **Horizontal Position** и **Vertical Position** в пикселях. Оставьте одно поле пустым, чтобы не менять его значение.
  - **Element** (только для областей): прокручивает так, чтобы элемент с указанным в **Identifier of the Element to Scroll To** идентификатором оказался в начале.
  - **Line Number** (только для текстовых элементов): первой строке соответствует номер `1`.
  - **Line with Text** (только для текстовых элементов): первая строка, содержащая текст из поля **Text in the Line**. Регистр букв не учитывается.
- **Glide There**: плавная прокрутка вместо перехода к нужному месту. Для элемента должна быть включена плавная прокрутка.

Ничего не происходит, если такого элемента нет.

## Аудио и видео

### Следующий трек

**Идентификатор:** `audio_next_track`

Переключает на следующий трек [аудиоэлемента](/elements#audio).

**Значение:** идентификатор аудиоэлемента, например `menu_music`

### Предыдущий трек

**Идентификатор:** `audio_previous_track`

Возвращает предыдущий трек [аудиоэлемента](/elements#audio).

**Значение:** идентификатор аудиоэлемента

### Установить громкость трека

**Идентификатор:** `set_audio_element_volume`

Устанавливает громкость [аудиоэлемента](/elements#audio) от `0.0` (0%) до `1.0` (100%).

**Значение:** `element_identifier:volume`, например `menu_music:0.5`

### Переключить воспроизведение или паузу трека

**Идентификатор:** `audio_toggle_play`

Ставит воспроизводимый [аудиоэлемент](/elements#audio) на паузу или возобновляет приостановленное воспроизведение.

**Значение:** идентификатор аудиоэлемента

### Воспроизвести аудио

**Идентификатор:** `play_audio`

Однократно воспроизводит аудиофайл. В отдельном окне укажите **Audio Source**, **Sound Channel** и **Base Volume** (до 100%).

- FancyMenu ожидает загрузки аудио до десяти секунд.
- Не работает в [тикере](/elements#ticker), который выполняется в фоновом режиме (асинхронно). Вместо этого FancyMenu покажет ошибку.

Действие [**Stop All Action Audios**](#stop-all-action-audios) останавливает аудио, запущенное этим действием.

### Остановить всё аудио действий

**Идентификатор:** `stop_all_action_audios`

Останавливает всё аудио, запущенное действием [**Play Audio**](#play-audio). Аудиоэлементы, звуки меню и кнопок продолжат воспроизводиться.

**Значение:** нет

Устанавливает громкость [видеоэлемента](/video) от `0.0` (0%) до `1.0` (100%).

**Значение:** `video_element_identifier:volume`

### Задать время воспроизведения видеоэлемента

Перематывает [видеоэлемент](/video) на указанное время в миллисекундах.

**Значение:** `video_element_identifier:time_in_ms`, например `intro_video:30000`

### Переключить паузу видеоэлемента

Ставит воспроизводимый [видеоэлемент](/video) на паузу или возобновляет приостановленное воспроизведение.

**Значение:** идентификатор видеоэлемента

### Установить громкость видеофона

**Идентификатор:** `set_video_menu_background_volume`

Устанавливает громкость [видеофона меню](/video) от `0.0` (0%) до `1.0` (100%).

**Значение:** `background_identifier:volume`

> [!NOTE]

### Задать время воспроизведения видеофона

Перематывает [видеофон меню](/video) на указанное время в миллисекундах.

### Переключить паузу видеофона

**Идентификатор:** `toggle_video_menu_background_pause_state`

Ставит воспроизводимый [видеофон меню](/video) на паузу или возобновляет приостановленное воспроизведение.

**Значение:** идентификатор фона меню

## Миры и серверы

### Подключиться к серверу

**Идентификатор:** `joinserver`

Подключается к серверу Minecraft.

**Значение:** `адрес` или `адрес:порт`, например `play.example.net`

Если порт не указан, используется `25565`. Если мир или сервер уже загружен, вместо подключения появится сообщение об ошибке. Серверы, которых ещё нет в списке, добавляются в него.

### Войти в мир

**Идентификатор:** `loadworld`

Загружает одиночный мир.

**Значение:** имя папки мира в `saves`, например `Survival Island`

Ничего не происходит, если такого мира нет. Если мир или сервер уже загружен, вместо загрузки появится сообщение об ошибке.

### Войти в последний мир или на последний сервер

**Идентификатор:** `join_last_world`

Загружает мир или подключается к серверу, в котором игрок играл в последний раз.

**Значение:** нет

Если мир или сервер уже загружен, вместо этого появится сообщение об ошибке. Сервер, которого ещё нет в списке, добавляется в него.

### Покинуть мир или сервер

**Идентификатор:** `disconnect_server_or_world`

Покидает мир или сервер и открывает меню.

**Значение:** [идентификатор экрана](/screen-identifiers) меню, например `title_screen`

Работает только при загруженном мире. Также поддерживаются [пользовательские интерфейсы](/custom-guis). Если меню открыть не удастся, появится главное меню.

## Переменные и списки

### Задать значение переменной (переменная FM)

**Идентификатор:** `set_variable`

Задаёт значение [переменной](/variables).

**Значение:** `имя_переменной:значение`, например `coins:100`

- Только первый символ `:` разделяет имя и значение.
- [Списковые переменные](/variables#text-and-list-variables) остаются списками: JSON-массив, например `["a","b"]`, превращается в элементы списка; любой другой текст становится единственным элементом, а пустой текст очищает список.

### Удалить переменную (переменная FM)

**Идентификатор:** `delete_variable`

Полностью удаляет [переменную](/variables). Остальные переменные сохраняются. Чтобы лишь очистить переменную, используйте [**Задать значение переменной (переменная FM)**](#set-variable-value-fm-variable).

**Значение:** имя переменной

### Очистить все переменные (переменная FM)

**Идентификатор:** `clear_variables`

Удаляет все [переменные](/variables), в том числе текстовые и списковые.

**Значение:** нет

### Добавить элемент в список (переменная FM)

**Идентификатор:** `add_to_list`

Добавляет элемент в [списковую переменную](/variables#list-actions).

- **List Variable**: имя списка. Если переменной с таким именем ещё нет, действие создаст список.
- **New Entry**: текст нового элемента.
- **Index (Optional)**: место для нового элемента. Если оставить поле пустым, элемент добавится в конец. Все последующие элементы сдвинутся на одну позицию.
- **Skip If Already in List**: не добавляет элемент, если в списке уже есть элемент с таким же текстом. Параметр **Ignore Case** позволяет считать `Apple` и `apple` совпадением.

### Изменить элемент списка (переменная FM)

**Идентификатор:** `set_list_entry`

Заменяет элемент по указанному **Index** в [списковой переменной](/variables#list-actions) на **New Value**. Ничего не происходит, если в списке нет элемента с таким индексом.

### Удалить элемент из списка (переменная FM)

**Идентификатор:** `remove_from_list`

Удаляет элементы из [списковой переменной](/variables#list-actions). В параметре **Remove** укажите, что именно удалить:

- **Entry at Index**: элемент с указанным индексом.
- **First Match**: первый элемент, полностью совпадающий с **Value to Remove**.
- **All Matches**: все элементы, совпадающие с этим значением.

Параметр **Ignore Case** позволяет считать `Apple` и `apple` совпадением.

### Очистить список (переменная FM)

**Идентификатор:** `clear_list`

Удаляет все элементы [списковой переменной](/variables#list-actions). Пустой список сохраняется.

### Задать список (переменная FM)

**Идентификатор:** `set_list`

Заменяет все элементы [списковой переменной](/variables#list-actions). В параметре **Entries From** выберите источник элементов:

- **Split Text**: разбивает **Text to Split** по **Separator**, например `,`. Пустой разделитель разбивает текст по переводам строк. Параметр **Trim Entries** удаляет пробелы в начале и конце элементов, а **Skip Empty Entries** исключает пустые элементы.
- **JSON Array**: использует элементы массива, например `["Diamonds","Emeralds"]`, или значение `$$other_list`, чтобы скопировать другой список. Любой другой текст становится единственным элементом, а пустой текст очищает список.

В окне отображается предварительный просмотр элементов.

### Упорядочить список (переменная FM)

**Идентификатор:** `arrange_list`

Изменяет порядок элементов [списковой переменной](/variables#list-actions). В параметре **Arrangement** выберите вариант:

- **Sort A–Z** и **Sort Z–A**: сортировка по алфавиту.
- **Numbers, Smallest First** и **Numbers, Biggest First**: сортировка по числовому значению. Элементы, не являющиеся числами, перемещаются в конец.
- **Reverse Order**: последний элемент становится первым.
- **Shuffle**: случайный порядок.
- **Remove Duplicates**: оставляет только первое вхождение каждого значения.

Во всех действиях со списками индекс первого элемента равен `0`, а `-1` обозначает последний элемент. Имя списка может содержать плейсхолдеры; если перед ним поставить `$$`, действие использует значение этой переменной в качестве имени списка. Текстовые переменные со значением остаются без изменений, а в журнал игры записывается предупреждение.

## Интернет и сеть

### Открыть ссылку в браузере

**Идентификатор:** `openlink`

Открывает ссылку в браузере по умолчанию без запроса подтверждения.

**Значение:** ссылка, например `https://discord.gg/example`

Используйте только ссылки, которым доверяете.

### Отправить HTTP-запрос

**Идентификатор:** `send_http_request`

Отправляет веб-запрос в фоновом режиме. Ответ можно записать в журнал игры или сохранить в переменной.

| Параметр | Описание |
|---|---|
| URL | HTTP- или HTTPS-адрес. |
| Method | Метод запроса: `GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `HEAD` или `OPTIONS`. |
| Body | Отправляемые данные. Не отправляется для методов `GET` и `HEAD`. |
| Content type | Тип содержимого `Content-Type`, например `application/json`. |
| Timeout | Время ожидания соединения и ответа в секундах. |
| Log response | Записывает ответ в журнал игры. |
| Response variable | Сохраняет ответ в указанную переменную после его получения. |
| Single-line response | Удаляет переводы строк из ответа перед сохранением. |
| Authentication | Тип авторизации: None, Basic, Bearer или API key. |
| Headers | Дополнительные заголовки запроса. |

Следующее действие не ждёт получения ответа. Ошибки в ответах также записываются в журнал и сохраняются. Не указывайте в действии пароли или токены доступа: любой, у кого есть этот макет, сможет их прочитать.

### Отправить данные FM на сервер

**Идентификатор:** `send_fm_data_to_server`

Отправляет [данные FM](/fm-data) на сервер, на котором также должен быть установлен FancyMenu.

**Значение:** `data_identifier||data`

### Подключиться к удалённому серверу

**Идентификатор:** `connect_to_remote_server`

Подключается к удалённому серверу или использует уже открытое соединение.

**Значение:** адрес сервера, например `wss://example.com/ws`

Поддерживаемые адреса см. в разделе [Связь с удалённым сервером](/remote-server-communication#url-modes).

### Отправить данные удалённому серверу

**Идентификатор:** `send_data_to_remote_server`

Отправляет текст удалённому серверу и при необходимости сначала устанавливает соединение.

**Значение:** `server_address||data`

### Закрыть соединение с удалённым сервером

**Идентификатор:** `close_remote_server_connection`

Закрывает одно соединение с удалённым сервером.

**Значение:** идентификатор запроса; обычно это `$$request_id` из слушателя [**On Remote Server Connected**](/listeners#on-remote-server-connected)

### Закрыть все соединения с удалёнными серверами

**Идентификатор:** `close_all_remote_server_connections`

Закрывает все соединения с удалёнными серверами, открытые FancyMenu.

**Значение:** нет

## Файлы

### Создать файл в папке игры

**Идентификатор:** `create_file_in_game_dir`

Создаёт пустой файл. При необходимости создаёт и отсутствующие папки. Существующий файл остаётся без изменений.

**Значение:** путь к файлу, например `config/mymodpack/first_start.txt`

Все действия с файлами работают только внутри папки игры (папки экземпляра). Пути, начинающиеся с `.minecraft/`, вместо этого используют папку `.minecraft` по умолчанию, которая может находиться в другом месте.

### Удалить файл или папку в папке игры

**Идентификатор:** `delete_file_in_game_dir`

Удаляет файл или папку вместе со всем её содержимым.

**Значение:** путь, например `config/mymodpack/cache.txt`

Если в конце пути поставить `*`, например `config/downloads/*`, действие удалит все файлы непосредственно в этой папке, но сохранит саму папку и вложенные папки.

### Копировать файл или папку в папке игры

**Идентификатор:** `copy_file_in_game_dir`

Копирует файл или папку вместе со всем её содержимым.

**Значение:** `source||destination`, например `config/presets/default.json||config/mymod/settings.json`

- Если в конце источника поставить `*`, например `config/presets/*||config/mymod/`, действие скопирует все файлы непосредственно в этой папке, но не сами папки. В этом случае назначение должно быть папкой; при необходимости она будет создана.
- Существующие файлы не перезаписываются: если файл назначения уже существует, действие завершится с ошибкой.

### Переместить файл или папку в папке игры

**Идентификатор:** `move_file_in_game_dir`

Перемещает файл или папку вместе со всем её содержимым.

**Значение:** `source||destination`

Звёздочка `*` в конце источника работает так же, как в действии [**Копировать файл или папку в папке игры**](#copy-filefolder-in-game-directory). Существующие файлы не перезаписываются.

### Переименовать файл или папку в папке игры

**Идентификатор:** `rename_file_in_game_dir`

Переименовывает файл или папку. Действие завершится с ошибкой, если объект с новым именем уже существует.

**Значение:** `path||new_name`, например `config/mymod/old_name.txt||new_name.txt`

### Скачать файл в папку игры

**Идентификатор:** `download_file_to_game_dir`

Загружает файл в папку в фоновом режиме.

**Значение:** `url||target_folder`, например `https://example.com/pack.zip||downloads`

- Во второй части указывается папка, а не имя файла. FancyMenu определяет имя по загруженному файлу или ссылке.
- Файл с таким же именем будет перезаписан.
- Слушатель [**On File Downloaded via Action**](/listeners#on-file-downloaded-via-action) запускается после успешного завершения или ошибки загрузки. При успехе `$$target_file_path` содержит путь к сохранённому файлу.

### Распаковать ZIP-архив в папке игры

**Идентификатор:** `extract_zip_file_in_game_dir`

Распаковывает ZIP-архив в папку в фоновом режиме.

**Значение:** `zip_path||target_folder`, например `downloads/pack.zip||resourcepacks/MyPack`

Файлы с совпадающими именами будут заменены. Дополнительная папка с именем ZIP-архива не создаётся. После завершения запускается слушатель [**On ZIP Extracted via Action**](/listeners#on-zip-extracted-via-action). Распаковывайте только архивы, которым доверяете.

### Открыть файл или папку в папке игры

**Идентификатор:** `open_file_folder_in_game_dir`

Открывает файл или папку в программе, которая используется для этого типа файлов в системе.

**Значение:** путь, например `screenshots`

### Записать данные в файл в папке игры

**Идентификатор:** `write_file_in_game_dir`

Записывает текст в файл. При необходимости файл и содержащие его папки будут созданы.

**Значение:** `path|||text|||append`, например `config/mymodpack/log.txt|||Подключился к серверу\n|||true`

`\n` начинает новую строку. Если для `append` указать `true`, текст добавится в конец файла; если `false` — заменит его содержимое.

### Выбрать файл в системе

**Идентификатор:** `select_file_to_game_dir`

Открывает системный диалог выбора файла и копирует выбранный файл в папку игры.

**Значение:** `target_path|||filter_name|||extensions|||overwrite`, например `config/fancymenu/assets/background.png|||Images|||png;jpg|||true`

- `target_path` — полный путь копии, включая имя файла.
- Разделяйте расширения символами `;` или `,`. Если расширения не указаны, можно выбрать любой файл.
- Если для `overwrite` указать `false`, действие завершится с ошибкой, если файл уже существует.

Слушатель [**On File Selected**](/listeners#on-file-selected) запускается после копирования файла, отмены выбора или возникновения ошибки.

## Игра и FancyMenu

### Выйти из Minecraft

**Идентификатор:** `quitgame`

Закрывает игру.

**Значение:** нет

### Изменить настройку Minecraft

**Идентификатор:** `edit_minecraft_option`

Изменяет настройку Minecraft, например дальность прорисовки или масштаб интерфейса.

**Значение:** `option_name:value`, например `renderDistance:12`

Названия параметров см. в разделе [Настройки Minecraft](/minecraft-options).

### Имитировать нажатие клавиши

**Идентификатор:** `mimic_keybind`

Нажимает назначенную клавишу Minecraft, например клавишу прыжка или крадущегося шага; клавишу также можно удерживать.

**Значение:** `keybind|||hold|||duration_ms`, например `key.jump|||false|||1000`

| Часть | Описание |
|---|---|
| `keybind` | Идентификатор назначения клавиши, например `key.jump` или `key.sneak`. |
| `hold` | `true` удерживает клавишу, `false` нажимает её один раз. |
| `duration_ms` | Длительность удержания в миллисекундах. По умолчанию — `1000`. |

### Управлять набором ресурсов

**Идентификатор:** `manage_resource_pack`

Включает или отключает набор ресурсов. Настройте действие в отдельном окне:

- **Target Resource Pack**: название набора, отображаемое на экране наборов ресурсов. Регистр букв не учитывается.
- **Action Mode**: **Enable**, **Disable** или **Toggle**.
- **Reload Resources**: перезагружает наборы ресурсов сразу после изменения. Отключите параметр, чтобы перезагрузить их позже, например с помощью действия [**Reload Resource Packs**](#reload-resource-packs).

Наборы ресурсов, необходимые игре, отключить нельзя.

### Перезагрузить наборы ресурсов

**Идентификатор:** `reload_resource_packs`

Перезагружает наборы ресурсов, как сочетание клавиш `F3 + T`. В течение пяти секунд после перезагрузки действие ничего не делает, чтобы не допустить постоянной перезагрузки.

**Значение:** нет

### Перезагрузить FancyMenu

**Идентификатор:** `reloadmenu`

Перезагружает макеты, [пользовательские интерфейсы](/custom-guis), [панорамы](/panoramas), [слайд-шоу](/slideshows), настройки и файлы FancyMenu. Наборы ресурсов не перезагружаются.

**Значение:** нет

> [!WARNING]
> Перезагрузка занимает некоторое время. Используйте это действие на кнопке, но не в [тикере](/elements#ticker) или [слушателе](/listeners), которые срабатывают часто.

### Запустить планировщик

**Идентификатор:** `start_scheduler`

Запускает [планировщик](/schedulers).

**Значение:** идентификатор планировщика

### Остановить планировщик

**Идентификатор:** `stop_scheduler`

Останавливает [планировщик](/schedulers).

**Значение:** идентификатор планировщика

### Скопировать текст в буфер обмена

**Идентификатор:** `copytoclipboard`

Копирует текст в буфер обмена.

**Значение:** текст, например `play.example.net`

### Вывести текст в журнал игры

**Идентификатор:** `print_to_log`

Записывает строку в журнал игры. Полезно для проверки работы скрипта.

**Значение:** текст
