# Скрипты действий

FancyMenu позволяет добавлять интерактивность в ваши меню, назначая элементам **действия**. Эти действия выполняются при нажатии кнопки, при тике тикера, при использовании ползунка или при открытии/закрытии экрана. Вы также можете создавать расширенные скрипты действий с помощью простых управляющих операторов, таких как **if**, **else-if**, **else** и **while**, чтобы контролировать, какие действия выполняются и когда.

# Что такое действия?

**Действие** — это задача или операция, которую FancyMenu выполняет при срабатывании. Например, действие может открыть новый экран, отправить сообщение в чат или изменить громкость аудиоэлемента. В редакторе FancyMenu действия настраиваются со значением (если оно нужно), которое задаёт дополнительные сведения — например, URL или адрес сервера.

# Что такое операторы?

Чтобы создавать более сложное поведение, FancyMenu поддерживает базовые управляющие операторы в скриптах действий. К ним относятся:

- **Оператор If:** Выполняет блок действий только если выполнено указанное [условие](/en/conditions).
- **Оператор Else-If:** Проверяет другое [условие](/en/conditions), если предыдущее *if* (или более раннее *else-if*) не было выполнено.
- **Оператор Else:** Выполняется, если ни одно из предыдущих [условий](/en/conditions) не выполнено.
- **Оператор While:** Повторяет блок действий непрерывно, пока [условие](/en/conditions) остаётся истинным (с встроенным тайм-аутом для предотвращения бесконечных циклов).
- **Блок задержки:** Ждёт указанное время перед выполнением содержащихся в нём действий. Остальная часть скрипта продолжает выполняться, пока идёт отсчёт задержки.
- **Блок выполнения позже:** Ставит содержащиеся действия в очередь для выполнения в основном потоке после задержки в миллисекундах.
- **Комментарий:** Добавляет заметку внутрь скрипта для удобства. Комментарии не выполняют никаких действий.

Сочетая эти операторы с действиями, вы можете создавать динамическое и условное поведение, например проверять, низко ли здоровье игрока, прежде чем отправить предупреждение, или повторять обновление, пока условие не изменится.

# Где можно использовать скрипты действий?

Скрипты действий универсальны и могут использоваться по всему вашему макету. Их можно назначать, например, следующим элементам:

- **Кнопки:** Выполняют действие при нажатии.
- **Тикеры:** Непрерывно запускают скрипт действий для обновления информации на экране в рамках макета.
- **Ползунки:** Запускают скрипт действий всякий раз, когда изменяется значение ползунка.
- **События экрана:** Запускают скрипты при открытии или закрытии экрана (например, воспроизведение звука при появлении меню).
- **Слушатели:** Когда срабатывает слушатель, отслеживающий определённое событие, он выполняет свой скрипт действий.
- **Планировщики:** Выполняют действия по расписанию, даже когда ни один экран не открыт.

# Использование плейсхолдеров в действиях

Значения действий поддерживают динамический контент через **плейсхолдеры**. Чаще всего эти плейсхолдеры используют синтаксис, похожий на JSON, и подставляют актуальные данные во время выполнения действия.

## Плейсхолдеры в JSON-подобном формате

Это обычные [плейсхолдеры](/en/placeholders), которые можно использовать во многих местах макетов.

Они используют такой синтаксис:

```json
{"placeholder": "placeholder_id", "values": {"key1": "value1", "key2": "value2"}}
```

Они могут получать игровые данные, например имя игрока, размеры экрана или вычисленные значения с помощью плейсхолдера **Calculator**. Для более продвинутых сценариев вы также можете вкладывать плейсхолдеры друг в друга.

## Плейсхолдеры `$$` (переменные)

Плейсхолдеры `$$` — особые. Некоторые функции FancyMenu предоставляют эти специальные плейсхолдеры для вложенных действий, требований и обычных плейсхолдеров, чтобы внутри них можно было получить больше информации об окружении (элементе, слушателе и т. д.), в котором они находятся.

Например, если действия используются внутри ползунка, то `$$value` в действии будет заменён текущим значением ползунка.

При использовании действий в слушателях каждый слушатель предоставляет свой уникальный набор переменных/плейсхолдеров для получения дополнительной информации о слушателе, такой как нажатая кнопка мыши, введённая структура и т. д.

# Как настроить и редактировать действия

Чтобы добавить, изменить или удалить действия (и блоки операторов) для элемента, просто **щёлкните по элементу правой кнопкой мыши** (будь то кнопка, ползунок, тикер или другой интерактивный элемент), а затем выберите **Manage Action Script**. Откроется экран управления действиями, где вы сможете:

- **Добавлять новые действия или операторы:** Вставлять новые записи действий или управляющие операторы (if, else-if, else, while) для построения скрипта.
- **Редактировать существующие действия или операторы:** Изменять значение действия или логику управления.
- **Удалять действия или операторы:** Убирать ненужные действия из скрипта.

Для [слушателей](/listeners) есть специальное меню для управления и создания слушателей, включая доступ к их скриптам действий, чтобы получить такой же опыт, как при редактировании скрипта действий кнопки или ползунка, например.

> На экране редактора скриптов действий просто щёлкните правой кнопкой мыши по большой тёмно-серой области, чтобы открыть контекстное меню для добавления действий, операторов и многого другого.
{.is-info}


# Сочетания клавиш и другие возможности редактора скриптов действий

Редактор скриптов действий имеет отличные QoL-функции, которые делают редактирование скриптов очень простым.

## Сочетания клавиш

- `DEL` : Быстро удалить выбранную запись
- `ENTER` : Начать встроенное редактирование выбранной записи (или открыть экран редактирования, если для выбранной записи нет встроенного редактирования)
- `CTRL + C` : Копировать выбранное действие (пока работает только с действиями)
- `CTRL + V` : Вставить ранее скопированное действие
- `CTRL + Z` : Шаг назад (отменить)
- `CTRL + Y` : Шаг вперёд (повторить)
- `ARROW UP` : Перейти на одну запись выше от текущей выбранной
- `ARROW DOWN` : Перейти на одну запись ниже от текущей выбранной
- `SHIFT + ARROW UP` : Переместить выбранную запись на одну позицию вверх
- `SHIFT + ARROW DOWN` : Переместить выбранную запись на одну позицию вниз
- `A` : Быстро открыть экран выбора действия, чтобы добавить новое действие
- `CTRL + S` : Готово/сохранить из окна редактора

## Другие удобные функции

- Двойной щелчок по значению действия позволяет редактировать значение, не переходя в полный экран редактирования значения.
- Цепочки операторов IF (с добавленными ELSE/ELSE-IF), циклы WHILE и папки можно сворачивать (только визуально, это не влияет на логику скрипта).
- Редактор всегда добавляет новые действия ниже выбранной записи (или вложенными в выбранную цепочку/цикл/папку).
- Щелчок правой кнопкой мыши по тёмно-серому фону области скрипта открывает контекстное меню с опциями для добавления действий, операторов и всего остального важного.

# Действия подробно

Этот список содержит большинство, если не все, действия, доступные в FancyMenu. Возможно, иногда список немного устаревает из-за обновлений мода.

## Следующий трек (`audio_next_track`)
- **Описание:** Переходит к следующему треку в аудиоэлементе
- **Требуется значение:** Да - `audio_element_identifier` (ID аудиоэлемента, которым нужно управлять)

## Предыдущий трек (`audio_previous_track`)
- **Описание:** Переходит к предыдущему треку в аудиоэлементе
- **Требуется значение:** Да - `audio_element_identifier` (ID аудиоэлемента, которым нужно управлять)

## Установить громкость трека (`set_audio_element_volume`)
- **Описание:** Устанавливает громкость аудиоэлемента (0.0–1.0)
- **Требуется значение:** Да - `element_identifier:volume`

## Переключить воспроизведение/паузу трека (`audio_toggle_play`)
- **Описание:** Переключает состояние воспроизведения/паузы текущего трека аудиоэлемента
- **Требуется значение:** Да - `audio_element_identifier`

## Воспроизвести аудио (`play_audio`)
- **Описание:** Однократно воспроизводит аудиоресурс. Действие отслеживает запущенное им аудио, чтобы его позже можно было остановить с помощью `stop_all_action_audios`.
- **Требуется значение:** Да - JSON-конфигурация с `audioSource`, `soundChannel` и `baseVolume`
- **Пример значения:** `{"audioSource":"[source:local]/config/fancymenu/assets/example.ogg","soundChannel":"master","baseVolume":1.0}`

## Остановить все аудио действий (`stop_all_action_audios`)
- **Описание:** Останавливает все аудиодорожки, запущенные действием **Play Audio**. Это не останавливает аудиоэлементы, звуки открытия/закрытия меню, звуки кнопок или другие аудиосистемы.
- **Требуется значение:** Нет

## Установить громкость видеоэлемента (`set_video_element_volume`)
- **Описание:** Устанавливает громкость видеоэлемента (0.0–1.0)
- **Требуется значение:** Да - `video_element_identifier:volume`

## Установить позицию воспроизведения видеоэлемента (`set_video_element_play_time`)
- **Описание:** Перемещает видеоэлемент к отметке времени в миллисекундах
- **Требуется значение:** Да - `video_element_identifier:timestamp_ms`

## Переключить состояние паузы видеоэлемента (`toggle_video_element_pause_state`)
- **Описание:** Переключает состояние паузы видеоэлемента
- **Требуется значение:** Да - `video_element_identifier`

## Установить громкость видеофона (`set_video_menu_background_volume`)
- **Описание:** Устанавливает громкость видеофона меню (0.0–1.0)
- **Требуется значение:** Да - `background_identifier:volume`

> Чтобы получить идентификатор фона, щёлкните правой кнопкой мыши по фону редактора и нажмите «Copy Background Identifier».
{.is-info}

## Установить позицию воспроизведения видеофона (`set_video_menu_background_play_time`)
- **Описание:** Перемещает видеофон меню к отметке времени в миллисекундах
- **Требуется значение:** Да - `background_identifier:timestamp_ms`

> Чтобы получить идентификатор фона, щёлкните правой кнопкой мыши по фону редактора и нажмите «Copy Background Identifier».
{.is-info}

## Переключить состояние паузы видеофона (`toggle_video_menu_background_pause_state`)
- **Описание:** Переключает состояние паузы видеофона меню
- **Требуется значение:** Да - `background_identifier`

> Чтобы получить идентификатор фона, щёлкните правой кнопкой мыши по фону редактора и нажмите «Copy Background Identifier».
{.is-info}

## Переключить макет (`toggle_layout`)
- **Описание:** Переключает макет (включить/выключить) по его имени
- **Требуется значение:** Да - `layout_name`

## Включить макет (`enable_layout`)
- **Описание:** Включает макет по его имени
- **Требуется значение:** Да - `layout_name`

## Выключить макет (`disable_layout`)
- **Описание:** Выключает макет по его имени
- **Требуется значение:** Да - `layout_name`

## Открыть экран или пользовательский GUI (`opengui`)
- **Описание:** Открывает экран по его идентификатору (ванильный, модовый или пользовательский GUI)
- **Требуется значение:** Да - `screen_identifier`

> Это действие **не будет работать для каждого экрана**, особенно для экранов модов. Если действие не сможет открыть экран, будет показана ошибка. В таком случае мало что можно сделать, потому что, вероятно, это слишком сложный экран, который FancyMenu не может открыть автоматически.
> 
> Совместимость с экранами модов больше не будет добавляться вручную со стороны FancyMenu, потому что добавление поддержки для всех существующих модов заняло бы вечность, извините. В большинстве случаев также не рекомендуется обращаться к разработчику другого мода, потому что если FancyMenu не может открыть экран, то добавить поддержку для него непросто. Рекомендуемый обходной путь — попробовать использовать действие **"Mimic Vanilla/Mod Button"**, чтобы имитировать кнопку, открывающую нужный экран. Если такой кнопки нет, то, к сожалению, вам не повезло.
{.is-info}

## Закрыть экран (`closegui`)
- **Описание:** Закрывает активный экран
- **Требуется значение:** Нет

## Обновить экран (`update_screen`)
- **Описание:** Переинициализирует текущий экран
- **Требуется значение:** Нет

## Назад к последнему экрану (`back_to_last_screen`)
- **Описание:** Возвращается к предыдущему экрану (тому, что был перед текущим)
- **Требуется значение:** Нет

## Подключиться к серверу (`joinserver`)
- **Описание:** Подключает игрока к серверу Minecraft
- **Требуется значение:** Да - `server_ip:port`

## Войти в мир (`loadworld`)
- **Описание:** Заходит в мир Minecraft
- **Требуется значение:** Да - `world_folder_name`

## Войти в последний мир/на последний сервер (`join_last_world`)
- **Описание:** Заходит в последний мир или на последний сервер, где был игрок
- **Требуется значение:** Нет

## Покинуть мир или сервер (`disconnect_server_or_world`)
- **Описание:** Покидает мир или сервер и открывает указанный экран
- **Требуется значение:** Да - `screen_identifier`

## Выйти из Minecraft (`quitgame`)
- **Описание:** Полностью закрывает Minecraft
- **Требуется значение:** Нет

## Отправить сообщение/команду в чат (`sendmessage`)
- **Описание:** Отправляет сообщение в чат или выполняет чат-команду
- **Требуется значение:** Да - `message_text` или `/command_text`

## Выполнить команду от имени встроенного сервера (`execute_command_as_integrated_server`)
- **Описание:** Принудительно выполняет команду в одиночной игре от имени встроенного сервера, игнорируя права и настройку читов.
- **Требуется значение:** Да - текст команды, например `/give @p minecraft:diamond 1`

> Это действие работает только в одиночной игре, пока мир не открыт по LAN. В многопользовательских серверах оно намеренно ничего не делает.
{.is-warning}

## Вставить в чат (`paste_to_chat`)
- **Описание:** Вставляет текст в поле ввода чата (добавить или заменить)
- **Требуется значение:** Да - `true:Text` или `false:Text`

## Показать в чате [клиентская сторона] (`display_in_chat_client_side`)
- **Описание:** Выводит текст прямо в локальный чат (без сервера)
- **Требуется значение:** Да - `text_or_json`

## Отправить данные FM на сервер (`send_fm_data_to_server`)
- **Описание:** Отправляет пользовательские текстовые данные на текущий сервер FancyMenu через канал пакетов FM Data.
- **Требуется значение:** Да - `data_identifier||data`

## Подключиться к удалённому серверу (`connect_to_remote_server`)
- **Описание:** Открывает или повторно использует инициированное клиентом WebSocket-подключение к внешнему удалённому серверу.
- **Требуется значение:** Да - URL удалённого сервера, например `wss://example.com/ws`

## Отправить данные на удалённый сервер (`send_data_to_remote_server`)
- **Описание:** Открывает или повторно использует подключение к удалённому серверу и отправляет на него текстовые данные.
- **Требуется значение:** Да - `remote_server_url||data`

## Закрыть соединение с удалённым сервером (`close_remote_server_connection`)
- **Описание:** Закрывает конкретное соединение с удалённым сервером по ID запроса.
- **Требуется значение:** Да - ID запроса, обычно из переменной слушателя Remote Server, например `$$request_id`

## Закрыть все соединения с удалёнными серверами (`close_all_remote_server_connections`)
- **Описание:** Закрывает все активные соединения с удалёнными серверами, открытые FancyMenu.
- **Требуется значение:** Нет

## Открыть URL в браузере (`openlink`)
- **Описание:** Открывает ссылку в браузере по умолчанию
- **Требуется значение:** Да - `https://example.com`

## Скопировать текст в буфер обмена (`copytoclipboard`)
- **Описание:** Копирует текст в буфер обмена
- **Требуется значение:** Да - `text_to_copy`

## Вывести в журнал игры (`print_to_log`)
- **Описание:** Записывает строку в журнал игры
- **Требуется значение:** Да - `text_to_log`

## Установить значение переменной (FM Variable) (`set_variable`)
- **Описание:** Сохраняет текстовое содержимое в переменную FancyMenu
- **Требуется значение:** Да - `variable_name:variable_value`

## Очистить все переменные (FM Variable) (`clear_variables`)
- **Описание:** Очищает ВСЕ сохранённые переменные FancyMenu
- **Требуется значение:** Нет

## Отправить HTTP-запрос (`send_http_request`)
- **Описание:** Отправляет HTTP-запрос; может сохранить ответ в переменную
- **Требуется значение:** Да - конфигурация HTTP-запроса

> Это действие позволяет отправлять данные в REST API, webhook'и или любой HTTP-эндпоинт.
> Поддерживает различные методы аутентификации, пользовательские заголовки и разные типы запросов.
> 
> Это действие также позволяет сохранить ответ запроса в переменную FancyMenu для последующего использования!
{.is-info}

## Управлять ресурс-паком (`manage_resource_pack`)
- **Описание:** Включить/выключить/переключить ресурс-пак по отображаемому имени (с необязательной перезагрузкой)
- **Требуется значение:** Да - `pack_name|||MODE|||reload_bool`

## Перезагрузить ресурс-паки (`reload_resource_packs`)
- **Описание:** Перезагружает ресурс-паки (кулдаун 5 секунд)
- **Требуется значение:** Нет

## Перезагрузить FancyMenu (`reloadmenu`)
- **Описание:** Перезагружает FancyMenu, включая панорамы, слайд-шоу и все ресурсы (тяжёлая операция)
- **Требуется значение:** Нет

> Это действие оказывает **сильное влияние на производительность** и может вызывать лаги, если использовать его в тикерах. Не рекомендуется использовать это действие где-либо, кроме кнопки.
{.is-warning}

## Переключить аниматор элемента (`toggle_element_animator`)
- **Описание:** Переключает состояние воспроизведения аниматора элемента
- **Требуется значение:** Да - `animator_identifier`

## Включить аниматор элемента (`enable_element_animator`)
- **Описание:** Включает аниматор элемента
- **Требуется значение:** Да - `animator_identifier`

## Выключить аниматор элемента (`disable_element_animator`)
- **Описание:** Выключает аниматор элемента
- **Требуется значение:** Да - `animator_identifier`

## Сбросить аниматор элемента (`reset_element_animator`)
- **Описание:** Сбрасывает таймлайн/состояние аниматора элемента
- **Требуется значение:** Да - `animator_identifier`

## Имитировать кнопку Vanilla/Mod (`mimicbutton`)
- **Описание:** Имитирует действие нажатия кнопки vanilla или мода
- **Требуется значение:** Да - `screen_identifier:widget_locator`

## Имитировать назначение клавиши (`mimic_keybind`)
- **Описание:** Выполняет Minecraft-назначение клавиши (с опциональным удержанием)
- **Требуется значение:** Да - `keybind_id|||keep_pressed_bool|||duration_ms`

## Установить значение поля текстового ввода (`set_text_input_field_value`)
- **Описание:** Устанавливает значение пользовательского или ванильного поля ввода по идентификатору элемента.
- **Требуется значение:** Да - `element_identifier|||new_value|||force_set_when_inactive`

## Создать файл в каталоге игры (`create_file_in_game_dir`)
- **Описание:** Создаёт пустой файл в каталоге игры (корень инстанса). Поддерживает префикс `.minecraft/` для указания каталога профиля стандартного лаунчера (он может отличаться от текущего каталога инстанса).
- **Требуется значение:** Да - `file_path`

## Удалить файл/папку в каталоге игры (`delete_file_in_game_dir`)
- **Описание:** Удаляет файл или папку в каталоге игры (корень инстанса). Поддерживает префикс `.minecraft/` для работы с профилем стандартного лаунчера (может отличаться от текущего инстанса). Добавьте `*`, чтобы удалить **все файлы непосредственно внутри** папки (игнорируя подпапки; сама папка сохраняется).
- **Требуется значение:** Да - `target_path`

## Скопировать файл/папку в каталоге игры (`copy_file_in_game_dir`)
- **Описание:** Копирует внутри каталога игры (корень инстанса); префикс `.minecraft/` указывает на каталог профиля стандартного лаунчера (не всегда текущий инстанс). Добавьте `*` к пути **источника**, чтобы скопировать каждый файл непосредственно внутри этой папки (игнорируя подпапки); назначение должно быть каталогом и не может использовать `*`.
- **Требуется значение:** Да - `source||destination`

## Переместить файл/папку в каталоге игры (`move_file_in_game_dir`)
- **Описание:** Перемещает внутри каталога игры (корень инстанса); префикс `.minecraft/` указывает на каталог профиля стандартного лаунчера (может отличаться от текущего инстанса). Добавьте `*` к пути **источника**, чтобы переместить каждый файл непосредственно внутри этой папки (игнорируя подпапки); назначение должно быть каталогом и не может использовать `*`.
- **Требуется значение:** Да - `source||destination`

## Переименовать файл/папку в каталоге игры (`rename_file_in_game_dir`)
- **Описание:** Переименовывает файл или папку внутри каталога игры (корень инстанса); префикс `.minecraft/` указывает на каталог профиля стандартного лаунчера (может отличаться от текущего инстанса). Содержимое сохраняется, меняется только имя.
- **Требуется значение:** Да - `path||new_name`

## Скачать файл в каталог игры (`download_file_to_game_dir`)
- **Описание:** Асинхронно скачивает файл в каталог игры (корень инстанса); префикс `.minecraft/` указывает на каталог профиля стандартного лаунчера (не обязательно текущий инстанс). Укажите **целевую папку**; имя файла определяется по заголовкам/URL автоматически.
- **Требуется значение:** Да - `url||target_folder`

## Извлечь ZIP-файл в каталоге игры (`extract_zip_file_in_game_dir`)
- **Описание:** Извлекает ZIP-файл в целевую папку внутри каталога игры или стандартного каталога `.minecraft`. По завершении запускает слушатель **On ZIP Extracted via Action**.
- **Требуется значение:** Да - `source_zip_path||target_folder_path`

## Открыть файл/папку в каталоге игры (`open_file_folder_in_game_dir`)
- **Описание:** Открывает файл или папку с помощью приложения по умолчанию в операционной системе. По соображениям безопасности целевой путь должен оставаться внутри каталога игры или стандартного каталога `.minecraft`.
- **Требуется значение:** Да - `target_path`

## Записать файл в каталоге игры (`write_file_in_game_dir`)
- **Описание:** Записывает или добавляет текст внутри каталога игры (корень инстанса); префикс `.minecraft/` указывает на каталог профиля стандартного лаунчера (может отличаться от этого инстанса). Создаёт файл, если его нет. Поддерживает `\n` в значении для вставки переносов строк; режим добавления управляется последним логическим значением.
- **Требуется значение:** Да - `path|||content|||append_bool`

## Выбрать файл из системы (`select_file_to_game_dir`)
- **Описание:** Открывает нативный диалог выбора файла (в любом расположении) и копирует выбранный файл в каталог игры (корень инстанса) или в стандартный `.minecraft/` при использовании префикса (этот каталог может отличаться от текущего инстанса). Поддерживает фильтры расширений, собственную подпись фильтра и необязательное переключение перезаписи.
- **Требуется значение:** Да - конфигурация выбора

## Показать уведомление Toast (`show_toast`)
- **Описание:** Показывает настраиваемое уведомление toast
