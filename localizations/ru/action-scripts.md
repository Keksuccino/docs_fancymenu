# Скрипты действий

Скрипты действий запускают настроенные задачи, когда нажимают на [Button](./elements#button), обновляется [Ticker](./elements#ticker), изменяется [Slider](./elements#slider), открывается или закрывается экран либо происходит другое поддерживаемое событие. Операторы **if**, **else-if**, **else** и **while** добавляют условное управление.

> [!CAUTION]
> Импортированные скрипты действий могут изменять файлы, обращаться к серверам, открывать ссылки или выполнять команды. Используйте только те источники, которым доверяете.

# Что такое действия?

**Действие** — это задача или операция, которую FancyMenu выполняет при срабатывании. Например, действие может открыть новый экран, отправить сообщение в чат или изменить громкость [Audio element](./elements#audio). В редакторе FancyMenu действия настраиваются со значением (если оно нужно), которое задаёт дополнительные сведения — например URL или адрес сервера.

# Операторы

Чтобы создавать более сложное поведение, FancyMenu поддерживает операторы управления в скриптах действий:

| Оператор | Поведение |
|---|---|
| **If** | Выполняет свои действия только тогда, когда выполнены его [условия](./conditions). |
| **Else-If** | Проверяет другой набор [условий](./conditions), если предыдущий **If** или **Else-If** не был выполнен. |
| **Else** | Выполняется, когда ни одно из предыдущих условий **If** или **Else-If** не выполнено. |
| **While** | Повторяет свои действия, пока его [условия](./conditions) остаются истинными. Останавливается через три секунды, чтобы предотвратить бесконечные циклы; не используйте его как таймер. |

# Блоки

В скрипты можно добавлять блоки, которые дают полезные возможности для большего контроля над потоком/временем выполнения скрипта и добавляют удобные функции:

| Блок | Поведение |
|---|---|
| **Delay** | Запускает обратный отсчёт, не останавливая остальную часть скрипта. Вложенные действия становятся доступными после задержки; переинициализация экрана сбрасывает обратный отсчёт. |
| **Execute Later** | Планирует новый запуск вложенных действий после задержки каждый раз, когда блок достигается. |
| **Comment** | Добавляет заметку внутри скрипта для организации и не выполняет действие. |

# Выполнение скрипта

Действия выполняются сверху вниз. Неудачное действие записывается в журнал, затем скрипт продолжается.

Загрузки, извлечение ZIP и HTTP-запросы завершаются позже; следующее действие их не ждёт. Используйте [**On File Downloaded via Action**](./listeners#on-file-downloaded-via-action-file_downloaded_via_action), [**On ZIP Extracted via Action**](./listeners#on-zip-extracted-via-action-zip_extracted_via_action) или переменную ответа HTTP, если последующая работа зависит от результата.

# Где можно использовать скрипты действий?

Скрипты действий универсальны и могут использоваться по всему макету. Их можно назначать, например, на:

- [**Buttons**](./elements#button): Выполнять действие при нажатии на кнопку.
- [**Tickers**](./elements#ticker): Непрерывно запускать скрипт действий для обновления информации на экране внутри макета.
- [**Sliders**](./elements#slider): Запускать скрипт действий каждый раз, когда меняется значение слайдера.
- **События экрана:** Запускать скрипты при открытии или закрытии экрана (например, воспроизводить звук при появлении меню).
- [**Listeners**](./listeners): Когда слушатель получает настроенное событие, он запускает свой скрипт действий.
- [**Schedulers**](./schedulers): Выполнять действия по расписанию, даже когда ни один экран не открыт.

# Использование плейсхолдеров в действиях

Значения действий поддерживают динамическое содержимое через **плейсхолдеры**. Обычно эти плейсхолдеры используют синтаксис, похожий на JSON, и подставляют актуальные данные во время выполнения действия.

## Плейсхолдеры в формате JSON-подобного синтаксиса

Это обычные [плейсхолдеры](./placeholders), которые можно использовать во многих местах макетов.

Они имеют такой синтаксис:

```json
{"placeholder": "placeholder_id", "values": {"key1": "value1", "key2": "value2"}}
```

Они могут получать игровые данные, такие как имя игрока, размеры экрана или вычисленные значения с помощью [**Calculator** placeholder](./placeholders#calculator-calc). Также можно вкладывать плейсхолдеры друг в друга для более продвинутого использования.

## `$$` Плейсхолдеры (переменные)

Значения `$$` — это значения только для чтения, которые предоставляются определённому скрипту действий функцией, запускающей его.

Например, [Slider](./elements#slider) передаёт своё текущее значение как `$$value`.

Каждый [listener](./listeners) документирует передаваемые им значения `$$`, например нажатую кнопку мыши или введённую структуру.

Имена `$$` чувствительны к регистру и работают только в том скрипте, который их предоставляет. См. [Listeners](./listeners#listener-variables).

## Разделители значений действий

Используйте точный разделитель, указанный для каждого действия: `:`, `||` или `|||`. Внутри поля нет синтаксиса экранирования для разделителей.

Плейсхолдеры подставляются до разделения значения. Для `set_variable` только первое двоеточие отделяет имя от значения, поэтому все последующие двоеточия остаются частью значения.

## Текстовые значения

Коды форматирования [FancyMenu](./text-formatting#minecraft-text-formatting) используют `&` вместо символа Minecraft `§` везде, где действие принимает форматированный текст.

- [**Send Chat Message/Command**](#send-chat-messagecommand-sendmessage) и [**Paste to Chat**](#paste-to-chat-paste_to_chat) поддерживают эти коды форматирования.
- [**Display In Chat [Client-Side]**](#display-in-chat-client-side-display_in_chat_client_side) принимает обычный текст или сериализованный JSON-компонент текста Minecraft.
- [**Open URL in Browser**](#open-url-in-browser-openlink) применяет то же преобразование кодов форматирования перед передачей URL в операционную систему.

# Как настроить и редактировать действия

Чтобы редактировать действия элемента и блоки операторов, **щелкните по элементу правой кнопкой мыши** и выберите **Manage Action Script**. В редакторе можно:

- **Добавлять новые действия или операторы:** Вставляйте новые записи действий или операторы управления (if, else-if, else, while), чтобы собрать свой скрипт.
- **Редактировать существующие действия или операторы:** Изменяйте значение действия или логику управления.
- **Удалять действия или операторы:** Убирайте ненужные действия из скрипта.

Создавайте и редактируйте скрипты слушателей через [**Customization -> Manage Listeners**](./listeners#using-listeners).

# Горячие клавиши редактора скриптов действий

## Горячие клавиши

- `DEL` : Быстро удалить выбранную запись
- `ENTER` : Начинает редактирование выбранной записи прямо в строке (или открывает экран редактирования, если для выбранной записи нет встроенного редактирования)
- `Ctrl/Command + C` : Скопировать выбранное действие (пока работает только с действиями)
- `Ctrl/Command + V` : Вставить ранее скопированное действие
- `Ctrl/Command + Z` : На один шаг назад (undo)
- `Ctrl/Command + Y` : На один шаг вперёд (redo)
- `ARROW UP` : Перейти на одну запись вверх от текущей выбранной
- `ARROW DOWN` : Перейти на одну запись вниз от текущей выбранной
- `SHIFT + ARROW UP` : Переместить выбранную запись на одну позицию вверх
- `SHIFT + ARROW DOWN` : Переместить выбранную запись на одну позицию вниз
- `A` : Быстро открыть экран выбора действия, чтобы добавить новое действие
- `Ctrl/Command + S` : Готово/сохранить из окна редактора

## Редактирование

- Двойной щелчок по значению действия позволяет редактировать значение без перехода в полный экран редактирования значения.
- Цепочки операторов IF (с добавленными ELSE/ELSE-IF), циклы WHILE и папки можно сворачивать (это только визуально и не влияет на логику скрипта).
- Редактор всегда добавляет новые действия ниже выбранной записи (или внутрь выбранной цепочки/цикла/папки).
- Щелчок правой кнопкой мыши по тёмно-серому фону области скрипта открывает контекстное меню с вариантами добавления действий, операторов и всего остального важного.

# Действия подробно

В этом разделе перечислены встроенные действия FancyMenu.

## Следующий трек (`audio_next_track`)

**Назначение:** Переходит к следующему треку в [Audio element](./elements#audio)

**Значение:** Обязательно — `audio_element_identifier` (ID аудио-элемента, которым нужно управлять)

## Предыдущий трек (`audio_previous_track`)

**Назначение:** Переходит к предыдущему треку в [Audio element](./elements#audio)

**Значение:** Обязательно — `audio_element_identifier` (ID аудио-элемента, которым нужно управлять)

## Установить громкость трека (`set_audio_element_volume`)

**Назначение:** Устанавливает громкость [Audio element](./elements#audio) (`0.0`–`1.0`)

**Значение:** Обязательно — `element_identifier:volume`

## Переключить воспроизведение/паузу трека (`audio_toggle_play`)

**Назначение:** Переключает текущий трек [Audio element](./elements#audio) между воспроизведением и паузой

**Значение:** Обязательно — `audio_element_identifier`

## Воспроизвести аудио (`play_audio`)

**Назначение:** Один раз воспроизводит аудиоресурс. Аудио, запущенное этим действием, позже можно остановить с помощью [**Stop All Action Audios**](#stop-all-action-audios-stop_all_action_audios).

**Значение:** Обязательно — JSON-конфигурация с `audioSource`, `soundChannel` и `baseVolume`

**Пример:** `{"audioSource":"[source:local]/config/fancymenu/assets/example.ogg","soundChannel":"master","baseVolume":1.0}`

**Поведение:**

- `baseVolume` ограничивается диапазоном `0.0`–`1.0`.
- Неизвестный звуковой канал использует канал Master.
- Действие не может запускаться из асинхронного [Ticker](./elements#ticker); вместо этого FancyMenu показывает ошибку.
- FancyMenu ждёт до десяти секунд, пока аудиоресурс станет доступным.
- Успешно запущенные треки можно остановить с помощью [**Stop All Action Audios**](#stop-all-action-audios-stop_all_action_audios).

## Остановить все аудио действий (`stop_all_action_audios`)

**Назначение:** Останавливает все аудиодорожки, запущенные действием [**Play Audio**](#play-audio-play_audio). Это не останавливает [Audio elements](./elements#audio), звуки открытия/закрытия меню, звуки кнопок или другие аудиосистемы.

**Значение:** Не требуется

## Установить громкость виде-элемента (`set_video_element_volume`)

**Назначение:** Устанавливает громкость [Video element](./video) (`0.0`–`1.0`)

**Значение:** Обязательно — `video_element_identifier:volume`

## Установить время воспроизведения видео-элемента (`set_video_element_play_time`)

**Назначение:** Перемещает [Video element](./video) к метке времени в миллисекундах

**Значение:** Обязательно — `video_element_identifier:timestamp_ms`

## Переключить состояние паузы видео-элемента (`toggle_video_element_pause_state`)

**Назначение:** Переключает состояние паузы [Video element](./video)

**Значение:** Обязательно — `video_element_identifier`

## Установить громкость видео-фона (`set_video_menu_background_volume`)

**Назначение:** Устанавливает громкость [Video menu background](./video) (`0.0`–`1.0`)

**Значение:** Обязательно — `background_identifier:volume`

> [!NOTE]
> Чтобы получить идентификатор фона, щёлкните правой кнопкой мыши по фону редактора и нажмите 'Copy Background Identifier'.

## Установить время воспроизведения видео-фона (`set_video_menu_background_play_time`)

**Назначение:** Перемещает [Video menu background](./video) к метке времени в миллисекундах

**Значение:** Обязательно — `background_identifier:timestamp_ms`

> [!NOTE]
> Чтобы получить идентификатор фона, щёлкните правой кнопкой мыши по фону редактора и нажмите 'Copy Background Identifier'.

## Переключить состояние паузы видео-фона (`toggle_video_menu_background_pause_state`)

**Назначение:** Переключает состояние паузы [Video menu background](./video)

**Значение:** Обязательно — `background_identifier`

> [!NOTE]
> Чтобы получить идентификатор фона, щёлкните правой кнопкой мыши по фону редактора и нажмите 'Copy Background Identifier'.

## Переключить макет (`toggle_layout`)

**Назначение:** Переключает макет (включить/выключить) по имени файла без `.txt`

**Значение:** Обязательно — `layout_name`

## Включить макет (`enable_layout`)

**Назначение:** Включает и сохраняет макет по имени файла без `.txt`

**Значение:** Обязательно — `layout_name`

## Выключить макет (`disable_layout`)

**Назначение:** Выключает и сохраняет макет по имени файла без `.txt`

**Значение:** Обязательно — `layout_name`

Все три действия с макетами сохраняют состояние в файле макета и сразу обновляют текущий экран. Используйте имя файла с учётом регистра, без `.txt`.

## Открыть экран или пользовательский GUI (`opengui`)

**Назначение:** Открывает экран по его идентификатору (vanilla, модификация или пользовательский GUI)

**Значение:** Обязательно — `screen_identifier`

Скопируйте точный идентификатор с учётом регистра из отладочного оверлея [Screen Identifiers](./screen-identifiers).

Некоторые экраны модов нельзя создать напрямую. Если открытие не удаётся, используйте [**Mimic Vanilla/Mod Button**](#mimic-vanillamod-button-mimicbutton) на виджете, который обычно открывает этот экран.

## Закрыть экран (`closegui`)

**Назначение:** Закрывает активный экран

**Значение:** Не требуется

## Обновить экран (`update_screen`)

**Назначение:** Переинициализирует текущий экран

**Значение:** Не требуется

## Назад к последнему экрану (`back_to_last_screen`)

**Назначение:** Возвращается к родительскому экрану [Custom GUI](./custom-guis) или к последнему закрытому экземпляру экрана

**Значение:** Не требуется

## Присоединиться к серверу (`joinserver`)

**Назначение:** Подключает игрока к Minecraft-серверу

**Значение:** Обязательно — `server_ip` или `server_ip:port`

Это действие не может выполняться, если мир или сервер уже загружен. Если порт не указан, используется `25565`. Если адрес отсутствует в сохранённом списке серверов Minecraft, FancyMenu добавляет и сохраняет его.

## Войти в мир (`loadworld`)

**Назначение:** Заходит в мир Minecraft

**Значение:** Обязательно — `world_folder_name`

Значение — это имя папки сохранения. Действие ничего не делает, если такого сохранения не существует или уже загружен другой мир/сервер.

## Войти/подключиться к последнему миру/серверу (`join_last_world`)

**Назначение:** Заходит/подключается к последнему миру или серверу, на котором был игрок

**Значение:** Не требуется

Это действие не может выполняться, если уже загружен другой мир/сервер. Запомненный сервер, которого нет в списке сохранённых серверов Minecraft, добавляется и сохраняется перед подключением.

## Покинуть мир или сервер (`disconnect_server_or_world`)

**Назначение:** Покидает мир или сервер и открывает указанный экран

**Значение:** Обязательно — `screen_identifier`

Это действие работает только тогда, когда загружены мир и игрок. Цель может быть идентификатором [Custom GUI](./custom-guis) или [screen identifier](./screen-identifiers), который FancyMenu может создать. Если цель невозможно открыть, FancyMenu возвращается на экран Title.

## Выйти из Minecraft (`quitgame`)

**Назначение:** Полностью закрывает Minecraft

**Значение:** Не требуется

## Отправить сообщение/команду в чат (`sendmessage`)

**Назначение:** Отправляет сообщение в чат или выполняет чат-команду. Текст сообщения поддерживает [коды форматирования FancyMenu](./text-formatting#minecraft-text-formatting).

**Значение:** Обязательно — `message_text` или `/command_text`

## Выполнить команду как встроенный сервер (`execute_command_as_integrated_server`)

**Назначение:** Принудительно выполняет команду в одиночной игре как встроенный сервер, игнорируя права доступа и настройку читов.

**Значение:** Обязательно — текст команды, например `/give @p minecraft:diamond 1`

> [!WARNING]
> Это действие работает только в одиночной игре, пока мир **не открыт для LAN**. Оно намеренно ничего не делает, если встроенного сервера нет или если встроенный сервер опубликован в LAN.

## Вставить в чат (`paste_to_chat`)

**Назначение:** Вставляет форматированный текст в поле ввода чата, пока загружен игрок/мир

**Значение:** Обязательно — `true:Text` или `false:Text`

Если чат ещё не открыт, FancyMenu откроет его и установит текст ввода. Если чат уже открыт, `true` добавляет текст к уже существующему вводу, а `false` заменяет его.

## Показать в чате [Client-Side] (`display_in_chat_client_side`)

**Назначение:** Показывает клиентское сообщение в чате, пока загружен мир или сервер. Оно ничего не отправляет на сервер.

**Значение:** Обязательно — `text_or_json`

Значение может быть обычным текстом или сериализованным компонентом текста Minecraft. Действие ничего не делает, если мир не загружен.

## Отправить данные FM на сервер (`send_fm_data_to_server`)

**Назначение:** Отправляет [FM Data](./fm-data) на текущий сервер FancyMenu.

**Значение:** Обязательно — `data_identifier||data`

## Подключиться к удалённому серверу (`connect_to_remote_server`)

**Назначение:** Открывает или повторно использует инициированное клиентом WebSocket-соединение с внешним удалённым сервером.

**Значение:** Обязательно — URL удалённого сервера, например `wss://example.com/ws`

См. [Remote Server Communication](./remote-server-communication#url-modes) для поддерживаемых форматов URL.

## Отправить данные на удалённый сервер (`send_data_to_remote_server`)

**Назначение:** Открывает или повторно использует соединение с удалённым сервером и отправляет на него текстовые данные.

**Значение:** Обязательно — `remote_server_url||data`

## Закрыть соединение с удалённым сервером (`close_remote_server_connection`)

**Назначение:** Закрывает определённое соединение с удалённым сервером по ID запроса.

**Значение:** Обязательно — ID запроса, обычно `$$request_id` из [**On Remote Server Connected**](./listeners#on-remote-server-connected-remote_server_connected)

**Назначение:** Закрывает все активные соединения с удалёнными серверами, открытые FancyMenu.

**Значение:** Не требуется

**Значение:** Обязательно — `https://example.com`

Используйте доверенные ссылки `https://`. FancyMenu не показывает запрос подтверждения перед передачей URL операционной системе.

**Назначение:** Сохраняет текстовое содержимое в [FancyMenu variable](./variables)

Первое двоеточие отделяет имя от значения. Последующие двоеточия остаются частью значения. Изменения сохраняются сразу.

## Отправить HTTP-запрос (`send_http_request`)

**Назначение:** Запускает HTTP/HTTPS-запрос в фоне; может записать ответ в журнал и/или сохранить его в переменную

**Значение:** Обязательно — конфигурация HTTP-запроса

| Настройка | Поведение |
|---|---|
| URL | HTTP- или HTTPS-адрес |
| Method | `GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `HEAD` или `OPTIONS` |
| Body | Отправляется для методов, отличных от `GET` и `HEAD` |
| Content type | Значение `Content-Type` запроса |
| Timeout | Секунды, используемые и для соединения, и для чтения ответа |
| Log response | Читает и записывает ответ в журнал |
| Response variable | Читает ответ и сохраняет его после завершения запроса |
| Single-line response | Удаляет переносы строк из ответа перед сохранением |
| Authentication | None, Basic, Bearer или API key |
| Headers | Необязательные пользовательские заголовки запроса |

Запросы выполняются асинхронно, поэтому следующее действие их не ждёт. Тела ответов читаются только если включено логирование или настроена переменная ответа; тела неуспешных ответов читаются из ответа об ошибке. Не сохраняйте пароли или токены доступа в конфигурации действия.

## Управление ресурс-паком (`manage_resource_pack`)

**Назначение:** Включает, отключает или переключает ресурс-пак, с необязательной перезагрузкой

**Значение:** Обязательно — `pack_name_or_id|||MODE|||reload_bool`

Отображаемые названия и внутренние ID паков сопоставляются без учёта регистра. Паки, помеченные как обязательные, нельзя отключить.

## Перезагрузить ресурс-паки (`reload_resource_packs`)

**Назначение:** Перезагружает ресурс-паки Minecraft. Встроенный пятисекундный кулдаун игнорирует повторные срабатывания в этот период, чтобы предотвратить спам перезагрузок.

**Значение:** Не требуется

## Перезагрузить FancyMenu (`reloadmenu`)

**Назначение:** Перезагружает макеты, [Custom GUIs](./custom-guis), [panoramas](./panoramas), [slideshows](./slideshows), настройки и ресурсы, управляемые FancyMenu

**Значение:** Не требуется

Это не перезагружает ресурс-паки Minecraft. Для этого используйте [**Reload Resource Packs**](#reload-resource-packs-reload_resource_packs).

> [!WARNING]
> Перезагрузка — дорогая операция. Запускайте её с осознанного действия кнопки, а не из [Ticker](./elements#ticker) или часто срабатывающего [listener](./listeners).

**Значение:** Обязательно — `animator_identifier`

См. [Element Animator](./element-animator) для настройки и сведений об идентификаторе.

## Включить Animator элемента (`enable_element_animator`)

**Назначение:** Включает воспроизведение; активная временная шкала Animator сбрасывается только при смене состояния с выключенного на включённое

**Значение:** Обязательно — `animator_identifier`

## Выключить Animator элемента (`disable_element_animator`)

**Назначение:** Выключает воспроизведение и сбрасывает соответствующую активную временную шкалу Animator

**Значение:** Обязательно — `animator_identifier`

## Сбросить Animator элемента (`reset_element_animator`)

**Назначение:** Сбрасывает соответствующую активную временную шкалу Animator, не изменяя, включено ли воспроизведение

**Значение:** Обязательно — `animator_identifier`

## Имитировать кнопку Vanilla/Mod (`mimicbutton`)

**Назначение:** Имитирует действие нажатия на кнопку vanilla или модификации

**Значение:** Обязательно — полный [widget locator](./widget-locators), например `example.menu.identifier:505280`

## Имитировать назначение клавиши (`mimic_keybind`)

**Назначение:** Выполняет Minecraft-привязку клавиши или кнопки мыши, при необходимости удерживая её

**Значение:** Обязательно — `keybind_id|||keep_pressed_bool|||duration_ms`

| Поле | Значение |
|---|---|
| `keybind_id` | Идентификатор привязки Minecraft, например `key.jump` |
| `keep_pressed_bool` | `true`, чтобы удерживать клавишу; `false`, чтобы сделать обычное нажатие |
| `duration_ms` | Длительность удержания, когда `keep_pressed_bool` равно `true`; по умолчанию `1000` |

## Установить значение поля текстового ввода (`set_text_input_field_value`)

**Назначение:** Устанавливает значение пользовательского или Vanilla [Text Input Field](./elements#text-input-field) по идентификатору элемента.

**Значение:** Обязательно — `element_identifier|||new_value|||force_set_when_inactive`

Три поля должны разделяться разделителем `|||`. Установите `force_set_when_inactive` в `true`, чтобы обновлять также отключённое поле ввода; когда `false`, неактивные поля остаются без изменений.

## Создать файл в каталоге игры (`create_file_in_game_dir`)

**Назначение:** Создаёт пустой файл относительно активного каталога игры. Принимает префикс `.minecraft/` для указания стандартного каталога Minecraft (который может отличаться от текущего экземпляра).

**Значение:** Обязательно — `file_path`

Пример: `config/some_mod_folder/new_file.txt`. Отсутствующие родительские каталоги создаются; существующий файл остаётся без изменений.

## Удалить файл/папку в каталоге игры (`delete_file_in_game_dir`)

**Назначение:** Удаляет файл или рекурсивно удаляет папку относительно активного каталога игры. Принимает `.minecraft/` для указания стандартного каталога Minecraft. Добавьте `*`, чтобы удалить **все файлы непосредственно внутри** папки (игнорирует подкаталоги и оставляет папку).

**Значение:** Обязательно — `target_path`

Например, `config/downloads/*` удаляет файлы непосредственно внутри `config/downloads/`, но не проходит по её подкаталогам и не удаляет их.

## Копировать файл/папку в каталоге игры (`copy_file_in_game_dir`)

**Назначение:** Копирует внутри активного каталога игры; `.minecraft/` указывает на стандартный каталог Minecraft. Именованная папка копируется рекурсивно. Добавьте `*` к пути **источника**, чтобы копировать только каждый файл прямого потомка; назначение должно быть папкой и не может использовать `*`.

**Значение:** Обязательно — `source||destination`

Например, `config/source/*||config/destination/` копирует только файлы, находящиеся непосредственно внутри `config/source/`. При использовании источника с подстановочным знаком FancyMenu создаёт папку назначения при необходимости, но не копирует подкаталоги источника. Копирование отказывает в существующем файле назначения/конфликтующем файле вместо перезаписи.

## Переместить файл/папку в каталоге игры (`move_file_in_game_dir`)

**Назначение:** Перемещает внутри активного каталога игры; `.minecraft/` указывает на стандартный каталог Minecraft. Добавьте `*` к пути **источника**, чтобы переместить только каждый файл прямого потомка; назначение должно быть папкой и не может использовать `*`.

**Значение:** Обязательно — `source||destination`

Например, `config/source/*||config/destination/` перемещает только файлы, находящиеся непосредственно внутри `config/source/`. При использовании источника с подстановочным знаком FancyMenu создаёт папку назначения при необходимости, но оставляет подкаталоги источника на месте. Перемещение отказывает при существующем файле назначения/конфликтующем файле вместо перезаписи.

## Переименовать файл/папку в каталоге игры (`rename_file_in_game_dir`)

**Назначение:** Переименовывает файл или папку в пределах её текущего родительского каталога; `.minecraft/` указывает на стандартный каталог Minecraft. Сохраняет содержимое и отказывает при существующем имени назначения.

**Значение:** Обязательно — `path||new_name`

## Скачать файл в каталог игры (`download_file_to_game_dir`)

**Назначение:** Скачивает файл в фоне в каталог относительно активного каталога игры; `.minecraft/` указывает на стандартный каталог Minecraft.

**Значение:** Обязательно — `url||target_folder`

Второе поле — это **каталог назначения**, а не полный путь к файлу назначения. FancyMenu создаёт каталог при необходимости и определяет имя файла по заголовку `Content-Disposition` ответа, а затем использует путь URL как запасной вариант. Полученное имя перед использованием декодируется из URL и очищается; если ни один источник не даёт пригодного имени, FancyMenu создаёт его автоматически. Существующий файл с тем же именем перезаписывается.

[**On File Downloaded via Action** listener](./listeners#on-file-downloaded-via-action-file_downloaded_via_action) срабатывает после успешных и неудачных попыток загрузки и предоставляет URL, вычисленный путь назначения и статус успеха.

При успехе `$$target_file_path` — это путь к сохранённому файлу. При неудаче он может содержать только каталог назначения, потому что окончательное имя файла не было определено.

## Извлечь ZIP-файл в каталоге игры (`extract_zip_file_in_game_dir`)

**Назначение:** Извлекает ZIP в целевую папку внутри активного каталога игры или стандартного каталога `.minecraft`. По завершении запускает [**On ZIP Extracted via Action**](./listeners#on-zip-extracted-via-action-zip_extracted_via_action).

**Значение:** Обязательно — `source_zip_path||target_folder_path`

Существующие файлы с совпадающими именами заменяются. Извлекайте только доверенные ZIP-файлы.

## Открыть файл/папку в каталоге игры (`open_file_folder_in_game_dir`)

**Назначение:** Открывает файл или папку в приложении по умолчанию операционной системы. По соображениям безопасности цель должна оставаться внутри каталога игры или стандартного каталога `.minecraft`.

**Значение:** Обязательно — `target_path`

## Записать файл в каталоге игры (`write_file_in_game_dir`)

**Назначение:** Записывает или дописывает текст относительно активного каталога игры; `.minecraft/` указывает на стандартный каталог Minecraft. Создаёт файл и родительские каталоги, если их нет. `\n` вставляет переносы строк; `append_bool=false` заменяет существующий файл.

**Значение:** Обязательно — `path|||content|||append_bool`

## Выбрать файл из системы (`select_file_to_game_dir`)

**Назначение:** Открывает системный диалог выбора файла и копирует выбранный файл внутри активного каталога игры или стандартного `.minecraft/`, если указан префикс. Поддерживает фильтры по расширениям, собственную метку фильтра и переключатель перезаписи.

**Значение:** Обязательно — `target_path|||filter_description|||extensions|||overwrite_bool`

`target_path` — это полный путь к файлу назначения. Несколько расширений разделяйте `;` или `,`, например `png;jpg`; пустой список расширений разрешает все файлы. Если `overwrite_bool` равно `false`, действие завершится ошибкой вместо замены существующего файла назначения.

[**On File Selected** listener](./listeners#on-file-selected-file_selected_via_action) срабатывает, когда файл скопирован, выбор отменён или выбор не удался. Он предоставляет выбранный путь, вычисленный путь назначения, статусы успеха/отмены и причину ошибки.

## Показать всплывающее уведомление (`show_toast`)

**Назначение:** Показывает настраиваемое toast-уведомление

**Значение:** Обязательно — JSON-конфигурация toast

Редактор хранит это действие как JSON. Лучше использовать окно настройки, а не редактировать значение вручную.

| Поле | Значение |

| `width` | Ограничивается диапазоном `120`–`320` пикселей |
| `durationMs` | Ограничивается диапазоном `1000`–`600000` миллисекунд |
| `title` | Обычный текст, сериализованный компонент текста Minecraft или пусто |
| `message` | Обычный текст, сериализованный компонент текста или пусто |
| `iconSource` | Необязательный [image source](./resources) |
| `backgroundSource` | Необязательный [image source](./resources) |
