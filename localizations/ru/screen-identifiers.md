# Идентификаторы экранов

FancyMenu использует идентификаторы экранов для макетов, стандартных виджетов, [действий экранов](./action-scripts#open-screen-or-custom-gui-opengui) и [переопределений Custom GUI](./custom-guis#overriding-an-existing-screen). Идентификаторы чувствительны к регистру, поэтому копируйте их точно из отладочного оверлея.

Встроенные экраны обычно используют короткий универсальный идентификатор, например `title_screen`. Другие экраны модов могут использовать имя их класса Java. Для Custom GUI используется идентификатор, введённый в их менеджере. Это идентификаторы экранов FancyMenu, а не ресурсы Minecraft.

# Как найти идентификатор экрана

Вы можете увидеть идентификатор текущего активного меню с помощью **отладочного оверлея**.
Он содержит идентификатор текущего экрана и позволяет скопировать его в буфер обмена щелчком левой кнопкой мыши.

>[!TIP]
>Вы можете включить **отладочный оверлей**, нажав **CTRL + ALT + D**, когда вы **не** находитесь в редакторе макетов.

# Открытие экранов

[**Действие Open Screen or Custom GUI**](./action-scripts#open-screen-or-custom-gui-opengui) может открывать только те экраны, которые FancyMenu может создать в текущем состоянии игры. Для некоторых экранов требуется загруженный мир, подключение, игрок или исходный родительский экран.

Если FancyMenu не может создать экран по указанному идентификатору, он покажет ошибку. Используйте [**Mimic Vanilla/Mod Button**](./action-scripts#mimic-vanillamod-button-mimicbutton) для виджета, который обычно открывает этот экран.
