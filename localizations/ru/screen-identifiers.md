# Идентификаторы экранов

FancyMenu использует идентификаторы экранов для макетов, ванильных виджетов, [действий экранов](/action-scripts#open-screen-or-custom-gui) и [переопределений пользовательских GUI](/custom-guis#overriding-an-existing-screen). Идентификаторы чувствительны к регистру, поэтому копируйте их точно из отладочной панели.

Для встроенных экранов обычно используется короткий универсальный идентификатор, например `title_screen`. Экраны других модов могут использовать имя Java-класса. Для пользовательских GUI используется идентификатор, указанный в их менеджере. Это идентификаторы экранов FancyMenu, а не местоположения ресурсов Minecraft.

# Как найти идентификатор экрана

Узнать идентификатор текущего меню можно с помощью **отладочной панели**.
На ней отображается идентификатор текущего экрана. Нажмите на него левой кнопкой мыши, чтобы скопировать его в буфер обмена.

>[!TIP]
>Чтобы включить **отладочную панель**, нажмите **CTRL + ALT + D**, находясь **вне** редактора макетов.

# Открытие экранов

Действие [**Открыть экран или пользовательский GUI**](/action-scripts#open-screen-or-custom-gui) может открывать только те экраны, которые FancyMenu может создать в текущем состоянии игры. Для некоторых экранов требуется загруженный мир, подключение, игрок или исходный родительский экран.

Если FancyMenu не удаётся создать экран по указанному идентификатору, появится ошибка. Используйте действие [**Имитировать кнопку ванильной игры/мода**](/action-scripts#mimic-vanillamod-button) для виджета, который обычно открывает этот экран.
