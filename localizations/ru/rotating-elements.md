# Поворот элементов

Начиная с FancyMenu v3.8.0, стало возможно поворачивать **большинство** элементов!

Чтобы повернуть элемент, выберите его в редакторе макета, и если вокруг элемента видна круглая форма, значит к нему прикреплён маркер, за который можно потянуть, чтобы повернуть элемент вокруг своей оси.

Если вокруг элемента нет круглой формы, повернуть его нельзя.

# Дополнительно

Вы также можете щёлкнуть по элементу правой кнопкой мыши, чтобы вручную задать значения поворота через прямой ввод текста. Этот прямой ввод поддерживает [подстановки](/placeholders), поэтому вы можете динамически изменять поворот элемента, комбинируя его с подстановками, чтобы получать значения переменных FancyMenu или подобные данные.

# Кнопки, ползунки и другие интерактивные элементы

В случае интерактивных элементов поворот возможен, но он только визуальный. Например, кнопка всё равно будет реагировать только на клики внутри своей исходной области, даже если из-за поворота она частично сместилась из этой области.
