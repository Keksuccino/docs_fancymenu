# Поворот элементов

Большинство элементов можно поворачивать.

Выберите элемент в редакторе макета. Если поворот поддерживается, вокруг него появятся круговой контур и маркер. Перетащите маркер, чтобы повернуть элемент.

Если вокруг элемента нет кругового контура, значит, его нельзя повернуть.

# Дополнительно

Вы также можете щёлкнуть по элементу правой кнопкой мыши, чтобы вручную задать значения поворота через прямой ввод текста. Этот прямой ввод поддерживает [подстановки](/placeholders), поэтому вы можете динамически менять поворот элемента, сочетая его с подстановками, чтобы получать значения переменных FancyMenu или аналогичные.

# Кнопки, ползунки и другие интерактивные элементы

Для интерактивных элементов поворот носит только визуальный характер. Повернутая кнопка по-прежнему принимает клики в пределах своей исходной, неповернутой области.
