# Поворот и наклон элементов

Большинство элементов можно поворачивать и наклонять. Оба действия выполняются вокруг центра элемента, а его положение и размер не меняются.

- **Поворот** разворачивает элемент, как стрелку часов.
- **Вертикальный наклон** наклоняет элемент назад, а **Горизонтальный наклон** — в сторону. Наклонённые элементы отображаются без перспективы, поэтому они становятся только ниже или уже. При использовании обоих наклонов элемент также становится косым.

# В редакторе макетов

<img width="800" alt="В редакторе макетов стикер Season 3 поворачивают с помощью маркера на окружности вокруг него, а затем панель Patch Notes наклоняют с помощью маркеров на линиях справа и снизу от неё" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/rotating_tilting_editor.gif?raw=true">

Выберите элемент в [редакторе макетов](/layout-editor) и перетаскивайте его маркеры:

- Маркер на окружности вокруг элемента поворачивает его.
- Маркер на линии справа от элемента задаёт **Вертикальный наклон**, а маркер на линии под ним — **Горизонтальный наклон**. В середине линии наклона нет.

Во время перетаскивания:

- Удерживайте `Shift`, чтобы перемещать маркер с шагом: 45 градусов для поворота и 15 градусов для наклона.
- При приближении к 0 маркеры фиксируются на 0, чтобы вы могли легко выровнять элемент.
- В левом верхнем углу элемента отображаются его поворот и наклон.

Полезно знать:

- Рамка выделения остаётся ровной. Щёлкните внутри неё, чтобы выбрать или переместить элемент.
- Маркеры отображаются, только если выбран один элемент.
- Элемент без окружности или линий нельзя поворачивать или наклонять. См. раздел [Элементы без поворота и наклона](#elements-without-rotation-or-tilt).
- Пункты **строка меню -> Window -> Element Rotation Controls** и **Element Tilt Controls** скрывают маркеры всех элементов.

# Точные значения

Щёлкните элемент правой кнопкой мыши, чтобы открыть эти настройки. Для каждой доступны параметры **Set Via Number Picker**, **Set As Plain Text** и **Reset to Default**.

| Настройка | Действие |
|---|---|
| **Поворот** | Количество градусов поворота по часовой стрелке: например, `90` для четверти оборота. Отрицательные значения задают поворот против часовой стрелки. |
| **Вертикальный наклон** | Насколько элемент наклонён назад, от `-60` до `60` градусов. |
| **Горизонтальный наклон** | Насколько элемент наклонён в сторону, от `-60` до `60` градусов. |

Один наклон выглядит одинаково при положительном и отрицательном значении. Если заданы оба наклона, их знаки определяют, в какую сторону будет наклонён элемент.

## Использование плейсхолдеров

Чтобы повернуть или наклонить элемент с помощью [переменной](/variables) или другого [плейсхолдера](/placeholders):

1. Щёлкните элемент правой кнопкой мыши и включите **Advanced Rotation Mode**, **Advanced Vertical Tilt Mode** или **Advanced Horizontal Tilt Mode**.
2. Нажмите **Rotation**, **Vertical Tilt** или **Horizontal Tilt**, затем **Set As Plain Text** и введите плейсхолдер.

В расширенных режимах используются собственные значения, а маркер скрывается, поэтому перетаскивание не заменит ваш плейсхолдер. При выключении режима элементу возвращается прежнее значение.

Логотип, который делает полный оборот каждые 3,6 секунды. Для этого в поле **Rotation** включите **Advanced Rotation Mode**. Чтобы замедлить вращение, делите на число больше `10`:

```
{"placeholder":"calc","values":{"expression":"{"placeholder":"unix_time"} / 10 % 360"}}
```

Стрелка, которая указывает на значение переменной `needle_angle`. Его можно задать с помощью кнопок или [ползунка](/elements#slider):

```
{"placeholder":"getvariable","values":{"name":"needle_angle"}}
```

# Нажатия и указатель мыши

Кнопки, ползунки, ссылки и полосы прокрутки текстовых элементов реагируют на указатель мыши там, где отображаются, даже если они повёрнуты или наклонены. То же относится к условиям [**Is Element Hovered**](/conditions#is-element-hovered), [**Is Any Element Hovered**](/conditions#is-any-element-hovered) и [**Is Any Button Hovered**](/conditions#is-any-button-hovered).

> [!NOTE]
> Флажки, поля ввода текста, перетаскиваемые элементы и браузеры по-прежнему реагируют в пределах рамки, которая была бы у них без поворота и наклона. Не наклоняйте их.

# Элементы без поворота и наклона

- Без поворота и наклона: [Области прокрутки](/scrollable-areas), [шейдеры GLSL](/elements#glsl-shader), [JSON-модели блоков и предметов](/elements#blockitem-json-model), [сущности игроков](/player-entities) и [ванильные элементы](/vanilla-elements), например кнопки самого экрана.
- Только поворот, без наклона: [всплывающие подсказки](/elements#tooltip) и [предметы](/elements#item).

Элементы внутри области прокрутки можно поворачивать и наклонять, но саму область — нельзя.

У элементов [текста на заставке](/splash-text) также есть отдельная настройка **Rotation** ниже в контекстном меню. Она задаёт характерный наклон текста и работает вместе с поворотом, описанным на этой странице.
