# JSON-пути в FancyMenu

Плейсхолдер **JSON Parser** в FancyMenu использует [Jayway JsonPath](https://github.com/json-path/JsonPath) для получения данных из JSON-файлов.
На этой странице подробно объясняются JSON-пути.

Текст на этой странице является копией README из репозитория Jayway JsonPath на GitHub.

> В этом тексте термин «выражение JsonPath» относится к JSON-пути.
{.is-info}

# JsonPath

Выражения JsonPath всегда ссылаются на JSON-структуру так же, как выражения XPath используются вместе 
с XML-документом. «Корневой объект-член» в JsonPath всегда обозначается как `$`, независимо от того, 
является ли он объектом или массивом.

Выражения JsonPath могут использовать точечную нотацию

`$.store.book[0].title`

или нотацию в квадратных скобках

`$['store']['book'][0]['title']`

## Операторы

| Оператор                  | Описание                                                        |
| :------------------------ | :----------------------------------------------------------------- |
| `$`                       | Корневой элемент для запроса. С него начинаются все выражения пути.       |
| `@`                       | Текущий узел, обрабатываемый предикатом фильтра.            |
| `*`                       | Подстановочный символ. Доступен везде, где требуется имя или число.       |
| `..`                      | Рекурсивный поиск. Доступен везде, где требуется имя.                  |
| `.<name>`                 | Дочерний элемент в точечной нотации                                                  |
| `['<name>' (, '<name>')]` | Дочерний элемент или элементы в нотации квадратных скобок                                  |
| `[<number> (, <number>)]` | Индекс или индексы массива                                             |
| `[start:end]`             | Оператор среза массива                                               |
| `[?(<expression>)]`       | Выражение фильтра. Выражение должно вычисляться в логическое значение.    |


## Функции

Функции можно вызывать в конце пути — входом для функции является результат выражения пути.
Результат функции определяется самой функцией.

| Функция                  | Описание                                                         | Тип результата |
| :------------------------ | :------------------------------------------------------------------ |:----------- |
| min()                     | Возвращает минимальное значение массива чисел                       | Double      |
| max()                     | Возвращает максимальное значение массива чисел                       | Double      |
| avg()                     | Возвращает среднее значение массива чисел                   | Double      | 
| stddev()                  | Возвращает стандартное отклонение значений массива чисел        | Double      | 
| length()                  | Возвращает длину массива                                     | Integer     |
| sum()                     | Возвращает сумму значений массива чисел                       | Double      |
| keys()                    | Возвращает ключи свойств (альтернатива завершающей тильде `~`)  | `Set<E>`    |
| concat(X)                 | Возвращает объединённый вариант результата пути с новым элементом  | как у входа  |
| append(X)                 | Добавляет элемент в массив результата JSON-пути                           | как у входа  |

## Операторы фильтрации

Фильтры — это логические выражения, используемые для фильтрации массивов. Типичный фильтр выглядит так: `[?(@.age > 18)]`, где `@` представляет текущий обрабатываемый элемент. Более сложные фильтры можно создавать с помощью логических операторов `&&` и `||`. Строковые литералы должны быть заключены в одинарные или двойные кавычки (`[?(@.color == 'blue')]` или `[?(@.color == "blue")]`).   

| Оператор                 | Описание                                                           |
| :----------------------- | :-------------------------------------------------------------------- |
| ==                       | левое значение равно правому (обратите внимание, что 1 не равно '1')              |
| !=                       | левое значение не равно правому                                            |
| <                        | левое значение меньше правого                                               |
| <=                       | левое значение меньше или равно правому                                        |
| >                        | левое значение больше правого                                            |
| >=                       | левое значение больше или равно правому                                |
| =~                       | левое значение соответствует регулярному выражению  [?(@.name =~ /foo.*?/i)]             |
| in                       | левое значение присутствует в правом [?(@.size in ['S', 'M'])]                        |
| nin                      | левое значение отсутствует в правом                                         |
| subsetof                 | левое значение является подмножеством правого [?(@.sizes subsetof ['S', 'M', 'L'])]       |
| anyof                    | у левого значения есть пересечение с правым [?(@.sizes anyof ['M', 'L'])]     |
| noneof                   | у левого значения нет пересечения с правым [?(@.sizes noneof ['M', 'L'])]    |
| size                     | размер левого значения (массив или строка) должен совпадать с правым                     |
| empty                    | левое значение (массив или строка) должно быть пустым                                |


## Примеры путей

При наличии JSON

```javascript
{
    "store": {
        "book": [
            {
                "category": "reference",
                "author": "Nigel Rees",
                "title": "Sayings of the Century",
                "price": 8.95
            },
            {
                "category": "fiction",
                "author": "Evelyn Waugh",
                "title": "Sword of Honour",
                "price": 12.99
            },
            {
                "category": "fiction",
                "author": "Herman Melville",
                "title": "Moby Dick",
                "isbn": "0-553-21311-3",
                "price": 8.99
            },
            {
                "category": "fiction",
                "author": "J. R. R. Tolkien",
                "title": "The Lord of the Rings",
                "isbn": "0-395-19395-8",
                "price": 22.99
            }
        ],
        "bicycle": {
            "color": "red",
            "price": 19.95
        }
    },
    "expensive": 10
}
```
