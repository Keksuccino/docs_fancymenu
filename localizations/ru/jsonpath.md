# JSON-пути в FancyMenu

Заполнитель **JSON Parser** в FancyMenu использует [Jayway JsonPath](https://github.com/json-path/JsonPath) для получения содержимого из JSON-файлов.
На этой странице подробно описаны JSON-пути.

Текст этой страницы является копией README из репозитория Jayway JsonPath на GitHub.

> [!NOTE]
> В этом тексте термин «выражение JsonPath» означает JSON-путь.

# JsonPath

Выражения JsonPath всегда ссылаются на структуру JSON так же, как выражения XPath используются в сочетании 
с XML-документом. «Корневой объект» в JsonPath всегда обозначается как `$`, независимо от того, является ли он 
объектом или массивом.

В выражениях JsonPath можно использовать точечную нотацию

`$.store.book[0].title`

или скобочную нотацию

`$['store']['book'][0]['title']`

## Операторы

| Оператор                  | Описание                                                        |
| :------------------------ | :-------------------------------------------------------------- |
| `$`                       | Корневой элемент запроса. С него начинаются все выражения пути. |
| `@`                       | Текущий узел, обрабатываемый предикатом фильтра.                |
| `*`                       | Подстановочный знак. Доступен везде, где требуется имя или число. |
| `..`                      | Глубокое сканирование. Доступно везде, где требуется имя.       |
| `.<name>`                 | Дочерний элемент в точечной нотации                           |
| `['<name>' (, '<name>')]` | Дочерний элемент или дочерние элементы в скобочной нотации     |
| `[<number> (, <number>)]` | Индекс или индексы массива                                     |
| `[start:end]`             | Оператор среза массива                                         |
| `[?(<expression>)]`       | Выражение фильтра. Результатом выражения должно быть логическое значение. |


## Функции

Функции можно вызывать в конце пути — входными данными функции является результат выражения пути.
Тип результата функции определяется самой функцией.

| Функция                  | Описание                                                         | Тип результата |
| :------------------------ | :--------------------------------------------------------------- |:--------------- |
| min()                     | Возвращает минимальное значение массива чисел                    | Double      |
| max()                     | Возвращает максимальное значение массива чисел                    | Double      |
| avg()                     | Возвращает среднее значение массива чисел                        | Double      | 
| stddev()                  | Возвращает стандартное отклонение массива чисел                  | Double      | 
| length()                  | Возвращает длину массива                                         | Integer     |
| sum()                     | Возвращает сумму значений массива чисел                          | Double      |
| keys()                    | Возвращает ключи свойств (альтернатива завершающей тильде `~`)   | `Set<E>`    |
| concat(X)                 | Возвращает результат пути, объединённый с новым элементом       | как у входных данных  |
| append(X)                 | Добавляет элемент в массив результатов JSON-пути                 | как у входных данных  |

## Операторы фильтра

Фильтры — это логические выражения, используемые для фильтрации массивов. Типичный фильтр выглядит так: `[?(@.age > 18)]`, где `@` обозначает обрабатываемый текущий элемент. Более сложные фильтры можно создавать с помощью логических операторов `&&` и `||`. Строковые литералы должны быть заключены в одинарные или двойные кавычки (`[?(@.color == 'blue')]` или `[?(@.color == "blue")]`).   

| Оператор                 | Описание                                                           |
| :----------------------- | :----------------------------------------------------------------- |
| ==                       | левое значение равно правому (обратите внимание: 1 не равно '1')   |
| !=                       | левое значение не равно правому                                   |
| <                        | левое значение меньше правого                                     |
| <=                       | левое значение меньше или равно правому                           |
| >                        | левое значение больше правого                                     |
| >=                       | левое значение больше или равно правому                           |
| =~                       | левое значение соответствует регулярному выражению  [?(@.name =~ /foo.*?/i)] |
| in                       | левое значение содержится в правом [?(@.size in ['S', 'M'])]      |
| nin                      | левое значение не содержится в правом                             |
| subsetof                 | левое значение является подмножеством правого [?(@.sizes subsetof ['S', 'M', 'L'])] |
| anyof                    | левое значение пересекается с правым [?(@.sizes anyof ['M', 'L'])] |
| noneof                   | левое значение не пересекается с правым [?(@.sizes noneof ['M', 'L'])] |
| size                     | размер левого значения (массива или строки) должен совпадать с правым |
| empty                    | левое значение (массив или строка) должно быть пустым             |


## Примеры путей

Дан следующий JSON:

```javascript
{
    "store": {
        "book": [
            {
                "category": "reference",
                "author": "Nigel Rees",
                "title": "Sayings of the Century",
                "price": 8.95
            },
            {
                "category": "fiction",
                "author": "Evelyn Waugh",
                "title": "Sword of Honour",
                "price": 12.99
            },
            {
                "category": "fiction",
                "author": "Herman Melville",
                "title": "Moby Dick",
                "isbn": "0-553-21311-3",
                "price": 8.99
            },
            {
                "category": "fiction",
                "author": "J. R. R. Tolkien",
                "title": "The Lord of the Rings",
                "isbn": "0-395-19395-8",
                "price": 22.99
            }
        ],
        "bicycle": {
            "color": "red",
            "price": 19.95
        }
    },
    "expensive": 10
}
```

| JsonPath (нажмите ссылку, чтобы попробовать)| Результат |
| :------- | :----- |
| <a href="http://jsonpath.herokuapp.com/?path=$.store.book[*].author" target="_blank">$.store.book[*].author</a>| Авторы всех книг     |
| <a href="http://jsonpath.herokuapp.com/?path=$..author" target="_blank">$..author</a>                   | Все авторы                         |
| <a href="http://jsonpath.herokuapp.com/?path=$.store.*" target="_blank">$.store.*</a>                  | Все элементы: и книги, и велосипеды  |
| <a href="http://jsonpath.herokuapp.com/?path=$.store..price" target="_blank">$.store..price</a>             | Цена всего         |
| <a href="http://jsonpath.herokuapp.com/?path=$..book[2]" target="_blank">$..book[2]</a>                 | Третья книга                      |
| <a href="http://jsonpath.herokuapp.com/?path=$..book[2]" target="_blank">$..book[-2]</a>                 | Предпоследняя книга            |
| <a href="http://jsonpath.herokuapp.com/?path=$..book[0,1]" target="_blank">$..book[0,1]</a>               | Первые две книги               |
| <a href="http://jsonpath.herokuapp.com/?path=$..book[:2]" target="_blank">$..book[:2]</a>                | Все книги с индекса 0 (включительно) до индекса 2 (не включительно) |
| <a href="http://jsonpath.herokuapp.com/?path=$..book[1:2]" target="_blank">$..book[1:2]</a>                | Все книги с индекса 1 (включительно) до индекса 2 (не включительно) |
| <a href="http://jsonpath.herokuapp.com/?path=$..book[-2:]" target="_blank">$..book[-2:]</a>                | Последние две книги                   |
| <a href="http://jsonpath.herokuapp.com/?path=$..book[2:]" target="_blank">$..book[2:]</a>                | Книги начиная со второй          |
| <a href="http://jsonpath.herokuapp.com/?path=$..book[?(@.isbn)]" target="_blank">$..book[?(@.isbn)]</a>          | Все книги с номером ISBN         |
| <a href="http://jsonpath.herokuapp.com/?path=$.store.book[?(@.price < 10)]" target="_blank">$.store.book[?(@.price < 10)]</a> | Все книги в магазине дешевле 10  |
| <a href="http://jsonpath.herokuapp.com/?path=$..book[?(@.price <= $['expensive'])]" target="_blank">$..book[?(@.price <= $['expensive'])]</a> | Все книги в магазине, которые не являются «дорогими»  |
| <a href="http://jsonpath.herokuapp.com/?path=$..book[?(@.author =~ /.*REES/i)]" target="_blank">$..book[?(@.author =~ /.*REES/i)]</a> | Все книги, соответствующие регулярному выражению (без учёта регистра)  |
| <a href="http://jsonpath.herokuapp.com/?path=$..*" target="_blank">$..*</a>                        | Показать всё   
| <a href="http://jsonpath.herokuapp.com/?path=$..book.length()" target="_blank">$..book.length()</a>                 | Количество книг                      |
