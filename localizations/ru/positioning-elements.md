# Позиционирование элементов в FancyMenu

В FancyMenu положение каждого элемента определяется **точками привязки**. Они нужны, чтобы вычислять, где элемент должен отображаться на экране, и не допускать наложения элементов, их смещения за пределы экрана или неправильного перемещения при изменении размера окна.

## Точки привязки

Точка привязки служит началом координат, относительно которого рассчитывается положение элемента. По умолчанию элементы, добавленные в макет, привязаны к точке **«Центр экрана»**. Это точная середина экрана независимо от размера окна.

Например, если элемент привязан к точке **«Центр экрана»** и находится в 2 сантиметрах от середины экрана, он сохранит это расстояние при любом изменении размера окна.

## Работа с точками привязки

При перетаскивании элемента в редакторе подсвечивается точка привязки, к которой он прикреплён. По умолчанию при этом также отображаются все остальные доступные точки привязки. Чтобы изменить точку привязки элемента, перетащите его на другую точку и дождитесь, пока заполнится индикатор загрузки.

## Привязка элементов к другим элементам

В качестве точки привязки элемента можно использовать другой элемент. Тогда он будет перемещаться вместе с ним, сохраняя расстояние до его верхнего левого угла. Это удобно для панелей из нескольких элементов, подписей рядом со стандартными кнопками и [перетаскивателей](/dragger).

Это можно сделать двумя способами. В обоих случаях элемент останется на прежнем месте.

### Перетаскиванием

1. Перетащите элемент и задержите указатель над другим элементом.
2. Дождитесь, пока индикатор заполнится, а затем отпустите кнопку мыши.

Если в начале перетаскивания указатель уже находится над другим элементом, сначала переместите его за пределы этого элемента, а затем обратно. Элементы, которые изначально находились под указателем, не учитываются.

Для этого в меню **«Окно»** должны быть включены параметры **«Наведение на область привязки»** и **«Наведение на элемент привязки»**. По умолчанию включены оба параметра. Первый включает и выключает привязку удержанием указателя, а второй добавляет другие элементы в список точек привязки. Параметр **«Время удержания указателя над областью/элементом привязки (секунды)»** в том же меню задаёт, сколько нужно удерживать указатель. По умолчанию — 2 секунды.

### По идентификатору

1. Щёлкните правой кнопкой мыши по другому элементу и выберите **«Копировать ID элемента»**.
2. Щёлкните правой кнопкой мыши по нужному элементу и выберите **«Точка привязки -> Другой элемент»**.
3. Вставьте ID в поле **«ID элемента»** и нажмите **«Готово»**.

Если выбрано несколько элементов, на шагах 2 и 3 точка привязки будет задана сразу для всех. Подробнее об ID см. в разделе [Идентификаторы элементов](/element-identifiers).

## Точки привязки в прокручиваемых областях

У элементов в [прокручиваемой области](/scrollable-areas) тоже есть точки привязки, но они относятся к содержимому области, а не к экрану:

- **«Верхний левый угол»** — это верхний левый угол содержимого, **«Центр экрана»** — его середина, а точки привязки внизу фиксируются у конца содержимого. Благодаря этому элемент может располагаться в самом конце длинного списка и оставаться там, даже когда список становится длиннее.
- Элементы внутри области можно привязывать только к другим элементам из этой же области.
- Если переместить элемент в область или из неё, элементы, привязанные через её границу, получат точку привязки **«Верхний левый угол»** и останутся на прежнем месте.

Это работает в режиме **«Точки привязки»** области. В остальных режимах область размещает элементы самостоятельно. Подробнее см. в разделе [Прокручиваемые области](/scrollable-areas#anchors-mode).

Все элементы, которые должны оставаться в центре экрана (кнопки и сущность игрока), привязаны к точке **«Центр экрана»**.

Элемент изображения в нижнем правом углу привязан к точке **«Нижний правый угол»**, поскольку должен оставаться в этом углу.

## Перемещение элементов за пределы экрана

По умолчанию элементы нельзя перемещать за пределы экрана. Это служит защитой на случай, если макет будет загружен в очень маленьком окне или окне необычного размера: элементы останутся видимыми и доступными для взаимодействия.

Элементы всегда остаются на экране, сохраняя небольшой отступ от его краёв.

Эту функцию можно **отключить** для отдельных элементов: щёлкните по ним **правой кнопкой мыши** и отключите параметр **«Оставаться на экране»**.

> [!WARNING]
> Отключение этой функции иногда может привести к исчезновению элемента: его фактическое положение находится за пределами экрана, но функция позволяла ему оставаться видимым. Если это произошло, **отмените** последнее действие (отключение параметра **«Оставаться на экране»**) с помощью сочетания клавиш для отмены или через меню **«Строка меню -> Правка -> Отменить»**, затем вручную переместите элемент в центр экрана и снова отключите параметр **«Оставаться на экране»**. Теперь элемент должен оставаться видимым и при отключённой функции.

## Центрирование элементов

Если размер элемента фиксирован, центрировать его очень просто: достаточно привязать его к точке, расположенной по центру.

Если размер элемента динамически меняется в зависимости от условий или других факторов, всё немного сложнее. Но в FancyMenu есть полезная функция, которая поможет с этим! Сначала привяжите элемент к точке, расположенной по центру, а затем щёлкните по нему правой кнопкой мыши. В контекстном меню включите параметр **«Фиксированная привязка»**. Эта функция меняет способ, которым FancyMenu рассчитывает положение элемента, и позволяет сохранять одно и то же расстояние до точки привязки независимо от изменения размера элемента. Для точек привязки по центру расстояние до точки будет всегда отсчитываться от абсолютного центра элемента — благодаря этому он будет оставаться по центру. Для точек привязки слева расстояние всегда отсчитывается от левого края элемента, а для точек привязки справа — от правого.

## Другие способы улучшить позиционирование элементов

Если **все точки привязки выбраны правильно**, но элементы всё равно накладываются друг на друга при слишком маленьком размере окна, возможно, макет просто слишком перегружен для стандартной логики масштабирования интерфейса Minecraft.

### Принудительный масштаб интерфейса

Один из способов улучшить позиционирование элементов макета — принудительно задать масштаб интерфейса для меню. Для этого **щёлкните правой кнопкой мыши по фону редактора** и выберите **«Принудительный масштаб интерфейса»**. Тогда масштаб интерфейса меню не будет зависеть от масштаба, заданного в настройках Minecraft.

### Автомасштабирование

Последний способ устранить наложение элементов — включить **автомасштабирование**.
Эта настройка автоматически масштабирует меню в зависимости от размера окна, чтобы при его изменении по возможности сохранить положение элементов. Чтобы включить автомасштабирование, **щёлкните правой кнопкой мыши по фону редактора**, а затем выберите **«Автомасштабирование»**.

> [!WARNING]
> **Автомасштабирование** может ухудшить отображение **текста**, отрисовываемого Minecraft. Это не ошибка — так устроен рендеринг текста в Minecraft. Для кнопок можно использовать обходное решение: добавить надписи на кнопках в текстуру фона и задать для стандартной подписи кнопки пустое значение.
