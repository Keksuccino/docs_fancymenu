# Универсальные макеты

Универсальный макет учитывается для каждого поддерживаемого экрана, для которого включена настройка экранов. Он не применяется к [заблокированным](/incompatibility-list#screens-where-customization-is-intentionally-disabled) и другим исключённым экранам.

Используйте универсальные макеты для общих элементов, таких как логотипы, навигация, наложения или [аудиоэлементы](/elements#audio), которые должны отображаться на нескольких экранах.

# Создание макета

1. Откройте поддерживаемый экран и отобразите строку меню FancyMenu.
2. Выберите **Layouts -> New -> For All Screens [Universal]**.
3. Добавьте элементы и настройте их.
4. Сохраните макет.

Для обычных экранов по-прежнему необходимо включить **Current Screen Customization**. Глобального переключателя для включения настройки всех экранов нет, поскольку настройка экранов неподдерживаемых модов может приводить к сбоям.

# Ограничение списка экранов

Откройте настройки универсального макета через контекстное меню фона редактора.

- **Белый список:** макет применяется только к указанным идентификаторам экранов.
- **Чёрный список:** макет применяется ко всем подходящим экранам, кроме экранов с указанными идентификаторами.

Используйте **Customization -> Copy Identifier of Current Screen**, чтобы скопировать [идентификатор экрана](/screen-identifiers).

Вы также можете добавить [условия для всего макета](/conditions#layout-wide-requirements), чтобы задать, когда он применяется.

# Порядок макетов

Подходящие универсальные макеты и макеты для конкретных экранов объединяются и упорядочиваются по **Layout Index**. Сначала применяются макеты с меньшими индексами; более поздние настройки, допускающие наложение, могут переопределять более ранние. Макеты с одинаковым индексом собираются в следующем порядке: сначала универсальные, затем макеты для конкретных экранов.
