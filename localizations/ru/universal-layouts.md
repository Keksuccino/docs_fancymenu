# Что такое универсальные макеты?

Универсальные макеты — это мощная функция FancyMenu, которая позволяет создавать макеты, применяемые к **нескольким экранам**, а не только к одному конкретному экрану. Это делает их невероятно полезными для создания единых элементов интерфейса, которые отображаются во всей игре.

Представьте универсальные макеты как «глобальные» макеты, которые могут появляться везде в вашей игре.

# Зачем использовать универсальные макеты?

Универсальные макеты очень полезны, когда нужно:

- Добавить один и тот же фон на все экраны
- Создать логотип или текст, который отображается на многих экранах
- Сделать так, чтобы аудиоэлементы продолжали воспроизводиться между разными экранами
- Создать единый стиль и внешний вид во всей игре

# Как работают универсальные макеты

Когда вы создаёте универсальный макет, он по умолчанию загружается **на каждом экране** в игре. Это означает, что любые элементы, которые вы добавите в универсальный макет (например, кнопки, изображения или текст), будут отображаться на всех экранах.

Но не волнуйтесь! Также можно настроить, чтобы универсальный макет загружался только на определённых экранах! Для этого прокрутите ниже до разделов **blacklist** и **whitelist**.

# Создание универсального макета

1. Откройте любой экран в игре
2. Нажмите **Ctrl+Alt+C**, чтобы открыть меню настройки
3. Перейдите в **Layouts → New → For All Screens [Universal]**
4. Оформите макет с помощью элементов, таких как изображения, текст или кнопки
5. Сохраните макет с понятным названием

# Управление тем, на каких экранах будет ваш универсальный макет

## Использование blacklist

Blacklist позволяет указать экраны, на которых вы НЕ хотите видеть ваш универсальный макет:

1. В редакторе макета щёлкните правой кнопкой мыши по фону
2. Выберите **Layout Settings → Universal Layout Options**
3. Нажмите **Add Screen To Blacklist**
4. Введите идентификатор экрана (например, `title_screen` для экрана заголовка)

Теперь ваш универсальный макет будет отображаться на всех экранах, КРОМЕ тех, которые вы добавили в blacklist.

## Использование whitelist

Whitelist — это противоположный вариант: он показывает ваш универсальный макет ТОЛЬКО на определённых экранах:

1. В редакторе макета щёлкните правой кнопкой мыши по фону
2. Выберите **Layout Settings → Universal Layout Options**
3. Нажмите **Add Screen To Whitelist**
4. Введите идентификатор каждого экрана, на котором должен отображаться макет

При использовании whitelist ваш универсальный макет будет отображаться ТОЛЬКО на экранах, которые вы указали.

# Как найти идентификаторы экранов

Чтобы добавить экраны в whitelist или blacklist, нужно знать их идентификаторы:

1. Перейдите на экран, который нужно определить
2. Нажмите **Ctrl+Alt+C**, чтобы открыть меню настройки
3. Нажмите **Customization → Copy Identifier of Current Screen**
4. Идентификатор будет скопирован в буфер обмена

Вы можете вставить этот идентификатор в whitelist или blacklist.

# Включение настройки для всех экранов

Невозможно включить настройку для всех экранов сразу.
Это сделано намеренно и помогает избежать ситуации, когда пользователь случайно ломает игру, включив настройку для модифицированного экрана, который не поддерживается.

# Дополнительные советы

## Управление порядком загрузки

Если у вас есть и универсальные, и экранные макеты, универсальные макеты загружаются ПЕРВЫМИ. Это означает, что экранные макеты могут переопределять элементы из универсальных макетов.

## Условия загрузки

Вы можете добавить условия загрузки для вашего универсального макета, чтобы он загружался только при определённых обстоятельствах:

1. Щёлкните правой кнопкой мыши в редакторе
2. Выберите **Layout Settings → Layout-Wide Requirements**
3. Добавьте условия, такие как время суток, операционная система или другие требования
