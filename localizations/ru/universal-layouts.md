# Универсальные макеты

Универсальный макет учитывается для каждого поддерживаемого экрана, для которого включена настройка экрана. Он не применяется к [заблокированным](./incompatibility-list#screens-where-customization-is-intentionally-disabled) или иным образом исключённым экранам.

Используйте универсальные макеты для общих элементов, таких как логотипы, навигация, наложения или [аудиоэлементы](./elements#audio), которые должны отображаться на нескольких экранах.

# Создание

1. Откройте поддерживаемый экран и покажите панель меню FancyMenu.
2. Выберите **Layouts -> New -> For All Screens [Universal]**.
3. Добавьте и настройте элементы.
4. Сохраните макет.

Обычные экраны по-прежнему требуют, чтобы была включена **Current Screen Customization**. Глобального переключателя «включить для всех» нет, потому что неподдерживаемые экраны модов могут сломаться при настройке.

# Ограничение экранов

Откройте настройки универсального макета из контекстного меню фона редактора.

- **Whitelist:** макет применяется только к перечисленным идентификаторам экранов.
- **Blacklist:** макет применяется ко всем подходящим экранам, кроме перечисленных идентификаторов.

Используйте **Customization -> Copy Identifier of Current Screen**, чтобы скопировать [идентификатор экрана](./screen-identifiers).

Вы также можете добавить [общие для макета требования](./conditions#layout-wide-requirements), чтобы управлять тем, когда макет применяется.

# Порядок макетов

Подходящие универсальные макеты и макеты для конкретных экранов объединяются и накладываются друг на друга по **Layout Index**. Макеты с меньшими индексами применяются первыми; более поздние настраиваемые параметры могут переопределять предыдущие. При одинаковом индексе сначала учитываются универсальные макеты, а затем макеты для конкретных экранов.
