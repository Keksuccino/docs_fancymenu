# Локаторы виджетов

Локаторы виджетов используются для указания на конкретный виджет Vanilla (кнопку, ползунок, поле ввода текста) в меню. Это нужно для некоторых функций FancyMenu, которым требуется как-то взаимодействовать с виджетом.

# Получение локатора виджета

Есть два способа получить локатор виджета Vanilla.

Первый — включить **отладочный оверлей** в меню, которое содержит виджет, нажав **CTRL + ALT + D**, а затем **щёлкнуть по виджету правой кнопкой мыши**. Откроется контекстное меню с опцией копирования локатора в буфер обмена.

Второй — открыть **редактор макета** для меню, которое содержит виджет, а затем **щёлкнуть правой кнопкой мыши по элементу виджета**. Также откроется контекстное меню с опцией копирования локатора в буфер обмена.

>[!WARNING]
>Если вы **не можете щёлкнуть по виджету правой кнопкой мыши** через отладочный оверлей или он **не отображается** в редакторе макета, вероятно, он не виден для FancyMenu, а значит, в этом случае у него нет локатора. Чаще всего это происходит с кнопками модов, которые добавляются в меню необычным способом.
