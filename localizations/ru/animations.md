# Анимации

FancyMenu воспроизводит анимированные изображения практически везде, где можно использовать обычные изображения: в [элементах изображения](/elements#image), [фонах меню с изображениями](/menu-backgrounds#image), текстурах кнопок и ползунков, [вступительном экране игры](/game-intro) и других местах.

Для анимации используйте файлы **APNG** или **GIF**:

- **APNG** (анимированный PNG) обеспечивает более высокое качество: все цвета обычного PNG и корректную прозрачность с мягкими краями. Это лучший вариант для логотипов, фонов и всего, где нужна прозрачность.
- **GIF** распространённее, поэтому для его создания и редактирования есть больше инструментов. Однако в GIF на каждый кадр приходится только 256 цветов, а пиксели могут быть либо полностью прозрачными, либо непрозрачными.

> [!NOTE]
> Собственные форматы анимации FancyMenu — FMA и AFMA — устарели. Существующие файлы по-прежнему работают, но для новых анимаций используйте APNG или GIF. Подробнее: [FMA и AFMA](#fma-and-afma).

# Использование анимаций

1. Поместите файл в `<game-directory>/config/fancymenu/assets/`, чтобы он появился в окне выбора файлов FancyMenu. Также можно использовать веб-ссылки и файлы из пакетов ресурсов — см. раздел [Ресурсы](/resources).
2. Выберите его, как любое другое изображение, например в параметре **Источник изображения** элемента изображения.

> [!WARNING]
> Файлы APNG должны иметь расширение `.apng`. Многие инструменты сохраняют APNG с расширением `.png`, поэтому переименуйте файл — иначе FancyMenu покажет его как статичное изображение. Это же правило действует для веб-ссылок: они должны оканчиваться на `.apng`.

## Воспроизведение анимаций

- Анимация воспроизводится столько раз, сколько указано в файле, а затем останавливается на последнем кадре. Количество повторов задаётся при создании файла.
- Анимации воспроизводятся, только когда находятся на экране. Когда они появляются снова, воспроизведение продолжается с места остановки.
- Параметр **Перезапускать анимированные текстуры при открытии экрана** заставляет элементы изображения и фоны меню с изображениями запускать анимацию с начала при каждом открытии экрана.
- Параметр **Перезапускать анимированные текстуры при наведении** заставляет текстуры кнопок и ползунков запускаться с начала каждый раз, когда на них наводят указатель мыши.
- Слушатели [**Воспроизведение анимированной текстуры началось**](/listeners#animated-texture-started-playing) и [**Воспроизведение анимированной текстуры завершилось**](/listeners#animated-texture-finished-playing) запускают действия при начале и завершении анимации.

## Производительность

FancyMenu декодирует APNG и GIF во время воспроизведения, обрабатывая лишь несколько кадров наперёд, поэтому даже для длинных анимаций требуется мало памяти.

Большие кадры и высокая частота кадров всё же снижают производительность. Подбирайте размер кадров примерно под их отображаемый на экране размер — см. раздел [Оптимизация текстур](/optimizing-textures). Для длинных роликов со звуком вместо этого используйте [видео](/video).

# Создание анимаций

Эти бесплатные инструменты позволяют создавать APNG и GIF из отдельных кадров или видео:

- [ScreenToGif](https://www.screentogif.com/) (Windows): нажмите **Editor**, перетащите в него кадры PNG, задайте задержку между кадрами и сохраните анимацию в формате APNG или GIF. Количество повторов можно настроить в меню сохранения.
- [ezgif](https://ezgif.com/) (онлайн, скачивать ничего не нужно): создавайте [GIF](https://ezgif.com/maker) или [APNG](https://ezgif.com/apng-maker) из изображений, преобразуйте видео в [GIF](https://ezgif.com/video-to-gif) или [APNG](https://ezgif.com/video-to-apng), а также конвертируйте [GIF в APNG](https://ezgif.com/gif-to-apng) и [APNG в GIF](https://ezgif.com/apng-to-gif).
- [FFmpeg](https://ffmpeg.org/download.html) (командная строка): см. инструкции ниже.

## С помощью FFmpeg

Преобразуйте пронумерованные кадры PNG, например `frame_0001.png`, `frame_0002.png` и так далее, в APNG с бесконечным циклом воспроизведения. Параметр `-framerate 20` задаёт частоту 20 кадров в секунду:

```bash
ffmpeg -framerate 20 -i frame_%04d.png -plays 0 animation.apng
```

Преобразуйте видео в APNG. Параметр `fps=20` задаёт частоту 20 кадров в секунду, а `scale=960:-1` — ширину 960 пикселей:

```bash
ffmpeg -i trailer.mp4 -vf "fps=20,scale=960:-1" -plays 0 trailer.apng
```

Преобразуйте видео в GIF с бесконечным циклом воспроизведения. Часть `palettegen` подбирает для видео оптимальные 256 цветов:

```bash
ffmpeg -i trailer.mp4 -vf "fps=15,scale=640:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" -loop 0 trailer.gif
```

Преобразуйте GIF в APNG:

```bash
ffmpeg -i logo.gif -plays 0 logo.apng
```

# FMA и AFMA

FMA и AFMA — собственные форматы анимации FancyMenu. Оба устарели: они по-прежнему воспроизводятся, но для новых анимаций лучше использовать APNG или GIF.

Если всё же хотите создать AFMA:

1. Поместите кадры в формате PNG в одну папку. Они воспроизводятся в порядке имён, например `frame_1.png`, `frame_2.png`, ..., `frame_10.png`.
2. Откройте **строка меню -> Tools -> AFMA Creator**.
3. Укажите папку в поле **Main Frames Directory**. Кадры из папки **Intro Frames Directory** воспроизводятся один раз перед основными кадрами.
4. Задайте значения **Main Frame Time (ms)** и **Loop Count**. Значение `0` в поле количества повторов означает бесконечный цикл.
5. Укажите файл в поле **Output AFMA File** и нажмите **Export**.
