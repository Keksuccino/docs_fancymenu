# Пользовательские интерфейсы

Пользовательские интерфейсы — это меню, которые вы создаёте сами: например, экран с информацией о сборке модов, серверное лобби или страницу с правилами. Изначально они пусты. Заполните их с помощью [макета](/layout-editor), как и любое другое меню. Затем открывайте их кнопками, клавишами и командами.

# Создание пользовательского интерфейса

<img width="800" alt="Открытие раздела «Управление пользовательскими интерфейсами», нажатие кнопки «Новый интерфейс», ввод идентификатора modpack_info, включение режима всплывающего окна и открытие нового пользовательского интерфейса" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/custom_guis_new.gif?raw=true">

1. Откройте **панель меню -> Настройка -> Пользовательские интерфейсы -> Управление пользовательскими интерфейсами**.
2. Нажмите **Новый интерфейс**.
3. Введите **идентификатор пользовательского интерфейса**, например `modpack_info`, настройте [параметры](#параметры) и нажмите **Готово**.
4. Выберите новый пользовательский интерфейс в списке и нажмите **Открыть интерфейс**.
5. Нажмите **Готово**, чтобы закрыть окно **Управление пользовательскими интерфейсами**.

Изменения в разделе **Управление пользовательскими интерфейсами** сохраняются только после нажатия **Готово** или **Открыть интерфейс**. Кнопка **Отмена** отменяет изменения.

## Идентификатор

Кнопки, команды и макеты находят пользовательский интерфейс по его идентификатору.

- Допустимы только строчные латинские буквы, цифры, `.`, `_` и `-`. У каждого пользовательского интерфейса должен быть уникальный идентификатор.
- Не используйте [идентификатор другого экрана](/screen-identifiers), например `title_screen`. В этом случае пользовательский интерфейс будет использовать те же макеты, что и этот экран.
- Если позже изменить идентификатор, макеты, а также кнопки и команды со старым идентификатором перестанут его находить. Верните прежний идентификатор — и они снова заработают.

## Создание макета

1. Откройте пользовательский интерфейс.
2. Нажмите **панель меню -> Настройка -> Макеты -> Создать -> Для текущего экрана**. Настройка всегда включена для пользовательских интерфейсов.
3. Добавьте элементы и сохраните макет. См. раздел [Редактор макетов](/layout-editor).

В пользовательском интерфейсе изначально ничего нет, даже кнопки «Назад». Добавьте [кнопку](/elements#button) с действием [**Вернуться к предыдущему экрану**](/action-scripts#back-to-last-screen) или оставьте включённым параметр **Разрешить закрытие интерфейса клавишей ESC**, чтобы игроки могли выйти из него.

# Параметры

Пункт **Изменить интерфейс** в разделе **Управление пользовательскими интерфейсами** позволяет изменить параметры выбранного интерфейса.

| Параметр | Описание |
|---|---|
| **Идентификатор пользовательского интерфейса** | Название пользовательского интерфейса. См. раздел [Идентификатор](#идентификатор). |
| **Заголовок экрана (необязательно)** | Белый заголовок в верхней части интерфейса. Оставьте поле пустым, если заголовок не нужен. Поддерживаются [плейсхолдеры](/placeholders), а ключи локализации игры, модов и наборов ресурсов отображаются на языке игрока. |
| **Разрешить закрытие интерфейса клавишей ESC** | Клавиша `Esc` закрывает интерфейс. Включено по умолчанию. |
| **Приостанавливать игру/мир** | При открытом интерфейсе игра в одиночном мире приостанавливается. Включено по умолчанию. |
| **Отображать фон мира** | Во время игры за интерфейсом виден мир. Вне мира или если параметр отключён, отображается панорама Minecraft. Включено по умолчанию. |
| **Отображать затемнение фона мира** | Размывает и затемняет мир или панораму за интерфейсом, как в меню паузы. Работает только вместе с параметром **Отображать фон мира**: без него панорама всегда будет размытой и затемнённой. Включено по умолчанию. |
| **Режим всплывающего окна** | Интерфейс отображается поверх меню, из которого его открыли. См. раздел [Режим всплывающего окна](#режим-всплывающего-окна). |
| **Затемнение фона всплывающего окна** | Размывает меню за всплывающим окном. Работает только в **режиме всплывающего окна**. Включено по умолчанию. |

- Сила размытия соответствует параметру Minecraft **Размытие фона меню**.
- [Фон меню](/menu-backgrounds) в макете перекрывает всё это: мир, панораму и меню за всплывающим окном.
- В редакторе макетов нельзя изменить заголовок пользовательского интерфейса (**Заголовок пользовательского экрана**). Измените параметр **Заголовок экрана (необязательно)**. Чтобы настроить для заголовка собственный шрифт, цвет или расположение, оставьте это поле пустым и добавьте [текстовый элемент](/elements#text).

## Режим всплывающего окна

В **режиме всплывающего окна** меню, из которого открыли пользовательский интерфейс, остаётся видимым под ним вместе со своим макетом. Пока всплывающее окно открыто, нажимать на меню нельзя.

- Всплывающие окна лучше всего подходят для небольших элементов: например, информационного блока, подтверждения действия или панели настроек. Оставьте свободное место, чтобы было видно меню под окном.
- Не добавляйте фон меню в макет всплывающего окна, иначе меню под ним исчезнет.
- Если пользовательский интерфейс открывается, когда никакое меню не открыто, например клавишей во время игры, меню на заднем плане не будет. В этом случае отображается обычный фон интерфейса.

# Открытие пользовательского интерфейса

Любой способ открытия экранов позволяет открыть пользовательский интерфейс по его идентификатору:

- **Кнопки:** действие [**Открыть экран или пользовательский интерфейс**](/action-scripts#open-screen-or-custom-gui) со значением `modpack_info`.
- **Клавиши:** слушатель [**При нажатии клавиши**](/listeners#listener-variables) с тем же действием. Он открывает пользовательский интерфейс в меню и во время игры.
- **Команды:** `/openguiscreen modpack_info`. Её также можно использовать на серверах, в командных блоках и в наградах за задания. См. раздел [Команды](/commands#openguiscreen).
- **Выход из мира:** действие [**Покинуть мир или сервер**](/action-scripts#leave-world-or-server) с этим идентификатором открывает пользовательский интерфейс после выхода.

Пользовательские интерфейсы входят в индивидуальную конфигурацию FancyMenu каждого игрока. Сервер может открывать только те интерфейсы, которые есть у его игроков, например добавленные сборкой модов.

Чтобы закрыть пользовательский интерфейс:

- Клавиша `Esc` (если включён параметр **Разрешить закрытие интерфейса клавишей ESC**) и действие **Вернуться к предыдущему экрану** возвращают в меню, из которого был открыт интерфейс. Если до этого меню не было открыто, клавиша `Esc` возвращает в игру.
- Действие [**Закрыть экран**](/action-scripts#close-screen) закрывает его. Если вы находитесь вне мира, откроется главный экран.

# Замена существующего экрана

Пользовательский интерфейс может заменить меню игры или мода. Каждый раз, когда должно открыться это меню, вместо него будет открыт пользовательский интерфейс.

> [!WARNING]
> Заменённое меню больше не открывается, поэтому выполняемые им действия не срабатывают. Это также может нарушить работу других модов, которым оно нужно. По возможности изменяйте меню с помощью обычного макета. Заменяйте меню, только если макет не позволяет добиться нужного результата.

1. Включите **панель меню -> Настройка -> Параметры -> Расширенный режим настройки**.
2. Откройте меню, которое хотите заменить.
3. Нажмите **панель меню -> Настройка -> Пользовательские интерфейсы -> Заменить текущий экран пользовательским интерфейсом**.
4. Подтвердите предупреждение и выберите пользовательский интерфейс в окне **Выбор пользовательского интерфейса**.

Пользовательский интерфейс откроется сразу. Клавиша `Esc` и действие **Вернуться к предыдущему экрану** вернут в меню, которое было открыто до заменённого.

Чтобы отменить замену, откройте **панель меню -> Настройка -> Пользовательские интерфейсы -> Управление заменёнными экранами**, нажмите **Удалить правило замены** под нужным экраном и затем нажмите **Готово**.

> [!TIP]
> Чтобы заменять меню только в определённых случаях, например когда задана [переменная](/variables), используйте вместо этого слушатель [**При открытии экрана**](/listeners#on-screen-opened) с условием IF.

# Управление пользовательскими интерфейсами

- Кнопки **Новый интерфейс**, **Изменить интерфейс** и **Открыть интерфейс** в разделе **Управление пользовательскими интерфейсами** позволяют создавать, изменять и открывать пользовательские интерфейсы.
- Кнопка **Удалить интерфейс** удаляет выбранный пользовательский интерфейс после подтверждения. Его макеты сохраняются и снова появятся у нового пользовательского интерфейса с тем же идентификатором.
- В строке поиска можно найти пользовательские интерфейсы по идентификатору.
- **панель меню -> Справка -> Экспорт для ИИ -> Пользовательские интерфейсы** экспортирует все пользовательские интерфейсы и правила замены для [чата с ИИ](/export-for-ai).

Пользовательские интерфейсы и правила замены сохраняются в `config/fancymenu/custom_gui_screens.txt`, а их макеты — в `config/fancymenu/customization/`, как и остальные макеты (см. раздел [Расположение файлов данных](/data-storage-locations)). У каждого [профиля](/profiles) свой набор пользовательских интерфейсов.
