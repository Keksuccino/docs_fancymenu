# Пользовательские GUI

FancyMenu позволяет настраивать существующие экраны GUI, а также добавлять совершенно новые и наполнять их элементами.

# Добавление нового экрана

Чтобы добавить новый экран, перейдите в **Customization -> Custom GUIs -> Manage Custom GUIs**.

![custom_gui_1](https://github.com/Keksuccino/FancyMenu/assets/35544624/23e704ee-ccb5-434d-b75f-f4418399d9b7)

В следующем меню нажмите **New GUI**.

![custom_gui_2](https://github.com/Keksuccino/FancyMenu/assets/35544624/035454e8-b089-4b9a-9092-89a193c0eacd)

Здесь вам нужно задать новому GUI уникальный идентификатор, а также можно настроить другие параметры базового поведения экрана.
Когда закончите, нажмите **Done**.

![custom_gui_3](https://github.com/Keksuccino/FancyMenu/assets/35544624/1fbed3f9-9c81-4c73-85c7-d152146c55d8)

Теперь у вас есть новый пустой GUI. Чтобы открыть его, выберите GUI в меню **Manage Custom GUIs** и нажмите **Open GUI**.

![custom_gui_4](https://github.com/Keksuccino/FancyMenu/assets/35544624/b2e6a4b7-540d-4bf2-9dce-09bfff11ae7e)

Откроется всё ещё довольно пустой экран GUI. Чтобы сделать его менее пустым, просто создайте для него новый макет так же, как вы бы сделали для любого другого экрана.

![custom_gui_5](https://github.com/Keksuccino/FancyMenu/assets/35544624/e7e06a5f-46b3-48f1-9ad9-96a7565c97a9)

# Открытие GUI через действие

Последний шаг — дать обычным пользователям доступ к вашему GUI. Проще всего сделать это с помощью действия **Open Screen or Custom GUI** для кнопки, слайдера или тикера.

![custom_gui_6](https://github.com/Keksuccino/FancyMenu/assets/35544624/b5cc6518-3fc4-4715-96d4-44b65ab7831d)

# Открытие GUI через команду

Вы также можете открывать ваш пользовательский GUI через [внутриигровую команду](./commands#openguiscreen).
Это даже позволяет удалённо открывать GUI для других пользователей!

# Режим всплывающего окна

Начиная с FancyMenu v3.8.0, пользовательские GUI поддерживают "Popup Mode", который делает их похожими на всплывающее окно, открывающееся поверх другого экрана (предыдущего экрана, из которого был открыт пользовательский GUI). Этот параметр можно включать и отключать отдельно для каждого пользовательского GUI в его настройках.

FancyMenu 3.9.0 также добавляет возможность переключать наложение фона экрана для пользовательских GUI, когда вы находитесь в мире. Используйте её, если хотите отключить или сохранить размытый/затемнённый фон за пользовательским GUI, открытым поверх игрового процесса.
