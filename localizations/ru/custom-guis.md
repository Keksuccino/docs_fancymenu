# Пользовательские GUI

Пользовательские GUI — это новые экраны, которые вы можете заполнить [элементами](./elements) FancyMenu.

> [!CAUTION]
> Пользовательские GUI могут выполнять действия. Импортируйте их только из источников, которым доверяете.

# Создание пользовательского GUI

1. Откройте **Customization -> Custom GUIs -> Manage Custom GUIs**.
2. Выберите **New GUI**.
3. Введите идентификатор и настройте параметры экрана.
4. Выберите **Done**, затем откройте новое GUI из менеджера.
5. Создайте и отредактируйте его макет, как любой другой экран.

Идентификаторы могут содержать строчные буквы, цифры, `.`, `_` и `-`. Они не могут содержать пробелы и должны быть уникальными. Нельзя сохранить пустые, недопустимые или повторяющиеся идентификаторы.

У пользовательских GUI всегда включена настройка кастомизации экрана; переключатель кастомизации для них нельзя отключить.

# Настройки экрана

| Параметр | Поведение |
|---|---|
| Allow ESC | Позволяет клавише Escape закрывать GUI и возвращать вас на его родительский экран |
| Pause Game/World | Приостанавливает одиночную игру, пока GUI открыт |
| Render World Background | Показывает загруженный мир позади GUI |
| World Background Overlay | Добавляет стандартное размытие/затемняющую накладку поверх мира |
| Popup Mode | Оставляет родительский экран видимым позади пользовательского GUI |
| Popup Background Overlay | Добавляет размытие/тонирование поверх родительского экрана в режиме Popup Mode |

Popup Mode не объединяет два экрана. Пользовательский GUI остаётся активным экраном, а его родительский экран отрисовывается позади него. При закрытии пользовательского GUI вы возвращаетесь к родительскому экрану, если он существует.

# Открытие пользовательского GUI

Используйте точный идентификатор пользовательского GUI с помощью:

- [**Open Screen or Custom GUI** action](./action-scripts#open-screen-or-custom-gui-opengui).
- [`/openguiscreen` command](./commands#openguiscreen).

# Переопределение существующего экрана

Пользовательский GUI может заменить экран Vanilla или модификации каждый раз, когда открывается этот экран.

1. Создайте пользовательский GUI-замену.
2. Откройте экран, который хотите заменить.
3. Включите **Customization -> Settings -> Advanced Customization Mode**.
4. Выберите **Customization -> Custom GUIs -> Override Current with Custom GUI**.
5. Выберите пользовательский GUI-замену.

Управляйте сохранёнными переопределениями через **Customization -> Custom GUIs -> Manage Overridden Screens**.

Переопределение пропускает оригинальный экран, поэтому проверьте его навигацию и любые функции, которые зависят от поведения оригинального экрана.
