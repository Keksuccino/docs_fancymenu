# Бесшовная загрузка мира

Бесшовная загрузка мира делает снимок экрана, когда вы покидаете мир или сервер, и использует его в качестве фона загрузки при следующем запуске.

Это делает переходы при загрузке более плавными, потому что экран загрузки будет соответствовать тому, что вы увидите после завершения загрузки.

# Где найти

Откройте **панель меню** FancyMenu, **не** находясь в редакторе макета, затем выберите **Customization -> Global Customizations**.

# Включить / выключить

1. Откройте **Customization -> Global Customizations**.
2. Найдите **Seamless World Loading**.
3. Установите значение **Enabled** или **Disabled**.

# Как это работает

- Когда функция включена, FancyMenu сохраняет снимок экрана, когда вы покидаете мир/сервер.
- При следующей загрузке этот снимок используется как фон загрузки.
- Первое использование: если снимок ещё не существует, показывать нечего, пока вы один раз не покинете мир/сервер.
