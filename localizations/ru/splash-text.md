# Элемент пользовательского текста заставки

Элемент Splash Text в FancyMenu — это полностью настраиваемое улучшение прыгающих заголовков Minecraft. Он сохраняет знакомое подпрыгивание, но при этом даёт вам контроль над тем, что отображается, как это выглядит и когда обновляется.

> Имейте в виду, что оригинальный ванильный элемент Splash Text на экране заголовка почти не настраивается, поэтому его следует **удалить** и вместо него использовать пользовательский элемент Splash Text.
{.is-warning}

## Добавление и выбор элемента
- Откройте редактор макета и добавьте элемент `Splash Text`.
- Щёлкните по нему левой кнопкой один раз, чтобы выбрать его и показать ограничивающую рамку, затем щёлкните правой кнопкой, чтобы открыть контекстное меню. Все параметры настройки находятся именно там.

## Выбор источника текста заставки
- `Source Mode: Vanilla` сохраняет классические случайные тексты заставки, которые поставляются вместе с Minecraft.
- `Source Mode: Direct Input` позволяет ввести свой текст через `Input Splash Text`. Поддерживается только одна строка текста заставки, но она может содержать плейсхолдеры.
- `Source Mode: Text File` берёт случайную строку из `.txt`-файла, который вы выбираете через `Set Source Text File`. Каждая непустая строка может стать активной заставкой.
- Переключение режимов сбрасывает активный текст, так что вы можете безопасно экспериментировать. Если кажется, что текст «застрял», переключите другой режим или нажмите `Refresh On Screen Load: Enabled`, чтобы принудительно выбирать новый вариант каждый раз при открытии меню.

## Пример текстового файла
При использовании режима источника `Text File` сохраните список заставок как обычный текст (UTF-8 без BOM). Каждая строка — это возможная заставка:

```
Welcome to FancyMenu!
{"placeholder":"your_placeholder_id_here"}
{"text":"This is gold and bold text.","color":"gold","bold":true}
&6Use &lMinecraft formatting codes!
```

Замените `your_placeholder_id_here` на плейсхолдер, который вы хотите разрешать во время выполнения. FancyMenu выбирает случайную непустую строку каждый раз, когда текст заставки обновляется.

## Как сделать внешний вид нужным вам
- Используйте `Set Scale` и `Set Rotation`, чтобы управлять размером и углом поворота.
- `Set Text Color` принимает шестнадцатеричное значение (например `#FFFF00`), чтобы оно соответствовало вашей теме.
- `Shadow: Enabled` добавляет тень Minecraft; отключите её для плоского текста.
- `Bouncing: Enabled` сохраняет знакомое подпрыгивание; отключите, если нужен статичный текст.
- FancyMenu отображает заставку как полноценный компонент Minecraft, поэтому коды цвета и другие текстовые оформления работают как ожидается.

## Динамические возможности текста
- Плейсхолдеры разрешаются перед отрисовкой, поэтому внутри текста заставки можно использовать имена игроков, даты и другие поддерживаемые значения.
- Поскольку элемент принимает сериализованный JSON-компонент Minecraft, вы можете вставлять продвинутые JSON-фрагменты в Direct Input или в текстовый файл. Элемент автоматически десериализует их и при ошибке откатится к буквальному тексту.

## Устранение неполадок
- Пустой текст в Direct Input показывает `< empty splash element >` во время редактирования. Введите что угодно (даже пробел), чтобы убрать предупреждение.
- Если текстовый файл не содержит ни одной валидной строки, элемент отображает `ERROR: SPLASH FILE IS EMPTY`. Добавьте хотя бы одну непустую строку и снова откройте экран.
- Ошибки сериализованного JSON приводят к откату на обычный текст. Используйте стандартную JSON-структуру Mojang или сначала проверьте фрагменты с помощью ванильной команды `/tellraw`, прежде чем вставлять их.
