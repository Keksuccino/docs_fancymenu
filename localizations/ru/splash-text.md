# Элемент пользовательского текста заставки

Элемент Splash Text в FancyMenu — это полностью настраиваемое улучшение классических подпрыгивающих заголовков Minecraft. Он сохраняет привычную анимацию, но при этом даёт вам контроль над тем, что показывается, как это выглядит и когда обновляется.

> [!WARNING]
> Имейте в виду: оригинальный элемент Vanilla Splash Text на титульном экране почти невозможно настраивать, поэтому его следует **удалить** и вместо него использовать пользовательский элемент Splash Text.

## Добавление и выбор элемента
- Откройте редактор макета и добавьте элемент `Splash Text`.
- Щёлкните по нему левой кнопкой один раз, чтобы выбрать его и показать рамку, затем щёлкните правой кнопкой, чтобы открыть контекстное меню. Все параметры настройки находятся именно там.

## Выбор источника текста заставки
- `Source Mode: Vanilla` сохраняет классические случайные заставки, которые идут вместе с Minecraft.
- `Source Mode: Direct Input` позволяет ввести собственный текст через `Input Splash Text`. Поддерживается только одна строка заставки, но в ней могут быть плейсхолдеры.
- `Source Mode: Text File` берёт случайную строку из `.txt` файла, который вы выбираете через `Set Source Text File`. Каждая непустая строка может стать активной заставкой.
- Переключение режимов сбрасывает активный текст, так что можно безопасно экспериментировать. Если кажется, что текст «застрял», переключите другой режим или нажмите `Refresh On Screen Load: Enabled`, чтобы принудительно выбирать новый вариант при каждом открытии меню.

## Пример текстового файла
При использовании режима источника "Text File" сохраните список заставок в виде обычного текста (UTF-8 без BOM). Каждая строка — это возможная заставка:

```
Welcome to FancyMenu!
{"placeholder":"your_placeholder_id_here"}
{"text":"This is gold and bold text.","color":"gold","bold":true}
&6Use &lMinecraft formatting codes!
```

Замените `your_placeholder_id_here` на плейсхолдер, который вы хотите подставлять во время выполнения. FancyMenu выбирает случайную непустую строку каждый раз, когда заставка обновляется.

## Настройка внешнего вида
- Используйте `Set Scale` и `Set Rotation`, чтобы управлять размером и углом поворота.
- `Set Text Color` принимает шестнадцатеричное значение (например, `#FFFF00`), чтобы соответствовать вашей теме.
- `Shadow: Enabled` добавляет тень, как в Minecraft; отключите её, если нужен плоский текст.
- `Bouncing: Enabled` сохраняет привычное подпрыгивание; отключите, если нужен статичный текст.
- FancyMenu рендерит заставку как полноценный компонент Minecraft, поэтому цветовые коды и другие текстовые оформления работают как ожидается.

## Динамические возможности текста
- Плейсхолдеры подставляются до рендеринга, поэтому в тексте заставки можно использовать имя игрока, дату или другие поддерживаемые значения.
- Поскольку элемент принимает сериализованный JSON-компонент Minecraft, вы можете вставлять сложные JSON-фрагменты в Direct Input или в текстовый файл. Элемент автоматически десериализует их и при ошибке откатится к буквальному тексту.

## Устранение неполадок
- Пустой текст в Direct Input показывает `< empty splash element >` во время редактирования. Введите что угодно (даже пробел), чтобы убрать предупреждение.
- Если текстовый файл не содержит ни одной допустимой строки, элемент отображает `ERROR: SPLASH FILE IS EMPTY`. Добавьте хотя бы одну непустую строку и снова откройте экран.
- Ошибки сериализованного JSON откатываются к обычному тексту. Используйте стандартную JSON-структуру Mojang или сначала проверьте фрагменты с помощью ванильной команды `/tellraw`, прежде чем вставлять их.
