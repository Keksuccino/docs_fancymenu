# Экраны загрузки мира

Когда вы загружаетесь в мир или подключаетесь к серверу, вы, вероятно, замечали экраны, которые появляются там и которые нельзя по-настоящему настроить, потому что они автоматически закрываются.

Чтобы редактировать их, нужно открыть их экземпляр, который будет оставаться открытым столько, сколько вам нужно. Это можно сделать, открыв для них «dummy screen instance».

«Dummy Screen Instances» — это функция FancyMenu, которая позволяет открыть НЕКОТОРЫЕ экраны, исчезающие слишком быстро, чтобы их можно было настроить.

Чтобы увидеть все экраны, которые можно открыть через функцию Dummy Screen Instance, нажмите **menu bar -> Tools -> Dummy Screen Instances**. Открывшееся меню показывает все экраны, которые можно открыть как dummy screen instance. **Щелчок левой кнопкой мыши** по экранам в меню откроет для вас их dummy-экземпляр, чтобы вы могли спокойно их настроить.

Например, при входе в мир или на сервер во время загрузки отображаются как минимум два экрана:

- Level Loading Screen (также известен как World Loading Screen)
- Generic Dirt Message Screen (также известен как Dirt Message Screen)

> [!WARNING]
> **Важно:** "World Loading Screen" — это не то же самое, что "Game Loading Screen" (также известный как Splash Screen или Resource Reloading Screen). "Game Loading Screen" можно настроить с помощью **Drippy Loading Screen**, который является дополнением для FancyMenu.
