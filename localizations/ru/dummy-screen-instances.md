# Экраны загрузки мира

Когда вы загружаетесь в мир или подключаетесь к серверу, вы, вероятно, замечали, что там появляются экраны, которые нельзя толком настроить, потому что они автоматически закрываются.

Чтобы их отредактировать, нужно открыть их экземпляр, который будет оставаться открытым столько, сколько вам нужно. Это можно сделать, открыв у них "dummy screen instance".

"Dummy Screen Instances" — это функция FancyMenu, которая позволяет открывать НЕКОТОРЫЕ экраны, исчезающие слишком быстро, чтобы их можно было настроить.

Чтобы увидеть все экраны, которые можно открыть через функцию Dummy Screen Instance, нажмите **панель меню -> Tools -> Dummy Screen Instances**. Открывшееся меню покажет все экраны, которые можно открыть как dummy screen instance. **Щелчок левой кнопкой мыши** по экрану в меню откроет его dummy-экземпляр, чтобы вы могли спокойно его настроить.

Например, при входе в мир или на сервер во время загрузки показываются как минимум два экрана:

- Экран загрузки уровня (он же World Loading Screen)
- Generic Dirt Message Screen (он же Dirt Message Screen)

> **Важно:** "World Loading Screen" — это не то же самое, что "Game Loading Screen" (он же Splash Screen или Resource Reloading Screen). "Game Loading Screen" можно настраивать с помощью **Drippy Loading Screen**, это дополнение для FancyMenu.
