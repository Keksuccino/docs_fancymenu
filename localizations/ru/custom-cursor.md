# Пользовательский курсор мыши

FancyMenu позволяет задавать отдельный пользовательский курсор мыши для каждого экрана.

Чтобы сделать это, просто добавьте новый элемент **Cursor** в макет и щёлкните по нему правой кнопкой мыши, чтобы задать текстуру курсора.

Если вы хотите, чтобы пользовательский курсор отображался на всех экранах, следует использовать **универсальный макет**.
