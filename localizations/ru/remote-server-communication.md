# Связь с удалённым сервером

Система "Связь с удалённым сервером" позволяет клиентам FancyMenu взаимодействовать с внешними серверами с помощью WebSocket-соединений.

Все данные передаются в текстовом виде:

- Поддерживается обычный текст
- Поддерживается JSON (как обычный текст)

Для каждого URL сервера во время работы создаётся один кэшированный **ID запроса**.
FancyMenu использует этот ID для отслеживания соединения и передачи его в переменные слушателей.

# Быстрый старт

1. Добавьте действие **Подключиться к удалённому серверу** (необязательно, но полезно для раннего открытия соединения)
2. Добавьте действие **Отправить данные на удалённый сервер** с тем же URL
3. Добавьте слушатель **При получении данных от удалённого сервера**, чтобы реагировать на ответы
4. Используйте **При подключении к удалённому серверу** / **При закрытии соединения с удалённым сервером** для логики состояния соединения
5. Закрывайте соединения при необходимости с помощью действий закрытия

# Действия

## Подключиться к удалённому серверу

Инициализирует соединение с удалённым сервером без отправки полезных данных.

Входные данные:

- URL удалённого сервера

## Отправить данные на удалённый сервер

Подключается (или использует уже существующее соединение) и отправляет текстовые данные.

Входные данные:

1. URL удалённого сервера
2. Данные

## Закрыть соединение с удалённым сервером

Закрывает одно соединение по ID запроса.

Входные данные:

- ID запроса соединения

## Закрыть все соединения с удалённым сервером

Закрывает все активные в данный момент соединения с удалённым сервером.

# Слушатели

## При подключении к удалённому серверу

Срабатывает, когда соединение с удалённым сервером инициализируется.

Переменные:

- `$$request_id`
- `$$remote_server_url`

## При получении данных от удалённого сервера

Срабатывает, когда от подключённого удалённого сервера получены данные.

Переменные:

- `$$request_id`
- `$$remote_server_url`
- `$$data`

## При закрытии соединения с удалённым сервером

Срабатывает, когда соединение с удалённым сервером закрывается.

Переменные:

- `$$request_id`
- `$$remote_server_url`
- `$$intentionally_closed`
- `$$crashed`
- `$$unknown_close_reason`

# Поведение соединения

- Соединения **инициируются клиентом**
- FancyMenu поддерживает соединения активными в фоновом режиме
- Если соединение аварийно завершается или истекает по тайм-ауту, FancyMenu повторяет попытку каждые 10 секунд
- Когда аварийно завершённое соединение восстанавливается, FancyMenu выводит сообщение о восстановлении
- Неотправленные исходящие сообщения ставятся в очередь с **максимальным возрастом 30 секунд**
- Сообщения в очереди старше 30 секунд удаляются

# Режимы URL

- `wss://` = защищённый (TLS), рекомендуется
- `ws://` = без шифрования, полезно для локального тестирования

Пример локального URL:

- `ws://127.0.0.1:8765`

# Рекомендации

1. Используйте один стабильный URL для каждого серверного сервиса.
2. Поддерживайте единый формат полезной нагрузки для каждого сценария использования.
3. Обрабатывайте закрытые/аварийно завершённые соединения с помощью резервной UI-логики.
4. Используйте действия закрытия, когда ваш сценарий завершён.
5. Используйте `wss://` для production-окружений.
