# Удалённое взаимодействие с сервером

Система «Удалённое взаимодействие с сервером» позволяет клиентам FancyMenu обмениваться данными с внешними серверами с помощью WebSocket-соединений.

Все данные передаются в текстовом виде:

- Поддерживается обычный текст
- Поддерживается JSON (как обычный текст)

Для каждого URL сервера во время работы создаётся один кэшированный **ID запроса**.
FancyMenu использует этот ID для отслеживания соединения и отображения его в переменных слушателей.

# Быстрый старт

1. Добавьте [**Подключиться к удалённому серверу**](#connect-to-remote-server), если соединение должно открываться заранее.
2. Добавьте [**Отправить данные на удалённый сервер**](#send-data-to-remote-server) с тем же URL.
3. Добавьте [**При получении данных от удалённого сервера**](#on-remote-server-data-received), чтобы реагировать на ответы.
4. Используйте [**При подключении к удалённому серверу**](#on-remote-server-connected) и [**При закрытии соединения с удалённым сервером**](#on-remote-server-connection-closed) для логики, связанной со состоянием соединения.
5. Закрывайте соединения с помощью [**Закрыть соединение с удалённым сервером**](#close-remote-server-connection) или [**Закрыть все соединения с удалёнными серверами**](#close-all-remote-server-connections).

# Действия

## Подключиться к удалённому серверу

Открывает или повторно использует соединение с удалённым сервером без отправки полезной нагрузки.

Вход:

- URL удалённого сервера

## Отправить данные на удалённый сервер

Подключается (или повторно использует существующее соединение) и отправляет текстовые данные.

Входы:

1. URL удалённого сервера
2. Данные

## Закрыть соединение с удалённым сервером

Закрывает одно соединение по ID запроса.

Вход:

- ID запроса соединения

## Закрыть все соединения с удалёнными серверами

Закрывает все текущие активные соединения с удалёнными серверами.

# Слушатели

## При подключении к удалённому серверу

Срабатывает после успешного открытия соединения с удалённым сервером.

Переменные:

- `$$request_id`
- `$$remote_server_url`

## При получении данных от удалённого сервера

Срабатывает, когда от подключённого удалённого сервера получены данные.

Переменные:

- `$$request_id`
- `$$remote_server_url`
- `$$data`

## При закрытии соединения с удалённым сервером

Срабатывает, когда соединение с удалённым сервером закрывается.

Переменные:

- `$$request_id`
- `$$remote_server_url`
- `$$intentionally_closed`
- `$$crashed`
- `$$unknown_close_reason`

# Поведение соединения

- Соединения **инициируются клиентом**
- FancyMenu поддерживает соединения активными в фоне
- Если соединение аварийно завершается или истекает по тайм-ауту, FancyMenu повторяет попытку каждые 10 секунд
- Когда аварийно завершённое соединение восстанавливается, FancyMenu выводит сообщение о восстановлении
- Исходящие неотправленные сообщения ставятся в очередь с **максимальным сроком хранения 30 секунд**
- Сообщения в очереди старше 30 секунд удаляются

# Режимы URL

- `wss://` используется как написано и рекомендуется.
- `ws://` используется как написано и не шифруется.
- `https://` преобразуется в `wss://`.
- `http://` преобразуется в `ws://`.
- Обычный хост дополняется префиксом `wss://`.
- Другие явно указанные схемы URL отклоняются.

По возможности используйте явные URL `wss://`. Пример локального URL:

- `ws://127.0.0.1:8765`

Используйте один стабильный URL для каждого сервиса, обрабатывайте состояния закрытого/аварийно завершённого слушателя и закрывайте соединения, когда они больше не нужны.
