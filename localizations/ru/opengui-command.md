# Открытие GUI с помощью команды

Команда `/openguiscreen` открывает ванильные, модифицированные и [пользовательские GUI](/custom-guis). Если FancyMenu установлен на сервере и у игроков на клиенте, команду можно использовать для открытия GUI другим игрокам.

Чтобы открыть GUI, используйте `/openguiscreen <screen_identifier> [<target_players>]`.

Замените `<screen_identifier>` точным идентификатором пользовательского GUI или ванильного/модифицированного экрана. Учитывайте регистр символов.

Чтобы узнать идентификатор, откройте нужный экран и включите отладочную панель сочетанием клавиш **CTRL + ALT + D**. Выберите идентификатор в первой строке, чтобы скопировать его. Подробнее см. в разделе [Идентификаторы экранов](/screen-identifiers).

![копировать_идентификатор](https://github.com/Keksuccino/FancyMenu/assets/35544624/dd6c53d9-d2bd-4810-be03-3741e326bd5a)

Не указывайте `[<target_players>]`, чтобы открыть GUI для себя, или укажите имя игрока либо селектор, например `@a`, чтобы открыть его для одного или нескольких игроков. Для передачи аргумента с целевыми игроками требуется уровень разрешений 2 (игровой мастер / OP уровня 2), даже если в качестве цели указаны вы сами. У каждого целевого игрока должен быть установлен FancyMenu на клиенте.

Не каждый экран мода можно создать напрямую. Если целевой экран не поддерживается, FancyMenu покажет ошибку. В локальном макете используйте [**Имитировать кнопку ванильного/модифицированного экрана**](/action-scripts#mimic-vanillamod-button) для виджета, который обычно открывает этот экран.

# Закрытие GUI с помощью команды

В редких случаях может понадобиться команда `/closeguiscreen [<target_players>]`, которая закрывает текущий экран. Если целевые игроки не указаны, команда действует на вас. Для передачи аргумента с целевыми игроками требуется уровень разрешений 2.
