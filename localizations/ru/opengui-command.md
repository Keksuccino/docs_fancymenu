# Открытие GUI по команде

FancyMenu поставляется с командой, которая позволяет открывать Vanilla и пользовательские GUI через команду.
Вы даже можете удалённо открывать GUI для **других игроков**, если установите FancyMenu и на **сервере, и на клиентах**.

Чтобы открыть GUI, просто используйте команду `/openguiscreen <screen_identifier> <target_player>`.

Замените `<screen_identifier>` на фактический идентификатор меню того GUI, который вы хотите открыть.
Это может быть идентификатор вашего пользовательского GUI (созданного с помощью FancyMenu) или обычный идентификатор меню Vanilla/mod GUI.

Чтобы узнать **идентификатор меню Vanilla/mod GUI**, откройте нужное меню и включите **debug overlay** FancyMenu через **Customization -> Debug Overlay**, после чего вы сможете нажать на идентификатор, показанный в первой строке, чтобы скопировать его в буфер обмена.

![copy_identifier](https://github.com/Keksuccino/FancyMenu/assets/35544624/dd6c53d9-d2bd-4810-be03-3741e326bd5a)

Оставьте аргумент `<target_player>` пустым, чтобы открыть GUI для вашего клиента, или укажите игрока (или нескольких игроков), для которых нужно открыть GUI.
Имейте в виду, что у другого игрока должен быть установлен FancyMenu на клиенте.

Эта команда работает не для каждого экрана, особенно для экранов модов. Если команде не удастся открыть экран, будет показана ошибка. В таком случае вы мало что сможете сделать, потому что, скорее всего, это экран, который слишком сложен для автоматического открытия через FancyMenu.

Я также больше не буду вручную добавлять поддержку экранов модов, потому что добавление совместимости для всех существующих модов заняло бы у меня вечность, извините.

# Закрытие GUI по команде

В редком случае, если вам это понадобится, есть также команда `/closeguiscreen <target_player>`, которая закрывает текущий экран.
