# Открытие GUI по команде

Команда `/openguiscreen` открывает стандартные GUI Vanilla, GUI модов и [пользовательские GUI](./custom-guis). Она может обращаться к другим игрокам, если FancyMenu установлен на сервере и на их клиентах.

Чтобы открыть GUI, используйте `/openguiscreen <screen_identifier> [<target_players>]`.

Замените `<screen_identifier>` на точный, чувствительный к регистру идентификатор пользовательского GUI или экрана Vanilla/мода.

Чтобы найти идентификатор, откройте нужный экран и включите отладочный оверлей с помощью **CTRL + ALT + D**. Выберите идентификатор в его первой строке, чтобы скопировать его. См. [Идентификаторы экранов](./screen-identifiers).

![copy_identifier](https://github.com/Keksuccino/FancyMenu/assets/35544624/dd6c53d9-d2bd-4810-be03-3741e326bd5a)

Не указывайте `[<target_players>]`, чтобы открыть GUI для себя, или используйте имя игрока либо селектор, например `@a`, чтобы открыть его для одного или нескольких игроков. Передача аргумента цели требует уровень доступа 2 (Game Master / OP уровень 2), даже если цель — вы сами, и у каждого указанного игрока должен быть установлен FancyMenu на клиенте.

Не каждый экран мода можно создать напрямую. FancyMenu показывает ошибку, если целевой экран не поддерживается. В локальной разметке используйте [**Кнопку Mimic Vanilla/Mod**](./action-scripts#mimic-vanillamod-button-mimicbutton) на виджете, который обычно открывает этот экран.

# Закрытие GUI по команде

В редком случае, если это нужно, `/closeguiscreen [<target_players>]` закрывает текущий экран. Если цель не указана, команда действует на вас; передача аргумента цели требует уровень доступа 2.
