# Заполнители

Заполнители подставляют актуальные значения в текст, кнопки, требования и другие поддерживаемые поля.

# Общая информация

## Базовый синтаксис
Заполнители в FancyMenu используют синтаксис, похожий на JSON:
```
{"placeholder":"modversion","values":{"modid":"fancymenu"}}
```

Например, чтобы вывести имя игрока:
```
{"placeholder":"playername"}
```

## Вложенные заполнители
Вы можете использовать один заполнитель внутри значения другого заполнителя.

Пример вложенных заполнителей:
```
{"placeholder":"calc","values":{"decimal":"true","expression":"{"placeholder":"maxram"} / 1024"}}
```
Этот пример берёт максимальный объём RAM и делит его на 1024, чтобы перевести значение из МБ в ГБ.

> [!IMPORTANT]
> Это синтаксис FancyMenu, а не JSON. Вложенные заполнители используют точную неэкранированную форму, показанную выше, поэтому JSON-форматтеры будут отклонять или переписывать их. Имена заполнителей чувствительны к регистру; неверно написанные или неизвестные заполнители остаются видимыми как текст и записываются в журнал.

# Использование заполнителей

Большинство элементов с полями ввода текста поддерживают заполнители. Вы можете увидеть, поддерживает ли текстовое поле заполнители, при его редактировании. Если при редактировании текста открывается полноэкранный **редактор текста**, значит он поддерживает заполнители.

Чтобы открыть **список всех заполнителей**, просто нажмите кнопку **Заполнители** в **правом верхнем углу** **редактора текста**.

Вверху списка заполнителей есть **строка поиска**, которая позволяет находить нужные заполнители.

Нажатие на заполнитель в списке вставит его в текст.

# Заполнители подробно

В этом разделе перечислены встроенные заполнители FancyMenu.

## Недоступные значения

Результат заполнителя всегда является текстом. Если данные недоступны, результат зависит от заполнителя: распространённые варианты — пустая строка, `0`, `0.0`, `00:00`, `false`, `UNKNOWN` или `ERROR`. Для записей с конкретным запасным значением оно указано явно; проверяйте запасное значение перед использованием зависящего от окружения вывода в [требовании](./conditions), пути, команде или URL.

## Последний мир или сервер (`last_world_server`)

**Назначение:** Возвращает информацию о последнем открытом мире или сервере.

**Значения:** `type`, `full_world_path`

**Пример:**

```
{"placeholder":"last_world_server","values":{"type":"both","full_world_path":"true"}}
```
Параметры:
- `type`: Определяет, какой тип информации возвращать
  - `"both"`: Возвращает последний открытый мир или сервер (по умолчанию)
  - `"server"`: Возвращает только если последним был сервер
  - `"world"`: Возвращает только если последним был мир
- `full_world_path`: Управляет отображением пути к миру
  - `"true"`: Возвращает полный путь к миру (по умолчанию)
  - `"false"`: Возвращает только имя мира без пути (не влияет на серверы)

Примеры:
- Сервер: `mc.hypixel.net`
- Мир с полным путём: `saves/New World`
- Мир без полного пути: `New World`

## Калькулятор (`calc`)

**Назначение:** Заполнитель калькулятора — это мощный инструмент, позволяющий выполнять математические вычисления внутри ваших макетов. Он поддерживает широкий набор математических операций и может работать как с десятичными, так и с целыми числами.

**Значения:** `decimal`, `expression`

### Базовый синтаксис

**Пример:**

```
{"placeholder":"calc","values":{"decimal":"true/false","expression":"your_expression"}}
```

У калькулятора есть два основных параметра:
- `decimal`: Определяет, должен ли результат содержать десятичные знаки (`true`) или быть округлён до целых (`false`)
- `expression`: Математическое выражение для вычисления

### Поддерживаемые операции
Калькулятор поддерживает следующие математические операции:
- Базовая арифметика: `+` (сложение), `-` (вычитание), `*` (умножение), `/` (деление)
- Скобки: `( )` для группировки операций
- Степень: `^` для возведения в степень
- Квадратный корень: `sqrt()`
- Тригонометрические функции: `sin()`, `cos()`, `tan()`
- Математические константы: `pi`, `e`
- Абсолютное значение: `abs()`
- Логарифмы: `log()`, `ln()`

## Случайный текст (`randomtext`)

**Назначение:** Возвращает случайную строку из текстового файла, URL или напрямую заданного обычного текста. Текст меняется через указанные интервалы. Содержимое файла и URL обновляется примерно каждые 30 секунд; напрямую заданный обычный текст кэшируется, так как его не нужно перезагружать.

**Значения:** `source`, `interval`

В значениях заполнителя `/config/...` означает `<game-directory>/config/...`; это не путь от корня файловой системы. См. [Ресурсы](./resources#local-resources).

**Пример:**

```
{"placeholder":"randomtext","values":{"source":"/config/fancymenu/assets/<file_name.txt>","interval":"10"}}
```
Параметры:
- `source`: Источник строк текста (заменяет старый параметр `path`)
  - Путь к файлу: `/config/fancymenu/assets/quotes.txt`
  - URL: `https://example.com/quotes.txt`
  - Обычный текст: `Line 1\nLine 2\nLine 3`
- `interval`: Время в секундах между сменой текста

Теперь заполнитель поддерживает три типа источника:
1. **Локальные файлы**: текстовые файлы из вашей папки игры
   ```
   {"placeholder":"randomtext","values":{"source":"/config/fancymenu/assets/quotes.txt","interval":"10"}}
   ```
2. **URL**: удалённые текстовые файлы из интернета
   ```
   {"placeholder":"randomtext","values":{"source":"https://example.com/quotes.txt","interval":"10"}}
   ```
3. **Обычный текст**: прямой ввод текста с разделением строк через `\n`
   ```
   {"placeholder":"randomtext","values":{"source":"First line\nSecond line\nThird line","interval":"5"}}
   ```

Примечание: старые заполнители, использующие `path` вместо `source`, по-прежнему будут работать.

## Парсер JSON (`json`)

**Назначение:** Парсит JSON-данные из файла, URL или напрямую заданного JSON-содержимого и извлекает значения с помощью JSONPath-выражений.

**Значения:** `source`, `json_path`

**Пример:**

```
{"placeholder":"json","values":{"source":"path_or_link_or_json_content","json_path":"$.some.json.path"}}
```
Параметры:
- `source`: Источник JSON-данных
  - Путь к файлу: `/config/fancymenu/assets/data.json`
  - URL: `https://api.example.com/data.json`
  - Прямой JSON: `{"name":"Steve","level":42}`
- `json_path`: JSONPath-выражение для извлечения данных

Теперь заполнитель поддерживает три типа источника:
1. **Локальные файлы**: JSON-файлы из вашей папки игры
   ```
   {"placeholder":"json","values":{"source":"/config/fancymenu/assets/playerdata.json","json_path":"$.player.name"}}
   ```
2. **URL**: удалённые JSON-данные из API или веб-сервисов
   ```
   {"placeholder":"json","values":{"source":"https://api.minecraft.com/server/status","json_path":"$.online"}}
   ```
3. **Прямой JSON**: встроенное JSON-содержимое
   ```
   {"placeholder":"json","values":{"source":"{"name":"Steve","score":42,"rank":"Diamond"}","json_path":"$.rank"}}
   ```

Примеры JSONPath:
- `$.name` — получает поле "name" из корня
- `$.player.level` — получает вложенное поле "level" внутри "player"
- `$.items[0].id` — получает "id" первого элемента массива
- `$.scores.*` — получает все значения объекта "scores"

- `source_type`: `"entity"` или `"block"`
- `entity_selector`: Селектор сущности, например `@s`, `@p`, `@e`, или UUID/имя (для сущностей)
- `block_pos`: Позиция блока в формате `"x y z"` (для блоков)
- `nbt_path`: Путь NBT для извлечения
- `scale`: Необязательный коэффициент масштабирования для числовых значений (по умолчанию: `"1.0"`)
- `return_type`: Как возвращать данные:
  - `"value"`: По умолчанию, возвращает значение (с возможным масштабированием для чисел)
  - `"string"`: Возвращает фактические NBT-данные в виде строки
  - `"snbt"`: Возвращает SNBT (форматированный NBT)
  - `"json"`: Возвращает JSON-форматированный компонент (для compound-тегов)

**Вывод:** `20` (для уровня голода)

## Получить NBT-данные (со стороны сервера) (`nbt_data_get_server`)

**Назначение:** Запрашивает NBT-данные на стороне сервера (через пакет) и ненадолго кэширует результаты. Значения аналогичны клиентскому заполнителю.

**Значения:** `source_type`, `entity_selector`, `block_pos`, `storage_id`, `nbt_path`, `scale`, `return_type`

**Пример:**

```
{"placeholder":"nbt_data_get_server","values":{"source_type":"entity","entity_selector":"@s","block_pos":"","storage_id":"minecraft:storage_key","nbt_path":"SelectedItem.id","scale":"1.0","return_type":"value"}}
```

**Вывод:** `minecraft:diamond_sword`

## Последнее сообщение о смерти (`lastdeathmessage`)

**Назначение:** Возвращает последнее зафиксированное сообщение о смерти клиентского игрока. Установите `as_json_component` в `"true"`, чтобы получить сырой JSON-компонент текста.

**Значения:** `as_json_component`

**Пример:**

```
{"placeholder":"lastdeathmessage","values":{"as_json_component":"false"}}
```

**Вывод:** `Steve was slain by Zombie`

## Длительность работы (`uptime_duration`)

**Назначение:** Возвращает, как долго загружен FancyMenu. По умолчанию значение указано в секундах; установите `output_as_millis` в `"true"`, чтобы получить миллисекунды.

**Значения:** `output_as_millis`

**Пример:**

```
{"placeholder":"uptime_duration","values":{"output_as_millis":"false"}}
```

**Вывод:** `742` (секунд с момента загрузки)

## Имена сохранений миров (`level_save_names`)

**Назначение:** Перечисляет все локальные сохранения миров, объединённые выбранным разделителем. Выполняется в потоке клиента.

**Значения:** `separator`

**Пример:**

```
{"placeholder":"level_save_names","values":{"separator":", "}}
```

**Вывод:** `Creative Test, Survival World, Hardcore`

## Данные сохранения мира (`level_save_data`)

**Назначение:** Возвращает сериализованные данные мира для указанного имени мира (должно совпадать с отображаемым именем в списке сохранений).

**Значения:** `level_name`

**Пример:**

```
{"placeholder":"level_save_data","values":{"level_name":"Survival World"}}
```

**Вывод:** `{"name":"Survival World","gameMode":"survival",...}`

## Конвертер системы счисления (`number_base_convert`)

**Назначение:** Преобразует число (целое или дробное) из одной системы счисления в другую (2–36). По умолчанию используется десятичная система, если основания не указаны.

**Значения:** `input`, `from_base`, `to_base`

**Пример:**

```
{"placeholder":"number_base_convert","values":{"input":"67.5","from_base":"10","to_base":"16"}}
```

**Вывод:** `43.8`

## Размер файла (`file_size`)

**Назначение:** Возвращает размер локального файла в байтах. Разрешены только локальные пути.

**Значения:** `path`

**Пример:**

```
{"placeholder":"file_size","values":{"path":"/config/fancymenu/assets/notes.txt"}}
```

**Вывод:** `1284`

## MD5 файла (`file_md5`)

**Назначение:** Возвращает MD5-хэш локального файла в виде шестнадцатеричной строки в нижнем регистре.

**Значения:** `path`

**Пример:**

```
{"placeholder":"file_md5","values":{"path":"/config/fancymenu/assets/notes.txt"}}
```

**Вывод:** `d41d8cd98f00b204e9800998ecf8427e`

# Лучшие практики

1. **Кэшируйте дорогие операции**: Некоторые заполнители (например, те, что читают системную информацию) могут быть ресурсоёмкими. Если нужно использовать их несколько раз, рассмотрите возможность сохранения их значений в переменные.

2. **Используйте подходящие настройки десятичных значений**: При работе с вычислениями правильно используйте параметр `decimal`. Устанавливайте его в `false`, когда нужны целые числа, и в `true`, когда нужны точные десятичные значения.

3. **Обрабатывайте отсутствующие значения**: Всегда учитывайте, что должно происходить, если заполнитель не возвращает значение. В таких случаях может быть полезно задать значения по умолчанию.

4. **Проверяйте производительность**: При использовании большого количества заполнителей или сложных вложенных структур тестируйте влияние на производительность, особенно на слабых системах.

5. **Используйте продвинутое масштабирование и позиционирование**: Для динамических элементов интерфейса комбинируйте заполнители с расширенным масштабированием и позиционированием, чтобы создавать адаптивные макеты.

6. **Комбинируйте с переменными**: Используйте заполнители вместе с переменными для ещё более динамического контента, который можно обновлять через действия.

# Частые проблемы и решения

## Заполнитель не обновляется
Если значение заполнителя не обновляется так, как ожидалось, проверьте:
- Правильно ли отформатирован заполнитель
- Используете ли вы правильный регистр для идентификаторов заполнителей
- Требует ли заполнитель особых условий для обновления

## Вложенные заполнители не работают
При вложении заполнителей:
- Убедитесь, что кавычки правильно экранированы
- Проверьте, что каждый вложенный заполнитель сам по себе корректен

## Проблемы с производительностью
Если вы заметили проблемы с производительностью:
- Уменьшите количество используемых заполнителей
- Избегайте лишнего вложения
- Рассмотрите возможность использования переменных для часто запрашиваемых значений
- Используйте подходящий заполнитель для вашей задачи (например, не используйте заполнители реального времени, если достаточно статических значений)
