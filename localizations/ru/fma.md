# Анимации

Файлы AFMA и FMA — это форматы анимированных текстур, созданные для FancyMenu.

# Файлы AFMA

**AFMA** (Advanced FancyMenu Animation) — это преемник классических файлов FMA.

AFMA использует формат не на основе ZIP, благодаря чему файлы меньше, расход памяти ниже, а производительность лучше, чем у классического FMA.

Для больших или сложных анимированных текстур используйте **AFMA** вместо классического FMA.

Создавайте файлы AFMA с помощью встроенного создателя:

1. Откройте строку меню FancyMenu.
2. Перейдите в **Tools -> AFMA Creator**.
3. Импортируйте/конвертируйте кадры с помощью создателя.

> [!IMPORTANT]
> Файлы AFMA нельзя упаковать вручную. Используйте **Tools -> AFMA Creator**.

Классические файлы FMA по-прежнему поддерживаются, поэтому существующие макеты не нужно немедленно конвертировать.

# Классические файлы FMA

## Создание FMA

Классический файл FMA — это ZIP-архив с расширением `.fma`.

### Расширения файлов

Перед созданием или переименованием файлов ниже включите отображение расширений файлов в вашем файловом менеджере.

В Windows откройте Проводник и включите **Вид -> Расширения имён файлов**.

### Подготовка

Создайте папку `fancymenu_animation` для содержимого архива.

Создайте внутри неё обязательный каталог `frames` и необязательный каталог `intro_frames`.

В той же папке создайте `metadata.json`. Убедитесь, что расширение файла — `.json`, а не `.txt`.

Теперь папка должна содержать `frames/`, `intro_frames/` и `metadata.json`.

<br>
<img width="700" alt="Screenshot_3" src="https://gist.github.com/assets/35544624/e29f6666-ee4a-4d79-b7e2-1b640f40ce78">

### JSON-метаданные

Откройте `metadata.json` в текстовом редакторе и используйте этот шаблон:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
  },
  "custom_frame_times_intro": {
  }
}
```

Отредактируйте значения по необходимости.

#### `loop_count`

Управляет тем, сколько раз проигрывается анимация. Используйте `0`, чтобы зациклить её бесконечно. Положительное значение проиграет анимацию указанное число раз, а затем оставит последний кадр.

#### `frame_time`

Задаёт, как долго каждый обычный кадр остаётся видимым, в миллисекундах.

#### `frame_time_intro`

Задаёт время кадра для необязательных кадров **intro**.

#### `custom_frame_times`

Необязательно переопределяет длительность отдельных обычных кадров. В этом примере кадры `0` и `1` будут видимы по `5000` миллисекунд, а остальные кадры будут использовать `frame_time`:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
    "0": 5000,
    "1": 5000
  },
  "custom_frame_times_intro": {
  }
}
```

Индексы кадров начинаются с нуля: первый кадр — `0`, второй — `1` и так далее.

Добавляйте запятую после каждой записи custom frame time, кроме последней.

#### `custom_frame_times_intro`

Использует тот же формат, что и `custom_frame_times`, но применяется к необязательным кадрам intro.

Сохраните `metadata.json`.

### Кадры

> [!CAUTION]
> Ограничивайте классические анимации FMA 200 кадрами и разрешением 1080p или ниже. Для длинного контента или контента с высокой частотой кадров используйте [Видео](./video).

Поместите обычные кадры в `frames/`. Это должны быть PNG-файлы, названные последовательно, начиная с `0.png`, например `0.png`, `1.png` и `2.png`. Другие форматы и имена не поддерживаются.

Чтобы извлечь кадры из видео, см. [Извлечение кадров с помощью FFmpeg](./ffmpeg-frames).

### Intro

Поместите необязательные intro-кадры в `intro_frames/`. Они следуют тем же правилам именования PNG, что и обычные кадры, проигрываются один раз перед основной последовательностью и не зацикливаются.

### Упаковка файла FMA

Создайте ZIP-архив, содержащий содержимое папки. `metadata.json`, `frames/` и необязательный каталог `intro_frames/` должны находиться в корне ZIP-архива, а не внутри другой папки.

В Windows выделите содержимое `fancymenu_animation`, щёлкните правой кнопкой мыши по выделению и выберите **Отправить -> Сжатая ZIP-папка**.

Найдите получившийся ZIP-файл.

Переименуйте файл в `fancymenu_animation.fma`, заменив расширение `.zip`. Имя файла может быть другим, но расширение `.fma` обязательно.

Теперь переименованный архив готов к использованию как файл FMA.

# Использование файлов AFMA и FMA в FancyMenu

> [!IMPORTANT]
> Файлы AFMA/FMA — это анимированные текстуры, поэтому добавляйте их через вводы [**Image**](./elements#image). Почти всё, что принимает изображения, также принимает файлы AFMA и FMA.

Используйте файлы AFMA/FMA везде, где принимается изображение, включая [элементы Image](./elements#image) и [фоны меню Image](./menu-backgrounds).

Поместите файл AFMA/FMA в `<game-directory>/config/fancymenu/assets/`, чтобы он отображался во встроенном локальном выборе ресурсов FancyMenu.
