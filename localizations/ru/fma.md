# Анимации

Файлы AFMA/FMA — это специальные анимированные текстурные файлы, созданные для FancyMenu.
Они по сути почти такие же, как APNG, но гораздо лучше оптимизированы для FancyMenu.

# Файлы AFMA

FancyMenu 3.9.0 добавляет **AFMA** (Advanced FancyMenu Animation) — преемника классических файлов FMA.

Файлы AFMA больше не являются ZIP-архивами. Они используют новый формат анимации FancyMenu с меньшим размером файлов, меньшим потреблением памяти и лучшей производительностью.

Для новых больших или сложных анимированных текстур используйте **AFMA** вместо классического FMA.

Чтобы создать файл AFMA, сделайте следующее:

1. Откройте меню FancyMenu.
2. Перейдите в **Tools -> AFMA Creator**.
3. Импортируйте/конвертируйте свои кадры с помощью этого инструмента.

> [!IMPORTANT]
> Файлы AFMA нельзя упаковать вручную, как классические FMA-файлы. Для их упаковки/создания нужно использовать **AFMA Creator**.

Классические файлы FMA по-прежнему поддерживаются и были оптимизированы в FancyMenu 3.9.0, поэтому существующие макеты не нужно немедленно конвертировать.

# Классические файлы FMA

## Создание FMA

Создать файл FMA так же просто, как создать ZIP-архив! Ну, в основном потому, что внутри это _и есть_ ZIP-архив.

### Расширения файлов

Чтобы следовать этой документации, вам нужно видеть расширения файлов, поэтому перед началом обязательно **ВКЛЮЧИТЕ ОТОБРАЖЕНИЕ РАСШИРЕНИЙ ФАЙЛОВ**.

В Windows это делается так: откройте любую папку и нажмите на стрелку в правом верхнем углу, чтобы раскрыть меню ниже.

Затем перейдите на вкладку **Вид** и включите **Расширения имен файлов**.

### Подготовка

Начнем с создания новой папки для содержимого FMA-файла.
В этом примере назовем папку `fancymenu_animation`.

Внутри этой папки создайте еще две папки. Первая папка **обязательно** должна называться `frames`, а вторая папка **обязательно** должна называться `intro_frames`.

Теперь в этой же папке создайте новый TXT-файл и переименуйте его в `metadata.json`.
Пожалуйста, убедитесь, что файл по-прежнему не является TXT-файлом. Вы **должны** изменить расширение файла на `json`.

Теперь у вас должна быть папка `fancymenu_animation`, а внутри нее — папка `frames`, папка `intro_frames` и JSON-файл `metadata.json`.

### JSON-метаданные

Этот файл сообщает FancyMenu, как следует обрабатывать вашу FMA-текстуру.
Он содержит такую информацию, как время кадров (как долго кадр виден) и количество циклов.

Откройте файл `metadata.json` в текстовом редакторе.

Скопируйте в файл этот текст:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
  },
  "custom_frame_times_intro": {
  }
}
```

Это базовый шаблон того, как должен выглядеть файл.
Теперь вы можете настроить его по своему вкусу.

#### `loop_count`

Этот параметр управляет тем, сколько раз текстура должна повторяться (перезапускать свою анимацию).

Значение `0` означает бесконечный цикл. Он _никогда не остановится_.

Любое значение больше `0` означает количество проигрываний текстуры. Например, значение `1` означает, что текстура проиграется один раз, а затем остановится на последнем кадре; `2` — проиграется два раза, затем остановится на последнем кадре _и так далее_.

#### `frame_time`

Это универсальное время кадра в **миллисекундах** для кадров анимированной текстуры.
Время кадра — это то, как долго кадр виден, прежде чем анимация перейдет к следующему кадру.

#### `frame_time_intro`

По сути это то же самое, что и `frame_time`, но для кадров **intro** вашей анимированной текстуры.
Кадры intro **необязательны**, и подробнее о них вы узнаете позже.

#### `custom_frame_times`

Это **необязательный** параметр, который можно использовать для переопределения времени кадра для конкретных (не intro) кадров.
Например, вы хотите, чтобы все кадры отображались по `41` миллисекунде, поэтому задаете `frame_time` равным `41`, но первые и вторые кадры должны отображаться по `5000` миллисекунд.

В таком случае нужно сделать так:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
    0: 5000,
    1: 5000
  },
  "custom_frame_times_intro": {
  }
}
```

Нумерация кадров начинается с нуля, то есть первый кадр анимации — это `0`, второй — `1` и так далее.

В конце каждой записи `custom_frame_times` должна быть **запятая**, **кроме** последней!

#### `custom_frame_times_intro`

Это точно то же самое, что и `custom_frame_times`, но в данном случае для кадров **intro**. Кадры intro **необязательны**, и подробнее о них вы узнаете позже.

На этом всё для файла `metadata.json`. Теперь сохраните его и закройте текстовый редактор.

### Кадры

> Рекомендуется использовать **не более 200 кадров** при **максимальном разрешении 1080p** на одну анимацию, потому что анимации потребляют много памяти и это не видео. Они предназначены для коротких анимированных циклов, а не для воспроизведения полноценных видео с 24 FPS.
{.is-danger}

Кадры вашей анимированной текстуры помещаются в папку `frames`.

Кадры должны быть **PNG-ФАЙЛАМИ**! **ПОДДЕРЖКИ JPEG И ДРУГИХ ФОРМАТОВ НЕТ**!

Каждый кадр **обязательно** должен называться только номером кадра и расширением файла.
Первый кадр должен называться `0.png`, второй — `1.png`, третий — `2.png` и так далее.
Текстура **НЕ БУДЕТ РАБОТАТЬ**, если у кадров неверные имена файлов!

Чтобы **извлечь кадры из видео**, посмотрите [эту страницу документации](/ffmpeg-frames).

### Intro

Эта функция **НЕОБЯЗАТЕЛЬНА**.

Функция **intro** в файлах FMA — это особый способ проиграть несколько кадров **до** того, как начнут воспроизводиться обычные кадры из папки `frames`. 

Intro **никогда не зацикливается** и воспроизводится только в самый первый раз, когда запускается анимация. Это позволяет, например, проиграть анимацию появления перед тем, как начнется основной зацикленный фрагмент.

Кадры intro помещаются в папку `intro_frames` и работают так же, как обычные кадры:

Кадры должны быть **PNG-ФАЙЛАМИ**! **ПОДДЕРЖКИ JPEG И ДРУГИХ ФОРМАТОВ НЕТ**!

Каждый кадр **обязательно** должен называться только номером кадра и расширением файла.
Первый кадр должен называться `0.png`, второй — `1.png`, третий — `2.png` и так далее.
Текстура **НЕ БУДЕТ РАБОТАТЬ**, если у кадров неверные имена файлов!

### Упаковка файла FMA

Теперь всё важное находится в папке `fancymenu_animation`, так что можно упаковать ваш FMA-файл!

Упаковка FMA-файла по сути означает просто запаковать содержимое папки в ZIP-архив.
Содержимое должно находиться в **КОРНЕ ZIP-архива**, то есть не должно быть дополнительной папки внутри ZIP.

В Windows самый простой способ упаковать содержимое FMA в ZIP — выделить всё в папке `fancymenu_animation`, а затем **щелкнуть правой кнопкой мыши** по файлу `metadata.json`. В открывшемся контекстном меню нажмите **Отправить -> Сжатая ZIP-папка**.

Теперь в папке `fancymenu_animation` должен появиться новый ZIP-файл с названием `metadata.zip`, `frames.zip` или `intro_frames.zip`.

Конечно, часть `fancymenu_animation` можно изменить на любое другое имя, но убедитесь, что файл остается с расширением `.fma`!

Вот и всё! Теперь у вас есть (надеемся) рабочий FMA-файл!

# Использование файлов AFMA и FMA в FancyMenu

> [!IMPORTANT]
> Файлы AFMA/FMA считаются **анимированными текстурами**, поэтому их нужно добавлять через поля **Image**. Почти всё, что принимает изображения (PNG, JPEG, GIF и т. д.), также принимает файлы FMA и AFMA.

Вы можете использовать файлы AFMA/FMA как любой другой формат анимированной текстуры/изображения. FancyMenu воспринимает их как обычное изображение, поэтому их можно использовать везде, где можно назначить текстуру, например в **элементах Image или фонах меню Image**.

Убедитесь, что файл AFMA/FMA находится в папке `/config/fancymenu/assets/`, потому что FancyMenu может выбирать текстуры и другие ресурсы только из папки `assets`.
