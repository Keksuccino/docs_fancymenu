# Горячие клавиши и сочетания клавиш

В FancyMenu есть множество полезных сочетаний клавиш, которые делают работу с **редактором макета** и другими частями мода проще и эффективнее.

# Редактор макета

<br>

## CTRL + ЛКМ

Вы можете выделять несколько элементов, удерживая **CTRL** и **щелкая левой кнопкой мыши** по элементам.
Также можно **перетаскивать/перемещать несколько элементов** мышью, удерживая **CTRL**.

## SHIFT + изменение размера элемента

Удерживание SHIFT при изменении размера элементов сохранит их пропорции.

## Стрелки

Стрелки можно использовать для **перемещения** выбранных элементов с максимальной точностью.

## CTRL + A

Выбрать все элементы сразу.

## CTRL + C

**Скопировать** все выбранные элементы в буфер обмена.

## CTRL + V

**Вставить** все элементы, которые сейчас находятся в буфере обмена.
Это также работает между разными макетами, так что вы можете копировать элементы в макете A и вставлять их в макет B.

## CTRL + S

Быстро **сохранить** макет.

## CTRL + ALT + L

Быстро открыть редактор макета с последним отредактированным макетом.

## CTRL + Z

**Отменить** последнее действие.

## CTRL + Y

**Повторить** ранее отменённое действие.

## CTRL + G

Быстро переключить **сетку**.

## O

Удерживание **O** показывает наложение точки привязки, если для её видимости установлено значение **Показывать при нажатии клавиши** в **Окно -> Видимость наложения точек привязки**.

## DEL

**Удалить** все выбранные элементы.

# Текстовый редактор

<br>

## CTRL + C

**Скопировать** выделенный текст в буфер обмена.

## CTRL + V

**Вставить** текст, который сейчас находится в буфере обмена.

## CTRL + Z

**Отменить** последнее действие.

## CTRL + Y

**Повторить** ранее отменённое действие.

## CTRL + A

**Выделить** весь текст.

## CTRL + D

**Дублировать** текущую строку.

## CTRL + U

**Вырезать** выделенный текст.

## ALT + Стрелка вверх / Стрелка вниз

Переместить текущую строку вверх или вниз.

## CTRL + Home / CTRL + End

Переместить курсор в начало или конец текста.

## CTRL + G

Открыть поле **Перейти к строке**.

## CTRL + S

Подтвердить редактор, то же самое, что нажать **Готово**.

## SHIFT + Стрелки

Выделять текст при перемещении курсора.

## Стрелки

Стрелки можно использовать для перемещения курсора по тексту.

# В меню

<br>

## CTRL + ALT + C

Переключить видимость **панели меню** FancyMenu в верхней части меню.

## CTRL + ALT + R

**Перезагрузить** FancyMenu.
Это включает полную перезагрузку ресурсов/ассетов, и большинство кэшей будет очищено.

## CTRL + ALT + D

Переключить видимость **отладочного оверлея** FancyMenu.

# Окна редактирования

Многие окна редактирования FancyMenu в v3.9.0 поддерживают навигацию с клавиатуры с помощью **стрелок** и **Enter**. Во многих окнах также используется **CTRL + S** как сочетание для **Готово**, а **ESC** — как **Отмена**.

Переработанные окна Action Script Editor, Manage Requirements и Manage Variables также поддерживают контекстные меню по правому клику, поиск, отмену/повтор действий и навигацию с клавиатуры для своих списков.
