# Горячие клавиши и сочетания клавиш

**Модификатор сочетаний:** используйте `Ctrl` в Windows/Linux и `Command` в macOS, где это поддерживается.

# Редактор макетов

| Сочетание | Действие |
|---|---|
| `Ctrl/Command + левый клик` | Выбрать или перетащить несколько элементов |
| `Shift + изменение размера` | Сохранить пропорции элемента |
| Клавиши со стрелками | Точно перемещать выбранные элементы |
| `Ctrl/Command + A` | Выбрать все элементы |
| `Ctrl/Command + C` | Копировать выбранные элементы |
| `Ctrl/Command + V` | Вставить скопированные элементы, в том числе в другой макет |
| `Ctrl/Command + S` | Сохранить макет |
| `Ctrl/Command + Z` | Отменить |
| `Ctrl/Command + Y` | Повторить |
| `Ctrl/Command + G` | Показать или скрыть сетку |
| `O` | Показывать точки привязки при удержании, если для **Window -> Anchor Overlay Visibility** установлено значение **Show On Key Press** |
| `Delete` | Удалить выбранные элементы |

# Текстовый редактор

| Сочетание | Действие |
|---|---|
| `Ctrl/Command + C` | Копировать выбранный текст |
| `Ctrl/Command + V` | Вставить текст |
| `Ctrl/Command + Z` | Отменить |
| `Ctrl/Command + Y` | Повторить |
| `Ctrl/Command + A` | Выбрать весь текст |
| `Ctrl/Command + D` | Дублировать текущую строку |
| `Ctrl/Command + U` | Вырезать выбранный текст |
| `Alt + Стрелка вверх/вниз` | Переместить текущую строку |
| `Ctrl/Command + Home/End` | Перейти в начало или конец текста |
| `Ctrl/Command + G` | Открыть **Go To Line** |
| `Ctrl/Command + S` | Подтвердить редактор |
| `Shift + клавиши со стрелками` | Расширить выделение текста |
| Клавиши со стрелками | Перемещать курсор |

# Глобальные сочетания меню

Эти сочетания используют точную комбинацию `Ctrl + Alt`:

| Сочетание | Действие |
|---|---|
| `Ctrl + Alt + L` | Открыть редактор макетов с последним редактированным макетом |
| `Ctrl + Alt + C` | Включить или выключить строку меню FancyMenu |
| `Ctrl + Alt + R` | Перезагрузить FancyMenu и управляемые им ресурсы/кэши |
| `Ctrl + Alt + D` | Включить или выключить отладочный оверлей FancyMenu |

# Окна редактирования

Окна редактирования FancyMenu поддерживают навигацию с клавиатуры с помощью клавиш со стрелками и `Enter`. Во многих также используются `Ctrl/Command + S` для **Done** и `Escape` для **Cancel**.

Редакторы Action Script, Requirements и Variables также поддерживают контекстные меню по правому клику, поиск, отмену/повтор и навигацию по спискам с клавиатуры.
