# Кубические панорамы

У каждой панорамы есть свой каталог ниже:

```text
<game-directory>/config/fancymenu/panoramas/
```

`<game-directory>` — это активный экземпляр лаунчера, который может отличаться от обычного каталога `.minecraft`.

# Структура каталога

```text
<game-directory>/config/fancymenu/panoramas/
└── mypanorama/
    ├── properties.txt
    ├── overlay.png          # optional
    └── panorama/
        ├── panorama_0.png
        ├── panorama_1.png
        ├── panorama_2.png
        ├── panorama_3.png
        ├── panorama_4.png
        └── panorama_5.png
```

Шесть изображений граней должны быть PNG-файлами с точными именами, указанными выше, и все шесть должны иметь одинаковые размеры. Регистр букв в имени файла может иметь значение в некоторых операционных системах.

Добавьте необязательный `overlay.png` рядом с `properties.txt` для виньетки или другого полноэкранного наложения панорамы.

# `properties.txt`

```text
type = panorama

panorama-meta {
  name = name_of_your_panorama
  speed = 1.0
  fov = 85.0
  angle = 25.0
  start_rotation = 0
}
```

| Свойство | Значение |
|---|---|
| `name` | Обязательный, чувствительный к регистру идентификатор во время выполнения; сделайте его уникальным |
| `speed` | Множитель скорости вращения; `1.0` — значение по умолчанию |
| `fov` | Поле зрения в градусах |
| `angle` | Вертикальный угол обзора в градусах |
| `start_rotation` | Начальный горизонтальный поворот в градусах |

Требуется только `name`. Если необязательные значения отсутствуют, используются значения по умолчанию из примера. Не изменяйте `type = panorama` и `panorama-meta`; записывайте по одной паре `key = value` на строку и используйте точку для дробных чисел.

Дубликаты имён не отклоняются, и порядок сканирования каталогов определяет, какая панорама останется доступной. Делайте имена уникальными внутри каталога panoramas. Имена панорам и слайд-шоу используют отдельные списки.

# Использование панорамы

Перезагрузите FancyMenu через **Customization -> Reload FancyMenu** или перезапустите клиент. Затем щёлкните правой кнопкой мыши по фону редактора макета и выберите [**Menu Backgrounds**](./menu-backgrounds) -> **Cubic Panorama**.
