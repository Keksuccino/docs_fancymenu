# Кубические панорамы

FancyMenu поддерживает загрузку пользовательских кубов панорамы из 6 изображений в качестве фона для меню.

Эти панорамы — особый формат кубической панорамы, который Minecraft использует в качестве фона на экране заголовка; он состоит из 6 изображений (сторон), которые отображаются как куб (или, точнее, skybox).

> **ВАЖНО**: Если вы используете Windows, не забудьте включить [отображение расширений файлов](https://cdn.discordapp.com/attachments/795308330746511390/801561308012347482/unknown.png), иначе позже вы не сможете увидеть важные части имён файлов!
{.is-warning}

# Создание панорамы

Если вы не знаете, как Minecraft обрабатывает фоновые панорамы и как их создавать, посмотрите [это видео](https://www.youtube.com/watch?v=F7jMd3zsjZQ&t).
Оно даст вам очень хорошее понимание того, как работают панорамы Minecraft и как сделать свою!

После просмотра видео вы заметите, что создание таких панорам может занять довольно много времени.
Чтобы сэкономить ваше время, возможно, стоит использовать мод, который создаёт их за вас.
Некоторые из них можно найти, поискав `minecraft panorama mod`, но один из них — это [Panoramica](https://www.curseforge.com/minecraft/mc-mods/panoramica) (сделан мной).

# Подготовка панорамы

После того как вы получили 6 изображений панорамы, вам нужно переместить их в правильное место!

Каталог панорам FancyMenu находится по пути `.minecraft/config/fancymenu/panoramas`.
Это каталог для всех панорам, которые вы хотите использовать в моде.

## Папка панорамы

У каждой панорамы есть своя папка.
Вам нужно создать новую папку в `.minecraft/config/fancymenu/panoramas`, если вы хотите добавить новую панораму.
В моём примере я назову папку `mypanorama`.

![1](https://user-images.githubusercontent.com/35544624/100791916-2802d380-341a-11eb-8e32-f9913e93a38c.png)

## Содержимое папки

После создания папки вам нужно заполнить её.

### Файл свойств
Для работы каждой панорамы нужен файл свойств.
Этот файл всегда должен называться `properties.txt`, и в него нужно записать некоторую важную информацию.

Содержимое файла свойств панорамы всегда должно выглядеть так:
```
type = panorama

panorama-meta {
  name = name_of_your_panorama
  speed = 1.0
  fov = 85.0
  angle = 25.0
  start_rotation = 0
}
```
Изменять можно только переменные внутри секции `panorama-meta`!

#### name
Это должно быть **уникальное** имя вашей панорамы.
Невозможно загрузить две панорамы с одинаковым именем!
Позже вы будете использовать это имя, чтобы идентифицировать свою панораму.

#### speed
Скорость, с которой вращается ваша панорама.
Это значение является множителем скорости. Например, `1.0` — это скорость по умолчанию, `2.0` удваивает скорость, а `0.5` — уменьшает её вдвое.
Отрицательные значения не поддерживаются; используйте дробные значения, чтобы замедлить скорость.

#### fov
Угол обзора.
Стандартный FOV — `85.0`.
Слишком большие или маленькие значения здесь могут сломать панораму. Просто поэкспериментируйте, чтобы найти нужный вам FOV.

#### angle
Вертикальный угол, под которым отображается панорама.
Стандартное значение угла — `25.0`.

#### start_rotation
Угол поворота (по горизонтали), с которого должна начинаться панорама. Значение от 0 до 360.

<br>

### Папка изображений панорамы

Вторая обязательная вещь, которая нужна вашей папке панорамы, — это собственно папка с изображениями, содержащая файлы панорамы.

Имя этой папки должно быть `panorama`.

Поместите в неё все изображения панорамы, но не забудьте правильно назвать их, как показано в [видео](https://www.youtube.com/watch?v=F7jMd3zsjZQ&t) выше!

![3](https://user-images.githubusercontent.com/35544624/100791922-29340080-341a-11eb-8174-874a180d0485.png)

> В качестве изображений панорамы поддерживаются только PNG!
{.is-warning}

### Наложение панорамы

Последний шаг **необязательный** и его можно пропустить, если вам не нужно наложение поверх панорамы.

Если вы хотите добавить виньетку или другие типы наложения к вашей панораме, вы можете добавить файл с именем `overlay.png`.
Учтите, что для наложения поддерживается только PNG, и имя файла всегда должно быть `overlay.png`!

### Ещё раз всё проверьте

Теперь у вас должна быть папка по пути `.minecraft/config/fancymenu/panoramas`, содержащая файл `properties.txt`, другую папку с именем `panorama` и, возможно, наложение `overlay.png`.

![2](https://user-images.githubusercontent.com/35544624/100791920-29340080-341a-11eb-8e26-98a7fd2ad7eb.png)

# Использование панорамы

После (пере)запуска игры или перезагрузки FancyMenu через **Customization -> Reload FancyMenu** вы должны сможете установить свою панораму в качестве фона меню. Для этого щёлкните правой кнопкой мыши по фону редактора макета и нажмите **Menu Background**.
