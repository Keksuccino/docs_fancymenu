# Панорамы

Панорама — это фон, который медленно вращается вокруг вас, как на главном экране Minecraft. Она состоит из шести изображений, образующих куб вокруг зрителя.

Вы можете использовать собственные панорамы в качестве [фона меню](/menu-backgrounds) макета или вместо панорамы Minecraft во всех меню.

> [!TIP]
> Панораму с этой страницы можно бесплатно использовать для тестирования и в собственных сборках модов: [forest_homestead.zip](https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/forest_homestead.zip) (4 МБ). Распакуйте архив в `config/fancymenu/panoramas/` и перезагрузите FancyMenu.

# Создание панорамы

1. Откройте папку `panoramas` в каталоге игры `config/fancymenu/`. Команда **строка меню -> Tools -> Open FancyMenu Directory** открывает папку `config/fancymenu/`.
2. Создайте в ней папку для панорамы, например `forest_homestead`. Имя папки не имеет значения.
3. Поместите в неё файл `properties.txt` и папку `panorama` с [шестью изображениями](#шесть-изображений). Файл `overlay.png` добавлять необязательно.
4. Перезагрузите FancyMenu с помощью команды **строка меню -> Customization -> Reload FancyMenu** или сочетания клавиш `Ctrl + Alt + R` (`Cmd + Alt + R` в macOS). Также можно перезапустить игру.

```text
config/fancymenu/panoramas/
└── forest_homestead/
    ├── properties.txt
    ├── overlay.png
    └── panorama/
        ├── panorama_0.png
        ├── panorama_1.png
        ├── panorama_2.png
        ├── panorama_3.png
        ├── panorama_4.png
        └── panorama_5.png
```

# Шесть изображений

Каждое изображение — одна из сторон куба:

<img width="796" alt="Шесть изображений панорамы лесной усадьбы разложены в виде развёртки куба: верхнее изображение над передним, левое, переднее, правое и заднее изображения в ряд, нижнее изображение под передним" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/panoramas_cube.png?raw=true">

| Изображение | Сторона |
|---|---|
| `panorama_0.png` | Передняя |
| `panorama_1.png` | Правая |
| `panorama_2.png` | Задняя |
| `panorama_3.png` | Левая |
| `panorama_4.png` | Верхняя |
| `panorama_5.png` | Нижняя |

- Четыре боковые стороны располагаются вокруг вас в следующем порядке: правый край каждого изображения продолжается у левого края следующего, а правый край `panorama_3.png` соединяется с левым краем `panorama_0.png`.
- Нижний край верхнего изображения соприкасается с верхним краем переднего. Верхний край нижнего изображения соприкасается с нижним краем переднего.
- Все шесть файлов должны быть в формате PNG и иметь одинаковый размер. Используйте квадратные изображения, например 1024 × 1024 пикселя.
- FancyMenu не сглаживает изображения, поэтому пиксельная графика остаётся чёткой.

Minecraft использует для своей панорамы такую же раскладку, поэтому подойдут и панорамы, созданные для Minecraft.

# properties.txt

```text
type = panorama

panorama-meta {
  name = forest_homestead
  speed = 2.0
  fov = 85.0
  angle = 25.0
  start_rotation = 0
}
```

| Параметр | Назначение |
|---|---|
| `name` | Имя, по которому можно выбрать панораму. Каждой панораме нужно задать уникальное имя. |
| `speed` | Скорость вращения. При значении `1.0` панорама совершает полный оборот примерно за 4 минуты, а при `2.0` вращается вдвое быстрее. Значение `0` останавливает вращение. Значения выше `10.0` не увеличивают скорость. |
| `fov` | Какая часть панорамы помещается на экране; значение задаётся в градусах по вертикали. Чем меньше число, тем сильнее приближение. |
| `angle` | Угол наклона взгляда вниз в градусах. При значении `0` взгляд направлен прямо на горизонт, отрицательные значения направляют его вверх. |
| `start_rotation` | Начальное положение панорамы в градусах — от `0` до `360`. При значении `0` изображение передней стороны находится по центру. |

Обязательно указывать только `name`. Для пропущенных параметров используются значения `speed = 1.0`, `fov = 85.0`, `angle = 25.0` и `start_rotation = 0`. Не изменяйте строки `type = panorama` и `panorama-meta {`. Указывайте по одному параметру на строку и используйте точку в десятичных числах, например `1.5`.

# Наложение

Файл `overlay.png`, расположенный рядом с `properties.txt`, накладывается поверх панорамы и растягивается на весь экран. Он не вращается вместе с панорамой, поэтому подходит для таких эффектов, как виньетка, рамка или цветной фильтр. Сквозь прозрачные участки видно панораму.

# Использование панорамы

## В качестве фона меню

<img width="800" alt="Открытие раздела Menu Backgrounds, выбор Cubic Panorama в редакторе макета, включение Show Background и выбор forest_homestead в Choose Panorama; затем панорама вращается за кнопками главного экрана" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/panoramas_background.gif?raw=true">

1. В [редакторе макетов](/layout-editor) щёлкните правой кнопкой мыши по фону и откройте **Menu Backgrounds -> Cubic Panorama**.
2. Нажмите **Show Background**, чтобы включить фон.
3. Нажмите **Panorama Name**, выберите панораму и нажмите **Done**. Справа в окне предварительного просмотра будет показано, как она вращается.

Нажмите **Clear Panorama**, чтобы удалить панораму. Инструкции по сочетанию её с другими фонами см. в разделе [Фоны меню](/menu-backgrounds).

## Во всех меню

Пункт **строка меню -> Customization -> Global Customizations -> Custom Menu Background Panorama -> Choose Panorama** позволяет показывать выбранную панораму вместо панорамы Minecraft на главном экране и во всех меню до входа в мир. Подробнее: [Глобальные настройки](/global-customizations#menu-backgrounds).

## Предварительная загрузка

Большой панораме может потребоваться некоторое время, чтобы появиться при первом запуске. Чтобы загружать её во время запуска игры, добавьте её с помощью команды **Add Cubic Panorama** в разделе **строка меню -> Customization -> Pre-Load Resources**. Подробнее: [Предварительная загрузка ресурсов](/preload-layouts#pre-loading-slideshows--panoramas).

# Полезно знать

- Панорамы вращаются вправо: переднее изображение смещается влево, а справа появляется изображение правой стороны.
- Во всех меню, где используется одна и та же панорама, применяется общее положение вращения. Поэтому при переключении между такими меню она продолжает вращаться плавно. Если панорама не отображается ни в одном меню, вращение приостанавливается.
- После перезагрузки FancyMenu вращение каждой панорамы начинается заново с положения `start_rotation`.
- Панорамы относятся к загруженному [профилю](/profiles).
- Если панорамы нет в списке **Choose Panorama**, значит, она не загрузилась. В журнале игры `logs/latest.log` указана причина, например отсутствующее имя `name` или изображение.
- Фиолетовая с чёрным шахматная доска означает, что панорама ещё не выбрана, размеры её шести изображений различаются или в макете используется имя панорамы, которой больше нет.
- Если у двух панорам совпадает значение `name`, отображаться будет только одна из них.
