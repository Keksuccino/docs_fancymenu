# Значок и заголовок окна

FancyMenu позволяет изменить значок и заголовок окна Minecraft.

![настройка_окна](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# Пользовательский значок

Чтобы установить пользовательский значок, откройте [**Глобальные настройки**](/global-customizations) через меню **Настройка -> Глобальные настройки**.

![значок_окна](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- Значки должны быть в формате **PNG** (а для **macOS — ICNS**)
- Чтобы значок не отображался некорректно, в нём должен быть как минимум **1 прозрачный пиксель** (ошибка MC/LWJGL)
- Чтобы включить переключатель пользовательского значка, нужно указать допустимые файлы для всех трёх вариантов значка (16x16, 32x32 и macOS)

> [!CAUTION]
> **Ещё раз**: чтобы значок не отображался некорректно, в нём должен быть как минимум **1 прозрачный пиксель** (ошибка MC/LWJGL). Если в значке нет хотя бы одного полностью прозрачного пикселя, он будет отображаться неправильно!


# Пользовательский заголовок

Чтобы установить пользовательский заголовок, откройте [**Глобальные настройки**](/global-customizations) через меню **Настройка -> Глобальные настройки**.
