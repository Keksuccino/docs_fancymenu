# Значок и заголовок окна

FancyMenu позволяет изменять значок и заголовок окна Minecraft.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# Пользовательский значок

Чтобы установить собственный значок, откройте [**Глобальные настройки**](./global-customizations) через **Настройка -> Глобальные настройки**.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- Значки должны быть файлами **PNG** (а для macOS — **ICNS**)
- В значке должен быть как минимум **1 прозрачный пиксель**, чтобы он не отображался с искажениями (ошибка MC/LWJGL)
- Чтобы включить переключатель пользовательского значка, нужно указать корректные файлы для всех 3 версий значка (16x16, 32x32, macOS)

> [!CAUTION]
> **Снова**: в значке должен быть как минимум **1 прозрачный пиксель**, чтобы он не отображался с искажениями (ошибка MC/LWJGL). Значок будет выглядеть сломанным, если в нём нет хотя бы одного полностью прозрачного пикселя!


# Пользовательский заголовок

Чтобы установить собственный заголовок, откройте [**Глобальные настройки**](./global-customizations) через **Настройка -> Глобальные настройки**.
