# Значок и заголовок окна

FancyMenu позволяет изменить значок и заголовок окна Minecraft.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# Пользовательский значок

Чтобы установить пользовательский значок для окна Minecraft в FancyMenu 3.9.0+, откройте **Настройка -> Глобальные настройки** в **строке меню**.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- Значки должны быть файлами **PNG** (а для **macOS** — **ICNS**)
- В значках должен быть как минимум **1 прозрачный пиксель**, иначе они могут отображаться с искажениями (ошибка MC/LWJGL)
- Чтобы включить переключатель пользовательского значка, нужно указать корректные файлы для всех 3 версий значка (16x16, 32x32, macOS)

> **Ещё раз**: В значках должен быть как минимум **1 прозрачный пиксель**, иначе они могут отображаться с искажениями (ошибка MC/LWJGL). Если значок не содержит хотя бы одного полностью прозрачного пикселя, он будет выглядеть сломанным!

# Пользовательский заголовок

Чтобы установить пользовательский заголовок для окна Minecraft в FancyMenu 3.9.0+, откройте **Настройка -> Глобальные настройки** в **строке меню**.
