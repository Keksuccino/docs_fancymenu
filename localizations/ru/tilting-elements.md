# Наклон элементов

Начиная с FancyMenu v3.8.0, большинство элементов можно наклонять по вертикали и горизонтали!

Чтобы наклонить элемент, выберите его в редакторе макета. Если вы видите две линии с маркерами перетаскивания (одна вертикальная, одна горизонтальная), которые не являются границей элемента, вы можете потянуть за маркеры, чтобы наклонить элемент в нужном направлении.

Если на элементе нет линий с маркерами, его нельзя наклонять.

# Дополнительно

Также можно щёлкнуть правой кнопкой мыши по элементу, чтобы вручную задать значения наклона через прямой ввод текста. Этот способ поддерживает [плейсхолдеры](/placeholders), поэтому вы можете динамически изменять наклон элемента, комбинируя его с плейсхолдерами для получения значений переменных FancyMenu или аналогичных данных.

# Кнопки, ползунки и другие интерактивные элементы

В случае интерактивных элементов наклон тоже возможен, но он только визуальный. Например, кнопка по-прежнему будет реагировать только на щелчки внутри своей исходной области, даже если наклон частично сместил её за пределы этой области.
