# Наклон элементов

Большинство элементов можно наклонять по вертикали и горизонтали.

Выберите элемент в редакторе макета. Если наклон поддерживается, вокруг него появятся вертикальные и горизонтальные направляющие с маркерами. Перетащите маркер, чтобы наклонить элемент по этой оси.

Если на элементе нет линий с маркерами, значит, его нельзя наклонить.

# Дополнительно

Вы также можете щёлкнуть элемент правой кнопкой мыши, чтобы вручную задать значения наклона через прямой текстовый ввод. Этот прямой ввод поддерживает [placeholders](/placeholders), поэтому вы можете динамически изменять наклон элемента, комбинируя его с placeholders, чтобы получать значения переменных FancyMenu или аналогичные.

# Кнопки, ползунки и другие интерактивные элементы

Для интерактивных элементов наклон влияет только на внешний вид. Наклонённая кнопка по-прежнему принимает клики в пределах своей исходной, ненаклонённой области.
