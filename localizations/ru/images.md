# Изображения

FancyMenu поддерживает изображения во многих элементах, например в фонах меню, текстурах кнопок и многом другом.

В FancyMenu можно использовать изображения в форматах PNG, JPEG, GIF и APNG, но для статичных изображений по возможности рекомендуется использовать PNG. Для анимаций вместо GIF и APNG лучше использовать [файл AFMA](/fma) — собственный формат анимированных изображений FancyMenu. Файлы AFMA гораздо лучше оптимизированы, чем GIF/APNG, потребляют меньше оперативной памяти и оказывают меньшее влияние на производительность.

# Конвертация изображений в поддерживаемые форматы

Если вам нужно преобразовать изображения в один из форматов, поддерживаемых FancyMenu, или просто конвертировать один поддерживаемый формат в другой по какой-либо причине, воспользуйтесь приведённым ниже списком сайтов для удобной онлайн-конвертации изображений без необходимости скачивать какое-либо программное обеспечение.

## GIF в APNG
Для конвертации изображения GIF в APNG используйте этот сервис: https://ezgif.com/gif-to-apng.

## APNG в GIF
Для конвертации APNG в GIF вам понадобится этот сервис: https://ezgif.com/apng-to-gif.

## MP4 в APNG
Если вам нужно преобразовать короткий видеофрагмент в APNG, попробуйте этот сервис: https://ezgif.com/video-to-apng

## PNG в JPEG
Иногда использование JPEG позволяет уменьшить размер ресурсов, поэтому в таких случаях может быть полезно использовать JPEG вместо PNG: https://www.freeconvert.com/png-to-jpeg. Обратите внимание, что JPEG не поддерживает прозрачность.

## JPEG в PNG
Для распространённого случая конвертации JPEG в PNG попробуйте этот сервис: https://jpg2png.com/

## WebP в PNG
Файлы WebP не поддерживаются FancyMenu, поэтому их необходимо конвертировать в PNG: https://convertio.co/webp-png/

# Ограничения анимированных текстур

FancyMenu использует собственный [формат AFMA](/fma) для оптимизированных анимаций. Он позволяет [файлам AFMA](/fma) содержать множество кадров в высоком разрешении. Однако для устаревших анимированных форматов, таких как GIF и APNG, следует придерживаться приведённых ниже рекомендаций, чтобы не расходовать слишком много оперативной памяти и не снижать производительность игры:

- Используйте не более **200 кадров** в одной анимации.
- Используйте максимальное разрешение кадров **1080p**.
- Общее количество кадров во **ВСЕХ анимациях вместе** не должно превышать **1000**, поскольку в память загружаются все кадры, даже если в каждой анимации используется не более 200 кадров. Поэтому слишком большое количество анимаций одновременно всё равно может заполнить оперативную память.

> [!IMPORTANT]
> Эти ограничения НЕ распространяются на [файлы AFMA](/fma), поскольку AFMA не загружает все кадры в память и значительно лучше оптимизирован. Поэтому такие файлы оказывают меньшее влияние на производительность, чем устаревшие типы анимаций.
