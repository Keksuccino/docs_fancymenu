# Экспорт для ИИ

**Экспорт для ИИ** преобразует часть настроек FancyMenu в текст, подготовленный для ИИ-помощников, например Alice — бота-помощника на [сервере FancyMenu в Discord](https://discord.gg/rhayah27GC). Вставьте его в чат, и ИИ увидит, как именно всё настроено, вместо того чтобы гадать.

<img width="800" alt="Сообщение в Discord: Alice просит экспорт, находит в нём проблему и помогает игроку исправить кнопку" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/export_for_ai_chat.gif?raw=true">

# Зачем это нужно

Снимок экрана показывает, как что-то выглядит, но не то, как оно настроено. Вручную описывать скрипт действий или условие долго, и именно важная деталь часто теряется по пути.

В экспорте есть всё необходимое ИИ:

- Все настройки, действия, условия и значения того, что вы экспортируете.
- Версии FancyMenu, Minecraft, загрузчика модов, Java и вашей системы.
- Краткие объяснения принципов работы FancyMenu, чтобы ИИ правильно понял данные.

Экспорт всегда создаётся на английском языке, независимо от того, на каком языке вы играете. Имя вашей учётной записи в путях к файлам заменяется на `<user>`, поэтому экспорт можно публиковать в открытых чатах.

# Когда это пригодится

- Что-то работает не так, как должно: например, кнопка ничего не делает или элемент никогда не появляется.
- FancyMenu показывает ошибку или предупреждение.
- Вы хотите помочь с созданием чего-либо: например, скрипта действий, условия или целого меню.
- Вы хотите узнать, что можно сделать в игре. Раздел **Всё, на что способен FancyMenu** содержит список всех доступных вам элементов, фонов, действий, условий, заполнителей и слушателей, в том числе добавленных дополнениями.

Экспортируйте только то, чего касается ваш вопрос, например одну неработающую кнопку. Чем меньше экспорт, тем проще ИИ сосредоточиться. Затем расскажите ему, чего вы ожидали и что произошло на самом деле.

# Как экспортировать

Каждый из перечисленных ниже пунктов открывает небольшое меню:

- **Копировать в буфер обмена** копирует экспорт, чтобы вы могли вставить его в чат с помощью `Ctrl + V` (`Cmd + V` в macOS).
- **Сохранить как файл** сохраняет экспорт в виде файла Markdown в `<game-directory>/fancymenu_data/ai_exports/` и открывает эту папку, чтобы вы могли перетащить файл в чат. Используйте этот вариант для больших экспортов, которые не помещаются в сообщение.

Экспорт из редактора макетов, а также из окон слушателей и планировщиков включает несохранённые изменения.

# Где можно экспортировать

## Строка меню

| Что экспортируется | Где найти |
|---|---|
| Текущий экран, его виджеты и действия FancyMenu на нём | **строка меню -> Настройка -> Экспортировать текущий экран для ИИ** |
| Макет | **строка меню -> Настройка -> Макеты**, выберите макет, затем **Экспортировать макет для ИИ** |
| Информация об игре, оборудовании и модах, а также о возможностях FancyMenu, например поддержке видео и браузера | **строка меню -> Справка -> Экспорт для ИИ -> Сведения о системе** |
| Все настройки FancyMenu, включая [глобальные настройки](/global-customizations) | **строка меню -> Справка -> Экспорт для ИИ -> Настройки FancyMenu** |
| Все [переменные](/variables) | **строка меню -> Справка -> Экспорт для ИИ -> Все переменные** |
| Все [слушатели](/listeners) | **строка меню -> Справка -> Экспорт для ИИ -> Все слушатели** |
| Все [планировщики](/schedulers) | **строка меню -> Справка -> Экспорт для ИИ -> Все планировщики** |
| Все [пользовательские GUI](/custom-guis) | **строка меню -> Справка -> Экспорт для ИИ -> Пользовательские GUI** |
| Все [профили](/profiles) | **строка меню -> Справка -> Экспорт для ИИ -> Профили** |
| Все элементы, фоны, действия, условия, заполнители и слушатели, доступные в вашей игре | **строка меню -> Справка -> Экспорт для ИИ -> Всё, на что способен FancyMenu** |

## Редактор макетов

| Что экспортируется | Где найти |
|---|---|
| Макет, который вы редактируете | **Макет -> Экспортировать макет для ИИ** в строке меню редактора |
| Другой макет этого экрана | **Макет -> Открыть** в строке меню редактора, выберите макет, затем **Экспортировать макет для ИИ** |
| Один элемент | Щёлкните элемент правой кнопкой мыши, затем выберите **Экспорт для ИИ** |
| Все выбранные элементы | **Правка -> Экспортировать выбранные элементы для ИИ** в строке меню редактора |
| [Фон меню](/menu-backgrounds) | Щёлкните фон редактора правой кнопкой мыши, затем выберите **Фоны меню**, выберите фон, затем **Экспорт для ИИ** |
| [Декоративный оверлей](/decoration-overlays) | Щёлкните фон редактора правой кнопкой мыши, затем выберите **Декоративные оверлеи**, выберите оверлей, затем **Экспорт для ИИ** |

## Редакторы и окна

| Что экспортируется | Где найти |
|---|---|
| [Скрипт действий](/action-scripts) | Щёлкните правой кнопкой мыши в редакторе скриптов действий, затем выберите **Экспортировать скрипт действий для ИИ** |
| [Условия](/conditions) | Щёлкните правой кнопкой мыши в окне **Управление условиями**, затем выберите **Экспортировать условия для ИИ** |
| Текст, например содержимое текстового элемента | Щёлкните правой кнопкой мыши в текстовом редакторе, затем выберите **Экспортировать текст для ИИ** |
| Одну переменную или все переменные | Откройте **строка меню -> Настройка -> Управление переменными**, щёлкните правой кнопкой мыши, затем выберите **Экспортировать переменную для ИИ** или **Экспортировать все переменные для ИИ** |
| Один слушатель или все слушатели | Откройте **строка меню -> Настройка -> Управление слушателями**, нажмите **Экспорт для ИИ**, затем выберите **Выбранный слушатель** или **Все слушатели** |
| Один планировщик или все планировщики | Откройте **строка меню -> Настройка -> Управление планировщиками**, нажмите **Экспорт для ИИ**, затем выберите **Выбранный планировщик** или **Все планировщики** |

## Ошибки и предупреждения

Когда FancyMenu показывает ошибку или предупреждение, нажмите **Экспорт для ИИ** рядом с **ОК**, чтобы экспортировать сообщение.

## Серверы

Настройки [FMData](/fm-data) сервера, включая его серверные слушатели и приветственные данные, можно экспортировать с помощью команды. Для этого нужен уровень разрешений 2, как и для всех команд `/fmdata`.

```mcfunction
/fmdata export_for_ai copy
/fmdata export_for_ai file
```

- `copy` отправляет сообщение в чат. Нажмите на него, чтобы скопировать экспорт. В консоли сервера вместо этого отображается весь экспорт.
- `file` сохраняет экспорт на сервере в `fancymenu_data/ai_exports/`. Используйте этот вариант, если экспорт слишком большой для чата.
