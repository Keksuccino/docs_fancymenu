# Фоновая музыка меню

FancyMenu позволяет отключить музыку меню Vanilla, воспроизводить общий список треков или использовать [аудиоэлементы](/elements#audio) для музыки, зависящей от макета.

# Общая музыка меню

Откройте [**Глобальные настройки**](/global-customizations) через меню **Настройка -> Глобальные настройки** вне редактора макетов.

Используйте следующие настройки:

- **Воспроизводить музыку меню Vanilla** включает или отключает музыку меню Vanilla во всём интерфейсе.
- **Пользовательские музыкальные треки меню** позволяет управлять общим списком заменяющих треков.

> [!IMPORTANT]
> Общие пользовательские треки меню воспроизводятся только тогда, когда мир не загружен, например на экране заголовка. Для воспроизведения звука в меню внутри мира используйте элемент [**Аудио**](/elements#audio).

Общие треки используют канал звука «Музыка». Первый трек начинает воспроизводиться примерно через пять секунд; для последующих треков используется случайная задержка от одной до тридцати секунд. Треки выбираются случайным образом; если настроено больше одного трека, предыдущий трек не повторяется сразу.

# Управление музыкой на отдельных экранах

Добавьте в макет элемент [**Контроллер музыки**](/elements#music-controller), чтобы управлять музыкой Vanilla на этом экране:

1. Щёлкните правой кнопкой мыши по фону редактора.
2. Выберите **Новый элемент -> Контроллер музыки**.
3. Настройте музыку меню и музыку мира по отдельности.

Для элемента поддерживаются [условия загрузки](/conditions).

Если отключить музыку меню с помощью контроллера музыки, общий список пользовательских треков меню также не будет воспроизводиться на этом экране.

# Пользовательская музыка с помощью аудиоэлементов

Используйте элемент [**Аудио**](/elements#audio), если вам нужно:

- Разная музыка на разных экранах.
- Музыка на экранах внутри мира.
- Требования к макету, плейлисты с заданным порядком, настройки перемешивания, громкости или канала.

Разместите [аудиоэлемент](/elements#audio) в [универсальном макете](/universal-layouts), чтобы один и тот же проигрыватель оставался активным на поддерживаемых экранах, загружающих этот макет. На каждом обычном экране, где должен применяться универсальный макет, необходимо включить настройку экрана.
