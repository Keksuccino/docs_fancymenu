# Видимость элементов

Элементы не обязательно должны отображаться постоянно. Их можно показывать только в определённых ситуациях, с небольшой задержкой, с эффектом плавного появления и исчезновения или включать и выключать кнопкой.

<img width="800" alt="Приветственный текст плавно появляется через несколько секунд после открытия экрана, затем кнопка «Правила сервера» плавно показывает и скрывает панель с правилами" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/element_visibility_toggle.gif?raw=true">

В редакторе макетов элементы отображаются всегда, чтобы вы могли их редактировать. Всё, о чём рассказывается на этой странице, работает вне редактора.

> [!TIP]
> Полный список требований приведён в разделе [Требования](/conditions).

# Показ элементов только в определённых случаях

Щёлкните элемент правой кнопкой мыши и выберите **Требования для отображения**. Элемент будет отображаться, только пока выполняются все его [требования](/conditions), например «курсор находится над этой кнопкой», «сейчас декабрь» или «переменная имеет это значение». FancyMenu постоянно проверяет требования, поэтому элемент сразу появляется и скрывается при изменении условий.

- **Режим требования** «Обратное» меняет требование на противоположное, например «НЕ декабрь».
- Группы позволяют задать условие «это ИЛИ то».
- У ванильных элементов тоже есть **Требования для отображения**. Чтобы полностью удалить такой элемент, см. раздел [Удалённые ванильные элементы](/deleted-vanilla-elements).

Как добавлять и объединять требования: [Требования](/conditions#adding-a-requirement).

## Загружать один раз за сеанс

Щёлкните элемент правой кнопкой мыши и включите **Загружать один раз за сеанс**. Элемент появится при первом открытии экрана. Когда игрок перейдёт на другой экран, элемент останется скрытым до перезапуска игры.

Это удобно для подсказок, которые должны показываться только один раз за запуск игры, например «Нажмите F1, чтобы увидеть управление». Для использования того же принципа в сценариях действий есть требование [**Только один раз за сеанс**](/conditions#only-once-per-session).

# Задержка показа элементов

## Задержка появления

Щёлкните элемент правой кнопкой мыши и выберите **Задержка появления**:

- **Задержка**:
  - **Без задержки**: элемент появляется сразу.
  - **Только при первом появлении**: задержка применяется только при первом появлении элемента после запуска игры.
  - **Каждый раз**: задержка применяется при каждом открытии экрана и при каждом повторном выполнении требований.
- **Задержка в секундах**: сколько ждать, например `1.5`.

Изменение размера окна не запускает задержку заново.

## Задержка исчезновения

Щёлкните элемент правой кнопкой мыши и выберите **Задержка исчезновения**. Когда требования перестанут выполняться, элемент будет отображаться ещё **Задержка в секундах**, а затем исчезнет. Для параметра **Задержка** доступны те же варианты, что и выше.

Например, информационный блок с требованием [**Курсор над элементом**](/conditions#is-element-hovered) для кнопки будет оставаться на экране ещё 1 секунду после того, как курсор покинет кнопку.

# Плавное появление и исчезновение

Щёлкните элемент правой кнопкой мыши и выберите **Плавное появление/исчезновение**:

- **Плавное появление** и **Плавное исчезновение**:
  - **Без эффекта**: элемент сразу появляется или скрывается.
  - **Только один раз**: эффект применяется только при первом появлении после запуска игры.
  - **Каждый раз**: эффект применяется каждый раз.
- **Скорость появления** и **Скорость исчезновения**: при значении `1` плавный переход занимает 2,5 секунды. Значение `2` ускоряет его вдвое.

Элементы плавно появляются при открытии экрана и при выполнении требований. Если задана **Задержка появления**, эффект начинается после задержки.

Плавное исчезновение происходит только тогда, когда элемент скрывается из-за требований, но не при закрытии экрана.

# Прозрачность

Щёлкните элемент правой кнопкой мыши и выберите **Прозрачность**: `1.0` — элемент полностью виден, `0.5` — наполовину прозрачный, `0.0` — невидимый. Этот параметр есть у большинства элементов.

В качестве значения прозрачности можно использовать [подстановки](/placeholders) и [переменные](/variables), например `$$panel_opacity`. При плавном появлении элемент не станет прозрачнее заданного значения.

# Переключение элементов кнопкой

Кнопка может показывать и скрывать элементы, например панель с правилами на GIF выше. [Переменная](/variables) хранит информацию о том, отображается ли панель.

1. Щёлкните панель правой кнопкой мыши и выберите **Требования для отображения**. Добавьте [**Значение переменной (переменная FM)**](/conditions#is-variable-value-fm-variable) с переменной `show_rules` и значением `true`.
2. Щёлкните кнопку правой кнопкой мыши и выберите **Редактировать сценарий действий**.
3. Щёлкните правой кнопкой мыши область сценария и выберите **Добавить оператор IF**. Добавьте то же требование, что и для панели.
4. Внутри IF добавьте [**Задать значение переменной (переменная FM)**](/action-scripts#set-variable-value-fm-variable) со следующим значением:

   ```
   show_rules:false
   ```

5. Щёлкните IF правой кнопкой мыши и выберите **Добавить оператор ELSE**. Внутри ELSE добавьте **Задать значение переменной (переменная FM)** со следующим значением:

   ```
   show_rules:true
   ```

При каждом нажатии значение переменной меняется на противоположное: отображаемые панели скрываются, а скрытые — появляются. Все элементы с одинаковым требованием будут появляться и скрываться одновременно. Для плавного перехода задайте для панели значения **Каждый раз** в параметрах **Плавное появление** и **Плавное исчезновение**.

Подробнее об IF и ELSE: [Сценарии действий](/action-scripts#if-else-if-and-else).

> [!NOTE]
> Переменные сохраняются после закрытия игры, поэтому при следующем запуске панель останется открытой. Чтобы она закрывалась при каждом запуске, щёлкните переменную правой кнопкой мыши в разделе **Управление переменными** и включите **Очищать переменную при запуске игры**.

## Переключение между вариантами

Кнопка также может переключаться между более чем двумя вариантами, например между тремя фонами:

1. В меню **Панель меню -> Настройка -> Управление переменными** добавьте текстовую переменную `background` со значением `0`.
2. Задайте для трёх [элементов изображения](/elements#image) требование **Значение переменной (переменная FM)** для переменной `background`, указав значения `0`, `1` и `2`.
3. Для кнопки задайте действие **Задать значение переменной (переменная FM)** со следующим значением. Оно циклически меняется между `0`, `1` и `2`, а затем снова начинается с `0`:

   ```
   background:{"placeholder":"calc","values":{"decimal":"false","expression":"({"placeholder":"getvariable","values":{"name":"background"}} + 1) % 3"}}
   ```

Чтобы добавить больше вариантов, измените последнюю цифру `3`. Подробнее о вычислениях см. раздел [**Калькулятор**](/placeholders#calculator).

# Включение и выключение макетов

Чтобы показать или скрыть весь макет:

- **Требования для отображения [для всего макета]** в контекстном меню фона редактора работают так же, как требования для элементов. См. раздел [Требования для всего макета](/conditions#layout-wide-requirements).
- Действия [**Переключить макет**](/action-scripts#toggle-layout), [**Включить макет**](/action-scripts#enable-layout) и [**Выключить макет**](/action-scripts#disable-layout) включают и выключают макет по его имени.

Разместите кнопку в другом макете, а не в том, который она выключает. Иначе кнопка исчезнет вместе с ним, и включить макет снова будет нечем.
