# Переключение частей макетов

Иногда приятно иметь выбор! Возможно, некоторым вашим пользователям не нравится постоянно слышать Rick Astley в качестве музыки меню или хочется другого милого аниме-девочки на фоне меню.

Что ж, это не проблема! Вы можете сделать так, чтобы пользователи могли включать и выключать части ваших макетов или переключаться между несколькими версиями этих частей.

# Включение и выключение

Чтобы переключать, например, видимость элемента по нажатию кнопки, вам нужно использовать переменную, которая устанавливается при нажатии кнопки, а элемент, который вы хотите переключать, должен проверять в своих требованиях к загрузке, имеет ли эта переменная нужное значение.

## Переменная

Первое, что нужно сделать, — создать переменную, в которой будет храниться состояние видимости элемента, который вы хотите переключать.

Чтобы добавить новую переменную, перейдите на вкладку **Customization** в строке меню и нажмите **Variables -> Manage Variables**, затем добавьте новую переменную с **уникальным** именем! Убедитесь, что используете действительно **уникальное** имя, которое ещё не занято.

После создания переменной установите её значение в `true`.

<br>
<img width="494" alt="Screenshot_9" src="https://gist.github.com/assets/35544624/1e29be13-e601-4669-8fa2-d78db945b07f">

## Элемент

Следующий шаг — добавить элемент, который вы хотите включать и выключать.

<br>
<img width="270" alt="Screenshot_3" src="https://gist.github.com/assets/35544624/317460fc-310b-4941-ab9a-b56490c5ebb9">

Теперь щёлкните по элементу правой кнопкой мыши и нажмите **Loading Requirements**.
Это откроет экран Manage Requirements. Нажмите **Add Requirement**.

Найдите требование **Is Variable Value**, выберите его и нажмите **Edit Requirement Value**.

<br>
<img width="501" alt="Screenshot_1" src="https://gist.github.com/assets/35544624/d0d342f5-617c-415e-b6f7-05087fc204b7">

Теперь введите имя переменной, которую вы создали ранее, и укажите, чтобы требование проверяло значение `true`.

<br>
<img width="500" alt="Screenshot_2" src="https://gist.github.com/assets/35544624/a1f356e9-7f96-4d8b-87b0-51f05898409a">

На этом всё для этой части. Теперь ваш элемент будет видим, когда значение переменной равно `true`.

## Кнопка

Теперь нам нужно добавить новый элемент Button.

<br>
<img width="270" alt="Screenshot_4" src="https://gist.github.com/assets/35544624/1bd1b781-0cdb-4b52-80a0-db8f44ead0db">

После добавления щёлкните по нему правой кнопкой мыши и нажмите **Edit Action Script**.
Это откроет экран Manage Action Script для кнопки.

Нажмите **Add IF Statement**, добавьте к нему требование **Is Variable Value** и установите для него режим **OPPOSITE**.

<br>
<img width="520" alt="Screenshot_5" src="https://gist.github.com/assets/35544624/a024ea21-2244-4ca6-b44b-1a80f7936b8f">

Теперь нажмите **Edit Requirement Value**, как вы делали это ранее для элемента, и просто введите то же самое имя переменной и то же значение, которое нужно проверять.

<br>
<img width="500" alt="Screenshot_2" src="https://gist.github.com/assets/35544624/a1f356e9-7f96-4d8b-87b0-51f05898409a">

Поскольку мы установили режим требования в **OPPOSITE**, теперь будет проверяться, что значение переменной НЕ равно `true`, а именно это нам и нужно.

Вернувшись на экран Edit Action Script, вы увидите только что добавленное IF-условие.

<br>
<img width="495" alt="Screenshot_6" src="https://gist.github.com/assets/35544624/6ac8444c-ca15-43ff-a633-df63e76e7433">

Теперь нажмите **Add Action**, найдите действие **Set Variable Value**, выберите его и затем нажмите **Edit Action Value**.

<br>
<img width="494" alt="Screenshot_7" src="https://gist.github.com/assets/35544624/8568e539-b4d0-49bd-89c4-4659ee71754c">

В качестве значения действия сначала введите имя вашей переменной, а затем значение, которое хотите ей присвоить. Разделяйте имя и значение символом `:`.
В этом случае мы хотим установить значение `true`, потому что это действие позже выполняется, когда значение НЕ равно `true`.

<br>
<img width="496" alt="Screenshot_8" src="https://gist.github.com/assets/35544624/fab440ad-b335-4751-9651-4bb0b65bc968">

Теперь добавьте действие в IF-условие, перетащив его поверх IF-условия, чтобы оно выполнялось только тогда, когда значение нашей переменной НЕ равно `true`.

<br>
<img width="496" alt="Screenshot_8" src="https://gist.github.com/assets/35544624/d1ac3ea9-44d7-4ad6-a4b2-455b21f6d1c4">

После этого выберите IF-условие, а затем нажмите **Append ELSE Statement**.

Теперь добавьте ещё одно действие **Set Variable Value**, но вместо установки значения переменной в `true` установите его в `false`.

<br>
<img width="494" alt="Screenshot_9" src="https://gist.github.com/assets/35544624/d05400dc-b9b7-4c1a-8657-9e34939ed599">

Теперь добавьте второе действие в ELSE-условие, чтобы оно выполнялось, если значение переменной РАВНО `true`.

<br>
<img width="494" alt="Screenshot_9" src="https://gist.github.com/assets/35544624/3191a1cc-c5c2-4cf1-a620-23bdbe639bf2">

Вот и всё! Сначала это может показаться большим количеством шагов, но на самом деле после небольшой практики это довольно простая и быстрая вещь.

Теперь вы можете сохранить макет, выйти из редактора и нажать кнопку, чтобы проверить, работает ли всё как надо!

<br>
<img width="494" alt="Screenshot_9" src="https://gist.github.com/assets/35544624/e9a87aca-ba0f-4ce6-a39e-1e1d3796c9e3">

Не стесняйтесь использовать ту же переменную для других элементов, чтобы по нажатию кнопки **переключать несколько элементов одновременно**.

Вы даже можете переключать целые макеты, используя **Layout-Wide Loading Requirements**. Чтобы настроить требования для всего макета, щёлкните правой кнопкой мыши по фону редактора. Только не забудьте добавить кнопку в другой макет, а не в тот, который вы хотите переключать.
