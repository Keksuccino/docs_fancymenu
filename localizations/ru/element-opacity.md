# Непрозрачность элементов

Большинство элементов в FancyMenu (за некоторыми исключениями) поддерживают установку прозрачности через контекстное меню по щелчку правой кнопкой мыши.

Значение непрозрачности элементов поддерживает плейсхолдеры, что позволяет динамически обновлять их непрозрачность в зависимости от плейсхолдера.

Это позволяет создавать собственную логику плавного исчезновения и появления при использовании вместе с элементами Ticker для обновления значений переменных, а затем применять их как непрозрачность через плейсхолдеры.

Чтобы задать непрозрачность элементов, **щелкните элемент правой кнопкой мыши -> Непрозрачность -> Установить**.

# Плавное появление/исчезновение элементов

Если вы просто хотите, чтобы элементы плавно появлялись или исчезали, вероятно, проще использовать встроенную функцию плавного перехода элементов. Её можно включить в контекстном меню элементов по правому клику.

Эта функция заставляет элементы плавно появляться каждый раз при загрузке — будь то начальная загрузка при открытии меню или момент, когда элемент загружается из-за своих условий загрузки. Они будут плавно исчезать всякий раз, когда их условия загрузки вызывают их выгрузку/скрытие.

Функция плавного перехода поддерживает настройку скорости, чтобы контролировать, насколько быстро элемент должен появляться или исчезать.
