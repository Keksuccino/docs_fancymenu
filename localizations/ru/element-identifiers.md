# Идентификаторы элементов

У каждого элемента в FancyMenu есть уникальный идентификатор, который автоматически назначается ему при создании.

Эти идентификаторы используются, ну, для идентификации элемента, чтобы другие части FancyMenu, такие как плейсхолдеры, действия и требования к загрузке, могли взаимодействовать с этим элементом.

# Получение идентификатора элемента

Чтобы получить идентификатор элемента, если он нужен вам где-то ещё, просто **щёлкните правой кнопкой мыши** по элементу в редакторе и нажмите **Копировать идентификатор элемента**. После этого идентификатор элемента будет скопирован в буфер обмена, и вы сможете легко вставить его туда, где он вам нужен.
