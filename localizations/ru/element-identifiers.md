# Идентификаторы элементов

Каждому элементу в FancyMenu при создании автоматически присваивается уникальный идентификатор.

Идентификаторы используются для определения элементов, чтобы другие компоненты FancyMenu, например плейсхолдеры, действия и требования загрузки, могли взаимодействовать с ними.

# Как узнать идентификатор элемента

Чтобы узнать идентификатор элемента, щёлкните его правой кнопкой мыши в редакторе и выберите **Copy Element ID**. Идентификатор будет скопирован в буфер обмена, и вы сможете вставить его куда нужно.
