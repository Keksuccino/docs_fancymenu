# Команды

FancyMenu добавляет в игру несколько команд, которые могут быть очень полезны при использовании вместе с другими модами, например FTB Quests.

> [!WARNING]
> Чтобы использовать команды в многопользовательской игре, FancyMenu должен быть установлен на **СЕРВЕРЕ** (и на клиенте)!

## Целевые игроки и права доступа

Аргумент целевого игрока в `/openguiscreen`, `/closeguiscreen` и `/fmlayout` необязателен. Если игрок не указывает его, команда применяется к этому игроку. Если цель указана, можно использовать обычные имена игроков и селекторы, такие как `@a`.

- Указание аргумента цели для `/openguiscreen` или `/closeguiscreen` требует **уровня прав 2** (Game Master / уровень OP 2), даже если он указывает на источник команды.
- Указание аргумента цели для `/fmlayout` требует **уровня прав 3** (Admin / уровень OP 3), даже если он указывает на источник команды.
- Каждый подкомандой `/fmdata` требует **уровня прав 2** (Game Master / уровень OP 2).

Для всех трёх команд с необязательной целью пропуск аргумента цели работает только тогда, когда источником команды является игрок. Консоль сервера должна указать цель и соответствовать требованию по правам для аргумента цели.

## /openguiscreen

Команда `/openguiscreen` открывает ванильный экран, экран мода или [пользовательский GUI](./custom-guis). Она может воздействовать на других игроков, если FancyMenu установлен на сервере и у клиентов.

См. [Открытие GUI по команде](./opengui-command) и [Идентификаторы экранов](./screen-identifiers).

Не каждый экран мода можно создать напрямую. FancyMenu показывает ошибку, если целевой экран не поддерживается. В локальном макете используйте [**Кнопку Mimic Vanilla/Mod**](./action-scripts#mimic-vanillamod-button-mimicbutton) на виджете, который обычно открывает этот экран.

**Использование:** `/openguiscreen <screen_identifier> [<target_players>]`

## /closeguiscreen

Команда `/closeguiscreen` закрывает текущий экран для источника команды или выбранных игроков. Она полезна с модами квестов, событий или автоматизации, которые могут выполнять команды.

**Использование:** `/closeguiscreen [<target_players>]`

## /fmlayout

Команда `/fmlayout` включает или отключает макет на одном или нескольких клиентах. Используйте имя макета точно так, как оно отображается в FancyMenu, а имена с пробелами заключайте в кавычки.

**Использование:** `/fmlayout <layout_name> <true|false> [<target_players>]`

Примеры:

- `/fmlayout quest_complete true` включает `quest_complete` для игрока, который выполняет команду.
- `/fmlayout quest_complete false @a` отключает его для всех игроков онлайн. Указание аргумента цели требует уровень прав 3.

## /fmvariable

Команда `/fmvariable` задаёт и читает [переменные FancyMenu](./variables).

Чтобы выполнить эту команду от имени другого игрока, используйте ванильную команду `/execute as`:
`/execute as ExamplePlayer run fmvariable ...`

**Использование:**

- `/fmvariable get <variable_name>`
- `/fmvariable set <variable_name> <send_chat_feedback> <set_to_value>`

### Получение

Чтобы **получить значение переменной**, используйте подкоманду `get` так:
`/fmvariable get some_variable`

Затем значение этой переменной будет выведено в ваш чат.

### Установка

Чтобы **установить переменную**, укажите булевый параметр обратной связи в чат перед новым значением:
`/fmvariable set some_variable true new_value`

Аргумент `send_chat_feedback` управляет тем, будет ли FancyMenu подтверждать изменение в чате. Аргумент `set_to_value` захватывает остаток команды, поэтому значение может содержать пробелы. Например, `/fmvariable set greeting false Hello from FancyMenu` сохранит `Hello from FancyMenu` без сообщения об успешном выполнении.

## /fmdata

Команда `/fmdata` отправляет пользовательские данные между сервером и клиентами FancyMenu, управляет серверными слушателями и настраивает данные, которые отправляются при входе игроков. Каждый подкомандой `/fmdata` требует уровень прав 2.

См. [FM Data](./fm-data) для всех подкоманд, синтаксиса и примеров.
