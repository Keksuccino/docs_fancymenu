# Команды

FancyMenu добавляет в игру несколько команд, которые могут быть очень полезны в сочетании с другими модами, например FTB Quests.

> Для использования команд в многопользовательской игре FancyMenu должен быть установлен на **СЕРВЕРЕ** (и у клиента)!
{.is-warning}

## /openguiscreen

Команда `/openguiscreen` позволяет открыть GUI (ванильный/модовый и пользовательский интерфейсы).
Она даже может удалённо открывать GUI для других игроков, если FancyMenu установлен и на сервере, и у клиентов.

Более подробное описание этой команды см. на странице [Открытие GUI по команде](/opengui-command).

Эта команда работает не для каждого экрана, особенно для экранов модов. Если команде не удастся открыть экран, будет показана ошибка. В таком случае сделать почти ничего нельзя, потому что, скорее всего, это экран, который слишком сложен для автоматического открытия FancyMenu.

Я также больше не буду вручную добавлять совместимость для экранов модов, потому что добавление поддержки для всех существующих модов заняло бы у меня вечность, извините.

**Использование:** `/openguiscreen <screen_identifier> <target_player>`

## /closeguiscreen

Команда `/closeguiscreen` позволяет закрыть текущий GUI.

Что? Вы скажете, это совершенно бесполезно?
Ну да, но вообще-то нет.

Эта команда полезна, если вы используете моды, которые запускают команды при определённых действиях.
Так что да, без других модов эта команда действительно совершенно бесполезна, но может быть очень полезной, если у вас установлены нужные моды!

**Использование:** `/closeguiscreen <target_player>`

## /fmvariable

Команда `/fmvariable` позволяет устанавливать и получать переменные FancyMenu.

Чтобы выполнить эту команду от имени другого игрока на сервере, можно использовать стандартную команду `/execute as`.
Например, если вы хотите выполнить команду `/fmvariable` от имени игрока `ExamplePlayer`, введите:
`/execute as ExamplePlayer run fmvariable...`.

**Использование:** `/fmvariable <get_or_set> <variable_name> [<set_to_value>] [<send_chat_feedback>]`

### Получение
Чтобы **получить значение переменной**, используйте подкоманду `get` вот так:
`/fmvariable get some_variable`

Затем значение этой переменной будет выведено в ваш чат.

### Установка
Чтобы **установить переменную**, используйте подкоманду `set` вот так:
`/fmvariable set some_variable new_value true`

Последний аргумент здесь задаёт, хотите ли вы получать обратную связь в чате, то есть нужно ли этой команде выводить сообщения в ваш чат.
