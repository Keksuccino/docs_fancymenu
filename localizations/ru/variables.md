# Переменные в FancyMenu

Переменные — это мощная функция FancyMenu, которая позволяет хранить и повторно использовать информацию во всех настройках вашего меню. Они работают как контейнеры: в них можно помещать данные разных типов, присваивать каждому контейнеру имя, а затем получать доступ к этим данным позже по имени переменной. Переменные открывают массу возможностей для создания динамических меню, которые меняются в зависимости от заданных вами условий.

## Создание переменных

Чтобы создать переменную в FancyMenu:

1. Убедитесь, что вы сейчас не находитесь в редакторе макета. 
2. Нажмите на строку меню в верхней части экрана.
3. Перейдите в **Customization -> Variables -> Manage Variables**.
4. В открывшемся окне «Manage Variables» нажмите кнопку **Add Variable**.
5. Введите имя для новой переменной и нажмите **OK**.

Готово! Ваша переменная готова к использованию. Вы увидите её в списке в окне «Manage Variables».

В FancyMenu 3.9.0 окно Manage Variables было переработано. Важные действия доступны через контекстное меню по правому клику, список поддерживает навигацию с клавиатуры, переменные можно копировать и вставлять, изменения можно отменять и повторять, ввод текста запускает поиск, **DEL** удаляет выбранную переменную, а **CTRL + S** подтверждает окно.

## Установка значений переменных

Пустая переменная сама по себе не очень полезна. Чтобы переменные работали на вас, нужно записывать в них данные. В FancyMenu это называется «установка значения переменной». 

Есть два основных способа задать значение переменной:

1. В окне «Manage Variables» найдите переменную в списке, нажмите на неё, а затем нажмите **Set Value**. Введите данные, которые хотите сохранить.

2. При настройке меню используйте действие **Set Variable** для элемента Button, Slider или Ticker. В этом действии вы указываете имя переменной и значение, которое нужно в неё сохранить. Когда кто-то, например, нажимает кнопку с этим действием, значение переменной обновится на новое.

Например, допустим, вы создаёте переменную с именем `clicks`, чтобы считать, сколько раз была нажата кнопка. Вы добавили бы действие **Set Variable** к кнопке и использовали бы плейсхолдер в значении действия, чтобы увеличивать счётчик кликов каждый раз, например так:

```
clicks:{"placeholder":"calc","values":{"expression":"{"placeholder":"getvariable","values":{"name":"clicks"}} + 1"}}
```

Вот как это работает:
1. Плейсхолдер **Get Stored Variable** получает текущее значение переменной `clicks`.
2. Плейсхолдер **Calculator** берёт это значение и прибавляет к нему 1.
3. Затем результат сохраняется обратно в переменную `clicks` с помощью действия **Set Variable**.

Так что каждый раз при нажатии кнопки переменная `clicks` будет увеличиваться на 1, фактически считая общее количество нажатий.

## Использование переменных

Теперь, когда у вас есть переменные, хранящие данные, вы можете использовать эти данные в разных частях настройки меню:

* **Требования загрузки**: Вы можете проверять значение переменной в требовании загрузки, чтобы управлять тем, когда появляются определённые элементы меню. Например, можно сделать так, чтобы элемент показывался только если значение переменной `clicks` больше 5, используя сочетание требования **Is Number** и плейсхолдера **Get Stored Variable**.

* **Плейсхолдеры**: Переменные можно вставлять в текст с помощью плейсхолдера **Get Stored Variable**. Если у вас есть текстовый элемент, вы можете использовать `{"placeholder":"getvariable","values":{"name":"clicks"}}`, чтобы отобразить текущее значение переменной «clicks».

* **Вложенные плейсхолдеры**: Вы даже можете использовать переменные внутри других плейсхолдеров! В примере со счётчиком кликов выше это было показано с помощью плейсхолдера **Get Stored Variable** внутри плейсхолдера **Calculator**.

* **Действия**: Переменные можно использовать в действиях, чтобы создавать динамическое поведение в зависимости от их значений. Вот несколько примеров:
    - Используйте оператор **IF** в скрипте действия, чтобы проверить значение переменной с помощью сочетания требования загрузки **Is Number** и действия **Get Stored Variable**, а затем выполните разные действия в зависимости от результата. Например, можно сделать кнопку с текстом «Вы нажали меня X раз!» и использовать блок IF, чтобы показывать специальное сообщение, если число нажатий больше 10.
    - Скомбинируйте плейсхолдер **Get Stored Variable** с действием **Copy to Clipboard**, чтобы пользователи могли копировать значение переменной в буфер обмена.
    - Используйте переменные в действии **Open GUI**, чтобы загружать разные экраны в зависимости от прогресса или предпочтений пользователя, которые вы отслеживаете с помощью переменных.

## Примеры использования переменных

Вот несколько примеров, которые могут вдохновить вас на собственное использование переменных:

1. **Рекордный счёт**: Создайте переменную `highscore` и кнопку, которая устанавливает в неё текущий счёт игрока, если он выше существующего значения. Отображайте рекордный счёт в меню с помощью плейсхолдера **Get Stored Variable**.

2. **Выбор сложности**: Создайте переменные для разных уровней сложности, например `easy`, `medium` и `hard`. Используйте кнопки для установки переменной сложности и показывайте или скрывайте элементы в зависимости от выбранной сложности.

3. **Прогресс обучения**: Добавьте переменные, чтобы отслеживать прогресс игрока в обучении, например `tutorial_step`. Увеличивайте значение переменной по мере прохождения каждого шага и используйте требования загрузки, чтобы постепенно открывать новые элементы меню.

Переменные в сочетании с другими возможностями FancyMenu дают вам невероятную гибкость для создания меню, адаптированных под действия и предпочтения каждого игрока. Экспериментируйте с разными настройками переменных, чтобы раскрыть весь потенциал своих меню!
