# Переменные

Переменные — это значения, которые FancyMenu запоминает даже после закрытия игры. Используйте их, чтобы считать нажатия, запоминать выбор, отслеживать прогресс или хранить списки, например советы на экране загрузки. Тексты, действия, требования, слушатели и некоторые элементы могут читать и изменять переменные.

> [!TIP]
> Действия для работы с переменными перечислены в разделе [Скрипты действий](/action-scripts), требования — в разделе [Требования](/conditions), а слушатель — в разделе [Слушатели](/listeners#on-variable-updated-fm-variable).

# Текстовые переменные и переменные-списки

Существует два вида переменных:

- Текстовые переменные хранят один текст, например `dark`, `5` или `true`.
- Переменные-списки хранят список записей, например советы на экране загрузки или названия серверов. Каждая запись — отдельный текст.

Положение записи в списке называется индексом. Индекс первой записи — `0`, второй — `1` и так далее. Отрицательные индексы отсчитываются с конца: `-1` — это последняя запись.

Если функция работает только с текстом, например `$$name` или **Значение переменной равно (FM Variable)**, список будет представлен в виде JSON-массива записей, например `["Craft a bed before your first night.","Torches keep most mobs away."]`.

# Управление переменными

Откройте **строка меню -> Настройка -> Управление переменными**. Этот пункт есть в строке меню только за пределами редактора макетов.

## Добавление переменных

1. Щёлкните правой кнопкой мыши по списку и выберите **Добавить текстовую переменную** или **Добавить переменную-список**.
2. Введите имя и нажмите **Готово**.

В именах можно использовать строчные буквы, цифры, `.`, `_` и `-`. Каждое имя может существовать только один раз.

## Изменение переменных

Щёлкните переменную правой кнопкой мыши, чтобы открыть следующие действия:

| Действие | Что оно делает |
|---|---|
| **Задать значение** | Задаёт текстовое значение текстовой переменной. |
| **Изменить список** | Открывает редактор списка (см. ниже). |
| **Преобразовать в список…** | Преобразует текстовую переменную в список. **Разделитель** разбивает текст на записи: введите `\n`, чтобы разделить его по переносам строк. Параметр **Удалить пробелы по краям записей** удаляет пробелы в начале и конце каждой записи, а **Пропускать пустые записи** исключает пустые записи. Текст, который уже является JSON-массивом, например `["a","b"]`, будет прочитан как один массив (**Читать как JSON-массив**). |
| **Преобразовать в текст…** | Преобразует список в текстовую переменную. **Разделитель** вставляется между записями, а параметр **Сохранить текст в формате JSON** оставляет список в виде JSON-массива. |
| **Очищать переменную при запуске игры** | Очищает переменную при каждом запуске игры. Подходит для значений, которые должны сохраняться только в течение одного сеанса. |
| **Удалить переменную** | Удаляет переменную. |
| **Копировать** и **Вставить** | Создают копию переменной. |
| **Экспортировать переменную для ИИ** | Экспортирует переменную для [чатов с ИИ](/export-for-ai). |

Изменения применяются сразу. Отменить их можно сочетанием `Ctrl + Z`, а повторить — `Ctrl + Y` (на macOS используйте `Cmd`). Начните вводить текст, чтобы выполнить поиск; нажмите `Enter`, чтобы изменить выбранную переменную, или `Delete`, чтобы удалить её.

## Редактирование списков

В редакторе списка каждая запись показана вместе со своим индексом.

- Чтобы добавить запись, нажмите **Добавить запись** под списком, введите текст и нажмите `Enter`. Сразу начнётся добавление следующей записи. Нажмите `Enter` в пустой записи или `Esc`, чтобы завершить добавление.
- Чтобы изменить запись, дважды щёлкните по ней. Сочетание `Shift + Enter` откроет её в текстовом редакторе, где можно добавлять переносы строк.
- Чтобы изменить порядок записей, перетащите их или используйте сочетания `Alt + Up` и `Alt + Down`.
- Щёлкните запись правой кнопкой мыши, чтобы выбрать **Дублировать запись** (`Ctrl + D`), **Удалить запись** (`Delete`), **Копировать**, **Вставить**, **Переместить вверх** или **Переместить вниз**.
- Пункт **Изменить как текст** позволяет редактировать все записи сразу, по одной на строку.

Кнопка **Готово** сохраняет список. Кнопка **Отмена** отбрасывает все изменения, внесённые в редакторе списка.

# Отображение переменных в тексте

Введите `$$`, а затем имя переменной, чтобы показать её значение: переменная с именем `menu_theme` обозначается как `$$menu_theme`. Это работает во всех текстовых полях, поддерживающих [подстановки](/placeholders), например в [текстовых элементах](/text-in-menus), подписях кнопок, всплывающих подсказках, а также значениях действий и требований. Текст обновляется автоматически при изменении переменной.

```
Current theme: $$menu_theme
```

- Если переменной с именем `name` не существует, `$$name` останется без изменений.
- Если имена начинаются одинаково, например `coins` и `coins_record`, запись `$$coins_record` всегда будет обозначать более длинное имя.
- Список отображается как JSON-массив. Следующие подстановки позволяют отобразить списки удобнее:

| Подстановка | Пример | Результат |
|---|---|---|
| **Получить значение переменной (FM Variable)** | `{"placeholder":"getvariable","values":{"name":"clicks"}}` | Значение или `0`, если переменная пуста либо не существует. Лучше всего подходит для чисел. |
| **Получить запись списка (FM Variable)** | `{"placeholder":"list_get","values":{"name":"tips","index":"0","fallback":"No tips yet"}}` | Запись с указанным индексом или значение `fallback`, если такой записи нет. |
| **Размер списка (FM Variable)** | `{"placeholder":"list_size","values":{"name":"tips"}}` | Количество записей в списке. |
| **Индекс записи списка (FM Variable)** | `{"placeholder":"list_index_of","values":{"name":"tips","value":"Torches keep most mobs away.","ignore_case":"false"}}` | Индекс первой записи, полностью совпадающей со значением `value`, или `-1`. |
| **Объединить записи списка (FM Variable)** | `{"placeholder":"list_join","values":{"name":"tips","separator":"\n"}}` | Все записи в виде одного текста с `separator` между ними (если параметр не задан, используется `, `). `\n` означает перенос строки. |

# Изменение переменных с помощью действий

[Скрипты действий](/action-scripts) изменяют переменные, когда нажимают кнопку, запускается таймер, срабатывает слушатель и так далее.

## Текстовые переменные

Действие [**Задать значение переменной (FM Variable)**](/action-scripts#set-variable-value-fm-variable) принимает имя и новое значение, разделённые символом `:`. Если переменной ещё нет, она будет создана.

```
menu_theme:dark
```

Только первый символ `:` отделяет имя от значения, поэтому в значении могут быть и другие такие символы, например `last_server:play.example.net:25565`.

Чтобы считать нажатия кнопки, прибавьте 1 к предыдущему значению:

```
clicks:{"placeholder":"calc","values":{"decimal":"false","expression":"{"placeholder":"getvariable","values":{"name":"clicks"}} + 1"}}
```

Пока переменная `clicks` пуста, подстановка **Получить значение переменной (FM Variable)** возвращает `0`, поэтому после первого нажатия её значение станет `1`.

Действие «Задать значение переменной» никогда не преобразует список в текст. JSON-массив становится записями списка, пустой текст очищает список, а любой другой текст становится его единственной записью.

Действие [**Удалить переменную (FM Variable)**](/action-scripts#delete-variable-fm-variable) удаляет одну переменную, а [**Очистить все переменные (FM Variable)**](/action-scripts#clear-all-variables-fm-variable) удаляет их все.

## Действия со списками

Для каждого действия со списками открывается отдельное окно. Во всех его полях поддерживаются подстановки.

| Действие | Что оно делает |
|---|---|
| [**Добавить в список (FM Variable)**](/action-scripts#add-to-list-fm-variable) | Добавляет запись в конец списка или по указанному индексу. Параметр **Не добавлять, если запись уже есть в списке** отменяет добавление, если запись уже присутствует. |
| [**Задать запись списка (FM Variable)**](/action-scripts#set-list-entry-fm-variable) | Заменяет запись с указанным индексом. |
| [**Удалить из списка (FM Variable)**](/action-scripts#remove-from-list-fm-variable) | Удаляет **запись с индексом**, **первое совпадение** со значением или **все совпадения**. |
| [**Очистить список (FM Variable)**](/action-scripts#clear-list-fm-variable) | Удаляет все записи. Сам список остаётся, но становится пустым. |
| [**Задать список (FM Variable)**](/action-scripts#set-list-fm-variable) | Заменяет все записи частями **разделённого текста** или записями **JSON-массива**. Если в качестве JSON-массива указать `$$other_list`, будет скопирован другой список. |
| [**Упорядочить список (FM Variable)**](/action-scripts#arrange-list-fm-variable) | **Сортировка от А до Я**, **Сортировка от Я до А**, **Числа по возрастанию**, **Числа по убыванию**, **Обратный порядок**, **Перемешать** или **Удалить дубликаты**. |

- Действия со списками создают список, если его ещё нет, и преобразуют пустые текстовые переменные в списки. Они никогда не изменяют текстовую переменную с заданным значением: сначала [преобразуйте её](#изменение-переменных).
- Укажите имя списка без `$$`. Если использовать `$$`, действие возьмёт значение этой переменной в качестве имени.

Например, текстовый элемент показывает первую запись списка `tips`:

```
{"placeholder":"list_get","values":{"name":"tips","index":"0"}}
```

Кнопке «Следующий совет» под ним назначено действие **Упорядочить список (FM Variable)** с режимом **Перемешать**:

## Перебор списка

Цикл [FOR EACH](/action-scripts#for-each-loop) выполняет вложенные в него действия один раз для каждой записи списка, от первой до последней.

1. Щёлкните правой кнопкой мыши по области скрипта в редакторе скриптов действий и выберите **Добавить цикл FOR EACH**.
2. Введите имя переменной-списка без `$$` и нажмите **Готово**.
3. Добавьте действия внутрь цикла. В их значениях `$$list_entry` обозначает текущую запись, а `$$list_index` — её индекс.

Например, список `starter_commands` содержит записи `/time set day` и `/weather clear`. Если добавить внутрь цикла действие [**Отправить сообщение/команду в чат**](/action-scripts#send-chat-messagecommand) со следующим значением, выполнятся обе команды:

```
$$list_entry
```

- Цикл считывает список при запуске. Действия внутри него могут изменять список, но это не повлияет на записи, которые перебирает цикл.
- Если указана текстовая переменная или несуществующий список, цикл выполнится ноль раз.
- Как и циклы WHILE, цикл останавливается через 3 секунды, поэтому он не может зависнуть и заморозить игру.

# Проверка переменных

[Требования](/conditions) позволяют показывать элементы или выполнять части скрипта действий только при заданном значении переменной.

- [**Значение переменной равно (FM Variable)**](/conditions#is-variable-value-fm-variable) проверяет полное значение. Для списков сравнивается JSON-массив всех записей.
- [**Список содержит запись (FM Variable)**](/conditions#list-contains-entry-fm-variable) проверяет, есть ли в списке указанная запись. Она должна совпадать целиком. Параметр **Игнорировать регистр** позволяет считать `Apple` и `apple` совпадением.
- [**Является числом**](/conditions#is-number) сравнивает числа, например проверяет, больше ли `$$clicks`, чем `5`.

Например, кнопка открывает последнюю новость и с помощью действия **Добавить в список (FM Variable)** добавляет `news_42` в список `read_news`. Для значка «Новое!» рядом с кнопкой задаётся требование **Список содержит запись (FM Variable)** со значением `news_42` и режимом **Инвертировать требование**. Поэтому значок исчезнет, когда игрок прочитает публикацию.

# Связывание переменных с элементами

- [Поле ввода текста](/elements#text-input-field): параметр **Связать с переменной** записывает введённый игроком текст в переменную, а поле показывает её значение. Если связать поле со списком, введённый текст заменит весь список.
- [Флажок](/elements#checkbox): включите **Режим переменной** и задайте параметр **Связать с переменной**. Флажок записывает в переменную `true` или `false`.
- [Ползунок](/elements#slider) типа **Список значений**: параметр **Значения из переменной-списка** берёт значения ползунка из списка. Новые и удалённые записи сразу отражаются в нём.

# Реакция на изменения

- Слушатель [**При обновлении переменной [FM Variable]**](/listeners#on-variable-updated-fm-variable) запускает скрипт действий каждый раз, когда задаётся переменная.
- Команда [`/fmvariable`](/commands#fmvariable) позволяет задавать и считывать переменные из чата, командных блоков и других модов.

# Где хранятся переменные

FancyMenu сразу сохраняет переменные в файле `<game-directory>/config/fancymenu/user_variables.db`, поэтому они сохраняются после перезапуска игры.

- Переменные относятся ко всему экземпляру Minecraft и его активному [профилю](/profiles). Они не разделяются по макетам, мирам, серверам или игрокам.
- Имена чувствительны к регистру.
- Не храните в переменных пароли, токены и другие секреты. Их может прочитать любой, у кого есть доступ к папке игры.
