# Inclinação de elementos

A maioria dos elementos pode ser inclinada vertical e horizontalmente.

Selecione um elemento no editor de layout. Se a inclinação for compatível, guias verticais e horizontais com alças aparecerão ao redor dele. Arraste uma alça para inclinar o elemento nesse eixo.

Se não houver linhas com alças no elemento, não será possível incliná-lo.

# Avançado

Você também pode clicar com o botão direito no elemento para definir manualmente os valores de inclinação por meio de um campo de texto direto. Esse campo aceita [placeholders](/placeholders), permitindo alterar dinamicamente a inclinação do elemento ao combiná-los com placeholders para obter valores de variáveis do FancyMenu ou algo semelhante.

# Botões, controles deslizantes e outros elementos interativos

A inclinação é apenas visual para elementos interativos. Um botão inclinado ainda aceita cliques dentro de sua área original, sem inclinação.
