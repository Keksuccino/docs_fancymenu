# Elementos com Inclinação

A partir do FancyMenu v3.8.0, é possível inclinar **a maioria** dos elementos verticalmente e horizontalmente!

Para inclinar um elemento, selecione-o no editor de layout. Se você vir duas linhas com uma alça de arraste presa a elas (uma linha vertical e uma linha horizontal) que não sejam a borda do elemento, você pode arrastar as alças para inclinar o elemento na direção desejada.

Se não houver linhas com alças no elemento, não será possível incliná-lo.

# Avançado

Você também pode clicar com o botão direito no elemento para definir manualmente os valores de inclinação por meio de uma entrada de texto direta. Essa entrada direta suporta [placeholders](/placeholders), então você pode alterar dinamicamente a inclinação do elemento ao combiná-la com placeholders para obter valores de variáveis do FancyMenu ou similares.

# Botões, Sliders e Outros Elementos Interativos

No caso de elementos interativos, é possível incliná-los, mas a inclinação é apenas visual. Então o botão, por exemplo, ainda só reagirá a cliques dentro de sua área original, mesmo que a inclinação possa tê-lo deslocado parcialmente para fora dessa área.
