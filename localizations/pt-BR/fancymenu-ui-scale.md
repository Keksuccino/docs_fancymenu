# Escala da interface do FancyMenu

A interface do FancyMenu (como a barra de menu e os menus de contexto) usa uma escala separada que não está vinculada à escala normal da interface do Minecraft.

Se a interface do FancyMenu parecer muito pequena ou muito grande para você, é possível alterar a escala da interface em **barra de menu -> Personalização -> Configurações -> Interface do FancyMenu**.

Quando a escala da interface está definida como **Auto**, a menor escala automática é `1.25`. Você pode selecionar manualmente a escala `1`.

A única exceção a isso são as telas completas adicionadas pelo FancyMenu, como a tela para gerenciar variáveis ou o editor de layout. Essas telas, na maioria dos casos, usam a escala normal da interface do Minecraft, mas é possível que algumas usem uma lógica de autoescala diferente para serem exibidas automaticamente em uma escala menor quando a janela, de outra forma, ficaria pequena demais para comportar todo o conteúdo da tela.
