# Escala da interface do FancyMenu

A interface do FancyMenu (como a barra de menu e os menus de contexto) usa uma escala separada, que não está vinculada à escala normal da interface gráfica do Minecraft.

Caso a interface do FancyMenu pareça muito pequena ou muito grande para você, você pode alterar a escala da interface em **barra de menu -> Personalização -> Configurações -> Interface do FancyMenu**.

O FancyMenu 3.9.0 adiciona mais opções de escala da interface. Quando a escala da interface está definida como **Auto**, a menor escala automática agora é `1.25`; ainda é possível escolher manualmente a escala `1` se preferir.

A única exceção a isso são as telas completas adicionadas pelo FancyMenu, como a tela para gerenciar variáveis ou o editor de layout. Essas telas, na maioria dos casos, usam a escala normal da interface gráfica do Minecraft, mas é possível que algumas usem uma lógica de autoajuste diferente para serem exibidas automaticamente em uma escala menor quando a janela, de outra forma, seria pequena demais para caber todo o conteúdo da tela.
