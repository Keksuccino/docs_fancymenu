# Ícone e título da janela

O FancyMenu permite alterar o ícone e o título da janela do Minecraft.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# Ícone personalizado

Para definir um ícone personalizado, abra [**Personalizações globais**](/global-customizations) em **Personalização -> Personalizações globais**.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- Os ícones precisam estar no formato **PNG** (e **ICNS para macOS**)
- Os ícones precisam ter pelo menos **1 pixel transparente** para não ficarem com aparência distorcida (um bug do MC/LWJGL)
- É necessário definir arquivos válidos para as 3 versões do ícone (16x16, 32x32 e macOS) para ativar a opção de ícone personalizado

> [!CAUTION]
> **Reforçando**: os ícones precisam ter pelo menos **1 pixel transparente** para não ficarem com aparência distorcida (um bug do MC/LWJGL). O ícone ficará com aparência quebrada se não tiver pelo menos um pixel totalmente transparente!


# Título personalizado

Para definir um título personalizado, abra [**Personalizações globais**](/global-customizations) em **Personalização -> Personalizações globais**.
