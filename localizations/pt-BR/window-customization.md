# Ícone e Título da Janela

O FancyMenu permite que você altere o ícone e o título da janela do Minecraft.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# Ícone Personalizado

Para definir um ícone personalizado para a janela do Minecraft no FancyMenu 3.9.0+, navegue até **Customização -> Customizações Globais** na **barra de menu**.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- Os ícones precisam ser arquivos **PNG** (e **ICNS para macOS**)
- Os ícones precisam ter pelo menos **1 pixel transparente** para não parecerem bugados (bug do MC/LWJGL)
- Você precisa definir arquivos válidos para todas as 3 versões do ícone (16x16, 32x32, macOS) para ativar a opção de ícone personalizado

> **Novamente**: Os ícones precisam ter pelo menos **1 pixel transparente** para não parecerem bugados (bug do MC/LWJGL). O ícone ficará quebrado se não tiver pelo menos um pixel totalmente transparente!
