# Personalizando a tela de carregamento

**O FancyMenu não pode personalizar sozinho a tela de carregamento/inicial do Minecraft**. É exatamente por isso que existe o complemento [Drippy Loading Screen](https://www.curseforge.com/minecraft/mc-mods/drippy-loading-screen) (você também pode encontrá-lo [aqui](https://modrinth.com/mod/drippy-loading-screen) no Modrinth).

> [!IMPORTANT]
>Para saber como usar o Drippy Loading Screen, consulte a [wiki](https://github.com/Keksuccino/Drippy-Loading-Screen/wiki).
