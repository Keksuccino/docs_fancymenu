# Carregamento Contínuo do Mundo

O Carregamento Contínuo do Mundo captura uma captura de tela quando você sai de um mundo ou servidor e a usa como plano de fundo de carregamento na próxima vez.

Isso torna as transições de carregamento mais suaves, porque a tela de carregamento vai corresponder ao que você verá quando o carregamento terminar.

# Onde Encontrar

Abra a **barra de menu** do FancyMenu enquanto **não** estiver no editor de layout e vá em **Customização -> Customizações Globais**.

# Ativar / Desativar

1. Abra **Customização -> Customizações Globais**.
2. Encontre **Carregamento Contínuo do Mundo**.
3. Defina como **Ativado** ou **Desativado**.

# Como Funciona

- Quando ativado, o FancyMenu salva uma captura de tela quando você sai de um mundo/servidor.
- No próximo carregamento, essa captura de tela é usada como plano de fundo de carregamento.
- Primeiro uso: se ainda não existir nenhuma captura de tela, não há nada para mostrar até você sair de um mundo/servidor uma vez.
