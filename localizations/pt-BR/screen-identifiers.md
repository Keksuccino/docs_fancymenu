# Identificadores de Tela

O FancyMenu usa identificadores de tela para saber a qual tela um layout pertence, para apontar para um botão em uma tela específica e outras coisas que exigem que o mod se comunique com ou personalize uma tela específica.

# Encontrando o Identificador de uma Tela

Você pode ver o identificador do menu atualmente ativo usando a **Sobreposição de Depuração**.
Ela contém o identificador da tela atual e permite copiá-lo para a área de transferência ao clicar com o botão esquerdo nele.
