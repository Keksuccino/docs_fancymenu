# Excluindo Elementos Vanilla

Você pode ocultar todos os elementos padrão/Vanilla (incluindo alguns elementos de mod) que estão visíveis no editor de layout. Se eles estiverem visíveis, basta **clicar com o botão direito** neles e clicar em **Excluir**.


# Trazendo de Volta Elementos Vanilla Excluídos

Para tornar visíveis novamente elementos Vanilla excluídos/ocultos, como botões, logotipos ou outros tipos de elementos, basta abrir o layout em que você os excluiu e então **navegar até a barra de menus -> Elemento -> Elementos Vanilla Excluídos** e **clicar com o botão esquerdo** no(s) elemento(s) que você deseja tornar visível(is) novamente.

Se os elementos excluídos não estiverem listados no menu, você abriu o layout errado e precisa encontrar aquele em que eles foram excluídos.
