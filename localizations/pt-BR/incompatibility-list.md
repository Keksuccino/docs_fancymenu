# Lista de Mods Incompatíveis

Os mods a seguir são conhecidos por serem incompatíveis com o FancyMenu de alguma forma.

Alguns dos mods têm alternativas para fazer com que funcionem com o FancyMenu.
Se for o caso, isso será indicado após o nome do mod na lista abaixo.

**Caso você tenha encontrado um mod incompatível que ainda não esteja nesta lista, abra uma issue no GitHub! Muito obrigado!**

* [Animated Loading Screen](https://modrinth.com/mod/animated-loading-screen) (Faz os menus parecerem bugados)
* [Animated Mojang Logo](https://www.curseforge.com/minecraft/mc-mods/animated-mojang-logo) (Os layouts às vezes não carregam; também quebra o Drippy Loading Screen)
* [Bedrockify](https://www.curseforge.com/minecraft/mc-mods/bedrockify) (Compatível quando você desativa todas as modificações de menu do mod, pelo menos para os menus que deseja personalizar)
* [BetterFPS](https://www.curseforge.com/minecraft/mc-mods/betterfps) (Os botões e menus deste mod não são personalizáveis)
* [Chat Colors](https://www.curseforge.com/minecraft/mc-mods/chat-colours) (Falha ao iniciar)
* [Chloride](https://modrinth.com/mod/chloride) (O placeholder de FPS não funciona quando este mod está instalado)
* [Colormatic](https://www.curseforge.com/minecraft/mc-mods/colormatic) (Grande lag ao iniciar o Minecraft e quebra os recursos de áudio do FM)
* [Controllable](https://www.curseforge.com/minecraft/mc-mods/controllable) (Botões personalizados adicionados aos menus com o FancyMenu não podem ser clicados usando o recurso “Virtual Mouse” do Controllable)
* [Controlify](https://modrinth.com/mod/controlify) (Parece causar crash no jogo, mas eu não consigo corrigir isso do meu lado - veja [este issue](https://github.com/Keksuccino/FancyMenu/issues/1144) para mais contexto)
* [Crash To Main Menu](https://www.curseforge.com/minecraft/mc-mods/crash-to-main-menu)
* [Custom Loading Screen](https://www.curseforge.com/minecraft/mc-mods/better-loading-screen)
* [Custom Main Menu](https://www.curseforge.com/minecraft/mc-mods/custom-main-menu)
* [Debugify](https://www.curseforge.com/minecraft/mc-mods/debugify) (Use [Modern Debugify](https://www.curseforge.com/minecraft/mc-mods/modern-debugify) em vez disso)
* [Dynamic Surroundings](https://www.curseforge.com/minecraft/mc-mods/dynamic-surroundings) (Quebra os elementos de áudio do FancyMenu, mas qualquer outra coisa deve funcionar normalmente)
* [EnhancedVisuals](https://www.curseforge.com/minecraft/mc-mods/enhancedvisuals) (Parece quebrar animações, deixa fundos translúcidos e provavelmente mais coisas)
* [Entity Model Features](https://modrinth.com/mod/entity-model-features) (Causa crash no jogo, mas eu não consigo corrigir isso do meu lado - veja [este issue](https://github.com/Keksuccino/FancyMenu/issues/1115) para mais contexto)
* [Fossils and Archeology Revival](https://www.curseforge.com/minecraft/mc-mods/fossils) (Funciona no jogo, mas o menu principal customizado não é suportado — pode ser desativado na configuração)
* [Holographic Renderers](https://www.curseforge.com/minecraft/mc-mods/holographic-renderers) (Falha ao iniciar)
* [Ice and Fire](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons) (Funciona se o menu principal customizado estiver desativado na configuração)
* [Jurassicraft](https://www.curseforge.com/minecraft/mc-mods/jurassicraft) (Causa crash ao iniciar quando as personalizações para suas GUIs são ativadas — exclua-as de `config/fancymenu/customizablemenus.txt`)
* [Legacy4J](https://www.curseforge.com/minecraft/mc-mods/legacy-minecraft) (Causa crash no jogo)
* [MalisisCore](https://www.curseforge.com/minecraft/mc-mods/malisiscore) (Quebra a personalização do menu principal)
* [Main Menu Scale Mod](https://www.curseforge.com/minecraft/mc-mods/main-menu-scale)
* [MCA Reborn](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-reborn) (Funciona, mas alguns de seus menus quebram a barra de menu do FM e/ou não são personalizáveis)
* [Minecraft Comes Alive](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-mca) (Funciona normalmente, mas seus menus não são personalizáveis)
* [MineTogether](https://www.curseforge.com/minecraft/mc-mods/creeperhost-minetogether) (Parece quebrar os layouts quando a escala da GUI é > 2)
* [Mod Menu](https://www.curseforge.com/minecraft/mc-mods/modmenu) (**FUNCIONA NORMALMENTE** na maioria dos casos, mas se você tiver um botão Mods duplicado ou não personalizável, altere a configuração do botão do Mod Menu para "Adjacent": Main Menu > Mods > Mod Menu > Mods Button: Adjacent)
* [Modern Online Picture Frames](https://www.curseforge.com/minecraft/mc-mods/online-picture-frame) (Crash — veja [este issue](https://github.com/Keksuccino/FancyMenu/issues/776))
* [Not Enough Animations](https://www.curseforge.com/minecraft/mc-mods/not-enough-animations) (Funciona normalmente na 1.16+, mas quebra na 1.12)
* **OptiFine** (Quebra o mod! Use [estas alternativas](./optifine-alternatives) em vez disso)
* [Optiscale](https://www.curseforge.com/minecraft/mc-mods/optiscale) (Quebra a UI do FancyMenu; os botões não podem ser clicados)
* [Pack Menu](https://www.curseforge.com/minecraft/mc-mods/packmenu)
* [Panorama Screens](https://modrinth.com/mod/panorama-screens) (Não funcionará e causará problemas, porque empilhar mods de personalização de menu nunca é uma boa ideia)
* [QuestCraft](https://github.com/QuestCraftPlusPlus/QuestCraft) (O jogo não consegue carregar)
* [RandomPatches](https://www.curseforge.com/minecraft/mc-mods/randompatches-forge) (Funciona se `patchMinecraftClass = false` estiver na configuração)
* [Remove Reloading Screen](https://www.curseforge.com/minecraft/mc-mods/rrls) (Quebra o FM e o Drippy. Não use esse mod.)
* [Replay Mod](https://www.replaymod.com/download/) (Funciona quando você define `mainMenuButton` como **BIG** em `.minecraft/config/replaymod.json`)
* [Seamless Loading Screen](https://www.curseforge.com/minecraft/mc-mods/seamless-loading-screen) (Causa crash no jogo)
* [Slight Gui Modifications](https://www.curseforge.com/minecraft/mc-mods/slight-gui-modifications)
* [Skin Layers 3D](https://www.curseforge.com/minecraft/mc-mods/skin-layers-3d) (Funciona normalmente na 1.16+, mas quebra na 1.12)
* [Smooth Scrolling Everywhere](https://www.curseforge.com/minecraft/mc-mods/smooth-scrolling-everywhere)
* [Sound Filters](https://www.curseforge.com/minecraft/mc-mods/sound-filters) (A extensão de áudio não funcionará com este mod instalado)
* [Sound Physics Remastered](https://www.curseforge.com/minecraft/mc-mods/sound-physics-remastered) (A extensão de áudio não funcionará com este mod instalado)
* [Stylish Effects](https://www.curseforge.com/minecraft/mc-mods/stylish-effects) (O menu principal falha ao carregar os layouts na primeira vez que é exibido)
* [Supplementaries](https://www.curseforge.com/minecraft/mc-mods/supplementaries) (Causa crash aleatoriamente ao personalizar a tela de configuração; exclua o layout problemático de `.minecraft/config/fancymenu/customization`)
* [Terraria Craft](https://www.curseforge.com/minecraft/mc-mods/terraria-craft)
* [The Dalek Mod](https://www.curseforge.com/minecraft/mc-mods/the-dalek-mod) (Funciona se o menu principal customizado estiver desativado na configuração)
* [ThonkUtil](https://www.curseforge.com/minecraft/mc-mods/thonkutil) (Funciona, mas atualmente adiciona um texto que não pode ser removido ao menu principal)
* [Trade Uses](https://modrinth.com/mod/trade-uses) (Causa crashes no menu de troca com aldeões — possivelmente apenas quando "Easy Villagers" também estiver instalado)
* [VanillaFix](https://www.curseforge.com/minecraft/mc-mods/vanillafix) (Utilizável, mas alguns usuários relatam problemas com a tela de crash do VanillaFix)
* [FireplaceMode](https://www.curseforge.com/minecraft/mc-mods/fireplacemode) (A tela de pausa às vezes redefine suas personalizações com este mod instalado)
* [Respackopts](https://www.curseforge.com/minecraft/mc-mods/respackopts) (Funciona, mas somente se você desativar as personalizações da tela de Pacotes de Recursos)
* [Bind Pizzeria](https://modrinth.com/mod/jjpizza) (Quebra a renderização de texto nos menus de contexto do FancyMenu)
* [EnhancedTooltips](https://www.curseforge.com/minecraft/mc-mods/enhancedtooltips) (Quebra as dicas de ferramenta do FancyMenu)
