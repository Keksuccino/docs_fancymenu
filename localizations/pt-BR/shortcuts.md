# Atalhos e Teclas de Atalho

**Modificador de atalho:** Use `Ctrl` no Windows/Linux e `Command` no macOS quando houver suporte.

# Editor de Layout

| Atalho | Ação |
|---|---|
| `Ctrl/Command + clique esquerdo` | Selecionar ou arrastar vários elementos |
| `Shift + redimensionar` | Preservar a proporção do elemento |
| Setas do teclado | Mover os elementos selecionados com precisão |
| `Ctrl/Command + A` | Selecionar todos os elementos |
| `Ctrl/Command + C` | Copiar os elementos selecionados |
| `Ctrl/Command + V` | Colar os elementos copiados, inclusive em outro layout |
| `Ctrl/Command + S` | Salvar o layout |
| `Ctrl/Command + Z` | Desfazer |
| `Ctrl/Command + Y` | Refazer |
| `Ctrl/Command + G` | Alternar a grade |
| `O` | Mostrar os pontos de ancoragem enquanto estiver pressionada quando **Window -> Anchor Overlay Visibility** estiver definido como **Show On Key Press** |
| `Delete` | Excluir os elementos selecionados |

# Editor de Texto

| Atalho | Ação |
|---|---|
| `Ctrl/Command + C` | Copiar o texto selecionado |
| `Ctrl/Command + V` | Colar texto |
| `Ctrl/Command + Z` | Desfazer |
| `Ctrl/Command + Y` | Refazer |
| `Ctrl/Command + A` | Selecionar todo o texto |
| `Ctrl/Command + D` | Duplicar a linha atual |
| `Ctrl/Command + U` | Recortar o texto selecionado |
| `Alt + Seta para cima/baixo` | Mover a linha atual |
| `Ctrl/Command + Home/End` | Ir para o início ou o fim do texto |
| `Ctrl/Command + G` | Abrir **Ir Para Linha** |
| `Ctrl/Command + S` | Confirmar o editor |
| `Shift + setas do teclado` | Expandir a seleção de texto |
| Setas do teclado | Mover o cursor |

# Atalhos Globais do Menu

Esses atalhos usam a combinação exata `Ctrl + Alt`:

| Atalho | Ação |
|---|---|
| `Ctrl + Alt + L` | Abrir o editor de layout com o último layout editado |
| `Ctrl + Alt + C` | Alternar a barra de menu do FancyMenu |
| `Ctrl + Alt + R` | Recarregar o FancyMenu e seus recursos/caches gerenciados |
| `Ctrl + Alt + D` | Alternar a sobreposição de depuração do FancyMenu |

# Janelas de Edição

As janelas de edição do FancyMenu oferecem suporte à navegação pelo teclado com as setas e `Enter`. Muitas também usam `Ctrl/Command + S` para **Concluído** e `Escape` para **Cancelar**.

Os editores de Script de Ação, Requisitos e Variáveis também oferecem suporte a menus de contexto com o botão direito, busca, desfazer/refazer e navegação por listas pelo teclado.
