# Atalhos e Combinações de Teclas

O FancyMenu tem muitos atalhos úteis que tornam o trabalho com o **editor de layout** e outras partes do mod mais fácil e eficiente.

# Editor de Layout

<br>

## CTRL + Clique com o botão esquerdo

Você pode selecionar vários elementos mantendo **CTRL** pressionado enquanto clica com o **botão esquerdo** nos elementos.
Também é possível **arrastar/mover vários elementos** com o mouse mantendo **CTRL** pressionado.

## SHIFT + Redimensionar Elemento

Manter SHIFT pressionado enquanto redimensiona elementos preservará a proporção deles.

## Teclas de Seta

As teclas de seta podem ser usadas para **mover** os elementos selecionados com máxima precisão.

## CTRL + A

Seleciona todos os elementos de uma vez.

## CTRL + C

**Copiar** todos os elementos selecionados para a área de transferência.

## CTRL + V

**Colar** todos os elementos que estão atualmente na área de transferência.
Isso também funciona de um layout para outro, então você pode copiar elementos no layout A e colá-los no layout B.

## CTRL + S

**Salvar** o layout rapidamente.

## CTRL + ALT + L

Abrir rapidamente o editor de layout com o último layout editado.

## CTRL + Z

**Desfazer** a última ação.

## CTRL + Y

**Refazer** uma ação desfeita anteriormente.

## CTRL + G

Alternar rapidamente a **grade**.

## O

Manter **O** pressionado mostra a sobreposição do ponto âncora se a visibilidade estiver definida como **Mostrar ao Pressionar a Tecla** em **Window -> Anchor Overlay Visibility**.

## DEL

**Excluir** todos os elementos selecionados.

# Editor de Texto

<br>

## CTRL + C

**Copiar** o texto selecionado para a área de transferência.

## CTRL + V

**Colar** o texto que está atualmente na área de transferência.

## CTRL + Z

**Desfazer** a última ação.

## CTRL + Y

**Refazer** uma ação desfeita anteriormente.

## CTRL + A

**Selecionar** todo o texto.

## CTRL + D

**Duplicar** a linha atual.

## CTRL + U

**Recortar** o texto selecionado.

## ALT + Seta para Cima / ALT + Seta para Baixo

Mover a linha atual para cima ou para baixo.

## CTRL + Home / CTRL + End

Mover o cursor para o início ou o fim do texto.

## CTRL + G

Abrir a entrada **Ir para Linha**.

## CTRL + S

Confirmar o editor, igual a clicar em **Concluído**.

## SHIFT + Teclas de Seta

Selecionar/destacar texto enquanto move o cursor.

## Teclas de Seta

As teclas de seta podem ser usadas para navegar o cursor no texto.

# Nos Menus

<br>

## CTRL + ALT + C

Alternar a visibilidade da **barra de menu** do FancyMenu no topo dos menus.

## CTRL + ALT + R

**Recarregar** o FancyMenu.
Isso inclui um recarregamento completo de recursos/ativos e a maioria dos caches é limpa.

## CTRL + ALT + D

Alternar a visibilidade da **sobreposição de depuração** do FancyMenu.

# Janelas de Edição

Muitas janelas de edição do FancyMenu na v3.9.0 oferecem suporte à navegação por teclado com as **Teclas de Seta** e **Enter**. Muitas janelas também usam **CTRL + S** como atalho para **Concluído** e **ESC** como **Cancelar**.

As janelas reformuladas do Editor de Script de Ação, Gerenciar Requisitos e Gerenciar Variáveis também oferecem suporte a menus de contexto com o botão direito, pesquisa, desfazer/refazer e navegação por teclado em suas listas.
