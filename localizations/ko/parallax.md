# 패럴랙스 효과란 무엇인가요?

패럴랙스 효과는 메뉴 배경과 요소에 깊이가 있는 것처럼 보이게 만드는 멋진 시각 효과입니다. 마우스 커서를 움직이면 패럴랙스가 활성화된 요소가 약간씩 움직여, 2D 메뉴 안에 3D 공간이 있는 듯한 착시를 만들어냅니다. 

차를 타고 갈 때 가까이 있는 것들(예: 도로 표지판)이 멀리 있는 것들(예: 산)보다 더 빨리 움직이는 것처럼 보이는 상황을 떠올려 보세요. FancyMenu에서는 이와 같은 원리를 사용해 더 역동적이고 상호작용적인 경험을 제공합니다.

# FancyMenu에서 패럴랙스를 어디에 사용할 수 있나요?

FancyMenu에서는 패럴랙스 효과를 크게 두 곳에 사용할 수 있습니다:

1. **메뉴 배경**: 메뉴 전체 배경이 마우스 커서를 따라 약간 움직이게 만들기
2. **요소**: 이미지, 버튼, 텍스트 같은 개별 요소가 각각 독립적으로 움직이게 만들기

# 메뉴 배경에 패럴랙스 적용하는 방법

메뉴 배경에 패럴랙스 효과를 추가하는 방법은 아주 쉽습니다:

1. **CTRL+ALT+C**를 눌러 메뉴 바를 표시한 뒤 **Customization**으로 이동하여 메뉴 편집기를 엽니다
2. 새 레이아웃을 만들거나 기존 레이아웃을 편집합니다
3. **Layout → Properties**를 클릭합니다
4. **Menu Backgrounds**를 엽니다
5. 배경 유형으로 **Image**를 선택합니다
6. 이미지 배경을 설정합니다:
   - 이미지(로컬 또는 웹에서)를 선택합니다
   - 토글 버튼을 클릭하여 **Parallax Effect**를 활성화합니다
   - **Parallax Effect Intensity X**와 **Parallax Effect Intensity Y**를 설정합니다(0.0~1.0 사이)
   - 필요하면 **Invert Parallax Movement**를 활성화하여 방향을 바꿉니다

> **팁**: 강도 값이 높을수록 배경이 더 많이 움직입니다. FancyMenu 3.9.0에서는 X와 Y 강도를 각각 따로 설정할 수 있어, 가로 이동을 세로 이동보다 더 강하게 만들거나 그 반대로 설정할 수 있습니다.

# 개별 요소에 패럴랙스 적용하는 방법

레이어별 효과를 만들기 위해 개별 요소에도 패럴랙스를 적용할 수 있습니다:

1. 편집기에서 아무 요소나 클릭하여 선택합니다
2. 요소를 마우스 오른쪽 버튼으로 클릭하여 컨텍스트 메뉴를 엽니다
3. 아래로 스크롤하여 **Parallax Effect: Enabled/Disabled**를 찾습니다
4. 이를 **Enabled**로 전환합니다
5. **Parallax Intensity X**와 **Parallax Intensity Y** 값을 조정합니다(0.0~1.0 사이)
6. 필요하면 **Invert Parallax**를 활성화하여 이동 방향을 바꿉니다

# 멋진 패럴랙스 효과를 만드는 팁

## 요소를 레이어별로 배치하세요

서로 다른 요소에 서로 다른 패럴랙스 강도 값을 사용하면 깊이감을 만들 수 있습니다. X와 Y를 각각 따로 조정할 수 있습니다:

- **배경**: 낮은 강도(0.1-0.3)
- **중간 레이어 요소**: 중간 강도(0.3-0.6)
- **전경 요소**: 높은 강도(0.6-0.9)

마우스를 움직일 때 꽤 그럴듯한 3D 효과를 만들 수 있습니다!

## 일반 패럴랙스와 반전 패럴랙스를 함께 사용해 보세요

일부 요소는 **Invert Parallax Movement: Enabled**로, 다른 요소는 **Disabled**로 설정해 보세요. 이렇게 하면 요소들이 서로 반대 방향으로 움직여 깊이감이 더욱 살아납니다.

## 너무 과하게 사용하지 마세요

움직임이 너무 많으면 오히려 방해가 될 수 있습니다. 특히 강도 값을 높게 설정할 때는 패럴랙스 효과를 적절히 사용하는 것이 좋습니다.

# 문제 해결

## 패럴랙스가 작동하지 않나요?

1. 패럴랙스 효과가 활성화되어 있는지 확인하세요
2. 패럴랙스 강도가 0으로 설정되어 있지 않은지 확인하세요
4. "Slide Wide Images From Left To Right" 옵션이 비활성화되어 있는지 확인하세요(이 옵션은 패럴랙스와 충돌합니다)

## 패럴랙스 이동이 너무 빠르거나 느린가요?

**Parallax Intensity X/Y** 값을 조정하세요:
- 더 낮은 값(0에 가까움) = 더 느리고 미묘한 움직임
- 더 높은 값(1에 가까움) = 더 빠르고 강한 움직임

## 패럴랙스가 부드럽지 않거나 끊기는 것 같나요?

이는 패럴랙스 효과의 한계입니다. 마인크래프트는 정수 기반 좌표(정수 값)를 사용하기 때문에 요소가 약간 "튀는" 것처럼 느껴질 수 있습니다. 하지만 "일반" 패럴랙스 강도 값을 사용하고 너무 작거나 큰 값만 피한다면 크게 눈에 띄지 않아야 합니다.
