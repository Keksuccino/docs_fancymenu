# 패럴랙스 효과란?

패럴랙스 효과는 메뉴의 배경과 요소에 깊이가 있는 것처럼 보이게 해주는 멋진 시각 효과입니다. 마우스 커서를 움직이면 패럴랙스가 활성화된 요소가 살짝 움직여, 2D 메뉴 안에서 3D 공간처럼 보이는 착시를 만들어냅니다.

차를 타고 이동할 때를 떠올려 보세요. 가까운 것(도로 표지판 등)은 먼 것(산 등)보다 더 빨리 움직이는 것처럼 보입니다. FancyMenu에서는 이와 같은 원리를 사용해 더 역동적이고 상호작용적인 경험을 만들 수 있습니다.

# FancyMenu에서 패럴랙스를 어디에 사용할 수 있나요?

FancyMenu에서는 패럴랙스 효과를 크게 두 군데에 적용할 수 있습니다.

1. **메뉴 배경**: 전체 메뉴 배경이 마우스 커서를 따라 살짝 움직이게 하기
2. **요소**: 이미지, 버튼, 텍스트 같은 개별 요소가 독립적으로 움직이게 하기

# 메뉴 배경에 패럴랙스 적용하는 방법

메뉴 배경에 패럴랙스 효과를 추가하는 것은 아주 쉽습니다.

1. **CTRL+ALT+C**를 눌러 메뉴 바를 표시한 다음, **Customization**으로 이동해 메뉴 편집기를 엽니다.
2. 새 레이아웃을 만들거나 기존 레이아웃을 편집합니다.
3. **Layout → Properties**를 클릭합니다. 
4. **Menu Backgrounds**를 엽니다.
5. 배경 유형으로 **Image**를 선택합니다.
6. 이미지 배경을 설정합니다.
   - 이미지 선택하기(로컬 파일 또는 웹 이미지)
   - 토글 버튼을 클릭해 **Parallax Effect**를 활성화하기
   - **Parallax Effect Intensity X**와 **Parallax Effect Intensity Y**를 설정하기(0.0~1.0)
   - 필요하면 **Invert Parallax Movement**를 활성화해 이동 방향을 반대로 바꾸기

> **팁**: 강도 값이 높을수록 배경이 더 많이 움직입니다. FancyMenu 3.9.0부터는 X와 Y 강도를 각각 따로 설정할 수 있어, 가로 방향만 더 강하게 움직이도록 하거나 반대로 설정할 수 있습니다.

# 개별 요소에 패럴랙스 적용하는 방법

레이어 효과를 만들기 위해 개별 요소에도 패럴랙스를 추가할 수 있습니다.

1. 편집기에서 원하는 요소를 클릭해 선택합니다.
2. 요소를 우클릭해 컨텍스트 메뉴를 엽니다.
3. 아래로 스크롤해 **Parallax Effect: Enabled/Disabled**를 찾습니다.
4. 이를 **Enabled**로 전환합니다.
5. **Parallax Intensity X**와 **Parallax Intensity Y** 값을 조정합니다(0.0~1.0)
6. 필요하면 **Invert Parallax**를 활성화해 이동 방향을 바꿉니다.

# 멋진 패럴랙스 효과를 만드는 팁

## 요소를 레이어처럼 배치하기

서로 다른 요소에 서로 다른 패럴랙스 강도 값을 사용해 깊이를 표현해 보세요. X와 Y를 각각 따로 조정할 수 있습니다.

- **배경**: 낮은 강도(0.1~0.3)
- **중간 레이어 요소**: 중간 강도(0.3~0.6)
- **전경 요소**: 높은 강도(0.6~0.9)

마우스를 움직일 때 꽤 그럴듯한 3D 효과가 만들어집니다!

## 일반 방향과 반전 방향 패럴랙스 조합하기

몇몇 요소는 **Invert Parallax Movement: Enabled**로, 다른 요소는 **Disabled**로 설정해 보세요. 요소들이 서로 반대 방향으로 움직이면서 깊이감이 더 강해집니다.

## 너무 과하게 사용하지 않기

너무 많은 움직임은 오히려 산만할 수 있습니다. 특히 높은 강도 값에서는 패럴랙스 효과를 적당히 사용하는 것이 좋습니다.

# 문제 해결

## 패럴랙스가 작동하지 않나요?

1. 패럴랙스 효과가 활성화되어 있는지 확인합니다.
2. 패럴랙스 강도가 0으로 설정되어 있지 않은지 확인합니다.
4. "Slide Wide Images From Left To Right" 옵션이 비활성화되어 있는지 확인합니다. 이 옵션은 패럴랙스와 충돌합니다.

## 패럴랙스 움직임이 너무 빠르거나 느린가요?

**Parallax Intensity X/Y** 값을 조정하세요.
- 낮은 값(0에 가까움) = 더 느리고 은은한 움직임
- 높은 값(1에 가까움) = 더 빠르고 극적인 움직임

# 마무리

패럴랙스 효과는 마인크래프트 메뉴를 더 생동감 있고 상호작용적으로 만드는 훌륭한 방법입니다. 배경과 요소의 패럴랙스를 다양하게 조합해, 마우스 움직임에 반응하는 멋지고 역동적인 레이아웃을 만들어 보세요!

가장 좋은 효과는 종종 은은한 경우가 많습니다. 작은 움직임만으로도 몰입감 있는 경험을 만드는 데 충분합니다.
