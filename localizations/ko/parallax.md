# 시차 효과

시차는 마우스 움직임에 따라 배경이나 요소를 오프셋하여 시각적 깊이를 만들어냅니다.

# 이미지 메뉴 배경

1. 레이아웃 편집기 배경을 마우스 오른쪽 버튼으로 클릭합니다.
2. [**메뉴 배경**](./menu-backgrounds) -> **이미지**를 엽니다.
3. 이미지 소스를 설정합니다.
4. **시차 효과**를 활성화합니다.
5. X 및 Y 강도 값을 설정합니다.
6. 필요에 따라 **시차 이동 반전**을 활성화합니다.

X 및 Y 값은 수평 및 수직 이동을 각각 독립적으로 제어합니다. `0.0`(없음)부터 `1.0`(최대)까지의 값을 사용하세요.

# 요소

1. [요소](./elements)를 마우스 오른쪽 버튼으로 클릭합니다.
2. **시차 효과**를 활성화합니다.
3. **시차 강도 X**와 **시차 강도 Y**를 설정합니다.
4. 필요에 따라 이동을 반전합니다.

멀리 있는 레이어에는 더 낮은 강도를, 전경 레이어에는 더 높은 강도를 사용하세요. 큰 차이 또는 반전된 레이어는 더 강한 깊이 효과를 만듭니다.

# 문제 해결

- 강도 값이 `0`이면 해당 축에서는 움직임이 발생하지 않습니다.
- **왼쪽에서 오른쪽으로 넓은 이미지 슬라이드**는 배경 시차와 충돌하므로 비활성화해야 합니다.
- 매우 작은 움직임은 GUI 위치가 정수 픽셀을 사용하기 때문에 계단처럼 보일 수 있습니다.
