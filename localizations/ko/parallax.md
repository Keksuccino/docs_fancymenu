# 시차 효과

시차 효과는 마우스를 움직일 때 메뉴 배경이나 요소를 조금씩 움직입니다. 멀리 있는 레이어는 적게, 가까이 있는 레이어는 많이 움직이면 메뉴에 깊이감이 생깁니다.

<img width="640" alt="해 질 녘 풍경이 네 개의 레이어로 구성된 타이틀 화면. 마우스를 움직이면 앞쪽 나무가 가장 많이 움직이고, 언덕은 덜 움직이며, 산과 하늘은 아주 조금만 움직입니다." src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/parallax_scene.gif?raw=true">

[요소](/elements)와 **이미지** 및 **비디오** [메뉴 배경](/menu-backgrounds)에 사용할 수 있습니다.

# 요소

<img width="640" alt="왼쪽에 버튼이 세로로 배치된 타이틀 화면. 레이아웃 편집기에서 클릭과 Ctrl + 클릭으로 버튼 5개를 선택하고, 모두 시차 효과를 활성화한 뒤 시차 강도 (X)를 1.0으로 설정하고 저장 후 편집기를 닫습니다. 타이틀 화면에서 마우스를 좌우로 움직이면 버튼이 조금씩 움직이며, 로고와 풍경은 그대로 있습니다." src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/parallax_element_settings.gif?raw=true">

1. 레이아웃 편집기에서 요소를 마우스 오른쪽 버튼으로 클릭하고 아래로 스크롤해 **시차 효과**를 찾습니다.
2. **시차 효과**를 클릭해 **활성화**로 설정합니다.
3. **시차 강도 (X)**와 **시차 강도 (Y)**를 클릭해 이동 거리를 설정합니다.
4. 레이아웃을 저장하고 편집기를 닫습니다. 요소는 편집기 밖에서만 움직입니다.

여러 요소에 한 번에 효과를 적용하려면 먼저 요소를 [선택](/layout-editor#selecting)한 다음(`Ctrl` + 클릭하면 선택 항목에 요소가 추가됩니다) 그중 하나를 마우스 오른쪽 버튼으로 클릭합니다.

| 설정 | 기능 |
|---|---|
| **시차 효과** | 효과를 켭니다. |
| **시차 강도 (X)** | 요소가 좌우로 움직이는 거리입니다. `0.0`(전혀 움직이지 않음)부터 `1.0`까지 설정할 수 있습니다. 새 요소의 기본값은 `0.5`입니다. |
| **시차 강도 (Y)** | 요소가 위아래로 움직이는 거리입니다. |
| **시차 이동 반전** | 요소를 마우스와 같은 방향으로 움직입니다. 이 옵션을 끄면 반대 방향으로 움직입니다. |

`1.0`으로 설정하면 마우스가 화면 가장자리에 있을 때 요소가 화면 너비의 최대 5%만큼 좌우로, 화면 높이의 최대 5%만큼 위아래로 움직입니다. 화면 중앙에서는 요소가 원래 배치한 위치에 있습니다.

- 효과가 적용된 요소에 [고정된](/positioning-elements) 요소는 함께 움직이며, 고정된 요소 자체의 효과도 더해집니다.
- **화면 안에 유지**를 켜도 효과가 적용된 요소는 화면 안에 머물지 않으므로 화면 가장자리를 벗어날 수 있습니다.
- 늘어난 요소는 늘어난 방향으로 움직이지 않습니다.
- [바닐라 버튼과 슬라이더](/vanilla-elements)는 직접 이동한 뒤에만 움직입니다. 고정 지점을 **바닐라 (기본값)**으로 설정하면 게임이 배치한 위치에 그대로 있습니다.
- 버튼은 화면에 표시되는 위치에서 클릭할 수 있습니다.
- [스크롤 가능한 영역](/scrollable-areas), 그 안의 요소, 툴팁 요소에는 시차 효과가 적용되지 않습니다.

# 메뉴 배경

<img width="800" alt="레이아웃 편집기에서 메뉴 배경 및 이미지를 연 마우스 오른쪽 버튼 메뉴. 시차 효과, 시차 효과 강도 (X) 설정, 시차 효과 강도 (Y) 설정, 시차 이동 반전이 표시되어 있습니다." src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/parallax_background_settings.png?raw=true">

1. 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **메뉴 배경 -> 이미지**(또는 **비디오**)를 엽니다.
2. **시차 효과**를 클릭해 **활성화**로 설정합니다.
3. **시차 효과 강도 (X) 설정**과 **시차 효과 강도 (Y) 설정**을 지정합니다.

배경은 요소보다 훨씬 크게 움직입니다. 가장자리가 드러나지 않도록 배경은 강도에 비례해 커집니다. `1.0`이면 화면의 두 배 크기가 되고, 좌우로 화면 너비의 최대 절반만큼 움직입니다. 값을 낮게 설정하세요. 새 배경의 기본값은 `0.02`이며, `0.01`에서 `0.1` 사이가 적당합니다.

- **시차 이동 반전**을 켜면 배경이 마우스와 같은 방향으로 움직입니다.
- **넓은 이미지 왼쪽에서 오른쪽으로 슬라이드**와 **시차 효과**는 동시에 켤 수 없습니다.
- **텍스처 반복** 및 **배경 종횡비 유지** 옵션을 함께 사용할 수 있습니다.
- 배경은 레이아웃 편집기에서도 움직입니다.

# 깊이감 있는 장면 만들기

페이지 맨 위에 있는 장면은 타이틀 화면에 하늘과 세 개의 레이어를 배치한 예시입니다.

1. 하늘, 산, 언덕, 전경처럼 먼 곳부터 가까운 곳 순으로 장면을 여러 레이어로 그립니다. 하늘을 제외한 모든 레이어는 투명한 부분이 있는 PNG 이미지여야 합니다.
2. 하늘을 **이미지** 메뉴 배경으로 설정하고 시차 효과를 켭니다.
3. 나머지 레이어를 먼 곳부터 가까운 곳 순으로 각각 [이미지 요소](/elements#image)로 추가합니다. 가장 가까운 레이어가 맨 위에 오도록 합니다.
4. 레이어가 움직여도 가장자리가 드러나지 않도록 화면보다 조금 크게 만듭니다. 강도가 `1.0`인 레이어는 화면 너비보다 좌우로 각각 5%, 화면 높이보다 위아래로 각각 5% 더 커야 합니다. 화면 밖으로 배치하려면 **화면 안에 유지**를 끕니다.
5. 모든 레이어의 시차 효과를 켭니다. 먼 레이어는 강도를 낮게, 가까운 레이어는 높게 설정합니다.
6. 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **사용자 지정 요소를 바닐라 요소 뒤에 배치**를 **활성화**로 설정하면 레이어가 버튼과 로고 뒤에 표시됩니다.

장면에 사용된 강도는 다음과 같습니다.

| 레이어 | 강도 (X) | 강도 (Y) |
|---|---|---|
| 하늘 (메뉴 배경) | `0.02` | `0.01` |
| 산 | `0.35` | `0.2` |
| 언덕 | `0.6` | `0.3` |
| 전경 | `1.0` | `0.5` |

> [!TIP]
> Y축 강도는 X축 강도의 절반 정도로 설정하세요. 그러면 풍경의 지면이 위아래로 크게 흔들리지 않습니다.

# 알아두면 좋은 점

- 모든 움직임은 GUI의 정수 픽셀 단위로 처리되므로 강도가 낮으면 작은 단위로 움직입니다.
- 강도 설정에는 [플레이스홀더](/placeholders)를 사용할 수 있습니다. 플레이스홀더 위에 커서를 두고 옆에 표시되는 작은 메뉴에서 **일반 텍스트로 설정**을 클릭하세요. [변수](/variables)를 사용하면 플레이어가 직접 만든 설정 메뉴에서 효과의 강도를 낮출 수 있습니다.
