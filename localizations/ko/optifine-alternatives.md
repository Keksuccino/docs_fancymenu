# OptiFine 대체 모드

저는 OptiFine을 공식적으로 **_지원하지 않습니다_**.
대부분의 모드와 충돌하며, 소스 코드가 공개되어 있지 않기 때문에 이로 인해 발생한 버그를 수정하는 데 매우 답답하고 시간이 많이 듭니다.

대신 Oculus/Iris와 Rubidium/Sodium을 사용하세요.
훨씬 더 안정적이고, 이것저것 깨뜨리지 않습니다.

## Forge

- [Embeddium](https://www.curseforge.com/minecraft/mc-mods/embeddium) (성능 향상)
- [Oculus](https://www.curseforge.com/minecraft/mc-mods/oculus) (셰이더)
- [Capes](https://www.curseforge.com/minecraft/mc-mods/capes) (OptiFine를 설치하지 않아도 OptiFine 망토를 사용할 수 있게 해줍니다)
- [Just Zoom](https://legacy.curseforge.com/minecraft/mc-mods/just-zoom-forge) (OptiFine처럼 키를 눌러 확대할 수 있게 해줍니다)

## Fabric

- [Sodium](https://www.curseforge.com/minecraft/mc-mods/sodium) (성능 향상)
- [Lithium](https://modrinth.com/mod/lithium) (추가 성능 향상)
- [Iris](https://www.curseforge.com/minecraft/mc-mods/irisshaders) (셰이더)
- [Capes](https://www.curseforge.com/minecraft/mc-mods/capes) (OptiFine를 설치하지 않아도 OptiFine 망토를 사용할 수 있게 해줍니다)
- [Zoomify](https://www.curseforge.com/minecraft/mc-mods/zoomify) 또는 [Just Zoom](https://legacy.curseforge.com/minecraft/mc-mods/just-zoom-forge) (OptiFine처럼 키를 눌러 확대할 수 있게 해줍니다)
- [CIT Resewn](https://www.curseforge.com/minecraft/mc-mods/cit-resewn) (OptiFine 리소스 팩을 OptiFine 없이도 지원합니다)
