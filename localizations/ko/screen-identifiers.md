# 화면 식별자

FancyMenu는 화면 식별자를 사용하여 어떤 레이아웃이 어떤 화면에 속하는지 알아내고, 특정 화면의 버튼을 가리키거나, 모드가 특정 화면과 통신하거나 이를 사용자 지정해야 하는 다른 작업들을 수행합니다.

# 화면의 식별자 찾기

**디버그 오버레이**를 사용하면 현재 활성화된 메뉴의 식별자를 확인할 수 있습니다.
여기에는 현재 화면의 식별자가 표시되며, 왼쪽 클릭하면 클립보드에 복사할 수 있습니다.
