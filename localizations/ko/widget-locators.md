# 위젯 로케이터

위젯 로케이터는 메뉴 안의 특정 Vanilla/모드 위젯(버튼, 슬라이더, 텍스트 입력 필드)을 가리키는 데 사용됩니다. 이는 위젯과 어떤 방식으로든 상호작용해야 하는 FancyMenu의 일부 기능에 필요합니다.

# 위젯의 로케이터 얻기

Vanilla/모드 위젯의 로케이터를 얻는 방법은 두 가지가 있습니다.

첫 번째 방법은 해당 위젯이 포함된 메뉴에서 **디버그 오버레이**를 활성화한 다음, **CTRL + ALT + D**를 누르고 **위젯을 우클릭**하는 것입니다. 그러면 로케이터를 클립보드에 복사하는 옵션이 있는 컨텍스트 메뉴가 열립니다.

두 번째 방법은 해당 위젯이 포함된 메뉴의 **레이아웃 편집기**를 연 다음, **위젯 요소를 우클릭**하는 것입니다. 이 경우에도 로케이터를 클립보드에 복사하는 옵션이 있는 컨텍스트 메뉴가 열립니다.

>[!WARNING]
>디버그 오버레이에서 위젯을 **우클릭할 수 없거나**, 레이아웃 편집기에서 **표시되지 않는다면**, 해당 위젯은 FancyMenu에서 보이지 않는 것일 가능성이 높습니다. 즉, 그 경우에는 로케이터가 없습니다. 이는 주로 메뉴에 이상한 방식으로 추가된 모드 버튼에서 발생합니다.
