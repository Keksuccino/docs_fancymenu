# 버튼 요소를 버튼과 슬라이더용 템플릿으로 사용하기

버튼 요소를 다른 버튼은 물론 슬라이더의 템플릿으로도 사용할 수 있습니다. 이를 통해 메뉴 안의 모든 버튼/슬라이더, 또는 유니버설 레이아웃을 사용할 경우 모든 메뉴의 버튼/슬라이더에 특정 디자인을 적용할 수 있습니다.

> [!IMPORTANT]
> FancyMenu 3.9.0부터는 가능한 경우 버튼/슬라이더 템플릿 대신 [전역 사용자 지정](/global-customizations)을 사용하는 것이 권장됩니다. 전역 사용자 지정은 리소스 팩 없이도 바닐라 버튼과 슬라이더의 텍스처를 전역적으로 바꿀 수 있습니다. 광범위한 바닐라 UI 스타일링에는 전역 사용자 지정을 사용하고, 레이아웃별 동작이 필요할 때만 템플릿을 사용하세요.

# 시작하기 전에 알아둘 점

단일 버튼이나 슬라이더의 텍스처만 바꾸고 싶다면, 편집기에서 버튼이나 슬라이더(바닐라 및 커스텀)를 **마우스 오른쪽 클릭**하는 것이 가장 쉽고 권장됩니다. 버튼과 슬라이더의 **배경 텍스처**(및 슬라이더 핸들 텍스처)를 설정하는 옵션이 있습니다.

# 템플릿 버튼이란?

템플릿 버튼은 FancyMenu의 특별한 커스텀 버튼으로, 다른 버튼과 슬라이더의 모양과 동작을 제어할 수 있게 해줍니다. 여러 요소가 따르게 될 마스터 디자인을 만드는 것과 비슷합니다.

템플릿 버튼을 만들면 여러 버튼이나 슬라이더가 다음 항목을 공유하도록 할 수 있습니다.
- 크기(너비와 높이)
- 위치
- 표시 여부
- 불투명도(얼마나 투명한지)
- 텍스트 레이블
- **버튼 텍스처**(커스텀 텍스처가 설정된 경우 자동으로 공유됨)

메뉴를 일관되게 보이게 하거나, 여러 버튼을 한 번에 업데이트해야 할 때 매우 유용합니다!

# 누가 템플릿을 사용할 수 있나요?

오직 **커스텀 버튼**만 템플릿으로 사용할 수 있습니다. 하지만 이 템플릿은 다음 요소에 적용할 수 있습니다.
- 바닐라 버튼(기본 Minecraft 버튼)
- 커스텀 버튼(FancyMenu에서 만드는 버튼)
- 바닐라 슬라이더(예: 볼륨 조절)
- 커스텀 슬라이더(FancyMenu에서 만드는 슬라이더)

# 템플릿 버튼 만드는 방법

1. 사용자 지정할 화면의 FancyMenu 편집기를 엽니다
2. 레이아웃에 새 커스텀 버튼 요소를 추가합니다
3. 새 버튼을 마우스 오른쪽 클릭합니다
4. 메뉴에서 "Template Settings"를 선택합니다
5. "Is Template: ON"을 클릭해 템플릿 모드를 활성화합니다

이제 버튼을 다른 버튼과 슬라이더의 템플릿으로 사용할 준비가 되었습니다!

# 템플릿 공유 옵션

템플릿이 어떤 종류의 요소에 영향을 줄지 선택할 수 있습니다.
- **Buttons** - 템플릿이 버튼(바닐라 및 커스텀)에만 영향을 줍니다
- **Sliders** - 템플릿이 슬라이더(바닐라 및 커스텀)에만 영향을 줍니다

이 옵션을 설정하려면:
1. 템플릿 버튼을 마우스 오른쪽 클릭합니다
2. "Template Settings"로 이동합니다
3. "Share With: [현재 옵션]"을 클릭해 옵션을 순환합니다

> **Important**: 버튼용 템플릿 하나와 슬라이더용 템플릿 하나, 이렇게 두 개의 템플릿을 동시에 활성화할 수 있습니다. 즉, 같은 화면에서 요소 유형별로 별도의 템플릿 디자인을 만들 수 있습니다!

# 템플릿으로 적용할 수 있는 항목

템플릿이 다른 요소와 공유할 속성을 정확히 지정할 수 있습니다.

## 켜고 끌 수 있는 속성:

1. 템플릿 버튼을 마우스 오른쪽 클릭합니다
2. "Template Settings"로 이동합니다
3. 다음 옵션들을 원하는 대로 전환합니다.
   - **Width** - 영향을 받는 모든 요소의 너비를 템플릿과 같게 합니다
   - **Height** - 영향을 받는 모든 요소의 높이를 템플릿과 같게 합니다
   - **X Position** - 영향을 받는 모든 요소를 템플릿과 같은 X 좌표에 배치합니다
   - **Y Position** - 영향을 받는 모든 요소를 템플릿과 같은 Y 좌표에 배치합니다
   - **Opacity** - 영향을 받는 모든 요소의 투명도를 템플릿과 같게 합니다
   - **Visibility** - 영향을 받는 요소를 표시할지 숨길지 제어합니다
   - **Label** - 영향을 받는 모든 요소가 템플릿과 같은 텍스트를 사용하게 합니다

## 항상 공유되는 속성:

- **Button textures** - 템플릿에 커스텀 텍스처를 설정하면, 영향을 받는 모든 요소에 자동으로 적용됩니다
  - 다른 속성과 달리 텍스처 공유는 끌 수 없습니다
  - 텍스처는 템플릿에 실제로 커스텀 텍스처가 설정되어 있을 때만 적용됩니다
  - 커스텀 텍스처가 설정되어 있지 않으면 원래 요소의 텍스처가 사용됩니다

# 템플릿 외형 사용자 지정

템플릿 버튼도 다른 버튼과 마찬가지로 사용자 지정할 수 있습니다.

1. 템플릿 버튼을 마우스 오른쪽 클릭합니다
2. 다음을 설정할 수 있습니다.
   - 버튼 텍스처(일반, 호버, 비활성 상태)
   - 레이블(일반 및 호버)
   - 소리(호버 및 클릭)
   - 툴팁

버튼의 경우 서로 다른 상태에 대해 커스텀 텍스처를 설정할 수 있습니다.
- 일반 배경(상호작용하지 않을 때)
- 호버 배경(마우스가 위에 있을 때)
- 비활성 배경(버튼이 비활성화되었을 때)

슬라이더의 경우 다음도 설정할 수 있습니다.
- 슬라이더 핸들 텍스처
- 슬라이더 배경 텍스처

# 중요한 팁

1. **템플릿 버튼은 게임 안에 표시되지 않습니다** - 편집기에서만 보이므로, 편한 곳에 배치하면 됩니다.

2. **두 개의 템플릿을 동시에 활성화할 수 있습니다** - 버튼용 템플릿 하나와 슬라이더용 템플릿 하나를 동시에 활성화할 수 있습니다.

3. **유형별로 활성 템플릿은 하나만 사용됩니다** - 버튼 템플릿이 여러 개 있더라도, 요소 목록에서 가장 위에 있는 것만 버튼에 사용됩니다. 슬라이더 템플릿도 마찬가지입니다.

4. **템플릿 변경 사항은 즉시 적용됩니다** - 템플릿을 편집하면 영향을 받는 모든 버튼과 슬라이더가 바로 업데이트됩니다.

5. **올바른 공유 모드를 사용하세요** - "Buttons" 모드는 슬라이더에 영향을 주지 않으며, "Sliders" 모드는 버튼에 영향을 주지 않는다는 점을 기억하세요.

6. **속성을 선택적으로 적용하세요** - 모든 속성을 적용할 필요는 없습니다. 예를 들어 텍스처와 크기만 템플릿으로 적용하고, 요소가 원래 위치를 유지하게 할 수도 있습니다.

7. **텍스처는 설정되면 항상 공유됩니다** - 다른 속성과 달리 템플릿에 적용한 커스텀 텍스처는 일치하는 요소와 자동으로 공유됩니다. 이 기능을 켜거나 끌 필요가 없습니다.

# 사용 예시

- 화면의 모든 버튼에 일관된 스타일 적용
- 별도의 템플릿으로 모든 슬라이더를 사용자 지정 테마에 맞춤
- 여러 버튼을 한 번에 표시/숨기기 위한 "숨김 모드" 만들기
- 한 번의 편집으로 여러 버튼의 크기 변경
- 메뉴의 모든 버튼에 동일한 커스텀 텍스처와 소리 적용
