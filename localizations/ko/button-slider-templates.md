# 버튼 및 슬라이더 템플릿

템플릿은 화면의 다른 모든 버튼 또는 슬라이더에 모양을 적용하는 [버튼 요소](/elements#button)입니다. 기본 제공 버튼과 직접 만든 버튼 모두에 적용됩니다. 템플릿을 변경하면 다른 요소에도 변경 사항이 적용됩니다.

> [!TIP]
> 게임의 모든 메뉴에서 같은 모양을 사용하려면 대신 [전역 사용자 지정](/global-customizations)을 사용하세요. 템플릿은 한 화면이나 [범용 레이아웃](/universal-layouts)이 불러오는 모든 화면에 적용됩니다.

# 템플릿 만들기

1. 레이아웃에 버튼 요소를 추가합니다.
2. 요소를 마우스 오른쪽 버튼으로 클릭하고 **템플릿 설정**을 연 다음 **템플릿 모드**를 켭니다.
3. **설정 공유 대상**을 **버튼** 또는 **슬라이더**로 설정합니다.
4. 다른 버튼과 마찬가지로 템플릿에 원하는 텍스처, 사운드, 레이블 설정을 지정합니다. **슬라이더**로 설정하면 텍스처 설정이 슬라이더 텍스처에 적용됩니다.

템플릿은 편집기 밖에서는 표시되지 않으므로, 방해되지 않는 곳에 배치하면 됩니다. 편집기에서는 슬라이더 템플릿이 슬라이더처럼 보입니다.

# 템플릿이 공유하는 항목

## 항상 공유

- 템플릿의 버튼 텍스처(또는 슬라이더 텍스처)와 [나인 슬라이싱](/nine-slicing-and-tiling) 설정
- 템플릿의 마우스 오버, 마우스 오버 해제, 클릭 사운드

템플릿이 적용되는 동안 버튼은 자체 텍스처와 사운드 대신 템플릿의 텍스처와 사운드를 사용합니다. 템플릿에 텍스처가 없으면 버튼도 자체 텍스처를 사용하지 않습니다.

## 설정을 켰을 때 공유

템플릿의 **템플릿 설정**에서 다음 항목을 켜세요.

| 설정 | 버튼이 템플릿에서 가져오는 항목 |
|---|---|
| **템플릿 모드에서 레이블 공유** | 템플릿의 **레이블** 및 **마우스 오버 레이블**과 레이블 스타일 전체: **레이블 정렬**, **레이블 크기**, **레이블 기본 색상**, **레이블 마우스 오버 색상**, **레이블 그림자**, **마우스 오버 시 레이블에 밑줄 표시** |
| **템플릿 모드에서 X 위치 공유** 및 **템플릿 모드에서 Y 위치 공유** | 템플릿의 위치. 기본 제공 버튼은 **기본값(원래 위치)**이 아닌 **기준점**을 선택해야 이동합니다. |
| **템플릿 모드에서 불투명도 공유** | 템플릿의 불투명도 |

## 모든 버튼의 레이블 정렬

**템플릿 모드에서 레이블 공유**를 켜면 모든 버튼이 템플릿의 텍스트도 가져오므로, 모든 버튼에 같은 문구를 표시할 화면에서 사용하도록 만들어진 기능입니다.

텍스트는 그대로 두고 레이블만 정렬하려면 다음 방법을 사용하세요.

- 한 화면에서 적용하려면 `Ctrl`을 누른 채 클릭하여 버튼을 선택한 다음([선택](/layout-editor#selecting) 참고), 버튼 중 하나를 마우스 오른쪽 버튼으로 클릭하고 **레이블 정렬**을 설정합니다. 선택한 버튼 전체에 한 번에 적용됩니다.
- 모든 메뉴에 적용하려면 [전역 사용자 지정](/global-customizations#labels)에서 **레이블 정렬**을 사용하세요.

# 알아두면 좋은 점

- 버튼 요소만 템플릿으로 사용할 수 있지만, 기본 제공 버튼과 직접 만든 버튼 및 슬라이더에 모두 적용됩니다.
- 한 화면에서 버튼용 템플릿과 슬라이더용 템플릿을 동시에 하나씩 사용할 수 있습니다. 같은 종류의 템플릿이 여러 개 있으면 하나만 적용됩니다.
- 템플릿은 표시되는 동안에만 적용됩니다. 템플릿에 [표시 조건](/element-visibility)을 설정하면 템플릿을 켜고 끌 수 있습니다.
