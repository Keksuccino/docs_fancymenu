# 레이아웃 편집기

레이아웃 편집기에서 [레이아웃](/home#your-first-layout)을 만들 수 있습니다. 요소를 추가하고 이동하거나 크기를 조정하고, 요소 주변의 메뉴를 변경할 수 있습니다. 플레이어에게 보이는 그대로 메뉴가 표시되므로 레이아웃의 모습을 바로 확인할 수 있습니다.

# 편집기 열기

1. 제목 화면처럼 변경할 메뉴를 엽니다.
2. **메뉴 표시줄 -> 사용자 지정 -> 현재 화면 사용자 지정**을 클릭해 **활성화됨**으로 표시되게 합니다.
3. **메뉴 표시줄 -> 사용자 지정 -> 레이아웃 -> 새로 만들기 -> 현재 화면용**을 클릭합니다.

- **모든 화면용 [범용]**은 모든 메뉴에 표시되는 [범용 레이아웃](/universal-layouts)을 만듭니다.
- 이미 만든 레이아웃도 **레이아웃** 목록에 표시됩니다. 레이아웃에 마우스를 올린 다음 **레이아웃 편집**을 클릭합니다.
- 어떤 메뉴에서든 `Ctrl + Alt + L`을 누르면 마지막으로 편집한 레이아웃이 열립니다. [메뉴 표시줄 단축키](/home#menu-bar-shortcuts)를 참조하세요.

# 편집기 한눈에 보기

<img width="800" alt="선택된 서버 접속 버튼, 위쪽 메뉴 표시줄, 오른쪽의 레이어 위젯이 보이는 레이아웃 편집기" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/layout_editor_overview.png?raw=true">

- 배경을 마우스 오른쪽 버튼으로 클릭하면 전체 레이아웃의 설정을 열고 **새 요소**를 눌러 요소를 추가할 수 있습니다.
- 요소를 마우스 오른쪽 버튼으로 클릭하면 해당 요소의 설정을 열 수 있습니다. [요소](/elements#settings-of-all-elements)를 참조하세요.
- 오른쪽의 **레이어**에는 레이아웃의 모든 요소가 표시됩니다. [레이어 및 그룹](#layers-and-groups)을 참조하세요.
- 위쪽 메뉴 표시줄:

| 메뉴 | 포함 항목 |
|---|---|
| **레이아웃** | **새로 만들기**, **열기**, **저장**, **다른 이름으로 저장**, **AI용 레이아웃 내보내기**, **레이아웃 속성**(배경을 마우스 오른쪽 버튼으로 클릭했을 때와 동일), **설정**, **편집기 닫기** |
| **편집** | **실행 취소**, **다시 실행**, **복사**, **붙여넣기**, **모두 선택** |
| **요소** | 요소를 추가하는 **새로 만들기**, [삭제한 바닐라 요소](/deleted-vanilla-elements)를 복원하는 **삭제된 바닐라 요소** |
| **창** | **편집기 위젯**, [격자](#grid-and-anchor-overlay), [앵커 오버레이](#grid-and-anchor-overlay), **요소 회전 컨트롤**, **요소 기울이기 컨트롤** |

## 레이아웃 설정

배경을 마우스 오른쪽 버튼으로 클릭하면 레이아웃 자체에 관한 모든 설정을 볼 수 있습니다. 예를 들면 다음과 같습니다.

- [**메뉴 배경**](/menu-backgrounds) 및 [**장식 오버레이**](/decoration-overlays)
- 일부 메뉴 위쪽에 표시되는 "옵션" 같은 텍스트를 설정하는 **사용자 지정 화면 제목**. 여기에 [플레이스홀더](/placeholders)를 사용할 수 있습니다.
- [스크롤 가능한 화면](/customizing-scrollable-screens)의 [**머리글/바닥글 사용자 지정**](/customizing-scrollable-screens)
- 한 메뉴에서 [여러 레이아웃을 사용할 때](/randomize-layouts) 설정하는 **레이아웃 인덱스 [다중 레이아웃 순서]** 및 **무작위 모드**
- **로딩 요구 사항 [전체 레이아웃]**. [요구 사항](/conditions#layout-wide-requirements)을 참조하세요.
- **'화면 열기' 액션 스크립트 편집** 및 **'화면 닫기' 액션 스크립트 편집**. [액션 스크립트](/action-scripts)를 참조하세요.
- [범용 레이아웃](/universal-layouts)에서만 사용할 수 있는 **범용 레이아웃 옵션**

# 요소 작업하기

## 선택

- 요소를 클릭해 선택합니다. 배경을 클릭하면 선택이 모두 해제됩니다.
- 배경을 가로질러 드래그하면 사각형 안의 모든 요소를 선택합니다.
- `Ctrl`을 누른 채 클릭하면 요소를 선택 항목에 추가하거나, 이미 선택된 요소를 선택 항목에서 제외합니다.
- `Ctrl + A`를 누르면 모든 요소를 선택합니다.

클릭, 사각형 선택, `Ctrl + A`는 [레이어에서 숨긴](#hiding-and-renaming) 요소를 선택하지 않습니다.

## 이동

- 요소를 드래그해 이동합니다. 선택된 요소 여러 개를 이동하려면 드래그를 시작할 때 `Ctrl`을 누른 상태로 유지합니다. `Ctrl`을 누르지 않으면 클릭한 요소만 선택됩니다.
- 화살표 키를 누르면 선택된 요소가 1픽셀씩 이동합니다.
- 드래그하는 동안 앵커 지점이 표시됩니다. 요소를 다른 앵커 지점이나 요소 위에 올려놓으면 해당 지점에 고정됩니다. [요소 배치](/positioning-elements)를 참조하세요.
- 요소를 [스크롤 가능 영역](/scrollable-areas)에 놓으면 해당 영역 안으로 들어갑니다.

## 크기 조정

선택한 요소의 가장자리나 모서리를 드래그합니다. 종횡비를 유지하려면 `Shift`를 누른 상태로 드래그합니다.

한 번에 요소 하나만 선택했을 때 크기를 조정할 수 있습니다.

## 회전 및 기울이기

회전 및 기울이기를 지원하는 요소를 선택하면 [회전 및 기울이기](/rotating-elements) 컨트롤이 표시됩니다. 드래그하는 동안 `Shift`를 누르면 일정한 간격으로 맞춰집니다. 회전은 45°, 기울이기는 15° 단위입니다.

**창 -> 요소 회전 컨트롤** 및 **요소 기울이기 컨트롤**을 사용하면 해당 컨트롤을 숨길 수 있습니다.

## 복사, 붙여넣기 및 삭제

- `Ctrl + C`를 누르면 선택한 요소를 복사하고, `Ctrl + V`를 누르면 붙여넣습니다. 복사본은 원본 위에 놓인 상태로 선택되므로 바로 드래그해 옮길 수 있습니다.
- 게임을 종료하기 전까지는 다른 레이아웃에도 붙여넣을 수 있습니다.
- `Delete`를 누르면 선택한 요소가 삭제됩니다. 바닐라 요소는 숨겨지기만 합니다. **요소 -> 삭제된 바닐라 요소**를 사용해 복원하세요.
- 스크롤 가능 영역을 삭제하면 그 안의 콘텐츠도 함께 삭제할지, 레이아웃에 남겨둘지 묻는 메시지가 표시됩니다.

## 실행 취소 및 다시 실행

`Ctrl + Z`를 누르면 마지막 변경 사항을 취소하고, `Ctrl + Y`를 누르면 취소한 변경 사항을 다시 적용합니다. 두 기능은 **편집** 메뉴에서도 사용할 수 있습니다.

## 보이지 않는 요소

플레이어는 [오디오](/elements#audio), [드래거](/dragger), [요소 애니메이터](/element-animator), [음악 컨트롤러](/elements#music-controller), [티커](/elements#ticker) 요소를 볼 수 없습니다. 편집기에서는 이러한 요소가 이름이 표시된 색상 상자로 나타나므로 찾아서 이동하거나 크기를 조정할 수 있습니다.

- 요소를 마우스 오른쪽 버튼으로 클릭하고 **편집기 내 색상**을 선택하면 상자 색상을 변경할 수 있습니다. 예를 들어 티커를 여러 개 사용할 때 각각을 구분하는 데 유용합니다. 색상은 `#RRGGBB` 형식이며, 투명도를 포함하려면 `#RRGGBBAA` 형식을 사용합니다. `#E30E2366`처럼 비쳐 보이는 색상은 상자 뒤쪽을 보여 줍니다.
- 상자에 표시되는 이름은 요소의 레이어 이름입니다. [숨기기 및 이름 바꾸기](#hiding-and-renaming)를 참조하세요.

플레이어에게는 상자와 그 색상, 이름이 표시되지 않습니다.

# 레이어 및 그룹

**레이어**에는 레이아웃의 모든 요소가 위에서부터 표시됩니다. 목록에서 위쪽에 있는 요소가 아래쪽의 모든 요소 앞에 나타납니다. **창 -> 편집기 위젯 -> 레이어**를 클릭하면 레이어 목록을 표시하거나 숨길 수 있습니다.

## 순서 변경

- 레이어를 클릭해 해당 요소를 선택한 다음 위아래로 드래그합니다. 놓일 위치에 선이 표시됩니다. 선택한 레이어는 모두 함께 이동합니다.
- 또는 요소나 해당 레이어를 마우스 오른쪽 버튼으로 클릭하고 **레이어 한 단계 위로 이동** 또는 **레이어 한 단계 아래로 이동**을 클릭합니다.

편집기에서는 선택된 요소가 항상 다른 요소 앞에 표시됩니다. 실제 순서를 확인하려면 선택을 해제하세요.

일부 Minecraft 버전에서는 [플레이어 엔티티](/elements#player-entity) 및 [아이템](/elements#item) 요소가 레이어 순서와 관계없이 항상 맨 앞에 표시됩니다. [알려진 문제](/known-issues#1-player-entity--item-elements-are-always-in-front-of-everything)를 참조하세요.

## 바닐라 요소

**바닐라 요소** 행은 버튼처럼 메뉴 자체에 포함된 모든 요소를 나타냅니다. 이 요소들의 순서는 변경할 수 없지만, 행 오른쪽의 버튼을 누르면 모든 사용자 요소를 바닐라 요소의 뒤나 앞으로 보낼 수 있습니다. 배경을 마우스 오른쪽 버튼으로 클릭했을 때의 **바닐라 요소 뒤에 사용자 요소 표시**와 같은 기능입니다.

## 숨기기 및 이름 바꾸기

- 레이어의 눈 아이콘을 누르면 편집기에서 해당 요소가 숨겨집니다. 다른 요소를 편집하는 동안 방해받지 않도록 숨길 수 있습니다. 눈 아이콘을 다시 클릭하면 요소가 표시됩니다.
- 숨겨진 요소는 클릭하거나 이동하거나 복사하거나 삭제할 수 없습니다. 플레이어에게는 계속 표시되며, 편집기에서만 숨겨집니다. 레이아웃은 숨긴 요소를 기억합니다.
- 레이어를 마우스 오른쪽 버튼으로 클릭하고 **레이어 이름 바꾸기**를 선택하면 `뉴스 패널`처럼 알아보기 쉬운 이름을 지정할 수 있습니다. 이 이름은 요소의 **편집기 내 표시 이름**과 동일하며 플레이어에게는 표시되지 않습니다.

## 그룹

그룹을 사용하면 뉴스 패널의 각 부분처럼 서로 관련된 레이어를 하나의 이름 아래에 모을 수 있습니다. 그룹은 목록의 순서만 정리하며 요소는 이전과 동일하게 표시되고 작동합니다.

- 레이어 목록 안을 마우스 오른쪽 버튼으로 클릭하고 **그룹 추가**를 선택합니다. 그룹은 레이어 아래에 표시됩니다.
- 레이어를 그룹 위로 드래그해 그룹에 넣습니다. 그룹 밖으로 드래그하면 그룹에서 꺼낼 수 있습니다.
- 그룹을 클릭하면 그룹에 포함된 모든 요소가 선택됩니다. 그룹을 드래그하면 포함된 요소를 모두 한꺼번에 위아래로 이동할 수 있습니다.
- 그룹의 화살표를 누르면 그룹의 레이어를 접거나 펼칠 수 있고, 눈 아이콘을 누르면 그룹의 모든 레이어를 숨기거나 표시할 수 있습니다.
- 그룹을 마우스 오른쪽 버튼으로 클릭하면 이름을 바꾸거나, 한 단계 위나 아래로 이동하거나, 삭제할 수 있습니다. **그룹 삭제**를 선택해도 그룹 안의 요소는 그대로 유지됩니다.

**레이어 한 단계 위로 이동** 및 **레이어 한 단계 아래로 이동**을 사용하면 요소가 그룹 안에 그대로 유지됩니다. 요소를 그룹에서 꺼내려면 해당 레이어를 그룹 밖으로 드래그하세요.

레이아웃은 그룹과 그룹을 접었는지 여부를 저장합니다.

## 스크롤 가능 영역

[스크롤 가능 영역](/scrollable-areas)에 포함된 요소는 영역의 레이어 아래에 들여쓰기되어 표시됩니다.

- 레이어를 영역 레이어의 아래쪽 절반으로 드래그하면 요소가 해당 영역 안으로 들어갑니다. 다른 레이어 사이로 드래그해 빼내면 영역에서 나옵니다. 화면에서의 위치는 그대로 유지됩니다.
- 영역 레이어의 화살표를 누르면 영역의 요소를 접거나 펼칠 수 있습니다.
- 영역 안의 요소는 어떤 그룹에도 속하지 않습니다. 해당 요소는 영역과 함께 이동합니다.

# 격자 및 앵커 오버레이

**창** 메뉴에서 편집기의 보조 기능을 설정할 수 있습니다.

- **격자**를 선택하면 격자선이 표시됩니다. `Ctrl + G`를 누르면 격자선을 켜거나 끌 수 있습니다. **격자 크기**에서는 격자선 사이의 간격을 설정합니다.
- **격자에 맞추기**를 켜면 격자가 표시되는 동안 드래그한 요소가 격자선에 맞춰집니다. **격자 맞춤 강도**에서 맞춤 강도를 설정합니다.
- **앵커 오버레이 표시 여부**에서 앵커 지점이 표시되는 방식을 설정합니다.
  - **요소를 드래그할 때 표시**: 요소를 드래그하는 동안 표시합니다.
  - **항상 표시**: 항상 표시합니다.
  - **키를 누를 때 표시(키 "O")**: `O`를 누르고 있는 동안 표시합니다.
  - **사용 안 함**: 표시하지 않습니다.
- **앵커 영역에 올리기**를 켜면 요소를 앵커 지점 위에 올렸을 때 해당 요소의 앵커가 변경됩니다. **앵커 요소에 올리기**를 켜면 다른 요소도 앵커 지점으로 사용할 수 있습니다. 이 기능은 **앵커 영역에 올리기**도 켜져 있을 때만 작동합니다.

# 저장 및 닫기

- `Ctrl + S`를 누르거나 **레이아웃 -> 저장**을 선택하면 레이아웃이 저장됩니다. 처음 저장할 때는 FancyMenu에서 파일 이름을 입력하라고 요청합니다.
- **레이아웃 -> 다른 이름으로 저장**을 선택하면 레이아웃을 새 파일로 저장합니다.
- 저장되지 않은 변경 사항이 있으면 메뉴 표시줄에 **\* 저장되지 않은 변경 사항! \***이 표시됩니다.
- 메뉴 표시줄 오른쪽의 X를 클릭하거나 **레이아웃 -> 편집기 닫기**를 선택하면 편집기가 닫힙니다. 저장되지 않은 변경 사항이 있으면 먼저 확인 메시지가 표시됩니다.

# 단축키

macOS에서는 `Ctrl` 대신 `Cmd`를 사용합니다.

| 단축키 | 기능 |
|---|---|
| `Ctrl + S` | 저장 |
| `Ctrl + Z` | 실행 취소 |
| `Ctrl + Y` | 다시 실행 |
| `Ctrl + C` | 선택한 요소 복사 |
| `Ctrl + V` | 붙여넣기 |
| `Ctrl + A` | 모든 요소 선택 |
| `Delete` | 선택한 요소 삭제 |
| 화살표 키 | 선택한 요소를 1픽셀씩 이동 |
| `Ctrl` + 클릭 | 요소를 선택 항목에 추가하거나 선택 항목에서 제외 |
| `Ctrl` + 드래그 | 선택한 요소 여러 개 이동 |
| `Shift` + 크기 조정 | 종횡비 유지 |
| `Shift` + 회전 또는 기울이기 | 일정한 간격으로 맞춤 |
| `Ctrl + G` | 격자 켜기 또는 끄기 |
| `O` 누르기 | **키를 누를 때 표시(키 "O")**가 설정된 경우 앵커 지점 표시 |

> [!TIP]
> 텍스트 편집기에는 자체 단축키가 있습니다. [메뉴의 텍스트](/text-in-menus#the-text-editor)를 참조하세요. [액션 스크립트](/action-scripts#shortcuts) 같은 창의 단축키는 해당 설명 페이지에 나와 있습니다.
