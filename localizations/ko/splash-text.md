# 사용자 지정 스플래시 텍스트 요소

FancyMenu의 스플래시 텍스트 요소는 Minecraft의 튀어 오르는 제목 스플래시를 완전히 사용자 지정할 수 있게 확장한 버전입니다. 익숙한 튀는 효과는 그대로 유지하면서, 어떤 문구를 표시할지, 어떻게 보일지, 언제 갱신될지를 직접 제어할 수 있습니다.

> 기본 Title 화면의 Vanilla 스플래시 텍스트 요소는 사실상 사용자 지정이 불가능하므로, 이를 **삭제**하고 대신 사용자 지정 스플래시 텍스트 요소를 사용해야 합니다.
{.is-warning}

## 요소 추가 및 선택하기
- 레이아웃 편집기를 열고 `Splash Text`라는 요소를 추가합니다.
- 한 번 왼쪽 클릭하여 선택하고 경계 상자를 표시한 다음, 오른쪽 클릭하여 컨텍스트 메뉴를 엽니다. 모든 설정 옵션은 그 메뉴 안에 있습니다.

## 스플래시 텍스트의 출처 선택하기
- `Source Mode: Vanilla`는 Minecraft에 기본 포함된 전통적인 무작위 스플래시를 유지합니다.
- `Source Mode: Direct Input`은 `Input Splash Text`를 통해 직접 텍스트를 입력할 수 있게 해줍니다. 이 방식은 스플래시 텍스트 한 줄만 지원하지만, 그 줄 안에 플레이스홀더를 넣을 수 있습니다.
- `Source Mode: Text File`은 `Set Source Text File`로 선택한 `.txt` 파일에서 무작위 한 줄을 가져옵니다. 비어 있지 않은 각 줄이 활성 스플래시가 될 수 있습니다.
- 모드를 바꾸면 활성 텍스트가 초기화되므로 안심하고 시험해 볼 수 있습니다. 텍스트가 고정된 것처럼 느껴지면 다른 모드로 전환했다가 다시 돌아오거나, 메뉴가 열릴 때마다 다시 뽑히도록 `Refresh On Screen Load: Enabled`를 켜세요.

## 예시 텍스트 파일
"Text File" 소스 모드를 사용할 때는 스플래시 목록을 일반 텍스트(UTF-8, BOM 없음)로 저장하세요. 각 줄이 하나의 스플래시 후보입니다:

```
FancyMenu에 오신 것을 환영합니다!
{"placeholder":"your_placeholder_id_here"}
{"text":"이 문장은 금색이고 굵게 표시됩니다.","color":"gold","bold":true}
&6Minecraft 서식 코드를 &l사용해 보세요!
```

`your_placeholder_id_here`를 런타임에 해석할 플레이스홀더로 바꾸세요. FancyMenu는 스플래시가 갱신될 때마다 비어 있지 않은 줄 중 하나를 무작위로 선택합니다.

## 원하는 모양으로 만들기
- 크기와 회전 각도는 `Set Scale`과 `Set Rotation`으로 조절합니다.
- `Set Text Color`는 테마에 맞는 hex 값(예: `#FFFF00`)을 입력할 수 있습니다.
- `Shadow: Enabled`는 Minecraft의 그림자를 추가합니다. 평면 텍스트가 필요하면 끄세요.
- `Bouncing: Enabled`는 익숙한 흔들리는 동작을 유지합니다. 정적인 레이블이 필요하면 비활성화하세요.
- FancyMenu는 스플래시를 완전한 Minecraft 컴포넌트로 렌더링하므로, 색상 코드와 다른 텍스트 장식도 예상대로 작동합니다.

## 동적 텍스트 기능
- 플레이스홀더는 렌더링 전에 해석되므로, 스플래시 텍스트 안에 플레이어 이름, 날짜 또는 다른 지원되는 값을 참조할 수 있습니다.
- 이 요소는 Minecraft의 직렬화된 컴포넌트 JSON을 지원하므로, Direct Input이나 텍스트 파일에 고급 JSON 조각을 붙여 넣을 수 있습니다. 요소가 이를 자동으로 역직렬화하며, 문제가 생기면 일반 텍스트로 되돌아갑니다.

## 문제 해결
- Direct Input에서 텍스트가 비어 있으면 편집 중에 `< empty splash element >`가 표시됩니다. 경고를 없애려면 무엇이든 입력하세요(공백 한 칸도 가능).
- 텍스트 파일에 유효한 줄이 하나도 없으면 요소에 `ERROR: SPLASH FILE IS EMPTY`가 표시됩니다. 비어 있지 않은 줄을 최소 하나 추가한 뒤 화면을 다시 여세요.
- 직렬화된 JSON에 오류가 있으면 일반 텍스트로 대체됩니다. Mojang의 표준 JSON 구조를 사용하거나, 붙여 넣기 전에 바닐라 `/tellraw` 명령으로 테스트해 보세요.
