# 요소 회전 및 기울이기

대부분의 요소는 회전하거나 기울일 수 있습니다. 두 작업 모두 요소의 중심을 기준으로 이루어지며, 요소의 위치와 크기는 그대로 유지됩니다.

- **회전**은 시곗바늘처럼 요소를 돌립니다.
- **세로 기울이기**는 요소를 뒤로 젖히고, **가로 기울이기**는 옆으로 돌립니다. 기울어진 요소는 원근감 없이 표시되므로 세로로 짧아지거나 가로로 좁아지기만 합니다. 두 방향 모두 기울이면 비스듬해집니다.

# 레이아웃 편집기에서

<img width="800" alt="레이아웃 편집기에서 원 주위의 조절 핸들로 시즌 3 스티커를 회전한 다음, 오른쪽과 아래쪽 선의 조절 핸들로 패치 노트 패널을 기울입니다." src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/rotating_tilting_editor.gif?raw=true">

[레이아웃 편집기](/layout-editor)에서 요소를 선택하고 조절 핸들을 드래그합니다.

- 요소 주위의 원에 있는 조절 핸들로 요소를 회전합니다.
- 오른쪽 선에 있는 조절 핸들로 **세로 기울이기**를 설정하고, 아래쪽 선에 있는 핸들로 **가로 기울이기**를 설정합니다. 선의 가운데는 기울이지 않은 상태입니다.

드래그하는 동안 다음과 같이 할 수 있습니다.

- `Shift`를 누르면 일정한 단위로 맞춰집니다. 회전은 45도, 기울이기는 15도 단위입니다.
- 0에 가까워지면 조절 핸들이 0에 맞춰지므로 요소를 쉽게 다시 똑바로 만들 수 있습니다.
- 요소의 왼쪽 위에 회전 및 기울기 값이 표시됩니다.

알아 두면 좋습니다.

- 선택 프레임은 똑바른 상태를 유지합니다. 프레임 안을 클릭하면 요소를 선택하거나 이동할 수 있습니다.
- 조절 핸들은 요소 하나를 선택했을 때만 표시됩니다.
- 원이나 선이 없는 요소는 회전하거나 기울일 수 없습니다. [회전하거나 기울일 수 없는 요소](#elements-without-rotation-or-tilt)를 참고하세요.
- **메뉴 바 -> 창 -> 요소 회전 컨트롤** 및 **요소 기울이기 컨트롤**을 사용하면 모든 요소의 조절 핸들을 숨길 수 있습니다.

# 정확한 값

요소를 마우스 오른쪽 버튼으로 클릭해 다음 설정을 찾으세요. 각 설정에는 **숫자 선택기로 설정**, **일반 텍스트로 설정**, **기본값으로 재설정**이 있습니다.

| 설정 | 기능 |
|---|---|
| **회전** | 요소가 시계 방향으로 회전하는 각도입니다. 예를 들어 `90`은 4분의 1바퀴입니다. 음수 값은 시계 반대 방향으로 회전합니다. |
| **세로 기울이기** | 요소를 뒤로 젖히는 정도로, `-60`도에서 `60`도까지 설정할 수 있습니다. |
| **가로 기울이기** | 요소를 옆으로 돌리는 정도로, `-60`도에서 `60`도까지 설정할 수 있습니다. |

한 방향으로만 기울일 경우 양수와 음수 값은 같은 모양으로 보입니다. 두 방향 모두 기울이면 각 값의 부호에 따라 요소가 기울어지는 방향이 달라집니다.

## 플레이스홀더 사용

[변수](/variables)나 다른 [플레이스홀더](/placeholders)를 사용해 요소를 회전하거나 기울이려면 다음을 따르세요.

1. 요소를 마우스 오른쪽 버튼으로 클릭하고 **고급 회전 모드**, **고급 세로 기울이기 모드** 또는 **고급 가로 기울이기 모드**를 켭니다.
2. **회전**, **세로 기울이기** 또는 **가로 기울이기**를 클릭한 다음 **일반 텍스트로 설정**을 선택하고 플레이스홀더를 입력합니다.

고급 모드는 별도의 값을 유지하고 조절 핸들을 숨기므로, 드래그해도 플레이스홀더가 다른 값으로 바뀌지 않습니다. 고급 모드를 끄면 요소에 이전 값이 다시 적용됩니다.

**고급 회전 모드**에서 다음 **회전** 값을 사용하면 로고가 3.6초마다 한 바퀴 회전합니다. `10`보다 큰 값으로 나누면 회전 속도가 느려집니다.

```
{"placeholder":"calc","values":{"expression":"{"placeholder":"unix_time"} / 10 % 360"}}
```

변수 `needle_angle`의 값이 가리키는 방향을 가리키는 바늘입니다. 버튼이나 [슬라이더](/elements#slider)로 변수 값을 설정할 수 있습니다.

```
{"placeholder":"getvariable","values":{"name":"needle_angle"}}
```

버튼, 슬라이더, 텍스트 요소의 링크와 스크롤 막대는 회전하거나 기울어진 경우에도 화면에 표시되는 위치에서 마우스에 반응합니다. 다음 조건도 마찬가지입니다. [**요소에 마우스를 올렸는가**](/conditions#is-element-hovered), [**어떤 요소에든 마우스를 올렸는가**](/conditions#is-any-element-hovered), [**어떤 버튼에든 마우스를 올렸는가**](/conditions#is-any-button-hovered).

> [!NOTE]
> 체크박스, 텍스트 입력 필드, 드래거, 브라우저는 회전하거나 기울이지 않았을 때의 상자 영역에서 계속 반응합니다. 이 요소들은 똑바로 유지하세요.

# 회전하거나 기울일 수 없는 요소

- 회전과 기울이기를 모두 적용할 수 없는 요소: [스크롤 가능 영역](/scrollable-areas), [GLSL 셰이더](/elements#glsl-shader), [블록/아이템 JSON 모델](/elements#blockitem-json-model), [플레이어 엔티티](/player-entities), 그리고 화면 자체의 버튼 같은 [바닐라 요소](/vanilla-elements).
- 회전할 수 있지만 기울일 수 없는 요소: [툴팁](/elements#tooltip) 및 [아이템](/elements#item).

스크롤 가능 영역 안의 요소는 회전하거나 기울일 수 있습니다. 영역 자체만 회전하거나 기울일 수 없습니다.

[Splash Text](/splash-text) 요소에는 마우스 오른쪽 버튼 메뉴의 아래쪽에 별도의 **회전** 설정도 있습니다. 이 설정은 스플래시 텍스트 특유의 기울기를 지정하며, 이 페이지의 회전 설정과 함께 적용됩니다.
