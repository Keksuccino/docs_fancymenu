# 리소스

FancyMenu의 리소스 시스템을 사용하면 Minecraft 자체 리소스 로더(**리소스 팩**), **로컬** 리소스(클라이언트 시스템의 파일), 그리고 **웹** 소스(온라인에 저장된 파일)에서 리소스를 사용할 수 있습니다.

이미지, 오디오, 비디오, 텍스트 등 거의 모든 리소스 입력은 FancyMenu의 리소스 선택기를 통해 설정됩니다. 플레이스홀더나 액션의 소스 경로를 설정할 때처럼 몇 가지 예외는 있지만, 대부분의 경우 동일한 리소스 선택기 인터페이스로 리소스를 설정합니다.

리소스 선택기 인터페이스로 리소스 입력을 설정하면, 기본적으로 FancyMenu에서 그렇게 부르는 이른바 "리소스 소스"를 선택하게 됩니다. 이는 소스 유형에 따라 경로, 링크 또는 리소스 위치가 될 수 있습니다.

FancyMenu 3.9.0에서는 리소스 선택기에 Minecraft 리소스 브라우저가 추가됩니다. 이를 통해 모든 리소스 위치를 직접 입력하지 않고도, 디렉터리처럼 리소스 팩을 통해 로드된 리소스를 탐색할 수 있습니다.

# Minecraft 리소스(리소스 팩)

Minecraft는 리소스를 "가리키기" 위해 이른바 "리소스 위치"를 사용합니다.

텍스트로 작성된 리소스 위치는 콜론(`:`)으로 구분된 두 부분으로 구성됩니다.
첫 번째 부분은 **네임스페이스**이고, 두 번째 경로는 파일 확장자를 포함한 리소스까지의 나머지 **경로**입니다.

리소스 위치의 **네임스페이스**는 항상 리소스의 전체 경로에서 가장 상위에 있는 **최상위 디렉터리/폴더**입니다.

예를 들어 `/assets/custom_resources/images/image.png`에 저장된 `image.png`라는 리소스가 있는 리소스 팩을 불러온다고 해봅시다.
이 경우 리소스 위치의 **네임스페이스**는 `custom_resources`입니다. 왜냐하면 `/assets/`는 Minecraft가 모든 리소스를 불러오는 위치일 뿐이고, `custom_resources`가 해당 리소스의 **최상위 디렉터리**이기 때문입니다.
즉, `images/image.png`는 리소스까지의 **나머지 경로**가 됩니다.

따라서 `image.png` 리소스에 대한 올바른 리소스 위치는 다음과 같습니다:
`custom_resources:images/image.png`

> **재미있는 사실**: Minecraft는 대부분의 리소스를 `/assets/minecraft/`에 저장하므로, 대부분의 Minecraft 리소스의 **네임스페이스**는 `minecraft`입니다.
{.is-info}

# 로컬 리소스

리소스를 불러오는 가장 쉬운 방법은 클라이언트에 저장된 로컬 파일(대부분의 경우 모드팩과 함께 포함됨)을 사용하는 것입니다.

FancyMenu는 `/config/fancymenu/assets/`에 저장된 로컬 리소스만 불러올 수 있으므로, 모든 리소스를 반드시 그곳에 저장하세요!

이 방식은 대부분의 모드팩 시스템(CurseForge, Modrinth 등)이 기본적으로 모드 설정 폴더 배포를 지원하므로, [모드팩과 함께 로컬 리소스를 배포하는 것](./modpacks)도 매우 쉽게 해줍니다.

# 웹 리소스

모드팩을 업데이트하지 않고도 리소스를 동적으로 변경해야 할 때는 **웹** 리소스가 가장 좋은 선택입니다.

웹 리소스는 기본적으로 서버에 저장된 파일의 **URL**일 뿐입니다. 예를 들어 `https://example-domain.net/image.png`와 같습니다.

항상 **직접 URL**을 사용하세요. 즉, 위 예시 URL처럼 리소스의 **파일 이름과 확장자**로 끝나는 URL을 말합니다.
직접이 아닌 URL을 사용하면 성능이 저하되고 실패할 가능성도 더 높습니다.

# 리소스 소스의 플레이스홀더

로컬 소스의 경로, 웹 소스의 URL, 또는 Minecraft 리소스의 리소스 위치처럼 리소스 소스에서 FancyMenu의 플레이스홀더를 사용할 수 있습니다.

이렇게 하면 동적으로 소스를 업데이트할 수 있습니다. 예를 들어 FancyMenu 변수를 설정할 때 메뉴 배경의 이미지 소스를 변경하여, 변수 값에 따라 다른 배경을 표시할 수 있습니다.

리소스 소스 입력 필드 오른쪽에 있는 **편집기에서 열기** 버튼을 클릭하면 소스를 수동으로 편집할 수 있습니다.

> 이 기능은 일반적인 리소스 선택기 인터페이스를 사용하는 리소스 입력에만 적용된다는 점을 기억하세요. 선택기를 사용하지 않는 *일부* 리소스 입력은 플레이스홀더를 **지원하지 않거나**, 플레이스홀더가 변경되어도 동적으로 업데이트되지 않을 수 있습니다.
{.is-warning}
