# 메뉴 배경

FancyMenu를 사용하면 메뉴에 사용자 지정 배경을 설정할 수 있습니다. 이미지, 애니메이션 텍스처, 슬라이드쇼, 큐빅 파노라마, 색상, 브라우저, 동영상, GLSL 셰이더 등을 사용할 수 있습니다.

# 배경 설정

메뉴 배경 사용자 지정은 레이아웃 편집기의 컨텍스트 메뉴에서 사용할 수 있습니다.

1. 레이아웃 편집기를 엽니다.
2. 편집기 배경을 마우스 오른쪽 버튼으로 클릭합니다.
3. **메뉴 배경**을 엽니다.
4. 원하는 배경 유형을 활성화하고 구성합니다.

일반적인 배경 유형은 다음과 같습니다.

- 바닐라
- 이미지
- 슬라이드쇼
- 큐빅 파노라마
- 색상(HEX)
- 브라우저
- 동영상
- GLSL 셰이더
- 동영상 [Rinku](지원 중단됨)
- 추가 애드온 배경 유형

기존 **동영상 [Rinku]** 배경 유형은 지원이 중단되었습니다. 새로운 레이아웃에서는 Watermedia V3를 기반으로 하는 [네이티브 **동영상** 배경](./video)을 사용하세요.

# 사용자 지정 배경 제거

**메뉴 배경**을 다시 열고 더 이상 필요하지 않은 사용자 지정 배경 유형을 비활성화하거나 제거합니다. 활성화된 사용자 지정 배경 유형이 없으면 화면은 일반적인 바닐라 배경 동작으로 돌아갑니다.

# 배경 쌓기

하나의 레이아웃에서 여러 메뉴 배경 유형을 활성화할 수 있습니다. 활성화된 배경은 스택으로 렌더링되므로 기본 이미지나 파노라마에 반투명 브라우저, 셰이더, 패럴랙스 또는 기타 레이어를 결합할 수 있습니다.

여러 레이아웃을 동시에 활성화한 경우 각 레이아웃의 배경 스택이 서로 결합될 수도 있습니다. 레이아웃을 정렬하여 특정 순서로 표시하려면 편집기 배경을 마우스 오른쪽 버튼으로 클릭한 다음 **레이아웃 인덱스**를 클릭합니다.

# 투명한 배경

FancyMenu는 활성화된 사용자 지정 배경 뒤에 검은색 배경 레이어를 렌더링합니다. 따라서 가장 아래에 있는 배경의 투명한 픽셀은 검은색으로 표시됩니다. 불투명한 기본 배경을 사용한 다음 그 위에 반투명 배경을 쌓으세요.

배경 이미지를 반투명하게 만들려면 원하는 이미지 편집기를 사용하세요.

# 브라우저 배경

**브라우저** 배경 유형은 [브라우저 요소](./elements#browser)와 비슷하게 작동하지만 전체 화면을 채우며 자동으로 포커스됩니다. 전체 화면 웹 콘텐츠, 로컬 HTML 페이지 또는 웹 동영상 레이어에 유용합니다.

# GLSL 셰이더 배경

**GLSL 셰이더** 배경 유형은 사용자 지정 GLSL 셰이더를 렌더링하며 Shadertoy 스타일의 셰이더 작성을 지원합니다. 지원되는 유니폼과 셰이더 구조는 [GLSL 셰이더 API](/glsl-shader-api) 페이지를 참조하세요.
