# 메뉴 배경

레이아웃에서 화면에 고유한 배경을 지정할 수 있습니다. 이미지, 애니메이션, 파노라마, 슬라이드쇼, 동영상, 색상, 웹사이트 또는 셰이더를 배경으로 사용할 수 있습니다. 이렇게 지정한 배경은 제목 화면의 파노라마, 다른 메뉴의 블러 효과, 일시 정지 메뉴 뒤에 보이는 월드처럼 화면에 기본으로 표시되는 배경을 대체합니다.

<img width="800" alt="눈 덮인 계곡의 픽셀 아트 배경이 있는 제목 화면. 밤하늘에는 오로라와 보름달이 떠 있고, 창문에 불이 켜진 오두막이 보입니다." src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_hero.png?raw=true">

> [!TIP]
> 레이아웃을 만들지 않고 모든 메뉴에 같은 배경을 지정하려면 [전역 사용자 지정](/global-customizations#menu-backgrounds)을 사용하세요.

# 배경 설정하기

<img width="800" alt="제목 화면의 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고, 메뉴 배경과 이미지를 연 다음 배경 표시를 켜고 이미지 선택으로 이미지를 고르는 모습" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_image.gif?raw=true">

1. [레이아웃 편집기](/layout-editor)에서 해당 화면의 레이아웃을 엽니다.
2. 편집기의 배경을 마우스 오른쪽 버튼으로 클릭하고 **메뉴 배경**을 엽니다. **메뉴 바 -> 레이아웃 -> 레이아웃 속성**에서도 열 수 있습니다.
3. **이미지**와 같은 배경 유형을 엽니다.
4. **배경 표시**를 클릭해 **활성화됨**으로 설정합니다.
5. 이미지 배경이라면 **이미지 선택**을 사용하는 것처럼 배경을 설정합니다.

<img width="800" alt="메뉴 배경 메뉴에서 이미지 앞에는 체크 표시가 있고 다른 모든 유형 앞에는 X 표시가 있으며, 아래에는 각 배경의 설정이 표시됩니다." src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_menu.png?raw=true">

**메뉴 배경**에서 활성화된 유형 앞에는 ✔가 표시되고, 비활성화된 유형 앞에는 ✖가 표시됩니다. 유형 위에 마우스를 올리면 해당 유형의 기능을 확인할 수 있습니다.

화면의 기본 배경을 다시 표시하려면 해당 유형의 **배경 표시**를 **비활성화됨**으로 설정하세요. 설정은 그대로 유지되므로 나중에 다시 켤 수 있습니다.

# 배경 유형

## 이미지

파일, 웹사이트 또는 게임 리소스에 있는 이미지를 화면 전체에 늘려 표시합니다. 애니메이션 이미지도 재생됩니다. 지원되는 파일은 [이미지](/images)에 나와 있습니다.

- **이미지 선택**: 이미지입니다. 이미지를 가져올 수 있는 위치는 [리소스](/resources)를 참조하세요.
- **대체 이미지 선택**: 이미지가 로드되지 않을 때 표시합니다. 오프라인 상태일 때 웹 이미지 대신 표시되는 경우가 그 예입니다.
- **화면을 열 때 애니메이션 텍스처 다시 시작**: 화면을 열 때마다 [애니메이션 이미지](/animations)를 처음부터 재생합니다. 이 옵션을 끄면 이전에 재생하던 부분부터 이어서 재생합니다.
- **텍스처 반복**: 이미지를 늘리는 대신 화면에 타일처럼 반복해서 표시합니다. [나인 슬라이싱과 타일링](/nine-slicing-and-tiling)을 참조하세요.
- **넓은 이미지 왼쪽에서 오른쪽으로 슬라이드**: 풍경 전체를 담은 사진처럼 넓은 이미지를 화면 높이에 맞춰 표시하고, 양 끝에서 잠시 멈추며 천천히 좌우로 이동합니다.
- **시차 효과** 및 관련 설정: 이미지가 마우스 움직임에 따라 조금씩 움직입니다. [시차 효과](/parallax#menu-backgrounds)를 참조하세요.

**넓은 이미지 왼쪽에서 오른쪽으로 슬라이드**는 **텍스처 반복** 또는 **시차 효과**와 동시에 사용할 수 없습니다.

## 색상

화면 전체에 단일 색상을 표시합니다.

- **색상 [HEX]**: 색상입니다. 예를 들어 `#1B2440`처럼 입력할 수 있습니다. 뒤에 두 자릿수를 더 입력하면 투명도를 지정할 수 있습니다. 예: `#1B2440C8`. [플레이스홀더](/placeholders)도 사용할 수 있습니다.

색상은 레이아웃의 다른 모든 배경 아래에 표시되므로 다른 배경의 투명한 부분을 채웁니다. [배경 쌓기](#stacking-backgrounds)를 참조하세요.

## 입방체 파노라마

제목 화면의 파노라마처럼 천천히 회전하는 파노라마를 표시합니다. `config/fancymenu/panoramas/`에서 파노라마를 만들 수 있습니다. [파노라마](/panoramas)를 참조하세요.

- **파노라마 이름**: **파노라마 선택**을 열어 파노라마를 선택하고 미리 볼 수 있습니다.
- **파노라마 지우기**: 파노라마를 삭제합니다.

파노라마를 지정하지 않으면 배경에 마인크래프트의 보라색과 검은색 누락 텍스처가 표시됩니다.

## 슬라이드쇼

슬라이드쇼에 포함된 이미지를 차례대로 표시합니다. `config/fancymenu/slideshows/`에서 슬라이드쇼를 만들 수 있습니다. [슬라이드쇼](/slideshows)를 참조하세요.

- **슬라이드쇼 이름**: **슬라이드쇼 선택**을 열어 슬라이드쇼를 선택할 수 있습니다.
- **슬라이드쇼 지우기**: 슬라이드쇼를 삭제합니다.

슬라이드쇼를 지정하지 않으면 배경에 마인크래프트의 누락 텍스처가 표시됩니다.

## 동영상

파일, 웹사이트 또는 게임 리소스에 있는 동영상을 재생합니다. Watermedia가 필요합니다. [동영상](/video#requirements)을 참조하세요. Watermedia가 없으면 배경에 다운로드 링크가 포함된 안내문이 표시됩니다.

- **동영상 소스**: 동영상입니다.
- **동영상 반복**, **음량**, **사운드 채널**: 동영상 재생 방식을 설정합니다.
- **시차 효과** 및 관련 설정: 이미지 배경과 같은 기능입니다.
- **레이아웃 편집기에서 동영상 재생**: 끄면 레이아웃 편집기에서 동영상이 일시 정지된 상태로 유지됩니다.

[액션](/video)을 사용하면 동영상을 일시 정지하고 음량과 재생 시간을 변경할 수 있습니다. 액션을 사용하려면 배경의 ID가 필요합니다. 배경 설정에서 **배경 식별자 복사**를 클릭하세요.

## 브라우저

[브라우저 요소](/elements#browser)처럼 웹사이트를 화면 전체에 표시합니다.

> [!IMPORTANT]
> 브라우저를 사용하려면 [Rinku](https://modrinth.com/mod/rinku) 모드가 필요합니다. Rinku가 없으면 배경이 빨간색으로 표시되고 Rinku가 없다는 안내가 나타납니다.

- **URL**: 웹사이트 주소입니다. [플레이스홀더](/placeholders)를 포함할 수 있습니다.
- **마우스 클릭 처리**, **마우스 스크롤 처리**, **키보드 입력 처리**: 플레이어가 웹사이트를 클릭하고 스크롤하며 입력할 수 있게 합니다. 화면이 열리면 키보드 입력을 받습니다.
- **마우스 클릭 소비**, **마우스 스크롤 소비**, **키보드 입력 소비**: 웹사이트에서 클릭, 스크롤, 키 입력을 소비하여 화면 자체가 해당 입력에 반응하지 않도록 합니다.
- **브라우저 음소거**, **오디오/동영상 음량**, **동영상 반복**, **동영상 컨트롤 숨기기**: 웹사이트의 미디어를 설정합니다.

배경 앞에 있는 버튼과 요소가 항상 클릭을 먼저 받습니다. 레이아웃 편집기에서는 웹사이트 대신 줄무늬가 배경에 표시됩니다.

## GLSL 셰이더

애니메이션 파도, 별, 패턴 등을 그리는 그래픽 카드용 작은 프로그램인 셰이더를 렌더링합니다. Shadertoy의 셰이더도 사용할 수 있습니다.

- **셰이더 소스**: 셰이더 코드입니다.
- **컴파일 오류 표시**: 코드의 오류를 화면에 표시합니다. 완성된 레이아웃에서는 이 옵션을 끄세요.

추가 패스, 텍스처, 시간 등의 나머지 설정은 [GLSL 셰이더 API](/glsl-shader-api)에 설명되어 있습니다.

## 동영상 [Rinku]

Rinku가 필요한 이전 버전의 동영상 배경입니다. 이전 버전으로 만든 레이아웃처럼 이 배경이 켜져 있을 때만 목록에 표시됩니다. 대신 **동영상**을 사용하세요.

# 모든 배경에 적용되는 설정

배경 유형 아래의 **메뉴 배경**에는 레이아웃의 모든 배경에 적용되는 설정이 있습니다.

- **배경 종횡비 유지**: 이미지, 슬라이드쇼, 동영상 배경의 비율을 유지합니다. 배경은 여전히 화면 전체를 채우며, 화면에 맞지 않는 부분은 잘립니다. 이 옵션을 끄면 배경이 화면 크기에 맞게 늘어납니다.
- **사용자 지정 배경에 어두운 오버레이 표시**: 마인크래프트 메뉴의 반투명한 어두운 레이어를 배경 위에 표시해 버튼과 텍스트를 더 잘 보이게 합니다.
- **바닐라 배경 블러 적용**: 마인크래프트가 메뉴 뒤의 월드에 블러를 적용하는 것처럼 배경을 흐리게 표시합니다. 블러 강도는 마인크래프트의 **접근성 설정**에 있는 플레이어의 **메뉴 배경 블러** 설정에 따라 달라집니다. `0`이면 블러가 적용되지 않습니다.

<img width="800" alt="같은 배경을 나란히 세 번 표시한 이미지. 왼쪽부터 원래 배경, 사용자 지정 배경에 어두운 오버레이 표시를 적용해 어두워진 배경, 바닐라 배경 블러 적용을 적용해 흐려진 배경입니다." src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_effects.png?raw=true">

왼쪽부터 설정 없음, **사용자 지정 배경에 어두운 오버레이 표시**, **바닐라 배경 블러 적용**입니다.

# 배경 쌓기

하나의 레이아웃에서 여러 유형을 활성화할 수 있습니다. 배경은 아래에서 위로 다음 순서대로 렌더링됩니다.

1. 색상
2. 입방체 파노라마
3. 이미지
4. 슬라이드쇼
5. 동영상
6. 동영상 [Rinku]
7. 브라우저
8. GLSL 셰이더

다른 모드가 추가한 유형은 맨 위에 표시됩니다.

FancyMenu는 배경 뒤에 검은색을 표시하므로 이미지의 투명한 부분은 검은색으로 보입니다. 이미지 아래에 색상 배경을 두면 투명한 부분을 색상으로 채울 수 있습니다.

<img width="800" alt="하늘이 투명한 픽셀 아트 풍경. 왼쪽 절반의 하늘은 검은색이고, 오른쪽 절반은 파란색 색상 배경으로 채워져 있습니다." src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/menu_backgrounds_stacking.png?raw=true">

왼쪽에는 이미지만 활성화되어 있습니다. 오른쪽에는 색상 배경이 하늘을 채웁니다.

- 입방체 파노라마 위에 투명한 이미지, 슬라이드쇼 또는 셰이더를 올리면 회전하는 파노라마 주위의 액자처럼 표시됩니다.
- 동영상 배경은 투명하게 표시되지 않습니다. 동영상이 닿지 않는 부분을 포함해 아래의 모든 배경을 가립니다.

## 여러 레이아웃

[범용 레이아웃](/universal-layouts)과 해당 화면의 레이아웃처럼 여러 레이아웃이 화면에서 활성화되어 있으면 배경도 함께 쌓입니다.

- **레이아웃 인덱스 [다중 레이아웃 순서]** 값이 더 높은 레이아웃이 위에 표시됩니다. 편집기 배경을 마우스 오른쪽 버튼으로 클릭해 설정하세요.
- 레이아웃 중 하나에서 [모든 배경에 적용되는 설정](#settings-for-all-backgrounds)을 켜면 모든 레이아웃의 배경에 적용됩니다.
- 레이아웃 편집기에는 편집 중인 레이아웃의 배경만 표시됩니다.

# 알아 두면 좋은 점

- 레이아웃의 요소는 항상 해당 레이아웃의 배경 앞에 표시됩니다.
- 각 유형의 설정에 있는 **배경 식별자 복사**를 클릭하면 액션과 배경을 제어하는 플레이스홀더에서 사용할 배경 ID를 복사합니다. [동영상 배경](/video)의 설정이 한 예입니다.
- 각 유형의 설정에 있는 **AI용 내보내기**를 클릭하면 [AI 채팅](/export-for-ai)에 사용할 배경을 복사합니다.
- 월드 목록처럼 목록이 표시되는 화면의 머리글과 바닥글에는 고유한 텍스처가 있습니다. 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **머리글/바닥글 사용자 지정**을 여세요.
