# 메뉴 배경

FancyMenu를 사용하면 메뉴에 사용자 지정 배경을 설정할 수 있습니다. 이미지, 애니메이션 텍스처, 슬라이드쇼, 큐빅 파노라마, 색상, 브라우저, 비디오, GLSL 셰이더 등을 사용할 수 있습니다.

# 배경 설정하기

FancyMenu 3.9.0 이상에서는 메뉴 배경 사용자 지정이 레이아웃 편집기 컨텍스트 메뉴에서 직접 이루어집니다.

1. 레이아웃 편집기를 엽니다.
2. 편집기 배경을 마우스 오른쪽 버튼으로 클릭합니다.
3. **메뉴 배경**을 엽니다.
4. 원하는 배경 유형을 활성화하고 설정합니다.

일반적인 배경 유형은 다음과 같습니다.

- 바닐라
- 이미지
- 슬라이드쇼
- 큐빅 파노라마
- 색상(HEX)
- 브라우저
- 비디오
- GLSL 셰이더
- 비디오 [MCEF] (사용 중단됨)
- 기타..

기존의 **비디오 [MCEF]** 배경 유형은 FancyMenu 3.9.0에서 사용 중단되었습니다. 새 레이아웃에는 Watermedia V3로 구동되는 새로운 기본 **비디오** 배경을 사용하세요.

# 사용자 지정 배경 제거하기

**메뉴 배경**을 다시 열고 더 이상 원하지 않는 사용자 지정 배경 유형을 비활성화하거나 제거합니다. 활성화된 사용자 지정 배경 유형이 없으면 화면은 일반적인 바닐라 배경 동작으로 돌아갑니다.

# 배경 쌓기

FancyMenu 3.9.0에서는 같은 레이아웃에서 여러 메뉴 배경 유형을 함께 활성화할 수 있습니다. 활성 배경은 스택처럼 렌더링되므로, 기본 이미지나 파노라마에 반투명 오버레이, 브라우저 레이어, 셰이더 레이어, 패럴랙스 레이어 및 기타 효과를 조합할 수 있습니다.

여러 레이아웃도 함께 활성화되어 있다면, 각 레이아웃의 배경 스택도 함께 조합될 수 있습니다. 레이아웃의 순서를 정리하고 특정 순서로 표시되게 하려면 편집기 배경을 마우스 오른쪽 버튼으로 클릭한 다음 **레이아웃 인덱스**를 클릭하세요.

# 투명 배경

배경 뒤에는 아무것도 없기 때문에, 가장 아래에 있는 배경을 투명하게 만드는 것은 불가능합니다. 그렇게 하면 그래픽 오류가 발생하기 때문입니다. 하지만 가장 아래 항목이 완전 불투명하게 유지되는 한, 스택형 배경 구성에서는 투명도를 사용하는 것이 완전히 가능합니다. 이렇게 하면 맨 아래 배경 위에 반투명 배경 레이어를 올릴 수 있습니다.

배경 이미지를 반투명하게 만들려면 원하는 이미지 편집기를 사용하세요.

# 브라우저 배경

**브라우저** 배경 유형은 브라우저 요소처럼 동작하지만, 전체 화면을 채우고 자동으로 포커스됩니다. 이는 전체 화면 웹 콘텐츠, 로컬 HTML 페이지 또는 웹 비디오 레이어에 유용합니다.

# GLSL 셰이더 배경

**GLSL 셰이더** 배경 유형은 사용자 지정 GLSL 셰이더를 렌더링하며 Shadertoy 스타일의 셰이더 작성 방식을 지원합니다. 지원되는 uniform과 셰이더 구조는 [GLSL 셰이더 API](/glsl-shader-api) 페이지를 참조하세요.
