# 메뉴 배경

FancyMenu를 사용하면 메뉴에 사용자 지정 배경을 설정할 수 있습니다. 이미지, 애니메이션 텍스처, 슬라이드쇼, 큐빅 파노라마, 색상, 브라우저, 비디오, GLSL 셰이더 등 다양한 유형을 사용할 수 있습니다.

# 배경 설정하기

메뉴 배경 사용자 지정은 레이아웃 편집기의 컨텍스트 메뉴에서 할 수 있습니다:

1. 레이아웃 편집기를 엽니다.
2. 편집기 배경을 마우스 오른쪽 버튼으로 클릭합니다.
3. **메뉴 배경**을 엽니다.
4. 원하는 배경 유형을 활성화하고 설정합니다.

일반적인 배경 유형은 다음과 같습니다:

- Vanilla
- 이미지
- 슬라이드쇼
- 큐빅 파노라마
- 색상(HEX)
- 브라우저
- 비디오
- GLSL 셰이더
- Video [MCEF] (사용 중단됨)
- 추가 애드온 배경 유형

기존의 **Video [MCEF]** 배경 유형은 더 이상 사용되지 않습니다. 새 레이아웃에는 Watermedia V3 기반의 [기본 제공 **비디오** 배경](./video)을 사용하세요.

# 사용자 지정 배경 제거하기

**메뉴 배경**을 다시 열고 더 이상 사용하지 않을 사용자 지정 배경 유형을 비활성화하거나 제거합니다. 활성화된 사용자 지정 배경 유형이 없으면, 화면은 일반적인 기본 배경 동작으로 돌아갑니다.

# 배경 겹쳐 사용하기

하나의 레이아웃에서 여러 메뉴 배경 유형을 활성화할 수 있습니다. 활성 배경은 레이어처럼 쌓여 렌더링되므로, 기본 이미지나 파노라마 위에 반투명 브라우저, 셰이더, 패럴랙스 또는 다른 레이어를 조합할 수 있습니다.

여러 레이아웃이 동시에 활성화되어 있는 경우, 각각의 배경 스택도 함께 조합될 수 있습니다. 레이아웃의 순서를 정해 특정 순서로 표시되게 하려면 편집기 배경을 마우스 오른쪽 버튼으로 클릭한 다음 **레이아웃 인덱스**를 클릭합니다.

# 투명 배경

FancyMenu는 활성화된 사용자 지정 배경 뒤에 검은색 기본 레이어를 렌더링합니다. 따라서 가장 아래에 있는 배경의 투명 픽셀은 검은색으로 보입니다. 불투명한 기본 배경을 사용한 뒤, 그 위에 반투명 배경을 겹쳐 사용하세요.

배경 이미지를 반투명하게 만들려면 원하는 이미지 편집기를 사용하세요.

# 브라우저 배경

**브라우저** 배경 유형은 [브라우저 요소](./elements#browser)와 비슷하게 동작하지만, 화면 전체를 채우고 자동으로 포커스됩니다. 이는 전체 화면 웹 콘텐츠, 로컬 HTML 페이지 또는 웹 비디오 레이어에 유용합니다.

# GLSL 셰이더 배경

**GLSL 셰이더** 배경 유형은 사용자 지정 GLSL 셰이더를 렌더링하며, Shadertoy 스타일의 셰이더 작성도 지원합니다. 지원되는 uniform과 셰이더 구조는 [GLSL 셰이더 API](/glsl-shader-api) 페이지를 참조하세요.
