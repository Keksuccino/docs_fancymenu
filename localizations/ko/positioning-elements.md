# FancyMenu에서 요소 배치하기

FancyMenu에서는 각 요소의 위치가 **앵커 포인트**에 따라 결정됩니다. 앵커 포인트는 화면에서 요소가 표시될 위치를 계산하는 데 사용되며, 요소가 서로 겹치거나 화면 밖으로 벗어나거나 창 크기를 조정할 때 잘못 이동하는 것을 방지합니다.

## 앵커 포인트 이해하기

앵커 포인트는 요소의 위치를 계산할 때 기준이 되는 원점입니다. 기본적으로 레이아웃에 추가하는 요소는 **"화면 중앙"** 앵커 포인트에 연결됩니다. 이 앵커는 창 크기와 관계없이 화면의 정확한 중앙을 가리킵니다.

예를 들어 요소가 **"화면 중앙"** 앵커에 연결되어 있고 화면 중앙에서 2cm 떨어져 있다면, 창 크기가 바뀌어도 이 간격은 그대로 유지됩니다.

## 앵커 포인트 사용하기

편집기에서 요소를 드래그하면 요소가 연결된 앵커 포인트가 강조 표시됩니다. 기본 설정에서는 사용 가능한 다른 앵커 포인트도 모두 표시됩니다. 요소를 다른 앵커 포인트 위로 드래그한 다음 로딩 바가 다 찰 때까지 기다리면 앵커를 변경할 수 있습니다.

## 요소를 다른 요소에 고정하기

다른 요소를 앵커로 사용할 수도 있습니다. 이렇게 하면 해당 요소를 따라 이동하며, 앵커로 지정한 요소의 왼쪽 위 모서리와의 간격을 유지합니다. 여러 요소로 구성된 패널이나 바닐라 버튼 옆의 레이블, [드래거](/dragger)를 배치할 때 유용합니다.

두 가지 방법으로 설정할 수 있으며, 어느 방법을 사용하든 요소의 현재 위치는 유지됩니다.

### 드래그해서 설정하기

1. 요소를 드래그하고 포인터를 다른 요소 위에 둡니다.
2. 바가 가득 찰 때까지 기다린 다음 놓습니다.

드래그를 시작할 때 포인터가 이미 다른 요소 위에 있다면, 포인터를 해당 요소 바깥으로 옮겼다가 다시 위에 놓으세요. 드래그를 시작할 때부터 포인터 아래에 있던 요소는 대상으로 인식되지 않습니다.

이 기능을 사용하려면 **Window** 메뉴에서 **Anchor Area Hovering**과 **Anchor Element Hovering**을 켜야 합니다. 기본적으로 둘 다 켜져 있습니다. 첫 번째 설정은 포인터를 올려 고정하는 기능을 켜고 끄며, 두 번째 설정은 다른 요소를 앵커 포인트에 추가합니다. 같은 메뉴의 **Anchor Area/Element Hover Charging Time (Seconds)**에서 포인터를 올려 두어야 하는 시간을 설정할 수 있으며, 기본값은 2초입니다.

### ID로 설정하기

1. 다른 요소를 마우스 오른쪽 버튼으로 클릭하고 **Copy Element ID**를 클릭합니다.
2. 고정할 요소를 마우스 오른쪽 버튼으로 클릭하고 **Anchor Point -> Other Element**를 클릭합니다.
3. **Element ID**에 ID를 붙여 넣고 **Done**을 클릭합니다.

여러 요소를 선택한 상태라면 2단계와 3단계를 통해 선택한 요소를 모두 한 번에 고정할 수 있습니다. ID에 관한 자세한 내용은 [요소 식별자](/element-identifiers)를 참고하세요.

## 스크롤 영역의 앵커

[스크롤 영역](/scrollable-areas)의 요소에도 앵커가 있지만, 화면이 아닌 해당 영역의 콘텐츠를 기준으로 합니다.

- **Top-Left Corner**는 콘텐츠의 왼쪽 위 모서리, **Center of Screen**은 콘텐츠의 중앙을 가리키며, 아래쪽 앵커는 콘텐츠의 끝에 고정됩니다. 따라서 긴 목록의 맨 끝에 요소를 배치하면 목록이 길어져도 그 위치를 유지할 수 있습니다.
- 영역 안의 요소는 같은 영역에 있는 다른 요소만 앵커로 사용할 수 있습니다.
- 요소를 영역 안팎으로 이동하면 경계를 넘어 서로 고정되어 있던 요소에는 **Top-Left Corner** 앵커가 지정되며, 현재 위치가 유지됩니다.

이 기능은 해당 영역의 **Anchors** 모드에서 사용할 수 있습니다. 다른 모드에서는 영역이 요소를 직접 배치합니다. 자세한 내용은 [스크롤 영역](/scrollable-areas#anchors-mode)을 참고하세요.

## 요소를 화면 밖으로 이동하기

기본적으로 요소를 화면 밖으로 이동할 수 없습니다. 이는 레이아웃이 아주 작거나 특이한 크기의 창에서 로드될 때 요소가 계속 표시되고 상호작용할 수 있도록 하는 안전장치입니다.

요소는 항상 화면 안에 머물며 화면 가장자리와 약간의 간격을 유지합니다.

요소를 마우스 오른쪽 버튼으로 클릭한 다음 **Stay on Screen**을 끄면 해당 요소에 한해 이 기능을 **비활성화**할 수 있습니다.

> [!WARNING]
> 실제 요소의 위치가 화면 밖에 있었지만 이 기능으로 인해 표시되고 있었다면, 기능을 끄는 순간 요소가 사라질 수 있습니다. 이런 경우 실행 취소 단축키를 사용하거나 **menu bar -> Edit -> Undo**를 클릭해 마지막 작업(**Stay on Screen** 비활성화)을 **실행 취소**하세요. 그런 다음 요소를 화면 중앙으로 직접 옮기고 **Stay on Screen**을 다시 끄면 기능을 비활성화한 상태에서도 요소가 계속 표시됩니다.

## 요소 중앙 정렬하기

요소의 크기가 고정되어 있다면 중앙을 기준으로 하는 앵커 포인트에 고정하는 것만으로 쉽게 중앙 정렬할 수 있습니다.

조건 등에 따라 요소 크기가 동적으로 바뀐다면 조금 까다롭지만, FancyMenu에는 이를 위한 편리한 기능이 있습니다. 먼저 요소를 중앙 기준 앵커 포인트에 고정한 다음 마우스 오른쪽 버튼으로 클릭하세요. 컨텍스트 메뉴에서 **Sticky Anchor**를 켭니다. 이 기능은 FancyMenu가 요소의 위치를 계산하는 방식을 바꿔 크기가 변하더라도 앵커 포인트와의 간격을 일정하게 유지합니다. 중앙 기준 앵커를 사용하면 요소의 절대 중심을 기준으로 앵커와의 간격을 유지하므로 요소가 항상 중앙에 정렬됩니다. (왼쪽 기준 앵커는 요소의 왼쪽 가장자리, 오른쪽 기준 앵커는 오른쪽 가장자리를 기준으로 앵커와의 간격을 일정하게 유지합니다.)

## 요소 배치를 개선하는 다른 방법

**모든 앵커 포인트가 올바른데도** 창이 너무 작을 때 요소끼리 겹친다면, 레이아웃이 Minecraft의 기본 GUI 크기 조정 방식으로 표시하기에는 너무 복잡할 수 있습니다.

### GUI 크기 강제 지정

레이아웃 요소의 배치를 개선하는 한 가지 방법은 편집기 배경을 **마우스 오른쪽 버튼으로 클릭**하고 **Force GUI Scale**을 선택해 메뉴의 GUI 크기를 강제로 지정하는 것입니다. 이렇게 하면 Minecraft 옵션에서 어떤 크기를 설정했는지와 관계없이 메뉴의 GUI 크기가 항상 일정하게 유지됩니다.

### 자동 크기 조정

요소가 겹치는 문제를 해결하는 마지막 방법은 **자동 크기 조정**을 사용하는 것입니다.
이 설정은 창 크기에 따라 메뉴 크기를 자동으로 조정하여 창 크기를 바꿀 때 요소의 위치를 최대한 유지합니다. 자동 크기 조정을 켜려면 편집기 배경을 **마우스 오른쪽 버튼으로 클릭**한 다음 **Auto-Scaling**을 클릭하세요.

> [!WARNING]
> **자동 크기 조정**을 사용하면 Minecraft에서 렌더링하는 **텍스트가 보기 좋지 않게** 표시될 수 있습니다. 버그가 아니라 Minecraft의 텍스트 렌더링 방식 때문입니다. 버튼의 경우 버튼 배경 텍스처에 레이블을 포함하고 기본 버튼 레이블은 비워 두면 이 문제를 잘 해결할 수 있습니다.
