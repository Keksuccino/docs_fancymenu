# FancyMenu에서 요소 배치하기

FancyMenu에서는 각 요소의 위치가 **앵커 포인트**에 의해 결정됩니다. 이 포인트는 요소가 화면의 어디에 표시되어야 하는지 계산하는 데 필요하며, 창 크기가 변경될 때 요소가 겹치거나 화면 밖으로 벗어나거나 잘못 이동하지 않도록 해줍니다.

## 앵커 포인트 이해하기

앵커 포인트는 요소 위치를 계산하는 기준점 역할을 합니다. 기본적으로 레이아웃에 추가한 요소는 **"화면 중앙"** 앵커 포인트에 연결됩니다. 이 앵커는 창 크기와 관계없이 화면의 정확한 중앙입니다.

예를 들어, 요소가 **"화면 중앙"** 앵커에 연결된 상태에서 화면 중앙으로부터 2cm 떨어져 있다면, 창 크기가 어떻게 바뀌어도 그 거리는 유지됩니다.

## 앵커 포인트와 상호작용하기

편집기에서 요소를 드래그하면, 그 요소가 연결된 앵커 포인트가 강조 표시됩니다. 기본적으로 이 동작은 사용 가능한 다른 앵커 포인트들도 모두 표시합니다. 요소를 다른 앵커 포인트 위로 드래그한 뒤 로딩 바가 채워질 때까지 기다리면, 해당 요소의 앵커를 변경할 수 있습니다.

## 다른 요소에 요소 고정하기

요소는 다른 요소의 앵커 포인트 역할도 할 수 있습니다. 이 기능은 Vanilla 메뉴 디자인을 수정할 때 모든 Vanilla 요소를 일일이 조정하지 않고도 사용자 정의 요소를 자연스럽게 통합하는 데 특히 유용합니다.

한 요소를 다른 요소에 고정하려면, 원하는 요소 쪽으로 그냥 드래그하면 됩니다. 드래그 중인 요소가 다른 요소 위에 올라가면, 실제 앵커 포인트 위에 마우스를 올렸을 때와 마찬가지로 그 요소가 가리키는 앵커 포인트로 변경됩니다.

이렇게 하면 요소가 부모 요소와 함께 움직이게 됩니다.

오른쪽 아래 모서리에 있는 이미지 요소는 **우측 하단 모서리** 앵커 포인트에 고정됩니다. 그래야 오른쪽 아래 모서리에 계속 머물 수 있기 때문입니다.

## 요소를 화면 밖으로 이동시키기

기본적으로 요소를 화면 밖으로 이동할 수 없습니다. 이는 레이아웃이 매우 작은 창 크기나 이상한 창 크기로 로드되었을 때를 대비한 안전장치로, 요소가 여전히 보이고 상호작용할 수 있도록 하기 위한 것입니다.

요소는 항상 화면 안에 남아 있으며, 요소와 화면 가장자리 사이에는 작은 간격이 유지됩니다.

개별 요소에 대해서는 해당 요소를 **우클릭**한 뒤 **화면에 유지(Stay On Screen)** 를 비활성화하여 이 기능을 **끄기**할 수 있습니다.

> [!WARNING]
> 이 기능을 끄면 때때로 요소가 사라질 수 있습니다. 실제/원래 위치가 화면 밖에 있었지만, 이 기능이 보이도록 유지하고 있었기 때문입니다. 이런 경우에는 실행 취소 단축키 또는 **메뉴 바 -> 편집 -> 실행 취소**를 사용해 마지막 작업(**화면에 유지(Stay On Screen)** 비활성화)을 **되돌린 뒤**, 요소를 화면 중앙으로 직접 이동하고 **화면에 유지(Stay On Screen)** 를 다시 비활성화하세요. 그러면 기능을 꺼도 요소가 계속 보일 것입니다.

## 요소 중앙 맞추기

요소의 크기가 고정되어 있다면, 중앙 정렬은 중심 기반 앵커 포인트에 고정하는 것만으로 쉽게 할 수 있습니다.

조건이나 다른 이유로 요소의 크기가 동적으로 바뀌는 경우에는 조금 더 복잡하지만, FancyMenu에는 이를 위한 훌륭한 기능이 있습니다! 이 경우 먼저 요소를 중심 기반 앵커 포인트에 고정한 다음, 요소를 **우클릭**하세요. 컨텍스트 메뉴에서 **Sticky Anchors**를 활성화합니다. 이 기능은 FancyMenu가 요소의 위치를 계산하는 방식을 바꿔, 크기가 변하더라도 앵커 포인트와의 거리가 항상 같게 유지되도록 합니다. 중심 기반 앵커의 경우, 요소의 절대 중심에서 앵커까지의 거리가 항상 같게 유지되므로 중심 기반 앵커를 사용할 때 항상 가운데에 머무르게 됩니다. (왼쪽 기준 앵커의 경우 요소의 왼쪽 가장자리와 앵커 사이의 거리가 항상 같게 유지되고, 오른쪽 기준 앵커의 경우 요소의 오른쪽 가장자리와의 거리가 항상 같게 유지됩니다.)

## 요소 위치를 개선하는 더 많은 방법

**모든 앵커 포인트가 올바른데도**, 창이 너무 작아지면 요소들이 서로 겹친다면, 레이아웃이 Minecraft의 일반 GUI 스케일링 로직 기준으로 너무 빽빽한 것일 수 있습니다.

### 강제 GUI 스케일

레이아웃 요소 배치를 개선하는 한 가지 방법은 **편집기 배경을 우클릭**한 뒤 **강제 GUI 스케일(Force GUI Scale)** 을 선택해 메뉴에 GUI 스케일을 강제로 적용하는 것입니다. 그러면 Minecraft 옵션에서 어떤 스케일이 설정되어 있든 메뉴는 항상 같은 GUI 스케일을 사용하게 됩니다.

### 자동 스케일링

겹침 문제를 해결하는 마지막 옵션은 **자동 스케일링**을 사용하는 것입니다.
이 설정은 창 크기에 따라 메뉴를 자동으로 스케일하여, 창 크기가 변경될 때 요소의 위치를 최대한 잘 보존하도록 합니다. 자동 스케일링을 활성화하려면 **편집기 배경을 우클릭**한 다음 **자동 스케일링(Auto-Scaling)** 을 클릭하세요.

> [!WARNING]
> **자동 스케일링**은 Minecraft가 렌더링한 **텍스트**가 **보기 좋지 않게** 만들 수 있습니다. 이는 버그가 아니라 Minecraft의 텍스트 렌더링 방식 때문입니다. 버튼의 경우, 이를 우회하는 좋은 방법은 버튼 라벨을 버튼 배경 텍스처의 일부로 만들고 일반 버튼 라벨은 빈 값으로 설정하는 것입니다.
