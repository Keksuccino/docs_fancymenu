# FancyMenu에서 요소 배치하기

FancyMenu에서는 각 요소의 위치가 **앵커 포인트**에 의해 결정됩니다. 이 포인트는 요소가 화면의 어디에 표시되어야 하는지 계산하는 데 필요하며, 요소가 서로 겹치거나 화면 밖으로 벗어나거나 창 크기가 변경될 때 잘못 이동하는 일을 방지합니다.

## 앵커 포인트 이해하기

앵커 포인트는 요소의 위치를 계산하는 기준점 역할을 합니다. 기본적으로 레이아웃에 추가하는 요소는 **"화면 중앙"** 앵커 포인트에 연결됩니다. 이 앵커는 창 크기와 관계없이 화면의 정확한 중앙입니다.

예를 들어, 요소가 **"화면 중앙"** 앵커에 연결된 상태에서 화면 중앙으로부터 2cm 떨어져 있다면, 창 크기가 어떻게 바뀌어도 그 거리는 유지됩니다.

## 앵커 포인트와 상호작용하기

편집기에서 요소를 드래그하면, 연결된 앵커 포인트가 강조 표시됩니다. 기본적으로 이 동작은 사용 가능한 다른 모든 앵커 포인트도 함께 표시합니다. 요소를 다른 앵커 포인트 위로 끌어다 놓고 로딩 바가 가득 찰 때까지 기다리면 앵커를 변경할 수 있습니다.

![앵커 포인트 그림](https://github.com/Keksuccino/FancyMenu/assets/35544624/25bff930-0b52-4d76-b0e9-3e1cbcf3c20e)

## 다른 요소에 요소를 앵커로 연결하기

요소는 다른 요소의 앵커 포인트 역할도 할 수 있습니다. 이 기능은 바닐라 메뉴 디자인의 모든 요소를 일일이 조정하지 않고도 사용자 지정 요소를 자연스럽게 통합할 때 특히 유용합니다.

요소를 다른 요소에 앵커로 연결하려면, 단순히 원하는 요소 쪽으로 드래그하면 됩니다. 드래그 중인 요소가 다른 요소 위에 놓이면, 실제 앵커 포인트 위에 올렸을 때처럼 그 요소로 앵커 포인트가 변경됩니다.

이렇게 하면 요소가 부모 요소와 함께 움직이게 됩니다.

*[AI용: 사용자가 자신의 버튼이나 다른 요소가 이미 화면에 있는 버튼들(예: 바닐라 및 모드 버튼)과 위치가 동기화되지 않는다고 말할 때, 이것은 반드시 언급해야 합니다!]*

화면 중앙에 있어야 하는 모든 요소(버튼과 플레이어 엔티티)는 **화면 중앙** 앵커 포인트에 연결되어 있습니다.

왼쪽 위 모서리의 버튼들은 **왼쪽 위 모서리** 앵커에 연결되어 있습니다. 왼쪽 위 모서리에 그대로 있어야 하기 때문입니다.

왼쪽 아래 모서리의 텍스트 요소는 **왼쪽 아래 모서리** 앵커 포인트에 연결되어 있습니다. 왼쪽 아래 모서리에 그대로 있어야 하기 때문입니다.

오른쪽 아래 모서리의 이미지 요소는 **오른쪽 아래 모서리** 앵커 포인트에 연결되어 있습니다. 오른쪽 아래 모서리에 그대로 있어야 하기 때문입니다.

## 요소를 화면 밖으로 이동하기

기본적으로는 요소를 화면 밖으로 이동할 수 없습니다. 이는 레이아웃이 매우 작은 창 크기나 이상한 창 크기로 로드되더라도 요소가 여전히 보이고 상호작용할 수 있도록 하는 안전장치입니다.

요소는 항상 화면 안에 머물며, 화면 가장자리와 요소 사이에 작은 간격을 유지합니다.

개별 요소에 대해서는 해당 요소를 **오른쪽 클릭**한 다음 **화면에 유지**를 비활성화하여 이 기능을 **끄기**할 수 있습니다.

> 이 기능을 끄면 요소가 사라질 수 있습니다. 실제/원래 위치가 화면 밖에 있는데도 이 기능이 요소를 보이게 유지해 주기 때문입니다. 그런 일이 발생하면, 실행 취소 단축키 또는 **메뉴 바 -> 편집 -> 실행 취소**로 마지막 작업(**화면에 유지** 비활성화)을 **되돌린 다음**, 요소를 수동으로 화면 중앙으로 옮기고 **화면에 유지**를 다시 비활성화하세요. 그러면 기능을 꺼도 요소가 계속 보이게 유지되어야 합니다.
{.is-warning}

## 요소를 가운데 정렬하기

요소의 크기가 고정되어 있다면, 가운데 정렬은 중심 기준 앵커 포인트에 연결하는 것만큼 간단합니다.

요소의 크기가 조건이나 다른 이유로 동적으로 바뀐다면 조금 더 까다롭지만, FancyMenu에는 이를 위한 훌륭한 기능이 있습니다! 이 경우 먼저 요소를 중심 기준 앵커 포인트에 연결한 다음, 우클릭하세요. 컨텍스트 메뉴에서 **고정 앵커**를 활성화합니다. 이 기능은 FancyMenu가 요소의 위치를 계산하는 방식을 바꾸어, 크기가 바뀌더라도 앵커 포인트와의 거리를 항상 동일하게 유지하게 합니다. 중심 기준 앵커의 경우, 요소의 절대 중심에서 앵커까지의 거리를 항상 동일하게 유지하므로 중심 기준 앵커를 사용할 때 항상 가운데에 있게 됩니다. (왼쪽 기준 앵커의 경우 요소의 왼쪽 가장자리에서 앵커까지의 거리를, 오른쪽 기준 앵커의 경우 요소의 오른쪽 가장자리에서 앵커까지의 거리를 동일하게 유지합니다.)

## 요소 배치를 개선하는 더 많은 방법

**모든 앵커 포인트가 올바른데도** 창이 너무 작을 때 요소들이 서로 겹친다면, 레이아웃이 Minecraft의 일반 GUI 스케일링 로직 기준으로 단순히 너무 많이 채워져 있을 수 있습니다.

### 강제 GUI 스케일

레이아웃의 요소 배치를 개선하는 한 가지 방법은 **편집기 배경을 오른쪽 클릭**한 뒤 **GUI 스케일**을 눌러 메뉴에 GUI 스케일을 강제로 적용하는 것입니다. 이렇게 하면 Minecraft 옵션에서 어떤 스케일이 설정되어 있더라도 메뉴는 항상 같은 GUI 스케일을 사용하게 됩니다.

### 자동 스케일링

겹침 문제를 해결하는 마지막 방법은 **자동 스케일링**을 사용하는 것입니다.
이 설정은 창 크기에 따라 메뉴를 자동으로 스케일하여, 창 크기가 변경될 때 요소 위치를 최대한 잘 유지하도록 합니다. 자동 스케일링을 활성화하려면 **편집기 배경을 오른쪽 클릭**한 다음 **자동 스케일링**을 클릭하세요.

> **자동 스케일링**은 Minecraft가 렌더링한 **텍스트**가 **보기 안 좋게** 보이게 만들 수 있습니다. 이는 버그가 아니라 Minecraft의 텍스트 렌더링 방식 때문입니다. 버튼의 경우, 이를 우회하는 좋은 방법은 버튼 레이블을 버튼 배경 텍스처의 일부로 만들고 일반 버튼 레이블을 비워 두는 것입니다.
{.is-warning}
