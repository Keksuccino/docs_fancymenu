# 타이틀 화면의 에메랄드/다이아몬드 아이콘

타이틀 화면에 계속 나타나는 작은 아이콘을 숨기고 싶고, 그 아이콘이 작은 다이아몬드나 에메랄드(초록색 또는 파란색 작은 아이콘)처럼 보인다면, 이는 대부분 Mod Menu(Fabric 모드) 또는 Forge(내장 모드 로더 기능)의 모드 업데이트 알림입니다.

경우에 따라서는 바닐라 마인크래프트의 Realms 버튼(알림 표시용)일 수도 있습니다.

# Mod Menu 아이콘 숨기기

Mod Menu의 글리프를 숨기려면 설정에서 "업데이트 표시기"를 비활성화해야 합니다.

**Mods** 버튼을 클릭한 다음 -> 모드 목록에서 Mod Menu 모드 아이콘 위에 마우스를 올리고 -> 클릭한 뒤 -> "Update Indicator"를 "Hidden"으로 설정하세요.

# Forge 아이콘 숨기기

Forge는 내장 버전 검사 기능을 사용해 모드가 오래되었을 때 해당 에메랄드 아이콘을 표시합니다. 이를 끌 수 있습니다:

1. config/fml.toml 파일을 엽니다.
2. `versionCheck` 설정을 찾습니다.
3. 값을 `false`로 설정합니다: `versionCheck = false`
4. 저장한 뒤 마인크래프트를 다시 시작합니다.

이렇게 하면 버전 검사가 완전히 비활성화되며, 시작 시 에메랄드 글리프도 숨겨집니다.

또 다른 방법은 FancyMenu를 사용해 아예 Mods 버튼 전체를 숨기는 것입니다. 버튼을 숨기면 글리프도 함께 숨겨집니다.

# 바닐라 Realms 아이콘 숨기기

Mod Menu도 아니고 Forge 글리프도 아니라면, 아마 마인크래프트 자체의 Realms 알림 아이콘일 것입니다. 이 아이콘은 대략 Realms 버튼 위치에 표시되며, FancyMenu의 레이아웃 편집기에서 숨길 수 있습니다. "현재 화면용" 레이아웃(이 경우 타이틀 화면용)을 만든 다음, 편집기에서 Realms 아이콘이 별도의 요소로 표시되는 것을 볼 수 있습니다. 숨기려면 그냥 **오른쪽 클릭**한 다음 **Delete**를 클릭하세요.

Realms 아이콘은 신문 아이콘, 다이아몬드 글리프, 또는 알림 숫자가 표시된 빨간 원 등 여러 형태일 수 있습니다.
