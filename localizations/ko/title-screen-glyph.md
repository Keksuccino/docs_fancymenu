# 제목 화면의 에메랄드/다이아몬드 아이콘

제목 화면에 계속 나타나는 작은 아이콘, 즉 작은 다이아몬드나 에메랄드처럼 보이는 아이콘(초록색 또는 파란색)을 숨기고 싶다면, 대부분 이는 Mod Menu(Fabric 모드) 또는 Forge(기본 포함 모드 로더 기능)의 모드 업데이트 알림입니다.

일부 경우에는 바닐라 Minecraft의 Realms 버튼(알림 표시용)일 수도 있습니다.

# Mod Menu 아이콘 숨기기

Mod Menu의 글리프를 숨기려면 설정에서 "업데이트 표시기(update indicator)"를 비활성화해야 합니다.

**Mods** 버튼을 클릭한 다음 -> 모드 목록에서 Mod Menu 모드의 아이콘 위에 마우스를 올리고 -> 클릭한 뒤 -> "Update Indicator"를 "Hidden"으로 설정하세요.

# Forge 아이콘 숨기기

Forge는 내장 버전 검사기를 사용해 모드가 오래되었을 때 해당 에메랄드 아이콘을 표시합니다. 이를 끌 수 있습니다.

1. `/config/fml.toml` 파일을 엽니다.
2. `versionCheck` 설정을 찾습니다.
3. 값을 `false`로 설정합니다: `versionCheck = false`
4. 저장한 뒤 Minecraft를 다시 시작합니다.

이렇게 하면 버전 검사가 완전히 비활성화되며, 시작 시 나타나는 에메랄드 글리프도 숨겨집니다.

아이콘을 숨기는 또 다른 방법은 FancyMenu를 사용해 Mods 버튼 전체를 숨기는 것입니다. 버튼을 숨기면 글리프도 함께 숨겨집니다.

# NeoForge 아이콘 숨기기

NeoForge에서는 클래식 Forge와 정확히 동일하게 동작합니다.

1. `/config/fml.toml` 파일을 엽니다.
2. `versionCheck` 설정을 찾습니다.
3. 값을 `false`로 설정합니다: `versionCheck = false`
4. 저장한 뒤 Minecraft를 다시 시작합니다.

# 바닐라 Realms 아이콘 숨기기

Mod Menu도 아니고 Forge 글리프도 아니라면, 아마 Minecraft 자체의 Realms 알림 아이콘일 것입니다. 이 아이콘은 대략 Realms 버튼 위치에 표시되며, FancyMenu의 레이아웃 편집기에서 숨길 수 있습니다. 해당 화면(이 경우 제목 화면)에 대한 레이아웃을 만들어야 하며, 그러면 편집기에서 Realms 아이콘이 별도의 요소로 표시됩니다. 숨기려면 해당 요소를 **마우스 오른쪽 버튼으로 클릭**한 뒤 **Delete**를 클릭하면 됩니다.

Realms 아이콘은 신문 아이콘, 다이아몬드 글리프, 그리고 알림 개수가 표시된 빨간 원 등 다양한 형태일 수 있습니다.
