# 범용 레이아웃

범용 레이아웃은 화면 사용자 지정이 활성화된 모든 지원 화면에 적용됩니다. [차단된 화면](/incompatibility-list#screens-where-customization-is-intentionally-disabled)이나 기타 제외된 화면에는 적용되지 않습니다.

로고, 탐색 메뉴, 오버레이 또는 여러 화면에서 계속 표시되어야 하는 [오디오 요소](/elements#audio)와 같은 공통 요소에는 범용 레이아웃을 사용하세요.

# 범용 레이아웃 만들기

1. 지원되는 화면을 열고 FancyMenu 메뉴 표시줄을 표시합니다.
2. **레이아웃 -> 새로 만들기 -> 모든 화면용 [범용]**을 선택합니다.
3. 요소를 추가하고 설정합니다.
4. 레이아웃을 저장합니다.

일반 화면에서는 **현재 화면 사용자 지정**도 활성화해야 합니다. 지원되지 않는 모드 화면은 사용자 지정 시 문제가 발생할 수 있으므로, 모든 화면을 한 번에 활성화하는 전역 스위치는 없습니다.

# 적용 화면 제한하기

편집기 배경의 컨텍스트 메뉴에서 범용 레이아웃 설정을 엽니다.

- **허용 목록:** 레이아웃을 목록에 있는 화면 식별자에만 적용합니다.
- **차단 목록:** 목록에 있는 화면 식별자를 제외한 모든 적용 가능한 화면에 레이아웃을 적용합니다.

**사용자 지정 -> 현재 화면 식별자 복사**를 사용하여 [화면 식별자](/screen-identifiers)를 복사할 수 있습니다.

레이아웃이 적용되는 시점을 제어하려면 [레이아웃 전체 요구 사항](/conditions#layout-wide-requirements)을 추가할 수도 있습니다.

# 레이아웃 순서

적용 가능한 범용 레이아웃과 화면별 레이아웃은 **레이아웃 인덱스**에 따라 결합되고 쌓입니다. 인덱스가 낮은 레이아웃이 먼저 적용되며, 뒤에 쌓이는 레이아웃의 설정이 앞선 설정을 덮어쓸 수 있습니다. 인덱스가 같으면 범용 레이아웃이 화면별 레이아웃보다 먼저 모입니다.
