# 범용 레이아웃이란?

범용 레이아웃은 FancyMenu의 강력한 기능으로, 하나의 특정 화면에만 적용하는 대신 **여러 화면**에 적용할 수 있는 레이아웃을 만들 수 있게 해줍니다. 이를 통해 게임 전체에 걸쳐 나타나는 일관된 UI 요소를 만들 때 매우 유용합니다.

범용 레이아웃은 게임의 어디에서나 표시될 수 있는 "전역" 레이아웃이라고 생각하면 됩니다.

# 왜 범용 레이아웃을 사용하나요?

범용 레이아웃은 다음과 같은 경우에 매우 유용합니다:

- 모든 화면에 같은 배경을 추가하고 싶을 때
- 여러 화면에 표시되는 로고나 텍스트를 만들고 싶을 때
- 오디오 요소가 여러 화면에 걸쳐 계속 재생되게 하고 싶을 때
- 게임 전반에 걸쳐 일관된 분위기와 시각적 스타일을 만들고 싶을 때

# 범용 레이아웃은 어떻게 작동하나요?

범용 레이아웃을 만들면 기본적으로 게임의 **모든 화면**과 함께 로드됩니다. 즉, 범용 레이아웃에 추가한 어떤 요소(예: 버튼, 이미지, 텍스트)도 모든 화면에 표시됩니다.

하지만 걱정하지 마세요! 범용 레이아웃을 특정 화면에서만 로드되도록 설정하는 것도 가능합니다. 이를 위해서는 아래의 **블랙리스트**와 **화이트리스트** 섹션을 확인하세요.

# 범용 레이아웃 만들기

1. 게임 내 아무 화면이나 엽니다
2. **Ctrl+Alt+C**를 눌러 커스터마이즈 메뉴를 엽니다
3. **레이아웃 → 새로 만들기 → 모든 화면용 [범용]**으로 이동합니다
4. 이미지, 텍스트, 버튼 같은 요소로 레이아웃을 디자인합니다
5. 설명적인 이름으로 레이아웃을 저장합니다

# 범용 레이아웃이 적용될 화면 관리하기

## 블랙리스트 사용하기

블랙리스트를 사용하면 범용 레이아웃이 **표시되지 않게 할** 화면을 지정할 수 있습니다:

1. 레이아웃 편집기에서 배경을 마우스 오른쪽 버튼으로 클릭합니다
2. **레이아웃 설정 → 범용 레이아웃 옵션**을 선택합니다
3. **화면을 블랙리스트에 추가**를 클릭합니다
4. 화면 식별자(예: 타이틀 화면의 `title_screen`)를 입력합니다

이제 범용 레이아웃은 블랙리스트에 추가한 화면을 제외한 모든 화면에 표시됩니다.

## 화이트리스트 사용하기

화이트리스트는 그 반대로, 범용 레이아웃을 **특정 화면에만** 표시합니다:

1. 레이아웃 편집기에서 배경을 마우스 오른쪽 버튼으로 클릭합니다
2. **레이아웃 설정 → 범용 레이아웃 옵션**을 선택합니다
3. **화면을 화이트리스트에 추가**를 클릭합니다
4. 레이아웃을 표시하고 싶은 각 화면의 식별자를 입력합니다

화이트리스트를 사용하면 범용 레이아웃은 목록에 추가한 화면에만 표시됩니다.

# 화면 식별자 찾기

화면을 화이트리스트나 블랙리스트에 추가하려면 해당 화면의 식별자를 알아야 합니다:

1. 식별하려는 화면으로 이동합니다
2. **Ctrl+Alt+C**를 눌러 커스터마이즈 메뉴를 엽니다
3. **커스터마이즈 → 현재 화면의 식별자 복사**를 클릭합니다
4. 식별자가 클립보드에 복사됩니다

이 식별자를 화이트리스트나 블랙리스트에 붙여넣으면 됩니다.

# 모든 화면에 대한 커스터마이즈 활성화하기

모든 화면에 대해 커스터마이즈를 한 번에 활성화하는 것은 불가능합니다.
이는 의도된 동작이며, 지원되지 않는 모드화된 화면에서 커스터마이즈를 활성화해 게임이 망가지는 일을 방지하기 위한 것입니다.

# 고급 팁

## 로드 순서 관리하기

범용 레이아웃과 화면 전용 레이아웃을 모두 사용하면, 범용 레이아웃이 먼저 로드됩니다. 즉, 화면 전용 레이아웃이 범용 레이아웃의 요소를 덮어쓸 수 있습니다.

## 로드 조건

범용 레이아웃에 로드 조건을 추가하여 특정 조건에서만 로드되도록 할 수 있습니다:

1. 편집기에서 마우스 오른쪽 버튼을 클릭합니다
2. **레이아웃 설정 → 레이아웃 전체 조건**을 선택합니다
3. 낮/밤, 운영체제 또는 기타 조건과 같은 조건을 추가합니다
