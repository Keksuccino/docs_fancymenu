# 바닐라 요소

FancyMenu를 사용하면 화면에 새로운 항목을 추가할 수 있을 뿐만 아니라, 기본 게임(바닐라) 및 다른 모드에 포함된 기존 요소도 사용자 지정할 수 있습니다.

## 바닐라 버튼 및 슬라이더(위젯)

기존 바닐라/모드 위젯을 사용자 지정하려면 **"현재 화면용"** 레이아웃을 새로 만들어야 합니다(범용 레이아웃은 안 됨!). 그런 다음 커스텀 요소와 마찬가지로 편집기에서 해당 요소를 **마우스 오른쪽 버튼으로 클릭**하세요.

커스텀 버튼 및 슬라이더와 마찬가지로 **레이블과 텍스처**를 사용자 지정할 수 있습니다.

바닐라/모드 위젯에서 **할 수 없는** 작업은 **액션 스크립트**를 사용자 지정하는 것입니다(예: 위젯과 상호 작용할 때 수행하는 동작 변경). 이 기능은 커스텀 버튼 및 슬라이더에서만 사용할 수 있습니다.

## 자동 클릭

바닐라 및 모드 위젯에는 **자동 클릭** 속성이 있습니다. 화면이 로드될 때 위젯의 원래 왼쪽 클릭 동작을 지정한 횟수만큼 실행하려면 `0`보다 큰 정수로 설정하세요. 예를 들어 `2`로 설정하면 새로 열린 각 화면의 첫 번째 업데이트 중에 위젯을 두 번 클릭합니다. 기본값인 `0`은 자동 클릭을 비활성화합니다.

이는 실제 위젯 클릭입니다. 클릭할 때마다 슬라이더 또는 순환 버튼의 값이 변경되거나, 위젯의 일반 콜백이 실행되거나, 다른 화면이 열릴 수도 있습니다. 특히 클릭 횟수를 여러 번 설정할 때는 결과를 주의 깊게 테스트하세요.

바닐라/모드 위젯을 **이동**하거나 **크기 조정**하려면 먼저 앵커 포인트를 지정해야 합니다. 그러려면 해당 요소를 **마우스 오른쪽 버튼으로 클릭**하고 **앵커 포인트**를 클릭하세요. 바닐라/모드 요소의 기본 앵커는 **원본**이므로, **원본** 이외의 값으로 설정하세요.

바닐라/모드 위젯은 해당 요소를 **마우스 오른쪽 버튼으로 클릭**한 다음 **삭제**를 클릭하여 **숨길** 수도 있습니다. 실제로 삭제되는 것은 아니며 숨겨지는 것이므로, **메뉴 바 -> 요소 -> 삭제된 바닐라 요소**를 클릭한 다음 다시 표시하려는 요소를 **마우스 왼쪽 버튼으로 클릭**하여 복원할 수 있습니다.

> [!WARNING]
> 타이틀 화면의 **저작권** 위젯은 숨기거나 삭제할 수 **없는** 유일한 위젯입니다. 이는 의도된 동작입니다. 저작권 표시를 제거하지 마세요.

## 타이틀 화면 요소

타이틀 화면에는 일반 위젯이 아닌 요소(로고, 스플래시 텍스트 등)가 있으며, 이러한 요소는 이동하거나 사용자 지정할 수 없습니다. 이러한 요소는 삭제한 후 커스텀 요소로 대체하도록 설계되었습니다(예: 로고는 이미지 요소로, 바닐라 스플래시 텍스트는 커스텀 스플래시 텍스트 요소로 대체).

삭제하려면 해당 요소를 마우스 오른쪽 버튼으로 클릭하세요. 나중에 복원하려면 **메뉴 바 -> 요소 -> 삭제된 바닐라 요소**를 클릭한 다음 다시 표시하려는 요소를 **마우스 왼쪽 버튼으로 클릭**하세요.

## 문제 해결: 편집기에 바닐라 요소가 표시되지 않음

편집기에서 바닐라 요소를 볼 수 없다면 **현재 화면용** 레이아웃이 아닌 **범용 레이아웃**을 사용하고 있기 때문일 가능성이 큽니다. 현재 화면용 레이아웃을 만들어야 합니다. 해당 화면에 사용자 지정 기능이 활성화되어 있을 때만 현재 화면용 레이아웃을 만들 수 있습니다.

## 문제 해결: 사용자 지정이 적용되지 않음

바닐라 요소에 대한 사용자 지정이 편집기 외부에서 적용되지 않는다면, 대개 다른 모드가 바닐라 요소의 상위 메뉴를 재정의하거나 변경하고 있기 때문입니다.

화면/메뉴를 재정의하는 모드의 좋은 예로 **Ice and Fire**가 있습니다. 이 모드는 타이틀 화면을 재정의합니다.

메뉴에 사용자 지정이 적용되지 않는 문제는 바닐라 요소에만 해당하지 않습니다. 모드가 화면을 재정의하거나 변경하는 경우, 화면에 추가한 커스텀 요소 역시 메뉴에 적용되지 않을 수 있습니다.
