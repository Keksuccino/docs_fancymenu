# 바닐라 요소

FancyMenu는 화면에 새로운 항목을 추가할 수 있을 뿐만 아니라, 기본 게임(Vanilla)의 기존 요소는 물론 다른 모드의 요소까지 사용자 지정할 수 있게 해줍니다.

## 바닐라 버튼 및 슬라이더(위젯)

기존 바닐라/모드 위젯을 사용자 지정하려면, **"현재 화면용"** 새 레이아웃을 만들고(**전역 레이아웃이 아님!**), 편집기에서 사용자 지정 요소를 다룰 때처럼 해당 요소를 **오른쪽 클릭**하면 됩니다.

커스텀 버튼과 슬라이더처럼 해당 요소의 **레이블**과 **텍스처**를 사용자 지정할 수 있습니다.

바닐라/모드 위젯에서 **할 수 없는** 유일한 것은 **동작 스크립트**를 사용자 지정하는 것(예: 상호작용했을 때 무엇을 하게 할지 변경)입니다. 이 기능은 커스텀 버튼과 슬라이더에서만 가능합니다.

바닐라/모드 위젯을 **이동**하고 **크기 조절**하려면 먼저 앵커 포인트를 지정해야 합니다. 그러려면 해당 요소를 **오른쪽 클릭**한 뒤 **Anchor Point**를 클릭하세요. **Original**이 아닌 다른 값으로 설정해야 합니다. **Original**은 바닐라/모드 요소의 기본 앵커이기 때문입니다.

바닐라/모드 위젯은 **오른쪽 클릭**한 뒤 **Delete**를 클릭해서 **숨길** 수도 있습니다. 실제로 삭제되는 것은 아니고 숨겨지는 것이며, **메뉴 바 -> Element -> Deleted Vanilla Elements**로 이동한 다음 다시 보이게 할 요소를 **왼쪽 클릭**하면 복원할 수 있습니다.

> 제목 화면의 **Copyright** 위젯은 **숨기거나 삭제할 수 없는** 유일한 요소입니다. 이는 의도된 동작입니다. 저작권 표시는 제거하지 말아 주세요.
{.is-warning}

## 제목 화면 요소

제목 화면에는 로고, 스플래시 텍스트 등 일반 위젯이 아닌 요소가 있으며, 이런 요소들은 이동하거나 사용자 지정할 수 없습니다. 이들은 삭제하고, 대신 커스텀 요소(예: 로고용 Image 요소나 바닐라 스플래시 텍스트용 커스텀 Splash Text 요소)로 대체하도록 되어 있습니다.

삭제하려면 그냥 **오른쪽 클릭**하면 됩니다. 나중에 다시 복원하려면 **메뉴 바 -> Element -> Deleted Vanilla Elements**를 클릭한 뒤 다시 보이게 할 요소를 **왼쪽 클릭**하세요.

## 문제 해결: 편집기에서 바닐라 요소가 보이지 않음

편집기에서 바닐라 요소가 보이지 않는다면, 아마 **현재 화면용 레이아웃**이 아니라 **전역 레이아웃**을 사용하고 있기 때문일 가능성이 큽니다. 현재 화면용 레이아웃을 만들었는지 확인하세요. 현재 화면에 대한 사용자 지정은 해당 화면에서 사용자 지정이 활성화되어 있을 때만 만들 수 있습니다.

## 문제 해결: 사용자 지정이 적용되지 않음

바닐라 요소에 대한 사용자 지정이 편집기 밖에서 적용되지 않는다면, 보통 다른 모드가 바닐라 요소의 상위 메뉴를 덮어쓰거나 변경하고 있기 때문입니다.

화면/메뉴를 덮어쓰는 모드의 좋은 예로는 제목 화면을 덮어쓰는 **Ice and Fire**가 있습니다.

메뉴에 사용자 지정이 적용되지 않는 문제는 바닐라 요소에만 국한되지 않습니다. 화면에 추가된 커스텀 요소도, 모드가 해당 메뉴를 덮어쓰거나 변경하고 있다면 메뉴에 적용되지 않을 가능성이 높습니다.
