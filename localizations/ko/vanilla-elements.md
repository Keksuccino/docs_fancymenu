# 바닐라 요소

FancyMenu에서는 화면에 새 요소를 추가할 수 있을 뿐만 아니라, 기본 게임(바닐라)이나 다른 모드에 포함된 기존 요소도 사용자 지정할 수 있습니다.

## 바닐라 버튼 및 슬라이더(위젯)

화면의 버튼과 슬라이더를 사용자 지정하려면 현재 화면에 사용할 레이아웃([범용 레이아웃](/universal-layouts)이 아닌 레이아웃)을 만들고 편집기에서 해당 요소를 마우스 오른쪽 버튼으로 클릭하세요.

자체 [버튼](/elements#button) 및 [슬라이더](/elements#slider)와 마찬가지로 텍스처, 소리, 툴팁 등의 설정을 변경할 수 있습니다. 다만 동작 스크립트는 변경할 수 없습니다. 기존에 하던 동작은 그대로 유지됩니다.

바닐라 요소는 메뉴 자체에 속하기 때문에 [스크롤 가능한 영역](/scrollable-areas)에 넣을 수 없습니다.

### 레이블

- **레이블**과 **마우스 오버 레이블**은 버튼의 텍스트를 바꿉니다. 슬라이더와 같은 다른 위젯에서는 각각 **위젯 텍스트**와 **마우스 오버 위젯 텍스트**라고 합니다. 이 설정을 사용하지 않으면 위젯에 원래 표시되던 텍스트가 유지됩니다.
- **레이블 정렬**은 위젯의 **왼쪽**, **가운데** 또는 **오른쪽**에 레이블을 배치합니다. 레이블이 위젯보다 너무 넓으면 정렬 위치와 관계없이 좌우로 스크롤됩니다.
- **레이블 크기**, **레이블 기본 색상**, **레이블 마우스 오버 색상**, **레이블 그림자**, **마우스 오버 시 레이블에 밑줄 표시** 설정으로 레이블의 크기와 색상, 그림자를 변경할 수 있습니다.

여러 버튼의 레이블을 한 번에 정렬하려면 `Ctrl`을 누른 채 클릭해 버튼을 선택한 다음([선택](/layout-editor#selecting) 참고), 버튼 하나를 마우스 오른쪽 버튼으로 클릭하고 **레이블 정렬**을 설정하세요. 모든 메뉴의 레이블을 정렬하려면 [전역 사용자 지정](/global-customizations#labels)의 **레이블 정렬**을 사용하세요. [템플릿](/button-slider-templates)을 사용하면 화면의 모든 버튼에 동일한 레이블 스타일을 적용할 수도 있습니다.

## 자동 클릭

바닐라 위젯과 모드 위젯에는 **자동 클릭** 속성이 있습니다. 이 속성을 `0`보다 큰 정수로 설정하면 화면이 로드될 때 위젯의 원래 왼쪽 클릭 동작을 설정한 횟수만큼 실행합니다. 예를 들어 `2`로 설정하면 새 화면이 열릴 때마다 첫 번째 업데이트 중에 위젯을 두 번 클릭합니다. 기본값인 `0`은 자동 클릭을 사용하지 않도록 설정합니다.

실제로 위젯을 클릭하는 동작이므로 클릭할 때마다 슬라이더나 순환 버튼의 값이 바뀌거나, 위젯의 일반 콜백이 실행되거나, 다른 화면이 열릴 수도 있습니다. 특히 클릭 횟수를 2회 이상으로 설정할 때는 결과를 주의 깊게 확인하세요.

바닐라/모드 위젯을 **이동**하거나 **크기 조정**하려면 먼저 기준점을 지정해야 합니다. 위젯을 **마우스 오른쪽 버튼으로 클릭**한 다음 **기준점**을 클릭하세요. 바닐라/모드 요소의 기본 기준점인 **원본** 이외의 값을 선택하세요.

바닐라/모드 위젯을 **숨길** 수도 있습니다. 위젯을 **마우스 오른쪽 버튼으로 클릭**하고 **삭제**를 클릭하면 됩니다. 실제로 삭제되는 것은 아니며 숨겨집니다. 다시 표시하려면 **메뉴 바 -> 요소 -> 삭제된 바닐라 요소**를 클릭한 다음, 다시 표시할 요소를 **마우스 왼쪽 버튼으로 클릭**하세요.

> [!WARNING]
> 타이틀 화면의 **저작권** 위젯만 숨기거나 삭제할 **수 없습니다**. 이는 의도된 동작입니다. 저작권 고지를 제거하지 마세요.

## 타이틀 화면 요소

타이틀 화면에는 로고나 스플래시 텍스트처럼 일반 위젯이 아닌 요소가 있습니다. 이러한 요소는 이동하거나 사용자 지정할 수 없습니다. 대신 삭제한 뒤 사용자 지정 요소로 대체하도록 되어 있습니다. 예를 들어 로고는 이미지 요소로, 바닐라 스플래시 텍스트는 사용자 지정 스플래시 텍스트 요소로 바꿀 수 있습니다.

삭제하려면 해당 요소를 마우스 오른쪽 버튼으로 클릭하세요. 나중에 복원하려면 **메뉴 바 -> 요소 -> 삭제된 바닐라 요소**를 클릭한 다음, 다시 표시할 요소를 **마우스 왼쪽 버튼으로 클릭**하세요.

## 문제 해결: 편집기에서 바닐라 요소가 보이지 않음

편집기에서 바닐라 요소가 보이지 않는다면 현재 화면용 레이아웃이 아닌 **범용 레이아웃**을 사용하고 있을 가능성이 큽니다. 현재 화면용 레이아웃을 만들었는지 확인하세요. 해당 화면에서 사용자 지정이 활성화되어 있어야 현재 화면용 레이아웃을 만들 수 있습니다.

## 문제 해결: 사용자 지정이 적용되지 않음

편집기 밖에서 바닐라 요소의 사용자 지정이 적용되지 않는다면, 다른 모드가 해당 바닐라 요소의 상위 메뉴를 재정의하거나 변경하는 경우가 많습니다.

화면/메뉴를 재정의하는 모드의 대표적인 예로 타이틀 화면을 재정의하는 **Ice and Fire**가 있습니다.

메뉴에 사용자 지정이 적용되지 않는 문제는 바닐라 요소에만 국한되지 않습니다. 모드가 화면을 재정의하거나 변경하면 화면에 추가한 사용자 지정 요소도 메뉴에 적용되지 않을 수 있습니다.
