# 원격 서버 통신

"원격 서버 통신" 시스템을 사용하면 FancyMenu 클라이언트가 WebSocket 연결을 통해 외부 서버와 통신할 수 있습니다.

모든 데이터는 텍스트 기반입니다:

- 일반 텍스트 지원
- JSON 지원(일반 텍스트로 처리됨)

각 서버 URL은 실행 중에 하나의 캐시된 **요청 ID**를 받습니다.
FancyMenu는 이 ID를 사용해 연결을 추적하고 리스너 변수로 노출합니다.

# 빠른 시작

1. 연결을 일찍 열어야 할 때 [**원격 서버에 연결**](#connect-to-remote-server)을 추가합니다.
2. 같은 URL로 [**원격 서버로 데이터 보내기**](#send-data-to-remote-server)를 추가합니다.
3. 응답에 반응하려면 [**원격 서버 데이터 수신 시**](#on-remote-server-data-received)를 추가합니다.
4. 연결 상태 로직에는 [**원격 서버 연결 시**](#on-remote-server-connected) 및 [**원격 서버 연결 종료 시**](#on-remote-server-connection-closed)를 사용합니다.
5. [**원격 서버 연결 닫기**](#close-remote-server-connection) 또는 [**모든 원격 서버 연결 닫기**](#close-all-remote-server-connections)로 연결을 종료합니다.

# 작업

## 원격 서버에 연결

페이로드 데이터를 보내지 않고 원격 서버 연결을 열거나 기존 연결을 재사용합니다.

입력:

- 원격 서버 URL

## 원격 서버로 데이터 보내기

연결을 만들거나(또는 기존 연결을 재사용하여) 텍스트 데이터를 전송합니다.

입력:

1. 원격 서버 URL
2. 데이터

## 원격 서버 연결 닫기

요청 ID를 기준으로 하나의 연결을 닫습니다.

입력:

- 연결 요청 ID

## 모든 원격 서버 연결 닫기

현재 활성화된 모든 원격 서버 연결을 닫습니다.

# 리스너

## 원격 서버 연결 시

원격 서버 연결이 성공적으로 열리면 트리거됩니다.

변수:

- `$$request_id`
- `$$remote_server_url`

## 원격 서버 데이터 수신 시

연결된 원격 서버에서 데이터가 수신되면 트리거됩니다.

변수:

- `$$request_id`
- `$$remote_server_url`
- `$$data`

## 원격 서버 연결 종료 시

원격 서버 연결이 닫힐 때 트리거됩니다.

변수:

- `$$request_id`
- `$$remote_server_url`
- `$$intentionally_closed`
- `$$crashed`
- `$$unknown_close_reason`

# 연결 동작

- 연결은 **클라이언트가 시작**합니다.
- FancyMenu는 연결을 백그라운드에서 활성 상태로 유지합니다.
- 연결이 충돌하거나 시간 초과되면 FancyMenu가 10초마다 재시도합니다.
- 충돌한 연결이 복구되면 FancyMenu가 복구 메시지를 기록합니다.
- 전송되지 않은 메시지는 **최대 30초** 동안 큐에 보관됩니다.
- 30초가 지난 대기 중인 메시지는 삭제됩니다.

# URL 모드

- `wss://`는 그대로 사용되며 권장됩니다.
- `ws://`는 그대로 사용되며 암호화되지 않습니다.
- `https://`는 `wss://`로 변환됩니다.
- `http://`는 `ws://`로 변환됩니다.
- 호스트만 있는 경우 `wss://`가 앞에 붙습니다.
- 다른 명시적 URL 스킴은 거부됩니다.

명시적인 `wss://` URL 사용을 권장합니다. 로컬 URL 예시:

- `ws://127.0.0.1:8765`

서비스마다 하나의 안정적인 URL을 사용하고, 닫힘/충돌 리스너 상태를 처리하며, 더 이상 필요하지 않을 때 연결을 닫으세요.
