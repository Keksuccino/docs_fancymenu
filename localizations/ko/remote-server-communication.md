# 원격 서버 통신

"원격 서버 통신" 시스템을 사용하면 FancyMenu 클라이언트가 WebSocket 연결을 통해 외부 서버와 통신할 수 있습니다.

모든 데이터는 텍스트 기반입니다:

- 일반 텍스트 지원
- JSON 지원(일반 텍스트로 처리)

각 서버 URL에는 실행 중 하나의 캐시된 **요청 ID**가 할당됩니다.
FancyMenu는 이 ID를 사용해 연결을 추적하고 리스너 변수에 노출합니다.

# 빠른 시작

1. 액션 **원격 서버에 연결** 추가(선택 사항이지만, 미리 열어두는 데 유용함)
2. 같은 URL로 액션 **원격 서버로 데이터 보내기** 추가
3. 응답에 반응하려면 리스너 **원격 서버 데이터 수신 시** 추가
4. 연결 상태 로직에는 **원격 서버 연결 시** / **원격 서버 연결 종료 시** 사용
5. 필요할 때 닫기 액션으로 연결을 종료

# 액션

## 원격 서버에 연결

페이로드 데이터를 보내지 않고 원격 서버 연결을 초기화합니다.

입력:

- 원격 서버 URL

## 원격 서버로 데이터 보내기

연결을 생성하거나(또는 기존 연결 재사용) 텍스트 데이터를 전송합니다.

입력:

1. 원격 서버 URL
2. 데이터

## 원격 서버 연결 닫기

요청 ID를 기준으로 연결 하나를 닫습니다.

입력:

- 연결 요청 ID

## 모든 원격 서버 연결 닫기

현재 활성화된 모든 원격 서버 연결을 닫습니다.

# 리스너

## 원격 서버 연결 시

원격 서버 연결이 초기화되면 트리거됩니다.

변수:

- `$$request_id`
- `$$remote_server_url`

## 원격 서버 데이터 수신 시

연결된 원격 서버로부터 데이터가 수신되면 트리거됩니다.

변수:

- `$$request_id`
- `$$remote_server_url`
- `$$data`

## 원격 서버 연결 종료 시

원격 서버 연결이 닫힐 때 트리거됩니다.

변수:

- `$$request_id`
- `$$remote_server_url`
- `$$intentionally_closed`
- `$$crashed`
- `$$unknown_close_reason`

# 연결 동작

- 연결은 **클라이언트가 먼저 시작**합니다
- FancyMenu는 연결을 백그라운드에서 활성 상태로 유지합니다
- 연결이 충돌하거나 시간 초과되면 FancyMenu는 10초마다 다시 시도합니다
- 충돌한 연결이 복구되면 FancyMenu는 복구 메시지를 로그에 남깁니다
- 전송되지 않은 발신 메시지는 **최대 30초의 수명**으로 대기열에 저장됩니다
- 30초보다 오래된 대기열 메시지는 삭제됩니다

# URL 모드

- `wss://` = 보안(TLS), 권장됨
- `ws://` = 암호화되지 않음, 로컬 테스트에 유용

로컬 URL 예시:

- `ws://127.0.0.1:8765`

# 모범 사례

1. 백엔드 서비스마다 하나의 안정적인 URL을 사용하세요.
2. 각 사용 사례에 맞게 페이로드 형식을 일관되게 유지하세요.
3. 닫히거나 충돌한 연결은 대체 UI 로직으로 처리하세요.
4. 흐름이 끝나면 닫기 액션을 사용하세요.
5. 운영 환경에서는 `wss://`를 사용하세요.
