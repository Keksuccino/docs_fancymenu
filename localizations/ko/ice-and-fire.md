# Ice & Fire 메인 메뉴

Ice and Fire 모드의 사용자 지정 타이틀 화면을 비활성화하려면 설정을 변경해야 합니다. 방법은 다음과 같습니다:

## 1. 설정 파일 찾기
- **파일 이름:** 이 설정은 **`iceandfire-client.toml`** 파일에 있습니다.
- **폴더 위치:** 이 파일은 보통 **`<game-directory>/config/`** 폴더에 있으며, 여기서 `<game-directory>`는 현재 사용 중인 런처의 인스턴스/프로필 디렉터리입니다.

## 2. 설정 파일 수정
- **파일 열기:** 일반 텍스트 편집기(Windows의 메모장이나 macOS의 TextEdit 등)로 `iceandfire-client.toml`을 엽니다.
- **설정 찾기:** 아래로 스크롤하여 사용자 지정 메인 메뉴와 관련된 옵션을 찾습니다. 주석 처리되어 있고 다음과 비슷하게 표시될 수 있습니다:
  ```toml
  # 메인 메뉴에 드래곤을 표시할지 여부 [기본값: true]
  B:"Custom main menu"=true
  ```
- **값 변경:** 이 옵션을 **false**로 설정하려면 다음처럼 줄을 바꿉니다:
  ```toml
  B:"Custom main menu"=false
  ```
  이렇게 변경하면 모드가 자체 사용자 지정 메인 메뉴(보통 드래곤이나 다른 테마 비주얼이 포함됨)를 렌더링하지 않도록 합니다.

## 3. 저장하고 다시 시작
- **파일 저장:** 변경한 뒤 파일을 저장합니다.
- **Minecraft 다시 시작:** 변경 사항을 적용하려면 Minecraft를 완전히 종료한 후 다시 시작합니다. 게임이 로드되면 모드의 사용자 지정 메뉴 대신 기본 메인 메뉴가 표시되어야 합니다.

## 추가 팁
- **올바른 파일을 편집하고 있는지 다시 확인:** 별도의 공통 설정 파일이 있을 수 있으므로, 반드시 **`iceandfire-client.toml`**을 편집하고 있는지 확인하세요. (이 파일은 공통 설정이 아닌 클라이언트 전용 설정입니다.)
- **먼저 백업하기:** 수정하기 전에 원본 설정 파일을 백업해 두는 것이 좋습니다.
- **모드팩 사용 시:** 모드팩을 사용 중이라면 설정 파일이 팩의 폴더 구조 안에 있을 수 있지만, 원리는 동일합니다.

이 단계를 따르면 모드가 제공하는 사용자 지정 메인 메뉴가 비활성화되어, 대신 텍스처 팩의 자체 메인 메뉴 배경을 사용할 수 있습니다.
