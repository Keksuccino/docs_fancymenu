---
title: Ice & Fire 메인 메뉴
description: Ice and Fire의 사용자 지정 메인 메뉴를 비활성화하는 방법.
---

Ice and Fire 모드의 사용자 지정 타이틀 화면을 비활성화하려면 설정을 변경해야 합니다. 방법은 다음과 같습니다:

## 1. 설정 파일 찾기
- **파일 이름:** 이 설정은 **`iceandfire-client.toml`** 파일에 있습니다.
- **폴더 위치:** 이 파일은 보통 **`.minecraft/config`** 폴더(또는 사용자 지정 런처나 모드팩을 사용하는 경우 해당 설정 디렉터리) 안에 있습니다.

## 2. 설정 파일 수정하기
- **파일 열기:** 메모장(Windows)이나 텍스트 편집기(macOS의 TextEdit 등) 같은 일반 텍스트 편집기로 `iceandfire-client.toml`을 엽니다.
- **설정 찾기:** 아래로 스크롤해서 사용자 지정 메인 메뉴와 관련된 옵션을 찾습니다. 주석 처리되어 있으며 다음과 비슷하게 보일 수 있습니다:
  ```toml
  # 메인 메뉴에서 용을 표시할지 여부 [기본값: true]
  B:"Custom main menu"=true
  ```
- **값 변경:** 해당 줄을 다음과 같이 바꾸어 이 옵션을 **false**로 설정합니다:
  ```toml
  B:"Custom main menu"=false
  ```
  이렇게 변경하면 모드가 사용자 지정 메인 메뉴(대개 용이나 다른 테마 비주얼이 포함됨)를 렌더링하지 않도록 합니다.

## 3. 저장하고 다시 시작하기
- **파일 저장:** 변경을 완료한 뒤 파일을 저장합니다.
- **Minecraft 재시작:** 변경 사항을 적용하려면 Minecraft를 종료한 뒤 다시 실행합니다. 게임을 불러오면 이제 모드의 사용자 지정 메뉴 대신 기본 메인 메뉴가 표시되어야 합니다.

## 추가 팁
- **올바른 파일을 수정하고 있는지 확인:** 별도의 공용 설정 파일이 있을 수도 있으니, 반드시 **`iceandfire-client.toml`**을 수정하고 있는지 확인하세요(이 파일은 공용 설정이 아니라 클라이언트 전용 설정입니다).
- **먼저 백업하기:** 원본 설정 파일을 수정하기 전에 백업을 만들어 두는 것이 좋습니다.
- **모드팩 사용 시:** 모드팩을 사용 중이라면 설정 파일이 팩의 폴더 구조 안에 있을 수 있지만, 원리는 동일합니다.

이 방법은 커뮤니티 사용자들에 의해 확인되었습니다. 예를 들어 Feed The Beast 포럼의 여러 사용자는 **`iceandfire-client.toml`**에서 `"Custom main menu"` 옵션을 찾아 변경하면 문제가 해결된다고 언급했습니다. (한 사용자는 “ice and fire config에서 표시하지 않도록 설정하고, 파일은 config 폴더에 있다”고 말했습니다.) citeturn0search1
