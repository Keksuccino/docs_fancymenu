# FAQ

### 문제에 대한 도움이 필요합니다. 어떤 정보를 제공해야 하나요?

최대한 정확한 도움을 받으려면 다음과 같이 가능한 한 많은 정보를 제공해 주세요.
1.  **문제에 대한 명확한 설명:** 어떤 일이 일어나기를 기대했으며, 실제로는 어떤 일이 일어났나요?
2.  **`latest.log` 파일:** `<game-directory>/logs/latest.log`에서 찾을 수 있습니다. **특별히 요청받은 경우가 아니라면 크래시 로그를 보내지 마세요.** 일반적으로 필요한 정보는 `latest.log`에 포함되어 있습니다. 파일을 게시할 때는 https://gist.github.com 같은 사이트를 사용하세요.
3.  **Minecraft 버전:** (예: 1.20.1)
4.  **모드 로더 및 버전:** (예: Forge 47.2.0, Fabric 0.15.7)
5.  **FancyMenu 버전:** (예: 3.5.2)
6.  문제의 **스크린샷이나 동영상**도 큰 도움이 될 수 있습니다.

### 요소의 레이어 순서를 어떻게 변경하나요? (다른 요소의 앞이나 뒤로 이동하는 방법)

*   **커스텀 요소 간:** **Window -> Editor Widgets -> Layers**를 열고 계층 구조에서 요소를 드래그하세요. 요소를 마우스 오른쪽 버튼으로 클릭한 뒤 **Move One Layer Up/Down**을 사용할 수도 있습니다. [레이어와 그룹](./layers-and-groups)을 참고하세요.
*   **커스텀 요소와 바닐라 요소 간:** 모든 커스텀 요소를 모든 바닐라 요소보다 뒤에 렌더링하려면 (예: 기본 버튼 뒤에 배경 이미지를 배치하려면) **편집기 배경을 마우스 오른쪽 버튼으로 클릭**하고 **"Render Custom Elements Behind Vanilla"** 옵션을 활성화하세요.

### 특정 버튼을 범용 버튼 템플릿에서 제외할 수 있나요?

**아니요. 템플릿 버튼에 커스텀 텍스처가 설정되어 있으면 해당 텍스처는 영향을 받는 모든 요소와 항상 공유됩니다. 개별 버튼을 제외할 수는 없습니다.**

### 버튼을 클릭했을 때 특정 동작을 하게 하려면 어떻게 하나요?

[**액션 스크립트**](./action-scripts)를 사용하세요.
1.  편집기에서 버튼을 마우스 오른쪽 버튼으로 클릭합니다.
2.  **Edit Action Script**를 선택합니다.
3. **Add Action**을 클릭하고 [**Open Screen or Custom GUI**](./action-scripts#open-screen-or-custom-gui-opengui), [**Join Server**](./action-scripts#join-server-joinserver), [**Set Variable Value**](./action-scripts#set-variable-value-fm-variable-set_variable)와 같은 동작을 선택합니다.

### 완전히 새로운 메뉴 화면을 처음부터 만들 수 있나요?

[**커스텀 GUI**](./custom-guis)를 사용하세요.
1.  메뉴 바에서 **Customization -> Custom GUIs -> Manage Custom GUIs**로 이동합니다.
2.  **"New GUI"**를 클릭하고 고유한 식별자를 지정합니다.
3.  새로 만든 빈 화면을 연 다음 레이아웃을 만들고 원하는 요소를 추가할 수 있습니다.
4. [**Open Screen or Custom GUI** 동작](./action-scripts#open-screen-or-custom-gui-opengui)을 사용해 커스텀 GUI를 엽니다.

### 프리로딩을 활성화한 후 게임 로딩에 너무 오래 걸립니다.

이는 정상적인 동작입니다. 고해상도 애니메이션이나 사운드처럼 용량이 큰 리소스를 시작 시 미리 로드하면 게임 로딩 시간이 자연스럽게 늘어납니다.

### FMA 애니메이션이 RAM을 너무 많이 사용합니다!

많은 고해상도 프레임이 포함된 클래식 [FMA 애니메이션](./fma)은 메모리를 많이 사용할 수 있습니다. 크거나 복잡한 애니메이션 텍스처에는 AFMA가 더 적합합니다. 클래식 FMA 애니메이션은 짧게 유지하고, 전체 동영상 재생에는 [Video](./video)를 사용하세요.

### FancyMenu는 OptiFine과 함께 사용할 수 있나요?

아니요. OptiFine은 **호환되지 않으며**, FancyMenu를 포함한 많은 모드를 손상시키는 것으로 알려져 있습니다. Sodium/Embeddium + Iris/Oculus와 같은 최신 대체 모드를 사용하는 것을 강력히 권장합니다.
[OptiFine 대체 모드](./optifine-alternatives)를 참고하세요.

### 게임이 충돌합니다. 모드 충돌인지 확인하려면 어떻게 해야 하나요?

모드 충돌을 확인하는 가장 좋은 방법은 **FancyMenu와 해당 종속성**(Konkrete, Melody)만 설치한 상태로 게임을 실행하는 것입니다. 충돌이 더 이상 발생하지 않는다면 다른 모드를 소그룹으로 조금씩 다시 추가하면서 충돌이 재발하는지 확인해 충돌을 일으키는 모드를 찾을 수 있습니다.

### 다른 모드의 버튼이 사라지거나 편집하려고 하면 작동하지 않습니다.

일부 모드는 FancyMenu가 감지하거나 커스터마이즈할 수 없는 방식으로 위젯을 추가합니다. [바닐라/모드 요소](./vanilla-elements)와 목록 기반 화면의 경우 [스크롤 가능한 화면 커스터마이즈](./customizing-scrollable-screens)를 확인하세요. 위젯이 여전히 표시되지 않는다면 해당 위젯을 추가하는 모드가 이를 지원되는 화면 위젯으로 제공해야 합니다.

### FancyMenu 레이아웃을 서버에서 사용할 수 있나요?

레이아웃과 시각적 커스터마이즈는 플레이어의 클라이언트에 저장되므로, 서버가 설정되지 않은 클라이언트에 이를 강제로 적용할 수는 없습니다. 모드팩의 일부로 배포하세요. [서버 명령어](./commands), [FM Data](./fm-data), [서버 측 NBT 액세스](./nbt-data-placeholder#server-side-placeholder), 게임 규칙, 구조물 또는 서버 리스너가 필요할 때는 서버에 FancyMenu를 설치하세요.

### 구버전 MC용 FancyMenu v2와 v3의 차이점은 무엇인가요?

FancyMenu v3는 많은 새 기능, 더욱 안정적인 아키텍처, 향상된 성능을 갖춘 완전한 재작성 버전입니다. V2는 오래되었고 더 이상 지원되지 않으며, 고급 플레이스홀더와 스크립팅 같은 많은 기능이 없습니다. 최신 Minecraft 버전(1.18.2 이상)에서는 v3를 사용하는 것을 강력히 권장합니다. V2 레이아웃은 불러올 때 v3로 자동 변환할 수 있지만, 일부 수동 수정이 필요할 수 있습니다.

### 미리 만들어진 레이아웃과 템플릿은 어디에서 찾을 수 있나요?

FancyMenu 커뮤니티는 공식 Keksuccino's Mods Discord 서버("Kekscord")의 [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) 채널에서 레이아웃을 공유합니다.

### Player Entity를 다른 요소보다 뒤에 렌더링하려면 어떻게 하나요?

일반적으로 [Layers 위젯](./layers-and-groups)을 통해 [Player Entity 요소](./elements#player-entity)를 일반적인 2D 요소보다 뒤에 강제로 배치할 수는 없습니다. 해당 렌더러는 일반 GUI 레이어 순서를 무시할 수 있습니다. 이러한 제한을 고려해 레이아웃을 설계하거나, 엄격한 레이어 순서가 필요할 때는 미리 렌더링한 이미지를 사용하세요.

### Player Entity의 다리가 하나밖에 없습니다! 어떻게 된 건가요?

이는 플레이어 애니메이션이나 모델을 변경하는 다른 모드와의 충돌로 인해 발생했을 가능성이 높은 시각적 오류입니다. Player Entity의 Pose 설정을 확인하여 다리가 실수로 회전되거나 이동되지 않았는지 살펴보세요.

### 스크립트에서 동작 사이에 지연을 만들려면 어떻게 하나요?

지연된 동작 로직에는 [**Delay** 또는 **Execute Later** 블록](./action-scripts#what-are-statements)을 사용하세요. 반복되는 백그라운드 로직에는 [스케줄러](./schedulers)를 사용하세요.

### Create 모드의 메뉴를 커스터마이즈할 수 있나요?

아니요. Create 화면은 의도적으로 커스터마이즈가 비활성화되어 있습니다. [커스터마이즈가 의도적으로 비활성화된 화면](./incompatibility-list#screens-where-customization-is-intentionally-disabled)을 참고하세요.

### 배경 이미지와 버튼 텍스처에 권장되는 해상도는 무엇인가요?

배경: 표준 1920x1080(1080p) 이미지는 좋은 출발점이며 대부분의 사용자에게 적절하게 크기가 조정됩니다.
버튼: 대부분의 바닐라 버튼은 너비 약 150~200픽셀, 높이 20픽셀입니다. 일관성을 위해 커스텀 텍스처도 이 크기에 맞추는 것이 좋습니다.

### 플레이어가 게임 내 목표(예: 퀘스트)를 완료했을 때 메뉴를 자동으로 열거나 명령어를 실행할 방법이 있나요?
FancyMenu에는 다양한 [내장 게임 이벤트 리스너](./listeners)가 있지만, 모든 서드파티 퀘스트 시스템을 위한 범용 리스너는 없습니다. 퀘스트 모드가 명령어 보상을 지원한다면 이를 사용해 [`/openguiscreen`](./commands#openguiscreen), [`/fmvariable`](./commands#fmvariable) 또는 적절한 다른 [FancyMenu 명령어](./commands)를 실행하세요.

### 버튼을 비활성화하거나 "회색으로" 표시하려면 어떻게 하나요?

[로딩 요구 사항](./conditions)을 사용해 버튼의 활성 상태를 제어할 수 있습니다.
편집기에서 버튼을 마우스 오른쪽 버튼으로 클릭하고 **Control Active State**를 선택합니다.
버튼이 활성화되기 위해 충족해야 하는 요구 사항을 추가하세요. 영구적으로 비활성화하려면 [**Is Number**](./conditions#is-number-fancymenu_visibility_requirement_is_number)를 사용해 0이 1과 같은지 확인하도록 설정하세요.
이제 버튼은 "Inactive Background" 텍스처를 사용하며 클릭할 수 없게 됩니다.

### 스크롤 가능한 화면에서 헤더와 푸터(흙 텍스처 막대)를 제거하려면 어떻게 하나요?

레이아웃 편집기에서 **Layout Properties -> Header/Footer Customizations**를 엽니다. 텍스처를 투명하게 설정하세요. 일부 모드 화면에서는 이 옵션을 사용할 수 없습니다.

### "현재 화면에 대해" 레이아웃을 만들 수 없습니다. 버튼이 회색으로 표시됩니다.

먼저 **메뉴 바 -> Customization -> Current Screen Customizations -> Enabled**를 통해 해당 화면의 커스터마이즈를 활성화해야 합니다.

### 편집기에서 화면을 열면 요소를 전혀 커스터마이즈할 수 없습니다. 빈 화면만 표시됩니다.

현재 화면에 **대한 레이아웃** 대신 [범용 레이아웃](./universal-layouts)을 만들었기 때문일 수 있습니다.

또한 [스크롤 가능한 화면](./customizing-scrollable-screens)일 수도 있으며, FancyMenu에서는 기본적으로 이를 커스터마이즈할 수 없습니다.

세 번째 가능성은 모드가 바닐라 방식이 아닌 방법으로 요소를 추가하는 화면일 수 있다는 것입니다. 이 경우 FancyMenu가 해당 요소를 커스터마이즈할 수 없습니다.

### Text 요소에 이상한 회색 상자가 표시됩니다.

이 반투명한 상자는 [Text 요소](./elements#text)의 스크롤 잡이이며, 렌더링 오류가 아닙니다.

상자를 표시하지 않으려면 요소를 마우스 오른쪽 버튼으로 클릭하고 스크롤을 완전히 비활성화하거나, 요소를 계속 스크롤할 수 있도록 같은 오른쪽 클릭 메뉴에서 잡이 텍스처를 완전히 투명한 텍스처로 설정할 수 있습니다.

### 메뉴에 최신 Minecraft 변경 로그를 표시하려면 어떻게 하나요?

Minecraft의 변경 로그를 FancyMenu 호환 Markdown으로 변환해 메뉴에 최신 MC 변경 로그를 표시할 수 있게 해 주는 훌륭한 [GitHub 프로젝트](https://github.com/ClaytonTDM/minecraft-changelogs-markdown)가 있습니다! 매일 업데이트되어 새 변경 로그를 가져옵니다.

[Text 요소](./elements#text)에 표시하려면 **Source Mode**를 **Resource**로 설정하고 리소스 소스를 **Web**으로 설정하세요. `https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`를 사용하세요.

### 모든 요소를 화면 크기에 맞게 늘리는 가장 쉬운 방법은 무엇인가요?

대부분의 요소는 오른쪽 클릭 컨텍스트 메뉴에서 가로 및 세로로 늘리는 옵션을 제공합니다. 이 옵션을 활성화하면 요소가 항상 화면의 전체 너비 및/또는 높이에 맞게 늘어납니다. 가로 및 세로 늘리기는 각각 독립적으로 설정할 수 있습니다.

### Text 요소의 앞이나 뒤에 버튼 또는 슬라이더가 있으면 클릭하거나 상호작용할 수 없습니다.

Text 요소는 기본적으로 상호작용 가능하기 때문에 발생합니다. 스크롤 잡이를 드래그하거나 Markdown 하이퍼링크를 클릭할 수 있어 마우스 클릭과 스크롤 이벤트를 소비합니다. 가장 좋은 방법은 버튼을 Text 요소의 앞이나 뒤로 이동하지 않는 것이지만, 다른 방법이 없다면 **Text 요소를 마우스 오른쪽 버튼으로 클릭**한 다음 **Interactable**을 **Disabled**로 설정해 상호작용할 수 없게 만들 수 있습니다. 이렇게 하면 Text 요소가 정적이고 상호작용할 수 없는 텍스트가 되므로 더 이상 스크롤하거나 하이퍼링크를 클릭할 수 없습니다.

### 화면에서 화살표 및 Tab 키로 탐색할 때 버튼과 슬라이더가 더 이상 선택되거나 포커스를 받지 않게 하려면 어떻게 하나요?

버튼과 슬라이더를 탐색할 수 없게 하려면 해당 요소를 **마우스 오른쪽 버튼으로 클릭**하고 **Navigable**을 **Disabled**로 설정하세요. 버튼이나 슬라이더를 클릭할 수는 있지만, 더 이상 화살표 키나 Tab 키로 포커스를 이동할 수 없습니다.

이는 Chat 화면에 버튼이나 슬라이더를 추가할 때도 유용합니다. 화면에서 버튼이나 슬라이더를 실수로 선택하지 않고 위쪽 화살표 키를 사용해 이전 메시지를 계속 스크롤할 수 있습니다.

### FancyMenu의 컨텍스트 메뉴 중 하나에 있어야 할 옵션이 없습니다.

FancyMenu의 컨텍스트 메뉴(어딘가를 마우스 오른쪽 버튼으로 클릭하거나 메뉴 바와 상호작용할 때 열리는 메뉴)는 **스크롤할 수 있습니다**. 즉, 마우스 커서를 메뉴 위에 둔 상태에서 마우스 휠을 사용해 위아래로 스크롤하면 이전에 표시되지 않았던 더 많은 옵션을 볼 수 있습니다.

### Title 화면을 커스터마이즈할 수 없고, 편집기를 나가면 원래 화면이 계속 표시됩니다.

다른 모드가 원래 `title_screen`을 대체하고 있습니다. 해당 모드의 설정에서 커스텀 Title 화면을 비활성화하세요. 그런 옵션이 없다면 FancyMenu는 대체된 화면에 레이아웃을 적용할 수 없습니다.
