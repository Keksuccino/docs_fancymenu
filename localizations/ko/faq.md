# 자주 묻는 질문

### 문제에 대한 도움이 필요합니다. 어떤 정보를 제공해야 하나요?

최대한 정확한 도움을 받으려면 다음과 같이 가능한 한 많은 정보를 제공해 주세요:
1.  **문제에 대한 명확한 설명:** 어떤 결과를 예상했으며 실제로는 어떻게 되었나요?
2.  **`latest.log` 파일:** `<game-directory>/logs/latest.log`에서 찾을 수 있습니다. **특별히 요청받은 경우가 아니라면 크래시 로그를 보내지 마세요.** 일반적으로 필요한 내용은 `latest.log`에 포함되어 있습니다. 게시할 때는 https://gist.github.com 같은 사이트를 이용하세요.
3.  **Minecraft 버전:** (예: 1.20.1)
4.  **모드 로더 및 버전:** (예: Forge 47.2.0, Fabric 0.15.7)
5.  **FancyMenu 버전:** (예: 3.5.2)
6.  문제를 보여 주는 **스크린샷 또는 동영상**도 큰 도움이 될 수 있습니다.

### 요소의 레이어 순서를 어떻게 변경하나요? (다른 요소 앞이나 뒤로 이동)

*   **커스텀 요소 간:** **Window -> Editor Widgets -> Layers**를 열고 계층 구조에서 요소를 드래그하세요. 요소를 마우스 오른쪽 버튼으로 클릭한 다음 **Move One Layer Up/Down**을 사용할 수도 있습니다. [레이어와 그룹](./layers-and-groups)을 참고하세요.
*   **커스텀 요소와 바닐라 요소 간:** 모든 커스텀 요소를 모든 바닐라 요소 뒤에 렌더링하려면 (예: 기본 버튼 뒤에 배경 이미지를 배치하려면) **편집기 배경을 마우스 오른쪽 버튼으로 클릭**하고 **"Render Custom Elements Behind Vanilla"** 옵션을 켜세요.

### 유니버설 버튼 템플릿에서 특정 버튼을 제외할 수 있나요?

**아니요. 템플릿 버튼에 커스텀 텍스처가 설정되어 있으면 해당 텍스처는 영향을 받는 모든 요소와 항상 공유됩니다. 개별 버튼을 제외할 수 없습니다.**

### 버튼을 클릭했을 때 무언가를 실행하게 하려면 어떻게 하나요?

[**액션 스크립트**](./action-scripts)를 사용하세요.
1.  편집기에서 버튼을 마우스 오른쪽 버튼으로 클릭합니다.
2.  **Edit Action Script**를 선택합니다.
3. **Add Action**을 클릭하고 [**Open Screen or Custom GUI**](./action-scripts#open-screen-or-custom-gui-opengui), [**Join Server**](./action-scripts#join-server-joinserver), [**Set Variable Value**](./action-scripts#set-variable-value-fm-variable-set_variable)와 같은 액션을 선택합니다.

### 완전히 새로운 메뉴 화면을 처음부터 만들 수 있나요?

[**커스텀 GUI**](./custom-guis)를 사용하세요.
1.  메뉴 바에서 **Customization -> Custom GUIs -> Manage Custom GUIs**로 이동합니다.
2.  **"New GUI"**를 클릭하고 고유 식별자를 지정합니다.
3.  이제 새 빈 화면을 열고 원하는 요소를 추가하여 레이아웃을 만들 수 있습니다.
4. [**Open Screen or Custom GUI** 액션](./action-scripts#open-screen-or-custom-gui-opengui)을 사용해 커스텀 GUI를 엽니다.

### 사전 로딩을 활성화한 후 게임을 불러오는 데 너무 오래 걸립니다.

이는 정상적인 동작입니다. 고해상도 애니메이션이나 사운드와 같은 대용량 리소스를 게임 시작 시 미리 로드하면 자연스럽게 게임 로딩 시간이 길어집니다.

### FMA 애니메이션이 RAM을 너무 많이 사용합니다!

클래식 [FMA 애니메이션](./fma)에 고해상도 프레임이 많이 포함되어 있으면 메모리를 많이 사용할 수 있습니다. 크거나 복잡한 애니메이션 텍스처에는 AFMA가 더 적합합니다. 클래식 FMA 애니메이션은 짧게 유지하고, 전체 동영상 재생에는 [Video](./video)를 사용하세요.

### FancyMenu는 OptiFine과 함께 사용할 수 있나요?

아니요. OptiFine은 **호환되지 않으며** FancyMenu를 포함한 여러 모드를 망가뜨리는 것으로 알려져 있습니다. Sodium/Embeddium + Iris/Oculus와 같은 최신 대체 모드를 사용하는 것을 강력히 권장합니다.
[OptiFine 대체 모드](./optifine-alternatives)를 참고하세요.

### 게임이 충돌합니다. 모드 충돌인지 어떻게 확인하나요?

모드 충돌을 확인하는 가장 좋은 방법은 **FancyMenu와 해당 종속성**(Konkrete, Melody)만 설치한 상태로 게임을 실행하는 것입니다. 더 이상 충돌이 발생하지 않는다면 다른 모드를 소그룹 단위로 다시 추가하면서 충돌이 다시 발생하는 시점을 확인하여 충돌하는 모드를 찾을 수 있습니다.

### 다른 모드의 버튼이 사라지거나 편집하려고 하면 작동하지 않습니다.

일부 모드는 FancyMenu가 감지하거나 커스터마이즈할 수 없는 방식으로 위젯을 추가합니다. [바닐라/모드 요소](./vanilla-elements)와 목록 기반 화면의 경우 [스크롤 가능한 화면 커스터마이즈](./customizing-scrollable-screens)를 확인하세요. 위젯이 여전히 표시되지 않는다면 해당 위젯을 추가하는 모드가 지원되는 화면 위젯으로 제공해야 합니다.

### 서버에서 FancyMenu 레이아웃을 사용할 수 있나요?

레이아웃과 시각적 커스터마이즈는 플레이어의 클라이언트에 저장되므로, 서버가 설정되지 않은 클라이언트에 이를 강제로 적용할 수는 없습니다. 모드팩의 일부로 배포하세요. [서버 명령어](./commands), [FM Data](./fm-data), [서버 측 NBT 접근](./nbt-data-placeholder#server-side-placeholder), 게임 규칙, 구조물 또는 서버 리스너가 필요할 때는 서버에 FancyMenu를 설치하세요.

### 이전 Minecraft 버전용 FancyMenu v2와 v3의 차이는 무엇인가요?

FancyMenu v3는 많은 새로운 기능과 더 안정적인 아키텍처, 향상된 성능을 갖춘 완전한 재작성 버전입니다. V2는 오래되어 더 이상 지원되지 않으며, 고급 플레이스홀더와 스크립팅 같은 많은 기능이 빠져 있습니다. 최신 Minecraft 버전(1.18.2 이상)에서는 v3를 사용하는 것을 강력히 권장합니다. V2 레이아웃은 불러올 때 v3로 자동 변환할 수 있지만 일부는 수동으로 수정해야 할 수 있습니다.

### 미리 만들어진 레이아웃과 템플릿은 어디에서 찾을 수 있나요?

FancyMenu 커뮤니티는 공식 Keksuccino's Mods Discord 서버("Kekscord")의 [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) 채널에서 레이아웃을 공유합니다.

### Player Entity를 다른 요소 뒤에 렌더링하려면 어떻게 하나요?

일반적으로 [Layers 위젯](./layers-and-groups)을 통해 [Player Entity 요소](./elements#player-entity)를 일반 2D 요소 뒤에 강제로 배치할 수 없습니다. Player Entity의 렌더러가 일반 GUI 레이어 순서를 무시할 수 있기 때문입니다. 이러한 제한을 고려해 레이아웃을 설계하거나, 엄격한 레이어 순서가 필요한 경우 미리 렌더링한 이미지를 사용하세요.

### Player Entity에 다리가 하나만 있습니다! 어떻게 된 건가요?

다른 모드가 플레이어 애니메이션이나 모델을 변경하면서 발생하는 모드 충돌로 인한 시각적 오류일 가능성이 높습니다. Player Entity의 포즈 설정에서 다리가 실수로 회전되거나 이동되었는지 확인하세요.

### 스크립트에서 액션 사이에 지연 시간을 만들려면 어떻게 하나요?

지연된 액션 로직에는 [**Delay** 또는 **Execute Later** 블록](./action-scripts#what-are-statements)을 사용하세요. 반복되는 백그라운드 로직에는 [스케줄러](./schedulers)를 사용하세요.

### Create 모드의 메뉴를 커스터마이즈할 수 있나요?

아니요. Create 화면은 의도적으로 커스터마이즈가 비활성화되어 있습니다. [커스터마이즈가 의도적으로 비활성화된 화면](./incompatibility-list#screens-where-customization-is-intentionally-disabled)을 참고하세요.

### 배경 이미지와 버튼 텍스처에 권장되는 해상도는 무엇인가요?

배경: 표준 1920x1080(1080p) 이미지를 시작점으로 사용하면 대부분의 사용자 환경에서 잘 맞습니다.
버튼: 대부분의 바닐라 버튼은 너비 약 150~200픽셀, 높이 20픽셀입니다. 일관성을 위해 커스텀 텍스처도 이 크기에 맞추는 것이 좋습니다.

### 플레이어가 게임 내 목표(예: 퀘스트)를 완료했을 때 메뉴를 자동으로 열거나 명령어를 실행할 방법이 있나요?

FancyMenu에는 다양한 [내장 게임 이벤트 리스너](./listeners)가 있지만, 모든 서드파티 퀘스트 시스템을 지원하는 범용 리스너는 없습니다. 퀘스트 모드가 명령어 보상을 지원한다면 이를 사용해 [`/openguiscreen`](./commands#openguiscreen), [`/fmvariable`](./commands#fmvariable) 또는 적절한 다른 [FancyMenu 명령어](./commands)를 실행하세요.

### 버튼을 비활성화하거나 "회색으로" 표시하려면 어떻게 하나요?

[로딩 요구 사항](./conditions)을 사용해 버튼의 활성 상태를 제어할 수 있습니다.
편집기에서 버튼을 마우스 오른쪽 버튼으로 클릭하고 **Control Active State**를 선택하세요.
버튼이 활성화되기 위해 충족해야 하는 요구 사항을 추가합니다. 영구적으로 비활성화하려면 [**Is Number**](./conditions#is-number-fancymenu_visibility_requirement_is_number)를 사용해 0이 1과 같은지 확인하세요.
이제 버튼은 "Inactive Background" 텍스처를 사용하며 클릭할 수 없게 됩니다.

### 스크롤 가능한 화면에서 헤더와 푸터(흙 텍스처 막대)를 제거하려면 어떻게 하나요?

레이아웃 편집기에서 **Layout Properties -> Header/Footer Customizations**를 엽니다. 텍스처를 투명하게 설정하세요. 일부 모드 화면에서는 이 옵션을 사용할 수 없을 수 있습니다.

### "현재 화면용" 레이아웃을 만들 수 없습니다. 버튼이 회색으로 표시됩니다.

먼저 **메뉴 바 -> Customization -> Current Screen Customizations -> Enabled**를 통해 해당 화면의 커스터마이즈를 활성화해야 합니다.

### 편집기에서 화면을 열면 어떤 요소도 커스터마이즈할 수 없습니다. 빈 화면만 표시됩니다.

현재 화면 **용** 레이아웃이 아니라 [유니버설 레이아웃](./universal-layouts)을 만들었기 때문일 수 있습니다.

또한 [스크롤 가능한 화면](./customizing-scrollable-screens)일 수도 있으며, FancyMenu는 기본적으로 이러한 화면을 커스터마이즈할 수 없습니다.

세 번째 가능성은 모드가 바닐라 방식이 아닌 방법으로 요소를 추가하는 화면이어서 FancyMenu가 해당 요소를 커스터마이즈할 수 없는 경우입니다.

### Text 요소에 이상한 회색 상자가 표시됩니다.

이 반투명한 상자는 렌더링 오류가 아니라 [Text 요소](./elements#text)의 스크롤 손잡이입니다.

이 상자를 표시하고 싶지 않다면 요소를 마우스 오른쪽 버튼으로 클릭해 스크롤을 완전히 비활성화하세요. 또는 요소를 계속 스크롤할 수 있도록 같은 오른쪽 클릭 메뉴에서 손잡이 텍스처를 완전히 투명한 텍스처로 설정할 수도 있습니다.

### 메뉴에 최신 Minecraft 변경 로그를 표시하려면 어떻게 하나요?

Minecraft의 변경 로그를 FancyMenu 호환 Markdown으로 변환해 주는 훌륭한 [GitHub 프로젝트](https://github.com/ClaytonTDM/minecraft-changelogs-markdown)가 있습니다. 이를 사용하면 메뉴에 최신 MC 변경 로그를 표시할 수 있습니다! 매일 업데이트되어 새로운 변경 로그를 가져옵니다.

[Text 요소](./elements#text)에 표시하려면 **Source Mode**를 **Resource**로 설정하고 리소스 소스를 **Web**으로 설정하세요. `https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`를 사용합니다.

### 요소를 화면 크기에 맞게 늘리는 가장 쉬운 방법은 무엇인가요?

대부분의 요소는 오른쪽 클릭 컨텍스트 메뉴에서 가로 및 세로로 늘리는 옵션을 제공합니다. 이 옵션을 활성화하면 요소가 항상 화면의 전체 너비 및/또는 높이에 맞게 늘어납니다. 가로 늘리기와 세로 늘리기는 각각 독립적으로 설정할 수 있습니다.

### Text 요소의 뒤나 앞에 있는 버튼을 클릭하거나 슬라이더와 상호작용할 수 없습니다.

Text 요소는 기본적으로 상호작용 가능하기 때문에 발생합니다. 스크롤 손잡이를 잡거나 Markdown 하이퍼링크를 클릭할 수 있도록 설정되어 있어 마우스 클릭과 스크롤 이벤트를 차단합니다. 가장 좋은 방법은 버튼을 Text 요소의 뒤나 앞으로 이동하지 않는 것이지만, 다른 방법이 없다면 **마우스 오른쪽 버튼으로 Text 요소를 클릭**한 다음 **Interactable**을 **Disabled**로 설정해 상호작용할 수 없게 만들 수 있습니다. 이렇게 하면 Text 요소가 정적이고 상호작용할 수 없는 텍스트가 되므로 더 이상 스크롤하거나 하이퍼링크를 클릭할 수 없습니다.

### 화면에서 화살표 및 Tab 키로 이동할 때 버튼과 슬라이더가 더 이상 선택되거나 포커스를 받지 않게 하려면 어떻게 하나요?

버튼과 슬라이더를 탐색할 수 없게 하려면 해당 요소를 **마우스 오른쪽 버튼으로 클릭**하고 **Navigable**을 **Disabled**로 설정하세요. 버튼이나 슬라이더는 여전히 클릭할 수 있지만, 더 이상 화살표 키나 Tab 키로 포커스를 지정할 수 없습니다.

이는 Chat 화면에 버튼이나 슬라이더를 추가할 때도 유용합니다. 화면에서 버튼이나 슬라이더를 실수로 선택하지 않고도 위쪽 화살표 키를 사용해 이전 메시지를 계속 스크롤할 수 있습니다.

### FancyMenu의 컨텍스트 메뉴 중 하나에 있어야 할 옵션이 없습니다.

FancyMenu의 컨텍스트 메뉴(어딘가를 마우스 오른쪽 버튼으로 클릭하거나 메뉴 바와 상호작용할 때 열리는 메뉴)는 스크롤할 수 있습니다. 즉, 마우스 커서를 메뉴 위에 놓고 마우스 휠을 사용해 위아래로 스크롤하면 이전에 표시되지 않던 더 많은 옵션을 볼 수 있습니다.

### Title 화면을 커스터마이즈할 수 없습니다. 편집기를 나가면 원래 화면이 계속 표시됩니다.

다른 모드가 원래 `title_screen`을 대체하고 있는 것입니다. 해당 모드의 설정에서 커스텀 Title 화면을 비활성화하세요. 그런 옵션이 없다면 FancyMenu는 대체된 화면에 레이아웃을 적용할 수 없습니다.

### 인벤토리 화면을 커스터마이즈하려고 할 때 인벤토리 컨테이너를 커스터마이즈할 수 없습니다.

이는 정상적인 동작입니다. FancyMenu는 모든 종류의 인벤토리 화면(플레이어 인벤토리, 상자, 작업대 등)의 실제 컨테이너를 편집하는 기능을 지원하지 않습니다. 이를 지원하는 것은 매우 어렵기 때문입니다.

그래도 이러한 화면에 새 요소를 추가하는 것은 가능하지만 컨테이너 자체는 편집할 수 없습니다.

참고로 SpiffyHUD도 이 문제를 해결해 주지 않습니다. SpiffyHUD는 HUD(예: 아이템 핫바)를 편집하기 위한 것이며, 화면(예: 인벤토리 화면)은 편집할 수 없습니다.
