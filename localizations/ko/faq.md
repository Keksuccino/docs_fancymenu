# 자주 묻는 질문

### 문제를 해결하는 데 도움이 필요해요. 어떤 정보를 제공해야 하나요?

최대한 도움을 받으려면 가능한 한 많은 정보를 제공해 주세요.
1.  **문제에 대한 명확한 설명:** 무엇을 예상했고, 실제로는 어떤 일이 일어났나요?
2.  **`latest.log` 파일:** `<game-directory>/logs/latest.log`에서 찾을 수 있습니다. 특별히 요청받지 않았다면 **크래시 로그는 보내지 마세요.** 보통 `latest.log`에 필요한 정보가 들어 있습니다. 로그를 게시할 때는 https://gist.github.com 같은 사이트를 이용하세요.
3.  **Minecraft 버전:** (예: 1.20.1)
4.  **모드 로더 및 버전:** (예: Forge 47.2.0, Fabric 0.15.7)
5.  **FancyMenu 버전:** (예: 3.5.2)
6.  문제를 보여 주는 **스크린샷이나 동영상**도 큰 도움이 됩니다.

> [!TIP]
> Alice나 다른 AI에게 도움을 요청하나요? 작동하지 않는 항목의 [AI용 내보내기](/export-for-ai)를 첨부하세요. 설정 상태를 AI에게 정확히 보여 주며, Minecraft, 모드 로더, FancyMenu 버전도 이미 포함되어 있습니다.

### 요소의 레이어 순서를 바꾸려면 어떻게 하나요? (다른 요소 앞이나 뒤로 이동)

- **직접 만든 요소:** 레이아웃 편집기의 Layers 위젯에서 레이어를 드래그하거나, 요소를 마우스 오른쪽 버튼으로 클릭한 다음 **한 레이어 위로 이동** 또는 **한 레이어 아래로 이동**을 클릭하세요. [레이어 및 그룹](/layout-editor#layers-and-groups)을 참고하세요.
- **직접 만든 요소와 바닐라 요소:** 바닐라 요소의 순서는 바꿀 수 없습니다. 기본 버튼 뒤에 배경 이미지를 놓는 것처럼 직접 만든 모든 요소를 바닐라 요소 뒤에 배치하려면 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **바닐라 요소 뒤에 사용자 지정 요소 표시**를 **활성화**로 설정하세요.

### 범용 버튼 템플릿에서 특정 버튼만 제외할 수 있나요?

**아니요. 템플릿 버튼에 사용자 지정 텍스처를 설정하면 영향을 받는 모든 요소가 항상 해당 텍스처를 공유합니다. 개별 버튼을 제외할 수 없습니다.**

### 버튼을 클릭했을 때 어떤 작업이 실행되도록 하려면 어떻게 하나요?

[**액션 스크립트**](/action-scripts)를 사용하세요.
1.  편집기에서 버튼을 마우스 오른쪽 버튼으로 클릭합니다.
2.  **액션 스크립트 편집**을 선택합니다.
3. **액션 추가**를 클릭하고 [**화면 또는 사용자 지정 GUI 열기**](/action-scripts#open-screen-or-custom-gui), [**서버 접속**](/action-scripts#join-server), [**변수 값 설정**](/action-scripts#set-variable-value-fm-variable) 등의 액션을 선택합니다.

### 완전히 새로운 메뉴 화면을 처음부터 만들 수 있나요?

네, [사용자 지정 GUI](/custom-guis)를 사용하면 됩니다.

1. **메뉴 바 -> 사용자 지정 -> 사용자 지정 GUI -> 사용자 지정 GUI 관리**를 열고 **새 GUI**를 클릭합니다.
2. `modpack_info`와 같은 식별자를 입력하고 **완료**를 클릭합니다.
3. **GUI 열기**를 사용해 GUI를 열고 다른 메뉴와 마찬가지로 레이아웃을 만듭니다.
4. 버튼에서 [**화면 또는 사용자 지정 GUI 열기**](/action-scripts#open-screen-or-custom-gui) 액션과 해당 식별자를 사용해 GUI를 엽니다.

### 사전 로딩을 활성화한 뒤 게임 로딩 시간이 너무 오래 걸려요.

예상된 동작입니다. 고해상도 애니메이션이나 사운드 같은 대용량 리소스를 게임 시작 시 사전 로딩하면 게임 로딩 시간이 자연스럽게 늘어납니다.

### 애니메이션이 RAM을 너무 많이 사용하거나 게임을 느리게 만들어요!

프레임 크기가 크고 프레임 속도가 높으면 메모리와 성능을 많이 사용합니다. 프레임 크기는 화면에 표시되는 크기에 맞추고, 초당 프레임 수를 줄이세요. [애니메이션](/animations#performance)을 참고하세요. 사운드가 포함된 긴 영상에는 대신 [비디오](/video)를 사용하세요.

### FancyMenu는 OptiFine과 함께 사용할 수 있나요?

아니요. OptiFine은 **호환되지 않으며** FancyMenu를 포함한 여러 모드를 손상시키는 것으로 알려져 있습니다. Sodium/Embeddium + Iris/Oculus 같은 최신 대안을 사용하는 것을 적극 권장합니다.
[OptiFine 대안](/optifine-alternatives)을 참고하세요.

### 게임이 충돌해요. 모드 충돌인지 어떻게 확인하나요?

모드 충돌을 확인하는 가장 좋은 방법은 **FancyMenu와 종속성(Konkrete, Melody)만 설치한 상태로 게임을 실행하는 것**입니다. 더 이상 충돌이 발생하지 않는다면 다른 모드를 소규모로 나누어 추가하고, 충돌이 다시 발생할 때까지 반복해 충돌을 일으키는 모드를 찾으세요.

### 다른 모드의 버튼이 사라지거나 편집하려고 하면 작동하지 않아요.

일부 모드는 FancyMenu가 감지하거나 사용자 지정할 수 없는 방식으로 위젯을 추가합니다. [바닐라/모드 요소](/vanilla-elements)를 확인하고, 목록 기반 화면이라면 [스크롤 가능한 화면 사용자 지정](/customizing-scrollable-screens)도 참고하세요. 그래도 위젯이 표시되지 않는다면 해당 위젯을 추가하는 모드에서 지원되는 화면 위젯으로 제공해야 합니다.

### FancyMenu 레이아웃을 서버에서 사용할 수 있나요?

레이아웃과 시각적 사용자 지정은 플레이어의 클라이언트에 저장되므로, 서버에서 설정되지 않은 클라이언트에 이를 강제로 적용할 수는 없습니다. 모드팩에 포함해 배포하세요. [서버 명령어](/commands), [FM 데이터](/fm-data), [서버 측 NBT 접근](/nbt-data-placeholder#server-side-placeholder), 게임 규칙, 구조물 또는 서버 리스너가 필요한 경우 서버에 FancyMenu를 설치하세요.

### 구형 Minecraft 버전용 FancyMenu v2와 v3의 차이점은 무엇인가요?

FancyMenu v3는 완전히 새로 작성되어 많은 새 기능과 더 안정적인 아키텍처, 향상된 성능을 제공합니다. v2는 구식이며 더 이상 지원되지 않고, 고급 플레이스홀더나 스크립팅 같은 여러 기능이 없습니다. 최신 Minecraft 버전(1.18.2 이상)에서는 v3를 사용하는 것을 적극 권장합니다. v2 레이아웃은 불러올 때 v3 형식으로 자동 변환할 수 있지만, 일부는 수동으로 수정해야 할 수 있습니다.

### 미리 만들어진 레이아웃과 템플릿은 어디서 찾을 수 있나요?

FancyMenu 커뮤니티는 공식 Discord 서버(“Kekscord”)의 [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) 채널에서 완성된 설정을 공유합니다. 해당 설정을 별도의 프로필로 설치하세요. [레이아웃 템플릿](/profiles#layout-templates)을 참고하세요.

### 플레이어 엔티티를 다른 요소 뒤에 표시하려면 어떻게 하나요?

일반적으로 [레이어](/layout-editor#layers-and-groups) 위젯만으로 [플레이어 엔티티 요소](/elements#player-entity)를 일반 2D 요소 뒤에 강제로 배치할 수 없습니다. 렌더러가 일반 GUI 레이어 순서를 무시할 수 있기 때문입니다. 이 제한을 고려해 레이아웃을 디자인하거나, 레이어 순서를 엄격하게 제어해야 한다면 미리 렌더링한 이미지를 사용하세요.

### 플레이어 엔티티의 다리가 하나만 보여요! 무슨 일이죠?

시각적 오류이며, 플레이어 애니메이션이나 모델을 변경하는 다른 모드와의 충돌 때문일 가능성이 높습니다. 플레이어 엔티티의 자세 설정에서 다리가 실수로 회전되거나 이동되지 않았는지 확인하세요.

### 스크립트의 액션 사이에 지연을 넣으려면 어떻게 하나요?

액션 스크립트 편집기의 스크립트 영역을 마우스 오른쪽 버튼으로 클릭하고 **EXECUTE LATER 블록 추가**를 클릭한 다음, 지연할 액션을 블록 안에 넣으세요. 해당 액션은 설정한 시간(밀리초)이 지난 뒤 한 번 실행되며, 스크립트의 나머지 부분은 바로 계속 실행됩니다. [나중에 실행](/action-scripts#execute-later)을 참고하세요.

반복해서 실행할 작업에는 [스케줄러](/schedulers)를 사용하세요.

### Create 모드의 메뉴를 사용자 지정할 수 있나요?

아니요. Create 화면은 의도적으로 사용자 지정을 비활성화했습니다. [사용자 지정이 의도적으로 비활성화된 화면](/incompatibility-list#screens-where-customization-is-intentionally-disabled)을 참고하세요.

### 배경 이미지와 버튼 텍스처에 권장되는 해상도는 무엇인가요?

배경: 표준 1920x1080(1080p) 이미지로 시작하면 대부분의 사용자 화면에 잘 맞게 조정됩니다.
버튼: 바닐라 버튼 대부분은 너비가 약 150~200픽셀, 높이가 20픽셀입니다. 일관성을 위해 사용자 지정 텍스처도 이 크기에 맞추는 것이 좋습니다.

### 플레이어가 게임 내 목표(예: 퀘스트)를 완료하면 메뉴를 자동으로 열거나 명령어를 실행할 수 있나요?

FancyMenu에는 다양한 [내장 게임 이벤트 리스너](/listeners)가 있지만, 모든 서드파티 퀘스트 시스템에 대응하는 범용 리스너는 없습니다. 퀘스트 모드에서 명령어 보상을 지원한다면 이를 사용해 [`/openguiscreen`](/commands#openguiscreen), [`/fmvariable`](/commands#fmvariable) 또는 다른 적절한 [FancyMenu 명령어](/commands)를 실행하세요.

### 버튼을 비활성화하거나 “회색으로 표시”하려면 어떻게 하나요?

[조건](/conditions)을 사용해 버튼의 활성 상태를 제어할 수 있습니다.
편집기에서 버튼을 마우스 오른쪽 버튼으로 클릭하고 **활성 상태 제어**를 선택하세요.
버튼을 활성화하기 위해 충족해야 하는 조건을 추가합니다. 버튼을 영구적으로 비활성화하려면 [**숫자인지 확인**](/conditions#is-number)을 사용해 0과 1이 같은지 확인하세요.
이제 버튼에 “비활성 배경” 텍스처가 표시되고 클릭할 수 없게 됩니다.

### 스크롤 가능한 화면에서 머리글과 바닥글(흙 텍스처 막대)을 없애려면 어떻게 하나요?

레이아웃 편집기에서 **레이아웃 속성 -> 머리글/바닥글 사용자 지정**을 엽니다. 텍스처를 투명하게 설정하세요. 일부 모드 화면에서는 이 옵션을 사용할 수 없을 수 있습니다.

### “현재 화면용” 레이아웃을 만들 수 없어요. 버튼이 회색으로 비활성화되어 있어요.

먼저 해당 화면의 사용자 지정을 켜세요. **메뉴 바 -> 사용자 지정 -> 현재 화면 사용자 지정**을 클릭해 **활성화**로 표시되도록 합니다.

### 편집기에서 화면을 열면 요소를 전혀 사용자 지정할 수 없고 화면이 비어 있어요.

**현재 화면용** 레이아웃 대신 [범용 레이아웃](/universal-layouts)을 만들었을 수 있습니다.

또는 [스크롤 가능한 화면](/customizing-scrollable-screens)일 수 있습니다. FancyMenu는 기본적으로 이러한 화면을 사용자 지정할 수 없습니다.

세 번째 가능성은 바닐라와 다른 방식으로 요소를 추가하는 모드의 화면일 수 있습니다. 이 경우 FancyMenu가 해당 요소를 사용자 지정할 수 없습니다.

### 텍스트 요소에 이상한 회색 상자가 보여요.

이것은 [텍스트 요소](/elements#text)의 스크롤 막대입니다. 텍스트가 요소 안에 다 들어가지 않을 때 표시되어 플레이어가 내용을 스크롤할 수 있게 합니다.

- 요소를 크게 만들거나 텍스트를 줄이면 스크롤 막대가 사라집니다.
- 요소를 마우스 오른쪽 버튼으로 클릭하고 **스크롤 막대**를 여세요. **표시**에서 표시 방식을 설정할 수 있습니다. **항상**, **스크롤 중에만** 또는 **안 함** 중에서 선택하세요. **안 함**으로 설정해도 마우스 휠로 스크롤할 수 있습니다.
- 같은 메뉴의 **스크롤 핸들 스타일**, **스크롤 핸들 텍스처**, **스크롤 핸들 색상 [HEX]**을 사용해 모양을 바꿀 수 있습니다.

스크롤 막대 설정 전체는 [메뉴의 텍스트](/text-in-menus#scroll-bars)를 참고하세요.

### 최신 Minecraft 변경 로그를 메뉴에 표시하려면 어떻게 하나요?

Minecraft 변경 로그를 FancyMenu와 호환되는 Markdown으로 변환해 주는 훌륭한 [GitHub 프로젝트](https://github.com/ClaytonTDM/minecraft-changelogs-markdown)가 있습니다. 이 프로젝트를 사용하면 최신 MC 변경 로그를 메뉴에 표시할 수 있습니다. 새 변경 로그를 가져오도록 매일 업데이트됩니다.

[텍스트 요소](/elements#text)에 표시하려면 **소스 모드**를 **리소스**로 설정하고 리소스 소스를 **웹**으로 설정하세요. 다음 주소를 사용합니다: `https://clay.is-a.dev/minecraft-changelogs-markdown/{"placeholder":"mcversion"}/fancymenu.md`.

### 요소를 화면 크기에 맞게 늘리는 가장 쉬운 방법은 무엇인가요?

대부분의 요소는 마우스 오른쪽 버튼을 클릭했을 때 열리는 메뉴에서 가로 및 세로로 늘리는 옵션을 제공합니다. 이 옵션을 켜면 요소가 항상 화면의 전체 너비 및/또는 높이에 맞게 늘어납니다. 가로와 세로 늘리기는 각각 따로 설정할 수 있습니다.

### 텍스트 요소 뒤나 앞에 있는 버튼을 클릭하거나 슬라이더를 조작할 수 없어요.

텍스트 요소는 기본적으로 상호작용할 수 있습니다. 스크롤 핸들을 잡거나 Markdown 하이퍼링크를 클릭할 수 있도록 하기 위한 것으로, 그 결과 마우스 클릭과 스크롤 이벤트를 소비합니다. 가장 좋은 방법은 버튼을 텍스트 요소 앞이나 뒤로 옮기지 않는 것입니다. 다른 방법이 없다면 텍스트 요소를 **마우스 오른쪽 버튼으로 클릭**하고 **상호작용 가능**을 **비활성화**로 설정하세요. 이렇게 하면 텍스트 요소가 정적인 비상호작용 텍스트가 되어 더 이상 스크롤하거나 하이퍼링크를 클릭할 수 없습니다.

### 화면에서 화살표 키나 Tab 키로 이동할 때 버튼과 슬라이더가 선택되거나 포커스되지 않게 하려면 어떻게 하나요?

버튼이나 슬라이더를 키보드로 이동할 수 없게 하려면 해당 요소를 **마우스 오른쪽 버튼으로 클릭**하고 **키보드 탐색 가능**을 **비활성화**로 설정하세요. 버튼이나 슬라이더는 계속 클릭할 수 있지만, 화살표 키나 Tab 키로 포커스를 이동할 수는 없습니다.

채팅 화면에 버튼이나 슬라이더를 추가할 때도 유용합니다. 화면의 버튼이나 슬라이더를 실수로 선택하지 않고 위쪽 화살표 키로 이전 메시지를 탐색할 수 있습니다.

### FancyMenu의 컨텍스트 메뉴에 있어야 할 옵션이 보이지 않아요.

FancyMenu의 컨텍스트 메뉴(어딘가를 마우스 오른쪽 버튼으로 클릭하거나 메뉴 바를 조작할 때 열리는 메뉴)는 **스크롤할 수 있습니다.** 마우스 커서를 메뉴 위에 둔 상태에서 스크롤 휠을 사용해 위아래로 이동하면, 이전에 보이지 않던 옵션을 더 확인할 수 있습니다.

### 타이틀 화면을 사용자 지정했는데 편집기를 나가면 원래 화면이 계속 표시돼요.

다른 모드가 원래 `title_screen`을 대체하고 있습니다. 해당 모드 설정에서 사용자 지정 타이틀 화면을 비활성화하세요. 그런 옵션이 없다면 FancyMenu는 대체된 화면에 레이아웃을 적용할 수 없습니다.

### 인벤토리 화면을 사용자 지정하려는데 인벤토리 컨테이너는 편집할 수 없어요.

예상된 동작입니다. FancyMenu는 어떤 종류의 인벤토리 화면(플레이어 인벤토리, 상자, 작업대 등)이든 실제 컨테이너를 편집하는 기능을 지원하지 않습니다. 이를 지원하기는 매우 어렵기 때문입니다.

그래도 이 화면에 새 요소를 추가할 수는 있지만 컨테이너 자체는 편집할 수 없습니다.

참고로 SpiffyHUD도 여기에는 도움이 되지 않습니다. HUD(예: 아이템 핫바)를 편집하는 모드이며 인벤토리 화면 같은 화면을 편집할 수는 없습니다.
