# 장식 오버레이

장식 오버레이는 메뉴 요소 앞에 렌더링되는 전체 화면 효과입니다.

이 효과는 직접 만들지 않고도 메뉴에 분위기나 움직임을 추가하고 싶을 때 유용합니다.

일반적인 예:

- 눈이 쌓이는 겨울 메뉴를 위해 **눈 내리기** 추가
- 웅덩이와 물방울이 있는 폭풍 분위기를 위해 **비 내리기** 추가
- 차분한 밤 분위기의 메뉴를 위해 **반딧불이** 추가
- 축제 분위기나 장식용 메뉴 테마를 위해 **전구 조명** 추가
- 계절/이벤트 메뉴를 위해 **낙엽**, **불꽃놀이**, 또는 **컨페티** 추가
- 전체 화면 웹페이지/비디오 레이어를 표시하려면 **브라우저** 오버레이 추가

# 찾는 방법

레이아웃 편집기에서 레이아웃을 연 다음, 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **장식 오버레이**를 엽니다.

# 빠른 시작

1. 레이아웃 편집기에서 레이아웃을 엽니다.
2. 배경(빈 영역)을 마우스 오른쪽 버튼으로 클릭합니다.
3. **장식 오버레이**를 엽니다.
4. 오버레이 유형을 선택합니다.
5. **오버레이 표시**를 **활성화됨**으로 설정합니다.
6. 오버레이 설정을 구성합니다.
7. 레이아웃을 저장하고 화면을 테스트합니다.

# 오버레이 유형 작동 방식

각 오버레이 유형에는 고유한 하위 메뉴와 고유한 **오버레이 표시** 토글이 있습니다.

- 원하는 유형만 활성화할 수 있습니다.
- 하나의 레이아웃에서 여러 활성화된 유형을 함께 사용할 수 있습니다.
- 설정은 오버레이 유형별로 적용됩니다(예: 색상, 강도, 속도, 밀도, 크기, 특수 동작).

> [!INFO]
> 같은 유형을 활성화한 여러 레이아웃을 사용하면 동일한 오버레이 유형의 인스턴스를 여러 개 겹쳐 사용할 수 있습니다.

# 오버레이 유형

- **눈 내리기**: 표면/버튼 위에 눈이 쌓이는 옵션이 있는 눈 내림 효과.
- **비 내리기**: 웅덩이, 물방울, 선택 가능한 천둥 번개 효과가 있는 비 효과.
- **반딧불이**: 그룹 수, 밀도, 크기, 색상을 설정할 수 있는 움직이는 반딧불이 그룹.
- **전구 조명**: 구성 가능한 전구 조합, 조명 색상, 바람/깜빡임 동작, 휴일 색상 모드.
- **낙엽**: 색상, 바람, 속도, 크기, 밀도를 설정할 수 있는 떨어지는 나뭇잎.
- **불꽃놀이**: 수량, 폭발 크기, 크기를 설정할 수 있는 자주 나타나는 불꽃놀이.
- **컨페티**: 마우스 클릭 컨페티 모드가 포함된 컨페티 비.
- **브라우저**: URL 및 미디어 설정이 있는 전체 화면 브라우저 오버레이.
- **GLSL 셰이더**: 전체 화면 사용자 지정 셰이더 오버레이(애니메이션 또는 정적 셰이더 기반 시각 효과용).

# 브라우저 오버레이: 인터랙티브 vs 패시브

브라우저 오버레이는 상호작용 가능한 브라우저로도, 수동적인 시각 레이어로도 구성할 수 있습니다.

- **마우스/키보드 처리(Process Mouse/Keyboard)** 설정은 브라우저 자체가 입력을 처리할지 여부를 제어합니다.
- **마우스/키보드 차단(Consume Mouse/Keyboard)** 설정은 뒤에 있는 메뉴로 입력이 전달되지 않도록 막을지 여부를 제어합니다.

실전 설정 예:

- 앞에 있는 상호작용 가능한 브라우저: **Process**와 **Consume**를 모두 활성화
- 시각 전용 브라우저 레이어: **Process**를 비활성화하고 **Consume**도 비활성화

> [!IMPORTANT]
> 브라우저 장식 오버레이를 사용하려면 **MCEF** 모드가 필요합니다.
