# 장식 오버레이

장식 오버레이는 눈 내리기, 반딧불이, 안개, 전구 장식처럼 화면 전체에 적용되는 애니메이션 효과입니다. 오버레이 중 상당수는 메뉴와 상호작용합니다. 버튼 위에 눈이 쌓이거나 새가 버튼에 내려앉고, 마우스 주변의 안개가 걷히기도 합니다.

<img width="800" alt="눈 내림과 전구 장식이 적용된 밤의 타이틀 화면. 버튼 위에 눈이 쌓여 있다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_hero.png?raw=true">

# 오버레이 추가하기

1. 레이아웃 편집기에서 레이아웃을 엽니다.
2. 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **장식 오버레이**를 엽니다.
3. **눈 내림**과 같은 오버레이를 엽니다.
4. **오버레이 표시**를 클릭해 켭니다.

켜진 오버레이는 목록에 ✔ 표시가 나타납니다. 레이아웃에 원하는 만큼 오버레이를 표시할 수 있습니다. 오버레이나 설정 위에 마우스를 올리면 기능을 확인할 수 있습니다.

오버레이는 레이아웃 편집기에서도 재생되지만, 실제 메뉴에서만 요소에 반응합니다. 레이아웃을 저장한 다음 메뉴를 열어 전체 효과를 확인하세요.

한 화면에 여러 레이아웃이 있고 각각 오버레이가 설정되어 있다면, 같은 오버레이라도 중복해서 모두 재생됩니다. 여기에는 [유니버설 레이아웃](/universal-layouts)도 포함됩니다.

# 모든 오버레이에 공통되는 설정

모든 오버레이에는 다음 두 가지 설정이 있습니다.

- **오버레이 표시**는 오버레이를 켜거나 끕니다.
- **레이어**는 오버레이가 그려지는 위치를 설정합니다.
  - **배경 및 전경**: 먼 부분은 요소 뒤에, 가까운 부분은 요소 앞에 그려져 입체감을 줍니다. 기본 설정입니다.
  - **배경만**: 모든 부분이 요소 뒤, 메뉴 배경 앞에 그려집니다.
  - **전경만**: 모든 부분이 요소 앞에 그려집니다.

버튼 위의 눈처럼 오버레이가 요소에 직접 표시되는 효과는 항상 요소 위에 유지됩니다.

많은 오버레이에는 다음 설정도 있습니다.

| 설정 | 기능 |
|---|---|
| **양 (%)** | 효과의 양을 25%에서 300%까지 조절합니다. 기본 양은 100%입니다. |
| **크기** | 픽셀 아트의 크기를 2배 또는 3배로 만듭니다. 각 픽셀은 선명한 정사각형으로 유지됩니다. |
| **모양** | **세밀함**은 음영과 추가 효과가 적용된 픽셀 아트를 그대로 표시합니다. **단순함**은 더 평면적이며 클래식한 모양에 가깝습니다. |

# 오버레이와 요소

많은 오버레이는 요소와 상호작용합니다. 눈, 재, 색종이 조각은 요소 위에 쌓이고, 고드름은 요소에 매달리며, 이끼는 요소 위에서 자라고, 새는 요소에 내려앉습니다.

상호작용할 요소를 선택하려면 요소를 마우스 오른쪽 버튼으로 클릭하고 **장식 오버레이의 영향을 받음**을 설정하세요.

- 버튼, 슬라이더, 체크박스, 입력 필드 및 [바닐라 요소](/vanilla-elements)는 기본적으로 켜져 있습니다.
- 타이틀 화면의 로고, 스플래시 텍스트, 브랜딩 및 저작권 표시도 포함됩니다. 이런 요소에 아무것도 내려앉지 않게 하려면 설정을 끄세요.
- 숨겨진 요소는 상호작용하지 않습니다. [스크롤 영역](/scrollable-areas)에서 잘려 보이지 않는 요소의 일부도 마찬가지입니다.

> [!TIP]
> 요소 사이에 최소 13픽셀의 간격을 두세요. 요소 위에 쌓이거나 아래에 매달리는 효과는 다음 요소까지의 간격만큼만 커질 수 있습니다.

거품, 서리, 색종이 조각처럼 클릭에 반응하는 오버레이도 있습니다. 클릭은 버튼에도 정상적으로 전달됩니다.

# 모든 장식 오버레이

FancyMenu의 모든 장식 오버레이를 테마별로 정리했습니다.

## 날씨

### 눈 내림

눈이 내려 버튼 위와 화면 아래쪽에 천천히 쌓입니다.

<img width="800" alt="밤의 타이틀 화면에 눈이 내리고 버튼과 화면 아래쪽에 눈이 쌓여 있다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_snowfall.png?raw=true">

- **눈 쌓이기**를 켜면 눈이 쌓입니다.
- **눈 색상 [HEX]**, **눈 내리는 속도**, **양 (%)**, **크기**로 눈 효과를 조절합니다.

### 비 내림

비가 내리고, 얕은 웅덩이에 물결이 일며 버튼에서 물방울이 떨어집니다.

<img width="800" alt="밤의 타이틀 화면에 비가 내리는 모습" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_rainfall.png?raw=true">

- **웅덩이**를 켜면 요소와 화면 아래쪽에 얇은 물막이 생깁니다. 빗방울이 닿으면 물결이 일어납니다.
- **물방울**을 켜면 요소에 물방울이 맺혀 떨어집니다.
- **천둥 번쩍임**을 켜면 가지처럼 뻗는 번개와 은은한 섬광이 가끔 나타납니다. **천둥 번쩍임 밝기**로 밝기를 설정합니다.
- **비 색상 [HEX]**, **양 (%)**, **크기**로 비 효과를 조절합니다.

> [!WARNING]
> **천둥 번쩍임**을 켜면 화면이 번쩍입니다. 플레이어가 점멸하는 빛에 민감할 수 있다면 이 설정을 끄세요.

### 안개

부드러운 안개층이 화면과 요소 위를 가로질러 흐르며, 지면 가까이에서 가장 짙어집니다.

<img width="800" alt="타이틀 화면 위로 흐르는 안개. 화면 아래쪽에서 가장 짙다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_fog.png?raw=true">

- **포인터 주변 안개 걷기**를 켜면 마우스 주변의 안개가 갈라집니다.

### 서리

메뉴 전체가 얼어붙습니다. 얼음이 가장자리를 따라 모서리와 요소까지 번집니다. 얼음을 클릭해 조각을 깨뜨릴 수 있습니다.

<img width="800" alt="타이틀 화면의 서리. 가장자리와 모서리, 버튼에 얼음이 끼어 있다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_frost.png?raw=true">

- **화면 가장자리**, **모서리**, **요소 위**를 켜거나 끄면 얼음의 각 부분을 표시하거나 숨길 수 있습니다. 요소의 텍스트는 가려지지 않습니다.

## 자연

### 나뭇잎

나뭇잎이 떨어지고 돌풍에 휩쓸려 움직입니다.

<img width="800" alt="타이틀 화면 위로 떨어지는 나뭇잎" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_leaves.png?raw=true">

- **모양**에서 나뭇잎의 **세밀함**과 **단순함**을 전환합니다.
- **색상**에서 **가을 색상 혼합**(따뜻한 가을 색상 5가지) 또는 **사용자 지정 범위**(**나뭇잎 시작 색상 [HEX]**과 **나뭇잎 끝 색상 [HEX]** 사이의 색상 5가지)를 선택합니다.
- **바람 불기**를 켜거나 끄면 강한 돌풍이 표시되거나 숨겨집니다. **바람 세기**로 바람의 강도를 설정합니다.
- **나뭇잎 밀도**, **나뭇잎 낙하 속도**, **나뭇잎 오버레이 크기**로 나뭇잎 효과를 조절합니다.

### 벚꽃

꽃이 핀 나뭇가지가 화면 위쪽 모서리에서 뻗어 나오고 꽃잎이 흩날립니다.

<img width="800" alt="타이틀 화면 위쪽 모서리에 가지가 뻗어 있고 버튼 위로 꽃잎이 흩날리는 벚꽃 효과" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_cherry_blossoms.png?raw=true">

- **왼쪽 가지**와 **오른쪽 가지**를 켜거나 끄면 각 가지를 표시하거나 숨길 수 있습니다.
- **모양**과 **양 (%)**으로 꽃잎 효과를 조절합니다.

### 무성한 식물

이끼, 덩굴, 풀, 꽃이 메뉴 곳곳에서 천천히 자라며 자연이 메뉴를 뒤덮습니다.

<img width="800" alt="타이틀 화면의 무성한 식물 효과. 버튼에 덩굴, 풀, 꽃, 이끼가 자라 있다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_overgrowth.png?raw=true">

- **풀**, **왼쪽 덩굴**, **오른쪽 덩굴**, **요소 위**를 켜거나 끄면 각 식물 효과를 표시하거나 숨길 수 있습니다. 요소의 텍스트는 가려지지 않습니다.
- **덩굴에 꽃 피우기**, **요소에 꽃 피우기**, **풀밭에 꽃 피우기**를 켜면 해당 위치에 꽃이 핍니다. **꽃 (%)**으로 꽃의 수를 설정합니다.

### 구름

푹신한 픽셀 구름이 요소 뒤의 하늘을 세 가지 깊이 레이어로 나뉘어 가로질러 흐릅니다. 구름에는 별도의 설정이 없습니다.

<img width="800" alt="타이틀 화면의 로고와 버튼 뒤로 흐르는 구름" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_clouds.png?raw=true">

### 햇살

화면 밖에 있는 태양에서 햇살이 부채꼴로 퍼지고, 햇빛 속에서 먼지가 춤춥니다.

<img width="800" alt="타이틀 화면 왼쪽 위에서 비치는 햇살" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_sunbeams.png?raw=true">

- **태양 방향**은 태양이 화면 어느 가장자리 뒤에 있는지 설정합니다. **태양 각도 (°)**를 조절하면 태양이 해당 가장자리를 따라 움직입니다.
- **햇빛 색상 [HEX]**과 **강도 (%)**로 빛을 조절합니다.
- **태양 광채**를 켜면 태양에서 은은한 빛이 퍼집니다.
- **먼지**를 켜면 햇살 사이로 먼지가 떠다닙니다. 마우스를 움직이면 먼지가 흩날립니다.
- **요소에 닿으면 멈춤**을 켜면 햇살이 요소 앞에서 멈추고, 요소 가장자리를 밝히며 그림자를 드리웁니다. 끄면 햇살이 요소 앞에 비칩니다.

### 거품

거품이 줄지어 흔들리며 떠오르고 요소 밑면을 따라 미끄러집니다. 클릭해서 터뜨려 보세요! 거품에는 별도의 설정이 없습니다.

<img width="800" alt="타이틀 화면 위로 떠오르는 거품" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_bubbles.png?raw=true">

## 동물

### 새

작은 새가 날아와 요소 위를 깡충깡충 돌아다니다가 마우스가 너무 가까이 오면 날아갑니다.

<img width="800" alt="타이틀 화면의 버튼 위에 앉아 있는 크기 2배, 양 50%의 새" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_birds.png?raw=true">

### 나비

알록달록한 나비가 팔랑거리며 날아다니고 요소에 앉기도 합니다. 마우스가 다가오면 피합니다.

<img width="800" alt="타이틀 화면의 버튼 주변을 팔랑거리며 날아다니는 나비" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_butterflies.png?raw=true">

### 박쥐

박쥐가 작은 무리를 지어 화면을 가로질러 날고 요소 밑에 매달려 잠듭니다. 너무 가까이 다가가면 깨어납니다!

<img width="800" alt="크기 2배의 박쥐가 타이틀 화면 위를 날고 버튼 아래에 매달려 있다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_bats.png?raw=true">

새, 나비, 박쥐에는 **양 (%)**과 **크기** 설정이 있습니다.

### 반딧불이

반딧불이가 무리를 지어 빛을 내며 돌아다니고, 일부는 요소에 내려앉습니다.

<img width="800" alt="밤의 타이틀 화면 버튼 주위에서 빛나는 크기 2배의 반딧불이" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_fireflies.png?raw=true">

- **모양**에서 반딧불이의 **세밀함**과 **단순함**을 전환합니다. **빛이 꺼졌을 때 몸통 표시**를 켜면 빛을 내지 않을 때 어두운 작은 몸통이 보입니다.
- **마우스 따라가기**를 켜면 마우스가 가까이 있을 때 반딧불이 무리가 마우스를 따라옵니다.
- **내려앉기**를 켜면 반딧불이가 가끔 요소에 내려앉습니다.
- **반딧불이 색상 [HEX]**, **무리 수**, **무리 밀도**, **무리 크기**, **반딧불이 크기**로 반딧불이 효과를 조절합니다.

### 버디

버디는 메뉴 아래쪽에 사는 작은 가상 반려동물입니다. 이리저리 걸어 다니고, 말풍선으로 필요한 것을 알리며, 함께 놀면 반응합니다. 게임을 종료해도 모든 상태를 기억합니다.

<img width="480" alt="타이틀 화면 아래쪽을 걸어 다니는 작고 분홍색인 반려동물 버디" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_buddy.png?raw=true">

#### 버디 돌보기

버디에게는 `0`에서 `100`까지의 네 가지 욕구가 있습니다.

- **배고픔**은 시간이 지나면서 줄어듭니다. 먹이를 주면 채워집니다.
- **행복**은 시간이 지나면서 줄어듭니다. 쓰다듬거나 먹이를 주거나 함께 놀면 높아집니다.
- **에너지**는 버디가 깨어 있는 동안 줄어들고, 잠자는 동안 회복됩니다.
- **즐거움**은 시간이 지나면서 줄어듭니다. 함께 놀면 높아집니다.

버디를 돌보는 방법은 다음과 같습니다.

- 버디를 마우스 왼쪽 버튼으로 클릭해 쓰다듬습니다. 이 방법으로 잠에서 깨우면 행복이 조금 줄어듭니다.
- 버디를 마우스 오른쪽 버튼으로 클릭해 상태 화면을 엽니다. **능력치** 탭에서 욕구, 레벨, 경험치를 확인할 수 있습니다. **업적** 탭에는 업적이 표시됩니다.
- 상태 화면에서 **먹이 주기**를 클릭한 다음 먹이를 버디에게 끌어다 놓습니다.
- 상태 화면에서 **놀기**를 클릭한 다음 공을 끌어다 놓고 마우스 버튼을 놓아 던집니다. 버디가 공을 쫓아가 잡습니다.
- **잠자기**를 클릭하면 버디가 쉽니다. 에너지가 매우 낮아지면 버디가 저절로 잠들기도 합니다.
- 버디는 가끔 똥을 쌉니다. 똥을 마우스 왼쪽 버튼으로 클릭해 치우세요. 똥이 세 개 이상 쌓이면 버디의 행복이 계속 줄어듭니다.

#### 레벨과 업적

버디를 돌보면 경험치를 얻습니다. 버디의 레벨은 1에서 30까지 올라갑니다. 레벨이 높을수록 배고픔, 행복, 에너지가 더 천천히 줄어들며, 30레벨에서는 감소 속도가 절반까지 느려집니다.

#### 버디가 죽는 경우

배고픔이나 행복이 실제 시간으로 10시간 동안 `0`에 머무르면 버디가 죽고 묘비가 남습니다. 묘비를 마우스 왼쪽 버튼으로 클릭하면 새 버디와 함께 다시 시작합니다. 버디가 죽지 않게 하려면 **버디가 죽을 수 있음**을 끄세요.

**버디 저장 데이터 초기화**를 사용하면 언제든 처음부터 다시 시작할 수 있습니다.

> [!WARNING]
> 버디를 초기화하면 욕구, 레벨, 경험치, 업적, 똥이 영구적으로 삭제됩니다.

#### 저장 및 사용자 지정

버디는 약 2분마다, 그리고 화면을 닫을 때마다 `<game-directory>/fancymenu_data/buddy/`에 자동 저장됩니다. 버디 오버레이마다 저장 파일이 따로 있습니다. 자세한 내용은 [데이터 저장 위치](/data-storage-locations)를 참조하세요.

- **사용자 지정 텍스처**를 사용하면 버디의 스프라이트, 아이템, 아이콘, 상태 화면, 묘비를 원하는 텍스처로 바꿀 수 있습니다.
- **능력치 조정**으로 욕구가 줄어드는 속도, 활동에 드는 비용과 활동으로 얻는 효과, 주변에 놓일 수 있는 똥의 최대 개수(**최대 똥 개수**)를 바꿀 수 있습니다.

## 밤하늘

### 오로라

빛나는 오로라가 하늘 위쪽에 걸려 요소 뒤에서 천천히 물결칩니다.

<img width="800" alt="밤의 타이틀 화면 로고 뒤에서 빛나는 오로라" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_aurora.png?raw=true">

- **가장자리 색상 [HEX]**은 아래쪽의 밝은 가장자리 색상을 설정합니다. **끝부분 색상 [HEX]**은 빛줄기가 서서히 바뀌는 색상을 설정합니다.

### 별똥별

요소 뒤로 별이 반짝이는 밤하늘이 펼쳐집니다. 몇 초마다 별똥별이 나타나고, 가끔 유성우가 쏟아집니다. 별똥별에는 별도의 설정이 없습니다.

<img width="800" alt="타이틀 화면 뒤로 별똥별이 지나가는 별이 빛나는 밤하늘" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_shooting_stars.png?raw=true">

### 하늘 등불

빛나는 종이 등불이 밤하늘로 떠오르며, 가끔 한꺼번에 여러 개가 올라갑니다. 하늘 등불에는 **양 (%)**과 **크기** 설정이 있습니다.

<img width="800" alt="밤의 타이틀 화면 위로 떠오르는 크기 2배, 양 25%의 하늘 등불" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_sky_lanterns.png?raw=true">

## 파티

### 색종이 조각

화면 아래쪽 모서리에 있는 파티용 폭죽이 몇 초마다 색종이 조각을 쏘아 올립니다. 색종이 조각은 요소 위에 쌓입니다.

<img width="800" alt="타이틀 화면 위로 떨어져 버튼에 쌓인 색종이 조각" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_confetti.png?raw=true">

- **모서리 폭죽**을 켜거나 끕니다.
- **클릭할 때 폭죽 터뜨리기**를 켜면 클릭한 위치에서 색종이 조각이 조금 터져 나옵니다.
- **색상 혼합 모드**를 켜면 무작위 색상을 사용합니다. 끄면 모든 색종이에 **색종이 색상 [HEX]**을 사용합니다.
- **바닥에 쌓이는 입자 최대 개수**로 한 번에 쌓여 있을 수 있는 색종이 조각의 수를 설정합니다.
- **양 (%)**, **크기**, **색종이 낙하 속도**로 색종이 효과를 조절합니다.

### 불꽃놀이

로켓이 날아올라 불꽃을 터뜨립니다.

<img width="800" alt="밤의 타이틀 화면 위로 터지는 불꽃놀이" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_fireworks.png?raw=true">

- **로켓 비행 표시**를 켜면 로켓이 날아오르는 모습이 표시됩니다.
- **양 (%)**, **크기**, **폭발 크기**로 불꽃놀이 효과를 조절합니다.

### 전구 장식

전구 줄이 메뉴 위로 드리워져 바람에 흔들립니다.

<img width="800" alt="밤의 타이틀 화면 위로 드리워진 전구 장식" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_string_lights.png?raw=true">

- **모양**에서 전구를 **단순함**과 **세밀함**으로 전환합니다. **소나무 장식**을 켜면 전선이 솔잎과 장식구로 바뀝니다.
- **전구 패턴**으로 전구의 점등과 깜박임 방식을 설정합니다(아래 참조).
- **전구 장식 크기**, **바람 세기**, **깜박임 속도**는 모든 전구 줄에 적용됩니다.
- **전구 줄** 메뉴에서 전구 줄을 걸 수 있는 여덟 위치를 각각 설정할 수 있습니다. **전구 줄 표시**를 켜면 해당 위치에 전구 줄이 나타납니다.

각 전구 줄에는 다음 설정이 있습니다.

- **전구 개수**로 줄에 걸 전구의 수를 설정합니다. `0`으로 설정하면 줄 길이에 맞춰 전구를 채웁니다.
- **전구 색상 [HEX]**으로 전구 색상을 설정합니다. **크리스마스 전구 모드**를 켜면 여러 가지 색상이 사용됩니다.
- **전선 색상 [HEX]**으로 전선 색상을 설정합니다. 알파 채널을 사용해 전선을 투명하게 만들거나 숨길 수 있습니다.
- **전구별 색상**과 **전구별 크기**를 사용하면 쉼표로 구분한 목록을 입력해 각 전구의 색상이나 크기를 지정할 수 있습니다. 전구 수보다 값이 적으면 목록을 처음부터 반복합니다.

```
#FF0000, #00FF00, #0000FF
```

| 전구 패턴 | 전구 동작 |
|---|---|
| **켜짐** | 모든 전구가 빛나며, 실제 전구처럼 가끔 하나가 살짝 어두워집니다. |
| **항상 밝게** | 모든 전구가 최대 밝기로 빛납니다. |
| **절반 밝기** | 모든 전구가 절반 밝기로 빛납니다. |
| **꺼짐** | 모든 전구가 꺼집니다. |
| **순환** | 반짝임, 추격, 교대, 숨쉬기 효과가 7초마다 바뀝니다. |
| **반짝임** | 전구가 무작위로 깜박입니다. |
| **추격** | 밝은 빛이 전구 줄을 따라 움직입니다. |
| **교대** | 한 칸씩 건너뛴 전구가 빛난 뒤 나머지 전구가 이어서 빛납니다. |
| **숨쉬기** | 모든 전구가 천천히 함께 밝아졌다 어두워집니다. |

## 으스스함

### 거미줄

먼지 쌓인 거미줄이 위쪽 모서리에 드리워지고, 작은 거미가 실을 타고 내려옵니다.

<img width="800" alt="타이틀 화면 위쪽 모서리의 거미줄과 실에 매달린 거미" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_cobwebs.png?raw=true">

- **왼쪽 거미줄**과 **오른쪽 거미줄**을 켜거나 끄면 거미와 함께 해당 거미줄을 표시하거나 숨길 수 있습니다.
- **거미**를 켜면 거미가 실을 타고 내려와 머물렀다가 다시 올라갑니다. 거미는 마우스를 피해 달아납니다.
- **앞쪽 테두리 연결**을 켜면 실의 끝부분을 테두리로 연결해 화면에 실이 늘어지지 않게 합니다.

### 불씨

아래쪽에서 빛나는 불씨가 올라오고, 재가 흩날리며 쌓입니다.

<img width="800" alt="밤의 타이틀 화면 아래쪽에서 올라오는 불씨와 버튼 위에 쌓인 재" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/decoration_overlay_embers.png?raw=true">

- **바닥에 재 표시**를 켜면 화면 아래쪽에 깊게 쌓인 재와 불씨, 빛나는 숯이 나타납니다.
- **요소에 재 쌓기**를 켜면 요소 위에 재가 쌓입니다.

## 사용자 지정

### 브라우저

브라우저 오버레이는 화면 전체에 웹사이트를 표시합니다.

> [!IMPORTANT]
> 브라우저 오버레이를 사용하려면 [Rinku](https://modrinth.com/mod/rinku) 모드가 필요합니다.

- **URL**에서 표시할 웹사이트를 설정합니다.
- **마우스 클릭 입력 차단**, **마우스 스크롤 입력 차단**, **키보드 입력 차단**을 켜면 브라우저 뒤에 있는 메뉴로 입력이 전달되지 않습니다.
- **마우스 클릭 입력 처리**, **마우스 스크롤 입력 처리**, **키보드 입력 처리**를 켜면 브라우저가 해당 입력에 반응합니다.
- **동영상 컨트롤 숨기기**, **동영상 반복 재생**, **브라우저 음소거**, **오디오/비디오 볼륨**으로 웹사이트의 동영상과 소리를 조절합니다.

입력 차단 및 입력 처리 설정은 기본적으로 켜져 있으므로 브라우저가 메뉴 앞에서 일반 브라우저처럼 작동합니다. 웹사이트를 배경으로만 표시하려면 해당 설정을 모두 끄세요.

웹사이트에서 FancyMenu 작업을 실행하고 플레이스홀더를 읽을 수도 있습니다. 자세한 내용은 [브라우저 JavaScript API](/browser-api)를 참조하세요.

### GLSL 셰이더

GLSL 셰이더 오버레이는 애니메이션 또는 정지 효과를 위해 화면 전체에 사용자 지정 셰이더를 그립니다. 셰이더 코드를 **셰이더 소스**에 붙여 넣으세요.

FancyMenu용 셰이더 작성 방법은 [GLSL 셰이더 API](/glsl-shader-api)를 참조하세요.
