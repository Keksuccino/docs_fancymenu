# 장식 오버레이

장식 오버레이는 메뉴 요소 앞쪽에 렌더링되는 전체 화면 효과입니다.

효과를 직접 만들지 않고도 메뉴에 분위기나 움직임을 더하고 싶을 때 유용합니다.

# 찾는 방법

레이아웃 편집기에서 레이아웃을 연 다음, 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **장식 오버레이**를 엽니다.

# 빠른 시작

1. 레이아웃 편집기에서 레이아웃을 엽니다.
2. 배경(빈 영역)을 마우스 오른쪽 버튼으로 클릭합니다.
3. **장식 오버레이**를 엽니다.
4. 오버레이 유형을 선택합니다.
5. **오버레이 표시**를 **활성화**로 설정합니다.
6. 오버레이 설정을 구성합니다.
7. 레이아웃을 저장하고 화면에서 테스트합니다.

# 오버레이 유형의 작동 방식

각 오버레이 유형에는 고유한 하위 메뉴와 고유한 **오버레이 표시** 토글이 있습니다.

- 원하는 유형만 활성화할 수 있습니다.
- 하나의 레이아웃에서 여러 활성 유형을 함께 조합할 수 있습니다.
- 설정은 오버레이 유형별로 적용됩니다(예: 색상, 강도, 속도, 밀도, 크기, 특수 동작).

> [!INFO]
> 같은 유형을 활성화한 여러 레이아웃을 사용하면 동일한 오버레이 유형을 여러 인스턴스로 겹쳐 배치할 수 있습니다.

# 오버레이 유형

- **눈 내림**: 표면/버튼 위에 눈이 쌓이는 옵션이 있는 눈 내림 효과입니다.
- **비 내림**: 웅덩이, 빗방울, 천둥 번개 효과 옵션이 있는 비 효과입니다.
- **반딧불이**: 그룹 수, 밀도, 크기, 색상을 설정할 수 있는 움직이는 반딧불이 그룹입니다.
- **줄 조명**: 구성 가능한 조명 조합, 조명 색상, 바람/깜빡임 동작, 휴일 색상 모드가 있는 조명입니다.
- **나뭇잎**: 색상, 바람, 속도, 크기, 밀도를 설정할 수 있는 떨어지는 나뭇잎입니다.
- **불꽃놀이**: 수량, 폭발 크기, 크기를 설정할 수 있는 빈번한 불꽃놀이입니다.
- **컨페티**: 마우스 클릭 컨페티 모드 옵션이 있는 컨페티 비입니다.
- **버디**: 배고픔, 행복, 에너지, 재미, 활동, 레벨업, 업적, 지속 상태를 갖춘 상호작용형 가상 반려동물입니다.
- **브라우저**: URL 및 미디어 설정이 있는 전체 화면 브라우저 오버레이입니다.
- **GLSL 셰이더**: 애니메이션 또는 정적 셰이더 기반 시각 효과를 위한 전체 화면 사용자 정의 셰이더 오버레이입니다.

# 버디 가상 반려동물

**버디** 오버레이는 단순한 시각적 캐릭터가 아니라, 다마고치 스타일의 가상 반려동물입니다. 화면 하단을 따라 움직이고, 필요 상태를 생각풍선으로 표시하며, 상호작용에 반응하고, 게임 세션 사이에도 상태를 유지합니다.

## 필요 상태와 조작

버디는 `0`에서 `100` 사이의 네 가지 값을 추적합니다.

- **배고픔**은 시간이 지남에 따라 감소하며 먹이를 통해 회복됩니다.
- **행복**은 시간이 지남에 따라 감소하며, 쓰다듬기와 놀이를 포함한 돌봄을 통해 증가합니다.
- **에너지**는 깨어 있는 동안과 활동 중에 감소하고, 잠자는 동안 재생됩니다.
- **재미**는 시간이 지남에 따라 감소하며 놀 때 증가합니다.

다음 마우스 조작과 상태 화면을 사용해 돌봐 주세요:

- **버디를 왼쪽 클릭**하여 쓰다듬습니다. 자는 중에 왼쪽 클릭하면 깨우며 작은 행복 패널티가 적용됩니다.
- **버디를 오른쪽 클릭**하여 상태 화면을 엽니다. Stats 탭에는 네 가지 필요 상태, 레벨, XP가 모두 표시되며, Achievements 탭에는 업적 진행도가 표시됩니다.
- 상태 화면에서 **Feed**를 선택한 뒤 먹이를 버디에게 드래그합니다. 먹이는 배고픔과 행복을 회복합니다.
- 상태 화면에서 **Play**를 선택한 뒤 공을 드래그했다가 놓습니다. 공은 마우스의 이동을 사용해 던지기 속도를 계산하며, 버디가 쫓아가고, 잡고, 들고, 가지고 놀 수 있습니다.
- 버튼이 사용 가능할 때 **Sleep**을 선택하면 에너지를 회복합니다. 버디는 에너지가 매우 낮아지면 자동으로 잠들기도 합니다.
- 버디는 가끔 똥을 남깁니다. **똥을 왼쪽 클릭**하여 치웁니다. 화면에 똥이 세 개 이상 남아 있으면 세 개 미만이 될 때까지 행복이 계속 낮아집니다. 최대 똥 개수는 설정할 수 있습니다.

## XP, 레벨, 업적

버디를 돌보고, 똥을 치우고, 필요 상태를 좋게 유지하고, 다른 목표를 달성하면 XP를 얻습니다. 버디는 1레벨에서 시작하며 최대 30레벨까지 올릴 수 있습니다. 레벨이 높아질수록 배고픔, 행복, 에너지 감소가 점차 줄어들고(30레벨에서 최대 50%), 여러 돌봄 및 XP 효과가 개선됩니다.

업적은 상호작용, 능력치, 레벨, 세션, 특수 목표의 진행도를 추적합니다. 오른쪽 클릭으로 상태 화면을 열어 두 진행 시스템을 모두 확인하세요.

## 사망 및 저장 초기화

기본적으로 **버디 사망 가능**이 활성화되어 있습니다. 배고픔이나 행복 중 하나가 `0`인 상태가 **실제 시간 10시간** 동안 계속되면 버디가 죽고 묘비로 대체됩니다. 시간 내에 `0` 값의 필요 상태를 다시 올리면 해당 타이머가 초기화되며, **버디 사망 가능**을 비활성화하면 두 타이머가 모두 지워집니다.

사망 후 다시 시작하려면 묘비를 왼쪽 클릭합니다. 또한 언제든지 버디 오버레이 설정의 **버디 저장 초기화**를 사용할 수 있습니다. 초기화하면 해당 오버레이 인스턴스의 반려동물 상태 저장과 별도의 레벨링/업적 저장이 모두 제거됩니다.

> [!WARNING]
> 버디 저장을 초기화하면 필요 상태, 레벨, XP, 업적, 활동 카운터, 저장된 똥 상태가 영구적으로 삭제됩니다.

## 지속 저장 및 사용자 지정

버디 상태는 약 2분마다 자동 저장되며 화면을 닫을 때도 저장됩니다. 반려동물 상태와 레벨링 상태는 `<game-directory>/fancymenu_data/buddy/` 안의 각 오버레이 인스턴스별로 별도의 JSON 파일을 사용합니다. 전체 FancyMenu 경로 참고 자료는 [데이터 저장 위치](./data-storage-locations)를 참조하세요.

오버레이 설정에서는 버디의 스프라이트 아틀라스, 상호작용 아이템, 필요 아이콘, 상태 화면 텍스처, 묘비도 교체할 수 있습니다. 고급 능력치 설정에서는 감소량, 활동 비용과 증가량, 돌봄 효과, 최대 똥 개수, 사망 활성화 여부를 제어합니다.

# 브라우저 오버레이: 상호작용형 vs 수동형

브라우저 오버레이는 상호작용형 브라우저 또는 수동형 시각 레이어로 구성할 수 있습니다.

- **마우스/키보드 처리** 설정은 브라우저 자체가 입력을 처리할지 여부를 제어합니다.
- **마우스/키보드 소비** 설정은 입력이 뒤에 있는 메뉴로 전달되는 것을 차단할지 여부를 제어합니다.

실제 설정 예시:

- 전면 상호작용형 브라우저: **처리**와 **소비**를 모두 활성화합니다.
- 시각 전용 브라우저 레이어: **처리**를 비활성화하고 **소비**도 비활성화합니다.

> [!IMPORTANT]
> 브라우저 장식 오버레이를 사용하려면 **MCEF** 모드가 필요합니다.
