# 메뉴의 텍스트

FancyMenu에서는 **텍스트** 요소를 사용해 메뉴/화면에 텍스트 내용을 추가할 수 있습니다.

이 요소는 스크롤이 가능하고, Markdown을 완전히 지원하며, 줄바꿈도 지원합니다. 그래서 복잡한 텍스트를 표시하는 데도 매우 강력하지만, 간단한 한 줄 텍스트를 보여주는 데도 아주 유용합니다.

# 텍스트 내용

텍스트 요소는 내용을 여러 방식으로 가져올 수 있습니다. 텍스트 내용의 소스를 설정할 수 있으며, 이 소스는 직접 입력한 일반 텍스트, FancyMenu의 assets 디렉터리(`&lt;game-directory&gt;/config/fancymenu/assets/`)에 있는 로컬 텍스트 파일, 웹 텍스트 파일(URL을 통해), 또는 리소스 팩을 통해 불러온 로컬 텍스트 파일일 수 있습니다.

웹 소스 유형을 텍스트 소스로 사용하는 것은, 모드팩을 업데이트하지 않아도 항상 최신 상태를 유지해야 하는 변경 내역이나 뉴스 티커 같은 것을 만들 때 특히 유용합니다.

FancyMenu는 텍스트 소스의 내용을 캐시하므로, 성능에 좋지 않게 내용을 계속 다시 가져오지 않아도 됩니다. 이 캐시는 현재 세션 동안에만 유지되므로 게임을 다시 시작하면 초기화됩니다. 또한 **메뉴 바 -> 커스터마이징 -> FancyMenu 다시 불러오기**를 통해 FancyMenu를 다시 로드해 캐시를 지울 수도 있습니다.

# 플레이스홀더

텍스트 요소는 FancyMenu의 플레이스홀더 시스템도 지원하므로, 텍스트 내용을 동적으로 만들고 메뉴, 월드, 플레이어 등의 다양한 변화에 반응하게 할 수 있습니다.

# Markdown 사용자 지정 또는 비활성화

제목 색상이나 Markdown과 관련된 다른 항목의 색상을 사용자 지정하고 싶다면, 텍스트 요소를 **마우스 오른쪽 버튼으로 클릭**한 다음 **Markdown**을 클릭하세요. 열리는 하위 컨텍스트 메뉴에서 Markdown 파서의 모양과 동작을 사용자 지정할 수 있는 다양한 옵션을 볼 수 있습니다.

긴 텍스트의 성능을 개선하기 위해 Markdown 파싱이 전혀 필요하지 않다면, 텍스트 요소를 **마우스 오른쪽 버튼으로 클릭**했을 때 열리는 **Markdown** 메뉴에서 Markdown을 완전히 비활성화할 수 있습니다.

# 줄바꿈 비활성화

줄바꿈이 필요하지 않다면, 텍스트 요소를 **마우스 오른쪽 버튼으로 클릭**해서 비활성화할 수 있습니다.

# 스크롤 비활성화 및 스크롤 손잡이 숨기기

텍스트 요소는 기본적으로 스크롤이 가능하며, 요소가 사용자가 모든 내용을 보기 위해 스크롤해야 한다고 판단하면 스크롤 바/손잡이를 표시합니다. 이는 텍스트 요소의 오른쪽과 아래쪽에 나타나는 작고 회색의 반투명한 막대(세로 및 가로 스크롤 바)입니다. 이 스크롤 손잡이는 때때로 그림자로 오해되기도 합니다.

**Scrolling**을 끄면 이 손잡이들을 비활성화할 수 있습니다. 이는 손잡이만이 아니라 스크롤 자체를 전반적으로 비활성화합니다. 스크롤은 그대로 유지하면서 손잡이만 보이지 않게 하고 싶다면, 요소를 마우스 오른쪽 버튼으로 클릭해 사용자 지정 스크롤 손잡이 텍스처를 설정할 수 있습니다. 여기에는 완전히 투명한 텍스처를 지정하면 됩니다.

# Minecraft의 Raw Component Text 형식(직렬화된 JSON 컴포넌트)

텍스트 요소는 Minecraft의 raw component 형식을 지원하지 않습니다. 이 형식은 버튼과 슬라이더 레이블에서만 지원됩니다.
