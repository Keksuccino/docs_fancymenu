# 메뉴의 텍스트

FancyMenu에서는 **텍스트** 요소를 사용해 메뉴/화면에 텍스트 콘텐츠를 추가할 수 있습니다.

이 요소는 스크롤 가능하고, Markdown을 완벽하게 지원하며, 자동 줄바꿈도 지원합니다. 덕분에 복잡한 텍스트 콘텐츠도 아주 강력하게 표시할 수 있고, 간단한 한 줄 텍스트를 보여주기에도 좋습니다.

## 텍스트 콘텐츠

텍스트 요소는 여러 가지 방법으로 콘텐츠를 가져올 수 있습니다. 텍스트 콘텐츠의 소스를 직접 지정할 수 있는데, 일반 텍스트 직접 입력, FancyMenu의 `assets` 폴더(`/config/fancymenu/assets/`)에 있는 로컬 텍스트 파일, 웹 텍스트 파일(URL 통해), 또는 리소스 팩을 통해 불러오는 로컬 텍스트 파일이 될 수 있습니다.

텍스트 소스로 웹 소스를 사용하는 것은, 모드팩을 업데이트하지 않아도 항상 최신 상태를 유지해야 하는 변경 로그나 뉴스 티커 같은 콘텐츠를 만들 때 특히 유용합니다.

FancyMenu는 텍스트 소스의 콘텐츠를 캐시한다는 점을 기억하세요. 이는 콘텐츠를 계속해서 다시 가져와야 하는 일을 방지하기 위함이며, 성능에 매우 좋지 않기 때문입니다. 이 캐시는 현재 활성 세션에만 유지되므로, 게임을 재시작하면 캐시가 지워집니다. 또한 **메뉴 바 -> 사용자 지정 -> FancyMenu 다시 불러오기**를 통해 FancyMenu를 다시 로드하면 캐시를 지울 수 있습니다.

## 플레이스홀더

텍스트 요소는 FancyMenu의 플레이스홀더 시스템도 지원하므로, 텍스트 콘텐츠를 동적으로 만들고 메뉴, 월드, 플레이어 등의 다양한 변화에 반응하게 할 수 있습니다.

## Markdown 사용자 지정 또는 비활성화

제목 색상이나 Markdown과 관련된 다른 요소를 사용자 지정하고 싶다면, 텍스트 요소를 **우클릭**한 다음 **Markdown**을 클릭하세요. 열리는 하위 컨텍스트 메뉴에서 Markdown 파서의 모양과 동작을 사용자 지정할 수 있는 다양한 옵션을 볼 수 있습니다.

긴 텍스트 콘텐츠의 성능을 개선하기 위해 Markdown 파싱이 전혀 필요하지 않다면, 텍스트 요소를 **우클릭**했을 때 열리는 **Markdown** 메뉴에서 Markdown을 완전히 비활성화할 수 있습니다.

## 자동 줄바꿈 비활성화

자동 줄바꿈이 필요하지 않다면, 텍스트 요소를 **우클릭**하여 비활성화할 수 있습니다.

## 스크롤 비활성화

텍스트 요소는 기본적으로 스크롤 가능하며, 요소가 사용자가 모든 콘텐츠를 보려면 스크롤이 필요하다고 판단하면 스크롤 바를 표시합니다. 이는 텍스트 요소의 오른쪽과 아래쪽에 있는 작은 회색 막대(세로 및 가로 스크롤 바)입니다.

요소를 **우클릭**했을 때 열리는 메뉴에서 **스크롤링**을 꺼서 이 막대들을 비활성화할 수 있습니다. 이렇게 하면 막대만이 아니라 스크롤 기능 전체가 비활성화됩니다. 대신 막대를 보이지 않게만 만들고 싶다면, 요소를 우클릭하여 사용자 지정 스크롤 바 텍스처를 설정할 수 있습니다. 그곳에 완전히 투명한 텍스처를 지정하면 됩니다.

## Minecraft의 Raw Component Text 형식(직렬화된 JSON 컴포넌트)

텍스트 요소는 Minecraft의 raw component 형식을 지원하지 않습니다. 이 형식은 버튼과 슬라이더 레이블에서만 지원됩니다.
