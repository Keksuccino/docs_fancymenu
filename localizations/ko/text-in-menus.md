# 메뉴의 텍스트

FancyMenu에는 텍스트를 표시하는 두 가지 요소가 있습니다.

- **Text**는 메뉴에 텍스트를 바로 표시합니다. 한 줄부터 변경 사항, 규칙 또는 뉴스처럼 길고 스크롤할 수 있는 페이지까지 표시할 수 있습니다.
- **Tooltip**은 고정된 위치나 마우스 옆에 텍스트 상자를 표시합니다. 예를 들어 버튼 위에 마우스를 올렸을 때 표시할 수 있습니다.

두 요소 모두 [Markdown](/text-formatting)과 [플레이스홀더](/placeholders)를 지원하며, 모양과 스타일 설정을 공유합니다.

<img width="800" alt="Text 요소 편집" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/text_editor_showcase.gif?raw=true">

> [!TIP]
> 이 페이지에서는 요소와 설정을 설명합니다. 제목, 목록, 링크, 색상 등 텍스트에 입력할 수 있는 내용은 [텍스트 서식](/text-formatting)을 참고하세요.

# 텍스트 추가

1. 레이아웃 편집기에서 레이아웃을 엽니다.
2. 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **새 요소 -> Text**를 선택합니다.
3. 새 요소를 마우스 오른쪽 버튼으로 클릭하고 **텍스트 내용**을 선택합니다.
4. 텍스트를 입력하고 **완료**를 클릭합니다.

# 텍스트 내용

## 소스 모드

요소를 마우스 오른쪽 버튼으로 클릭하고 **소스 모드**를 설정합니다.

- **직접 입력**: 텍스트 편집기에서 직접 텍스트를 입력합니다.
- **리소스**: 텍스트 파일에서 텍스트를 가져옵니다. **텍스트 소스**를 클릭해 `<game-directory>/config/fancymenu/assets/`의 로컬 파일, 웹 URL 또는 리소스 팩 파일을 선택합니다. [리소스](/resources)를 참고하세요.

웹 소스를 사용하면 모드팩을 업데이트하지 않아도 변경 사항이나 뉴스를 항상 최신 상태로 유지할 수 있습니다.

FancyMenu는 게임을 종료할 때까지 파일과 웹 소스의 텍스트를 기억합니다. 다시 불러오려면 **메뉴 바 -> 사용자 지정 -> FancyMenu 다시 불러오기**를 선택해 FancyMenu를 새로고침하세요.

## 동적 텍스트

[플레이스홀더](/placeholders)를 사용하면 `환영합니다, {"placeholder":"playername"}!`처럼 실시간 값을 텍스트에 표시할 수 있습니다. [변수](/variables)의 값도 표시할 수 있습니다. 값이 바뀌면 텍스트가 자동으로 업데이트됩니다.

## 텍스트 편집기

**텍스트 내용**을 클릭하면 텍스트 편집기가 열립니다. 오른쪽 위의 **플레이스홀더**를 클릭해 모든 플레이스홀더를 찾아보고 텍스트에 추가할 수 있습니다.

### 서식 단축키

Text 및 Tooltip 요소의 텍스트 편집기에는 자주 쓰는 서식 단축키가 있습니다. macOS에서는 `Ctrl` 대신 `Cmd`를 사용하세요.

| 단축키 | 기능 |
|---|---|
| `Ctrl + B` | 굵게 |
| `Ctrl + I` | 기울임꼴 |
| `Ctrl + U` | 밑줄 |
| `Ctrl + L` | 왼쪽 정렬 |
| `Ctrl + E` | 가운데 정렬 |
| `Ctrl + R` | 오른쪽 정렬 |

- 서식을 적용하려면 먼저 텍스트를 선택하세요. 같은 단축키를 다시 누르면 서식이 제거됩니다.
- 텍스트를 선택하지 않은 상태에서 단축키를 누르면 서식 문자가 추가되고 커서가 그 사이에 놓입니다. 바로 이어서 입력하면 됩니다.
- 정렬 단축키는 선택한 줄 또는 커서가 있는 줄에 적용됩니다. 이미 가운데나 오른쪽으로 정렬된 줄에서 `Ctrl + E` 또는 `Ctrl + R`을 누르면 왼쪽 정렬로 바뀝니다.
- 편집기에서 마우스 오른쪽 버튼을 클릭하고 **서식**을 열면 이 모든 기능을 메뉴에서 확인할 수 있습니다.

### 기타 단축키

FancyMenu의 대부분의 텍스트, 예를 들어 동작 값이나 여러 요소 설정에서 같은 텍스트 편집기가 열립니다. 아래 단축키는 모든 편집기에서 사용할 수 있습니다. macOS에서는 `Ctrl` 대신 `Cmd`를 사용하세요.

| 단축키 | 기능 |
|---|---|
| `Ctrl + C` | 선택한 텍스트 복사 |
| `Ctrl + X` | 선택한 텍스트 잘라내기 |
| `Ctrl + V` | 붙여넣기 |
| `Ctrl + A` | 전체 텍스트 선택 |
| `Ctrl + Z` | 실행 취소 |
| `Ctrl + Y` | 다시 실행 |
| `Ctrl + D` | 커서가 있는 줄 복제 |
| `Alt + Arrow Up` / `Alt + Arrow Down` | 커서가 있는 줄을 위나 아래로 이동 |
| `Shift + Arrow keys` | 텍스트 선택 |
| `Ctrl + Home` / `Ctrl + End` | 텍스트의 시작이나 끝으로 이동 |
| `Ctrl + G` | 줄로 이동: 줄 번호를 입력하고 `Enter` 누르기 |
| `Ctrl + S` | **완료**와 같은 기능 |

레이아웃 편집기 단축키는 [레이아웃 편집기](/layout-editor#shortcuts)를 참고하세요.

# 모양과 스타일

요소를 마우스 오른쪽 버튼으로 클릭하고 **Markdown**을 열어 텍스트 모양을 변경합니다.

## 모양

**모양**을 선택하면 텍스트의 모든 스타일 옵션이 한 번에 설정됩니다.

- **픽셀**: Minecraft 글꼴에 어울리는 픽셀 아트 스타일로, 따뜻한 색상과 금색 장식, 손으로 그린 표시가 특징입니다.
- **클래식**: 흰색 텍스트, 회색 상자와 선으로 구성된 FancyMenu의 기본 스타일입니다.
- **중립**: 현재 FancyMenu UI 테마 색상을 사용하는 깔끔한 스타일입니다. 색상은 요소와 함께 저장되므로 나중에 테마를 바꿔도 그대로 유지됩니다.

<img width="800" alt="세 가지 Markdown 모양" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/markdown_looks.png?raw=true">

새 요소는 픽셀 모양으로 시작합니다. 이전 레이아웃의 요소는 기존처럼 클래식 모양을 유지합니다.

> [!NOTE]
> 모양을 선택하면 직접 변경한 스타일이 모두 대체됩니다. 마음이 바뀌었나요? `Ctrl + Z`를 눌러 되돌리세요.

## 스타일 옵션

모양을 선택한 뒤에도 세부 요소별로 설정을 조정할 수 있습니다. **Markdown** 메뉴에는 **텍스트**, **제목**, **목록**, **링크**, **코드**, **인용문**, **콜아웃**, **표**, **이미지**, **구분선** 옵션이 있습니다. 각 옵션에 마우스를 올리면 기능을 확인할 수 있습니다.

**Markdown -> 텍스트**에는 텍스트 색상, 그림자, 줄 간격, 텍스트와 요소 가장자리 사이의 여백 등 기본 설정이 있습니다.

## Markdown 끄기

Markdown이 필요하지 않다면 **Markdown -> Markdown 파서**를 끄세요. 그러면 입력한 텍스트가 그대로 표시됩니다. 긴 텍스트의 경우 처리 속도도 조금 더 빨라집니다.

## 기타 텍스트 설정

요소를 마우스 오른쪽 버튼으로 클릭하면 다음 설정도 찾을 수 있습니다.

- **텍스트 배율**은 텍스트 크기를 조정합니다.
- **대소문자 모드**는 텍스트를 일반적인 형태, 모두 대문자 또는 모두 소문자로 표시합니다.
- **자동 줄 바꿈**은 요소 너비보다 긴 줄을 줄 바꿈합니다. 이 기능을 끄면 긴 줄이 계속 이어집니다.
- **HTML 줄 바꿈 제거**는 텍스트에서 HTML 줄 바꿈(`<br>`)을 제거합니다. 웹사이트에서 가져온 텍스트에 유용합니다.

# 배경

Text 요소는 텍스트 뒤에 패널을 표시할 수 있습니다. 요소를 마우스 오른쪽 버튼으로 클릭하고 **배경**을 엽니다.

- **배경 표시**는 패널을 켜거나 끕니다. 새 Text 요소에서는 기본적으로 켜져 있습니다.
- 기본 배경은 내장된 어두운 패널입니다. 직접 만든 텍스처를 사용할 수도 있습니다. [나인 슬라이싱](/nine-slicing-and-tiling)과 타일링을 사용하면 가장자리 모양을 유지할 수 있습니다.
- **여백**은 배경이 텍스트 바깥으로 얼마나 넓게 표시될지 설정합니다.
- **스크롤 막대 뒤까지 배경 표시**를 사용하면 배경이 스크롤 막대까지 덮습니다. 이 기능을 끄면 스크롤 막대가 배경 바로 옆에 표시됩니다.

Tooltip에는 별도의 **배경** 메뉴가 있으며, 여기서 텍스처와 나인 슬라이싱을 설정할 수 있습니다.

# 스크롤

Text 요소의 텍스트가 요소 안에 다 표시되지 않으면 스크롤할 수 있습니다. 마우스 휠로 스크롤하고, `Shift`를 누른 상태로 가로 스크롤하세요.

**스크롤 방향**에서는 텍스트를 **세로**, **가로** 또는 **양방향**으로 스크롤할지 설정합니다. 스크롤하지 않는 방향에서는 표시 영역을 벗어난 내용이 잘립니다.

## 스크롤 설정

요소를 마우스 오른쪽 버튼으로 클릭하고 **스크롤**을 엽니다.

| 설정 | 기능 |
|---|---|
| **플레이어 스크롤 허용** | 플레이어가 텍스트를 직접 스크롤할 수 있는지 설정합니다. 끄면 텍스트는 자동으로 스크롤되거나 동작으로 제어될 때만 이동합니다. |
| **스크롤 속도** | 마우스 휠을 한 번 움직일 때 스크롤되는 거리입니다. |
| **부드러운 스크롤** | 텍스트가 계단식으로 이동하는 대신 부드럽게 움직입니다. |
| **드래그하여 스크롤** | 터치스크린처럼 플레이어가 마우스로 텍스트를 잡아 끌 수 있습니다. |
| **키보드로 스크롤** | 마우스가 텍스트 위에 있을 때 `Page Up`과 `Page Down`으로 한 페이지씩 스크롤하고, `Home`과 `End`로 처음과 끝으로 이동합니다. |
| **맞춤** | 텍스트가 멈추는 위치를 설정합니다. 어디서든 멈추려면 (**끔**), 줄 하나가 맨 위에 오도록 하려면 (**줄에 맞춤**), 제목이 맨 위에 오도록 하려면 (**제목에 맞춤**), 한 페이지 단위로 이동하려면 (**페이지에 맞춤**)을 선택합니다. |
| **시작 위치** | 텍스트가 **처음** 또는 **끝**에서 시작할지 설정합니다. 최신 내용이 맨 아래에 추가되는 로그에는 끝에서 시작하는 설정이 유용합니다. |
| **화면을 열 때 초기화** | 화면을 열 때마다 텍스트를 처음 위치로 되돌립니다. 끄면 게임을 종료할 때까지 마지막 스크롤 위치가 유지됩니다. |

## 자동 스크롤

**자동 스크롤**을 열어 크레딧이나 뉴스 티커처럼 텍스트를 천천히 자동으로 스크롤할 수 있습니다.

- **자동 스크롤**을 켜면 기능이 활성화됩니다.
- **속도 [초당 픽셀]**에서 스크롤 속도를 설정합니다.
- **끝에서 처음으로 돌아가기**를 켜면 끝에 도달한 후 다시 맨 위에서 시작합니다.
- **마우스를 올리면 일시 정지**를 켜면 마우스가 텍스트 위에 있는 동안 스크롤이 멈춰 편하게 읽을 수 있습니다.

## 스크롤 막대

**스크롤 막대**를 열어 막대 설정을 변경합니다.

- **표시**에서 막대를 표시할 시점을 설정합니다. **항상**, **스크롤 중에만** 또는 **표시 안 함**을 선택할 수 있습니다. **표시 안 함**으로 설정해도 마우스 휠로 스크롤할 수 있습니다.
- **두께**에서 막대의 두께를 설정합니다.
- **세로 막대를 왼쪽에 표시**와 **가로 막대를 위쪽에 표시**를 사용하면 막대를 반대편으로 옮길 수 있습니다.
- **스크롤 손잡이 스타일**에서 손잡이 모양을 선택합니다. **테마 막대**는 FancyMenu UI 테마 색상을 사용하고, **픽셀 손잡이**는 픽셀 모양으로 픽셀 스타일과 잘 어울립니다.
- **스크롤 손잡이 텍스처**와 **스크롤 손잡이 색상 [HEX]**을 사용하면 손잡이 텍스처나 색상을 직접 지정할 수 있습니다.
- **스크롤 막대 배경**을 사용하면 손잡이가 움직이는 경로 뒤에 텍스처를 표시할 수 있습니다.

## 동작으로 스크롤 제어하기

FancyMenu의 다른 기능에서 스크롤을 제어하거나 현재 위치를 확인할 수도 있습니다.

- **요소 스크롤** [동작](/action-scripts)을 사용하면 Text 요소를 처음, 끝, 특정 위치, 줄 번호 또는 특정 텍스트가 포함된 첫 번째 줄로 이동할 수 있습니다.
- **요소 스크롤 위치**, **요소 스크롤 백분율**, **요소 스크롤 콘텐츠 크기** [플레이스홀더](/placeholders)는 텍스트가 얼마나 스크롤되었는지와 콘텐츠 크기를 알려줍니다.
- **요소가 끝까지 스크롤되었는가** [조건](/conditions)은 텍스트가 끝까지 스크롤되었는지 확인합니다. 예를 들어 규칙을 읽은 뒤에만 '동의' 버튼을 활성화할 수 있습니다.
- **요소 스크롤 시**, **요소가 처음까지 스크롤되었을 때**, **요소가 끝까지 스크롤되었을 때** [리스너](/listeners)는 텍스트가 스크롤되는 동안 동작을 실행합니다.

이 기능을 모두 사용하려면 Text 요소의 [요소 식별자](/element-identifiers)가 필요합니다.

# Text 요소 뒤로 클릭 전달

Text 요소는 마우스 입력에 반응하므로 링크와 스크롤 막대가 작동합니다. 하지만 클릭도 가로채기 때문에 Text 요소의 앞이나 뒤에 있는 버튼이 클릭을 받지 못할 수 있습니다.

문제가 된다면 Text 요소를 마우스 오른쪽 버튼으로 클릭하고 **상호작용 가능**을 끄세요. 그러면 텍스트를 스크롤할 수 없고 링크도 클릭할 수 없습니다.

# 툴팁

Tooltip 요소는 스크롤 기능이 없는 Text 요소와 같습니다.

- 텍스트, 모양, 스타일 설정은 Text 요소와 동일합니다.
- **마우스 따라가기**를 켜면 툴팁이 마우스를 따라 움직입니다.
- [조건](/conditions)을 사용해 툴팁을 표시할 시점을 설정할 수 있습니다. 예를 들어 [**요소에 마우스를 올렸는가**](/conditions#is-element-hovered) 조건을 사용하면 버튼 위에 마우스를 올렸을 때 툴팁을 표시할 수 있습니다.
