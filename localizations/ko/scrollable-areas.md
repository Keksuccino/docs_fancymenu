# 스크롤 영역

**스크롤 영역**은 다른 요소를 담아 플레이어가 그 안을 스크롤할 수 있게 해 줍니다. 긴 버튼 목록, 월드 또는 서버 선택기, 아이템 쇼케이스, 뉴스 패널처럼 한 화면에 다 들어가지 않는 콘텐츠를 표시하기에 좋습니다.

영역 안의 모든 요소는 영역과 함께 스크롤되고 가장자리에서 잘립니다.

<img width="800" alt="버튼을 스크롤 영역에 넣고 차례로 쌓기" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/scroll_area_showcase.gif?raw=true">

> [!NOTE]
> 레이아웃에 추가한 요소만 영역에 넣을 수 있습니다. [바닐라 요소](/vanilla-elements)는 메뉴 자체에 속하므로 넣을 수 없습니다.

# 스크롤 영역 추가하기

1. 레이아웃 편집기에서 레이아웃을 엽니다.
2. 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **새 요소 -> 스크롤 영역**을 선택합니다.
3. 요소를 영역 안으로 드래그합니다.

# 요소 넣기 및 꺼내기

- 요소를 영역 위로 드래그하면 영역 안에 넣을 수 있습니다. 요소를 받아들일 때 영역이 밝게 표시됩니다. 요소의 일부라도 영역 안에 있어야 들어갑니다.
- 여러 선택된 요소를 한 번에 드래그하려면 드래그를 시작할 때 `Ctrl`(macOS에서는 `Cmd`)을 누른 상태로 유지합니다.
- 요소를 영역 가장자리 가까이 드래그하면 영역이 스크롤되어 모든 부분에 접근할 수 있습니다. 편집기에서 마우스 휠을 사용해 스크롤할 수도 있습니다.
- 요소를 꺼내려면 영역 밖으로 드래그하거나, 요소를 마우스 오른쪽 버튼으로 클릭하고 **스크롤 영역에서 꺼내기**를 선택합니다. 요소는 화면에서 현재 위치에 그대로 남습니다.
- 영역 안에 다른 영역을 넣을 수도 있습니다.

## 레이어

[레이어 위젯](/layout-editor#scrollable-areas)에서는 영역의 요소가 해당 영역 아래에 표시됩니다. 레이어를 드래그해 영역 안팎으로 옮기거나 순서를 바꿀 수 있습니다. 영역 레이어의 접기 버튼을 누르면 목록에서 해당 요소가 숨겨집니다.

## 복사 및 삭제

- 영역을 복사하면 영역 안의 모든 요소도 함께 복사됩니다.
- 요소가 들어 있는 영역을 삭제하면 해당 요소를 어떻게 처리할지 묻습니다. **요소 삭제**를 선택하면 요소도 삭제되고, **요소 유지**를 선택하면 요소가 화면의 현재 위치에 남습니다.

# 요소 배치하기

영역을 마우스 오른쪽 버튼으로 클릭하고 **배치**를 엽니다. **모드**에서 영역이 요소를 배치하는 방식을 설정합니다.

- **앵커**: 나머지 레이아웃과 마찬가지로 요소를 직접 배치합니다. 새 영역은 이 모드로 만들어집니다.
- **스택**: 요소를 차례로 나열합니다.
- **그리드**: 같은 크기의 셀에 요소를 나열합니다.
- **흐름**: 요소를 나란히 나열하고 한 줄이 꽉 차면 다음 줄을 시작합니다.

<img width="800" alt="스택, 그리드, 흐름 모드의 스크롤 영역" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/scroll_area_modes.png?raw=true">

## 앵커 모드

영역 안의 요소에는 자체 앵커가 있으며, 앵커는 화면이 아니라 영역의 콘텐츠를 기준으로 합니다. 예를 들어 **왼쪽 위 모서리** 앵커는 콘텐츠의 왼쪽 위 모서리를 가리키고, 아래쪽 앵커는 콘텐츠 끝에 고정됩니다. 앵커 작동 방식은 [요소 위치 지정](/positioning-elements)을 참고하세요.

- **가로로 늘이기**와 **세로로 늘이기**를 사용하면 요소가 콘텐츠의 너비 또는 높이에 맞춰집니다.
- 요소는 같은 영역 안의 다른 요소에만 앵커를 지정할 수 있습니다. 요소를 영역 안팎으로 옮기면 영역 경계를 넘어 앵커로 연결되어 있던 요소는 **왼쪽 위 모서리** 앵커로 바뀌고 현재 위치에 그대로 남습니다.

### 콘텐츠 크기

앵커 모드에서는 콘텐츠 크기를 직접 정하며, 이에 따라 영역이 스크롤되는 거리도 결정됩니다.

영역을 선택하고 콘텐츠 끝에 있는 핸들을 드래그합니다. 계속 드래그해 영역 가장자리를 넘어가면 영역도 함께 스크롤됩니다.

<img width="698" alt="선택한 스크롤 영역의 콘텐츠 핸들" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/scroll_area_content_handle.png?raw=true">

영역을 마우스 오른쪽 버튼으로 클릭하고 **콘텐츠 크기**를 열어 설정할 수도 있습니다.

- **콘텐츠 너비**와 **콘텐츠 높이**에서 숫자로 크기를 지정합니다. [플레이스홀더](/placeholders)를 지원합니다. 플레이스홀더를 사용하면 핸들을 드래그할 수 없습니다.
- **콘텐츠에 맞추기**를 선택하면 마지막 요소가 끝나는 지점에서 콘텐츠가 끝납니다. 콘텐츠의 가운데나 끝에 앵커로 고정된 요소는 콘텐츠와 함께 이동하므로 계산에 포함되지 않습니다.

콘텐츠는 영역보다 작아지지 않으며, 영역이 스크롤되는 방향으로만 커집니다.

## 스택, 그리드, 흐름

- 영역이 요소를 자동으로 배치하고, 콘텐츠도 요소에 맞춰 자동으로 커집니다.
- 요소를 드래그해 순서를 바꿉니다. 이동할 위치에 선이 표시됩니다.
- 앵커 모드에서 이 모드 중 하나로 전환하면 화면에 표시되던 요소 순서가 유지됩니다. 다시 앵커 모드로 전환하면 각 요소가 기존 위치에 그대로 남습니다.
- [조건](/conditions)에 따라 숨겨진 요소는 빈 공간을 차지하지 않습니다.
- 이 모드에서는 늘이기가 작동하지 않습니다.
- 이 모드에서는 한 방향으로만 스크롤됩니다. **양방향**으로 설정된 영역은 세로로 스크롤됩니다.

세부 설정을 조정하려면 **배치**를 엽니다.

| 설정 | 기능 |
|---|---|
| **정렬** | 요소가 나열되는 방향을 기준으로 요소를 어디에 배치할지 설정합니다. **시작**, **가운데**, **끝**, **채우기** 중에서 선택할 수 있습니다. **채우기**를 선택하면 요소가 사용 가능한 공간에 맞춰 너비만큼(가로 스크롤 영역에서는 높이만큼) 늘어납니다. 흐름 모드에는 **채우기**가 없습니다. |
| **간격** | 요소 사이의 간격입니다. |
| **안쪽 여백** | 요소와 콘텐츠 가장자리 사이의 간격입니다. |
| **줄당 요소 수** | 그리드 전용 설정입니다. 한 줄에 들어갈 요소 수를 정합니다. |
| **가능한 한 많이 맞추기** | 그리드 전용 설정입니다. 고정된 개수 대신 공간이 허용하는 만큼 한 줄에 요소를 배치합니다. **최소 셀 크기**에서 배치할 개수가 결정됩니다. |

# 스크롤

플레이어는 마우스 휠로 영역을 스크롤합니다. 옆으로 스크롤하려면 `Shift`를 누른 상태로 휠을 사용합니다.

- **스크롤 방향**에서 영역이 **세로**, **가로**, **양방향** 중 어느 방향으로 스크롤할지 설정합니다. 스크롤하지 않는 방향에서는 콘텐츠 크기가 영역과 정확히 같아집니다.
- 영역 안의 텍스트 요소가 먼저 스크롤됩니다. 텍스트의 끝에 도달하면 영역이 계속 스크롤됩니다.
- 플레이어가 `Tab`으로 버튼 사이를 이동하면 영역이 선택된 버튼까지 스크롤됩니다.

**스크롤**, **자동 스크롤**, **스크롤 막대** 메뉴에는 텍스트 요소와 동일한 설정이 있습니다. 자세한 내용은 [메뉴의 텍스트](/text-in-menus#scrolling-settings)를 참고하세요. 다른 점은 다음과 같습니다.

- **맞춤**을 사용하면 콘텐츠를 **요소에 맞춤**으로 정렬해 요소가 항상 영역의 시작 부분에 오게 하거나, **페이지에 맞춤**으로 정렬할 수 있습니다.
- **드래그하여 스크롤**을 켜도 버튼과 영역의 다른 요소는 계속 작동합니다.
- 스크롤 핸들은 픽셀 핸들입니다. 직접 **스크롤 핸들 텍스처**나 **스크롤 핸들 색상 [HEX]**을 지정할 수도 있습니다.

# 배경

영역은 콘텐츠 뒤에 패널을 그립니다. 변경하려면 **배경**을 엽니다. [텍스트 요소의 배경](/text-in-menus#background)과 동일하게 작동합니다. **배경 표시**를 꺼서 배경을 숨기고, [나인 슬라이싱](/nine-slicing-and-tiling) 또는 타일링으로 원하는 텍스처를 사용하고, **안쪽 여백**으로 배경이 뻗어 나가는 범위를 조정할 수 있습니다.

# 동작으로 스크롤하기

FancyMenu의 다른 부분에서 영역을 제어하거나 상태를 확인할 수도 있습니다.

- **요소 스크롤** [동작](/action-scripts)을 사용하면 영역을 시작, 끝, 특정 위치 또는 영역 안의 요소까지 스크롤할 수 있습니다.
- **요소 스크롤 위치**, **요소 스크롤 백분율**, **요소 스크롤 콘텐츠 크기** [플레이스홀더](/placeholders)를 사용하면 영역이 얼마나 스크롤되었는지, 콘텐츠 크기가 얼마인지 확인할 수 있습니다.
- **요소가 끝까지 스크롤되었는가** [조건](/conditions)을 사용하면 영역이 끝까지 스크롤되었는지 확인할 수 있습니다.
- **요소 스크롤 중**, **요소가 시작으로 스크롤됨**, **요소가 끝으로 스크롤됨** [리스너](/listeners)는 영역이 스크롤될 때 동작을 실행합니다.

이 기능을 모두 사용하려면 영역의 [요소 식별자](/element-identifiers)가 필요합니다. 예를 들어 다음은 영역이 스크롤된 정도를 0에서 100까지 표시합니다.

```
{"placeholder":"scroll_area_scroll_percent","values":{"element_identifier":"3f2a9c1e-7b4d-4e8a-9c2f-1d5e6a7b8c9d-1763950000000","axis":"vertical"}}
```

# 알아두면 좋은 점

- 영역을 숨기면 안에 있는 모든 요소도 숨겨지며, 영역의 불투명도는 안에 있는 모든 요소에도 적용됩니다.
- 영역은 회전하거나 기울일 수 없으며, 시차 효과는 영역과 영역 안의 요소에 적용되지 않습니다.
- 영역 안의 툴팁 요소는 가장자리에서 잘립니다. 단, 마우스를 따라다니는 툴팁은 예외입니다.
