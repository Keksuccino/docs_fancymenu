# 레이아웃 템플릿

FancyMenu 또는 SpiffyHUD, Drippy Loading Screen과 같은 애드온용 디자인 템플릿을 다운로드하려면 [Kekscord Discord 서버](https://discord.gg/rhayah27GC)(Keksuccino의 모드 지원 공식 Discord 서버)의 [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) 채널을 확인하는 것이 가장 좋습니다. 이 채널에는 커뮤니티에서 제작한 완성된 FancyMenu 설정이 올라오며, 모든 설정의 다운로드 링크도 제공됩니다.

이 채널의 모든 템플릿 게시물은 동일한 형식을 따릅니다. 모든 게시물에는 프로필 파일(`.fmp`) 또는 `fancymenu` 폴더 형태의 완성된 FancyMenu 설정 다운로드 링크가 있어야 합니다.

> [!CAUTION]
> 커뮤니티 템플릿은 작업을 실행할 수 있습니다. 신뢰할 수 있는 출처에서만 가져오세요.

# 템플릿 설치

템플릿은 완성된 FancyMenu 설정이며 대부분 매우 복잡하므로, 기존 설정에 템플릿을 병합하는 것은 권장하지 않습니다. 대신 별도의 [프로필](./profiles)로 추가하세요.

- **`.fmp` 파일:** **메뉴 바 -> Customization -> Profiles**를 열고 파일을 [가져옵니다](./profiles#importing). 예를 들어 파일을 창으로 드래그하면 됩니다.
- **`fancymenu` 폴더:** [폴더를 프로필로 추가합니다](./profiles#adding-setup-folders).

그런 다음 Profiles 창에서 템플릿을 선택하고 **Load Profile**을 클릭하세요. 현재 설정은 별도의 프로필로 계속 사용할 수 있으므로 언제든지 다시 전환할 수 있습니다.

# 템플릿 편집 또는 프로젝트에 사용

채널의 대부분의 템플릿은 편집할 수 있으며, 모드팩과 같은 자신의 프로젝트에서 사용할 수도 있습니다. 하지만 **템플릿 게시물에서 해당 템플릿으로 무엇을 할 수 있는지 반드시 확인해야 합니다**!

모든 템플릿이 모든 작업을 허용하는 것은 아닙니다.
