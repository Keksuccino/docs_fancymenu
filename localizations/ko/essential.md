# Essential

최근 버전의 Essential 모드에는 FancyMenu 호환성이 추가되었습니다. 이제 Title 화면과 Pause 화면에 Essential이 추가하는 모든 요소를 완전히 사용자 지정할 수 있어야 합니다!

Essential의 UI를 자세히 사용자 지정하는 방법은 Essential 위키의 [이 위키 페이지](https://essential.gg/wiki/fancymenu)를 참고하세요!

# 사용자 지정 문제

Essential의 요소를 사용자 지정하는 동안 버그나 불편한 점이 발생한다면, 대부분은 Essential 때문에 발생한 것이며 Essential 개발자들이 그쪽에서 수정해야 합니다.

해당 버그/문제는 Essential 팀의 Discord 또는 GitHub를 통해 신고해 주세요.
