# Essential

Essential은 제목 화면과 일시 정지 화면에 추가하는 요소에 대해 FancyMenu 통합을 제공합니다.

지원되는 사용자 지정 워크플로에 대해서는 [Essential의 FancyMenu 가이드](https://essential.gg/wiki/fancymenu)를 참조하세요.

# 사용자 지정 문제

Essential은 자체 FancyMenu 통합을 제공합니다. Essential이 소유한 위젯이 누락되었거나 일반 Minecraft 위젯과 다르게 동작한다면, 현재 버전으로 문제를 재현한 뒤 해당 위젯을 소유한 프로젝트에 보고하세요.
