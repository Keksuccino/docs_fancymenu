# 요소 식별자

FancyMenu의 모든 요소에는 생성 시 자동으로 적용되는 고유한 식별자가 있습니다.

이 식별자는 말 그대로 요소를 식별하는 데 사용되며, 자리표시자, 동작, 로드 요구 사항 같은 FancyMenu의 다른 부분이 해당 요소와 통신할 수 있게 해 줍니다.

# 요소의 식별자 가져오기

다른 곳에서 필요해서 요소의 식별자를 가져와야 한다면, 편집기에서 해당 요소를 **오른쪽 클릭**한 다음 **요소 식별자 복사**를 클릭하세요. 그러면 요소의 식별자가 클립보드에 복사되어 필요한 곳에 쉽게 붙여넣을 수 있습니다.
