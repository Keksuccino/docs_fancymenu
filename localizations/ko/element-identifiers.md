# 요소 식별자

FancyMenu의 모든 요소에는 고유한 식별자가 있으며, 요소를 만들 때 자동으로 적용됩니다.

이 식별자는 요소를 구분하는 데 사용됩니다. 따라서 자리 표시자, 동작, 로드 요구 사항 등 FancyMenu의 다른 기능이 해당 요소와 상호작용할 수 있습니다.

# 요소 식별자 확인하기

요소의 식별자를 확인하려면 편집기에서 해당 요소를 마우스 오른쪽 버튼으로 클릭한 다음 **요소 ID 복사**를 클릭하세요. 식별자가 클립보드에 복사되므로 필요한 곳에 붙여넣을 수 있습니다.
