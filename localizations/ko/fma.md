# 애니메이션

AFMA/FMA 파일은 FancyMenu를 위해 만들어진 특수한 애니메이션 텍스처 파일입니다.
이 파일들은 APNG와 거의 비슷하지만, FancyMenu에 맞게 훨씬 더 최적화되어 있습니다.

# AFMA 파일

FancyMenu 3.9.0에서는 기존 FMA 파일의 후속인 **AFMA**(Advanced FancyMenu Animation)가 추가되었습니다.

AFMA 파일은 더 이상 ZIP 파일이 아닙니다. 더 나은 파일 크기, 더 적은 메모리 사용량, 더 좋은 성능을 제공하는 FancyMenu의 새로운 애니메이션 형식을 사용합니다.

새롭고 크거나 복잡한 애니메이션 텍스처에는 기존 FMA 대신 **AFMA**를 사용하세요.

AFMA 파일을 만들려면 다음과 같이 하세요:

1. FancyMenu의 메뉴 바를 엽니다.
2. **Tools -> AFMA Creator**로 이동합니다.
3. 크리에이터에서 프레임을 가져오거나 변환합니다.

> [!IMPORTANT]
> AFMA 파일은 기존 FMA 파일처럼 수동으로 압축할 수 없습니다. 반드시 **AFMA Creator**를 사용해 패키징/생성해야 합니다.

기존 FMA 파일도 여전히 지원되며 FancyMenu 3.9.0에서 최적화되었으므로, 기존 레이아웃을 즉시 변환할 필요는 없습니다.

# 기존 FMA 파일

## FMA 만들기

FMA 파일을 만드는 것은 ZIP 파일을 만드는 것만큼 쉽습니다! 사실 내부적으로는 거의 ZIP 파일과 같기 때문입니다.

### 파일 확장자

이 문서를 따라 하려면 파일 확장자가 보여야 하므로, 시작하기 전에 반드시 **파일 확장자 표시를 활성화**하세요.

Windows에서는 아무 폴더나 연 다음, 오른쪽 위에 있는 화살표를 클릭해 메뉴를 아래로 펼칩니다.

그다음 **보기** 탭으로 이동하여 **파일 확장명**을 활성화하세요.

### 준비

먼저 FMA 파일 내용용 새 폴더를 만듭니다.
이 예시에서는 폴더 이름을 `fancymenu_animation`이라고 하겠습니다.

이 폴더 안에 두 개의 폴더를 더 만듭니다. 첫 번째 폴더는 반드시 `frames`여야 하고, 두 번째 폴더는 반드시 `intro_frames`여야 합니다.

이제 같은 폴더 안에 새 TXT 파일을 만들고 이름을 `metadata.json`으로 바꾸세요.
아직 TXT 파일로 남아 있지 않은지 꼭 확인하세요. 파일 확장자를 반드시 `json`으로 바꿔야 합니다.

이제 `fancymenu_animation` 폴더가 있고, 그 안에 `frames` 폴더, `intro_frames` 폴더, 그리고 `metadata.json`이라는 JSON 파일이 있어야 합니다.

### 메타데이터 JSON

이 파일은 FancyMenu가 FMA 텍스처를 어떻게 처리해야 하는지 알려줍니다.
여기에는 프레임 시간(프레임이 얼마나 오래 보이는지)과 반복 횟수 같은 정보가 들어 있습니다.

`metadata.json` 파일을 텍스트 편집기로 여세요.

다음 텍스트를 파일에 복사하세요:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
  },
  "custom_frame_times_intro": {
  }
}
```

이것이 파일이 기본적으로 어떤 모습이어야 하는지 보여주는 템플릿입니다.
이제 원하는 대로 설정을 바꿀 수 있습니다.

#### `loop_count`

텍스처가 몇 번 반복 재생될지를 제어합니다(애니메이션을 다시 시작하는 횟수).

이 값을 `0`으로 설정하면 무한 반복됩니다. 즉, **절대 멈추지 않습니다**.

`0`보다 큰 값은 텍스처가 몇 번 재생되는지를 의미합니다. 예를 들어 값을 `1`로 설정하면 텍스처는 한 번만 재생되고 마지막 프레임에서 멈춥니다. `2`는 두 번 재생된 뒤 마지막 프레임에서 멈추며, 이런 식으로 이어집니다.

#### `frame_time`

애니메이션 텍스처의 프레임에 대한 **밀리초** 단위의 공통 프레임 시간입니다.
프레임 시간은 애니메이션이 다음 프레임으로 넘어가기 전에 현재 프레임이 얼마나 오래 표시되는지를 뜻합니다.

#### `frame_time_intro`

기본적으로 `frame_time`과 같지만, 애니메이션 텍스처의 **인트로** 프레임에 적용됩니다.
인트로 프레임은 **선택 사항**이며, 이에 대해서는 나중에 더 자세히 설명합니다.

#### `custom_frame_times`

이 항목은 **선택 사항**이며, 특정(인트로가 아닌) 프레임의 프레임 시간을 덮어쓰는 데 사용할 수 있습니다.
예를 들어 모든 프레임을 `41`밀리초 동안 표시하도록 `frame_time`을 `41`로 설정했지만, 첫 번째와 두 번째 프레임은 `5000`밀리초 동안 보이게 하고 싶다고 해봅시다.

그 경우 다음처럼 설정합니다:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
    0: 5000,
    1: 5000
  },
  "custom_frame_times_intro": {
  }
}
```

프레임 번호는 0부터 시작합니다. 즉, 애니메이션의 첫 번째 프레임은 `0`, 두 번째는 `1`, 이런 식입니다.

모든 사용자 지정 프레임 시간 항목의 끝에는 **쉼표**가 있어야 하며, **마지막 항목만** 예외입니다!

#### `custom_frame_times_intro`

이것은 `custom_frame_times`와 완전히 같지만, 이번에는 **인트로** 프레임용입니다. 인트로 프레임은 **선택 사항**이며, 이에 대해서는 나중에 더 자세히 설명합니다.

`metadata.json` 파일에 대한 설명은 여기까지입니다. 이제 저장하고 텍스트 편집기를 닫으세요.

### 프레임

> 애니메이션은 많은 메모리를 사용하고 비디오가 아니기 때문에, 애니메이션당 **최대 200프레임**, **최대 해상도 1080p**를 사용하는 것이 좋습니다. 애니메이션은 24 FPS로 전체 영상을 재생하는 용도가 아니라, 짧은 루프 애니메이션용입니다.
{.is-danger}

애니메이션 텍스처의 프레임은 `frames` 폴더에 넣습니다.

프레임은 **PNG 파일**이어야 합니다! **JPEG 및 다른 형식은 지원되지 않습니다**!

각 프레임의 이름은 반드시 프레임 번호와 파일 확장자만으로 구성되어야 합니다.
첫 번째 프레임은 `0.png`, 두 번째는 `1.png`, 세 번째는 `2.png`처럼 이름을 지정하세요.
프레임 이름이 잘못되어 있으면 텍스처가 **작동하지 않습니다**!

비디오에서 **프레임을 추출**하려면 [이 문서 페이지](/ffmpeg-frames)를 참고하세요.

### 인트로

이 기능은 **선택 사항**입니다.

FMA 파일의 **인트로** 기능은 `frames` 폴더의 실제 프레임이 재생되기 전에 일부 프레임을 **먼저** 재생하는 특별한 방식입니다. 

인트로는 **절대 반복되지 않으며**, 애니메이션이 처음 재생될 때만 한 번 실행됩니다. 이를 통해 실제 애니메이션이 루프 재생되기 전에 페이드 인 같은 효과를 넣을 수 있습니다.

인트로 프레임은 `intro_frames` 폴더에 넣으며, 일반 프레임과 동일하게 동작합니다:

프레임은 **PNG 파일**이어야 합니다! **JPEG 및 다른 형식은 지원되지 않습니다**!

각 프레임의 이름은 반드시 프레임 번호와 파일 확장자만으로 구성되어야 합니다.
첫 번째 프레임은 `0.png`, 두 번째는 `1.png`, 세 번째는 `2.png`처럼 이름을 지정하세요.
프레임 이름이 잘못되어 있으면 텍스처가 **작동하지 않습니다**!

### FMA 파일 패키징

이제 `fancymenu_animation` 폴더에 중요한 내용이 모두 들어갔으므로, FMA 파일을 패키징할 차례입니다!

FMA 파일을 패키징한다는 것은 폴더 내용을 ZIP 파일로 묶는 것을 의미합니다.
내용은 ZIP 파일의 **루트**에 있어야 하므로, ZIP 안에 추가 폴더가 하나 더 들어가 있으면 안 됩니다.

Windows에서는 `fancymenu_animation` 폴더 안의 모든 항목을 선택한 뒤, `metadata.json` 파일을 **오른쪽 클릭**하는 것이 가장 쉽습니다. 열리는 컨텍스트 메뉴에서 **보내기 -> 압축(ZIP) 폴더**를 클릭하세요.

물론 `fancymenu_animation` 부분은 원하는 이름으로 바꿀 수 있지만, 파일 확장자는 반드시 `.fma`여야 합니다!

# FancyMenu에서 AFMA 및 FMA 파일 사용하기

> [!IMPORTANT]
> AFMA/FMA 파일은 **애니메이션 텍스처**로 간주되므로, **이미지** 입력을 통해 추가합니다. 이미지를 받는 거의 모든 항목(PNG, JPEG, GIF 등)은 FMA 및 AFMA 파일도 사용할 수 있습니다.

AFMA/FMA 파일은 다른 애니메이션 텍스처/이미지 형식처럼 사용할 수 있습니다. FancyMenu는 이를 일반 이미지로 인식하므로, **이미지 요소**나 **이미지 메뉴 배경**처럼 텍스처를 지정할 수 있는 곳이면 어디서나 사용할 수 있습니다.

AFMA/FMA 파일은 반드시 `/config/fancymenu/assets/` 폴더에 있어야 합니다. FancyMenu는 `assets` 폴더에서만 텍스처와 기타 리소스를 불러올 수 있기 때문입니다.
