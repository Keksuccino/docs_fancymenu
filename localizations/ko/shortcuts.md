# 단축키 및 키 바인드

**단축키 수정 키:** 지원되는 경우 Windows/Linux에서는 `Ctrl`을, macOS에서는 `Command`를 사용하세요.

# 레이아웃 편집기

| 단축키 | 동작 |
|---|---|
| `Ctrl/Command + 왼쪽 클릭` | 여러 요소를 선택하거나 드래그 |
| `Shift + 크기 조절` | 요소의 가로세로 비율 유지 |
| 화살표 키 | 선택한 요소를 정밀하게 이동 |
| `Ctrl/Command + A` | 모든 요소 선택 |
| `Ctrl/Command + C` | 선택한 요소 복사 |
| `Ctrl/Command + V` | 복사한 요소 붙여넣기, 다른 레이아웃에도 붙여넣기 가능 |
| `Ctrl/Command + S` | 레이아웃 저장 |
| `Ctrl/Command + Z` | 실행 취소 |
| `Ctrl/Command + Y` | 다시 실행 |
| `Ctrl/Command + G` | 그리드 토글 |
| `O` | **Window -> Anchor Overlay Visibility**가 **Show On Key Press**로 설정되어 있을 때, 누르고 있는 동안 앵커 포인트 표시 |
| `Delete` | 선택한 요소 삭제 |

# 텍스트 편집기

| 단축키 | 동작 |
|---|---|
| `Ctrl/Command + C` | 선택한 텍스트 복사 |
| `Ctrl/Command + V` | 텍스트 붙여넣기 |
| `Ctrl/Command + Z` | 실행 취소 |
| `Ctrl/Command + Y` | 다시 실행 |
| `Ctrl/Command + A` | 모든 텍스트 선택 |
| `Ctrl/Command + D` | 현재 줄 복제 |
| `Ctrl/Command + U` | 선택한 텍스트 잘라내기 |
| `Alt + 위/아래 화살표` | 현재 줄 이동 |
| `Ctrl/Command + Home/End` | 텍스트의 시작 또는 끝으로 이동 |
| `Ctrl/Command + G` | **Go To Line** 열기 |
| `Ctrl/Command + S` | 편집기 확정 |
| `Shift + 화살표 키` | 텍스트 선택 범위 확장 |
| 화살표 키 | 커서 이동 |

# 전역 메뉴 단축키

이 단축키들은 정확히 `Ctrl + Alt` 조합을 사용합니다:

| 단축키 | 동작 |
|---|---|
| `Ctrl + Alt + L` | 마지막으로 편집한 레이아웃으로 레이아웃 편집기 열기 |
| `Ctrl + Alt + C` | FancyMenu의 메뉴 바 토글 |
| `Ctrl + Alt + R` | FancyMenu와 관리 중인 리소스/캐시 다시 불러오기 |
| `Ctrl + Alt + D` | FancyMenu의 디버그 오버레이 토글 |

# 편집 창

FancyMenu 편집 창은 화살표 키와 `Enter`로 키보드 탐색을 지원합니다. 또한 많은 창에서 **완료**에는 `Ctrl/Command + S`, **취소**에는 `Escape`를 사용합니다.

Action Script, Requirements, Variables 편집기에서는 우클릭 컨텍스트 메뉴, 검색, 실행 취소/다시 실행, 키보드 목록 탐색도 지원합니다.
