# 단축키 및 키바인드

FancyMenu에는 **레이아웃 편집기**와 모드의 다른 부분을 더 쉽고 효율적으로 사용할 수 있게 해주는 유용한 단축키가 많이 있습니다.

# 레이아웃 편집기

<br>

## CTRL + 왼쪽 클릭

**CTRL**을 누른 상태로 요소를 **왼쪽 클릭**하면 여러 요소를 선택할 수 있습니다.
또한 **CTRL**을 누른 상태로 마우스로 **여러 요소를 드래그/이동**할 수도 있습니다.

## SHIFT + 요소 크기 조절

요소의 크기를 조절하는 동안 SHIFT를 누르고 있으면 가로세로 비율이 유지됩니다.

## 화살표 키

화살표 키를 사용해 선택한 요소를 최대한 정밀하게 **이동**할 수 있습니다.

## CTRL + A

모든 요소를 한 번에 선택합니다.

## CTRL + C

선택한 모든 요소를 클립보드에 **복사**합니다.

## CTRL + V

현재 클립보드에 있는 모든 요소를 **붙여넣기**합니다.
이 기능은 한 레이아웃에서 다른 레이아웃으로도 사용할 수 있어, 레이아웃 A의 요소를 복사해 레이아웃 B에 붙여넣을 수 있습니다.

## CTRL + S

레이아웃을 빠르게 **저장**합니다.

## CTRL + ALT + L

마지막으로 편집한 레이아웃으로 레이아웃 편집기를 빠르게 엽니다.

## CTRL + Z

마지막 작업을 **실행 취소**합니다.

## CTRL + Y

이전에 실행 취소한 작업을 **다시 실행**합니다.

## CTRL + G

**그리드** 표시를 빠르게 켜거나 끕니다.

## O

**O**를 누르고 있으면 **Window -> Anchor Overlay Visibility**에서 표시가 **Show On Key Press**로 설정된 경우 앵커 포인트 오버레이가 표시됩니다.

## DEL

선택한 모든 요소를 **삭제**합니다.

# 텍스트 편집기

<br>

## CTRL + C

선택한 텍스트를 클립보드에 **복사**합니다.

## CTRL + V

현재 클립보드에 있는 텍스트를 **붙여넣기**합니다.

## CTRL + Z

마지막 작업을 **실행 취소**합니다.

## CTRL + Y

이전에 실행 취소한 작업을 **다시 실행**합니다.

## CTRL + A

전체 텍스트를 **선택**합니다.

## CTRL + D

현재 줄을 **복제**합니다.

## CTRL + U

선택한 텍스트를 **잘라내기**합니다.

## ALT + 위쪽 화살표 / 아래쪽 화살표

현재 줄을 위 또는 아래로 이동합니다.

## CTRL + Home / CTRL + End

커서를 텍스트의 시작 또는 끝으로 이동합니다.

## CTRL + G

**Go To Line** 입력창을 엽니다.

## CTRL + S

편집기를 확정합니다. **Done**을 클릭한 것과 같습니다.

## SHIFT + 화살표 키

커서를 이동하면서 텍스트를 선택/강조합니다.

## 화살표 키

화살표 키를 사용해 텍스트 내에서 커서를 이동할 수 있습니다.

# 메뉴에서

<br>

## CTRL + ALT + C

메뉴 상단에 있는 FancyMenu의 **메뉴 바** 표시를 켜거나 끕니다.

## CTRL + ALT + R

FancyMenu를 **다시 불러오기**합니다.
이 작업에는 전체 리소스/에셋 재불러오기가 포함되며 대부분의 캐시가 지워집니다.

## CTRL + ALT + D

FancyMenu의 **디버그 오버레이** 표시를 켜거나 끕니다.

# 편집 창

FancyMenu v3.9.0의 많은 편집 창은 **화살표 키**와 **Enter**를 사용한 키보드 탐색을 지원합니다. 또한 많은 창에서 **CTRL + S**를 **Done**의 단축키로, **ESC**를 **Cancel**로 사용합니다.

개편된 Action Script Editor, Manage Requirements, Manage Variables 창은 목록에 대해 마우스 오른쪽 버튼 컨텍스트 메뉴, 검색, 실행 취소/다시 실행, 키보드 탐색도 지원합니다.
