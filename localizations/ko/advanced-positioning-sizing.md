# 고급 위치 지정 및 크기 조정

고급 위치 지정/크기 조정은 **요소의 위치와 크기를 완전히 제어**할 수 있게 해줍니다. 이는 매우 강력하지만, FancyMenu의 자동 크기 조정 및 위치 지정 기능을 사용하는 것보다 **훨씬 더 시간이 많이 듭니다**.

> 요소가 Minecraft의 **GUI 배율**에 맞춰 더 잘 스케일되기만 원한다면, 대신 레이아웃 전체의 **자동 스케일링**을 사용하는 것을 권장합니다. 이는 편집기 배경을 우클릭했을 때 열리는 메뉴에서 먼저 GUI 배율을 강제로 지정한 다음, 같은 메뉴에서 **자동 스케일링**을 활성화하면 됩니다.
{.is-warning}


# 고급 위치 지정/크기 조정 모드 전환

요소에 대해 고급 위치 지정/크기 조정을 **활성화**하려면, 해당 요소를 **우클릭**한 뒤 **고급 위치 지정** 또는 **고급 크기 조정**을 클릭하세요.
고급 위치 또는 크기 값을 설정하면 요소는 자동으로 고급 모드로 전환됩니다.

이를 **비활성화**하고 일반 위치 지정/크기 조정으로 되돌리려면, **모든 위치 지정/크기 조정 값을 지우면** 됩니다.

> 요소가 고급 크기 조정/위치 지정 모드에 있는 동안에는 요소의 크기 조절 및/또는 이동이 비활성화되거나 제한될 수 있습니다.
{.is-warning}

# 위치/크기 계산하기

고급 위치 지정/크기 조정이 매우 강력한 이유는 위치/크기 값에 **플레이스홀더**를 사용할 수 있기 때문입니다.

이를 통해 **고급** 플레이스홀더 카테고리에 있는 **계산기** 플레이스홀더를 **GUI** 카테고리의 플레이스홀더들, 예를 들어 **화면 너비**, **GUI 배율**, **요소 너비** 등과 함께 사용할 수 있습니다.

> 텍스트 편집기 오른쪽 위에 있는 **플레이스홀더** 버튼을 클릭해 플레이스홀더를 추가할 수 있습니다. 이 버튼이 보이지 않는다면, 편집하려는 콘텐츠는 플레이스홀더를 **지원하지 않습니다**.
{.is-info}

**계산기** 플레이스홀더로 값을 계산하려면 예시 식을 원하는 식으로 바꾸면 됩니다. 식 안에 중첩된 플레이스홀더를 사용할 수 있으므로, 화면 크기나 요소 크기 등의 플레이스홀더를 활용할 수 있습니다.

예를 들어, 다음 플레이스홀더는 `1 + 1`을 계산하여 나중에 `2`로 표시합니다:

`{"placeholder":"calc","values":{"expression":"1 + 1","decimal":"false"}}`

`decimal` 변수는 `false`로 설정되어 있는데, 이는 대부분의 크기/위치 계산에서 중요하므로, 고급 위치 지정/크기 조정을 사용할 때는 항상 `false`로 설정하세요.

다음 계산기는 **화면 너비** 플레이스홀더를 사용해 그 값을 `2`로 나눕니다:

`{"placeholder":"calc","values":{"expression":"{"placeholder":"guiwidth"} / 2","decimal":"false"}}`
