# 월드 생성 화면

이미 월드 생성 화면(일명 Create World, New World, New Game)을 사용자 지정해 보셨다면, 아마 이것이 얼마나 _골치 아픈지_ 깨달았을 것입니다. 이 화면은 꽤 복잡하고, 버튼과 다른 GUI 요소들이 겹쳐 쌓이는 방식으로 만들어져 있어 FancyMenu가 제대로 사용자 지정하기 매우 어렵기 때문입니다.

더 최신 버전의 Minecraft에서는 새로운 탭 시스템 때문에 사용자 지정 가능성이 더 나빠졌습니다.

이 모든 이유로 인해, 이 화면을 사용자 지정하는 것은 **권장되지 않습니다**. 적어도 기존 GUI 요소(예: 바닐라 버튼 등)를 수정하거나 새로운 사용자 지정 요소를 추가하는 것처럼 복잡한 사용자 지정은 권장하지 않습니다. 사용자 지정 배경을 설정하는 정도는 괜찮을 수 있지만, 그 이상은 점점 복잡해지므로 가급적 많이 사용자 지정하지 않는 것이 좋습니다.
