# 게임 인트로

게임 인트로는 Minecraft 로딩 화면이 끝난 직후, 게임이 시작될 때 애니메이션이나 동영상을 재생합니다. 재생이 끝나면 타이틀 화면으로 페이드됩니다. 모드팩에 어울리도록 로고, 스튜디오 인트로 또는 짧은 예고편을 재생할 수 있습니다.

<img width="800" alt="Skyhaven 인트로: 떠 있는 섬 위로 밤이 새벽으로 바뀌고, 로고가 한 글자씩 나타난 뒤 타이틀 화면으로 페이드됩니다. 타이틀 화면의 배경에도 같은 섬이 표시됩니다." src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/game_intro_showcase.gif?raw=true">

플레이어는 아무 키나 누르거나 클릭해서 인트로를 건너뛸 수 있습니다. 게임 인트로는 [전역 사용자 지정](/global-customizations) 중 하나이므로 레이아웃이 필요하지 않습니다.

# 인트로 설정하기

<img width="800" alt="메뉴 바에서 전역 사용자 지정과 게임 인트로를 열고, Set Game Intro에서 skyhaven_intro.apng를 선택한 다음 Re-Trigger Game Intro로 재생하고 Space 키로 건너뛰는 모습" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/game_intro_setup.gif?raw=true">

1. 애니메이션이나 동영상을 `<game-directory>/config/fancymenu/assets/`에 넣습니다.
2. **메뉴 바 -> 사용자 지정 -> 전역 사용자 지정 -> 게임 인트로**를 엽니다.
3. **게임 인트로 설정**을 클릭합니다. **소스 유형**이 **로컬**로 설정되어 있는지 확인한 뒤, **로컬 리소스 파일 선택**을 클릭하고 파일을 선택한 다음 **확인**을 클릭합니다.
4. **게임 인트로 다시 실행**을 클릭하면 바로 확인할 수 있습니다.

인트로를 제거하려면 마우스를 **게임 인트로 설정**에 올리고 **기본값으로 재설정**을 클릭합니다.

## 애니메이션 및 동영상

- **애니메이션:** APNG 또는 GIF 파일입니다. 만드는 방법은 [애니메이션](/animations)을 참조하세요.
- **동영상:** MP4 파일입니다. Watermedia V3 및 Watermedia Binaries V3 모드가 필요합니다. 자세한 내용은 [동영상](/video#requirements)을 참조하세요. 이 모드가 없으면 동영상 인트로에는 다운로드 링크가 포함된 빨간색 안내 문구가 몇 초 동안만 표시됩니다.
- 인스턴스 파일과 리소스 팩 파일은 사용할 수 있지만, 웹 링크는 사용할 수 없습니다. [리소스](/resources)를 참조하세요.

인트로는 화면 전체를 채우면서 원래 비율을 유지하므로, 화면 비율이 다르면 일부가 잘립니다. 대부분의 화면은 16:9이므로 인트로도 1920x1080과 같은 16:9 비율로 만드세요. 투명한 부분은 검은색으로 표시됩니다.

> [!TIP]
> 플레이어는 게임을 시작할 때마다 인트로를 보게 되므로, 약 5~10초 정도로 짧게 만드세요.

## 무료 예시 인트로

이 페이지의 GIF에 나오는 Skyhaven 인트로는 테스트와 모드팩에서 무료로 사용할 수 있습니다.

- [skyhaven_intro.apng](https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/skyhaven_intro.apng?raw=true): 인트로 파일입니다. 해상도는 1280x720이고 길이는 5.4초이며, 한 번 재생됩니다.
- [skyhaven_menu.png](https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/skyhaven_menu.png?raw=true): 로고가 없는 마지막 장면입니다. 해상도는 1280x720입니다. 타이틀 화면 레이아웃의 [이미지 배경](/menu-backgrounds#image)으로 지정하면 첫 번째 GIF처럼 인트로에서 어울리는 메뉴 화면으로 페이드됩니다.

# 설정

모든 설정은 **메뉴 바 -> 사용자 지정 -> 전역 사용자 지정 -> 게임 인트로**에서 찾을 수 있습니다.

| 설정 | 기능 |
|---|---|
| **게임 인트로 설정** | 재생할 애니메이션이나 동영상입니다. |
| **게임 인트로 건너뛰기** | 아무 키나 클릭으로 인트로를 건너뛸 수 있으며, 화면 하단에 **아무 키나 눌러 건너뛰기**가 표시됩니다. 건너뛰면 페이드 없이 인트로가 즉시 종료됩니다. 끄면 인트로가 끝까지 재생됩니다. |
| **게임 인트로 페이드 아웃** | 인트로가 끝날 때 타이틀 화면으로 페이드합니다. 끄면 타이틀 화면이 즉시 나타납니다. |
| **게임 인트로 반복 무시** | 애니메이션이 반복 재생되도록 설정되어 있어도 한 번 재생한 뒤 인트로를 종료합니다. 끄면 애니메이션이 반복되는 횟수만큼 모두 재생됩니다. 동영상은 항상 한 번만 재생됩니다. |
| **사용자 지정 건너뛰기 문구** | **아무 키나 눌러 건너뛰기** 문구를 `아무 키나 눌러 모험을 시작하세요`와 같은 문구로 바꿉니다. 리소스 팩의 `skyhaven.intro.skip`과 같은 현지화 키를 사용하면 플레이어의 언어로 문구가 표시됩니다. |
| **게임 인트로 볼륨** | 동영상 인트로의 음량을 0%에서 100%까지 설정합니다. |
| **게임 인트로 사운드 채널** | 동영상 인트로의 사운드 채널을 설정합니다(예: 음악). 이 채널의 음량과 Minecraft 사운드 설정의 마스터 음량이 추가로 적용됩니다. |
| **게임 인트로 다시 실행** | 현재 화면 위에서 인트로를 즉시 재생합니다. |

**게임 인트로 건너뛰기**, **게임 인트로 페이드 아웃**, **게임 인트로 반복 무시**는 기본적으로 켜져 있습니다.

> [!WARNING]
> **게임 인트로 건너뛰기**와 **게임 인트로 반복 무시**를 모두 끄면 무한 반복 애니메이션이 끝나지 않아 플레이어가 타이틀 화면으로 이동할 수 없습니다.

# 알아두면 좋은 점

- 인트로는 게임을 시작할 때마다 한 번 재생되며, 로딩 화면 다음에 표시되는 첫 화면보다 먼저 재생됩니다. 일반적으로 첫 화면은 타이틀 화면입니다.
- 인트로 앞에 표시되는 Minecraft 로딩 화면을 변경하려면 [로딩 화면](/loading-screen)을 참조하세요.
- 인트로 소스에는 [자리표시자](/resources#placeholders-in-resource-sources)가 포함될 수 있습니다.
- 게임 인트로 설정은 FancyMenu의 `options.txt`에 저장되므로 현재 로드된 [프로필](/profiles)에 속합니다. `config/fancymenu/`를 포함하는 모드팩에는 `assets/`에 있는 인트로 파일과 함께 해당 설정도 포함됩니다. [모드팩](/modpacks)을 참조하세요.
