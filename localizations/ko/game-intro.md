# 게임 인트로

게임을 시작할 때 나오는 멋진 작은 영상들, 알고 계시나요?
FancyMenu를 사용하면 Minecraft에서 이것을 구현할 수 있습니다!

# 인트로로 APNG, GIF 및 비디오 사용하기

FancyMenu는 애니메이션 텍스처를 지원하며, FancyMenu 3.9.0부터는 게임 인트로 콘텐츠로 비디오도 지원합니다.

FancyMenu 3.9.0+에서 인트로 콘텐츠를 설정하려면 FancyMenu의 **메뉴 바**에서 **Customization -> Global Customizations**로 이동한 다음, 그곳에서 **Game Intro**를 설정하세요.

비디오 인트로는 볼륨 및 사운드 채널 설정을 포함한 사운드를 지원합니다. 기본 비디오 지원에는 **Watermedia V3**와 **Watermedia Binaries V3**가 필요합니다.
