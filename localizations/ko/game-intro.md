# 게임 인트로

게임 인트로는 타이틀 화면이 처음 나타나기 전에 애니메이션 이미지나 동영상을 재생합니다.

# 설정

**사용자 지정 -> 전역 사용자 지정**을 통해 [**전역 사용자 지정**](./global-customizations)을 연 다음, 다음 설정을 구성하세요:

| 설정 | 동작 |
|---|---|
| 게임 인트로 설정 | 로컬, 웹, 또는 Minecraft 리소스의 애니메이션 이미지나 동영상을 선택합니다 |
| 게임 인트로 건너뛰기 | 아무 키나 마우스 클릭으로 인트로를 건너뛸 수 있게 합니다 |
| 게임 인트로 페이드아웃 | 인트로를 대상 화면으로 페이드 전환합니다 |
| 사용자 지정 건너뛰기 텍스트 | 기본 건너뛰기 안내를 일반 텍스트 또는 지역화 키로 바꿉니다 |
| 게임 인트로 볼륨 | 기본 볼륨을 `0.0`에서 `1.0` 사이로 설정합니다 |
| 게임 인트로 사운드 채널 | Minecraft 사운드 카테고리를 선택합니다 |
| 게임 인트로 다시 트리거 | 설정한 인트로를 다시 재생해 테스트합니다 |

동영상 인트로를 사용하려면 **Watermedia V3**, **Watermedia Binaries V3**, 그리고 OpenGL 렌더러가 필요합니다. Vulkan에서는 Watermedia 동영상 재생을 사용할 수 없습니다. 재생할 수 없을 때는 FancyMenu가 인트로 화면 위에 설명을 표시합니다. [동영상](./video#requirements)을 참조하세요.
