# 로딩 화면 사용자 지정

**FancyMenu만으로는 Minecraft의 로딩/스플래시 화면을 사용자 지정할 수 없습니다**. 그래서 [Drippy Loading Screen](https://www.curseforge.com/minecraft/mc-mods/drippy-loading-screen) 애드온이 있습니다(Modrinth에서도 [여기](https://modrinth.com/mod/drippy-loading-screen)에서 확인할 수 있습니다).

> [!IMPORTANT]
>Drippy Loading Screen 사용 방법은 해당 [위키](https://github.com/Keksuccino/Drippy-Loading-Screen/wiki)를 참고하세요.
