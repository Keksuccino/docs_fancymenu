# 월드 로딩 화면

월드에 로드되거나 서버에 접속할 때, 자동으로 닫히기 때문에 실제로는 마음대로 커스터마이즈할 수 없는 화면이 표시되는 것을 아마 보셨을 겁니다.

이 화면들을 편집하려면, 원하는 만큼 계속 열려 있는 인스턴스를 열어야 합니다. 이는 해당 화면의 "더미 화면 인스턴스"를 열면 가능합니다.

"더미 화면 인스턴스"는 FancyMenu의 기능으로, 너무 빨리 사라져서 커스터마이즈하기 어려운 일부 화면을 열 수 있게 해줍니다.

더미 화면 인스턴스 기능으로 열 수 있는 모든 화면을 보려면 **메뉴 바 -> 도구 -> 더미 화면 인스턴스**를 클릭하세요. 열리는 메뉴에는 더미 화면 인스턴스로 열 수 있는 모든 화면이 표시됩니다. 메뉴에서 화면을 **왼쪽 클릭**하면 해당 화면의 더미 인스턴스가 열리며, 이를 통해 마음 편히 커스터마이즈할 수 있습니다.

예를 들어, 월드나 서버에 접속할 때 로딩 중에 최소한 다음 두 화면이 표시됩니다:

- 레벨 로딩 화면(= 월드 로딩 화면)
- 일반 흙 메시지 화면(= 흙 메시지 화면)

> **중요:** "월드 로딩 화면"은 "게임 로딩 화면"(= 스플래시 화면 또는 리소스 재로딩 화면)과 같은 것이 아닙니다. "게임 로딩 화면"은 FancyMenu의 애드온인 **Drippy Loading Screen**으로 커스터마이즈할 수 있습니다.
