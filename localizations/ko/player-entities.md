# 플레이어 엔티티

FancyMenu를 사용하면 화면에 플레이어 엔티티를 추가할 수 있어, 클라이언트 플레이어나 다른 플레이어를 표시할 수 있습니다. 또한 실제 플레이어를 나타내지 않는 커스텀 엔티티도 커스텀 스킨, 이름, 망토 등을 사용해 표시할 수 있습니다.

# 클라이언트 플레이어

클라이언트 플레이어의 "거울상"을 표시하려면 Player Entity 요소를 우클릭한 뒤 **Copy Client Player**를 활성화하면 됩니다. 그러면 클라이언트 플레이어의 스킨, 망토, 이름이 복사됩니다.

# 다른 플레이어

다른 기존 플레이어를 표시하고 싶다면, 요소를 우클릭한 뒤 **Player Name**을 실제 존재하는 플레이어 이름으로 설정하세요. 이렇게 하면 커스텀 스킨이나 망토를 설정하지 않았고 **Copy Client Player**가 **비활성화**되어 있는 한, 해당 플레이어의 스킨, 망토, 이름이 자동으로 표시됩니다.

# 커스텀 플레이어 엔티티

실제 플레이어를 표시하고 싶지 않고 엔티티의 스킨, 망토, 이름을 완전히 직접 설정하고 싶다면, 요소를 우클릭하세요. 여기서 커스텀 스킨과 망토 텍스처를 설정할 수 있습니다. 커스텀 스킨과 망토가 활성화되어 있으면, 플레이어가 실제로 존재하더라도 해당 플레이어 이름의 스킨을 복사하지 않고 원하는 플레이어 이름을 얼마든지 설정할 수 있습니다.

# 엔티티 포즈

Player Entity 요소는 포즈 커스터마이징을 완벽하게 지원하므로, 다시 말해 팔다리, 몸통 등 모든 신체 부위를 자유롭게 움직일 수 있습니다.

이렇게 하려면 요소를 우클릭한 뒤 **Player Pose**를 클릭하세요. 그러면 모든 신체 부위의 X/Y/Z 회전을 설정할 수 있는 슬라이더가 있는 화면이 열립니다.

플레이어 포즈 설정에는 슬라이더로 회전을 조정할 수 있는 일반 모드가 있으며, 모든 회전에 대해 완전한 플레이스홀더 지원이 포함된 텍스트 입력을 사용할 수 있는 고급 모드도 있습니다. 이를 통해 회전 변수를 설정하는 Ticker 요소로 엔티티를 애니메이션하는 것도 가능합니다!

# 엔티티 크기 변경

Minecraft 1.21.1+에서는 요소의 일반 리사이즈 그랩버를 사용해 엔티티의 크기를 조절할 수 있습니다.

이전 버전(1.21.0 이하)에서는 Player Entity 요소가 리사이즈 그랩버를 통한 직접적인 크기 조절을 지원하지 않습니다. 대신 요소를 우클릭한 뒤 **Scale**을 클릭해야 합니다. 여기서 요소의 배율을 설정할 수 있습니다. 기본값은 `30`이며, 예를 들어 `60`으로 설정하면 플레이어가 평소보다 두 배 크게 표시되고, `15`로 설정하면 절반 크기로 표시되는 식입니다.

# 종속성: Fancy Entity Renderer (FER)

Minecraft 1.21.1+에서는 Player Entity 요소를 사용하기 위해 추가 모드가 필요합니다. 이 모드는 "Fancy Entity Renderer"라고 하며 CurseForge와 Modrinth에서 받을 수 있습니다.

사용 중인 Minecraft 버전에 아직 사용할 수 있는 빌드가 없다면, 이후에 출시될 가능성이 높습니다.

FER는 Keksuccino가 개발한 것이 아니므로, 언제 빌드가 출시될지는 그가 제어할 수 없다는 점을 유의해 주세요.
