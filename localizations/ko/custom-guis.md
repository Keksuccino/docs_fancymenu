# 사용자 지정 GUI

사용자 지정 GUI는 FancyMenu [요소](./elements)로 채울 수 있는 새로운 화면입니다.

> [!CAUTION]
> 사용자 지정 GUI는 동작을 실행할 수 있습니다. 신뢰할 수 있는 출처에서만 가져오세요.

# 사용자 지정 GUI 만들기

1. **사용자 지정 -> 사용자 지정 GUI -> 사용자 지정 GUI 관리**를 엽니다.
2. **새 GUI**를 선택합니다.
3. 식별자를 입력하고 화면 설정을 구성합니다.
4. **완료**를 선택한 다음, 관리 도구에서 새 GUI를 엽니다.
5. 다른 화면과 마찬가지로 레이아웃을 만들고 편집합니다.

식별자는 소문자, 숫자, `.`, `_`, `-`를 사용할 수 있습니다. 공백을 포함할 수 없으며, 반드시 고유해야 합니다. 비어 있거나, 잘못되었거나, 중복된 식별자는 저장할 수 없습니다.

사용자 지정 GUI는 항상 화면 사용자 지정이 활성화되어 있습니다. 따라서 사용자 지정 토글을 비활성화할 수 없습니다.

# 화면 설정

| 설정 | 동작 |
|---|---|
| ESC 허용 | Escape 키로 GUI를 닫고 상위 화면으로 돌아가게 합니다 |
| 게임/월드 일시 정지 | GUI가 열려 있을 때 싱글플레이를 일시 정지합니다 |
| 월드 배경 렌더링 | GUI 뒤에 로드된 월드를 표시합니다 |
| 월드 배경 오버레이 | 월드 위에 기본 흐림/어두움 오버레이를 추가합니다 |
| 팝업 모드 | 사용자 지정 GUI 뒤에 상위 화면이 보이도록 유지합니다 |
| 팝업 배경 오버레이 | 팝업 모드에서 상위 화면 위에 흐림/색조 오버레이를 추가합니다 |

팝업 모드는 두 화면을 병합하지 않습니다. 사용자 지정 GUI는 활성 화면으로 유지되고, 그 뒤에 상위 화면이 렌더링됩니다. 사용자 지정 GUI를 닫으면 상위 화면이 있는 경우 그 화면으로 돌아갑니다.

# 사용자 지정 GUI 열기

다음 중 하나에서 정확한 사용자 지정 GUI 식별자를 사용하세요:

- [**화면 또는 사용자 지정 GUI 열기** 동작](./action-scripts#open-screen-or-custom-gui-opengui)
- [`/openguiscreen` 명령](./commands#openguiscreen)

# 기존 화면 재정의하기

사용자 지정 GUI는 해당 화면이 열릴 때마다 바닐라 또는 모드 화면을 대체할 수 있습니다.

1. 대체할 사용자 지정 GUI를 만듭니다.
2. 대체하려는 화면을 엽니다.
3. **사용자 지정 -> 설정 -> 고급 사용자 지정 모드**를 활성화합니다.
4. **사용자 지정 -> 사용자 지정 GUI -> 현재 화면을 사용자 지정 GUI로 재정의**를 선택합니다.
5. 대체할 사용자 지정 GUI를 선택합니다.

저장된 재정의는 **사용자 지정 -> 사용자 지정 GUI -> 재정의된 화면 관리**에서 관리할 수 있습니다.

재정의는 원래 화면을 건너뛰므로, 해당 화면의 탐색 방식과 원래 화면의 동작에 의존하는 기능들을 반드시 테스트하세요.
