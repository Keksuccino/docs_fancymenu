# 사용자 지정 GUI

사용자 지정 GUI는 모드팩 정보 화면, 서버 허브 또는 규칙 페이지처럼 직접 만드는 메뉴입니다. 처음에는 비어 있으며, 다른 메뉴와 마찬가지로 [레이아웃](/layout-editor)을 추가해 꾸밀 수 있습니다. 그런 다음 버튼, 키 또는 명령어로 열 수 있습니다.

# 사용자 지정 GUI 만들기

<img width="800" alt="사용자 지정 GUI 관리 화면을 열고, 새 GUI를 클릭한 다음 식별자 modpack_info를 입력하고 팝업 모드를 켠 뒤 새 사용자 지정 GUI를 여는 모습" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/custom_guis_new.gif?raw=true">

1. **메뉴 바 -> 사용자 지정 -> 사용자 지정 GUI -> 사용자 지정 GUI 관리**를 엽니다.
2. **새 GUI**를 클릭합니다.
3. `modpack_info`와 같은 **사용자 지정 GUI 식별자**를 입력하고, [설정](#settings)을 구성한 뒤 **완료**를 클릭합니다.
4. 목록에서 새 사용자 지정 GUI를 클릭한 다음 **GUI 열기**를 클릭합니다.
5. **완료**를 클릭해 **사용자 지정 GUI 관리**를 닫습니다.

**사용자 지정 GUI 관리**에서 변경한 내용은 **완료** 또는 **GUI 열기**를 클릭해야 저장됩니다. **취소**를 클릭하면 변경 사항이 버려집니다.

## 식별자

버튼, 명령어, 레이아웃은 식별자를 사용해 사용자 지정 GUI를 찾습니다.

- 소문자, 숫자, `.`, `_`, `-`만 사용할 수 있습니다. 사용자 지정 GUI마다 고유한 식별자가 필요합니다.
- `title_screen`처럼 다른 [화면의 식별자](/screen-identifiers)는 사용하지 마세요. 해당 화면과 레이아웃을 공유하게 됩니다.
- 나중에 식별자를 바꾸면 레이아웃과 이전 식별자를 사용하는 버튼 및 명령어가 더 이상 GUI를 찾지 못합니다. 식별자를 원래대로 바꾸면 다시 찾을 수 있습니다.

## 레이아웃 만들기

1. 사용자 지정 GUI를 엽니다.
2. **메뉴 바 -> 사용자 지정 -> 레이아웃 -> 새로 만들기 -> 현재 화면용**을 클릭합니다. 사용자 지정 GUI에서는 사용자 지정 기능이 항상 켜져 있습니다.
3. 요소를 추가하고 레이아웃을 저장합니다. [레이아웃 편집기](/layout-editor)를 참고하세요.

사용자 지정 GUI는 뒤로 버튼조차 없이 아무것도 들어 있지 않습니다. [버튼](/elements#button)에 [**마지막 화면으로 돌아가기**](/action-scripts#back-to-last-screen) 동작을 지정하거나, 플레이어가 나갈 수 있도록 **Esc 키로 GUI 닫기 허용**을 켜 두세요.

# 설정

**사용자 지정 GUI 관리**에서 **GUI 편집**을 클릭하면 선택한 사용자 지정 GUI의 설정을 변경할 수 있습니다.

| 설정 | 기능 |
|---|---|
| **사용자 지정 GUI 식별자** | 사용자 지정 GUI의 이름입니다. [식별자](#the-identifier)를 참고하세요. |
| **화면 제목(선택 사항)** | GUI 상단에 흰색 제목을 표시합니다. 비워 두면 제목이 표시되지 않습니다. [플레이스홀더](/placeholders)를 사용할 수 있으며, 게임·모드·리소스 팩의 현지화 키는 플레이어의 언어로 표시됩니다. |
| **Esc 키로 GUI 닫기 허용** | `Esc` 키를 누르면 GUI가 닫힙니다. 기본적으로 켜져 있습니다. |
| **게임/월드 일시 정지** | GUI가 열려 있는 동안 싱글플레이 월드를 일시 정지합니다. 기본적으로 켜져 있습니다. |
| **월드 배경 렌더링** | 플레이 중 GUI 뒤에 월드를 표시합니다. 월드 밖에 있거나 이 설정이 꺼져 있으면 마인크래프트 파노라마가 표시됩니다. 기본적으로 켜져 있습니다. |
| **월드 배경 오버레이 렌더링** | 일시 정지 메뉴처럼 GUI 뒤의 월드나 파노라마를 흐리게 하고 어둡게 만듭니다. **월드 배경 렌더링**이 켜져 있을 때만 작동합니다. 이 설정이 꺼져 있으면 파노라마가 항상 흐리고 어둡게 표시됩니다. 기본적으로 켜져 있습니다. |
| **팝업 모드** | GUI를 열었던 메뉴 위에 표시합니다. [팝업 모드](#popup-mode)를 참고하세요. |
| **팝업 모드 배경 오버레이** | 팝업 뒤의 메뉴를 흐리게 만듭니다. **팝업 모드**에서만 작동합니다. 기본적으로 켜져 있습니다. |

- 흐림 효과의 강도는 마인크래프트의 **메뉴 배경 흐림** 설정과 같습니다.
- 레이아웃에 [메뉴 배경](/menu-backgrounds)을 지정하면 월드, 파노라마, 팝업 뒤의 메뉴 배경이 모두 가려집니다.
- 레이아웃 편집기에서는 사용자 지정 GUI의 제목(**사용자 지정 화면 제목**)을 변경할 수 없습니다. 대신 **화면 제목(선택 사항)**을 변경하세요. 자체 글꼴, 색상 또는 위치를 지정한 제목을 만들려면 이 설정을 비워 두고 [텍스트 요소](/elements#text)를 추가하세요.

## 팝업 모드

**팝업 모드**를 사용하면 사용자 지정 GUI를 열었던 메뉴가 레이아웃과 함께 뒤에 계속 표시됩니다. 팝업이 열려 있는 동안에는 뒤의 메뉴를 클릭할 수 없습니다.

- 팝업은 정보 상자, 확인 메시지, 설정 패널처럼 작은 항목에 가장 적합합니다. 뒤의 메뉴가 보이도록 공간을 비워 두세요.
- 팝업 레이아웃에 메뉴 배경을 지정하지 마세요. 뒤의 메뉴가 사라집니다.
- 플레이 중 키를 눌렀을 때처럼 메뉴가 열려 있지 않은 상태에서 사용자 지정 GUI를 열면 뒤에 표시할 메뉴가 없습니다. 이때는 일반 배경이 표시됩니다.

# 사용자 지정 GUI 열기

화면을 여는 기능은 무엇이든 식별자를 사용해 사용자 지정 GUI를 열 수 있습니다.

- **버튼:** `modpack_info` 값을 지정한 [**화면 또는 사용자 지정 GUI 열기**](/action-scripts#open-screen-or-custom-gui) 동작을 사용합니다.
- **키:** 같은 동작을 지정한 [**키보드 키를 눌렀을 때** 리스너](/listeners#listener-variables)를 사용합니다. 메뉴 안에서도, 플레이 중에도 사용자 지정 GUI를 열 수 있습니다.
- **명령어:** 서버, 명령 블록, 퀘스트 보상에서도 사용할 수 있는 `/openguiscreen modpack_info`를 입력합니다. [명령어](/commands#openguiscreen)를 참고하세요.
- **월드 나가기:** 식별자를 지정한 [**월드 또는 서버 나가기**](/action-scripts#leave-world-or-server) 동작을 사용하면 나간 뒤 사용자 지정 GUI가 열립니다.

사용자 지정 GUI는 각 플레이어의 FancyMenu 설정에 포함됩니다. 서버는 플레이어가 보유한 사용자 지정 GUI만 열 수 있으며, 여기에는 모드팩에 포함된 GUI도 해당합니다.

사용자 지정 GUI를 닫는 방법:

- (**Esc 키로 GUI 닫기 허용**이 켜져 있을 때) `Esc` 키를 누르거나 **마지막 화면으로 돌아가기** 동작을 사용하면 GUI를 열었던 메뉴로 돌아갑니다. 열려 있던 메뉴가 없으면 `Esc` 키를 눌러 게임으로 돌아갑니다.
- [**화면 닫기**](/action-scripts#close-screen) 동작을 사용하면 GUI가 닫힙니다. 월드 밖에서는 타이틀 화면이 열립니다.

# 기존 화면 대체하기

사용자 지정 GUI로 게임이나 모드의 메뉴를 대체할 수 있습니다. 해당 메뉴가 열릴 때마다 사용자 지정 GUI가 대신 열립니다.

> [!WARNING]
> 대체된 메뉴는 열리지 않으므로 원래 메뉴에서 수행하던 작업이 모두 실행되지 않으며, 해당 메뉴가 필요한 다른 모드가 제대로 작동하지 않을 수 있습니다. 가능하면 일반 레이아웃으로 메뉴를 변경하세요. 레이아웃으로 필요한 작업을 할 수 없을 때만 메뉴를 대체하세요.

1. **메뉴 바 -> 사용자 지정 -> 설정 -> 고급 사용자 지정 모드**를 켭니다.
2. 대체하려는 메뉴를 엽니다.
3. **메뉴 바 -> 사용자 지정 -> 사용자 지정 GUI -> 현재 화면을 사용자 지정 GUI로 대체**를 클릭합니다.
4. 경고를 확인하고 **사용자 지정 GUI 선택**에서 GUI를 선택합니다.

사용자 지정 GUI가 바로 열립니다. GUI에서 `Esc` 키를 누르거나 **마지막 화면으로 돌아가기**를 사용하면 대체된 메뉴가 열리기 전의 화면으로 돌아갑니다.

대체를 취소하려면 **메뉴 바 -> 사용자 지정 -> 사용자 지정 GUI -> 대체된 화면 관리**를 열고, 해당 화면 아래의 **대체 규칙 삭제**를 클릭한 다음 **완료**를 클릭합니다.

> [!TIP]
> [변수](/variables)가 설정된 경우에만 메뉴를 대체하는 등 특정 조건에서만 대체하려면 [**화면이 열렸을 때** 리스너](/listeners#on-screen-opened)에서 IF 문을 사용하세요.

# 사용자 지정 GUI 관리

- **사용자 지정 GUI 관리**의 **새 GUI**, **GUI 편집**, **GUI 열기**를 사용해 사용자 지정 GUI를 추가, 변경, 열 수 있습니다.
- **GUI 삭제**를 클릭하면 확인 후 선택한 사용자 지정 GUI가 삭제됩니다. 레이아웃은 그대로 남으며, 같은 식별자로 새 사용자 지정 GUI를 만들면 다시 표시됩니다.
- 검색창에서 식별자로 사용자 지정 GUI를 찾을 수 있습니다.
- **메뉴 바 -> 도움말 -> AI용 내보내기 -> 사용자 지정 GUI**를 사용하면 모든 사용자 지정 GUI와 대체 규칙을 [AI 채팅](/export-for-ai)용으로 내보냅니다.

사용자 지정 GUI와 대체 규칙은 `config/fancymenu/custom_gui_screens.txt`에 저장되며, 레이아웃은 다른 레이아웃과 마찬가지로 `config/fancymenu/customization/`에 저장됩니다([데이터 저장 위치](/data-storage-locations) 참고). 각 [프로필](/profiles)은 자체 사용자 지정 GUI를 가집니다.
