# 창 아이콘 및 제목

FancyMenu를 사용하면 Minecraft 창의 아이콘과 제목을 변경할 수 있습니다.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# 사용자 지정 아이콘

사용자 지정 아이콘을 설정하려면 **Customization -> Global Customizations**를 통해 [**Global Customizations**](./global-customizations)를 여세요.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- 아이콘은 **PNG** 파일이어야 합니다(**macOS에서는 ICNS**)
- 아이콘에는 깨져 보이지 않도록 **최소 1개의 투명 픽셀**이 있어야 합니다(MC/LWJGL 버그)
- 사용자 지정 아이콘 토글을 활성화하려면 3가지 아이콘 버전(16x16, 32x32, macOS)에 모두 대해 유효한 파일을 설정해야 합니다

> [!CAUTION]
> **다시 한 번**: 아이콘에는 깨져 보이지 않도록 **최소 1개의 투명 픽셀**이 있어야 합니다(MC/LWJGL 버그). 완전히 투명한 픽셀이 하나도 없으면 아이콘이 깨져 보입니다!


# 사용자 지정 제목

사용자 지정 제목을 설정하려면 **Customization -> Global Customizations**를 통해 [**Global Customizations**](./global-customizations)를 여세요.
