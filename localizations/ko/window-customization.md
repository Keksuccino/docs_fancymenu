# 창 아이콘 및 제목

FancyMenu를 사용하면 Minecraft 창의 아이콘과 제목을 변경할 수 있습니다.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# 사용자 지정 아이콘

사용자 지정 아이콘을 설정하려면 **사용자 지정 -> 전역 사용자 지정**에서 [**전역 사용자 지정**](/global-customizations)을 엽니다.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- 아이콘 파일은 **PNG** 형식이어야 합니다(macOS는 **ICNS**).
- 아이콘이 깨져 보이지 않도록 투명 픽셀이 **1개 이상** 있어야 합니다(MC/LWJGL 버그).
- 사용자 지정 아이콘 토글을 활성화하려면 아이콘 버전 3개(16x16, 32x32, macOS) 모두에 유효한 파일을 지정해야 합니다.

> [!CAUTION]
> **다시 한 번 강조합니다**: 아이콘이 깨져 보이지 않도록 투명 픽셀이 **1개 이상** 있어야 합니다(MC/LWJGL 버그). 완전히 투명한 픽셀이 하나라도 없으면 아이콘이 깨져 보입니다!


# 사용자 지정 제목

사용자 지정 제목을 설정하려면 **사용자 지정 -> 전역 사용자 지정**에서 [**전역 사용자 지정**](/global-customizations)을 엽니다.
