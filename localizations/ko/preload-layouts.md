# 리소스 사전 로드

사전 로드는 메뉴가 필요로 하기 전에 선택한 리소스를 미리 준비합니다. 그렇지 않으면 깜빡이거나, 첫 프레임이 검게 보이거나, 늦게 시작하는 리소스에 사용하세요.

# 사전 로더에 리소스 추가하기

**사용자 설정 -> 리소스 사전 로드**를 엽니다.

<br>

<img width="350" alt="Screenshot_1" src="https://github.com/Keksuccino/FancyMenu/assets/35544624/3265da80-1bbc-4634-bd94-ba2795d7e3f2">

목록에는 로컬 파일, 웹 URL, 또는 리소스 팩의 지원되는 이미지, 애니메이션, 오디오, 비디오, 텍스트 리소스를 추가할 수 있습니다. 살아 있는 [브라우저](./elements#browser) 페이지는 사전 로드하지 않습니다.

사전 로더는 게임 시작과 Minecraft 리소스 재로드 중에 실행됩니다. 각 항목이 완료되거나 실패할 때까지 기다린 뒤 다음 항목으로 진행하며, 항목당 최대 두 분이 제한입니다.

로드된 리소스는 FancyMenu가 리소스를 재로드하거나 클라이언트가 종료될 때 해제할 때까지 캐시에 유지됩니다. **사용자 설정 -> FancyMenu 다시 로드**는 캐시를 해제하지만 사전 로더를 다시 실행하지는 않습니다.

사전 로드는 로딩 시간과 RAM/VRAM 사용량을 늘립니다. 즉시 준비되어 있어야 하는 리소스만 추가하고, 클라이언트의 메모리가 부족해지면 큰 항목은 제거하세요.

# 슬라이드쇼 및 파노라마 사전 로드

[슬라이드쇼](./slideshows)를 추가하면 해당 슬라이드쇼의 모든 이미지와 선택적 오버레이가 로드됩니다. [파노라마](./panoramas)를 추가하면 6개의 모든 면과 선택적 오버레이가 로드됩니다.

**사용자 설정 -> FancyMenu 다시 로드**는 사전 로더를 실행하지 않습니다. 사전 로드 목록을 변경한 뒤에는 Minecraft 리소스를 재로드하거나 게임을 다시 시작하세요.
