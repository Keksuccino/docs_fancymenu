# 리소스 사전 로드

사전 로드를 사용하면 메뉴에서 리소스가 필요해지기 전에 미리 준비할 수 있습니다. 깜빡이거나, 첫 프레임이 검은색으로 표시되거나, 늦게 표시되는 리소스에 사용하세요.

# 사전 로더에 리소스 추가

**사용자 지정 -> 리소스 사전 로드**를 여세요.

<br>

<img width="350" alt="Screenshot_1" src="https://github.com/Keksuccino/FancyMenu/assets/35544624/3265da80-1bbc-4634-bd94-ba2795d7e3f2">

이 목록에는 로컬 파일, 웹 URL 또는 리소스 팩에 있는 지원되는 이미지, 애니메이션, 오디오, 동영상 및 텍스트 리소스를 추가할 수 있습니다. 실시간 [브라우저](/elements#browser) 페이지는 사전 로드되지 않습니다.

사전 로더는 게임 시작 및 Minecraft 리소스 다시 로드 시 실행됩니다. 다음 항목으로 넘어가기 전에 각 항목의 로드가 완료되거나 실패할 때까지 기다리며, 항목당 제한 시간은 2분입니다.

로드된 리소스는 다시 로드하거나 클라이언트를 종료할 때 FancyMenu가 리소스를 해제할 때까지 캐시에 유지됩니다. **사용자 지정 -> FancyMenu 다시 로드**를 선택하면 캐시는 해제되지만 사전 로더가 다시 실행되지는 않습니다.

사전 로드는 로딩 시간과 RAM/VRAM 사용량을 늘립니다. 즉시 사용할 준비가 되어 있어야 하는 리소스만 추가하고, 클라이언트의 메모리가 부족해지면 용량이 큰 항목을 제거하세요.

# 슬라이드쇼 및 파노라마 사전 로드

[슬라이드쇼](/slideshows)를 추가하면 모든 이미지와 선택적 오버레이가 로드됩니다. [파노라마](/panoramas)를 추가하면 여섯 면과 선택적 오버레이가 모두 로드됩니다.

**사용자 지정 -> FancyMenu 다시 로드**는 사전 로더를 실행하지 않습니다. 사전 로드 목록을 변경한 뒤에는 Minecraft 리소스를 다시 로드하거나 게임을 재시작하세요.
