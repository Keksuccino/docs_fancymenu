# 나인 슬라이싱 및 타일링

FancyMenu로 Minecraft에서 멋진 메뉴를 디자인할 때, 크기를 적절히 조절해야 하거나 패턴처럼 반복되어야 하는 이미지를 사용하고 싶을 수 있습니다. 이 가이드에서는 메뉴를 멋지게 보이게 만드는 **나인 슬라이싱(Nine-Slicing)** 과 **타일링(Tiling)** (반복 텍스처라고도 함) 사용법을 설명합니다!

# 나인 슬라이싱이란?

나인 슬라이싱은 이미지를 이상해 보이지 않게 원하는 크기로 늘릴 수 있게 해주는 기법입니다. 이미지를 아홉 개의 부분(틱택토 판처럼)으로 나누어 작동합니다. 모서리는 원래 크기를 유지하고, 가장자리는 한 방향으로 늘어나며, 가운데는 양방향으로 늘어납니다.

## 나인 슬라이싱은 어디에 사용할 수 있나요?

FancyMenu에서 나인 슬라이싱은 다음에 사용할 수 있습니다:
- **버튼 요소**(사용자 지정 버튼과 바닐라 버튼 편집 모두)
- **진행 바 텍스처**(바 및 배경 텍스처)

## 버튼에 나인 슬라이싱 사용하는 방법

1. 레이아웃 편집기에서 **버튼 요소**를 생성하거나 선택합니다.
2. 버튼을 우클릭하고 "Button Textures" 옵션을 찾습니다.
3. 버튼의 배경 텍스처(일반, 호버, 비활성 상태)를 설정합니다.
4. "Nine-Slice Custom Background" 옵션을 활성화합니다.
5. **Nine-Slice Background X-Borders**(왼쪽과 오른쪽 테두리 크기)를 설정합니다.
6. **Nine-Slice Background Y-Borders**(위쪽과 아래쪽 테두리 크기)를 설정합니다.

### 버튼 나인 슬라이싱 팁

- 테두리와 모서리가 구분되는 이미지를 사용하세요.
- 테두리 값(X와 Y)은 FancyMenu가 각 가장자리에서 몇 픽셀을 테두리로 처리할지 알려줍니다.
- 일반적인 값은 X와 Y 테두리 모두 5픽셀 정도입니다.
- 모서리는 항상 같은 크기를 유지하고, 가운데 부분은 버튼 크기에 맞게 늘어납니다.

# 타일링이란?

타일링(반복 텍스처라고도 함)은 바닥 타일처럼 이미지를 반복하여 작은 이미지로 넓은 영역을 채우는 방식입니다. 배경이나 패턴이 계속 이어져야 하는 큰 이미지에 적합합니다.

## 타일링은 어디에 사용할 수 있나요?

FancyMenu에서 타일링은 다음에 사용할 수 있습니다:
- **이미지 요소**
- **이미지 메뉴 배경**

## 이미지 요소에 타일링 사용하는 방법

1. 레이아웃 편집기에서 **이미지 요소**를 생성하거나 선택합니다.
2. 이미지를 우클릭하고 텍스처를 설정할 수 있는 "Image Source"를 찾습니다.
3. **"Repeat Texture"** 옵션을 찾아 활성화합니다.
4. 이미지 요소의 크기를 조절해 텍스처가 공간을 채우도록 반복되는지 확인합니다.

## 메뉴 배경에 타일링 사용하는 방법

1. 레이아웃 편집기의 배경 컨텍스트 메뉴에서 **Menu Backgrounds**를 엽니다.
2. **Image** 배경 유형을 선택합니다.
3. 배경 이미지를 선택합니다.
4. **"Repeat Texture"** 옵션을 활성화합니다.
5. 이제 배경이 텍스처를 반복하여 전체 화면을 채웁니다.

# 나인 슬라이싱과 타일링에 좋은 텍스처 만들기

## 나인 슬라이싱용:
- 테두리와 모서리가 뚜렷한 텍스처를 만드세요.
- 테두리가 분명하고 폭이 일정해야 합니다.
- 다양한 테두리 크기를 테스트해 가장 잘 맞는 값을 찾으세요.
- 버튼은 보통 3~5픽셀 테두리에서 잘 작동합니다.

## 타일링용:
- 모든 방향에서 서로 이어질 수 있는 seamless 텍스처를 만드세요.
- 시각적 혼란을 줄이기 위해 패턴은 단순하게 유지하세요.
- 먼저 작은 영역에서 반복해 보며 텍스처를 테스트하세요.

# 예시

## 나인 슬라이스 버튼 예시
간단한 버튼은 처음에 각 변에 5픽셀 테두리가 있는 30x30 이미지일 수 있습니다. 버튼을 더 크게 만들면 모서리는 5x5픽셀 크기를 유지하고, 가장자리와 가운데는 버튼 크기에 맞게 늘어납니다.

## 타일링된 배경 예시
미세한 패턴이 있는 작은 64x64 타일은 화면 크기와 상관없이 메뉴 배경 전체를 채우도록 반복될 수 있습니다.

# 일반적인 문제와 해결 방법

## 나인 슬라이스 버튼이 늘어나거나 왜곡되어 보여요:
- 테두리 값이 너무 작거나 너무 클 수 있습니다
- 실제 텍스처에 맞게 테두리 값을 변경해 보세요

## 타일링된 배경에 이음새가 보여요:
- 텍스처가 seamless가 아닙니다
- 가장자리가 완벽하게 맞도록 이미지를 수정해 보세요

## 크기를 조절하면 텍스처가 흐릿해 보여요:
- 더 높은 해상도의 텍스처를 사용하세요
- 깔끔한 선을 가진 단순한 디자인을 유지하세요

# 기억하세요

- **나인 슬라이싱**은 크기는 바뀌지만 모양은 유지해야 하는 UI 요소(예: 버튼)에 완벽합니다.
- **타일링**은 패턴으로 넓은 영역을 채울 때 좋습니다(예: 배경).
- 두 기능 모두 어떤 해상도나 화면 크기에서도 UI를 보기 좋게 만들어 줍니다!

이제 완벽하게 늘어난 버튼과 아름답게 타일링된 배경으로 멋진 Minecraft 메뉴를 만들어 보세요!
