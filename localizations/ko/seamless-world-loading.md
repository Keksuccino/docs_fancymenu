# 매끄러운 월드 로딩

매끄러운 월드 로딩은 월드나 서버를 나갈 때 스크린샷을 찍어 두었다가, 다음에 로딩할 때 그 이미지를 배경으로 사용합니다.

이렇게 하면 로딩 화면이 로딩이 끝난 뒤 보게 될 장면과 일치하므로, 전환이 더 부드럽게 느껴집니다.

# 위치

레이아웃 편집기 **밖**에 있는 상태에서 FancyMenu의 **메뉴 바**를 연 다음, **Customization -> Global Customizations**로 이동하세요.

# 활성화 / 비활성화

1. **Customization -> Global Customizations**를 엽니다.
2. **Seamless World Loading**을 찾습니다.
3. **Enabled** 또는 **Disabled**로 설정합니다.

# 동작 방식

- 활성화하면 FancyMenu가 월드/서버를 나갈 때 스크린샷을 저장합니다.
- 다음 로딩 시 그 스크린샷이 로딩 배경으로 사용됩니다.
- 처음 사용하는 경우: 아직 저장된 스크린샷이 없으면, 한 번 월드/서버를 나가기 전까지는 표시할 내용이 없습니다.
