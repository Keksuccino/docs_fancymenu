# 매끄러운 월드 로딩

매끄러운 월드 로딩은 월드 또는 서버의 최근 화면을 다음 로딩 화면 배경으로 사용합니다.

[**사용자 지정 -> 전역 사용자 지정**](./global-customizations) -> **매끄러운 월드 로딩**에서 활성화할 수 있습니다.

# 작동 방식

- FancyMenu는 추적 중인 월드나 서버에 있는 동안 현재 프레임을 주기적으로 캡처합니다.
- 마지막 캡처는 나갈 때 저장됩니다.
- 각 월드와 서버는 고유한 해시 PNG 파일명을 가집니다.
- FancyMenu는 최근 월드 캡처 5개와 최근 서버 캡처 5개까지 미리 불러옵니다.
- 대상에 대한 첫 번째 캡처가 저장되기 전까지는 아무것도 표시되지 않습니다.

캡처는 다음 위치에 저장됩니다:

```text
<game-directory>/fancymenu_data/seamless_world_loading/
```

스크린샷에는 캡처 시 월드에서 보이던 모든 내용이 포함될 수 있습니다. 매끄러운 월드 로딩을 비활성화하면 캡처와 사용은 중지되지만, 기존 PNG 파일은 삭제되지 않습니다. 원치 않는 캡처는 게임을 종료한 상태에서 해당 디렉터리에서 삭제하세요.
