# 매끄러운 월드 로딩

매끄러운 월드 로딩은 월드나 서버에서 최근에 본 화면을 다음 로딩 화면의 배경으로 사용합니다.

[**사용자 지정 -> 전역 사용자 지정**](/global-customizations) -> **매끄러운 월드 로딩**에서 활성화하세요.

# 작동 방식

- 추적 중인 월드나 서버에 있는 동안 FancyMenu가 현재 화면을 주기적으로 캡처합니다.
- 월드나 서버에서 나가면 가장 최근에 캡처한 이미지가 저장됩니다.
- 각 월드와 서버에는 고유한 해시 PNG 파일 이름이 지정됩니다.
- FancyMenu는 최근 월드 캡처를 최대 5개, 최근 서버 캡처를 최대 5개까지 미리 불러옵니다.
- 대상의 첫 캡처가 저장되기 전까지는 해당 대상에 아무것도 표시되지 않습니다.

캡처 이미지는 다음 위치에 저장됩니다.

```text
<game-directory>/fancymenu_data/seamless_world_loading/
```

스크린샷에는 캡처 당시 월드에서 보이는 모든 것이 포함될 수 있습니다. 매끄러운 월드 로딩을 비활성화하면 캡처와 사용이 중단되지만, 기존 PNG 파일은 삭제되지 않습니다. 원하지 않는 캡처 이미지는 게임을 종료한 상태에서 해당 디렉터리에서 삭제하세요.
