# AI용 내보내기

**AI용 내보내기**는 FancyMenu 설정의 일부를 Alice 같은 AI 도우미가 읽기 좋은 텍스트로 변환합니다. Alice는 [FancyMenu Discord](https://discord.gg/rhayah27GC)의 도우미 봇입니다. 내보낸 내용을 채팅에 붙여 넣으면 AI가 추측하는 대신 설정을 정확히 파악할 수 있습니다.

# 이 기능이 있는 이유

스크린샷으로는 화면이 어떻게 보이는지 알 수 있지만, 어떻게 설정했는지는 알 수 없습니다. 액션 스크립트나 요구 사항을 직접 입력하는 데는 시간이 오래 걸리고, 정작 중요한 세부 정보가 입력 과정에서 빠지기도 합니다.

내보내기에는 AI가 알아야 할 내용이 모두 포함됩니다.

- 내보낸 항목의 모든 설정, 액션, 요구 사항 및 값
- FancyMenu, Minecraft, 모드 로더, Java 및 시스템 버전
- AI가 내용을 올바르게 이해할 수 있도록 돕는 FancyMenu 작동 방식에 대한 간단한 설명

플레이하는 언어와 관계없이 내보내기 내용은 항상 영어로 생성됩니다. 파일 경로에 포함된 계정 이름은 `<user>`로 바뀌므로 공개 채팅에서도 내보내기를 안전하게 공유할 수 있습니다.

# 사용 시점

- 버튼을 눌러도 아무 반응이 없거나 요소가 표시되지 않는 등, 무언가가 예상대로 작동하지 않을 때
- FancyMenu에 오류나 경고가 표시될 때
- 액션 스크립트, 요구 사항 또는 전체 메뉴를 만드는 데 도움이 필요할 때
- 게임에서 무엇을 할 수 있는지 알고 싶을 때. **FancyMenu에서 할 수 있는 모든 것**에는 애드온에 포함된 항목까지, 사용할 수 있는 모든 요소, 배경, 액션, 요구 사항, 자리 표시자 및 리스너가 나열되어 있습니다.

질문과 관련된 항목만 내보내세요. 예를 들어 작동하지 않는 버튼 하나만 내보내면 됩니다. 내보내기 범위가 작을수록 AI가 문제에 집중하기 쉽습니다. 그런 다음 기대했던 동작과 실제로 일어난 일을 설명하세요.

# 내보내는 방법

아래 각 메뉴 항목을 선택하면 작은 메뉴가 열립니다.

- **클립보드에 복사**는 내보내기 내용을 복사합니다. 채팅에서 `Ctrl + V`(macOS에서는 `Cmd + V`)를 눌러 붙여 넣으세요.
- **파일로 저장**은 Markdown 파일을 `<game-directory>/fancymenu_data/ai_exports/`에 저장한 다음 해당 폴더를 엽니다. 파일을 채팅으로 끌어다 놓으면 됩니다. 채팅 메시지에 담기 어려울 만큼 큰 내보내기에 사용하세요.

레이아웃 편집기, 리스너 창 및 스케줄러 창에서 내보내면 아직 저장하지 않은 변경 사항도 포함됩니다.

# 내보내기 가능한 항목

## 메뉴 표시줄

| 내보내는 항목 | 위치 |
|---|---|
| 현재 화면과 해당 화면의 위젯 및 FancyMenu가 화면에서 수행하는 작업 | **메뉴 표시줄 -> 사용자 지정 -> 현재 화면을 AI용으로 내보내기** |
| 레이아웃 | **메뉴 표시줄 -> 사용자 지정 -> 레이아웃**에서 레이아웃을 선택한 다음 **레이아웃을 AI용으로 내보내기** |
| 게임, 하드웨어 및 모드 정보, 그리고 비디오 및 브라우저 지원 등 FancyMenu에서 사용할 수 있는 기능 | **메뉴 표시줄 -> 도움말 -> AI용 내보내기 -> 시스템 정보** |
| [전역 사용자 지정](/global-customizations)을 포함한 FancyMenu의 모든 설정 | **메뉴 표시줄 -> 도움말 -> AI용 내보내기 -> FancyMenu 설정** |
| 모든 [변수](/variables) | **메뉴 표시줄 -> 도움말 -> AI용 내보내기 -> 모든 변수** |
| 모든 [리스너](/listeners) | **메뉴 표시줄 -> 도움말 -> AI용 내보내기 -> 모든 리스너** |
| 모든 [스케줄러](/schedulers) | **메뉴 표시줄 -> 도움말 -> AI용 내보내기 -> 모든 스케줄러** |
| 모든 [사용자 지정 GUI](/custom-guis) | **메뉴 표시줄 -> 도움말 -> AI용 내보내기 -> 사용자 지정 GUI** |
| 모든 [프로필](/profiles) | **메뉴 표시줄 -> 도움말 -> AI용 내보내기 -> 프로필** |
| 게임에서 사용할 수 있는 모든 요소, 배경, 액션, 요구 사항, 자리 표시자 및 리스너 | **메뉴 표시줄 -> 도움말 -> AI용 내보내기 -> FancyMenu에서 할 수 있는 모든 것** |

## 레이아웃 편집기

| 내보내는 항목 | 위치 |
|---|---|
| 편집 중인 레이아웃 | 편집기의 메뉴 표시줄에서 **레이아웃 -> 레이아웃을 AI용으로 내보내기** |
| 화면의 다른 레이아웃 | 편집기의 메뉴 표시줄에서 **레이아웃 -> 열기**를 선택하고 레이아웃을 고른 다음 **레이아웃을 AI용으로 내보내기** |
| 요소 하나 | 요소를 마우스 오른쪽 버튼으로 클릭한 다음 **AI용으로 내보내기** |
| 선택한 모든 요소 | 편집기의 메뉴 표시줄에서 **편집 -> 선택한 요소를 AI용으로 내보내기** |
| [메뉴 배경](/menu-backgrounds) | 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **메뉴 배경**을 선택한 다음 배경을 고르고 **AI용으로 내보내기** |
| [장식 오버레이](/decoration-overlays) | 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **장식 오버레이**를 선택한 다음 오버레이를 고르고 **AI용으로 내보내기** |

## 오류 및 경고

FancyMenu에 오류나 경고가 표시되면 **확인** 옆의 **AI용으로 내보내기**를 클릭해 메시지를 내보내세요.

## 서버

서버의 [FMData](/fm-data) 설정과 서버 리스너 및 환영 데이터를 명령어로 내보낼 수 있습니다. 모든 `/fmdata` 명령어와 마찬가지로 권한 레벨 2가 필요합니다.

```mcfunction
/fmdata export_for_ai copy
/fmdata export_for_ai file
```

- `copy`는 채팅 메시지를 보냅니다. 메시지를 클릭하면 내보내기 내용을 복사할 수 있습니다. 서버 콘솔에서는 내보내기 내용 전체가 표시됩니다.
- `file`은 서버의 `fancymenu_data/ai_exports/`에 내보내기 파일을 저장합니다. 채팅에 담기에는 내보내기 내용이 너무 클 때 사용하세요.
