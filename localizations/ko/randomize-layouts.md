# 무작위화

FancyMenu에는 레이아웃 전체 또는 일부를 무작위로 선택하는 데 도움이 되는 다양한 기능이 있습니다.

예를 들어 사용자가 화면을 열 때마다 다른 화면 배경을 보게 하거나, 로딩 화면에 무작위 팁을 표시하고 싶을 때 유용합니다.

# 레이아웃 무작위화

FancyMenu에는 여러 레이아웃을 하나의 그룹으로 만들고, 시스템이 이 그룹에서 무작위로 레이아웃 하나를 자동으로 선택하는 기능이 있습니다. 이렇게 하면 사용자가 게임을 실행하거나 화면을 열 때마다 완전히 다른 무작위 메뉴 디자인을 보여줄 수 있지만, 배경처럼 화면의 일부만 바꾸는 용도로도 사용할 수 있습니다.

## 무작위 모드

레이아웃을 무작위화하려면 무작위 선택 대상이 될 모든 레이아웃에서 **무작위 모드(Random Mode)** 를 활성화해야 합니다. 그러려면 **편집기 배경**을 **마우스 오른쪽 버튼으로 클릭**하고 **Random Mode** 항목을 찾으세요.

## 무작위 그룹 식별자

무작위 모드를 활성화한 뒤에는 **무작위 그룹 식별자(Random Group Identifier)** 를 설정해야 합니다.
이 숫자는 **같은 그룹**에 포함될 모든 레이아웃에서 **반드시 동일**해야 합니다.

## 무작위화 동작

그룹에서 무작위 레이아웃을 **게임 세션당 한 번만** 선택하게 하려면 **Randomize Only First Time** 을 활성화하세요. 그러면 화면이 처음 열릴 때 한 번 레이아웃을 선택하고, 이후에는 처음 선택한 레이아웃을 계속 사용합니다. 이 옵션을 비활성화하면 화면이 열릴 때마다 매번 무작위 레이아웃을 선택합니다.

# 예시 시나리오 1: 배경

예를 들어 타이틀 화면의 배경을 무작위화하고 싶다고 해봅시다.

그러려면 **배경마다 하나의 레이아웃**을 만들고, 이 레이아웃들에서는 _**오직**_ 배경만 변경한 뒤 올바른 무작위 그룹 식별자와 함께 무작위 모드를 활성화해야 합니다.

이 예시에서는 무작위 그룹 식별자로 **10**을 사용합니다. 이 식별자는 이 무작위 레이아웃 그룹의 모든 레이아웃에 설정되어야 합니다.

가장 쉬운 방법은 올바른 무작위 그룹 식별자가 설정된 레이아웃을 하나 준비한 다음 **다른 이름으로 저장(Save As)** 을 사용하는 것입니다. 새 이름으로 저장할 때마다 배경을 바꾸면, 서로 다른 배경을 가진 여러 레이아웃이 만들어지고, 그중 하나가 화면을 열 때마다 또는 게임 세션마다 선택됩니다.

# 예시 시나리오 2: 요소

또 다른 흔한 사용 사례는 텍스트나 이미지 요소를 무작위화하는 것입니다.

배경과 마찬가지로, 무작위로 선택하고 싶은 요소 버전마다 하나의 레이아웃을 만드세요. 각 레이아웃에는 해당 요소만 추가하고 다른 것은 넣지 마세요. 어떤 것도 사용자 지정하지 말고, 다른 요소도 추가하지 마세요.

그다음 모든 레이아웃을 같은 무작위 그룹 식별자로 저장하면, 화면을 열거나 게임을 실행할 때 그룹의 레이아웃 하나가 선택됩니다.
