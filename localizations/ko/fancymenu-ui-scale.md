# FancyMenu의 UI 크기

FancyMenu의 UI(예: 메뉴 바와 컨텍스트 메뉴)는 Minecraft의 일반 GUI 크기와 연결되지 않은 별도의 크기 설정을 사용합니다.

FancyMenu의 UI가 너무 작거나 크게 보인다면, **메뉴 바 -> 사용자 지정 -> 설정 -> FancyMenu의 UI**에서 UI 크기를 변경할 수 있습니다.

FancyMenu 3.9.0에서는 더 많은 UI 크기 옵션이 추가되었습니다. UI 크기가 **Auto**로 설정되어 있으면, 가장 작은 자동 크기는 이제 `1.25`입니다. 원한다면 여전히 `1`을 수동으로 선택할 수 있습니다.

이에 대한 유일한 예외는 변수 관리 화면이나 레이아웃 편집기처럼 FancyMenu가 추가한 실제 전체 화면입니다. 이러한 화면은 대부분 Minecraft의 일반 GUI 크기를 사용하지만, 일부 화면은 창이 화면의 모든 내용을 담기에는 너무 작을 경우 더 작은 크기로 자동 표시되도록 다른 자동 크기 조정 로직을 사용할 수도 있습니다.
