# FancyMenu UI 스케일

FancyMenu의 UI(예: 메뉴 바와 컨텍스트 메뉴)는 Minecraft의 일반 GUI 스케일과 연결되지 않은 별도의 스케일을 사용합니다.

FancyMenu의 UI가 너무 작거나 크게 보인다면, **메뉴 바 -> 사용자 지정 -> 설정 -> FancyMenu의 UI**에서 UI 스케일을 변경할 수 있습니다.

UI 스케일이 **Auto**로 설정되어 있을 때, 가장 작은 자동 스케일은 `1.25`입니다. 수동으로 스케일 `1`을 선택할 수도 있습니다.

이 예외는 FancyMenu가 추가한 실제 전체 화면에만 해당합니다. 예를 들어 변수 관리 화면이나 레이아웃 편집기 같은 화면입니다. 이러한 화면은 대부분 Minecraft의 일반 GUI 스케일을 사용하지만, 창이 너무 작아 화면의 모든 내용을 표시할 수 없을 경우 더 작은 크기로 자동 표시되도록 다른 자동 스케일링 로직을 사용하는 화면도 있을 수 있습니다.
