# 요구 사항

요구 사항은 "마우스가 이 버튼 위에 있음", "12월임" 또는 "월드가 로드됨"과 같은 조건입니다. 다음과 같은 용도로 사용하세요.

- [요소](/elements)를 특정 상황에서만 표시하기
- 레이아웃 전체를 특정 상황에서만 로드하기
- 버튼, 슬라이더, 체크박스를 특정 상황에서만 클릭할 수 있게 하기
- [작업 스크립트](/action-scripts)의 일부를 특정 상황에서만 실행하기

FancyMenu는 메뉴가 열려 있는 동안 계속 요구 사항을 확인하므로, 조건에 따라 항목이 바로 표시되거나 숨겨지고 변경됩니다. 이 정보 상자는 마우스가 "멀티플레이" 위에 있을 때만 표시됩니다.

# 요구 사항을 찾을 수 있는 곳

| 위치 | 요구 사항의 기능 |
|---|---|
| 요소를 마우스 오른쪽 버튼으로 클릭 -> **로드 요구 사항** | 요구 사항이 충족될 때만 요소를 표시합니다. [바닐라 요소](/vanilla-elements)에도 사용할 수 있습니다. |
| 편집기 배경을 마우스 오른쪽 버튼으로 클릭 -> **로드 요구 사항 [레이아웃 전체]** | 요구 사항이 충족될 때만 레이아웃 전체를 로드합니다. [레이아웃 전체 요구 사항](#레이아웃-전체-요구-사항)을 참조하세요. |
| 버튼, 슬라이더 또는 체크박스를 마우스 오른쪽 버튼으로 클릭 -> **컨트롤 활성 상태** | 요구 사항이 충족될 때만 클릭할 수 있습니다. 그렇지 않으면 비활성화되어 표시됩니다. 바닐라 버튼에도 적용할 수 있습니다. |
| [작업 스크립트](/action-scripts#statements)의 IF, ELSE-IF, WHILE | 요구 사항이 충족될 때만 내부 작업을 실행합니다. |

레이아웃 편집기에서는 요소가 항상 표시되므로 계속 편집할 수 있습니다. 요소의 요구 사항은 편집기 밖에서 적용됩니다.

> [!TIP]
> [요소 표시 여부](/element-visibility)에서 지연, 페이드, 버튼을 이용한 전환 등 요소를 표시하거나 숨기는 다양한 방법을 확인할 수 있습니다.

# 요구 사항 추가하기

<img width="800" alt="멀티플레이 버튼의 ID를 복사한 다음, 요구 사항 관리에서 정보 상자에 해당 ID를 사용해 요소 위에 마우스가 있는지 확인하는 요구 사항을 추가합니다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/requirements_add.gif?raw=true">

1. 요소를 마우스 오른쪽 버튼으로 클릭하고 **로드 요구 사항**을 클릭합니다. **요구 사항 관리** 창이 열립니다.
2. 빈 목록을 마우스 오른쪽 버튼으로 클릭하고 **요구 사항 추가**를 클릭하거나 `A`를 누릅니다.
3. **사용 가능한 요구 사항**에서 카테고리를 클릭하거나 입력을 시작해 이름과 설명을 검색합니다. **요구 사항 설명**에 선택한 요구 사항에 대한 설명이 표시됩니다.
4. **다음 단계**를 클릭해 값을 설정합니다. 값이 필요 없는 요구 사항에는 대신 **완료**가 표시됩니다. 요구 사항을 두 번 클릭해도 같은 작업을 할 수 있습니다.
5. 값을 입력하고 **완료**를 클릭합니다. 예를 들어, **요소 위에 마우스가 있는지 확인**에는 요소 ID가 필요합니다. 편집기에서 요소를 마우스 오른쪽 버튼으로 클릭하고 **요소 ID 복사**를 클릭하면 ID를 가져올 수 있습니다.
6. **요구 사항 관리**에서 **완료**를 클릭합니다.

## 요구 사항 모드

요구 사항 선택 창의 **요구 사항 모드** 버튼을 누르면 다음 모드로 전환됩니다.

- **일반**: 조건이 참일 때 충족됩니다.
- **반대**: 조건이 참이 아닐 때 충족됩니다. 예를 들어, **월드 로드 여부**를 반대 모드로 설정하면 메인 메뉴에서만 충족됩니다.

**요구 사항 관리**에는 각 요구 사항의 모드와 값이 표시됩니다.

## 값

- 값에는 `$$coins`와 같은 [자리 표시자](/placeholders)와 [변수](/variables#showing-variables-in-text)를 사용할 수 있습니다. FancyMenu는 요구 사항을 확인할 때마다 값을 입력된 내용으로 바꿉니다.
- 생물 군계, 모드 ID, 언어, 변수 이름 등 여러 값 입력란에서는 입력하는 동안 값을 추천합니다. 추천 항목을 클릭하거나 `Tab`을 누르세요.
- 간단한 값을 사용하는 요구 사항을 선택하면 한 줄짜리 텍스트 편집기가 열립니다. 제목에 **대상 요소 ID**처럼 입력할 내용이 표시됩니다.

## 요구 사항 관리

**요구 사항 관리**에서 목록, 요구 사항 또는 그룹을 마우스 오른쪽 버튼으로 클릭하면 다음 옵션을 사용할 수 있습니다.

| 옵션 | 단축키 | 기능 |
|---|---|---|
| **요구 사항 추가** | `A` | 요구 사항을 추가합니다. |
| **그룹 추가** | `G` | 그룹을 추가합니다(아래 참조). |
| **요구 사항 편집** | `Enter` 또는 두 번 클릭 | 유형, 모드, 값을 설정하는 요구 사항 선택 창을 엽니다. |
| **요구 사항 제거** / **그룹 제거** | `Delete` | 항목을 제거합니다. |
| **실행 취소** / **다시 실행** | `Ctrl + Z` / `Ctrl + Y` | 이 창에서 변경한 내용을 실행 취소하거나 다시 실행합니다. |
| **AI용 요구 사항 내보내기** | | 저장하지 않은 변경 사항을 포함해 이 창의 모든 요구 사항을 [AI 채팅](/export-for-ai)용으로 내보냅니다. |

`위쪽`과 `아래쪽` 키를 누르면 위나 아래의 요구 사항을 선택합니다. **완료**(`Ctrl + S`)를 누르면 저장하고, **취소**를 누르면 이 창에서 변경한 내용이 모두 취소됩니다. macOS에서는 `Ctrl` 대신 `Cmd`를 사용하세요.

여러 요소를 선택한 상태에서 **로드 요구 사항**을 변경하면 선택한 모든 요소의 요구 사항이 변경됩니다. 요소마다 요구 사항이 다르면 기존 요구 사항이 모두 교체되므로 FancyMenu에서 먼저 확인을 요청합니다.

# 요구 사항 결합하기

**요구 사항 관리**에 있는 모든 요구 사항이 충족되어야 합니다. "이것 또는 저것"을 지정하려면 그룹을 사용하세요.

그룹은 하나의 요구 사항처럼 작동합니다.

- **And** 모드: 그룹 안의 모든 조건이 충족되어야 합니다. 새 그룹은 기본적으로 이 모드로 생성됩니다.
- **Or** 모드: 그룹 안의 조건 중 하나만 충족되어도 됩니다.

1. 목록을 마우스 오른쪽 버튼으로 클릭하고 **그룹 추가**를 클릭하거나 `G`를 누릅니다. 그룹 이름은 `group_1`처럼 지정됩니다.
2. 그룹을 마우스 오른쪽 버튼으로 클릭하고 **그룹 모드**를 클릭해 **And**와 **Or** 사이를 전환합니다.
3. **그룹 요구 사항 편집**을 클릭하거나 그룹을 두 번 클릭합니다. **요구 사항 관리**와 비슷한 창이 그룹에 대해 열립니다.
4. 그룹에 요구 사항을 추가하고 **완료**를 클릭합니다.

예를 들어 12월 또는 플레이어가 `xmas_lights`를 켰을 때 크리스마스 인사말을 표시하려면 **Or** 그룹에 **실시간 월 확인** `12`와 변수 `xmas_lights`의 값이 `on`인지 확인하는 **변수 값 확인(FM 변수)**을 추가합니다.

<img width="800" alt="요구 사항 관리에서 그룹을 추가하고 Or 모드로 전환한 다음, 실시간 월 확인과 변수 값 확인(FM 변수)을 추가합니다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/requirements_group.gif?raw=true">

- 그룹 안에 다른 그룹을 넣을 수 있으므로 "(A 그리고 B) 또는 (C 그리고 D)"와 같은 조건을 만들 수 있습니다. 창 제목에는 `그룹 편집: group_1 › group_2`처럼 현재 위치가 표시됩니다.
- **그룹 식별자 편집**으로 그룹 이름을 바꿀 수 있습니다. 그룹 안을 포함해 이름은 각각 한 번씩만 사용할 수 있습니다.
- **Or** 모드의 빈 그룹은 충족되지 않습니다.

# 레이아웃 전체 요구 사항

레이아웃 전체 요구 사항은 레이아웃 전체를 로드할지 결정합니다. 타이틀 화면의 야간 버전, 언어별 레이아웃 또는 싱글플레이에서만 표시되는 레이아웃 등에 활용할 수 있습니다.

편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **로드 요구 사항 [레이아웃 전체]**를 클릭하세요. **메뉴 바 -> 레이아웃 -> 레이아웃 속성**에서도 찾을 수 있습니다.

- 메뉴가 열려 있는 동안 결과가 바뀌면 FancyMenu는 현재 충족되는 레이아웃을 사용해 화면을 다시 구성합니다.
- [범용 레이아웃](/universal-layouts)에도 적용됩니다.
- 버튼으로 레이아웃을 켜고 끄려면 버튼을 다른 레이아웃에 넣으세요. [레이아웃 켜기 및 끄기](/element-visibility#turning-layouts-on-and-off)를 참조하세요.

# 참고 사항

- 월드가 로드되지 않은 경우(예: 메인 메뉴) 월드 및 플레이어 관련 요구 사항은 충족되지 않습니다.
- [티커](/elements#ticker)에서 **비동기**를 켜면 요소, 마우스 커서, 인벤토리, 플레이어, 월드 관련 요구 사항이 작동하지 않습니다. 이 경우 FancyMenu는 해당 요구 사항의 이름과 함께 오류를 표시합니다.
- 제거한 애드온의 요구 사항은 건너뜁니다. 편집기에서 레이아웃을 저장하면 해당 요구 사항이 완전히 제거됩니다.
- **메뉴 바 -> 사용자 지정 -> 설정 -> 요구 사항 캐시 시간 [MS]**는 몇 밀리초 동안 요구 사항의 결과를 재사용해 큰 레이아웃의 속도를 높입니다. 기본값은 `0`이며, 캐시를 사용하지 않습니다. 캐싱을 사용하면 작업 스크립트와 빠른 변경이 예상과 다르게 작동할 수 있습니다.

# 모든 요구 사항

요구 사항은 요구 사항 선택 창과 같은 방식으로 카테고리별, 이름순으로 정렬되어 있습니다. 카테고리가 없는 요구 사항은 선택 창의 맨 아래에 표시되며, 여기서는 [기타](#기타) 섹션에 있습니다.

## GUI

### 활성 커서 유형 확인

**식별자:** `is_active_cursor_type`

마우스 커서의 모양이 특정 유형일 때 충족됩니다. 예를 들어 링크 위에서 **가리키는 손** 모양이거나 텍스트 입력란 위에서 **텍스트 커서** 모양일 때입니다.

- 값: **커서 유형**을 클릭해 **일반**, **텍스트 커서**, **십자선**, **가리키는 손**, **가로 크기 조절**, **세로 크기 조절**, **북서-남동 크기 조절**, **북동-남서 크기 조절**, **전체 크기 조절**, **허용 안 됨** 중에서 선택합니다.

### 마우스가 버튼 위에 있는지 확인

**식별자:** `fancymenu_visibility_requirement_is_any_button_hovered`

바닐라 버튼이나 사용자 지정 버튼을 포함해 표시 중인 버튼 위에 마우스가 있을 때 충족됩니다.

### 마우스가 요소 위에 있는지 확인

**식별자:** `fancymenu_visibility_requirement_is_any_element_hovered`

버튼뿐 아니라 표시 중인 요소 위에 마우스가 있을 때 충족됩니다.

### 화면이 열려 있는지 확인

**식별자:** `is_any_screen_open`

일시 정지 메뉴나 인벤토리처럼 메뉴가 열려 있을 때 충족됩니다. 메뉴 없이 플레이 중일 때는 충족되지 않습니다.

### 버튼 활성 여부 확인

**식별자:** `fancymenu_visibility_requirement_is_button_active`

버튼을 클릭할 수 있을 때 충족됩니다.

- 값: 버튼의 [요소 ID](/element-identifiers)입니다. 편집기에서 버튼을 마우스 오른쪽 버튼으로 클릭하고 **요소 ID 복사**를 클릭하세요.

### 사용자 지정 메뉴 바 표시 여부 확인

**식별자:** `is_customization_menu_bar_visible`

FancyMenu의 메뉴 바가 표시될 때 충족됩니다. 모드팩 모드에서나 메뉴 바가 꺼져 있을 때는 충족되지 않습니다.

### 요소 포커스 여부 확인

**식별자:** `is_element_focused`

요소에 포커스가 있을 때 충족됩니다. 버튼과 슬라이더는 클릭하거나 방향키 또는 `Tab`으로 이동해 포커스를 얻습니다. 키를 눌러 요소로 이동하는 것은 마우스를 올린 것으로 간주되지 않습니다. 키보드를 사용하는 플레이어도 고려하려면 이 요구 사항과 **요소 위에 마우스가 있는지 확인**을 [Or 그룹](#요구-사항-결합하기)에 넣으세요.

- 값: `mc_titlescreen_multiplayer_button`과 같은 [요소 ID](/element-identifiers)입니다.

### 요소 위에 마우스가 있는지 확인

**식별자:** `fancymenu_visibility_requirement_is_element_hovered`

요소 위에 마우스가 있을 때 충족됩니다. 해당 요소가 표시 중이어야 합니다.

- 값: 타이틀 화면의 멀티플레이 버튼에 해당하는 `mc_titlescreen_multiplayer_button`과 같은 [요소 ID](/element-identifiers)입니다. 편집기에서 요소를 마우스 오른쪽 버튼으로 클릭하고 **요소 ID 복사**를 클릭하면 ID를 가져올 수 있습니다.

### 요소가 끝까지 스크롤되었는지 확인

**식별자:** `is_scroll_area_scrolled_to_end`

[스크롤 가능 영역](/scrollable-areas) 또는 텍스트 요소의 내용을 맨 아래까지 스크롤하면 충족됩니다. 스크롤할 내용이 없는 요소도 끝까지 스크롤된 것으로 간주됩니다. 플레이어가 규칙을 끝까지 읽은 다음에만 작동하는 **수락** 버튼 등에 유용합니다.

- 값: 스크롤 가능 영역 또는 텍스트 요소의 [요소 ID](/element-identifiers)입니다.

### GUI 배율 확인

**식별자:** `fancymenu_loading_requirement_is_gui_scale`

Minecraft의 GUI 배율이 조건과 일치할 때 충족됩니다.

- 값: 정확히 해당 배율일 때는 `2`처럼 입력하고, 2보다 클 때는 `>2`, 4보다 작을 때는 `<4`처럼 입력합니다. `<3.5`처럼 소수도 사용할 수 있습니다.
- 여러 조건은 쉼표로 구분합니다. 부등호가 없는 숫자는 하나만 일치하면 됩니다(예: `2,3`). `>`와 `<` 조건은 모두 일치해야 합니다(예: `>1,<4`).

### 키를 눌렀는지 확인

**식별자:** `is_key_pressed`

키를 누르고 있는 동안 충족됩니다. 키를 누를 때마다 작업을 한 번만 실행하려면 대신 [**키보드 키를 눌렀을 때**](/listeners#on-keyboard-key-pressed) 리스너를 사용하세요.

- 값: **키 선택**에서 **키 변경**을 클릭하고 원하는 키를 누릅니다.

### 레이아웃 활성 여부 확인

**식별자:** `fancymenu_visibility_requirement_is_layout_enabled`

레이아웃이 활성화되어 있을 때 충족됩니다.

- 값: `winter_title_screen`과 같은 레이아웃 이름입니다.

### MC 디버그 오버레이 활성 여부 확인

**식별자:** `is_debug_overlay_enabled`

F3 디버그 화면이 표시될 때 충족됩니다. F1로 HUD를 숨겼을 때는 충족되지 않습니다.

### 모드팩 모드 활성 여부 확인

**식별자:** `is_modpack_mode_enabled`

FancyMenu의 모드팩 모드가 켜져 있을 때 충족됩니다.

### 화면 제목 확인

**식별자:** `is_menu_title`

열려 있는 화면의 제목이 "설정" 또는 "게임 메뉴"와 일치할 때 충족됩니다. 여기서 제목은 플레이어에게 보이는 제목이며, [화면 식별자](/screen-identifiers)가 아닙니다.

- 값: `options.title`과 같은 제목 텍스트 또는 현지화 키입니다. 값을 입력하는 창에는 편집 중인 화면의 두 값이 모두 표시되고, 현지화 키도 추천됩니다.
- 현지화 키는 모든 언어에서 작동합니다. 제목 텍스트는 정확히 일치해야 합니다.

## 실시간

이 요구 사항은 플레이어 컴퓨터의 시계를 확인합니다. 여러 값은 쉼표로 구분하며, 값 중 하나만 일치하면 됩니다.

### 실시간 날짜 확인

**식별자:** `fancymenu_visibility_requirement_is_realtime_day`

매월 특정 날짜에 충족됩니다.

- 값: `1`부터 `31`까지 입력합니다(예: `24,25,26`).

### 실시간 시 확인

**식별자:** `fancymenu_visibility_requirement_is_realtime_hour`

특정 시간에 충족됩니다.

- 값: 저녁을 나타내는 `20,21,22,23`처럼 `0`부터 `23`까지 입력합니다.

### 실시간 분 확인

**식별자:** `fancymenu_visibility_requirement_is_realtime_minute`

매시간 특정 분에 충족됩니다.

- 값: `0`부터 `59`까지 입력합니다.

### 실시간 월 확인

**식별자:** `fancymenu_visibility_requirement_is_realtime_month`

특정 월에 충족됩니다.

- 값: 1월은 `1`, 12월은 `12`입니다. 크리스마스에는 `12`를 사용합니다.

### 실시간 초 확인

**식별자:** `fancymenu_visibility_requirement_is_realtime_second`

매분 특정 초에 충족됩니다.

- 값: `0`부터 `59`까지 입력합니다.

### 실시간 요일 확인

**식별자:** `fancymenu_visibility_requirement_is_realtime_week_day`

특정 요일에 충족됩니다.

- 값: 일요일은 `1`, 토요일은 `7`입니다. 주말에는 `1,7`을 사용합니다.

### 실시간 연도 확인

**식별자:** `fancymenu_visibility_requirement_is_realtime_year`

특정 연도에 충족됩니다.

- 값: `2027`과 같이 연도를 모두 입력합니다.

## 시스템

### 파일/폴더 존재 여부 확인

**식별자:** `fancymenu_loading_requirement_file_exists`

파일이나 폴더가 존재할 때 충족됩니다.

- 값: `config/mymodpack/welcome_seen.txt`와 같은 게임 폴더 기준 경로입니다. `.minecraft/`로 시작하는 경로는 기본 `.minecraft` 폴더를 가리킵니다.

### 인터넷 연결 사용 가능 여부 확인

**식별자:** `is_internet_connection_available`

컴퓨터가 인터넷에 연결되어 있을 때 충족됩니다. FancyMenu는 백그라운드에서 가끔 연결 상태를 확인합니다.

### Linux 운영 체제 확인

**식별자:** `fancymenu_loading_requirement_is_os_linux`

Linux에서 충족됩니다. 엄밀히 말하면 Windows나 macOS가 아닌 모든 시스템에서 충족됩니다.

### macOS 운영 체제 확인

**식별자:** `fancymenu_loading_requirement_is_os_macos`

macOS에서 충족됩니다.

### Windows 운영 체제 확인

**식별자:** `fancymenu_loading_requirement_is_os_windows`

Windows에서 충족됩니다.

### 스케줄러 실행 여부 확인

**식별자:** `fancymenu_visibility_requirement_is_scheduler_running`

[스케줄러](/schedulers)가 실행 중일 때 충족됩니다.

- 값: `my_scheduler`와 같은 스케줄러 식별자입니다.

## 창

창 크기는 GUI 픽셀이 아니라 게임 창의 실제 픽셀 단위로 표시됩니다. 요구 사항 설명에 현재 크기가 표시됩니다.

### 전체 화면 여부 확인

**식별자:** `fancymenu_loading_requirement_is_fullscreen`

게임이 전체 화면일 때 충족됩니다.

### 창 높이 확인

**식별자:** `fancymenu_loading_requirement_is_window_height`

창 높이가 지정한 값과 일치할 때 충족됩니다.

- 값: `1080`과 같은 높이입니다. 여러 높이는 쉼표로 구분하며, 그중 하나만 일치하면 됩니다.

### 창 높이가 지정값보다 큰지 확인

**식별자:** `fancymenu_loading_requirement_is_window_height_bigger_than`

창 높이가 지정한 값보다 클 때 충족됩니다.

- 값: `1080`과 같은 높이입니다.

### 창 너비 확인

**식별자:** `fancymenu_loading_requirement_is_window_width`

창 너비가 지정한 값과 일치할 때 충족됩니다.

- 값: `1920`과 같은 너비입니다. 여러 너비는 쉼표로 구분하며, 그중 하나만 일치하면 됩니다.

### 창 너비가 지정값보다 큰지 확인

**식별자:** `fancymenu_loading_requirement_is_window_width_bigger_than`

창 너비가 지정한 값보다 클 때 충족됩니다.

- 값: `1920`과 같은 너비입니다.

## 월드

월드가 로드되지 않으면 이 요구 사항들은 충족되지 않습니다. **플레이어가 구조물 안에 있는지 확인**과 **활성 습격 지역에 있는지 확인**을 사용하려면 서버에 FancyMenu가 설치되어 있어야 합니다. 싱글플레이에서는 항상 작동합니다.

### 플레이어에게 흡수 하트가 있는지 확인

**식별자:** `has_player_absorption_hearts`

플레이어에게 황금색 흡수 하트가 있을 때 충족됩니다.

### 플레이어 권한 레벨 확인

**식별자:** `fancymenu_loading_requirement_has_player_permission_level`

플레이어가 월드나 서버에서 지정한 권한 레벨 이상(예: 관리자 권한)을 보유할 때 충족됩니다.

- 값: `0`부터 `4`까지 입력합니다. `0`은 항상 충족됩니다. `/gamemode`와 같은 명령어에는 `2`면 충분하고, `/op` 명령어는 `4` 레벨을 부여합니다.

### 모험 모드 확인

**식별자:** `fancymenu_visibility_requirement_is_adventure`

플레이어가 모험 모드일 때 충족됩니다.

### 효과 활성 여부 확인

**식별자:** `is_any_effect_active`

플레이어에게 신속이나 독과 같은 효과가 하나라도 있을 때 충족됩니다.

### 공격 강도가 약해졌는지 확인

**식별자:** `is_attack_strength_weakened`

플레이어의 공격이 완전히 충전되지 않았을 때 충족됩니다. 이때 공격 표시기가 나타납니다.

### 블록/아이템이 태그에 포함되는지 확인

**식별자:** `is_in_tag`

블록이나 아이템이 `minecraft:logs` 또는 `c:tools`와 같은 태그에 속할 때 충족됩니다. 태그는 월드가 로드된 동안에만 존재합니다.

- 값: **태그 유형**을 클릭해 **블록** 또는 **아이템**을 선택한 다음 **블록/아이템 키**와 **태그**를 입력합니다. 두 입력란 모두 값을 추천합니다. 태그 앞의 `#`은 생략해도 됩니다.
- 키는 `$$block_key`와 같은 리스너 변수와 함께 사용하면 편리합니다. 예를 들어 [**블록을 부쉈을 때**](/listeners#on-block-broke) 리스너 스크립트의 IF 문을 사용해 통나무를 부쉈을 때만 알림을 표시할 수 있습니다.

### 카메라 시점 확인

**식별자:** `is_camera_perspective`

카메라가 특정 시점(F5)에 있을 때 충족됩니다.

- 값: 버튼을 클릭해 **1인칭**, **3인칭** 또는 **정면**을 선택합니다.

### 맑은 날씨인지 확인

**식별자:** `is_clear_weather`

비나 천둥이 치지 않을 때 충족됩니다.

### 크리에이티브 모드 확인

**식별자:** `fancymenu_visibility_requirement_is_creative`

플레이어가 크리에이티브 모드일 때 충족됩니다.

### 커서가 인벤토리 아이템을 들고 있는지 확인

**식별자:** `is_cursor_holding_inventory_item`

인벤토리 화면에서 마우스 커서가 아이템을 들고 있을 때 충족됩니다.

### 난이도 확인

**식별자:** `is_difficulty`

월드의 난이도가 지정한 값과 일치할 때 충족됩니다.

- 값: `peaceful`, `easy`, `normal` 또는 `hard`입니다.

### 효과 활성 여부 확인

**식별자:** `is_effect_active`

플레이어에게 지정한 효과가 있을 때 충족됩니다.

- 값: `minecraft:speed`와 같은 효과 키입니다. 월드에 있는 동안 입력란에서 효과를 추천합니다.

### 주변에 엔티티가 있는지 확인

**식별자:** `is_entity_nearby`

지정한 유형의 엔티티가 플레이어 근처에 있을 때 충족됩니다.

- 값: `minecraft:creeper`와 같은 **엔티티 레지스트리 키**와 `10`과 같은 **확인 반경(블록)**입니다. 월드에 있는 동안 키 입력란에서 엔티티를 추천합니다.

### 게임 모드 확인

**식별자:** `is_gamemode`

플레이어가 지정한 게임 모드일 때 충족됩니다.

- 값: `survival`, `creative`, `adventure` 또는 `spectator`입니다.

### 하드코어 모드 확인

**식별자:** `is_hardcore`

하드코어 월드에서 충족됩니다.

### 선택된 핫바 슬롯 확인

**식별자:** `is_hotbar_slot_active`

지정한 핫바 슬롯을 선택했을 때 충족됩니다.

- 값: 가장 왼쪽 슬롯은 `0`이며, 나머지는 `8`까지입니다.

### 활성 습격 지역에 있는지 확인

**식별자:** `is_in_active_raid_area`

습격 막대가 표시되는 습격 지역에 플레이어가 있을 때 충족됩니다. 서버에 FancyMenu가 설치되어 있어야 합니다.

### 인벤토리 슬롯이 채워져 있는지 확인

**식별자:** `is_inventory_slot_filled`

플레이어 인벤토리의 슬롯에 아이템이 있을 때 충족됩니다.

- 값: 슬롯 번호입니다. `0`부터 `8`까지는 핫바이며, `9`부터 `35`까지는 나머지 인벤토리입니다.

### 인벤토리에서 아이템 위에 마우스가 있는지 확인

**식별자:** `is_item_hovered_in_inventory`

플레이어 인벤토리나 상자처럼 인벤토리 화면의 아이템 위에 마우스가 있을 때 충족됩니다.

### 멀티플레이 여부 확인

**식별자:** `fancymenu_loading_requirement_is_multiplayer`

플레이어가 서버에 접속 중일 때 충족됩니다.

### 플레이어가 크리에이티브 비행 중인지 확인

**식별자:** `is_player_creative_flying`

플레이어가 크리에이티브 모드에서 날고 있을 때 충족됩니다.

### 플레이어가 겉날개로 비행 중인지 확인

**식별자:** `is_player_flying_with_elytra`

플레이어가 겉날개로 활강 중일 때 충족됩니다.

### 플레이어가 완전히 얼었는지 확인

**식별자:** `is_player_fully_frozen`

플레이어가 가루눈에 완전히 얼어 체력 막대에 얼어붙은 하트가 표시될 때 충족됩니다.

### 플레이어가 특정 생물 군계에 있는지 확인

**식별자:** `is_player_in_biome`

플레이어가 지정한 생물 군계에 있을 때 충족됩니다.

- 값: `minecraft:birch_forest`와 같은 생물 군계 키입니다. 월드에 있는 동안 입력란에서 생물 군계를 추천합니다.

### 플레이어가 특정 차원에 있는지 확인

**식별자:** `is_player_in_dimension`

플레이어가 지정한 차원에 있을 때 충족됩니다.

- 값: 차원 키입니다. `minecraft:overworld`, `minecraft:the_nether`, `minecraft:the_end` 또는 모드에서 추가한 차원 키를 입력합니다. 월드에 있는 동안 입력란에서 차원을 추천합니다.

### 플레이어가 유체 안에 있는지 확인

**식별자:** `is_player_in_fluid`

플레이어가 물이나 용암과 같은 유체 안에 있을 때 충족됩니다.

### 플레이어가 용암에 있는지 확인

**식별자:** `is_player_in_lava`

## 기타

### 게임 언어 확인

**식별자:** `fancymenu_loading_requirement_is_language`

Minecraft에서 지정한 언어를 사용 중일 때 충족됩니다.

- 값: `en_us` 또는 `de_de`와 같은 언어 코드입니다. 입력란에서 모든 언어를 추천합니다.

### 모드 로드 여부 확인

**식별자:** `fancymenu_loading_requirement_is_mod_loaded`

지정한 모드가 설치되어 있을 때 충족됩니다.

- 값: `jei`와 같은 모드 ID입니다. 입력란에서 설치된 모드의 ID를 추천합니다. 여러 ID는 쉼표로 구분하며, 모두 설치되어 있어야 합니다. `optifine`은 OptiFine 설치 여부를 확인합니다.

### 숫자 확인

**식별자:** `fancymenu_visibility_requirement_is_number`

두 숫자를 비교합니다. 입력란에 `$$coins`와 같은 자리 표시자나 변수를 입력할 수 있습니다.

- **비교 모드**: **같음**, **보다 큼**, **보다 작음**, **크거나 같음**, **작거나 같음** 중에서 선택합니다.
- **숫자**: `$$coins`와 같이 확인할 숫자를 입력합니다.
- **비교할 숫자**: `100`과 같이 비교 대상 숫자를 입력합니다.

`2.5`와 같은 소수를 사용할 수 있습니다. 입력란의 값이 숫자가 아니면 요구 사항은 충족되지 않습니다.

### 리소스 팩 활성 여부 확인

**식별자:** `is_resource_pack_enabled`

리소스 팩이 활성화되어 있을 때 충족됩니다.

- 값: 리소스 팩 화면에 표시되는 `Programmer Art`와 같은 팩 이름 또는 팩 ID입니다. 대소문자는 구분하지 않습니다.

### Rinku 로드 여부 확인

**식별자:** `is_rinku_loaded`

[Rinku](https://modrinth.com/mod/rinku) 모드가 설치되어 있을 때 충족됩니다. [브라우저 요소](/elements#browser)와 기존의 [Rinku 기반 동영상 유형](/video#requirements)에 필요합니다.

### 서버 IP 확인

**식별자:** `fancymenu_visibility_requirement_is_server_ip`

플레이어가 지정한 서버에 접속 중일 때 충족됩니다.

- 값: `play.example.net`과 같은 서버 주소입니다. `play.example.net:25566`처럼 포트를 입력하면 포트도 일치해야 합니다.

### 서버 온라인 여부 확인

**식별자:** `fancymenu_loading_requirement_is_server_online`

서버가 온라인일 때 충족됩니다. FancyMenu는 백그라운드에서 약 30초마다 서버에 핑을 보내므로 게임을 시작한 직후에는 확인에 시간이 걸릴 수 있습니다.

- 값: `play.example.net`과 같은 서버 주소입니다.

### 텍스트 확인

**식별자:** `fancymenu_visibility_requirement_is_text`

두 텍스트를 비교합니다. 입력란에 `$$key_name`과 같은 자리 표시자나 변수를 입력할 수 있습니다.

- **비교 모드**: **같음**, **포함**, **시작 부분 일치**, **끝 부분 일치** 중에서 선택합니다.
- **텍스트**: 확인할 텍스트를 입력합니다.
- **비교할 텍스트**: 비교할 대상 텍스트를 입력합니다.

대소문자를 구분합니다.

### 변수 값 확인(FM 변수)

**식별자:** `fancymenu_visibility_requirement_is_variable_value`

[변수](/variables)의 값이 지정한 값과 일치할 때 충족됩니다.

- **변수 이름**: `$$`를 제외한 변수 이름입니다. 입력란에서 변수를 추천합니다.
- **확인할 변수 값**: `on`과 같은 값입니다. 대소문자를 구분하며 전체 값이 일치해야 합니다.

변수가 없으면 충족되지 않습니다. 목록 변수의 경우 `[\"apple\",\"banana\"]`처럼 모든 항목이 들어 있는 JSON 배열과 비교합니다. 목록의 항목 하나를 확인하려면 **목록에 항목 포함(FM 변수)**을 사용하세요.

### 목록에 항목 포함(FM 변수)

**식별자:** `list_contains_entry`

[목록 변수](/variables#text-and-list-variables)에 지정한 항목이 있을 때 충족됩니다.

- **목록 변수 이름**: `$$`를 제외한 목록 이름입니다. 입력란에서 목록 변수를 추천하며, 텍스트 변수 이름을 입력하면 경고합니다.
- **찾을 항목**: 확인할 항목입니다. 항목의 일부가 아니라 전체가 일치해야 합니다.
- **대소문자 무시**: 켜면 `Apple`로 `apple`도 일치하는 것으로 처리합니다.

목록이 없으면 충족되지 않습니다.

### 마우스 버튼을 눌렀는지 확인

**식별자:** `mouse_click`

마우스 버튼을 누르고 있는 동안 충족됩니다. 클릭할 때마다 작업을 한 번만 실행하려면 대신 [**마우스 버튼을 클릭했을 때**](/listeners#on-mouse-button-clicked) 리스너를 사용하세요.

- 값: `left` 또는 `right`입니다.

### 세션당 한 번만

**식별자:** `once_per_session`

처음 확인할 때 충족된 뒤, 게임을 다시 시작할 때까지 다시는 충족되지 않습니다. 각각의 복사본은 별도로 취급됩니다.

게임 세션당 한 번만 표시할 요소라면 요소의 [**세션당 한 번만 로드**](/element-visibility#load-once-per-session) 옵션을 사용하는 편이 더 간단합니다. 이 옵션을 사용하면 새 화면이 열릴 때까지 요소가 표시된 상태로 유지됩니다.
