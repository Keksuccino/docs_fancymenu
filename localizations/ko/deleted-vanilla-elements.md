# Vanilla 요소 삭제하기

레이아웃 편집기에서 보이는 모든 기본/Vanilla 요소(일부 모드 요소 포함)를 숨길 수 있습니다. 요소가 보인다면, 해당 요소를 **마우스 오른쪽 버튼으로 클릭**한 다음 **Delete**를 클릭하세요.


# 삭제된 Vanilla 요소 다시 표시하기

버튼, 로고 또는 다른 유형의 삭제/숨김 상태인 Vanilla 요소를 다시 보이게 하려면, 해당 요소를 삭제했던 레이아웃을 연 다음 **메뉴 바 -> Element -> Deleted Vanilla Elements**로 이동하여 다시 보이게 할 요소를 **왼쪽 클릭**하세요.

삭제된 요소가 메뉴에 표시되지 않는다면, 올바른 레이아웃이 열려 있지 않은 것이므로 삭제했던 레이아웃을 찾아야 합니다.
