# Element Animator

**Animator**는 다른 요소를 애니메이션할 수 있게 해주는 요소입니다. 이 요소를 사용하면 키프레임을 통해 다른 요소의 크기, 위치, 앵커 포인트를 시간에 따라 부드럽게 변경할 수 있습니다. 키프레임은 특정 시점에 요소가 어떻게 보여야 하는지를 담아두는 스냅샷과 같습니다. 그런 다음 Animator 요소가 이 스냅샷들을 순서대로 재생하여 부드러운 움직임을 만듭니다.

> **Element Animator**는 요소의 **위치, 크기, 앵커 포인트**를 제어할 수 있게 해줍니다. 투명도, 표시 여부, 회전 등 요소의 다른 설정은 **제어할 수 없습니다**!

# Animator 요소 추가하기

1. **배경을 우클릭합니다:**  
   레이아웃 편집기에서 배경을 마우스 오른쪽 버튼으로 클릭합니다.

2. **새 요소 -> Element Animator 선택:**  
   나타나는 메뉴에서 **New Element**로 이동한 뒤 **Element Animator**를 클릭합니다. 그러면 Animator 요소가 레이아웃에 추가됩니다.

3. **설정하기:**  
   추가하면 Animator 요소가 기본 설정으로 표시됩니다. Animator를 우클릭한 다음 메뉴에서 선택하여 반복 재생이나 색상 같은 옵션을 변경할 수 있습니다.

# 키프레임 관리하기

키프레임은 특정 시점에 Animator가 요소를 어떻게 보여야 하는지 알려주는 북마크와 같습니다.

## 키프레임 편집기 열기

- **편집기 열기:**  
   Animator 요소를 우클릭하고 **Edit Keyframes**(또는 **Manage Keyframes**)를 선택합니다. 그러면 키프레임을 추가, 수정, 삭제할 수 있는 화면이 열립니다.

## 녹화 및 키프레임 추가하기

- **녹화 시작:**  
   키프레임 편집기에서 **`R` 키**를 눌러 녹화를 시작합니다. 녹화 중에는 미리보기 상자의 색이 바뀌어 활성 상태임을 보여줍니다.
  
- **미리보기 변경:**  
   원하는 모양이 되도록 미리보기 상자를 이동하거나 크기를 조절합니다. 오프셋 모드에서는 미리보기가 십자선 중심에 유지되며, 변경 사항이 오프셋으로 표시됩니다.
  
- **키프레임 추가:**  
   **`K` 키**를 눌러 현재 상태를 키프레임으로 저장합니다. 이 키프레임은 미리보기의 위치, 크기, 앵커 설정을 저장합니다.

## 키프레임 편집하기

- **키프레임 선택:**  
   타임라인에서 키프레임 마커를 클릭합니다. **Ctrl**을 누른 채 클릭하면 여러 개를 선택할 수도 있습니다.
  
- **키프레임 이동:**  
   키프레임 마커를 왼쪽이나 오른쪽으로 드래그하여 시간을 변경합니다. 또는 다음 단축키를 사용할 수 있습니다.
  - **왼쪽 화살표:** 100ms 더 앞당깁니다.
  - **오른쪽 화살표:** 100ms 더 늦춥니다.
  
- **미리보기 세부 조정:**  
   키프레임이 선택되어 있을 때 미리보기 상자를 이동하거나 크기를 조절하여 조정합니다. 필요하면 **Ctrl + Z**로 실행 취소하고 **Ctrl + Y**로 다시 실행할 수 있습니다.

## 키프레임 삭제하기

- **키프레임 삭제:**  
   키프레임을 선택한 뒤 **Delete 키**를 눌러 삭제합니다.
  
- **여러 키프레임 삭제:**  
   여러 키프레임을 선택한 다음(예: **Ctrl + A**로 전체 선택) Delete를 눌러 한 번에 삭제할 수 있습니다.

## 키프레임 스무딩

키프레임 스무딩은 키프레임 간 간격을 고르게 맞춰주는 기능입니다. 이를 통해 애니메이션이 더 일정하고 부드럽게 보이게 됩니다.

- **여러 키프레임 선택:**  
   먼저 스무딩하려는 키프레임 두 개 이상을 선택합니다(**Ctrl + 클릭** 또는 **Ctrl + A** 사용).

- **스무딩 버튼 클릭:**  
   키프레임 편집기 하단 툴바에서 **Distance Smoothing** 버튼을 클릭합니다.

- **새 간격 입력:**  
   작은 입력 상자가 나타납니다. 선택한 각 키프레임 사이의 동일한 시간 간격을 설정하려면 값(밀리초)을 입력합니다.

- **스무딩 적용:**  
   Enter를 눌러 스무딩을 적용합니다. 그러면 키프레임 사이의 시간 차이가 고르게 조정됩니다.

# 애니메이션 미리보기

키프레임을 기록한 후에는 애니메이션이 어떻게 보이는지 확인할 수 있습니다.

- **애니메이션 재생:**  
   키프레임 편집기에서 **`P` 키**를 누르거나 재생 버튼을 클릭합니다. 미리보기가 처음부터 시작되어 시간이 지나며 미리보기 상자가 어떻게 변하는지 보여줍니다.
  
- **반복 재생 참고:**  
   키프레임 편집기에서 미리보기를 할 때는 애니메이션이 **반복 재생되지 않습니다**. 즉, 처음부터 끝까지 한 번만 재생됩니다. 반복 재생은 최종 레이아웃에서 Animator 요소를 대상 요소에 적용할 때만 활성화됩니다.
  
- **미리보기 일시 정지:**  
   특정 지점에서 멈추고 싶다면 **`P` 키**를 다시 눌러 애니메이션을 일시 정지합니다.
  
- **진행 막대 드래그:**  
   가능하다면 타임라인 마커를 드래그하여 원하는 시점의 애니메이션 모습을 확인할 수 있습니다.

# 대상 요소 선택하기

키프레임을 설정한 후에는 어떤 레이아웃 요소를 애니메이션할지 선택해야 합니다.

1. **대상 관리자 열기:**  
   Animator 요소를 우클릭하고 **Manage Targets**를 선택합니다.
  
2. **대상 추가:**  
   **Add Target**을 클릭하면 사용 가능한 요소 목록이 나타납니다. 애니메이션할 요소를 선택합니다.
  
3. **대상 제거:**  
   대상을 제거하려면 관리자를 열고 **Remove Target**을 클릭합니다.

최종 레이아웃에서 애니메이션이 재생되면, Animator는 키프레임을 사용해 선택한 요소의 크기, 위치 등을 변경합니다. 설정해 두었다면 여기서 반복 재생도 적용됩니다.

# 키보드 단축키

키프레임 편집기에서 다음 단축키를 사용하면 더 빠르게 작업할 수 있습니다.

- **`R` 키:** 녹화를 시작하거나 중지합니다.
- **`T` 키:** 녹화를 일시 정지하거나 다시 시작합니다.
- **`P` 키:** 애니메이션 미리보기를 재생하거나 일시 정지합니다.
- **`K` 키:** 현재 시간에 새 키프레임을 추가합니다.
- **왼쪽/오른쪽 화살표 키:**  
  - **왼쪽 화살표:** 키프레임을 100ms 더 앞당깁니다.
  - **오른쪽 화살표:** 키프레임을 100ms 더 늦춥니다.
- **Delete 키:** 선택한 키프레임을 삭제합니다.
- **Ctrl + A:** 모든 키프레임을 선택합니다.
- **Ctrl + Z:** 마지막 변경 사항을 실행 취소합니다.
- **Ctrl + Y:** 방금 실행 취소한 작업을 다시 실행합니다.
- **Ctrl + 키프레임 드래그**: 여러 선택된 키프레임을 한 번에 드래그합니다.

# 추가 설정 및 팁

- **애니메이션 반복:**  
   Animator를 반복 재생하도록 설정할 수 있습니다. 반복이 켜져 있으면 마지막 키프레임 이후 애니메이션이 다시 시작됩니다. 다만 이는 최종 대상 요소에만 적용됩니다. 키프레임 편집기 미리보기에서는 반복되지 않습니다.
  
- **크기/위치 무시:**  
   키프레임이 요소의 크기나 위치를 변경하지 않게 하려면 이 옵션을 끕니다.

- **타이밍 오프셋:**
   FancyMenu 3.9.0은 제어되는 요소에 타이밍 오프셋을 추가합니다. 개별 대상 요소에 오프셋을 적용하거나, 설정된 범위 내에서 랜덤 타이밍 오프셋을 사용할 수 있어 하나의 애니메이션이 각 대상마다 약간 다른 시간에 시작되도록 할 수 있습니다.
  
- **오프셋 모드:**  
   오프셋 모드에서는 애니메이션이 요소의 원래 위치에서의 변화로 적용됩니다. 미리보기는 십자선 중심에 표시됩니다.
  
- **실행 취소 및 다시 실행:**  
   **Ctrl + Z**로 실행 취소하고 **Ctrl + Y**로 변경 사항을 다시 실행합니다.
  
- **순서 확인:**  
   키프레임이 시간 순서대로 올바르게 배치되어 있는지 확인하세요. 시스템이 자동으로 정렬하지만, 하나를 이동했다면 순서를 다시 확인하는 것이 좋습니다.
  
- **미리보기 확인:**  
   저장하기 전에 재생 버튼이나 **`P` 키**를 사용해 애니메이션을 미리 확인하세요.

# 마무리

이 간단한 단계를 따르면 레이아웃에 Animator 요소를 추가하고 부드러운 애니메이션을 만들 수 있습니다. 미리보기로 실시간 변경 사항을 기록하든, 키보드로 키프레임을 조정하든, 어떤 요소를 애니메이션할지 선택하든, 또는 애니메이션 미리보기로 결과를 확인하든, Animator 요소는 사용자 지정 메뉴에 생동감을 더하는 쉬운 방법을 제공합니다.

즐거운 애니메이션 제작 되세요!
