# 전역 사용자 지정

전역 사용자 지정을 사용하면 버튼, 슬라이더, 메뉴 배경, 음악, 게임 창 등을 모든 화면에서 한 번에 변경할 수 있습니다. 레이아웃이 필요 없으며, 사용자 지정이 꺼져 있는 화면에서도 작동합니다.

레이아웃 편집기 밖의 화면에서 **메뉴 표시줄 -> 사용자 지정 -> 전역 사용자 지정**을 열면 됩니다. 변경 사항은 즉시 적용되고 자동으로 저장됩니다.

> [!TIP]
> 일부 화면만 변경하려면 [레이아웃](/layout-editor)을 사용하세요. 특정 레이아웃의 버튼에 고유한 모양을 적용하려면 [버튼 및 슬라이더 템플릿](/button-slider-templates)을 사용하세요.

# 버튼 및 슬라이더

이 설정은 다른 모드의 버튼과 슬라이더를 포함해 모든 화면의 버튼과 슬라이더를 변경합니다.

- [레이아웃](/layout-editor) 또는 [템플릿](/button-slider-templates)에서 자체 텍스처나 레이블 설정을 적용한 버튼과 슬라이더는 해당 설정을 유지합니다.
- 레시피 북 버튼처럼 이미지로만 이루어진 버튼은 모양이 바뀌지 않습니다.

## 버튼 텍스처

**사용자 지정 버튼 텍스처**에서는 버튼 상태별로 텍스처를 하나씩 설정할 수 있습니다.

- **기본**
- **마우스 오버**: 버튼 위에 마우스를 올렸거나 키보드로 버튼을 선택했을 때 표시됩니다.
- **비활성**: 버튼을 클릭할 수 없을 때 표시됩니다.

세 가지 상태를 모두 설정하세요. 상태에 텍스처를 지정하지 않으면 Minecraft 기본 버튼이 표시됩니다.

같은 메뉴에 있는 추가 설정:

- **배경 투명하게**를 켜면 모든 버튼의 배경이 숨겨지고 레이블만 표시됩니다. 이 설정은 텍스처보다 우선 적용됩니다.
- **나인 슬라이스 버튼 배경**을 켜면 아래의 네 가지 테두리 크기를 기준으로 버튼 크기가 달라져도 텍스처 가장자리가 선명하게 유지됩니다. 자세한 내용은 [나인 슬라이싱 및 타일링](/nine-slicing-and-tiling)을 참조하세요.

> [!TIP]
> 나인 슬라이싱을 사용하지 않으면 버튼 크기에 맞춰 텍스처가 늘어납니다. Minecraft 버튼의 높이는 20픽셀이며 너비는 대부분 200픽셀 또는 150픽셀입니다. 나인 슬라이싱을 사용하면 작은 텍스처 하나로 모든 버튼에 맞출 수 있습니다.

## 슬라이더 텍스처

**사용자 지정 슬라이더 텍스처**에는 두 가지 부분이 있습니다.

- **슬라이더 배경 텍스처**: 슬라이더의 막대입니다. **텍스처 설정**을 사용해 지정하세요. **배경 투명하게**와 **슬라이더 배경 나인 슬라이스**는 버튼의 해당 설정과 같은 방식으로 작동합니다.
- **슬라이더 손잡이 텍스처**: 드래그하는 부분입니다. **기본**, **마우스 오버**, **비활성** 텍스처와 **슬라이더 손잡이 나인 슬라이스**를 설정할 수 있습니다.

Minecraft 슬라이더 손잡이의 너비는 8픽셀이며 높이는 슬라이더와 같습니다. 대부분 20픽셀입니다. 나인 슬라이싱을 사용하지 않으면 손잡이 텍스처가 이 크기에 맞춰 늘어납니다.

## 레이블

**버튼 레이블**과 **슬라이더 레이블**에는 같은 설정이 있습니다.

| 설정 | 설명 |
|---|---|
| **마우스 오버 시 레이블에 밑줄 표시** | 레이블 위에 마우스를 올리면 밑줄을 표시합니다. |
| **레이블 기본 색상** | 레이블 색상입니다. 색상 선택기를 사용하거나 `#FFF1D6` 같은 HEX 코드를 입력하세요. |
| **레이블 마우스 오버 색상** | 레이블 위에 마우스를 올렸을 때의 색상입니다. |
| **레이블 크기** | 레이블 크기입니다. `1`은 기본 크기입니다. |
| **레이블 정렬** | **왼쪽**, **가운데** 또는 **오른쪽**으로 정렬합니다. |
| **레이블 그림자** | 레이블 뒤에 어두운 그림자를 표시합니다. 이 설정을 끄면 레이아웃의 레이블을 포함해 모든 레이블의 그림자가 사라집니다. |

레이아웃이나 템플릿에서 자체 설정을 지정한 레이블은 해당 설정을 유지합니다. **레이블 크기**와 **레이블 정렬**의 경우, 기본 크기이면서 **가운데** 정렬된 레이블에만 전역 설정이 적용됩니다.

## 클릭 소리

- **사용자 지정 버튼 클릭 소리**는 버튼과 슬라이더의 Minecraft 클릭 소리를 대체합니다. 레이아웃에서 자체 클릭 소리를 지정한 버튼은 해당 소리를 유지합니다.
- **사용자 지정 버튼 클릭 소리 음량**은 0%부터 100%까지 설정할 수 있습니다. Minecraft 소리 설정에서 해당 소리 채널의 음량 슬라이더를 조정하면 이 설정에 추가로 적용됩니다.
- **사용자 지정 버튼 클릭 소리 채널**은 클릭 소리가 재생되는 소리 채널입니다. 예를 들어 음악 채널을 선택할 수 있습니다. 기본값은 모든 소리가 재생되는 마스터 음량입니다.

# 메뉴 배경

**사용자 지정 메뉴 배경 텍스처**는 타이틀 화면을 제외한 모든 메뉴 뒤에 표시되는 이미지입니다.

- 게임을 플레이하는 동안 일시 정지 메뉴와 옵션 화면 뒤에도 표시되어 그곳의 게임 월드를 가립니다. 인벤토리, 표지판, 책은 계속 투명하게 표시됩니다.
- **배경 텍스처 종횡비 유지**를 켜면 이미지의 비율이 유지됩니다. 화면 전체를 채우며, 화면에 맞지 않는 부분은 잘립니다. 끄면 이미지가 화면 크기에 맞춰 늘어납니다.

**사용자 지정 메뉴 배경 파노라마**는 타이틀 화면과 월드에 접속하기 전의 모든 메뉴에서 Minecraft 파노라마를 대체합니다.

- **파노라마 선택**을 사용해 [파노라마](/panoramas) 중 하나를 선택합니다.
- **파노라마 지우기**를 누르면 Minecraft 파노라마가 다시 표시됩니다.
- **현재 파노라마**에 설정된 파노라마가 표시됩니다.

두 설정을 모두 적용하면 텍스처가 파노라마를 덮으므로 타이틀 화면에서만 파노라마가 표시됩니다.

레이아웃에 자체 [메뉴 배경](/menu-backgrounds)이 설정된 화면에는 해당 배경이 표시됩니다.

# 메뉴 음악

- **바닐라 메뉴 음악 재생**을 사용하면 메뉴에서 Minecraft 음악을 켜거나 끌 수 있습니다.
- **사용자 지정 메뉴 음악 트랙**을 누르면 **메뉴 음악 트랙 관리**가 열립니다. **트랙 추가**는 소리를 추가하고, **트랙 제거**는 선택한 트랙을 삭제하며, **트랙 모두 지우기**는 모든 트랙을 삭제하고, **완료**는 목록을 저장합니다.

트랙은 월드에 접속하기 전 메뉴에서 Minecraft 메뉴 음악 대신 무작위 순서로 재생됩니다. 트랙과 개별 화면의 음악에 대한 자세한 내용은 [메뉴 배경 음악](/background-music)을 참조하세요.

# 화면 및 팝업

| 설정 | 설명 |
|---|---|
| [**게임 인트로**](/game-intro) | 타이틀 화면이 표시되기 전에 애니메이션이나 동영상을 재생합니다. |
| **싱글플레이 화면 월드 아이콘** | 월드 목록에 표시되는 월드 아이콘입니다. 끄면 아이콘이 숨겨집니다. |
| **멀티플레이 화면 서버 아이콘** | 서버 목록에 표시되는 서버 아이콘입니다. 끄면 아이콘이 숨겨집니다. |
| [**매끄러운 월드 로딩**](/seamless-world-loading) | 월드나 서버에서 나갈 때 스크린샷을 찍고, 다시 접속할 때 로딩 배경으로 표시합니다. |
| **도전 과제 알림** | 도전 과제를 달성했을 때 오른쪽 위에 표시되는 팝업과 알림 소리입니다. 끄면 숨겨집니다. 채팅의 도전 과제 메시지는 계속 표시되며, [도전 과제 달성 시](/listeners#on-achievement-unlocked) 리스너도 계속 작동합니다. |

# 창 및 게임 시작

| 설정 | 설명 |
|---|---|
| [**사용자 지정 창 아이콘**](/window-customization#custom-icon) | 게임 창의 아이콘입니다. 16x16 및 32x32 PNG 아이콘과 macOS 아이콘이 필요합니다. |
| [**사용자 지정 창 제목**](/window-customization#custom-title) | Minecraft 창 제목을 대체합니다. [플레이스홀더](/placeholders)를 사용할 수 있으며, 값이 바뀌면 제목이 업데이트됩니다. |
| **기본 GUI 크기** | `2` 또는 `3`처럼 게임 인스턴스를 처음 시작할 때 Minecraft GUI 크기를 한 번 설정합니다. `-1`은 기능을 끕니다. 모드팩용 기능입니다. |
| **시작 시 전체 화면 강제 적용** | 게임을 시작할 때마다 전체 화면으로 전환합니다. |

FancyMenu는 `fancymenu_data/default_scale_set.fm`에 **기본 GUI 크기**를 설정했는지 기록합니다. 이 파일을 삭제하면 다음 시작 시 크기를 다시 설정합니다([데이터 저장 위치](/data-storage-locations#instance-data) 참조).

# 알아두면 좋은 점

- 전역 사용자 지정은 FancyMenu의 `options.txt`에 저장되므로 불러온 [프로필](/profiles)에 적용되며, `config/fancymenu/`를 포함하는 모드팩에도 함께 포함됩니다.
- 텍스처와 소리는 인스턴스 파일, 웹 링크 또는 리소스 팩 파일을 사용할 수 있습니다. [리소스](/resources)를 참조하세요.
- [AI 채팅](/export-for-ai)에 질문할 때 **메뉴 표시줄 -> 도움말 -> AI용 내보내기 -> FancyMenu 설정**을 사용하면 전역 사용자 지정도 내보내기에 포함됩니다.
