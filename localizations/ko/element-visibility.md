# 요소 표시 여부

요소를 항상 표시할 필요는 없습니다. 특정 상황에서만 표시하거나, 잠시 후에 나타나게 하거나, 서서히 나타나고 사라지게 하거나, 버튼으로 켜고 끌 수 있습니다.

<img width="800" alt="화면이 열린 뒤 몇 초 후 환영 문구가 서서히 나타나고, 서버 규칙 버튼을 누르면 규칙 패널이 서서히 나타나거나 사라집니다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/element_visibility_toggle.gif?raw=true">

레이아웃 편집기에서는 편집할 수 있도록 요소가 항상 표시됩니다. 이 페이지의 모든 기능은 편집기 밖에서 작동합니다.

> [!TIP]
> 모든 요구 사항은 [요구 사항](/conditions)에 나와 있습니다.

# 특정 상황에서만 요소 표시하기

요소를 마우스 오른쪽 버튼으로 클릭하고 **로딩 요구 사항**을 클릭하세요. “마우스가 이 버튼 위에 있음”, “12월임”, “변수 값이 특정 값임”과 같은 [요구 사항](/conditions)이 모두 충족될 때만 요소가 표시됩니다. FancyMenu는 요구 사항을 계속 확인하므로 요소가 즉시 나타나거나 숨겨집니다.

- **요구 사항 모드**의 반대 설정은 요구 사항을 뒤집습니다. 예를 들어 “12월이 아님”으로 바꿀 수 있습니다.
- 그룹을 사용하면 “이것 또는 저것” 조건을 만들 수 있습니다.
- 바닐라 요소에도 **로딩 요구 사항**이 있습니다. 요소를 완전히 제거하려면 [바닐라 요소 삭제](/deleted-vanilla-elements)를 참고하세요.

요구 사항을 추가하고 조합하는 방법은 [요구 사항](/conditions#adding-a-requirement)을 참고하세요.

## 세션당 한 번만 로드하기

요소를 마우스 오른쪽 버튼으로 클릭하고 **세션당 한 번만 로드**를 켜세요. 요소는 해당 화면이 처음 열릴 때 표시됩니다. 플레이어가 다른 화면으로 이동하면 게임을 다시 시작할 때까지 숨겨진 상태로 유지됩니다.

“F1을 눌러 조작법 보기”처럼 게임을 시작할 때 한 번만 표시할 안내에 유용합니다. 액션 스크립트에서 같은 기능을 사용하려면 [**세션당 한 번만**](/conditions#only-once-per-session) 요구 사항을 사용하세요.

# 요소 표시 지연하기

## 표시 지연

요소를 마우스 오른쪽 버튼으로 클릭하고 **표시 지연**을 클릭하세요.

- **지연**:
  - **지연 없음**: 즉시 표시됩니다.
  - **처음 한 번**: 게임을 시작한 뒤 요소가 처음 표시될 때만 기다립니다.
  - **매번**: 화면이 열릴 때마다, 그리고 요구 사항이 다시 충족될 때마다 기다립니다.
- **지연 시간(초)**: 기다릴 시간입니다. 예를 들어 `1.5`로 설정할 수 있습니다.

창 크기를 조정해도 지연 시간이 다시 시작되지는 않습니다.

## 사라짐 지연

요소를 마우스 오른쪽 버튼으로 클릭하고 **사라짐 지연**을 클릭하세요. 요구 사항이 더 이상 충족되지 않으면 요소가 사라지기 전에 **지연 시간(초)**만큼 더 표시됩니다. **지연** 옵션은 위와 같습니다.

예를 들어 버튼에 [**요소 위에 마우스가 있음**](/conditions#is-element-hovered) 요구 사항이 설정된 정보 상자는 마우스가 버튼을 벗어난 뒤에도 1초 동안 표시됩니다.

# 페이드 인 및 페이드 아웃

요소를 마우스 오른쪽 버튼으로 클릭하고 **페이드 인/아웃**을 클릭하세요.

- **페이드 인** 및 **페이드 아웃**:
  - **페이드 없음**: 즉시 표시되거나 숨겨집니다.
  - **처음 한 번만**: 게임을 시작한 뒤 처음 한 번만 페이드 효과가 적용됩니다.
  - **매번**: 매번 페이드 효과가 적용됩니다.
- **페이드 인 속도** 및 **페이드 아웃 속도**: `1`이면 페이드에 2.5초가 걸립니다. `2`는 두 배 빠릅니다.

화면이 열릴 때와 요구 사항이 충족될 때 요소가 페이드 인됩니다. **표시 지연**을 설정하면 지연이 끝난 뒤 페이드가 시작됩니다.

페이드 아웃은 요구 사항으로 요소를 숨길 때만 적용되며, 화면을 닫을 때는 적용되지 않습니다.

# 불투명도

요소를 마우스 오른쪽 버튼으로 클릭하고 **불투명도**를 클릭하세요. `1.0`은 완전히 표시, `0.5`는 반투명, `0.0`은 보이지 않는 상태입니다. 대부분의 요소에서 설정할 수 있습니다.

불투명도에는 `$$panel_opacity`와 같은 [자리표시자](/placeholders)와 [변수](/variables)를 사용할 수 있습니다. 페이드 인은 요소의 불투명도에 도달하면 멈춥니다.

# 버튼으로 요소 표시 여부 전환하기

버튼으로 위 GIF의 규칙 패널처럼 요소를 표시하거나 숨길 수 있습니다. 패널 표시 여부는 [변수](/variables)에 저장됩니다.

1. 패널을 마우스 오른쪽 버튼으로 클릭하고 **로딩 요구 사항**을 클릭하세요. 변수 `show_rules`와 값 `true`를 사용해 [**변수 값임(FM 변수)**](/conditions#is-variable-value-fm-variable)을 추가하세요.
2. 버튼을 마우스 오른쪽 버튼으로 클릭하고 **액션 스크립트 편집**을 클릭하세요.
3. 스크립트 영역을 마우스 오른쪽 버튼으로 클릭하고 **IF 문 추가**를 클릭하세요. 패널과 동일한 요구 사항을 설정하세요.
4. IF 안에 [**변수 값 설정(FM 변수)**](/action-scripts#set-variable-value-fm-variable)을 추가하고 다음 값을 입력하세요.

   ```
   show_rules:false
   ```

5. IF를 마우스 오른쪽 버튼으로 클릭하고 **ELSE 문 추가**를 클릭하세요. ELSE 안에 **변수 값 설정(FM 변수)**을 추가하고 다음 값을 입력하세요.

   ```
   show_rules:true
   ```

이제 클릭할 때마다 변수가 전환됩니다. 표시된 패널은 숨겨지고, 숨겨진 패널은 표시됩니다. 같은 요구 사항을 사용하는 모든 요소가 함께 나타나고 숨겨집니다. 부드러운 전환을 원한다면 패널의 **페이드 인**과 **페이드 아웃**을 **매번**으로 설정하세요.

IF와 ELSE에 관한 자세한 내용은 [액션 스크립트](/action-scripts#if-else-if-and-else)를 참고하세요.

> [!NOTE]
> 변수는 게임을 종료한 뒤에도 유지되므로 다음에 게임을 시작할 때 패널이 계속 열려 있습니다. 매번 시작할 때 패널을 닫으려면 **변수 관리**에서 해당 변수를 마우스 오른쪽 버튼으로 클릭하고 **게임 시작 시 변수 초기화**를 켜세요.

## 여러 버전 순환하기

버튼으로 세 가지 배경처럼 두 가지가 넘는 버전을 전환할 수도 있습니다.

1. **메뉴 모음 -> 사용자 지정 -> 변수 관리**에서 값이 `0`인 텍스트 변수 `background`를 추가하세요.
2. 세 개의 [이미지 요소](/elements#image)에 변수 `background`의 값이 각각 `0`, `1`, `2`일 때 충족되는 **변수 값임(FM 변수)** 요구 사항을 설정하세요.
3. 버튼에 **변수 값 설정(FM 변수)**을 추가하고 다음 값을 입력하세요. 값은 `0`, `1`, `2` 순서로 바뀐 뒤 다시 `0`부터 시작합니다.

   ```
   background:{"placeholder":"calc","values":{"decimal":"false","expression":"({"placeholder":"getvariable","values":{"name":"background"}} + 1) % 3"}}
   ```

버전을 더 추가하려면 끝에 있는 `3`을 바꾸세요. 계산 방법은 [**계산기**](/placeholders#calculator)를 참고하세요.

# 레이아웃 켜고 끄기

레이아웃 전체를 표시하거나 숨기려면 다음 방법을 사용할 수 있습니다.

- 편집기 배경을 마우스 오른쪽 버튼으로 클릭했을 때 나오는 메뉴의 **로딩 요구 사항 [레이아웃 전체]**는 요소의 요구 사항과 같은 방식으로 작동합니다. [레이아웃 전체 요구 사항](/conditions#layout-wide-requirements)을 참고하세요.
- [**레이아웃 전환**](/action-scripts#toggle-layout), [**레이아웃 활성화**](/action-scripts#enable-layout), [**레이아웃 비활성화**](/action-scripts#disable-layout) 액션은 이름으로 레이아웃을 켜고 끕니다.

버튼으로 끌 레이아웃과 다른 레이아웃에 버튼을 배치하세요. 그렇지 않으면 레이아웃과 함께 버튼도 사라져 레이아웃을 다시 켤 수 없습니다.
