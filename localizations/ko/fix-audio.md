# 오디오 파일 수정

오디오 파일이 다른 곳에서는 재생되지만 FancyMenu에서는 재생되지 않는다면, OGG 또는 PCM WAV로 다시 인코딩하세요. WAV의 경우 48 kHz, 16비트 오디오를 시도해 보세요.

FFmpeg 또는 신뢰할 수 있는 다른 오디오 변환기를 사용할 수 있습니다. 현재 파일 확장자와 보고된 설정이 이미 올바르게 보여도 다시 인코딩하는 것은 유용합니다.

# 확인 사항

- 다시 인코딩한 파일이 다른 오디오 플레이어에서 재생되는지 확인하세요.
- 메모리에 민감한 화면에서는 매우 큰 오디오 파일을 사용하지 마세요.
- [오디오 요소](./elements#audio) 또는 동작에서 선택한 사운드 채널을 확인하세요.
- Minecraft의 마스터 볼륨과 선택한 채널의 볼륨을 확인하세요.
- 그래도 오디오가 실패한다면, Minecraft 오디오를 대체하거나 처리하는 다른 모드를 비활성화한 상태로 테스트해 보세요.
