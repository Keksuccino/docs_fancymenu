# 메뉴 배경 음악

Minecraft의 기본 메뉴 배경 음악을 사용자 지정 트랙으로 바꾸거나, 메뉴에서 재생되는 일반 바닐라 음악을 아예 비활성화할 수 있습니다.

# 바닐라 음악 비활성화

FancyMenu는 바닐라 메뉴 음악을 비활성화하는 여러 가지 방법을 제공합니다. 화면에서 다른 오디오 트랙을 재생하려는 경우나, 일부 화면에서 음악이 전혀 재생되지 않게 하고 싶을 때 유용합니다.

## 전역적으로

메뉴에서 음악이 전혀 나오지 않게 하고 싶다면, 이 방법이 가장 쉽습니다.

FancyMenu 3.9.0+에서 바닐라 메뉴 음악을 전역적으로 비활성화하거나 바꾸려면, 화면 상단의 FancyMenu 메뉴 바에서 **Customization -> Global Customizations**를 클릭하세요. Global Customizations를 사용하면 리소스 팩 없이도, 그리고 각 화면마다 사용자 지정을 활성화하지 않아도 메뉴 음악을 바꿀 수 있습니다.

{.is-info}

## 화면별로

바닐라 메뉴 음악이 어디에서 재생될지 더 세밀하게 제어하고 싶다면 **Music Controller** 요소를 사용해야 합니다. 이 요소는 다른 요소들과 마찬가지로 **편집기 배경을 우클릭**한 다음 **New Element -> Music Controller**를 클릭해 레이아웃에 추가할 수 있습니다.

요소를 **우클릭**하면 메뉴에서 재생되는 어떤 종류의 음악을 비활성화할지 사용자 지정할 수 있습니다(일반 메뉴 음악과, 게임을 일시 정지하지 않는 화면, 예를 들어 인벤토리 화면에서 계속 재생되는 월드 음악).

> 이 요소는 **로드 조건**을 지원하므로, 바닐라 음악이 언제 재생될지 더 세밀하게 제어할 수 있습니다!
{.is-info}


# 사용자 지정 음악 추가

이제 실제 사용자 지정 배경 음악을 추가해 보겠습니다.

모든 화면에서 같은 사용자 지정 음악을 재생하고, 레이아웃 수준에서 제어가 필요하다면, 사용자 지정이 활성화된 모든 화면에 로드되는 **universal layout**을 사용해야 합니다. 단순히 전역 메뉴 음악을 바꾸는 것이라면 대신 [Global Customizations](/global-customizations)를 사용하세요.

universal layout을 사용하면, 해당 레이아웃이 활성화된 메뉴에서 다른 같은 레이아웃이 활성화된 메뉴로 이동해도 음악이 **계속 재생**됩니다.

화면별로 다른 음악을 재생하고 싶다면 일반 레이아웃을 사용하세요.

이 예제에서는 **universal layout**을 사용하겠습니다.

universal layout에 새 **Audio** 요소를 추가하세요. 이 요소가 배경 음악 플레이어 역할을 합니다.

이제 배경에서 재생할 음악 트랙을 추가하세요.

이 정도면 거의 끝입니다.
필요하다면 Audio 요소를 셔플 모드로 설정하고 사운드 채널도 변경할 수 있습니다.

레이아웃을 저장하고 편집기를 나가세요.

# 모든 메뉴에 사용자 지정 활성화

이 예제에서는 여러 화면에서 배경 음악이 재생되길 원하기 때문에 **universal layout**을 사용했습니다.

레이아웃은 **사용자 지정이 활성화된** 화면에서만 로드되므로, 음악을 재생할 모든 화면에 대해 지금 활성화해 주어야 합니다.

그렇게 하려면 **Customization**을 클릭한 다음 **Current Screen Customization**을 활성화하세요.
