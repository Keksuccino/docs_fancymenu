# 메뉴 배경 음악

FancyMenu는 바닐라 메뉴 음악을 비활성화하거나, 전역 트랙 목록을 재생하거나, 레이아웃별 음악에 [Audio 요소](./elements#audio)를 사용할 수 있습니다.

# 전역 메뉴 음악

레이아웃 편집기 밖에서 **사용자 지정 -> 전역 사용자 지정**을 통해 [**전역 사용자 지정**](./global-customizations)을 엽니다.

다음 설정을 사용하세요:

- **바닐라 메뉴 음악 재생**은 전역적으로 바닐라 메뉴 음악을 켜거나 끕니다.
- **사용자 지정 메뉴 음악 트랙**은 전역 대체 트랙 목록을 관리합니다.

> [!IMPORTANT]
> 전역 사용자 지정 메뉴 트랙은 월드가 로드되지 않았을 때만 재생됩니다. 예를 들어 제목 화면에서만 재생됩니다. 인게임 메뉴 오디오에는 [**Audio** 요소](./elements#audio)를 사용하세요.

전역 트랙은 Music 사운드 채널을 사용합니다. 첫 번째 트랙은 약 5초 후에 시작하며, 이후 트랙은 약 1~30초의 무작위 지연 후 재생됩니다. 여러 트랙이 설정된 경우 선택은 무작위이며, 바로 이전에 재생한 트랙이 즉시 반복되지 않도록 합니다.

# 화면별 음악 제어

해당 화면의 바닐라 음악을 제어하려면 레이아웃에 [**Music Controller** 요소](./elements#music-controller)를 추가하세요:

1. 편집기 배경을 마우스 오른쪽 버튼으로 클릭합니다.
2. **새 요소 -> Music Controller**를 선택합니다.
3. 메뉴 음악과 월드 음악을 각각 따로 설정합니다.

이 요소는 [로딩 요구 사항](./conditions)을 지원합니다.

Music Controller로 메뉴 음악을 비활성화하면 해당 화면에서 전역 사용자 지정 메뉴 트랙 목록도 재생되지 않습니다.

# Audio 요소로 사용자 지정 음악 사용

다음이 필요할 때는 [**Audio** 요소](./elements#audio)를 사용하세요:

- 화면마다 다른 음악.
- 인게임 화면에서의 음악.
- 레이아웃 요구 사항, 순서 있는 재생 목록, 셔플 설정, 볼륨 또는 채널 제어.

[유니버설 레이아웃](./universal-layouts)에 [Audio 요소](./elements#audio)를 배치하면, 해당 레이아웃을 불러오는 지원되는 화면 전체에서 동일한 플레이어가 활성 상태로 유지됩니다. 유니버설 레이아웃이 적용되어야 하는 각 일반 화면에서 화면 사용자 지정이 활성화되어 있어야 합니다.
