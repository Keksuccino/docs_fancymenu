# 메뉴 배경 음악

FancyMenu에서는 바닐라 메뉴 음악을 끄거나, 전체 메뉴에 적용할 재생 목록을 재생하거나, [오디오 요소](/elements#audio)를 사용해 레이아웃별 음악을 재생할 수 있습니다.

# 전체 메뉴 음악

레이아웃 편집기 밖에서 **사용자 지정 -> 전체 사용자 지정**을 통해 [**전체 사용자 지정**](/global-customizations)을 엽니다.

다음 설정을 사용하세요.

- **바닐라 메뉴 음악 재생**은 바닐라 메뉴 음악을 전체적으로 켜거나 끕니다.
- **사용자 지정 메뉴 음악 트랙**에서는 전체 메뉴에 적용할 대체 재생 목록을 관리합니다.

> [!IMPORTANT]
> 전체 사용자 지정 메뉴 트랙은 타이틀 화면처럼 월드가 로드되지 않은 상태에서만 재생됩니다. 월드 내 메뉴에서 오디오를 재생하려면 [**오디오** 요소](/elements#audio)를 사용하세요.

전체 메뉴 트랙은 음악 사운드 채널을 사용합니다. 첫 번째 트랙은 약 5초 후 재생되며, 이후 트랙은 약 1~30초 사이의 무작위 지연 시간 후 재생됩니다. 트랙은 무작위로 선택되며, 두 개 이상의 트랙이 설정된 경우 직전에 재생한 트랙은 바로 다시 선택되지 않습니다.

# 화면별 음악 제어

화면의 바닐라 음악을 제어하려면 레이아웃에 [**음악 제어기** 요소](/elements#music-controller)를 추가하세요.

1. 편집기 배경을 마우스 오른쪽 버튼으로 클릭합니다.
2. **새 요소 -> 음악 제어기**를 선택합니다.
3. 메뉴 음악과 월드 음악을 각각 설정합니다.

이 요소는 [로드 조건](/conditions)을 지원합니다.

음악 제어기로 메뉴 음악을 끄면 해당 화면에서 전체 사용자 지정 메뉴 트랙 목록도 재생되지 않습니다.

# 오디오 요소로 사용자 지정 음악 재생

다음과 같은 경우 [**오디오** 요소](/elements#audio)를 사용하세요.

- 화면마다 다른 음악을 재생하려는 경우
- 월드 내 화면에서 음악을 재생하려는 경우
- 레이아웃 조건, 순서가 지정된 재생 목록, 셔플 설정, 볼륨 또는 채널 제어가 필요한 경우

지원되는 화면에서 해당 레이아웃이 로드되는 동안 같은 플레이어를 계속 활성 상태로 유지하려면 [범용 레이아웃](/universal-layouts)에 [오디오 요소](/elements#audio)를 배치하세요. 범용 레이아웃을 적용할 일반 화면마다 화면 사용자 지정 기능을 활성화해야 합니다.
