# 스케줄러

스케줄러는 타이머에 따라 [작업 스크립트](/action-scripts)를 실행합니다. 대기 후 한 번, 몇 번 또는 무언가가 중지할 때까지 계속 반복해서 실행할 수 있습니다. 모든 메뉴와 게임 플레이 중에 작동하며, 메뉴가 열려 있지 않아도 실행됩니다. 레이아웃에 종속되지 않습니다.

나중에 실행하거나 반복해서 실행해야 하는 작업에는 스케줄러를 사용하는 것이 좋습니다. 가능한 경우 [티커 요소](/elements#ticker) 대신 스케줄러를 사용하세요.

<img width="800" alt="스케줄러가 팁 목록을 섞기 때문에 생존 팁 상자에 4초마다 다른 팁이 표시됩니다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/schedulers_tips.gif?raw=true">

> [!CAUTION]
> 메뉴가 열려 있지 않아도 스케줄러는 파일, 네트워크, 명령어, 클립보드, 리소스 팩 및 링크 작업을 실행할 수 있습니다. 신뢰하는 사람의 프로필과 파일에서만 스케줄러를 사용하세요.

# 스케줄러 추가하기

<img width="800" alt="스케줄러 관리 창을 열고 스케줄러 추가를 클릭한 다음, 팁 목록에 섞기 옵션이 적용된 목록 정렬 작업을 지정합니다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/schedulers_add.gif?raw=true">

1. **메뉴 바 -> 사용자 지정 -> 스케줄러 관리**를 엽니다.
2. **스케줄러 추가**를 클릭합니다. 작업 스크립트 편집기가 열립니다.
3. 매번 실행할 작업을 추가하고 **완료**를 클릭합니다. [작업 스크립트](/action-scripts#making-an-action-script)를 참고하세요.

<img width="800" alt="설정 편집에서 새 스케줄러의 이름을 random_tip으로 지정하고, 틱 간격을 4000으로, 시작 시 실행을 켠 다음 스케줄러를 시작하자 메뉴의 팁이 바뀝니다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/schedulers_start.gif?raw=true">

4. 새 스케줄러가 임의 ID로 표시됩니다. 클릭한 다음 **설정 편집**을 클릭합니다.
5. `random_tip`과 같은 **스케줄러 ID**를 지정하고 [타이머](#settings)를 설정한 다음 **완료**를 클릭합니다.
6. **지금 시작**을 클릭해 시험해 봅니다.

**스케줄러 관리**에서 변경한 내용은 모두 즉시 저장됩니다.

GIF에 나오는 스케줄러는 4초마다 `tips` 목록에 **섞기** 옵션을 적용한 [**목록 정렬 (FM 변수)**](/action-scripts#arrange-list-fm-variable) 작업을 실행합니다. 텍스트 요소는 목록의 첫 번째 항목을 표시하므로 무작위 팁이 표시됩니다. 목록과 텍스트가 작동하는 방식은 [목록 작업](/variables#list-actions)을 참고하세요.

# 설정

| 설정 | 설명 |
|---|---|
| **스케줄러 ID** | 작업과 요구 사항에서 사용하는 이름입니다. 소문자, 숫자, `.`, `_`, `-`만 사용할 수 있습니다. |
| **시작 지연 (ms)** | 시작된 후 첫 번째로 실행되기 전까지 기다리는 시간입니다. `0`이면 즉시 실행됩니다. |
| **틱 간격 (ms)** | 두 번 실행 사이의 시간입니다. `0`이면 매 틱마다, 초당 20회 실행됩니다. |
| **실행 틱 수** | 자동으로 중지되기 전까지 실행할 횟수입니다. `0`이면 무언가가 중지할 때까지 계속 실행됩니다. |
| **시작 시 실행** | 게임이 시작될 때마다 스케줄러를 시작합니다. |

시간은 밀리초 단위입니다. `1000`은 1초, `60000`은 1분, `1800000`은 30분입니다.

# 시작 및 중지

스케줄러는 시작된 후에만 실행됩니다.

- **시작 시 실행**을 설정하면 게임이 시작될 때와 [프로필](/profiles)을 전환한 후에 실행됩니다.
- **스케줄러 관리**에서 **지금 시작**을 클릭해 실행합니다. 스케줄러가 실행 중이면 버튼이 **지금 중지**로 바뀝니다.
- 스케줄러 ID를 지정해 [**스케줄러 시작**](/action-scripts#start-scheduler) 작업을 실행합니다. 버튼 스크립트나 [리스너](/listeners)의 스크립트에서 사용할 수 있습니다.

다음과 같은 경우 스케줄러가 중지됩니다.

- **실행 틱 수**만큼 실행한 후 자동으로 중지됩니다.
- **지금 중지**를 클릭하거나 ID를 지정해 [**스케줄러 중지**](/action-scripts#stop-scheduler) 작업을 실행합니다.
- 이름을 바꾸거나 삭제할 때, [프로필](/profiles)을 전환할 때, 게임을 종료할 때 중지됩니다. 게임을 다시 시작하면 **시작 시 실행**이 설정된 스케줄러만 다시 실행됩니다.

실행 중인 스케줄러는 다시 시작할 수 없습니다. 스케줄러가 중지될 때까지 **스케줄러 시작**은 아무 작업도 하지 않습니다. 다시 시작하려면 **스케줄러 중지**를 실행한 다음 **스케줄러 시작**을 실행하세요.

[**스케줄러 실행 중**](/conditions#scheduler-is-running) 조건으로 스케줄러의 실행 여부를 확인할 수 있습니다. 예를 들어 스케줄러가 실행 중일 때만 중지 버튼을 표시할 수 있습니다.

## 화면이 열려 있을 때만 실행하기

예를 들어 타이틀 화면처럼 특정 화면이 열려 있는 동안에만 스케줄러를 실행하려면 다음을 따르세요.

1. 레이아웃 편집기에서 해당 화면의 레이아웃을 엽니다.
2. 편집기 배경을 마우스 오른쪽 버튼으로 클릭하고 **'화면 열기' 작업 스크립트 편집**을 클릭한 다음, 스케줄러 ID를 지정해 **스케줄러 시작**을 추가합니다.
3. 배경을 다시 마우스 오른쪽 버튼으로 클릭하고 **'화면 닫기' 작업 스크립트 편집**을 클릭한 다음, 같은 ID로 **스케줄러 중지**를 추가합니다.

# 스케줄러 관리

<img width="800" alt="스케줄러가 세 개 표시된 스케줄러 관리 창. random_tip이 선택되어 있고 오른쪽에 설정과 실행 중 상태가 표시됩니다" src="https://raw.githubusercontent.com/Keksuccino/docs_fancymenu/refs/heads/wiki-2026/assets/schedulers_manage.png?raw=true">

- 스케줄러를 클릭하면 오른쪽에 설정, 실행 여부 및 작업 스크립트가 표시됩니다.
- **작업 편집**을 클릭하거나 스케줄러를 마우스 오른쪽 버튼으로 클릭하면 작업 스크립트가 열립니다.
- 스케줄러 ID를 두 번 클릭하면 이름을 바꿀 수 있습니다. `Enter`를 누르면 이름이 저장되고, `Esc`를 누르면 취소됩니다. 이름을 바꾸면 스케줄러가 중지되며, 이전 ID를 사용하는 작업은 해당 스케줄러를 더 이상 찾지 못합니다.
- **스케줄러 제거**를 클릭하면 확인 절차를 거친 뒤 선택한 스케줄러가 삭제됩니다.
- **AI용 내보내기**를 클릭하면 선택한 스케줄러 또는 모든 스케줄러가 [AI 채팅](/export-for-ai)에 사용할 수 있도록 복사됩니다.
- 검색창에서 스케줄러 ID로 스케줄러를 찾을 수 있습니다.

스케줄러는 `config/fancymenu/scheduler_instances.txt`에 저장됩니다([데이터 저장 위치](/data-storage-locations) 참고). 각 [프로필](/profiles)에는 별도의 스케줄러가 있습니다.

# 예시: 휴식 알림

게임 시작 후 30분마다 토스트 알림을 표시하려면 다음과 같이 설정합니다.

1. [**토스트 표시**](/action-scripts#show-toast) 작업이 있는 스케줄러를 추가합니다. **제목**을 `Time for a Break`으로, **메시지**를 `Stand up, stretch and drink some water.`로 설정합니다.
2. **설정 편집**에서 **스케줄러 ID**를 `break_reminder`로 설정하고, **시작 지연 (ms)**과 **틱 간격 (ms)**을 `1800000`으로 설정한 다음 **시작 시 실행**을 **활성화**로 설정합니다.

**시작 지연 (ms)**을 설정하지 않으면 게임이 시작되는 즉시 첫 번째 토스트가 표시됩니다.

# 알아두면 좋은 점

- 작업에 필요한 만큼 **틱 간격 (ms)**을 크게 설정하세요. `0`이면 작업이 초당 20회 실행되며, 실행 시간이 오래 걸리는 작업은 게임을 느리게 만들 수 있습니다.
- 게임이 느려지면 실행이 여러 번 연달아 일어날 수 있습니다.
- 작업 스크립트의 변경 사항은 스케줄러가 실행 중이어도 즉시 적용됩니다. 설정 변경 사항은 다음에 스케줄러가 시작될 때 적용됩니다.
- 작업이 실패해도 스케줄러는 계속 실행됩니다. 오류는 게임 로그 파일인 `logs/latest.log`에 기록됩니다.
- 하나의 작업 스크립트 안에서 한 번만 대기하려는 경우(예: "클릭 후 2초 뒤에 화면 열기")에는 [나중에 실행](/action-scripts#execute-later) 블록을 사용하는 편이 더 간단합니다.
