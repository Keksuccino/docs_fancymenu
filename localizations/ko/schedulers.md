# 스케줄러

스케줄러는 액션 스크립트를 타이머에 맞춰 실행합니다.

스케줄러는 전역적이며(특정 화면에 묶이지 않음), GUI가 열려 있지 않아도 계속 실행될 수 있습니다.

한 번만 실행되는 동작이 아니라 시간에 따른 자동화를 원할 때 스케줄러를 사용하세요.
반복 작업, 지연 작업, 백그라운드 로직에 유용합니다.

일반적인 예시:

- 몇 초마다 변수나 텍스트 요소를 업데이트하기(예: 커스텀 시계/상태 표시)
- 주기적으로 확인을 수행하고 조건이 충족되면 액션 실행하기
- 타이머 루프를 이용해 메뉴 효과, 사운드 또는 다른 스크립트 동작 시작하기
- 화면을 계속 열어 두지 않아도 나중에 실행되도록 액션을 지연하기

# 찾는 위치

레이아웃 편집기가 **아닌 상태에서** FancyMenu의 **메뉴 바**를 연 다음, **Customization -> Manage Schedulers**로 이동하세요.

# 빠른 시작

1. **Customization -> Manage Schedulers**를 엽니다.
2. **Add Scheduler**를 클릭합니다.
3. 스케줄러의 **Action Script**를 만듭니다(이 스크립트는 스케줄러 틱마다 한 번 실행됩니다).
4. 스케줄러를 선택한 뒤 **Edit Settings**를 클릭합니다.
5. 다음을 설정합니다:
   - **Scheduler ID**(고유한 스케줄러 이름; Start/Stop 액션과 요구사항에서 사용됨; 허용: `a-z`, `0-9`, `.`, `_`, `-`)
   - **Start Delay (ms)**(첫 틱이 실행되기 전 대기 시간)
   - **Tick Delay (ms)**(틱 사이의 대기 시간; `0` = 매 게임 틱마다)
   - **Ticks to Run**(자동 중지 전까지 실행할 틱 수; `0` = 영구적으로 실행)
   - **Start on Launch**(FancyMenu가 로드될 때 이 스케줄러를 자동으로 시작)
6. **Start Now**를 사용해 즉시 실행합니다.
7. **Stop Now**를 사용해 중지합니다.

# 스케줄러 제어 및 상태 확인

스케줄러를 제어하고 실행 중 상태를 확인할 수 있는 액션과 요구사항이 있습니다.

## 액션

- **Start Scheduler**는 스케줄러 ID를 받아, 이미 실행 중이 아니라면 시작합니다.
- **Stop Scheduler**도 스케줄러 ID를 받아 중지합니다.

## 요구사항

스케줄러가 현재 실행 중인지 확인하려면 **Scheduler Is Running** 요구사항을 사용하세요. 이 요구사항은 스케줄러 ID를 받습니다.

# 팁

1. `hud_update`, `menu_animation`, `music_fade`처럼 명확한 ID를 사용하세요.
2. 먼저 더 큰 틱 지연(예: `200`-`1000` ms)으로 시작한 뒤, 필요할 때만 낮춰 성능을 아끼세요.
3. 스케줄러 목록에서 스케줄러를 마우스 오른쪽 버튼으로 클릭하면 액션을 빠르게 편집할 수 있습니다.
4. 스케줄러 목록에서 스케줄러 ID를 두 번 클릭하면 이름을 변경할 수 있습니다.
