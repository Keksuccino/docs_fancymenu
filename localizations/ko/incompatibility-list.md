# 호환되지 않는 모드 목록

다음 모드들은 어떤 방식으로든 FancyMenu와 호환되지 않는 것으로 알려져 있습니다.

일부 모드는 FancyMenu와 함께 작동하도록 우회 방법이 있습니다.
그런 경우에는 아래 목록의 모드 이름 뒤에 따로 적어두었습니다.

**이 목록에 아직 포함되지 않은 호환되지 않는 모드를 발견하셨다면, GitHub에 이슈를 열어 주세요! 정말 감사합니다!**

* [Animated Loading Screen](https://modrinth.com/mod/animated-loading-screen) (메뉴가 버그가 난 것처럼 보이게 함)
* [Animated Mojang Logo](https://www.curseforge.com/minecraft/mc-mods/animated-mojang-logo) (레이아웃이 가끔 로드되지 않음; Drippy Loading Screen도 망가뜨림)
* [Bedrockify](https://www.curseforge.com/minecraft/mc-mods/bedrockify) (이 모드의 모든 메뉴 변경을 비활성화하면 호환됨. 적어도 사용자 지정하려는 메뉴에 대해서는)
* [BetterFPS](https://www.curseforge.com/minecraft/mc-mods/betterfps) (이 모드의 버튼과 메뉴는 사용자 지정할 수 없음)
* [Chat Colors](https://www.curseforge.com/minecraft/mc-mods/chat-colours) (시작 시 충돌)
* [Chloride](https://modrinth.com/mod/chloride) (이 모드가 설치되어 있으면 FPS 플레이스홀더가 작동하지 않음)
* [Colormatic](https://www.curseforge.com/minecraft/mc-mods/colormatic) (MC 시작 시 심한 렉이 발생하고 FM의 오디오 관련 요소가 망가짐)
* [Controllable](https://www.curseforge.com/minecraft/mc-mods/controllable) (FancyMenu로 추가한 사용자 지정 버튼은 Controllable의 “Virtual Mouse” 기능으로 클릭할 수 없음)
* [Controlify](https://modrinth.com/mod/controlify) (게임이 충돌하는 것 같지만, 이쪽에서 수정할 수는 없음 - 자세한 맥락은 [이 이슈](https://github.com/Keksuccino/FancyMenu/issues/1144)를 참고하세요)
* [Crash To Main Menu](https://www.curseforge.com/minecraft/mc-mods/crash-to-main-menu)
* [Custom Loading Screen](https://www.curseforge.com/minecraft/mc-mods/better-loading-screen)
* [Custom Main Menu](https://www.curseforge.com/minecraft/mc-mods/custom-main-menu)
* [Debugify](https://www.curseforge.com/minecraft/mc-mods/debugify) ([Modern Debugify](https://www.curseforge.com/minecraft/mc-mods/modern-debugify)를 대신 사용하세요)
* [Dynamic Surroundings](https://www.curseforge.com/minecraft/mc-mods/dynamic-surroundings) (FancyMenu의 오디오 요소를 망가뜨리지만, 그 외에는 정상 작동해야 함)
* [EnhancedVisuals](https://www.curseforge.com/minecraft/mc-mods/enhancedvisuals) (애니메이션을 망가뜨리고, 배경을 반투명하게 만들며, 아마 그 외에도 문제가 생김)
* [Entity Model Features](https://modrinth.com/mod/entity-model-features) (게임이 충돌하지만, 이쪽에서 수정할 수는 없음 - 자세한 맥락은 [이 이슈](https://github.com/Keksuccino/FancyMenu/issues/1115)를 참고하세요)
* [Fossils and Archeology Revival](https://www.curseforge.com/minecraft/mc-mods/fossils) (게임 내에서는 작동하지만, 사용자 지정 메인 메뉴는 지원되지 않음—설정에서 비활성화할 수 있음)
* [Holographic Renderers](https://www.curseforge.com/minecraft/mc-mods/holographic-renderers) (시작 시 충돌)
* [Ice and Fire](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons) (설정에서 사용자 지정 메인 메뉴를 비활성화하면 작동함)
* [Jurassicraft](https://www.curseforge.com/minecraft/mc-mods/jurassicraft) (GUI에 대한 사용자 지정을 활성화하면 시작 시 충돌함—`config/fancymenu/customizablemenus.txt`에서 해당 항목을 삭제하세요)
* [Legacy4J](https://www.curseforge.com/minecraft/mc-mods/legacy-minecraft) (게임이 충돌함)
* [MalisisCore](https://www.curseforge.com/minecraft/mc-mods/malisiscore) (메인 메뉴 사용자 지정을 망가뜨림)
* [Main Menu Scale Mod](https://www.curseforge.com/minecraft/mc-mods/main-menu-scale)
* [MCA Reborn](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-reborn) (작동하지만, 일부 메뉴가 FM의 메뉴 바를 망가뜨리거나 사용자 지정할 수 없음)
* [Minecraft Comes Alive](https://www.curseforge.com/minecraft/mc-mods/minecraft-comes-alive-mca) (정상 작동하지만, 메뉴는 사용자 지정할 수 없음)
* [MineTogether](https://www.curseforge.com/minecraft/mc-mods/creeperhost-minetogether) (GUI 크기가 2보다 클 때 레이아웃이 망가지는 것 같음)
* [Mod Menu](https://www.curseforge.com/minecraft/mc-mods/modmenu) (대부분의 경우 **문제 없이 작동**하지만, Mods 버튼이 중복되거나 사용자 지정할 수 없다면 Mod Menu 버튼 설정을 "Adjacent"로 바꾸세요: Main Menu > Mods > Mod Menu > Mods Button: Adjacent)
* [Modern Online Picture Frames](https://www.curseforge.com/minecraft/mc-mods/online-picture-frame) (충돌—[이 이슈](https://github.com/Keksuccino/FancyMenu/issues/776)를 참고하세요)
* [Not Enough Animations](https://www.curseforge.com/minecraft/mc-mods/not-enough-animations) (1.16+에서는 정상 작동하지만, 1.12에서는 망가짐)
* **OptiFine** (이 모드를 망가뜨립니다! 대신 [이 대안들](./optifine-alternatives)을 사용하세요)
* [Optiscale](https://www.curseforge.com/minecraft/mc-mods/optiscale) (FancyMenu의 UI를 망가뜨림; 버튼을 클릭할 수 없음)
* [Pack Menu](https://www.curseforge.com/minecraft/mc-mods/packmenu)
* [Panorama Screens](https://modrinth.com/mod/panorama-screens) (절대 좋은 생각이 아니므로, 메뉴 사용자 지정 모드를 여러 개 겹쳐 쓰면 작동하지 않고 문제를 일으킴)
* [QuestCraft](https://github.com/QuestCraftPlusPlus/QuestCraft) (게임 로드 실패)
* [RandomPatches](https://www.curseforge.com/minecraft/mc-mods/randompatches-forge) (설정에서 `patchMinecraftClass = false`로 하면 작동함)
* [Remove Reloading Screen](https://www.curseforge.com/minecraft/mc-mods/rrls) (FM과 Drippy를 망가뜨림. 이 모드는 사용하지 마세요.)
* [Replay Mod](https://www.replaymod.com/download/) (`.minecraft/config/replaymod.json`에서 `mainMenuButton`을 **BIG**으로 설정하면 작동함)
* [Seamless Loading Screen](https://www.curseforge.com/minecraft/mc-mods/seamless-loading-screen) (게임이 충돌함)
* [Slight Gui Modifications](https://www.curseforge.com/minecraft/mc-mods/slight-gui-modifications)
* [Skin Layers 3D](https://www.curseforge.com/minecraft/mc-mods/skin-layers-3d) (1.16+에서는 정상 작동하지만, 1.12에서는 망가짐)
* [Smooth Scrolling Everywhere](https://www.curseforge.com/minecraft/mc-mods/smooth-scrolling-everywhere)
* [Sound Filters](https://www.curseforge.com/minecraft/mc-mods/sound-filters) (이 모드가 설치되어 있으면 오디오 확장 기능이 작동하지 않음)
* [Sound Physics Remastered](https://www.curseforge.com/minecraft/mc-mods/sound-physics-remastered) (이 모드가 설치되어 있으면 오디오 확장 기능이 작동하지 않음)
* [Stylish Effects](https://www.curseforge.com/minecraft/mc-mods/stylish-effects) (메인 메뉴가 처음 표시될 때 레이아웃 로드에 실패함)
* [Supplementaries](https://www.curseforge.com/minecraft/mc-mods/supplementaries) (설정 화면을 사용자 지정할 때 무작위로 충돌함; 문제가 되는 레이아웃을 `.minecraft/config/fancymenu/customization`에서 삭제하세요)
* [Terraria Craft](https://www.curseforge.com/minecraft/mc-mods/terraria-craft)
* [The Dalek Mod](https://www.curseforge.com/minecraft/mc-mods/the-dalek-mod) (설정에서 사용자 지정 메인 메뉴를 비활성화하면 작동함)
* [ThonkUtil](https://www.curseforge.com/minecraft/mc-mods/thonkutil) (작동하지만, 현재 메인 메뉴에 제거할 수 없는 텍스트를 추가함)
* [Trade Uses](https://modrinth.com/mod/trade-uses) (주민 거래 메뉴에서 충돌을 일으킴—아마도 “Easy Villagers”도 함께 설치되어 있을 때만 해당)
* [VanillaFix](https://www.curseforge.com/minecraft/mc-mods/vanillafix) (사용은 가능하지만, 일부 사용자는 VanillaFix 충돌 화면에서 문제를 보고함)
* [FireplaceMode](https://www.curseforge.com/minecraft/mc-mods/fireplacemode) (이 모드가 설치되어 있으면 일시정지 화면의 사용자 지정이 가끔 초기화됨)
* [Respackopts](https://www.curseforge.com/minecraft/mc-mods/respackopts) (리소스 팩 화면의 사용자 지정을 비활성화하면 작동함)
* [Bind Pizzeria](https://modrinth.com/mod/jjpizza) (FancyMenu의 컨텍스트 메뉴에서 텍스트 렌더링을 망가뜨림)
* [EnhancedTooltips](https://www.curseforge.com/minecraft/mc-mods/enhancedtooltips) (FancyMenu의 툴팁을 망가뜨림)
