# 사용자 지정 마우스 커서

해당 화면의 시스템 커서를 대체하려면 레이아웃에 [**Cursor** 요소](./elements#cursor)를 추가하세요:

1. **새 요소 -> Cursor**를 선택합니다.
2. RGBA 색상의 PNG 텍스처를 설정합니다.
3. 클릭이 발생해야 하는 텍스처 픽셀에 **Hotspot X**와 **Hotspot Y**를 설정합니다.
4. 편집 중 커서를 확인하고 싶을 때는 에디터 미리보기를 활성화합니다.
5. 동일한 커서를 여러 지원 화면에 표시하려면 [Universal Layout](./universal-layouts)을 사용합니다.

`32×32` 또는 `64×64`와 같은 작은 커서 텍스처를 권장합니다. 커서의 모양과 동작은 운영 체제에 따라 달라질 수 있습니다.
