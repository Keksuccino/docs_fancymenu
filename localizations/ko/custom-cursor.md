# 사용자 지정 마우스 커서

레이아웃에 [**Cursor** 요소](/elements#cursor)를 추가하면 해당 화면에서 시스템 커서를 대체할 수 있습니다.

1. **새 요소 -> Cursor**를 선택합니다.
2. RGBA 색상이 포함된 PNG 텍스처를 설정합니다.
3. 클릭이 발생해야 하는 텍스처 픽셀에 맞춰 **Hotspot X**와 **Hotspot Y**를 설정합니다.
4. 편집 중 커서를 확인하려면 편집기 미리 보기를 활성화합니다.
5. 지원되는 여러 화면에서 같은 커서를 표시하려면 [Universal Layout](/universal-layouts)을 사용합니다.

`32×32` 또는 `64×64`와 같은 작은 커서 텍스처를 사용하는 것이 좋습니다. 커서의 모양과 동작은 운영 체제에 따라 다를 수 있습니다.
