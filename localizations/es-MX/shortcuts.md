# Atajos y combinaciones de teclas

FancyMenu tiene muchos atajos útiles que hacen que trabajar con el **editor de diseño** y otras partes del mod sea más fácil y eficiente.

# Editor de diseño

<br>

## CTRL + clic izquierdo

Puedes seleccionar varios elementos manteniendo presionado **CTRL** mientras haces **clic izquierdo** en los elementos.
También es posible **arrastrar/mover varios elementos** con el mouse manteniendo presionado **CTRL**.

## SHIFT + cambiar tamaño de un elemento

Mantener presionada la tecla SHIFT mientras cambias el tamaño de los elementos preservará su relación de aspecto.

## Teclas de flecha

Las teclas de flecha se pueden usar para **mover** los elementos seleccionados con la máxima precisión.

## CTRL + A

Selecciona todos los elementos a la vez.

## CTRL + C

**Copia** todos los elementos seleccionados al portapapeles.

## CTRL + V

**Pega** todos los elementos que estén actualmente en el portapapeles.
Esto también funciona de un diseño a otro, así que puedes copiar elementos en el diseño A y pegarlos en el diseño B.

## CTRL + S

**Guarda** el diseño rápidamente.

## CTRL + ALT + L

Abre rápidamente el editor de diseño con el último diseño editado.

## CTRL + Z

**Deshace** la última acción.

## CTRL + Y

**Rehace** una acción deshecha previamente.

## CTRL + G

Activa o desactiva rápidamente la **cuadrícula**.

## O

Mantener presionada la tecla **O** muestra la superposición del punto de anclaje si su visibilidad está configurada como **Mostrar al presionar una tecla** en **Ventana -> Visibilidad de superposición de anclaje**.

## DEL

**Elimina** todos los elementos seleccionados.

# Editor de texto

<br>

## CTRL + C

**Copia** el texto seleccionado al portapapeles.

## CTRL + V

**Pega** el texto que esté actualmente en el portapapeles.

## CTRL + Z

**Deshace** la última acción.

## CTRL + Y

**Rehace** una acción deshecha previamente.

## CTRL + A

**Selecciona** todo el texto.

## CTRL + D

**Duplica** la línea actual.

## CTRL + U

**Corta** el texto seleccionado.

## ALT + Flecha arriba / Flecha abajo

Mueve la línea actual hacia arriba o hacia abajo.

## CTRL + Inicio / CTRL + Fin

Mueve el cursor al inicio o al final del texto.

## CTRL + G

Abre la entrada **Ir a línea**.

## CTRL + S

Confirma el editor, igual que hacer clic en **Listo**.

## SHIFT + teclas de flecha

Selecciona/resalta texto mientras mueves el cursor.

## Teclas de flecha

Las teclas de flecha se pueden usar para navegar el cursor en el texto.

# En los menús

<br>

## CTRL + ALT + C

Activa o desactiva la visibilidad de la **barra de menú** de FancyMenu en la parte superior de los menús.

## CTRL + ALT + R

**Recarga** FancyMenu.
Esto incluye una recarga completa de recursos/activos y se limpian la mayoría de las cachés.

## CTRL + ALT + D

Activa o desactiva la visibilidad de la **superposición de depuración** de FancyMenu.

# Ventanas de edición

Muchas ventanas de edición de FancyMenu en la versión v3.9.0 admiten navegación con teclado mediante **teclas de flecha** y **Enter**. Muchas ventanas también usan **CTRL + S** como atajo para **Listo** y **ESC** como **Cancelar**.

Las ventanas rediseñadas del Editor de Script de Acción, Administrar requisitos y Administrar variables también admiten menús contextuales con clic derecho, búsqueda, deshacer/rehacer y navegación con teclado en sus listas.
