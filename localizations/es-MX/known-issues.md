# Problemas conocidos en FancyMenu

Esta lista siempre contiene los problemas conocidos de la versión más reciente de FancyMenu que aún no se han solucionado o que no se pueden solucionar debido a las limitaciones de Minecraft, conflictos con otros mods, etc.

# Solucionables

Estos problemas se pueden solucionar y se solucionarán en el futuro.

_Actualmente no hay problemas conocidos._

# No solucionables

Estos problemas no se pueden solucionar y probablemente permanecerán para siempre, a menos que se solucionen por el otro lado (Minecraft, otro mod, etc.).

### 1. Las entidades de jugador y los elementos de objetos siempre aparecen delante de todo.

El sistema de capas de FancyMenu no funciona para las entidades de jugador ni para los elementos de objetos debido a la forma en que Minecraft los renderiza. Siempre se renderizan delante de todos los demás elementos de la interfaz, al menos en las versiones antiguas de Minecraft. Es posible que Minecraft 1.21.8 o versiones posteriores ya no se vean afectadas por este problema.
