# Capas y grupos

Abre el widget de Capas a través de **Window -> Editor Widgets -> Layers**.

# Orden de las capas

Arrastra las capas en la lista para cambiar su orden de renderizado. También puedes hacer clic derecho en un elemento y usar **Move One Layer Up** o **Move One Layer Down**.

Los elementos [Player Entity](./elements#player-entity) y [Item](./elements#item) pueden tener límites de renderizado que impiden el orden normal de las capas.

# Grupos

Los grupos organizan capas relacionadas y te permiten moverlas u ocultarlas juntas.

- Crea y renombra grupos.
- Renombra capas individuales.
- Arrastra capas dentro o fuera de los grupos.
- Arrastra un grupo para mover todas sus capas en el orden.
- Contrae o expande un grupo.
- Muestra u oculta todas las capas de un grupo.
- Elimina un grupo sin eliminar sus capas.

La pertenencia a grupos y el estado contraído se guardan con el diseño.
