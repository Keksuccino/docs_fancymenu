# Ícono y título de la ventana

FancyMenu te permite cambiar el ícono y el título de la ventana de Minecraft.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# Ícono personalizado

Para establecer un ícono personalizado, abre [**Personalizaciones globales**](/global-customizations) desde **Personalización -> Personalizaciones globales**.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- Los íconos deben ser archivos **PNG** (y **ICNS para macOS**).
- Los íconos deben tener al menos **1 píxel transparente** para que no se vean defectuosos (error de MC/LWJGL).
- Debes seleccionar archivos válidos para las 3 versiones del ícono (16x16, 32x32 y macOS) para activar la opción de ícono personalizado.

> [!CAUTION]
> **De nuevo**: Los íconos deben tener al menos **1 píxel transparente** para que no se vean defectuosos (error de MC/LWJGL). ¡El ícono se verá dañado si no tiene al menos un píxel completamente transparente!


# Título personalizado

Para establecer un título personalizado, abre [**Personalizaciones globales**](/global-customizations) desde **Personalización -> Personalizaciones globales**.
