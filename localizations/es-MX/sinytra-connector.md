# Sinytra Connector

FancyMenu no tiene soporte oficial para [Sinytra Connector](https://modrinth.com/mod/connector) y **no se recomienda usar este mod** (en mi opinión).

[Sinytra Connector](https://modrinth.com/mod/connector) no es un mod normal. Te permite combinar mods de diferentes loaders en una sola instancia, lo que suena a **inestabilidad y cierres inesperados**.
No puedes esperar tener una instancia de Minecraft estable al usar este mod.

Si estás experimentando cierres inesperados y tienes este mod instalado, primero intenta **eliminar [Sinytra Connector](https://modrinth.com/mod/connector)** y revisa si eso soluciona el problema.
