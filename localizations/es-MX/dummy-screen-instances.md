# Pantallas de carga del mundo

Cuando cargas un mundo o te unes a un servidor, probablemente hayas notado que ahí aparecen pantallas que en realidad no puedes personalizar, porque se cierran automáticamente.

Para editarlas, necesitas abrir una instancia de ellas que se mantenga abierta todo el tiempo que quieras, lo cual es posible al abrir una "instancia de pantalla ficticia" de estas.

Las "Instancias de pantalla ficticia" son una función de FancyMenu que permite abrir ALGUNAS de las pantallas que desaparecen demasiado rápido como para personalizarlas.

Para ver todas las pantallas que se pueden abrir mediante la función de Instancia de pantalla ficticia, haz clic en **barra de menú -> Herramientas -> Instancias de pantalla ficticia**. El menú que se abre muestra todas las pantallas que puedes abrir como una instancia de pantalla ficticia. **Al hacer clic izquierdo** sobre las pantallas del menú, se abrirá una instancia ficticia para que puedas personalizarla con calma.

Por ejemplo, al unirte a un mundo o servidor, hay al menos dos pantallas que aparecerán durante la carga:

- Pantalla de carga del nivel (también conocida como Pantalla de carga del mundo)
- Pantalla genérica de mensaje de tierra (también conocida como Pantalla de mensaje de tierra)

> **Importante:** La "Pantalla de carga del mundo" no es lo mismo que la "Pantalla de carga del juego" (también conocida como Pantalla de inicio o Pantalla de recarga de recursos). La "Pantalla de carga del juego" se puede personalizar con **Drippy Loading Screen**, que es un complemento para FancyMenu.
