# Pantallas de carga del mundo

Cuando cargas un mundo o te unes a un servidor, seguramente has notado que aparecen pantallas ahí que realmente no puedes personalizar, porque se cierran automáticamente.

Para editarlas, necesitas abrir una instancia de ellas que permanezca abierta todo el tiempo que quieras, lo cual es posible al abrir una "instancia ficticia de pantalla" de ellas.

Las "instancias ficticias de pantalla" son una función de FancyMenu que permite abrir ALGUNAS de las pantallas que desaparecen demasiado rápido como para personalizarlas.

Para ver todas las pantallas que se pueden abrir mediante la función de Instancias ficticias de pantalla, haz clic en **barra de menú -> Tools -> Dummy Screen Instances**. El menú que se abre muestra todas las pantallas que puedes abrir como una instancia ficticia de pantalla. **Haciendo clic izquierdo** en las pantallas del menú, se abrirá una instancia ficticia de ellas para que puedas personalizarlas con calma.

Por ejemplo, al unirte a un mundo o servidor, hay al menos dos pantallas que aparecerán durante la carga:

- Pantalla de carga del nivel (también conocida como Pantalla de carga del mundo)
- Pantalla genérica de mensaje de tierra (también conocida como Pantalla de mensaje de tierra)

> [!WARNING]
> **Importante:** La "Pantalla de carga del mundo" no es lo mismo que la "Pantalla de carga del juego" (también conocida como Pantalla de inicio o Pantalla de recarga de recursos). La "Pantalla de carga del juego" se puede personalizar con **Drippy Loading Screen**, que es un complemento para FancyMenu.
