# Icono y título de la ventana

FancyMenu te permite cambiar el icono y el título de la ventana de Minecraft.

![window_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/7ec0cf75-c79e-4398-b2e4-331c8fbae8b1)

# Icono personalizado

Para establecer un icono personalizado, abre [**Personalizaciones globales**](/global-customizations) desde **Personalización -> Personalizaciones globales**.

![window_icon](https://github.com/Keksuccino/FancyMenu/assets/35544624/6d826bd5-3db0-4f1b-918d-8ccbe944b5c0)

- Los iconos deben ser archivos **PNG** (y **ICNS para macOS**).
- Los iconos deben tener al menos **1 píxel transparente** para que no se vean defectuosos (error de MC/LWJGL).
- Debes seleccionar archivos válidos para las 3 versiones del icono (16x16, 32x32 y macOS) para activar la opción del icono personalizado.

> [!CAUTION]
> **Insistimos**: Los iconos deben tener al menos **1 píxel transparente** para que no se vean defectuosos (error de MC/LWJGL). ¡El icono se verá mal si no tiene al menos un píxel totalmente transparente!


# Título personalizado

Para establecer un título personalizado, abre [**Personalizaciones globales**](/global-customizations) desde **Personalización -> Personalizaciones globales**.
