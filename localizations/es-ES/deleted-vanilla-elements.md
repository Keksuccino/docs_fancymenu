# Eliminación de elementos Vanilla

Puedes ocultar todos los elementos predeterminados/Vanilla (incluidos algunos elementos del mod) que sean visibles en el editor de diseño. Si están visibles, simplemente haz **clic derecho** sobre ellos y haz clic en **Eliminar**.


# Volver a mostrar elementos Vanilla eliminados

Para volver a hacer visibles elementos Vanilla eliminados/ocultos, como botones, logotipos u otros tipos de elementos, solo tienes que abrir el diseño en el que los eliminaste y luego **ir a la barra de menú -> Elemento -> Elementos Vanilla eliminados** y hacer **clic izquierdo** en el/los elemento(s) que quieras volver a hacer visibles.

Si los elementos eliminados no aparecen en la lista del menú, tienes abierto el diseño incorrecto y necesitas encontrar aquel en el que los eliminaste.
