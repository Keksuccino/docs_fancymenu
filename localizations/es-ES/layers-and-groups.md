# Capas y grupos

Abre el widget Capas a través de **Ventana -> Widgets del editor -> Capas**.

# Orden de las capas

Arrastra las capas en la lista para cambiar su orden de renderizado. También puedes hacer clic con el botón derecho en un elemento y usar **Subir una capa** o **Bajar una capa**.

Los elementos [Player Entity](./elements#player-entity) y [Item](./elements#item) pueden tener límites de renderizado que impiden el orden normal de las capas.

# Grupos

Los grupos organizan capas relacionadas y te permiten moverlas u ocultarlas juntas.

- Crear y renombrar grupos.
- Renombrar capas individuales.
- Arrastrar capas dentro o fuera de grupos.
- Arrastrar un grupo para mover todas sus capas en el orden.
- Contraer o expandir un grupo.
- Mostrar u ocultar todas las capas de un grupo.
- Eliminar un grupo sin borrar sus capas.

La pertenencia a grupos y el estado contraído se guardan con el diseño.
