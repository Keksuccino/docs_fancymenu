# Imágenes

FancyMenu muestra imágenes en muchos lugares, como elementos de imagen, fondos de menús y texturas de botones. Admite estos archivos:

- PNG (`.png`): la mejor opción para imágenes estáticas con transparencia.
- JPEG (`.jpg` o `.jpeg`): archivos más pequeños para fotografías, pero sin transparencia.
- APNG (`.apng`) y GIF (`.gif`): imágenes animadas. Consulta [Animaciones](/animations).

FancyMenu distingue los tipos de imagen por su extensión, así que el nombre del archivo debe terminar con la extensión correcta.

> [!TIP]
> FancyMenu usa las imágenes tal cual. Para que se vean nítidas y se carguen rápido, consulta [Optimizar texturas](/optimizing-textures).

# Convertir imágenes

FancyMenu no admite otros formatos, como WebP. Primero tendrás que convertirlos, por ejemplo, en línea:

- [De WebP a PNG](https://convertio.co/webp-png/)
- [De JPEG a PNG](https://jpg2png.com/)
- [De PNG a JPEG](https://www.freeconvert.com/png-to-jpeg): reduce el tamaño de las imágenes grandes, pero elimina la transparencia.

Para crear o convertir animaciones, consulta [Crear animaciones](/animations#making-animations).
