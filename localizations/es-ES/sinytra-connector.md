# Sinytra Connector

FancyMenu no ofrece compatibilidad oficial con [Sinytra Connector](https://modrinth.com/mod/connector) y **no se recomienda usar este mod** (en mi opinión).

[Sinytra Connector](https://modrinth.com/mod/connector) no es un mod normal. Permite combinar mods de distintos cargadores en una misma instancia, lo que es una clara receta para la **inestabilidad y los fallos**.
No puedes esperar tener una instancia de Minecraft estable cuando uses este mod.

Si estás sufriendo fallos y tienes este mod instalado, prueba primero a **eliminar [Sinytra Connector](https://modrinth.com/mod/connector)** y comprueba si eso soluciona el problema.
