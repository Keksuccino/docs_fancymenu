# Escala de la interfaz de usuario de FancyMenu

La interfaz de usuario de FancyMenu (como la barra de menús y los menús contextuales) usa una escala independiente que no está vinculada a la escala normal de la interfaz gráfica de Minecraft.

En caso de que la interfaz de usuario de FancyMenu se vea demasiado pequeña o demasiado grande, puedes cambiar la escala de la interfaz a través de **barra de menús -> Personalización -> Ajustes -> Interfaz de usuario de FancyMenu**.

Cuando la escala de la interfaz está configurada en **Auto**, la escala automática mínima es `1.25`. Puedes seleccionar manualmente la escala `1`.

La única excepción a esto son las pantallas completas añadidas por FancyMenu, como la pantalla para gestionar variables o el editor de diseños. Estas pantallas, en la mayoría de los casos, usan la escala normal de la interfaz gráfica de Minecraft, pero es posible que algunas pantallas usen una lógica de autoescalado diferente para mostrarse automáticamente a una escala menor cuando la ventana, de otro modo, sería demasiado pequeña para contener todo el contenido de la pantalla.
