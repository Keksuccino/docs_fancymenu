# Identificadores de elementos

Cada elemento de FancyMenu tiene un identificador único que se le aplica automáticamente al crearlo.

Estos identificadores se usan, bueno, para identificar el elemento, de modo que otras partes de FancyMenu, como los marcadores de posición, las acciones y los requisitos de carga, puedan comunicarse con el elemento.

# Obtener el identificador de los elementos

Para obtener el identificador de un elemento, porque lo necesitas en otro sitio, solo tienes que hacer **clic derecho** en el elemento del editor y hacer clic en **Copiar identificador del elemento**. Al hacerlo, se copiará el identificador del elemento al portapapeles, para que puedas pegarlo fácilmente donde lo necesites.
