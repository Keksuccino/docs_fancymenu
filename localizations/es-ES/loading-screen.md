# Personalizar la pantalla de carga

**FancyMenu no puede personalizar por sí solo la pantalla de carga/de bienvenida de Minecraft**. Precisamente por eso tenemos el complemento [Drippy Loading Screen](https://www.curseforge.com/minecraft/mc-mods/drippy-loading-screen) (también disponible [aquí](https://modrinth.com/mod/drippy-loading-screen) en Modrinth).

# Drippy Loading Screen

Si acabas de instalar el complemento Drippy Loading Screen por primera vez, solo tienes que hacer clic en la pequeña pestaña resaltada abajo para entrar en la pantalla desde la que luego podrás [usar el editor de FancyMenu](https://docs.fancymenu.net) para personalizar la pantalla de carga.
