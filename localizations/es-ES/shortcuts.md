# Atajos y combinaciones de teclas

**Modificador de atajos:** usa `Ctrl` en Windows/Linux y `Command` en macOS cuando esté disponible.

# Editor de diseño

| Atajo | Acción |
|---|---|
| `Ctrl/Command + clic izquierdo` | Seleccionar o arrastrar varios elementos |
| `Shift + redimensionar` | Mantener la proporción del elemento |
| Teclas de flecha | Mover con precisión los elementos seleccionados |
| `Ctrl/Command + A` | Seleccionar todos los elementos |
| `Ctrl/Command + C` | Copiar los elementos seleccionados |
| `Ctrl/Command + V` | Pegar los elementos copiados, incluso en otro diseño |
| `Ctrl/Command + S` | Guardar el diseño |
| `Ctrl/Command + Z` | Deshacer |
| `Ctrl/Command + Y` | Rehacer |
| `Ctrl/Command + G` | Activar o desactivar la cuadrícula |
| `O` | Mostrar los puntos de anclaje mientras se mantiene pulsada cuando **Ventana -> Visibilidad de la superposición de anclajes** está configurado en **Mostrar al pulsar una tecla** |
| `Delete` | Eliminar los elementos seleccionados |

# Editor de texto

| Atajo | Acción |
|---|---|
| `Ctrl/Command + C` | Copiar el texto seleccionado |
| `Ctrl/Command + V` | Pegar texto |
| `Ctrl/Command + Z` | Deshacer |
| `Ctrl/Command + Y` | Rehacer |
| `Ctrl/Command + A` | Seleccionar todo el texto |
| `Ctrl/Command + D` | Duplicar la línea actual |
| `Ctrl/Command + U` | Cortar el texto seleccionado |
| `Alt + Flecha arriba/abajo` | Mover la línea actual |
| `Ctrl/Command + Inicio/Fin` | Ir al inicio o al final del texto |
| `Ctrl/Command + G` | Abrir **Ir a línea** |
| `Ctrl/Command + S` | Confirmar el editor |
| `Shift + teclas de flecha` | Ampliar la selección de texto |
| Teclas de flecha | Mover el cursor |

# Atajos globales del menú

Estos atajos usan exactamente la combinación `Ctrl + Alt`:

| Atajo | Acción |
|---|---|
| `Ctrl + Alt + L` | Abrir el editor de diseño con el último diseño editado |
| `Ctrl + Alt + C` | Activar o desactivar la barra de menú de FancyMenu |
| `Ctrl + Alt + R` | Recargar FancyMenu y sus recursos/cachés administrados |
| `Ctrl + Alt + D` | Activar o desactivar la superposición de depuración de FancyMenu |

# Ventanas de edición

Las ventanas de edición de FancyMenu admiten la navegación con el teclado mediante las teclas de flecha y `Enter`. Muchas también usan `Ctrl/Command + S` para **Hecho** y `Escape` para **Cancelar**.

Los editores de Script de acción, Requisitos y Variables también admiten menús contextuales con clic derecho, búsqueda, deshacer/rehacer y navegación por listas con el teclado.
