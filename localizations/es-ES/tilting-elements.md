# Inclinación de elementos

La mayoría de los elementos se pueden inclinar vertical y horizontalmente.

Selecciona un elemento en el editor de diseño. Si la inclinación es compatible, aparecerán a su alrededor guías verticales y horizontales con tiradores. Arrastra un tirador para inclinar el elemento en ese eje.

Si el elemento no muestra líneas con tiradores, no se puede inclinar.

# Avanzado

También puedes hacer clic con el botón derecho en el elemento para establecer manualmente los valores de inclinación mediante una entrada de texto directa. Esta entrada directa admite [placeholders](/placeholders), por lo que puedes cambiar dinámicamente la inclinación del elemento al combinarla con placeholders para obtener valores de variables de FancyMenu o algo similar.

# Botones, deslizadores y otros elementos interactivos

La inclinación es solo visual para los elementos interactivos. Un botón inclinado seguirá aceptando clics dentro de su área original, sin inclinar.
