# Arrastrador

El elemento Arrastrador es un elemento de FancyMenu que te permite hacer que los menús sean interactivos de una forma bastante poco habitual. El Arrastrador es un elemento que se puede arrastrar con el ratón FUERA del editor, lo que significa que los usuarios pueden básicamente agarrar el elemento y moverlo libremente.

Esto está muy bien y todo eso, pero mover un elemento que no hace nada más es bastante inútil, ¿no? Pues no, porque puedes adjuntar otros elementos a él estableciendo el elemento Arrastrador como punto de anclaje para los demás elementos que deban moverse con el Arrastrador.

El desplazamiento de posición de los elementos Arrastrador es persistente y se guarda entre reinicios del juego, lo que básicamente significa que, cuando un usuario mueve el Arrastrador, este permanece en esa posición "personalizada", incluso al reiniciar el juego.

El elemento Arrastrador solo es visible en el editor e invisible fuera de él, así que asegúrate de usar otro elemento como su "cuerpo" si quieres que el usuario vea dónde está el área arrastrable.
