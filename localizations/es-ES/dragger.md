# Arrastrador

Un Arrastrador es un elemento invisible que los usuarios pueden mover con el ratón fuera del editor de diseño. Puedes anclarle otros elementos para que se muevan junto con el Arrastrador.

1. Añade un [**elemento Arrastrador**](./elements#dragger).
2. Ancla al Arrastrador los elementos que deban moverse.
3. Ajusta el tamaño y la posición del Arrastrador sobre el área visible que los usuarios deban arrastrar.

Activa **Guardar desplazamiento del arrastre del usuario** para conservar la posición arrastrada entre aperturas de pantalla y reinicios del juego. Desactívalo cuando el desplazamiento deba restablecerse.

El Arrastrador solo es visible en el editor. Usa una [Imagen](./elements#image), [Forma](./elements#rectangle-shape) u otro elemento anclado como su cuerpo visible.
