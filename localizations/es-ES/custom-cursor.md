# Cursor de ratón personalizado

FancyMenu te permite establecer un cursor de ratón personalizado por pantalla.

Para hacerlo, simplemente añade un nuevo elemento **Cursor** a un diseño y haz clic derecho sobre él para establecer una textura de cursor.

Si quieres que el cursor personalizado aparezca en todas las pantallas, deberías usar un **diseño universal**.
