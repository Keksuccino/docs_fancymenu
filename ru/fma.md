# Анимации

Файлы FMA — это специальные анимированные текстурные файлы, созданные для FancyMenu.  
Они практически идентичны APNG, но намного более оптимизированы для FancyMenu.

> Эта функция доступна только в FancyMenu версии 3.2.0+!  
{.is-warning}

# Создание FMA

Создать файл FMA так же просто, как создать ZIP-файл! В основном потому, что под капотом это _и есть_ ZIP-файл.

## Расширения файлов

Чтобы следовать этой документации, вам нужно видеть расширения файлов, поэтому убедитесь, что **ВКЛЮЧЕНЫ РАСШИРЕНИЯ ФАЙЛОВ** перед началом.

В Windows это делается следующим образом: откройте любую папку, затем нажмите стрелку в правом верхнем углу, чтобы расширить меню.

Затем перейдите на вкладку **Вид** и включите **Расширения имен файлов**.

## Подготовка

Начнем с создания новой папки для содержимого файла FMA.  
В этом примере назовем папку `fancymenu_animation`.

В этой папке создайте еще две папки. Первая папка **обязательно** должна называться `frames`, а вторая — `intro_frames`.

Теперь в этой же папке создайте новый TXT-файл и переименуйте его в `metadata.json`.  
Убедитесь, что файл больше не является TXT-файлом. Вы **обязаны** изменить его расширение на `json`.

Теперь у вас должна быть папка `fancymenu_animation`, в которой находятся папки `frames`, `intro_frames` и JSON-файл `metadata.json`.

## Метаданные JSON

Этот файл сообщает FancyMenu, как работать с текстурой FMA.  
Он содержит информацию, такую как время кадров (сколько времени кадр отображается) и количество повторений.

Откройте файл `metadata.json` в текстовом редакторе.

Скопируйте этот текст в файл:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
  },
  "custom_frame_times_intro": {
  }
}
```

Это базовый шаблон того, как должен выглядеть файл.  
Теперь вы можете настроить его по своему усмотрению.

### `loop_count`

Управляет количеством повторений текстуры (перезапуском анимации).  

Значение `0` означает, что анимация будет повторяться бесконечно и **никогда не остановится**.  

Любое значение больше `0` указывает, сколько раз текстура будет проигрываться. Например, `1` означает, что текстура проиграется один раз, затем остановится на последнем кадре, `2` — два раза и так далее.

### `frame_time`

Общее время кадра в **миллисекундах** для кадров анимации.  
Время кадра указывает, как долго кадр будет отображаться перед переходом к следующему.

### `frame_time_intro`

То же самое, что и `frame_time`, но для **вводных** кадров вашей анимации.  
Вводные кадры — это **опция**, о которой вы узнаете позже.

### `custom_frame_times`

**Опционально**. Используется для задания индивидуального времени отображения определенных (не вводных) кадров.  

Пример: если вы хотите, чтобы все кадры отображались по `41` миллисекунде, но первые два кадра — по `5000` миллисекунд, настройте это так:

```json
{
  "loop_count": 0,
  "frame_time": 41,
  "frame_time_intro": 41,
  "custom_frame_times": {
    0: 5000,
    1: 5000
  },
  "custom_frame_times_intro": {
  }
}
```

Кадры отсчитываются с нуля: первый кадр — `0`, второй — `1` и так далее.

### `custom_frame_times_intro`

Аналогично `custom_frame_times`, но для вводных кадров.  

Сохраните и закройте текстовый редактор.

## Кадры

> Рекомендуется использовать не более **200 кадров** с максимальным разрешением **1080p** для одной анимации, так как анимации требуют много памяти и не являются видео. Они предназначены для коротких зацикленных анимаций, а не для воспроизведения полного видео с частотой 24 FPS.  
{.is-danger}

Кадры анимации должны быть помещены в папку `frames`.

Кадры должны быть **PNG-ФАЙЛАМИ**! Поддерживаются **только PNG**!  

Каждый кадр **обязательно** должен называться номером кадра и иметь расширение `.png`.  
Например, `0.png`, `1.png`, `2.png` и т. д.

Чтобы извлечь кадры из видео, пожалуйста, ознакомьтесь с [этой страницей документации](/ru/ffmpeg-frames).

## Вводные кадры (Intro)

Эта функция — **ОПЦИОНАЛЬНАЯ**.  
Вводные кадры проигрываются **перед** основными и не зацикливаются.

Кадры вводной части размещаются в папке `intro_frames` и работают так же, как обычные кадры.

## Упаковка файла FMA

После подготовки содержимого в папке `fancymenu_animation` упакуйте его в ZIP-файл, а затем переименуйте его в `.fma`.  

Теперь ваш файл FMA готов!
