# Панель меню

Одной из первых вещей, которые вы заметите при запуске игры, будет **панель меню** в верхней части каждого экрана.

**Панель меню** — это точка входа ко всем функциям FancyMenu, таким как **создание макетов** для настройки меню, изменение **заголовка окна и иконки** и многое другое.

![menu_bar](https://github.com/Keksuccino/FancyMenu/assets/35544624/7100521c-8893-4eea-b0c1-1f02f4025ed7)

# Ваш первый макет

Поскольку вы, вероятно, хотите настроить меню Minecraft, давайте поговорим о **макетах**!

Макеты — это как слои настройки для меню, которые позволяют добавлять новые элементы и настраивать существующие.

Чтобы создать новый макет для **конкретного меню**:
1. Откройте меню, для которого вы хотите создать макет (например, главный экран).
2. Перейдите во вкладку **Customization** на **панели меню**.

По умолчанию настройки отключены для всех меню, и вам нужно включить их для каждого меню, которое вы хотите настроить.  
Для этого щелкните запись **"Current Screen Customization: Disabled"**, чтобы переключить её в состояние **Enabled**.

![toggle_customizations](https://github.com/Keksuccino/FancyMenu/assets/35544624/1654b7b1-cbab-4321-908c-7e3bf3239e75)

Затем нажмите **Layouts -> New -> For Current Screen**.

Откроется **редактор макета**, где вы можете добавлять элементы в макет и настраивать элементы Minecraft и модов (например, кнопки).

![new_layout_current](https://github.com/Keksuccino/FancyMenu/assets/35544624/065c3dd7-b3df-4501-b721-118ed819a93f)

## Редактирование макета

Большинство параметров настройки доступны через **щелчок правой кнопкой мыши по фону редактора**.  
Это откроет контекстное меню с множеством опций, например, настройкой **фона меню** или **добавлением элементов** в макет.

## Добавление элементов в макеты

Чтобы добавить новый элемент в макет, **щелкните правой кнопкой мыши** по фону редактора.

В открывшемся контекстном меню выберите **New Element** и выберите один из множества типов элементов.

![add_element](https://github.com/Keksuccino/FancyMenu/assets/35544624/865a66c5-76a6-404d-b746-d57802b1c12f)

## Настройка элементов

Чтобы настроить элемент, **щелкните по нему правой кнопкой мыши**.  
Это откроет контекстное меню со всеми параметрами настройки для данного типа элемента.

![element_customization](https://github.com/Keksuccino/FancyMenu/assets/35544624/cfa3c357-d6be-4ed9-a6f0-a63f751e545a)

## Позиционирование элементов

Каждый элемент в FancyMenu привязан к **точке привязки**.

Точки привязки используются для расчета положения элемента и предотвращают наложение элементов друг на друга, выход за границы экрана или перемещение в неправильное место при изменении размера окна.

По умолчанию элементы связаны с точкой привязки **"Center of Screen"** (центр экрана).  
Если элемент находится на 2 см от центра экрана, он останется на этом расстоянии, независимо от размера окна.

![anchor_points](https://github.com/Keksuccino/FancyMenu/assets/35544624/25bff930-0b52-4d76-b0e9-3e1cbcf3c20e)

## Сохранение работы

Не забудьте сохранить вашу работу!

Это можно сделать, нажав **CTRL + S** или выбрав **Layout -> Save**.

![save_your_work](https://github.com/Keksuccino/FancyMenu/assets/35544624/93436ec9-343e-4d10-85d9-de8982712c4a)
