# Как извлечь кадры из видео с помощью FFmpeg

*Эта страница была частично сгенерирована ИИ ChatGPT.*

FFmpeg — это бесплатный инструмент, который помогает работать с видео- и аудиофайлами. Одной из полезных функций является возможность извлекать кадры из видео, например MP4-файла. Вот пошаговая инструкция, как это сделать.

MP4 будет использоваться в приведенных ниже командах, но FFmpeg также поддерживает другие форматы видео, такие как AVI, MOV, MKV и MPEG.

# Что потребуется

Перед началом убедитесь, что у вас есть:

1. **Установленный FFmpeg**:

   - Скачайте FFmpeg с официального [сайта FFmpeg](https://ffmpeg.org/download.html). Убедитесь, что вы скачали "полную" версию.
   - Следуйте инструкциям по установке для вашей операционной системы.

2. **Доступ к командной строке**:

   - Используйте терминал (Linux/macOS) или командную строку (Windows) для выполнения команд FFmpeg.

3. **Видео файл**:

   - Подготовьте MP4, AVI, MOV, MKV или MPEG файл для работы.

# Перед началом

Перед выполнением команд подготовьте следующее:

## Включите отображение расширений файлов

- Важно видеть расширения файлов, такие как `.mp4` или `.avi`, чтобы переименовать видеофайл.

  - **В Windows**:

    - Откройте Проводник.
    - Нажмите на вкладку "Вид" в верхней части окна.
    - Установите галочку "Расширения имен файлов".

  - **В macOS**:

    - Откройте Finder.
    - Нажмите "Finder" в строке меню и выберите "Настройки".
    - Перейдите на вкладку "Дополнительно" и установите галочку "Показывать все расширения имен файлов".

## Создайте папку для сохранения кадров

- Создайте папку с именем `output_frames` в директории, где находится исполняемый файл FFmpeg. В эту папку будут сохраняться извлеченные кадры.

## Подготовьте видеофайл

- Поместите видеофайл, из которого вы хотите извлечь кадры, в ту же директорию, что и исполняемый файл FFmpeg.
- Переименуйте видеофайл в `input` с соответствующим расширением (например, `input.mp4`, `input.avi` и т. д.). Это гарантирует, что команды ниже будут работать без изменений.

# Как открыть FFmpeg

Перед использованием FFmpeg его нужно запустить через командную строку. Вот пошаговая инструкция для Windows и macOS.

## В Windows:

1. **Откройте командную строку**:
   - Нажмите одновременно клавиши `Windows` и `R`, чтобы открыть окно "Выполнить".
   - Введите `cmd` и нажмите Enter. Это откроет командную строку.

2. **Перейдите в папку с FFmpeg**:
   - Используйте команду `cd`, чтобы перейти в папку, где вы сохранили FFmpeg.
   - Например, если FFmpeg находится в папке `ffmpeg-2024\bin` на вашем рабочем столе, введите:
     ```bash
     cd C:\Users\ВашеИмяПользователя\Desktop\ffmpeg-2024\bin
     ```
     (Замените "ВашеИмяПользователя" на ваше фактическое имя пользователя в системе.)

3. **Проверьте работу FFmpeg**:
   - Чтобы убедиться, что FFmpeg работает, введите:
     ```bash
     ffmpeg -version
     ```
   - Если все в порядке, вы увидите информацию о FFmpeg.

## В macOS:

1. **Откройте терминал**:
   - Нажмите одновременно клавиши `Command` и `Пробел`, чтобы открыть Spotlight Search.
   - Введите `Terminal` и нажмите Enter для открытия терминала.

2. **Перейдите в папку с FFmpeg**:
   - Используйте команду `cd`, чтобы перейти в папку, где вы сохранили FFmpeg.
   - Например, если FFmpeg находится в папке `Загрузки`, введите:
     ```bash
     cd ~/Downloads/ffmpeg-2024/bin
     ```

3. **Проверьте работу FFmpeg**:
   - Чтобы убедиться, что FFmpeg готов, введите:
     ```bash
     ./ffmpeg -version
     ```
   - Если все настроено правильно, вы увидите детали о программе.

# Как сохранить все кадры

Чтобы сохранить все кадры из видео, используйте следующую команду:

```bash
ffmpeg -i input.mp4 output_frames/%d.png
```

## Что это значит:

- `-i input.mp4`: Ваш исходный видеофайл. Он должен находиться в той же папке, что и исполняемый файл FFmpeg. Убедитесь, что `input.mp4` заменен на правильное имя и расширение файла.
- `output_frames/%d.png`: Формат, в котором будут сохраняться кадры:
  - `output_frames/`: Все кадры сохранятся в папке `output_frames`.
  - `%d.png`: Кадры будут называться числами, например `1.png`, `2.png` и так далее.

# Сохранение кадров через определенные интервалы

Если вам не нужны все кадры, можно сохранять один кадр каждую секунду (или с другими интервалами). Используйте эту команду:

```bash
ffmpeg -i input.mp4 -vf "fps=1" output_frames/%d.png
```

## Что это значит:

- `-i input.mp4`: Исходный видеофайл.
- `-vf "fps=1"`: Сохраняет один кадр в секунду. Измените `1` на другое значение для более редких или частых интервалов (например, `fps=0.5` сохранит один кадр каждые две секунды, а `fps=2` — два кадра в секунду).
- `output_frames/%d.png`: Кадры сохранятся в папке `output_frames`.

# Изменение размера и качества кадров

Вы также можете настроить размер и качество сохраняемых кадров. Вот как это сделать:

```bash
ffmpeg -i input.mp4 -vf "scale=1280:720" -q:v 2 output_frames/%d.png
```

## Что это значит:

- `-vf "scale=1280:720"`: Изменяет размер кадров на 1280x720 пикселей.
- `-q:v 2`: Устанавливает качество изображения (1 — лучшее качество, чем больше число, тем ниже качество).
- `output_frames/%d.png`: Кадры сохранятся в папке `output_frames`.

# Полезные советы

1. **Экономьте место**:
   - Если видео длинное, сохраняйте кадры с интервалами вместо всех подряд. Это особенно полезно, если вы используете их как анимацию FMA в FancyMenu.

2. **Узнайте больше**:
   - Введите `ffmpeg -h` в терминале, чтобы увидеть все возможности FFmpeg.
