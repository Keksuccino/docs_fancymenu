# Rotating Elements

FancyMenu does NOT directly support rotating elements, because this is a very difficult thing to implement, eapecially for interactable elements.

As a compensation, _some_ elements have special options in their right-click menu to control things like the direction they face to and similar things that could be seen as an alternative to rotation.

The **Progress Bar** element for example has options to set the direction the bar should fill to (to the top, right, bottom, left).

The only element with actual rotation support is the **Splash Text** element. This one lets you set a text rotation in degrees.
