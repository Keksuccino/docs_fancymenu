# Layout Templates

If you want to download design templates for FancyMenu, or one of its addons, like SpiffyHUD or Drippy Loading Screen, the best place to check is the [`#layout-templates`](https://discord.com/channels/704163135787106365/1234093433795383316) channel in the [Kekscord Discord server](https://discord.gg/rhayah27GC) (Keksuccino's official Discord server for mod support). This channel contains full FancyMenu setups made by the community, with download links for all of them.

All template posts in there follow the same pattern. They should all have a download link to a full FancyMenu setup, either as profile file (`.fmp`) or as `fancymenu` folder.

> [!CAUTION]
> Community templates can run actions. Import them only from sources you trust.

# Installing Templates

Templates are complete FancyMenu setups and very complex most of the time, so it is not recommended to try to merge a template with your existing setup. Add it as its own [profile](./profiles) instead:

- **`.fmp` file:** Open **menu bar -> Customization -> Profiles** and [import](./profiles#importing) the file, for example by dragging it onto the window.
- **`fancymenu` folder:** [Add the folder as a profile](./profiles#adding-setup-folders).

Then select the template in the Profiles window and click **Load Profile**. Your current setup stays available as its own profile, so you can always switch back.

# Editing Templates or Using Them For Projects

Most templates in the channel allow you to edit them, and even using them in your own projects, like modpacks, but it is very important that you **check the template post for what you are allowed to do with it**!

Not all of them give you permission to do everything.
