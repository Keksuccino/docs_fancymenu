# Images

FancyMenu shows images in many places, like Image elements, menu backgrounds and button textures. It supports these files:

- PNG (`.png`): the best choice for still images, with transparency.
- JPEG (`.jpg` or `.jpeg`): smaller files for photos, but without transparency.
- APNG (`.apng`) and GIF (`.gif`): animated images. See [Animations](./fma).

FancyMenu tells image types apart by their file extension, so the file name has to end with the right one.

> [!TIP]
> FancyMenu uses your images exactly as they are. To keep them sharp and fast, see [Optimizing Textures](./optimizing-textures).

# Converting Images

Other formats, like WebP, don't work in FancyMenu. Convert them first, for example online:

- [WebP to PNG](https://convertio.co/webp-png/)
- [JPEG to PNG](https://jpg2png.com/)
- [PNG to JPEG](https://www.freeconvert.com/png-to-jpeg): makes big images smaller, but removes their transparency.

To make or convert animations, see [Making Animations](./fma#making-animations).
