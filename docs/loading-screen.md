# Customizing The Loading Screen

**FancyMenu cannot customize Minecraft's loading/splash screen alone**. That is exactly why we have the [Drippy Loading Screen](https://www.curseforge.com/minecraft/mc-mods/drippy-loading-screen) add-on (Find it [here](https://modrinth.com/mod/drippy-loading-screen) on Modrinth too).

# Drippy Loading Screen

If you've just installed the Drippy Loading Screen add-on for the very first time, you just have to click on the little tab highlighted below in order to enter the screen where you can then [use the FancyMenu editor](https://docs.fancymenu.net) for customizing the loading screen.
