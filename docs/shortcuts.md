# Shortcuts & Keybinds

**Shortcut modifier:** Use `Ctrl` on Windows/Linux and `Command` on macOS where supported.

# Layout Editor

| Shortcut | Action |
|---|---|
| `Ctrl/Command + left-click` | Select or drag multiple elements |
| `Shift + resize` | Preserve the element's aspect ratio |
| Arrow keys | Move selected elements precisely |
| `Ctrl/Command + A` | Select all elements |
| `Ctrl/Command + C` | Copy selected elements |
| `Ctrl/Command + V` | Paste copied elements, including into another layout |
| `Ctrl/Command + S` | Save the layout |
| `Ctrl/Command + Z` | Undo |
| `Ctrl/Command + Y` | Redo |
| `Ctrl/Command + G` | Toggle the grid |
| `O` | Show anchor points while held when **Window -> Anchor Overlay Visibility** is set to **Show On Key Press** |
| `Delete` | Delete selected elements |

# Text Editor

| Shortcut | Action |
|---|---|
| `Ctrl/Command + C` | Copy selected text |
| `Ctrl/Command + V` | Paste text |
| `Ctrl/Command + Z` | Undo |
| `Ctrl/Command + Y` | Redo |
| `Ctrl/Command + A` | Select all text |
| `Ctrl/Command + D` | Duplicate the current line |
| `Ctrl/Command + U` | Cut selected text |
| `Alt + Arrow Up/Down` | Move the current line |
| `Ctrl/Command + Home/End` | Move to the start or end of the text |
| `Ctrl/Command + G` | Open **Go To Line** |
| `Ctrl/Command + S` | Confirm the editor |
| `Shift + Arrow keys` | Extend the text selection |
| Arrow keys | Move the cursor |

# Global Menu Shortcuts

These shortcuts use the exact `Ctrl + Alt` combination:

| Shortcut | Action |
|---|---|
| `Ctrl + Alt + L` | Open the layout editor with the last edited layout |
| `Ctrl + Alt + C` | Toggle FancyMenu's menu bar |
| `Ctrl + Alt + R` | Reload FancyMenu and its managed resources/caches |
| `Ctrl + Alt + D` | Toggle FancyMenu's debug overlay |

# Editing Windows

FancyMenu editing windows support keyboard navigation with arrow keys and `Enter`. Many also use `Ctrl/Command + S` for **Done** and `Escape` for **Cancel**.

The Action Script, Requirements, and Variables editors also support right-click context menus, search, undo/redo, and keyboard list navigation.
